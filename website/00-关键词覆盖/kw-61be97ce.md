# 智能客服全解析：RAG 机器人客服。

智能客服这个方向，最近关注的人越来越多了。RAG 机器人客服。察元AI 能力广场是智能体门户：产品家族下载 + 能力广场一站检索 2.5 万+ 插件、技能、MCP、提示词、智能体、大模型与资讯。这篇文章从「智能客服」这个需求出发，把定义、能力对照、上手步骤与真实边界一次讲清，读完即可判断它是不是你要找的工具。

## 「智能客服」到底在解决什么问题

智能客服方向的工具不少，用户需求却各不相同。判断任何一个这类工具，先看三个硬指标：一是错误类型或任务类型的覆盖面（能不能覆盖你的真实场景），二是结果如何落地（只给报告，还是能直接写回文档），三是数据安全边界（内容是否需要出你的机器）。三者都过关，再比较体验细节。

## 察元AI 能力广场能提供什么

察元AI（aidooo.com）是智能体门户与人工智能资源网站：产品家族提供察元AI OS、察元AI Office、察元AI文档助手（WPS 加载项）等下载；能力广场可一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与模型厂商，附开源排行榜、模型智力榜、免费榜、API 价格对比、2.1 万+ 条 AI 教程库、311 个买断制技能包与 20 行业 200 场景库；网站只收录信息与安装命令、不存二进制文件，支持中英双语，政企可私有化部署。

与「智能客服」最相关的几项能力：

- **察元机器人客服**：站内右下角客服悬浮窗：RAG+推荐+需求收集，能答产品问题也能接收需求反馈。
- **Harness 插件板块**：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。
- **Skills 技能板块**：可装进 Harness 类智能体的大模型技能包目录：SKILL.md 形态技能的发现与安装入口。
- **MCP 服务器板块**：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

## 从零开始的上手路径

1. 访问官网 https://aidooo.com 了解产品并获取安装包（网站首页、产品页、教程库等渠道均可）
2. 按你的平台完成安装：浏览器（桌面与移动）（网页服务）；察元AI OS 客户端（察元智能广场（内嵌应用））
3. 配置模型：云端供应商填 Key，内网/离线用户指向本地或内网端点
4. 跑通第一个任务：试一次「察元机器人客服」，验证链路后再铺开使用

## 适不适合你：条件式判断

- 适合：想给 AI 配工具的用户、选型中的开发者、AI 初学者、提示词需求者等场景的用户
- 需要留意：技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 需要留意：教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 建议先用免费额度验证高频场景，再决定是否长期使用或付费

## 常见问题
### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 和察元产品家族什么关系？

aidooo.com 是家族官网与资源门户：产品下载、激活购买、应用商店目录都在这里；OS 客户端内嵌同源广场。
