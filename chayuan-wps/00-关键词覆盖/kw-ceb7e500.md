# 文档智能体一文讲透：是什么、怎么用、边界在哪

文档智能体这个方向，最近关注的人越来越多了。文档智能体的能力构成。察元AI文档助手是装进 WPS 文字的 AI 文档智能体：对话、审查、校对、脱密，改完直接写回正文。这篇文章从「文档智能体」这个需求出发，把定义、能力对照、上手步骤与真实边界一次讲清，读完即可判断它是不是你要找的工具。

## 「文档智能体」到底在解决什么问题

文档智能体方向的工具不少，用户需求却各不相同。判断任何一个这类工具，先看三个硬指标：一是错误类型或任务类型的覆盖面（能不能覆盖你的真实场景），二是结果如何落地（只给报告，还是能直接写回文档），三是数据安全边界（内容是否需要出你的机器）。三者都过关，再比较体验细节。

## 察元AI文档助手能提供什么

察元AI文档助手是一款 WPS 文字智能加载项（jsaddons 形态），在编辑器内提供「察元 AI 助理」与「察元 AI 编审」两个功能页签，用大模型完成文档对话、校对审查、表单填报与正文写回；同时内置本机 MCP 文档智能体服务（127.0.0.1:62588），可被 Claude Code、Codex、Cursor 等外部智能体直接调用读写本机 WPS 文档，支持离线/内网模型，文档与密钥不出本机。

与「文档智能体」最相关的几项能力：

- **应用内文档智能体**：对话框内的文档智能体车道：AgentLoop 自循环（最多 16 轮工具调用）、todo_write 任务清单（先列计划边做边勾）、三档写权限（变更前确认/自动执行/完全访问）、写前快照一键撤销、文档写锁（FIFO+OCC）与「声称核对」防谎报。
- **本机 MCP 文档智能体服务**：内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。
- **拼写与语法检查**：面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文批量审校前的初筛。
- **纠正拼写和语法**：与结构化校对互补的整段修正路径：直接产出改正后的全文或片段，适合确认无需逐条审阅、只想快速拿到干净稿的场景。

## 从零开始的上手路径

1. 访问官网 https://aidooo.com 了解产品并获取安装包（官网 aidooo.com、GitHub 仓库、Gitee 国内镜像、百度网盘等渠道均可）
2. 按你的平台完成安装：Windows（自解压 exe（约 35MB，带 .sha256 校验文件））；macOS（pkg 安装包（约 35MB））；Linux（deb 安装包（约 35MB））
3. 配置模型：云端供应商填 Key，内网/离线用户指向本地或内网端点
4. 跑通第一个任务：试一次「应用内文档智能体」，验证链路后再铺开使用

## 适不适合你：条件式判断

- 适合：机关文秘、法务/律师助理、招投标专员、研究生/科研人员等场景的用户
- 需要留意：校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型
- 需要留意：保密检查、AI 痕迹检查为辅助参考，不构成定密或定性结论
- 建议先用免费额度验证高频场景，再决定是否长期使用或付费

## 常见问题
### 必须会写提示词吗？

不必。常用能力已做成按钮与 4526 个领域助手；对话模式适合进阶用户自定义任务。

### 升级会丢配置吗？

不会。重跑安装器或一行命令 -Fetch 覆盖升级，模型配置、知识库凭据与规则文件保留在独立数据目录。

### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。
