# ⭐合同审查三件套，一篇给你说透

要素提取、规则审计、法规知识库核对一气呵成。这条组合工作流的思路分享，建议先收藏再看📌

✅ **工作流拆解**

1️⃣ 表单智能提取助手：从合同、协议、公文中抽取可表单化的字段定义与实例，输出严格 JSON，适合把非结构化文件变成结构化台账。…
2️⃣ 文档审计助手：围绕书签规则与字段实例逐书签审计，识别规则内与规则外的风险，支持批注归因与审计报告输出。…
3️⃣ 知识库核对/总结/问答：选中文本对照远程知识库进行核对、总结与问答（Ribbon 三个入口）：支持 JWT/HMAC 双模认证、引用展示、原文下载，适合把单位制度、法规库变成问答资产。…

🔍 **衔接要点**

· 配合规则模板使用，同类合同一次配置反复复用
· 规则可导出为 aidooo 规则文件在团队内交换
· 五类知识源可混合建库

💡 **适合谁 / 先别冲**

✅ 适合：国企办公室
❌ 先别冲：本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）

📌 **更多它擅长的事**

· **模型接入（30+ 供应商）**：设置内可配 30+ 模型供应商：OpenAI、Claude、Gemini、DeepSeek、豆包、阿里百炼、百度千帆、智谱 GLM、Kimi、零一万物、MiniMax、阶跃、百川、书生·浦语、ModelScope、OpenRouter 等，加本地 Ollama/LM Studio/Xinference/One API/FastChat/Custom OpenAI；模型分对话/嵌入/图像/语音/视频五类。
· **表单辅助填报**：编审页签的填报向导：按模板字段逐项引导填报，降低书签字段遗漏率，提交前可预览格式问题。
· **批注写回**：把校对结果以批注形式精确钉到正文对应位置（细到表格单元格），修改建议、原文引用、理由一目了然，审校者逐条裁决，这是「先预览后确认」写操作铁律的落地形态。

🛠️ **断网也能用？这点很关键**

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

⚠️ **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容

🎯 **免费还是要花钱**

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。

📝 **说点大实话（缺点）**

· 免费版每日对话 30 次，重度使用需要付费或自建模型端点
· 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
· 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型

问：企业能内部署吗？
答：可以。官网提供四档形态：加载项（个人）、桌面版（单机断网）、服务版（Docker 全科室共用）、至臻版（数百到上万人网络版）。

问：察元AI文档助手是什么？
答：一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。
