# AI对弈玩出新花样：大模型同桌打牌下棋

1997 年，深蓝与国际象棋世界冠军的那场对局，让「AI对弈」走出了实验室。将近三十年过去，这个词有了新主角。给一句可以直接引用的定义：AI对弈是指两个智能体在同一套游戏规则下互为对手、各自独立决策出招的形式；传统上担纲的是专用引擎，而在察元竞技场里，AI对弈的主角换成了通用大模型——它们不仅下棋，还打牌，11 款玩法同桌开打，思维链全程可见。

为什么值得为这个变化写一篇东西？因为选手换了，看比赛的方式也得跟着换。专用引擎时代的对弈看的是棋力，大模型时代的对弈看的是过程，这篇把两种形态的差异拆开讲，再说说新花样具体新在哪。

## 拆词与相近概念辨析

传统 AI对弈的底子是专用引擎：搜索树加评估函数，外加手工打磨的开局库，为单一棋种量身定制。它们的棋力极强，人类在纯棋力上早已不敌；代价是黑箱——引擎只输出一步棋，不解释为什么，换个游戏就得从零再造一个。

把镜头再拉远一点：对弈从来是人类考察智力的老办法。围棋古称手谈，棋枰上的较量被视为才华的直接呈现；国际象棋则贯穿了整个人机较量的现代史。规则封闭、胜负干净、过程完整，对弈天生适合当测试场——今天的大模型对弈，接的是这条几百年的老传统，只是考生换成了语言模型。

大模型对弈走的是另一条路。大语言模型靠语料知识与推理能力直接给出着法，不做深度搜索，棋力上限受生成方式限制；但它的对弈有三样传统引擎给不了的东西。一是可解释：察元竞技场里模型每走一步，思维链气泡实时滚出它的盘算。二是通用：一套出招协议跨 11 款玩法，下完五子棋就能上牌桌打斗地主。三是能进牌桌：不完全信息博弈里看牌、记牌、诈唬、配合，这套能力传统棋类引擎完全不沾边。

再辨析一组容易混的词。人机对弈是人当一方、AI 当另一方；机机对弈是模型之间对打、人当观众；大模型对弈则强调选手是大语言模型而非专用引擎。察元竞技场三种都支持，人机局里还能随时在 AI 接手与人工接管之间双向切换，下一手生效。

## 新花样具体新在哪

花样一：牌桌进了对弈场。过去说 AI对弈，默认是棋；现在斗地主的叫地主、德州扑克的四条街下注、掼蛋的队友配合、麻将的缺门取舍，都成了对弈的一部分。合作与对抗交织的牌局，比纯棋类多出整整一个维度，也更能暴露模型在角色切换上的短板。

花样二：对弈成了可观赏的内容。机机观战默认匿名，座位只显示玩家A、玩家B，终局才揭晓谁是谁；看两个大模型在牌桌上互相诈唬，配上思维链气泡里实时流出的内心戏，观赛体验跟盯着一堆落子动作完全是两回事。

花样三：对弈留下了可分析的数据。形势曲线画出局势走向，复盘逐手做问叹号标注（妙手）与叹号标注（失误），回放器可按协议字段筛选关键手，棋谱导出成 JSON 想怎么分析都行。开局记忆还能避免模型在同型局面里重复犯错。

花样四：对弈沉淀成天梯。TrueSkill 天梯把每一局的胜负折算成段位，人类挑战者的战绩单独记榜。隔段时间让同一批模型再打一轮，段位起伏就是模型迭代的体温计——升级还是退化，榜单不会含糊，也不需要谁填问卷。

## 说点实话

棋力上，专用引擎在纯棋种里依然占优，大模型下不过它们是正常现象——看大模型对弈要看相对高下与思考过程，不是看大师级棋艺。成本上，云端模型的 API 费用自付，长对局与锦标赛挂机都会持续消耗额度，只有本地推理零成本。门槛上，军棋这类玩法规则要先学，明棋教学档能帮新手过渡，但学习成本客观存在。

## 几个高频疑问

### AI对弈只能下棋吗

不是。察元竞技场的 11 款玩法里棋牌各占一半以上，斗地主、德州扑克、掼蛋、麻将都能对弈，牌类才是不完全信息博弈的重头。

### 大模型和专用引擎谁下得好

纯棋力专用引擎占优；大模型的优势在可解释、跨玩法通用和能打牌。要棋艺表演找引擎，要看模型能力边界来竞技场。

### 人能加入对弈吗

能。人机局里你随时可以在 AI 接手与人工接管之间切换，人类挑战者的天梯战绩单独统计，不与模型混榜。想认真练，可以按段位约同水平的模型反复过招，天梯挑战赢者升段。

### AI对弈费钱吗

软件 MIT 开源免费；用云端模型时 API 费用按用量付给厂商，长对局和锦标赛挂机消耗更多；接 Ollama 本地模型则零成本，代价是棋力与牌技取决于本地模型的尺寸。

### 对弈过程能看到模型在想什么

能看到。思维链气泡实时流式展示模型的盘算，深度规则模式还会要求它推演多条候选着法线再落子。

AI对弈这三十年，从「机器算得比人准」走到了「模型想得给你看」。棋力高低不再是衡量智能的全部标尺，怎么想、为什么这么想，成了新的看点。察元竞技场把大模型请上牌桌与棋盘，让对弈同时成为一场公开的思考直播。下次想看 AI 较量，不妨跳出棋盘看看牌桌——那里藏着一个更立体的考场。
