# 模型配置可一键写入五家：whisper本地部署概念与上手

whisper本地部署被搜得多，原因不难猜：语音识别这活儿天然涉及录音隐私，云端方案总让人心里打鼓。这篇讲清楚把它放到自己机器上跑的那条路，顺带把并发、路由这些容易被忽略的口径交底。

## 什么是whisper本地部署

whisper 是 OpenAI 开源的语音识别模型家族，按参数量分大小几档，本地跑主要吃内存。把whisper本地部署拆开看，指的是在自家机器上装好权重、接好转写链路这件事。落到产品上：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

口径来源是官方文档，版本对应关系见文末。

## whisper 在这套系统里的位置

语音记录的转写引擎就是 whisper 权重：录音进来先 VAD 切分、再逐段转写，贴顶长条边说边出字。权重装好后，对话、嵌入、重排、语音端点齐备；已经下载过 whisper 权重的机器可以按路径直接导入，零拷贝、不必重下。选档思路也简单：转写准确率要求高就上大档权重，机器吃紧就用小档，换档就是换一行配置的事。

## 启动加载这步会发生什么

权重下好后，模型会自动从「模型库」挪进上方「我的模型」。点「启动」，先见提示「已发起启动（后台预热）」，随后系统做内存预算预检、拉起引擎进程并做健康检查，大模型头一回加载可能要等十几秒。预检不过时错误写得很明白：「内存预算不足：加载需要约 XGB，当前预算 YGB 已被运行中的模型占用。请先在模型管理中卸载：<名单>」，或者「此机器内存不足以加载该模型…请选择更小的模型」。成功后行首亮起绿点（即运行中）；黄点表示「运行中·探针验证中」，探针还没确认，顶部计数随之加一。再点「测试」可以验证整条链路：通过显示「测试通过 · <耗时>ms」（嵌入模型附维度、对话模型附样例回复），失败则给出「关闭 测试失败 · <原因>」。

## 权重下载与行内管理速览

模型库里点行尾「下载 <体积>」（如「下载 1.6GB」）开始下载：进度条约 1.5 秒刷新一次，源站名与百分比实时可见；中途取消也不亏，断点保留、随时续传。某个源 404 或超时会自动换下一个重试：优先 ModelScope（含 API 通道），之后依次是 hf-mirror 的两个镜像与 aifasthub，HuggingFace 官方源整体垫底；全部失败时行内会给出具体错误，点「重试下载」接着来。

权重落库后，「我的模型」每行按钮（悬停有说明）：「停用」立即卸载并释放内存；「钉住」可豁免空闲自动卸载；「设置」里是省内存、均衡、性能三档启动参数加高级覆盖；「删除」带二次确认，删的是已下载权重，之后想用可重新下载。

## 并发上限与模型路由

- 转写并发：本地引擎档同时最多 4 路，厂商云端档 16 路，超出排队；本地模型多宠同发时也会在 4 路上限内排队
- 路由策略：自动模式本地优先，主强子弱的路由让润色翻译这类轻任务自动落本地小模型，省算力省钱
- 统一出口：本机 OpenAI 兼容出口（127.0.0.1:52581），智能体只配一个地址

这三条合起来读：本地档跑得动就少碰云端，跑不动再借云端扩并发，全程一个地址不变。

## 装机前的边界清单

- 8GB 内存的机器，对话模型同时只装一个，复杂任务受限明显
- 龙芯暂未适配；视频生成本地没有，由云端路由承接
- 要调用云端厂商模型，先备好自己的 API Key
- Docker 云桌面、跨终端互联这类进阶形态，动手量不小

把这几条对着自己的机器核一遍，再决定动不动手，比事后补救省心。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 部署路上的五个疑问

### 磁盘空间要留多少才够下权重？

系统会自动预检：模型体积 × 1.05 再加 200MB；不够时会报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 装的时候报架构不匹配怎么办？

终端跑一下 uname -m 看架构：aarch64 对应 arm64 包，x86_64 对应 x64 包；飞腾与鲲鹏设备都属于 arm64。

### Docker 起容器撞了端口怎么处理？

网页桌面默认端口是 52584，被占用就改 compose 端口映射；各服务端口有统一注册表，动之前先查占用。

### 语音权重下载完还要联网干活吗？

不用。转写由本机权重承担，录音不出机器；并发上限见前文「并发上限与模型路由」一节，本地档 4 路、云端档 16 路，超出排队。

### 模型权重和转写结果放在哪？

推理引擎（llama-server / whisper-server 等）随安装包分发，不用额外下载；权重走模型库管理，手工放置、与内置目录疑似同款的权重行会出现「认领」按钮，认领后即纳入管理。换机时数据目录整体拷走即可。

## 一句收束

whisper本地部署的账很好算：录音敏感就走本地，转写量大就看并发。把上文「并发上限与模型路由」里的数字代入自己的工作量，结论会自己浮出来。真机操作一遍比看十遍文章有用，这话对部署类话题尤其成立。
