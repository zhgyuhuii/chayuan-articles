**对战模式**
- 人机局：你 vs 大模型，中途「AI 接手 ↔ 人工接管」随时双向切换（下一手生效）
- 机机观战：两个/多个模型对打你旁观，默认匿名观战（座位显示玩家A/B/C/D，终局由对局引擎揭晓身份）；支持批量选模型
- 锦标赛：多模型循环赛自动排程、积分榜实时刷新，打完出冠军；支持单模型开局、控制合行
- 天梯挑战：按 TrueSkill 段位约战，赢者升段；人类挑战者战绩独立统计，不与模型混榜

**出招与容错（工程口径，写技术文用）**
- LLM 玩家统一出招协议 `{move, comment}`；强模型支持两段思考「分析：… 答案：{json}」（答案段内先行解析）；深度规则模式（DEEP_RULES）要求三段输出：分析（推演 3 条候选着法线，至少 1 条吃子线 1 条防守线，≤120 字）→ 结论（≤30 字）→ 答案 JSON
- 解析容错链：剥 <think> 思维链块 → 剥代码围栏 → 抽 {} → 截断补尾 → 空白规整 → 正则抽取 → 无 JSON 时全文扫「当前合法动作串」精确词命中（词边界防误配，取最靠文末命中）——只认合法清单成员，绝不产出非法串
- 429 限流自动退避；重试回喂；仍失败走启发式代走（能挡杀就挡、能吃就吃；麻将取缺门里价值最低的一张）；同一玩家代走计数超限判负——一个模型 API 抽风不会卡死整局
- 对局信息给模型的方式：着法/事件历史优先于棋盘图示，合法步清单显式附上，多人游戏附合作上下文
