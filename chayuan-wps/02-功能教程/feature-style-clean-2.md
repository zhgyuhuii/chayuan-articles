# 拆开看空行清理：扫描识别稿清理

空行清理这件事，值不值得专门学一篇，看一个细节就够：样式统一。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI文档助手。

## 这个功能到底解决什么问题

空行清理能做的事拆开就这几件：样式统一；一键执行，空行清理。对应的界面入口是样式治理与空行清理

先把定位立住，再看步骤。

## 样式治理与空行清理：从入口到完成

按最短路径验证一遍：

入口：顶部「察元AI助理」选项卡 ＞ 「文档批量」分组，三个大按钮从左到右依次为「清理未使用的样式」「统计已使用样式」「删除空白行」。

3. 「删除空白行」

1. 做什么：点「删除空白行」即执行，无确认弹窗。从文末往前逐段检查，段落内容去掉段落符、换行、制表符、空格（含不间断空格）后为空的整段删除；表格内部的段落全部跳过，不影响表格结构。
2. 看到什么：完成弹「已删除 N 个空白行」；没有空白行弹「文档中没有找到空白行」。

## 它的局限也要说清楚

边界先摆在桌面上：

- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 常见问题

### 清理未使用的样式，会不会把正文正在用的格式删乱？

不会。清单只收录「全部段落扫一遍后没有任何段落引用」的段落样式，正在使用的样式不进清单；勾选默认全选，但可以逐项取消勾选再清除。被清掉的样式没有任何段落在用，正文外观不变。

### 为什么有的样式明明没用却删不掉？

内置样式（如「正文」「标题 1」等程序内置项）受 WPS 保护，删除接口对其无效。代码会把这些计入失败并在完成提示里显示「有 X 个样式无法删除（可能为内置样式）。」，属正常现象。

### 统计表里页码看起来不对？

统计前段落数少于 10000 时会先重新分页再取页码；超过 10000 段的超大文档为性能跳过重新分页，页码按当前分页计算。改过内容后重新点一次「统计已使用样式」即可刷新。

### 「删除空白行」会把表格里用来占位的空段删掉吗？

不会。删除逻辑明确跳过表格内段落，只处理正文中的空段；表格行列数与结构不变。

## 更多操作细节

1. 「清理未使用的样式」

1. 在哪：点「清理未使用的样式」，弹出「未使用样式清理」窗口。
2. 看到什么：窗口打开即自动扫描，显示「正在扫描未使用的样式...」和进度「已扫描段落 X/Y」。
3. 做什么：扫描完成后列出所有未被任何段落使用的段落样式，页面提示「以下样式在文档中未被任何段落使用，可勾选后清除。」；每项前面有勾选框，默认全部勾选，顶部有「全选」框和「已选 N / M」计数；可逐项取消勾选保留个别样式。
4. 点「确定清除」（一项都没勾时按钮置灰；执行中显示「清除中...」）。
5. 看到什么：清除完成弹「已删除 N 个样式。」；若有删不掉的会追加「有 X 个样式无法删除（可能为内置样式）。」；清单清空后窗口自动关闭。一个未使用样式都没有时列表处显示「未发现未使用的样式」。不想清理时点「取消」或右上角「×」关闭窗口。

## 更多操作细节

2. 「统计已使用样式」

1. 在哪：点「统计已使用样式」，弹出「样式使用统计」窗口。
2. 看到什么：窗口打开即扫描，显示「正在统计样式...」和进度「已处理 X/Y 个段落 (N%)」；段落数少于 10000 时会先对文档重新分页再统计，保证页码准确。
3. 做什么：扫描完自动生成两列表格：「样式名称」「页码」。每个样式一行合并单元格，右侧列出它出现过的所有页（同一页去重、按页码升序），页码单元格显示「第 N 页」。
4. 想看某处：双击对应「第 N 页」单元格，正文会跳到该页并选中该样式的段落，窗口保持打开可继续跳（页码格悬停提示「双击跳转到第 N 页」）。
5. 看完点右下「关闭」。文档没有任何段落样式可统计时显示「文档中未找到使用的样式」。扫描期间你在正文里的光标选区会被临时保存、统计完成后自动恢复，不需要自己找回位置。

## 更多操作细节

验证

1. 「文档批量」分组三个按钮名称与本篇引号内文案一致。
2. 新建文档 ＞ 样式面板随意新建一个不用的段落样式 ＞ 点「清理未使用的样式」＞ 该样式出现在勾选清单中，点「确定清除」后弹「已删除 1 个样式。」，样式面板里它消失。
3. 在文档不同页用「标题 1」＞ 点「统计已使用样式」＞ 表格出现「标题 1」一行，页码列出对应页；双击页码格正文跳转选中。
4. 连敲几次回车制造空行 ＞ 点「删除空白行」＞ 弹「已删除 N 个空白行」，表格内空段保留。

## 补充答疑

### 清理/统计窗口一直显示「正在扫描」？

两份扫描都按批次逐段处理并显示「已扫描段落 X/Y」「已处理 X/Y 个段落 (N%)」，大文档需要等待；若弹出「当前没有打开任何文档」，先确认文档仍处于打开状态；「清理未使用的样式」失败显示「扫描失败：…」、「统计已使用样式」失败显示「加载样式统计失败：…」，重开窗口再试即可。

### 字符样式、表格样式为什么不在清单/统计表里？

两个窗口都只处理段落样式：「清理未使用的样式」扫描时直接跳过非段落类型，「统计已使用样式」统计的是各段落的段落样式。字符样式、表格样式、列表样式暂不在治理范围内，需在样式面板手工管理。

### 只含空格的段落会被删吗？全角空格呢？

半角空格、不间断空格、制表符与换行/段落符都在空白判定剔除范围内，只含这些的段落会按空白行删除；全角空格不在剔除范围，只含全角空格的段落不会被当作空白行删掉。
