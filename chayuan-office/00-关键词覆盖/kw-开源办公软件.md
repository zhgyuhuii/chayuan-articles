# 开源办公软件入门指南：天试用到期后会锁功能吗

开源办公软件这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI Office为例。

## 什么是开源办公软件

开源办公软件，先给一句能直接引用的定义：察元AI Office（Chayuan AI Office）是一款 Apache-2.0 开源的 AI 办公套件，把 docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器装进一个应用，AI 校对以批注锚定原文、修订追踪生成通用修订，Docs 端内置 4576 个领域助手，支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点，覆盖 Windows/macOS/Linux（含麒麟/UOS），本地优先、离线可用。

全部口径出自aidooo.com官方文档，版本对应关系见文末。

## 平台与形态

能跑在哪：Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；另有浏览器 SaaS 与 dsh 插件形态（五编辑器，无 HTML）。

## 在察元AI Office里落在哪

开源办公软件在察元AI Office里的落点是购买授权与试用：Apache-2.0 开源，90 天静默免费试用到期不锁功能（每日一次购买页加每 30 分钟温和提醒）；扫码到官网购买页下单，离线短序列号激活（Crockford base32，HMAC 绑定 16 位机器指纹，无需激活服务器）；同机察元AI OS 已激活则 Office 免激活。

为什么值得单独说：先免费用满 90 天，觉得值再买，功能永不锁。

## 最短上手路径

试一遍就明白：

第 1 步 · 查看授权状态

1. 菜单栏打开「激活」菜单：第一行是只读状态行——「免费体验中 · 剩 {n} 天」/「已激活 · 有效期至 {日期}」/「体验期已结束 · 购买后提醒消失」。
2. 点「购买 / 激活…」打开购买弹窗「察元AI Office · 购买授权」。同一弹窗也可由试用到期后的每日自动弹窗、或右下角提醒气泡的点击打开。

## 察元AI Office的能力地图

- 下载安装与首次启动：Windows 用 NSIS 安装器、macOS 用 dmg、Linux 有 deb、rpm 与 AppImage（glibc 2.34 以上），官网 aidooo.com 与 GitHub Releases 是仅有的官方渠道。
- 主页与文件管理：主页承担最近文件、新建入口与 AI 对话发起；文件管理支持搜索、排序与标签页式多开。
- 新建与打开文件：打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；doc 与 ppt 老格式明确不支持，需要先转成新格式。
- 设置总览：十分区设置地图：通用、语言（22 种）、主题、模型、知识库、隐私等，通用区逐项可调。
- 应用内手册与快捷键：F1 或 Cmd 加斜杠打开应用内手册：18 主题乘 22 语言的图文手册，可搜索，附全键位表。
- 模型供应商 BYOK：94 家供应商目录（国内 29、国际 34、本地 9、聚合 22）配 28 个适配器，

## 实话实说：哪些人不必急着装

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- API Key 存本机 ai-settings.json 不上传，支持环境变量引用
- PDF 涂黑生成物理删除的 -redacted.pdf 副本，不是注释遮盖
- 文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代
- 遥测仅匿名统计且可关闭；自建部署可做到零遥测

## 你可能会问

### 不购买会怎样？会锁功能吗？

不会。试用到期后只有每日一次的购买页和每 30 分钟一次的温和气泡提醒，全部编辑器与 AI 功能完全不受影响（弹窗原文即写明「不购买也完全不影响使用」）。

### 激活报「序列号与本机不匹配」？

序列号签发时绑定了下单页显示的本机指纹。核对弹窗「本机指纹」与当初报给客服/购买页的指纹是否一致（指纹由本机硬件标识散列而来，整机稳定不变）；换主板、重装系统等导致硬件标识变化后，需要按新指纹重新获取序列号。

### 重装 Office 后还要重新激活吗？

序列号校验只看本机指纹：只要指纹未变，重装后用同一条序列号重新激活即可。授权记录 purchase.json 在用户数据目录，删除它等于回到未激活状态。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

## 更多操作细节

第 2 步 · 扫码购买

1. 弹窗内有两个页签：「扫码购买」/「分享」，默认扫码购买。二维码在本机离线生成，内容是包含本机指纹的购买页地址（aidooo.com 购买页，buy?app=office&mid={本机指纹}）。
2. 下方按钮：「在浏览器中打开」「复制链接」——不方便扫码时用电脑浏览器打开同一购买页。
3. 手机付款流程（弹窗内「如何购买？」折叠说明原文）：① 用手机扫码打开购买页；② 在手机上选择档位并付款（档位和价格以购买页为准）；③ 付款后页面会显示一条序列号，复制回来；④ 粘贴到上方输入框点「激活」即可，序列号会自动识别所购档位。全程在手机上完成支付，电脑无需联网。（扫码页说明另注明：手机扫码选档付款支持微信 / 支付宝。）
4. 「分享」页签：二维码指向分享页（share?mid={本机指纹}），说明「分享给好友，好友购买后你可获赠使用权益」。
