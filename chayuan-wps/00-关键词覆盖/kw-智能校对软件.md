# 智能校对软件：发文前全文校对

智能校对软件这个叫法，在不同人嘴里指向的东西差别不小：有人指 Word 自带的拼写检查，有人指出版行业的老牌校对系统，也有人指近几年出现的 AI 校验工具。这篇把范围限定在最后一类，产品样本取察元AI文档助手，定义、数字、边界一样不少。

## 什么是智能校对软件

智能校对软件不是装完就一个按钮的东西，它有入口、有步骤、也有边界，摊开是一整面能力。WPS 三端智能加载项：校对、编审、核对、脱密，一个文档智能体。

挑这类软件时值得盯两个地方：一是误报率，工具把正常句子标成问题的频率；二是结果的呈现方式，弹窗列表式的结果复核起来费眼，挂在原文处的批注读上下文就能判断对错。这两点都比功能数量更影响日常体验。

版本号与各项数字的核对情况，文末尾注统一说明，正文不逐处标注。

## 最短上手路径

从这几步开始：

1. 选区全文两档：选中状态下只查选中内容，未选中则对全文执行
2. 分块并发：长文按默认 6000 字一块并发检查
3. 批注锚定：结果以批注挂在对应原文位置
4. 场景验证：发文前全文校对
5. 场景验证：重点段落精查
6. 串联场景：WPS 里打开文稿

第 4、5 两步建议连着做：先全文跑一遍抓面上的错，再对标题、导语、人名地名这些要害位置选区精查一遍。全文档扫出的问题多，不代表文档质量差，只说明基线错误本来就存在；要害位置漏一个，代价往往比面上错十个还大。

## 察元AI文档助手的能力地图

- 助手管理：助手目录搜索、收藏常用、按领域浏览，形成自己的助手工作台。
- 拼写与语法检查：走 AI 助手组的大按钮，选中状态下仅查选中内容。
- 脱密复原：脱密复原按钮（仅已脱密文档亮起）：输密码确定复原，按占位符就地还原，脱密后被编辑过也能还原。
- 启动本机 MCP 服务：绑定回环地址的 62588 端口。
- 外部智能体接入 MCP：外部智能体一行配置接入：Claude Code 用 claude mcp add 命令、Codex 改 config.toml、Cursor 写 mcp.json，选 HTTP 类型指向本机地址；Inspector 可验证连通。

## 装之前想清楚四件事

- 收费点集中在四项：脱密、复原、保密检查、涉密关键词提取，这几项没有免费额度
- 占位替换能还原的前提是密码在手，密码遗失后免密恢复不存在
- 送检文本会整体交给你配置的模型，涉密文档建议先切到本机离线模型
- AI 痕迹检查标注的性质是疑似线索，不下定论

边界都摆在明处，主线校对不受影响，影响的是你对成本的预期。

## 数据与安全设计

- 每一次确认写操作都会被 audit.jsonl 审计日志留痕
- 保密检查充当辅助筛查：关键词命中不说明泄密，也下不了定密结论
- 脱密恢复载荷以 AES-GCM-256 加密并随文件保存，密码在手即可还原原文

## 价格口径

- 免费额度按天刷新，对话与助手分池、各自计量，次日重置

## 读者常问的两条

### 智能校对软件检查时非联网不可吗

看模型放在哪：送检文本会整体交给你配置的模型，配的是云端模型，网就是硬前提；涉密文档建议先切到本机离线模型再查。

### 智能校对软件哪些功能要额外付费

日常校对消耗免费每日额度，对话与助手分开计量、次日重置；脱密、复原、保密检查、涉密关键词提取四项属付费专属，零免费额度、仅文字端提供。具体价格以官方文档的收费说明页为准。

## 一句收束

值不值得引入，看你的发文频率：天天出长文的团队，批注式逐条确认能省下不少人工通读；一年改不了几份文档的个人，先用手头工具顶一阵也行。

## 放进整套盘面里看

校对之外，它还开着本机 62588 端口的 MCP 文档智能体服务；工具面按域聚合后好记好用，写确认纪律保证外部智能体不能悄悄改你的文档。Claude Code 接进来能直接操作你正开着的 WPS 文档，编程智能体与办公文档打通。全文校对分块并发，块长默认 6000 字，长文不超时。

## 安全侧的两条事实

整机翻译走语种动态菜单，逐段安全替换写回：译文直接替换原文段落、保留格式；涉密场景的辅助筛查不定密，最终以人工保密审查为准。

## 平台与形态

macOS 侧两个已知情况：容器写入失败有修复脚本可跑；安装器无完全磁盘访问权限会假成功，跑修复脚本后再装即可。

## 校对之外的搭配能力

配图不出软件：写好提示词就地生成；智能提取从样例文档抽字段、自动生成表单规则后人工微调。

## 断网环境怎么办

离线时先弄清数据去向：本地数据落盘位置有说明可查，帮助手册、在线客服与关于页都有入口。MCP 服务开在本机，不占外网；校对要不要网取决于模型配置，前面「读者常问的两条」里说过。

全文就记一条：选中与全文是两档，选区模式只查选中部分——细节都在上面「最短上手路径」里。
