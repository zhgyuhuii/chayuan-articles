# 官方下载渠道安装指南：全平台步骤与验证

官方下载渠道是什么、怎么用，一篇讲清楚。智能体门户，插件、技能、MCP、提示词、大模型资源一站检索与下载。下面进入正题：先概念，再步骤，最后是边界与常见问题，基于察元AI 能力广场整理。

## 安装前确认

- 系统要求：现代浏览器
- 安装包：网页服务
- 说明：仅官网与 Releases。

网页端 aidooo.com；桌面产品可从站内下载 Windows/macOS/Linux（含麒麟/UOS）安装包。安装包从官网 aidooo.com 获取。

## 一步步来：从入口到完成

1. 浏览器打开 aidooo.com
2. 导航进智能广场或教程库
3. 登录后可收藏、投稿、下载产品安装包
4. 产品下载页按平台与架构给出直链

## 装完后的第一件事

开始页新建一个 docx，在设置模型里接上厂商 API 或本机 Ollama，然后让首页 AI 生成一段测试文本——三步都通，环境就绪。

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 若没有生效，先完全退出宿主软件再重启一次

## 这些坑和边界要知道

如实说明，它不是万能的：

- 教程库只做元数据导航，正文仍在源站
- 榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜

## 你可能会问

### 下载安装包需要登录吗？

需要。完成站内账号或微信扫码登录后即可下载，登录后还能收藏资源与管理下载记录。

### 怎么确认下载的是官方安装包？

官网 aidooo.com 是仅有的官方分发入口，下载页直链由管理后台自动同步生成；不要使用第三方站点的镜像包。

## 补充答疑

### 服务版和至臻版在哪买？

首页产品区的授权入口进购买页，大批量授权建议先联系商务。

### 下载页的直链是谁维护的？

由管理后台的发布流程自动同步生成下载清单（产品、渠道、平台、架构），手工编辑会被下次发布覆盖，保证链接永远指向最新版本。

### 提取码是什么？

部分网盘直链带提取码，下载页会自动复制提取码并给出提示。
