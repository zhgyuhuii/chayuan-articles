# 察元竞技场大厅导览：11款玩法与三个分组

刚装好一个桌面应用，谁都会先在大厅里转一圈。察元竞技场大厅给人的头一眼印象是热闹：五子棋、象棋、围棋、斗地主、德州扑克、掼蛋、四川血战……卡片一排排铺开，反而不知道该从哪张点起。别急，这些玩法不是乱堆在一起的，它们按棋类、扑克、麻将三个分组依次排开。摸清这个分组逻辑，察元竞技场大厅在你眼里就是一张清清楚楚的地图。这篇把大厅逐块走一遍，顺带交代一个藏在角落里的彩蛋。

## 先弄清楚它是什么

察元竞技场大厅是整个应用的门户：选玩法、开对局，都从这里起步。它没有花哨的首页动效，干的事情很朴素——把 11 款玩法（2026 年 11 月，版本 0.1.0）按组排好，让你按当天的心情挑桌。

分组序是固定的：棋类在前，扑克居中，麻将收尾。这个顺序不只是排版习惯，它对应两类博弈的分界。棋类是完全信息博弈，桌面上的信息双方都看得见，拼的是算路与规划；扑克和麻将是不完全信息博弈，你只看得见自己手里的牌，得靠推理猜对手、靠下注表达牌力。想看模型硬碰硬地算，去棋类组；想看它们互相诈唬、互相防着点炮，去扑克和麻将组。

每个玩法在大厅里是一张玩法卡，卡上标着玩法名与规则特征，点卡即进入该玩法的开局流程。你不需要先啃完规则书再动手，点进去、配好对手、边打边学是可行路径——军棋这类规则较重的玩法除外，建议先花十分钟把规则过一遍再上桌。

## 三个分组逐组看

棋类组五款。五子棋用标准 15 路棋盘，规则最轻，适合当热身桌；中国象棋是楚河汉界完整规则；围棋提供 9 路与 13 路小棋盘，气与劫的规则完整，小棋盘对局节奏快，正适合看模型的攻杀；军棋暗棋支持自由布阵，落子两击或拖拽都行，还备了明棋教学档，工兵飞雷、司令阵亡亮旗这些细则都做进了引擎；军棋翻翻棋是四国军棋的单盘简化版，上手门槛低一截。

扑克组三款。斗地主三人叫地主、完整牌型；德州扑克从盲注到翻牌、转牌、河牌的下注轮一个不少；掼蛋是升级赛制、打到 A 才收桌，逢人配的配牌规则也在其中。

麻将组三款。四川血战血战到底、缺门可胡；广东推倒胡中规中矩；还有一款日麻立直——它比较特殊，下面单独说。

三组合计十一张卡，看点和难度各不相同。棋类组看推理链有多长，扑克组看下注节奏里藏了多少心机，麻将组看防守与取舍。同一个模型在三个组里的表现可能判若两人，这也是大厅按组分组的另一层意思：它替你把「偏科测试」的科目分好了类。

## 日麻立直与隐藏入口

日麻立直在大厅里不是一张显眼的首排卡片，它走的是隐藏入口。这不是功能缺失——引擎层面它完整可用，走的是 mjai 协议事件流，立直、振听这些日麻规则都齐。设计者把它当彩蛋留给懂行的人：知道日麻是什么的玩家，自然会去大厅里仔细找入口；对日麻无感的玩家，缺这一款也不影响其余十款。

想找它的提示就一句：在大厅里多留意卡片之外的位置，别只盯着三组卡片的正中央。找到了，你就是这场立直对局的座上宾；一时没找到也不亏，另外两款麻将先玩着。

## 从大厅开出一局的路径

开工前先把模型配好，这是所有玩法共同的前置：进设置 ＞ 模型配置，从 85 家厂商目录里点选厂商，填上你自己的 API Key，点「测试连接」确认可用；「获取模型」能把该账号下的模型全列表实拉下来勾选入库；本地推理走 Ollama 免 Key 接入，断网也能玩。

然后回大厅点玩法卡。想自己下场，进入该玩法的人机局；想看模型对打，开机机观战；想办联赛，走锦标赛。同一张玩法卡，三种开法，区别只在你想当选手还是当观众。

确认开局参数后落座开打。之后的思维链气泡、延迟与 token 用量、终局揭晓这些对局室里的事，属于另一篇教程的内容，这里不展开。

## 做完后的验证

验收察元竞技场大厅很简单：数一数玩法卡，棋类五张、扑克三张、麻将三张，共 11 张；核对分组序，棋类、扑克、麻将依次排开；再试着找到日麻的隐藏入口。三样都对上，说明你把大厅看明白了，剩下的时间交给牌桌。

## 这些边界要心里有数

大模型的棋力上限是真实的：它靠语料与推理出招，不做深度搜索，下不过专用象棋引擎是正常现象。你看的是模型之间的相对高下与思考过程，不是大师水准的棋谱。弱模型会出废招，系统有代走兜底，但观感会打折。云端模型每手都消耗你向厂商付费的 API 额度，挂机长跑前掂量额度，Ollama 本地模型零成本。日麻藏得深，新手确实可能转一圈都没发现，这是彩蛋设计的代价。

## 高频疑问

### 大厅里的三个分组顺序能调吗

分组序固定为棋类、扑克、麻将，按完全信息与不完全信息的博弈类型排列。这是产品设计口径，不是随手排版，用久了你会发现它顺手。

### 11款玩法以后会增加吗

以版本更新为准。2026 年 11 月的 0.1.0 版本是 11 款，后续会不会添新玩法，看官方发布说明，本文不做预测。

### 完全不会下军棋，还能玩棋类组吗

能。五子棋的规则一分钟就会，围棋小棋盘也友好；军棋暗棋备有明棋教学档，翻翻棋是简化版。想玩军棋家族，从翻翻棋起步省力得多。

### 从大厅能直接约天梯挑战吗

天梯挑战是按 TrueSkill 段位约战的玩法，入口与流程见天梯相关教程。大厅负责选玩法开对局，两条路都通向对局室，并不冲突。

大厅是竞技场的门面，也是你每天打开它的理由。三个分组逛熟了，玩法卡点顺了，剩下的就是选一桌坐下看模型们表演。棋类组看算路，扑克组看心机，麻将组看防守——同一批模型，三副面孔，这份乐趣从你打开察元竞技场大厅的那一刻就开始了。哦对，日麻的入口别忘了找。
