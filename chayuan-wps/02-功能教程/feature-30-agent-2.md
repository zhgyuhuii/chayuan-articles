# 应用内文档智能体怎么用：察元文档助手新手入门

文档智能体是察元AI文档助手里使用频率很高的一项能力。它的「应用内文档智能体」这样工作：对话框内的文档智能体车道：AgentLoop 自循环（最多 16 轮工具调用）、todo_write 任务清单（先列计划边做边勾）、三档写权限（变更前确认/自动执行/完全访问）、写前快照一键撤销、文档写锁（FIFO+OCC）与「声称核对」防谎报。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

对话框内的文档智能体车道：AgentLoop 自循环（最多 16 轮工具调用）、todo_write 任务清单（先列计划边做边勾）、三档写权限（变更前确认/自动执行/完全访问）、写前快照一键撤销、文档写锁（FIFO+OCC）与「声称核对」防谎报。

从任务视角看，它对应的关键词是「文档智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 在对话框切到文档智能体
2. 下达复合任务（如「核对全文数字与表格一致性并修订」）
3. 查看任务清单与每步工具调用
4. 按写权限确认变更，不满意用快照撤销

## 适用场景

- 一句话完成「查+改+核」复合任务
- 长文档多轮整理

## 进阶技巧

- 默认「变更前确认」档最稳，熟悉后可切自动执行
- todo 清单让你随时知道智能体做到哪一步

## 注意事项与边界

- 保密检查、AI 痕迹检查为辅助参考，不构成定密或定性结论
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域

## 常见问题
### 我的文档会上传到云端吗？

不会强制上传。使用本地/内网模型时文档不出本机；MCP 服务只监听 127.0.0.1:62588 回环地址；只有你主动配置云端模型时，对话内容才会发往对应服务商。

### 能处理多长的文档？

长文分块读取（document_chunks）对百万字级文档友好；校对建议分批确认，避免一次任务过大。

### 察元AI文档助手是什么？

一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。
