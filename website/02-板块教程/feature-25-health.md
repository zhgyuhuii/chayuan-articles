# 资源失效攻略：资源健康与风险标注的关键点拆解

资源失效是察元AI 能力广场里使用频率很高的一项能力。它的「资源健康与风险标注」这样工作：条目级 health 状态机（active/degraded/dead/archived）与 MCP scopes 风险分级（0-3 级）：资源可用性与权限风险透明可见。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

条目级 health 状态机（active/degraded/dead/archived）与 MCP scopes 风险分级（0-3 级）：资源可用性与权限风险透明可见。

从任务视角看，它对应的关键词是「资源失效」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 看条目上的状态标签
2. MCP 条目查看 scopes 等级
3. 优先使用 active 低风险条目

## 适用场景

- 避坑失效资源
- 评估 MCP 权限风险

## 实用技巧

- degraded 条目备好替代方案

## 注意事项与边界

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### 要注册才能用吗？

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。
