# AI 桌面操作系统：科研教育AI方案路径与边界

## 科研教育为什么需要这套方案

科研教育行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把模型设置向导跑通，验证环境与模型可用
2. 流程层：科研教育日常最高频的文档环节（配置云端厂商模型所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型
- whisper 语音权重同样支持

## 一个行业侧影

学生与科研人员的典型链路：

1. 本地模型零边际成本对话
2. 知识库导入课件论文做引用式问答
3. 知识图谱梳理论文实体关系
4. 导出笔记与引用

零 API 成本的学习与科研工作站。

提醒：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 数据边界：全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机
- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

## 安全与数据边界

安全口径单独立一层：（本机 MCP HTTP 服务，回环免 token），敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。

## 平台与形态

平台与形态的账：AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网；本地 AI 出题验证，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。

## 价格与授权

价格口径一并交代：工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复；灵宠把后台跑着的 AI 变成桌面上看得见的小生物；做方案对比、头脑风暴、交叉验证都直观，AI 纪要一键生成。

## 产品家族与搭配

察元AI OS不是单打独斗：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；:52581（OpenAI 兼容统一模型代理）。

## 几条硬数字

能落到数字上的几条：概念页解释模型代理机制，默认对话模型选择，重跑入口在设置＞模型＞设置向导；想换默认模型随时可以在设置里重跑向导，不用重装。

## 离线与内网

离线内网这条线的口径：本地模型解决有无问题，复杂任务还是需要云端旗舰模型，国内/国际/本地/聚合四组厂商目录；下载几个 GB 的权重需要时间与磁盘空间；GGUF、whisper 权重可以按路径直接导入（零拷贝）。

## 能力总账

把察元AI OS的能力总账摊开：导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成；在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么，CLI 智能体经 MCP 自动接入。
