# 任务灵宠：巡检类任务的值守宠，一次走通

任务灵宠这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决每晚汇总新闻的任务宠。

## 这个功能到底解决什么问题

任务灵宠，先给一句能直接引用的定义：把一只灵宠绑定到常驻任务后，任务每次执行时这只灵宠自动上桌（不钉住也会上桌），头顶气泡流式滚动任务输出（相位标签「思考中」/「输出中」）；任务结束后 10 秒内气泡切换为结果摘要（绿色「完成」/红色「失败」），同时向通知中心推一条「常驻任务」消息。

入口、步骤、验证三段看清，这事就顺了。

## 开工前检查这几样

- 桌面形态（察元AI OS）：任务灵宠的气泡与上桌表现都在桌面灵宠层。
- 至少一个常驻任务：设置 ＞ 常驻任务 ＞ 「新建任务」（没有任务时建宠表单的绑定下拉只有默认项）。
- 任务要能跑起来：
- 「模型直跑（不经过智能体）」方式：模型代理需在运行（本机固定 127.0.0.1:52581，随模型服务自启）；任务未单独指定模型时用全局默认对话模型；
- 「智能体无人值守」方式：仅 Codex / Claude Code / OpenCode 三家支持，其余家不可选。
- 一只灵宠。

## 实操全过程

第 1 步 · 建常驻任务（设置 ＞ 常驻任务）

1. 打开 设置 ＞ 常驻任务（分区标题「常驻任务（Always-on）」，说明行含「绑定灵宠后，任务执行时灵宠上桌并流式展示输出」）。
2. 点蓝色「新建任务」弹出表单，逐项填：
    1. 任务名（占位符「任务名（如：每日晨报）」）与任务指令（每次运行发给模型的提示词）；
    2. 排程：「每 N 分钟」（1–10080）或「每天定时」（HH:MM）二选一；
    3. 执行方式：留空「模型直跑（不经过智能体）」，或选 Codex / Claude Code / OpenCode 无人值守跑（完整智能体能力）；
    4. 可选增强：模型（与建宠同款选择器，「自动」=用全局默认对话模型）、工作区、知识库（每次运行先检索注入）、附件（≤3 个）、勾选「启用联网搜索（每次运行前检索最新信息）」。
    5. 点「保存」，列表出现该任务行（默认启用，圆点绿色）。

第 2 步 · 绑定灵宠（两条路任选，绑定真相源都是灵宠档案的 taskId）

1. 路 A（设置面）：设置 ＞ 常驻任务 ＞ 找到任务行，行首下拉默认显示「未绑定灵宠」＞ 展开列出全部灵宠 ＞ 选中一只即完成绑定。在设置面改绑另一只时，原来那只自动解绑（设置面保证一个任务只挂一只灵宠；灵宠档案侧的任务字段本身也只有一个）。
2. 路 B（建宠/编辑宠表单）：建宠或右键「编辑灵宠」＞「绑定常驻任务（任务灵宠）」下拉（默认「不绑定（普通灵宠）」）＞ 选任务名 ＞ 保存。

第 3 步 · 触发执行

1. 等排程：调度器每 60 秒扫描一次到期任务自动执行；也可点任务行琥珀色「立即运行」按钮（页面提示「已触发运行…」）。
2. 绑定后名册里该宠状态徽标变为下次运行倒计时（「即将运行」/「N 分钟后」…）。

## 如何确认操作生效

验证

1. 按第 2 步绑定后，设置页任务行下拉显示所绑灵宠名；底栏「灵宠」名册里该宠出现倒计时徽标。
2. 点「立即运行」：桌面出现该灵宠 + 头顶气泡滚动输出（相位在「思考中」/「输出中」间切换）；结束后 10 秒内气泡变绿「完成」+摘要，通知中心出现「<任务名> · 完成」条目。
3. 任务行点「历史(1)」：列出一条 记录，悬停能看到 ~/always-on/ 下的报告文件路径；用文件管理器打开该路径能读到完整报告。

## 谁需要这个功能

巡检类任务的值守宠，每晚汇总新闻的任务宠；任务跑完气泡一闪就没了，想知道完整结果去哪里补看；建宠表单里有个「绑定常驻任务（任务灵宠）」下拉，不知道选了会怎样。

用户常搜的问法：绑定了常驻任务的灵宠是干什么的？怎么让任务结果在桌面上显示；任务灵宠头顶的气泡显示的是什么？为什么只有最后一段字。

## 这些坑和边界要知道

边界先摆在桌面上：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 任务在跑，桌面上怎么没看到灵宠？

该任务没有绑定灵宠（设置 ＞ 常驻任务，看任务行下拉是否显示「未绑定灵宠」），或绑的是另一只。按第 2 步绑定即可；绑定关系在下次执行时生效。

### 气泡里只有最后几个字，前面的输出去哪了？

气泡是约 200 字符的滚动尾窗，只做「活着」的视觉反馈。完整输出看报告文件（~/always-on/）或任务行「历史」。

### 结果气泡一闪就没了，来得及看吗？

停留期固定 10 秒。错过就看三处：通知中心的「常驻任务」条目（含摘要）、任务行的 / 与「历史」、~/always-on/ 报告全文。

### 页面刷新/电脑重启后，正在跑的任务宠还在吗？

在。每次运行会写运行态快照，页面刷新或重启后：5 分钟内仍在跑的恢复为「执行中」（灵宠重新上桌带气泡），10 秒内刚跑完的恢复结果摘要。

### 任务选了智能体方式，为什么运行失败？

无人值守执行当前仅支持 Codex / Claude Code / OpenCode 三家（表单下拉也只列这三家）。失败会留痕：任务行 、「历史」里可看错误，报告文件的「错误」小节有详情。
