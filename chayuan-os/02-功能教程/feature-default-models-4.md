# 主强子弱：怎么全局设置模型，别再瞎试

主强子弱这件事，值不值得专门学一篇，看一个细节就够：11 类任务独立设置。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 先定位问题在哪一层

主强子弱的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把有可选的模型，二选一：本地已安装模型，核一遍，再查路径。

## 高频故障与对策

### 重排 / 决策为什么选不了厂商模型？

这两类树只列本地模型（决策为本地专属能力）。没有就到 设置 ＞ 模型 ＞ 本地模型 组下载（重排见模型库「重排序」分类）。

## 正确的操作路径

5. 保存时系统做了什么（理解行为用）

点「保存并更新技能」或弹窗「确定」后，系统依次：

「自动」的回退规则（源码 autoResolve）：本地第一个可用模型 ＞ 云端第一个匹配类型 ＞ 都没有（无可用模型），即本地优先。

1. 云端选择涉及的厂商自动确保已加入模型代理路由（真实厂商 key 不出凭证库）；
2. 渲染 models.md：十一类「分类 | 默认模型 | 调用（模型名）」表 + 代理调用面（Base URL http://127.0.0.1:52581/v1）+ 已启用的网络搜索平台清单；
3. 落盘 defaults 文档，主进程防抖后把 models.md 作为系统技能（chatop-system）伴随文件镜像进六家智能体技能目录（dsh / Claude Code / ZCode / Codex / OpenCode / OpenClaw）——智能体读技能文档就知道每类默认模型怎么调。

最短路径走一遍：（第 4 个切入角度）

1. 11 类任务独立设置
2. 自动模式本地优先
3. 设置结果分发到智能体侧
4. 确认边界：指定模型未加载时会按策略自动拉起
5. 场景验证：日常轻任务走本地、攻坚任务指云端
6. 场景验证：统一团队的任务模型基线

## 怎么确认做成了

验证

1. 保存后页面出现绿色「已保存，系统技能已更新并分发到各智能体」。
2. 桌面形态下打开任一智能体技能目录核对 models.md 已更新，如 ~/.claude/skills/chatop-system/models.md（ZCode 对应 ~/.zcode/skills/chatop-system/models.md），「分类默认」表里能看到你选的模型。
3. 默认对话模型同步成功后，打开 DeepSeek Harness 对话窗，模型下拉里出现所写模型；指定了云端模型时，浏览器访问 http://127.0.0.1:52581/v1/models（免 key）能看到 <厂商id>/<模型名> 条目。
4. 把「自动」所在行的灰字与预期对照：装了本地对话模型时应显示「本地 · <模型id>」。

## 常见问题

### 图生图 / 视频生成分类里为什么没有本地模型？

本地引擎暂无这两类能力（本地 SD 仅文生图；视频生成模型尚未开放下载），这两类全部列已启用厂商的图像生成 / 视频生成模型。想用就先配一家支持该能力的厂商。

### 默认语音合成 / 语音转文字模型影响什么？

保存后同样写进 models.md 随技能分发：语音合成对应本地 Piper / 云端 tts 类模型，语音转文字对应本地 Whisper / 云端 asr 类模型，按代理命名空间（local/<id> 或 <厂商id>/<模型>）调用。

## 动手前再核对一遍

- 有可选的模型，二选一：本地已安装模型，或已在 设置 ＞ 模型 启用过云端厂商。都没有时每类显示「无可用模型」。
- 指定云端模型时需要模型代理在运行（本机固定 127.0.0.1:52581，随模型服务自启）；代理未运行时保存会报错（见常见问题 Q1）。
- 「默认对话模型」一键同步智能体需桌面形态（浏览器形态见「形态差异」）。
