# AI素质教育课堂方案：思维可视化教具

讲人工智能的课，最常出现的场面是老师在讲台上讲概念，学生在下面抄名词：什么是大模型、什么是参数、什么是训练。抄完还是隔着一层，因为这些东西看不见。学生真正想问的是那句没人答得直白的话——AI 到底是怎么想的？AI素质教育要往下走，缺的不是知识点，而是一件能把模型的思考过程摆上大屏、让学生亲眼看见的教具。

这篇给一线教师和教研团队一套可落地的课堂方案：用开源的察元竞技场让大模型当堂对弈，把思维链气泡、形势曲线、复盘标注这些过程证据变成课堂素材，同时给出课堂组织流程、观察任务单的设计办法与费用合规的边界。方案的原则只有一条：让学生的注意力有落点，看热闹也要看出门道。

## 为什么棋牌对局适合进课堂

棋牌是少数几种不需要背景知识就能看懂的AI演示载体。规则三五分钟讲完，谁攻谁守、谁占上风，小学生也看得出来。更要紧的是，大模型每走一手，它的推理过程会以思维链气泡的形式在对局室里实时流式展示——先看哪些着法、怎么权衡、为什么选这一手，全程摊开给全班看。这比任何一张讲解图表都直接。

察元竞技场目前有 11 款玩法（2026 年 11 月，版本 0.1.0）：棋类的五子棋、中国象棋、围棋（9 路/13 路小棋盘），扑克类的斗地主、德州扑克、掼蛋，还有军棋与麻将。完全信息博弈考推理，不完全信息博弈考判断，教学上正好对应两个主题：确定性规则下的计算，与不确定局面下的决策。胜负判定全部由代码裁判完成，模型只出招不判罚，公平性一句话就能跟学生讲清。

教学目标上，这套教具能接住三类课。讲「AI 如何做决策」的课用棋类：模型推演候选着法的过程全部写在思维链里；讲「概率与风险」的课用斗地主或掼蛋：叫牌、拆牌、报牌都是活教材；讲「信息不对称」的课用军棋暗棋：看得到与看不到的部分，规则本身就替你把概念演示了。一节课对准一个目标，比一节课塞三个概念有效得多。

## 课前准备：一台教师机就够

硬件上只需要一台教师机加投影或大屏。察元竞技场是 Electron 桌面应用，Windows、macOS、Linux 都有安装包，常规办公电脑就能跑。

模型接入在设置 ＞ 模型配置里完成：从内置的 85 家厂商目录点选机构要用的厂商——DeepSeek、智谱 GLM、通义千问、Kimi 这些都在目录里——填上机构自己的 API Key，点「测试连接」确认可用；不确定账号下有哪些模型的，点「获取模型」把可用列表实拉下来勾选。对数据要求严格的机房，可以配 Ollama 本地推理：免 Key、断网可玩，整堂课的数据不出机房，代价是本地模型的棋力与讲解质量都弱一档。

最后一步是打样。上课前自己把要演示的对局先跑一遍，看看模型当天的发挥、对局时长和思维链气泡的可读性，别把意外留给课堂。

## 课堂组织：四十分钟怎么切

给一个可以直接抄的四十分切片：

5 分钟讲规则。选零门槛玩法开场，五子棋最稳；军棋暗棋有明棋教学档，想讲信息不对称概念的时候用得上。

10 分钟机机观战。两个模型对打，座位默认匿名，显示玩家A、玩家B，终局才揭晓身份。让学生先猜哪个座位更强，猜完再验，参与感就是这么来的。

10 分钟填观察任务单。学生边看边记，具体设计见下一节。

10 分钟人机局。学生代表上场挑战模型，教师握着「AI 接手 与 人工接管」的双向切换权，局面崩了随时让模型续盘，节奏不断。

5 分钟复盘收尾。打开形势曲线和逐手的 ？!标注（妙手与失误），全班聊一句「哪一手是转折」。

## 观察任务单：让学生有东西可填

看模型对弈最怕变成集体发呆。任务单的作用是把观看变成采集，三栏设计：

一栏抄思维链。从对局室的思维链气泡里抄下模型的一段盘算，用一句话概括它先想什么、后想什么。学生动手抄写时，自然会注意到模型的推理是有顺序的。

一栏找转折。对着形势曲线标出局势反转的位置，再去复盘的 ？!标注里找对应那一手，判断它是妙手还是失误。这一步把图表和数据连了起来。

一栏提问题。写一个想问模型的问题，下课后由教师汇总——这些问题就是下一堂课的起点，课程自然接续。

任务单不必追求填满，写两行有价值的观察，胜过抄满一页。低年级可以把「抄思维链」换成「画局面」：把转折时刻的棋盘画下来，配上自己的判断，同样达到聚焦的目的。

## 费用与合规：先算账再开课

费用结构很简单：软件本身 MIT 协议开源免费；模型 API 的调用费用由机构向厂商支付，用 Ollama 本地模型则零成本。控成本的办法是选短对局：9 路围棋、五子棋一手几秒，一节课的调用量可控；德州扑克、掼蛋这类长局留给兴趣社团。给教务的做法是把模型费用单独列一项「教学演示用量」，与办公用量分开核算，一学期下来这台教师机花了多少，一张表说清。

合规上注意三件事。其一，API Key 只存在教师机的本机应用数据目录，永不上传，但应由教师统一保管，不装进学生机、不写进共享文档。其二，走云端模型时对局文本会发送给模型厂商，学校若对外发数据有明确规定，改用本地模型方案。其三，宣传口径守住线：这是观察与启蒙教具，不是刷题提分工具，别向家长承诺任何分数收益。

## 常见疑问

### 机房断网还能上课吗
能。配 Ollama 本地推理即可全程离线，免 Key、数据不出机房。本地模型棋力与讲解弱于云端大模型，安排简单玩法即可。

### 一节课的模型费用怎么控制
软件免费，费用只在模型调用上。选五子棋、9 路围棋这类短对局，控制场次数量，或直接用本地模型，预算就压得住。

### 学生能自己装来玩吗
可以。家用电脑装好即可，但 API Key 建议由家长或教师保管，账号信息不交给孩子。

### 哪些玩法适合课堂
五子棋、斗地主这类规则熟悉的先上；军棋要先花时间学规则；日麻立直在大厅是隐藏入口，公众课堂不必安排。

教具的价值不在炫技，而在把抽象的东西变成可讨论的对象。一堂课下来，学生未必记住大模型的原理，但「AI 是一步一步想的、它也会犯错、裁判是代码不是模型」这三件事，会随着那局棋留下来。对 AI素质教育来说，这三件事比十个名词解释都更接近教育的本意。


## 边界与合规

- 模型调用费用自付：课堂高频使用建议配 Ollama 本地模型或限额厂商 Key，课前列好预算。
- 竞技场是教学载体不是测评工具，别把对局胜负当评分项；思维链气泡是分析性意见，不是标准答案。
