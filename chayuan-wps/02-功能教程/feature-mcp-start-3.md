# 首次启用文档智能体：用文档智能体实操跑通一个真实场景

文档智能体实操的麻烦不在功能本身，在于信息散。MCP 服务是外部智能体操作 WPS 文档的桥，开机自启保证随时可用。这篇把它收拢成一条能照着走的路径。

## 先看看痛点对不对得上

助手窗格里文档智能体显示「未就绪」，需要手动拉起服务；首次启用文档智能体；服务没起来自查，想让 Claude Code / Codex / Cursor 直接操作 WPS 文档，第一步是把本机 MCP 服务跑起来。

## 关键能力点

- 三种启动方式
- 三平台自启
- healthz 健康检查

## 几个容易忽略的细节

边界先摆在桌面上：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型

## 你可能会问

### 另一台电脑能直接连我这台的 62588 吗？

不能。服务固定只监听 127.0.0.1（涉密不出域的设计）。跨机使用需在本机做代理/SSH 转发，见对应教程 的「远程机器」节。

## 安全与数据边界

安全口径单独立一层：自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源；每次确认写操作记入 audit.jsonl 审计日志，脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原，语种动态菜单逐段安全替换写回：译文直接替换原文段落，保留格式。

## 平台与形态

平台与形态的账：多人协作的文档格式千疮百孔，治理三件套一键回魂，把固定格式文档变成可填报可校验的表单，填报错误在源头拦住，红头文件、标书这类强格式文档，用模板加 AI 填充是最稳的生成方式，原模板零修改，加结构件补齐、整套翻译、转讲义文档、课件生成、习题互动页等 81 个配方。

## 产品家族与搭配

察元AI文档助手不是单打独斗：文档脱密、脱密复原、保密检查、涉密关键词提取四项为付费专属、零免费额度，全文会发送给所配置的模型，涉密文档建议先切到本机离线模型；优先支持离线内网模型是这套加载项的立场：涉密文档不出网也能用 AI；对话窗格多会话页签，历史按文档隔离：换一份文档就是一套会话上下文；按文档隔离的会话不会串味，A 文档的上下文不会污染 B 文档。

## 几条硬数字

能落到数字上的几条：文本转图像与文本转视频按钮预填多模态提示词进对话，按对应类型模型生成，不会写公式就按公式助手，不会分析就按数据洞察，表格工作的台阶被垫平，配图三级降级链：第一级模型生图（最多试 3 个模型）；配图这事儿要稳定：模型挂了搜图顶上，搜图不行矢量兜底，成本不会偷偷变。

## 离线与内网

离线内网这条线的口径：让 Claude Code 直接操作你正开着的 WPS 文档，编程智能体与办公文档打通，工具面按域聚合后好记好用，写确认纪律保证外部智能体不能悄悄改你的文档，智能提取让 AI 从样例文档抽字段自动生成表单规则，再人工微调，优先支持离线内网模型是这套加载项的立场：涉密文档不出网也能用 AI。
