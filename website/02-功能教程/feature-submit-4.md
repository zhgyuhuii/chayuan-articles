# 产品反馈实操：作品投稿审核制，别再瞎试

## 先定位问题在哪一层

产品反馈实操的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把环境与模型这两件事核一遍，再查路径。

## 正确的操作路径

在需求墙提需求

1. 进需求墙选产品（五款产品二级菜单）
2. 点「提需求」或唤起提需求机器人
3. 相同诉求会自动归并到已有条目，累计人数
4. 按处理状态过滤盯进展，全程公开

从这几步开始：（第 4 个切入角度）

1. 作品投稿审核制
2. 受控标签词表
3. 需求自动归并
4. 进展全程公开
5. 场景验证：把自己的 MCP 服务上架
6. 场景验证：许愿一个想要的功能

## 更多操作细节

投稿你的作品

1. 登录后进提交作品页
2. 填写资源名称、主页或演示地址、图标外链
3. 分类必选，标签从受控词表搜选 2 到 5 个
4. 提交进入人工审核队列，通过后上架展示
