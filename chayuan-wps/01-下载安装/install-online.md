# 企业在线部署安装：三平台安装包

企业在线部署这件事，值不值得专门学一篇，看一个细节就够：三平台安装包。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI文档助手。

## 安装前确认

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：静态服务器集中分发。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载 exe
2. 双击安装：加载项进入 WPS jsaddons 目录，本机服务自注册并带看门狗
3. 完全退出并重启 WPS
4. 文字端出现察元AI助理与察元AI编审两个选项卡即成功

## 其他平台装法速览

Linux：sudo dpkg -i 安装 deb；加载项进入 ~/.local/share/Kingsoft/wps/jsaddons；选项卡没出现时执行 quickstartoffice restart。

## 装完后的第一件事

第一件事是配模型：设置里选一家已购通道或本机 Ollama，点测试连接通过后，随便开一篇文档跑一次 AI 助手对话，通了再干正事。

## 如何确认操作生效

- 重启 WPS 后文字端出现察元AI助理与察元AI编审两个选项卡
- 若没有生效，先完全退出宿主软件再重启一次

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- macOS 安装器无完全磁盘访问权限会假成功
- Win7 与 Win8 的 MCP 二进制跑不了，需 Node 16 回落
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 动手前再核对一遍

- 本机已安装 WPS Office（文字 / 表格 / 演示任意端均可；三端使用同一套前端构建产物，差异只在安装路径与部署方式）。
- 本篇以 v6.1.2 发布产物为准；升级安装直接用新版安装包覆盖即可。
