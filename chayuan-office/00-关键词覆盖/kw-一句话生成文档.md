# 一句话生成文档：继续生成续长文

搜一句话生成文档的人，心里想的往往是「能不能省掉憋初稿的那段功夫」。这篇把它的定义、用法与边界摊开，配着官方口径逐条过。

## 什么是一句话生成文档

一句话生成文档指的是这样一种用法：在主页的对话里说出要什么文档，系统直接产出正文并打开成品。它依托的开源套件一个应用装下六个编辑器，AI 能力融进各个环节，入口、步骤与边界一应俱全，构成一套完整能力面。

数字类条目写作前都查过官方文档，具体版本与截止时间放尾注。

## 这个能力在哪里用

落点就在主页：对话里直接说要什么文档——docx、md、html、pdf 的正文直传生成并自动打开，卡片会提示已创建并已在新标签页打开；xlsx 与 pptx 只建空白文件，内容到各编辑器 AI 面板继续；生成被截断时有继续生成按钮；计划模式只出方案不动文件。

把它单独拎出来讲，是因为从空白页到初稿的启动成本被压成了一句话。

## 最短上手路径

下面几步按使用顺序排，前两步就能验证核心体验，后面的步骤管边界与习惯养成：

1. 在主页对话里直接说要什么文档，docx、md、html、pdf 的正文直传生成并自动打开
2. 遇到截断点「继续生成」，长文一段一段续
3. 复杂需求先开计划模式，看过方案再决定动不动文件
4. 表格与演示只建空白文件，内容到各编辑器 AI 面板继续
5. 首页会话本机最多 50 个，重要产出及时另存
6. 用会议纪要场景验证一遍，看初稿能不能直接上手改

## 计划模式与继续生成的分工

这两个入口解决的是长文写作的两类断点。继续生成处理物理断点：模型单轮输出到头、正文被截断，按钮一点就从断点续写；计划模式处理思路断点：需求复杂时先让模型出方案，人审过方案再让它动文件，避免方向跑偏后整篇重来。两个入口配合着用，长文的连贯性与正确方向都能兼顾。

## 从会议纪要开始验证

第六步建议拿会议纪要当考题，理由很实际：纪要结构固定，时间、参会人、议题、结论、待办一层层摆下来，生成质量一眼能判断；初稿到手后的人工修改量，就是评价这类工具的真实依据。验证时留意两点：口述需求把目标格式说清楚（比如直接说「生成 docx」），产出后立刻另存——首页会话本机最多 50 个，会话列表不是可靠的存放处。

## 周边能力速览

- 扫描件 OCR：没有按钮、自动触发，页面有效文字不足 8 字符即判为扫描页，随后交给系统引擎
- HTML 可视化编辑：预览与源码切换、点选元素就地编辑、样式面板、面包屑、Ask AI、插入骨架、图片去背景；
- 字节保真与格式兼容：未触碰的块逐字节写回；1GB 大 docx 打开不卡
- CLI 命令行：chaoffice 命令行 17 个子命令：
- 打印与自动保存：六编辑器统一打印链路；30 秒自动保存，关闭时询问未保存项。

这些周边能力不必一次掌握，用到哪块翻哪块：OCR 在打开扫描件时自动生效，自动保存会定期兜底，CLI 等命令行习惯建立后再上手。

## 主页生成常见疑问

### 主页对话能直接产出哪几种文件

docx、md、html、pdf 四种，正文直传生成并自动打开；xlsx 与 pptx 只建空白文件，正文内容要到各编辑器的 AI 面板里继续。

### 生成到一半停住了怎么办

截断处有「继续生成」按钮，点一下从断点接着写；如果只是想先看思路，切到计划模式，它只出方案不动文件。

### 首页的会话会不会越攒越多

会。本机最多保留 50 个，重要的产出要尽早落到文档里。

## 批量处理与大体量文档

文档相关操作分批量、批量操作、表单辅助三组：批量转换与处理，书签转内容控件的表单化；扫描 PDF 经此变成可搜索可引用的活文档，档案数字化从这一步起步；GB 级文档保持流畅；加密只读文档仅支持查看，这条边界要提前知道。壳内 MCP 服务（端口 52588）把文档操作能力开放成 MCP 工具，外部智能体可借此直接读写文档，Claude Code 这类编程智能体写代码调文档 API 不用翻文档。团队共享文档目录还能直连对象存储，保存即同步。对多人协作的文档流而言，这条同步链路比单机端的任何花活都更影响日常体验。

## 与知识库、主页动线的配合

写材料时引用内部资料且带出处，写作与知识库在同一条链上；主页承担动线起点的角色，打开就找得到文件、张嘴就能生成文档，从空白页到初稿的启动成本被压成一句话。这条链路对经常写材料的人省事在哪儿：出处由知识库层兜住，正文由主页对话生成，两步之间不换应用；写完的稿子走六编辑器统一的打印链路，中途出意外也有定期自动保存垫底。

## 一句收束

一句话生成文档适合谁，判断起来不复杂：日常要从零起稿、又愿意把初稿再改一遍的人，它能省下最枯燥的那段；指望输入一句话就直接交稿的人，边界条目已经给出了答案。
