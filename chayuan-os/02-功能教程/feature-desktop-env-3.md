## 它的局限也要说清楚

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 你可能会问

### macOS风格要联网吗

本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；Monaco 同款编辑器；设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关。以官网 aidooo.com 当前页面为准。

### macOS风格数据存在哪

每次产出 markdown 报告落盘归档，周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；markdown 报告归档。以官网 aidooo.com 当前页面为准。

## 更多操作细节

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 更多操作细节

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 安全与数据边界

安全口径单独立一层：隐私敏感环境先关遥测再干活，处置设备前清数据，（本机 MCP HTTP 服务，回环免 token）；敏感操作全部写审计日志 audit.jsonl，可回放检查，远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用。

## 价格与授权

价格口径一并交代：四档价格：149/359/599/1049 元；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签），跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定。

## 几条硬数字

能落到数字上的几条：local 星号开头的本地模型未运行自动加载，让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；本地模型按需自动加载；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。

## 离线与内网

离线内网这条线的口径：离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）；全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，断网时云端模型不可用，可设自动回落本地；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 能力总账

把察元AI OS的能力总账摊开：三级知识库优先级，知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么。
