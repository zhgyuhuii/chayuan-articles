# 财务会计AI方案落地：AI 桌面操作系统

## 财务会计为什么需要这套方案

财务会计行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把模型设置向导跑通，验证环境与模型可用
2. 流程层：财务会计日常最高频的文档环节（配置云端厂商模型所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型
- whisper 语音权重同样支持

## 一个行业侧影

需要多方意见的决策者的典型链路：

1. 给几只灵宠配不同厂商的模型
2. 建宠物群聊勾选成员，选并行或串行
3. 抛一个命题让它们讨论，开视角讨论强制多角度
4. 开共识模式让它们互相评审收敛结论

同一命题的多模型观点同屏呈现，分歧与共识一目了然。

提醒：本地模型并发上限 4 路，全员本地模型时发言会排队。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

## 放回产品盘面看

把财务会计AI方案放回察元AI OS的整体盘面：可选群分区（桌面出图标双击进群），知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，点击互跳定位原文，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 安全与数据边界

安全口径单独立一层：全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583）；审计日志全量记录。

## 平台与形态

平台与形态的账：让特定文件类型默认交给智能体处理，双击即用 AI；智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；桌面本身能被 AI 定义，能力边界从预装走向按需生成；（web/Docker 形态网页桌面默认端口）。

## 价格与授权

价格口径一并交代：AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；:52581（OpenAI 兼容统一模型代理），很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。

## 产品家族与搭配

察元AI OS不是单打独斗：做方案对比、头脑风暴、交叉验证都直观；AI 纪要一键生成；AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题。

## 几条硬数字

能落到数字上的几条：模型配置改乱了、服务起不来，回到出厂态是最干净的自救手段；一键回到出厂模型配置；恢复后自定义的模型清单需要重新导入；模型直跑模式无需角色卡，编辑面板改模型、知识库、人设。

## 离线与内网

离线内网这条线的口径：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；让特定文件类型默认交给智能体处理，双击即用 AI，智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用。
