# 模型配置可一键写入五家：whisper本地部署概念与上手

关于whisper本地部署，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是whisper本地部署

把whisper本地部署拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 最短上手路径

试一遍就明白：

7. 下载完成 ＞ 启动加载

1. 下载完成后模型自动从「模型库」进入上方「我的模型」列表；
2. 点该行「启动」：提示「已发起启动（后台预热）」——系统先做内存预算预检，再拉起引擎进程、健康检查，大模型首次加载可能需要十几秒；
3. 预检不过会明确报错：「内存预算不足：加载需要约 XGB，当前预算 YGB 已被运行中的模型占用。请先在模型管理中卸载：<名单>」，或「此机器内存不足以加载该模型…请选择更小的模型」；
4. 加载成功：行首亮绿点（运行中）；黄点 = 「运行中·探针验证中」（探针尚未确认）。顶部计数 +1；
5. 点「测试」验证链路：通过显示「测试通过 · <耗时>ms」（嵌入模型附维度、对话模型附样例回复），失败显示「关闭 测试失败 · <原因>」。

## 察元AI OS的能力地图

- 恢复出厂模型：设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态。
- 新建灵宠：桌面底栏灵宠名册里点添加：起名字、选挂不挂智能体（不挂也能模型直跑）、挑模型……
- 灵宠名册：底栏爪印按钮打开名册：全部灵宠与群的状态徽标（空闲、开窗、任务中）、钉住快切……
- 新建知识库：知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。
- 文生图应用：Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；
- web 与 docker 访问链接：web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 下载前要预留多少磁盘？

系统自动预检：模型体积 × 1.05 + 200MB；不足时报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

### whisper本地部署要联网吗

本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队；本地模型多宠同发会排队（本地档 4 路并发上限），就触发 kb_search、kb_list、kb_read_doc 工具链。以官网 aidooo.com 当前页面为准。

### whisper本地部署数据存在哪

润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱；自动模式本地优先，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。以官网 aidooo.com 当前页面为准。

## 更多操作细节

5. 开始下载

点行尾「下载 <体积>」（如「下载 1.6GB」）：

1. 进行中：按钮变「取消下载」，行下出现进度条，右侧显示「排队中…」或「<源站名> 百分比」（如 ModelScope 37%）；下载中页面约 1.5 秒自动刷新一次进度；
2. 点「取消下载」：断点保留，之后可续传。

## 更多操作细节

6. 失败自动换源、断点续传

1. 单个源 404 / 超时 / 中断：自动切换下一源重试，顺序 = ModelScope（含 API 通道）＞ hf-mirror.com ＞ hf-mirror.net ＞ aifasthub.com ＞ HuggingFace 官方（整体垫底）；
2. 连接中断：报「连接提前中断（断点已保留，可续传）」，按钮变「继续下载」；手动暂停同理；
3. 所有源都失败：报「所有 N 个源均失败（断点已保留，可重新下载续传）」，按钮变「重试下载」，行内显示具体错误；
4. 断点保留意味着任何中断都不用从头重下。

## 更多操作细节

8. （可选）我的模型行内其他操作

每行按钮（悬停有说明）：「停用」（卸载运行中的模型，立即释放内存）/「钉住」（悬停「钉住：空闲自动卸载豁免」，钉住后行内显示 ；「取消钉住」恢复参与自动卸载）/「设置」（启动参数：省内存·均衡·性能三档与高级覆盖，见后续教程 M5）/「删除」——行内二次确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」点「好」执行、「取消」收回。手工放置过、与内置目录疑似同款的权重行会出现「认领」/「已认领（撤销）」。
