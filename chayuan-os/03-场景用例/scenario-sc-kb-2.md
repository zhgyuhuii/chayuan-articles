# 个人知识库实操，怎么新建一个知识库

很多人搜「怎么新建一个知识库」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把个人知识库从打开哪个应用讲到看到什么结果。

## 先弄清楚它是什么

个人知识库是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，新建知识库是其中面向这类需求的一环。

按真实界面写，按钮文案原样引用。

## 操作步骤详解

从这几步开始：（第 2 个切入角度）

1. 知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载
2. 混合检索加可选重排保证命中质量
3. 引用式问答每个观点带编号脚注
4. 点脚注跳回原文核对并下载源文件
5. 多库并存
6. 独立存储互不干扰

## 适用场景

制度与技术资料分库，想先建一个测试库试上传、试检索，不动正式库，给每个客户建独立资料库，第一次打开「知识库」应用，想知道左栏的库列表是哪来的、怎么再加一个、default 是什么、库能不能删。

用户常搜的问法：怎么新建一个知识库；可以建多个知识库吗？数据是放在一起吗。

## 这些坑和边界要知道

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 常见问题

### 个人知识库要联网吗

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入，与知识库、模型联动，写材料时直接问公司知识库，回答带引用插进文档，办公与知识库一条链。以官网 aidooo.com 当前页面为准。

### 个人知识库数据存在哪

隐私敏感环境先关遥测再干活，处置设备前清数据，升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。以官网 aidooo.com 当前页面为准。

## 几条硬数字

能落到数字上的几条：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑；GB 内存建议一次只加载一个对话模型；或按直链目录放置后执行扫描本地放置的模型。
