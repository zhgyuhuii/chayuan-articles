# 校对管线：结构化问题清单到批注钉字（原理解析）

这是「察元文档助手技术解析」系列的一篇。校对管线：结构化问题清单到批注钉字是理解这款产品设计哲学的关键切面——看完你会明白它为什么这样设计、这样设计换来了什么、代价是什么。

## 一句话结论

proofread_run 输出结构化 issues（原文 quote+建议+理由），proofread_apply_comments 把批注精确钉到对应文字（含表格单元格）；应用内另有「校对写回 OCC 拦截改显式确认重试」的保护层。校对是「大模型推理+确定性写回」的混合管线：模型负责发现与解释，工具负责精确落点。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 常见问题
### 和 WPS 自带的 AI 有什么区别？

本产品是独立的开源加载项，特色在结构化校对批注写回、保密/脱密工具链、本机 MCP 服务与离线内网支持；两者可并存使用。

### 安装包多大？在哪里下载？

约 35MB（各平台相近），官网 aidooo.com、GitHub（zhgyuhuii/chayuan-wps-releases）、Gitee 国内镜像与百度网盘均可下载，每个包带 sha256 校验文件。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。
