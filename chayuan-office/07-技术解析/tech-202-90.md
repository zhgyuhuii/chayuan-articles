# 90 天试用与离线激活的授权工程：察元Office的原理解析

90 天试用与离线激活的授权工程常被用户问到。这篇原理解析从察元AI Office的实际实现出发，讲清楚设计取舍与使用层面的意义。

## 一句话结论

授权与费用的事实边界如下：开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。付费部分：试用期满后每日一次购买提醒弹窗（可手动关闭）+ 主页每 30 分钟温和提醒；离线 HMAC 短序列号激活，绑定机器指纹本地验证，无需联网激活服务器。所有声明都写成可验证的口径，而不是营销话术。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

- AI 默认不启用：配了 Key 或本地端点才会把对话内容发往所配服务商
- 安全工程：全窗口 contextIsolation + sandbox、IPC schema 校验、外链协议白名单、无硬编码密钥
- PDF→Word/PPT/Excel 转换与 OCR 均为本地引擎，扫描件不上传
- 相关能力以官网 https://aidooo.com 最新版本为准

## 常见问题
### 文件被其他程序抢关联了怎么办？

在系统「默认应用」设置里把 docx/xlsx/pptx/pdf 指回察元AI Office 即可。

### 遇到 bug 去哪反馈？

GitHub 仓库提 issue，或通过官网渠道反馈；项目有 75 个端到端测试用例保障迭代质量。

### 能改 PDF 里的文字吗？

能。PDF 编辑器做的是真文本编辑：段落选中、块内重排、原字体保留，通过重写页面内容流实现，不是贴图遮盖。
