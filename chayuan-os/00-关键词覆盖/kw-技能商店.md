# 技能商店入门指南：应用商店里都有什么

关于技能商店，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是技能商店

技能商店这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

全部口径出自aidooo.com官方文档，版本对应关系见文末。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| mcpTools | 86 个 MCP 工具（2026 年 10 月实测） |
| kbPort | 52582（知识库对外服务，固定端口） |
| storeCats | 插件、技能、MCP 插件、智能体、技能包五大类 |

## 在察元AI OS里落在哪

技能商店在察元AI OS里的落点是应用商店与智能广场：应用商店对接察元AI 能力广场（aidooo.com）：插件、技能、技能包、MCP 插件、智能体五类内容在线下载与云端推送更新，聚合全球生态资源并配排行榜；内网环境走离线包导入。

为什么值得单独说：能力不是写死在系统里的，是从商店长出来的，越用越全。

## 最短上手路径

试一遍就明白：

第 3 步 · 插件（桌面插件目录）

1. 来源 pills：桌面形态默认「npm」；host/web 形态可选「npm」「npmmirror 镜像」「社区精选」（自定义社区源经设置追加）。部分源带分类 pills（全部/工具/界面/知识/实用/集成/安全/智能体）。
2. 空搜索即浏览全部（提示「浏览全部插件」）；输入关键词点「搜索」出「{n} 个结果+」。列表滚动到底自动加载，尽头显示「没有更多了」。
3. 每条：包名、描述、版本、发布者、来源徽标（npm / git 仓库）；点「安装」＞「安装中…」＞ 装完变「已安装」；无安装地址的条目按钮为「仅展示」。
4. 装完后底部出现黄色提示条「插件已变化，重新启动后生效」＋「重新启动」按钮（重启 dsh 运行时后生效）。插件装到应用管理「插件」页签统一管理。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### MCP 广场报「察元能力广场限流（HTTP 429）」？

上游目录限流，自动加载已暂停；稍等片刻点错误行右侧「重试」按当前进度续页，或先用「精选目录」源。

### 技能商店要联网吗

插件、技能、MCP 插件、智能体、技能包五大类，保存后随系统技能分发到智能体，断网时联网搜索自然不可用。以官网 aidooo.com 当前页面为准。

### 技能商店数据存在哪

断网可用、数据不出本机；插件、技能、MCP 插件、智能体、技能包五大类；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。以官网 aidooo.com 当前页面为准。

## 更多操作细节

第 4 步 · MCP 插件（能力广场目录）

1. 提示行「安装后注册为 MCP 服务器并同步到各智能体」。来源 pills：「察元能力广场」（默认，服务端分页目录——代码注释标注其收录 6600+ 条，界面实际显示「{n} 个 MCP 服务器 / {total}」以服务端返回的总数为准）、「精选目录」（内置种子清单，不走网络）、「＋ 添加目录源」（展开后填「源名称」「目录 JSON URL（https://…）」点「添加」接入自定义目录）。
2. 工具栏搜索框做服务端检索（占位「搜索能力广场，或输入关键词筛选…」），面板内另有本地过滤框「筛选 MCP…」。列表滚动到底自动翻页。
3. 每条：名称/发布者/类型徽标（远端/本地命令/仓库）/描述/标签。按钮二态「安装」/「卸载」；仓库型（无标准化接入配置）只有「查看仓库」跳官方仓库。
4. 安装 = 写入本机 MCP 清单并同步进支持 MCP 的智能体配置，日志「已安装 MCP：{name}（已同步到各智能体）」。限流时提示「察元能力广场限流（HTTP 429），已停止自动加载，稍后可重试。」，点「重试」续页。

## 更多操作细节

第 5 步 · 智能体 / 技能页签

1. 「智能体」：16 行 CLI 智能体清单，npm 一键安装/升级、Cursor CLI 官方脚本、Aider/Goose 自装探测——完整流程见对应教程，能力矩阵见对应教程。
2. 「技能」：技能源 pills「精选」「GitHub 仓库」；搜索占位「搜索 GitHub 技能仓库（owner/repo 或关键词）…」，计数「{n} 个技能仓库」。每条显示仓库、 star、徽标「技能仓库 ＞ ~/.dsh/skills」；点「安装」下载 tarball 校验解压进 ~/.dsh/skills/，日志「已安装技能：{names}」「（已存在跳过：{names}）」。
