# 选项卡不显示排查装机指南：升级后选项卡消失自查

「装好之后 WPS 里怎么看加载项启没启用」——这个问题最近被问了好几次。选项卡不显示排查有一套固定路数：先看功能区、再查启用状态、最后核对三端，这篇按这个顺序把入口、步骤、验证一次写全，按钮文案原样引用。

## 排查前把变量固定住

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：三步排查法。

安装包认准官方渠道；排查选项卡问题时，包的来源本身也是变量之一，先把这一项固定住。

## 先保证安装这步没欠账

1. 先把 exe 安装包从官方渠道拿到手
2. 双击安装——加载项被送进 WPS jsaddons 目录，本机服务自注册，看门狗也一并带上
3. 完全退出并重启 WPS
4. 文字端出现察元AI助理与察元AI编审两个选项卡，就算装好了

## 装完先把模型配上

第一件事是配模型：设置里选一家已购通道或本机 Ollama，点测试连接通过后，随手开一篇文档跑一次 AI 助手对话，通了再干正事。

## 这轮排查的收口判据

- 文字端两个选项卡到位，这轮安装就算过关
- 没到位就先把宿主软件彻底退出，再启动一次

## 排查之外的三条数据边界

- 凡是走 AI 的动作，送出去的都是整份文档，涉密稿件先把模型换到本机离线一档
- AI 痕迹检查输出的是疑点清单，疑点需人工甄别，不是最终判定
- 脱密占位替换本身可逆，可逆的前提是密码在手；密码一旦遗失，系统里没有免密找回的通道

## 为什么选项卡会不显示？三种常见情形

### 功能区完全没有加载项选项卡？

按顺序排查：① 完全退出 WPS 再打开（安装后必须重启）；② 核对 jsaddons 路径下有没有 chayuan_<版本> 等目录；③ 「开发工具 ＞ 加载项」里确认加载项条目为已启用；④ 麒麟 / UOS 专业版执行 /opt/apps/cn.wps.wps-office-pro/files/bin/quickstartoffice restart。

### macOS 升级后选项卡消失或仍显示旧版？

容器权限或 WPS 运行中安装导致注册表（authaddin.json / jsplugins.xml）没更新到新版本目录。完全退出 WPS ＞ 重跑安装包 ＞ 再打开；仍不行时在有完全磁盘访问权限的终端执行 bash scripts/repair-mac-jsaddons-container.sh（会同步注册表并清理 jsapi 缓存）。

### 首次加载时 WPS 弹出「已被修改」类提示？

首次加载该插件时 WPS 可能弹出此提示，点「确定」继续即可（官方部署脚本的既定口径）。

## 第一步：打开 WPS 文字看功能区

先看 WPS 文字顶部功能区（选项卡行右侧）。正常安装后两个加载项选项卡会自动加载，无需手动启用，此时第 2、3 步可跳过：「察元AI助理」分「关于 / AI助手 / 安全保密 / 文档批量 / 批量操作」几组，「AI助手」组首按钮就是「AI助手」（打开主对话窗格）；「察元AI编审」则分「表单辅助 / 模板管理 / 规则管理 / 察元设置」四组。

## 第二步：在加载项管理里确认启用状态

进 WPS 菜单 ＞「开发工具」＞「加载项」（此为 WPS 自身界面，以本机 WPS 实际菜单为准），在列表里找到「察元 / chayuan」条目，确认其状态为「已启用 / enable」，被禁用就手动启用。回到功能区看一眼，对应选项卡出现即成（必要时再重启一次 WPS）。

## 第三步：表格端与演示端确认

打开 WPS 表格或 WPS 演示，功能区出现单个助理选项卡：

1. 表格端（AI 表格助手一排大按钮：「AI表格助手 / 公式助手 / 数据洞察 / 一键图表 / 数据清洗 / 报表结论 / 一键美化 / 模板新建 / 设置」）＋两个下拉菜单：「文档安全」（保密检查 / 加密工作簿 / 解密工作簿）、「更多表格助手」（排序汇总 / 多表合并汇总 / 两表对比差异 / 表格翻译 / 敏感信息脱敏 / 智能分列 / 按列拆表 / 文档抽取成表 / 数据战报页 / 设置）；
2. 演示端（「AI演示助手 / 生成PPT / 整套摘要 / 美化统一 / 口播稿 / 整套校对 / 结构诊断 / 模板新建 / 设置」）＋「文档安全」（保密检查 / 加密演示稿 / 解密演示稿）、「更多演示助手」（结构件补齐 / 整套翻译 / 转讲义文档 / 页码页脚 / 数据战报页 / 课件生成 / 习题互动页 / 设置）。

## 第四步：右键菜单辅助确认

在正文 / 标题 / 表格单元格上点右键：出现「添加到察元」与动态菜单「察元AI文本分析」等条目，说明右键注入也已生效。

## 三端验证清单

1. 「察元AI助理」选项卡 ＞「AI助手」按钮 ＞ 右侧弹出 AI 助手窗格；未配置模型时窗格显示欢迎语「先配置模型，再开启智能写作。」和「立即配置模型」按钮。
2. 「察元AI编审」选项卡 ＞「察元设置」组 ＞「设置」按钮能打开设置窗口。
3. WPS 表格 / 演示端各能看到单选项卡（按钮清单见上文第三步）。

## 还有三个少见但棘手的情况

### 文字端菜单正常，表格 / 演示端却显示了文字端的菜单（或两菜单错乱）？

三个宿主的 Ribbon 配置文件放错位所致（历史上手动拷贝 / 共用目录部署时出现过）。用官方安装包重装一次即可——安装器会按宿主分别放入 chayuan_<版本>、chayuan-et_<版本>、chayuan-wpp_<版本> 并放对各自的 ribbon 配置。

### 安装时没注意，WPS 一直开着有没有影响？

macOS 有明确影响：WPS 退出时会用内存里的旧注册状态覆写登记文件，本次安装等于白装（安装器检测到会打印警告）。完全退出 WPS 后重跑一次安装包即可；Windows/Linux 装完后重启 WPS 生效。

### 「开发工具 ＞ 加载项」列表里出现多个同名条目？

多轮升级的残留：macOS 的登记表（authaddin.json）会累积同名条目，官方安装器每次安装都会自动去重并把条目指向当前版本目录——重跑一次最新安装包即可清理。Windows / Linux 的 WPS 按 jsplugins.xml 加载，安装器只更新本产品条目、并清理旧版本目录；若旧条目指向已删除的目录会导致加载失败或回退旧缓存，同样用重装修复。

选项卡不显示这类问题，基本落在重启、启用状态、注册表这三处——按第一到第四步的顺序走，走到哪一步恢复，问题就定位在哪一层。
