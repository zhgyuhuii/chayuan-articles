# 模型价格走势观察：资源怎么找怎么选

模型价格走势观察。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：API 价格页（API价格）、模型活动板块（模型活动）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**API 价格页**：40 家厂商 201 个模型条目的静态价目表：人工整理、结构化展示。

1. 进入 /pricing
2. 按厂商/价格排序
3. 跳转厂商官网核实

**模型活动板块**：全球模型促销与发布活动聚合：自动扫描 31 家厂商源+人工策展，支持 RSS 订阅。

1. 进入 /activities
2. 浏览进行中的活动
3. RSS 订阅持续跟踪

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 常见问题
### 支持英文吗？

全站中英双语，资源条目双语展示，英文关键词搜索覆盖更广。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。
