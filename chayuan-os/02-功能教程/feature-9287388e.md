# 会议与语音工作流（察元OS速查手册）

语音记录、投屏共享、日程落地。这套组合工作流把语音输入与语音记录→共享桌面→便签/日历/提醒/联系人串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

语音记录、投屏共享、日程落地。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·语音输入与语音记录**：对话框麦克风本地 whisper 转写回填；桌面右键贴顶长条录音 V2 边说边出字（VAD 静音切分+逐段转写上屏）；piper 中文语音合成。

1. 对话输入框点麦克风说话
2. 或桌面右键开启语音记录长条
3. 说完自动转写上屏

**第 2 步·共享桌面**：局域网内多用户桌面共享：权限分主机/编辑者/观看者三级，适合会议室投屏协作与远程指导。

1. 发起共享桌面
2. 参与者按权限观看或操作
3. 结束共享自动断开

**第 3 步·便签/日历/提醒/联系人**：系统级个人信息管理四件套：便签贴桌面、日历日程、提醒事项、联系人，全部可被智能体通过控制面读写。

1. Dock 打开对应应用
2. 手动或让 AI 添加日程提醒
3. 智能体可读取作为上下文

## 衔接点与易错处

- 本地转写不上传录音
- 纯局域网不经过公网
- 「帮我明早九点提醒开会」一句话落地

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 常见问题
### 其他软件能用本机模型吗？

能。统一模型代理提供 OpenAI 兼容与 Anthropic 协议接口（对话/嵌入/重排/语音），任何支持的客户端指向本地代理即可。

### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 语音输入是本地的吗？

是。whisper 本地转写，录音不上传；另有贴顶语音长条「边说边出字」与 piper 中文语音合成。
