# 三审三校实操入门指南：AI 助手组大按钮拼写与语法检查

三审三校实操这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI文档助手为例。

## 什么是三审三校实操

三审三校实操这个说法对应的产品是察元AI文档助手（Chayuan AI Document Assistant）：WPS 三端智能加载项，校对、编审、核对、脱密，一个文档智能体。北京智灵鸟科技中心出品。

本文数字与版本口径以官方文档为准，文末尾注标了截止时间。

## 平台与形态

支持的系统与形态：Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）。

## 最短上手路径

试一遍就明白：

5. 对话里也可以校对（MCP 链路）

1. 在哪：AI 助手窗格开启文档智能体后，直接对 AI 说「校对一下这篇文档」。
2. 看到什么：模型跑校对任务后，消息里出现「校对结果」卡（汇总发现 N 处问题），下方两个按钮：「写成批注」和「直接改正正文」——选哪个由你决定，不会不打招呼就改正文；本轮修改前已创建快照时还有「一键撤销」卡。

## 落点的能力面

- 选区全文两档
- 分块并发
- 批注锚定

## 察元AI文档助手的能力地图

- 设置面板总览：设置面板一站式：模型清单管理、助手设置（默认写回动作可改）、网络与升级等。
- AI 助手窗格摆放：AI 窗格支持浮窗与停靠两种形态，位置随手的习惯走。
- 对话与多会话：对话窗格多会话页签，历史按文档隔离：换一份文档就是一套会话上下文。

## 实话实说：哪些人不必急着装

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- Win7/8 能装加载项但 MCP 预编译二进制跑不了，需要 Node.js 16 回落

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- 每次确认写操作记入 audit.jsonl 审计日志
- 保密检查只做辅助筛查，关键词命中不等于泄密，不构成定密结论
- 脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原

## 价格口径

- 免费有每日额度（对话与助手独立额度池，次日重置）

## 你可能会问

### 报「请先在设置中配置拼写与语法检查模型」？

说明默认对话模型也没配好。到设置里配好对话模型，或在设置里专门指定「拼写与语法检查模型」后重试。

### 检查会直接改动我的正文吗？

不会。检查结果只加批注；要把建议落到正文，用对话链路「校对结果」卡上的「直接改正正文」按钮（按定位逐处安全替换，定位不稳的自动降级为批注），或按批注手动修改。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### 支持哪些系统？

Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）；前提是已装 WPS Office。

### 三审三校实操要联网吗

任务进度窗统一展示后台任务，确认写回按钮集中把关，支持一键撤销（有快照时），批量任务跑完先看再落盘，写错了能撤回，胆子才能大起来；文本转图像与文本转视频按钮预填多模态提示词进对话，按对应类型模型生成。以官网 aidooo.com 当前页面为准。

## 更多操作细节

1. 发起检查

1. 在哪：顶部工具栏「AI 助手」分组的大按钮「拼写与语法检查」。
2. 看到什么（按选区分流）：
    1. 有选中（不少于 2 个字符）：直接以「选中」模式启动，只检查选中内容；
    2. 无选中：弹确认框「当前未选中文档内容，将对全文执行“拼写与语法检查”。 点击“确定”后开始处理全文。」——全文超过 12000 字时附加「当前内容较长，处理可能需要更久，请耐心等待。」，超过 30000 字时附加「当前内容很长，处理时间可能较久，并可能触发分段或较长响应，请确认后继续。」；点「确定」开始，「取消」不执行；
    3. 文档没有正文：提示「当前文档没有可检查的正文内容」。

## 更多操作细节

2. 读进度窗

1. 看到什么：独立提示窗，标题「拼写与语法检查」（选区模式为「拼写与语法检查（选中）」），标题旁状态徽章：准备中 / 进行中 / 已完成 / 失败 / 异常结束 / 已停止。
2. 副标题固定一行：「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」
3. 进度区：「正在检查：第 x / y 段」+ 百分比进度条 +「当前检查内容」卡显示正在检查的原文片段。
4. 右上按钮：「停止任务」（仅任务运行中显示）和「关闭」。
5. 完成时显示「已完成，共添加 N 处批注」，随后提示「即将自动关闭」并自动关窗；停止后显示「任务已停止」。
6. 底部提示：「可在「任务清单」中查看详细进度；关闭此提示窗不会停止任务。」

## 更多操作细节

3. 看结果：批注钉在原文上

1. 看到什么：每处问题在原文对应位置加一条批注。模型按结构化 JSON 返回每个问题的问题片段、建议改法、原因、所在整句和前后各最多 12 个字的锚定上下文；程序按「原文查找 ＞ 范围复核」把批注精确钉到问题文字上（表格里的坐标漂移会自动重定位，钉不上就不硬挂）。
2. 批注内容格式：「<原因>: 建议改为「<建议>」」（无建议时只写原因），例如「错别字: 建议改为「作业」」。
