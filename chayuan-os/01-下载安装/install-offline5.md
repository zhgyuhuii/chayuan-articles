# 离线部署五步法安装：政企内网的标准部署路径

离线部署五步法，面向政企内网这类装完就不联网的机器。这篇在察元AI OS上按真实界面顺序把部署走完，从取包到验收的每个环节都交代清楚，隔网环境的特殊口径也单独列出。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：政企内网的标准部署路径。

安装包先从官方渠道下到有外网的机器，再用介质摆渡进内网，隔离环境不直连下载。

## 实操全过程

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

四步在内网机器上通常一口气做完；真正的分水岭在第四步——机器此后不再联网，本地模型链路就是它所有 AI 能力的来源，权重文件提前经介质摆渡进来，才谈得上离线即用。

## 摆渡进内网的两点实操

介质摆渡这一步有两条纪律值得写进部署单：一是包的校验在进内网前完成——在外网机器上核对文件大小与完整性，进了内网再发现包损坏，来回又是一趟；二是摆渡介质专用，装过其他来路不明文件的 U 盘不要用于生产内网，装机现场最常见的污染源就是随手一支盘。

## 怎么确认做成了

- 桌面可进、对话应用选本地模型能应答，两条都满足才算装成
- 初始化用时 5 到 30 秒都属正常现象，无需人工干预

验收时顺手把 uname -m 的输出、包文件名、装机日期记进台账，日后升级按架构取包不会发错。

## 隔离环境的边界清单

先把做不到的事说明白：

- 云端厂商模型用自己申请的 API Key，包里不带
- Docker 云桌面、跨终端互联这类进阶形态得会一点运维
- 龙芯平台暂无适配；视频生成本机做不了，走云端路由
- 8GB 内存档的机器对话模型一次只装一个，复杂任务会受限

## 内网里的协作与反馈入口

部署完成后，内网里也有完整的协作面：tar 包离线迁移可用；与配对终端能互发消息附件、让对方智能体执行任务，消息离线暂存、可达时送达，对端状态看武力值徽标（信号格加等效算力）。反馈与求助走产品内的提交反馈与帮助中心——六节手册加搜索都离线可读。

## 无人值守与数据卫生

值守类的活可以交给系统：周期巡检、每天早报、定时盯数据这类任务排给智能体，早上来收报告即可。数据卫生两条：遥测可关、清除桌面数据有警示（破坏性操作）；升级不丢数据是底线，检查更新静默失败也不影响使用。

## 网页与云桌面形态

web 与 docker 形态提供 9 位字母外网后缀访问链接，带 wa 会话管理与踢线操作；内置浏览器窗配合 webwindows 可被智能体驱动；整套系统还能无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态），员工浏览器打开即用。Dock 的文生图应用支持提示词加负面提示词，生成结果可设为壁纸或开 30 分钟自动换壁纸。

## 模型接入与内置素材的免费范围

接云端模型需要相应平台的 Key（部分有免费额度）；内置素材侧，形象可从灵宠商店免费获取、也可工坊自定义，内置场景免费切换，场景、形象、元素、主题包四个页签的东西全部免费，下载带进度与失败重试。

## 与察元AI Office 的联动

这套系统与办公套件是打通的：Dock 直开内置的察元AI Office，文档、表格、演示在线编辑；OS 授权生效后，同机的察元AI Office 自动免激活。Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，按三层检查能定位到具体一层。激活走离线短码：HMAC 签发、绑定 16 位机器指纹、本地验签。

## 默认模型的重跑入口

默认对话模型在 设置＞模型＞设置向导 里定，之后想换，重跑一遍向导就行，不必重装。定位上，本地模型管的是有没有，复杂任务仍要靠云端旗舰模型。

## 本地权重的放置与扫描

本地权重的来源有固定口径：按直链目录放置后，执行「扫描本地放置的模型」把它们登记进来；whisper 语音权重同样在支持之列。手动加载卸载叠加自动卸载策略，内存才守得住预算。

## 知识库的建库与图谱

知识库这条线的能力可以说清：三级优先级；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；导入零门槛，拖进去点加载两步完事——这是知识库能不能被用起来的第一道坎。知识图谱页签会自动生成文档与实体的二部图，点实体或文档可互跳、定位来源、重新生成。

## 装完之后的日常维护

内网机器装完不是终点：插件更新、权重补装、数据备份都走离线通道——从有外网的机器取回新版本，经摆渡介质转入后离线完成；数据定期用 tar 包做离线备份，涉密环境的审计日志定期回放检查。这些动作都不破坏隔离性，也都不需要临时开网。

这篇把离线部署五步法的链路拆完了。哪一步卡住，回「隔离环境的边界清单」与「本地权重的放置与扫描」对照。
