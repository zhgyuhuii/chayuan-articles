# 模型会话中热切换：用会话切模型跑通一个真实场景

会话切模型的麻烦不在功能本身，在于信息散。工具调用可视化是它和网页聊天框的本质区别：这篇把它收拢成一条能照着走的路径。

## 先看看痛点对不对得上

日常问答与长文写作；想知道「智能路由 / smart/auto」是什么、怎么让对话自动分配模型，观察智能体怎么调工具干活，会话里想临时换模型——本地断网用、云端联网用，或换个更强的。

## 一步步来

5. 热更新表现（下拉实时变化）

1. 厂商侧：厂商卡「保存并启用」＞ 提示「已开启，模型下拉框即刻可见」，勾选的模型实时出现在下拉框，无需重开窗口；「停用」＞ 该厂商模型即时消失，配置保留可随时恢复；
2. 本地侧：下拉数据源是本地已安装清单——模型库下载完成或离线导入登记后进入下拉（不要求已加载）；删除权重后从下拉消失；
3. 列表刷新期间短暂空列表属正常，稍候即回。

6. 会话中切换模型

在模型下拉里直接另选一个模型即可完成切换：历史消息保留，新消息按新选的模型回答。本地 云端可来回切。

8. 智能路由（主强子弱）

```bash
curl -X POST http://127.0.0.1:52584/api/chatop-models/proxy/routing \
-H "content-type: application/json" \
-d '{"strongModel":"<厂商id>/<模型名>","lightModel":"local/<模型id>","interceptStrong":true}'
```

strongModel 必填（不含则智能路由关闭），lightModel 可空（一律走强模型），interceptStrong 开全量拦截。灵宠对话窗另有「智能路由 · 自动选择模型」直选入口。

1. 含义：模型代理的一个开关能力——把「强模型」设为主力、可选一个「轻模型」兜轻活；请求按难度分类后改写目标：带工具调用、长上下文（>6000 字符）、命中重任务关键词（规划/分析/排障/实现…）＞ 强模型；短输入（≤1200 字符）且是机械性轻活（翻译/润色/总结/改格式…）、或寒暄级短句 ＞ 轻模型；拿不准一律走强模型（质量优先）。已配置时代理模型清单会列出一个虚拟模型名 smart/auto，选它即等于「让代理替我选」。
2. 对 Harness 会话窗的生效方式：会话模型走代理档案（local (proxy)）且代理开了「全智能体拦截」（interceptStrong）时，发给强模型的轻任务会被透明降级到轻模型——会话里零配置，无感知；或在应用模型时把 smart/auto 写进模型清单，在下拉里直接选它。

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 无显式模型偏好时自动指向本地模型
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 你可能会问

### 模型下拉里看不到本地模型？

下拉只列已安装的对话/图像理解类模型。若装的是嵌入/重排/语音类，它们不进对话下拉（供知识库/语音用）；若一个对话模型都没有，去模型库下载或导入，完成即在列。

### 选本地模型发消息报「本地模型未加载」？

对话窗直连档（chatop-local）不做自动加载。两个办法：① 到 设置 ＞ 模型 给该模型点「启动」，建议顺手「钉住」防空闲卸载；② 改用经代理的 local/<id>（M9 应用后出现）——未运行时首调自动拉起，等待最长 90 秒。

### 切换模型后，之前的对话还在吗？

在。切模型只影响之后的消息用哪个模型回答，历史记录保留在同一会话里。

## 更多操作细节

1. 打开对话窗

点 Dock 上的「DeepSeek Harness」图标（品牌蓝鲸鱼标）。首次打开窗口显示加载动画「正在启动 DeepSeek Harness…」，就绪后进入会话界面。

## 更多操作细节

2. （桌面形态）全局快捷键唤起

默认 ⌥Space（Alt+Space） 在任何应用里都能唤起/聚焦会话窗：无窗新开、有窗聚焦最近一个、连按在多个会话窗间循环。开关与键位在 设置 ＞ 通用 ＞ 「全局唤起对话」改（仅桌面形态可用）。开机自动打开会话窗：设置 ＞ 桌面与 Dock ＞ 「开机自动打开 Harness」。

## 更多操作细节

3. 认识窗口与多开

窗口工具栏极简：左上红绿灯关/最小化/全屏，居中标题「DeepSeek Harness」，右侧「＋」按钮（悬停提示「新建会话窗口」）——点击再开一个独立会话窗，各窗会话互不影响。没有地址栏。

## 更多操作细节

4. 认识模型下拉（三个来源）

会话内的模型选择器列出三类条目：

1. 本地模型：来自「本地模型」提供方，= 本机已安装的对话/图像理解模型，显示名形如 Qwen3.5-4B Q4_K_M（装机即用对话）；
2. 云端厂商模型：你在 设置 ＞ 模型 里「保存并启用」过的厂商模型，状态行就叫「已开启 · 显示在 Harness 模型下拉框」；
3. 代理档案模型：经「应用到智能体」写入的 local (proxy) 档，模型名形如 local/<模型id>、<厂商id>/<模型名>。

## 更多操作细节

7. 发消息与附件

输入框输入、回车发送，回复流式输出。图片附件只有发给带「图像理解」能力的模型才有效：本地模型须是视觉档（下发时以 image 输入传给引擎）；对话-only 模型收不了图。附件的具体支持类型与大小上限：（会话输入框属 dsh 核心界面，不在察元仓库源内）。

## 更多操作细节

9. （可选）连接远程 Harness

设置 ＞ Harness 连接：「DeepSeek Harness 地址」留空用当前本机 dsh 站点；填入远程 dsh web 地址（如 http://192.168.1.5:52584）＞「测试连接」（在线/无法连接）后，新打开的会话窗将连接该远程站点，已打开的窗口不受影响。
