# OpenCode是什么

关于OpenCode，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是OpenCode

OpenCode不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

本文数字与版本口径以官方文档为准，文末尾注标了截止时间。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 价格口径

- 首运行起 90 天完全静默，之后每日首次启动弹一次购买页（可关闭）

## 你可能会问

### OpenCode要联网吗

断网时联网搜索自然不可用；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。以官网 aidooo.com 当前页面为准。

### OpenCode数据存在哪

数据文件不受影响，知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；三条路都不满足就只能清数据重装，务必提前生成恢复密钥。以官网 aidooo.com 当前页面为准。
