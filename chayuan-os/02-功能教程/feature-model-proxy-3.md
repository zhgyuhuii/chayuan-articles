# 模型代理的作用是什么：用模型网关跑通一个真实场景

用模型网关之前有一条边界要先知道：代理只监听本机回环，跨机访问需要另行打通。知道边界再用，这篇剩下的篇幅讲怎么把它用对。

## 为什么值得了解

把本地模型共享给全机软件；不明白「模型代理」是什么、向导和文档里反复提到的 52581 是干嘛的；智能体报连接不上模型，需要确认代理在不在运行、怎么验证它工作正常，想让某个智能体 / 自写脚本用上本机的本地模型和已配置厂商，但不想逐家配地址和 key。

3. 看运行状态（最上面一张卡）

1. 绿点 + 「代理运行中」，右侧灰底等宽字显示当前基址 http://127.0.0.1:52581/v1；

区底固定说明：「免 key 直连：本机任意智能体不带 key 即可用（审计归因 anonymous）；Bearer 虚拟 key 可选（上方签发，用于审计归因与吊销管控）。模型名形如 local/<id>（本地）或 <厂商>/<model>。」

5. 让智能体 / 脚本接入（怎么用）

```bash
curl http://127.0.0.1:52581/v1/chat/completions \
-H "Content-Type: application/json" \
-d '{"model":"local/<你的模型id>","messages":[{"role":"user","content":"你好"}]}'
```

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- 云端厂商模型调用需自备 API Key
- 代理只监听本机回环，跨机访问需要另行打通
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 需要填 API key 吗？被请求会不会泄露厂商 key？

不需要也不会。代理只监听本机回环、免 key 直连；转发云端时真实厂商 key 由代理在本机凭证库（~/.dsh/.credentials.yaml）里解析并只在服务端注入，调用方永远接触不到。

### 能从局域网其他电脑访问这个代理吗？

不能。代理只接受本机回环请求，其余一律 403 loopback-only。这是设计行为：密钥与模型都在本机，不对外暴露。

### 调本地模型第一次特别慢，是不是坏了？

大概率是代理在自动拉起模型：已安装未运行的 local/<id> 首调会触发加载（引擎进程启动 + 权重加载 + 健康检查），大模型需要等待。想常驻不冷启动，去 设置 ＞ 模型 ＞ 我的模型 手动「启动」并「钉住」。

## 更多操作细节

验证

1. 浏览器打开 http://127.0.0.1:52581/health：返回 {"ok":true,"service":"chatop-model-proxy"} 即代理在运行。
2. 浏览器打开 http://127.0.0.1:52581/v1/models（免 key）：返回 JSON {"object":"list","data":[...]}——已安装本地模型是 local/<id> 条目（带 running 运行标记与 capabilities 能力数组），已加入代理的厂商是 <厂商id>/<模型名> 条目。
3. 代理设置页顶部显示绿点「代理运行中」，基址代码块为 http://127.0.0.1:52581/v1。
4. 发一次真实调用（上面 curl 示例换成自己的模型名）：正常返回聊天 JSON；调未运行的本地模型首次会有加载等待。

## 动手前再核对一遍

- 无需任何配置：代理随本地模型服务（chatop-models）自启，端口按注册表写死 52581（一号一口，不顺延、不换号；被占时由桌面启动序清场保证原位可用）。
- 只监听本机回环（127.0.0.1 / ::1），本机之外的请求一律 403——局域网其他设备不能直接调用。
- 调 local/<id> 需该模型已下载 / 导入；调 <厂商id>/<模型名> 需该厂商已启用并加入代理路由。

## 放回产品盘面看

把模型网关放回察元AI OS的整体盘面：配置入口在设置＞默认模型＞网络资源页签；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。

## 安全与数据边界

安全口径单独立一层：厂商、类型、模型三级树选择；不同宠配不同模型是群聊多模型讨论的前提，轻任务宠配小模型、主力宠配旗舰；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；双击模型直跑灵宠直达。

## 平台与形态

平台与形态的账：断网时云端模型不可用，可设自动回落本地，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑，GB 内存建议一次只加载一个对话模型。

## 价格与授权

价格口径一并交代：两条路：自动一键把代理地址加模型写入五家（备份可回退），模型清单动态生成，与知识库、模型联动；共享同一个模型代理。
