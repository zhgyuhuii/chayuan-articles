# 本地模型去哪里下载：本地LLM概念与上手

本地LLM这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是本地LLM

本地LLM不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 平台与形态

平台覆盖：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

本地LLM在察元AI OS里的落点是下载本地模型：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），支持断点续传，下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

为什么值得单独说：断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 怎么删掉下错的模型？

「我的模型」行内「删除」＞ 确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」运行中的模型要先「停用」再删。注意权重全机一份，删除影响本机所有用户；「装机即用」五件套权重随安装包分发、不占额外磁盘，无需删除。

### 下载前要预留多少磁盘？

系统自动预检：模型体积 × 1.05 + 200MB；不足时报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 启动报「二进制缺失 / 引擎缺失」？

推理引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；恢复方法详见帮助中心「引擎二进制」。

### 检查更新失败？

更新需要联网访问官网接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

## 更多操作细节

2. 认识状态条（顶部）

1. 健康灯 + 文字：「正常」（绿）/「引擎异常」（黄）/「不可达」（红）/「已停用」（灰）/「引擎缺失」（黄）；
2. 实例计数：「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示「空闲自动卸载策略」）：「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，默认 15 分钟；
4. 「重启全部」「全部关闭」：点击后行内出现红色二次确认条——「重启全部运行中的模型？」/「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，点「好」执行、「取消」收回；
5. 服务被停用时，此处只剩「启动」按钮。
