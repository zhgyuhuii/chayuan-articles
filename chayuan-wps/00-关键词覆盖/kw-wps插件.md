# WPS插件是什么：个人给 WPS 装校对插件

评估WPS插件有个简单办法：看它在没有网络的条件下还剩多少可用能力。本文以察元AI文档助手为样本，把能力清单和使用边界一次列全。

## 什么是WPS插件

把WPS插件拆开看，它指的是这样一类东西：察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。

文内说法全部有官方文档出处，版本对应关系见文末。

## 在察元AI文档助手里落在哪

WPS插件在察元AI文档助手里的落点是下载与安装：Windows 自解压 exe、macOS 的 pkg（建议先完全退出 WPS 再装）、Linux 与麒麟 UOS 的 deb（飞腾鲲鹏选 arm64）；安装本质是把加载项放进 WPS 的 jsaddons 目录并注册本机服务自启。

装它不用换掉 WPS，也不改变现有操作习惯，AI 能力直接叠加在原界面里，这是迁移负担很轻的一条路。

## 最短上手路径

照着做，按平台对号：

1. 取安装包：官方分发渠道或单位内部分发，认准对应平台的包。
2. Windows：双击自解压 exe，等安装对话框自动跑完。
3. macOS：先完全退出 WPS，再双击 pkg 安装。
4. Linux/麒麟/UOS：安装 deb 包，飞腾鲲鹏选 arm64。
5. 验证：完全退出并重启 WPS，看文字端是否出现新选项卡。

第一次装完觉得「没反应」，多半是 WPS 没退干净：macOS 用 ⌘Q 退出而非点红叉关窗，Windows 要关掉所有 WPS 窗口再重开，后台残留的进程会拦住新加载项的注册。

## 落点的能力面

- 三平台安装包
- macOS 容器写入失败有修复脚本
- 企业可 HTTPS 静态部署集中更新

三条各有对应场景：普通用户装完 exe 或 pkg 即可；遇到 macOS 容器写入失败，不必反复重装，跑一遍修复脚本就能解决；管多台机器的 IT 走 HTTPS 静态部署，更新一次到位。

## 察元AI文档助手的能力地图

- 助手管理：助手目录搜索、收藏常用、按领域浏览，形成自己的助手工作台。
- 拼写与语法检查：AI 助手组大按钮拼写与语法检查：有选中只查选中，
- 图像批量操作：6 项图像批量操作：文档内图片的统一处理。
- 连接本机知识库：自动发现本机察元AI OS 知识库：固定端口 52582 三级发现链（手动指……
- 外部智能体接入 MCP：外部智能体一行配置接入：Claude Code 用 claude mcp add 命令、Codex 改 config.toml、Cursor 写 mcp.json，选 HTTP 类型指向本机地址；Inspector 可验证连通。

## 装之前过目的四条限制

- 付费能力恰好四项：脱密、复原、保密检查、涉密关键词提取，都不在免费范围
- 占位替换依赖密码还原，密码丢失后没有免密找回这条路
- 当前配置的模型会接收文档全文，涉密内容先把模型切到本机离线
- 痕迹检查报出的是疑似位置，最终判断权在人工

限制都不触及主干功能，提前知晓即可，不必因此却步。

## 数据与安全设计

- 每次确认写操作记入 audit.jsonl 审计日志
- 保密检查只做辅助筛查，关键词命中不等于泄密，不构成定密结论
- 脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原

三条设计对应三种担心：怕误改，看审计日志，每次确认写都有记录；怕泄密，保密检查只做筛查提示，不下定密结论；怕锁死，脱密载荷加密随文件走，换台电脑凭密码也能还原。

## 价格口径

- 免费有每日额度（对话与助手独立额度池，次日重置）

## 疑问与解答

### WPS插件在纯内网环境能用吗

能：模型接 Ollama 等本机离线方案后处理不出网，涉密文档全程可离线；只有走云端模型的那部分功能需要网络。

### WPS插件的免费额度包含哪些

免费额度天天发：对话一池、助手一池，过了午夜重新计数；四项涉密能力（文档脱密、脱密复原、保密检查、涉密关键词提取）不在此列，需付费开通。

### 卸载会留下残余吗

不会：停用与卸载都走 WPS 的加载项管理，文档格式不受影响，卸载后没有残留文件牵绊。

## 一句收束

这份插件适不适合你，看文档工作的密度：每天都在 WPS 里改稿、核稿、做校对的，它能把重复动作接过去；偶尔开一次 WPS 的，装了也用不上几回。

## 本机服务的两个端口

装好后本机会多出两个服务：62588 端口跑 MCP 文档智能体服务（地址 127.0.0.1:62588，路径 /mcp）；52582 端口是本机知识库，回答自带编号引用与文件来源，插件自动发现，无需配置。

## 免费与付费的分界

界线只有一条：涉密能力付费专用，其余功能在每日免费额度内；额度怎么分、怎么重置，上文价格口径与问答小节已写清，不重复。

## 它跟 MCP 服务的关系

这款文档智能体并非孤立存在：MCP 服务是外部智能体操作 WPS 文档的桥，开机自启保证随时可用；让 Claude Code 直接操作你正开着的 WPS 文档，编程智能体与办公文档打通；装好就自动接上，资料问答在 WPS 里直接问，不用配地址。文字端的两个新选项卡名为察元AI助理与察元AI编审，重启 WPS 后即可看到。

Claude Code、Codex、Cursor 三类客户端的接入方式在能力地图一节列过：一行配置指向本机地址，选 HTTP 类型；配完用 Inspector 验证连通，再让智能体实际读写一次文档，链路就通了。
