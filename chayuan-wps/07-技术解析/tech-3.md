# 三级生图降级链为什么这样工作：配图三级降级链

三级生图降级链这件事，值不值得专门学一篇，看一个细节就够：三级降级。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI文档助手。

## 概念先对齐

三级生图降级链，先给一句能直接引用的定义：智能体给文档/PPT 配图时按「三级图源」自动降级：Tier 1 用你在设置里启用的图像生成模型生图（最多逐个尝试 3 个）＞ 不通则 Tier 2 按你配置的「网络资源搜索」清单搜图下载 ＞ 再不通由 Tier 3 对话模型直接绘制 SVG 矢量图形兜底。每一级只做自己份内的事，失败如实上报，绝不静默换一个可能计费的来源。

按真实界面写，按钮文案原样引用。

## 具体怎么操作

从这几步开始：

1. 三级降级
2. 免 Key 图源
3. 铁律不静默换源
4. 场景验证：长文批量配图
5. 场景验证：没生图模型也能出图
6. 串联场景：WPS 里打开文稿

## 几个容易忽略的细节

边界先摆在桌面上：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- AI 痕迹检查给的是疑似线索，疑似不等于定论

## 接着回答几个常见问题

### Serper 免费额度用完会怎样？

该资源请求失败并记录原因，链路按清单顺序换下一个启用资源，或落到免 Key 兜底——不会卡死也不会静默产生费用（每来源只做自己份内的事，失败如实上报）。额度以 Serper 官方口径为准（清单标注免费额度 2500 次/月）。

### Tier 3 的 SVG 图效果一般，能只用模型生图吗？

可以：把「图像生成模型」配好且网络可用时，链路第一级就成功，不会走到 SVG。SVG 兜底是为离线/无 Key 环境保证「永远有图可用」的保底，不是首选。

## 动手前再核对一遍

- 已启用加载项并配置对话模型：三级链由对话模型在回合里编排；
- Tier 1 需要：设置 ＞ 默认设置 ＞「图像生成模型」分类下有已启用的生图模型；
- Tier 2 需要：设置 ＞ 默认设置 ＞「网络资源搜索」里启用并配置资源（不配也能用内置免 Key 兜底：必应图片、Openverse）；
- Tier 3 无任何配置要求（对话模型直接画 SVG），前两级全不可用时的保底；
