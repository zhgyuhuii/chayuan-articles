# 国产系统AI实战：AI 桌面操作系统

先说这篇能帮你干什么：读完能在察元AI OS里独立完成国产系统AI，路径是给政企用户完整的桌面迁移体验。步骤里的每个「」按钮都是界面原文。

1. 麒麟与 UOS 上能用的 AI 软件少
2. 飞腾鲲鹏架构兼容性存疑

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

场景提醒：暂不支持龙芯平台。

## 安全与数据边界

安全口径单独立一层：它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭；智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；桌面本身能被 AI 定义，能力边界从预装走向按需生成；断网可用、数据不出本机。

## 平台与形态

平台与形态的账：数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，智能体动系统能力分级确认：T0 只读直放。

## 价格与授权

价格口径一并交代：跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定，需要相应平台的 Key（部分有免费额度），形象可从灵宠商店免费获取，也可工坊自定义，内置场景免费切换，场景、形象、元素、主题包四个页签，全部免费获取，带下载进度与失败重试。

## 产品家族与搭配

察元AI OS不是单打独斗：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。

## 几条硬数字

能落到数字上的几条：local 星号开头的本地模型未运行自动加载；本地模型按需自动加载，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 离线与内网

离线内网这条线的口径：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；断网时云端模型不可用，可设自动回落本地，断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑；帮助中心离线可读，断网也能查手册。
