# 人力资源AI方案：AI 桌面操作系统

## 人力资源为什么需要这套方案

人力资源行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把联网搜索配置跑通，验证环境与模型可用
2. 流程层：人力资源日常最高频的文档环节（应用商店与智能广场所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 联网搜索配置

- 五家搜索源可配
- 图片搜索与图库平台支持
- 默认内置 web_search 工具多档兜底

### 应用商店与智能广场

- 五大类内容
- 排行榜发现好物
- 云端推送更新

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

## 进阶能力组合

跑顺基础流程后，这些能力可以继续提效：

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型

### 本地模型运行管理

- 内存仪表实时显示占用
- 启动参数四档可调

### 全局默认模型

- 11 类任务独立设置
- 自动模式本地优先

## 一个行业侧影

资料重度用户的典型链路：

1. 知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载
2. 混合检索加可选重排保证命中质量
3. 引用式问答每个观点带编号脚注
4. 点脚注跳回原文核对并下载源文件

私有资料变成可信可溯源的问答库。

提醒：单文件 48MB 上限，超限拆分后再传。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

## 放回产品盘面看

把人力资源AI方案放回察元AI OS的整体盘面：购买 OS 授权后，同机察元AI Office 自动免激活；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感。

## 安全与数据边界

安全口径单独立一层：（本机 MCP HTTP 服务，回环免 token），敏感操作全部写审计日志 audit.jsonl，可回放检查，远端调用以远端访客身份过对端权限门并留审计，API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。

## 平台与形态

平台与形态的账：Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；每次产出 markdown 报告落盘归档。

## 价格与授权

价格口径一并交代：聚合全球生态资源并配排行榜；右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入，键盘党的启动器：一个快捷键管启动、找文件、直接问 AI 三件事。

## 产品家族与搭配

察元AI OS不是单打独斗：配置入口在设置＞默认模型＞网络资源页签，灵宠把后台跑着的 AI 变成桌面上看得见的小生物；做方案对比、头脑风暴、交叉验证都直观；AI 纪要一键生成。

## 几条硬数字

能落到数字上的几条：给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，写入的是代理地址，代理停了智能体就连不上模型，会话中随时切换模型（本地与已启用厂商热更新）；模型会话中热切换。

## 离线与内网

离线内网这条线的口径：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；插件启停卸载、离线安装，装了什么、开了什么，需要一个总账页面，离线环境靠导出导入搬迁，tar 包离线迁移。

## 能力总账
