# RAG建库排查路径：知识库怎么导入文档

很多人搜「知识库怎么导入文档」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把RAG建库从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

RAG建库的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把桌面形态，已在知识库应用「文档」页选中一个库。核一遍，再查路径。

## 高频故障与对策

### 单文件上限多少？超了怎么办？

上限 48MB（代码硬编码 48×1024×1024 字节），超限文件在上传阶段即被拒绝并提示「文件过大（>48MB）」。请拆分文件后再传。

## 正确的操作路径

最短路径走一遍：（第 4 个切入角度）

1. 六种格式加扫描件 OCR
2. 自动去重
3. 进度可取消可恢复
4. 确认边界：单文件 48MB 上限，超限拆分
5. 确认边界：点加载才开始解析，上传不等于入库
6. 场景验证：把部门规章一次性灌入库

## 如何确认操作生效

验证

1. 上传完成：文档行出现，状态徽标「未加载」；此刻到右栏检索台搜文件里的词，无命中——证明「上传≠可检索」。
2. 点 加载：状态徽标依次走到「解析中 x%」「向量化中 x%」，最终变「就绪」、进度条消失。
3. 加载完成后右栏切到「检索」，输入文档中的关键词：出现带序号的命中卡（文档名 · 标题路径 ＋ 片段文本）——解析、切分、索引全部生效。

## 你可能会问

### 同一个文件传了两遍，会不会重复？

不会。上传按内容指纹自动去重（前 64KB＋字节数），重复文件不会产生第二行待加载记录（只有旧档案处于「失败」状态时不判重，以便重试）。改名不改变内容，同样会被判重。

### 加载到一半关机/系统崩了，文件要重传吗？

不用。重启后处于「解析中/向量化中」的文档自动重置为「未加载」，原文完好，再点一次「加载」即可。

### 加载时能关掉知识库窗口吗？

能。解析与向量化跑在知识库后台服务里，应用窗口只是显示进度；关窗后再打开，状态徽标会显示最新进度。

## 动手前再核对一遍

- 桌面形态，已在知识库应用「文档」页选中一个库。
- 格式与大小：支持 txt / md / markdown / log / csv / tsv / html / htm / docx / xlsx / xls / pdf；单文件 ≤ 48MB，超限报「文件过大（>48MB）」；空文件报「空文件」。
- 嵌入链路决定「向量化」这一步（解析与全文索引不需要模型）：嵌入链路可用（本机装有嵌入模型——运行中或可经模型代理自动拉起——或配了厂商/云端嵌入，见教程对应教程《知识库设置》）＞ 语义向量＋全文双路索引；完全没有任何嵌入来源时，加载依然会成功，只是只建全文索引（纯字面检索，语义检索命中为空）。设置页「测试连接」在该状态会报「没有可用的嵌入来源：本地运行时未运行嵌入模型，且云端参数/密钥未配齐」。
- 不支持格式的文件（如图片、ppt、zip）会在上传时被自动跳过，不会报错中断整批。
