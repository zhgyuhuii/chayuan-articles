开源榜单不是单一功能，是一套带入口、步骤与边界的完整能力面。智能体门户：插件、技能、MCP、提示词、大模型资源一站检索与下载。

## 在察元AI 能力广场里落在哪

开源榜单在察元AI 能力广场里的落点是开源榜单机制：榜单分热门、新品、趋势三个维度：日、周、月、季、半年、年六档周期按 star 增量计算（每日同步抓快照），无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；真实增量数据自 2026-09-15 起积累，此前的周期按星标总量排序并明确标注；失效资源自动剔除出榜。

## 你可能会问

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

### 开源榜单要注册吗

五维分数人工整理自公开榜单，配日、周、月、季、半年、年六档榜单与模型智力榜，榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜。以官网 aidooo.com 当前页面为准。

### 开源榜单资源免费吗

榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜，智能体门户：插件、技能、MCP、提示词、大模型资源一站检索与下载；配日、周、月、季、半年、年六档榜单与模型智力榜。以官网 aidooo.com 当前页面为准。
