# 📌检查段落序号格式隐藏用法｜序号格式检查一次讲清

用过察元文档助手的宝子看过来，检查段落序号格式这个功能很多人没用到极致👇

✅ **它能干嘛**

针对公文、标书、制度文件的编号体系（一、（一）、1.、（1））做一致性检查，输出分级结论与修改建议，默认不改写正文。

🔍 **三步用起来**

1️⃣ 打开公文/制度文件，发起「检查段落序号格式」
2️⃣ 查看分级结论（哪里跳号、哪里体例混用）
3️⃣ 按建议手动调整或确认后批量修正

💡 **什么场景最香**

· 红头文件的编号体系自检
· 长制度文件多人分段起草后的体例统一

📌 **避坑提醒**

⚠️ 免费版每日对话 30 次，重度使用需要付费或自建模型端点

🛠️ **更多它擅长的事**

· **文档脱密**：把确认的敏感词替换为占位符并建立密码保护的映射关系，实现可逆脱敏：对外发送脱敏版，内部留存映射可一键复原（付费功能）。
· **纠正拼写和语法**：与结构化校对互补的整段修正路径：直接产出改正后的全文或片段，适合确认无需逐条审阅、只想快速拿到干净稿的场景。
· **文本转图像/语音/视频**：多模态三件套：文本生成配图、文本转语音配音、文本转视频（脚本+分镜关键帧，参数卡确认画幅/时长/音色）。

⚠️ **断网也能用？这点很关键**

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

🎯 **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容
