# 多用户云桌面实战：一个真实场景的完整工作流

多用户云桌面这件事，说简单也简单，说麻烦是真麻烦——麻烦不在功能本身，在于信息散落在各处，拼出一个完整流程要查好几篇资料。这篇文章把它一次讲全：是什么、入口在哪、具体步骤、边界在哪，全部基于察元AI OS的真实界面。

## 先看看痛点对不对得上

培训机房批量部署；团队统一 AI 工位。

## 操作步骤详解

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 关键能力点

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 注意事项与真实边界

边界都在这：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 云桌面和桌面版功能一样吗？

核心能力面一致（对话、知识库、模型、办公），形态差异在：云桌面无本地文件直通、语音输入依赖浏览器权限、部分外设在浏览器里受限。

### 多少人共用一台服务器合适？

取决于是否同时跑本地模型：只做对话与知识库，十几人一台中配服务器可行；要并行跑本地推理，按并发数加内存或改用厂商模型分流。

### 数据存在哪里？

全部落在服务器的数据卷里（含用户空间、知识库、配置），挂载出来后备份一个目录等于备份全组。

## 安装与运行答疑

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

## 一个真实场景

需要多方意见的决策者的典型用法：给几只灵宠配不同厂商的模型，建宠物群聊勾选成员，选并行或串行，抛一个命题让它们讨论，开视角讨论强制多角度。同一命题的多模型观点同屏呈现，分歧与共识一目了然。注意：本地模型并发上限 4 路，全员本地模型时发言会排队。

## 顺带了解

MCP 服务管理：MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583），先验证连接再保存，启停即同步写入支持 MCP 的 13 家智能体。

为什么值得看：MCP 是智能体的手，一处配置全家生效，改之前能验证连接省得排错。

## 还有这个能力

恢复出厂模型：设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态。

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 边界速览

- 云端厂商模型调用需自备 API Key

## 数字口径

- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商

- 127.0.0.1:52581（OpenAI 兼容统一模型代理）

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。

## 灵宠与任务灵宠

每个智能体可以化身桌面灵宠：在壁纸上活动，动作与体型反映记忆负载，头顶流式气泡，双击直开工作台。绑定常驻任务的任务灵宠会在执行期上桌直播输出，结束时气泡显示成败摘要——定时任务从日志文件变成看得见的桌面直播。
