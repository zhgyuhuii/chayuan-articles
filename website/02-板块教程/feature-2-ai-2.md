# 一文打通系统自学 AI 路线｜AI教程

教程库按主题推进+标签聚合+资讯跟新。这套组合工作流把AI 教程库→标签聚合页→资讯板块串成一条线，在察元AI 能力广场里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

教程库按主题推进+标签聚合+资讯跟新。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI 能力广场的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·AI 教程库**：2.1 万+ 条全球 AI 学习资源导航：视频/文章/课程/电子书/文档/仓库七类，主题覆盖 LLM/Agent/RAG/Prompt/部署/微调/MCP/技能等，来源含 arxiv、github、B 站等。

1. 进入 /tutorials
2. 按主题（llm/agent/rag/prompt…）筛选
3. 按类型（视频/文章/课程…）收窄

**第 2 步·标签聚合页**：受控词表的标签聚合页：同一主题跨板块资源汇总（≥20 条资源的标签才进 sitemap）。

1. 点击任意标签进入聚合页
2. 浏览同主题资源
3. 配合筛选细化

**第 3 步·资讯板块**：生态动态与新闻收录：原文链接跳转，配合 RSS 的活动订阅。

1. 进入 news 板块
2. 按时间浏览
3. 跳转原文阅读

## 衔接点与易错处

- topic×type 组合筛选效率最高
- 标签页是按主题找资源的捷径
- 配合 /activities RSS 订阅

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 政企可私有化部署（Docker），数据自主可控
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 常见问题
### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 手机能用吗？

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。
