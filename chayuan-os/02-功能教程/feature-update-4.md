# 升级不丢数据出问题怎么办：排查手册加进阶技巧

写这篇的起因是群里有人问升级不丢数据，我发现自己也说不完整，索性把察元AI OS里的检查更新从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（完整检查更新流程仅桌面（打包安装）形态：需要 Electron 更新桥（chatopDesktop.updateCheck），更新源为 GitHub Releases（发布通道在 desktop/electron-builder.yml 里配置 provider: github）。），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 「检查更新失败」怎么回事？

多为网络访问 GitHub Releases 失败。按提示「可到 Releases 页手动下载」：Releases 页地址为 https://github.com/zhgyuhuii/chayuan-harness/releases，手动下载最新安装包覆盖安装即可。

### 更新会丢数据吗？

不会。安装包只更新程序文件，你的数据根目录不动（帮助中心 ＞ 参考 ＞ 常见问题 FAQ 同口径）。

## 正确的操作路径

第 1 步 · 打开「关于」面板

两个入口，打开的是同一个面板：

面板内容从上到下：察元 logo、名称「察元」、副标题「察元AI OS · 离线 AI 办公助手」、等宽字体的版本号 v{X.Y.Z}、厂商行「厂商 北京智灵鸟科技中心」、版权行「© {年份} 北京智灵鸟科技中心 版权所有」。版本号单一来源是 dsh-plugin/package.json 的 version（打包时自动同步外壳，关于窗口与设置分区都从这里取，杜绝手写过期）。

1. Dock ＞ 「设置」＞ 左栏「关于」，内容卡片标题「察元」；
2. 屏幕左上角察元菜单（logo 菜单）＞ 「关于 察元」，弹出独立关于窗口。

第 2 步 · 「检查更新…」

1. 做什么：点面板下方的「检查更新…」按钮。
2. 状态行按结果变化（就在按钮下方，进度实时刷新）：
    1. 检查中：显示「正在检查更新…」；
    2. 已是最新：显示「已是最新版本」；
    3. 有新版本：自动开始后台下载（无需再点下载），状态行显示「下载更新中 {p}%」实时走百分比；按钮下方同时显示新版发布说明摘要（取自 Releases 的 releaseNotes，剥掉 HTML 按纯文本展示，最多 400 字）；
    4. 失败：显示「检查更新失败（可到 Releases 页手动下载）」，并在后面附具体错误原因。
    5. 没有自动检查：开机、日常使用中都不会自动检查更新，只有点这个按钮才检查。

第 3 步 · 「重启并安装」

1. 下载完成后，状态行变为「已下载 v{新版本}，重启完成安装」，下方出现蓝色按钮「重启并安装」。
2. 做什么：点「重启并安装」＞ 应用退出并自动安装新版，装完自动重启回到桌面。
3. 不点它也没关系：已下载的更新会在下次正常退出应用时自动安装（安装器开启 autoInstallOnAppQuit），再开机即是新版。
4. 设置分区和独立「关于 察元」窗口是同一个面板、同一份更新状态：一边看下载进度，另一边打开也是同样的状态行（状态由主进程实时推送）。

## 怎么确认做成了

验证

1. 升级完成后重新打开 设置 ＞ 关于，等宽版本号应显示为新版本号。
2. 下载过程中可以关掉设置页去干别的；重新打开关于面板会拉取当前更新状态（进度/已下载/出错都会照常显示）。

## 进阶用法与边界

- 在线检查更新
- 重启安装
- 数据保留

## 接着回答几个常见问题

### 点「检查更新…」却打开了一个网页？

那是网页（浏览器）形态：没有桌面更新桥，按钮降级为打开官方站点页。完整的检查-下载-安装流程需要桌面安装版（察元AI OS 桌面应用）。

### 为什么从来不弹更新提醒？

产品采用手动检查模式：不静默检查、不强更。想升级时到 设置 ＞ 关于 点一次「检查更新…」。

### 下载进度一直不动 / 下载中断了？

重新打开关于面板看状态行；若已报错会显示失败原因（网络断续常见），网络恢复后再点一次「检查更新…」重新下载即可。

## 安装与运行答疑

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

## 一个真实场景

学生与科研人员的典型用法：本地模型零边际成本对话，知识库导入课件论文做引用式问答，知识图谱梳理论文实体关系。零 API 成本的学习与科研工作站。注意：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 顺带了解

灵宠对话窗：多会话 Tab、流式回复、附件上传，输入框旁有知识库绑定与模型选择（含智能路由自动选模型），双击模型直跑灵宠直达。

为什么值得看：不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处。

## 还有这个能力

灵宠名册：底栏爪印按钮打开名册：全部灵宠与群的状态徽标（空闲、开窗、任务中）、钉住快切、常驻任务倒计时、搜索、双击直达。

## 硬口径两三条

- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness

## 如实说不足

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。
