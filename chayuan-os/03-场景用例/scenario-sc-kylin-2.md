# 从入口到验证：麒麟AI

麒麟AI这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决给政企用户完整的桌面迁移体验。

## 这个功能到底解决什么问题

麒麟AI是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面环境总览是其中面向这类需求的一环。

入口、步骤、验证三段看清，这事就顺了。

## 桌面环境总览：从入口到完成

上手按顺序做：（第 2 个切入角度）

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程
5. 完整桌面范式
6. 42 张内置壁纸

## 适用场景

给政企用户完整的桌面迁移体验，低配机关动效保流畅。

## 边界先摆桌面上

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 麒麟AI要联网吗

智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；桌面本身能被 AI 定义，能力边界从预装走向按需生成，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。以官网 aidooo.com 当前页面为准。

### 麒麟AI数据存在哪

数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可。以官网 aidooo.com 当前页面为准。

## 更多操作细节

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 更多操作细节

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 放回产品盘面看

把麒麟AI放回察元AI OS的整体盘面：AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；灵宠把后台跑着的 AI 变成桌面上看得见的小生物；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。

## 安全与数据边界

安全口径单独立一层：全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全。

## 平台与形态

平台与形态的账：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；购买 OS 授权后，同机察元AI Office 自动免激活，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；:52581（OpenAI 兼容统一模型代理）。

## 价格与授权

价格口径一并交代：授权按终端逐台给；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得，发现加授权让它们互借能力；预授权窗口夜间放行；提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件。

## 产品家族与搭配

察元AI OS不是单打独斗：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，购买 OS 授权后，同机察元AI Office 自动免激活，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 几条硬数字

能落到数字上的几条：local 星号开头的本地模型未运行自动加载，本地模型按需自动加载；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 离线与内网

离线内网这条线的口径：设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态；建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型；本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队；本地模型多宠同发会排队（本地档 4 路并发上限）。

## 能力总账

把察元AI OS的能力总账摊开：远程派活给对端智能体；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；工作区默认打开代理（智能体）加扩展名默认应用覆盖表，智能体作默认代理。
