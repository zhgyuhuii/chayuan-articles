# 政务行业技能包盘点：资源怎么找怎么选

政务行业技能包盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：技能包商城（技能包商城）、行业场景库（行业AI方案）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**技能包商城**：311 个买断制技能包、13 大行业两级分类：包详情含解决什么问题/适合谁，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

1. 进入 /skillpacks 按行业浏览
2. 看包详情的 solves/audience
3. 微信/支付宝买断购买

**行业场景库**：20 个行业 × 200 个场景的 AI 应用导航：从行业到场景到对应资源的结构化路径。

1. 进入 /scenarios 选行业
2. 浏览该行业场景列表
3. 进入场景看对应资源与方案

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 手机能用吗？

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。

### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。
