# 教师办公完整方案：教师场景全拆解

如果你是教师，下面这些场景大概率不陌生：课件讲义考试多样产出。一间办公室搞定全部教学材料。这篇完整方案以察元Office为工具，把这个岗位的教师办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 课件讲义考试多样产出
- 学校电脑系统不一
- 需要公式与图文混排

## 用察元Office怎么解：工作流拆解

1. Slides 做课件（公式墨迹支持）
2. Docs 出讲义与试卷
3. PDF 归档分发

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「Slides 做课件（公式墨迹支持）」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。一间办公室搞定全部教学材料。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 重度宏（VBA/宏表）与部分深度排版长尾功能与微软 Office 存在差距，复杂场景可能仍需商业套件兜底
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

文档编辑与格式转换完全本地化：打开、编辑、保存不出机器；PDF 转 Word/PPT/Excel 由内置 PDFium 引擎做字符级提取与几何版面分析，全程离线、无云端参与，扫描件 OCR 也走系统本地引擎（macOS 用 Vision，Windows 用系统 OCR），适合对数据敏感的政企与个人用户。

## 数据安全与隐私边界

- 文档打开/编辑/保存全程本机完成，不经任何服务器
- PDF→Word/PPT/Excel 转换与 OCR 均为本地引擎，扫描件不上传
- 遥测仅匿名统计且可一键关闭，永不收集文档内容与身份信息
- 安全工程：全窗口 contextIsolation + sandbox、IPC schema 校验、外链协议白名单、无硬编码密钥

## 费用与授权的边界（如实说明）

开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。付费部分：试用期满后每日一次购买提醒弹窗（可手动关闭）+ 主页每 30 分钟温和提醒；离线 HMAC 短序列号激活，绑定机器指纹本地验证，无需联网激活服务器

## 如实说说它的不足

- 网页版 SaaS 形态需要自行部署维护（Docker + 数据库）
- AI 能力需自配模型（云端 Key 或本地端点），不配置时 AI 功能不可用
- 官方安装包 90 天试用后会有每日一次的购买提醒（不锁功能、可关闭）

## 常见问题
### 遇到 bug 去哪反馈？

GitHub 仓库提 issue，或通过官网渠道反馈；项目有 75 个端到端测试用例保障迭代质量。

### 升级会丢数据吗？

不会。覆盖安装/更新不触碰用户文稿目录；更新通道为官网检查+安装包下载双通道。

### 有自己的命令行吗？

有：chaoffice CLI 支持 headless 格式转换、结构化编辑、逐页渲染 PNG，并内置 MCP server，可让 Claude Code 等智能体直接操作 Office 文件。
