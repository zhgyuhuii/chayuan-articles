# 一文读懂MCP 服务器板块｜实操教程

MCP服务器列表是察元AI 能力广场里使用频率很高的一项能力。它的「MCP 服务器板块」这样工作：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

从任务视角看，它对应的关键词是「MCP服务器列表」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 mcp 板块
2. 按功能关键词搜索
3. 复制 JSON 配置片段到客户端
4. 对照风险分级评估权限

## 适用场景

- 给 Claude Code/Cursor 等找工具
- 智能体能力扩展

## 实用技巧

- 配置片段可直接粘贴进客户端 MCP 配置
- 优先选 active 状态条目

## 注意事项与边界

- 高权限 scopes 条目谨慎授予
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 政企可私有化部署（Docker），数据自主可控

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。
