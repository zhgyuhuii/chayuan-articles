# ✨创造模式隐藏用法｜智能体插件一次讲清

用过察元OS的宝子看过来，创造模式这个功能很多人没用到极致👇

✅ **它能干嘛**

会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

🔍 **三步用起来**

1️⃣ 在会话中进入创造模式
2️⃣ 定义智能体与要挂载的插件
3️⃣ 运行并迭代

💡 **什么场景最香**

· 快速原型化一个专用智能体

📌 **避坑提醒**

⚠️ 云厂商模型调用需自备 Key，免费额度视厂商政策

🛠️ **更多它擅长的事**

· **共享桌面**：局域网内多用户桌面共享：权限分主机/编辑者/观看者三级，适合会议室投屏协作与远程指导。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。
· **本地知识库**：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。

⚠️ **断网也能用？这点很关键**

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

❓ **常见疑问快答**

问：能多人共用一台设备吗？
答：能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

问：数据存在哪里？怎么备份？
答：数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。
