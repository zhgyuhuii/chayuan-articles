# 提示词是什么：一文讲透

搜提示词的人通常带着两个问题：是不是噱头、值不值得装。这篇不站队，定义、口径、边界三段摆开，你自己对号。

## 什么是提示词

提示词不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

本文数字与版本口径以官方文档为准，文末尾注标了截止时间。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 你可能会问

### 提示词要联网吗

本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，联网环境下内置 web_search 工具默认走 DeepSeek 搜索；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。以官网 aidooo.com 当前页面为准。

### 提示词数据存在哪

隐私敏感环境先关遥测再干活，处置设备前清数据；升级不丢数据是底线，检查更新静默失败不影响使用，账户隔离、数据在服务器侧统一管理；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。以官网 aidooo.com 当前页面为准。

## 一句收束

提示词值不值得深入，判断标准很简单：把上面的口径与边界代入你的实际需求，对得上就装来试，对不上不必跟风。

## 放回产品盘面看

把提示词放回察元AI OS的整体盘面：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注；共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸，本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。

## 安全与数据边界

安全口径单独立一层：三条路都不满足就只能清数据重装，务必提前生成恢复密钥，需要提前开启并积累足够记忆数据；管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。

## 平台与形态

平台与形态的账：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力，web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作；内置浏览器窗，配合 webwindows 可被智能体驱动，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌。

## 价格与授权

价格口径一并交代：官方免费素材库，不用去网上乱找 png；对配对终端开模型加知识库授权，资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问。

## 产品家族与搭配

察元AI OS不是单打独斗：购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 几条硬数字

能落到数字上的几条：对配对终端开模型加知识库授权；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）；生图模型不配好，画图应用与智能体的生图指令都落空，各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。

## 离线与内网

离线内网这条线的口径：local 星号开头的本地模型未运行自动加载；本地模型按需自动加载，会话中随时切换模型（本地与已启用厂商热更新）；无显式模型偏好时自动指向本地模型。
