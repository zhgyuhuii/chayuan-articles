# 开源趋势日报流（能力广场速查手册）

排行榜+资讯+活动订阅的每日信息流。这套组合工作流把开源排行榜→资讯板块→模型活动板块串成一条线，在察元AI 能力广场里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

排行榜+资讯+活动订阅的每日信息流。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI 能力广场的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·开源排行榜**：基于 star 快照差分的榜单：hot/new/trend 与日/周/月/季/半年/年六周期，每日 03:30 定时重算。

1. 进入 /rank
2. 切换榜单与周期
3. 点进条目详情

**第 2 步·资讯板块**：生态动态与新闻收录：原文链接跳转，配合 RSS 的活动订阅。

1. 进入 news 板块
2. 按时间浏览
3. 跳转原文阅读

**第 3 步·模型活动板块**：全球模型促销与发布活动聚合：自动扫描 31 家厂商源+人工策展，支持 RSS 订阅。

1. 进入 /activities
2. 浏览进行中的活动
3. RSS 订阅持续跟踪

## 衔接点与易错处

- trend 榜看中期走势
- 配合 /activities RSS 订阅
- RSS 订阅不漏重要活动

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 投稿有人工审核门槛，重复或低活跃项目会被拒

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 政企可以私有化部署吗？

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。
