# 智能体知识库排错：家外部 CLI 智能体

智能体知识库的麻烦不在功能本身，在于信息散。不用切应用，在正在干活的对话里直接问资料，出处照样带。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

智能体知识库的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把库里有「就绪」状态的文档；检索质量依赖嵌入链路。核一遍，再查路径。

## 正确的操作路径

4. 在 CLI 智能体里查库（Claude Code / Codex 等）

1. 打开对应智能体的会话（如灵宠挂的智能体工作台、或直接在终端跑 CLI），同样说「查一下知识库里…」。
2. 工具经由自动写入的 MCP 条目接入：chatop-kb（HTTP，52582 /mcp，三工具语义与 dsh 原生一致）与 chatop（系统控制面，含 kb 三工具）。智能体同时收到《察元知识库检索手册》技能，按「先 kb_list 看库 ＞ kb_search 检索 ＞ 需要原文再 kb_read_doc」的顺序工作，回复带 [n] 文档名 · 章节路径 出处。

5. 灵宠对话窗（模型直跑）：绑定库自动注入

1. 灵宠对话窗输入框左侧有一个书本按钮（悬停提示「选择知识库」），点开选一个库（「不绑定知识库」/ 各库名 / 空态「暂无知识库（桌面建库后可选）」）。绑定后会话 Tab 上出现「KB」徽标，此后每条发言自动先检索再把【知识库参考】注入（片段带 [n] 文档名 · 章节）；本轮没检索到时注入「【知识库参考】本轮对所提内容检索无结果：库里没有匹配内容，请如实说明没查到……」的指令。详见对应教程。

## 进阶用法与边界

- 三个 KB 工具自然语言触发
- CLI 智能体经 MCP 自动接入
- 出处引用不丢

## 高频疑问

### kb_search 一次查几个库？

一次一个库（kbId 参数）。想跨库对比就分别指定库名多次检索；跨终端的库共享是另一回事。

## 更多操作细节

6. 宠物群聊：挂群库

1. 群聊输入框的 选择器给全群挂「群默认库」（优先级：群库 > 宠物绑定库）；没挂库时命题里提到「知识库」，消息流会落系统提示「本群与成员宠物都未挂知识库——宠物无法真的查库…」。详见对应教程。

## 动手前再核对一遍

- 库里有「就绪」状态的文档；检索质量依赖嵌入链路。
- dsh 会话（Dock ＞ DeepSeek Harness 打开的对话窗）：三个 kb 工具随知识库服务原生注册，开箱即用，无需任何配置（挂了 CLI 智能体的灵宠，其工作台走的是下一条 CLI 通道）。
- CLI 智能体：需已安装并被桌面感知。系统会自动做两件事，无需手工干预：
- MCP 条目自动写入：名为 chatop 的系统控制面适配器（含 kb 工具透传）＋ 名为 chatop-kb 的知识库专属 MCP（HTTP 端点 http://127.0.0.1:52582/mcp，端口读知识库服务落盘的 service.json，即固定端口 52582；知识库服务不在场时该条目自动移除）；

## 放回产品盘面看

把智能体知识库放回察元AI OS的整体盘面：统一应用到智能体；设置结果分发到智能体侧，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；还有可复制的各家智能体配置片段。

## 安全与数据边界

安全口径单独立一层：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；代理只监听本机回环，跨机访问需要另行打通，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 平台与形态

平台与形态的账：写入的是代理地址，代理停了智能体就连不上模型；智能体默认不知道今天发生了什么，接一路搜索源它才能查实时资料；编辑面板改模型、知识库、人设；保存时同步写入所挂智能体。

## 价格与授权

价格口径一并交代：故障转智能体修复，智能筛选（今天、已计划、旗标、已完成）、多列表管理；购买 OS 授权后，同机察元AI Office 自动免激活；免费下载使用，购买只停提醒、不锁功能。

## 产品家族与搭配

察元AI OS不是单打独斗：在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么；CLI 智能体经 MCP 自动接入，对配对终端开模型加知识库授权，在 WPS 里检索引用知识库内容。

## 几条硬数字

能落到数字上的几条：输入框旁有知识库绑定与模型选择（含智能路由自动选模型），（知识库对外服务，固定端口），很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；写入的是代理地址，代理停了智能体就连不上模型。

## 离线与内网

离线内网这条线的口径：输入框旁有知识库绑定与模型选择（含智能路由自动选模型），与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）；（知识库对外服务，固定端口），插件、技能、MCP 插件、智能体、技能包五大类。

## 能力总账

把察元AI OS的能力总账摊开：换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；工作区默认打开代理（智能体）加扩展名默认应用覆盖表，让特定文件类型默认交给智能体处理，双击即用 AI；智能体作默认代理。
