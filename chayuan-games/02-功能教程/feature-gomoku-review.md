# 五子棋复盘教程：从形势曲线找胜负手

五子棋的胜负常浓缩在一两手之间，输的一方往往只记得「突然就没了」，具体败在哪一手，说不上来。五子棋复盘要解决的就是这笔糊涂账：察元竞技场把形势曲线、问叹号标注、回放串成一条链路，先定范围、再定那一手、后看全过程。这篇按顺序走一遍，教你从曲线交叉点把胜负手揪出来。

## 复盘三件套各管一段

先认识工具。形势曲线是每局自动生成的局势走向图：横轴手数、纵轴优劣，模型落一手曲线走一格，谁压着谁打一眼可辨。问叹号标注是逐手挂的记号：问叹号（？！）落在妙手上，叹号（！）落在失误上。回放负责还原，逐手推进，每一手都带着模型的 comment 与当时的思维链气泡。三件套的分工一句话：曲线告诉你「哪里出的事」，标注告诉你「是哪一手」，回放告诉你「怎么出的」。回放器还支持按协议字段筛选关键手，配合标注跳看，比纯手动拖进度条省力。三样同屏不占地，对局进行中也能瞄一眼曲线，提前看到倾斜。开始复盘前建议先看一遍终局结果，知道谁赢再看曲线，方向感完全不同——带着结果读过程，是复盘的隐藏乐趣。

还有一层背景值得知道：对局引擎带开局记忆，避免模型在同型局面重复犯错。也就是说，若某局输在开局的老毛病上，模型那边的旧错会被逐渐压住；你自己的旧错，得靠复盘一遍遍亲手压。

## 动手前要备好什么

一局已经结束的对局即可，人机局、机机观战打出来的都能复盘。装好察元竞技场（版本 0.1.0），从记录页找到这局、走回放入口。复盘功能不另外收费，软件 MIT 开源免费；打对局消耗的模型 API 费用照常自理，用 Ollama 本地模型则零成本。

## 完整步骤：四步锁定胜负手

第一步，打开形势曲线找交叉点。两条线交汇的位置就是局势易手处。五子棋曲线的特点是节奏快、跳变大，攻杀得手时曲线陡动，所以别只找一个交叉点，把陡变明显的段落都圈出来。圈段落时顺手记下手数，回放里直接跳过去，不用从头翻；五子棋的转折往往就一两手，范围圈得准，复盘时间省一半。

第二步，从交叉点跳进回放，前后各看几手。重点对照两样东西：模型当时的思维链气泡——它是算到了还是随手的；双方的 comment——谁在进攻谁在防守。胜负手通常就藏在这几手里。

第三步，对问叹号标注。五子棋复盘里有个常见现象：胜负手往往是「一妙一错」成对出现——一手做杀的妙，配一手漏防的错。妙手挂着问叹号，失误挂着叹号，两条线索一碰，整局的转折故事就齐了。

第四步，呼应开局记忆。如果曲线显示倾斜从开局阶段就开始，说明败因埋在序盘。这时可以多安排几局同型开局，观察模型是否不再复读旧错——那是开局记忆在工作；同时观察你自己：同样的布局坑，你还在往里跳吗？模型的错有引擎帮着压，你的错只有复盘能治。验证记忆效果别心急，同型局面至少复现三五次，样本太少看不出趋势，还容易被单局运气带偏。

## 进阶用法：把复盘串成一条线

单局复盘是点，多局串起来才是线。同样两个模型多打几局，把每局的转折点排一排：总在同一类局面摔倒，是套路问题；随机摔倒，是稳定性问题，两种毛病的解法完全不同。人机局里这条线更实用——把自己的失误标注汇总成错题本，每隔几天重翻一遍，你会清楚看到哪类坑已经填了、哪类坑还在跳。开局记忆替模型压旧错，错题本替你压旧错，一套复盘流程，两头都在涨。这条线拉得越长，你对各家模型的理解就越接近一份性格画像，而不是零散印象。

## 做完后的验证

检验标准：合上回放，你能用一句话讲清这局——第几十手、谁走了什么、曲线从此倾斜、胜负定型。讲得出，这局的学费就没白交；讲不出，说明你只是划了一遍进度条，回到交叉点重新看。验证顺便做减法：这局里标注最密集的一段，往往就是你最该专攻的课题，别平均用力。

## 这些边界要心里有数

标注是引擎按局面评估自动生成的口径，不是人工棋评，个别认定可能与你的直觉有出入，保留自己的判断即可。曲线是快照不是预言，五子棋里一条漏防就能让优势掉头，别拿中途的领先当定局。弱模型对局的失误标注会相当密集，逐条深究很累，挑曲线剧烈变化附近的看就够。想带走数据，用棋谱导出拿 JSON，自建分析自己做主。还有一条时间账：精读一局复盘不比看直播省时，气泡、标注、曲线来回对照，一局看下来十几分钟很正常，安排复盘别按刷视频的节奏来。容量倒不用担心，记录与导出的 JSON 都在本机，体量很小，定期清理旧局即可。

## 高频疑问

### 曲线交叉点就一定是胜负手吗

不一定。交叉点是局势易手的位置，胜负手通常在附近，但也可能另有其手；曲线负责缩小范围，最终认定要结合标注与回放，把交叉点前后各几手都过一遍再下结论，别只看交点本身。

### 人机局里我自己下的棋也会被标注吗

会，复盘对每一手一视同仁，你的妙手与失误同样挂着记号，这正是五子棋复盘当学棋工具用的价值。

### 复盘要另外花钱吗

不收。复盘链路是软件的组成部分，MIT 开源免费；只有打对局的模型 API 费用自理，Ollama 本地模型零成本。

### 棋谱导出有什么用

导出 JSON 棋谱可以带走做自建分析、存档、喂给自己的程序；想给棋友讲棋，也是个现成的素材。

### 开局记忆能看到吗

它在对局引擎里自动工作，不设独立开关；效果要在多局对比里观察——同型开局多打几遍，看旧错是否被压住。

### 多局对比要在同一玩法里做吗

建议同一玩法内对比，变量才可控；跨玩法比的是另一套能力，结论容易失真。

五子棋复盘的核心不是把每一步都看懂，而是把那一两手真正看懂。曲线给你指路，标注给你点名，回放给你放慢动作，开局记忆帮你把旧账翻篇。工具都备齐了，剩下的功夫只有一种：输完别急着开下一局，先回来站十分钟。
