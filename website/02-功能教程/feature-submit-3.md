# 资源提交落地记：万+ 资源一站检索

资源提交这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI 能力广场的真实界面顺序走一遍，先解决把自己的 MCP 服务上架。

## 解决什么痛点

把自己的 MCP 服务上架；许愿一个想要的功能。

## 具体怎么操作

投稿你的作品

1. 登录后进提交作品页
2. 填写资源名称、主页或演示地址、图标外链
3. 分类必选，标签从受控词表搜选 2 到 5 个
4. 提交进入人工审核队列，通过后上架展示

在需求墙提需求

1. 进需求墙选产品（五款产品二级菜单）
2. 点「提需求」或唤起提需求机器人
3. 相同诉求会自动归并到已有条目，累计人数
4. 按处理状态过滤盯进展，全程公开

## 关键能力点

- 作品投稿审核制
- 受控标签词表
- 需求自动归并
- 进展全程公开

## 边界先摆桌面上

如实说明，它不是万能的：

- 教程库只做元数据导航，正文仍在源站
- 下载前需要完成登录（账号或微信扫码）

## 你可能会问

### 投稿后多久上架？

经审核后上架，审核主要看资源真实性与信息完整度；状态可在投稿记录里查。

### 需求墙的需求真的会被实现吗？

需求墙是公开的，官方与社区按需求热度排期，obot 客服也会收集对话里的需求进同一个池子。

安全口径单独立一层：导航智能广场分三栏：资源类型装了就用（智能体、MCP、插件、技能、教程库、提示词、技能包）；MCP 板块收录 MCP 服务器资源，失效资源自动剔除出榜，智能体应用板块收录可直接使用的智能体应用形态资源，配合产品使用或独立运行。
