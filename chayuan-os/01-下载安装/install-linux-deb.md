# Linux deb安装：deb 安装与数据目录初始化

Linux deb安装这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序把 deb 路线走一遍，数据目录的初始化也一并交代。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：deb 安装与数据目录初始化。

deb 安装包认准官方渠道下载，社区转贴的包不要装。

## 一步步来

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 其他平台装法速览

Linux（AppImage）：chmod +x 加执行权限后运行；缺 FUSE 时安装 libfuse2 或改用 --appimage-extract-and-run；免安装形态适合无 root 权限与便携场景。

macOS：从官方渠道下载 dmg 并打开，把察元AI OS 拖入应用程序文件夹；启动后创建账户进入桌面。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

进桌面先验两条通路：对话应用里用本地模型搭上话、应用商店里插件列表刷得出来；哪条不通，问题就定位在哪条链路上。这条验法的前提是机器能联网：插件列表走的是网络链路，断网的机器上它刷不出来属正常现象，此时只验本地模型对话这一条即可。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 收尾检查

- 桌面就绪后，对话应用切本地模型问一句，答得上即达标
- 首次初始化在 5 到 30 秒内完成都正常，交给系统自己处理

## 它的局限也要说清楚

底下几条是这款系统当下的实情，装之前掂量一下：

- Docker 云桌面、跨终端互联属于进阶形态，没点动手能力玩不转
- 云端厂商模型的调用各凭各的 API Key，系统不代管
- 8GB 内存的设备一次加载一个对话模型为宜，复杂任务受的限明显
- 龙芯平台暂不支持；视频生成不在本地能力清单里，走云端路由

## 数据目录初始化的两三件事

首次启动的自动初始化并不只是转圈等进度条：系统会建好数据目录，账户信息、应用配置、智能体数据此后都收在这一个根里。对 deb 用户有两点实际好处：备份时只需备这一个目录；磁盘吃紧时整个目录可搬走，迁移不等于重装。初始化只在首启发生一次，之后的升级与覆盖安装不会重建它。

## 桌面与终端的基本盘

装完 deb 之后，值得认识一下这套桌面的基本盘：内置终端是真实 shell，会话持久、环境延续；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明。文档类文件打开即看、不挑格式，走系统级默认打开体验。换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。

## 多人共用与隐私口径

多人合用一台设备时，数据隔离是底线：账号由管理员统一立、统一管，比各用各的安全；隐私敏感环境先关遥测再干活，处置或转手设备前把数据清掉。

## 桌面与 Dock 可调的地方

桌面外观与 Dock 可调的地方不少：Dock 里的文生图应用支持提示词加负面提示词，生成结果可设为壁纸，或开 30 分钟自动换壁纸；应用页签里能隐藏 dock 应用、新建分组，把自定义网页、本地程序、HTML、文件四类应用封装上桌；桌面与 Dock 的设置项涵盖位置、自动隐藏、图标放大与大小、开机自动打开 Harness。Dock 是使用频率最高的区域，位置与大小顺不顺眼很影响手感。

## 主题包与远端协作

还有几块能拼上的能力：灵宠商店的主题页签提供整套组合包——场景背景加 36 图标皮肤加灵宠皮；WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色，共享房间与连接终端状态都看得见；把设置指向远程 dsh web 地址并测试连接后，桌面客户端就能接远端算力；动态 WebGL 壁纸也在设置里。检查更新则到 设置＞关于 点一下，下载后重启安装。

## 默认模型与路由

默认对话模型的选择入口在 设置＞模型＞设置向导，想换随时可以重跑向导，不用重装。定位上，本地模型解决有无问题，复杂任务还是需要云端旗舰模型。

## 本地模型的加载与路由

模型路由上有个「主强子弱」的思路：润色翻译这类轻任务交给旗舰模型是浪费，让轻任务自动落本地小模型，省算力也省预算；自动模式下本地优先，名称以 local 星号开头的本地模型未运行时会自动加载，按需启用。

## 知识库与文档的衔接

知识库这条线也有交代：编辑面板能改模型、知识库、人设；输入框旁有知识库绑定与模型选择，含智能路由自动选模型；检索引用知识库内容并带出处写进文档，WPS 里同样能检索引用知识库内容。
