# 象棋复盘教程：用标注找回丢子那一步

下象棋最懊恼的时刻不是被将死那一下，而是往前倒几步——「我的车到底什么时候没的？」丢子很少是一手造成的，从漏算到失子往往隔着好几手棋。象棋复盘就是要算清这笔账：察元竞技场把形势曲线、问叹号标注、赛后解说串成一条链，这篇教你顺着它找回丢子那一步。

## 复盘链路各管一段

先认工具。形势曲线是每局自动生成的局势走向图，子力易手这类事件在曲线上动静很大；问叹号标注逐手挂记号，问叹号（？！）标妙手、叹号（！）标失误；回放逐手推进，每一手带着模型的 comment 与思维链气泡；赛后解说把整局串成一段话；棋谱导出给你 JSON 存档。五件套合起来一句话：曲线指段落，标注点那一手，回放还原现场，解说讲明白，导出带走。这几样是同一条流水线上的工序，读的时候别拆开：先曲线后回放是省力顺序，先标注后解说是理解顺序，顺序对了，一局的账十分钟就能算清。

## 动手前要备好什么

一局打完的象棋对局即可，人机局、机机观战、锦标赛产出都能复盘，其中人机局尤其实用——自己下的棋自己懂，找根因最快。装好察元竞技场（版本 0.1.0），从记录页找到目标对局进回放。复盘不额外收费，软件 MIT 开源免费；打局消耗的模型 API 费用照常自理，接 Ollama 本地模型则零成本。挑对局也有讲究：优先选手数多、曲线起伏大的局，丢子样本足，复盘读起来信息量大；一边倒的快局看点少，留着凑数即可。

## 完整步骤：三步找回丢子那一步

第一步，看曲线拐点。子力易手在曲线上的动静最响——陡降的那一段，多半有子丢了。把明显的拐点都记下手数，别只记一个：丢子常常是连环的，丢车之后丢马。拐点还分大小：大拐点是子力直接易手，小拐点是位置亏损累积，先抓大的再验小的，翻车点通常藏在大拐点前后一两手。

第二步，拐点附近开回放。对照双方 comment 与思维链气泡看谁漏算了什么：是走子次序出了破绽，还是被对手一手两用的招骗了。丢子那手常被标了叹号，得子的对手那手可能挂着问叹号——两条记号一碰，事故现场就复原了。读气泡时留意时间线：漏算往往发生在它以为安全的那几手，往前倒一手，找出它产生安全错觉的原因，比盯着丢子那手本身更有价值。顺便把对手得子的那手也看一遍，好棋值得学，别只记教训不记样板。

第三步，让赛后解说串一遍。单看一手只能知道丢了什么，看完解说才知道为什么丢：前几手哪步埋的祸根、丢子之后为什么再也守不住。听完整段再回到回放里验证一遍，这笔账才算真正算清。解说还有一个用法是当「第二意见」：你对丢子原因有了自己的判断，听解说怎么讲，讲得一致就放心，讲得不一致就回回放找证据，两种可能都别放过。

第四步，导出存档。棋谱导出成 JSON 带走，丢子片段单独记进自己的错题集；下次再遇到同型局面，翻出来看一眼，比再输一局便宜。错题集不用做得多精致，手数、子名、一句话根因，三样齐了就够用，贵在坚持记。

## 把丢子复盘变成长期习惯

一次复盘是一次清账，长期复盘才是练功。给自己立个流程：每局复盘挑一个丢子片段记进错题集，写清丢的是什么、根因在哪手；每攒十条，回头通读一遍，你会发现自己丢子的方式其实就那两三种。模型那边，开局记忆在引擎里默默压同型旧错；你这边，错题集就是你的开局记忆。两边对着看还有个乐趣：它不再犯的错你还犯不犯，你改掉的毛病它改没改，对照着比，进步看得见。这个习惯坚持一个月，效果比背十篇棋诀实在——丢子这件事，防不住的是没见过的花样，防得住的是见过的套路。

## 做完后的验证

检验标准一句话：你能指着棋谱说出丢子发生在第几十手、丢的什么子、根因是哪一手埋的。说得出，这局的学费交得值；说不出，回到曲线拐点再看一遍，答案总在标注与气泡之间。自测通过后再进一步：把这局的丢子讲给朋友听，讲得清楚，说明因果链你真捋顺了；讲不清楚，说明还欠一层理解。

## 这些边界要心里有数

标注是引擎的评估口径，不是人工棋评，个别认定可能与你的直觉相反，保留判断即可。曲线拐点不全是丢子，也可能是攻势转换或大子兑现，别见到陡降就喊丢子，回放验证一步不能省。模型不做深度搜索，漏算是常态，复盘的意义在于看懂它错在哪，而不是要求它不出错。数据都在本机，导出的棋谱自己保管。复盘习惯上也有个坑：别把每次丢子都归咎于漏算，有的丢子是对手下得好，承认这一点，复盘的结论才客观。也别把标注当判决，个别手引擎与你的看法不同很正常，两说并存。

## 高频疑问

### 丢子一定是失误吗

多数是，但个别时候弃子换势是主动选择——判断标准看后续有没有找回收益。标注与解说给参考，最终解读保留你的判断。

### 曲线没拐也丢了子怎么找

小幅度的位置损失在曲线上动静不大。这时直接翻问叹号标注，从叹号密集的段落下手，配合回放逐手看。

### 赛后解说能重看吗

能，复盘内容随对局记录保存在本机，随时从记录页再进；具体保存与删除操作以应用内为准。

### 我的象棋复盘数据在哪儿

在本机。对局记录、复盘标注、导出的棋谱都存本地，不上传云端，换设备不会自动跟随，需要的话自行备份。

### 复盘跟开局记忆有什么关系

复盘找出旧错，开局记忆帮模型压住同型局面的重复错误；你的旧错引擎管不了，只能靠复盘一遍遍提醒自己。

### 人机局里我丢的子也能这么找吗

能，复盘对你与模型的每一手一视同仁，曲线、标注、回放同样适用；找自己丢子的根因，往往比找模型的更有收获。

丢子是象棋里最诚实的一面镜子：它照出漏算，也照出侥幸。曲线给范围，标注给点名，解说给因果，几样凑齐，丢的那步车就躺在棋谱里等你。复盘做完再开下一局，你会发现丢子这件事，慢慢就从「莫名其妙」变成了「早有预兆」。
