# 察元OSFAQ：故障排查 8 问

把故障排查 8 问相关的高频问题集中回答，一篇看完，省得一个个搜。每个回答都给到可操作的结论。

## 快问快答

**1. 升级会丢数据吗？**

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。

**2. 能多人共用一台设备吗？**

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

**3. 首次启动感觉「卡住」了？**

首启要初始化数据目录并加载模型服务，5-30 秒属正常范围；期间无需干预，完成后自动进入桌面。

**4. 锁屏密码忘了？**

多用户体系提供管理员密码找回流程：以管理员身份登录后在用户管理中重置目标账户密码。

**5. 免费吗？怎么收费？**

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。

**6. 四家智能体是内置的吗？**

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

## 一条通用排查思路

绝大多数问题出在三层：环境层（安装与版本）、配置层（模型端点与密钥）、用法层（入口与步骤）。先分层再定位，比盲目重装效率高得多。

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 常见问题
### Docker 部署端口冲突？

默认网页桌面端口 52584，被占用时修改 compose 映射端口；系统各服务端口有统一注册表，改前先查占用。

### 模型加载失败或内存不足？

系统有内存预算线（总内存的 45%）保护：卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。
