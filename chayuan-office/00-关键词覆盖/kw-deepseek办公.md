# DeepSeek办公怎么做：概念厘清与上手要点

DeepSeek办公作为一个搜索词，背后是两种东西被混着谈：一是 DeepSeek 模型本身的网页对话，二是把这类模型接进办公软件后的整套工作方式。本文说的是后者，以察元AI Office为样本，给出可核对的口径与边界。

## 什么是DeepSeek办公

把它拆开是两件事：DeepSeek 提供模型能力，办公软件提供文档、表格、演示这些载体。对应的载体察元AI Office（Chayuan AI Office）是开源 AI 办公套件，六编辑器一体，AI 嵌进每个编辑器。

组合的意义在于，推理发生在你正在编辑的文件旁边，不必在聊天网页与编辑器之间来回复制。判断一套「DeepSeek办公」名不副实还是货真价实，就看模型能力嵌进编辑流程的深度：只在侧边挂个聊天窗算浅，能对选区改写、全文校对、直接生成整篇文档才算嵌了进去。

顺带厘清一个常见误解：DeepSeek办公不等于「用 DeepSeek 写文档」这一个动作。它覆盖的是写、改、校、转的整条链——初稿可以交给模型生成，改写对着选区做，校对以批注落在原文上，格式转换在本地完成。链上每一环用不用 AI、用哪家模型，决定权都在使用者手里。

文中数字与版本的依据是官方文档，具体截止时间在文末。

## DeepSeek 在套件里的接入位置

接入走 BYOK：把 Key 配进供应商目录（全目录 94 家，DeepSeek 位列其中），各编辑器的 AI 功能即可调用；模型层不由厂商预置，本地端点如 Ollama 同样能接。值得留意的是默认模型按能力分设：对话、生图、媒体、搜索各选各的——文本类请求交给 DeepSeek，其余能力可以指定更合适的模型，不必绑死在一处。智能体方面，Claude Code 这类工具经标准协议直接读写文档，写代码调文档 API 不用翻文档。

## 上手的三步

1. 装软件本体：桌面端按系统选对应安装包，装完打开任意编辑器确认界面正常。
2. 配模型：设置里找到 DeepSeek 的供应商条目，填入 API 地址与密钥，获取模型列表、勾选要用的型号，保存并启用。
3. 日常使用：写作卡住时在对话里要一版草稿；成稿后跑一遍全文校对；表格与演示的处理同理，AI 入口都在编辑器内部，不必跳出文档。

三步走完，剩下的是习惯问题——把原本要去网页聊天框完成的事，挪到文档旁边来做。

## 领域助手库的数字

Docs 端有 4576 个领域助手、229 个领域包，全库约 4600 个。与通用对话的差别在于：通用对话每回都得自己组织提示词，领域助手则把行业 knowhow 封装成一次点击的动作。写周报、拟通知、整理会议纪要这类高频事务，都能在领域包里找到现成条目；点一下，助手自带执行范围与写回方式，比从零写提示词省心。另有壳内 MCP 服务（端口 52588），把文档操作能力开放成 MCP 工具。

## 离线装机这条路

开源办公套件能离线装，信创环境也能跑——麒麟与 UOS 走 AppImage 加 deb；整体本地优先、离线可用，配合本地模型端点在内网照样干活；自建部署可以做到零遥测，手册离线可读，快捷键表齐全，从新手到熟手不用依赖在线帮助。服务器部署时全员经浏览器可用，算团队化办公的形态。离线这条路的意义不妨多说一句：它把「能不能用」从网络状况里解耦出来，出差、机房、涉密环境都不必为断网做预案。

## 边界与底线

- Linux 无系统 OCR 引擎，扫描页保留位图不识别
- 仅桌面形态提供 HTML 编辑器
- AI 能力的前提是模型先配好，没配模型时它就是一款传统办公软件
- 格式兼容上明确写清支持什么、不支持什么，比含糊其辞负责任
- 打印不掉链子、断电不丢稿，是办公软件该守的两条底线

这几条边界摆在一起看，共同点是都能事先查证：装之前翻一眼系统要求，用之前确认格式清单，比事后返工从容。

## 三问三答

先把读者最常纠结的几个问题放在这里回答。

### 不连网时它还剩多少功能？

传统办公部分完整保留：文档、表格、演示的编辑照常进行；受影响的只有 AI 部分，若此前配的是云端模型，断网期间无法调用——换成本地端点则不受此限。

### 收费模式是怎样的？

Apache-2.0 开源；授权相关的细则以官方文档为准，本文不展开商业条款。

### 已有 DeepSeek 的 Key，还能同时用别家模型吗？

可以。供应商目录支持多家并存、分别启用，各能力默认模型也分开设置；DeepSeek 与其他厂商的组合使用没有限制。

## 什么人用得上它

适合与否的分界线并不复杂：日常产出以文档为主、又想用国产模型提效的人，这套组合对路；偶尔问两句、文档量不大的人，网页对话已经够用，不必专门装一套软件。另外，对数据流向敏感的单位，本地端点这条路值得优先评估——模型在本机或内网里跑，文档内容不出域，合规上的压力小得多。
