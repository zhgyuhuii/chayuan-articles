# 一文分清大模型教程：选模型看目录比看营销稿靠谱

学大模型，路线比资料重要：先补哪块、用什么练手、怎么验证进步，比囤几百个教程链接有用。这篇把门户里学习相关的板块串成一条线，顺带交代边界。

## 什么是大模型教程

大模型教程这个搜索词，背后是「从哪学起」的需求。承接需求的载体是察元AI 能力广场：插件、技能、MCP、提示词、大模型资源一站检索与下载的智能体门户，配日、周、月、季、半年、年六档榜单与模型智力榜；察元AI OS、察元AI Office、察元AI文档助手、察元AI工舱四条产品线也挂在这处门户下。

口径与数字整理自官方文档，截止时间见文末。

## 学到哪一步用什么板块

- 补基础：教程库另含 4526 篇内置助手教程，按 228 个行业领域分目录，四千多个助手怎么选怎么用，每篇教程就是一份说明书
- 选练手模型：模型中心三件套——大模型目录、厂商页、对比页；按厂商、能力、价格几栏查询与对比（最多 6 个并排），厂商页收的都是核验过的厂商与网关，对比结果链接可直接分享
- 跟行业动态：资讯板块跟踪模型厂商动态与生态消息

三段各取所需，凑成一条从学到用的完整动线。动线走顺的标志是：遇到新概念知道去哪查，遇到新任务知道从哪起步——这两个「知道」比记住任何具体知识点都值钱。

## 一条可照抄的学习路线

- 起步阶段：把提示词写利索。不碰代码，纯对话把摘要、翻译、改写三类任务做熟，先建立体感
- 第二阶段：接一次真实接口。挑个顺手的模型写调用脚本，处理报错、限流、超时，工程感就是从这些琐碎里长出来的
- 第三阶段：做一个组合任务。检索加生成、多轮对话加工具调用，把零散技能串成完整流程

每阶段都有板块可以配合：起步阶段借助智力榜配套的改提示词与模型选型指导，第二阶段靠厂商页接接口，第三阶段翻教程库找同类案例。路线不必死守，卡在哪一阶段就回炉哪一阶段，回炉不是退步，是止损。

## 从教程到实践的过渡

教程看懂和上手会做之间隔着一步，过渡有几个着力点：

- 先复现再改造：照教程原样跑通一遍，再换自己的数据改一版，两轮下来知识点才真正落地
- 小任务开路：别一上来就挑大项目，摘要、分类、改写这类小任务最适合当练手题
- 记录踩坑：每次报错和解决方式记下来，攒成自己的错题本，比任何教程都贴合你的环境
- 定期回头补：学完实践再翻旧教程，常能读出新东西，初读没看懂的地方未必是难点，可能只是时候未到

还有一个笨办法但特别有效：把学过的内容讲给别人听。讲不顺的地方就是没学透的地方，回头补，比再刷十篇教程管用。

过渡期的核心动作就一个：把别人的例子变成自己的例子。

## 对比页的走法

1. 先进模型中心的大模型目录
2. 选定要对比的模型，最多勾 6 个
3. 对比表里看能力、上下文、价格三栏
4. 拷贝对比页链接给同事传阅

## 厂商页的走法

1. 厂商名录里看已核验厂商与网关的名单
2. 按接入方式过滤（OpenAI 兼容、网关转发两类）
3. 厂商页里翻模型清单，把定价看仔细
4. 选定后按厂商页说明接入

## 学习路上的疑问

### 一个对比页能装下几个模型

对比页支持多选，最多 6 个并排，能力、上下文长度、价格三维度同页呈现；练习期拿它观察不同模型的性格差异，比背参数表直观得多。

### 智力榜对学习者有什么用

按五维度综合评测，每维度 0-100 百分位、总分取五维等权均值，含改提示词与模型选型指导——学提示词时拿它当参照系，知道自己调的方向是变好还是变坏。

### 免费模型榜怎么配合学习

另有免费模型榜，智力榜看能力上限，免费榜看成本下限；练习期用免费榜控成本，出活后按智力榜升级，节奏就顺了。

## 榜单之外的补充

- 智能广场的导航分三栏，资源按类型即取即用：智能体、MCP、插件、技能、教程库、提示词、技能包
- 模型价格和新品动态来得勤，常翻资讯页跟住节奏
- 榜单排序里，无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先
- 学到半途发现方向不对，及时止损换线也是能力——路线是拿来调整的，不是拿来供着的
