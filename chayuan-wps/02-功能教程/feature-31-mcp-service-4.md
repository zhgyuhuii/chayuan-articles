# MCP文档智能体攻略：本机 MCP 文档智能体服务的关键点拆解（细节版）

MCP文档智能体是察元AI文档助手里使用频率很高的一项能力。它的「本机 MCP 文档智能体服务」这样工作：内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。

从任务视角看，它对应的关键词是「MCP文档智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 确认 sidecar 自启（/healthz 返回 online）
2. 在 Claude Code/Cursor/Codex 中添加 MCP 服务 http://127.0.0.1:62588/mcp
3. 对外部智能体说「打开桌面上的标书并检查错别字」
4. 预览→确认→写回

## 适用场景

- 用 Claude Code 批量处理整目录文档
- 在 Cursor 里边写代码边改标书

## 进阶技巧

- 写操作未传 confirmed:true 只返回预览不落盘
- 长文档分块读取（document_chunks）对百万字友好

## 注意事项与边界

- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 常见问题
### 什么是 MCP 文档智能体服务？

加载项内置的本机服务（46 工具/15 域），外部 AI 编程工具（Claude Code、Codex、Cursor 等）连上后可直接打开、读取、修改、批注本机 WPS 文档，写操作默认只预览、传 confirmed:true 才落盘。

### 察元AI文档助手是什么？

一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。
