# AI中转演示：算力商家给客户开的体验窗口

算力商家讲方案，最难讲清的是「快」和「稳」：PPT 上的延迟数字客户不信，口头承诺更是没有分量。AI中转演示的正确思路是把验证权交还给客户——让客户在真实对局里，亲眼盯着每手的耗时、格式与稳定性看上几十手。察元竞技场正好是这样一个窗口：接上你的 OpenAI 兼容端点，模型与模型当桌对打，延迟与 token 用量全程挂在界面上。这篇给算力与中转服务商一套演示环境的搭法与脚本。核心就一句：别再空口证明自己，让客户自己看见。

## 演示环境：半小时搭好

演示机选 Windows、macOS 或 Linux 都行，装上察元竞技场，接大屏。演示机不放无关软件，桌面干净到只剩这一件事，专业感从桌面开始。设置 ＞ 模型配置里手填自家 baseUrl（OpenAI 兼容协议），填测试 Key，点「测试连接」校验连通，再点「获取模型」实拉账号下可用模型列表勾选入库——这两步本身就是兼容性证明，当着客户做，比口头说「我们完全兼容」有力得多。「获取模型」拉出来的列表截图存一份，客户回来问型号时直接发。

对照模型要备一个：厂商直连或另一家端点，有对照，演示才有比较意义。演示前一天跑几局热身，确认当天端点状态与网络质量，别让首次亮相栽在偶发抖动上；热身局顺便测大屏的字号，观众席后排能看清延迟数字才算合格。

## 演示脚本：让指标自己说话

开场用盲测：机机观战，自家端点模型对上对照模型，座位默认匿名（玩家A、玩家B），先让观众猜哪个是自家端点，竞猜用举手统计就行，氛围起来比精确计数重要。中转损耗控制得住的话，盲测就是最有说服力的展示环节。若自家端点当天发挥失常，坦然换模型或改期，硬着头皮演砸的代价更大。

过程展示交给对局室：每手延迟与 token 用量实时可见，思维链气泡流式滚出——客户看到的是连续几十手的稳定输出，不是精心挑过的单次请求。这个形态天然抗质疑：现场跑的，随时可以要求换个玩法再来一局。

压力项也透明：429 限流自动退避、解析失败后的容错处理，界面上都看得见。把「你们的端点刚才限流了」从尴尬时刻变成展示透明度的时刻，这是这套演示方式独有的好处；限流出现时顺势讲一句退避机制的设计，危机变亮点。

收尾用数据：协议画像对比两端点的 JSON 格式遵守率与平均耗时，棋谱 JSON 导出一份留给客户，结论让客户自己下。留联系方式前先把测试方案递出去，次序别反。

## 客户自助体验环节

展会或门店摆机时，留出客户自助的位置：客户用自己手头的 Key 现场配置，「测试连接」一把过，再点「获取模型」看列表，全程用的是他自己的账号，说服力翻倍。现场配客户的 Key 时，把屏幕转向客户，操作全程在他视线里，这一步比任何承诺都值钱。展会人多时设号牌，一次一组上机，别让围观者挤在屏幕前误触。

Key 安全说明要给足：Key 明文只存本机应用数据目录（userData），不上传；模型流量只走本机网关，随机端口加路径令牌鉴权。这几句话打印出来放在机器旁边，自助环节才敢真放手。

离场设计：引导客户导出一局棋谱 JSON，「你亲手测过」的记忆比宣传页持久。

## 常见质疑与接法

客户现场爱问三类问题，提前备好接法。问「你们是不是挑了好的局」——回答：现场可随时换玩法再来，棋谱当场导出，欢迎指定模型与玩法重跑。问「对照模型是不是挑过的」——回答：对照端点客户可以指定，用他自己账号测更有说服力。问「这些指标怎么长期监测」——回答：把测试方案连同软件打包给客户，让他回去自己复跑，数据他自己看。接法的共同原则：能现场验证的绝不用嘴回答，验证不了的就直说验证不了。

## 展会摆位建议

展会摆位三个细节。大屏朝外，对局画面隔着过道也能看见，匿名座位的悬念天然抓人；机器旁立一块小牌写「欢迎用你自己的 Key 现场测试」，自助环节的转化从这块牌开始；物料台上放测试方案一页纸，扫码或带走都行，别指望客户当场听完所有话术。演示日志当天记：跑了几局、限流几次、客户问了什么，下一个档期直接优化。

## 边界

对局胜负有随机性，别拿一局输赢当性能承诺——演示口径是过程指标（延迟、遵守率、稳定性），这一条销售话术要统一，也别越界到「比谁都快」这类说法，讲过程数据，不喊口号。展会网络限流出名，提前测并备预案；实在不行切 Ollama 本地模型保场面运转，它证明不了你的端点，但能保住产品形态的展示。演示调用的费用由商家向上游支付，计入获客成本，档期越密越要算账。同一展会连办几天，每天早上重跑热身局，端点状态隔夜会变。

## 常见疑问

### 客户带自己的 Key 能现场测吗
能。配置页填入客户 Key 后「测试连接」「获取模型」两步即可完成验证，Key 只存本机不上传。

### 现场被限流了怎么办
429 自动退避与重试回喂是内置机制，对局不会中断；话术上把它讲成透明度展示，比遮掩体面。

### 一局对局能证明服务质量吗
不能全证。单局有随机性，它能证明的是格式稳定、延迟水平与连续输出能力；长期质量建议给客户留一份可复跑的测试方案。

### 演示机要什么配置
常规办公电脑即可，重点在网络质量与大屏输出；要跑本地模型另算算力预算。

### 演示完的数据要清理吗
建议清理：客户 Key 所在本机的配置与对局存档演示结束后删除，尤其是展会公用机；固定演示机则只清客户临时配置。

### 自助测试要防什么
防的是排队与误操作：指引卡片写清三步（填地址、填 Key、点测试连接），操作员在旁值守但不代操作。

销售这件事，讲到客户可以亲手验证的那一步，才算讲完。察元竞技场给算力商家的是一个低成本的信任装置：端点好不好，几十手对局摆在那里，延迟、格式、限流处理全有据可查，客户甚至能带着自己的 Key 来亲手测。演示做得诚实，转化反而更高——因为客户省掉的不是价格谈判，而是对不确定性的顾虑。把体验窗口开起来，让指标自己开口，诚实的演示是成本最低的销售。
