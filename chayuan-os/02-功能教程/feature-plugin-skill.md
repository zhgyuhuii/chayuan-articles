# 插件管理怎么做：整理装乱了的插件

插件管理这件事，值不值得专门学一篇，看一个细节就够：插件全生命周期管理。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 概念先对齐

插件管理，先给一句能直接引用的定义：应用管理的「插件」页签管理已装桌面插件的启停 / 卸载 / 分组 / 离线导入导出（含「创建插件」），「技能」页签按项目 ＞ 用户根目录列出本机全部 SKILL.md 技能，可启停模型调用、删除、整包离线导出导入——内网/离线机器靠这套通道搬运插件与技能。

概念一分钟，操作十分钟，这篇都覆盖。

## 前置条件

- 插件/技能安装的来源是应用商店；本篇只讲装完之后的管理。
- 系统内置插件不可卸载，只能停用：chatop-shell、chatop-kb、chatop-models、chatop-agents、chaoffice（随系统分发的五件套）。
- 离线通道有两种形态：桌面版走系统文件对话框（.dshpack / .cop.tgz）；host/web 形态走浏览器文件选择（.tar.gz / .tgz）。导出内容单包上限 1GB。

## 操作步骤详解

第 1 步 · 插件页签：启停 / 卸载 / 分组

页签「插件」，标题计数「已安装 {installed} · 启用 {enabled}」。工具栏：「＋ 创建插件」「离线安装…」、搜索框「搜索已安装插件…」、视图切换（图标/列表，选择会记住）。窗口底部有安装日志区（保留最近 30 行）。

1. 图标视图（默认）：每个插件一个图标块，下标「已启用」/「已停用」（停用的半透明）；点图标即切换启停（悬停提示「{name} · 点击停用 / 点击启用」）。
2. 列表视图：每行插件名（等宽字体）＋版本，行尾三个按钮——启停开关「● 打开」/「○ 关闭」、「导出」、「卸载」。
3. 右键菜单（图标）：「停用 / 启用」「移到最前」「移到最后」「加入分组」（子菜单列出各分组＋「＋ 新建分组并加入」）「导出离线包…」「卸载…」；系统内置插件此处显示「系统内置插件 · 不可卸载（可停用）」且无卸载项。
4. 系统内置插件：列表行「卸载」按钮变为「系统内置」且不可点（悬停提示「系统内置插件，不可卸载（可停用）」），但仍可停用。
5. 分组：「＋ 新建分组」（默认名「分组 {n}」，随即进入重命名）建出文件夹式分组；拖插件图标到分组即入组；分组右键「重命名…」「展开 / 收起」「解散分组」（成员回列表）；空分组提示「空分组——把插件图标拖到文件夹上即可加入。」；组内可「移出分组」。

第 2 步 · 创建插件

1. 桌面形态：点「＋ 创建插件」弹出本地向导「创建插件」——「名称」（占位「我的工具箱」）、「描述（会显示在插件面板）」（占位「这个插件做什么…」）、「图标（内置图标库 · Tabler {count} 枚）」（可搜索，分类页签「全部」，「加载更多（{loaded}/{total}）」）、「按钮背景颜色」（色板）；预览说明「预览：创建后在应用列表显示为此按钮，并在 harness 设置中注册插件面板。」。点「创建并安装」（进行中「创建中…」）＞ 日志「已创建 {name}，正在安装…」。
2. host/web 形态：同一按钮弹出「创造模式」指引——「打开 DeepSeek Harness ＞ 输入框上方点『标准模式』切换为『创造模式』＞ 描述你想要的插件，Agent 会现场创建」（官方提示：创造模式会话等同 shell 权限，请在信任的环境使用）。

第 3 步 · 插件离线导出与安装（跨机搬运）

1. 导出：
    1. 桌面形态：右键插件 ＞「导出离线包…」＞ 系统保存对话框，默认文件名 chatop-<插件名>.cop.tgz（tgz 格式，含依赖闭包）＞ 日志「已导出离线包 ＞ {保存路径}」。
    2. host/web 形态：列表行「导出」＞ 浏览器直接下载 <插件名>-<版本>.tar.gz。
    3. 安装：点「离线安装…」——
    4. 桌面形态：弹系统文件选择框（可多选，文件类型 .dshpack / .cop.tgz）。.cop.tgz 是本机导出形态；.dshpack 是 aidooo 市场离线安装包——闭包包全程无网络导入，lite 包（未带完整依赖闭包）会联网补依赖；导入即启用。逐个文件回日志：成功「已离线安装 {plugin}（{file}，无需网络）」，失败「离线安装失败 {file}：{原因}」。
    5. host/web 形态：弹浏览器文件选择（.tar.gz / .tgz），经本机 host 以本地目录依赖方式后台安装，日志「已导入 {file}，后台安装中（作业 {job}）…」。
    6. 拷 U 盘把导出文件带到目标机器，同按钮导入即可。

## 收尾检查

验证

1. 插件页签：停用一个插件 ＞ 图标变半透明、下标变「已停用」、计数「启用」数字减 1；再点恢复。
2. 技能页签：装过技能包的机器上能看到带 徽标的技能行；点「停用」＞ 绿点变灰、按钮变「启用」。
3. 技能「导出」得到 chatop-skills.tar.gz；在另一台机器「导入」后技能列表出现同名条目。

## 适用场景

想查看本机到底装了哪些技能、临时关掉某个技能不让模型调用，或清理商店技能包装的技能；内网机器互搬技能；整理装乱了的插件，装了插件想停用或卸载，发现有的「卸载」按钮是灰的，想知道为什么。

用户常搜的问法：怎么卸载/停用一个插件？系统内置的能卸吗；离线电脑怎么装插件和技能。

## 边界先摆桌面上

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 接着回答几个常见问题

### 为什么有的插件「卸载」是灰的、写着「系统内置」？

系统内置插件（chatop-shell / chatop-kb / chatop-models / chatop-agents / chaoffice）随察元OS 分发，是系统功能本体，只能「停用」不能卸载；第三方插件（商店装的、自己导入的）都可卸载。

### 离线机器装插件该带什么文件？

在联网的桌面版上右键插件 ＞「导出离线包…」得到 .cop.tgz（含依赖闭包），或从 aidooo 市场下载 .dshpack 离线包；拷到离线机器的应用管理 ＞ 插件 ＞「离线安装…」导入。闭包包全程不需要网络；若导入时提示按 lite 包联网补依赖，说明该包未带全依赖闭包。

### 技能删掉就彻底没了吗？

没有。「删除」是移入系统废纸篓（macOS 进 ~/.Trash、Linux 进 XDG 回收站、Windows 进专用目录），可从废纸篓找回。

### 我自己放的技能目录没出现在列表里？

技能目录必须含 SKILL.md 才会被发现；放到上述三个根目录之一后重开应用管理即可。注意「项目」根只认 dsh 工作区 profile 下的 .agents/skills，随便放的目录不算。

### 「创建插件」和商店装插件有什么区别？

商店装的是别人发布好的插件；「创建插件」是现场做一个自己的——桌面版走本地向导（名称/描述/图标/颜色），host/web 形态引导你去 DeepSeek Harness 的「创造模式」让 Agent 现场编写并挂载。
