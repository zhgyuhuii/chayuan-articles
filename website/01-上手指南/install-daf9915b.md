# 登录异常怎么做？登录异常排查一次讲清

验证码与会话过期。本文以「登录异常排查」为主题，给出察元AI 能力广场的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：网站首页 https://aidooo.com；产品页 https://aidooo.com/products；教程库 https://aidooo.com/tutorials。系统要求总览：浏览器（桌面与移动）——现代浏览器即可，无需安装客户端；察元AI OS 客户端——安装察元AI OS。

## 问题定位与处理

安装类问题九成出在三个环节：安装包与系统架构不匹配、安装目录权限不足、安全软件拦截。先按这三条排查，再进入具体问题处理。

1. 症状确认：复制了安装命令但装不上？
2. 按官方口径处理：网站只收录信息与安装命令、不存二进制：命令执行依赖原始仓库可用性；先看条目 health 状态（active/degraded/dead），degraded/dead 的条目建议寻找替代。
3. 处理后在干净环境复现验证一次
4. 仍失败时收集系统版本与报错截图，通过官网支持渠道反馈

## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：升级采用覆盖安装方式，用户数据目录不受影响

## 相关报错速查

- 登录提示验证码错误或会话过期？——验证码区分大小写以页面提示为准；会话过期重新登录即可，收藏与投稿数据都在账号下不会丢失。
- 复制了安装命令但装不上？——网站只收录信息与安装命令、不存二进制：命令执行依赖原始仓库可用性；先看条目 health 状态（active/degraded/dead），degraded/dead 的条目建议寻找替代。
- 投稿没有通过审核？——常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 常见问题
### 投稿没有通过审核？

常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。

### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。
