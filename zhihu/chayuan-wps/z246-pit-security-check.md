# 察元文档助手保密检查实录没宣传的那么神，坑在这

用了一段时间之后，我对察元文档助手保密检查实录的态度从「真香」变成了「挑着用」。中间发生了什么，往下看。

先把预期摆正：任务清单：完整审查报告存入任务记录，小节固定为「总体结论 / 高风险项 / 中风险项 / 低风险或待人工复核 / 建议处理 / 可疑关键词汇总」，每条命中项含命中片段、命中关键词、风险类别、判断依据、建议处理。组织身份与单位名称：机关名称、部队番号、院所名称、公司全称、供应商、客户名称等。经营与商业敏感信息：报价、成本、投标方案、采购清单、客户名单、未发布经营数据等。

### 第三个坑：费用与额度

表现是这样的：涉密程度高的文档，建议先在设置里切换到本机离线模型再执行保密检查与脱密。

在对话窗格查看智能体返回的问题清单，按条目人工处理。表格端：扫描已用区域，识别手机号/身份证号/银行卡号/邮箱/工资薪酬列等敏感数据，输出「位置+类型+样例脱敏展示（如 1381234）」的问题清单，不修改任何单元格。

逐条核对批注与报告，按「建议处理」修改文档（删除或模糊密级标识、单位全称泛化为「有关单位」、隐去具体时间地点联系人编号等）。保密检查本身不改正文，改不改、怎么改由你决定。内部编号与项目标识：项目代号、型号代号、合同编号、文号、图号、批次号等。军工/政企文档高频敏感线索：机场、阵地、雷达站、研究所、专项任务、技术指标等。

根子在：请查看任务清单对照修改后重试。

绕法也有：它是辅助筛查，最终结论请以人工保密审查为准。

一个绕不开的问题：点「保密检查」弹出「购买授权」窗口？ 它对离线场景友好，接本机 Ollama 全程不出网，涉密文档也能用。

### 装完才懂的前提

遇到的画面是这样的：「文档外发前怎么自查敏感信息？」

表格/演示稿外发前快速过一遍敏感数据。具体到操作面，内部通讯录等这条在手册里写得很细。

人员与联络信息：联系人姓名、职务、手机号、邮箱、证件号、内部通讯录等。模型输出的片段若与原文对不上，该条会被跳过（不做整篇兜底批注），界面会有相应提示。这套做法谈不上新颖，但胜在稳。

根子在：打开任务清单看完整报告，对照「命中片段」手工定位即可。 说实话，第一眼我以为多余，用下来才知道是刚需。

解决办法很朴素：助手上千个，按行业领域分目录，每个助手对应一类高频文书。

### 文档没强调的一步

表现是这样的：免费额度按天重置，对话和助手是两个独立池子，轻度使用够用。

演示端：逐页检查敏感词/密级表述/内部代号/客户名与金额等，输出「页码+内容摘要+风险级别」的问题清单，不修改任何文字。文档外发、上报、公开前的自查：想知道里面有没有密级标识、部队/单位敏感表述、内部编号、联系人信息等。代价在这里，得认。

筛查定位：任务列表上方还有「全部定位质量 / 仅精确命中 / 包含整句回退 / 包含定位失败 / 高风险任务」下拉，可按批注锚定质量过滤任务，快速找出需要人工对照的报告。收到一份「要脱密处理」的文档，先摸清楚有哪些风险点，再决定用「文档脱密」遮盖哪些词。这不是玄学，是写进文档里的行为。

原因不复杂：典型提问（chabot 语料视角）： 这个细节不影响功能，但决定你愿不愿意一直开着。

绕法也有：翻译支持五十多个语种，逐段替换保持排版不乱。

说了这么多坑，也得给结论：它的保密结论只是辅助筛查，不构成定密结论，这点文档写得明明白白。说明：检查结果的锚点批注与「AI 痕迹检查」共用同一套「命中片段」抽取规则。默认写回动作为链接批注，要换成普通批注或不写回可在 设置 助手设置 中修改该助手配置。

在表格（ET）或演示（WPP）的「察元AI助理」选项卡，点「文档安全」▾菜单 「保密检查」。具体到操作面，命中片段以批注锚定到原文这条在手册里写得很细。这一点挺难得，很多同类产品只在宣传页里讲。
