# 察元OS 内置的浏览器窗口：内置浏览器完整走法

「察元OS 里有浏览器吗？怎么打开」——这个问题最近被问了好几次。答案不复杂：内置浏览器在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 一句话说清定位

内置浏览器，先给一句能直接引用的定义：察元OS 内置的浏览器窗口：地址栏兼搜索框（百度/谷歌/必应/360 四引擎可切换、选择被记住），带前进/后退/刷新/主页、图片下载到系统、一键转系统浏览器打开；桌面形态用独立渲染进程加载网页，绝大多数网站可直接内嵌显示。

入口、步骤、验证三段看清，这事就顺了。

## 动手前的准备

- 桌面/网页形态均可使用（网页形态以内嵌框架加载，拒嵌站点见第 5 步与 FAQ）。
- 联网可用（访问外部站点）。

## 一步步来

第 1 步 · 打开浏览器

Dock 点「浏览器」，窗口默认落在当前搜索引擎的主页。顶栏自左到右：红绿灯 | 「＜」「＞」「⟳」三个导航钮 | 地址栏 | 「主页」「下载图片」「外部打开」三钮。

第 2 步 · 地址栏：搜索或直达

1. 地址栏左侧是搜索引擎下拉（悬停提示「搜索引擎」）：「百度」（默认）/「谷歌」/「必应」/「360」。切换后立即跳到该引擎主页，且选择被记住（下次打开仍是它）；输入框占位随引擎变（如「搜索百度或输入网址」）。
2. 在地址栏输入后回车，自动判断意图：
    1. 内容含空格或没有点号 ＞ 当作搜索词，交给所选引擎出结果页；
    2. 形似域名 ＞ 自动补 https:// 直达。
    3. 加载期间整页显示旋转加载指示与「加载中…」，完成后消失。

第 3 步 · 导航三钮与主页

1. 「＜」后退、「＞」前进（无可退/进时置灰）；「⟳」刷新当前页（加载中时按钮旋转）。
2. 「主页」按钮（房子图标，悬停提示「主页」）：回到当前引擎主页（已在主页时等于刷新）。

## 怎么确认做成了

验证

1. 地址栏输入 察元OS 回车：进入当前引擎的搜索结果页（URL 形如引擎搜索链接）。
2. 搜索引擎下拉切到「必应」：页面立即变为必应主页；关掉浏览器重开，默认仍是必应。
3. 点「＜」：回到上一页；再点「＞」：前进到结果页。

## 适用场景

某些网站内嵌显示不了，需要转交系统浏览器；查资料；不想离开桌面就想查个资料、开个网页；让智能体盯网页。

用户常搜的问法：察元OS 里有浏览器吗？怎么打开；浏览器的默认搜索引擎怎么改？现在是百度。

## 这些坑和边界要知道

边界先摆在桌面上：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 常见问题

### 浏览器支持多标签吗？

当前是单页窗口（一个窗口一个页面），没有页签栏；Dock 上的「浏览器」点击时聚焦已有窗口。要看刚访问过的页面用「＜」后退、「＞」前进。

### GitHub / 知乎打不开，提示拒绝内嵌？

这类站点用 X-Frame-Options/CSP 禁止被框架内嵌。点提示条里的「在新窗口打开」（或顶栏「」）交给系统浏览器；桌面形态内置浏览器本身用独立渲染进程加载，一般不会遇到该提示。

### 怎么换默认搜索引擎？

地址栏左侧下拉直接选（百度/谷歌/必应/360），切换立即生效并记住；谷歌走内嵌兼容参数加载。

### 「将图片下载到系统」下载的图片在哪？

该功能把图片网址记入浏览器侧下载清单（对话框提示语「打开文件管理查看下载项」）。要把图片放进察元文件系统，改用在「我的电脑」上传。

## 更多操作细节

第 4 步 · 下载图片到系统

1. 「下载」按钮（绿色向下图标，悬停提示「将图片下载到系统」）：
    1. 当前页地址本身是图片（.jpg .png 等）＞ 直接记录该图片；
    2. 否则弹出「将图片下载到系统」对话框：按提示「粘贴要下载到系统的图片网址」填入图片 URL（占位 https://example.com/image.jpg），点「下载」或「取消」。对话框还带「小提示」：在浏览器中右键点按任意图片，选择「拷贝图片地址」，粘贴到此处即可下载到系统。
    3. 成功后显示「下载成功！」+ 文件名 +「打开文件管理查看下载项」。（该下载清单是浏览器侧的图片记录，写入系统内部下载列表；在桌面形态的「我的电脑」窗口中不显示。）

## 更多操作细节

第 5 步 · 转系统浏览器与拒嵌提示

1. 「」按钮（悬停提示「在新窗口（系统浏览器）打开」）：把当前页交给电脑默认浏览器打开。
2. 拒嵌提示条：网页形态下，遇到拒绝被内嵌的站点（X-Frame-Options / CSP，如 GitHub、X/Twitter、YouTube、知乎、B 站等已知拒嵌域，或加载 6 秒仍无响应）时，页面底部出现提示条「该网站拒绝在内嵌框架中显示（X-Frame-Options / CSP），可改用系统浏览器打开。」，右侧蓝色「在新窗口打开」一键转系统浏览器，× 可关闭提示条。
3. 桌面形态用独立渲染进程加载（非普通内嵌框架），绝大多数站点可直接显示，不受常见拒嵌限制。
