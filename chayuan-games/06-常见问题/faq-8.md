# 察元竞技场支持哪些系统：平台与安装包清单

打开下载页，dmg、exe、deb、rpm 一排排摆开，后面还跟着 arm64、x64 的后缀，不少人当场开始怀疑自己的电脑到底姓什么。察元竞技场支持哪些系统，其实一张清单就能说清：Windows、macOS、Linux 三大桌面平台全覆盖，每个平台再按芯片架构分两个包，下载渠道就两个。这篇按清单、选包、验证、下载的顺序讲，清单本身不复杂，复杂的是大家的机器五花八门，所以架构怎么判断、装错了怎么办、两个渠道有什么差别，都专门拿出来说。清单、架构、渠道，三个问题一次答完。

### 察元竞技场支持哪些系统？先看平台清单

三大桌面平台：macOS、Windows、Linux。具体到包：macOS 提供 dmg，分 arm64 和 x64 两个架构；Windows 提供 exe，分 x64 和 arm64；Linux 提供 deb 和 rpm 两种格式，各自也有 x64 和 arm64 版本。它按 Electron 的跨平台思路打包，一套代码出多平台安装包，三个平台的界面和功能一致，暗色竞技场 UI、中英双语，换平台不用重新适应；11 款玩法在三个平台上都齐，包括军棋暗棋这类规则较重的玩法，功能没有按平台阉割；三大平台一套玩法，谁也不偏心。全平台数下来一共八个包，覆盖市面上绝大多数桌面电脑，装完进大厅，看到的玩法分组和官网介绍一致，可以当作装对包的自检点。它是 Electron 桌面应用，安装后的产品名叫察元AI游戏，认准这个名字，别在应用列表里找错；下面这张清单建议照着自己的平台抄一遍，再动手下载。

### macOS 有几个安装包，Apple 芯片和 Intel 怎么选

两个 dmg 包，按芯片选。苹果自家的 M 系列芯片是 arm64 架构，2020 年底之后买的 Mac 基本都是这一类，选 arm64 包；老一些的 Intel 芯片 Mac 选 x64 包，公司配的 Intel 老机器跑云端模型毫无压力。不确定的话，点左上角苹果菜单看「关于本机」，芯片一栏写着 Apple 几就选 arm64，写着 Intel 就选 x64。dmg 拖进应用程序文件夹就能用，和普通 Mac 应用没有区别。装错架构轻则弹警告，重则应用打不开，下载前花十秒确认，比装完再折腾省事；两个包的玩法内容没有区别，差异只在架构适配。

### Windows 的 exe 分哪两种，arm64 给谁用

x64 是绝大多数 Windows 电脑的选择，Intel 和 AMD 的主流处理器都算这一类，主流台式机和笔记本都是它；arm64 包是给搭载高通骁龙这类 ARM 芯片的 Windows 设备准备的，比如部分新出的轻薄本和二合一设备，近两年的新物种；挑包之前把设备型号搜一下，一分钟就能确认是不是 ARM 阵营。分不清就选 x64，这是 Windows 阵营的主流通用包；ARM 设备装 x64 包有的也能靠转译跑起来，但原生 arm64 包更顺，能选原生就选原生。首次启动如果遇到系统拦截提示，按提示选择继续运行即可，桌面软件的常见情况。装完发现起不来，先回头查架构，别急着怀疑安装包本身；先查架构、再换包，九成的问题出在这一步。

### Linux 装 deb 还是 rpm

看发行版。Debian、Ubuntu 及其衍生版用 deb 包，Fedora、openEuler、openSUSE 这类用 rpm 包，两个格式各自覆盖 x64 和 arm64 架构，deb 和 rpm 不要混装，包管理器之间不认对方的包，混装只会收获报错。选错格式的表现通常是包管理器直接拒装，不会造成什么破坏，换对应的包重装即可；拿不准发行版用哪个包，去开源仓库的说明页对照一遍，比猜快，装完用包管理器的查询命令确认一下版本，顺手的事。信创环境的机器多数走 deb 或 rpm 加 arm64 这条线，装之前先确认系统版本和架构，再挑包，老机器和虚拟机尤其容易在架构上翻车，避免白下载一遍。

### 怎么确认自己机器的架构

macOS 看关于本机，芯片名称就是答案；Windows 在系统信息里看处理器型号，系统类型一栏也会写明是常规 64 位还是 ARM；Linux 跑一下 uname -m，输出 x86_64 对应 x64 包，输出 aarch64 对应 arm64 包，这是最省事的办法。虚拟机要按宿主分配给它的架构算，别按物理机算，这是容易踩的坑；Windows 用户也可以在系统设置里直接看设备规格，原理相同，两套办法互相印证，结论更稳。确认架构的动作在每个平台都只要十几秒，却能把返工概率压到接近零，值得在下载前做一次，养成这个习惯，换新机器、重装系统时同样用得上。

### 手机和平板能不能装

不能，它只出了桌面平台的安装包，没有移动端。这不难理解：棋盘对局界面、多座位观战、锦标赛积分面板这些设计都是按桌面尺寸做的，手机屏幕塞不下也不好用；键盘鼠标的操作效率，也比触屏点棋盘高得多；对局室的思维链气泡、形势曲线这些面板，在窄屏上只能牺牲信息密度，体验必然缩水。想在客厅大屏上玩，接一台小主机跑 Linux 版是更现实的路线；想在手机上跟进战况，目前只能靠桌面端跑着，人在旁边看，或者等官方后续的安排；这条边界写在这里，省得有人抱着手机等一个不存在的包。

### 安装包去哪里下才靠谱

两个渠道：官网 aidooo.com，和开源仓库 github.com/zhgyuhuii/chayuan-games。官网在察元AI 广场入口下找对应产品的下载页，介绍和文档对新手更友好；开源仓库连源代码一起给你，MIT 协议，版本记录和源码结构都摊开，对想研究实现的人是加分项；两个渠道都能拿到当前版本的安装包，版本对得上就放心用。下载后顺手核对文件名里的架构后缀和你的机器一致，这一步做了心里踏实。认准这两个地址，别从第三方转载站下安装包，桌面应用的安装包一旦被塞料，损失的就不只是体验了。

平台清单、架构后缀、下载渠道，三件事捋顺了，安装这一步基本不会翻车。记住主线：三大桌面平台，每平台两架构，Apple 芯片和 ARM Windows 走 arm64，其余走 x64，Linux 按发行版挑 deb 或 rpm，八个包不必背下来，用到哪个查哪个就行。选对包，剩下的就是配模型、进大厅、开打了；装好只是开始，配模型、挑玩法、上天梯才是正餐。下载完顺手看一眼文件体积是否正常，异常小或异常大都要警惕；移动端不是不能做，是现阶段没做，别把猜测当承诺。
