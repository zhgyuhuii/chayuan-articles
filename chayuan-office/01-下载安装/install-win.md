# Office Windows安装安装：NSIS 安装器步骤

Office Windows安装的主线是一条 NSIS 向导：取包、双击、选目录、启动，四步走完。这篇以 Windows 为主线把每一步的界面与验证写清，顺带交代 Windows 侧独有的细节与格式边界。

## 安装前确认

- 系统要求：Windows 10 及以上，x64/arm64
- 安装包：NSIS 安装器 exe
- 说明：NSIS 安装器步骤。

exe 的正规出处只有官方发布渠道，论坛帖、网盘转存一律当未知来源对待。

## 实操全过程

1. exe 从官方渠道取得，x64 与 arm64 包体按机器架构选
2. 双击安装
3. 启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama
4. 开始页新建或打开文档

## 其他平台装法速览

Linux：对应包型从官方发布处取；deb 用 dpkg -i，AppImage 加执行权限直接运行；麒麟/UOS 走 AppImage 加 deb，免 root。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

装好后先确认六个编辑器都能建新文档（docx/xlsx/pptx/PDF/Markdown/HTML），然后把模型配好、跑一次 AI 校对；两条线验证通过再正式开工。

## 如何确认操作生效

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

## 注意事项与真实边界

有几条边界值得在装包前先认：

- web/dsh 形态只装五个编辑器、不含 HTML，购买与激活界面也没有

## 装机前后常被问到的事

### 镜像站的包和官方包是一回事吗？

不建议赌运气。官方包只从自家发布渠道出去，镜像站那份是否被动过无从验证，装机后行为异常很难归因，回头重取官方包才是稳妥解。

### 麒麟/UOS 机器该选哪种包？不联网能装吗？

.AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb 都行。包拿到一次后即可拷进内网机器直接安装运行，应用本体不依赖联网。

## 拿包：按平台与架构选择

第 1 步 · 下载安装包

到官方下载中心按平台选择安装包：

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS | `.dmg`（另有 `.zip`） | macOS 11+；打开 dmg 后把应用拖入「应用程序」 |
| Windows | `.exe`（NSIS 安装向导） | Windows 10+；可选择安装目录；安装时注册 docx/xlsx/pptx/pdf/md/html 文件关联 |
| Linux（Debian/Ubuntu） | `.deb` | `sudo apt install ./…` |
| Linux（Fedora/RHEL/openSUSE） | `.rpm` | 用 `dnf` / `zypper` 安装 |
| Linux（麒麟/UOS/通用） | `.AppImage`（另有 `.deb`/`.arm64`） | 免 root、离线友好，适合信创与内网环境 |

## 装好并启动

第 2 步 · 安装并启动

1. macOS：挂载 dmg，把应用图标拖入 Applications，首次从启动台/应用程序打开；
2. Windows：运行 .exe 安装向导，按提示选择目录完成安装，从开始菜单/桌面打开；
3. Linux：按上表命令安装，或对 .AppImage 加执行权限后直接运行（无需安装、无需 root）。

## 验证清单

验证

1. 启动应用后能看到标签条第一格为「察元AIOffice」首页标签，首次启动出现上述三页引导，三页标题依次为「欢迎使用 察元AIOffice」「这只是一个开始」「人人免费」。
2. 点「跳过」或「开始使用」后引导关闭；关闭应用重新打开，引导不再出现。

## 补充答疑

### 三页欢迎误点了跳过，想补看怎么办？

没有补看入口，引导完成标记已保存、不再弹出。想系统了解功能，F1 呼出的手册（18 主题，可搜索）比引导页讲得更细。

## 装机自查清单

- 操作系统：Windows 10+、macOS 11+、Linux（含麒麟/UOS，AppImage 要求 glibc 2.34+）。
- 包体来源仅认官方发布渠道；除此之外的任何站点，其安装包都不算官方分发。

## Windows 安装版能力点

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

Windows 向导安装时可自选安装目录，装的时候顺带注册 docx/xlsx/pptx/pdf/md/html 六类文件关联，装完双击文档默认由本应用接手——这个细节对从旧办公软件迁移过来的用户最省心。系统盘空间紧张的机器，把目录改到数据盘即可，向导不强制默认路径。

## 图表与文档的边界

邮件页签支持批量套打（数据源合并成信函标签）；九种图表加推荐图表、图表库、数据透视图与迷你图，真图表对象直接存进 xlsx；图表是活的（对象级）不是贴图，改数据图跟着变；加密只读文档仅支持查看。

## 格式兼容口径

doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx；Linux 无系统 OCR 引擎，扫描页保留位图不识别。Windows 用户装完第一件事建议跑一遍存量文档盘点，老格式文件提前转存，避免开工当天才发现打不开。

安装到启动的链路就是这些。结果对不上时，先回到验证清单那节核对，再按各节顺序排查。
