# 模型配置可一键写入五家：用显存内存占用跑通一个真实场景

用显存内存占用之前有一条边界要先知道：自动卸载会释放常驻模型，重度使用记得钉住。知道边界再用，这篇剩下的篇幅讲怎么把它用对。

## 为什么值得了解

内存吃紧时手动卸载闲置模型；下载或导入完模型，要把它加载进内存供对话/知识库使用；给常用模型上钉子；模型用一会儿自己「消失」，想搞清 15 分钟空闲自动卸载并固定常用模型。

## 具体怎么操作

9. 重启全部 / 全部关闭

1. 「重启全部」：记录当前运行清单 ＞ 全部卸载 ＞ 按原清单依序重载（提示「已发起全局重启（按原运行清单依序重载）」），处理引擎假死；
2. 「全部关闭」：卸载全部实例（含钉住的）并置停用位，健康灯变灰「已停用」；此后状态条只剩「启动」，点击清停用位并走预热链补齐加载。

从这几步开始：（第 3 个切入角度）

1. 内存仪表实时显示占用
2. 启动参数四档可调
3. 健康灯异常一眼可见
4. 确认边界：自动卸载会释放常驻模型，重度使用记得钉住
5. 场景验证：内存吃紧时手动卸载闲置模型
6. 场景验证：给常用模型上钉子

## 高频疑问

### 为什么有的模型行没有「设置」按钮？

「启动参数」（并发/上下文/GPU 层/线程）只对走 llama-server 的对话能力模型有意义，嵌入/重排/语音等行内不显示该按钮。

### 灵宠群聊同时提问时报 500「Context size has been exceeded」？

并发路数不足或上下文打满。到该模型「设置」里升档（均衡 ＞ 性能）或手填并发路数（1–16），保存后实例自动重启按新参数拉起；每路上下文上限不变。

### 删除了「装机即用」模型，怎么找回？

「删除」只删共享副本并记账（重启播种不复活）。到 设置 ＞ 模型 ＞ 左栏「本地模型」组底部「恢复出厂模型」一键重播种五件套，详见对应教程。

## 更多操作细节

验证

1. 「启动」后行首绿点、状态条计数 +1（如「2 个模型运行中」）；黄点在数秒到十几秒内转绿。
2. 点「测试」显示「测试通过 · <耗时>ms」。
3. 浏览器打开 http://127.0.0.1:52581/v1/models（免 key）：该模型 local/<id> 条目的 running 为 true。
4. 改启动参数保存后，若模型在运行会自动重启——再发一条消息仍正常回复，即新参数生效。

## 动手前再核对一遍

- 至少有一个已安装的本地模型。
- 本地模型服务在运行：页面顶部健康灯绿色「正常」。推理引擎（llama-server / whisper-server）随安装包分发，缺失时见对应教程 常见问题 Q6。
- 「启动参数」仅对带对话能力的模型开放（嵌入/重排/语音等小件行内没有「设置」按钮）。
