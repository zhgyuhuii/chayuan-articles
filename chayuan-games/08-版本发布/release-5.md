# 观战复盘系统：解说、形势曲线与问叹号标注

一局棋的滋味，一半在落子时，一半在打完之后。只看过程不看复盘，输赢成了糊涂账；只看结果不看过程，又错过了模型思考的全程。察元竞技场把两头都做了：观战复盘系统在 0.1.0 里是整套交付的，观战有三件套，复盘有一条工具链。思路是把「看」与「想」分开——看的时候有人替你解说、有图替你标走势；想的时候有标注替你定位、有数据替你佐证。这篇按「看什么、怎么看、看完能留下什么」的顺序讲完。先把结论放在前面：这套系统值得单独开一晚来体验。

版本口径：察元竞技场 0.1.0，2026 年 11 月开源完整版，MIT 协议，仓库 github.com/zhgyuhuii/chayuan-games，官网 aidooo.com，观战与复盘能力随版本全量提供。

## 观战三件套

观战模式的门槛被刻意压到零：不用配策略，不用盯细节，选模型、开局、看，三步之外没有操作。

### 匿名机机观战

选两个或多个模型开一局，你在旁边看，什么都不用操作。座位默认匿名，显示玩家A、玩家B、玩家C、玩家D，身份到终局才由对局引擎揭晓。这个设计解决一个真实问题：知道某座是哪家模型，观众会不自觉地偏心或降低期待，匿名让观众只看棋、不看名字——名字会带偏见，看棋不该先看出身。想看大混战，批量选模型上桌就行：同厂不同代、同代不同厂、云端对本地，随便组局。匿名揭晓那一刻如果结果出乎意料，恰好说明你看棋的眼睛比想象中公正。

### AI 解说：实时与赛后两档

对局进行中可以开实时解说，AI 逐手点评这步棋的用意与局面的走向；一局结束还有赛后解说，把整局的转折点从头串一遍。两档分工清楚：实时档帮你看懂正在发生的事，赛后档帮你理清来龙去脉，看强模型对局时开实时解说，接近带着教练看比赛。解说由你配置的模型来当，想听谁的风格就配谁。看不懂围棋的攻杀、看不懂德州的加注，解说就是你的同声传译。

### 形势曲线

每局自动生成局势走向图，谁的胜面在扩大、谁在被翻盘，一条曲线看得清清楚楚。起伏本身就是剧情：平线说明一方稳压，反复交叉说明胶着，断崖式转折对应盘面上的某一手，配合逐手标注能秒定位。配上对局室里实时滚动的思维链气泡，以及每一手的延迟与 token 用量，观战时你能同时看到「局面在怎么变」和「模型在想什么」。

## 复盘工具链

### 问叹号标注

复盘模式会逐手打标：妙手与失误各有标注（即问叹号标注与叹号标注）。一局几十手上百手，标注帮你直接跳到局面反转的那几手，省去从头看到尾的工夫。它更像一个助手，替你从海量手数里挑出值得细看的部分。

### 回放器与协议筛选

回放器支持按协议字段筛选关键手，把特定类型的出招事件单独捞出来对照着看，定位效率高。几十手上百手的棋不必全量回看，筛出骨架几分钟过完。配合逐手标注，一局的骨架几分钟就能过完。

### 棋谱 JSON 导出

每局棋谱可以导出成 JSON 文件。想自己写程序分析、把对局喂给自己的研究项目、或者单纯留档，数据都在你手里——对局记录本来就只落本机，导出只是把门再打开一点。

### 协议画像与开局记忆

协议画像统计每个模型的出招协议习惯：JSON 格式遵守率、平均出招耗时等。这些数字单看没感觉，对比着看才有意思：遵守率低的模型出招常靠兜底救回，耗时长的模型每一步都在深思，画像看多了，选谁上场心里有谱。开局记忆则让模型避免在同型局面里重复犯错——同样的亏，吃过一次就记下了，下次再遇到相似局面，出招会带着上一次的教训。

### TrueSkill 天梯

胜负最终沉淀进 TrueSkill 天梯，微软算法自实现，段位分层排位，谁强谁弱一张榜看清。段位分层之后，谁和谁有得一打，榜上就有答案。人类挑战者的分数单独一个榜，不和模型混排。

## 怎么用，四步

1. 大厅选玩法，选机机观战，批量勾选模型开打。
2. 对局中开实时解说，盯着形势曲线与思维链气泡看走向。
3. 终局揭晓匿名身份，胜负进 TrueSkill 天梯。
4. 进回放看问叹号标注与赛后解说，需要就把棋谱导出 JSON。

整套流程走下来，一局的完整生命周期都在系统里：对局中看得见，对局后翻得出，想带走还导得出去。

## 已知边界

解说与标注是模型生成的观点，不是判罚——胜负永远由代码裁判决定，解说说错了不改变结果，把解说当参考而不是判决书。标注与解说的质量取决于你配的模型，弱模型的解说容易流于表面，这是模型能力问题不是系统问题。0.1.0 是早期版本，复盘功能的细节会随迭代调整，欢迎去仓库提 issue。复盘数据只落本机，导不导出、给谁看，都是你自己的决定，这一点在研究场景里尤其重要。另外提醒费用口径：软件 MIT 免费，云端模型 API 的费用由使用者向厂商支付，挂机观战同样消耗额度，本地 Ollama 模型零成本。

## 你可能会问

### 复盘标注是谁打的

妙手与失误的逐手标注由系统在复盘阶段生成，属于分析性意见；终局胜负则始终由裁判引擎判定，两者互不干扰。标注帮你定位关键手，不替你下结论。

### 形势曲线准不准

它反映的是系统对局面走向的评估，用来把握大势足够，不必当成精确胜率。看曲线的目的是知道谁压着谁、转折发生在哪一手。

### 观战要花什么钱

软件本身免费。观机机对局消耗的是模型 API 调用费用，由你向厂商支付，平台不加价；挂机看锦标赛要有额度预算，配 Ollama 本地模型则零成本。

### 匿名身份什么时候揭晓

终局时由对局引擎统一揭晓，观战过程中不会提前泄露。想提前知道也可以——自己开的人机局没有匿名一说，匿名只为观战设计。

### 棋谱导出能干什么

JSON 格式的棋谱可以直接喂给自己的分析程序、用作研究素材或者长期留档。数据从本机导出，格式公开，怎么用由你决定，对研究者来说这就是原始数据入口。

看比赛不解说是遗憾，打完不复盘是浪费。0.1.0 把这两件事都做成了系统能力，剩下的只是选择：让哪些模型上桌，把哪一局的曲线翻出来细看。
