# 开发者社区比赛：用开源竞技场办一场模型联赛

想给开发者社区办一场人人看得懂、还能真动手的比赛，答题赛太老，黑客松门槛高，拖到最后活动又黄了。开发者社区比赛还有第三种形态：模型联赛。参赛者带一个自己配置的模型上桌，打棋牌循环赛，观众看大屏，全程有思维链、有积分榜、有复盘。承载它的察元竞技场是 MIT 开源的桌面应用，办赛成本主要是模型调用。这篇从流程、参赛体验到结果公示，给一份能照抄的办赛手册。办赛的三个关键词提前说：统一环境、透明规则、留痕公示。

## 赛事流程：五个阶段

报名登记：参赛者提交模型信息——厂商与模型 id，或本地模型规格。主办方核对接入方式：85 家厂商目录点选、OpenAI 兼容端点手填 baseUrl、Ollama 本地模型免 Key，三条路都收。报名截止后冻结模型清单，中途换模型要过审核，防止临场换将。

环境统一：全部比赛用同一台（或同规格）机器、同一版本（0.1.0）跑，章程写明，这是后续一切争议的锚点。设备核验那天把「测试连接」当场跑一遍，问题模型留出调换窗口。

小组赛：机机观战批量选模型分组对打，匿名座位（玩家A、玩家B）顺便给观众留竞猜空间，比赛与传播同步发生。组数按机器数定，一组一天打完，别把赛程拖到观众没耐心。

决赛：锦标赛循环赛自动排程，积分榜实时刷新投大屏，打完当场出冠军。决赛局之间穿插观众互动，用上一轮的 ？!标注做有奖竞答。

公示：积分榜、TrueSkill 天梯分与全部棋谱 JSON 公开，获奖名单带着证据链发布，发布时间当天定死，拖到第二天热度就散了。

## 赛程时间表参考

一场一天的联赛时间表可以这样排：上午签到与设备核验两小时，模型配置逐台过；中午前小组赛开打，积分榜上墙；下午小组赛收尾，前几名进决赛；傍晚决赛与颁奖。规模大的拆两天：一天小组赛，一天决赛与复盘分享，分享环节让参赛者讲自己模型的坑，干货密度最高。

## 参赛者体验：配置五分钟的事

接入环节不用写代码：设置 ＞ 模型配置里点选厂商、填 Key，点「测试连接」验证连通性，点「获取模型」把账号下可用模型列表实拉下来勾选。本地玩家用 Ollama 免 Key 直连。

调优空间有限但真实。能做的三件事：选对玩法——有的模型擅长不完全信息博弈，有的在完全信息棋类里更稳，报名前试几局摸底；开深度规则模式（DEEP_RULES）约束输出结构，观察自己模型的遵守情况；赛前热身时盯协议画像里的 JSON 格式遵守率与平均耗时，遵守率难看的先解决格式问题。还有一条心理准备：调优的上限就是这几件事，联赛比的更多是选型眼光与稳定性，不是玄学秘技。报名前发一份接入指引截图，五分钟的配置别让任何人卡住。

观赛体验是参赛体验的一半：全程能看到自己模型的思维链气泡与每手延迟、token 用量，输了也输得明白，这是模型联赛对技术社区特有的诚意。

## 章程必写的几条

容错口径：模型解析失败会走启发式代走（能挡杀就挡、能吃就吃），代走超限判负；429 限流自动退避。这些机制等于赛规，赛前公示，赛中执行，赛后不翻案。

争议复核：以代码裁判结果与棋谱 JSON 为准。软件里胜负判定百分之百归引擎，模型没有判罚权，这条写在章程最前面能省掉大多数口舌。

费用分摊：主办方跑赛的调用费用与参赛者自测费用怎么分摊，报名前讲清。软件本身免费，模型 API 各自向厂商支付。章程里再补一条退赛与替补规则，比赛当天总有意外，规则兜底比现场协商体面。

## 结果公示

榜单证据一起发：锦标赛积分榜与天梯分截图、全部对局的棋谱 JSON 打包，社区里任何人都能下载复盘。公示文案里固定放一段「怎么自己验证」，教社区成员用回放器复核，透明做全套。

战报以复盘形式写：用逐手的 ？!标注与形势曲线讲关键局，比单纯报名次有内容得多，也顺手完成下一届的预热。

## 奖项设置

奖项建议与名次脱敏：冠军奖一份足矣，重头放在特色奖——「稳定输出奖」给代走最少的一方，「快枪手奖」给平均耗时最低的，「好风度奖」给败局复盘最认真的参赛者。特色奖从协议画像与棋谱里找依据，人人有盼头，笑声比名次多。奖品预算与费用分摊一起写进章程，别临时起意。

## 边界

模型波动是联赛的固有属性：同一模型发挥有随机性，一场定名次的赛制要在章程声明「当天状态」口径，或多局取均值。现场网络要压测，429 频发的端点提前替换。名次有随机成分，奖品以参与奖与过程奖为主更稳妥，高额名次奖慎设。联赛若连办几届，把每届的章程与环境记录归档，下一届直接继承改进，别从零开始。

## 常见疑问

### 参赛要会写代码吗
不用。配置界面上点选厂商、填 Key、测试连接即可；进阶调优也只是开关与选择，编码只在想做深度定制时才需要。

### 本地模型能参赛吗
能。Ollama 免 Key 接入，环境统一环节会校验本地模型规格；棋力有限，但同场条件下是公平的。

### 主办方要花什么钱
软件 MIT 开源免费，支出在跑赛的模型调用费用（向厂商支付）与场地设备上，规模可控。

### 争议局怎么处理
用回放器按协议字段筛关键手公开复核，以棋谱与代码裁判结果为准，流程写进章程。

### 观众怎么参与
竞猜加解说：小组赛全程匿名开竞猜，决赛开 AI 实时解说，观众看得懂也押得动；赛后把棋谱开放下载，复盘帖让他们自己写。

### 联赛能办成系列吗
能。单届跑顺后按玩法轮换办系列赛，每届环境与章程沿用微调，TrueSkill 分数跨届延续，社区会自己长出传统来。

办活动的怕冷场，参赛的怕黑箱，模型联赛恰好两头都治：大屏上有实时积分榜，章程里有可复核的棋谱，输了的人能看着思维链气泡指出自己模型错在哪一手。技术社区最认的就是这种透明。工具开源、流程五步、成本主要在调用费，剩下的变量只有一件事——你们社区的成员，愿不愿意把自己的模型押上桌。而好胜心，技术社区从来不缺，头一届办完，下一届的报名帖自己会长出来。
