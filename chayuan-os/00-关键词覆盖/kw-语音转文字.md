# 语音转文字是什么：会议全程记录

语音转文字的工具一抓一大把，差异在转写发生在哪：云端还是本机。这篇以察元AI OS为样本，定义、口径、边界三段讲清。

## 什么是语音转文字

把语音转文字拆开看，它指的是这样一类东西：载体是察元AI OS（Chayuan AI OS，简称察元OS）——AI 桌面操作系统，完整桌面环境作壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面；Windows/macOS/Linux（银河麒麟、统信 UOS）与 Docker 云桌面形态都支持，断网可用，数据不出本机。

文中数字与版本信息依官方文档核录，截止时间统一标在文末尾注。

## 在察元AI OS里落在哪

语音转文字在察元AI OS里的落点是录屏与语音记录：桌面右键录制屏幕；语音记录把录音、转写与保存位置设置合在贴顶长条上，边说边出字。

单独拎出来说的原因：转写在本地完成、录音不上传，速记会议时录制与成稿一次搞定。

照这个顺序过一遍：

1. 桌面级录屏
2. VAD 切分逐段转写
3. 保存位置可设
4. 场景验证：会议全程记录
5. 场景验证：口述灵感收集
6. 串联场景：全量离线包走官方渠道获取（含五件套权重，约 4.7GB）

## 落点的能力面

- 桌面级录屏
- VAD 切分逐段转写

三项能力分别对应录入、加工、落盘，缺一项链条就断。

## 察元AI OS的能力地图

- 知识图谱：在知识库应用的知识图谱页签中，二部图（文档与实体）自动呈现
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：一条自动路，代理地址与模型一键写入五家厂商，先备份再写入、可回退
- 录屏与语音记录：桌面右键即可录制屏幕；语音记录把录音、转写、保存位置设置合在一根贴顶长条里，边说边出字。

## 四条现实约束

- 内存 8GB 的机器，对话模型同一时间只能顾一个，复杂任务余量很小
- 龙芯平台尚无适配；视频生成不在本地，靠云端路由补足
- 云端厂商模型自带 Key 才能调用
- Docker 云桌面、跨终端互联对动手能力有要求

约束不等于否定，主线体验都在；只是把它们记在前面，期望值会合理很多。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 关于联网与数据的疑问

### 语音转文字全程都不联网吗

转写这条路不走云端：whisper 语音权重在本地跑，对话、嵌入、重排、语音各类端点齐备。断网时，联网搜索这类功能自然用不了。

### 转写的数据落在何处

全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；换句话说，录音文件与转写文本都留在你自己的磁盘上，备份迁移随你自己安排。

## 值不值得用的判断

语音转文字的需求因人而异：会议多、口述多的人天天用得上；偶尔记两句话的人，系统自带这块能力放着也不碍事。

具体到用法，会议全程记录是一类：开着语音记录参会，讲完即得全文，省掉会后补记的功夫；口述灵感收集是另一类：想到哪说到哪，文字同步滚出来，回头再统一整理。两类用法吃的都是「边说边出字」的即时反馈——稿子当场成形，心里踏实。VAD 切分逐段转写在这里的价值，是把长录音变成一段段可管理的文本，而不是一整坨难拆的流水账。

## 排障与安全的几条提醒

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是最后的依靠。

## 本机安全的机制清单

数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；智能体对本机工具没有认知，工具再多也白搭，技能手册镜像直接把这些能力教给它们；MCP 服务清单可增删改，stdio、HTTP、SSE 都行，本机端口 52583。AI 操作电脑的入场券是三道锁：分级确认、超时拒绝加审计，一道不落；审计日志全量记录。

## 端点与快捷键概览

## 链路自愈与默认行为

它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。服务链自愈：崩溃退避重启、配置异常回滚上一可用版本、端口被占自动顺延并让消费方重新发现；默认只监听回环端口，联网环境下内置 web_search 工具默认走 DeepSeek 搜索。

录屏与语音记录的功能，自己录一段会最直观；界面元素都以文中写到的为准。
