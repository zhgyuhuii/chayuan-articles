# 技能资产离线管理：速查手册

导出导入技能与插件的闭环。这套组合工作流把技能页签与技能商店→.cop.tgz 离线插件包串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

导出导入技能与插件的闭环。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·技能页签与技能商店**：技能管理页签：启停（改写 SKILL.md 元数据）、打开目录、删除（入废纸篓）、tar.gz 离线导出导入；技能商店可搜索 GitHub 技能仓库一键安装（内置 anthropics/skills 等精选）。

1. 应用管理→技能页签浏览已装技能
2. 技能商店搜索并一键安装
3. tar.gz 导出导入实现离线迁移

**第 2 步·.cop.tgz 离线插件包**：插件依赖闭包打包导出为 .cop.tgz，离线直拷导入（校验路径穿越、零网络），支持多选批量安装。

1. 在插件页签导出 .cop.tgz
2. 拷贝到目标机器
3. 导入并批量安装

## 衔接点与易错处

- 空关键词浏览内置精选库
- 导出即依赖闭包，不怕漏依赖

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 常见问题
### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。
