# 一文打通标书冲刺夜工作流｜标书校对

扩写控篇幅、统一术语、降 AI 味、批量错别字兜底。这套组合工作流把重写/扩写/缩写→术语统一→AI 痕迹检查→多文档错别字校对（MCP）串成一条线，在察元AI文档助手里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

扩写控篇幅、统一术语、降 AI 味、批量错别字兜底。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI文档助手的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·重写/扩写/缩写**：文本三件套：换种方式重写、扩写（补论据细节）、缩写（控篇幅），保持原意调整表达密度。

1. 选中段落，选择重写/扩写/缩写
2. 在参数卡确认力度（可选）
3. 查看结果写回或复制

**第 2 步·术语统一**：全篇扫描同一概念的不同表述并统一口径（如「甲方/建设单位/业主单位」），产出替换建议清单。

1. 发起术语统一
2. 确认目标术语与待替换变体
3. 批量替换并复核

**第 3 步·AI 痕迹检查**：从套话密度、结构模式、元话语等维度对文本做保守的疑似度评估，可定位原文片段辅助人工复核；明示不构成定论，用于起草后自检「AI 味」。

1. 选中正文或全文，发起「AI 痕迹检查」
2. 查看各维度疑似度评分与定位片段
3. 按提示改写高疑似段落（换具体事例、删套话）

**第 4 步·多文档错别字校对（MCP）**：通过本机 MCP 服务的 proofread_run 工具对多个文档执行错别字校对：先 dryRun 预览问题清单，确认后用 proofread_apply_comments 把批注钉到具体错字（含表格单元格），支持异步任务轮询。外部智能体（Claude Code、Codex、Cursor）可直接调用。

1. 在 Claude Code / Cursor / Codex 中连接本机 MCP 服务 http://127.0.0.1:62588/mcp
2. 调用 proofread_run 发起 dryRun，拿到全量问题清单
3. 人工复核清单后调用 proofread_apply_comments 批量落批注

## 衔接点与易错处

- 缩写后用术语统一再过一遍，防止口径漂移
- 与「前后矛盾检查」配合使用效果更佳
- 疑似度高不代表一定违规，核心是替换空洞套话为具体信息
- dryRun 预览→确认→写回是固定铁律，未确认绝不落盘
- 异步任务用 proofread_job_poll 轮询，长文档不阻塞

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 常见问题
### 免费额度用完会怎样？

对话超过每日 30 次会提示；MCP 调用返回 LICENSE_REQUIRED 错误码，次日恢复或升级付费。

### 能自定义助手吗？

可以按需组合提示词创建个人助手；内置助手覆盖 228 个领域可直接使用。

### 企业能内部署吗？

可以。官网提供四档形态：加载项（个人）、桌面版（单机断网）、服务版（Docker 全科室共用）、至臻版（数百到上万人网络版）。
