# 版本选择与升级建议（察元文档助手演进笔记）

版本选择与升级建议。版本号背后是产品重心的迁移，这篇笔记沿着时间线梳理这条演进线索，帮你判断「现在上车」处在什么阶段。

## 时间线

- **v1.0.1（2026-04）**：初版发布：察元 AI 助理 + 察元 AI 编审两个 Ribbon 页签；批量表格/图像/文档处理、文档脱密、编审表单
- **v2.0.0（2026 年中）**：政企文档生产场景重大重构；助手对话框、模型分类体系、任务系统；从功能堆叠走向可治理平台
- **v3.0（2026-05）**：远程知识库 RAG：JWT/HMAC 双模认证；引用展示与原文下载；3.0.1-3.0.13 快速迭代
- **v4.0.0（2026-08-10）**：本机 MCP 文档智能体正式版（26 工具）；三平台安装包 + sidecar 开机自启；离线/内网部署形态成熟
- **v4.1.0（2026-08-13）**：表格结构写回（12 action：插行/列、合并单元格）；工具目录 26→46；wps-skill-chayuan 技能双向自启
- **v4.1.1（2026-08-14）**：一行命令安装稳定性：PS 5.1 乱码修复；sha256 多源强校验；sidecar 重启 8 秒自愈
- **v4.1.2（2026-08-17）**：sidecar 隐藏启动：修复黑窗常驻与关窗断连；Linux 真机（Ubuntu arm64 + WPS 12.1）验证
- **v5.x（2026-09）**：应用内文档智能体自循环：AgentLoop + todo 任务清单；三档写权限、写前快照撤销、文档写锁；AI 助手窗五形态停靠；本地引擎一键安装引导
- **v5.1.4（2026-09-20）**：当前发布版本：三平台产物齐全；sidecar 最小 token 鉴权 + 审计；对话窗官网升级提醒（断网静默）

## 演进主线

从时间线可以看出，察元文档助手的重心在「能力广度→工程深度→规模化形态」之间稳步推进：早期铺功能，中期补安全与体验，近期重心在部署形态与生态联动。这也意味着现在的版本进入相对成熟区间，适合作为主力工具评估。

## 升级与版本策略建议

- 生产环境跟随稳定版，滞后一两个小版本
- 每次升级阅读更新说明中的行为变化
- 重要节点（大版本）升级前做全量备份

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 常见问题
### 安装包多大？在哪里下载？

约 35MB（各平台相近），官网 aidooo.com、GitHub（zhgyuhuii/chayuan-wps-releases）、Gitee 国内镜像与百度网盘均可下载，每个包带 sha256 校验文件。

### 升级会丢配置吗？

不会。重跑安装器或一行命令 -Fetch 覆盖升级，模型配置、知识库凭据与规则文件保留在独立数据目录。

### 能自定义助手吗？

可以按需组合提示词创建个人助手；内置助手覆盖 228 个领域可直接使用。
