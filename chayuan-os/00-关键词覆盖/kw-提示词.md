# 提示词是什么：一文讲透

查提示词这个词的人，多半想弄明白它到底指什么、在这套系统里怎么用。这篇把定义、口径、边界分开摆，不替你下结论。

## 什么是提示词

提示词，就是发给模型的那段指令文本，模型照它决定干什么、怎么干。在这套系统里，它有不止一副面孔：对话窗口里的输入、文生图应用里正负两栏的描述，都是它。

本文数字都有版本口径，截止时间在文末尾注里。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；

## 上手前先把短板认清

- 内存 8GB 的机器，同时跑一个对话模型是上限，复杂任务施展不开
- 龙芯版本还没有；视频生成本地不做，统一由云端路由
- 云端厂商的模型得配上自己的 API Key 才能调
- Docker 云桌面与跨终端互联属于进阶玩法，得折腾一阵

边界摆在这里不影响主干功能，心里有底再决定装不装。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 关于提示词的几个疑问

### 写提示词生成图片要不要联网

不用。本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；Dock 文生图应用里，提示词加负面提示词生成图片后，可设为壁纸或开 30 分钟自动换壁纸。

### 提示词数据存在哪

隐私敏感环境先关遥测再干活，处置设备前记得清数据；升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离，数据在服务器侧统一管理。

## 提示词怎么写才不踩空

写提示词的通则，是先把任务交代完整：目标是什么、有什么背景、要什么形式的输出。模型不会读心，指令含糊，回答就只能泛泛。生图场景里另有一栏负面提示词，专门用来排除不想要的元素，与正向描述配合着用效果更好。

一次写不到位很正常。把每次生成结果当成反馈，回头改指令：哪句话导致跑偏，就补一句约束进去；改的时候一次只动一处，变量多了就分不清是哪处起了作用。背景信息给多少也讲分寸，太少模型瞎猜，太多重点被淹，先给一两句关键上下文通常就够了。本机链路出图不联网，反复调试没有额外开销的顾虑，多改几轮就是了。还有个取巧办法：把稳定好用的指令存成自己的模板库，下次换个主题词直接复用，重复劳动能省则省。

## 一句收束

提示词这回事，值不值得花功夫，拿上面的口径与边界套一下自己的日常任务，套得上就值得。指令长度同样服从任务，一句话能说清的事别铺陈，需要角色设定与分步约束时再展开。

## 系统层的几个前提

这套系统不是只管提示词一个点：共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸，本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道。密码三条路都不满足时只能清数据重装，恢复密钥务必提前生成。管理员可以建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录。全新安装时选数据目录或导入拷贝根，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 形态与模型口径

web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作；内置浏览器窗，配合 webwindows 可被智能体驱动；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态），员工浏览器打开即用；应用页签支持 dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌。模型这头：local 星号开头的本地模型未运行自动加载，本地模型按需自动加载，会话中随时切换模型（本地与已启用厂商热更新），无显式模型偏好时自动指向本地模型。设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）；生图模型不配好，画图应用与智能体的生图指令都落空。各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。

## 配套与协作

官方免费素材库，不用去网上乱找 png；对配对终端开模型加知识库授权，资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问；Dock 直开内置的察元AI Office，文档、表格、演示在线编辑；内置 jspaint 画板（仅桌面形态）可涂鸦、批注、简单标注。
