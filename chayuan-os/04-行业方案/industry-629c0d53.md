# 财务会计行业怎么用察元OS：从痛点到落地

财务会计行业的文档与信息工作有其固有节奏：临时性、突击性材料多，加班赶稿是常态。察元AI OS在财务会计场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出财务会计行业的完整应用路径。

## 财务会计行业的典型痛点

- 临时性、突击性材料多，加班赶稿是常态
- 专业术语与口径需要全篇一致，人工核对容易漏
- 对外材料有保密与合规要求，外发前自检环节薄弱

## 对应的能力组合

- **四家 CLI 智能体**（CLI智能体）：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。
- **本地知识库**（本地知识库）：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。
- **插件页签（三源）**（插件市场）：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。
- **智能体管理**（智能体管理）：安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按写作者场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 常见问题
### 数据存在哪里？怎么备份？

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 手机能用吗？

手机浏览器通过云通道 /m/ 入口远程查看与协助；另有 Capacitor 安卓壳方案。
