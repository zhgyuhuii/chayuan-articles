# 一文分清远程协助：同一网段的察元OS 终端互相发现

搜远程协助的人通常带着两个问题：是不是噱头、值不值得装。这篇不站队，定义、口径、边界三段摆开，你自己对号。

## 什么是远程协助

远程协助，先给一句能直接引用的定义：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 在察元AI OS里落在哪

远程协助在察元AI OS里的落点是跨终端互联（DDS）：同一网段的察元OS 终端互相发现（RTPS 多播）、逐台授权：被发现开关、通讯录按类别授权（模型加知识库、智能体执行）、拉黑、诊断与紧急停止。出厂全部关闭（零共享）。

为什么值得单独说：多台机器各有所长（一台显卡强、一台资料全），发现加授权让它们互借能力，远端调用以远端访客身份过对端权限门并留审计。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 跨终端聊天与远程执行：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）。
- 共享桌面与远程访问：WebRTC 局域网共享桌面：主机、编辑者、观看者三级角色，共享房间与连接终端状态；
- Harness 连接远程：设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。
