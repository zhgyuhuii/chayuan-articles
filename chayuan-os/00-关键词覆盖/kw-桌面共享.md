# 什么是桌面共享？一文讲清概念、用法与选型

桌面共享是什么、怎么用，一篇讲清楚。AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。下面进入正题：先概念，再步骤，最后是边界与常见问题，基于察元AI OS整理。

## 什么是桌面共享

顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

放到察元AI OS的语境里：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面环境总览是其中承上启下的一环。

## 为什么值得了解

它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

典型使用场景：给政企用户完整的桌面迁移体验；低配机关动效保流畅。

## 在察元AI OS里怎么用

入口与核心步骤：

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 怎么判断适不适合你

适合你的情况：日常就是给政企用户完整的桌面迁移体验，希望流程固定、结果可验证。

不必勉强的情况：需求不在这条线上的人。察元AI OS的思路是把边界写明白，条件式地推荐。

## 你可能会问

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

## 安装与运行答疑

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

## 一个真实场景

需要多方意见的决策者的典型用法：给几只灵宠配不同厂商的模型，建宠物群聊勾选成员，选并行或串行，抛一个命题让它们讨论，开视角讨论强制多角度。同一命题的多模型观点同屏呈现，分歧与共识一目了然。注意：本地模型并发上限 4 路，全员本地模型时发言会排队。

## 顺带了解

共享桌面与远程访问：WebRTC 局域网共享桌面：主机、编辑者、观看者三级角色，共享房间与连接终端状态；公网远程走出站云中继（支持自建），还能生成限时云链接分享对话页（停止即失效）；手机浏览器可镜像桌面，另有安卓壳。

为什么值得看：远程指导、会议室投屏、手机救急，一套机制全覆盖。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 应用商店与离线分发

商店对接能力广场（aidooo.com），插件、技能、MCP 插件、智能体、技能包五类内容在线下载并云端推送更新，配排行榜辅助选型。内网环境走 .cop.tgz 离线包导入：导出即依赖闭包，导入逐文件校验，断网也能完成分发。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。
