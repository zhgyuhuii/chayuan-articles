# Dock位置场景实战：从需求到交付

内网机器要外接屏把 Dock 放右侧，过去要折腾好几个工具拼起来。现在察元AI OS把这件事做成了一个功能：Dock 设置。下面按我实际操作的顺序走一遍，包括容易踩的坑。

## 为什么值得了解

觉得 Dock 图标太小/太大，或不喜欢悬停放大效果，小屏开自动隐藏，外接屏把 Dock 放右侧，想开机进桌面就自动打开 DeepSeek Harness 会话窗，省一次点击。

用户常搜的问法：Dock 可以放到屏幕左边/右边吗？怎么自动隐藏；任务栏图标能调大一点吗？那个悬停放大怎么关。

## 实操全过程

第 1 步 · 进入设置分区

1. 点 Dock 上的「设置」图标打开设置窗口。
2. 左栏分区列表点「桌面与 Dock」，右侧两张卡：「Dock 位置」与「Dock 行为」。

第 2 步 · 「Dock 位置」

1. 卡内三个按钮「底部」「左侧」「右侧」，当前生效位蓝底高亮，点任一按钮 Dock 立即挪到对应屏幕边。
2. 等价快捷入口：在 Dock 空白处右键 ＞ 「停靠位置」＞ 「左侧停放」「右侧停放」「底部停放」（当前项带 ）。

第 3 步 · 「Dock 行为」

1. 「自动隐藏（鼠标贴边呼出）」勾选框：勾上后 Dock 平时收起、鼠标贴到所在屏幕边缘时浮出。设置页这个勾选是「隐藏/常驻」两态；更细的三态在 Dock 空白处右键 ＞ 「显示与隐藏」：
    1. 「始终显示」（默认）：Dock 常驻占位；
    2. 「窄视口自动隐藏」：窗口窄时才自动隐藏；
    3. 「始终隐藏」：一直隐藏，贴边呼出。
    4. 「图标放大效果（悬停放大）」勾选框（默认开）：鼠标扫过 Dock 时图标放大的鱼眼效果，关掉则无放大。它与「图标大小」是两回事——前者管悬停时的动态放大，后者管 Dock 的基础图标尺寸。
    5. 「图标大小」下拉框：「小」「中（默认）」「大」三挡基础图标尺寸，切换立即生效。
    6. 「开机自动打开 Harness」勾选框（默认关）：勾上后，登录进桌面时自动打开 DeepSeek Harness 会话窗口（桌面主对话窗）；不勾则开机不弹，需要时自己点 Dock 里的 Harness 图标。桌面主程序形态会等对话服务就绪后再开窗（避免开出空壳窗口）。

第 4 步 · Dock 图标管理（顺带总览）

1. 图标右键：「打开」「新建窗口」、智能体的「工作区」直达子菜单、「显示所有窗口」「隐藏」、「选项」（「在任务栏保留」「从任务栏移除」「登录时打开」）、「固定在 Dock/「取消固定」「在文件管理中显示」（自定义应用）、「从任务栏隐藏」「退出」——系统应用不能移除，会提示「系统应用不能从任务栏移除」。
2. 空白处右键：「停靠位置」「显示与隐藏」三态、「恢复已隐藏的图标」（把此前隐藏/移除的图标找回来，后缀数字为可恢复数量）、「应用管理」。
3. Dock 最右端是废纸篓：左键打开废纸篓应用，右键「打开废纸篓」「清倒废纸篓」，拖文件上去即删除进回收站。
4. 让智能体代改：系统技能提供 system_set_dock（位置 left/right/bottom 与自动隐藏）。

## 别在这几处栽跟头

功能归功能，这几个边界先摆清楚：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 误隐藏了 Dock 图标怎么找回？

Dock 空白处右键 ＞ 「恢复已隐藏的图标」；或在「应用管理」＞ 应用 页里重新显示/发送快捷方式到桌面。

### 共享桌面会话里改 Dock 设置，对方会跟着变吗？

不会。共享会话进行中，Dock 位置/显示隐藏的改动不会即时生效、也不进入共享画面，只记录到本机偏好，等共享结束后（重新进入设置或重启桌面）再体现。

### 「窄视口自动隐藏」和「始终隐藏」有什么区别？

前者只在窗口/视口较窄时收起（宽屏正常常驻），后者无条件一直隐藏。都在 Dock 空白处右键 ＞「显示与隐藏」里选。

## 补充答疑

### 勾了「开机自动打开 Harness」但开机没弹？

该开关只在「这台用户会话登录进桌面」时生效；若开机时已有 Harness 窗口（如会话恢复）则不重复弹。确认勾选已保存（设置页勾选框为勾态）再重启验证。

### 开了自动隐藏后 Dock 呼不出来？

贴边的判定位置跟着 Dock 位置走：Dock 在底部就贴屏幕底边、在右侧就贴右缘。如果开了「始终隐藏」后忘了位置，到 设置 ＞ 桌面与 Dock 取消「自动隐藏（鼠标贴边呼出）」即可强制常驻。

## 安装与运行答疑

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。

### 模型加载失败或提示内存不足？

系统有内存预算硬底线（总内存的 45%）保护：先卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

## 一个真实场景

国产化环境用户的典型用法：按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64，deb 包安装到银河麒麟 V10 或统信 UOS 20，本地五件套模型离线即用。信创环境一套完整的 AI 桌面与办公方案。注意：暂不支持龙芯平台。
