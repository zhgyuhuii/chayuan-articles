# 开机登录：数据目录自选

开机登录这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决把数据放 D 盘防重装丢失。

## 开机登录门与数据目录是个什么东西

为什么要有开机登录：数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。开机登录门与数据目录的定位是全新安装选数据目录或导入拷贝根，创建管理员；日常是用户卡片墙加密码，可选生成恢复密钥。

下面直接进正题。

## 准备清单

- 桌面形态（察元AI OS）。本篇的向导与登录门只出现在桌面应用；web/docker 形态没有开机门。
- 向导只在「没有任何用户」时出现（全新安装，或重装后选了「全新开始」）。已初始化的系统日常开机直接走登录门。
- 默认数据根：macOS/Linux ~/Documents/chatop-data/，Windows %USERPROFILE%\Documents\chatop-data\；每个账户的数据在其下 users/<账户>/ 目录里。
- 密码最短 3 位；恢复密钥在创建管理员时自动生成一次。

## 实操全过程

第 1 屏「欢迎使用察元」（创建管理员）

1. 页面引导语原文：「选择数据目录并创建管理员。此后把整个数据文件夹拷到另一台电脑，首次启动选择它即可同步用户、应用、插件与智能体等全部内容。」表单下方显示当前数据目录路径（默认为上面的 chatop-data）。
2. 逐项填写：
    1. 「管理员名称」：登录用的名字；
    2. 「昵称（必填：同网络其他终端将看到）」（≤24 字）：留空点创建会提示「请填写昵称（跨终端互联时其他终端将以此称呼你）」；
    3. 「管理员密码（至少 3 位）」＋「再输一次」：两次不一致提示「两次输入不一致」，太短提示「密码太短（至少 3 位）」。
    4. （可选）换数据目录：点表单下方小按钮「数据目录 · 更改…」进入第 2 屏；不换则直接点「创建并开始」。

第 2 屏「数据目录」（可跳过）

1. 标题「数据目录」＋「更改…」按钮：弹出系统目录选择框（可新建文件夹），选定后本屏与上一屏的目录提示同步更新。所选目录只是暂存，点「创建并开始」建管理员时才真正落到该目录；中途退出向导自然作废。
2. 选到同步盘目录会出现黄色警告，例如：「该目录位于 iCloud Drive 内：聊天记录与密钥会被同步软件带走，多台设备同时使用可能损坏数据。建议另选本地目录。」（Dropbox / OneDrive / Google Drive / 坚果云各有同款警告）。
3. 两个失败分支（点「创建并开始」时判定）：所选文件夹已经是完整数据根 ＞ 「该文件夹已经是数据目录（含用户数据）：要迁移它请返回用『从另一台电脑导入』，或另选一个空文件夹」；无法创建 ＞ 「无法在该文件夹创建数据目录（权限不足或路径无效），请另选位置」。
4. 本屏下方即「从另一台电脑导入」入口（见分支三）；「返回」回到管理员表单。

第 3 屏「抄写你的恢复密钥」

1. 创建管理员成功后自动进入。引导语原文：「忘记密码时，这串字符是最终保险。请抄写在纸上或存入密码管理器——它不会再次完整显示。」绿色等宽块显示 XXXX-XXXX-XXXX-XXXX 形式的密钥；「复制密钥」（点了短暂变「已复制」）。
2. 勾选「我已把恢复密钥抄写到安全的地方」后，「完成并进入」按钮亮起；下方链接「暂不抄写，直接进入（可稍后在 设置 ＞ 账号与找回 重新生成）」当前与「完成并进入」共用同一启用条件——不勾选时两个入口都不生效（以当前代码为准，疑似缺陷；密钥本身不因跳过而删除，事后可在 设置 ＞ 账号与找回 重新生成一把新的）。
3. 点「完成并进入」收尾：没换过数据目录 ＞ 直接进入桌面；换过 ＞ 按钮变为「正在切换到新数据目录，应用即将重启…」，应用自动重启并进入新目录（管理员已建在新根）。密钥生成失败（极少见）时跳过本屏直接进入。

## 怎么确认做成了

验证

1. 默认根：打开「文档」下的 chatop-data/，应能看到 registry.json、users/、shared/ 等条目；建过几个用户，users/ 下就有几个账户目录。
2. 换目录生效：向导里选过新目录并完成后，默认位置的 chatop-data/ 下会出现 .redirect 文件（内容指向新目录），实际数据在新目录里。
3. 导入：导入完成后重启，登录门卡片数量应与旧机用户数一致，用旧密码能登录。
4. 开机落点：开关保持默认（开）时重启，动画结束后应直接落上一位用户的锁屏，输密码即进。

## 什么情况下用得上

把数据放 D 盘防重装丢失；新装机第一次打开察元，被「欢迎使用察元」向导拦住，不知道每个框填什么、数据目录要不要改，想了解日常开机为什么要选用户输密码、能不能少输一次；旧机数据整体搬到新机。

用户常搜的问法：第一次启动要设置什么？数据都存在哪；怎么把旧电脑的察元数据整个搬到新电脑。

## 几个容易忽略的细节

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 数据目录能放进 iCloud/坚果云这类同步盘吗？

能选，但会立刻出现黄色警告：聊天记录与密钥会被同步软件带走，多台设备同时使用可能损坏数据，建议另选本地目录。要跨设备迁移，用「拷贝整个文件夹 ＞ 新机导入」的方式（分支三）更安全。

### 装好之后还能改数据目录吗？

界面层面不能——数据目录只在首装向导里可选，向导不会再出现。已初始化后的迁移办法：把整个 chatop-data 拷到目标位置/机器，在新机首启时走「从另一台电脑导入」（同平台直接原地接管）；或重装后选「全新开始」再导入旧根。

### 重装后弹「检测到重新安装」，选哪个？

想继续用原来的账号和数据选「继续使用现有数据」；想把机器转手/从头再来选「全新开始」——旧数据被整体封存为带时间戳的备份目录（不删除），反悔了还能通过「导入」找回。

### 导入时提示「该文件夹不是有效的察元数据目录（缺 registry.json）」？

选中的不是完整数据根。要拷的是整个 chatop-data 文件夹（里面有 registry.json、users/ 等），不是其中的某个子目录或安装目录。

### 开机每次都要输密码，能省掉吗？

密码本身不能置空（最短 3 位的硬校验）。默认的「开机登录」已经是最省路径：开机直接落上一位用户的锁屏，只输一次密码即进；在 设置 ＞ 用户 关闭该开关则会落在选人卡片墙。忘了密码看 A2。

如果只记一件事：数据目录自选。剩下的细节，照步骤节走就行。
