# Dock 与窗口管理怎么用：察元OS速查手册

Dock栏是察元AI OS里使用频率很高的一项能力。它的「Dock 与窗口管理」这样工作：Dock 支持位置/自动隐藏/放大效果/图标三挡大小、分组（徽章+溢出计数）、Windows 式最小化磁贴；多窗口可拖拽、多屏切换。这篇速查手册从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

Dock 支持位置/自动隐藏/放大效果/图标三挡大小、分组（徽章+溢出计数）、Windows 式最小化磁贴；多窗口可拖拽、多屏切换。

从任务视角看，它对应的关键词是「Dock栏」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 拖应用到 Dock 固定
2. 右键调整 Dock 设置
3. 多窗口自由排布或磁贴收纳

## 适用场景

- 多应用并行的重度使用

## 实用技巧

- 分组徽章让几十个应用不挤爆 Dock

## 注意事项与边界

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 常见问题
### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。

### 手机能用吗？

手机浏览器通过云通道 /m/ 入口远程查看与协助；另有 Capacitor 安卓壳方案。

### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。
