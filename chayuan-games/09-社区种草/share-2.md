# CoT气泡看AI心理活动比追剧还上头

首图建议：对局室思维链气泡展开的截图，配大字「AI心理活动大赏」

你有没有蹲在别人旁边，听人家打牌时嘟嘟囔囔的经历。
现在把这个画面换个主角：AI 落子之前的那几秒，它脑子里过了些什么。
在察元竞技场的对局室里，这件事是可视的——思维链气泡实时流式展开，模型一边推演一边往外蹦字，像把耳朵贴在它脑门上听自言自语。
这套 AI心理活动 观赏体验，讲真比追剧还上头。
关键词是实时流式：字是一点点往外冒的，你能看到它犹豫、改口、再下决心的全过程。
字未落定之前，谁都猜不到它下一步想什么。弹幕时代长大的人，对这种过程大于结果的节目天然没有抵抗力，何况这场节目还是活的。

先补个背景。察元竞技场是察元AI 家族里的开源棋牌竞技场，MIT 协议，2026 年 11 月的版本 0.1.0 带 11 款玩法和 85 家厂商目录，五子棋、象棋、围棋、军棋、斗地主、德扑、掼蛋、麻将全在一层大厅里，随便挑一张桌围观。它跟察元AI OS 内置的竞技场引擎层逐字节同构，桌面版独立安装也一样用。

## 气泡里都演些什么

普通对局里，气泡里滚的是模型的推演文本，行棋思路、顾虑、小算盘都在里面打转。
开了深度思考档更热闹，作业要求变成三段式：先推演三条候选着法线，至少一条吃子线、一条防守线，分析限 120 字，结论收进 30 字，答案用 JSON 交卷。
等于强迫它把内心戏按剧本演给你看，结构清楚多了。开不开这一档，一局的节奏感完全是两种东西，写技术分享想截图配图的人，这里的素材也管够。
对局室还顺手展示每手的延迟和 token 用量，话痨模型一开口，数字蹭蹭涨，娱乐和账单一起飙升。
再补一个冷知识：模型拿到的对局信息里，着法历史排在前、棋盘示意排在后，还附一份合法步清单，它内心戏的开场白基本都是先盘合法选项。

## 上桌前的两分钟

选手从 85 家厂商目录里挑，点选即填，接口清一色 OpenAI 兼容协议。填完 Key 先点「测试连接」，通了再「获取模型」把账号能用的型号拉出来勾上，前前后后两分钟。Key 只落在本机配置里，不上传。
想连 Key 都省掉的，接 Ollama 本地推理就行，气泡照滚，内心戏的成色看模型本身。
有的厂商连推理过程都不回传，遇到这类选手只能看个结果，习惯就好。

## 气泡怎么挑着看

85 家厂商目录里选手管够，围观的乐趣一半在选人。
有的模型回传的思维链又厚又密，看它下棋像看直播；有的干脆利落，气泡三行收工，果断得让人安心。
拿不准就批量选模型上桌，几个选手同台，气泡的贫富差距当场现形。
配合协议画像里的出招格式遵守率、平均耗时两项数据，谁话多谁高效，一张画像看清，选人不再靠撞运气。
追求性价比的话，白天看云端强模型的直播局，晚上接本地模型让它们自娱自乐，一分钱不多花。

## 几个真实感受

1. 心理活动厚度因模型而异。有的模型推演密不透风，有的只吐一个干巴巴的答案就收工，气泡的分量全看模型性子，想看热闹就挑话多的上场。围观的乐趣恰恰在这种参差里。
2. 话痨不耽误正事。有的模型爱把心里话糊在正文里，解析时会先剥掉思维链块再抽答案，落子该是谁还是谁，不会被废话带偏。
3. 真正上头的瞬间是改口。前一句还在吹自己的妙手，后一句突然发现自己漏了防，当场认错换方案——这种真场面包着代码味，编剧都写不出来。

## 也要说实话

- 内心戏不全是干货。模型也会绕圈子、凑字数，把三句话的事讲成一段散文，快进看重点就行。
- token 是真金白银。气泡每多滚一行都是调用费用，云端模型按厂商计费，看得越入迷账单越诚实。
- 不是每家都给你看。思维链回不回传、回传多少，取决于模型本身，遇到闷葫芦型选手，气泡安静得像自习室。
- 开局记忆能兜一部分底，避免同型局面重复犯错，但小模型的内心戏质量整体偏低，别抱太高期待。

适合谁：想研究模型行为、琢磨提示词写法的技术爱好者，以及纯粹爱看热闹的围观党。
不适合谁：只关心比分、不需要过程的效率型观众，气泡对你们就是噪音。

## 评论区高频问题

### 气泡里写的是它的真心话吗？

算是模型生成的推理文本。它对自己想法的转述本身也是生成物，当角色独白看就好，别当心理学报告逐句考证。

### 所有模型都有这么长的内心戏吗？

不一定，厚度看模型。有的话密如瀑布，有的惜字如金，甚至只交一个答案；想看得过瘾，选模型的时候把嘴皮子当一条标准。

### 开了深度思考档会慢很多吗？

会，每手多一段结构化分析，等待明显变长。但气泡一直在滚动，围观体验反而更充实，属于慢得有回报的那类。

### token 用量在哪看？

对局室里每手都标着延迟和用量，挂在对局信息那一排，全程可视化；想省着点花，就少开深度思考档、少请话痨选手。

### 看过的局还能再翻吗？

能，记录页存着历史对局，回放器随时重放，还能按协议字段筛出关键手，错过的内心戏都补得回来。
