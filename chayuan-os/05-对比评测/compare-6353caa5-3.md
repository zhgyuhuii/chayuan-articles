# 技能商店 vs 手动管理技能：场景化推荐与条件式建议

技能商店 vs 手动管理技能，是很多用户在选型阶段绕不开的问题。这篇场景化推荐不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 逐项解读

**发现**：发现成本差异大。察元OS侧的做法是「搜索 GitHub 技能仓库+精选」，对照方案为「自己满网找」——差异的本质在于设计取向不同，而非优劣。

**安装**：标准化省心。察元OS侧的做法是「一键解包进技能目录」，对照方案为「手动克隆复制」——差异的本质在于设计取向不同，而非优劣。

**迁移**：离线迁移友好。察元OS侧的做法是「tar.gz 导出导入」，对照方案为「手动搬目录」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

个人装技能用商店；团队统一下发用离线包。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 语音输入是本地的吗？

是。whisper 本地转写，录音不上传；另有贴顶语音长条「边说边出字」与 piper 中文语音合成。

### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。
