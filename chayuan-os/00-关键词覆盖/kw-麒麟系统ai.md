# 麒麟系统AI是什么：给政企用户完整的桌面迁移体验

关于麒麟系统AI，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是麒麟系统AI

麒麟系统AI这个说法对应的产品是察元AI OS（Chayuan AI OS）：把本地大模型、知识库、智能体、宠物群聊收进同一个桌面的 AI 桌面操作系统。

口径来源为官方文档，版本对应关系文末说明。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| mcpTools | 86 个 MCP 工具（2026 年 10 月实测） |
| kbPort | 52582（知识库对外服务，固定端口） |
| storeCats | 插件、技能、MCP 插件、智能体、技能包五大类 |

## 最短上手路径

先花五分钟把桌面摸熟：

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键菜单里就能更换墙纸与小组件

## 落点的能力面

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

这四条看似都是「面子工程」，其实前三条决定的是迁移阻力：桌面范式、壁纸、动效保住了，用户的心理门槛就低；窗口停靠则是每天高频的小效率，别小看它。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签会把文档与实体的二部图画出来
- WPS 引用知识库：察元AI文档助手（WPS 加载项）会自动发现本机 52582 端口上的知识库对外服务
- 知识库链路健康检查：三层检查里，用浏览器或 curl 请求 127.0.0.1:52582 的健康地址是最直接的一层
- 锁屏密码与自动锁屏：设置通用里设改清锁屏密码（留空保存即清除）、自动锁屏时限（需先设密码）、全局……
- 忘记密码三路找回：恢复密钥直接重置；找管理员重置；AI 面试官出题验证身份的智能体面试找回。
- 验证画像与 AI 面试：开启后从记忆、便签、日程等抽取事实卡（不足 3 张判不可用），

## 开装之前先把丑话说完

- 8GB 内存的机器，对话模型别贪多，一次一个，复杂任务本就受限
- 龙芯平台没有版本；视频生成本地不做，经由云端路由完成
- 云端厂商模型凭你自备的 API Key 调用
- Docker 云桌面、跨终端互联属于进阶玩法，动手量不小

丑话说在前面，后面用的才踏实；这些边界都不拦主线。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 内网与桌面的两问

### 麒麟系统AI在隔离内网怎么装模型

在线下载在完全隔离的内网走不通；U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。至于 OpenAI 风格与阿里百炼风格 API 的自动适配，省的是配置侧的功夫。模型设置保存后随系统技能分发到智能体。

### 桌面上能看到 AI 在干活吗

能。灵宠把在后台干活的 AI 具象成桌面上的小生物；AI 纪要一键生成，开完会即取即用。

## 一锤定音的说法

麒麟系统AI的成色，用开头那个问题检验：断网之后还剩多少可用。剩得多，环境形态就立得住；剩得少，再热闹的功能也只是网页套壳。政企环境里这个问题还有一层含义：断网往往是常态而非异常，能把常态当设计目标的系统，才配进涉密场景的备选清单。

## 窗口与多任务速记

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 模型配置的统一解法

很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；本机有统一的 OpenAI 兼容出口（127.0.0.1:52581），智能体端只填这一个地址。

## 新系统的肌肉记忆从哪来

Ctrl 或 Cmd 加 K 唤起聚焦搜索，搜应用、文件、内容，加问 AI 知识库直答，支持语音输入；键盘党的启动器则把启动、找文件、直接问 AI 三件事收进一个快捷键；再配上问 AI 直答卡，新桌面系统的肌肉记忆基本就齐了。

## 右键是桌面操作总入口

右键是桌面操作的集大成入口，「用智能体打开」即可把文件直接交给 AI 处理。

## 家族与生态的几张牌

数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；智能体若不知道自己掌握哪些本机工具，等于没有这些工具，技能手册镜像让它天然会用系统能力；智能体动系统能力分级确认，T0 只读直放。

## 桌面能力按需生成

智能体可以在运行时定义并挂载新插件，比如和 AI 说一句「给我做个每晚汇总新闻的应用」；桌面本身能被 AI 定义，能力边界从预装走向按需生成。

## 断网时的默认行为

无显式模型偏好时自动指向本地模型，断网时联网搜索自然不可用；设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态；建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型。

全部细节里最该带走的是完整桌面范式这一条；其余按步骤小节逐个落实即可。
