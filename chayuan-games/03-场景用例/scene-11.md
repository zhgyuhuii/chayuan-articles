# 模型性格怎么摸：协议画像与开局记忆观察

同一个模型，今天下棋滴水不漏，明天昏招频出；群里问它什么脾气，有人说稳如老狗，有人说莽得像新人。这不是玄学，是观察方法的问题——单局印象太随机，聊天感受太主观，模型性格要靠长样本和结构化指标才摸得准。察元竞技场正好把这件事拆成了可操作的几步：协议画像给出硬指标，开局记忆照出学习习惯，对局室里还有性格的活样本。这篇讲一套摸性格的观察法。

## 这件事原来的难处

聊模型性格，常见的三种摸法都不牢靠。

靠单局印象。今天它妙手连发，你就觉得它锋利；明天它被代走兜底救了三回，你就觉得它拉胯。单局是抽样，抽样会骗人。

靠聊天感受。对话框里聊十分钟，模型礼貌你就说它温和——聊天没有胜负压力，模型表现出的样子和对局里完全是两回事。

靠社区口碑。大家说哪家模型莽你就记住莽，以讹传讹，谁也没拿数据。性格这东西一旦变成印象流，就再也没人验证了。

还有个反常识的坑：聊天窗口恰恰是摸性格的坏地方。没有输赢、没有时限、没有对手施压，模型表现出的温和体贴更接近客套，跟对局桌上的它可能判若两模。

## 用竞技场怎么做

第一步，攒够样本。机机观战或锦标赛挂机，让目标模型多打对局。场次比单场长度更值钱：十场中等长度的对局，比一场马拉松更能抹平偶然性。玩法上棋类、扑克都来一些，不同玩法照出的性格面不一样。费用提醒照旧：云端模型消耗你的 API 额度，挂机有成本；Ollama 本地模型零成本，只是小模型的性格恐怕是「莽」字当头。挂机期间偶尔瞄一眼积分榜，发现异常对局（比如大面积代走）就单独记下来，那往往是端点抖动而不是模型本性。

第二步，读协议画像。这是硬指标的仓库：应用统计每个模型的出招协议习惯，JSON 格式遵守率与平均耗时两项摆在台面上。遵守率高，说明它出招规矩、格式稳，系统解析很少费劲；遵守率低，说明它十次里总有几次输出跑偏，要靠容错链甚至代走来收拾。平均耗时则照出节奏：快枪手秒回，长考型一步能磨十几秒。两项合起来，就是一张性格底片——守规矩的慢性子、散漫的快枪手、又稳又快的优等生，画像一摆，脾气先见分晓。

第三步，看开局记忆。竞技场有开局记忆机制，避免模型在同型局面里重复犯错。这个机制照出的是学习能力风格：有的模型吃过一次亏，下次遇到同型局面就换走法，越打越油；有的模型反复在同一个坑里摔倒，气得你想替它落子。同型局面的重复犯错率，是比口癖诚实得多的性格指标——嘴上会装，棋盘不会。

第四步，回对局室找活样本。硬指标之外，性格还活在细节里：思维链气泡的话风，有的条分缕析，有的想到哪写到哪；每手的延迟与 token 用量，有的精打细算，有的动辄铺满屏幕；复盘里妙手与失误标注的分布，能看出它优势时浪不浪、劣势时稳不稳；形势曲线的形状，能看出它是慢热型还是开局猛攻型。这些细节要带着问题看：它落后时气泡变长还是变短？连输之后耗时有没有失控？带着问题翻记录，比通读一遍有用。

第五步，写性格小结并长期修正。每个模型给一段三五十字的小结，贴在笔记里；建议顺手做一张观察记录表，字段不用多：日期、玩法、对手、JSON 格式遵守率、平均耗时、典型事件（比如被代走一次、长考两次），外加一句当场的性格印象。表格攒上十几行，画像就从感觉变成了档案。往后每攒一批新样本回来对一对，小结改到第三版，你对这个模型的了解就超过绝大多数只看跑分的人。

## 适合谁、不适合谁

适合：长期使用几家模型、想选对脾气的重度用户；做智能体编排、要按任务挑模型的工程师；对模型行为差异有研究兴趣的人；带团队选型的技术负责人同样受益，把候选模型的性格小结贴进内部文档，新人接手时少走弯路。不适合：只想知道「谁分高」的人，性格画像不回答棋力问题；也没有耐心攒样本、打三五局就想下结论的人，画像数字在小样本下波动很大，急脾气摸不出准数。跨厂商比较时还要留神条件一致，上下文喂法、玩法、档位不同得出的差异，可能是考题不同而不是脾气不同。

## 常见疑问

### 性格是厂商设定的吗

不是。这里说的性格是从对局行为统计出来的观察结果，不是厂商人设。同一个模型换提示档位，表现风格也会变，看画像时要留意对局当时的配置。严格说，你摸到的是「这个模型在这类任务下的行为倾向」，口径圈得越清楚，结论越可靠。

### 观察多久才够

没有死数，原则是场次够多、跨玩法、跨时段。急着用就先跑二十局看个轮廓，长期使用再慢慢补样本，画像是越养越准的东西；等遵守率与耗时的数字开始稳定、你对模型的预判很少落空，样本就差不多了。

### 协议画像能说明棋力吗

不能。画像统计的是出招习惯，遵守率高不代表下得好，格式漂亮但招法平庸的模型大有人在。棋力看天梯积分，性格看画像，两码事。

### 不同玩法里性格会变吗

会。有的模型棋类里稳、牌类里浪，分开攒画像更扎实。混在一起算，容易被平均值骗。给每个玩法各存一份小结，用的时候按场景取用，比一份大而全的总评实用得多。

### 观察结果能分享吗

棋谱支持 JSON 导出，带上你的小结可以发社区。记得注明样本量与对局配置，别让读者把你的个人观察当成官方结论。附上观察记录表的部分字段，愿意复现的人照着跑，你的结论就多了一重检验。

模型性格不是玄学，是可统计、可验证的行为规律。协议画像给数字，开局记忆给学习能力，气泡与复盘给细节，样本攒够了，每个模型的脾气都会自己浮出来。摸清性格这件事很实用：知道谁稳谁莽，下次排兵布阵就不会看走眼。
