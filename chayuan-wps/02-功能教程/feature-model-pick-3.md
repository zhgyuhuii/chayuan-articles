# 三个场景吃透多模型切换的用法

如果你正在琢磨多模型切换，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI文档助手的对话中选模型时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 为什么值得了解

配了多家厂商（或本地 Ollama/LM Studio），想在对话里随手换模型对比效果；对比两个模型的改写效果；某个任务更适合别的模型（长文摘要用大杯、快问快答用小杯）；新机器上还没配模型，点开下拉不知所以，需要被引导去配置。

用户常搜的问法：对话的时候怎么切换模型？换了以后哪条消息生效；模型下拉是空的/提示先配置模型，怎么办。

## 操作步骤详解

1. 认识模型按钮

1. 在哪：输入区工具条最左侧的芯片图标按钮（右边依次是机器人、知识库、回形针等工具钮）；已选模型时图标旁带厂商 logo 徽标（无已知 logo 的厂商显示模型名首字徽标），悬停提示当前模型名。
2. 未配置任何对话模型时悬停提示为「配置模型」。

2. 展开下拉并选择

1. 做什么：点芯片按钮展开下拉。
2. 看到什么：
    1. 模型按厂商分组排列：每组头是「▾ 箭头 + 厂商 logo/首字徽标 + 厂商名」，点组头可折叠/展开该组；有已知 logo 的厂商显示 logo，没有的显示厂商名首字徽标；
    2. 已配置「察元桌面版」时，末尾多出「察元桌面版 · 本地模型」等镜像分组，镜像察元桌面版里已配置的对话模型——选这类模型聊天经桌面版的模型代理（本机 62581 端口）转发；
    3. 当前选中的模型行高亮（active 态）。
    4. 做什么：点目标模型行即完成切换，下拉自动收起。
    5. 未配置任何模型时，下拉显示引导文案「请先在设置中配置模型：开启提供商、填写 API 地址与密钥、刷新模型清单」和按钮「立即配置模型」，点它打开设置页。

3. 生效时机与记忆

1. 生效：模型在发送时解析——切换后下一条消息即用新模型；已经在执行中的回合不受影响，任务窗的「换模型重跑」也会取当前选中的模型。
2. 记忆：选择立即写入加载项共享存储（复合 id 形如 DEEPSEEK|deepseek-chat），同时作为默认对话模型（defaultModelId/defaultModelsByCategory.chat）同步——重开窗格、重启 WPS 后仍保持；设置页与智能体链路读同一份默认值。
3. 作用范围：模型选择是全局的，不按会话单独记忆——切换后所有会话（含其它文档的会话）的下一条消息都用新模型。
4. 模型清单在窗口重新聚焦时自动刷新：刚在设置页增删了厂商/模型，回到助手窗格点一下任意处即可刷新下拉。

## 高频疑问

### 模型行前面显示的是首字方块而不是厂商 logo？

只有确有内置 logo 的厂商才显示 logo；没有已知 logo 的厂商/模型直接渲染名称首字徽标，不会去请求不存在的图片。属正常显示，不影响选用。

### 切换模型后，正在生成的回答会换吗？

不会。模型在发送时读取，切换只影响下一条消息；要换模型重跑可用任务窗的「换模型重跑」。

### 重启 WPS 后模型变回第一个了？

选择按复合 id 记忆并校验存在性：若该厂商被停用或模型清单里已无此模型，会回落到列表第一个。恢复启用该厂商即可找回原选择。

## 补充答疑

### 对话里选的模型会影响助手执行用的模型吗？

会参与。助手模型按优先级解析：助手显式配置的模型 > 对话框当前选中 > 助手分类默认 > 对话默认（跟随）；且对话选择会同步写入默认对话模型。要给单个助手固定模型，在助手编辑里单独设置。

### 「察元桌面版 · 本地模型」分组是怎么来的？

运行察元桌面版后，加载项会镜像桌面版里已配置的对话模型，按平台分组显示在下拉末尾；选这些模型聊天都经桌面版的模型代理（本机 62581 端口）转发。桌面版未在线时该分组无内容、不显示。

### 下拉里没有我刚在设置里加的厂商？

下拉只列「已启用 + 已填 API 地址 + 有模型清单」的厂商（Ollama 类本地厂商可免密钥）。回设置-模型设置确认该厂商已启用、地址正确并刷新过模型清单；模型清单在窗口重新聚焦时自动刷新（刚关掉设置页时点一下助手窗格即可），仍没有就重开 AI 助手窗格。

## 安装与运行答疑

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。
