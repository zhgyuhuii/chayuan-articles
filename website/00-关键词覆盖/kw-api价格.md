# API价格怎么查：模型目录、参数与定价页的对照方法

查API价格的人，多半刚被一串 token 单价绕晕。这篇不绕：查价入口、口径、边界三段摆开，自己对照。

## 什么是API价格

这里的API价格不是某一家厂商的报价，而是察元AI 能力广场里那套模型价格信息面：大模型目录带参数与价格对照，另有免费榜、定价页与资讯动态，查价不用逐家去翻各家页面。

本文口径整理自官方文档，版本对应关系见文末。

## 查价格的三个入口

- 模型目录：参数和价格摆在同一页，比营销稿直观
- 免费榜：按输入价门槛专列，零成本模型一屏看清
- 定价页：汇总各产品授权价格；配套的适用场景页按场景组织产品能力说明，行业页按行业给落地方案参考

三个入口的分工：目录回答「这个模型什么水平、什么价」，免费榜回答「不花钱能跑什么」，定价页回答「产品授权怎么算」。把问题先归类，再进对应页面，比一上来就翻列表快得多。

翻目录时有个省力技巧：先按用途锁定两三个候选，再横向比价，别从价格最低的开始挑。便宜模型省下的钱，常常在多出来的调试时间里加倍还回去；反过来，旗舰模型的能力如果你用不满，也是白花钱。先定任务难度，再定档位，最后在同档位里比价，这个顺序能避开大半选型弯路。

## 常见两问

### API价格要注册吗

查目录、看榜单不需要账号；收藏、下载、投稿需要登录。定价页汇总各产品授权价格，模型价格与新品节奏变动快，资讯页盯动态更稳。

### API价格资源免费吗

模型智力榜与免费模型榜都开放看；门户聚合的插件、技能、MCP、提示词、大模型资源一站检索与下载，总量为万+（站方口径）。

## 一句收束

API价格这件事，入口对了就是十分钟的事：目录对参数、免费榜对预算、资讯页对时效，三个页面各管一段。最后一句忠告：别把「查到便宜」当成目标，查价的终点是算清自己的用量，单价再低，乘上失控的调用量都是灾难。

## 价格口径与下单

免费榜按输入价门槛专列；购买授权页统一下单（扫码支付）；促销与免费额度可筛选。这三条是门户侧的口径，落到账单还要按自己的调用量算。把门户当比价台还有一个好处：同页对照逼着各家口径摊开，输入价、输出价、档位差异一目了然，比逐家翻文档省事，也比二手转述的报价帖可靠——报价帖不会告诉你它是什么时候的价格。

顺带提醒：免费榜适合试验和小流量场景，正式项目立项时按正式价测算，两套价差常常改变技术选型的结论。

## 算一笔 API 成本账

API 成本怎么估？先确定单次调用的输入输出规模，再乘以日均次数，得到日消耗量级，按月折算并留出余量。数字不必精确，量级对了就够用——多数人翻车不在单价，而在忘了算重试和长上下文那部分。做季度预算时再引入价格波动因素，把资讯页当参考系。还有一个常被忽略的项：失败重试。估算时把失败率也算进去，账才接近真实。

## 价格波动怎么应对

API 定价不是一锤子买卖，各家调价、上新、促销的节奏都不一样，昨天的结论今天可能就过时。应对办法有三个：一是把候选模型的当前价记档并注明日期，日后对比有依据；二是留意资讯动态，调价消息往往先于账单到达；三是选型时别把成本优势算得太满，留出价格上浮的预案，比如备一个同档位的替代模型。价格敏感的项目，把「换模型」当成常规操作而不是事故，架构上就不慌。
