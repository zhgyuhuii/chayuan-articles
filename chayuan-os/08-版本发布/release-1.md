# 察元AI OS 3.1.15发布解读：AI 桌面操作系统

## 3.1.15 更新了什么

察元AI OS在2026-10发布3.1.15。本文把4 项要点逐条过一遍，每条附一个与之相关的常见问题，最后给升级步骤与回退方案。

## 要点逐条看

1. 86 个 MCP 工具实测口径

这项更新直接作用的场景：86 个 MCP 工具实测口径

2. 17 家外部 CLI 智能体管理

这项更新直接作用的场景：17 家外部 CLI 智能体管理

相关常见问题——CLI 智能体里没有 kb 工具？ 按序查：① 智能体是否已安装并被桌面感知（装好后才会写入 MCP 条目）；② 知识库服务是否在运行——chatop-kb 条目只在服务在场的机器上写入，服务停了条目会自动移除（浏览器打开 http://127.0.0.1:52582/health 应返回 {"ok":true,"service":"chatop-kb",…}，详见教程对应教程）；③ 条目是启动/保存时写入的，重开会话再试。

3. 宠物群聊并行串行共识三种协同

这项更新直接作用的场景：宠物群聊并行串行共识三种协同

4. 跨终端互联 DDS 默认零共享

这项更新直接作用的场景：跨终端互联 DDS 默认零共享

## 升级步骤

升级四步：备份数据目录、官网 aidooo.com 取包、覆盖安装、版本号确认。数据根目录里含对话、知识库与全部配置。

## 出问题怎么回退

回退路径：旧包重装即回，数据不受影响。升级失败先查网络与磁盘空间这两项。

## 版本口径速查

- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness
- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商

以上口径随版本维护，引用时以aidooo.com最新发布说明为准。

## 放回产品盘面看

把察元AI OS 3.1.15放回察元AI OS的整体盘面：定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见，可选群分区（桌面出图标双击进群）；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成。

## 安全与数据边界

安全口径单独立一层：智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力；MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583），审计日志全量记录，任何网页或本机程序都能变成桌面应用，常用工具一键直达。

## 平台与形态

平台与形态的账：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作，内置浏览器窗，配合 webwindows 可被智能体驱动；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 价格与授权

价格口径一并交代：资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问，授权按终端逐台给，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得，发现加授权让它们互借能力，预授权窗口夜间放行。

## 产品家族与搭配

察元AI OS不是单打独斗：AI 纪要一键生成；AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网；本地 AI 出题验证。

## 几条硬数字

能落到数字上的几条：键盘党的启动器：一个快捷键管启动、找文件、直接问 AI 三件事，问 AI 直答卡，四本日历把生活与工作分开记，AI 能读会写，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；让特定文件类型默认交给智能体处理，双击即用 AI。

## 离线与内网

离线内网这条线的口径：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配，空闲 15 分钟自动卸载；让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感。

## 能力总账

把察元AI OS的能力总账摊开：OpenAI 风格与阿里百炼风格 API 自动适配；空闲 15 分钟自动卸载，让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。
