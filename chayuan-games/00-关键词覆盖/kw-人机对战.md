# 人机对战：和大模型同桌过招的正确姿势

围观了半天别人打模型，手痒了怎么办？人机对战就是为这一刻准备的。人机对战是指人类玩家与大模型同桌对弈、轮流出招的形式；在察元竞技场里，人机对战落地为人机局——你占一席，模型补齐其余座位，11 款玩法都能这么打，中途还能随时把棋子交给 AI 接手。

人机对战不是新概念，象棋软件时代就有了。变化在于对手的成分：对面从专用引擎换成了通用大模型，它会思考出声、会犯错、会换脾气。这篇讲清楚怎么跟这样的对手过招才不别扭。别扭的来源通常是预期错位：拿它当搜索引擎用会失望，拿它当陪练用刚刚好，这篇的立场就从这个预期出发。

## 拆词与相近概念辨析

先跟老对手划清界限。传统棋类软件：专用引擎做深度搜索，人类基本没有胜算，体验是单方面挨打。单机游戏的脚本 AI：按固定逻辑出招，摸清套路后就失去悬念。大模型对手：不靠搜索靠语料与推理，棋力有上限但行为有人味——会犹豫、会冒险、会在思维链气泡里跟你交代想法。你赢它有成就感，它赢你心服口服，这是人机对战里难得的平衡。平衡的代价是棋力上限：它不做深度搜索，别指望下出大师水准的神之一手，但它会犯人有过的错，这恰恰是练习的价值。

再辨析「人机局」与「人机混坐」：人机局是你与模型一对一或多对一的正式对局；在掼蛋这类合作玩法里，人机混坐还能让你与模型结成队友，配合的信息由合作上下文注入机制提供——队友看得见你的出牌历史，配合不靠猜。两种形态轮着来收获更大：先在人机局里跟模型过招，再去机机观战里看它跟别人打——对手视角与旁观视角一拼，模型的路数基本摸透。

## 随时双向切换的主动权

人机局里顶实用的设计是控制权切换：AI 接手与人工接管随时双向切换，下一手生效。用处分三种：打累了，把残局交给模型收尾；局面崩了，看模型怎么救——它的思维链就是一份现场教学；想学某类局面，先让模型示范几手，再接管回来自己练。三种用法可以混着用：一局之内先示范、再接管、又交回去，控制权跟着学习节奏走，没有必须一用到底的规矩。把人机局当学习工具也是正经用法：AI 接手的示范、复盘标注的定位、形势曲线的走势，合起来就是一套带练习的教材，比干看教程记得牢。主动权始终在你手里，下场与旁观之间没有墙。牌类里切换还有一层用法：合作玩法里你与模型是队友，把关键轮交给它处理，等于请了现场教练，思维链会解释为什么这么出，比看攻略直观。

## 战绩单独记账

人机局的胜负进 TrueSkill 天梯，但人类挑战者的战绩独立统计，不与模型混榜。理由很朴素：人类与模型的出招节奏、时间成本、精力曲线完全不同，混榜只会互相污染。你打你的升段曲线，模型跑模型的座次，各看各的进步，也各自体面。独立记账还有个好处：你可以放心挑战强模型，输再多也不影响模型的座次数据，两边的数据都保持纯净。

## 挑对手与挑玩法

对手怎么挑：先用机机观战看候选模型打几局，心里有个座次，再挑段位相近的下场，输赢都有悬念。玩法怎么挑：想练推理从棋类入手，想练心理从牌类入手，想轻松一点从自己玩得熟的那款入手——规则熟了，才分得出模型的好赖。拿不定主意就先各打一局试水，手感会告诉你答案。

不强求一开始就赢：与强模型的头几局大概率是学费，复盘标注会把学费花在哪一手标得清清楚楚。挑战强模型的正确姿势是把目标拆小：这局只求守住中盘不崩，下局试试收官不吃亏，目标拆细了，差距大的对局也有得练，等手感起来，再回头挑更强的对手，梯度自然就爬上去了。

三步。设置 ＞ 模型配置里选厂商、填 Key，「测试连接」通过；回大厅挑一款玩法开人机局，座位分配时留一席给自己；对局中想交棋就切 AI 接手，想回来再点人工接管，下一手生效。打完看形势曲线与复盘标注，棋谱导出留档，下一局换一家模型试试深浅。习惯养成建议：每局打完花两分钟看形势曲线，找到自己崩盘的那一手，进步速度比埋头连打快得多。

## 三条边界

模型出招消耗的是你的 API 额度：你下的每一手免费，对面模型出的每一手都在计费，云端模型费用自付，用 Ollama 本地模型才零成本。额度紧的话，把长对局留给锦标赛，人机局控制在短平快的玩法里。

强弱差距要自己把握：太强的模型让对局变成单方面挨打，太弱的又赢之无味，85 家厂商目录里多换几个对手，找合适的段位差。段位差可以从天梯上直接读：模型榜的座次摆在那里，照着挑就行。

部分玩法有学习成本：军棋要先花时间弄懂规则，日麻立直在大厅是隐藏入口，新手建议从五子棋或斗地主起步，规则的学习成本是一次性的，学会了就一直受益。

## 人机对战常见疑问

### 人机对战收费吗

软件 MIT 开源免费，模型 API 费用由你自己向厂商支付；用 Ollama 本地模型则零成本，断网也能打。想省钱就选轻玩法短对局，额度花在刀刃上。

### 打到一半能让AI替我下吗

能。AI 接手随时可切，下一手生效；想拿回控制权再切人工接管，同样下一手生效，双向都自由。切出去的几手照样有思维链可看，等于免费示范。

### 我的成绩会跟模型排在一起吗

不会。人类挑战者的战绩独立统计，天梯上单独一栏，不与模型混榜，你的升段曲线独立生长，成就感不打折。

### 新手适合从哪款玩法上手

五子棋规则负担轻，斗地主胜在熟悉，军棋暗棋与日麻立直建议先学规则再上场，麻将三系各有门槛。先易后难，兴趣才留得住。

人机对战的正确姿势，说到底是把模型当陪练而不是当考官：它出招你看思路，它接管你学收尾，它失误你捡漏练心态。察元竞技场把切换权与独立记账都留给了人——这场与通用大模型的同桌过招，输赢之外还有长进。
