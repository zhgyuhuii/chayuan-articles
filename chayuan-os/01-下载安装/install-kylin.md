# 银河麒麟安装：麒麟 V10 多架构选包要点

先说这篇能帮你干什么：读完能在察元AI OS里独立完成银河麒麟安装，路径是银河麒麟安装。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：麒麟 V10 多架构选包要点。

安装包从官网 aidooo.com 获取。

## 一步步来

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 其他平台装法速览

macOS：官网下载 dmg 并打开；把察元AI OS 拖入应用程序文件夹；启动后创建账户进入桌面。

Windows：官网 aidooo.com 下载对应架构的 exe 安装器；双击安装，零额外依赖；首次启动创建本机账户，进入桌面。

## 国产平台要点

银河麒麟 V10 的 x64 机型（兆芯、海光）选 x64 包，arm64 机型（飞腾、鲲鹏）选 arm64 包；统信 UOS 20 用 deb 形态，arm64 真机已实测。暂不支持龙芯，选包前用 uname -m 确认架构。

## 装完后的第一件事

装完先干两件事：一是让模型设置向导跑完，把默认模型应用到各家智能体；二是试一次断网对话，确认本地模型链路通了。恢复密钥也顺手生成，忘了密码时它是仅有自助路径。

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

边界先摆在桌面上：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
