# 察元竞技场0.1.0发布：11款玩法全量开源

棋类五款、扑克三款、麻将三款——察元竞技场0.1.0发布，把 11 款玩法一次性摆上了同一张桌子。没有灰度、没有分批，开源首版就是完整版本：从五子棋到德州扑克，从四川血战到藏起来的日麻立直，全部包含在内。

先给版本口径。这版是 0.1.0，时间口径 2026 年 11 月，MIT 协议开源，仓库地址 github.com/zhgyuhuii/chayuan-games，官方入口在 aidooo.com。有一点要说在前面：0.1.0 不是先发空壳再慢慢补的版本，11 款玩法、模型接入、对战模式、复盘体系，全都在安装包里。看文章的顺序也给你排好了：本篇是总览，玩法组、观战复盘与工程质量各有专篇展开。安装之后桌面上的产品名叫「察元AI游戏」，一个 Electron 桌面应用，暗色竞技场界面，中英双语。这篇把 0.1.0 的能力清单、上手路径与已知边界一次讲完。

## 这版有什么：11 款玩法一次给全

大厅按棋类、扑克、麻将三组排布：

| 组别 | 玩法 | 一句话看点 |
|---|---|---|
| 棋类 | 五子棋（15×15）、中国象棋、围棋（9 路/13 路）、军棋暗棋、军棋翻翻棋 | 完全信息博弈，纯拼计算与规划 |
| 扑克 | 斗地主、德州扑克、掼蛋 | 不完全信息，看牌、记牌、诈唬 |
| 麻将 | 四川血战、广东推倒胡、日麻立直 | 缺门、听牌、防守 |

几处容易漏掉的细节：军棋暗棋支持自由布阵，落子两击或拖拽都行，另有一个明棋教学档给没学过军棋的人，工兵飞雷、司令阵亡亮旗这些规则也都实现了；围棋是小棋盘，9 路与 13 路两档，气与劫的判定完整；日麻立直不摆在大厅显眼处，入口藏在彩蛋里，引擎完整可用，对局过程以 mjai 协议事件流记录。

## 胜负归代码裁判

11 款玩法各配一套纯逻辑裁判引擎，胜负判定全部由代码完成，模型只出招、不判罚，赢不了就是赢不了。裁判不吃外部输入、不做网络请求，只认规则真值，这保证了对局的公平底线。模型出的招要过一道解析容错链：先按标准格式解析，不行就剥思维链文本、剥代码围栏，再抽大括号、补截断的尾巴，最后在全文里按词边界扫合法动作串。逐级放宽，底线不动——只认合法清单成员，绝不产出非法着法。实在解析不出来，启发式代走兜底：能挡杀就挡，能吃就吃；代走次数超限判负。一个模型的 API 抽风，不会拖垮整局。

## 模型怎么上桌

设置 ＞ 模型配置，85 家厂商目录点选即填，DeepSeek、智谱 GLM、通义千问 Qwen、Moonshot Kimi、OpenAI、Anthropic Claude、Google Gemini 都在列表里。接入统一走 OpenAI 兼容协议，Claude 的原生协议由本机网关自动转换，不用改任何代码。手上有 Ollama 这类本地推理的话，免 Key 直接连，断网也能开局。不在目录里的端点也能手填 baseUrl 接入，OneAPI、NewAPI 这类中转同样适用；LM Studio、Xinference 这类本地引擎同样免 Key。

API Key 明文只存本机应用数据目录，永不上传；模型流量统一走本机网关，随机端口加路径令牌鉴权，外部进程够不到。这一层在 0.1.0 里是完整实现，不是占位。

## 四种开局姿势

- 人机局：你亲自下场，对面是模型。中途可以在 AI 接手与人工接管之间随时切换，下一手生效。
- 机机观战：选两个或多个模型对打，你在旁边看。座位默认匿名，显示玩家A、玩家B、玩家C、玩家D，身份到终局才揭晓。
- 锦标赛：多模型循环赛自动排程，积分榜实时刷新，跑完出冠军。
- 天梯挑战：按 TrueSkill 段位约战，人类挑战者的战绩独立统计，不与模型混榜。

对局室里能看到每一手的思维链气泡，模型怎么盘算这步棋实时流出来，旁边标着延迟与 token 用量。打完自动进 TrueSkill 天梯，段位分层排位。

这四种模式可以混着用。白天开一局人机局热身，晚上挂一场锦标赛跑循环赛，睡前切到机机观战看两个模型互咬——挂一晚跑完一轮，早上起来看积分榜与战报，是这类产品的经典用法。

## 用起来只要三步

1. 装包：按你的系统下载对应安装包，装完打开「察元AI游戏」。
2. 配模型：设置 ＞ 模型配置，选厂商、填 Key，点「测试连接」确认可用；也可以点「获取模型」实拉这家账号下可用的模型全列表，勾选入库。
3. 开局：回大厅挑一款玩法，选一个模式，模型就上桌了。

## 已知边界，先说在前面

0.1.0 是早期版本，功能会随迭代调整，遇到问题欢迎去仓库提 issue。两处容易困惑的细节提前交代：日麻立直藏在隐藏入口里，是彩蛋设计，不是功能缺失；军棋两款要先花些时间学规则，乐趣在规则熟练之后。软件 MIT 开源免费，但云端模型的 API 费用由使用者自己向厂商支付，挂机跑锦标赛烧的是自己的额度，配 Ollama 本地模型才零成本。另外要认一条：大模型靠语料与推理出招，不做深度搜索，下不过专用棋类引擎是正常现象，这个产品的看点在模型之间的相对高下与它们的思考过程，不在棋力神话。

## 怎么获取

安装包按三平台出齐：macOS dmg（arm64/x64）、Windows exe（x64/arm64）、Linux deb/rpm（x64/arm64）。开源仓库在 github.com/zhgyuhuii/chayuan-games，MIT 协议，想看引擎实现或者自己动手编译，直接 clone 下来跑；不想折腾的，去官网 aidooo.com 下载安装包即可。选包的粗略参照：苹果芯片 Mac 选 arm64，Intel 芯片 Mac 选 x64；Windows 绝大多数机器走 x64，骁龙本等 ARM 设备选 arm64；Linux 按发行版在 deb 与 rpm 里挑。

## 你可能会问

### 察元竞技场收费吗

软件本身 MIT 协议、开源免费。模型 API 的费用由你自己向厂商支付，配 Ollama 等本地模型则分文不花。安装包同样不收费，协议允许你自由使用、修改与分发。

### 为什么装完叫察元AI游戏

「察元AI游戏」是这个桌面应用的 Electron 产品名，察元竞技场是产品线名称，两者是同一个东西。安装包、界面与文档里可能遇到这两种叫法，认准仓库与官网就不会装错。

### 我的数据存在哪里

都在本机。API Key 明文只存本机应用数据目录的配置文件，永不上传；对局记录与天梯积分同样落在本机，想带走就导出棋谱 JSON。

### 人能下场跟模型打吗

能。人机局里随时可以在 AI 接手与人工接管之间双向切换，你的天梯战绩单独一个榜，不和模型混在一起。

### 和察元AI OS 内置的竞技场什么关系

同一个引擎。察元AI OS 内置同款竞技场，引擎层与独立桌面版逐字节同构；独立版适合没装察元AI OS、只想单独玩竞技场的人。

版本首发的价值在于口径干净：一个版本、一套规则、11 款玩法，没有功能分层，也没有历史包袱，这版能不能立住，交给对局说话。大模型们下棋打牌的真实水准，从此有了一张谁都能摆的擂台——它们究竟谁强，拉上桌打几局就知道了。
