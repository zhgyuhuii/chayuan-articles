# 图片查看排错：六种查看器

很多人搜「双击 .md 文件打开的是 Office，怎么改成 Markdown 预览」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把图片查看从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

按这个顺序排查图片查看通常最快：先确认前置条件（桌面形态（察元AI OS）。文件来自察元文件系统。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### Monaco 的 Save 按钮是灰的、⌘S 没反应？

Save 只在有未保存改动时可用（工具条文件名后出现 — 即为有改动）。⌘S/⌘F 需要编辑器区域持有焦点——点一下编辑区再按。

## 正确的操作路径

文件查看（BinaryViewer，兜底）

1. 入口：双击没有内置查看器的未知格式文件。
2. 窗口只展示元信息：文件名、大小（字节）与提示「没有内置查看器可以预览该文件，你可以下载到本地处理。」，下方蓝色「下载」按钮把文件取回本机用别的软件处理；空态同样提示双击进入。

Markdown 预览（Marked）

1. 入口：.md 双击默认进 Office；预览走桌面图标右键 ＞「打开方式」＞「Markdown 预览」（或改 .md 默认）。空态提示「在文件管理中双击 .md 文件即可在此预览。」（该提示写于 Office 接管之前，现状以关联表为准）。
2. 渲染：GitHub 风格 Markdown（GFM、换行即断行），正文经安全过滤后渲染；加载中显示「加载中…」，失败显示「加载失败: <原因>」。只读预览，编辑用 Office 或代码编辑。

## 如何确认操作生效

验证

1. 「我的电脑」双击一个 .txt：打开文本编辑，顶栏文件名与正文一致；改一行 ＞ 点「保存」＞ 按钮显示「已保存！」；重新双击该文件内容已更新。
2. 双击一个 .js：进入代码编辑，工具条显示语言 javascript；改一行后 Save 变为可点，⌘S 后浮出「已保存」。
3. 双击一张 .heic：先显示「解码中…」，随后出图；点「+」两下，比例显示从「适配」变为具体百分比。
4. 桌面图标右键一个 .md ＞「打开方式」＞「Markdown 预览」：渲染出标题/列表等格式。

## 高频疑问

### 从 Dock 打开的「文本编辑」写的东西保存后找不到了？

Dock 直开的文本编辑没有关联磁盘文件，「保存」不落盘。请从「我的电脑」双击文件进入编辑；新建文件用「我的电脑」空白右键「新建文本文档」。

### 图片显示「无法解码此格式」？

该文件扩展名在软解码名单内（heic/heif/jxl/tiff/qoi）但内容解码失败，或文件损坏。可用「我的电脑」右键「下载」取回本机，用系统图片工具打开确认文件本身。

### 未知格式文件双击只看到文件名和「下载」？

这就是兜底「文件查看」：没有内置查看器能预览它，只提供下载出口。音视频等有专属应用的格式不会落到这里。

## 更多操作细节

代码编辑（MonacoEditor）

1. 入口：双击代码文件（.js .jsx .ts .tsx .json .css .scss .less .py .go .rs .java .c .sh .sql .vue 等，按语言自动高亮）；Dock 图标名为「代码编辑」。
2. 窗口 = 标题条（文件名）+ 编辑器自带工具条：文件名（有未保存改动时后缀 —）、语言标识、内容大小 | 右侧三钮：⏎（自动换行开关，选中高亮）、Format（格式化，快捷键 ⌘/Ctrl++F）、Save（保存，快捷键 ⌘/Ctrl+S；无改动时禁用）。
3. 保存链：⌘S 或 Save ＞ 内容写回文件原路径，窗口下方浮出提示「已保存」（失败「保存失败: <原因>」）；读取文件失败显示「读取失败: <原因>」。保存只写回原文件，不做另存。
4. 格式化（Prettier）：支持 js/jsx/mjs/cjs/ts/tsx/json/css/scss/less/html/htm/md/markdown/yml/yaml/graphql/gql；不支持的格式（py/go/sh 等）点 Format 无动作；格式化出错浮出「格式化失败: <原因>」。
5. 主题跟随桌面深浅色；小地图（minimap）默认关闭。
