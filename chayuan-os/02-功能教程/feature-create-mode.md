# 创造模式：，一次走通

先说这篇能帮你干什么：读完能在察元AI OS里独立完成创造模式，路径是让 AI 造一个盯竞品的应用。步骤里的每个「」按钮都是界面原文。

## 是什么与为什么

为什么要有创造模式：桌面本身能被 AI 定义，能力边界从预装走向按需生成。创造模式的定位是智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用，

下面直接进正题。

## 完整操作步骤

试一次创造模式

1. 打开对话应用进入会话
2. 描述你要的应用：做什么、放哪里、多久更新
3. 智能体定义并挂载插件，权限门确认后生效
4. 桌面出现新应用，可继续让它迭代

迭代与沉淀

1. 对着新应用提修改意见，智能体原地升级插件
2. 满意后保留挂载，不满意右键卸载
3. 把好用的话术存进用户记忆，下次直接复用

## 谁需要这个功能

让 AI 造一个盯竞品的应用；快速原型化内部小工具。

## 它的局限也要说清楚

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 创造模式生成的应用稳定吗？

生成的是标准 dsh 插件结构，挂载后与其他插件同等对待：可启停、可卸载、可随会话迭代。复杂逻辑建议拆成多轮对话逐步逼近。

### 智能体造应用时要授权吗？

挂载插件属于系统级操作，会过权限门确认；高危动作（跑终端、装依赖）按 T1/T2 分级再确认，全程留审计。

### 适合造什么样的应用？

信息聚合展示类（盯价格、汇总新闻）、简单工具类（倒计时、随手记）最合适；重度数据处理建议走正规插件开发。

## 顺手把能力清单放这

- 运行时定义插件
- 即造即挂载
- 产物可留存复用
