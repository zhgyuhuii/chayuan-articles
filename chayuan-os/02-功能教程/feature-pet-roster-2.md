# 拆开看宠物状态徽标：原理、架构与实现细节

聊宠物状态徽标之前先划重点：它不是单一功能，而是一套带入口、步骤和验证的完整流程。察元AI OS在这件事上的设计思路是把入口收拢、把步骤做实、把边界说清，理解了这个，操作就顺了。

## 这个功能到底解决什么问题

桌面左下角的灵宠名册是全部灵宠与灵宠群的「控制台」：一屏看清每只的状态徽标（空闲/开窗中/任务执行中/下次运行倒计时）、快速钉住/取消钉住、点分区直达目录、搜索过滤，双击行直接打开对应工作台或群聊；顶部还是「添加灵宠」的入口。

养了十几个宠之后，谁在干活谁在睡觉需要一个总览台。

下面直接进入正题。

## 机制拆解

养了十几个宠之后，谁在干活谁在睡觉需要一个总览台。

能力面拆开看：钉住常用宠快速切换，状态徽标实时刷新，常驻任务倒计时可见。

一个常被问到的问题：为什么我建的灵宠在名册里显示「空闲」，桌面却看不到它。桌面只显示钉住、任务执行中、被双击启动的灵宠（在场规则），其余都收在名册里。在名册行点一下图钉把它钉住，它就常驻桌面了。

从提问口径看，用户最关心的是我的灵宠列表在哪里看？怎么找到不在桌面上的灵宠？

## 具体怎么操作

按最短路径验证一遍：

第 1 步 · 打开名册

点桌面左下角底栏的「灵宠」文字按钮（与「场景」「动态」并列；再点一次收起）。名册面板在该按钮正上方弹出：顶部一行是标题「灵宠」＋右侧蓝色「添加灵宠」按钮（点击打开建宠弹窗），下面一条搜索输入框，占位符「搜索灵宠 / 群…」。

1. 点桌面其他位置（名册面板和「灵宠」按钮自身除外）面板自动关闭。

第 2 步 · 看懂灵宠行

每只灵宠一行，从左到右六格：

还没有任何灵宠时列表区显示「还没有灵宠，点上方「添加灵宠」」。

| 格 | 内容 |
|---|---|
| 形象 | 灵宠形象缩略图，右下角叠加所挂智能体的小图标（模型直跑宠无角标） |
| 名字 | 灵宠名 |
| 模型 | 绑定的模型引用串尾段（如 glm-4-flash）；「自动」档显示「自动模型」 |
| 分区 | 分区目录名（蓝字按钮）。点击在文件管理器（我的电脑）中打开该分区；悬停显示完整路径 |
| 状态徽标 | 见第 3 步 |
| 操作 | 两个小按钮：铅笔、图钉（「钉住/取消钉住」） |

第 3 步 · 读状态徽标（按优先级从高到低）

1. 「任务执行中」（琥珀色底）：该宠绑定的常驻任务正在跑（或刚跑完 10 秒内的停留期）；
2. 「开窗中」（蓝色底）：该宠所挂智能体的工作台窗口正开着；
3. 下次运行倒计时（灰白药丸）：绑定了已启用的常驻任务且已排下一次运行，显示「即将运行」（到点）/「N 分钟后」/「N 小时后」/「N 天后」，面板每 30 秒自动刷新；
4. 以上都不是 ＞「空闲」。

## 它的局限也要说清楚

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 接着回答几个常见问题

### 状态倒计时一直不动？

名册面板每 30 秒刷新一次倒计时，属正常节奏；若长时间完全不变，检查该常驻任务是否仍处于启用状态且有下次运行时间（设置 ＞ 常驻任务）。

### 双击灵宠行没反应/弹了提示？

模型直跑灵宠没有智能体工作台，双击打开的是「灵宠对话」直聊窗；若该宠挂的智能体未安装，先去应用商店安装。

### 名册面板一点桌面其他地方就关了？

这是设计行为：名册是弹出面板，点面板外任意位置自动关闭；底栏「灵宠」按钮是开关，再点一次也可收起。

### 搜索框输入后群不见了？

搜索只按群名匹配群、按名字/任务 id 匹配灵宠。清空搜索框恢复全量列表。

## 补充答疑

### 为什么我建的灵宠在名册里显示「空闲」，桌面却看不到它？

桌面只显示钉住、任务执行中、被双击启动的灵宠（在场规则），其余都收在名册里。在名册行点一下图钉把它钉住，它就常驻桌面了。

## 更多操作细节

第 4 步 · 常用动作

1. 搜索：在搜索框输入关键词，实时按「名字」（灵宠还匹配任务 id、群按群名）过滤；无结果显示「没有匹配的灵宠」。
2. 钉住快切：点行尾图钉切换钉住态——钉住的图钉高亮（琥珀色），该灵宠常驻桌面不受在场规则约束；取消后收进名册（正在执行任务或开窗中的要等任务结束/窗关闭才离场）。
3. 编辑：点行尾铅笔打开「编辑灵宠」弹窗。
4. 双击直达：双击行——挂智能体的灵宠直接打开该智能体工作台窗口并落到它的分区（不弹工作区选择器）；模型直跑灵宠打开它自己的「灵宠对话」直聊窗（每宠独立窗口，复用已开的同宠窗口）。
5. 建宠：点顶部「添加灵宠」，走 P1 的建宠表单。

第 5 步 · 群聊一节

有群时，灵宠列表下方出现「群聊」分隔标题，每个群一行，格式与灵宠行同款六格： 图标、群名、「N 位成员」、群分区（蓝字按钮点击打开目录；建群未显式选分区的显示「自动（推荐）」）、状态徽标、编辑＋图钉。群状态徽标：

群行操作：铅笔打开群管理弹窗（改名/成员/协同方式/解散）；图钉切换「固定群到桌面（钉住常驻）」；双击群行打开宠物群聊应用并直接定位到该群。

1. 群内有成员正在发言（讨论进行中）＞「任务执行中」；
2. 群被钉住 ＞ 显示「钉住/取消钉住」；
3. 宠物群聊窗口开着 ＞「开窗中」；
4. 其余 ＞「空闲」。

## 能力点备忘

- 状态徽标实时刷新
- 钉住常用宠快速切换
- 常驻任务倒计时可见

## 安装与运行答疑

### 升级会丢数据吗？

不会。覆盖安装与自动更新都保留数据目录；升级前把数据根目录整体备份一份更稳妥。

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

整体用下来，灵宠名册的流程是清楚的：入口集中、步骤有反馈、做完有验证。第一次照着走一遍，后面基本就是肌肉记忆了。卡住就回看常见问题那一节。
