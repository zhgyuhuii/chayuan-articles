# 能力广场专题｜MCP 开发学习路线

MCP 开发学习路线。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：AI 教程库（AI教程）、MCP 服务器板块（MCP服务器列表）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**AI 教程库**：2.1 万+ 条全球 AI 学习资源导航：视频/文章/课程/电子书/文档/仓库七类，主题覆盖 LLM/Agent/RAG/Prompt/部署/微调/MCP/技能等，来源含 arxiv、github、B 站等。

1. 进入 /tutorials
2. 按主题（llm/agent/rag/prompt…）筛选
3. 按类型（视频/文章/课程…）收窄

**MCP 服务器板块**：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

1. 进入 mcp 板块
2. 按功能关键词搜索
3. 复制 JSON 配置片段到客户端

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 政企可私有化部署（Docker），数据自主可控
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 要注册才能用吗？

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。
