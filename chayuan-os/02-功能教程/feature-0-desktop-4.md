# 察元OSmacOS 风格桌面使用指南（AI桌面）（细节版）

AI桌面是察元AI OS里使用频率很高的一项能力。它的「macOS 风格桌面」这样工作：菜单栏 + Dock + 可拖拽多窗口的桌面体验：开机动画→锁屏→桌面三阶段，自动锁屏（Ctrl+L）、会话恢复、任务切换器（Alt/⌘+Tab）、通知中心、小组件面板、托盘驻留。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

菜单栏 + Dock + 可拖拽多窗口的桌面体验：开机动画→锁屏→桌面三阶段，自动锁屏（Ctrl+L）、会话恢复、任务切换器（Alt/⌘+Tab）、通知中心、小组件面板、托盘驻留。

从任务视角看，它对应的关键词是「AI桌面」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 启动进入锁屏，解锁进入桌面
2. Dock 点击启动应用，拖拽调整位置
3. Ctrl/⌘+Tab 切换任务，Ctrl+L 手动锁屏

## 适用场景

- 把 AI 能力当操作系统日常使用
- 演示与教学环境

## 进阶技巧

- 会话恢复保留窗口布局，重启不乱

## 注意事项与边界

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 常见问题
### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 和察元AI Office 什么关系？

Office 以内置插件形态运行在察元AI OS 中；购买 OS 授权后同机 Office 自动免激活。
