# 群媒体渲染实战：媒体直出可另存

群媒体渲染这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决把会议纪要任务交给群里自动生……。

## 解决什么痛点

一场讨论结束后要结论/待办/分工纪要，或要整理群（改名/换成员/清记录/解散），成员生成了图片/视频/音频链接，想直接在气泡里看、存到本地；让全群发言都基于同一份知识库资料（群默认库），或让不同灵宠各查各的库；把会议纪要任务交给群里自动生成。

## 完整操作步骤

一、附件（）

1. 点输入框左侧 （回形针图标，悬停提示「发送文件到群聊」）选择文件，可多选：
    1. 最多保留 8 个待发文件、单个不超过 2MB（超限文件被静默忽略）；
    2. 输入框上方出现文件小条（文件图标 + 文件名 +「×」移除）；
2. 点「发送」（或 Enter）：
    1. 附件先落盘到群分区的 attachments 子目录（无可见分区的群落 pet-attachments/ 兜底路径）；
    2. 随消息入群；只发附件不写字时，消息显示为「（附件）」；
3. 灵宠侧自动注入（每轮最多 3 个附件）：
    1. 转录里该消息标注「（附件：{文件名}…，内容摘录见下方）」；
    2. 上下文注入「【附件 {文件名}｜共约 {N} 行】+ 正文前约 3000 字」（超长只给头部样例，模型据此总结结构与样本）；
    3. 读取规则：doc/doc/xlsx/xls/pdf/pptx/ppt/html/htm 走抽取转正文；txt/csv/md 等文本类直接读；图片类不注入正文（灵宠只知道带了图、文件名列给它；svg 例外仍按文本注入）。

四、AI 纪要（「纪要」）

1. 点头部「纪要」（悬停提示「生成群聊纪要（AI 总结本群讨论要点）」），按钮转「…」表示生成中；
2. 引擎先做一道价值判定（决策模型 5 秒预算）：最近 40 条有效发言若被判定为寒暄/无实质结论（置信度 p < 0.35），直接落系统条「⏭ 决策门控：本轮讨论暂无值得纪要的结论（p=0.xx）」，不再调用模型；
3. 值得生成时：
    1. 使用本地已装对话模型（经模型代理，取第一个已装的本地 chat 模型），把最近讨论转录（「[发言人] 内容」逐行拼接、最多 8000 字）交给纪要模板；
    2. 结果以系统消息落群：「讨论纪要」+「## 结论 / ## 待办 / ## 分工」三节（条目化、不超过 300 字）；
    3. 本地没有任何已装对话模型时静默不生成（按钮自动恢复）——见常见问题 Q3。

五、群管理（「管理」）

点头部「管理」（悬停提示「管理群聊（改名/成员/模式设置）」），弹出「群管理」面板，自上而下：

另有头部「清空记录」按钮（悬停提示「清空本群聊天记录」）：一键清空本群全部消息并重置讨论状态（含接力交接单），群本身保留——与解散的区别就在这里。

1. 钉住：「固定群到桌面（钉住常驻）」复选框——勾选=桌面常驻圆桌群实体，已钉住时文案变「取消固定」；
2. 协同方式块：
    1. 「并行」「串行」切换（存量多步骤群另有「多步骤 · 旧版」编辑器）；
    2. 「打开群分区」：在我的电脑中打开本群分区目录；
    3. 「保存编排」（显示「已保存」）；非并行群另有「从头重新执行步骤链」；
    4. 「群名」：输入框改完失焦即保存；
    5. 「群分区」：下拉换分区（换过去即建好目录与 attachments 子目录）或切回「自动（推荐）」；下方提示「已选定分区：桌面将出现该分区图标，双击可打开群聊」；
3. 「成员列表」：
    1. 每行 = 头像 + 名字 +（所挂智能体名或「模型直跑」）+「移出」；
    2. 「+ 添加成员」展开候选灵宠列表（无可加时显示「没有可添加的宠物」），点「+」入群，立即出现在列表里；
    3. 「移出」即时生效（该成员停止参与后续轮次，历史消息保留）；
    4. 「解散群聊」：两步确认——
    5. 第一击按钮变红，显示「确认解散？再点一次（分区目录保留）」；
    6. 3 秒内再点才真正解散；
    7. 解散会删除该群的聊天记录、移除桌面圆桌实体与窝引用；群分区目录保留在原地；
    8. 「取消」关闭面板。

## 关键能力点

- 附件自动抽正文
- 三级知识库优先级
- 媒体直出可另存
- AI 纪要一键生成
- 500 条历史可回看

## 边界先摆桌面上

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 你可能会问

### 附件发了，灵宠却说没看到内容？

对照第一节的读取规则逐项核对：① 图片类附件不注入正文（只告知文件名）；② 单文件超 2MB 或总数超 8 个会被静默过滤；③ 每轮只注入前 3 个附件的正文（前约 3000 字）。文档类（docx/pdf/xlsx…）才走正文抽取。

### 群库和宠物自己绑的库，到底用哪个？

两级优先：群挂了库，全员一律用群库（宠物库被压住）；群没挂库，各宠物用自己绑定的库。想按宠物分库就别挂群库；想全群统一就挂群库。

### 点了「纪要」没任何输出？

纪要只走本地已装对话模型：本地一个对话模型都没装时静默不生成。先按 M3 装好并确认在 设置 ＞ 模型 里可见，再点纪要。

## 更多操作细节

二、知识库（）

1. 点输入框右侧 （书本图标，悬停提示「绑定知识库（宠物发言时自动检索）」），弹出菜单：
    1. 标题「知识库」+「不绑定」+ 各库条目「{库名} ({文档数})」；
    2. 一个库都没有时显示「暂无已导入的知识库」；
    3. 选中即持久化为群默认库（写入群档案）：输入框上方亮出「{库名}」徽标（带「×」可清），此后成员每轮发言自动检索该库；
2. 优先级（两级，2026-10-26 起口径）：
    1. 群挂了库 ＞ 全员一律用群库（宠物自己的绑定库被压住）；
    2. 群未挂库 ＞ 各成员用自己建宠时绑定的库（没绑就不检索）；
    3. 换群库即时生效，不会被旧消息钉在旧库上；
3. 检索行为（每轮自动）：
    1. 命中 ＞ 注入「【知识库参考】」片段块（带【文档名】前缀、清洗拼音噪声、按关键词居中截取约 200 字；串行接力群检索上一棒发言，其余检索最新命题）；
    2. 挂库但 0 命中 ＞ 显式注入「【知识库参考】本轮对「{q}」检索无结果：库里没有匹配内容，不要声称任何内容在库里。」；
    3. 灵宠可发起工具式补查：回复中输出 [[KB:查询词]] 时引擎代查并回填「【知识库查询结果：{q}】」（无匹配则回填「…无匹配内容——知识库里没有，不要声称在库里」），每次发言最多 2 次；协议标记不会出现在气泡里；
    4. 命题里提到「知识库/库里」但全群没挂任何库时，消息流落系统提示「本群与成员宠物都未挂知识库——宠物无法真的查库。点输入框 选择知识库（群库优先于宠物库）」。

如果只记一件事：附件自动抽正文。剩下的细节，照步骤节走就行。
