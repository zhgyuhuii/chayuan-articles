用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

1. 找经过验证的稳定项目看「热门」
2. 找新出的潜力项目看「新品」
3. 找近期涨势猛的看「趋势」
4. 增量数据积累中的板块会标注按星标总量排序，看到标注就换长周期档
