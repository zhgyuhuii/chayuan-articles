# 低代码页面避坑指南：边界、限制与对策

接手别人的察元AI Office环境时，我在低代码页面上卡了半小时——不是功能难，是没人告诉我完整的操作链。这篇就是当时想找而没找到的那篇文章。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（仅桌面壳形态提供 HTML 编辑器。），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 预览里点了某个元素，却提示「脚本生成」改不了？

这个元素是页面 JS 运行时插进 DOM 的，源码里没有对应标签，所以无法回写。要么改生成它的脚本源码，要么用 AI 面板描述意图让 AI 改；静态元素不受影响。

## 正确的操作路径

1. 新建/打开与「插入骨架」

1. 从主页「新建 HTML (.html)」或打开 .html/.htm 进入；空白页编辑区为空；
2. 工具条「更多」菜单里点「插入骨架」：把一页标准 HTML 骨架写进空白文档——<!DOCTYPE html>、按界面语言设置的 lang、<meta charset="UTF-8">、<title> 与空 <body>（页面有内容后该按钮置灰，避免重复塞骨架）。

2. 三种视图与状态栏

1. 工具条右侧一组三个页签：「预览」（整幅页面）、「分栏」（左源码右预览）、「源码」（整幅代码，CodeMirror 高亮）；「查找和替换 (⌘F)」作用于源码文本——在预览视图触发时会自动切到「分栏」让源码可见（区分大小写/全字匹配/替换/全部替换）；
2. 状态栏：源码视图显示「行 {n}，列 {n}」与字符数；右侧「设备」下拉切「桌面/平板/手机」三种预览宽度。

3. 插入元素（工具条「插入」组）

1. 「标题」「段落」：直接插入带占位文字的元素（「新标题」「在此输入文字。」）；
2. 「图片」：从本机选图插入；点右边的下拉箭头改「图片链接…」——填 https:// 地址插入网络图片；「插入」确认；
3. 「表格」：弹出 8×10 选格器，悬停显示「{r}×{c} 表格」，点击插入；
4. 「更多」菜单：「列表」「按钮」「区块」「分隔线」，以及「插入骨架」；页面没有 <body> 时提示「页面没有 <body>，无法插入元素」。

## 如何确认操作生效

验证

1. 新建 HTML ＞ 「更多」 「插入骨架」：源码出现完整的 doctype/lang/charset 骨架；切「分栏」右侧立即渲染出空页面。
2. 「插入」 「标题」后在预览中双击标题文字改为自己的文案，再切「源码」：能看到刚才只在你改的那一处发生了变化，其余源码未动。
3. 选中一张图片，点「去除背景」调「容差」：预览即时显示抠图效果，「应用」后写回；点「替换图片」换图成功（未保存的草稿会提示「保存文件后才能替换或编辑图片」）。
4. 「导出为单文件 HTML…」把副本发到别的机器/浏览器打开：页面完整显示，不依赖原 assets/ 文件夹。

## 你可能会问

### 导出单文件 HTML 时提示「有 {count} 个资源无法内嵌」？

内嵌只处理本地相对路径的图片/样式引用；网络图片（http/data: 开头）保持原样不内嵌。无法读取的本地文件会按原引用保留并在提示里给出第一个名字，检查该文件是否存在于文档旁边。

### 可视化改动会打乱我的源码格式吗？

不会。每处编辑是一次精确的连续替换，补丁式写回；缩进、注释、没动过的代码保持原样，BOM/CRLF/LF/末尾换行也原样保留。

### 面包屑提示「脚本已改动」是什么意思？

页面脚本在你选中后又改过这个元素。此时把可视化修改写回源码，下次脚本一跑就可能盖掉它；建议改脚本本身，或改完别再让脚本碰它。

## 补充答疑

### 预览里图片/样式没显示？

相对路径的资源要文件落盘后才解析。保存一次（⌘S），状态栏提示「保存文件后，相对路径的图片和样式才会在预览中显示」消失即正常。

### 导出的 Word 里为什么有的内容是图片？

HTML 里图表、图标、带复杂装饰的盒子没有可对应的 Word 结构，导出按截图保留外观；正文、标题、列表、表格则是原生可编辑的 Word 内容。

## 更多操作细节

4. 预览检查器（在预览里直接选中/改字）

1. 预览里单击元素即选中（选中元素出现高亮框与浮动工具栏）；双击文字直接就地编辑（提示文案：「单击预览中的元素选中，双击编辑文字」，显示在面包屑区域）；
2. 面包屑（元素路径）：显示选中元素的祖先链（如 div#app、section.hero），点某一节选中那个祖先元素；
3. 页面脚本动态生成的元素无法回写源码：面包屑标「脚本生成」，提示「此元素由页面脚本生成，源码中不存在；请通过源码或 AI 修改」；脚本后来改动过的元素标「脚本已改动」，提示「页面脚本改动过此元素，写回源码的修改可能被脚本覆盖」。

5. 元素工具栏（选中元素后浮出）

1. 文字：粗体/斜体、字号 −/+、颜色；
2. 图片元素另有：「替换图片」「裁剪」「去除背景」（自动从图片边缘采样背景色，「容差」滑块控制去除范围，实时预览去除比例）、水平翻转/垂直翻转/向左旋转/向右旋转、锁定宽高比、重置大小；
3. 结构：「上移」「下移」「复制元素」「删除元素」；
4. 「样式面板」打开右侧完整样式面板；「AI 修改」针对选中元素提修改（见第 7 步）。

6. 样式面板

1. 分区：文字排版（字号/字重/对齐）、尺寸（宽度/高度/圆角）、盒模型（内边距/透明度）、图片（替代文字/填充方式：拉伸填满/完整显示/裁切填满/原始尺寸）、颜色与背景色（主题颜色/标准色/其他颜色…）；
2. 「自定义样式」直接写 CSS；所有改动实时预览，「还原」撤销本面板的改动，「关闭样式面板」退出。

## 安装与运行答疑

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

## 一个真实场景

研究生与科研人员的典型用法：PDF 阅读器选区标注加问 AI，Zotero 引文插入与书目生成，扫描件自动 OCR 变可搜索文本。读、引、记、写在一个应用里闭环。注意：Linux 端无系统 OCR 引擎，扫描页不识别。

低代码页面的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
