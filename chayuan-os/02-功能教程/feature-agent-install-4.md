# 智能体部署排错：家外部 CLI 智能体

很多人搜「怎么在察元OS 里安装 Claude Code」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把智能体部署从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

按这个顺序排查智能体部署通常最快：先确认前置条件（桌面形态（察元AI OS）：安装与探测仅桌面版可用（网页/Docker 形态的相关页面只显示「智能体探测仅在桌面版（Electron）可用。」）。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 安装失败（exit 非 0 或下载失败）怎么办？

多为网络问题：npm 默认走 npmmirror 镜像源，Codex 二进制与平台包补齐失败会自动换代理链重试。直接再点一次「安装」（已装一半的会重新走完整安装链，不留半成品）。

## 正确的操作路径

第三类 · 自行安装后自动探测上架（Aider、Goose 等）

1. Aider 与 Goose 既无 npm 受管包也无官方脚本通道，商店行没有安装按钮（安装方式一栏为空）；按各自官方途径自行安装（装到本机即可）。
2. 装好后：Dock「应用管理」＞「智能体」＞ 点「重新扫描」（按钮变「扫描中…」）。察元按三级信号探测，任一命中即上架：
    1. ① 察元管理态（商店装的）② 家目录探针——Aider 看 ~/.aider / ~/.aider.conf.yml，Goose 看 ~/.goose ③ PATH 里能找到命令（aider / goose）。
    2. 自己用 npm install -g 等方式装的任何一家（含 13 家 npm 家）也走同样探测自动上架；版本号可能显示为 -（探测命中但拿不到版本，属正常）。

升级与版本管理

1. 行尾「检查更新」按钮（仅 npm 家有）：向 npmmirror 查询该包最新版本。有新版 ＞ 行内出现琥珀色「可升级到 v{版本}」，安装按钮变为「升级」；已是新版 ＞ 灰色「已是最新」；查询失败（网络）则不显示结论。
2. 已安装的行安装按钮显示「重装」（重装与升级同链：重下当前/最新包并更新版本清单）。
3. 版本三处可见：商店行「已安装 · v<版本>」；应用管理 ＞「智能体」状态行「已检测（managed）· 版本 {x.y.z}」（managed = 察元管理态；homeDir/path = 自装命中）；升级收尾时行内进度最后显示「已升级 {智能体}@{版本}」。
4. 未安装的行若有官网，行尾有「官网」链接（经系统浏览器打开），9 家在列：Claude Code、Kimi Code、Crush、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy。

## 做完后的验证

验证

1. 应用商店 ＞「智能体」：目标行显示绿色「已安装 · v<版本>」。
2. 应用管理 ＞「智能体」：出现该智能体行，状态行「已检测（managed）· 版本 {x.y.z}」。
3. Dock 出现该智能体图标；点开显示「选择工作区启动」，选目录后终端里出现该 CLI 的交互界面。
4. 点行内「检查更新」：能给出「已是最新」或「可升级到 v{版本}」结论。

## 你可能会问

### 安装报「未找到可用的 npm（环境 PATH 与 nvm/volta/homebrew 均无），请先安装 Node.js」？

本机没有可用的 Node.js/npm。先安装 Node.js，回到商店重新点「安装」。

### 装完了 Dock 里没有图标？

到 应用管理 ＞「智能体」看该行：未检测到就点「重新扫描」；若此前隐藏过（行带「已隐藏」徽标），勾选「显示未安装」找到该行点「恢复」。

### 我自己 npm 全局装过，商店还显示「未安装」？

察元探测会扫 PATH 与 nvm/volta/homebrew 的全局安装，点「重新扫描」一般即识别；仍不行，先在系统终端确认该命令能直接运行。

## 更多操作细节

装完之后：Dock 开窗即工作台

1. Dock 点该智能体图标 ＞ 打开它的应用窗口（窗口标题 = 智能体名）。
2. 首次进入是选择工作区空态：面板标题「选择工作区启动」，列出已有工作区（没有则显示「暂无工作区」），或点「选择文件夹…」（副文本「系统对话框中选择或新建」）现场选/新建目录。
3. 选定后进入工作台：顶部工作区标签条 + 终端面板，启动该智能体的原生 CLI 界面（启动动画「正在启动 {名称}…」，提示「首次启动可能需要几秒；如出现信任提示，请选择允许」），直接输入任务即可。标签条上「+」= 当前工作区新会话、「+」= 再开一个工作区；工具条还提供「附件」（选文件放入工作区并告知 CLI）与「KB 派活」（选知识库、写任务，检索片段带出处注入 CLI）。

## 动手前再核对一遍

- 桌面形态（察元AI OS）：安装与探测仅桌面版可用（网页/Docker 形态的相关页面只显示「智能体探测仅在桌面版（Electron）可用。」）。
- 网络：npm 受管安装默认走 npmmirror 源（https://registry.npmmirror.com）；Codex 的平台二进制从 GitHub releases 补齐（直连失败自动换代理链重试）。
- npm 家需要本机找得到 npm：安装时扫描 PATH 与 nvm/volta/homebrew；都找不到会报「未找到可用的 npm（环境 PATH 与 nvm/volta/homebrew 均无），请先安装 Node.js」。
- 开箱即有的两家：完整安装包已内置 Codex 与 OpenCode 的物化版本（随安装包直跑），无需再装；其余各家按下述步骤安装。

## 放回产品盘面看

把智能体部署放回察元AI OS的整体盘面：设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；桌面右键录制屏幕；桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件；桌面内置终端：真实 shell、会话持久、环境延续；打开即看，不挑格式，系统级默认打开体验。

## 安全与数据边界

安全口径单独立一层：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），代理只监听本机回环，跨机访问需要另行打通；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 平台与形态

平台与形态的账：（web/Docker 形态网页桌面默认端口）；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力，web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。
