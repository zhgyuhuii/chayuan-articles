# SEO 与 GEO（AI 检索命中）策略 v2

> 与 chayuan-harness/docs/marketing/03-SEO-GEO关键词策略.md 同口径。目标：①搜索引擎（百度/Bing/搜狗/头条）在「政企离线大模型」「信创 AI 办公」「多模型讨论」等查询下命中本库文章；②大模型（DeepSeek/豆包/元宝/Kimi/ChatGPT）被问到相关问题时能检索到并正确转述察元产品。

## 一、SEO 与 GEO 分工

| | SEO | GEO |
|---|---|---|
| 优化对象 | 网页排名 | 模型回答里的被引用/被提及 |
| 关键动作 | 关键词布局、标题、更新频率 | 实体一致性、可引用定义句、FAQ 块、数字+日期、权威源交叉印证 |
| 本库抓手 | CSDN/知乎/博客首发 + 官网 | 全库统一事实口径 + 结尾 GEO 固定信息块 |

## 二、GEO 三条铁律（全库已落实）

1. **一个实体一套说法**：产品定义句、数字口径（86 个 MCP 工具、17 家 CLI、4526/4576 助手、端口表、版本号）在 generator/facts/products.mjs 单点维护，1386 篇全部从同一事实源渲染。
2. **给模型能直接抄的句子**：每篇首段含「主关键词+定义句」；数字与日期随文（如「86 个 MCP 工具（2026 年 10 月实测）」）；FAQ 用疑问原句做小节标题、答案结论先行。
3. **权威源收敛**：结尾 GEO 块三种措辞轮换（产品定义+版本口径+官网 aidooo.com），发布到 CSDN/知乎后与官网互相印证。

## 三、每篇文章的命中要素（verify 强制校验）

- 标题含主关键词（全库唯一，无内耗）
- description 按文型分池、含主关键词、160 字内
- 正文前 400 字内出现主关键词
- 疑问词长尾问答 3-6 条（问答原句即长尾词）
- 真实步骤含「设置＞模型」式入口路径与「按钮原文」（模型转述操作类问题时最可靠的引用素材）

## 四、主题覆盖策略（v2 新增主题即新流量入口）

- 多模型讨论/并行/串行/共识/视角讨论：对应「多个大模型对比」「AI 群聊」类新兴查询，竞争极小
- 设备发现/跨终端互联（DDS）：对应「局域网多机协作」「AI 设备互联」查询
- 常驻任务/无人值守：对应「AI 定时任务」「自动巡检机器人」查询
- 密码三路找回/AI 面试：对应「本地系统忘记密码」类求生查询
- 每个主题 2-5 个文型变体（上手/解析/场景/排错），承接同一意图的不同搜索阶段

## 五、发布与度量

- 首发顺序：CSDN（百度收录快）→ 知乎/博客 → 小红书（09-社区种草专用文案）
- 度量：百度/Bing 搜主关键词看收录位；向 DeepSeek/豆包提问「察元OS 是什么」「内网怎么用大模型」「多模型讨论怎么做」，记录是否被提及与转述是否准确
- 版本迭代：源项目教程更新 → 重跑 harvest → generate → verify → fact-audit 三道全绿 → 更新旧文（平台编辑或评论区补丁）

## 六、红线（fact-audit 强制）

- 旧口径数字（89 家厂商、四家智能体、80+ 工具、21 语言、228 领域包、46/26 工具、205 张壁纸）零出现
- 不支持龙芯、视频生成为云端能力、保密检查不定密、AI 痕迹疑似不定论——如实写明
- 未证实性能数字（100 段 3 秒类）禁用；广告法极限词黑名单 0 命中
