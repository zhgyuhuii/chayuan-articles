# 批注写回避坑指南：从入口到完成的完整流程

校对批注是察元AI文档助手里使用频率很高的一项能力。它的「批注写回」这样工作：把校对结果以批注形式精确钉到正文对应位置（细到表格单元格），修改建议、原文引用、理由一目了然，审校者逐条裁决，这是「先预览后确认」写操作铁律的落地形态。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

把校对结果以批注形式精确钉到正文对应位置（细到表格单元格），修改建议、原文引用、理由一目了然，审校者逐条裁决，这是「先预览后确认」写操作铁律的落地形态。

从任务视角看，它对应的关键词是「校对批注」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 发起校对并等待问题清单
2. 选择「以批注写回」
3. 在 WPS 审阅视图逐条接受或拒绝批注

## 适用场景

- 三审三校流程中的机器初校环节
- 给领导/客户的留痕审校

## 进阶技巧

- 批注保留原文引用，方便向作者解释改动理由

## 注意事项与边界

- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 和 WPS 自带的 AI 有什么区别？

本产品是独立的开源加载项，特色在结构化校对批注写回、保密/脱密工具链、本机 MCP 服务与离线内网支持；两者可并存使用。

### 察元AI文档助手是什么？

一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。

### 能处理多长的文档？

长文分块读取（document_chunks）对百万字级文档友好；校对建议分批确认，避免一次任务过大。
