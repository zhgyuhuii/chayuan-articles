# 一文分清模型路由：统一团队的任务模型基线

模型路由这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是模型路由

模型路由这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

本文数字与版本口径以官方文档为准，文末尾注标了截止时间。

## 在察元AI OS里落在哪

模型路由在察元AI OS里的落点是全局默认模型：11 类任务各选默认模型：对话、嵌入、重排、决策、文生图、图生图、视频生成、图像理解、视频解析、语音合成、语音转文字，可选自动（本地优先）或指定，保存后随系统技能分发到智能体。

为什么值得单独说：润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 保存报「模型代理未运行，无法接入云端厂商（先在模型设置里确认服务状态）」？

代理随本地模型服务自启。到 设置 ＞ 模型 看页面顶部健康灯，服务恢复后回来重新保存；只选本地模型 / 「自动」不受此限。

### 「自动」到底会用哪个模型？

固定回退顺序：本地第一个可用 ＞ 云端第一个匹配 ＞ 无可用。想让某类明确用某个模型就指定它，不要留「自动」。

### 在页面上直接点选后忘了保存，生效吗？

不生效。直接点选只是暂存，必须点右下「保存并更新技能」；弹窗「设置…」的「确定」则是立即保存。

### 卸载会删掉我的数据吗？

卸载程序不移除数据目录，重要数据卸载前自行备份即可；要彻底清理就手动删数据根目录。

### 模型路由要联网吗

或按直链目录放置后执行扫描本地放置的模型，扫描本地放置的模型，我的模型面板管理加载、卸载、删除、钉住。以官网 aidooo.com 当前页面为准。

## 更多操作细节

2. 认识左栏的十一类

「默认对话模型」「默认嵌入模型」「默认重排模型」「默认决策模型」「默认文生图模型」「默认图生图模型」「默认视频生成模型」「默认图像理解模型」「默认视频解析模型」「默认语音合成模型」「默认语音转文字模型」。三类特殊口径（源码注释明确）：

1. 重排 / 决策：只列本地模型（决策类为本地专属能力，无云端对应类型）；
2. 图生图 / 视频生成：本地暂无此能力，全部列已启用厂商的对应类型模型。

## 更多操作细节

3. 在右栏选择模型（两种方式）

右栏卡片标题即分类名（如「默认对话模型」），下方说明文字：「选择该分类的默认模型；保存后写入系统技能（models.md）并自动分发到各智能体。云端厂商经本地 52581 代理调用（真实 key 不出凭证库）。」 标题行右侧两个按钮：

也可以直接点选卡片内的选择树：

1. 「管理本地模型…」：跳到 设置 ＞ 模型 的该分类本地模型页（下载 / 导入 / 启动模型用）；
2. 「设置…」（蓝色）：弹出选择弹窗（下一步）。
3. 第一行「自动」单选：右侧灰字实时显示「当前自动使用：{模型}」或「无可用模型」；
4. 「本地模型」分组标题下列出本地该能力模型，等宽字体模型 id，运行中的行尾带绿点（悬停提示「运行中」）；
5. 其下每个已启用厂商一组（组头是厂商名），列出该厂商在 Harness 注册的对应类型模型（等宽字体）；
6. 分类下什么都没有时显示「该分类暂无可用模型。点击右上「设置…」去模型设置启用厂商或安装本地模型。」
7. 点行即选中（单选），此时只是暂存，要点右下角「保存并更新技能」才生效（保存中按钮变「保存中…」，成功后绿色提示「已保存，系统技能已更新并分发到各智能体」）。
