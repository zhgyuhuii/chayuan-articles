# 🧩多文档错别字校对（MCP）隐藏用法｜批量校对一次讲清

用过察元文档助手的宝子看过来，多文档错别字校对（MCP）这个功能很多人没用到极致👇

✅ **它能干嘛**

通过本机 MCP 服务的 proofread_run 工具对多个文档执行错别字校对：先 dryRun 预览问题清单，确认后用 proofread_apply_comments 把批注钉到具体错字（含表格单元格），支持异步任务轮询。外部智能体（Claude Code、Codex、Cursor）可直接调用。

🔍 **三步用起来**

1️⃣ 在 Claude Code / Cursor / Codex 中连接本机 MCP 服务 http://127.0.0.1:62588/mcp
2️⃣ 调用 proofread_run 发起 dryRun，拿到全量问题清单
3️⃣ 人工复核清单后调用 proofread_apply_comments 批量落批注

💡 **什么场景最香**

· 整目录标书/合同批量错别字体检
· 科室多份材料的统一校对

📌 **避坑提醒**

⚠️ 仅支持 WPS 桌面端（12.x/365），不支持网页版 WPS 与其他办公软件

🛠️ **更多它擅长的事**

· **拼写与语法检查**：面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文批量审校前的初筛。
· **批注写回**：把校对结果以批注形式精确钉到正文对应位置（细到表格单元格），修改建议、原文引用、理由一目了然，审校者逐条裁决，这是「先预览后确认」写操作铁律的落地形态。
· **本机 MCP 文档智能体服务**：内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。

⚠️ **断网也能用？这点很关键**

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

🎯 **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容

📝 **免费还是要花钱**

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。

🧩 **说点大实话（缺点）**

· 免费版每日对话 30 次，重度使用需要付费或自建模型端点
· 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
· 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型

🚀 **延伸了解**

察元AI文档助手是一款 WPS 文字智能加载项（jsaddons 形态），在编辑器内提供「察元 AI 助理」与「察元 AI 编审」两个功能页签，用大模型完成文档对话、校对审查、表单填报与正文写回；同时内置本机 MCP 文档智能体服务（127.0.0.1:62588），可被 Claude Code、Codex、Cursor 等外部智能体直接调用读写本机 WPS 文档，支持离线/内网模型，文档与密钥不出本机。

❓ **常见疑问快答**

问：和察元AI Office 什么关系？
答：同属察元AI 产品家族：文档助手是 WPS 加载项形态；察元AI Office 是独立的开源 AI 办公套件（文档/表格/演示/PDF）；两者共享校对理念与领域助手体系。

问：数据目录在哪里？
答：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan，均可在设置中覆盖。
