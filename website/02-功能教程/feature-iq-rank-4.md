# 模型榜单排查路径：挑免费额度做原型

## 先定位问题在哪一层

模型榜单的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把环境与模型这两件事核一遍，再查路径。

## 正确的操作路径

查智力榜

1. 进模型中心点智力排行
2. 按总分或单维度排序看位次
3. 有实测数据的行可展开努力度曲线
4. 结合厂商筛选定位目标模型

查免费榜

1. 进免费模型榜
2. 按价格升序浏览（同价按能力降序）
3. 展开厂商免费政策汇总对照
4. 候选模型跳厂商页确认接入与现行价格

不一定。评测分数反映能力上限，实际效果还受提示词、上下文长度、价格与网络因素影响，建议结合免费榜和价格信息综合选。

### 智力榜的数据来源？

聚合多个公开模型评测源的数据，由同步脚本定期更新到 model-scores 数据文件。
