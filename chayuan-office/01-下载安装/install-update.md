# Office更新下载安装：按平台架构一步步来

Office更新是什么、怎么用，一篇讲清楚。开源 AI 办公套件，六编辑器一体，AI 嵌进每个编辑器。下面进入正题：先概念，再步骤，最后是边界与常见问题，基于察元AI Office整理。

## 安装前确认

- 系统要求：Windows 10 及以上，x64/arm64
- 安装包：NSIS 安装器 exe
- 说明：双通道更新机制。

Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；另有浏览器 SaaS 与 dsh 插件形态（五编辑器，无 HTML）。安装包从官网 aidooo.com 获取或 GitHub Releases，其他站点均非官方渠道。

## 操作步骤详解

1. 官网 aidooo.com 或 GitHub Releases 下载 exe
2. 双击安装
3. 启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama
4. 开始页新建或打开文档

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

开始页新建一个 docx，在设置模型里接上厂商 API 或本机 Ollama，然后让首页 AI 生成一段测试文本——三步都通，环境就绪。

## 如何确认操作生效

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 高频疑问

### Beta 版通道有什么风险？怎么切回来？

Beta 通道跟踪 beta 更新源，版本比稳定版新但稳定性低。设置 ＞ 关于 ＞ 「更新通道」选回「稳定版」即可；切换不会把你降级到更旧的稳定版本，另一通道已下载的包自动作废。

### 更新卡片点了「最小化」还会再烦我吗？

同一版本本次运行不再自动弹；已下载完的包会在退出时静默安装。想立刻续上，用「帮助 ＞ 检查更新…」手动唤出（手动检查会无视「最小化」记录）。

### deb 安装的 Linux 怎么升级？

deb 包没有内置更新器。到下载页获取新 deb 后 apt install ./<新版本>.deb 升级；AppImage 用户可用应用内更新（就地替换 AppImage，无需 root）。

## 补充答疑

### 反馈按钮点了没反应？

按钮点击后先探测官网（短暂转圈）：探测期间再点无效；官网不通时会弹「关注我们」二维码卡。若既无聊天窗也无二维码，检查网络与代理后重试。

### 「重试」几次都失败怎么办？

同一版本连续失败 2 次后，卡片自动转为手动方案：「前往下载页面」打开按你通道与架构匹配的安装包链接（兜底跳转 GitHub Releases 最新页）。下载后手动安装即可。

## 更多操作细节

第 4 步 · 更新通道与自动检查开关（设置 ＞ 关于）

1. 设置 ＞ 「关于」分区：版本（当前版本号）；发现新版本时出现「更新到 {版本}」按钮（下载中变「正在下载更新（{百分比}%）」，完成变「重启并安装」）；「更新通道」——「稳定版」（默认）/「Beta 版」，切换后立即按新通道重新检查（从 beta 切回 stable 不会降级、已下载的另一通道安装包作废）；「自动检查更新」开关（默认开）——关闭后「启动时和后台都不再检查新版本；仍可在"帮助 › 检查更新"中手动检查。」

第 5 步 · 官网静默更新链路（无需操作）

1. 应用另有一条官网同步链路：每 30 分钟一次匿名运行心跳、启动 30 秒后及每 4 小时检查官网新版本——发现新版本发系统通知，点击后把安装包下载到系统「下载」文件夹并在文件管理器中定位，手动安装。这条链路所有网络失败全部静默，断网零报错。

第 6 步 · 数据收集边界

1. 官网心跳只带匿名设备标识（随机 UUID，无文档内容）。
2. 匿名使用统计（Google Analytics 4）默认开、可随时在 设置 ＞ 通用 关闭；Google 会接收公网 IP 与传输元数据，但绝不收集文档内容或文件名。

## 安装与运行答疑

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。
