# 对话窗口在哪里打开：AI对话窗口完整走法

AI对话窗口的麻烦不在功能本身，在于信息散。工具调用可视化是它和网页聊天框的本质区别：这篇把它收拢成一条能照着走的路径。

## 概念先对齐

AI对话窗口在察元AI OS里的形态一句话说清：Dock 里的 DeepSeek Harness 是系统主对话窗：多会话多开、流式输出、工具调用全程可视化，会话中随时切换模型（本地与已启用厂商热更新），支持附件。

按真实界面写，按钮文案原样引用。

## 前置条件

- 桌面形态（察元AI OS）：对话窗内嵌本机 dsh 会话服务，随桌面自动启动。web/docker 形态见「形态差异」。
- 模型下拉要有内容，三选一即可：本地已安装对话/图像理解模型（M3 下载 / M4 导入）、已启用云端厂商（M2「保存并启用」）、或经 M9 写入的代理模型档案。
- 本地模型直接选（chatop-local 直连档）需先加载：到 设置 ＞ 模型 点「启动」；未加载就发消息会明确报错（见常见问题 Q2）。选经代理的 local/<id>（local (proxy) 档）则无需预先加载——首调由代理自动拉起（最长 90 秒）。

## 完整操作步骤

1. 打开对话窗

点 Dock 上的「DeepSeek Harness」图标（品牌蓝鲸鱼标）。首次打开窗口显示加载动画「正在启动 DeepSeek Harness…」，就绪后进入会话界面。

2. （桌面形态）全局快捷键唤起

默认 ⌥Space（Alt+Space） 在任何应用里都能唤起/聚焦会话窗：无窗新开、有窗聚焦最近一个、连按在多个会话窗间循环。开关与键位在 设置 ＞ 通用 ＞ 「全局唤起对话」改（仅桌面形态可用）。开机自动打开会话窗：设置 ＞ 桌面与 Dock ＞ 「开机自动打开 Harness」。

3. 认识窗口与多开

窗口工具栏极简：左上红绿灯关/最小化/全屏，居中标题「DeepSeek Harness」，右侧「＋」按钮（悬停提示「新建会话窗口」）——点击再开一个独立会话窗，各窗会话互不影响。没有地址栏。

## 做完后的验证

验证

1. 打开对话窗：标题「DeepSeek Harness」；点「＋」出现第二个独立会话窗。
2. 模型下拉三类来源可见：本地已装模型（装机即用对话档开箱即在）、已启用厂商模型、local (proxy) 档（若做过 M9 应用）。
3. 热更新实测：到 设置 ＞ 模型 把某厂商「停用」＞ 回会话窗下拉里该厂商模型即时消失；重新「保存并启用」＞ 即时回来（提示「已开启，模型下拉框即刻可见」）。
4. 选一个未加载的本地模型发消息 ＞ 收到「本地模型未加载：<名称>。请到「模型」应用（或设置 ＞ 本地模型）中加载后再试」；到 设置 ＞ 模型 「启动」该模型后重发即正常回复。

## 适用场景

日常 AI 对话的第一入口：打开就想聊，不知道从哪个应用进；想知道「智能路由 / smart/auto」是什么、怎么让对话自动分配模型；观察智能体怎么调工具干活；会话里想临时换模型——本地断网用、云端联网用，或换个更强的。

用户常搜的问法：对话窗口在哪里打开？可以开几个；对话里怎么切换模型？本地模型在哪里选。

## 它的局限也要说清楚

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 无显式模型偏好时自动指向本地模型
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 模型下拉里看不到本地模型？

下拉只列已安装的对话/图像理解类模型。若装的是嵌入/重排/语音类，它们不进对话下拉（供知识库/语音用）；若一个对话模型都没有，去模型库下载或导入，完成即在列。

### 选本地模型发消息报「本地模型未加载」？

对话窗直连档（chatop-local）不做自动加载。两个办法：① 到 设置 ＞ 模型 给该模型点「启动」，建议顺手「钉住」防空闲卸载；② 改用经代理的 local/<id>（M9 应用后出现）——未运行时首调自动拉起，等待最长 90 秒。

### 切换模型后，之前的对话还在吗？

在。切模型只影响之后的消息用哪个模型回答，历史记录保留在同一会话里。

### smart/auto / 智能路由在哪开？

设置界面暂无配置页，用第 8 步的 API 配置（或让智能体代配）；未配置 strongModel 时智能路由整体关闭。配置后最省心的用法是开 interceptStrong：会话照常选强模型，轻活自动降级。

### 改了「Harness 连接」地址，旧窗口怎么还连本机？

该设置只影响新打开的会话窗；已开窗口不动。关掉旧窗重开即连远程。

## 更多操作细节

4. 认识模型下拉（三个来源）

会话内的模型选择器列出三类条目：

1. 本地模型：来自「本地模型」提供方，= 本机已安装的对话/图像理解模型，显示名形如 Qwen3.5-4B Q4_K_M（装机即用对话）；
2. 云端厂商模型：你在 设置 ＞ 模型 里「保存并启用」过的厂商模型，状态行就叫「已开启 · 显示在 Harness 模型下拉框」；
3. 代理档案模型：经「应用到智能体」写入的 local (proxy) 档，模型名形如 local/<模型id>、<厂商id>/<模型名>。

## 更多操作细节

5. 热更新表现（下拉实时变化）

1. 厂商侧：厂商卡「保存并启用」＞ 提示「已开启，模型下拉框即刻可见」，勾选的模型实时出现在下拉框，无需重开窗口；「停用」＞ 该厂商模型即时消失，配置保留可随时恢复；
2. 本地侧：下拉数据源是本地已安装清单——模型库下载完成或离线导入登记后进入下拉（不要求已加载）；删除权重后从下拉消失；
3. 列表刷新期间短暂空列表属正常，稍候即回。

## 更多操作细节

6. 会话中切换模型

在模型下拉里直接另选一个模型即可完成切换：历史消息保留，新消息按新选的模型回答。本地 云端可来回切。
