### 额度与对抗方式的坑

天梯对局是动态对抗，对手行为会变，模型必须临场应对，没有固定剧本可背。

天梯挑战是带排位属性的约战玩法：你以挑战者的身份，从天梯榜上按段位物色对手，发起挑战，打完一局按 TrueSkill 规则结算评分，赢者升段。解说有成本：它本身是模型调用，云端解说员每一手点评都在消耗你的 API 额度，长局连开的账单要心里有数，本地解说员零成本但深度有限。

让大模型坐上牌桌这件事，在操作面上不用改任何代码，手册把这条写得很细，省下的折腾够你多看两局。

看不懂的规则细节（为什么这手必须定缺、为什么那样算诈唬），解说也会顺嘴带一句，这些往往才是看懂对局的入口。

误读代走的人最多：它不是纯随机，触发与出招都循章法，这一点文档写得很直白。

气泡与解说各有出处、各有立场，搭着读才看得到里外两层。
