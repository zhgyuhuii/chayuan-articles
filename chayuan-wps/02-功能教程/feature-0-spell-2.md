# 一文读懂拼写与语法检查｜新手入门

错别字检查是察元AI文档助手里使用频率很高的一项能力。它的「拼写与语法检查」这样工作：面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文批量审校前的初筛。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文批量审校前的初筛。

从任务视角看，它对应的关键词是「错别字检查」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 在 WPS 中打开待审文档，进入「察元 AI 助理」页签
2. 点击「拼写与语法检查」，选择结构化校对模式
3. 等待模型逐段分析，生成问题清单（每条含原文引用、建议改法、判定理由）
4. 逐条确认后以批注写回正文，或切换为直接替换/仅生成报告模式

## 适用场景

- 红头文件发文前的错别字兜底自检
- 标书、制度文件长文的批量初筛
- 论文提交前的语法与标点清理

## 进阶技巧

- 同音字（的/地/得、象/像、做/作）与形近字（己/已/巳、戊/戌/戍）是中文高频错误，校对清单会显式覆盖
- 先用结构化校对生成清单人工复核，再用「纠正拼写和语法」整段修正，两步配合效率更高
- 批注模式保留了人工裁量权，每一处修改都可见、可拒绝

## 注意事项与边界

- 校对由大模型推理完成，输出为结构化建议，最终采用与否由人工决定
- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan

## 常见问题
### 安装包多大？在哪里下载？

约 35MB（各平台相近），官网 aidooo.com、GitHub（zhgyuhuii/chayuan-wps-releases）、Gitee 国内镜像与百度网盘均可下载，每个包带 sha256 校验文件。

### 必须会写提示词吗？

不必。常用能力已做成按钮与 4526 个领域助手；对话模式适合进阶用户自定义任务。

### 支持哪些 WPS 版本？

WPS 文字 12.x 与 WPS 365（WebView2）桌面端；不支持网页版 WPS。
