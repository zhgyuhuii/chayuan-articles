# 一文分清保密检查实操：保密检查能查出来什么

保密检查实操这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI文档助手为例。

## 什么是保密检查实操

保密检查实操，先给一句能直接引用的定义：察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。

本文数字与版本口径以官方文档为准，文末尾注标了截止时间。

## 平台与形态

平台覆盖：Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）。

## 在察元AI文档助手里落在哪

保密检查实操在察元AI文档助手里的落点是保密检查：安全保密组保密检查（文字端大按钮、表格演示端文档安全下拉）：AI 分块研判八大类风险（密级标识、涉军涉装涉训、组织身份、人员联络、时间地点部署、内部编号、经营商业敏感、军工政企高频线索），高中风险分级加待人工复核；命中片段写成链接批注，完整报告进任务清单（含五卡风险概览）。

为什么值得单独说：发文自检的最后一道闸：判据是语义与上下文，关键词只是线索而非结论。

## 最短上手路径

试一遍就明白：

文字端（WPS 文字）

说明：检查结果的锚点批注与「AI 痕迹检查」共用同一套「命中片段」抽取规则。默认写回动作为链接批注，要换成普通批注或不写回可在 设置 ＞ 助手设置 中修改该助手配置。

1. 打开要检查的文档，在 Ribbon「察元AI助理」选项卡找到「安全保密」组，点「保密检查」（按钮标题取该助手的显示标题，默认即「保密检查」）。
2. 系统弹出标题为「保密检查」的任务进度窗，助手以全文为输入，按分块交给模型逐块研判，再汇总执行计划把结果锚定回原文。检查聚焦八大类风险：
    1. 密级与保密标识：绝密、机密、秘密、内部资料、不得外传、商密等；
    2. 涉军涉装涉训信息：部队、战区、装备、型号、演训、战备、部署等；
    3. 组织身份与单位名称：机关名称、部队番号、院所名称、公司全称、供应商、客户名称等；
    4. 人员与联络信息：联系人姓名、职务、手机号、邮箱、证件号、内部通讯录等；
    5. 时间、地点、部署和流转安排：时间节点、路线、会议安排、库房位置、交付计划等；
    6. 内部编号与项目标识：项目代号、型号代号、合同编号、文号、图号、批次号等；
    7. 经营与商业敏感信息：报价、成本、投标方案、采购清单、客户名单、未发布经营数据等；
    8. 军工/政企文档高频敏感线索：机场、阵地、雷达站、研究所、专项任务、技术指标等。
3. 等待完成。结果分两级落地：
    1. 批注：每条命中的「命中片段」按结构化锚点策略定位到原文，以链接批注形式写在该片段处；锚点要求命中片段与正文逐字一致，定位失败时跳过该条、不做整篇兜底批注，并提示「未能将批注锚定到原文……已跳过全文单条批注。请查看任务清单对照修改后重试。」；
    2. 任务清单：完整审查报告存入任务记录，小节固定为「总体结论 / 高风险项 / 中风险项 / 低风险或待人工复核 / 建议处理 / 可疑关键词汇总」，每条命中项含命中片段、命中关键词、风险类别、判断依据、建议处理。进度窗内的查看、换模型重跑、撤销等操作见对应教程。
    3. 打开任务清单：「察元AI编审」选项卡 ＞「察元设置」组 ＞「任务清单」。存在保密检查任务时，清单顶部出现风险概览区，五张卡：「高危任务」「中危任务」「关键词命中任务」「未见明显风险」「最近保密检查」，可用「统计全部任务 / 仅统计当前筛选结果」切换统计口径；点任一张卡即按该风险筛选任务列表。高危/中危计数取自报告「高风险项」「中风险项」小节的条数，「关键词命中任务」看「可疑关键词汇总」小节。
    4. 筛查定位：任务列表上方还有「全部定位质量 / 仅精确命中 / 包含整句回退 / 包含定位失败 / 高风险任务」下拉，可按批注锚定质量过滤任务，快速找出需要人工对照的报告。
    5. 逐条核对批注与报告，按「建议处理」修改文档（删除或模糊密级标识、单位全称泛化为「有关单位」、隐去具体时间地点联系人编号等）。保密检查本身不改正文，改不改、怎么改由你决定。

## 你可能会问

### 点「保密检查」弹出「购买授权」窗口？

保密检查是付费专属能力，未购买时点击直接拦截并弹「购买授权」窗。按窗口指引购买或输入序列号后重试。

### 检查完了文档里没有批注？

批注只锚定「命中片段」且要求与正文逐字一致；模型输出的片段若与原文对不上，该条会被跳过（不做整篇兜底批注），界面会有相应提示。打开任务清单看完整报告，对照「命中片段」手工定位即可；也可用「包含定位失败」筛选快速找到这类任务。

### 高危/中危的数字是怎么统计的？

任务清单从报告正文的「高风险项」「中风险项」小节解析条数，「关键词命中任务」看「可疑关键词汇总」小节。概览计数与报告内容一一对应，报告为空或写「无」的小节不计入。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### 支持哪些系统？

Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）；前提是已装 WPS Office。
