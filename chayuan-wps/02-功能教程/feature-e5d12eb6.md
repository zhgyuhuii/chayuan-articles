# 一文打通会议全流程记录法｜会议纪要生成

纪要生成加行动项提取，散会即出任务清单。这套组合工作流把生成标题/摘要/会议纪要→提取行动项/结论与风险串成一条线，在察元AI文档助手里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

纪要生成加行动项提取，散会即出任务清单。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI文档助手的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·生成标题/摘要/会议纪要**：一键生成标题、摘要（可开报告模式）与结构化会议纪要；另有提取行动项、提取结论与风险两个管理向工具。

1. 选中全文或会议记录
2. 选择生成标题/摘要/会议纪要
3. 按模板微调后使用

**第 2 步·提取行动项/结论与风险**：从会议记录、长材料中抽取行动项（谁、干什么、何时）与结论、风险点，输出结构化清单。

1. 选中会议记录/材料
2. 选择提取行动项或结论与风险
3. 清单导出或贴入任务系统

## 衔接点与易错处

- 会议纪要配「提取行动项」可直接产出任务清单
- 风险提取配合人工确认，避免漏判

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 必须会写提示词吗？

不必。常用能力已做成按钮与 4526 个领域助手；对话模式适合进阶用户自定义任务。

### 支持哪些 WPS 版本？

WPS 文字 12.x 与 WPS 365（WebView2）桌面端；不支持网页版 WPS。

### 安装包多大？在哪里下载？

约 35MB（各平台相近），官网 aidooo.com、GitHub（zhgyuhuii/chayuan-wps-releases）、Gitee 国内镜像与百度网盘均可下载，每个包带 sha256 校验文件。
