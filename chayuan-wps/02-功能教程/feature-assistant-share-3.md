# 团队共享助手实战：一个真实场景的完整工作流

很多团队共享助手的教程只讲是什么，不讲怎么做；或者讲了一半步骤，剩下的让你自己悟。这篇反着来：步骤写全、按钮文案原样引用、每步的界面反馈都说清楚，用的是察元AI文档助手（aidooo.com）。

## 解决什么痛点

把自己调好的助手发给同事，或拿到别人的 .json 助手文件想装进来，团队用 chayuan-server 智能空间统一管理文档助手，想在 WPS 里一键同步，把好助手分享到工作群，科室统一公文助手。

用户常搜的问法：怎么把助手发给同事？导入 json 报『导入文件不是有效的助手配置』怎么办；『从智能空间同步』要填什么地址和 token。

## 从打开到做完的每一步

1. 导出助手（分享给别人）

1. 打开设置窗口「助手设置」页，在左栏「助手设置项」里找到要分享的助手。
2. 在该助手条目上右键 ＞ 「导出助手」。
3. 浏览器下载一份 <助手名>.json 文件（内容含 type: "chayuan-assistant"、version: 1、导出时间和完整助手配置），消息条提示「已导出助手“<助手名>”」。
4. 把这个 json 文件发给同事即可——它就是助手的全部配置。

2. 导入助手

1. 在「助手设置」页左栏工具栏点「导入助手」，选择一个 .json 文件。
2. 产品读取并校验：标准导出文件（type: "chayuan-assistant"，也兼容旧 niudang-assistant 包装）取其中的 assistant 配置；格式不对会报「导入文件不是有效的助手配置」。
3. 校验通过即入库：重名自动追加序号，归入其声明的分组（分组不存在会自动创建），消息条提示「已导入助手“<助手名>”」，左栏自动选中它，可立即微调后点「保存」。
4. 另一条路：右键已有助手 ＞ 「复制为新助手」，在本机快速做一个可改的副本（同样自动去重命名）。

3. 从智能空间同步（团队批量分发）

两项会保存到本机设置，下次同步不再询问。

1. 「助手设置」页工具栏点「从智能空间同步」。
2. 首次使用会依次弹两次输入框：
    1. 「请输入智能空间(chayuan-server)地址,例如:http://localhost:7861」（必填，服务器根地址）；
    2. 「请输入访问 token(从 chayuan-client 登录后获取)」（必填，JWT 访问令牌）。
    3. 同步过程消息条实时显示「同步中(N/M):<助手名>」。拉取范围是服务器上的「文档助手」类应用（按 scope 取 mine/shared/public/all，默认 all）。
    4. 合并规则：与本机已有助手按 custom_cy_<appId> 标识匹配——已存在则覆盖更新，不存在则追加；本机自建的其他自定义助手不受影响。
    5. 完成后提示「同步完成:新增 X 个,更新 Y 个,共 Z 个」。若地址或 token 不对，报「同步失败,请检查智能空间地址 / token 是否正确」。

4. 管理 18 个内置增强助手

1. 8 个通用增强（语气调整、通俗化、列表＞段落、段落＞列表、纪要、引文核查、表格＞MD、时间线）+ 8 个领域助手（法务审核、学术摘要、出题、公文规范、医学术语、数字核对、术语对照、抽代码）+ 2 个补充（表格统计、笔记整理），共 18 个，现已直接注册为产品内置助手，在面板侧栏即可使用。
2. 旧版本曾把它们作为「自动安装」副本写进自定义助手列表；当前版本启动时会自动把这些旧副本迁移清理。管理入口在控制台（/control）：「自动安装助手」页签显示「已自动安装」「总可安装数」两个统计与已安装清单，提供「立即安装(force=true)」「全部卸载」「清理卸载标记(允许重新安装)」三个按钮；页面提示原文：「18 个新助手(P3 extra 8 + P5 领域 8 + P5+ 补 2)在首次启动时自动注入到 customAssistants。可在此重新安装或全部卸载;卸载后不会"复活"(用 _uninstallMarker 标记)。」。

## 这些坑和边界要知道

用之前要认的账：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 常见问题

### 导出的助手文件里会不会带我的密钥？

导出内容是助手配置（名称/提示词/参数等），不包含模型厂商的 API Key；收到的同事使用时走他自己配置的模型。

### 全部卸载后这 18 个助手还会自动装回来吗？

不会。卸载时写入了卸载标记，启动迁移不会恢复它们；想再要回来，到控制台点「清理卸载标记(允许重新安装)」再「立即安装(force=true)」，或直接用面板侧栏的内置助手（这 18 个能力本身已内置注册）。

### 「从智能空间同步」一直失败？

按顺序检查：地址是否能访问（浏览器打开 http://<服务器>:7861）、token 是否过期（到 chayuan-client 重新登录复制）、账号对该批文档助手是否有权限（scope 覆盖 mine/shared/public）。修正后重新点「从智能空间同步」。

## 补充答疑

### 导入后名字多了个数字后缀？

本机已有同名助手时自动去重（原名后追加序号），避免覆盖；可在导入后直接改名。

### 导入报「导入文件不是有效的助手配置」？

文件内容不是产品认的助手 JSON——可能是导出时被改动、截断，或拿错了别的配置文件。用文本编辑器确认文件里有 "type": "chayuan-assistant"（或旧版 niudang-assistant 包装）和 assistant 字段后重试。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。
