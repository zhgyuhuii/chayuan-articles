# macOS安装装机指南

先说这篇能帮你干什么：读完能在察元AI OS里独立完成macOS安装，路径是macOS安装。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：Apple Silicon 或 Intel
- 安装包：dmg（ChaAIOS-版本-arm64.dmg / x64.dmg）
- 说明：dmg 拖装与首次启动。

安装包从官网 aidooo.com 获取。

## 一步步来

1. 官网下载 dmg 并打开
2. 把察元AI OS 拖入应用程序文件夹
3. 启动后创建账户进入桌面
4. 模型服务自动加载装机五件套

## 其他平台装法速览

Linux（AppImage）：chmod +x 加执行权限后运行；缺 FUSE 时安装 libfuse2 或改用 --appimage-extract-and-run；免安装形态适合无 root 权限与便携场景。

Windows：官网 aidooo.com 下载对应架构的 exe 安装器；双击安装，零额外依赖；首次启动创建本机账户，进入桌面。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

开机进桌面后，先在对话应用里用本地模型聊一句，再打开应用商店看插件列表能不能加载——两个都通，说明模型服务与网络链路都就绪。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

边界先摆在桌面上：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

把macOS安装放回察元AI OS的整体盘面：桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件，右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；桌面右键录制屏幕。

## 安全与数据边界

安全口径单独立一层：需要提前开启并积累足够记忆数据，管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。

## 平台与形态

平台与形态的账：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；全新安装选数据目录或导入拷贝根，创建管理员，各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。

## 价格与授权

能落到数字上的几条：本地模型解决有无问题，复杂任务还是需要云端旗舰模型；断网时云端模型不可用，可设自动回落本地，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

离线内网这条线的口径：清单可离线导入导出，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；装了什么、开了什么，需要一个总账页面，离线环境靠导出导入搬迁，tar 包离线迁移。
