# 关于能力广场使用问题

## 能力广场使用问题：结论先行

围绕使用，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI 能力广场整理。

### 下载要登录吗

按官方口径归纳：下载量与 star 参照；无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先，智力榜看能力上限，免费榜看成本下限，两张榜定选型策略；单个技能解决单点问题，技能包按岗位工作流整套交付。口径以官网 aidooo.com 当前页面为准。

### 收藏上限多少

登录双通道：站内账号密码加图形验证码、微信扫码（开放平台与公众号带参码）；登录后可完善头像昵称、我的收藏（上限 200 条，新到旧排序）。

要点：会话管理；收藏 200 条上限，双通道登录。

### 榜单多久更新

按官方口径归纳：榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜；导航智能广场分三栏：资源类型装了就用（智能体、MCP、插件、技能、教程库、提示词、技能包）；系统装什么能力从插件开始，分类导航降低选择成本，五维分数人工整理自公开榜单。口径以官网 aidooo.com 当前页面为准。

### 资源失效怎么办

榜单分热门、新品、趋势三个维度：日、周、月、季、半年、年六档周期按 star 增量计算（每日同步抓快照），无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；真实增量数据自 2026-09-15 起积累，此前的周期按星标总量排序并明确标注；失效资源自动剔除出榜。

要点：热门/新品/趋势三维度，六档周期榜单，降级透明标注。

## 再补几个同主题问答

### 广场上的资源是官方出的吗

不全是。广场聚合全球生态资源（含社区作品）与察元官方内容，条目详情页标明来源与安装方式；上架投稿内容经人工审核。

### 不登录能逛广场吗

能。检索与浏览全量开放，下载安装包与收藏需要登录（站内账号或微信扫码）。

### 广场的插件和 OS 应用商店是什么关系

同源。广场是网页版检索入口，OS 商店是桌面端安装入口，内容与更新同步。

### MCP 板块的数据多久更新一次

每日同步任务抓取 star 与状态写快照，榜单随之重算；失效资源自动剔除出榜。

### 为什么同一个 MCP 在不同源名字不一样

多源采集后按仓库地址去重统一展示，个别改名条目以详情页的源站链接为准。

### 技能和插件有什么区别

技能是给智能体的操作手册（SKILL.md 文本包），教它按流程做事；插件是给系统装的新能力模块。一个管「怎么做」，一个管「能做什么」。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找官方入口
- 模型、权限、依赖先检查一遍
- 大小上限、付费范围、平台差异提前读一遍
