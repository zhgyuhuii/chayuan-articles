# 文档问答排错：怎么新建一个知识库

「怎么新建一个知识库」——这个问题最近被问了好几次。答案不复杂：文档问答在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

排文档问答的错，顺序比速度重要：环境与模型先就位，然后对操作路径，最后核边界。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

最短路径走一遍：（第 3 个切入角度）

1. 知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载
2. 混合检索加可选重排保证命中质量
3. 引用式问答每个观点带编号脚注
4. 点脚注跳回原文核对并下载源文件
5. 多库并存
6. 独立存储互不干扰

## 进阶用法与边界

- 多库并存
- 独立存储互不干扰
- 秒建秒删

## 高频疑问

### 文档问答要联网吗

检索引用知识库内容并带出处写进文档；引用带出处插入文档，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。以官网 aidooo.com 当前页面为准。

### 文档问答数据存在哪

知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，资料之间的关系用图看比用列表翻快得多，跨文档的实体关联一目了然，检索引用知识库内容并带出处写进文档。以官网 aidooo.com 当前页面为准。

安全口径单独立一层：隐私敏感环境先关遥测再干活，处置设备前清数据；（本机 MCP HTTP 服务，回环免 token）；敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用。
