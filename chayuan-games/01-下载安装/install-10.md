# 察元竞技场接入Ollama：本地模型免Key上桌

不想为 API 账单花钱也能玩竞技场，而且能玩得很完整。Ollama 这类本地推理服务把模型跑在你自己的电脑上，竞技场接它免 Key，调用零成本，断网照样开局。这篇把竞技场接入Ollama 讲全：配置步骤、免 Key 的原理、断网验证，以及本地模型的真实边界。

## 前置：先把 Ollama 装好

竞技场不管 Ollama 的安装，这一步在 Ollama 官网完成：按其官方指引下载安装你的系统对应的版本，装好后用它拉取你想跑的模型。拉什么模型看你的硬件，小参数模型门槛低，大参数模型吃显存和内存，具体型号的体积与要求以 Ollama 模型库页面为准，本文不转述。

模型拉好之后，Ollama 会在本机提供一个 OpenAI 兼容的接口服务，这就是竞技场能接它的前提。除了 Ollama，LM Studio、Xinference 这类本地推理服务同样免 Key 可接，原理一致，本篇以 Ollama 为例，手里已经有另外两家的人不必重复安装，竞技场对这几个引擎一视同仁。

装 Ollama 本身有几点提醒：按官网指引选对你的系统版本；模型动辄几个 GB，下载前看一眼磁盘余量；拉取时间取决于网速，本地宽带慢的话要有耐心。装好、模型拉好，再去竞技场里做后面的动作。

## 配置步骤：三下就通

进设置 ＞ 模型配置，在厂商目录里点选 Ollama。因为服务跑在本机，配置比云厂商还简单：不需要 Key，也不需要你操心远端地址，确认本机的 Ollama 服务在运行即可。

点「获取模型」，应用会实拉你本机 Ollama 已拉取的模型列表，返回你本地有哪些模型，从中勾选要上桌的。这一步还有个附带的好处：如果列表空了，说明你还没用 Ollama 拉模型，或者它的服务没在跑，等于顺手做了一次体检。Ollama 的配置没有 Key 可填，表单比云厂商简洁不少，这是本机服务的天然优势。

勾选入库后回大厅开局验证：选一款玩法开人机局或机机观战，模型出招时对局室里思维链气泡流式滚出、每手延迟与 token 用量正常标注，链路就通了。

## 选模型：从实拉列表到上桌判断

Ollama 的模型库里可拉的模型很多，给一个务实的上桌顺序。

先小后大：用小参数模型把全流程跑通，确认链路没问题，再根据硬件余量换更大的。先棋后牌：棋类对出招格式相对宽容，先玩五子棋这类完全信息玩法，再挑战麻将、德州这类规则与格式要求更高的。先看后挂：机机观战跑两局看看节奏，每手延迟可接受再考虑挂机跑锦标赛。

判断依据都在界面上：对局室的每手延迟与 token 用量、代走出现得勤不勤、思维链气泡连不连贯。硬件撑不撑得住，跑两局就知道，不用看任何跑分。

## 免 Key 的原理：为什么本地不要凭证

云端厂商要 Key，是因为你调用的是别人服务器上的算力，Key 是计费与鉴权的凭证。Ollama 跑在你自己的电脑上，算力是你自己的，电费是你自己交的，不存在向谁鉴权和计费的问题，自然不需要凭证。竞技场与它之间走的是本机到本机的 OpenAI 兼容接口，整条链路不出你的电脑。

这也带来两个直接的好处：一是零成本，跑多少局都没有 API 账单；二是隐私与离线，模型调用不经过任何第三方服务器，网络断了照样玩。

## 断网验证：一把就能试出来

想知道整条链路是不是真的全本地，验证方法很直接：把网络断掉，回大厅开一局人机局。模型能正常出招、思维链气泡照常滚动、对局能完整打完，说明这条链路没有依赖任何外部服务。想再狠一点，把云端厂商的配置全部停用，只留 Ollama，跑一局机机观战，两台「本机模型」互相打，全程离线。

断网验证要做就做全套：断网前先在设置里确认只有 Ollama 在配置里可用，云端厂商要么停用要么删掉，否则断网后对局调到云端模型失败，验证结果就不干净了。

顺带说一句，断网验证也是排查利器：离线能玩、在线反而卡，问题多半出在网络或云端厂商侧，而不是竞技场配置。验证通过后把网络恢复，想混玩云端厂商时再按需启用。

## 边界与实话

三条说在前面。本地小模型的棋力与出招格式遵守率有限，弱模型会出废招，系统有启发式代走兜底、代走超限判负，整局不会卡死，但观赏性打折，这是模型能力的现实，不是配置问题。硬件决定体验，模型越大每手等待越长，机器跟不上时对局节奏会很慢，选模型时量力而行。另外 Ollama 的安装与模型拉取本身要花你的磁盘空间和时间，模型动辄数 GB，磁盘紧张的话先规划。

还有一条：本地模型的版本更新靠自己，模型库升级后记得重新拉取需要的版本，竞技场里实拉列表看到的才是最新可用项，旧版本不会自己长出新能力。

## 你可能会问

### 断网真的能完整玩吗

能。只配 Ollama 的环境下整条链路都在本机，断网照常开局出招结算，天梯积分照常更新。用云端模型的部分才需要联网。

### 需要什么硬件

取决于你拉了多大的模型，小参数模型普通电脑就能跑，大参数模型需要更强的内存与显卡。以 Ollama 模型库页面的要求为准，先从小模型试起。

### 本地模型能和云端模型同台吗

能。Ollama 的模型与目录厂商的模型一样可以进锦标赛、机机观战，同台规则完全一致，花钱与否不影响赛制。

### 免 Key 是不是意味着谁都能用我的模型

不是。服务跑在你本机，接口只对本机的竞技场进程可用，外部的人够不到你的 Ollama，更用不了你的算力。

### 本地模型会毁掉天梯公平吗

不会。天梯按对手强弱算分，弱模型上桌分数自然上不去，它影响的是观赏体验，不是评分机制。

### 断网时还能看到思维链吗

能。思维链来自模型在本机的输出，与网络无关，离线对局里照样实时流式滚动，体验与在线时一致。

### 一台电脑能同时接几个本地服务吗

能。Ollama、LM Studio、Xinference 各自是独立服务，竞技场里分别配置即可。但同机跑多个推理服务对硬件是个考验，按需启用最实际。

Ollama 这条路是竞技场里成本最低的玩法：零账单、可离线、数据全在本机。代价是模型能力上限由你的硬件决定，想跑多强的模型，先看看自己机器的诚意。想要云端强模型的完整体验，回头看本系列各厂商接入篇；想先零成本玩起来，今天就装 Ollama。
