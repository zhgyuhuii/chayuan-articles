# Docker部署装机指南：培训机房批量部署

Docker部署这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决团队统一 AI 工位。

## 安装前确认

- 系统要求：任意可跑 Docker 的服务器
- 安装包：docker compose（察元AI工舱形态）
- 说明：工舱形态一条命令起服务。

安装包从官网 aidooo.com 获取。

## 一步步来

1. 获取 docker-compose.yml
2. docker compose up -d 启动
3. 浏览器访问默认 52584 端口得到多用户网页桌面
4. 账户隔离，数据在服务器侧统一管理

## 其他平台装法速览

Linux（deb）：按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64；sudo dpkg -i 安装 deb 包；应用菜单启动，首次启动自动初始化数据目录。

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥。这两件事做完，这台机器才算真正就绪。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 几个容易忽略的细节

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 更多操作细节

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

## 更多操作细节

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 补充答疑

### 云桌面和桌面版功能一样吗？

核心能力面一致（对话、知识库、模型、办公），形态差异在：云桌面无本地文件直通、语音输入依赖浏览器权限、部分外设在浏览器里受限。

### 多少人共用一台服务器合适？

取决于是否同时跑本地模型：只做对话与知识库，十几人一台中配服务器可行；要并行跑本地推理，按并发数加内存或改用厂商模型分流。

### 数据存在哪里？

全部落在服务器的数据卷里（含用户空间、知识库、配置），挂载出来后备份一个目录等于备份全组。

## 这几条能力放一起看更清楚

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 放回产品盘面看

把Docker部署放回察元AI OS的整体盘面：知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，点击互跳定位原文；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 安全与数据边界

安全口径单独立一层：拖拽上传 txt、md、html、docx、xlsx、pdf；就触发 kb_search、kb_list、kb_read_doc 工具链；断网可用、数据不出本机；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。

## 平台与形态

平台与形态的账：GGUF、whisper 权重可以按路径直接导入（零拷贝）；whisper 语音权重同样支持，local 星号开头的本地模型未运行自动加载，内置浏览器窗，配合 webwindows 可被智能体驱动。

## 价格与授权

价格口径一并交代：Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；（本机 MCP HTTP 服务，回环免 token）。

## 产品家族与搭配

察元AI OS不是单打独斗：docx/xlsx/pdf/csv/html 与扫描件 OCR，单文件不超过 48MB，GGUF、whisper 权重可以按路径直接导入（零拷贝）；whisper 语音权重同样支持，local 星号开头的本地模型未运行自动加载。

## 几条硬数字

能落到数字上的几条：多个大模型开始围绕它讨论，单个模型有偏好也有盲区；让几个模型围绕同一命题各自作答或接力深化；模型直跑宠无角色卡也能入群。

## 离线与内网

离线内网这条线的口径：显式的加载卸载加自动卸载策略是本地模型的生存之道；可选自动（本地优先）或指定；润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱，自动模式本地优先。
