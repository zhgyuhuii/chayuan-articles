# 轻量包是什么：模型配置可一键写入五家

先说这篇能帮你干什么：读完能在察元AI OS里独立完成轻量包，路径是轻量包。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：约 1GB 起步、模型后补的路线。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥。这两件事做完，这台机器才算真正就绪。

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 几个容易忽略的细节

用之前要认的账：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 放回产品盘面看

把轻量包放回察元AI OS的整体盘面：换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力，本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。

安全口径单独立一层：全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583）。
