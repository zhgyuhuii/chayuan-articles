# 能力广场 vs 通用搜索引擎找 AI 资源（选型指南）

能力广场 vs 通用搜索引擎找 AI 资源，是很多用户在选型阶段绕不开的问题。这篇选型指南不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（能力广场） | 对照方案 | 说明 |
|---|---|---|---|
| 结构化 | 八板块+标签+筛选，字段统一 | 结果零散质量参差 | 元数据站的价值 |
| 安装 | 每条带安装命令/配置片段 | 要自己满网找仓库 | 从发现到安装一步 |
| 时效 | health 状态机标注失效 | 旧文章照排前面 | 失效透明 |

## 逐项解读

**结构化**：元数据站的价值。能力广场侧的做法是「八板块+标签+筛选，字段统一」，对照方案为「结果零散质量参差」——差异的本质在于设计取向不同，而非优劣。

**安装**：从发现到安装一步。能力广场侧的做法是「每条带安装命令/配置片段」，对照方案为「要自己满网找仓库」——差异的本质在于设计取向不同，而非优劣。

**时效**：失效透明。能力广场侧的做法是「health 状态机标注失效」，对照方案为「旧文章照排前面」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

系统化找资源用能力广场；单点冷门问题搜索引擎补充。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 常见问题
### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

### 支持英文吗？

全站中英双语，资源条目双语展示，英文关键词搜索覆盖更广。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。
