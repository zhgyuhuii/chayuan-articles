# 察元OS断网能用吗常见问题合集：答案结论先行

## 察元OS断网能用吗：结论先行

围绕离线能力边界，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI OS（版本 3.1.15，aidooo.com）整理。文末附预防清单，多数问题的根子都在那三条里。

### 断网哪些功能可用

开启后从记忆、便签、日程等抽取事实卡（不足 3 张判不可用），忘记密码时本地 AI 面试官出题，答对即可重置；3 次失败冷却 24 小时。

要点：本地 AI 出题验证；失败冷却防爆破，事实卡自动抽取。

边界：需要提前开启并积累足够记忆数据

### 完全断网 / 所有源都下载失败怎么办？

断点已保留，联网后点「继续下载」从断点续传。彻底离线的机器：在任意联网电脑按帮助中心「离线下载与导入」的直链下载权重文件（U 盘/内网搬运）放到本机，再用「我的模型 ＞ ＋ 添加模型」按路径导入（不复制文件、原路径引用）。

### 内网如何升级版本

三类装法：npm 包一键安装升级（Claude Code、Codex 等 13 家，带图标与版本管理）；Cursor CLI 等走官方安装脚本；Aider、Goose 自行安装后自动探测上架。未装的显示官网指引，装完入 Dock 开窗即工作台。

要点：自装自动探测；5 秒感知上架，官方脚本两家。

### 涉密单位使用的边界

知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成。

要点：支持重算，文档实体二部图，点击互跳定位原文。

## 关于察元AI OS

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。官网 aidooo.com。

## 边界速览

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 数字口径

- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness
- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商
- 86 个 MCP 工具（2026 年 10 月实测）

## 云桌面形态

整套系统可无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离，数据在服务器侧统一管理。默认只监听回环端口，暴露面完全自己控制，适合团队统一供给算力与知识库。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 统一模型代理的用法

全部模型走一个本机回环地址（127.0.0.1:52581）对外服务：OpenAI chat、responses 与 Anthropic messages 协议互转，对话、嵌入、重排、语音端点齐备。智能体和其他软件只需指向这一个地址，本地模型没运行会自动拉起，厂商请求自动转发云端。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 应用商店与离线分发

商店对接能力广场（aidooo.com），插件、技能、MCP 插件、智能体、技能包五类内容在线下载并云端推送更新，配排行榜辅助选型。内网环境走 .cop.tgz 离线包导入：导出即依赖闭包，导入逐文件校验，断网也能完成分发。
