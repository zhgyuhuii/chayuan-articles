# AI工作站部署决策指南：Docker 服务器形态 vs 桌面安装

Docker 服务器形态 vs 桌面安装，是很多用户在选型阶段绕不开的问题。这篇选型指南不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（察元OS） | 对照方案 | 说明 |
|---|---|---|---|
| 硬件 | 服务器跑 Docker 共享一台 | 每台机器各自安装 | 团队看服务器 |
| 访问 | 浏览器打开即用 | 本地体验完整 | 图形体验桌面更强 |
| 管理 | 集中管理数据 | 分散各机 | 运维集中化 |

## 逐项解读

**硬件**：团队看服务器。察元OS侧的做法是「服务器跑 Docker 共享一台」，对照方案为「每台机器各自安装」——差异的本质在于设计取向不同，而非优劣。

**访问**：图形体验桌面更强。察元OS侧的做法是「浏览器打开即用」，对照方案为「本地体验完整」——差异的本质在于设计取向不同，而非优劣。

**管理**：运维集中化。察元OS侧的做法是「集中管理数据」，对照方案为「分散各机」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

个人桌面版；团队/服务器资源复用上 Docker。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 常见问题
### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。
