# PDF预览实操教程：从入口到完成每一步都有反馈

被PDF预览折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI OS为准。

## 先弄清楚它是什么

察元OS 为各类文件内置的一组查看/编辑器：文本编辑（纯文本）、PDF 预览、图片查看、文件查看（未知格式兜底）、Markdown 预览、代码编辑（Monaco）。双击文件时由关联表自动路由到对应查看器；Office 六类文档（.docx .xlsx .pptx .md .markdown .html .htm .pdf）默认被察元AI Office 接管，本篇这些查看器可用「打开方式」选用或设为默认。

打开即看，不挑格式，系统级默认打开体验。

入口、步骤、验证三段看清，这事就顺了。

## 先确认这些再开始

- 桌面形态（察元AI OS）。文件来自察元文件系统。
- 代码编辑与画图仅桌面形态可用（依赖桌面 edit:// 协议）；网页形态打开会停在「编辑器加载中…」。
- 从 Dock/应用管理直接打开任一查看器（不带文件）显示空态引导；正常用法是在文件管理/桌面双击文件进入。

## 从打开到做完的每一步

第 0 步 · 先弄清「双击会进哪个应用」（关联表）

双击文件的解析顺序：扩展名默认覆盖（你设过的）＞ Office 接管表（.docx .xlsx .pptx .md .markdown .html .htm .pdf ＞ 察元AI Office）＞ 内置种类表 ＞ 兜底「文件查看」：

换开/改默认：桌面目录中的文件用桌面图标右键 ＞「打开方式」（当前默认带「默认」徽标；底部「设为默认」按扩展名记住选择）；任何扩展名的默认可在 设置 ＞ 默认应用 ＞「文件扩展名默认」 查看/清除（清除后回内置规则）。窗口标题即应用名（Dock 里同名图标）。

| 文件类型（扩展名示例） | 默认应用 |
|---|---|
| .txt .csv .log .ini .cfg .conf .env .properties | 文本编辑 |
| .png .jpg .jpeg .gif .webp .svg .bmp .ico .heic .heif .jxl .tif .tiff .qoi .avif | 图片查看 |
| .mp3 .wav .m4a .flac .ogg .aac .oga / .mp4 .mov .webm .mkv 等 | 媒体播放器 |
| .js .jsx .ts .tsx .json .css .py .go .rs .sh .sql 等 | 代码编辑 |
| 其余未知格式 | 文件查看（兜底） |

文本编辑（TextEdit）

1. 入口：双击文本类文件（上表）；或 Dock「文本编辑」直接开一个空白编辑器。
2. 窗口顶栏：红绿灯 | 文件名输入框（居中，可直接改名；未命名时占位「未命名.txt」）——文件名后有改动时出现蓝色小圆点（提示「已编辑」）| 右侧「保存」按钮（有改动时蓝色高亮）。
3. 正文是等宽字体多行编辑区，占位「开始输入…」；读取失败显示「读取文件内容失败。」，解码失败显示「解码文本文件时出错。」。
4. 保存链：点「保存」——文件名没改：内容覆盖写回原路径，按钮短暂显示「已保存！」；文件名改了：先重命名文件再写回新名字的路径。保存失败显示「保存失败」。注意：从 Dock 直接打开的空白编辑器没有关联磁盘文件，点「保存」只清除未保存标记，不落盘——要写真实文件请从「我的电脑」双击打开（或在 Office 里建新文档）。
5. 关闭保护：有未保存改动时点红色关闭钮，弹确认「您有未存储的更改。仍要关闭吗？」，确认后才关窗。

PDF 预览（PDFViewer）

1. 入口：.pdf 双击默认进察元AI Office（接管表）；要用本应用：桌面图标右键 ＞「打开方式」＞「PDF 预览」，或在 设置 ＞ 默认应用 把 .pdf 默认改过来。
2. 窗口顶栏显示文件名，正文用内嵌渲染引擎显示 PDF；空态显示「在文件管理中双击文件即可在此打开预览。」。本应用只做预览，无批注/编辑（编辑去 Office）。

图片查看（ImageViewer）

1. 入口：双击图片文件（上表扩展名）；空态提示「在文件管理中双击文件即可在此打开预览。」。
2. 顶栏右侧四个控件（自左到右）：「−」（缩小，悬停提示「缩小」）、比例显示（「适配」或 100% 等）、「+」（放大，悬停「放大」）、「适配」按钮（悬停「适配窗口」）。
3. 缩放档位：以 25% 为步进，25%–800%；「适配」= 按窗口自适应（默认态）。
4. 软解码格式：heic/heif/jxl/tif/tiff/qoi 不被浏览器原生支持，打开时先显示「解码中…」，由内置解码器转出后再显示；失败显示「无法解码此格式」。png/jpg/gif/webp/avif/svg 等原生直出。
5. 想编辑图片：桌面图标右键 ＞「打开方式」＞「画图」。

文件查看（BinaryViewer，兜底）

1. 入口：双击没有内置查看器的未知格式文件。
2. 窗口只展示元信息：文件名、大小（字节）与提示「没有内置查看器可以预览该文件，你可以下载到本地处理。」，下方蓝色「下载」按钮把文件取回本机用别的软件处理；空态同样提示双击进入。

Markdown 预览（Marked）

1. 入口：.md 双击默认进 Office；预览走桌面图标右键 ＞「打开方式」＞「Markdown 预览」（或改 .md 默认）。空态提示「在文件管理中双击 .md 文件即可在此预览。」（该提示写于 Office 接管之前，现状以关联表为准）。
2. 渲染：GitHub 风格 Markdown（GFM、换行即断行），正文经安全过滤后渲染；加载中显示「加载中…」，失败显示「加载失败: <原因>」。只读预览，编辑用 Office 或代码编辑。

代码编辑（MonacoEditor）

1. 入口：双击代码文件（.js .jsx .ts .tsx .json .css .scss .less .py .go .rs .java .c .sh .sql .vue 等，按语言自动高亮）；Dock 图标名为「代码编辑」。
2. 窗口 = 标题条（文件名）+ 编辑器自带工具条：文件名（有未保存改动时后缀 —）、语言标识、内容大小 | 右侧三钮：⏎（自动换行开关，选中高亮）、Format（格式化，快捷键 ⌘/Ctrl++F）、Save（保存，快捷键 ⌘/Ctrl+S；无改动时禁用）。
3. 保存链：⌘S 或 Save ＞ 内容写回文件原路径，窗口下方浮出提示「已保存」（失败「保存失败: <原因>」）；读取文件失败显示「读取失败: <原因>」。保存只写回原文件，不做另存。
4. 格式化（Prettier）：支持 js/jsx/mjs/cjs/ts/tsx/json/css/scss/less/html/htm/md/markdown/yml/yaml/graphql/gql；不支持的格式（py/go/sh 等）点 Format 无动作；格式化出错浮出「格式化失败: <原因>」。
5. 主题跟随桌面深浅色；小地图（minimap）默认关闭。

## 做完后的验证

验证

1. 「我的电脑」双击一个 .txt：打开文本编辑，顶栏文件名与正文一致；改一行 ＞ 点「保存」＞ 按钮显示「已保存！」；重新双击该文件内容已更新。
2. 双击一个 .js：进入代码编辑，工具条显示语言 javascript；改一行后 Save 变为可点，⌘S 后浮出「已保存」。
3. 双击一张 .heic：先显示「解码中…」，随后出图；点「+」两下，比例显示从「适配」变为具体百分比。
4. 桌面图标右键一个 .md ＞「打开方式」＞「Markdown 预览」：渲染出标题/列表等格式。

## 适用场景

快速看图、翻 PDF、预览 Markdown、改几行文本或代码，不想另装软件；双击文件想看清它到底会用哪个应用打开、能不能换，快速看文档；某个奇怪格式的文件双击后进了「文件查看」，想知道那是什么。

用户常搜的问法：双击 .md 文件打开的是 Office，怎么改成 Markdown 预览；代码文件在察元里能用什么编辑？有格式化吗。

## 你可能会问

### 从 Dock 打开的「文本编辑」写的东西保存后找不到了？

Dock 直开的文本编辑没有关联磁盘文件，「保存」不落盘。请从「我的电脑」双击文件进入编辑；新建文件用「我的电脑」空白右键「新建文本文档」。

### Monaco 的 Save 按钮是灰的、⌘S 没反应？

Save 只在有未保存改动时可用（工具条文件名后出现 — 即为有改动）。⌘S/⌘F 需要编辑器区域持有焦点——点一下编辑区再按。

### 双击 .md / .pdf / .html 打开的是察元AI Office，不是本篇的预览器？

这是默认接管（Office 六类文档，2026-09-25 起）。想用内置预览：桌面图标右键 ＞「打开方式」本次换开，或「设为默认」/设置 ＞ 默认应用按扩展名改默认（如 .md ＞ Markdown 预览）。

### 图片显示「无法解码此格式」？

该文件扩展名在软解码名单内（heic/heif/jxl/tiff/qoi）但内容解码失败，或文件损坏。可用「我的电脑」右键「下载」取回本机，用系统图片工具打开确认文件本身。
