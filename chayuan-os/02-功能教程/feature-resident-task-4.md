# AI定时执行：AI 桌面操作系统，别再瞎试

「怎么让察元OS 每天定时帮我干活」——这个问题最近被问了好几次。答案不复杂：AI定时执行在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

AI定时执行的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把桌面形态（察元AI OS），设置左栏有「常驻任务」分区（分区标题「常驻任务（Always-on）」）。核一遍，再查路径。

## 高频故障与对策

### 任务失败，通知里只说「失败」，细节哪里看？

三处任选：任务行 悬停状态、「历史」里的错误摘要、~/always-on/ 报告的「失败原因」小节全文。

## 正确的操作路径

第 4 步 · 运行与控制（行内按钮）

1. 「立即运行」（琥珀色）：不等排程马上跑一次，页面提示「已触发运行…」；
2. 「暂停」/「启用」：暂停后不再排程（下次运行时刻清空），重新启用时按排程重算下次时刻；
3. 「编辑」：重开同一张表单（标题「编辑常驻任务」）改任意字段；
4. 「删除」：直接移除该任务（无确认弹窗）；
5. 行首下拉「未绑定灵宠」：选中一只灵宠即绑定（换绑时原灵宠自动解绑），任务执行时灵宠上桌+气泡，见对应教程。
6. 自动排程：后台调度器每 60 秒扫描一次，到点自动执行；间隔型=上次排程点 + N 分钟，每天型=下一个该 HH:MM（严格晚于当前时刻）。

第 5 步 · 看结果（三个去处）

1. 通知中心：每次结束推一条来源「常驻任务」的消息，标题「〈任务名〉 · 完成/失败」，正文为结果/错误摘要（最多 200 字）；
2. 运行历史：任务行「历史(N)」按钮展开最近 8 条（/ + 完成时间 + 报告文件名，悬停可见完整报告路径；全局历史保最近 100 条）；
3. 报告文件：每次运行写 〈用户主目录〉/always-on/〈任务名〉-〈时间戳〉.md，内含「〈任务名〉 · Always-on 运行报告」、任务 ID 与排程、起止时间与耗时、所用模型、状态（完成/失败）、任务指令与完整执行结果（或失败原因）。

## 做完后的验证

验证

1. 新建一个每 60 分钟、指令「用一句话报时」的直跑任务，点「立即运行」：约几十秒后任务行出现 ，通知中心出现「〈任务名〉 · 完成」。
2. 点「历史(1)」：列出一条 记录，悬停显示 ~/always-on/ 下的报告路径；用「我的电脑」打开该文件能看到完整报告（模型、耗时、输出全文）。
3. 把排程改成「每天定时」并填一个 1 分钟后的 HH:MM：等约 1–2 分钟（调度器 60 秒扫描一轮）应自动执行一次。

## 高频疑问

### 间隔最短/最长能设多少？

「每 N 分钟」合法范围 1–10080 分钟（一周）；「每天定时」为 HH:MM 24 小时制。超出范围保存时报「名称/指令/排程不合法」。

### 任务会不会偷偷动我的文件？

模型直跑是无工具的无头调用（只生成文本，不做写动作）。智能体方式按所选智能体自身的能力与权限在你的工作区目录下执行，建议给定时任务指定专用工作区以收敛影响面。

## 动手前再核对一遍

- 桌面形态（察元AI OS），设置左栏有「常驻任务」分区（分区标题「常驻任务（Always-on）」）。
- 模型直跑方式：本机模型代理需在运行（随模型服务自启，127.0.0.1:52581）；任务未单独指定模型时用全局默认对话模型。
- 智能体方式：当前仅支持 Codex / Claude Code / OpenCode 三家无人值守执行（下拉也只列这三家），需先装好对应 CLI。执行一律经本机模型代理路由（免 key，不用 CLI 自家的海外登录态）；任务选的模型会传给智能体（Codex / Claude Code 以命令行参数指定，OpenCode 经环境注入）。
- 可选：绑定一只灵宠，任务执行时它会上桌流式展示输出、结束弹结果气泡。
