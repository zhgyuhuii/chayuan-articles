# 察元OS v0.1.61-0.1.65 更新解读：引擎二进制入库、Milvus 双选型

v0.1.61-0.1.65（2026-09-18/19）带来了 3 项主要更新。这篇解读把每项更新「翻译」成使用层面的变化，并给出升级建议。

## 本版主要更新

- 引擎二进制入库、Milvus 双选型
- 产物改名 ChaAIOS-*、安装名「察元AI OS」
- KB 问答对话化+对外 REST、多智能体共享记忆、对接官网检查更新

## 值得展开说的一处

以「引擎二进制入库、Milvus 双选型」为例：它解决的是此前用户反馈集中的场景。升级后建议第一时间验证这个场景——如果它正是你的痛点，这一版就值得升；如果你的工作流不涉及，也可以观望一个补丁版本再升。

## 升级建议

1. 升级前备份用户数据目录（各产品数据目录见官方文档）
2. 从官网 https://aidooo.com 或对应发布渠道获取新版安装包
3. 覆盖安装，完成后验证常用链路
4. 如有问题，用备份目录回滚到旧版

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- Docker/云通道等进阶形态需要一定动手能力

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。
