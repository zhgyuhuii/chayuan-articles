# 一文打通国产化办公岛｜信创

麒麟/UOS 上的完整 AI 桌面。这套组合工作流把macOS 风格桌面→察元智能广场→本地模型服务串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

麒麟/UOS 上的完整 AI 桌面。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·macOS 风格桌面**：菜单栏 + Dock + 可拖拽多窗口的桌面体验：开机动画→锁屏→桌面三阶段，自动锁屏（Ctrl+L）、会话恢复、任务切换器（Alt/⌘+Tab）、通知中心、小组件面板、托盘驻留。

1. 启动进入锁屏，解锁进入桌面
2. Dock 点击启动应用，拖拽调整位置
3. Ctrl/⌘+Tab 切换任务，Ctrl+L 手动锁屏

**第 2 步·察元智能广场**：内嵌 aidooo.com 能力广场的桌面应用：离线时回落本地页；与网页版同源，检索 2.5 万+ 插件/技能/MCP/提示词/模型资源。

1. Dock 打开察元智能广场
2. 搜索或按板块浏览资源
3. 复制安装命令到终端执行

**第 3 步·本地模型服务**：llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。

1. 模型服务应用里浏览模型库
2. 显式加载需要的模型
3. 用完卸载释放内存

## 衔接点与易错处

- 会话恢复保留窗口布局，重启不乱
- 与网站账号体系打通
- 装机五件套已覆盖对话/嵌入/重排/语音全链路

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。
