# U盘搬运安装：隔离环境的标准搬运姿势

隔离内网里装这套系统，网络指望不上，一切靠 U 盘来回搬。这篇把U盘搬运安装的路径讲清楚：外网侧取什么、U 盘怎么准备、内网侧怎么导入，口径基于察元AI OS。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：隔离环境的标准搬运姿势。

内网侧的安装包由 U 盘从外网侧搬入，源头仍是官方渠道。

## 完整操作步骤

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## U 盘本身怎么选

权重文件动辄数 GB，U 盘要挑容量够、写入速度不拖后腿的；文件系统建议 exFAT——FAT32 单文件上限 4GB，4.7GB 的全量包根本放不下。搬完在目标机做一次校验（对照源机的哈希值），确认搬运过程没损坏文件。

## 外网侧到内网侧的流程

流程分三段：外网机器上从官方渠道取安装包与权重文件；U 盘中转，拔插之间留意查毒策略，隔离环境通常对移动介质有门禁；内网机器上先装主体，再走零拷贝导入权重。每段完成都做一次记录，出问题时能定位到段。

## 导入后的核对

导入完成别急着拔盘：先在设置里扫一眼模型列表，确认搬运的权重被识别；再试一次断网对话，本地链路通了才算搬运闭环。识别不到权重，多半是目录层级放错或文件损坏，回到外网侧重新核对哈希再搬一次。

## 摆渡机的角色

严格隔离的单位往往设有专门的摆渡机：外网文件先进摆渡机查毒，再写盘。有这道流程就别跳过，直接把 U 盘插内网机器看似省事，一旦带进去东西，追责与清理的成本远高于多走一道流程。摆渡机没装相应查毒能力时，至少在外网侧对文件做一次哈希记录，内外两份哈希对得上再导入。

## 搬运记录留痕

每次搬运留一行记录：日期、文件名、版本、哈希前几位、经手人。记录不为应付检查，是为了出问题时能回溯——某个版本在内网表现异常，翻记录就知道当时搬了什么、走的哪条路。隔离环境里信息本来就少，这点留痕的价值比联网环境大得多。

## 搬运前认下的几条线

- 龙芯暂无支持；视频生成本地不提供，经云端路由实现
- 调用云端厂商模型，得自备 API Key（需要相应平台的 Key，部分有免费额度）
- 设备内存 8GB 时，一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态，需要动手能力垫底

## 灵宠与可见性

后台的 AI 借灵宠化作桌面上有形的小生物；改配置走右键编辑，删除操作设了两步确认，外来落户的野宠经收编即可成为正式灵宠并留档；定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见。

## 主题包与更新

灵宠商店的主题页签里，场景背景、36 图标皮肤与灵宠皮打包成套装一次装齐；更新入口在设置的关于页，点检查更新、下载、重启即完成安装；服务端单台支撑全组，运维面只有一处，终端侧零安装负担；断网可用、数据不出本机。

## 零拷贝导入与包体积

彻底隔离的内网下载无门，模型权重只能靠 U 盘一趟趟搬，系统为此配了零拷贝导入来收尾；全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；首次安装时既可指定数据目录，也可导入拷贝根，管理员账号随后建好；每家智能体是否支持一键安装、可否写入模型、收不收系统技能、接不接 MCP、开不开记忆采集，能力矩阵逐项列明。

## 跨机授权的给法

对配对终端开模型加知识库授权；资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问，授权按终端逐台给；本机的 Stable Diffusion 出图全程离线完成。

## Office 联动的检查

知识库在 Office 或 WPS 里引用不出来的话，问题多半落在服务没起或端口被占上，按三层检查逐层过一遍，具体卡点就能现身。

## 模型回落的设置

想换默认模型随时可以在设置里重跑向导，不用重装；本地模型负责兜住有无，真正重活还得云端旗舰模型出面；断网时云端链路即告失效，好在能设成自动回落本地模型；内存预算定档这事先交给模型库，能跑、勉强、跑不动三档标记它替你分好。

## 本地优先的加载行为

自动模式本地优先，local 星号开头的本地模型未运行自动加载；本地模型按需自动加载，会话中随时切换模型（本地与已启用厂商热更新）。

## 知识库的建立与导入

单开一只灵宠不进群也能深聊，把知识库绑到会话上，回答便带着出处；三级知识库优先级；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事。

搬运这条链路走顺一次，之后每次隔离环境更新都照方抓药：取包、校验、导入、验证，四步一个不省。
