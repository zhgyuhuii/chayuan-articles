## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：重跑安装器即可升级到最新版，配置保留

## 相关报错速查

- 搜不到想要的资源？——尝试更换关键词（中英双语都试）、放宽筛选；确实未收录的资源可通过投稿页提交，进入人工审核队列；也可询问右下角机器人客服。
- 登录提示验证码错误或会话过期？——验证码区分大小写以页面提示为准；会话过期重新登录即可，收藏与投稿数据都在账号下不会丢失。
- 投稿没有通过审核？——常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 政企可私有化部署（Docker），数据自主可控

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。

### 资源数量有多少？

能力广场总条目 2.5 万+（站方口径，页面实时计数展示）；教程库 2.1 万+ 条；技能包 311 个；助手目录 4526 个助手/228 个领域；API 价格表 40 厂商 201 个模型条目。

### 智力榜的分数哪来的？

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。
