# 模板管理上手指南：照着做十分钟跑通

模板管理这件事，说简单也简单，说麻烦是真麻烦——麻烦不在功能本身，在于信息散落在各处，拼出一个完整流程要查好几篇资料。这篇文章把它一次讲全：是什么、入口在哪、具体步骤、边界在哪，全部基于察元AI文档助手的真实界面。

## 是什么与为什么

「模板管理」四件套维护一份本机文档模板库：把当前文档连同表单规则一起另存登记（导出模板）、把外部文件收进库（导入模板）、从库中复制一份开新文档（从模板新建）、把库中模板拷出到任意位置（下载模板）；「规则管理」的「规则导入／导出规则」则把表单规则集单独存成 .aidooo 文件在同事间流转。

模板与规则是团队资产，导入导出让资产流动。

先把这个定位立住，再看步骤。

## 前置条件

- WPS 文字端，「察元AI编审」选项卡（表格/演示端另有「从模板新建」入口按钮，对话框内按宿主过滤模板）；加载项已启用；
- 全部为本地功能，不需要模型；规则集落盘位置由 设置 ＞ 数据设置 决定。

## 操作步骤详解

1. 「导出模板」：当前文档另存并登记

1. 在哪：「模板管理」组点「导出模板」。
2. 看到什么：先静默把当前规则库写入本文档，再弹出「另存文档」对话框（默认文件名 = 当前文档名 + .aidocx，筛选「察元文档 (.aidocx)」「Word文档 (.docx)」，扩展名缺省自动补 .aidocx）。
3. 选好位置保存后：弹「文档已另存为：」+ 完整路径；同时该文件自动登记进本地模板库（按文件名去扩展名登记，登记失败不影响导出）。之后「从模板新建」里直接能选到它。没打开文档时提示「请先打开文档」；另存失败提示「另存文档失败：+原因」。

2. 「导入模板」：把文件收进模板库

1. 在哪：点「导入模板」。
2. 看到什么：弹窗「导入模板」（420×420），说明文字「选择模板文件（.docx / .xlsx / .pptx / .aidocx），将添加到本地模板库；从模板新建与 AI 生成时可从此处选择，模板类型须与当前文档类型一致。」
3. 做什么：点「选择模板文件」（执行中显示「添加中...」）选文件（支持 .aidocx/.docx/.doc/.xlsx/.xlsm/.et/.pptx/.ppsx/.dps）。成功提示「模板已添加到本地模板库」；下方「已保存的模板（共 N 个）」清单逐条显示类型徽章（文字/表格/演示）、名称与「×」删除（删的是登记项，不删磁盘文件）。库为空时显示「暂无模板，请点击上方按钮添加」。

3. 「从模板新建」：复制一份开新文档

1. 在哪：点「从模板新建」（表格/演示端为各自选项卡上的同名入口）。
2. 看到什么：弹窗「从模板新建文档」（表格端「…新建表格」、演示端「…新建演示」；420×480），说明「选择模板将复制一份打开并标记为新建；保存时会提示另存为新文件」。清单只显示与当前宿主同类的模板，末尾固定一项「空白文档／空白表格／空白演示」；没有同类模板时提示「暂无本类模板，可直接创建空白文档，或在「导入模板」中添加」。
3. 做什么：点选一个模板（或空白项）＞ 点「新建」（执行中「创建中...」）。产品行为：复制模板副本再打开、写「新建未保存」标记——绝不留空的新文档；成功提示「已创建：〈名称〉」（经系统级打开时追加「（系统打开，请点击该文档继续）」）。类型不匹配的模板会被同宿主闸门拦下并给出切换宿主指引。之后点保存会自动弹另存为，避免覆盖模板母本。

4. 「下载模板」：把库中模板拷出去

1. 在哪：点「下载模板」。
2. 看到什么：弹窗「下载模板」（420×500），说明「从列表中选择一个模板，点击确定后选择保存位置」；清单即本地模板库（与「导入模板」同一份），空时提示「暂无模板，请先在「导入模板」中添加 .aidocx 模板」。
3. 做什么：选中模板 ＞ 点「确定」（执行中「下载中...」）＞ 弹系统另存对话框（筛选「Word文档 (*.docx)」，默认名 = 模板名 + .docx）＞ 模板文件被复制到你选的位置。取消另存则不做任何事。

5. 「导出规则」：规则集存成 .aidooo 文件

1. 在哪：「规则管理」组点「导出规则」。
2. 看到什么：弹窗「导出规则」（420×480）：顶部搜索框（占位「按名称、标签搜索...」）、「全选」勾选框与「已选 N 项」计数、规则清单（每行名称 + 标签）；底部「保存文件名：」输入框（默认 chayuan_template_年-月-日.aidooo，尾注「（将保存为 .aidooo 格式）」）。
3. 做什么：勾选要共享的规则（可搜索过滤）＞ 点「确定导出」（执行中「导出中...」，未勾选时置灰）＞ 另存对话框（筛选「察元规则 (*.aidooo)」）。文件为带 format: aidooo 头的 JSON。库为空时显示「暂无规则项，请先在规则制作中添加」。

6. 「规则导入」：把 .aidooo 文件并回规则库

1. 在哪：点「规则导入」。
2. 看到什么：弹窗「规则导入」（400×320），说明「选择 .aidooo 格式的规则文件，将导入其中的规则项。ID 与现有规则重复的项将被跳过。」
3. 做什么：点「从本机选择文件」（执行中「导入中...」）选 .aidooo（或 JSON）文件。完成后显示「导入完成」：「成功：N 项」「失败（ID重复跳过）：M 项」。文件格式不对时提示「文件格式无效，请选择正确的 .aidooo 规则文件」。导入的规则立即出现在「规则制作」列表里。

## 如何确认操作生效

验证

1. 「导出模板」后打开「导入模板」：清单里出现刚另存的文件名；
2. 点「从模板新建」选它 ＞ 新窗口打开同款文档，点保存弹出另存为；「规则制作」里规则齐全（规则随文档走）；
3. 「导出规则」的 .aidooo 文件发给同事，对方「规则导入」后显示「成功：N 项」，其「规则制作」列表多出这些规则。

## 什么情况下用得上

拿到同事发来的模板文件或 .aidooo 规则文件，要收进自己的库，做好一份带规则库的公文/合同模板，要登记进模板库供日常「从模板新建」；跨科室共享审查规则，全院统一公文模板下发。

用户常搜的问法：导出模板和导出规则有什么区别；怎么把做好的模板给同事用。

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 你可能会问

### 模板登记信息存在哪？换机器会丢吗？

模板清单存在本机，不随文档走。换机器请重新「导入模板」登记一次，规则集用「导出规则/规则导入」迁移。

### 为什么「从模板新建」里看不到我导入的表格模板？

清单按宿主过滤：文字端只列文字（doc）类模板，表格/演示端同理。把 Excel 模板带进文字端会被拦截并提示去对应宿主使用——先把文件在对应端「导入模板」登记，或直接在对应对话/入口使用。

### 模板清单里的「×」删除会把文件删掉吗？

不会。删除的只是模板库登记项，磁盘上的模板文件原样保留；需要时重新「导入模板」即可。

### 「导出模板」和「导出规则」到底差在哪？

「导出模板」把整份文档（正文 + 内嵌规则库）另存为 .aidocx/.docx 并登记进模板库，适合交付完整模板；「导出规则」只把字段规则清单存成 .aidooo 小文件，适合同事之间只共享表单口径、不传文档。
