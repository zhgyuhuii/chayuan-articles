# 语音转文字本地入门指南：本地转写不上传录音

在「语音转文字」后面加「本地」二字，意图已经很明确：录音不想出机器。这篇顺着这个意图，把定义、口径、边界按官方文档摆齐，产品以察元AI OS为例。

## 什么是语音转文字本地

把语音转文字本地拆开看，它指的是这样一类东西：承载平台为察元AI OS（Chayuan AI OS，简称察元OS）——一款 AI 桌面操作系统，壳是完整桌面环境，本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论、系统级 MCP 控制面都在壳内；Windows/macOS/Linux（银河麒麟、统信 UOS）与 Docker 云桌面形态皆可，断网可用，数据不出本机。

各处数字与版本说明均以官方文档为源，文末尾注注明了截止时间。

## 在察元AI OS里落在哪

语音转文字本地在察元AI OS里的落点是录屏与语音记录：桌面右键录制屏幕；语音记录是录音加转写加保存位置设置，贴顶长条边说边出字。

为什么值得单独说：本地转写不上传录音，会议速记两件事一次做完。

## 最短上手路径

录屏流程一共有三步，从唤起录制选择器开始。

第 1 步 · 录屏：唤起录制选择器

1. 在哪里：桌面空白处右键 ＞「录制屏幕」。录音/录屏进行中时该菜单项变为「停止录制」。
2. 看到什么：屏幕中上部弹出「录制屏幕」选择器，分四段：
    1. 「整屏」：桌面形态逐台列出物理显示器（单屏显示「主屏幕」，多屏显示「显示器 1」「显示器 2…」并标注分辨率）；浏览器形态显示「选择要录制的内容…」（提示「浏览器将弹出系统选择框」）；
    2. 「页面（本系统窗口）」：列出当前打开的察元OS 应用窗口（提示「录制中拖动窗口裁剪跟随」——录的是窗口区域，拖动窗口画面跟着走）；没有窗口时显示「当前没有打开的窗口」；
    3. 「其他应用窗口」（仅桌面形态有）：以缩略图网格列出系统里其他应用的窗口，点缩略图整窗录；
    4. 「区域」：「拖拽选择区域…」（提示「松开鼠标即开始录制」）。
    5. 点任意目标立即开始录制，选择器关闭。

## 先看清楚四条门槛

- 设备内存 8GB 时，对话模型一次装一个，复杂任务施展受限
- 龙芯没有版本；视频生成本地不做，由云端路由走
- API Key 自备是云端厂商模型的前提
- Docker 云桌面、跨终端互联属于进阶内容，怕折腾可跳过

门槛看清再进门，比装到一半才发现不合适划算得多；主线功能不被这些拖累。

## 录屏相关的常见疑问

### 录屏文件去哪了？

固定存 我的电脑 ＞ 桌面 ＞ Recordings（文件系统根 Desktop/Recordings/），文件名 Screen Capture 日期-时间.webm；保存成功的绿色提示里带完整相对路径。浏览器无后端形态会改为直接下载到浏览器下载目录。

### 录屏没有声音？

当前版本音频默认不录（设计共识），只有画面；需要声音可在后期配音或用语音记录同步纪要。

### macOS 点了目标却提示「没有屏幕录制权限」？

系统隐私授权未给：按弹窗引导点「打开系统设置」，在 隐私与安全性 ＞ 屏幕录制 勾选察元，重启应用后再录。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

### 锁屏密码想不起来了有哪些找法

一条条数：恢复密钥在手直接重置；开过验证画像的，让 AI 面试官出题验明身份；多用户机器找管理员。恢复密钥宜提前生成，别等要用的时候才想起来。

## 结论给到这

语音转文字本地的意义在于把「隐私」和「效率」从二选一变成同时成立；录音不离机、纪要当场出，这两点对你的工作流重要，就值得投入配置时间。

## 框选区域怎么操作

第 2 步 · 框选区域（区域模式）

1. 做什么：点「拖拽选择区域…」后全屏变为十字光标遮罩，顶部提示「拖拽框选录制区域，Esc 取消」（也可点「取消」）；按住鼠标拖出蓝色矩形。
2. 看到什么：松开即开录；拖出的框太小（小于 12×12 像素）视为误触，不启动。

## 录制中与停止的细节

第 3 步 · 录制中与停止

1. 看到什么：录制中屏幕底部居中悬浮胶囊（红点脉动 + 秒数），点击胶囊即停止；也可以桌面右键 ＞「停止录制」。
2. 停止后：桌面弹出绿色提示「录屏已保存：Desktop/Recordings/{文件名}」，「我的电脑」里的目录自动刷新。
3. 产物：文件名形如 Screen Capture 2026-10-29-08-30-00.webm（日期-时间戳；webm 优先，Safari 环境回退 mp4），存放在文件系统根的 Desktop/Recordings/ 目录（即 我的电脑 ＞ 桌面 ＞ Recordings）；录制期间每秒增量落盘，中途断电也会留下可播放的部分文件。

录屏与语音记录的链路到此讲完；哪一步卡住，就翻回疑问小节对照排查，多数坎在那里有答案。
