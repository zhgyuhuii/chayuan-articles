# 开发者/自动化爱好者提效实录路线：自动化办公这样落地（2026 版）

如果你是开发者/自动化爱好者，下面这些场景大概率不陌生：脚本生成文档难。把文档处理写进代码流水线。这篇清单式指南以察元Office为工具，把这个岗位的自动化办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 脚本生成文档难
- CI 里要自动出 PDF
- 想让 AI 编程工具操作 Office

## 用察元Office怎么解：工作流拆解

1. chaoffice CLI 批量转换
2. MCP server 接入 Claude Code
3. 结构化 JSON 输出串联流程

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「chaoffice CLI 批量转换」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。把文档处理写进代码流水线。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 复杂版式 PDF 转换后需要人工抽查版面
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

AI 能力按需联网：内置十余家模型供应商接入（Claude、OpenAI、Gemini、DeepSeek、Kimi、GLM、Qwen、豆包、MiniMax、Grok、Mistral、OpenRouter 等），也支持任意 OpenAI 兼容端点——包括 Ollama 等本地模型服务，配置后即可断网使用 AI；不配置模型时，编辑、转换、批注、导出 PDF 等全部传统办公功能照常可用。

## 数据安全与隐私边界

- 文档打开/编辑/保存全程本机完成，不经任何服务器
- AI 默认不启用：配了 Key 或本地端点才会把对话内容发往所配服务商
- 开源 Apache-2.0 可审计（企业模块另有例外许可）
- 安全工程：全窗口 contextIsolation + sandbox、IPC schema 校验、外链协议白名单、无硬编码密钥

## 费用与授权的边界（如实说明）

开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。付费部分：试用期满后每日一次购买提醒弹窗（可手动关闭）+ 主页每 30 分钟温和提醒；离线 HMAC 短序列号激活，绑定机器指纹本地验证，无需联网激活服务器

## 如实说说它的不足

- 官方安装包 90 天试用后会有每日一次的购买提醒（不锁功能、可关闭）
- 网页版 SaaS 形态需要自行部署维护（Docker + 数据库）
- Linux 老发行版（glibc<2.34）无法安装

## 常见问题
### PDF 转 Word 会上传文件吗？

不会。转换由内置 PDFium 引擎在本地完成（字符级提取+几何版面分析），OCR 也走系统本地引擎，全程无上传。

### 遇到 bug 去哪反馈？

GitHub 仓库提 issue，或通过官网渠道反馈；项目有 75 个端到端测试用例保障迭代质量。

### 真的免费吗？

代码开源免费、可自行构建；官方安装包 90 天试用后仅每日温和提醒，不锁功能；购买授权属于支持开发，且购察元AI OS 后 Office 免激活。
