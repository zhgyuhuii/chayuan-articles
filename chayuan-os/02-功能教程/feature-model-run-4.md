# 模型运行监控排错：我的模型面板管理加载、卸载、删除

用模型运行监控之前有一条边界要先知道：自动卸载会释放常驻模型，重度使用记得钉住。知道边界再用，这篇剩下的篇幅讲怎么把它用对。

## 先定位问题在哪一层

排模型运行监控的错，顺序比速度重要：环境与模型先就位，然后对操作路径，最后核边界。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 健康灯黄色「引擎异常」怎么办？

多为引擎二进制缺失（杀毒隔离）或有实例不健康。先点「重启全部」；仍异常按 M4 常见问题 Q6 恢复引擎二进制；也可让智能体跑自诊断（GET http://127.0.0.1:52584/api/chatop-models/diagnose）按报告修。

## 正确的操作路径

9. 重启全部 / 全部关闭

1. 「重启全部」：记录当前运行清单 ＞ 全部卸载 ＞ 按原清单依序重载（提示「已发起全局重启（按原运行清单依序重载）」），处理引擎假死；
2. 「全部关闭」：卸载全部实例（含钉住的）并置停用位，健康灯变灰「已停用」；此后状态条只剩「启动」，点击清停用位并走预热链补齐加载。

从这几步开始：（第 4 个切入角度）

1. 内存仪表实时显示占用
2. 启动参数四档可调
3. 健康灯异常一眼可见
4. 确认边界：自动卸载会释放常驻模型，重度使用记得钉住
5. 场景验证：内存吃紧时手动卸载闲置模型
6. 场景验证：给常用模型上钉子

## 你可能会问

### 为什么有的模型行没有「设置」按钮？

「启动参数」（并发/上下文/GPU 层/线程）只对走 llama-server 的对话能力模型有意义，嵌入/重排/语音等行内不显示该按钮。

### 删除了「装机即用」模型，怎么找回？

「删除」只删共享副本并记账（重启播种不复活）。到 设置 ＞ 模型 ＞ 左栏「本地模型」组底部「恢复出厂模型」一键重播种五件套，详见对应教程。
