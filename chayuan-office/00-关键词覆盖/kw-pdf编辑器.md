# 一文分清PDF编辑器：PDF 怎么改文字

PDF编辑器这个词下面藏着两类东西：一类只让你看和批注，一类真能改字。区分它们的试金石很简单——改完的字能不能被复制出来当新文字用。本文按这条线展开，对象是察元AI Office。

这里的PDF编辑器指察元AI Office（Chayuan AI Office）中的真文本 PDF 编辑器：这款 Apache-2.0 开源 AI 办公套件装有 docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器，校对以批注锚定原文、修订追踪生成通用修订，Docs 端领域助手 4576 个，模型走 BYOK（94 家供应商）或本机 Ollama 等端点，Windows/macOS/Linux（含麒麟/UOS）均可运行，本地优先、离线可用。

## PDF 编辑落在哪块

真文本编辑与涂黑构成 PDF 编辑器这块的落点：引擎基于 PDFium wasm 重写页面内容流（沿用原字体，不走注释遮盖），可编辑文字、插入文字图片、编辑图片、处理水印页眉页脚；涂黑走物理删除，产出带 redacted 后缀的新文件。

值得展开讲的原因：市面上多数改字方案是贴白块盖图，这里改的是内容流本身——复制出来的是新文字，搜索、再编辑都成立。

## 实际改一次字试试

第 1 步 · 编辑页面上的文字（「编辑」页签 「编辑文字」）

1. 切到「编辑」页签，点「编辑文字」（提示「点击页面文字直接修改」），进入编辑模式。
2. 点击页面上的任意一段文字：原位出现编辑框，文字已预选中，直接输入替换。编辑框上方是样式条：
    1. 「字体」下拉：「原字体」（默认，沿用该段原字体）或 Arial / Times New Roman / Courier New；
    2. 字号数字框（4–200）、「B」加粗、「I」斜体、颜色块（取色器改文字颜色）、垃圾桶「删除这段文字」。
    3. 整段挪位置：鼠标按住编辑框边框拖动即可移动整段（提示「拖动边框移动整段文字」）。
    4. 提交与放弃：点击编辑框以外提交修改；按 Esc 放弃本次修改。
    5. 保存时改写才写盘（Ctrl/⌘+S）。个别页改写失败会被整页跳过并提示，不会损坏原文件——保存验证失败的提示原文：「第 {pages} 页的修改未能完整写回，已取消保存以保护原文件；请撤销该页的相关修改后重试」。

## 答疑五条

### 涂黑和直接画个黑色矩形盖住有什么区别？

画矩形只是加了一个图形对象，底下的文字还在文件里，复制粘贴或用工具提取就能拿到原文；「应用涂黑」生成副本时会把标记区域内覆盖到的页面对象从内容流里删除，文件里不再有这段内容。务必走「应用涂黑」流程，只拖框不应用没有保护效果。

### 为什么有的文字点不开编辑框？

两种常见原因：该页是扫描图片（没有文字对象可定位，等 OCR 识别后可用问 AI/搜索，但仍不能改字）；或该段文字被做成了特殊编码/曲线，定位不到文本对象时会明确提示「无法编辑这段文字」。曲线字只能用涂黑+插入文字的方式重做。

### 改完字以后字体变得和原来不一样？

「字体」下拉选了具体字体所致。改字时保持默认「原字体」即可沿用原字体；原字体画不全新字时应用会自动找本机替代字体并子集化嵌入。要求严格还原时，尽量只改动必要的字符。

### 扫描件在 Linux 上为什么识别不了？

Linux 没有系统 OCR 引擎可用，扫描页只能以位图形式保留；macOS 与 Windows 则由系统引擎自动完成识别。

### 能在哪些系统上运行？

Windows 10 及以上（x64/arm64）、macOS 11 及以上（Apple Silicon/Intel）、Linux（deb/rpm/AppImage）；浏览器 SaaS 与 dsh 插件形态也在支持之列。

## 选它的理由成不成立

PDF编辑器这一块要不要换成它，用一句话检验：你手头的 PDF 是改一处日期就要重出整份文件，还是只做阅读批注。前者吃真文本编辑的能力，这里对口；后者任何阅读器都够，不必多装。

## 「真文本」三个字的实现口径

第 2 步 · 为什么叫「真文本编辑」（实现口径，用户视角）

1. 应用通过 PDFium 引擎（wasm）直接操作 PDF 的文本对象：定位选中文字对应的文本对象 ＞ 用 FPDFText_SetText 重写其文字 ＞ 删除/插入页面对象 ＞ FPDFPage_GenerateContent 重新生成页面内容流。改完后页面里就是新文字本身，能被搜索、复制、再次编辑。
2. 字体处理：先校验原字体的字符表（cmap）能否画出所有新字——能画就沿用原字体；画不全时自动从本机字体里找能画全部新字的字体，并把用到的字形子集化嵌入文件，保证在没装该字体的电脑上显示一致。
3. 极限情况：一段文字里混着没有任何字体能画的字符（如 emoji），会提示「没有字体能在 PDF 中绘制这段文字（暂不支持 emoji 等特殊符号）」。
4. 定位不到对应文字对象时提示「无法编辑这段文字：未能在文档中定位到对应的文本」；改完太长放不下时提示「编辑后的段落放不下：多出的文字会盖住下方内容。请缩短文字，或按 Esc 放弃修改」。

真文本编辑与涂黑的行为细节都在上面了；找一份旧合同改个日期走一遍流程，成色如何立刻见分晓。
