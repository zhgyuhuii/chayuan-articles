# 从需求到交付：主题包

先说这篇能帮你干什么：读完能在察元AI OS里独立完成主题包，路径是给新宠挑形象。步骤里的每个「」按钮都是界面原文。

## 先看看痛点对不对得上

想给灵宠换房间背景、换形象，或整套主题换装（背景+图标+灵宠皮+摆件）；整套主题包一键换装；点了「免费获取」没反应或报「获取失败」，不知道怎么重试；关心获取的内容存在哪、断网还能不能用、能不能删。

## 灵宠商店：从入口到完成

第 1 步 · 打开商店（三个入口）

1. 建宠/编辑宠弹窗：形象卡组末尾的「···」卡（下方小字「更多」）＞ 打开商店并停在「形象」页签；
2. 场景条：桌面左下「场景」按钮 ＞ 场景条首格「+」（提示「获取更多场景」）＞ 打开并停在「场景」页签；
3. 宠物群聊 ＞ 「建宠物」弹窗：「更多形象与场景，去商店获取 ＞」文字链接，或形象区的「···」卡 ＞ 同样打开「形象」页签。

第 5 步 · 失败与重试

1. 单次获取失败：面板顶部出琥珀横幅「获取失败，请稍后重试（资源下载或市场服务暂不可用）」，点横幅右侧「取消」收起，再点该卡「免费获取」即重试；（视频场景的预下载失败不阻断安装：自动回落在线流式播放，下次仍可重新获取补缓存。）
2. 市场目录拉取失败：面板顶部出横幅「市场目录拉取失败（<原因>），当前显示本地内置」+「重试」链接——点「重试」重新拉取远程目录，成功后新条目补进列表。
3. 无本地数据通道（浏览器等非桌面环境）：横幅「当前环境没有本地数据通道，无法保存获取内容——请在察元OS 桌面内获取」。

第 6 步 · 存储、恢复与删除

1. 每次获取记入本机账本（获取记录+内容+本地缩略图持久落盘）；重启或离线后自动恢复注册——已获取的场景照常出现在场景条、形象照常出现在建宠卡组、主题包照常出现在设置场景卡。
2. 删除：场景与主题包可在场景条或 设置 ＞ 主题 ＞「灵宠场景」卡点「×」删除；形象与元素当前没有卸载入口，获取后一直在卡组/账本中。

## 关键能力点

- 四页签分类浏览
- 全部免费
- 下载失败可重试

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 你可能会问

### 点「免费获取」报「获取失败」？

多为下载源或市场服务暂时不可用。关掉失败横幅再点一次「免费获取」即重试；多次失败先确认网络，或等市场恢复（远程目录失败时顶部还有单独的「重试」链接）。

### 获取成功却找不到内容？

按页签找落点：场景＞桌面场景条与 设置 ＞ 主题 ＞「灵宠场景」卡；形象＞建宠/编辑宠弹窗形象卡组（自动刷新）；主题包＞先到场景条把场景切到该包才整桌换装。

### 商店里只有很少几条内容？

远程目录没拉全：顶部应出现「市场目录拉取失败…」横幅，点「重试」重新拉取；本地分片导入的条目不受网络影响始终在列。

## 更多操作细节

第 2 步 · 认识界面

弹出居中面板：标题「灵宠商店」（绿色商店图标），标题行右侧显示当前页签条目计数「N / M」与「取消」关闭按钮；下方四个页签按钮，从左到右为「主题包」「场景」「形象」「元素」（当前页签绿底高亮，默认打开「场景」或按入口直达对应页签）；卡片两列排布，每张卡=预览图+名称+价格标「永久免费」+按钮「免费获取」；滚动到底部自动加载下一批（出现「下滑加载更多」提示）；面板底部一行说明「商店内容当前全部免费获取。」。点面板外遮罩或「取消」关闭。

## 更多操作细节

第 3 步 · 四个页签逐页看

1. 主题包：整套内容——场景背景+图标皮肤+灵宠皮+场景元素（部分含开机/登录专属资产）。获取只下载包清单（秒级完成），皮肤/元素资产在使用时按需加载。获取后到场景条或 设置 ＞ 主题 ＞「灵宠场景」卡把场景切到该包，整桌即随包换装。
2. 场景：灵宠房间背景。图片场景下载后转为本地数据；视频场景真下载整个视频文件——按钮上如实显示「下载中 N%」，下载完成后离线也能播放。获取成功立即出现在桌面场景条与 设置 ＞ 主题 场景卡里。
3. 形象：建宠/编辑宠时可选的灵宠立绘。获取后建宠弹窗的形象卡组自动刷新出现新卡（含群聊建宠物表单），无需重开桌面。
4. 元素：房间小摆件。当前桌面还没有摆放编辑器——带标记的条目会注明「需摆放编辑器（即将上线）」；主题包自带的元素经 设置 ＞ 主题 的元素联动摆放（默认关）。

## 更多操作细节

第 4 步 · 获取与下载进度

点卡片上的「免费获取」：

1. 按钮翻转为下载进度态：总量已知时显示「下载中 N%」并带绿色填充进度条（主题包下清单秒级完成，会一闪而过）；总量未知但已有字节到达时显示「下载中…」；刚发起、还没有任何字节进度时显示转圈；
2. 成功后按钮翻为绿色「已获取」（带对钩，且禁用防重复），面板不会自动关闭——下载就地完成，翻牌即反馈；
3. 下载期间可继续浏览其他卡片，也可点「取消」关面板（下载在后台继续完成）。

这篇把灵宠商店的链路拆完了。卡住就回看常见问题那一节，多数坎都在那里。
