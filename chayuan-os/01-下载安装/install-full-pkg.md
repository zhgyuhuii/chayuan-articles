# 全量离线包安装：含五件套权重的完整离线包

全量离线包这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决全量离线包。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：含五件套权重的完整离线包。

安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥。这两件事做完，这台机器才算真正就绪。

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

把全量离线包放回察元AI OS的整体盘面：壁纸是最直接的个性化出口，动态壁纸让桌面活起来，桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件，右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness。
