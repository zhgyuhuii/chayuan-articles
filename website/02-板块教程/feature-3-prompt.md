# 一文读懂提示词板块｜实操教程

提示词库是察元AI 能力广场里使用频率很高的一项能力。它的「提示词板块」这样工作：高质量系统提示词与模板目录：复制正文即用，覆盖写作、编程、分析等场景。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

高质量系统提示词与模板目录：复制正文即用，覆盖写作、编程、分析等场景。

从任务视角看，它对应的关键词是「提示词库」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 prompt 板块
2. 按场景筛选
3. 复制提示词正文到你的模型对话

## 适用场景

- 快速获得专业系统提示词
- 提示词学习参考

## 实用技巧

- 好提示词先看结构（角色/约束/输出格式）

## 注意事项与边界

- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 怎么订阅模型活动？

活动板块支持 RSS 订阅，聚合 31 家厂商源的促销与发布动态。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。
