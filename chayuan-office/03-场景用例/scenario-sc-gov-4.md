# 用三审三校解决实际问题：场景化用法全记录

如果你正在琢磨三审三校，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI Office的下载安装与首次启动时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 为什么值得了解

1. 公文格式与措辞要求严
2. 送审前要过保密关
3. 修订要留痕可查

机关单位文字岗这个场景里，校对、保密、留痕一条链在离线环境完成。

## 实操全过程

把流程串起来：

1. Docs 写正文，察元AI 页签全文校对出批注
2. 保密检查八大类风险扫描
3. 修订追踪让 AI 改动落成通用修订，逐条接受
4. 审阅比较做送审前后对比

## 支撑功能的操作细节

流程里下载安装与首次启动的实际操作：

第 1 步 · 下载安装包

打开官网 aidooo.com 下载中心（或 GitHub Releases），按平台选择：

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS | .dmg（另有 .zip） | macOS 11+；打开 dmg 后把应用拖入「应用程序」 |
| Windows | .exe（NSIS 安装向导） | Windows 10+；可选择安装目录；安装时注册 docx/xlsx/pptx/pdf/md/html 文件关联 |
| Linux（Debian/Ubuntu） | .deb | sudo apt install ./… |
| Linux（Fedora/RHEL/openSUSE） | .rpm | 用 dnf / zypper 安装 |
| Linux（麒麟/UOS/通用） | .AppImage（另有 .deb/.arm64） | 免 root、离线友好，适合信创与内网环境 |

第 2 步 · 安装并启动

1. macOS：挂载 dmg，把察元AI Office 图标拖入 Applications，首次从启动台/应用程序打开；
2. Windows：运行 .exe 安装向导，按提示选择目录完成安装，从开始菜单/桌面打开；
3. Linux：按上表命令安装，或对 .AppImage 加执行权限后直接运行（无需安装、无需 root）。

## 关键能力点

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

## 别在这几处栽跟头

功能归功能，这几个边界先摆清楚：

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx

场景提醒：涉密文档建议接本地模型，全文不出机器。

## 你可能会问

### 第三方下载站 mirror 的安装包能用吗？

不能保证。官方分发只有 aidooo.com 与本仓库 GitHub Releases 两处，其余站点均非官方分发，存在被篡改风险，请从官方渠道重新下载。

### 90 天试用到期会锁功能吗？要注册账号吗？

不锁功能。到期后每日一次温和提醒（可关闭），不购买也完全不影响使用；购买走离线短序列号，内网无激活服务器也能激活。使用 AI 的云端能力需在设置中配置模型或登录账号，见产品内的对应手册产品内的对应手册。

### 欢迎引导被我关掉了，想再看一遍怎么办？

引导只出现一次，界面不提供「重看引导」入口。想系统了解产品，按 F1 打开内置图文手册（18 主题，可搜索），见产品内的对应手册。

## 补充答疑

### 麒麟/UOS 上装哪个包？要联网吗？

选 .AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb。下载一次后可拷贝到内网机器直接安装/运行，应用本体不依赖联网。

## 安装与运行答疑

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

## 一个真实场景

咨询顾问的典型用法：知识库检索客户行业资料引用入文，AI 改写统一口径与文风，对 AI 隐藏报价等敏感段。资料整合与写作提效，敏感信息可控。注意：引用上下文预算默认 12000 字，长文档分段引用。

## 顺带了解

批注与修订：审阅页签全解：批注增删、修订开关、显示标记四档、接受拒绝与上下条导航。

为什么值得看：审阅流是文档协作的核心动作，键盘流顺畅度决定采用率。

## 还有这个能力

全文搜索：文件名与正文双路搜索：索引启动约 4 秒后首轮扫描，上屏后约 0.15 秒出结果，Jev 重排约 0.6 秒（4 秒超时回退），单文件解析 120 秒超时。

## 如实说不足

- web/dsh 形态只有五编辑器（无 HTML），且无购买激活界面
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 定位与家族

察元AI Office（Chayuan AI Office）是一款 Apache-2.0 开源的 AI 办公套件，把 docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器装进一个应用，AI 校对以批注锚定原文、修订追踪生成通用修订，Docs 端内置 4576 个领域助手，支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点，覆盖 Windows/macOS/Linux（含麒麟/UOS），本地优先、离线可用。同家族产品：察元AI OS（AI 桌面操作系统）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。
