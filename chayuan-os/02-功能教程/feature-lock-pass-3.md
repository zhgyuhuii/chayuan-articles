# 桌面安全设置场景实战：从需求到交付

上周有同事问我：桌面安全设置这块到底该怎么弄。他折腾了半天没找到入口，其实不是功能难用，是没人把路径讲清楚。这篇就把锁屏密码与自动锁屏从入口到收尾完整过一遍，用的是察元AI OS的真实界面，照着点就行。

## 先看看痛点对不对得上

新装机建好账号后，想给桌面上一道密码门：手动锁屏、开机、闲置自动锁都要密码才能进，合租/办公室环境，人离开工位希望桌面自动上锁；给家里共用电脑上锁；工位离开自动锁屏。

用户常搜的问法：察元OS 怎么设置锁屏密码；怎么让电脑不动几分钟后自动锁屏。

## 从打开到做完的每一步

第 1 步 · 设置或修改密码（设置 ＞ 用户 ＞ 我的账号）

1. 在哪里：点击 Dock 中的「设置」应用，左侧栏选「用户」分区；顶部第一张卡标题为「我的账号」，卡片备注显示当前登录名与角色（「管理员」或「用户」）。
2. 做什么：卡片内并排三个密码框——「当前密码（未设过可留空）」「新密码（至少 3 位）」「再输一次」，填好后点「修改密码」。
3. 看到什么：成功后页面顶部出现绿色提示「密码已更新」，三个输入框清空；锁屏、开机登录门、远程访问随即改用新密码。
4. 分支：
    1. 两次新密码不一致 ＞ 显示红色提示「两次输入不一致」，不会提交；
    2. 当前密码输错或新密码不足 3 位 ＞ 保存失败，页面顶部显示红色错误信息，原密码保持不变；
    3. 账号体系没有「清除密码」：新密码留空提交只会失败（最短 3 位的硬校验），桌面账号始终带密码。设置 ＞ 通用 里旧的「锁屏密码」卡（含「留空清除」行为）已于 2026-09-23 移除，不要再找它。
    4. 改密成功后系统会静默刷新找回画像（若你开启过「验证画像」），并对没有任何找回保险的账号补发一次引导通知。

第 2 步 · 锁屏与解锁

1. 手动锁屏三种入口：
    1. 菜单栏菜单里的「锁定察元」（菜单项上标注 ⌃⌘Q 字样）；
    2. 键盘 Ctrl+L（桌面态直接落锁）；
    3. 闲置自动锁屏（第 3 步开启后生效）。
    4. 锁屏过程分两段：手动锁屏先进入全屏时钟/动画欢迎面，在画面上点一下任意处才出现密码框；开机/重启流程结束后的落锁跳过欢迎面，直接显示密码框（少点一次）。进入锁屏的同时，本应用的其他原生窗口（悬浮插件窗、智能体网页窗等）会被隐藏遮盖，解锁后原样恢复。
    5. 解锁在密码框输入账号密码（回车或点箭头提交），密码正确整个锁屏上滑退场回到桌面；密码错误输入框抖动并清空。
    6. 防爆破退避：密码连错 5 次起开始限流——第 5 次错后需等 5 秒，此后每多错一次等待时间翻倍（5s＞10s＞20s…）；退避状态持久化，重启电脑不清零；解锁成功即清零。退避期内即使输入正确密码也会被拒绝。

第 3 步 · 自动锁屏（设置 ＞ 通用）

「通用」分区从上到下依次是三张卡：「全局唤起对话」（第 4 步）、「后台驻留」（第 5 步）、「自动锁屏」，下方再接主题、菜单栏时钟、语言三个分区。

1. 在哪里：设置左侧栏选「通用」分区，找到「自动锁屏」卡，卡片说明「无操作到达设定时长后自动进入锁屏（需已设置锁屏密码）。」
2. 做什么：在下拉框选择时长——「关闭」（默认）／「1 分钟」／「5 分钟」／「10 分钟」／「30 分钟」／「60 分钟」。
3. 看到什么：选中即生效，无需保存按钮。
4. 行为细节：鼠标、键盘、滚动、触摸等任何操作都会重置计时；没有密码的账号不会触发自动锁（锁了也解不开，所以直接不锁）；正在参与共享桌面（作为房间参与者）时本机不自动锁。

第 4 步 · 全局唤起对话快捷键（设置 ＞ 通用）

1. 在哪里：「通用」分区第一张卡「全局唤起对话」，说明文案为「任何应用前按快捷键唤起/聚焦 DeepSeek Harness 会话窗口：无窗新开、有窗聚焦最近、连按循环多窗（conversation-entry-plan）。仅桌面形态可用。」
2. 做什么：勾选「启用快捷键」（默认已启用）开关；在「键位」输入框填写或修改快捷键（默认 Alt+Space，输入框旁有示例 Alt+Space / CmdOrCtrl+Shift+S …），回车或让输入框失焦即保存。
3. 看到什么：保存成功显示「已保存」；键位被其他应用占用时显示「注册失败：键位可能被其他应用占用」，此时保持旧注册不动，换一个键位再试。
4. 行为细节：在任何前台应用中按下——没有会话窗就新开一个，有窗聚焦最近使用的那扇，连按在多扇会话窗之间循环。配置持久化在主进程 <userData>/hotkey.json。

第 5 步 · 关窗驻留托盘（设置 ＞ 通用）

1. 在哪里：「通用」分区「后台驻留」卡，说明文案为「关窗 = 驻留系统托盘（云通道与远程访问不断），托盘菜单退出才真退；关闭后关窗即退出应用。」
2. 做什么：勾选/取消「关窗驻留托盘」（默认勾选）。配置持久化在主进程 <userData>/tray.json。
3. 看到什么：
    1. 勾选（默认）：点窗口关闭钮只是收进系统托盘，托盘图标（白鹰标）常驻，云通道与远程访问保持在线；托盘菜单含「chatop」（打开主窗）／「唤起会话」／「暂停云通道」（暂停后变「恢复云通道」）／「退出察元」（真退出）；有人发消息时托盘图标叠加未读数徽标。
    2. 取消勾选：关窗即退出整个应用。

## 关键能力点

- 密码设改清三操作
- 自动锁屏时限可调
- 托盘驻留不占任务栏

## 几个容易忽略的细节

用之前要认的账：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 快捷键提示「注册失败：键位可能被其他应用占用」？

该键位已被系统中其他应用注册。换一个组合（例如 CmdOrCtrl+Shift+S）保存即可；失败时旧键位仍然有效，不影响使用。

### 设置 ＞ 通用里找不到「锁屏密码」设置卡？

密码设置已移到 设置 ＞ 用户 ＞ 「我的账号」卡。通用分区里那张写 localStorage 的旧密码卡（含「留空保存=清除」）已于 2026-09-23 移除——它在桌面形态本来就不参与解锁校验。

### 自动锁屏选了时长但没有生效？

依次检查：① 账号是否设置了密码（无密码不触发）；② 是否正在参与共享桌面房间（参与者不自动锁）；③ 是否一直有操作在重置计时。另外该设置保存在浏览器本地（localStorage chatop_autolock_minutes），换机器/清数据后需重选。
