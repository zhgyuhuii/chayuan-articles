# 天梯挑战怎么约：按段位找对手赢者升段

榜单看久了，人会有一种冲动：光看它们排座次算什么，我要自己上去打一场。天梯挑战就是给这份冲动准备的正门——按 TrueSkill 段位找对手，约战开打，赢者升段。这篇把天梯挑战的约战流程与升段规则讲清楚，让你从看榜的人变成榜上的人。

## 先弄清楚它是什么

天梯挑战是带排位属性的约战玩法：你以挑战者的身份，从天梯榜上按段位物色对手，发起挑战，打完一局按 TrueSkill 规则结算评分，赢者升段。它与人机局的区别就在这个「约」字与「段」字——人机局是随手开局的对局，输赢当然也有结算，但天梯挑战是有坐标、有目的的征伐：你知道自己冲着哪一层、哪一位去的。

它解决的问题是「旗鼓相当从哪来」。随便开一局，对手的强弱全凭缘分；天梯挑战把对手选择的依据交给了段位——段位分层背后是评分分层，找同层对手，对局的悬念与含金量都有保障。想赢分，就往上找一层挑战强者；想稳稳涨，就在同层里磨。

还有一条设计要知道：人类挑战者的战绩独立统计，不与模型混榜。你的每一次约战、每一场胜负，都记在你自己的赛道里，模型们刷不完的对局数不会稀释你的名次——这是天梯对人类的尊重，也是分榜存在的理由。

## 动手前要备好什么

先看榜单，后动手。进天梯页把榜单过一遍：模型榜看格局，人类榜看同类，段位分层看清楚自己当前的位置与目标位置的距离。榜单结构不熟的话，天梯解读那篇教程建议先补课，约战是建立在读懂榜之上的动作。

然后确认模型可用：约战的对局还是要用模型出招或者当对手，设置 ＞ 模型配置里的厂商、Key、「测试连接」这套前置一个不能少；Ollama 本地模型免 Key 接入，零成本开打。最后想好玩法与自己的预期：冲段就选自己有把握的玩法，练兵就选想提高的玩法——天梯挑战的每一次结算都会留痕，别拿榜开玩笑。

## 约战流程一步步走

第一步，定目标。从榜单上物色对手：同段位的求稳，高一段的进取。看两样东西再定人——对方的评分与手数：手数少的还在冷启动期，赢它含金量打折；手数足、评分稳的对手，赢了才算真涨分。

第二步，发起天梯挑战。按应用内的挑战入口走，选定对手与玩法，约战成立。入口的具体位置与文案以 0.1.0 应用内界面为准，天梯页里顺着指引就能找到。

第三步，进对局室开打。约战的对局与日常对局共用对局室：思维链气泡照滚，延迟与 token 用量照挂，区别是这一局的每一手都压着你的评分。紧张是正常的，深呼吸，按你练过的路数走。

第四步，等结算。终局落定，胜负由代码裁判判定，TrueSkill 按双方评分与不确定性更新你的分数，赢者升段、输者让位，名次变化随后反映在榜上。

第五步，复盘这一局。不管输赢，回放里走一遍：赢的局看哪几手立了功，输的局看哪几手送了分，问叹号标注与形势曲线都在。约战的复盘比普通对局更有价值——它的每一手都带着真实的得失。

## 升段规则说清楚

升段的机制一句话：评分驱动段位，胜负驱动评分。你赢一场，TrueSkill 根据对手强弱更新你的评分，分数越过当前段位的门槛，段位上行；输给低于你的对手，掉分明显，段位随之下行。涨分的幅度不是固定的：赢强敌大赚，赢弱旅小补——所以约战时挑对手的策略，直接决定你涨分的效率。

这带来一条实用推论：与其反复挑战比自己低太多的对手（赢了也涨不了几分），不如把主要精力放在同层与上一层。按段位约战的机制本身就在引导这件事，顺着机制的指引走，天梯的爬升曲线才健康。

## 做完后的验证

约战一局后核对三处：天梯上你的评分随这局结果变化了（结算生效）；人类挑战者榜上的名次按新评分更新（独立统计在动）；回放里找得到这局的完整记录（留档无误）。三处都对，约战链路就通了，剩下的交给场次。

## 这些边界要心里有数

挑软柿子刷分行不通：TrueSkill 的设计就是让赢弱旅的收益趋近于零，与其刷不如打硬仗。段位不是永久头衔：评分双向更新，长期不动手，位置会被后来者顶上去。费用照旧：云端模型每一手都消耗你的 API 额度，约战的紧张感别变成无脑加场，本地模型零成本是练兵的好选择。冷启动期的对手名次不稳，约他们的战，赢了别飘输了别气——那几局的含金量本来就要打折。界面与入口细节以 0.1.0 实际呈现为准。

## 高频疑问

### 天梯挑战能跨段位约战吗

机制上按段位找对手，跳跃幅度过大时胜负悬念小、评分收益也小；具体约束以应用内实际规则为准。健康的爬法是同层磨、上层挑。

### 输了挑战会怎么样

评分按 TrueSkill 规则下调，输给低分对手掉得多，输给强敌损失有限。掉段不丢人，回去复盘、攒分再来，天梯永远开着。

### 天梯挑战和人机局有什么区别

人机局是日常对局，随时开局随时散；天梯挑战带排位属性，按段位约战、赢者升段，结算走 TrueSkill。想练手开人机局，想上分走挑战。

### 人类的战绩和模型的混在一起吗

不混。人类挑战者战绩独立统计、独立成榜，两边赛道分开，名次互不干扰。

### 约战要花钱吗

软件 MIT 开源免费，约战本身不收费；对局中的云端模型按 API 用量向厂商付费，Ollama 本地模型零成本。

天梯挑战怎么约？看榜定人、发起挑战、开打、等结算——流程就这四步，分量却比日常对局沉得多：每一手都记在你的赛道上。按段位找对手，赢者升段，输者再来，天梯的魅力不在榜顶那张椅子，而在往上爬的每一局都有账可查。
