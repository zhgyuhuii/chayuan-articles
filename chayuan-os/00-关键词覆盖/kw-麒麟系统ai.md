# 麒麟系统AI是什么：给政企用户完整的桌面迁移体验

关于麒麟系统AI，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是麒麟系统AI

麒麟系统AI这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 麒麟系统AI要联网吗

OpenAI 风格与阿里百炼风格 API 自动适配；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入；保存后随系统技能分发到智能体。以官网 aidooo.com 当前页面为准。

### 麒麟系统AI数据存在哪

数据文件不受影响，灵宠把后台跑着的 AI 变成桌面上看得见的小生物，AI 纪要一键生成。以官网 aidooo.com 当前页面为准。

## 离线与内网

离线内网这条线的口径：无显式模型偏好时自动指向本地模型，断网时联网搜索自然不可用；设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态，建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型。
