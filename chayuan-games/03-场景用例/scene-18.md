# 挂机跑分新姿势：锦标赛开一晚早上看战报

睡前把米下进电饭锅，定个时，早上起来粥正好——挂机跑分玩的就是这个逻辑：睡觉是你的，对局是机器的。察元竞技场把这件事做成了标准流程：睡前配一场多模型锦标赛，循环赛自动排程，积分榜实时刷新，早上睁眼看战报。一晚挂机换一份大模型棋牌能力的横评底稿，这篇把睡前配置、费用提醒与战报解读一次讲全。

## 手动刷分为什么坚持不下来

自己盯着模型打分，坚持一周就露馅。

时间对不上。模型对局一场接一场，盯着看既无聊又费神，你的晚间黄金时间全耗在监工上，搞两次就烦了。

样本上不去。手动开局，一周攒十局顶天，样本不够，任何排名都站不住。挂机的意义就是把局数堆上去，量变了才有质变。

口径乱。手动跑今天用这三个模型、明天换那两个，玩法忽东忽西，跑完自己都对不上数。横评要的是固定阵容、固定玩法、固定局数——这些恰恰是自动化最擅长守住的。

## 睡前十分钟配置流程

第一步，验模型。设置 ＞ 模型配置里把今晚参赛的模型挨个「测试连接」，Key 与额度确认好——睡后被欠费卡住，一晚就白挂了。

第二步，点选手。建锦标赛，批量勾选参赛模型。阵容建议四到六家，太少没有悬念，太多费用与时长失控；新上市想验证的模型，插一两个进去正合适。

第三步，选玩法。横评类挂机推荐五子棋与 9 路围棋：单局短，一晚能跑很多轮；想加心理战维度，掺一场德州扑克。玩法当晚固定，别中途换，局数口径也定一下，比如每对打几局，跑满即止；口径一致战报才好读。

第四步，开赛睡觉。循环赛排程应用自动生成，你不用排对阵表；积分榜实时刷新，把窗口留着让它自己跑，顺手确认电脑不休眠。挂机的两块基石是电与网，断一个就断报。

## 费用这件事，睡前就要心里有数

挂机烧的是真金白银。每手棋都是真实 API 调用，费用由你向厂商支付，跑一晚的花费与局数、模型档位、玩法手数全有关系。几个压费用的阀门：控制参赛模型数量；选短局玩法；赛前先用小局数试跑一轮，拿真实消耗外推整晚预算。额度告警也顺手设上，半夜超支没人拦你。预算敏感就换 Ollama 本地模型参赛，零成本挂一晚，代价是小模型棋力有限，战报的含金量要打折。软件本身 MIT 开源免费，这笔账里没有软件的钱。

## 早上怎么读战报

看榜。积分榜先扫名次，昨晚的领跑者与垫底者一目了然；循环赛打完，冠军自己浮出来。名次之外看结构：赢谁输谁比净胜场更有信息量，专克某家的模型值得单独记一笔。别急着定论，一晚的局数只够谈趋势。

看线。点开关键对局的形势曲线，哪几局是一边倒、哪几局是绝地翻盘，线上的拐点全是故事点；给别人讲战报时，拐点就是最省口舌的起手式。

看标注。复盘里逐手的妙手与失误标注，是战报里最有料的段落：垫底模型是被谁一波带走的、领跑模型靠什么稳住，翻两页标注就有答案。

看画像。协议画像里的 JSON 格式遵守率与平均耗时，告诉你谁出招守规矩、谁磨蹭、谁靠容错链续命。棋谱支持 JSON 导出，想深挖的手留档慢慢拆。

## 挂机前后的检查清单

睡前过一遍这张单子，能少踩九成的坑。

电源接好，系统休眠关掉；网络走有线更稳，走无线就离路由器近一点。

参赛模型挨个测过连接，Key 余额够撑一晚；名单与玩法在开赛前定稿，开赛后不再动。

窗口留着，别把应用关进后台；躺下前扫一眼积分榜，确认对局真的在走。

早上读战报前，先看昨晚有没有中断的痕迹——有的话，把中断的局排除再谈名次，别让半局棋污染了榜。

最后存档与复测：把榜单与棋谱归档，隔一两周用同阵容复测一轮，两份战报摆在一起，谁稳谁飘才有对照。

## 这套姿势适合谁

适合：想在各家模型间选主力、又懒得写评测脚本的人；做内容要素材的人，一晚挂机的战报够写两篇文章；团队选型的人，把战报往群里一发，讨论自然就来。不适合：要精确 benchmark 数字的研究者——对局跑分是体感参考，不是标准测试；电脑白天还要干活的人，挂机一晚占着机器，安排在备用机上更从容。

## 常见疑问

### 挂一晚大概花多少

没法给准数，花费取决于局数、模型档位与玩法手数，都是真实 API 调用。建议先用两小时试跑一轮看消耗，再决定整晚开多大阵容；云模型贵就掺本地模型，边际成本立降。

### 中途断网断电怎么办

断网后对局停在那，续上网能接着跑，但当晚排程大概率完不成；断电同理。想稳就插电、关休眠，重要挂机别挑雷雨夜。应用对 429 限流会自动退避，限流不等于中断，个别手被代走兜底属正常。战报短一截也别慌，名次照读，缺的局当不存在。

### 战报结果能当评测结论吗

当方向参考可以，当定论不行。一晚样本、单一玩法，撑不起「谁强」的断言；把它当筛选器用——从榜上挑出值得细看的模型，再补人工对局，这套组合拳才是正确用法。战报要发群里的话，一张积分榜截图配三行结论就够，追问的人自然会点开对局记录，长文留给周报；家里有闲置旧电脑的，改造成挂机专用机也很合适。

### 要不要盯着跑

不用。自动排程加代码裁判，整晚不需要人守；你顶多睡前瞄一眼积分榜动没动。第二天早上读战报的十分钟，才是你的工作量。挂机时段可以错峰挑，避开厂商高峰，限流少了战报更干净。

### 新模型挂进锦标赛合适吗

合适，这是新模型摸底的好姿势。首次参赛它会被循环赛盘个遍，强弱点一晚现形；不过发布日服务不稳时先别挂，等它站稳两天再上。中途也不要往跑着的锦标赛里加模型，积分口径会乱，想测新模型就单独开一场小锦标赛。

跑分这件事，费力从来不在跑，在盯。把盯的活交给锦标赛，把睡觉还给自己，把判断留给早上的十分钟——挂机的快乐是一种复利：你睡得越稳，样本攒得越多，结论就越靠得住。今晚就配一场，明早见分晓。
