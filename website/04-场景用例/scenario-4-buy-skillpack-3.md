# 行业从业者的技能包方案（效率视角）

如果你是行业从业者，下面这些场景大概率不陌生：一个个找技能太累。一次配齐行业技能的购物路径。这篇效率视角以能力广场为工具，把这个岗位的技能包工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 一个个找技能太累
- 不确定技能包值不值
- 买完不知道怎么装

## 用能力广场怎么解：工作流拆解

1. 技能包商城按行业浏览
2. 看包详情的 solves/audience
3. 买断后在 8 款智能体中激活

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「技能包商城按行业浏览」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。一次配齐行业技能的购物路径。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 限 3 台设备授权
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 政企可私有化部署（Docker），数据自主可控
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

### 资源失效了怎么办？

条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注；发现问题可通过反馈渠道或机器人客服上报。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### 资源数量有多少？

能力广场总条目 2.5 万+（站方口径，页面实时计数展示）；教程库 2.1 万+ 条；技能包 311 个；助手目录 4526 个助手/228 个领域；API 价格表 40 厂商 201 个模型条目。
