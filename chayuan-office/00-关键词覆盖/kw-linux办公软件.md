# Linux办公软件是什么

在 Linux 桌面上找一套顺手的办公软件，难点从来不是「有没有」，而是格式兼容、信创适配与离线能力这些具体环节。本文以察元AI Office为对象，逐项过一遍这些环节。

## 什么是Linux办公软件

Linux办公软件指运行在 Linux 桌面环境里的文档、表格、演示处理工具；本文讨论的这款是开源 AI 办公套件，六编辑器一体，AI 嵌在每个编辑器里，带完整的入口、步骤与边界。

把背景铺开一点：Linux 上的办公软件选择长期偏少，LibreOffice 算常青树，个别商业套件有 Linux 版但闭源，浏览器里的在线套件又依赖网络。既带 AI 能力、又能完整离线运行的原生选项，过去基本是空白——这也是这类产品开始被 Linux 用户留意的原因。

各项口径整理自官方文档，依据的版本在文末注明。

## 答疑两条

### 完全离线的 Linux 机器上能用它吗？

传统编辑不依赖网络；AI 部分看模型放在哪——云端模型需要联网，本地端点（如 Ollama）配好后离线也能跑。密钥只落在本机的 ai-settings.json 文件里，不往外传，也可以改用环境变量间接引用，避免明文落盘。

### 格式兼容上它是什么态度？

支持与不支持的项目都明确列出，不做模糊表述；扫描件方面，Linux 缺系统 OCR 引擎，扫描页会以位图原样保留、不做文字识别，需要识别的扫描件请预先安排；打印不中断、断电可恢复这两条底线也有对应的机制保障。

## 安装包怎么挑

发行版走 deb 系（Debian、Ubuntu 及其衍生）的直接拿 deb 包；rpm 系（Fedora、openSUSE 等）用 rpm 包；AppImage 不挑发行版，下载即用、免安装，但注意它对 glibc 的要求是 2.34 以上，太老的系统跑不动。架构上 x64 与 arm64 都有对应包；国产平台里的麒麟与 UOS 走 AppImage 加 deb 的组合，没有 root 权限也能装进用户目录。

## 迁移前的两个小准备

一是把常用字体在系统里装齐，免得打开旧文档时字体回退、版式偏移，公文体、仿宋这类字体尤其要提前就位；二是确认打印机已在系统层配好，应用内的打印走系统队列，驱动问题在系统层解决最省事。

## 模型与联网的关系

这一版的 AI 能力须先接入模型才能用：内置账号登录暂未开放，现阶段要么 BYOK 接厂商、要么配本地模型；没配模型时，它就是一款规规矩矩的传统办公软件。编辑器侧的 AI 面板六端通用，点「打开 AI 助手」即进，对话、改写、校对都在这个面板里发起。

## 部署形态与团队使用

单机之外还有两条路：服务器部署后全员经浏览器可用，适合团队化办公；自建网页版走生产端口 52587（能力地图那条已列）。对内网单位来说，开源办公套件能离线装、信创环境能跑，是它进入替换清单的起点。信创场景的关键诉求是离线与可控：安装不依赖外部网络，文档处理全程本地，再配一个本地模型端点，AI 校对与改写也能留在内网完成——公文、合同这类材料对此尤其在意。

## 数据安全的几条硬口径

文档脱密采用 AES-256-GCM 加密备份，PBKDF2-SHA-256 迭代 21 万次；涉密文档不出网，接本地模型时校对与改写在隔离环境照常进行；AI 服务不可用时自动落到 9 类本地正则兜底，基础处理不断档。转换也都在本机完成，合同文件不出机器——这一点与在线转换服务有本质分别。对 Linux 用户而言，这几条口径的意义比 Windows 用户更大：桌面 Linux 常被用在对外隔离的环境里，数据不出机器往往不是偏好，而是硬性要求。

## Linux 侧的特有边界

- 无系统 OCR 引擎，扫描页以位图保留、不识别文字
- 格式兼容的原则是明说：哪些能开、哪些不能开，写清楚比藏着掖着负责
- 打印与断电恢复，是衡量这类软件可靠性的两条底线

## 值不值得装到你的 Linux 上

答案取决于你缺什么：缺格式兼容与离线能力的，上文各节正好对症；已经用惯某套方案且协作环境固定的，迁移成本可能大于收益。先用一张日常最复杂的工作簿试开一次，字体、批注、修订、表格计算逐项比对，比看多少篇介绍都直接。顺带一提，它的命令行带 17 个子命令，习惯终端操作的 Linux 用户可以把常见转换、批处理动作脚本化，这往往是 Linux 老用户最先尝到的甜头。
