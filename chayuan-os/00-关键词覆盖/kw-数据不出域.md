# 数据不出域是什么：定义、场景与上手路径

先说结论：数据不出域在察元AI OS里是完整可用的，从桌面环境总览的入口进去，按下面步骤操作即可。这篇文章覆盖概念、步骤、验证和常见问题四部分，读完能独立完成整个流程。

## 什么是数据不出域

顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

放到察元AI OS的语境里：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面环境总览是其中承上启下的一环。

## 解决什么痛点

它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

典型使用场景：低配机关动效保流畅，给政企用户完整的桌面迁移体验。

## 在察元AI OS里怎么用

入口与核心步骤：

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 怎么判断适不适合你

适合你的情况：日常就是给政企用户完整的桌面迁移体验，希望流程固定、结果可验证。

不必勉强的情况：需求不在这条线上的人。察元AI OS的思路是把边界写明白，条件式地推荐。

## 高频疑问

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

## 安装与运行答疑

### AppImage 双击没反应怎么办？

多为缺 FUSE 2：安装 libfuse2（Ubuntu 24.04 为 libfuse2t64），或用 --appimage-extract-and-run 解压运行；统信 UOS 环境推荐直接用 deb 包。

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

## 一个真实场景

出差与远程办公者的典型用法：提前在机器上配置远程访问，公网走出站云中继（可自建），手机浏览器镜像桌面操作。手机随时连回自己的 AI 工作站。注意：公网访问依赖云通道可用性，高安全环境建议仅局域网使用。

## 顺带了解

对话中使用知识库：在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么，就触发 kb_search、kb_list、kb_read_doc 工具链；Claude Code、Codex 等 CLI 智能体经 MCP（52582 端口服务）自动具备同款能力，出处随回答带出。

为什么值得看：不用切应用，在正在干活的对话里直接问资料，出处照样带。

## 还有这个能力

web 与 docker 访问链接：web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作。

## 硬口径两三条

- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness

## 如实说不足

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 模型服务的实际构成

装机自带的五件套覆盖完整离线链路：Qwen3-4B 负责对话、BGE-M3 做嵌入、BGE 重排提升检索精度、whisper-small 跑语音识别、piper 做中文语音合成。模型中心里还能在线补更强档位（Qwen3-8B/14B、小内存档 LFM2.5、图像理解的 MiniCPM-V 等），下载源多路自动换。内存仪表实时显示每个模型的占用，空闲 15 分钟自动卸载，常用模型可钉住常驻。
