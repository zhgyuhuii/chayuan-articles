# 察元OS终端与文件管理使用指南（终端模拟器）（细节版）

终端模拟器是察元AI OS里使用频率很高的一项能力。它的「终端与文件管理」这样工作：zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。

从任务视角看，它对应的关键词是「终端模拟器」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

1. Dock 打开终端/我的电脑
2. 日常文件与命令行操作
3. 配套编辑器查看各类文件

## 适用场景

- 不离开系统完成开发运维

## 进阶技巧

- 终端会话持久，重开不丢历史

## 注意事项与边界

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。
