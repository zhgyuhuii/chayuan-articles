# AI工舱排查路径：团队统一 AI 工位

AI工舱这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决团队统一 AI 工位。

## 先定位问题在哪一层

按这个顺序排查AI工舱通常最快：先确认前置条件（环境与模型就绪），再核对操作路径，最后看边界限制。

## 正确的操作路径

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 进阶用法与边界

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 常见问题

### AI工舱要联网吗

智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用，桌面本身能被 AI 定义，能力边界从预装走向按需生成，联网环境下内置 web_search 工具默认走 DeepSeek 搜索。以官网 aidooo.com 当前页面为准。

### AI工舱数据存在哪

文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，让特定文件类型默认交给智能体处理，双击即用 AI。以官网 aidooo.com 当前页面为准。

## 安全与数据边界

安全口径单独立一层：需要提前开启并积累足够记忆数据；管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。

## 平台与形态

平台与形态的账：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness，Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；每次产出 markdown 报告落盘归档。

离线内网这条线的口径：whisper 语音权重同样支持；显式的加载卸载加自动卸载策略是本地模型的生存之道；可选自动（本地优先）或指定，润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱。
