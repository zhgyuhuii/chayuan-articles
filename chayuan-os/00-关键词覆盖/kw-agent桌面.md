# 什么是Agent桌面？一文讲清概念、用法与选型

聊Agent桌面之前先划重点：它不是单一功能，而是一套带入口、步骤和验证的完整流程。察元AI OS在这件事上的设计思路是把入口收拢、把步骤做实、把边界说清，理解了这个，操作就顺了。

## 什么是Agent桌面

顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

放到察元AI OS的语境里：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面环境总览是其中承上启下的一环。

## 为什么值得了解

它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

典型使用场景：低配机关动效保流畅；给政企用户完整的桌面迁移体验。

## 在察元AI OS里怎么用

入口与核心步骤：

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 怎么判断适不适合你

适合你的情况：日常就是给政企用户完整的桌面迁移体验，希望流程固定、结果可验证。

不必勉强的情况：需求不在这条线上的人。察元AI OS的思路是把边界写明白，条件式地推荐。

## 接着回答几个常见问题

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

## 安装与运行答疑

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

## 一个真实场景

家庭用户的典型用法：多用户各自账户独立空间，语音输入降低打字门槛，桌面灵宠给孩子当玩伴。干净、免费、多人友好的家庭 AI 电脑。注意：8GB 内存机器建议一次只加载一个对话模型。

## 顺带了解

用户记忆：全局记忆库三档作用域（global 全机、agent 单智能体、project 按项目）：手动添加、会话提炼、跨智能体采集，入册或丢弃，可升为全机共享，最新条目自动投影进各家 CLI 的 AGENTS.md 与 CLAUDE.md，每条带溯源。

为什么值得看：换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。

## 还有这个能力

模型代理进阶：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，还有可复制的各家智能体配置片段。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 桌面应用与创造模式

任何网页、本机程序、HTML 文件都能封装成桌面应用（web、local、html、file 四种类型），可放桌面快捷方式也能嵌进壁纸当小组件。创造模式更进一步：智能体在运行时定义并挂载新插件，说一句要什么应用，它能把应用造出来挂上桌面。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。
