# 三个场景吃透察元OS首次配置的用法

如果你正在琢磨察元OS首次配置，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI OS的模型设置向导时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 解决什么痛点

误关了向导或当时点了跳过，后来想重新走一遍，新装机、第一次登录桌面，被自动弹出的向导窗口拦住，不知道它要干什么、要不要点；新装机第一次进桌面；想把「默认模型」一次性写进 Harness / Claude Code / Codex / OpenCode / OpenClaw 的配置，而不是逐家手改配置文件。

用户常搜的问法：开机弹出来的『统一模型设置向导』是什么，必须配吗；怎么把模型配置一次性应用到所有智能体。

## 操作步骤详解

弹窗标题「统一模型设置向导」，标题行右侧显示进度「第 1 / 4 步」（数字随步骤走）。

第 1 步 · 概念页「一次设置，所有智能体共用」

1. 页面正文解释：察元AI OS 用「模型代理」做所有大模型的仅有出口。下方示意图从左到右三格：「本地模型（llama-server）」/「厂商模型（厂商路由）」＞「模型代理 127.0.0.1:52581」＞「对话 · 知识库 · 智能体」。
2. 三个按钮：
    1. 右下主按钮「下一步」＞ 进入第 2 步；
    2. 左下「我已经配置过，不再显示」＞ 标记完成，直接跳到第 4 步完成页；
    3. 右下「跳过向导」＞ 关闭弹窗并标记完成（之后可从设置重跑，见「验证」第 3 条）。
    4. 点弹窗外的深色遮罩等同「跳过向导」。

第 2 步 · 「选择默认对话模型」

1. 页面标题「选择默认对话模型」，正文说明：知识库问答、新会话、未单独配置模型的智能体都会先用这个默认模型。
2. 页面主体是一棵统一模型树，三级结构，同时列出本地与已配置厂商的对话模型：
    1. 第一级是组：树首固定为「本地与自建 · local/」（本机图标），下面每家已配置厂商各一组（厂商 logo 图标 + 厂商名）；
    2. 第二级是分类（本地组按「对话」等本地分类，厂商组按「对话模型」等类型）；
    3. 第三级是模型叶子，等宽字体显示引用串——本地形如 local/qwen3.5-4b-q4km，厂商形如 deepseek/deepseek-chat；
    4. 组行右侧有数字药丸（该组模型数）；行首箭头可折叠展开，默认展开两级；
    5. 单选树：叶子行整行可点，行首圆点被选中变蓝，选中行蓝底高亮并自动滚动到可见位置；再点一次取消选中；
    6. 本地正在运行的模型，行尾带绿色「运行中」标记——优先选它响应最快；
    7. 树异步加载后自动预选第一个叶子（本地组在树首，即默认选第一个本地对话模型）。
    8. 树下方是选中回显条：行首图标（本地模型 = 本机图标、厂商模型 = 厂商 logo）+「已选」+ 蓝色等宽引用串；鼠标悬停显示「厂商名 · 模型名」。
3. 分支与异常：
    1. 树为空时显示「还没有可用的对话模型（本地与厂商均未配置）。」，并给两个出口按钮：「去模型库下载 / 导入」和「去配置厂商模型（设置 ＞ 模型设置）」。两个按钮都会打开 设置 ＞ 模型 页（进页默认选中本地「对话」分类）；要配厂商密钥，在左栏展开厂商分组选厂商卡；
    2. 清单约 8 秒未加载出来时，显示「模型清单加载失败或超时（模型服务未响应）」和「重试」按钮；
    3. 保存失败时显示红色「保存失败：<原因>」。
    4. 选好后点右下主按钮「下一步（<引用串>）」保存（引用串超过 14 字符会截断成「前 14 字符…」；保存进行中按钮显示「…」）。保存动作：写入默认对话模型 ＞ 确认模型代理在运行（没运行自动拉起）＞ 选的是厂商模型时自动补齐代理路由 ＞ 生成 models.md 并随系统技能自动分发给各智能体。成功后自动进入第 3 步。
    5. 若代理停摆且自动拉起未果，报「模型代理未运行，自动拉起未果——请到 设置 ＞ 模型设置 检查服务状态后重试」，留在本步不前进。

第 3 步 · 「统一应用到智能体」

1. 页面标题「统一应用到智能体」，正文说明：把默认模型写入各智能体配置（写入前自动备份，可随时回退）；也可以稍后在 设置 ＞ 默认模型 ＞ 「应用到全部智能体」 重做。
2. 顶部等宽字体显示写入目标，形如 local/qwen3.5-4b-q4km @ http://127.0.0.1:52581。
3. 桌面形态下点「选择智能体并应用…」弹出应用对话框：
    1. 「模型名（写入智能体配置的长期契约）」输入框已预填第 2 步选的默认模型；
    2. 智能体勾选清单（默认五家全勾选）：「DeepSeek Harness（模型下拉）」「Claude Code（~/.claude/settings.json）」「Codex（~/.codex/config.toml）」「OpenCode（~/.config/opencode/opencode.json）」「OpenClaw（启动环境注入）」；本机感知到但不支持自动写入的智能体会灰显列出并注明「暂不支持自动写入模型配置」；
    3. 点「应用」逐家写入：每家成功显示绿色「已写入」，失败显示红色具体原因；写入内容 = 模型代理的 OpenAI 兼容地址 + 默认模型名（代理对本机调用免 key 直连，真实厂商密钥不出本机凭证库）；
    4. 点「关闭」收起弹窗；全部完成后向导页显示绿色「已应用」。
    5. 浏览器形态没有应用按钮，改为提示框：默认模型已保存，请到桌面应用里用 设置 ＞ 默认模型 ＞ 「应用到全部智能体」或重跑本向导补做。
    6. 左下「上一步」回第 2 步；右下「下一步」进第 4 步。

第 4 步 · 「设置完成」

1. 标题「设置完成」，正文「默认模型已就绪。想深入了解更多：」，列出两篇帮助中心教程：「统一模型设置与模型代理」「运行本地模型详解」（帮助中心 ＞ 模型服务）。
2. 提示行：「随时可在 设置 ＞ 模型设置 ＞ 「设置向导」 重新运行本向导。」（实际按钮位置见「验证」第 3 条）。
3. 「打开帮助中心」直接打开帮助中心应用；「完成」关闭向导。

## 关键能力点

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体
- 重跑入口在设置＞模型＞设置向导

## 几个容易忽略的细节

用之前要认的账：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 想换默认模型随时可以在设置里重跑向导，不用重装

## 你可能会问

### 第 2 步模型树一直显示「…」或加载失败？

约 8 秒未到会亮「重试」按钮，先点重试；仍失败多为模型服务未响应，到 设置 ＞ 模型 查看服务健康灯后再回来。

### 误点了「我已经配置过，不再显示」，其实还没配置？

没有影响。该按钮只是不再自动弹出，配置本身什么都没动；按 Q1 的入口重跑即可。

### 向导再也弹不出来了，怎么重跑？

任何方式退出（跳过/关闭/完成/「我已经配置过，不再显示」）都会写完成标记，之后不再自动弹。重跑走 设置 ＞ 模型 ＞ 左栏「本地模型」组 ＞ 「统一模型设置向导」。

这篇把模型设置向导的链路拆完了。真机操作一遍比看十遍文章有用，现在就动手试第一步。
