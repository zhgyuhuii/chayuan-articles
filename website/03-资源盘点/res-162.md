# 教师岗位助手盘点：资源怎么找怎么选

教师岗位助手盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：助手目录（AI助手目录）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**助手目录**：4526 个内置助手、228 个领域的在线目录：与察元AI文档助手/Office 同源，先在网页端浏览再装到工具里用。

1. 进入 /assistants
2. 按领域浏览
3. 找到需要的助手记住名称

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 常见问题
### 怎么订阅模型活动？

活动板块支持 RSS 订阅，聚合 31 家厂商源的促销与发布动态。

### 智力榜的分数哪来的？

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。

### 手机能用吗？

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。
