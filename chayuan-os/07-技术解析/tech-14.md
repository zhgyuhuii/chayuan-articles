# 模型自动卸载策略：我的模型面板管理加载、卸载、删除

用模型自动卸载策略之前有一条边界要先知道：自动卸载会释放常驻模型，重度使用记得钉住。知道边界再用，这篇剩下的篇幅讲怎么把它用对。

## 先弄清楚它是什么

为什么要有模型自动卸载策略：一台 16GB 内存的机器跑两个 8B 模型必然卡死，显式的加载卸载加自动卸载策略是本地模型的生存之道。本地模型运行管理的定位是我的模型面板管理加载、卸载、删除、钉住，可调启动参数（省内存、均衡、性能、自定义），

概念一分钟，操作十分钟，这篇都覆盖。

## 机制拆解

空闲 15 分钟卸载与钉住常驻的平衡。

能力面拆开看：启动参数四档可调，内存仪表实时显示占用；健康灯异常一眼可见。

一个常被问到的问题：为什么有的模型行没有「设置」按钮。「启动参数」（并发/上下文/GPU 层/线程）只对走 llama-server 的对话能力模型有意义，嵌入/重排/语音等行内不显示该按钮。

从提问口径看，用户最关心的是本地模型怎么加载/卸载？在哪里操作？

## 操作步骤详解

9. 重启全部 / 全部关闭

1. 「重启全部」：记录当前运行清单 ＞ 全部卸载 ＞ 按原清单依序重载（提示「已发起全局重启（按原运行清单依序重载）」），处理引擎假死；
2. 「全部关闭」：卸载全部实例（含钉住的）并置停用位，健康灯变灰「已停用」；此后状态条只剩「启动」，点击清停用位并走预热链补齐加载。

最短路径走一遍：

1. 内存仪表实时显示占用
2. 启动参数四档可调
3. 健康灯异常一眼可见
4. 确认边界：自动卸载会释放常驻模型，重度使用记得钉住
5. 场景验证：内存吃紧时手动卸载闲置模型
6. 场景验证：给常用模型上钉子

## 几个容易忽略的细节

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 自动卸载会释放常驻模型，重度使用记得钉住
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 健康灯黄色「引擎异常」怎么办？

多为引擎二进制缺失（杀毒隔离）或有实例不健康。先点「重启全部」；仍异常按 M4 常见问题 Q6 恢复引擎二进制；也可让智能体跑自诊断（GET http://127.0.0.1:52584/api/chatop-models/diagnose）按报告修。
