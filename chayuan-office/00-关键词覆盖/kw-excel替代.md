# Excel替代：经营数据透视分析

关于Excel替代，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI Office的能力面与边界一次说清。

## 什么是Excel替代

Excel替代这个说法对应的产品是察元AI Office（Chayuan AI Office）：开源 AI 办公套件，六编辑器一体，AI 嵌进每个编辑器。北京智灵鸟科技中心出品。

## 平台与形态

平台覆盖：Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；另有浏览器 SaaS 与 dsh 插件形态（五编辑器，无 HTML）。

## 在察元AI Office里落在哪

Excel替代在察元AI Office里的落点是Sheets 数据工具：基于开源 Univer 核心加自研 Rust 边车（calamine 加 IronCalc）的导入导出：数据透视表、切片器、日程表、条件格式、公式追踪、高级筛选、合并计算、模拟分析、分列、数据验证。

为什么值得单独说：透视表与公式引擎是表格软件的硬指标，自研边车保证 xlsx 往返不失真。

## 最短上手路径

试一遍就明白：

第 1 步 · 认识功能区与编辑区骨架

1. 页签行常驻七个页签，顺序固定：开始 / 插入 / 页面布局 / 公式 / 数据 / 审阅 / 视图。没有「文件」页签——文件命令（打开/保存/另存为/导出 PDF/打印）在系统应用菜单和工具栏图标里。
2. 四个上下文页签按选中对象出现，不打断当前所在页签：选中图表出现「图表设计」、光标进入表格（Table）出现「表设计」、选中可编辑形状出现「形状格式」、选中浮动图片出现「图片格式」；取消选中后自动消失。
3. 表格区上方是名称框行：左侧名称框显示当前单元格地址（如 B3），右侧「▾」按钮打开「定位」对话框（快捷键 ⌘G / Ctrl+G，或 F5）；公式栏在「视图」页签「显示」组用「编辑栏」开关显示/隐藏（⌘U / Ctrl+U 收起展开）。
4. 底部是工作表标签条。在标签上右键打开菜单：「插入…」「删除」「重命名」「移动或复制…」「保护工作表…（/撤销工作表保护…）」「工作表标签颜色」「隐藏」「取消隐藏…」「选定全部工作表」（成组后多「取消成组工作表」）。Ctrl/⌘+点击、Shift+点击可把多张表成组，删除/隐藏/标签颜色会作用于整组；成组时至少保留一张可见表，否则弹「工作簿至少要包含一个可见工作表。」拦截。
5. 最底部状态栏：左侧是操作消息；选中有数据时中间显示选区统计（求和、平均值等）；右侧是 50%–400% 的缩放滑杆加当前百分比。

## 实话实说：哪些人不必急着装

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- API Key 存本机 ai-settings.json 不上传，支持环境变量引用
- PDF 涂黑生成物理删除的 -redacted.pdf 副本，不是注释遮盖
- 文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代
- 遥测仅匿名统计且可关闭；自建部署可做到零遥测

## 你可能会问

### 点「删除重复值」提示「需要完整加载模式」？

这个工作簿太大，当前只做了流式加载（网格里只有你看过的区域有数据）。按提示确认完整加载整个工作簿后再执行；「分列」「筛选」等需要全量数据的工具同理。

### 切片器/日程表保存后在 Excel 里怎么不见了？

切片器与日程表控件目前只存在于会话内（OOXML 的 slicer 部件尚未写入文件），但它们对透视表做的筛选会随保存写入——Excel 打开看到的是同样的筛选结果，只是没有这个可视化控件。

### 透视表提示「透视表布局与输出区不一致——需要在 Excel 中刷新后才能重算」或「该透视表暂不支持编辑」？

这类提示出现在打开别人文件里的透视表时：紧凑布局、值字段位于行轴、特殊聚合方式（如乘积/数值计数）等形态暂不支持自动重排。按提示在 Excel 中刷新一次再回来，或改用「数据透视表＞刷新」重算。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。
