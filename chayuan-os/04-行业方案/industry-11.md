# 出版发行AI方案：AI 桌面操作系统

## 出版发行为什么需要这套方案

出版发行行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把模型设置向导跑通，验证环境与模型可用
2. 流程层：出版发行日常最高频的文档环节（配置云端厂商模型所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型
- whisper 语音权重同样支持

## 一个行业侧影

需要多方意见的决策者的典型链路：

1. 给几只灵宠配不同厂商的模型
2. 建宠物群聊勾选成员，选并行或串行
3. 抛一个命题让它们讨论，开视角讨论强制多角度
4. 开共识模式让它们互相评审收敛结论

同一命题的多模型观点同屏呈现，分歧与共识一目了然。

提醒：本地模型并发上限 4 路，全员本地模型时发言会排队。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

## 放回产品盘面看

把出版发行AI方案放回察元AI OS的整体盘面：知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，点击互跳定位原文，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。

## 安全与数据边界

安全口径单独立一层：（本机 MCP HTTP 服务，回环免 token）；敏感操作全部写审计日志 audit.jsonl，可回放检查，远端调用以远端访客身份过对端权限门并留审计，API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。

## 平台与形态

平台与形态的账：内置浏览器窗，配合 webwindows 可被智能体驱动，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness。

## 价格与授权

价格口径一并交代：键盘党的启动器：一个快捷键管启动、找文件、直接问 AI 三件事，问 AI 直答卡，四本日历把生活与工作分开记，AI 能读会写；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一。

## 产品家族与搭配

察元AI OS不是单打独斗：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，购买 OS 授权后，同机察元AI Office 自动免激活；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。
