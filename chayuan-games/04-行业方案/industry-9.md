# 企业内网AI娱乐：数据不出域的团建部署

每到团建季，行政想要的「有新意」和 IT 眼里的「不越线」经常凑不到一块：云服务要过安全评审，个人账号不该进公司网络，任何数据流向说不清的方案都会被一票否掉。企业内网AI娱乐要把事情办成，顺序得反过来——先跟安全团队把数据边界谈死，再谈好不好玩。察元竞技场在这件事上有先天优势：对局数据与 API Key 都只落本机，配本地模型可以把整条链路锁在域内。这篇给 IT 与行政一份能联合签发的部署方案。全文不绕弯：三条线、两个套餐、一套管理动作，看完就能进审批。

## 合规约束：先划三条线

数据线：API Key 明文只存本机应用数据目录（userData），不上传；对局记录、天梯积分都落在本机。模型流量只走本机网关一个口子，网关用随机端口加路径令牌鉴权，外部进程够不到。这几条写进方案时保留原文表述，安全部门复核时不用再解释。

账号线：不用员工个人账号的云服务。要走云端模型，用企业已采购的 Key，按既有审批流程来。

网络线：公司策略若要求完全不出域，走 Ollama 本地推理，免 Key，断网可玩，模型请求一步都不出内网。套餐B还有个附带好处：现场不依赖会场 Wi-Fi，信号再差也照办。

## 部署方案：两个套餐

套餐A（允许访问厂商 API）：团建机装察元竞技场（Electron 桌面应用，Windows、macOS、Linux 都有安装包），设置 ＞ 模型配置里从 85 家厂商目录点选企业已采购的厂商，填企业 Key，点「测试连接」验证。云端大模型的讲解与棋力观感好，费用按调用量向厂商支付，走企业模型预算。模型档位选一强一快两档，对局观赏性与节奏都顾上。

套餐B（完全不出域）：团建机另装 Ollama 与本地模型，竞技场接入本地推理，全程离线，零模型费用；代价是模型棋力与讲解质量有限，弱模型会出废招（系统有代走兜底，但观感打折）。本地模型的名单提前定死，活动现场不现装，装模型的时间比想象长。

两个套餐共同的功课：提前试跑一场完整对局或小型锦标赛，确认机器性能、对局时长与大屏信号都在掌控内。

## 部署时间表与验收清单

时间表给一个参考：提前一周定套餐与设备，提前三天装软件与模型并试跑一场，提前一天全流程彩排含大屏，活动当天只管执行。验收清单四项：断网场景实测（套餐B必做）、对局能完整跑完、大屏信号稳定、配置清理步骤验证过。四项全勾，活动当天出事的概率就很小。

## 团建环节设计

竞猜场开场：机机观战投大屏，座位匿名显示玩家A、玩家B，各队竞猜身份与胜负，终局揭晓计分——规则一分钟讲完，冷场克星。竞猜规则提前印在席位卡上，开场零解释。

挑战场分批：职工轮流人机局挑战模型，人类挑战者战绩独立统计，赢下一局有奖；跟不上节奏的环节按「AI 接手」让模型续盘，保持流动性。报名按部门混编，顺便让平时不说话的部门同桌。

决赛场压轴：锦标赛循环赛自动排程，积分榜实时刷新，全场看着夺冠时刻收尾。决赛前留五分钟让各队喊口号——团建要的就是这个。

## 管理建议

指定一名活动管理员：保管企业 Key 与设备配置，活动结束清理本机 userData 目录里的配置文件，Key 不落共享盘、不进群文件。管理员名单与联系方式写进活动方案，出状况能第一时间找到人。

口径报备：云端套餐的对局文本会发送给模型厂商——虽是娱乐对局内容，也要在活动方案里向安全部门写明这条数据流向，获批再开。

设备复用：团建机可以做成可还原的快照，用完还原，环境干净，下次活动直接复用。

预算与报备一起做：套餐A的调用费用预估进活动预算，套餐B把硬件折旧算进去，两条路径都给财务一句明白话。管理员交接要留书面清单：Key 的存放位置、清理步骤、联系人，别让信息锁在一个人脑子里。

## 活动后的复盘

团建结束别急着收摊，留十分钟复盘：哪个环节冷场了、模型发挥是否拖节奏、竞猜参与率如何。记录下来归进团建档案，下次活动换玩法换模型就有依据，第二年直接引用。天梯数据也顺手看一眼——人类挑战者的分数变化是职工参与度的硬指标。

## 边界

要说清楚一件事：「数据不出本机」不等于走云端模型时零外发——调用厂商 API 就有文本出域，这是套餐A的适用前提，两个套餐的口径别混着说。本地模型体验打折，棋力有限，活动预期按「好玩」定，不按「惊艳」定。费用上软件 MIT 开源免费，套餐A按调用量付费，套餐B零模型成本。最后提醒：方案是给「娱乐对局」的，别在团建环境里夹带任何业务数据，混了就说不清了。多分公司远程同步办的话，各点各自备机，别指望跨网联机——方案的边界就是本机与本域。

## 常见疑问

### 对局数据会上传到你们服务器吗
不会。软件是本机桌面应用，对局记录与天梯数据都落本机；走云端模型时文本发往对应厂商，走本地模型则全程不出设备。

### 用企业自己的 Key 算合规吗
走既有审批的路径，Key 只存本机应用数据目录且不上传；仍建议在活动方案里把数据流向写给安全部门过目。

### 完全不出域怎么部署
装 Ollama 本地推理，竞技场接入后免 Key、断网可玩，模型请求全程不离开域内设备。

### 团建完数据怎么清理
清理本机 userData 目录下的配置与存档即可，或直接还原设备快照，Key 与对局记录一并清掉。

### 员工能装在自己电脑上吗
个人兴趣使用与公司团建分开看：员工自装的实例用个人账号，不碰企业 Key；企业套餐只装在活动管理员的设备上。

### Ollama 机器不够强怎么办
降模型规格或降玩法复杂度：小模型陪玩足够；再把玩法换成五子棋这类短局，节奏稳住，体验照样在线。

团建方案的落地速度，取决于 IT 与行政能不能在同一页纸上签字。把数据边界写成三条线，把部署写成两个套餐，把管理写成三条建议——这份方案就能进审批流。察元竞技场给出的底气是结构性的：本机网关、本机存档、可选的本地推理，让「玩」这件事有了清晰的域界。团队围着大屏看两个模型斗智斗勇、为自己押注的座位较劲，这种场面比一顿饭更容易让陌生部门熟起来。
