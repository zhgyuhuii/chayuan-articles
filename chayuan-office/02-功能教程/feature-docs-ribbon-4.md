# AI 功能依赖已配置的模型：docx编辑的坑与对策

很多人搜「Docs 顶部那一排页签都各管什么」，搜到的多是概念解释，落不到操作。这篇以察元AI Office为准，把docx编辑从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

按这个顺序排查docx编辑通常最快：先确认前置条件（在察元AI Office 中用 Docs 编辑器打开了一个文档。），再核对操作路径，最后看边界限制。

## 正确的操作路径

第 4 步 · 「绘图」页签：墨迹批注

1. 「选择」组：「选择」工具（恢复正常编辑）。
2. 「绘图工具」组：「笔」「荧光笔」「橡皮擦」。
3. 「笔样式 / 荧光笔样式」组：10 种颜色色板；笔的粗细 1/2/3.5/5 像素，荧光笔 6/10/16 像素。
4. 「清除」组：「全部清除」清掉所有墨迹。墨迹是覆盖在页面上的批注层，不改正文文字。

第 5 步 · 「设计」与「布局」页签：整篇外观

1. 「设计」分两组：「文档格式」——「主题」及配套的「颜色」「字体」；「页面背景」——「页面颜色」「水印」（含「机密」等预设、「自定义文字水印…」、「删除水印」）、「页面边框」。
2. 「布局」分三组：「页面设置」——「页边距」（含自定义）、「纸张方向」（纵向/横向）、「纸张大小」、「分栏」（一栏/两栏/三栏）、「分隔符」（分页符/分栏符/自动换行符；分节符四档：下一页/连续/偶数页/奇数页）；「段落」——左/右缩进、段前/段后距；「排列」——「位置」（九宫格定位）与「环绕文字」，针对选中的浮动图片等对象。
3. 「引用」页签：「脚注」组（插入脚注/插入尾注）、「引文与索引」组（题注、插入引文、添加新源…、书目、标记条目(XE)、插入索引）；「邮件」页签为邮件合并。

## 怎么确认做成了

验证

1. 切到「视图」页签点「导航窗格」：左侧出现「导航」面板，「标题」页签按层级列出文档标题；点一个标题，正文滚动到对应位置；右键标题应弹出升级/降级/删除等菜单。
2. 按 ⌥⌘K：功能区命令区变成只剩图标的一行；再按一次恢复。按 ⌥⌘R（Windows Ctrl+F1）：命令区整个收起只剩页签行；点任意页签它又展开。
3. 「开始」＞「转换」＞「转换为 PDF…」：出现保存对话框，确认后状态栏提示导出完成的文件路径。

## 你可能会问

### 深色模式会把文档也改成黑底吗？

不会。按钮提示原文是「以深色显示编辑区域,不改变文档内容」——改的是界面观感，文档本身的页面颜色、打印和导出结果不受影响。

## 更多操作细节

第 6 步 · 「视图」页签与导航窗格

「审阅」页签（批注/修订/比较/保护）见对应教程；「察元 AI」页签（校对/文本分析/思维导图等）见对应教程。

1. 「视图」组五种形态：「页面视图」（按页面尺寸显示）、「Web 版式」、「大纲」、「阅读视图」、「分页预览」。
2. 「缩放」组：「缩放」对话框、缩小/放大、「100%」、「页宽」「整页」「多页」三个适配。
3. 「外观」组：「深色模式」——提示原文「以深色显示编辑区域,不改变文档内容」。
4. 「显示」组：「标尺」「网格线」（仅用于对齐，不会打印）「导航窗格」。
5. 「窗口」组：「新建标签」（再开一个本文件的标签）、「拆分」（同文档上下分栏）、「切换标签」（列出所有 Docs 标签跳转）。
6. 导航窗格：面板标题「导航」，三个页签——「标题」（大纲树，可展开/折叠）、「页面」（页面缩略图）、「结果」（顶部搜索框输入即全文搜索）。点击标题跳到正文对应位置；右键标题弹出菜单：「升级」「降级」「在前面新建标题」「在后面新建标题」「删除」（连同该标题下整块内容一起删）、「选择标题和内容」，面板级还有「全部展开」「全部折叠」和「显示标题级别」（只显示到第 N 级）。
