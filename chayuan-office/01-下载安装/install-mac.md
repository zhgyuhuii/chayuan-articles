# Office macOS安装安装：三平台五形态安装包

Office macOS安装的每一步其实都写在安装向导里，真正容易出错的是取包来源与拖装细节。本文以 dmg 拖装为主线，把界面按钮与验证口径对齐真实屏幕。

## 安装前确认

- 系统要求：macOS 11 及以上，Apple Silicon/Intel
- 安装包：dmg 与 zip
- 说明：dmg 拖装。

dmg 与 zip 均出自官方发布渠道，别的站点出现的同名包来源存疑。

## 完整操作步骤

1. 官方入口下载 dmg
2. 拖入应用程序文件夹启动
3. 设置＞模型设置里接入模型
4. 六编辑器从开始页进入

## 其他平台装法速览

Windows：官方渠道取 exe；双击安装；启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama。

Linux：安装包从官方发布处拿对应格式；deb 用 dpkg -i，AppImage 加执行权限直接运行；麒麟/UOS 走 AppImage 加 deb，免 root。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

装好后的贯通检查分两步：设置里完成模型接入（厂商 API 或本机 Ollama），新建 docx 让 AI 写段测试文本；两步都有响应即可开始日常使用。

macOS 装机多留一个心眼：dmg 挂载卷用完记得推出，应用本体已经进了「应用程序」文件夹，安装镜像留着没有意义；下载页同款位置的 zip 包是给不方便挂载镜像的场景备用的，两条路装出来的东西一致。

## 做完后的验证

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

## 它的局限也要说清楚

先把丑话讲在装包之前：

- web/dsh 形态只含五个编辑器、没有 HTML，也找不到购买与激活入口

## 下载环节的疑问

### 非官方渠道流出的 dmg 靠谱吗？

拿不准就别用。官方包只在自己发布的那两处入口流通，镜像站拿到的即使能装，安全性也无人背书。

### 麒麟/UOS 机器选哪个包？断网环境跑得起来吗？

选 .AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb。下载一次后可拷贝到内网机器直接安装/运行，应用本体不依赖联网。

## 拿包：分平台选择

第 1 步 · 下载安装包

进官方下载中心，按平台选择安装包：

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS | `.dmg`（另有 `.zip`） | macOS 11+；打开 dmg 后把应用拖入「应用程序」 |
| Windows | `.exe`（NSIS 安装向导） | Windows 10+；可选择安装目录；安装时注册 docx/xlsx/pptx/pdf/md/html 文件关联 |
| Linux（Debian/Ubuntu） | `.deb` | `sudo apt install ./…` |
| Linux（Fedora/RHEL/openSUSE） | `.rpm` | 用 `dnf` / `zypper` 安装 |
| Linux（麒麟/UOS/通用） | `.AppImage`（另有 `.deb`/`.arm64`） | 免 root、离线友好，适合信创与内网环境 |

## 安装与首次打开

第 2 步 · 安装并启动

1. macOS：挂载 dmg，把应用图标拖入 Applications，首次从启动台/应用程序打开；
2. Windows：运行 .exe 安装向导，按提示选择目录完成安装，从开始菜单/桌面打开；
3. Linux：按上表命令安装，或对 .AppImage 加执行权限后直接运行（无需安装、无需 root）。

## 装完怎么验证

验证

1. 启动应用后能看到标签条第一格为「察元AIOffice」首页标签，首次启动出现上述三页引导，三页标题依次为「欢迎使用 察元AIOffice」「这只是一个开始」「人人免费」。
2. 点「跳过」或「开始使用」后引导关闭；关闭应用重新打开，引导不再出现。

## 补充答疑

### 引导页被跳过了还能找回吗？

找不回。引导一生只弹一次，界面没有重放入口；想系统过一遍功能，按 F1 打开应用内图文手册（18 主题，支持搜索）更实用。

## 装机前的核对要点

- 操作系统：Windows 10+、macOS 11+、Linux（含麒麟/UOS，AppImage 要求 glibc 2.34+）。
- 包的来源判断标准很简单：官方发布渠道放出的才算数，其他途径拿到的一律存疑。

## macOS 安装版的能力点

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

## 桌面版独有与共享的能力

HTML 编辑器仅在桌面形态提供，web/dsh 形态拿不到；模型接入支持 BYOK 连 94 家供应商与本机 Ollama 等本地端点。PDF 涂黑走的是物理删除：生成 -redacted.pdf 副本，不是注释遮盖，脱敏后的文件可以直接外发。

## 数据处理的几条边界

搜索、数据库、浏览器这些 MCP 能力接进来，AI 面板就不止会改文档；chaoffice 命令行 17 个子命令把常用动作搬进终端。覆盖 Windows/macOS/Linux（含麒麟/UOS）三平台，但各形态能力并不完全对等，装包前按上文边界逐条核对。

苹果芯片与 Intel 机型的 dmg 是同一个发布渠道的不同包体，下载页会自动区分；拿错架构的包装不上，系统会直接提示，不会出现装上跑不稳的中间态。
