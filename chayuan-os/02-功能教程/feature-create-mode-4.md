# 运行时挂载插件避坑指南：边界、限制与对策

运行时挂载插件这个话题我被问过三次以上，每次都要重新讲一遍。与其反复口述，不如写成一篇：从创造模式的入口讲到验证，中间的分支也一并说清，基于察元AI OS。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（环境与模型就绪），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

试一次创造模式

1. 打开对话应用进入会话
2. 描述你要的应用：做什么、放哪里、多久更新
3. 智能体定义并挂载插件，权限门确认后生效
4. 桌面出现新应用，可继续让它迭代

迭代与沉淀

1. 对着新应用提修改意见，智能体原地升级插件
2. 满意后保留挂载，不满意右键卸载
3. 把好用的话术存进用户记忆，下次直接复用

## 进阶用法与边界

## 常见问题

### 创造模式生成的应用稳定吗？

生成的是标准 dsh 插件结构，挂载后与其他插件同等对待：可启停、可卸载、可随会话迭代。复杂逻辑建议拆成多轮对话逐步逼近。

### 智能体造应用时要授权吗？

挂载插件属于系统级操作，会过权限门确认；高危动作（跑终端、装依赖）按 T1/T2 分级再确认，全程留审计。

### 适合造什么样的应用？

信息聚合展示类（盯价格、汇总新闻）、简单工具类（倒计时、随手记）最合适；重度数据处理建议走正规插件开发。

## 安装与运行答疑

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

## 一个真实场景

出差与远程办公者的典型用法：提前在机器上配置远程访问，公网走出站云中继（可自建），手机浏览器镜像桌面操作。手机随时连回自己的 AI 工作站。注意：公网访问依赖云通道可用性，高安全环境建议仅局域网使用。

## 顺带了解

浏览器：内置浏览器窗，配合 webwindows 可被智能体驱动。

为什么值得看：不装第三方浏览器也能完成网页操作，智能体还能代劳。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 应用商店与离线分发

商店对接能力广场（aidooo.com），插件、技能、MCP 插件、智能体、技能包五类内容在线下载并云端推送更新，配排行榜辅助选型。内网环境走 .cop.tgz 离线包导入：导出即依赖闭包，导入逐文件校验，断网也能完成分发。

## 桌面应用与创造模式

任何网页、本机程序、HTML 文件都能封装成桌面应用（web、local、html、file 四种类型），可放桌面快捷方式也能嵌进壁纸当小组件。创造模式更进一步：智能体在运行时定义并挂载新插件，说一句要什么应用，它能把应用造出来挂上桌面。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 云桌面形态

整套系统可无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离，数据在服务器侧统一管理。默认只监听回环端口，暴露面完全自己控制，适合团队统一供给算力与知识库。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。
