### 它做对的那件事

做什么：写入与上面相同的 JSON（"mcpServers": { "chayuan-wps-mcp": { "url": … } }）。具体到操作面，WPS 加载项没连上这条在手册里写得很细。这句划重点，后面全是围绕它展开的。

协议内置「预览确认」：document_replace/document_insert/document_apply_ops 不带 confirmed: true 时只返回预览不落盘。要 token 的是加载项内部的 /agent/ 长任务通道和脱密等敏感通道，那由 WPS 加载项自己持有，外部客户端无需关心。
