# AI实时解说怎么开：每手点评设置指南

看模型下棋有个天然门槛：它走得妙你看不出妙在哪，它走得臭你也看不出臭在哪。没人报幕的棋局，外行只能看个热闹。AI实时解说就是给这场戏配的报幕员——每一手落定，点评跟着到。这篇讲清解说怎么配置、怎么开、怎么调出一副好听的解说席。

## 先弄清楚它是什么

AI实时解说是一种边打边讲的能力：对局进行中，由模型对每一手做点评，解说内容以实时流的方式跟着对局走，一手一条，节奏与棋局同步。它与赛后解说是一对兄弟——实时解说管「当下这手怎么样」，赛后解说管「整局怎么回事」，两篇配合食用，风味更全。

解说是谁讲的？也是大模型。竞技场里的模型调用是通用的，担任解说员的模型从你已接入的模型里出——这意味着解说的质量上限，由你给的解说模型决定。口才好的模型把一手棋讲得跌宕起伏，口才差的模型干巴巴一句「此步可行」；同样的对局，换个解说员就是两种观感。

它解决的问题是具体的：不完整信息玩法里，你只看得见公开信息，模型的下注动机藏在气泡里，普通观众读不出所以然，解说把这一层的门帘掀开；看不懂的规则细节（为什么这手必须缺门、为什么那样算诈唬），解说也能顺嘴带一句。观战体验的门槛，就这么降下来了。

## 开解说前挑好解说员

解说模型的选择是设置的核心，三步定人。一步看口才：解说吃语言表达，通用对话能力强的模型通常更胜任，尤其那些以文笔见长的。二步看速度：实时流讲求跟手，解说模型出得慢，点评就拖对局的后腿；响应快的轻量模型跟得上节奏，代价是点评偏浅。三步看钱包：解说每一次都是真实的模型调用，云端模型的费用按你的用量向厂商支付，挂一晚上解说就是一晚的额度；Ollama 本地模型零成本，适合长时间开着。

三样凑不齐时怎么办？经验做法是分工：观看节奏紧的对局配响应快的解说员，复盘性质的长局配口才好的解说员。解说员的挑法没有标准答案，换着听几次，你耳朵里自有一杆秤。

具体的解说模型选择入口与选项，以 0.1.0 版本应用内设置的实际呈现为准——进设置按解说相关的条目找，配置项不长，一眼就能配完。

## 配置与开启的步骤

第一步，备好模型池。解说员从你已配置的模型里来，模型池空着就无人在岗：设置 ＞ 模型配置里把要用的厂商与 Key 配好，「测试连接」通过、「获取模型」拉回列表，本地模型走 Ollama 免 Key 接入。

第二步，进对局找解说设置。开一局人机局或机机观战，对局室的解说相关设置里挑定解说模型，按上一节的口才、速度、费用三原则定人。

第三步，打开解说开关。开对局，开启实时解说，从这一手起点评开始随实时流滚动。之后你正常观战，解说员跟着棋局走，一手一评。

第四步，调观感。嫌吵就关，想听再开，解说开关的对局内随手可控；觉得点评太浅就换解说模型，觉得拖节奏就换更快的。解说是配菜，主菜永远是棋局本身。

第五步，打完接赛后。整局结束后想要一份从头讲到尾的完整讲解，赛后解说接得上，配合问叹号标注一起看，效果翻倍。

## 做完后的验证

开着解说打一小局，验证三件事：每一手之后解说有没有跟上（实时流通了）；点评内容与实际着法对得上号（解说员看得懂棋）；开关关掉后点评立刻停（控制权在你）。三样都对，这套解说席就算搭好了。

## 这些边界要心里有数

解说有成本：它本身是模型调用，云端解说员每一手点评都在消耗你的 API 额度，长局连开的账单要心里有数，本地解说员零成本但深度有限。解说有立场：它是一家模型对棋局的一家之言，偶尔会把妙手说平、把臭棋说稳，听个参考，别当判决书。解说有延迟：解说模型出得慢时，点评会落在棋局后面，实时感打折——这就是为什么挑解说员时速度很重要。弱模型解说的内容质量也不稳定，车轱辘话与错误判断都可能出现。界面与开关的具体位置以 0.1.0 实际呈现为准。

## 高频疑问

### 实时解说与赛后解说是不是一回事

不是。实时解说跟着对局走，一手一评，重在当下；赛后解说在整局结束后生成，从头讲到尾，重在来龙去脉。两篇搭配，观感完整。

### 解说用什么模型比较合适

口才与速度之间做取舍：重节奏选响应快的，重内容选表达强的。拿不定就都试一局，你的耳朵会替你选。费用敏感就用 Ollama 本地模型当解说员。

### 开解说会剧透匿名观战的座位身份吗

不会。匿名观战的座位身份到终局才由对局引擎揭晓，解说的点评围绕局面与着法展开，这条规则不会因为开了解说而改变。

### 解说能一直开着不管吗

技术上可以，账单上要清醒：云端解说按用量计费，长时挂机把解说一并开着，额度烧得更快。挂机长看建议换本地解说员或干脆关掉。

### 解说的点评可以关掉某个座位吗

解说按对局进程逐手点评，颗粒度以应用内实际能力为准。嫌密就先关开关，观感自己调——解说席的音量键在你手里。

AI实时解说这套东西，本质上给棋局雇了个懂球帝：你负责看，它负责讲，模型的每一次落子从此有了旁白。开不开、谁来开、开多大声，都在你的设置里——把解说席搭顺了，机机观战才真正从看棋升级成看戏。
