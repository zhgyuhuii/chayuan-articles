# 插件启停排查路径：技能清单双域

插件启停这件事，值不值得专门学一篇，看一个细节就够：插件全生命周期管理。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 先定位问题在哪一层

插件启停的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把插件/技能安装的来源是应用商店；本篇只讲装完之后的管理。核一遍，再查路径。

## 正确的操作路径

第 4 步 · 技能页签：清单与启停

页签「技能」，标题「技能（共 {total}）」，计数「技能 · 项目 / 用户根目录」，说明「按发现顺序：项目 ＞ 用户根目录；插件附带的技能随插件装卸」。列表按发现根分组（组头显示根名与路径，发现顺序）：

每个技能行：状态点（绿 = 「模型可调用」 / 灰 = 「已停用模型调用」）、名称（前缀）、来自商店技能包的带「{包名} · v{版本}」徽标（悬停「来自技能包 {pack}」）、描述；行尾三个按钮：

空态提示「暂无技能。把含 SKILL.md 的技能目录放入下列任一根目录即可被发现。」

1. 项目 ＞ ~/.dsh/profiles/web/.agents/skills（dsh web 工作区的项目技能根；DSH_HOME 环境变量可改根目录）
2. ~/.dsh/skills（用户技能根，商店技能包装在这里）
3. ~/.agents/skills
4. 「停用 / 启用」：改写该技能 SKILL.md 头部的 disable-model-invocation 开关——停用后模型不再调用它，技能文件仍保留；
5. 「打开目录」：系统文件管理器定位到该技能目录；
6. 「删除」：把技能目录移入系统废纸篓（可恢复）；商店包技能删除时会同步清掉安装记录（已购 token 保留，商店重装免再付费）。

第 5 步 · 技能离线导出与导入

标题行右侧「导出」「导入」。

1. 导出：点「导出」＞ 浏览器下载 chatop-skills.tar.gz（打包 ~/.dsh/skills 下全部含 SKILL.md 的技能目录；无可导出内容时报「没有可导出的技能」）。
2. 导入：点「导入」＞ 选择 .tar.gz / .tgz 文件 ＞ 解压落入 ~/.dsh/skills，列表刷新；结果回显「已导入：{names}」，重复的显示「（无新增，已存在跳过）」或「（跳过：{names}）」。

## 如何确认操作生效

验证

1. 插件页签：停用一个插件 ＞ 图标变半透明、下标变「已停用」、计数「启用」数字减 1；再点恢复。
2. 技能页签：装过技能包的机器上能看到带 徽标的技能行；点「停用」＞ 绿点变灰、按钮变「启用」。
3. 技能「导出」得到 chatop-skills.tar.gz；在另一台机器「导入」后技能列表出现同名条目。

## 高频疑问

### 技能删掉就彻底没了吗？

没有。「删除」是移入系统废纸篓（macOS 进 ~/.Trash、Linux 进 XDG 回收站、Windows 进专用目录），可从废纸篓找回。

### 我自己放的技能目录没出现在列表里？

技能目录必须含 SKILL.md 才会被发现；放到上述三个根目录之一后重开应用管理即可。注意「项目」根只认 dsh 工作区 profile 下的 .agents/skills，随便放的目录不算。

### 「创建插件」和商店装插件有什么区别？

商店装的是别人发布好的插件；「创建插件」是现场做一个自己的——桌面版走本地向导（名称/描述/图标/颜色），host/web 形态引导你去 DeepSeek Harness 的「创造模式」让 Agent 现场编写并挂载。

## 动手前再核对一遍

- 插件/技能安装的来源是应用商店；本篇只讲装完之后的管理。
- 系统内置插件不可卸载，只能停用：chatop-shell、chatop-kb、chatop-models、chatop-agents、chaoffice（随系统分发的五件套）。
- 离线通道有两种形态：桌面版走系统文件对话框（.dshpack / .cop.tgz）；host/web 形态走浏览器文件选择（.tar.gz / .tgz）。导出内容单包上限 1GB。

## 放回产品盘面看

把插件启停放回察元AI OS的整体盘面：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注，共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道。

## 安全与数据边界

安全口径单独立一层：一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全，隐私敏感环境先关遥测再干活，处置设备前清数据；（本机 MCP HTTP 服务，回环免 token），敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计。

平台与形态的账：内置浏览器窗，配合 webwindows 可被智能体驱动，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌。
