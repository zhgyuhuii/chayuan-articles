# 检查段落序号格式进阶技巧：从入口到完成的完整流程

序号格式检查是察元AI文档助手里使用频率很高的一项能力。它的「检查段落序号格式」这样工作：针对公文、标书、制度文件的编号体系（一、（一）、1.、（1））做一致性检查，输出分级结论与修改建议，默认不改写正文。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

针对公文、标书、制度文件的编号体系（一、（一）、1.、（1））做一致性检查，输出分级结论与修改建议，默认不改写正文。

从任务视角看，它对应的关键词是「序号格式检查」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 打开公文/制度文件，发起「检查段落序号格式」
2. 查看分级结论（哪里跳号、哪里体例混用）
3. 按建议手动调整或确认后批量修正

## 实用技巧

- 公文编号错误是退文高发原因，发文前必查

## 注意事项与边界

- 本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 常见问题
### 支持国产化环境吗？

支持麒麟、UOS 等国产化环境（arm64/x64），真机验证过 Ubuntu arm64 + WPS Office 12.1 组合。

### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。

### 能在完全断网的环境用吗？

能。配置 Ollama 或任意 OpenAI 兼容内网网关后全部功能可离线使用；安装包内嵌 sidecar 二进制并注册自启，适配离线与内网部署。
