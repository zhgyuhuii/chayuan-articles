# 覆盖升级装机指南：设置关于里检查更新、下载并重启安装

很多人搜「察元OS 怎么升级？在哪里检查更新」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把覆盖升级从打开哪个应用讲到看到什么结果。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：升级不丢数据的机制。

安装包从官网 aidooo.com 获取。

## 操作步骤详解

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 边界先摆桌面上

边界先摆在桌面上：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 「检查更新失败」怎么回事？

多为网络访问 GitHub Releases 失败。按提示「可到 Releases 页手动下载」：Releases 页地址为 https://github.com/zhgyuhuii/chayuan-harness/releases，手动下载最新安装包覆盖安装即可。

### 更新会丢数据吗？

不会。安装包只更新程序文件，你的数据根目录不动（帮助中心 ＞ 参考 ＞ 常见问题 FAQ 同口径）。

### 点「检查更新…」却打开了一个网页？

那是网页（浏览器）形态：没有桌面更新桥，按钮降级为打开官方站点页。完整的检查-下载-安装流程需要桌面安装版（察元AI OS 桌面应用）。

## 更多操作细节

第 1 步 · 打开「关于」面板

两个入口，打开的是同一个面板：

面板内容从上到下：察元 logo、名称「察元」、副标题「察元AI OS · 离线 AI 办公助手」、等宽字体的版本号 v{X.Y.Z}、厂商行「厂商 北京智灵鸟科技中心」、版权行「© {年份} 北京智灵鸟科技中心 版权所有」。版本号单一来源是 dsh-plugin/package.json 的 version（打包时自动同步外壳，关于窗口与设置分区都从这里取，杜绝手写过期）。

1. Dock ＞ 「设置」＞ 左栏「关于」，内容卡片标题「察元」；
2. 屏幕左上角察元菜单（logo 菜单）＞ 「关于 察元」，弹出独立关于窗口。

## 更多操作细节

第 2 步 · 「检查更新…」

1. 做什么：点面板下方的「检查更新…」按钮。
2. 状态行按结果变化（就在按钮下方，进度实时刷新）：
    1. 检查中：显示「正在检查更新…」；
    2. 已是最新：显示「已是最新版本」；
    3. 有新版本：自动开始后台下载（无需再点下载），状态行显示「下载更新中 {p}%」实时走百分比；按钮下方同时显示新版发布说明摘要（取自 Releases 的 releaseNotes，剥掉 HTML 按纯文本展示，最多 400 字）；
    4. 失败：显示「检查更新失败（可到 Releases 页手动下载）」，并在后面附具体错误原因。
    5. 没有自动检查：开机、日常使用中都不会自动检查更新，只有点这个按钮才检查。

## 更多操作细节

第 3 步 · 「重启并安装」

1. 下载完成后，状态行变为「已下载 v{新版本}，重启完成安装」，下方出现蓝色按钮「重启并安装」。
2. 做什么：点「重启并安装」＞ 应用退出并自动安装新版，装完自动重启回到桌面。
3. 不点它也没关系：已下载的更新会在下次正常退出应用时自动安装（安装器开启 autoInstallOnAppQuit），再开机即是新版。
4. 设置分区和独立「关于 察元」窗口是同一个面板、同一份更新状态：一边看下载进度，另一边打开也是同样的状态行（状态由主进程实时推送）。

## 更多操作细节

验证

1. 升级完成后重新打开 设置 ＞ 关于，等宽版本号应显示为新版本号。
2. 下载过程中可以关掉设置页去干别的；重新打开关于面板会拉取当前更新状态（进度/已下载/出错都会照常显示）。

## 补充答疑

### 下载进度一直不动 / 下载中断了？

重新打开关于面板看状态行；若已报错会显示失败原因（网络断续常见），网络恢复后再点一次「检查更新…」重新下载即可。

### 为什么从来不弹更新提醒？

产品采用手动检查模式：不静默检查、不强更。想升级时到 设置 ＞ 关于 点一次「检查更新…」。

## 动手前再核对一遍

- 完整检查更新流程仅桌面（打包安装）形态：需要 Electron 更新桥（chatopDesktop.updateCheck），更新源为 GitHub Releases（发布通道在 desktop/electron-builder.yml 里配置 provider: github）。
- 网页形态没有更新桥：点「检查更新…」不进入检查流程，而是在新窗口打开官方站点页（aidooo.com，见「形态差异」）。桌面开发（未打包）形态有桥但接的是空更新器，检查恒显示「已是最新版本」。
- 检查与下载需要能访问 GitHub Releases 的网络。

## 放回产品盘面看

把覆盖升级放回察元AI OS的整体盘面：智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明；打开即看，不挑格式，系统级默认打开体验；WebRTC 局域网共享桌面：主机、编辑者、观看者三级角色，共享房间与连接终端状态，换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。

## 安全与数据边界

安全口径单独立一层：远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。
