# 国产办公软件入门指南：个人替换订阅制办公软件

国产办公软件的搜索人群跨度很大：信创采购里的政企 IT、不想续订订阅的个人用户、只想找个离线工具的学生都在其中。这篇把装机形态、能力面与边界放在一起讲，以察元AI Office 为观察对象。

## 什么是国产办公软件

这篇讨论的国产办公软件，指能在国产系统与常规桌面环境都落地的办公套件。观察对象是察元AI Office（Chayuan AI Office）：Apache-2.0 协议下的开源 AI 办公套件，六个编辑器收进同一个应用，AI 嵌在各编辑器里，入口、步骤与边界俱全。

文中条目对照官方文档写就，版本与截止时间以尾注为准。

## 装机这件事

落点是下载安装与首次启动：Windows 走 NSIS 安装器，macOS 走 dmg，Linux 有 deb、rpm 与 AppImage 三种（AppImage 需 glibc 2.34 以上）；安装包从官方分发渠道获取，来源不明的镜像站别碰。

装机之所以值得先讲：国产环境里，安装形态决定能不能进门；进了门，才有资格谈能力。首次启动后先把设置面板的十个分区过一遍，语言与模型端点定下来，后面的使用会顺很多。

## 更新与反馈的通道

国产软件的另一个常见顾虑是更新节奏。它提供 stable 与 beta 双更新通道，外加手动检查更新；求稳的留在 stable，想早试新功能的切 beta，升级时机由用户自己掌握，这在管理严格的内网里尤其重要。反馈走在线客服通道，遇到问题有出口，不至于闷头排查。

## 最短上手路径

从这几步开始：

1. 核对系统与包形态的对应关系（共三平台五形态）
2. 确认安装权限：免 root 可装
3. 麒麟与 UOS 环境在 AppImage 与 deb 里选一种
4. 场景验证：政企内网批量装机
5. 场景验证：个人替换订阅制办公软件
6. 串联场景：Docs 写正文，察元AI 页签全文校对出批注

## 落点的能力面

- 安装包覆盖三平台五形态
- Linux 免 root 可装
- 麒麟与 UOS 有对应的包

## 能力板块速览

- PDF 阅读：五页签功能区的阅读器，拖选浮条带高亮、下划线、删除线、复制与问 AI，另有便签线程、书签、目录。
- PDF 真文本编辑与涂黑：基于 PDFium wasm 重写页面内容流，保留原字体，涂黑不是注释遮盖。
- PDF 签名与页面操作：手绘、图片、证书（p12 与 pfx）三种签名；页面页签支持旋转、重排、拆分、合并、Bates 编号、打印。
- 命令行：chaoffice 名下共 17 个子命令。
- 反馈与更新：在线客服反馈、stable 与 beta 双更新通道、手动检查更新。
- dsh 插件与 web 形态：察元AI OS 内以插件形态使用，或自建网页版（生产端口 52587），五编辑器（无 HTML）。

## 三问三答

### 国产办公软件离线能撑住日常吗？

本地优先、离线可用。AI 能力跟着模型配置走（BYOK 或本地端点），端点放本机时离线照样用；没配模型就只剩传统办公功能。

### 文档格式上有什么门槛？

打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；老格式给出明确提示，转存新格式再开。存量的老文档先批量转一遍，日常就顺了。

### 装在老机器上有什么要求？

Linux 的 AppImage 包要求 glibc 2.34 以上；其余平台按各自安装器的提示走即可。

## 个人用户的切换节奏

个人用户切换时最实际的两件事：格式与肌肉记忆。格式上，打开路由表覆盖主流格式，老格式转存即可；肌肉记忆上，常用操作的键位要重新记，前几天会慢，属于正常成本。建议按文档类型逐个切：先文字稿，再表格，最后演示，每类给几天适应期，比一刀切切换从容。

## 两处形态差异要知道

仅桌面形态提供 HTML 编辑器；Linux 侧没有系统 OCR 引擎，扫描页以位图保留、不识别。跨形态、跨系统混用的团队，这两条要写进验收单，免得上线后才发现形态对不上需求。HTML 编辑器的缺席对多数团队无感，网页类文档通常另有专门工具；OCR 那条则直接影响扫描件归档流程，涉及档案数字化的单位要先把扫描件预处理好再入库。

## 隐私与设置数字

文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代；Key 不出本机；首页会话本机最多 50 个。设置面板分十个区：通用、语言（22 种）、主题、模型、知识库、隐私等，通用区逐项可调。

## 助手与 MCP

通用对话得亲手写提示词，领域助手则把行业 knowhow 封装成一键执行；端口 52588 上的壳内 MCP 服务，把文档操作能力开放为 MCP 工具；模型接入支持 BYOK，94 家供应商与本机 Ollama 等本地端点都在目录里。目录这么宽的实际好处：换供应商不用换软件，供应商目录里的任何一家都能接进来，迁移成本被压在配置层。

## 表格、演示与智能体

表格侧透视表与公式引擎是硬指标，自研边车保证 xlsx 往返不失真；演示侧录课与路演的旁白在放映态内录完，不用第二个软件；文档能力还能开放给外部智能体直接调用，写代码调文档接口不必翻文档。这几项与国产化无关，属于任何办公套件都该过的基本盘。验收方法也简单：拿一份带公式的存量 xlsx 打开另存、比对结果，录一段旁白存盘回放，智能体调用走一次 MCP 端口，三步都过，基本盘就验完了。

## 一句收束

国产办公软件的选型，别被「国产」二字带节奏：装机形态、格式覆盖、离线条件三条过关就是合格选项；三条过不了关，情怀撑不起日常使用。
