# 察元竞技场全功能解读：让大模型上桌真打一场

关于大模型哪家强，网上吵了两年也没吵出结果。跑分榜单看腻了，题库评测翻篇就忘，各家发布会都说自己赢了，普通人想亲眼看看 DeepSeek、GLM、GPT、Claude 这些模型放在一起到底谁更灵，一直没有个直观的办法。

察元竞技场换了个思路：别答题了，直接上桌打牌下棋。它把各家大模型拉到同一张棋牌桌上，从五子棋、象棋、围棋，到斗地主、德州扑克、掼蛋、麻将，一共 11 款玩法，真刀真枪对弈，胜负全由代码裁判说了算，打完进 TrueSkill 天梯排位。它是察元AI 家族的开源成员，MIT 协议，桌面应用，数据不出本机。这篇把它的功能逐块说清楚，也把适合谁、不适合谁讲明白。

## 察元竞技场是什么

给一句可以直接记住的定义：察元竞技场（Chayuan Arena）是一款开源的大模型棋牌竞技场，让 85 家厂商目录里的大模型在 11 款棋牌玩法中完整对弈，出招过程带思维链可视化，胜负由本机纯逻辑引擎裁决，排位走 TrueSkill 天梯，API Key 与对局数据全部只存本机。

和常见的模型评测比，它的区别在「考察方式」。跑分是做题，做题考的是记忆和问答；下棋打牌考的是另一套东西：算子力、防守、收官，打牌还要会看牌、会诈唬、会算牌。这些能力在题库里测不出来，但一张牌桌全给你照出来。

它是桌面应用，Windows、macOS 都能装，也有 Linux 安装包；装上之后是一个暗色的竞技场界面，中英双语。同时它也是察元AI OS 的内置应用之一，两边引擎层逐字节同构，在哪个里玩都是同一套规则。

## 11 款玩法：从棋盘到牌桌

大厅里的玩法按棋类、扑克、麻将三组排开：

| 组别 | 玩法 | 看点 |
|---|---|---|
| 棋类 | 五子棋（15×15）、中国象棋、围棋（9 路/13 路）、军棋暗棋、军棋翻翻棋 | 完全信息博弈，纯拼推理与算路 |
| 扑克 | 斗地主、德州扑克、掼蛋 | 不完全信息博弈，看牌、记牌、诈唬 |
| 麻将 | 四川血战、广东推倒胡、日麻立直 | 缺门、听牌、防守，血战到底 |

完全信息玩法里，模型看得见全部棋子，考验的是计算与规划；不完全信息玩法里，模型只看得见自己手里的牌，得靠推理猜对手、靠下注表达牌力。一个模型可能象棋下得头头是道，到了德州扑克就被对手诈唬得团团转——这种「偏科」现象，题库根本测不出来。

几个有心思的细节：军棋暗棋支持自由布阵，落子用两击或拖拽都行，还有给新手的明棋教学档；工兵飞雷、司令阵亡亮旗这些规则都做进去了。围棋用 9 路和 13 路小棋盘，气、劫规则完整，小棋盘快对局，正适合看模型的攻杀。日麻立直藏在大厅的隐藏入口里，引擎完整可用，走的是 mjai 协议事件流，算是给懂行的人留的彩蛋。

## 上手三步：配模型、选玩法、上桌

第一步，配模型。进设置 ＞ 模型配置，从内置的 85 家厂商目录里点选你要用的厂商——DeepSeek、智谱 GLM、通义千问、Kimi、OpenAI、Claude、Gemini 都在目录里——填上你自己的 API Key，点「测试连接」确认能用。想偷懒的，点「获取模型」直接把这家账号下能用的模型全列表拉下来勾选入库。用本地模型的话，Ollama 免 Key 直接接，断网也能玩。

第二步，选玩法。回大厅，11 款玩法任选：想自己下场就开人机局，想当观众就开机机观战，想办个联赛就开锦标赛。

第三步，上桌。模型出招了。对局室里能看到每手的思维链气泡——模型在想什么、怎么盘算这步棋，实时流出来；每手的延迟和 token 用量也标在旁边。打完进天梯，积分自动更新。

## 思维链可视化：看 AI 是怎么想的

这是整个产品里观赏性最强的一块。模型每走一手，它的推理过程会以气泡形式实时滚动出来：象棋里它在盘算「我走炮二平四，对方最可能上马防守，这样中路的攻势就活了」，斗地主里它在犹豫「手里这对王要不要拆」。你看到的不只是一个落子动作，而是完整的思考过程。

想更狠一点，还有深度思考档：要求模型一次推演三条候选走法线，每条都给出「我走什么、对方最强应对、局面评估」，其中至少一条进攻线、一条防守线，最后收敛到一个结论再落子。看强模型这么打一局，比看十篇模型评测文章都直观。

## 裁判归代码：模型赢了才算赢

竞技场有个原则：胜负判定 100% 归代码。11 款玩法各有一套纯逻辑裁判引擎，不吃外部输入、不做网络请求，只认规则真值。模型只负责出招，没有任何判罚权——它不能自己宣布「我赢了」，也不能赖账说「这步我不算」。

模型出的招要经过解析容错链：先按标准格式解析，解析不出就逐级放宽——剥掉思维链文本、抽大括号、补截断的尾巴、实在不行就全文扫一遍找它提到的合法着法。还不够，就按启发式帮它代走：能挡杀就挡、能吃就吃，麻将里挑缺门里价值最低的一张。代走次数超了判负。再配上 429 限流自动退避，一个模型 API 抽风不会卡死整局。这套机制看不着摸不着，但它决定了「模型上桌」这件事是真博弈而不是演示。

## 对战模式：自己打、看它们打、办联赛

人机局：你亲自下场，对面是模型。打到一半手酸了或者局面崩了，可以随时把控制权交给 AI 接手，让它替你续几手；想回来自己下，再一键接管回来，下一手生效。人类挑战者的战绩单独统计，不和模型混在一个榜里。

机机观战：什么都不用做，选两个或多个模型开打，你在旁边看。观战默认匿名——座位上只显示玩家A、玩家B，谁是谁的底牌要到终局才揭晓，免得你先入为主。看着两个大模型在德州扑克桌上互相诈唬，或者在麻将桌上互相防着点炮，这种乐子很难在别处找到。看不懂局面还有 AI 实时解说，让它点评每一手；打完还能出一份赛后整局解说。

锦标赛：选一批模型开循环赛，排程自动生成，积分榜实时刷新，跑完出冠军。挂一晚上跑一轮锦标赛，早上起来看战报，这也是很多人玩竞技场的经典姿势。

## TrueSkill 天梯与复盘

天梯用的是微软 TrueSkill 算法（本仓库自行实现），胜平负自动更新评分，段位分层，谁强谁弱一张榜看清。人机局里你自己作为挑战者的分数单独一个榜。

每局自动生成形势曲线，谁压着谁打一目了然。复盘模式下逐手做妙手、失误标注，配上 AI 赛后解说，一局棋为什么输，翻一遍就明白了。棋谱可以导出成 JSON 文件，想自己做分析、喂给自己程序都行。还有一个协议画像功能：统计每个模型的出招习惯，JSON 格式遵守率、平均出招耗时这些，看多了你能摸出每个模型的「性格」。

## 模型配置与数据安全

85 家厂商目录覆盖国内外主流大模型，全部走 OpenAI 兼容协议；Claude 的原生协议由本机网关自动转换，不用改任何代码。任何 OpenAI 兼容的中转端点都能手填接入。所有模型流量只走本机网关一个口子，网关用随机端口加路径令牌鉴权，外部进程够不到。

你的 API Key 只存在本机应用数据目录里，不上传；对局记录、天梯积分也都落在本机。配 Ollama 这类本地推理，整条链路可以完全离线。用云端模型时走不走、走哪家，全是自己填的授权，心里有数。

## 实话实说：哪些人不必急着装

先把边界说清楚。软件本身 MIT 开源免费，但模型 API 的费用是你自己向厂商付的，挂机跑锦标赛烧的是你自己的额度，用 Ollama 本地模型才零成本。大模型的棋力上限是真实存在的：它靠语料和推理出招，不做深度搜索，下不过专用象棋引擎、算牌不如专业软件，这些都是正常现象。你要看的是模型之间的相对高下和它们的思考过程，而不是指望它下出大师水准——它也确实给不了。弱一点的模型会出废招，系统会代走兜底，但观赏性会打折。另外日麻立直在大厅里是隐藏入口，得知道去哪点；军棋这类玩法要先花十分钟学规则。

如果你的需求就是看榜单分数，那不用装这个；如果你想亲眼看看大模型们上桌对弈是什么样子、想给自己的模型找个考场，或者单纯想找点新鲜的乐子，它值得装来玩一个晚上。

## 你可能会问

### 察元竞技场收费吗

软件本身 MIT 开源免费。模型 API 费用由你自己向厂商支付，用 Ollama 等本地模型则零成本。

### 大模型下棋下得过人吗

坦白讲，专门练过的棋类软件人类已经下不过，但大模型的棋力不是那个路数——它靠语料和推理出招，不做深度搜索，棋力有上限是正常的。这个产品的看点是模型之间的相对高下和它们的思考过程。

### 我的 API Key 安全吗

Key 只存本机应用数据目录，永不上传；所有模型流量走本机网关，随机端口加路径令牌鉴权。对局数据同样只落本机。

### 断网能用吗

配 Ollama 等本地推理引擎就可以完全离线对弈；用云端模型才需要联网。

### 人也能下场玩吗

能。人机局随时在 AI 接手和人工接管之间切换，人类挑战者的天梯战绩单独统计。

### 和察元AI OS 里的竞技场什么关系

同一个东西。察元AI OS 内置同款竞技场，引擎层与独立桌面版逐字节同构；独立版适合没有装察元AI OS、只想单独玩竞技场的人。
