# 麒麟系统跑AI：AI 桌面操作系统

飞腾鲲鹏都能跑的 AI 桌面。用了两周，认真说说感受，好的坏的都讲。

先交个底：麒麟系统跑AI是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面环境总览是其中面向这类需求的一环。

## 我的使用顺序

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 三个点，两好一坑

下面几条是真实用出来的体感，不是参数表搬运：

1. 完整桌面范式
2. 42 张内置壁纸

## 也要说实话

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

适合谁：给政企用户完整的桌面迁移体验、低配机关动效保流畅这类需求的人。不适合谁：上面几条缺点正好戳中的场景，别硬上。

## 评论区高频问题

### 麒麟系统跑AI要联网吗

购买 OS 授权后，同机察元AI Office 自动免激活，很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配，完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。以官网 aidooo.com 当前页面为准。

### 麒麟系统跑AI数据存在哪

升级不丢数据是底线，检查更新静默失败不影响使用，它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把麒麟系统跑AI放回察元AI OS的整体盘面：定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见；可选群分区（桌面出图标双击进群）；知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，点击互跳定位原文。

## 安全与数据边界

安全口径单独立一层：恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网，本地 AI 出题验证；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集，智能体动系统能力分级确认：T0 只读直放。

## 平台与形态

平台与形态的账：购买 OS 授权后，同机察元AI Office 自动免激活；:52581（OpenAI 兼容统一模型代理），很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配。

## 价格与授权

价格口径一并交代：让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感，工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复；灵宠把后台跑着的 AI 变成桌面上看得见的小生物，AI 纪要一键生成。

## 产品家族与搭配

察元AI OS不是单打独斗：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配，完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入，保存后随系统技能分发到智能体。

## 几条硬数字

能落到数字上的几条：不同宠配不同模型是群聊多模型讨论的前提，轻任务宠配小模型、主力宠配旗舰；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；双击模型直跑灵宠直达；多个大模型开始围绕它讨论；单个模型有偏好也有盲区。

## 离线与内网

离线内网这条线的口径：本地模型解决有无问题，复杂任务还是需要云端旗舰模型；国内/国际/本地/聚合四组厂商目录；下载几个 GB 的权重需要时间与磁盘空间；GGUF、whisper 权重可以按路径直接导入（零拷贝）。

## 能力总账

把察元AI OS的能力总账摊开：统一应用到智能体，设置结果分发到智能体侧；还有可复制的各家智能体配置片段，各家智能体配置片段一键复制。
