# 助手收藏的底层逻辑：它为什么这样工作

写这篇的起因是群里有人问助手收藏，我发现自己也说不完整，索性把察元AI文档助手里的助手管理从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 它是什么，为谁服务

「助手管理」是设置窗口里的「助手设置」页：在这里统一启停内置助手、编辑助手参数、按分组整理排序、复制/删除/导出自定义助手；改完保存会同步刷新顶部菜单与右键菜单的助手入口。

四千多个助手，管理方式决定调用效率。

先把这个定位立住，再看步骤。

## 机制拆解

四千多个助手，管理方式决定调用效率。

能力面拆开看：搜索与收藏；领域浏览。

一个常被问到的问题：为什么我的助手管理里字段比别人的少。设置页按宿主分流：表格/演示端只管理各自的配方助手，可编辑字段也少（名称、说明、配方提示词、触发方式）；4526 个文档领域助手与完整字段要在文字（文档）端打开。

从提问口径看，用户最关心的是助手管理入口在哪里，怎么把不用的助手关掉？

## 完整操作步骤

按最短路径验证一遍：

1. 打开助手管理

1. 入口一（功能区）：「察元AI助理」选项卡 ＞「AI助手」组 ＞「助手管理」按钮。弹出独立设置窗口（窗口标题「助手管理」，约 1000×680），左导航自动定位到「助手设置」页签。
2. 入口二（面板）：AI 助手窗格侧栏底部齿轮「设置」按钮 ＞ 左导航点「助手设置」（左导航依次为：模型设置/默认设置/助手设置/常规设置，常规设置下还有数据设置、知识库设置、MCP 服务管理三个子页）。

2. 认识「助手设置」页布局

1. 左栏「助手设置项」：按分组折叠列出全部助手，组名右侧有数量；工具栏按钮（文字端）从左到右是「导入助手」「新建分组」「从智能空间同步」。分组标题行有一行提示：「可拖拽排序，右键菜单可复制、删除、上移、下移」。空分组里显示「将自定义助手拖到这里，或点击新建分组后在右侧创建助手」。
2. 右栏「助手设置」：点左栏任一助手后显示它的完整配置。

3. 启用 / 停用助手

1. 在左栏点选一个系统助手（如「拼写与语法检查设置」）；右栏头部右侧有一个开关。
2. 关掉开关并保存：该助手从功能区顶部菜单与右键菜单的入口消失（文档端侧栏「助手」页签清单仍会列出它，方便以后重新启用）；再打开开关即恢复。表格/演示宿主的配方助手停用后还会从面板侧栏隐藏——「停用后该助手将从面板隐藏」（设置页原文提示）。
3. 自定义助手没有启用开关，不想要就右键「删除」。

## 几个容易忽略的细节

用之前要认的账：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 接着回答几个常见问题

### 为什么我的助手管理里字段比别人的少？

设置页按宿主分流：表格/演示端只管理各自的配方助手，可编辑字段也少（名称、说明、配方提示词、触发方式）；4526 个文档领域助手与完整字段要在文字（文档）端打开。

### 停用的助手去哪了？会不会丢配置？

停用只是隐藏入口，配置原样保留；回到助手管理把开关打开再保存即可恢复。

### 提示「顶部菜单同步失败，请稍后点击保存重试」怎么办？

这是功能区（另一个 webview）刷新动作偶发失败，助手数据已经存上。回到设置窗口再点一次「保存」，让菜单刷新补做一遍；仍不生效就关掉 WPS 文档重开。

### 设置窗口里的「助手市场」页能一键安装助手吗？

不能。「助手市场」（/marketplace，独立页面）目前是纯展示页：按「内置/扩展/领域/第三方」四类来源汇总助手清单，支持按名称/标签/描述搜索、按分组与来源过滤，卡片上只有信息没有安装按钮。要新增助手请走「导入助手」（JSON 文件）或「从智能空间同步」。

## 更多操作细节

4. 编辑、排序与整理

1. 编辑参数：左栏点选助手 ＞ 右栏改字段 ＞ 点窗口底部「保存」。内置助手可改后用「恢复默认模板」一键还原。
2. 组内排序：直接拖拽助手条目到目标位置，也可右键用「上移」「下移」微调。
3. 复制为新助手：右键 ＞「复制为新助手」，生成一个副本进入编辑，重名会自动追加序号。
4. 删除：右键 ＞「删除」（仅自定义助手可删；内置助手不可删）。
5. 新建分组：点「新建分组」输入组名；在助手配置里把「所属分组」填成新组名也可以创建分组。

5. 保存与顶部菜单同步

保存助手配置后，产品会同步刷新顶部菜单/右键菜单的助手入口。如果个别同步动作失败，会给出单独提示（如「智能助手已删除，但顶部菜单同步失败，请稍后点击保存重试」「助手已导入，但同步到顶部菜单失败，请稍后点击保存重试」）——配置本身已保存，按提示再点一次「保存」即可补齐刷新。

## 安装与运行答疑

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。
