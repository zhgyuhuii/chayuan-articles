# 开局记忆原理：同型局面不再重复犯错

同一个开局陷阱，模型上一局刚栽过跟头，这一局又原模原样栽进去——不带记忆的对手，教训是白教的。察元竞技场给引擎层配了开局库，用开局记忆把摔过的跟头记下来，同型局面再出现时，上一次的坏下场就摊在桌面上，模型不至于在同一处反复付学费。这篇按记忆组织、命中复用、适用边界的顺序，把开局记忆原理讲透。

## 开局为什么最需要记忆

一局棋的套路化程度，从开局到残局是递减的。开局阶段分支虽多，套路却高度收敛：流行定式、常见陷阱、经典坏棋，翻来覆去就是那些。模型的规则记忆偏偏又不可靠——把「你现在能走哪些」白纸黑字列成合法清单才能压住非法出招率，这是喂局设计里已经验证过的判断。规则记忆靠不住，经验记忆同样靠不住：模型不会自己记住「上一局我在这走了那手坏棋」，它的每一局都是失忆重开。

开局记忆补的就是这块短板：把跨局的教训持久化下来，让同一个坑不必摔两次。它住在 src/arena/ 引擎层，与 TrueSkill 评分、对局引擎同层，是竞技与复盘能力里横跨多局的那一类——单局内的曲线与标注定格一局棋，开局记忆管的是局与局之间的事。

## 记忆怎么组织

开局记忆的锚点是局面。所谓同型局面，直接的理解就是走到了同一个地方：棋类里，着法序列是天然的钥匙，两家从同一条开局线走进去，中盘之前的局面高度重合；牌类里局面由洗牌随机主导，同型的概念淡得多，记忆的主战场在棋类玩法。

记的内容不止一层。走过什么是一层，走过之后的下场是另一层，而后者才是「避免重复犯错」的精髓：把一手棋和它带来的坏结果挂在一起，下次同型局面出现，这笔账就跟着局面一起翻出来。这与人类棋手的复盘习惯同构——人记棋谱也不是背每一步，是记住「这步走过，后果不好」。

组织粒度上有一道现实的取舍：锚定太细，精确到每一步每张牌，记忆几乎不命中；锚定太粗，只看子力形态，教训容易张冠李戴。同型判定具体怎么实现、粒度取在哪，以仓库代码为准，但方向是明确的：开局段命中率高，越往后越难命中。

## 命中与复用

同型局面再次出现时，库里那条记录就进入这一手的参考。它的作用路径延续喂局的老原则——着法与事件历史优先于棋盘图示：历史维度上多出一段「这条线此前走到过某处，结局不佳」的经验，模型拿到的不再是干巴巴的局面陈述，还附带一份前车之鉴。

复用的价值随对局深入衰减。开局十几手内同型概率可观，中局之后局面分岔指数级增长，记忆命中率骤降——这也是它叫开局记忆而不叫全局记忆的原因。同一批模型反复对练，库会越养越厚，教训的覆盖面越来越宽；对经常组织锦标赛的玩家，这层积累随时间复利。

有一条线要划清：记忆影响的是模型收到的参考信息，不动判定。出招仍由模型自己生成，合法与否由裁判的清单说了算，胜负判定依旧百分之百归代码。开局记忆是给选手递小抄，不是替选手下场。

## 与其他积累功能的分工

竞技与复盘层有几个跨局积累的功能，各记各的账：协议画像记模型的出招协议习惯，JSON 格式遵守率、平均耗时那一类；TrueSkill 记长期战绩，管段位座次；开局记忆记局面层面的教训。三者互不掺和——画像管「它怎么说话」，天梯管「它赢过谁」，开局记忆管「它在哪摔过跤」。

三本账合起来，才是对一个模型较完整的跨局观察：说话守不守规矩、战绩稳不稳、哪里栽过跟头，各答各的问题。给经常组织锦标赛的玩家一个实用的读法——画像与记忆表现都好、天梯名次也稳的模型，排进赛程可以放心些；账面互相矛盾的，先拉出来打几局热身再定。所有数据都在本机，随对局记录一起落盘，不上传。

## 设计取舍

一个诱人的岔路被绕开了：把开局库做成传统意义上的定式大全，直接给模型喂标准答案。这会让竞技场变味——考察对象从模型的博弈能力滑向它复述谱着的能力，而竞技场的看点是模型自己怎么想、怎么走。开局记忆的定位因此收得很谨慎：记教训、递参考，不背谱、不代下，这与代走机制「维持对局、不替模型赢棋」的立场一脉相承。

另一笔账是记忆的归属。教训记在局面名下还是记在某家模型名下，决定换一个模型上场时旧账还算不算数，这类实现细节以仓库为准；从「同型局面」这个口径看，锚点偏向局面侧。

## 边界

三条如实的局限。其一，牌局帮助有限：德州、麻将的局面被洗牌随机性主导，开局的「同型」几乎不存在，记忆的价值集中在棋类玩法。其二，教训可能记错账：完全信息的棋类里，坏结果基本能归因到坏棋；不完全信息的对局里，一手正确的牌也可能输给方差，把运气误记成错误，这种错账机制本身难以自纠。其三，记忆只对重复有效：模型若每次都走出全新的坏棋，库里没有同型可命中，它依然要靠解析容错与代走兜底——开局记忆治的是惯犯，不是初犯。

### 开局记忆原理是不是就是背棋谱

不是。背棋谱是给答案，开局记忆是记教训：库里存的是走过了什么、下场如何，复用时递给模型做参考。谱着不会替模型落子，判定权也仍在代码裁判手里。

### 同型局面是怎么判定的

棋类以着法序列与局面形态为锚，两家从同一条线走到同一处，即为同型。判定的具体粒度与算法以仓库实现为准，设计方向是开局段高命中、越深越难命中。

### 开局记忆存在哪里，安全吗

存在本机，与对局记录等数据一起落在应用数据目录，不上传。竞技场的数据口径是数据不出本机，开局记忆没有例外。

### 会不会让对局变成千篇一律的背谱

不会。记忆只提供「此路不通」式的参考，出招仍由模型实时生成，各家模型的棋风差异照旧。真担心重复，多换几个对手模型，局面分岔很快让记忆失效。

开局记忆原理说穿了很朴素：让桌面长记性。模型自己记不住的，棋盘替它记；同一个坑，摔过一回就该标出来。这个机制不炫技，却决定了多局对练时你面对的是一台在积累经验的考场，还是一台永远失忆的机器。
