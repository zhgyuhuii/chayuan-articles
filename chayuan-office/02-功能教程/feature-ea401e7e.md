# 多语种办公日：速查手册

界面语言、模型供应商随需切换。这套组合工作流把亮暗主题与多语言→模型接入（BYOK）串成一条线，在察元AI Office里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

界面语言、模型供应商随需切换。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI Office的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·亮暗主题与多语言**：亮/暗/跟随系统三种主题（文档面在暗色下保持白纸黑字避免刺眼）；界面支持 20 种语言。

1. 设置→外观选择主题
2. 语言切换即时生效

**第 2 步·模型接入（BYOK）**：自带 Key 接入十余家供应商：Claude、OpenAI、Gemini、DeepSeek、Kimi、GLM、Qwen、豆包、MiniMax、Grok、Mistral、OpenRouter，以及任意 OpenAI 兼容端点（含 Ollama 本地模型）。

1. 进入设置→模型
2. 填入供应商 API Key 或本地端点地址
3. 选择默认模型

## 衔接点与易错处

- 暗色下白纸设计兼顾习惯与舒适
- 内网用户把端点指向统一网关
- 换 Key 不换软件

## 离线运行与部署形态

官方安装包默认开启匿名 GA4 统计（不收集文档内容、文件名、路径与身份），设置里一键关闭；源码自行构建的版本零遥测。

## 数据安全与隐私边界

- 开源 Apache-2.0 可审计（企业模块另有例外许可）
- 安全工程：全窗口 contextIsolation + sandbox、IPC schema 校验、外链协议白名单、无硬编码密钥
- 遥测仅匿名统计且可一键关闭，永不收集文档内容与身份信息
- PDF→Word/PPT/Excel 转换与 OCR 均为本地引擎，扫描件不上传

## 费用与授权的边界（如实说明）

开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。付费部分：试用期满后每日一次购买提醒弹窗（可手动关闭）+ 主页每 30 分钟温和提醒；离线 HMAC 短序列号激活，绑定机器指纹本地验证，无需联网激活服务器

## 如实说说它的不足

- 官方安装包 90 天试用后会有每日一次的购买提醒（不锁功能、可关闭）
- 网页版 SaaS 形态需要自行部署维护（Docker + 数据库）
- Linux 老发行版（glibc<2.34）无法安装

## 产品家族与生态位

察元AI Office属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI OS（插件化的 AI 桌面操作系统，本地大模型与智能体工作站）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 遇到 bug 去哪反馈？

GitHub 仓库提 issue，或通过官网渠道反馈；项目有 75 个端到端测试用例保障迭代质量。

### 真的免费吗？

代码开源免费、可自行构建；官方安装包 90 天试用后仅每日温和提醒，不锁功能；购买授权属于支持开发，且购察元AI OS 后 Office 免激活。

### 支持多少种界面语言？

20 种界面语言（中英日韩法德西泰印尼俄阿葡意捷荷马来希伯来印地繁中等）。
