# AI操作审批出问题先看这：智能体调用察元系统能力

很多人搜「智能体要截屏/关机，能加一道确认吗」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把AI操作审批从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

按这个顺序排查AI操作审批通常最快：先确认前置条件（桌面形态（察元AI OS）：权限策略管理依赖桌面桥，其他形态显示「需要桌面形态（Electron 桥）才能管理权限策略。」。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 智能体在自己终端里执行命令，怎么没弹卡？

权限门只治理桌面控制面这条通道（MCP chatop / chatop os / 回环 HTTP）；智能体 pty 终端里的 shell 本就有用户全权，由各家 CLI 自带的审批机制管理——门不是沙箱。

## 正确的操作路径

从这几步开始：（第 4 个切入角度）

1. 三级分级确认
2. 120 秒超时 fail-closed
3. 审计日志全量记录
4. 场景验证：放心让智能体跑终端任务
5. 场景验证：事后审计谁动了系统设置
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 如何确认操作生效

验证

1. 勾选「启用权限门」后出现「已保存」；让任一智能体做一次 T1 动作（如「用系统浏览器打开 https://example.com」），桌面顶部应弹出「智能体权限请求」卡。
2. 卡上点「本次允许」，同一会话内再做同类动作不再弹卡；设置卡出现「本会话已放行」列表。
3. 取消勾选「启用权限门」后再做同类动作：直接执行、不弹卡；audit.jsonl 新增行的 decision 为 shadow_ask。

## 进阶用法与边界

- 三级分级确认
- 120 秒超时 fail-closed
- 审计日志全量记录

## 高频疑问

### 我想让某个工具彻底禁用？

设置表里该工具点「拒绝」：智能体调用立即被策略拒绝（deny_policy），不弹卡、不用等超时。

### 审计日志在哪里看？

桌面用户数据目录的 audit.jsonl（每调用一行 JSONL）。可按 decision 字段筛 shadow_ask（本会问而未问）、deny_timeout（超时被拒）等，核对智能体做过什么。

## 动手前再核对一遍

- 桌面形态（察元AI OS）：权限策略管理依赖桌面桥，其他形态显示「需要桌面形态（Electron 桥）才能管理权限策略。」。
- 权限门只治理智能体经察元控制面的调用——MCP chatop 条目、chatop os 命令行、回环 HTTP 三条通道在同一道门收口；智能体自己终端（pty）里跑的命令走各家 CLI 自己的机制，不在管辖内。
- 策略文件 permissions.json 存在当前登录用户的 profile 目录里，多用户互不继承（A 的「始终允许」不代表 B 允许）。

## 能力面再摊开一层

- 三级分级确认
- 120 秒超时 fail-closed
- 审计日志全量记录

## 放回产品盘面看

把AI操作审批放回察元AI OS的整体盘面：敏感操作全部写审计日志 audit.jsonl，可回放检查；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。

## 安全与数据边界

安全口径单独立一层：让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；敏感操作全部写审计日志 audit.jsonl，可回放检查。

## 平台与形态

平台与形态的账：（web/Docker 形态网页桌面默认端口）；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；内置浏览器窗，配合 webwindows 可被智能体驱动；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。
