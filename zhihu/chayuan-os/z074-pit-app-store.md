### 什么人该用，什么人别碰

说了这么多坑，也得给结论：按钮七态：免费安装 / 购买 ¥xx / 等待支付… / 已购直装 / 安装中… / 卸载 / 卸载中…（已装的显示「已装 v{版本}」徽标）。每条：包名、描述、版本、发布者、来源徽标（npm / git 仓库）；点「安装」「安装中…」 装完变「已安装」；无安装地址的条目按钮为「仅展示」。
