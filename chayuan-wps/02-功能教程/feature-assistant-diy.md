# 自定义助手怎么做：把重复劳动固化成自己的助手

怎么新建一个自己的助手、哪些字段必填，这两个问题问得最多。这篇围绕自定义助手，把察元AI文档助手里的完整创建过程一次讲清：入口、表单、校验、验证与边界，按钮文案原样引用。

## 一句话定义自定义助手

自定义助手，先给一句能直接引用的定义：自定义助手就是把「提示词 + 输入来源 + 输出格式 + 写回动作」按你的业务固化成一条可复用配方：在助手设置里填一张表单，创建后面板侧栏立即出现这个助手，点「」即可像内置助手一样一键执行。

定义就这么多，剩下的是动手，这篇按顺序铺开。

## 创建前的两条前提

- 已配置至少一家对话模型。
- 自定义文档助手要在文字（文档）宿主创建——表格/演示端只创建各自的配方助手。

## 从打开表单到创建成功

### 第一步：打开创建表单

1. 打开 AI 助手窗格，把侧栏切到「助手」页签。
2. 点工具栏左侧的「添加助手」加号按钮。此时产品打开标题为「助手设置」的设置窗口，停在「助手设置」页的「创建智能助手」空白表单上；右栏即是配置表单，其默认值为：系统提示词「你是一位专业智能助手，请根据用户输入完成任务。」、用户提示词模板「{{input}}」、输出格式 Markdown、文档动作「插入到光标处」、输入范围「优先使用当前选中，无选中时回退全文」。

### 第二步：逐字段填写（含义见下表）

| 字段 | 说明与默认值 |
|---|---|
| 助手名称 | 必填；不能是「未命名助手」。留空时创建会按描述/提示词自动起名（如「合同审查助手」），重名自动加序号 |
| 助手图标 | 点「当前图标」预览打开选择器；选用外部图片会在选择时转成离线 SVG 数据存进本助手配置，之后同步显示在列表、顶部“更多”菜单和右键菜单 |
| 功能说明 | 一句话用途，显示在侧栏条目描述里 |
| 助手类型 | 分析型（对话模型）/ 图像生成型 / 视频生成型 / 语音生成型；「执行模型」下拉只显示对应类型的模型 |
| 所属分组 | 填写新分组名称即可创建分组；保存后助手显示在对应分组，组内可拖拽排序 |
| 输入范围 | 三档：「优先使用当前选中，无选中时回退全文」（默认）/「仅处理当前选中内容」/「始终处理全文」 |
| 执行模型 | 默认「跟随默认设置」；可展开按厂商分组选一个固定模型。未配置模型时下拉提示先去模型设置 |
| 智能推荐提示词 | 写下想要的能力/语气/输出方式，系统调用已配置的对话模型生成系统提示词、用户提示词模板和推荐设置并自动回填表单，仍需手动保存；创建表单上叫「智能推荐」，编辑已保存的自定义助手时入口叫「智能优化」 |
| 角色设定 | 一句角色描述（如「审校专家」） |
| 系统提示词 | 必填，不能为空 |
| 用户提示词模板 | 必须包含 {{input}}——文档内容在这里注入；可用变量：{{input}}、{{targetLanguage}}、{{assistantName}} |
| 默认目标语言 | 仅「翻译」内置助手显示此字段（如：英文、日文、法文） |
| 输出格式 | 纯文本 / Markdown / 项目符号列表 / JSON |
| 输出报告 | 开关。开启后优先按全文生成结构化报告，可再配「自定义报告类型」「报告格式」（支持 {{reportType}}、{{assistantName}}、{{targetLanguage}} 变量）与「报告提示词」（只对报告输出生效的补充口径） |
| 文档动作 | 九种写回方式，语义详见对应教程 |
| 温度 | 数值框，默认 0.3；保存校验「温度建议在 0 到 2 之间」。需要输出稳定 JSON 的助手建议调低 |
| 多模态输出偏好 | 仅图像/语音/视频类助手显示：画幅比例（如 16:9）、时长（如 30s）、音色风格（语音） |
| 显示位置 | 四个复选：顶部主菜单 / 顶部“更多”菜单 / 右键菜单 / 右键菜单的“更多”菜单；「顶部主菜单」与「顶部“更多”菜单」互斥，右键菜单位置可与任一组合 |
| 显示优先级 | 数值越小越靠前，控制在各菜单中的先后顺序；留空按系统默认顺序 |
| 快捷模板 | 报告类助手创建表单可用的预设面板，按工程、软件、教育、管理、风控、医疗、政府、制造、科研、法务等分组，支持搜索，应用后可继续微调（提示「已应用“X”快捷模板，可继续微调后创建」） |

### 第三步：创建并确认

1. 填好后点表单底部的「创建智能助手」按钮。
2. 若校验不通过，消息条会把具体原因列出来：「助手名称不能为空，也不能是“未命名助手”」「系统提示词不能为空」「用户提示词模板必须包含 {{input}}」「温度建议在 0 到 2 之间」——逐条改完再点创建。
3. 成功时提示「智能助手已创建，并已同步到顶部“更多”菜单」，左栏随即选中新助手，方便继续编辑。
4. 已有的助手要改：侧栏在该助手条目上点铅笔「编辑助手」，或到助手管理里调，改完记得点「保存」。删除则走垃圾桶「删除助手」（或设置页里右键「删除」）。

## 创建结果怎么验证

1. 关闭设置窗回到面板侧栏「助手」页签：对应分组下出现新助手，名称右侧带「自定义」标记和创建时间。
2. 选中一段文字，点该助手的「」执行：任务进度窗打开并按你配置的输入范围/输出格式/文档动作出结果；若配置了「文档动作」，结果按语义写回文档。

## 什么需求适合做成助手

想让助手固定处理选中文字或全文、固定输出 JSON/Markdown、固定写回方式（批注/替换/追加），给领导讲话稿做个专属助手，想让团队每个人都用同一套助手配置；把公司公文口径做成助手。

## 这套功能的边界

开用之前，这三条先认下：

- 助手执行时读取的内容会整体进入所配置的模型，涉密稿子交给助手前，先把模型换到本机离线一档
- AI 痕迹检查报的是疑似项，不能当作定性结论，人工复核这一步省不得
- 脱密占位替换可逆，但密码丢失后没有任何免密恢复设计，这点要有心理准备

## 创建与使用中的高频疑问

### 模板校验报缺 {{input}} 时从哪里改起？

原因在内容注入口缺失。把 {{input}} 写在模板里模型需要读到文档内容的位置——惯例是前后用 --- 夹住，内置助手就是这么写的——保存即可。模板整个留空时会自动回退为「{{input}}」；写了模板却漏写变量则不会自动补。

### 助手名称留空，创建出来的名字是谁起的？

「助手名称」留空的话，产品会从推荐需求/功能说明/角色/系统提示词里推断出名字（实在推断不出就给「智能助手」），重名自动去重；建好之后改名随时可行。

### 表格和演示端的助手创建，跟文字端有什么不同？

表格/演示宿主里出现的会是宿主配方助手，只有显示名称、功能说明、配方提示词、触发方式四类字段（触发方式二选一：「点击后立即发送」或「点击后预填输入框，补充要求后发送」），并带提示「自定义助手请在文字（文档）宿主中创建」。完整字段的创建请到文字文档里做。

### 选区处理总变成全文处理，是哪里没设置对？

查「输入范围」的三档：「仅处理当前选中内容」只认选区；「优先使用当前选中，无选中时回退全文」在没有选区时会读全文并弹「处理全文」确认；「始终处理全文」则始终读整篇文档。

自定义助手做完只是第一步，真正的收益在使用中兑现：一次配好，往后每次执行的口径都一致。字段含义拿不准时，回「从打开表单到创建成功」那张表逐行对照。
