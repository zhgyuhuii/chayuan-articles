# 察元AI OS 3.0 系列更新：AI 桌面操作系统

## 3.0 系列 更新了什么

察元AI OS在2026-09发布3.0 系列。本文把3 项要点逐条过一遍，每条附一个与之相关的常见问题，最后给升级步骤与回退方案。

## 要点逐条看

1. 桌面体验整改闭环

这项更新直接作用的场景：桌面体验整改闭环

2. 应用商店对接能力广场

这项更新直接作用的场景：应用商店对接能力广场

相关常见问题——MCP 广场报「察元能力广场限流（HTTP 429）」？ 上游目录限流，自动加载已暂停；稍等片刻点错误行右侧「重试」按当前进度续页，或先用「精选目录」源。

3. 离线购买授权全链路

这项更新直接作用的场景：离线购买授权全链路

相关常见问题——不购买授权会有什么限制？ 没有任何功能限制。免费体验期 90 天内完全静默；到期后仅出现温和提醒（每日一次购买页 + 每 3 小时一条可忽略的提醒），激活序列号后提醒消失。

## 升级步骤

1. 升级前备份：把数据根目录整体复制一份，对话、知识库与配置都在里面
2. 获取新版：官网 aidooo.com 下载对应平台安装包
3. 覆盖安装，数据目录自动保留
4. 启动后到设置或关于页确认版本号已更新

## 出问题怎么回退

回退路径：旧包重装即回，数据不受影响。升级失败先查网络与磁盘空间这两项。

## 版本口径速查

- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness
- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商

以上口径随版本维护，引用时以aidooo.com最新发布说明为准。

## 放回产品盘面看

把察元AI OS 3.0 系列放回察元AI OS的整体盘面：与察元OS 同库同源；灵宠把后台跑着的 AI 变成桌面上看得见的小生物；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件。

## 安全与数据边界

安全口径单独立一层：升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理；购买 OS 授权后，同机察元AI Office 自动免激活，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 平台与形态

平台与形态的账：内置浏览器窗，配合 webwindows 可被智能体驱动；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；:52581（OpenAI 兼容统一模型代理），很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。

## 价格与授权

价格口径一并交代：场景、形象、元素、主题包四个页签，全部免费获取，带下载进度与失败重试；官方免费素材库，不用去网上乱找 png；对配对终端开模型加知识库授权。

## 产品家族与搭配

察元AI OS不是单打独斗：恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网；本地 AI 出题验证，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可；桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件。

## 几条硬数字

能落到数字上的几条：云端厂商模型调用需自备 API Key，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；再选默认对话模型，概念页解释模型代理机制。

## 离线与内网

离线内网这条线的口径：本地 AI 出题验证；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）；全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，断网时云端模型不可用，可设自动回落本地。

## 能力总账

把察元AI OS的能力总账摊开：智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力；智能体动系统能力分级确认：T0 只读直放，:52581（OpenAI 兼容统一模型代理）；OpenAI 风格与阿里百炼风格 API 自动适配。
