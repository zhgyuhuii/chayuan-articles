# 批量整理出问题怎么办：排查手册加进阶技巧

接手别人的察元AI文档助手环境时，我在批量整理上卡了半小时——不是功能难，是没人告诉我完整的操作链。这篇就是当时想找而没找到的那篇文章。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（WPS 文字端打开文档（「察元AI助理」选项卡仅文字端显示，表格/演示端没有本菜单）；），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 「删除全部表格」「首列添加序号」点了直接就执行，没有确认，做错了怎么挽回？

这两类直接批处理均无确认弹窗、加载项本身也不提供撤销入口。手快了先试 WPS 自带的撤销（Ctrl+Z）；批量整理前建议先另存一份副本。

## 正确的操作路径

入口：顶部「察元AI助理」选项卡 ＞ 「批量操作」分组 ＞ 「表格批量操作」▾，下拉共 14 项。以下按菜单顺序逐项说明。

1. 「导出全部表格」

1. 做什么：点击后先弹文件另存为对话框（标题「导出表格到Excel」，默认文件名「文档名_表格导出.xlsx」，可选 .xlsx 或 .xls），选好保存位置。
2. 看到什么：每张表导出为 Excel 里的一张工作表（名为「表格1」「表格2」…）。成功后弹「成功导出N个表格到: <路径>」；文档无表格先弹「文档中没有表格」。

2. 「删除全部表格」

1. 做什么：点击即执行，无确认弹窗，从后往前逐表删除。
2. 看到什么：完成后弹「已删除 N 个表格」。

## 收尾检查

验证

1. 「表格批量操作」▾ 展开，菜单项共 14 个，名称与本篇各步引号内文案一致。
2. 建一个含 2 张表的测试文档 ＞ 点「首列添加序号」＞ 弹「已完成：2 个表格均已首列添加序号（1、2、3…）」，两张表最左列出现居中序号。
3. 同一文档点「添加表格题注」（默认标签「表」、位置「上方」）＞ 两张表上方分别出现居中的「表1」「表2」。
4. 点「删除表格题注」＞ 弹「已删除 2 个表格题注（含标签）」，题注段落消失。
5. 点「根据第一表格刷新样式」前先把第 2 张表手工改乱，执行后第 2 张表边框底纹字体与第 1 张一致。

- 14 项批量动作

## 高频疑问

### 「追加替换文字」点确定后窗口直接关了，到底替换成功没有？

成功即关窗、无成功提示是设计行为。回正文翻表格核对；若窗口没关并显示红字（如「文档中没有表格」），才是没执行。

### 「导出全部表格」在 Mac 上没弹出保存对话框？

Windows 正常弹文件对话框；Mac 环境对话框可能不可用，代码会回退为把生成的 Excel 触发浏览器下载（弹「Excel文件已生成并触发下载！」并列出文件名）。按下载提示取文件即可。

### 「首列添加序号」点了两三次，表格前面多了好几列序号？

该功能每次执行都会在首列前再插一列序号列，代码没有「已有序号列就跳过」的判断。多余的序号列可点「删除文字所在列」按关键词处理，或手工删列；以后执行一次即可。

## 补充答疑

### 「删除文字所在行」会不会把别处同名的行一起删掉？

查找范围就是全部表格的单元格，包含匹配即命中，命中行都在删除清单里——确认页会显示「共找到 N 个相同的数据」，把 N 与预期对一下再点「确定删除」；关键词尽量带上前缀后缀以缩小命中。

## 更多操作细节

3. 「根据内容自动行宽」

1. 做什么：点击即对全部表格按内容自适应列宽。
2. 看到什么：成功弹「已完成：N 个表格已按内容自动调整列宽」；个别表失败弹「已处理 N 个表格，成功 X 个，失败 Y 个」。

4. 「根据窗口自动行宽」

1. 做什么：点击即对全部表格按页面窗口宽度平铺列宽。
2. 看到什么：成功弹「已完成：N 个表格已按窗口自动调整列宽」，失败分支同第 3 项。

5. 「根据第一表格刷新样式」

6. 「删除文字所在行」／7. 「删除文字所在列」（两步式对话框）

1. 做什么：点击即把第 1 张表的表格样式、样式选项（标题行/最后一行/首列/最后一列）与逐格格式（首行、首列、最后一行、最后一列、中间行按角色对应复制）刷到其余所有表格。
2. 看到什么：成功弹「已完成：N 个表格已与首表格样式完全一致（含首行、首列、最后一行、中间行等）」（N 为除首表外的表数）；文档只有一张表时弹「文档中仅有一个表格，无需刷新样式」。
3. 做什么：点击弹出「删除文字所在行/列」窗口（标题「删除文字所在行/列」，副标题「在文档全部表格中查找包含关键词的单元格，删除其所在行或列」）。菜单项已预选好「删除方式」（「删除行」/「删除列」单选，可改）；在「关键词」框输入要查找的文字，点「确定」。
4. 看到什么：找到后进入确认页「共找到 N 个相同的数据，是否删除每个文字所在的行/列？」，提示「点击“确定删除”将执行删除并关闭窗口。」——点「确定删除」才真正删；点「取消」退回输入页。没输入关键词提示「请输入关键词」；没找到提示「未找到包含“××”的文字」。
5. 执行后：显示绿色结果「已删除 N 行」（或「已删除 N 列」），点「关闭」退出。查找范围是全部表格的单元格文字（包含匹配）；同一行/列多个命中只删一次。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

## 一个真实场景

翻译从业者的典型用法：52 语种菜单选目标语言，逐段安全替换保持排版，术语口径统一助手兜专业词。排版不走样的整机翻译。注意：译文质量依赖所配模型档位，重要文件建议中高档模型。
