# 🚀故障一键转智能体修复隐藏用法｜智能体运维一次讲清

用过察元OS的宝子看过来，故障一键转智能体修复这个功能很多人没用到极致👇

✅ **它能干嘛**

系统故障时自动组装诊断上下文+排障知识库并派单给智能体处理，是「AI 服务的现场」的代表性能力。

🔍 **三步用起来**

1️⃣ 遇到故障在诊断入口发起
2️⃣ 系统打包诊断上下文
3️⃣ 智能体给出修复方案或直接处理

💡 **什么场景最香**

· 桌面异常自愈
· 模型服务排障

📌 **避坑提醒**

⚠️ 云厂商模型调用需自备 Key，免费额度视厂商政策

🛠️ **更多它擅长的事**

· **本地知识库**：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。
· **系统控制面（80+ 工具）**：MCP/HTTP/CLI 三通道的系统能力开放：桌面（壁纸/主题/Dock/锁屏/关机）、窗口与 webwindows（智能体开真实窗口、嵌网页、截图）、应用管理、终端、便签/笔记/日历/提醒/联系人、共享记忆、桌面截图、设置读写。
· **语音输入与语音记录**：对话框麦克风本地 whisper 转写回填；桌面右键贴顶长条录音 V2 边说边出字（VAD 静音切分+逐段转写上屏）；piper 中文语音合成。

⚠️ **断网也能用？这点很关键**

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

🧩 **说点大实话（缺点）**

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
· 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

🚀 **延伸了解**

察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

✅ **还有这些能力（1）**

· **对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

❓ **常见疑问快答**

问：其他软件能用本机模型吗？
答：能。统一模型代理提供 OpenAI 兼容与 Anthropic 协议接口（对话/嵌入/重排/语音），任何支持的客户端指向本地代理即可。

问：技能和插件有什么区别？
答：技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。
