# 🧩插件页签（三源）隐藏用法｜插件市场一次讲清

用过察元OS的宝子看过来，插件页签（三源）这个功能很多人没用到极致👇

✅ **它能干嘛**

npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。

🔍 **三步用起来**

1️⃣ 应用管理→插件页签
2️⃣ 切换源与分类筛选
3️⃣ 一键安装/卸载/排序

💡 **什么场景最香**

· 按需扩展系统能力

📌 **避坑提醒**

⚠️ Docker/云通道等进阶形态需要一定动手能力

🛠️ **更多它擅长的事**

· **应用商店**：插件/技能双类型商店（规划五类商品：插件/技能/MCP/提示词/智能体+技能包），aidooo.com 为默认首选源；免费直下，付费走内嵌收银台 webview，支持断点续传、sha256 校验、原子换入。
· **MCP 服务与同步**：系统级 MCP server（stdio `chatop mcp` + 本机 HTTP 52583，回环免 token）；MCP 配置自动传播注入六家智能体（claude-code/opencode/codex/zcode/openclaw/dsh）；设置里有 MCP 分区管理与清单离线导入导出。
· **webwindows 智能体开窗**：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。

⚠️ **断网也能用？这点很关键**

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

🧩 **说点大实话（缺点）**

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

🚀 **延伸了解**

察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

✅ **还有这些能力（1）**

· **对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。
