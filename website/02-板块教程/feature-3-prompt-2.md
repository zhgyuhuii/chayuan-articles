# 一文读懂提示词板块｜新手入门

提示词库是察元AI 能力广场里使用频率很高的一项能力。它的「提示词板块」这样工作：高质量系统提示词与模板目录：复制正文即用，覆盖写作、编程、分析等场景。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

高质量系统提示词与模板目录：复制正文即用，覆盖写作、编程、分析等场景。

从任务视角看，它对应的关键词是「提示词库」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 prompt 板块
2. 按场景筛选
3. 复制提示词正文到你的模型对话

## 适用场景

- 快速获得专业系统提示词
- 提示词学习参考

## 进阶技巧

- 好提示词先看结构（角色/约束/输出格式）

## 注意事项与边界

- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
