# 文档关系可视化实战：知识库应用的知识图谱页签

「知识库的知识图谱是干嘛的？怎么打开」——这个问题最近被问了好几次。答案不复杂：文档关系可视化在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 解决什么痛点

快速理解一批陌生资料，梳理项目干系人与文档的关系，库里文档多了，想快速浏览这个库覆盖哪些主题、哪几篇文档在讲同一件事；想从图上一路点到某篇文档，看它的来源路径或直接下载源文件。

## 知识图谱：从入口到完成

从这几步开始：（第 3 个切入角度）

1. 文档实体二部图
2. 点击互跳定位原文
3. 支持重算
4. 场景验证：梳理项目干系人与文档的关系
5. 场景验证：快速理解一批陌生资料
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 关键能力点

- 文档实体二部图
- 点击互跳定位原文
- 支持重算

## 这些坑和边界要知道

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 为什么有的实体节点没有名字？

名字标签只给「连线 ≥2 或频次 ≥4」的实体显示，避免满屏文字；没标签的小圆点照样可以点选。

### 库里有几百篇文档，图里只画了一部分？

单张图最多 120 篇最新就绪文档、60 个实体（见第 10 步）。这是可视化规模控制，检索与问答仍覆盖全部就绪文档。

### 图谱会影响检索或问答吗？

不会。图谱是只读可视化（数据是文档索引的衍生表，不参与检索链路）；检索/问答走独立的混合检索，见对应教程。

## 更多操作细节

验证

1. 在「文档」页把一篇文档加载到「就绪」，切到「知识图谱」：画布出现该文档的彩色圆点，圆下标着文件名。
2. 点一个实体：右侧「关联文档（n）」清单列出的文档，与画布上保持高亮（未淡出）的文档圆点一一对应。
3. 点任一文档圆点 ＞ 「下载源文件」：下载到本机的文件与库里该文档同名同内容。

## 动手前再核对一遍

- 桌面形态，Dock 打开「知识库」应用。
- 图谱只统计状态「就绪」的文档——库里没有就绪文档时，图谱页显示「暂无就绪文档——先在「文档」页上传并加载，图谱随索引自动生成」。
- 不依赖任何模型：实体抽取是纯统计（英文词＋中文 2~4 字词组＋停用词过滤），离线完成，没配嵌入模型也能用。

## 放回产品盘面看

把文档关系可视化放回察元AI OS的整体盘面：桌面右键录制屏幕，桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件；桌面内置终端：真实 shell、会话持久、环境延续；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明。

## 安全与数据边界

安全口径单独立一层：需要提前开启并积累足够记忆数据，管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录，全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。

## 平台与形态

平台与形态的账：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness，Dock 是使用频率最高的区域，位置与大小顺眼很影响手感。

## 价格与授权

价格口径一并交代：资料之间的关系用图看比用列表翻快得多，跨文档的实体关联一目了然；知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，检索引用知识库内容并带出处写进文档，引用带出处插入文档。

## 产品家族与搭配

察元AI OS不是单打独斗：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；资料之间的关系用图看比用列表翻快得多，跨文档的实体关联一目了然，工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。

## 几条硬数字

能落到数字上的几条：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；概念页解释模型代理机制，默认对话模型选择；重跑入口在设置＞模型＞设置向导。

## 离线与内网

离线内网这条线的口径：下载几个 GB 的权重需要时间与磁盘空间，GGUF、whisper 权重可以按路径直接导入（零拷贝）；或按直链目录放置后执行扫描本地放置的模型，扫描本地放置的模型。
