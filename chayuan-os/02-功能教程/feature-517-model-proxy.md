# 统一模型代理速查手册：从入口到完成的完整流程

模型网关是察元AI OS里使用频率很高的一项能力。它的「统一模型代理」这样工作：统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。这篇速查手册从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。

从任务视角看，它对应的关键词是「模型网关」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 任意 OpenAI 兼容客户端指向本地代理
2. 按需使用对话/嵌入/重排/语音端点
3. 给外部工具签发虚拟 Key

## 适用场景

- 把本地模型共享给全机软件
- 多协议客户端统一接入

## 实用技巧

- Anthropic 协议双向换算意味着 Claude 客户端也能用本地模型

## 注意事项与边界

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 常见问题
### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。
