# 一文打通断网环境完整工作台｜离线AI

本地模型对话+知识库问答的零网络方案。这套组合工作流把本地模型服务→对话（DeepSeek Harness 会话）→本地知识库串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

本地模型对话+知识库问答的零网络方案。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·本地模型服务**：llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。

1. 模型服务应用里浏览模型库
2. 显式加载需要的模型
3. 用完卸载释放内存

**第 2 步·对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。

1. 打开对话应用或按 ⌥Space
2. 选择本地或云端模型
3. 发起会话，多窗口并行不同任务

**第 3 步·本地知识库**：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。

1. 知识库应用新建库并导入文件
2. 等待异步摄取完成
3. 提问并查看带引用的回答

## 衔接点与易错处

- 装机五件套已覆盖对话/嵌入/重排/语音全链路
- 无显式模型偏好时自动指向本地模型，开箱即聊
- 嵌入模型切换会触发指纹检测与索引重建
- 可选 Milvus 作为向量库

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 常见问题
### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。
