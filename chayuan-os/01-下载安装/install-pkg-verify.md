# 安装包校验：逐文件校验的习惯

安装包校验这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决安装包校验。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：逐文件校验的习惯。

安装包从官网 aidooo.com 获取。

## 一步步来

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 边界先摆桌面上

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 放回产品盘面看

把安装包校验放回察元AI OS的整体盘面：设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness，桌面右键录制屏幕；桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件；桌面内置终端：真实 shell、会话持久、环境延续。

## 安全与数据边界

安全口径单独立一层：API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，代理只监听本机回环，跨机访问需要另行打通。

## 平台与形态

平台与形态的账：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 价格与授权

价格口径一并交代：免费下载使用，购买只停提醒、不锁功能；四档价格：149/359/599/1049 元；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签），跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定。

## 产品家族与搭配

察元AI OS不是单打独斗：插件启停卸载、离线安装；灵宠商店主题页签整套安装：场景背景加 36 图标皮肤加灵宠皮的组合包；设置关于里检查更新、下载并重启安装，一台服务器全组使用，运维只管一处，终端零安装。

## 几条硬数字

能落到数字上的几条：重跑入口在设置＞模型＞设置向导；想换默认模型随时可以在设置里重跑向导，不用重装，本地模型解决有无问题，复杂任务还是需要云端旗舰模型，断网时云端模型不可用，可设自动回落本地。

## 离线与内网

离线内网这条线的口径：本地音乐（用户音乐目录）与音视频播放，与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力），离线消息暂存后送达，内网或特殊网络环境装插件的必经配置。

## 能力总账

把察元AI OS的能力总账摊开：文件浏览上传、右键用智能体打开、设为默认打开方式，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明，内置浏览器窗，配合 webwindows 可被智能体驱动。
