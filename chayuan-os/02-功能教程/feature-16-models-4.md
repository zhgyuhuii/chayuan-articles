# 察元OS本地模型服务使用指南（本地大模型）（细节版）

本地大模型是察元AI OS里使用频率很高的一项能力。它的「本地模型服务」这样工作：llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。

从任务视角看，它对应的关键词是「本地大模型」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 模型服务应用里浏览模型库
2. 显式加载需要的模型
3. 用完卸载释放内存

## 适用场景

- 按任务灵活挂载模型

## 进阶技巧

- 装机五件套已覆盖对话/嵌入/重排/语音全链路

## 注意事项与边界

- 8GB 内存建议一次一个对话模型
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 常见问题
### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 语音输入是本地的吗？

是。whisper 本地转写，录音不上传；另有贴顶语音长条「边说边出字」与 piper 中文语音合成。
