# MCP文档智能体攻略：本机 MCP 文档智能体服务的关键点拆解

MCP文档智能体是察元AI文档助手里使用频率很高的一项能力。它的「本机 MCP 文档智能体服务」这样工作：内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

内置 46 工具/15 域的 MCP 服务（文档生命周期、读取定位、写回、格式、校对/知识库/助手/脱密、表格/批注/修订/水印/导出等聚合域），监听 127.0.0.1:62588，Claude Code、Codex、Cursor、ZCode 等外部智能体可直接连接读写本机 WPS 文档。

从任务视角看，它对应的关键词是「MCP文档智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 确认 sidecar 自启（/healthz 返回 online）
2. 在 Claude Code/Cursor/Codex 中添加 MCP 服务 http://127.0.0.1:62588/mcp
3. 对外部智能体说「打开桌面上的标书并检查错别字」
4. 预览→确认→写回

## 实用技巧

- 写操作未传 confirmed:true 只返回预览不落盘
- 长文档分块读取（document_chunks）对百万字友好

## 注意事项与边界

- 免费版每日对话 30 次，重度使用需要付费或自建模型端点
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。

### 什么是 MCP 文档智能体服务？

加载项内置的本机服务（46 工具/15 域），外部 AI 编程工具（Claude Code、Codex、Cursor 等）连上后可直接打开、读取、修改、批注本机 WPS 文档，写操作默认只预览、传 confirmed:true 才落盘。

### 免费额度用完会怎样？

对话超过每日 30 次会提示；MCP 调用返回 LICENSE_REQUIRED 错误码，次日恢复或升级付费。
