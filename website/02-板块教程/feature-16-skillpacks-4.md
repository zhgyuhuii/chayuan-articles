# 技能包商城避坑指南：从入口到完成的完整流程

技能包商城是察元AI 能力广场里使用频率很高的一项能力。它的「技能包商城」这样工作：311 个买断制技能包、13 大行业两级分类：包详情含解决什么问题/适合谁，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

311 个买断制技能包、13 大行业两级分类：包详情含解决什么问题/适合谁，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

从任务视角看，它对应的关键词是「技能包商城」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 /skillpacks 按行业浏览
2. 看包详情的 solves/audience
3. 微信/支付宝买断购买
4. 在智能体中激活使用

## 适用场景

- 按行业一次性配齐技能

## 进阶技巧

- 免费技能包约占一成，先试免费的

## 注意事项与边界

- token 授权限 3 台设备
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 常见问题
### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### 资源数量有多少？

能力广场总条目 2.5 万+（站方口径，页面实时计数展示）；教程库 2.1 万+ 条；技能包 311 个；助手目录 4526 个助手/228 个领域；API 价格表 40 厂商 201 个模型条目。
