# 一文打通让 AI 操作电脑｜智能体操作电脑

系统技能+控制面+开窗三步交权。这套组合工作流把系统技能（chatop-system）→系统控制面（80+ 工具）→webwindows 智能体开窗串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

系统技能+控制面+开窗三步交权。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·系统技能（chatop-system）**：对外能力的权威技能包：启动时自动镜像进六家智能体技能目录，让 Claude Code 等天然会用本机系统能力；设置里可查看/下载/按智能体应用。

1. 设置→系统技能查看已镜像状态
2. 在智能体里直接说「换张壁纸」「打开知识库」
3. 技能更新后自动同步

**第 2 步·系统控制面（80+ 工具）**：MCP/HTTP/CLI 三通道的系统能力开放：桌面（壁纸/主题/Dock/锁屏/关机）、窗口与 webwindows（智能体开真实窗口、嵌网页、截图）、应用管理、终端、便签/笔记/日历/提醒/联系人、共享记忆、桌面截图、设置读写。

1. 智能体里直接下指令（技能已镜像）
2. 权限门弹卡审批（T1 可记忆）
3. 查看审计日志确认执行

**第 3 步·webwindows 智能体开窗**：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。

1. 在智能体会话中要求打开某网页
2. 智能体截图理解页面
3. 按需执行 JS 或调整窗口属性

## 衔接点与易错处

- 六家智能体同步：claude-code/opencode/codex/zcode/openclaw/dsh
- T2 级操作（截图/关机）每次必问，安全优先
- 配合权限门审批使用

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
