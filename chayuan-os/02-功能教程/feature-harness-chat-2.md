# 拆开看桌面AI助手：原理、架构与实现细节

先说结论：桌面AI助手在察元AI OS里是完整可用的，从Harness 主对话窗的入口进去，按下面步骤操作即可。这篇文章覆盖概念、步骤、验证和常见问题四部分，读完能独立完成整个流程。

## 是什么与为什么

DeepSeek Harness 是察元AI OS 的主对话窗（Dock 上的鲸鱼图标）：每个窗口一个独立会话、可无限多开；会话模型下拉同时列出本地已安装模型与已启用云端厂商模型（两侧都实时热更新），会话中途随时切换；模型走代理接入时还能吃到「智能路由」（重任务上强模型、轻任务自动降级轻模型）。

工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。

下面直接进入正题。

## 机制拆解

工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。

能力面拆开看：附件上传；工具调用过程可视化；模型会话中热切换；多会话窗口并行。

从提问口径看，用户最关心的是对话窗口在哪里打开？可以开几个？

## 完整操作步骤

按最短路径验证一遍：

1. 打开对话窗

点 Dock 上的「DeepSeek Harness」图标（品牌蓝鲸鱼标）。首次打开窗口显示加载动画「正在启动 DeepSeek Harness…」，就绪后进入会话界面。

2. （桌面形态）全局快捷键唤起

默认 ⌥Space（Alt+Space） 在任何应用里都能唤起/聚焦会话窗：无窗新开、有窗聚焦最近一个、连按在多个会话窗间循环。开关与键位在 设置 ＞ 通用 ＞ 「全局唤起对话」改（仅桌面形态可用）。开机自动打开会话窗：设置 ＞ 桌面与 Dock ＞ 「开机自动打开 Harness」。

3. 认识窗口与多开

窗口工具栏极简：左上红绿灯关/最小化/全屏，居中标题「DeepSeek Harness」，右侧「＋」按钮（悬停提示「新建会话窗口」）——点击再开一个独立会话窗，各窗会话互不影响。没有地址栏。

## 别在这几处栽跟头

边界都在这：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 无显式模型偏好时自动指向本地模型
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 切换模型后，之前的对话还在吗？

在。切模型只影响之后的消息用哪个模型回答，历史记录保留在同一会话里。

### 能同时开几个会话窗？

没有数量限制，「＋」或 ⌥Space 连按循环切换；每个窗口是独立会话。

### 窗口一直停在「正在启动 DeepSeek Harness…」？

本机 dsh 会话服务未就绪或被停。先等几秒；到 设置 ＞ Harness 连接 点「测试连接」看在线状态；仍不行重启桌面应用。

### 改了「Harness 连接」地址，旧窗口怎么还连本机？

该设置只影响新打开的会话窗；已开窗口不动。关掉旧窗重开即连远程。

## 补充答疑

### 模型下拉里看不到本地模型？

下拉只列已安装的对话/图像理解类模型。若装的是嵌入/重排/语音类，它们不进对话下拉（供知识库/语音用）；若一个对话模型都没有，去模型库下载或导入，完成即在列。

### smart/auto / 智能路由在哪开？

设置界面暂无配置页，用第 8 步的 API 配置（或让智能体代配）；未配置 strongModel 时智能路由整体关闭。配置后最省心的用法是开 interceptStrong：会话照常选强模型，轻活自动降级。

### 选本地模型发消息报「本地模型未加载」？

对话窗直连档（chatop-local）不做自动加载。两个办法：① 到 设置 ＞ 模型 给该模型点「启动」，建议顺手「钉住」防空闲卸载；② 改用经代理的 local/<id>（M9 应用后出现）——未运行时首调自动拉起，等待最长 90 秒。

## 更多操作细节

4. 认识模型下拉（三个来源）

会话内的模型选择器列出三类条目：

1. 本地模型：来自「本地模型」提供方，= 本机已安装的对话/图像理解模型，显示名形如 Qwen3.5-4B Q4_K_M（装机即用对话）；
2. 云端厂商模型：你在 设置 ＞ 模型 里「保存并启用」过的厂商模型，状态行就叫「已开启 · 显示在 Harness 模型下拉框」；
3. 代理档案模型：经「应用到智能体」写入的 local (proxy) 档，模型名形如 local/<模型id>、<厂商id>/<模型名>。

5. 热更新表现（下拉实时变化）

1. 厂商侧：厂商卡「保存并启用」＞ 提示「已开启，模型下拉框即刻可见」，勾选的模型实时出现在下拉框，无需重开窗口；「停用」＞ 该厂商模型即时消失，配置保留可随时恢复；
2. 本地侧：下拉数据源是本地已安装清单——模型库下载完成或离线导入登记后进入下拉（不要求已加载）；删除权重后从下拉消失；
3. 列表刷新期间短暂空列表属正常，稍候即回。

6. 会话中切换模型

在模型下拉里直接另选一个模型即可完成切换：历史消息保留，新消息按新选的模型回答。本地 云端可来回切。

## 安装与运行答疑

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### 检查更新失败？

更新需要联网访问官网接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

## 一个真实场景

公文与材料写作者的典型用法：知识库导入本单位制度与历年材料，对话绑定知识库写初稿，回答带出处，察元AI Office 修订追踪留痕，逐条接受拒绝。从初稿到核稿全流程 AI 辅助且可溯源。注意：保密检查是辅助参考，定密以人工审查为准。

## 顺带了解

模型代理进阶：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，还有可复制的各家智能体配置片段。

为什么值得看：给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 还有这个能力

开机登录门与数据目录：全新安装选数据目录或导入拷贝根，创建管理员；日常是用户卡片墙加密码，可选生成恢复密钥。

整体用下来，Harness 主对话窗的流程是清楚的：入口集中、步骤有反馈、做完有验证。第一次照着走一遍，后面基本就是肌肉记忆了。卡住就回看常见问题那一节。
