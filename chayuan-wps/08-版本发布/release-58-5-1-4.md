# 察元文档助手 v5.1.4 更新解读：当前发布版本：三平台产物齐全

v5.1.4（2026-09-20）带来了 3 项主要更新。这篇解读把每项更新「翻译」成使用层面的变化，并给出升级建议。

## 本版主要更新

- 当前发布版本：三平台产物齐全
- sidecar 最小 token 鉴权 + 审计
- 对话窗官网升级提醒（断网静默）

## 值得展开说的一处

以「当前发布版本：三平台产物齐全」为例：它解决的是此前用户反馈集中的场景。升级后建议第一时间验证这个场景——如果它正是你的痛点，这一版就值得升；如果你的工作流不涉及，也可以观望一个补丁版本再升。

1. 升级前备份用户数据目录（各产品数据目录见官方文档）
2. 从官网 https://aidooo.com 或对应发布渠道获取新版安装包
3. 覆盖安装，完成后验证常用链路
4. 如有问题，用备份目录回滚到旧版

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 如实说说它的不足

- 免费版每日对话 30 次，重度使用需要付费或自建模型端点
- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 保密检查、AI 痕迹检查为辅助参考，不构成定密或定性结论

## 常见问题
### 安装包多大？在哪里下载？

约 35MB（各平台相近），官网 aidooo.com、GitHub（zhgyuhuii/chayuan-wps-releases）、Gitee 国内镜像与百度网盘均可下载，每个包带 sha256 校验文件。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。

### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。
