# 更新通道与数据保留：察元OS的实操要点

更新通道与数据保留常被用户问到。这篇实操要点从察元AI OS的实际实现出发，讲清楚设计取舍与使用层面的意义。

## 一句话结论

版本演进的完整时间线：

- v项目启动（0.0.x）（2026-08-27）：chatop desktop + chatop-shell 桌面接管 DeepSeek Harness
- v基础能力月（2026-09 上旬）：知识库/文件系统/媒体播放/共享桌面落地
- v0.1.5x（2026-09 中旬）：管理员多用户体系与 ChatOffice 内置
- v0.1.61-0.1.65（2026-09-18/19）：引擎二进制入库、Milvus 双选型
- v0.1.66（2026-09-21）：离线购买/授权全链（HMAC 短码）
- v桌面体验整改（2026-09-23/24）：桌面体验 28 项整改闭环（真机走查+CDP 截图）

版本策略的原则是行为变化写进更新说明、用户数据与版本解耦。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 对使用者意味着什么

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 相关能力以官网 https://aidooo.com 最新版本为准

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
