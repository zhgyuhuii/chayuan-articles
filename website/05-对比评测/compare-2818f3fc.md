# 网页版 vs 客户端内嵌广场：深度对比与条件式建议

网页版 vs 客户端内嵌广场，是很多用户在选型阶段绕不开的问题。这篇深度对比不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（能力广场） | 对照方案 | 说明 |
|---|---|---|---|
| 入口 | 浏览器随时访问 | OS 内一键直达 | 按使用环境 |
| 联动 | 网页复制命令手动执行 | 客户端复制命令直接落本机 | 客户端链路更短 |
| 离线 | 需网络 | 离线回落本地页 | 断网体验 |

## 逐项解读

**入口**：按使用环境。能力广场侧的做法是「浏览器随时访问」，对照方案为「OS 内一键直达」——差异的本质在于设计取向不同，而非优劣。

**联动**：客户端链路更短。能力广场侧的做法是「网页复制命令手动执行」，对照方案为「客户端复制命令直接落本机」——差异的本质在于设计取向不同，而非优劣。

**离线**：断网体验。能力广场侧的做法是「需网络」，对照方案为「离线回落本地页」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

日常网页版；OS 用户优先内嵌广场。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 资源数量有多少？

能力广场总条目 2.5 万+（站方口径，页面实时计数展示）；教程库 2.1 万+ 条；技能包 311 个；助手目录 4526 个助手/228 个领域；API 价格表 40 厂商 201 个模型条目。
