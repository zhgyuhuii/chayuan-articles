# AppImage运行装机指南

先说这篇能帮你干什么：读完能在察元AI OS里独立完成 AppImage 的赋权与运行，顺带弄清各平台该拿哪个包。步骤带编号，界面上的按钮名一律按原文抄录。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：免 root 便携运行与 FUSE 处理。

安装包只从官方渠道拿，来路不明的镜像站别碰。架构拿不准时别急着下，先到「架构对照速查」那一节对号。

## 一步步来

1. 从官方渠道下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 其他平台装法速览

Linux（AppImage）：chmod +x 加执行权限后运行；缺 FUSE 时安装 libfuse2 或改用 --appimage-extract-and-run；免安装形态适合无 root 权限与便携场景。

Docker 服务器：获取 docker-compose.yml；docker compose up -d 启动；浏览器访问默认 52584 端口得到多用户网页桌面。

## AppImage 三步走

1. 终端执行 uname -m 确认架构：输出 aarch64 取 arm64 包，输出 x86_64 取 x64 包，按结果拿对应架构的 AppImage 文件
2. chmod +x 给文件加上执行权限，之后即可运行
3. 遇到 FUSE 缺失报错时，先安装 libfuse2；机器不允许装依赖的话，改用 --appimage-extract-and-run 解压后再跑，绕开 FUSE

免安装形态的价值在无 root 权限与便携场景：机器不是你的、或者要把整套环境随身带走时，AppImage 比 deb 省事；代价是多一步赋权，以及 FUSE 这只小拦路虎。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

表格里银河麒麟 V10、统信 UOS 20 走 deb 是推荐路径，AppImage 则是不便装包时的备选；两条路最终进的是同一个桌面。

## 装完后的第一件事

装完先干两件事：一是让模型设置向导跑完，把默认模型应用到各家智能体；二是试一次断网对话，确认本地模型链路通了。恢复密钥也顺手生成，忘了密码时它是仅有自助路径。向导没跑完就急着用，各家智能体拿不到默认模型，后续排障容易绕远路；这几件事都轻，顺手做完最省心。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。两步定位最稳：先看芯片名单锁定架构，再用 uname -m 复核一遍；宁可多核一次，也别下错包再返工。

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

验证顺序建议从窄到宽：先等首启初始化跑完，再进对话应用选本地模型发一句话，能正常回复说明链路已通；最后按需做一次断网对话，确认整条链路不依赖外部服务。

## 边界如实交代

它并非什么场景都兜得住：

- 进阶形态里的 Docker 云桌面与跨终端互联，都得先掂掂自己的动手能力
- 龙芯机器暂时没有适配版本；视频生成本地缺位，交给云端路由
- 设备内存 8GB 时，同时运行的对话模型以一个为限，复杂任务受限
- 云端厂商模型的使用资格是自备 API Key

## 桌面盘面的几个角落

右键编辑改配置，删除要点两次确认；野宠能被收编进名册、转成正式灵宠；定时任务不再只留日志，进度直接直播在桌面上，跑没跑、成没成一眼可见；还有可选群分区，桌面出图标双击进群。知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。

## 共用机器的安全底线

一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全；隐私敏感环境先关遥测再干活，处置设备前清数据。权限上设了三级门：T0 只读直放、T1 高危每运行期首问（可记忆）、T2 截屏关机级每次必问。

## 形态与端口的零碎

每次产出的 markdown 报告会归档；local 星号开头的本地模型未运行时自动加载。

## 装好之后能连上什么

Dock 直开内置的察元AI Office，文档、表格、演示在线编辑；API Key 用 safeStorage 加密存储，遥测可整体停用。Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 群聊多模型的前提

不同宠配不同模型是群聊多模型讨论的前提，轻任务宠配小模型、主力宠配旗舰；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；双击模型直跑灵宠直达，多个大模型开始围绕它讨论。

## 离线时的模型调度

自动模式本地优先；本地模型按需自动加载；会话中随时切换模型（本地与已启用厂商热更新）；无显式模型偏好时自动指向本地模型。

## 智能体对桌面的手有多长

文件管理器右键就能把文件交给智能体，是最顺手的 AI 入口之一；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明。内置浏览器窗配合 webwindows 可被智能体驱动，不装第三方浏览器也能完成网页操作，智能体还能代劳。

AppImage 运行的链路到此走通；哪一步卡住，回到对应小节核对命令与输出，多数坎出在架构选错或权限没给。
