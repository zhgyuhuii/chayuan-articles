# 本地模型下载：模型配置可一键写入五家

「本地模型去哪里下载？模型库在哪里」——这个问题最近被问了好几次。答案不复杂：本地模型下载在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 一句话说清定位

本地模型下载是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，下载本地模型是其中面向这类需求的一环。

概念一分钟，操作十分钟，这篇都覆盖。

## 一步步来

9. 「＋ 添加模型」（离线导入入口）

「我的模型」标题行右侧「＋ 添加模型」打开导入对话框：填「模型文件路径」（桌面形态有「…」文件选择按钮）＞ 选模型类型（对话/嵌入/重排序/决策/代码补全/图像理解/语音识别）＞ 填「显示名称」与「上下文 (K)」＞ 点「导入并运行」。导入不复制文件，直接引用原路径。详细离线流程见后续教程 M4。

2. 断点续传与多路换源

4. 确认边界：8GB 内存建议一次只加载一个对话模型

## 这些坑和边界要知道

功能归功能，这几个边界先摆清楚：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存建议一次只加载一个对话模型
- 下载几个 GB 的权重需要时间与磁盘空间

## 高频疑问

### 本地模型下载要联网吗

润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱，会话中随时切换模型（本地与已启用厂商热更新），建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型。以官网 aidooo.com 当前页面为准。

### 本地模型下载数据存在哪

本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队；列表与卡片两种视图，搜索排序，批量加载、取消、下载、删除；换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页。以官网 aidooo.com 当前页面为准。

## 更多操作细节

验证

1. 「我的模型」列表出现目标模型（模型库对应行消失）。
2. 点「启动」后行首亮绿点，状态条计数 +1（如「1 个模型运行中」）；点「测试」显示「测试通过」。
3. 浏览器或终端访问 http://127.0.0.1:52581/v1/models（免 key）：清单出现 local/<模型id> 条目。
4. 在向导（M1 第 2 步）或灵宠选模型树里，该模型出现在「本地与自建 · local/」组下；运行中带绿色「运行中」标记。

## 动手前再核对一遍

- 联网。下载走多源自动轮换：ModelScope（主源，含其 API 通道）＞ hf-mirror.com / hf-mirror.net / aifasthub.com（AI快站）镜像 ＞ HuggingFace 官方垫底，国内网络可直接下载。
- 磁盘空间：下载前自动预检，需要约「模型体积 × 1.05 + 200MB」余量；不足直接报「磁盘不足：还需约 XGB，当前可用 YGB」。
- 权重全机一份：页面上有固定提示「模型全机只保留一份：下载/删除影响本机所有用户」。
- 不想下载？ 完整安装包随机播种的「装机即用」五件套开箱即可加载：Qwen3.5-4B Q4_K_M（对话）、BGE-M3（嵌入）、BGE Reranker v2 M3（重排）、Piper huayan 中文语音（语音合成）、Whisper Small（语音识别）；未带模型包的安装形态，模型库中有同量化的 Qwen3.5-4B 在线档可补装。
