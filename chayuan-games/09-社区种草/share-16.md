# 新模型上手三件事：到手先办这三样

首图建议：三格拼图，填 Key 的设置页、对局室棋盘、协议画像统计页各占一格。

新模型发布日，你照例火速充了值，然后呢？聊几句天气，问几个脑筋急转弯，得出一声「嗯还行」，就没有然后了。

考察一个模型，聊天只是开胃菜。新模型上手总得有个章法，这篇给你一套棋盘上的流程：配置、上桌、看画像，三件事办完，这个模型的底细你至少摸到一半。

场景工具是察元竞技场，让大模型在 11 款棋牌玩法里真对弈的开源竞技场，拿它当新模型的试金石正合适。

## 一步：配置，把门敲开

进设置 ＞ 模型配置，厂商目录里找到对应家，把 Key 贴进去。

两个按钮按顺序按。「测试连接」先发 GET 验 Key 的身份，不通就悄悄退回手填模型列表；「获取模型」用 POST 把这个账号可用的模型全列表拉回来，读的是你还没保存的输入，实拉不回退。拉回来的裸模型 id 勾选入库，配置就算落定。

用 Ollama 或 LM Studio 的本地模型？免 Key，端点指过去就行，这一步更快。

配置里容易忽略的一处：别只勾旗舰档，把同厂商的小型号也勾上，后面做画像对比有奇效。

## 二步：上桌，看它真实出招

聊天测的是嘴皮子，对局测的是脑子。上来别急着看输赢，分三段看过程。

热身局：人机局跟它单独过招，你走它应，感受应招速度和路数。中途随时可以 AI 接手或人工接管，双向切换下一手生效，关键局面你想自己接盘试试也行。

混战局：匿名观战拉两三个模型同桌，座位只显示玩家A/B/C/D，你猜谁是谁，终局揭晓对答案。猜错的那次震惊，往往就是新模型给你的印象分。

细节观察：对局室里思维链气泡实时流式，每手的延迟和 token 用量摆在旁边。它思考多久、话多不多、会不会中途改主意，这些都是聊天界面看不到的剖面。

还有一个容易被忽略的观察点：让同一个模型连打几局，看发挥稳不稳。有的模型风格恒定，有的时好时坏，这种波动信息聊天时完全看不出来，棋桌上藏不住。

## 三步：看画像，让数据说话

打上若干局之后，去翻协议画像。

这里统计的是每个模型的出招协议习惯：JSON 格式遵守率、平均耗时这类指标，攒成一份模型性格画像。格式遵守率低的模型，对局里更容易触发启发式代走兜底，看着是「它瞎走」，其实一半是协议没写对；平均耗时长的模型，锦标赛长赛程里会把节奏拖得很明显。

还有开局记忆这个机制值得留意：它让模型避免在同型局面里重复犯错。同一批局打下来，你能看到它有没有长记性，这比单局胜负有信息量得多。

## 三个点，两好一坑

1. 好在门槛低。填 Key、勾模型、开局，三分钟的事，本地模型连 Key 都省了。

2. 好在看得到过程。思维链气泡、每手延迟、token 用量、协议画像，一整套过程指标摆在明面上，不是只有个输赢数字。

3. 坑在样本量。三五局只能找感觉，画像要有参考价值得攒够局数，指望打一局就下结论，那是算命不是考察。

## 画像之外的旁证

协议画像是主干，旁边还有几条旁证值得看。

天梯段位：TrueSkill 排位随胜负浮动，段位变化是模型状态的长期记录；人类挑战者的战绩独立统计，不与模型混榜，你也可以自己上天梯试试水深水浅。

开局记忆：同一模型反复打同类局面，观察它是不是还在同一个坑里摔跤，长记性的速度本身就是性格。

再来一局的稳定性：状态稳的模型连打几局风格如一，状态飘的模型波动剧烈，这个差异在锦标赛长赛程里会被放大。

## 考察记录模板

跑完的局别让信息散掉，一行记录就能存下价值。

基础项：日期、玩法、对手模型、局数。过程项：出招快慢的体感、思维链风格是啰嗦还是干脆、有没有出现代走。结果项：输赢与关键手编号、复盘时印象深刻的一幕。结论项：一句话概括「它像什么类型的棋手」。

记满一个月回头翻，你会发现同一个模型在不同玩法里像换了个人，这种反差正是对局考察的乐趣，也是跑分表格给不了的东西。

## 也要说实话

- 大模型出招靠语料与推理，不做深度搜索，棋牌表现不能外推成综合能力，它是一个观察窗口，不是成绩单。
- API 费用自付，考察成本自己核算，Ollama 本地零成本路线可以分担预算压力。
- 版本 0.1.0 阶段各项统计口径还在演进，画像指标的具体含义以仓库文档为准，别拿单次数据当铁律。

适合谁：追新模型、不想只看跑分榜单、想亲手摸底的人。不适合谁：只要一个现成排名的人，这里给的是观察工具，结论要你自己打出来。

## 评论区高频问题

### 三件事里哪件不能省？

上桌那件。聊天感受太主观，对局过程全是可核对的细节，配置和画像都围着它转。

### 打多少局才算够？

没有标准线。个人找感觉几局起步，想形成自己的判断就开锦标赛，多模型循环赛自动排程，积分榜实时刷新，攒数据效率高。记录做得勤，十局八局也能看出门道。

### 新模型上手必须用棋牌吗？

不一定必须，但棋牌的优势是把推演、读牌、诈唬、收官塞进同一局里，考察维度天然多元，跑分给不了这种密度。
