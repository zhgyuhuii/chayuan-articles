# 清除数据为什么这样工作：遥测开关、清除桌面数据

「察元OS 会收集我的数据吗？怎么关闭遥测」——这个问题最近被问了好几次。答案不复杂：清除数据在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 遥测与清除数据是个什么东西

为什么要有清除数据：隐私敏感环境先关遥测再干活，处置设备前清数据。遥测与清除数据的定位是遥测开关、清除桌面数据（破坏性操作有警示）。

入口、步骤、验证三段看清，这事就顺了。

## 具体怎么操作

按最短路径验证一遍：

第 1 步 · 打开分区

Dock ＞ 「设置」＞ 左栏点「隐私与存储」。页面从上到下三张卡：「智能体权限门」＞「遥测」＞「清除桌面数据」。

第 3 步 · 清除桌面数据（破坏性，不可逆）

> 警示：这是本产品最重的重置按钮。没有二次确认弹窗——点下去立即清空并刷新页面，清掉的桌面状态无法找回。动手前确认上面没有舍不得的便签/提醒/布局。

1. 卡片说明原文：「清除本机保存的全部桌面状态（用户名/密码、分组排序、源设置、主题与偏好）并恢复默认，页面将刷新。」
2. 做什么：点红色按钮「清除并恢复默认」。
3. 逐屏流程：只有一屏。点击后代码立即执行两步——清空当前桌面页的全部 localStorage ＞ 整页自动刷新；刷新回来即默认桌面。
4. 清除范围（按代码核实）：该按钮的仅有动作是清空渲染层 localStorage。设置页文案列明「用户名/密码、分组排序、源设置、主题与偏好」；经逐项核实，以下同样存在 localStorage、会一并清掉——桌面便签（chatop_stickies_v1）、提醒事项（os_reminders_lists / os_reminders_tasks）、应用分组（app_groups）、锁屏用户名（lock_username）、主题/壁纸选择、Dock 布局偏好。
5. 不受影响（同一按钮代码只碰 localStorage）：磁盘上的文件（文档、下载）、知识库文档与索引、本地模型权重，以及由桌面主进程保管的账号密码哈希（开机登录/锁屏体系）都不经过这个按钮。
6. 不可逆：被清掉的偏好没有任何恢复入口。

## 几个容易忽略的细节

如实说明，它不是万能的：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 关了遥测，马上生效吗？

不。提示原文是「已保存，重启 dsh web 后生效」——写的是 dsh 的环境文件，需重启察元OS（dsh web 随之重启）后生效。

### 清除桌面数据会删掉我的文档、知识库或下载的模型吗？

不会。该按钮在代码上只清空渲染层 localStorage（桌面状态与偏好），不触碰磁盘文件、知识库存储和模型权重，也不动主进程保管的账号密码。

### 误点了「清除并恢复默认」，能撤销吗？

不能。按钮点击即执行，没有确认框，也没有恢复入口。好在它只清桌面偏好——重新设置主题、重建便签/提醒即可；账号与文件体系不受影响。

### 网页形态里「遥测」卡显示「宿主不可用」？

该卡要读写 dsh host 的 /env 接口；宿主不可达时只显示提示文字，开关不渲染。到桌面形态（察元AI OS）里再操作。

## 更多操作细节

第 2 步 · 遥测开关（可逆）

1. 卡片说明原文：「写入 DSH_TELEMETRY_DISABLED 到 ~/.dsh/.env；dsh 读取该变量停用遥测上报，重启后生效。」
2. 做什么：勾选复选框「停用遥测上报」。
3. 默认值：不勾选——即遥测上报默认开启（~/.dsh/.env 里没有 DSH_TELEMETRY_DISABLED 行时，状态就是「不停用」）。开关的显示状态不是本地猜的：每次打开设置页都会先向 dsh host 拉取该文件的真实状态再回显。
4. 看到什么：勾选/取消后卡片下方出现蓝色提示「已保存，重启 dsh web 后生效」（显示约 3 秒）。
5. 背后动作：勾选 = 在 ~/.dsh/.env（dsh 主目录，可用环境变量 DSH_HOME 覆盖）写入 DSH_TELEMETRY_DISABLED=1；取消勾选 = 删掉该行。要重启 dsh web（即重启察元OS）才真正生效。
6. 该文件同时保管模型密钥（DEEPSEEK_API_KEY 等）：改遥测开关逐行保留无关行，不会动你的密钥。

## 更多操作细节

验证

1. 遥测开关：勾选后用终端执行 cat ~/.dsh/.env，应看到一行 DSH_TELEMETRY_DISABLED=1；重启察元OS 再回设置页，复选框仍为勾选状态。取消勾选后再看该文件，这一行应已消失。
2. 清除效果：先在桌面放一张便签、移动一次 Dock 位置，再点「清除并恢复默认」——页面刷新后便签消失、桌面回到默认外观。

## 补充答疑

### 这个分区里的「智能体权限门」是干什么的？

那是另一张卡：智能体调用系统能力的分级确认（T0 直放/T1 首问/T2 每问），见对应教程 教程，与遥测、清除数据互不影响。

### 设置 ＞ 通用里填的用户名也会被清掉吗？

会。「通用」分区的用户名（lock_username，显示在锁屏与设置头像处）存在本机浏览器存储里，属于本按钮的清除范围，清除后需重新填写。开机登录体系的账号密码不受影响。

## 动手前再核对一遍

- 桌面形态（察元AI OS）。网页形态也能打开该分区，但「遥测」卡依赖 dsh host 的 /env 接口，宿主不可达时只显示「宿主不可用」，开关不出现。
- 「清除桌面数据」动手前先看清下方清除范围——执行后无法撤销。

## 放回产品盘面看

把清除数据放回察元AI OS的整体盘面：它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；以完整桌面环境为壳；（web/Docker 形态网页桌面默认端口）。
