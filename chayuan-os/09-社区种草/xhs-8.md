## 评论区高频问题

### 直跑任务报「未配置模型」？

任务没指定模型、且 设置 ＞ 默认模型 里也没有默认对话模型。二选一：在任务表单「指定模型」，或按对应教程配好默认对话模型。

### 智能体方式支持哪些智能体？别的家行吗？

当前仅 Codex / Claude Code / OpenCode 三家支持无人值守执行（表单下拉也只列这三家）。选了不支持的类型任务会直接失败并留报告。

### 间隔最短/最长能设多少？

「每 N 分钟」合法范围 1–10080 分钟（一周）；「每天定时」为 HH:MM 24 小时制。超出范围保存时报「名称/指令/排程不合法」。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。

## 应用商店与离线分发

商店对接能力广场（aidooo.com），插件、技能、MCP 插件、智能体、技能包五类内容在线下载并云端推送更新，配排行榜辅助选型。内网环境走 .cop.tgz 离线包导入：导出即依赖闭包，导入逐文件校验，断网也能完成分发。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。

## 桌面应用与创造模式

任何网页、本机程序、HTML 文件都能封装成桌面应用（web、local、html、file 四种类型），可放桌面快捷方式也能嵌进壁纸当小组件。创造模式更进一步：智能体在运行时定义并挂载新插件，说一句要什么应用，它能把应用造出来挂上桌面。

## 灵宠与任务灵宠

每个智能体可以化身桌面灵宠：在壁纸上活动，动作与体型反映记忆负载，头顶流式气泡，双击直开工作台。绑定常驻任务的任务灵宠会在执行期上桌直播输出，结束时气泡显示成败摘要——定时任务从日志文件变成看得见的桌面直播。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 统一模型代理的用法

全部模型走一个本机回环地址（127.0.0.1:52581）对外服务：OpenAI chat、responses 与 Anthropic messages 协议互转，对话、嵌入、重排、语音端点齐备。智能体和其他软件只需指向这一个地址，本地模型没运行会自动拉起，厂商请求自动转发云端。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。
