# 察元竞技场配置模型：从点选厂商到测试连接

配模型到底要几步？三步。进设置、点选厂商填 Key、验证连接。察元竞技场配置模型的完整链路就这么短，但每一步「看到什么、填什么、怎么确认」值得写清楚，因为配置环节是新用户流失最多的地方。这篇按真实操作顺序展开，按钮文案照原文引用，每步附界面反馈说明。

## 先弄清楚：配的到底是什么

配模型这件事，本质是告诉应用三样东西：调用哪家的服务、用你的什么凭证、调哪几个模型。竞技场内置了 85 家厂商目录，DeepSeek、智谱 GLM、通义千问、Kimi、OpenAI、Claude、Gemini 都在列，点选即填，不用你自己去查每家的接口地址。全部走 OpenAI 兼容协议，Claude 的原生协议由本机网关自动转换，所以目录里的厂商在操作上没有难度差异。

另一个要建立的认识：应用本身不管你有没有 Key。软件 MIT 开源免费，但调用云端模型产生的 API 费用由你自己向厂商支付。所谓配置，就是把你在厂商那里办好的「通行证」交给应用用。竞技场不卖模型、不代理模型、也不提供公共 Key，它提供的是场地与裁判，模型与凭证都是你自己的。这个定位决定了它是纯本机工具，费用模型也简单：软件免费，模型费用直付厂商，中间没有转手。

## 动手前准备两样

## 动手前准备两样

一是至少一家厂商的 API Key。去你选定的厂商官方开放平台注册账号，在控制台里创建 Key 并复制保存。Key 只显示一次的厂商不少，创建时就要存好。

二是想清楚先接哪家。85 家目录看着挑花眼，实用原则很简单：手上已经有 Key 的先接，没有的话就选一家价格与模型符合你预算的去注册。先接通一家，跑通全流程，再回头加别的，比一次配五家卡在半路强得多。Key 建议存进你自己的密码管理器或加密备忘，别放在聊天记录和明文文档里，这是长期保管凭证的通识。

## 三步走完配置

第一步：进配置入口。打开应用，从设置区进入模型配置页。页面里能看到厂商目录，85 家按列表排开，你可以直接滚动找，也可以按名字定位。

第二步：点选厂商、填入 Key。在目录里点中你要用的厂商，对应的配置表单随之展开，把你复制好的 API Key 粘贴进去。这一步不需要填接口地址，目录里的厂商地址已经内置好了；手填端点的能力留给 OpenAI 兼容中转这类场景，本系列另有一篇专讲。

第三步：验证与拉取模型。表单填好后有两条路可走。想快速确认这把 Key 能不能用，点「测试连接」，它是轻量校验，反馈很快。想把这家账号下可用的模型全列表拉下来勾选，用「获取模型」，它会实拉该账号可用的模型清单返回给你，你从返回的模型里勾选要上桌的，入库完成。勾选落定，这一家的配置就算立住了。

两步做完，这家厂商的配置就落好了。想多配几家，重复上面的点选、填 Key、验证三步即可，多家并存没有冲突，竞技玩法本来就吃多模型同台。

## 点选与手填是两条路，别混

配置模型有两条路，搞清自己该走哪条能省很多弯路。

点选厂商是主路：85 家目录里的厂商，接口地址都内置好了，你只需要点选、填 Key、验证三步。本篇讲的就是这条路，覆盖绝大多数人的场景。

手填端点是辅路：OpenAI 兼容中转、自托管网关这类目录之外的端点，走手填 baseUrl 的方式接入。这条路有自己的玩法与注意项，本系列有一篇专讲，初次配置不必碰。

拿不准就走主路。目录覆盖国内外主流厂商，先看目录里有没有你要的那家，有就点选，没有再研究手填。

## 做完后的验证

配置写好不算完，回大厅打一局才算闭环。选一款轻量的玩法，比如五子棋，开一局人机局或者机机观战，看模型能不能正常出招：对局室里思维链气泡随出招流式滚出，每手的延迟与 token 用量标在旁边。能看到这些，说明配置已经生效；看不到，就回设置区检查厂商与 Key 是否选对。

验证不顺时的排查顺序也给一句：先看厂商选没选对，再看 Key 是否完整粘贴，然后重新点「测试连接」看反馈。三样都过了还是不通，把这把 Key 放到厂商自己的控制台里试一试能否调通，用它区分问题在厂商侧还是在应用配置侧。

## 边界与实话

三条说在前面。模型 API 费用自付，机机观战和锦标赛会让多个模型持续互打，token 消耗比人机局高，挂机前心里要有账。弱一点的模型会出废招，系统有启发式代走兜底，能挡杀就挡、能吃就吃，代走次数超限判负，整局不会被一个抽风的模型卡死，但观赏性会打折。还有，本地小模型或者轻量模型的棋力与出招格式遵守率都有限，配置成功不代表对局好看，这是模型能力问题，不是你配错了。

顺带一句：85 家厂商目录的名单会随版本演进，以你实际打开的目录为准，出现文中没提到的新厂商或个别调整都不奇怪。

## 你可能会问

### 没有 API Key 能玩吗

能。接 Ollama、LM Studio、Xinference 这类本地推理服务就免 Key，本地跑的模型零成本，断网也能玩。想要云端模型的完整体验，就得自己去厂商平台注册创建 Key。

### Key 填错了会怎样

验证环节会反馈失败，把 Key 核对重新粘贴再测一次即可。配置没验证通过之前，对局调不到这家模型，不会产生误扣费——请求都发不出去，何谈计费。

### 能同时配几家厂商

多家都可以，配好各自验证通过就行。竞技场很多玩法天然吃多模型：锦标赛让它们循环赛，机机观战看它们互搏，配得越杂戏越好看。

### 配好的模型信息存在哪

存在你本机的应用数据目录里，不上传服务器。细节本系列有一篇专门讲 Key 的存储位置与安全机制，配置完值得看一眼，心里踏实。

### 勾选的模型多了有副作用吗

没有冲突，多勾只是多几个可上桌的选手，不用的不占资源。锦标赛和机机观战里多几个模型，戏反而更好看。

### 配置到一半关掉会丢吗

已经保存过的厂商配置不会丢，运行时热读取让改动能即时生效。没保存的输入才需要重新填，所以填完先验证再离开页面。

配置模型是整个竞技场体验的地基，三步走通之后，剩下的就是选玩法、看对局、做复盘这些享受环节了。地基打好，去大厅开你的头一局吧。
