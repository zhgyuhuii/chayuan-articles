# 从需求到交付：观看者编辑者

观看者编辑者的麻烦不在功能本身，在于信息散。远程指导、会议室投屏、手机救急，一套机制全覆盖。这篇把它收拢成一条能照着走的路径。

## 解决什么痛点

别人发来一个共享链接，不知道怎么加入、怎么看/操作对方的桌面；正在共享桌面，想知道「现在都有谁连着我、谁是只读谁在控制」；手机连回公司机器，想用手机或异地电脑查看/操作本机的 AI 对话页面，不想投屏、不想配公网 IP。

## 实操全过程

第 4 步 · 认识三种角色（整桌共享房间）

分享者的管理动作（共享进行时）在桌面右侧常驻的「远程用户」清单完成：

1. 每个成员行：昵称 + 角色徽章（「控制中」/「只读」）+「授予操作权」（对只读成员，变「降为只读」）+「踢出」（红色，点击弹确认「把 〈昵称〉 移出房间？其身份将被拉黑，重置链接前无法再进入。」）；
2. 访客点「申请操作权」时，对应成员行高亮并出现「同意控制」/「拒绝」按钮（30 秒未决自动消隐）；
3. 清单可折叠成右缘一个小圆点（角标=在线人数，有申请时橙色呼吸提醒）；访客发来的聊天消息也在清单里行内显示、可直接回复；
4. 整桌共享停止或你不是分享者时，这个清单不显示。

| 角色 | 谁是 | 能做什么 |
|---|---|---|
| 分享者（host） | 发起共享的这台机器 | 看到一切；逐个授予/撤销操作权、踢出成员、停止共享 |
| 可操作（editor，桌面清单里标「控制中」） | 被分享者授权的访客 | 查看并操作分享者的桌面 |
| 只读（viewer，新成员默认） | 普通访客 | 只能看，不能操作；可申请操作权 |

第 5 步 · 访客侧：加入共享桌面（拿到链接的人这样操作）

1. 浏览器打开分享者给的 /s/〈房间号〉 链接，出现「加入共享桌面」门：填「昵称（可选）」与「访问口令（9 位数字）」，点「加入」（连接中显示「连接中…」）；
2. 进入后看到「已加入共享桌面」横幅与自己的角色徽章：只读时提示「你处于只读模式：可以看到一切操作，但无法操作。」，可操作时提示「分享者已授予你操作权。」；
3. 只读访客可点「申请操作权」（已申请显示「已申请，等待分享者授权…」），等分享者在右侧清单里「同意控制」；
4. 左侧「在线成员」列表可看房间内所有人及角色；随时点「退出共享房间」离开。

## 关键能力点

- 三级权限角色
- 公网云中继可自建
- 限时分享链接
- 手机镜像

## 几个容易忽略的细节

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 高频疑问

### 二维码/链接位置一直转圈，或显示「网络异常」？

出码前产品会确认云端（aidooo.com）可达，探测波动会自动重试。先检查本机外网；持续「网络异常」可点「停止分享」稍后重开。

### 设置 ＞ 远程访问里一直「未共享」，但我明明在分享 Harness 页？

正常。该卡只反映整桌共享房间；「分享 Harness 页」是独立通道，不在这张卡里列成员。

### 帮助文档里说的「发起共享」「远程分享」「开启远程控制」按钮在哪？

2026-10-14 产品裁定后顶栏面板只保留「分享 Harness 页」（公网分享统一走真页面直开），整桌镜像的发起/远程分享/远程控制入口已从面板隐藏（能力保留在产品内，后续版本可能重新开放）；访客加入、成员角色管理与设置＞远程访问状态卡不受影响。

## 更多操作细节

验证

1. 顶栏手机图标打开面板：默认已出现二维码与 aidooo.com/h/… 链接、绿色「分享中」徽章；用手机扫码应直接打开本机 Harness 页并发一条消息，本机同步可见。
2. 点「停止分享」后刷新手机页面：链接失效；面板回到「开启分享」按钮。
3. 设置 ＞ 远程访问：整桌共享房间有成员时逐行可见「控制中/只读」与在线状态；5 秒内自动刷新（断开对方浏览器后其行变「离线」或消失）。

## 动手前再核对一遍

- 桌面形态（察元AI OS），共享面板与远程访问页均在桌面顶栏/设置中。
- 外网分享需要云端可达：分享链接由默认云端（https://aidooo.com）反代生成，装机零配置；云端不可达时面板显示「网络异常」并自动重试，期间不出链接/二维码。
- 访客加入整桌共享房间需要两样东西：共享链接（/s/〈房间号〉）+ 9 位数字访问口令（分享者面板上以 000-000-000 格式展示，可复制告知）。
- 口令错误有节流：连续输错会提示「尝试次数过多，请一分钟后再试」。

## 放回产品盘面看

把观看者编辑者放回察元AI OS的整体盘面：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注，共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道。

## 安全与数据边界

安全口径单独立一层：远端调用走权限门留审计；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。
