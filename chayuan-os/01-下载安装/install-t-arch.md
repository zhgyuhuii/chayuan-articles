# 架构不符排查：uname 确认架构再选包

先说这篇能帮你干什么：读完能在察元AI OS里独立完成架构不符排查，路径是架构不符排查。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：uname 确认架构再选包。

安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

把架构不符排查放回察元AI OS的整体盘面：灵宠把后台跑着的 AI 变成桌面上看得见的小生物；右键编辑改配置，删除有两步确认，桌面上的野宠可以收编为正式灵宠建档，定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见；可选群分区（桌面出图标双击进群）。
