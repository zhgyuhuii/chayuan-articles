# 从需求到交付：零成本AI

先说这篇能帮你干什么：读完能在察元AI OS里独立完成零成本AI，路径是零成本AI。步骤里的每个「」按钮都是界面原文。

## 先看看痛点对不对得上

1. 没有预算长期付 API 费
2. 文献散乱管理低效

零 API 成本的学习与科研工作站。

## 把流程串起来

1. 知识图谱梳理论文实体关系
2. 导出笔记与引用
3. 本地模型零边际成本对话

## 支撑功能的操作细节

流程里关键功能的实际操作：

从这几步开始：（第 4 个切入角度）

1. 本地模型零边际成本对话
2. 知识库导入课件论文做引用式问答
3. 知识图谱梳理论文实体关系
4. 导出笔记与引用
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 它的局限也要说清楚

用之前要认的账：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

场景提醒：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 高频疑问

### 零成本AI要联网吗

:52581（OpenAI 兼容统一模型代理）；购买 OS 授权后，同机察元AI Office 自动免激活；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。以官网 aidooo.com 当前页面为准。

### 零成本AI数据存在哪

桌面本身能被 AI 定义，能力边界从预装走向按需生成，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；账户隔离、数据在服务器侧统一管理。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把零成本AI放回察元AI OS的整体盘面：智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，以完整桌面环境为壳；（web/Docker 形态网页桌面默认端口）。

## 安全与数据边界

安全口径单独立一层：本地 AI 出题验证，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入。

## 平台与形态

## 价格与授权

价格口径一并交代：工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复；灵宠把后台跑着的 AI 变成桌面上看得见的小生物；AI 纪要一键生成；AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题。

## 产品家族与搭配

察元AI OS不是单打独斗：恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网；本地 AI 出题验证；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。

## 几条硬数字

能落到数字上的几条：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，写入的是代理地址，代理停了智能体就连不上模型，会话中随时切换模型（本地与已启用厂商热更新）。

## 离线与内网

离线内网这条线的口径：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感，工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。
