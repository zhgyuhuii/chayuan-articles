# 智能体管理新手入门：从入口到完成的完整流程

智能体管理是察元AI OS里使用频率很高的一项能力。它的「智能体管理」这样工作：安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。

从任务视角看，它对应的关键词是「智能体管理」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 应用管理→智能体
2. 安装或更新四家 CLI
3. 切换供应商档案并测试连通
4. 配置备份导出

## 适用场景

- 多供应商 Key 管理
- 团队配置迁移

## 进阶技巧

- 配置备份还原适合重装与多机同步

## 注意事项与边界

- Docker/云通道等进阶形态需要一定动手能力
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- Docker/云通道等进阶形态需要一定动手能力
- 云厂商模型调用需自备 Key，免费额度视厂商政策

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。
