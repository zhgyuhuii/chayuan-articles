# 内网/涉密单位用户的内网AI方案（完整方案）

如果你是内网/涉密单位用户，下面这些场景大概率不陌生：物理隔离无法用云端 AI。断网也有完整 AI 能力。这篇完整方案以察元OS为工具，把这个岗位的内网AI工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 物理隔离无法用云端 AI
- 数据严禁出域
- 部署没有运维人力

## 用察元OS怎么解：工作流拆解

1. 离线部署五步法装机
2. 本地五件套模型直接可用
3. 全部服务回环监听不出域

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「离线部署五步法装机」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。断网也有完整 AI 能力。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 涉密使用需本单位审批
- Docker/云通道等进阶形态需要一定动手能力
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### 其他软件能用本机模型吗？

能。统一模型代理提供 OpenAI 兼容与 Anthropic 协议接口（对话/嵌入/重排/语音），任何支持的客户端指向本地代理即可。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。
