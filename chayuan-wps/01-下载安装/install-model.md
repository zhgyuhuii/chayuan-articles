# 首次配模型：助手能对话的前提是接上一个对话大模型

首次配模型的麻烦不在功能本身，在于信息散：厂商清单、地址、密钥、检测入口分布在不同面板里。优先支持离线内网模型是这套加载项的立场：涉密文档不出网也能用 AI。这篇按实际点击顺序把整条配置链走一遍。

## 先把加载项装进 WPS

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：五家通道与本地端口。

安装包从官方发布渠道获取；第三方镜像站的包没法保证没被动过手脚。

## 装加载项只要四步

1. 从官方渠道获取 exe 安装包
2. 双击安装，加载项落进 WPS jsaddons 目录，本机服务同时完成自注册并带看门狗
3. 完全退出并重启 WPS
4. 文字端看到察元AI助理与察元AI编审两个选项卡，即算成功

## 装完先验一次批注链路

装完先挑一篇旧文档试试校对，批注能出来就说明模型通了；再进察元AI编审选项卡确认规则管理正常加载，两端都在，加载项就算装实了。

## 用这两个信号确认装到位

- 两个选项卡都现身，说明加载项本体已经就位
- 没生效就把宿主软件彻底关掉再开一次，多半是进程没退干净

## 模型配置之外的几条边界

- 配好云端厂商后，发给它的请求里带着整份文档内容；文档密级高的话，直接走本地 Ollama 这条线更安心
- 脱密占位替换支持还原，但这套可逆机制没有留后门：密码忘了就是忘了，没有免密恢复一说
- AI 痕迹检查的输出定位是排查参考，标出来的都只是疑似，别直接当结论用

## 配置时高频报错三问

### 检测时提示「请先填写 API 地址」/「请先填写 API 密钥」？

检测依赖地址＋密钥：地址必填；密钥对 Ollama 类免密钥供应商可空，云端厂商必填。补齐后再点检测图标。

### 检测报「连接失败： 401 / 403 / 404 …」怎么处理？

- 「401 未授权：请检查 API 密钥是否正确、是否已过期，或该密钥是否有访问权限」＞ 核对 / 重贴密钥；
- 「403 禁止访问：API 密钥可能无权限访问此接口」＞ 检查该 Key 的接口权限；
- 「404 未找到接口（探测 <地址>）：请确认服务已启动、地址正确」＞ 地址写错（多 / 少了 /v1）或本地服务没启动。
失败后该厂商清单行会挂「异常」徽标（悬停显示「最近检测失败：<原因>」）；修复后重新检测成功即自动清除。

### Ollama 显示「未检测到（未安装或未启动）」？

本机 11434 端口无响应。先确认 Ollama 服务已启动（终端能执行 ollama list）；没装就点「一键安装」，察元会自动择优打开官网 / ModelScope 镜像下载页；装好启动后回到该面板即自动识别。

## 第一步：从助手窗格进模型设置

入口在 AI 助手窗格，三种等价走法任挑一种：欢迎页标题「先配置模型，再开启智能写作。」下方点「立即配置模型」；或在输入区模型下拉（此时显示「配置模型」）展开后的空态提示「请先在设置中配置模型：开启提供商、填写 API 地址与密钥、刷新模型清单」里点「立即配置模型」；或点侧栏左下角的「设置」齿轮按钮（悬停提示「设置」）。打开后是一个独立的设置窗口（默认 1120×820），左栏默认停在「模型设置」。

## 第二步：供应商清单里选一家

设置窗口第二列是厂商清单。清单按五个分组折叠展示——「自定义 / 国内平台 / 国际平台 / 本地与自建 / API 聚合」；顶部有「全部 / 免Key / 免费」筛选下拉和搜索框。每行带标签徽标：「免Key」（本地 / 自建或无需 API Key 即可使用）、「免费」（注册即得免费 Key）、「免费额度」，以及状态徽标「已开启 / 已配置 / 未配置 / 异常」。出厂默认开启五家（「已开启」= 显示在察元AI助理的模型下拉中）：OpenAI、Ollama、DeepSeek、百度云千帆、阿里百炼。云端路线就点 DeepSeek（或其它云端厂商）；离线路线在「本地与自建」组里点 Ollama（或 LM Studio）。

## 第三步：填密钥与地址（云端以 DeepSeek 为例）

第三列是厂商配置面板，标题即厂商名，右侧带启用开关。面板里有「API 密钥」输入框（占位「请输入 API 密钥」，行尾三个小按钮：粘贴、显隐眼睛、检测图标），以及「API 地址」输入框——选中厂商时已按官方地址预填（DeepSeek 为 https://api.deepseek.com/v1，下方显示「对话接口预览: …」实时预览）；「模型」区初始显示「暂无模型」和提示「配置 API 地址后，点击"刷新模型"按钮获取可用模型」。

接下来四件事按顺序做：在「API 密钥」粘贴 Key（提示「多个密钥使用逗号分隔」；没有 Key 时点提示行里的「获取秘钥」链接直达该厂商密钥管理页）；确认「API 地址」为预填的官方地址；点「刷新模型」拉取模型清单（「管理」按钮可增删）；点密钥行的检测图标按钮（悬停提示「检测 API 密钥和地址是否可用」）。随后界面先提示「正在检测连接...」，成功后提示「连接成功，API 可用」；失败会给具体原因（见上面第二问）。另外，Ollama 类免密钥供应商（Ollama、LM Studio、Xinference、One API、FastChat、New API）可以不填密钥，检测时也不会被要求先填 Key。

## 第四步：离线路线连本机 Ollama 或 LM Studio

还是同一个面板，选中 Ollama（或 LM Studio）后，配置面板顶部会多出一条本地引擎状态条，自动探测后是三种结果之一：「Ollama 已安装并运行（<版本>）」；「未检测到 Ollama（未安装或未启动）」＋「一键安装」按钮——点击后自动择优打开 Ollama 官网或 ModelScope 镜像的下载页（按钮变为「正在打开…」；macOS / Linux 还会把官方安装命令复制到剪贴板备用），装好启动后回到此页即自动识别；或者「⏳ 正在检测 Ollama…」。

选中 Ollama 后「API 地址」已预填默认地址 http://localhost:11434，一般无需手填；若该框被清空且探测到服务在运行，状态条会提示「检测到本地服务运行于 127.0.0.1:11434，点击「填入地址」自动完成配置。」并出现「填入地址」按钮——点击一键补回默认地址。补填后提示「已填入 Ollama 默认地址 http://localhost:11434，可点击「刷新模型」获取本地模型列表」。LM Studio 同理（默认地址 http://localhost:1234，预填形式 http://localhost:1234/v1）。地址已配好时，状态条改为显示拉取模型的网络提示（如建议从 ModelScope 下载 GGUF 导入或配置国内镜像加速）。收尾动作是点「刷新模型」列出本机已拉取的模型。

主干抓住就不慌：默认五家通道里挑一家，云端填 Key、离线装 Ollama，检测图标点绿了再谈后续；分支情况等真遇到时，回「配置时高频报错三问」那一节对照。
