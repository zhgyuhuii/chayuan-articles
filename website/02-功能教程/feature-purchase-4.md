# 个人领促销折扣：促销活动的坑与对策

促销活动的麻烦不在功能本身，在于信息散。从下单到发票到售后，购买链路页面齐全。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

促销活动的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把环境与模型这两件事核一遍，再查路径。

## 正确的操作路径

购买与查单

1. 进购买授权页选产品与档位
2. 扫码支付完成下单
3. 需要时到查询页按机器指纹查记录
4. 按需申请发票

席位授权怎么激活

1. 后台部署授权页复制部署指纹（或扫码自动带入）
2. 购买席位时填写该指纹，席位绑定部署而非单设备
3. 桌面端在授权页复制 16 位本机指纹，多台用逗号隔开
4. 凭指纹取序列号，服务端幂等、重复取号结果一致

## 进阶用法与边界

- 扫码下单
- 指纹查单
- 发票申请
- 席位绑定部署
