# 首启慢排查怎么用：模型配置可一键写入五家

先说这篇能帮你干什么：读完能在察元AI OS里独立完成首启慢排查，路径是首启慢排查。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：初始化 5 到 30 秒属正常。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 它的局限也要说清楚

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 放回产品盘面看

把首启慢排查放回察元AI OS的整体盘面：暂不支持龙芯平台，Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。

## 安全与数据边界

安全口径单独立一层：数据文件不受影响，三条路都不满足就只能清数据重装，务必提前生成恢复密钥；需要提前开启并积累足够记忆数据，管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录。

## 平台与形态

平台与形态的账：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness。

## 离线与内网

离线内网这条线的口径：断网可用、数据不出本机；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；本地不提供视频生成（视频生成走云端路由），本地模型解决有无问题，复杂任务还是需要云端旗舰模型。
