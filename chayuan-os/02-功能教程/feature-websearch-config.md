# AI联网搜索怎么用：手把手走一遍完整流程

如果你正在琢磨AI联网搜索，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI OS的联网搜索配置时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 概念先掰开

在 设置 ＞ 默认模型 的「网络资源搜索」页里给智能体配联网检索与图片/图库平台：逐平台开关勾选、需 Key 的平台（Serper / Tavily / Linkup / SearXNG / DeepSeek 搜索 / Pexels / Pixabay / Unsplash 等）填入 API Key，还可以添加自定义平台；点「保存并更新技能」后，平台与 Key 写进系统技能伴随文件 models.md 并自动分发到各智能体，智能体的联网搜索即可用。

智能体默认不知道今天发生了什么，接一路搜索源它才能查实时资料。

下面直接进入正题。

## 开工前检查这几样

- 需要 Key 的平台先去对应官网注册并拿到 Key（每张平台卡上有「申请 Key」按钮直达官网）。
- 不配 Key 也能搜：系统的联网检索默认走「DeepSeek 搜索」（官方目前免费），不可用时逐平台降级，最终落到完全免 Key 的 DuckDuckGo 兜底；图片搜索组（Bing Images / Baidu Images / Openverse）也全部免 Key。参见下文「常见问题 Q1」。
- Key 保存在本机 harness 凭证库（~/.dsh/.credentials.yaml，引用名 CHATOP_SEARCH_<平台>_KEY），与模型厂商密钥同库。

## 从打开到做完的每一步

1. 进入页面

打开 设置，左栏第二项「默认模型」。页面为左右双栏：左栏是分类竖栏（十一个模型分类），最底部隔着一条分隔线有一项「网络资源搜索」，点击进入。右栏卡片标题「网络资源搜索」，说明文案：「勾选=允许智能体使用该平台；需 Key 的平台填写后才会写进技能。免 Key 平台即刻可用。」

2. 认识平台卡片

页面按四个分组排卡片，组头带图标、分组名和数量药丸（如「网络检索 6」）：

| 平台 | Key | 说明 |
|---|---|---|
| Serper | 需 Key | Google 检索 API（google.com/serper api） |
| Tavily | 需 Key | api.tavily.com/search |
| Linkup | 需 Key | api.linkup.so/v1/search |
| SearXNG | 需 Key | 填的是自托管实例 URL，不是 Key（见步骤 4） |
| DuckDuckGo | 免 Key | html.duckduckgo.com 网页解析，兜底档 |
| DeepSeek 搜索 | 需 Key | api.deepseek.com/v1/tools/search（目前免费） |

每张卡片：左侧字母渐变圆标 + 平台名 + 徽标（琥珀色「需 Key」或绿色「免 Key」）+ 等宽小字端点提示；右侧是平台开关（Switch）。开箱默认全部平台勾选。关掉开关的卡片整体变半透明，保存后不写进技能。

1. 「网络检索」组（6 个）——智能体联网查网页用：
    1. 「图片搜索」组（3 个）：Bing Images、Baidu Images、Openverse，全部免 Key；
    2. 「图库素材」组（3 个）：Pexels、Pixabay、Unsplash，全部需 Key（找素材图用）；
    3. 「自定义平台」组：你自己加的平台（见步骤 6）。

3. 给需 Key 的平台填 Key

需 Key 的卡片在名称行下方有一个 Key 输入框：

1. 占位提示「API Key」；右侧眼睛图标切换明文/密文显示；
2. 旁边「申请 Key」按钮打开该平台官网 Key 页（Serper ＞ serper.dev、Tavily ＞ app.tavily.com、Linkup ＞ linkup.so、DeepSeek ＞ platform.deepseek.com、Pexels/Pixabay/Unsplash ＞ 各自开发者页）；
3. 之前保存过的 Key 会自动回显在输入框里，输入框右侧亮绿点（悬停提示「已配置」）；回显后没改动的 Key 保存时不重写。

4. SearXNG 特殊：填实例 URL

SearXNG 是自托管元搜索引擎，输入框占位提示是「SearXNG 实例 URL」——填你自己或公共服务商的实例基址（必须以 http:// 或 https:// 开头，执行器用它拼 …/search?q=…&format=json 调 JSON API）。「申请 Key」按钮打开官方文档 docs.searxng.org。

5. 保存

点页面底部右侧蓝色按钮「保存并更新技能」（保存中显示「保存中…」）。保存动作依次做这几件事：

成功后右上角绿色提示「已保存，系统技能已更新并分发到各智能体」。失败显示红色错误——若报「模型代理未运行，无法接入云端厂商（先在模型设置里确认服务状态）」，见「常见问题 Q5」。

1. 把改动过的 Key 写入 harness 凭证库（CHATOP_SEARCH_<平台>_KEY）；
2. 若本次保存同时涉及某个模型分类新选了云端厂商，顺带确保该厂商加入模型代理路由（无此情形则跳过）；
3. 渲染 models.md：已勾选的平台进「网络资源搜索」表（免 Key 平台标「免 Key」，需 Key 未填的标「未配置（需 Key）」，已填的写入 Key 值；取消勾选的平台整行不出现）；
4. 落盘 defaults 文档，触发系统技能包（含 models.md）重新分发到各智能体。

6. 添加/删除自定义平台

1. 「自定义平台」组头右侧「+ 自定义平台」展开内联表单：「平台名称（如 必应）」（必填）、「端点/备注（可选，写入技能）」、「需要 Key」勾选框（默认勾选）＞「取消」/「添加」（名称为空时「添加」置灰）。新卡片带蓝色「自定义」小标；
2. 自定义平台同样可填 Key、可开关；卡片右上「关闭」删除（悬停提示「删除」）。

7. 配好的 Key 如何被用起来（不需要你操作，了解即可）

1. 网页检索降级链（智能体 web_search 工具与群聊 同一执行器）：默认 DeepSeek 搜索，不可用逐档降级 serper ＞ tavily ＞ linkup ＞ searxng ＞ duckduckgo，每档只在「Key 已配或免 Key」时尝试、单档 8 秒超时，直到有一档返回结果；
2. 图片搜索/图库素材：平台与 Key 随 models.md 写入智能体技能手册，智能体按手册直接调用对应平台。

## 收尾检查

验证

1. 保存成功后重新进入本页：已保存过 Key 的平台卡片输入框回显 Key 且右侧亮绿点（「已配置」）。
2. 取消勾选一个平台再保存，卡片变半透明；重新勾选再保存即恢复。
3. 配好 Serper（或任一需 Key 平台）的 Key 后，让任一智能体「联网搜一下今天的新闻」：回答应带搜索来源；完全没配任何 Key 时也能搜（默认 DeepSeek 搜索 ＞ DuckDuckGo 兜底链）。

## 适用场景

想让智能体/灵宠联网查资料，或想让群聊的 联网开关搜索到结果，已注册了某家搜索平台（Serper、Tavily、Linkup、图库站等）的 API Key，想知道填在哪里；不想配任何 Key，想知道系统默认能不能搜、用的是什么，智能体查最新行情写日报。

用户常搜的问法：怎么给智能体开联网搜索？搜索 API Key 填在哪里；不填 Key 能联网搜索吗？默认用哪个搜索引擎。

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 需要相应平台的 Key（部分有免费额度）
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 断网时联网搜索自然不可用
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 关掉某平台开关有什么影响？

该平台不写进 models.md；「网络检索」组的平台同时从降级链里消失（该档直接跳过）。开关只影响「允许智能体使用」，已存的 Key 仍保留在凭证库里，重新勾选即可恢复。

### Key 存在哪里？会泄露给谁？

Key 存在本机 harness 凭证库 ~/.dsh/.credentials.yaml（引用名 CHATOP_SEARCH_<平台>_KEY），回显后未改动不会重写。注意：已勾选且填了 Key 的平台，Key 值会明文写进 models.md——该文件作为系统技能伴随文件分发到本机各智能体的技能目录，供智能体直接调用；取消勾选即从 models.md 移除。

### 保存时报「模型代理未运行，无法接入云端厂商」？

本页保存时会顺带处理模型分类里选了云端厂商的路由。到 设置 ＞ 模型 查看本地模型服务健康灯、恢复模型代理（127.0.0.1:52581）后再回来点「保存并更新技能」。

### 一个 Key 都没配，智能体能联网搜索吗？

能。联网检索走降级链，默认「DeepSeek 搜索」（官方目前免费，但需要在 platform.deepseek.com 注册拿 Key 填入）；最终兜底的 DuckDuckGo 完全免 Key、无需任何配置。中间档（Serper/Tavily/Linkup/SearXNG）只在 Key 已填时参与。

AI联网搜索的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
