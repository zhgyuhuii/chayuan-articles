## 什么是麒麟办公软件

## 你可能会问

### 第三方下载站 mirror 的安装包能用吗？

不能保证。官方分发只有 aidooo.com 与本仓库 GitHub Releases 两处，其余站点均非官方分发，存在被篡改风险，请从官方渠道重新下载。

### 麒麟/UOS 上装哪个包？要联网吗？

选 .AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb。下载一次后可拷贝到内网机器直接安装/运行，应用本体不依赖联网。

### 90 天试用到期会锁功能吗？要注册账号吗？

不锁功能。到期后每日一次温和提醒（可关闭），不购买也完全不影响使用；购买走离线短序列号，内网无激活服务器也能激活。使用 AI 的云端能力需在设置中配置模型或登录账号，见产品内的对应手册产品内的对应手册。

### 麒麟办公软件要联网吗

透视表与公式引擎是表格软件的硬指标，自研边车保证 xlsx 往返不失真；录课与路演的旁白不用二次软件录制，放映态内完成，让 Claude Code 这类智能体直接读写你的文档，办公自动化从此有了标准协议。以官网 aidooo.com 当前页面为准。

### 麒麟办公软件支持哪些格式

格式兼容是办公软件的生死线，明确支持什么、不支持什么，比含糊其辞负责任，打印别掉链子、断电别丢稿，这是办公软件的两条底线；doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx。以官网 aidooo.com 当前页面为准。
