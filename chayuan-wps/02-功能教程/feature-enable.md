# WPS加载项实操实操，装完完全退出并重启 WPS

WPS加载项实操这件事，值不值得专门学一篇，看一个细节就够：三端选项卡分布明确。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI文档助手。

## 先弄清楚它是什么

为什么要有WPS加载项实操：选项卡出不来的排查路径写清楚了，装完第一次就能自己搞定。在 WPS 中启用的定位是装完完全退出并重启 WPS：文字端出现察元AI助理与察元AI编审两个选项卡，

先把定位立住，再看步骤。

## 准备清单

- 已按对应教程完成安装，并且完全退出后重启过 WPS（安装后不重启，WPS 不会加载新插件）。

## 完整操作步骤

第 1 步 · 打开 WPS 文字，看功能区

在哪：WPS 文字顶部功能区（选项卡行右侧）。

看到什么：出现两个察元选项卡——

正常安装后自动加载，无需手动启用。此时第 2、3 步可跳过。

1. 「察元AI助理」：分组「关于 / AI助手 / 安全保密 / 文档批量 / 批量操作」，其中「AI助手」组首按钮为「AI助手」（打开主对话窗格）；
2. 「察元AI编审」：分组「表单辅助 / 模板管理 / 规则管理 / 察元设置」。

第 2 步 · 没看到选项卡时：在「开发工具 ＞ 加载项」里确认启用状态

1. 在哪：WPS 菜单 ＞「开发工具」＞「加载项」（此为 WPS 自身界面，以本机 WPS 实际菜单为准）。
2. 做什么：在加载项列表里找到「察元 / chayuan」条目，确认其状态为「已启用 / enable」；若被禁用则启用。
3. 看到什么：回到功能区，察元选项卡出现（必要时再重启一次 WPS）。

第 3 步 · 表格端 / 演示端确认

打开 WPS 表格或 WPS 演示，功能区出现单个「察元AI助理」选项卡：

1. 表格端（AI 表格助手一排大按钮：「AI表格助手 / 公式助手 / 数据洞察 / 一键图表 / 数据清洗 / 报表结论 / 一键美化 / 模板新建 / 设置」）＋两个下拉菜单：「文档安全」（保密检查 / 加密工作簿 / 解密工作簿）、「更多表格助手」（排序汇总 / 多表合并汇总 / 两表对比差异 / 表格翻译 / 敏感信息脱敏 / 智能分列 / 按列拆表 / 文档抽取成表 / 数据战报页 / 设置）；
2. 演示端（「AI演示助手 / 生成PPT / 整套摘要 / 美化统一 / 口播稿 / 整套校对 / 结构诊断 / 模板新建 / 设置」）＋「文档安全」（保密检查 / 加密演示稿 / 解密演示稿）、「更多演示助手」（结构件补齐 / 整套翻译 / 转讲义文档 / 页码页脚 / 数据战报页 / 课件生成 / 习题互动页 / 设置）。

## 做完后的验证

验证

1. 「察元AI助理」选项卡 ＞「AI助手」按钮 ＞ 右侧弹出 AI 助手窗格；未配置模型时窗格显示欢迎语「先配置模型，再开启智能写作。」和「立即配置模型」按钮。
2. 「察元AI编审」选项卡 ＞「察元设置」组 ＞「设置」按钮能打开设置窗口。
3. WPS 表格 / 演示端各能看到「察元AI助理」单选项卡（按钮清单见第 3 步）。

## 什么情况下用得上

装完首验，装完察元，第一次打开 WPS 不知道去哪找入口，升级或重装后功能区里的察元选项卡消失了；升级后选项卡消失自查。

用户常搜的问法：装好之后 WPS 里怎么看加载项启没启用；WPS 功能区没有察元AI助理这个选项卡怎么办。

## 注意事项与真实边界

用之前要认的账：

- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 接着回答几个常见问题

### 功能区完全没有察元选项卡？

按顺序排查：① 完全退出 WPS 再打开（安装后必须重启）；② 核对 jsaddons 路径下有没有 chayuan_<版本> 等目录；③ 「开发工具 ＞ 加载项」里确认「察元 / chayuan」为已启用；④ 麒麟 / UOS 专业版执行 /opt/apps/cn.wps.wps-office-pro/files/bin/quickstartoffice restart。

### macOS 升级后选项卡消失或仍显示旧版？

容器权限或 WPS 运行中安装导致注册表（authaddin.json / jsplugins.xml）没更新到新版本目录。完全退出 WPS ＞ 重跑安装包 ＞ 再打开；仍不行时在有完全磁盘访问权限的终端执行 bash scripts/repair-mac-jsaddons-container.sh（会同步注册表并清理 jsapi 缓存）。

### 首次加载时 WPS 弹出「已被修改」类提示？

首次加载察元插件时 WPS 可能弹出该提示，点「确定」继续即可（察元官方部署脚本的既定口径）。

### 文字端菜单正常，表格 / 演示端却显示了文字端的菜单（或两菜单错乱）？

三个宿主的 Ribbon 配置文件放错位所致（历史上手动拷贝 / 共用目录部署时出现过）。用官方安装包重装一次即可——安装器会按宿主分别放入 chayuan_<版本>、chayuan-et_<版本>、chayuan-wpp_<版本> 并放对各自的 ribbon 配置。

### 安装时没注意，WPS 一直开着有没有影响？

macOS 有明确影响：WPS 退出时会用内存里的旧注册状态覆写登记文件，本次安装等于白装（安装器检测到会打印警告）。完全退出 WPS 后重跑一次安装包即可；Windows/Linux 装完后重启 WPS 生效。

## 更多操作细节

第 4 步 · 文字端右键菜单入口（辅助确认）

在正文 / 标题 / 表格单元格上点右键：出现「添加到察元」与动态菜单「察元AI文本分析」等察元条目，说明右键注入也已生效。

## 补充答疑

### 「开发工具 ＞ 加载项」列表里出现多个「察元」条目？

多轮升级的残留：macOS 的登记表（authaddin.json）会累积同名条目，官方安装器每次安装都会自动去重并把条目指向当前版本目录——重跑一次最新安装包即可清理。Windows / Linux 的 WPS 按 jsplugins.xml 加载，安装器只更新本产品条目、并清理旧版本目录；若旧条目指向已删除的目录会导致加载失败或回退旧缓存，同样用重装修复。
