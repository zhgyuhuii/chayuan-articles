# 文档智能体攻略：应用内文档智能体的关键点拆解（细节版）

文档智能体是察元AI文档助手里使用频率很高的一项能力。它的「应用内文档智能体」这样工作：对话框内的文档智能体车道：AgentLoop 自循环（最多 16 轮工具调用）、todo_write 任务清单（先列计划边做边勾）、三档写权限（变更前确认/自动执行/完全访问）、写前快照一键撤销、文档写锁（FIFO+OCC）与「声称核对」防谎报。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

对话框内的文档智能体车道：AgentLoop 自循环（最多 16 轮工具调用）、todo_write 任务清单（先列计划边做边勾）、三档写权限（变更前确认/自动执行/完全访问）、写前快照一键撤销、文档写锁（FIFO+OCC）与「声称核对」防谎报。

从任务视角看，它对应的关键词是「文档智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 在对话框切到文档智能体
2. 下达复合任务（如「核对全文数字与表格一致性并修订」）
3. 查看任务清单与每步工具调用
4. 按写权限确认变更，不满意用快照撤销

## 适用场景

- 一句话完成「查+改+核」复合任务
- 长文档多轮整理

## 进阶技巧

- 默认「变更前确认」档最稳，熟悉后可切自动执行
- todo 清单让你随时知道智能体做到哪一步

## 注意事项与边界

- 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 常见问题
### 能处理多长的文档？

长文分块读取（document_chunks）对百万字级文档友好；校对建议分批确认，避免一次任务过大。

### 什么是 MCP 文档智能体服务？

加载项内置的本机服务（46 工具/15 域），外部 AI 编程工具（Claude Code、Codex、Cursor 等）连上后可直接打开、读取、修改、批注本机 WPS 文档，写操作默认只预览、传 confirmed:true 才落盘。

### 它是免费的吗？

开源（Apache-2.0）可免费使用：免费版对话每日 30 次；文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能（免费每日 2 次共用池），购买后不限次数。
