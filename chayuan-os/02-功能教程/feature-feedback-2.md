# 产品反馈进阶理解：从会用到懂原理

写这篇的起因是群里有人问产品反馈，我发现自己也说不完整，索性把察元AI OS里的反馈与帮助中心从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 它是什么，为谁服务

察元OS 的求助与支持四件套：有问题找「帮助」菜单 ＞「反馈…」的在线客服（离线自动出公众号二维码兜底）；想支持产品走「激活与购买…」扫码购买授权（购买完全自愿，不买不影响任何功能）；自学查手册开「帮助中心」应用（六节手册 + 全文搜索）；桌面右下角还有「关注我们」二维码挂件。

帮助中心离线可读，断网也能查手册。

入口、步骤、验证三段看清，这事就顺了。

## 原理与设计取舍

帮助中心离线可读，断网也能查手册。

能力面拆开看：离线手册，反馈通道，授权管理。

## 实操全过程

按最短路径验证一遍：

板块一 · 反馈（在线客服）

1. 顶栏「帮助」菜单 ＞ 「反馈…」。
2. 弹出居中面板（标题栏可拖拽、双击标题栏回到居中）：标题「在线客服 · 察元AI」，标题栏上的绿点为在线指示。
3. 连接中显示「正在连接在线客服…」；连上后面板内嵌察元机器人聊天页（与官网同一界面），直接打字描述问题即可——会话带 channel=harness 渠道标识，客服后台按渠道筛选。
4. 离线/拒嵌兜底（断网或 10 秒未连上）：显示「当前网络不可用，无法打开在线客服」「请用微信扫码关注公众号，与我们联系」+ 本地内置的公众号二维码 + 「重试」按钮。
5. 点弹窗外的深色遮罩关闭。
6. 说明：旧版「反馈及建议」表单弹窗（类型/正文/附件/运行日志）的菜单入口已切换为在线客服，表单保留为备用通道，不再从菜单进入。

板块二 · 购买授权

1. 入口三合一：顶栏「帮助」菜单的授权状态行——未授权时显示「激活与购买…」，已激活显示「激活：已授权 · 至 {date}」，体验期显示「激活：免费体验中 · 剩 {n} 天」，到期显示「激活：体验期已结束 · 点击购买」；免费期结束后的温和提醒气泡（右下角，60 秒自动消失，点击打开）；以及到期后每日首次启动自动弹出的购买页。
2. 弹窗标题「察元AI OS · 购买授权」：顶部一行授权状态（已激活时附打码序列号），下接两个页签：
    1. 「扫码购买」：本机生成的二维码（编码 aidooo.com/buy?app=os&mid={本机指纹}）+ 说明「手机扫码选档付款（微信 / 支付宝），价格以购买页为准」+「在浏览器中打开」+「本机指纹」行与「复制」按钮（指纹 = 基于本机机器标识的 16 位十六进制码，一机一码）。
    2. 「分享」：二维码编码分享页（/share?mid={指纹}），说明「分享给好友，好友购买后你可获赠使用权益」。
    3. 购买流程（弹窗底部指南原文）：「① 手机扫码打开购买页；② 选档付款（档位价格以购买页为准）；③ 付款后页面显示序列号；④ 回这里粘贴激活，序列号会自动识别所购档位。支付在手机上完成，电脑无需联网。」
    4. 激活：在「已有序列号？输入即激活」输入框（占位 XXXXX-XXXXX-XXXXX-XXXXX-X）粘贴序列号 ＞ 点「激活」（期间显示「验证中…」）。成功显示绿色「激活成功 · 有效期至 {date} · 察元AI OS · 续期 {n} 天」；失败给出具体原因：「序列号格式不对或校验失败，请检查输入」「序列号与本机不匹配（请确认购买页指纹与「本机指纹」一致）」「这条序列号不适用于察元AI OS」「激活功能暂不可用，请联系客服」。
    5. 授权口径：免费体验期 90 天（首运行起，期内完全静默无提醒）；到期未购才出现「每日一次购买页 + 每 3 小时一条温和提醒」。购买完全自愿：不购买不影响任何功能，激活只是让提醒消失（到期自动恢复提醒）。序列号本地离线验签，有效期 = 激活时刻 + 所购天数。
    6. 应用商店里的付费技能包购买是另一条链路（应用内直购、换机可找回），见对应教程。

板块三 · 帮助中心

1. 入口：顶栏「帮助」菜单 ＞ 「察元帮助」（快捷键 ⌘?）；察元菜单（logo 菜单）＞ 「帮助中心」；Dock/启动台/Spotlight 里的「帮助中心」应用（单例窗口，重复打开复用）。
2. 结构：左侧章节树 + 右侧正文（Markdown 渲染），共六节 39 篇：
    1. 入门（5）：帮助中心、察元是什么、安装与首次启动、首次模型设置向导、桌面导览；
    2. 应用（14）：对话（DeepSeek Harness）、智能体、智能体识别与安装、知识库、模型服务、记忆、便签、插件、技能与技能包、应用商店与察元智能广场、灵宠、宠物群聊、察元AI Office、远程访问与共享、其他应用速览；
    3. 模型服务（6）：统一模型设置与模型代理、运行本地模型详解、模型服务架构、引擎二进制、模型文件与任意模型放置、离线下载与导入；
    4. 离线部署（6）：离线环境总纲、Windows/macOS/通用 Linux 离线部署、银河麒麟 Kylin V10、统信 UOS；
    5. 故障排查（5）：模型服务故障、知识库问题、智能体问题、桌面与更新问题、自助诊断与智能体排障；
    6. 参考（3）：目录与文件总表、常见问题 FAQ、多用户与账号找回。
    7. 搜索：标题栏搜索框「搜索帮助文档…（⌘F）」，⌘F/Ctrl+F 随时聚焦；标题命中优先计分、正文命中带摘要片段；侧栏顶部显示「{n} 条结果」或「没有匹配的内容」；按 Enter 或 直接打开第一条；Esc 清空关键词。

    9. 「关注我们」二维码挂件：桌面右下角常驻（与其他桌面挂件同层，应用窗口可以盖住它）——白底二维码 + 「关注我们」标签；左上角 关闭 关闭只对本次会话有效，重启/重载桌面自动回来；锁屏时隐藏。

## 注意事项与真实边界

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 高频疑问

### 右下角「关注我们」挂件能永久关掉吗？

关掉只影响当次会话，重启/重载桌面会自动回来（设计如此，不提供永久隐藏开关）；锁屏期间它不显示。

### 序列号激活报「与本机不匹配」？

序列号与机器指纹绑定。核对手机购买页地址里的 mid 与弹窗「本机指纹」行是否一致（点「复制」比对）；确认后重新获取对应本机的序列号再激活。

### 反馈一定要联网吗？

在线客服需要联网。断网（或 10 秒连不上）会自动出公众号二维码兜底页，微信扫码即可联系；网络恢复后点「重试」回到在线客服。

### 帮助中心的内容会更新吗？

手册随应用打包内置，更新察元OS 后手册随之刷新（内容由开发仓库 docs/help/ 生成）；当前安装版本里查到的就是随该版本发布的手册。

整体用下来，反馈与帮助中心的流程是清楚的：入口集中、步骤有反馈、做完有验证。第一次照着走一遍，后面基本就是肌肉记忆了。卡住就回看常见问题那一节。
