# AI教程攻略：AI 教程库的关键点拆解

AI教程是察元AI 能力广场里使用频率很高的一项能力。它的「AI 教程库」这样工作：2.1 万+ 条全球 AI 学习资源导航：视频/文章/课程/电子书/文档/仓库七类，主题覆盖 LLM/Agent/RAG/Prompt/部署/微调/MCP/技能等，来源含 arxiv、github、B 站等。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

2.1 万+ 条全球 AI 学习资源导航：视频/文章/课程/电子书/文档/仓库七类，主题覆盖 LLM/Agent/RAG/Prompt/部署/微调/MCP/技能等，来源含 arxiv、github、B 站等。

从任务视角看，它对应的关键词是「AI教程」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 /tutorials
2. 按主题（llm/agent/rag/prompt…）筛选
3. 按类型（视频/文章/课程…）收窄
4. 跳转原始链接学习

## 适用场景

- 系统自学 AI
- 查某个主题的资料

## 进阶技巧

- topic×type 组合筛选效率最高

## 注意事项与边界

- 内容为公开网络收录导航
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 网站不存任何二进制文件，安装一律跳转原始地址
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 产品家族与生态位

察元AI 能力广场属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI OS（插件化的 AI 桌面操作系统，本地大模型与智能体工作站）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 下载产品从哪个入口？

产品页（/products）集中提供察元AI OS、察元AI Office、察元AI文档助手等的版本说明与各平台安装包入口。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。
