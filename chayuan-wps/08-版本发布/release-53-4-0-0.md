# 察元文档助手 v4.0.0 更新解读：本机 MCP 文档智能体正式版（26 工具）

v4.0.0（2026-08-10）带来了 3 项主要更新。这篇解读把每项更新「翻译」成使用层面的变化，并给出升级建议。

## 本版主要更新

- 本机 MCP 文档智能体正式版（26 工具）
- 三平台安装包 + sidecar 开机自启
- 离线/内网部署形态成熟

## 值得展开说的一处

以「本机 MCP 文档智能体正式版（26 工具）」为例：它解决的是此前用户反馈集中的场景。升级后建议第一时间验证这个场景——如果它正是你的痛点，这一版就值得升；如果你的工作流不涉及，也可以观望一个补丁版本再升。

## 升级建议

1. 升级前备份用户数据目录（各产品数据目录见官方文档）
2. 从官网 https://aidooo.com 或对应发布渠道获取新版安装包
3. 覆盖安装，完成后验证常用链路
4. 如有问题，用备份目录回滚到旧版

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 如实说说它的不足

- 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型
- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 仅支持 WPS 桌面端（12.x/365），不支持网页版 WPS 与其他办公软件

## 产品家族与生态位

察元AI文档助手属于察元AI 产品家族，家族成员包括：察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF/Markdown/HTML 六编辑器）；察元AI OS（插件化的 AI 桌面操作系统，本地大模型与智能体工作站）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 数据目录在哪里？

Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan，均可在设置中覆盖。

### 能在完全断网的环境用吗？

能。配置 Ollama 或任意 OpenAI 兼容内网网关后全部功能可离线使用；安装包内嵌 sidecar 二进制并注册自启，适配离线与内网部署。

### 支持国产化环境吗？

支持麒麟、UOS 等国产化环境（arm64/x64），真机验证过 Ubuntu arm64 + WPS Office 12.1 组合。
