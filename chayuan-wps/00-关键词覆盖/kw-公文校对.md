# 一文分清公文校对：AI 助手组大按钮拼写与语法检查

公文的错别字和格式毛病，最容易在签发前夜冒出来。这篇以拼写与语法检查为主线，把察元AI文档助手里公文校对的入口、过程与边界连起来讲。

## 什么是公文校对

公文校对不是单一功能，是一套带入口、步骤与边界的完整能力面。WPS 三端智能加载项：校对、编审、核对、脱密，一个文档智能体。

表格与正文的口径都能在官方文档里对上，版本对应关系见文末。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| assistants | 文字端 4526 个领域助手、228 个行业领域；表格端 66 个配方；演示端 81 个；翻译 52 语种动态菜单 |
| 文字端两个选项卡 | 察元AI助理、察元AI编审；表格/演示端各一个察元AI助理选项卡 |
| mcp | 本机 MCP 服务监听 127.0.0.1:62588（路径 /mcp），源码定义 69 个工具、外部实见 53 个，仅监听回环 |
| kb | 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源 |
| proofread | 全文校对分块并发，块长默认 6000 字；超过 12000 字分档提示 |

## 平台与形态

能跑在哪：Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）。

## 在察元AI文档助手里落在哪

公文校对在察元AI文档助手里的落点是拼写与语法检查：AI 助手组大按钮拼写与语法检查：有选中只查选中，无选中弹确认框对全文执行（超 12000 字与 30000 字分档提示）；独立进度窗分块并发（块长默认 6000 字），关窗任务继续；结果批注格式为错别字建议改为某词，锚不到原文不硬挂。

它解决的是两个老问题：长文校对等到超时，结果一堆又不敢直接采纳——分块并发管前者，批注式落点管后者。

## 最短上手路径

校对的完整链路分四步，前三步在后面两节展开，这里先记一个要点：中途可以停——进度窗「停止任务」按钮（或任务清单里对应任务的停止入口），点完状态变「已停止」；停止信号跨窗口生效，即使进度窗关了，也能从任务清单停掉它。

## 使用前划重点的四条

- 免费池子装不下四项涉密能力：脱密、复原、保密检查、涉密关键词提取，需要单独购买

## 数据与安全设计

- MCP 服务只监听 127.0.0.1，写操作不带 confirmed 标记会被拒绝并要求确认
- 每次确认写操作记入 audit.jsonl 审计日志
- 保密检查只做辅助筛查，关键词命中不等于泄密，不构成定密结论
- 脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原

## 校对过程的疑问

### 关闭进度窗后任务还在跑吗？

在跑。副标题写明「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」关窗不影响检查；只有点「停止任务」（或任务清单里的停止）才会中止。

### 报「请先在设置中配置拼写与语法检查模型」？

说明默认对话模型也没配好。到设置里配好对话模型，或在设置里专门指定「拼写与语法检查模型」后重试。

### 检查会直接改动我的正文吗？

不会。检查结果只加批注；要把建议落到正文，用对话链路「校对结果」卡上的「直接改正正文」按钮（按定位逐处安全替换，定位不稳的自动降级为批注），或按批注手动修改。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有加载项文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认加载项已启用。

### 老款 Windows 机器带得动吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

## 一句收束

公文校对的自动化到什么程度合适，看出错成本：一个错字就可能引发歧义的正式文书，机器初筛加人工复核双保险；内部普通文稿，批注过一遍即可。

## 发起检查与范围分流

第 1 步，发起检查：

1. 在哪：顶部工具栏「AI 助手」分组的大按钮「拼写与语法检查」。
2. 看到什么（按选区分流）：
    1. 有选中（不少于 2 个字符）：直接以「选中」模式启动，只检查选中内容；
    2. 无选中：弹确认框「当前未选中文档内容，将对全文执行“拼写与语法检查”。 点击“确定”后开始处理全文。」——全文超过 12000 字时附加「当前内容较长，处理可能需要更久，请耐心等待。」，超过 30000 字时附加「当前内容很长，处理时间可能较久，并可能触发分段或较长响应，请确认后继续。」；点「确定」开始，「取消」不执行；
    3. 文档没有正文：提示「当前文档没有可检查的正文内容」。

## 进度窗逐项说明

第 2 步，读进度窗：

1. 看到什么：独立提示窗，标题「拼写与语法检查」（选区模式为「拼写与语法检查（选中）」），标题旁状态徽章：准备中 / 进行中 / 已完成 / 失败 / 异常结束 / 已停止。
2. 副标题固定一行：「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」
3. 进度区：「正在检查：第 x / y 段」+ 百分比进度条 +「当前检查内容」卡显示正在检查的原文片段。
4. 右上按钮：「停止任务」（仅任务运行中显示）和「关闭」。
5. 完成时显示「已完成，共添加 N 处批注」，随后提示「即将自动关闭」并自动关窗；停止后显示「任务已停止」。
6. 底部提示：「可在「任务清单」中查看详细进度；关闭此提示窗不会停止任务。」

带走一个记忆点就够：选区与全文是两个档位——选中即查选中，不选就整篇；其余细节，后两节步骤里按行可查。
