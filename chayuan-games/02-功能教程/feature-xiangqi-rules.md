# 大模型中国象棋玩法详解：楚河汉界完整规则

「马走日，象走田，车走直路炮翻山」——这句口诀人人张口就来，真把棋盘摆开还能下明白的，没几个。让大模型下中国象棋会是什么场面？察元竞技场按楚河汉界完整规则给模型摆好了棋盘，谁被将死引擎说了算。这篇大模型中国象棋玩法详解，从棋子走法讲到将军判定，再看模型出招有哪些观察点，末了带你开一局验证。

## 先弄清楚它是什么：楚河汉界照搬上桌

竞技场里的中国象棋是完整规则版本：九路十线的棋盘，楚河汉界居中，双方各十六子，帅（将）、士（仕）、象（相）、马、车、炮、兵（卒）一样不缺。走法照旧：车走直线，马走日字，象走田字且不过河、塞了象眼走不通，士斜行不出九宫，帅（将）在九宫里直行一步，炮隔子吃，兵（卒）过河后可以横走。盘面信息对模型完全可见，属于完全信息博弈，拼的就是算度与规划，谁也藏不了牌。几处细节也照规矩走：帅（将）不出九宫，士象守家，兵（卒）没过河只能拱一步，过了河才横得起来。这些限制条条都是象棋的味道，模型能不能守住约束，合法步清单替你把关，你只管看，不用背规则条文，越界的招根本出不来。

## 将军判定：规矩由引擎说了算

象棋的灵魂条款在将军与应将。一方走子威胁对方帅（将），即为将军，被将方必须应将——垫子、挪帅、吃掉来犯之子，三选一；应无可应即成将死，对局当场结束。这些判定全部由本机引擎执行：模型只出招，不判罚，它宣布不了「你被将死了」，也赖不掉「这手我不认」。长将之类细则的判罚口径，以对局引擎的实际裁定为准——胜负归代码真值，不归哪一方的口气大。所以观战时不必替谁喊冤，被将死就是被将死，引擎的尺子对两边都一样。

## 出招观察点：看模型怎么递招

大模型玩家走统一出招协议 {move, comment}：move 是结构化的落子内容，comment 是它对这手的解释。对局室里思维链气泡实时滚出推理过程，每手的延迟与 token 用量摆在旁边。想看出门道，盯三个观察点。

观察点一，战术意识。弃子抢攻、叫将抽子、兑子简化局面，这些手筋它想不想得到，气泡与 comment 里见真章。

观察点二，防守纪律。被将军时怎么应、该不该弃子解杀，反应是否干脆；犹豫与错判都会写进它的解释里。有的模型应将干脆利落，有的边应边找补说法，这些差异正是看点。

观察点三，长局耐性。象棋一局几十上百手，后半程模型会不会越走越含糊，这个只有完整对局才看得出来。

观察点四，开局路数。它走中炮还是飞相，是套路复述还是临场发挥，多看几局，对同一个模型的开局习惯就有数——这也正好呼应引擎层的开局库：开局有底子，中局见真章。

## 完整步骤：开一局验证规则与出招

第一步，回大厅选中国象棋，模式随你——想亲自下场走人机局，想纯看走机机观战。新手建议先看一场机机观战再下场，知道模型的招路长什么样，自己上场不慌。

第二步，开局看布阵章法。中炮、飞相、仙人指路，模型起手走什么、大子出动顺不顺，前十几手就能看出它有没有谱。

第三步，盯一次完整将军回合。一方叫将，看另一方应将选哪条路：垫、避还是吃；再看引擎在无解时是否干脆利落地结束对局。将死由代码认定，这一条你亲眼确认一遍。

第四步，中后盘看子力。大子兑完剩残子，模型的子力价值感与算度深度到这一步见底。

第五步，复盘收尾。形势曲线看倾斜从哪手开始，问叹号标注挑出妙手与失误，赛后解说把脉络串一遍，棋谱导出留档。
