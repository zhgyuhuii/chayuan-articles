# Ollama接入攻略：本地引擎一键安装引导的关键点拆解

Ollama接入是察元AI文档助手里使用频率很高的一项能力。它的「本地引擎一键安装引导」这样工作：自动检测本机环境，引导安装 Ollama 等本地推理引擎：官网与 ModelScope 镜像择优、适配国内网络，装完自动对接。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

自动检测本机环境，引导安装 Ollama 等本地推理引擎：官网与 ModelScope 镜像择优、适配国内网络，装完自动对接。

从任务视角看，它对应的关键词是「Ollama接入」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 设置→本地引擎，点击一键引导
2. 按提示安装 Ollama（或指向已有引擎）
3. 拉取对话模型并设为默认
4. 断网状态下验证可用

## 实用技巧

- 4GB 以上显存或 16GB 内存可跑 7B 级模型，校对够用

## 注意事项与边界

- 仅支持 WPS 桌面端（12.x/365），不支持网页版 WPS 与其他办公软件
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 如实说说它的不足

- 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型
- 本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）
- 免费版每日对话 30 次，重度使用需要付费或自建模型端点

## 常见问题
### 条形码等工具会消耗 AI 次数吗？

不会。工具助手（条形码批量生成、表格/图像/文档批量）不走大模型，确定性执行、无幻觉，也不计入对话额度。

### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。

### 数据目录在哪里？

Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan，均可在设置中覆盖。
