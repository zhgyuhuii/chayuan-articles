# 云端厂商生图可指：图生图模型的坑与对策

很多人搜「怎么设置默认的文生图模型」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把图生图模型从打开哪个应用讲到看到什么结果。

## 先定位问题在哪一层

按这个顺序排查图生图模型通常最快：先确认前置条件（要指定具体模型：先在 设置 ＞ 模型 配好并启用至少一家有图像生成模型的厂商，再核对操作路径，最后看边界限制。

## 正确的操作路径

4. 选定模型并保存（两条路）

保存成功后右上角绿色提示「已保存，系统技能已更新并分发到各智能体」；选了厂商模型时保存动作还会自动把该厂商加入代理路由（真实厂商 Key 不出凭证库）。失败显示红色错误——代理停摆时报「模型代理未运行，无法接入云端厂商（先在模型设置里确认服务状态）」。

1. 路 A（点选 + 底部保存）：直接点树里某个单选行（「自动」/本地/厂商模型），然后点页面底部右侧「保存并更新技能」（进行中显示「保存中…」）；
2. 路 B（弹窗，确定即生效）：点右上蓝色「设置…」弹出对话框，标题「选择默认文生图模型」（或「选择默认图生图模型」），说明「列表 = 本地模型 + 已启用厂商；点「确定」立即生效」。弹窗内是同款单选树（「自动」+ 可折叠的「本地模型」组与各厂商组，厂商组带 logo、组头右侧显示数量药丸与折叠时的选中摘要；打开时自动展开「本地模型」组和包含当前选中项的厂商组，其余折叠，点组头展开/收起）。选中后点「确定」（进行中显示「正在应用…」）立即保存，点「取消」放弃；点弹窗外遮罩也可关闭。
3. 想改回「自动」：点「自动」行（主树或弹窗均可）再按上述任一路保存即可。

5. 保存后谁在用它

1. 生成 models.md：表格里出现「默认文生图模型 | <厂商> · <模型> | <厂商id>/<模型>（经代理路由）」一行（图生图同理；表格列为「分类 | 默认模型 | 调用（模型名）」），随系统技能包分发到各智能体（dsh 用户技能根与各 CLI 智能体技能目录）；
2. 智能体按技能手册经模型代理调用：POST http://127.0.0.1:52581/v1/images/generations（模型名带命名空间，如 agnes-2/agnes-image-2.1-flash），返回 {data:[{url}]}；对 /v1/chat/completions 发图像类模型时代理也会自动换算成 images 调用并把结果包成 !image 文本；
3. 本地命名空间（local/*）在 images 端点会明确 404（「本地暂无图像生成模型，请使用厂商路由」）——所以当前默认图像模型实际只有云端链路。

## 怎么确认做成了

验证

1. 保存后回到本页：「自动」行或树中选中项与你的选择一致；重开页面状态保持。
2. 已选厂商模型时，浏览器或终端访问 http://127.0.0.1:52581/v1/models（免 key）：清单出现 <厂商id>/<图像模型名> 条目。
3. 终端实测出图链路：curl -s http://127.0.0.1:52581/v1/images/generations -H 'content-type: application/json' -d '{"model":"<厂商id>/<模型名>","prompt":"a cat"}' 应返回含图片 URL 的 JSON（需该厂商余额/额度可用）。

## 接着回答几个常见问题

### 保存时报「模型代理未运行，无法接入云端厂商」？

选了厂商模型时保存会自动确保该厂商的代理路由可用，这要求模型代理（52581）在运行。到 设置 ＞ 模型 查看服务健康灯（顶部状态条），服务正常后回来重新保存。

### 模型下拉/树里看不到刚启用的厂商模型？

本页厂商列表与 设置 ＞ 模型 的「已启用」状态同一条判定链：确认厂商卡状态行为「已开启 · 显示在 Harness 模型下拉框」，且「获取模型列表」快照里勾选了「图像生成」组的模型；新勾选后回本页重进即可看到。

## 更多操作细节

3. 「自动」的含义（本地优先逻辑）

「自动」的解析顺序：本地第一个可用模型 ＞ 云端第一个匹配的厂商模型 ＞ 都没有（无可用模型）。解析结果显示在「自动」行右侧灰字里，随本地/厂商配置变化自动更新，不需要手动刷新。

## 更多操作细节

6. 相关：设置 ＞ 模型 ＞ 本地「生图」分类

设置 ＞ 模型，左栏「本地模型」组里选「生图」分类：模型库里有一条「Stable Diffusion 1.5」（带黄色 beta 标），行尾按钮「前往画图应用」——本地 SD 权重的下载与运行都在「文生图」应用里完成，不在模型服务里，也不会出现在第 2 步的「本地模型」组。（注：该按钮的跳转链在代码里以小写应用 id 寻址，与注册名大小写不一致，点击可能无反应——届时直接从 Dock/启动入口打开「文生图」即可。）

## 动手前再核对一遍

- 要指定具体模型：先在 设置 ＞ 模型 配好并启用至少一家有图像生成模型的厂商。列表来源 = 本地已装模型 + 已启用厂商。
- 「自动」不需要任何配置，但没有可用模型时它什么也选不出（显示「无可用模型」）。
- 云端调用经本机模型代理（固定 127.0.0.1:52581）转发；保存选厂商模型时要求代理在运行。

把图生图模型放回察元AI OS的整体盘面：编辑面板改模型、知识库、人设；建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型；厂商、类型、模型三级树选择；不同宠配不同模型是群聊多模型讨论的前提，轻任务宠配小模型、主力宠配旗舰。

## 安全与数据边界

安全口径单独立一层：生图模型不配好，画图应用与智能体的生图指令都落空；文生图图生图分开设，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。
