# 论文提交前清理（察元文档助手速查手册）

语法标点、AI 痕迹、术语口径三项归零。这套组合工作流把拼写与语法检查→AI 痕迹检查→术语统一串成一条线，在察元AI文档助手里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

语法标点、AI 痕迹、术语口径三项归零。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI文档助手的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·拼写与语法检查**：面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文批量审校前的初筛。

1. 在 WPS 中打开待审文档，进入「察元 AI 助理」页签
2. 点击「拼写与语法检查」，选择结构化校对模式
3. 等待模型逐段分析，生成问题清单（每条含原文引用、建议改法、判定理由）

**第 2 步·AI 痕迹检查**：从套话密度、结构模式、元话语等维度对文本做保守的疑似度评估，可定位原文片段辅助人工复核；明示不构成定论，用于起草后自检「AI 味」。

1. 选中正文或全文，发起「AI 痕迹检查」
2. 查看各维度疑似度评分与定位片段
3. 按提示改写高疑似段落（换具体事例、删套话）

**第 3 步·术语统一**：全篇扫描同一概念的不同表述并统一口径（如「甲方/建设单位/业主单位」），产出替换建议清单。

1. 发起术语统一
2. 确认目标术语与待替换变体
3. 批量替换并复核

## 衔接点与易错处

- 同音字（的/地/得、象/像、做/作）与形近字（己/已/巳、戊/戌/戍）是中文高频错误，校对清单会显式覆盖
- 先用结构化校对生成清单人工复核，再用「纠正拼写和语法」整段修正，两步配合效率更高
- 疑似度高不代表一定违规，核心是替换空洞套话为具体信息
- 与「前后矛盾检查」配合使用效果更佳

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 常见问题
### 批注模式和直接替换怎么选？

重要文稿用批注模式留痕审校；快速出净稿用整段修正；批量任务用 MCP dryRun 预览后统一落批注。

### 升级会丢配置吗？

不会。重跑安装器或一行命令 -Fetch 覆盖升级，模型配置、知识库凭据与规则文件保留在独立数据目录。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。
