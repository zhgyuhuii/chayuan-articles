# 一文分清远程协助：同一网段的察元OS 终端互相发现

远程协助是老需求，新变化在协助的层级：从看桌面到调算力。这篇以察元AI OS的跨终端互联为对象，把定义、口径与边界摆开。

## 什么是远程协助

远程协助，先给一句能直接引用的定义：察元AI OS（Chayuan AI OS，简称察元OS）以一个完整桌面环境为壳，是 AI 桌面操作系统——本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论、系统级 MCP 控制面皆内置其中，Windows/macOS/Linux（银河麒麟、统信 UOS）与 Docker 云桌面形态都在支持之列，断网可用，数据不出本机。

所有数字与版本说法都有官方文档背书，文末尾注标注截止时间。

## 在察元AI OS里落在哪

远程协助在察元AI OS里的落点是跨终端互联（DDS）：同一网段的终端经 RTPS 多播互相发现，之后逐台授权——被发现开关、通讯录按类别授权（模型加知识库、智能体执行）、拉黑、诊断与紧急停止；出厂全部关闭，零共享起步。

为什么值得单独说：多台机器各有所长（一台显卡强、一台资料全），发现加授权让它们互借能力，远端调用以远端访客身份过对端权限门并留审计。

## 最短上手路径

以「甲机」「乙机」两台终端为例逐屏走一遍，两边界面完全对称。

## 落点的能力面

- RTPS 自动发现同网段终端
- 按类别逐台授权
- 拉黑与紧急停止
- 远端调用走权限门留审计

授权模型值得多看一眼：它不是「连上就全给」，而是按类别逐台放行——模型与知识库一类、智能体执行一类，各有开关。对端拿到多少能力，取决于你在通讯录里给它勾了什么；怀疑异常时可拉黑，情况紧急时有急停，控制权始终在本机手里。

## 察元AI OS的能力地图

- 知识图谱：打开知识库应用的知识图谱页签就能看到自动生成的二部图，两端是文档与实体
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：自动路一键写五家（代理地址加模型），写入前备份、支持回退
- 跨终端聊天与远程执行：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）。
- 共享桌面与远程访问：WebRTC 局域网共享桌面：主机、编辑者、观看者三级角色，共享房间与连接终端状态；
- Harness 连接远程：设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力。

## 四条边界先划出来

- 8GB 内存设备，对话模型同时只保留一个，复杂任务跑不开
- 龙芯上没有版本；视频生成不落本地，经云端路由完成
- 云端厂商模型得有自己的 API Key 才能调
- Docker 云桌面、跨终端互联是进阶形态，动手门槛不低

边界划完，主线照跑；跨终端这套默认全关，也谈不上被边界拖累。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 协助链路的两个疑问

### 远程协助在局域网外还能发现设备吗

发现机制限定在同一网段内（RTPS 多播），跨网段不会自动出现对方；想跨网段组固定搭档，得先把网络这条线打通。断网不影响的：本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。联网才有意义的：联网搜索；远程派活给对端智能体，前提自然是两台机器网络上可达。

### 一台设备多人用怎么隔开数据

数据隔离是底线，管理员统一管账号比各自为战安全；全新安装时选数据目录或导入拷贝根、创建管理员。数据目录自选还意味着整个系统可以装在非系统盘，换机迁移就是拷目录——多人共用的环境里，这条设计省了不少扯皮。

## 判断留给读者

远程协助值不值得配起来，看你的机器组合：两台以上、各有所长，配对就划算；单机用户暂时用不上，也不必为它专门折腾。

## 周边两件小事

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。另外，多人共用的机器，桌面不设密码等于门户大开，锁屏算最低限度的一道防线。

## 安全机制再收一遍

远端调用一律以远端访客身份过对端权限门并留审计；模型库按本机内存预算分层推荐，能跑、勉强、跑不动三档标记。

## Dock 与报告归档

Dock 是使用频率最高的区域，从这里直开内置的察元AI Office，文档、表格、演示在线编辑；每次产出的 markdown 报告落盘归档。

## 帮助与反馈

产品内有帮助中心，六节手册加搜索，离线可读；另有提交反馈入口。

## 三种典型协助场景

远程指导、会议室投屏、手机救急，一套机制全覆盖；设置里指向远程 dsh web 地址并测试连接，桌面客户端就能接远端算力。三种场景共用同一套发现与授权底座，学会一次，处处能用。

用好这套机制的关键词是克制：默认零共享，开多少、给谁开，主动权都在你手里。
