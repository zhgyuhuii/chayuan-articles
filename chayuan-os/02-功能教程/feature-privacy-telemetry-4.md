# 数据清理排查路径：遥测开关、清除桌面数据

数据清理的麻烦不在功能本身，在于信息散。隐私敏感环境先关遥测再干活，处置设备前清数据。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

按这个顺序排查数据清理通常最快：先确认前置条件（桌面形态（察元AI OS）。网页形态也能打开该分区，但「遥测」卡依赖 dsh host 的 /env 接口，宿主不可达时只显示「宿主不可用」，开关不出现。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 网页形态里「遥测」卡显示「宿主不可用」？

该卡要读写 dsh host 的 /env 接口；宿主不可达时只显示提示文字，开关不渲染。到桌面形态（察元AI OS）里再操作。

## 正确的操作路径

第 1 步 · 打开分区

Dock ＞ 「设置」＞ 左栏点「隐私与存储」。页面从上到下三张卡：「智能体权限门」＞「遥测」＞「清除桌面数据」。

上手按顺序做：（第 4 个切入角度）

1. 遥测一键停用
2. 数据彻底清除
3. 场景验证：涉密环境关遥测
4. 场景验证：退机前清理
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 进阶用法与边界

- 遥测一键停用
- 数据彻底清除

## 常见问题

### 关了遥测，马上生效吗？

不。提示原文是「已保存，重启 dsh web 后生效」——写的是 dsh 的环境文件，需重启察元OS（dsh web 随之重启）后生效。

### 误点了「清除并恢复默认」，能撤销吗？

不能。按钮点击即执行，没有确认框，也没有恢复入口。好在它只清桌面偏好——重新设置主题、重建便签/提醒即可；账号与文件体系不受影响。

### 这个分区里的「智能体权限门」是干什么的？

那是另一张卡：智能体调用系统能力的分级确认（T0 直放/T1 首问/T2 每问），见对应教程 教程，与遥测、清除数据互不影响。

## 放回产品盘面看

把数据清理放回察元AI OS的整体盘面：可选群分区（桌面出图标双击进群），知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，点击互跳定位原文。

## 安全与数据边界

安全口径单独立一层：（本机 MCP HTTP 服务，回环免 token），敏感操作全部写审计日志 audit.jsonl，可回放检查，远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用。

## 平台与形态

平台与形态的账：升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理；（web/Docker 形态网页桌面默认端口）；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 价格与授权

价格口径一并交代：免费下载使用，购买只停提醒、不锁功能；四档价格：149/359/599/1049 元；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）；跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；需要相应平台的 Key（部分有免费额度）。

## 产品家族与搭配

察元AI OS不是单打独斗：数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，遥测开关、清除桌面数据（破坏性操作有警示），隐私敏感环境先关遥测再干活，处置设备前清数据；升级不丢数据是底线，检查更新静默失败不影响使用。

## 几条硬数字

能落到数字上的几条：设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）；生图模型不配好，画图应用与智能体的生图指令都落空；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；两条路：自动一键把代理地址加模型写入五家（备份可回退）；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。

## 离线与内网

离线内网这条线的口径：润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱；自动模式本地优先，local 星号开头的本地模型未运行自动加载；本地模型按需自动加载。

## 能力总账

把察元AI OS的能力总账摊开：文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一，智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明；内置浏览器窗，配合 webwindows 可被智能体驱动；不装第三方浏览器也能完成网页操作，智能体还能代劳。
