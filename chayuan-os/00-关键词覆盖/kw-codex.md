## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### Codex要联网吗

下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换；装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平，断网时联网搜索自然不可用。以官网 aidooo.com 当前页面为准。

### Codex数据存在哪

全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；数据文件不受影响；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把Codex放回察元AI OS的整体盘面：新桌面系统的肌肉记忆速查，五分钟上手，桌面系统的基本尊严：能放歌能放片；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。

## 安全与数据边界

安全口径单独立一层：断网可用、数据不出本机；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全。

## 平台与形态

平台与形态的账：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；每次产出 markdown 报告落盘归档，markdown 报告归档，下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

## 价格与授权

价格口径一并交代：官方免费素材库，不用去网上乱找 png，对配对终端开模型加知识库授权；资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问。

## 产品家族与搭配

察元AI OS不是单打独斗：知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

## 几条硬数字

能落到数字上的几条：显式的加载卸载加自动卸载策略是本地模型的生存之道，自动卸载会释放常驻模型，重度使用记得钉住，润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱；指定模型未加载时会按策略自动拉起。

## 离线与内网

离线内网这条线的口径：无显式模型偏好时自动指向本地模型，断网时联网搜索自然不可用，设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态，建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型。

## 能力总账

把察元AI OS的能力总账摊开：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力），让 B 机器的智能体替你跑任务，结果回传，人不用挪窝；远程派活给对端智能体，换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。

这篇把支持的智能体总览的链路拆完了，照着走一遍就有手感。
