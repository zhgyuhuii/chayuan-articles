# 象棋机机观战：思维链气泡看模型斗法

象棋解说节目里观众问得最多的一句是「这步棋为什么这么走」。看大模型下象棋，这个问题有现成答案：思维链气泡把模型的盘算实时摊出来。象棋机机观战就是一个这样的直播间——两个模型隔河斗法，每一步的心思全程直播，你坐观众席。这篇讲清观战怎么设置、看点在哪、边界是什么。

## 一场全程开着天窗的对局

机机观战选两个或多个模型对打，你旁观。象棋机机观战的观众席体验有三层：棋盘层，楚河汉界完整规则，胜负由引擎判定；思考层，思维链气泡实时滚出两位棋手的盘算，每手的延迟与 token 用量摆在旁边；局势层，形势曲线同步画着谁压谁。默认匿名观战，座位显示玩家A、玩家B，哪家模型执红执白要等终局揭晓——先看棋后对号，判断不被牌子带偏。匿名还有个好处是悬念：不知道对手是谁，你会纯粹按棋风给两位棋手建模，这份观察比先看名字下结论更接近本质。

## 观战前的设置

先在设置 ＞ 模型配置里备好模型：85 家厂商目录点选、填 Key、「测试连接」逐个验通，批量选模型支持一次勾选多个；Ollama 本地模型免 Key，零成本。回大厅选中国象棋、走机机观战入口、点将上桌即可。对阵组合值得花心思：水平接近的两家打悬念，风格迥异的两家打反差，强强对话看细节，强弱对话看收割。批量选模型一次勾选多个，几组对阵排着看，一晚上的节目单就排满了。

## 完整步骤：一场斗法怎么看到底

第一步，开局看布局选择差异。同一个起点，两家模型常走出不同的布阵：有人急架中炮抢攻，有人飞相缓攻，有人走成对峙的屏风马。气泡里能读出它们对局势的理解差异——布局是性格，棋如其「模」。布局差异还能看出模型的开局底子：引擎层的开局库给双方兜底，出了库谁先走出自己的理解，谁就开始拉开差异，气泡里这段分化过程很值得读。

第二步，中盘曲线与气泡齐飞。形势曲线斜率一变就有大事；立刻回到气泡看它当时怎么盘算，把「发生了什么」与「为什么发生」对上号。这套「先看结果再找原因」的读法练熟了，你连自己下棋都会开始复盘。

第三步，攻杀回合放慢速度。弃子、叫将、抽子这些高光手，逐条读气泡，看它算了几层、留了几手后继。

第四步，终局揭晓与复盘。匿名揭开，进回放逐手过，问叹号标注（？！）把妙手失误挑出来，赛后解说串一遍胜负脉络。复盘时重点看两处：弃子那手的气泡写没写后继手段，曲线在弃子之后是塌了还是立住了，两样对上，这局的高光你就算吃透了。

## 弃子攻杀：观战的高光时刻

弃子是象棋里最考验计算的动作：丢一个大子换攻势，算得深是妙手，算浅了就是白送。看模型处理弃子攻杀格外有味道——它为什么肯丢子？气泡里写得直白：弃炮取势、几手之内找回收益，或者干脆判断失误、亏大了。无论结果如何，你看到的都是完整的决策过程：动机、推演、落子、后果，一条龙摊开。这种坦白程度，人类棋手的对局讲解都未必给得了。看弃子攻杀还有个诀窍：先读防守方的气泡，再读进攻方的。进攻方说要弃子，防守方接不接受、怎么接受，两份盘算对在一起，攻杀的成色立刻分出高下——是妙手还是赌博，一目了然。对了，弃子成功不代表全程压制，防守方喘过气反咬一口的剧本也常见，看到一半别下结论。

## 看不懂怎么办

AI 实时解说可以点评每一手，说清攻守意图；赛后整局解说把全盘脉络串成一段话。配合形势曲线与复盘标注，不懂象棋的观众也能跟上节奏。解说也不是万能的，个别局面它讲得笼统，别全盘照收，结合标注自己验一遍更稳。

## 这些边界要心里有数

弱模型的弃子多半是灾难现场，白送大子之后剧情就没悬念了，组局时挑模型很重要。思维链气泡展示的是模型给出的推理文本，能反映盘算路数，但别当成算无遗策的保证——模型不做深度搜索，漏算照旧发生。长挂观战消耗你自己的 API 额度，象棋手数多，云端按量计费要心里有数；Ollama 本地模型零成本，可劲看。还有一条耐心账：思考型模型长考多，直播观战的节奏天然偏慢，把等待当成读棋时间，或者挑轻量型凑快节奏，都是办法。个别时候接口波动会让某一手卡住，有限流退避与代走兜底在，多数会自己续上；实在中断，从记录页进回放接着看。

## 看完怎么算没白看

自测两问：终局揭晓前，你敢不敢押谁赢，说不出理由就是没读懂；复盘时，你能不能在曲线交叉点附近找到弃子攻杀的那一手。两问都过得去，这场观战就把价值吃满了；差一点也没关系，下一场带着问题看，进步看得见。观战本身是被动的，读气泡、盯曲线、猜意图却是主动的，主动的部分越多，收获越大。

## 高频疑问

### 象棋机机观战能同时挂几场

界面同时观战几局以 0.1.0 版本实际表现为准；想批量看多组对阵，锦标赛循环赛自动排程，挂一晚出积分榜，效率高得多。

### 思维链气泡内容可信吗

它是模型输出的推理文本，反映模型的盘算路数；方向可信，细节别迷信，毕竟模型自己也会算错。

### 匿名观战什么时候揭晓

打完才揭晓。观战全程座位只挂玩家A、玩家B 代号，终局由对局引擎公布身份，中途不剧透。

### 观战要花多少钱

软件 MIT 开源免费，消耗的是模型 API 额度，按用量向厂商支付；接 Ollama 本地模型则零成本。

### 能中途上场替某个模型走一手吗

不能，观战席不下场；想亲自对弈，另开人机局，随时都能玩。

### 锦标赛和单场观战怎么选

看单场细节选机机观战，气泡与曲线读得从容；看多组对阵与最终排名选锦标赛，自动排程省心，两者不冲突，轮流来。

看模型下象棋，比拼的其实是我们观众的眼光：气泡看得越细，斗法看得越透。布局差异告诉你模型性格，弃子攻杀告诉你计算深浅，匿名揭晓再给你留个复盘的谜面。下一场挂起来之前，先备好茶——思考型模型每手的延迟，够你喝上几口。
