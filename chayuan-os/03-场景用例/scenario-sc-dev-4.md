# 多智能体开发场景拆解：按项目选趁手的智能体

「察元OS 都支持哪些智能体」——这个问题最近被问了好几次。答案不复杂：多智能体开发在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先看看痛点对不对得上

1. Claude Code、Codex、OpenCode 各装一套、各配一遍模型
2. 本地模型与云端模型来回切换麻烦

一个桌面管全部编码智能体，模型配置只做一次。

## 把流程串起来

1. 系统技能镜像让智能体会操作本机
2. MCP 配置一次、13 家同步
3. 应用商店一键安装 17 家 CLI 智能体

## 支撑功能的操作细节

流程里支持的智能体总览的实际操作：

上手按顺序做：（第 4 个切入角度）

1. 应用商店一键安装 17 家 CLI 智能体
2. 模型设置向导一次配置，五家写入自动完成
3. 系统技能镜像让智能体会操作本机
4. MCP 配置一次、13 家同步
5. 17 家外部 CLI 加内置 Harness
6. 能力矩阵一目了然

## 关键能力点

- 17 家外部 CLI 加内置 Harness
- 能力矩阵一目了然
- 新装约 5 秒自动感知
- 官方品牌图标自动拉取

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

场景提醒：智能体二进制加模型权重占磁盘较大，注意预留空间。

## 常见问题

### 多智能体开发要联网吗

设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；插件、技能、MCP 插件、智能体、技能包五大类。以官网 aidooo.com 当前页面为准。

### 多智能体开发数据存在哪

CLI 智能体经 MCP 自动接入，生图模型不配好，画图应用与智能体的生图指令都落空；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把多智能体开发放回察元AI OS的整体盘面：遥测开关、清除桌面数据（破坏性操作有警示）；它能把应用造出来挂上桌面，桌面本身能被 AI 定义，能力边界从预装走向按需生成；搜索能力不绑定单一平台；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 安全与数据边界

安全口径单独立一层：文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明；内置浏览器窗，配合 webwindows 可被智能体驱动；不装第三方浏览器也能完成网页操作，智能体还能代劳，与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）。

## 平台与形态

平台与形态的账：右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理，用智能体打开文件；便签是智能体最容易帮你落地的载体，说一句放个便签就上桌；文件浏览上传、右键用智能体打开、设为默认打开方式。

## 价格与授权

价格口径一并交代：用智能体打开文件，便签是智能体最容易帮你落地的载体，说一句放个便签就上桌，文件浏览上传、右键用智能体打开、设为默认打开方式；文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一。

## 产品家族与搭配

察元AI OS不是单打独斗：AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，插件、技能、MCP 插件、智能体、技能包五大类；然后一键应用到各家智能体；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。

## 几条硬数字

能落到数字上的几条：配置入口在设置＞默认模型＞网络资源页签，默认内置 web_search 工具多档兜底；设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态；模型配置改乱了、服务起不来，回到出厂态是最干净的自救手段。

## 离线与内网

离线内网这条线的口径：工作区默认打开代理（智能体）加扩展名默认应用覆盖表；让特定文件类型默认交给智能体处理，双击即用 AI，智能体作默认代理，智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；故障转智能体修复。

## 能力总账

把察元AI OS的能力总账摊开：生图模型不配好，画图应用与智能体的生图指令都落空，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平，启停即同步写入支持 MCP 的 13 家智能体。
