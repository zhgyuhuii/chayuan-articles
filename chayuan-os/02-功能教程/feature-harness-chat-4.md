# 流式对话出问题先看这：对话窗口在哪里打开

「对话窗口在哪里打开？可以开几个」——这个问题最近被问了好几次。答案不复杂：流式对话在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

按这个顺序排查流式对话通常最快：先确认前置条件（桌面形态（察元AI OS）：对话窗内嵌本机 dsh 会话服务，随桌面自动启动。web/docker 形态见「形态差异」。），再核对操作路径，最后看边界限制。

## 正确的操作路径

7. 发消息与附件

输入框输入、回车发送，回复流式输出。图片附件只有发给带「图像理解」能力的模型才有效：本地模型须是视觉档（下发时以 image 输入传给引擎）；对话-only 模型收不了图。附件的具体支持类型与大小上限：（会话输入框属 dsh 核心界面，不在察元仓库源内）。

8. 智能路由（主强子弱）

```bash
curl -X POST http://127.0.0.1:52584/api/chatop-models/proxy/routing \
-H "content-type: application/json" \
-d '{"strongModel":"<厂商id>/<模型名>","lightModel":"local/<模型id>","interceptStrong":true}'
```

strongModel 必填（不含则智能路由关闭），lightModel 可空（一律走强模型），interceptStrong 开全量拦截。灵宠对话窗另有「智能路由 · 自动选择模型」直选入口。

1. 含义：模型代理的一个开关能力——把「强模型」设为主力、可选一个「轻模型」兜轻活；请求按难度分类后改写目标：带工具调用、长上下文（>6000 字符）、命中重任务关键词（规划/分析/排障/实现…）＞ 强模型；短输入（≤1200 字符）且是机械性轻活（翻译/润色/总结/改格式…）、或寒暄级短句 ＞ 轻模型；拿不准一律走强模型（质量优先）。已配置时代理模型清单会列出一个虚拟模型名 smart/auto，选它即等于「让代理替我选」。
2. 对 Harness 会话窗的生效方式：会话模型走代理档案（local (proxy)）且代理开了「全智能体拦截」（interceptStrong）时，发给强模型的轻任务会被透明降级到轻模型——会话里零配置，无感知；或在应用模型时把 smart/auto 写进模型清单，在下拉里直接选它。

## 收尾检查

验证

1. 打开对话窗：标题「DeepSeek Harness」；点「＋」出现第二个独立会话窗。
2. 模型下拉三类来源可见：本地已装模型（装机即用对话档开箱即在）、已启用厂商模型、local (proxy) 档（若做过 M9 应用）。
3. 热更新实测：到 设置 ＞ 模型 把某厂商「停用」＞ 回会话窗下拉里该厂商模型即时消失；重新「保存并启用」＞ 即时回来（提示「已开启，模型下拉框即刻可见」）。
4. 选一个未加载的本地模型发消息 ＞ 收到「本地模型未加载：<名称>。请到「模型」应用（或设置 ＞ 本地模型）中加载后再试」；到 设置 ＞ 模型 「启动」该模型后重发即正常回复。

## 高频疑问

### 切换模型后，之前的对话还在吗？

在。切模型只影响之后的消息用哪个模型回答，历史记录保留在同一会话里。

### smart/auto / 智能路由在哪开？

设置界面暂无配置页，用第 8 步的 API 配置（或让智能体代配）；未配置 strongModel 时智能路由整体关闭。配置后最省心的用法是开 interceptStrong：会话照常选强模型，轻活自动降级。

### 改了「Harness 连接」地址，旧窗口怎么还连本机？

该设置只影响新打开的会话窗；已开窗口不动。关掉旧窗重开即连远程。

## 更多操作细节

4. 认识模型下拉（三个来源）

会话内的模型选择器列出三类条目：

1. 本地模型：来自「本地模型」提供方，= 本机已安装的对话/图像理解模型，显示名形如 Qwen3.5-4B Q4_K_M（装机即用对话）；
2. 云端厂商模型：你在 设置 ＞ 模型 里「保存并启用」过的厂商模型，状态行就叫「已开启 · 显示在 Harness 模型下拉框」；
3. 代理档案模型：经「应用到智能体」写入的 local (proxy) 档，模型名形如 local/<模型id>、<厂商id>/<模型名>。

## 更多操作细节

9. （可选）连接远程 Harness

设置 ＞ Harness 连接：「DeepSeek Harness 地址」留空用当前本机 dsh 站点；填入远程 dsh web 地址（如 http://192.168.1.5:52584）＞「测试连接」（在线/无法连接）后，新打开的会话窗将连接该远程站点，已打开的窗口不受影响。

## 动手前再核对一遍

- 桌面形态（察元AI OS）：对话窗内嵌本机 dsh 会话服务，随桌面自动启动。web/docker 形态见「形态差异」。
- 模型下拉要有内容，三选一即可：本地已安装对话/图像理解模型（M3 下载 / M4 导入）、已启用云端厂商（M2「保存并启用」）、或经 M9 写入的代理模型档案。
- 本地模型直接选（chatop-local 直连档）需先加载：到 设置 ＞ 模型 点「启动」；未加载就发消息会明确报错（见常见问题 Q2）。选经代理的 local/<id>（local (proxy) 档）则无需预先加载——首调由代理自动拉起（最长 90 秒）。
