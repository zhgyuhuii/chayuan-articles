# 语音管线：whisper→VAD→piper：察元OS的原理解析

语音管线：whisper→VAD→piper常被用户问到。这篇原理解析从察元AI OS的实际实现出发，讲清楚设计取舍与使用层面的意义。

## 一句话结论

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 对使用者意味着什么

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 相关能力以官网 https://aidooo.com 最新版本为准

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 常见问题
### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 升级会丢数据吗？

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。
