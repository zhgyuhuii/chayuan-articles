# 本地模型和云端模型对弈表现差异观察

断网了还能不能下棋？这是不少人装察元竞技场之前会问的一句话。答案取决于你给桌上安排的是本地模型还是云端模型：本地模型接 Ollama 免 Key 完全离线，云端模型走厂商 API 需联网。本地模型和云端模型在同一张棋牌桌上表现有什么差别，这篇用条件式的方式聊聊，写给在两种接法之间选型的人——不吹不黑，也不编造跑分。

两种接法的关键差异，先上表。

| 维度 | 本地模型 | 云端模型 |
|---|---|---|
| 接入方式 | Ollama/LM Studio/Xinference 免 Key | 85 家厂商目录点选，填自己的 Key |
| 网络需求 | 可完全离线对弈 | 需要联网 |
| 费用 | 无 API 费用，电费与硬件自担 | 按 token 计费，费用自付 |
| 数据流向 | 请求不出本机 | 请求发往厂商，政策以其官方隐私条款为准 |
| 出招延迟 | 取决于本机硬件与模型规格 | 取决于网络与厂商服务状况 |
| 棋力预期 | 小参数模型通常有限 | 大参数模型长对局通常更稳 |

先把前提说清楚：下面关于表现的描述都是条件式的，基于出招机制的一般规律，不是实测榜单。谁强谁弱，你自己拉上桌打几局就知道。

## 出招质量：参数规模决定下限

云端厂商目录里的大参数模型，通常是各家迭代多轮的旗舰，语料覆盖广、指令遵循成熟，出招协议的遵守率一般更稳，长对局里状态起伏相对小。落到察元竞技场里，它们的思维链气泡往往更有内容，推演线写得更像样。想快速判断一款模型顺不顺手，可以先开一局五子棋试水：玩法简单、单局短，协议遵守率好不好几分钟见分晓，再决定要不要拉去复杂玩法。

本地模型看你自己跑什么规格。小参数模型在简单玩法里能正常对弈，但规则复杂的局面容易出错：JSON 格式写崩、合法着法认不全。竞技场对此有一整条解析容错链——剥思维链块、剥代码围栏、抽大括号、截断补尾、正则抽取、全文扫合法动作串——能救回来的会救回来，救不回来走启发式代走，能挡杀就挡、能吃就吃。代走一多，对局虽然不会卡死，观赏性就打折了。

## 延迟与节奏：两种慢法

云端模型每手要过网络，延迟由网络状况和厂商服务决定，碰上限流会触发 429 退避，等一等再重试。本地模型不占网络，但推理速度吃本机硬件——你跑的模型规格超过机器承载，每手的等待时间会明显拉长。两种慢法不一样：一个是等网络，一个是等机器。

顺带一提，对局室里每手延迟和 token 用量都标着，谁快谁慢一目了然，不用猜。观感上还有个差别：云端模型思维链流式滚出来的速度受网络抖动影响，本地模型的流式输出则跟着硬件走，同一款玩法两种节奏，各有各的味道。

## 接入与协议：两种接法的操作面

云端接法走 85 家厂商目录：设置 ＞ 模型配置里点选厂商、填 Key。各家协议不一，竞技场统一按 OpenAI 兼容协议处理，Anthropic 原生协议由本机网关自动转换，Claude 不用改任何东西直接上桌。「测试连接」校验 Key 是否可用，「获取模型」实拉该账号可用模型全列表勾选入库。

本地接法免 Key：Ollama、LM Studio、Xinference 这类本地推理直接填端点就能用，没有账号、没有厂商页面、没有额度概念。两边接好之后，在竞技场里都是同一副面孔——勾选、上桌、出招，谁也看不出对面走的是哪条链路，这正是接入层抽象的价值。

## 费用与隐私：两条账本

费用上，本地模型零 API 成本，挂一晚上锦标赛也不产生账单，硬件与电费自己担；云端模型按 token 计费，费用由你向厂商支付，锦标赛、批量观战这些多模型场景烧额度更快。预算敏感或者要长时间挂机，本地路线省心。顺带说清边界：竞技场本身不计量也不代付费，一切以厂商账单为准。

隐私上，本地模型整条链路可以完全离线，请求不出本机；云端模型的请求会发往你填的厂商，具体怎么处理以其官方隐私条款为准。竞技场这边能保证的是：API Key 明文只存本机，对局数据不出本机，模型流量走本机网关一个口子，随机端口加路径令牌鉴权。

## 混搭也是常见打法

两边不是单选题。锦标赛里本地模型和云端模型可以同场循环赛，11 款玩法随便挑着跑，看看你机器上那个免费选手能顶到什么位置；人机局里你也可以给自己配本地模型当陪练，输赢都不花一分钱额度。机机观战同样支持批量选模型，云端混本地随你排。

## 条件式推荐

在意零成本、断网可用、数据完全不出本机，选本地模型，Ollama 装好就能上桌，规格量力而行。

在意出招质量与长对局稳定性、想要有内容的思维链观赏，选云端模型，85 家厂商目录里点选你手上有 Key 的那家。

两头都要，就混着来：日常观战用本地省额度，重点对局和锦标赛用云端拉质量。

还有第三种玩法：把本地模型设成你的接替者。人机局里自己打一半交给 AI，如果 AI 侧配的是本地模型，整局可以做到零 API 消耗，费用心态也会随之变化——本地当日常陪练随便打，云端留给重点场次，同样的额度能多看好几倍的对局。

## 实话实说：三条边界

本地小模型的棋力和协议遵守率通常有限，代走兜底虽在但体验会打折；云端模型挂机要盯额度，API 费用自付；本机硬件跑不动大规格模型时，本地路线的等待时间会劝退急脾气的人。

## 你可能会问

### 本地模型需要多强的机器

取决于你跑的模型规格，规格越大吃硬件越多。建议从你能流畅跑的规格起步，不够再换更小的模型试。

### 本地模型和云端模型能同场打吗

能。锦标赛循环赛、机机观战、人机局里都可以云端混本地，按模型勾选即可。

### 用本地模型收费吗

不收 API 费。察元竞技场软件 MIT 免费，Ollama 等本地推理零成本，只有云端模型按各家口径计费、由你支付。

### 断网还能玩吗

配本地模型可以完全离线对弈；用云端模型必须联网。

### 云端模型的请求经过竞技场服务器吗

不经过。对局流量从本机网关直接发往你填的厂商地址，察元竞技场本身没有数据上传环节，Key 与对局记录只存本机。

零成本和高质量不是必须二选一。本地模型给你确定性——不花钱、不出网、随时能打；云端模型给你上限——更强的推理与更稳的协议。把两者放进同一场锦标赛，你很快就能摸清这条分界线在哪里。
