## 完整操作步骤

按最短路径验证一遍：

挑一个插件

1. 进插件板块按分类筛选
2. 对比下载量与榜单位置
3. 在 OS 应用商店搜索同名插件一键安装
4. 或按详情页说明手动安装

插件装到哪

1. 察元AI OS 用户走应用商店在线安装，与广场同源
2. 内网机器用 .cop.tgz 离线包导入，断网也能装
3. 装完在 OS 桌面或对应宿主里启用
4. 不想要了在商店里停用或卸载
