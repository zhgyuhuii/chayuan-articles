# 商店 M1 技能包闭环解读（察元OS演进笔记）

商店 M1 技能包闭环解读。版本号背后是产品重心的迁移，这篇笔记沿着时间线梳理这条演进线索，帮你判断「现在上车」处在什么阶段。

## 时间线

- **v项目启动（0.0.x）（2026-08-27）**：chatop desktop + chatop-shell 桌面接管 DeepSeek Harness；66 厂商模型设置
- **v基础能力月（2026-09 上旬）**：知识库/文件系统/媒体播放/共享桌面落地；移动壳规划（Capacitor）；权限门与 ⌥Space/Spotlight 对话入口共识
- **v0.1.5x（2026-09 中旬）**：管理员多用户体系与 ChatOffice 内置；察元智能广场上线、模型统一管理 P0-P4；装机五件套与语音记录 V2 边说边出字
- **v0.1.61-0.1.65（2026-09-18/19）**：引擎二进制入库、Milvus 双选型；产物改名 ChaAIOS-*、安装名「察元AI OS」；KB 问答对话化+对外 REST、多智能体共享记忆、对接官网检查更新
- **v0.1.66（2026-09-21）**：离线购买/授权全链（HMAC 短码）；应用商店 M1 技能包闭环（对接 aidooo.com）
- **v桌面体验整改（2026-09-23/24）**：桌面体验 28 项整改闭环（真机走查+CDP 截图）；商店 M1 真机验收

## 演进主线

从时间线可以看出，察元OS的重心在「能力广度→工程深度→规模化形态」之间稳步推进：早期铺功能，中期补安全与体验，近期重心在部署形态与生态联动。这也意味着现在的版本进入相对成熟区间，适合作为主力工具评估。

## 升级与版本策略建议

- 生产环境跟随稳定版，滞后一两个小版本
- 每次升级阅读更新说明中的行为变化
- 重要节点（大版本）升级前做全量备份

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。

### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。
