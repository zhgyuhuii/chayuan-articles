# 随手记场景拆解：备忘录在哪里

先说这篇能帮你干什么：读完能在察元AI OS里独立完成随手记，路径是会议要点。步骤里的每个「」按钮都是界面原文。

## 为什么值得了解

随手记一段文字（账号、地址、草稿片段），不想开正式文档，灵感本，让智能体帮忙记一条（写入同一数据源，应用里实时可见）；会议要点。

## 操作步骤详解

2. 编辑内容

右侧编辑区自上而下三块：

每条笔记自动保存（停止输入约 0.4 秒后落盘），无需手动保存。

1. 标题输入框：占位「标题」；
2. 正文输入区：占位「开始书写…」，纯文本多行输入（不支持富文本——加粗、插图等格式功能没有，需要富文本请用文档编辑器）；
3. 底部字数：显示「{n} 字」（正文字符数）。

3. 列表与搜索

1. 左栏列表每行显示：笔记标题（空标题显示「无标题」）、更新时间（月/日 时:分）和正文前 18 字预览；点行切换到该笔记；
2. 顶部「搜索…」框输入关键词，按标题+正文即时过滤；没有结果或没有笔记时显示「暂无备忘录」。

4. 删除备忘

选中笔记后点编辑区标题行右侧的垃圾桶按钮（悬停提示「删除」）＞ 该笔记从列表移除，自动切到相邻的一条（没有其他笔记时编辑区显示空态图标）。

## 关键能力点

- 富文本
- 快速检索

## 它的局限也要说清楚

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 高频疑问

### 备忘录支持富文本吗（加粗/列表/贴图）？

不支持。正文是纯文本编辑器；需要格式和插图请用文档编辑（双击 .docx 用察元AI Office 打开），需要贴图片/视频用便签。

### 删除能撤销吗？

不能。删除即时生效且没有回收站，删前确认内容不再需要。

### 能让 AI 帮我记吗？

可以。智能体经 notes_list / notes_get / notes_create / notes_update / notes_delete 工具直接读写备忘录，与应用同一数据源、实时同步——对它说「记一条备忘」即可。

## 更多操作细节

1. 新建备忘

窗口分两栏：左侧列表栏（顶部「新建」按钮 +「搜索…」框，下面是笔记列表）；右侧编辑区（标题 + 正文 + 底部字数）；窗口标题行有红绿灯和侧栏开合按钮，窄窗口时列表栏收进侧栏槽（用开合按钮切换）。

点左栏顶部琥珀色「新建」按钮 ＞ 列表最上方出现一条新笔记（默认标题「新备忘录」），右侧编辑区自动选中它，光标在标题框。

## 更多操作细节

验证

1. 点「新建」＞ 输入标题和几行正文 ＞ 切到别的笔记再切回来，内容还在（自动保存生效）；关闭窗口重开「备忘录」，笔记仍在；
2. 在「搜索…」里输入正文中的关键词 ＞ 列表只剩匹配的笔记；
3. 对智能体说「帮我记一条备忘录：路由器管理密码是 xxx」＞ 备忘录列表实时出现该笔记。

## 补充答疑

### 删除能撤销吗？

不能。删除即时生效且没有回收站，删前确认内容不再需要。

### 备忘录、便签、Office 文档该用哪个？

纯文字速记且要常驻眼前 ＞ 便签（桌面贴纸，可贴图）；纯文字速记但不需常驻 ＞ 备忘录；需要格式（加粗/表格/插图）或正式成文 ＞ 双击 .docx 用察元AI Office 编辑。

## 动手前再核对一遍

- 桌面形态（察元AI OS），Dock 默认固定「备忘录」图标；无需配置。
- 数据保存在本机（os-data/notes），与智能体 notes_* 工具同一数据源。

## 安全与数据边界

安全口径单独立一层：一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全，隐私敏感环境先关遥测再干活，处置设备前清数据，（本机 MCP HTTP 服务，回环免 token）。

## 平台与形态

平台与形态的账：Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness，Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 价格与授权

## 产品家族与搭配

察元AI OS不是单打独斗：购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；比便签正式、比文档轻量，随手记的中庸之选，写材料最需要的就是随手引用内部资料且带出处，不用来回切窗口复制粘贴。

## 几条硬数字

能落到数字上的几条：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）；生图模型不配好，画图应用与智能体的生图指令都落空；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。
