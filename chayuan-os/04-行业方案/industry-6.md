# AI 桌面操作系统：能源电力AI方案路径与边界

## 能源电力为什么需要这套方案

能源电力行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把模型设置向导跑通，验证环境与模型可用
2. 流程层：能源电力日常最高频的文档环节（配置云端厂商模型所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型
- whisper 语音权重同样支持

## 一个行业侧影

出差与远程办公者的典型链路：

1. 提前在机器上配置远程访问
2. 公网走出站云中继（可自建）
3. 手机浏览器镜像桌面操作
4. 生成限时云链接临时分享

手机随时连回自己的 AI 工作站。

提醒：公网访问依赖云通道可用性，高安全环境建议仅局域网使用。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

## 放回产品盘面看

把能源电力AI方案放回察元AI OS的整体盘面：以完整桌面环境为壳；（web/Docker 形态网页桌面默认端口），暂不支持龙芯平台；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 安全与数据边界

安全口径单独立一层：周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）；升级不丢数据是底线，检查更新静默失败不影响使用，账户隔离、数据在服务器侧统一管理。

## 平台与形态

平台与形态的账：四本日历把生活与工作分开记，AI 能读会写，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；让特定文件类型默认交给智能体处理，双击即用 AI；内置插件源开关、自定义社区源与技能源、npm registry 与代理设置。

## 价格与授权

价格口径一并交代：本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；发现加授权让它们互借能力；预授权窗口夜间放行，提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件，购买 OS 授权后，同机察元AI Office 自动免激活。

## 产品家族与搭配

察元AI OS不是单打独斗：让特定文件类型默认交给智能体处理，双击即用 AI；内置插件源开关、自定义社区源与技能源、npm registry 与代理设置；智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用，桌面本身能被 AI 定义，能力边界从预装走向按需生成。

## 几条硬数字

能落到数字上的几条：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案；写入的是代理地址，代理停了智能体就连不上模型，会话中随时切换模型（本地与已启用厂商热更新）。

## 离线与内网

离线内网这条线的口径：做方案对比、头脑风暴、交叉验证都直观；AI 纪要一键生成，AI 面试 3 次失败锁 24 小时，命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。

## 能力总账

把察元AI OS的能力总账摊开：内置插件源开关、自定义社区源与技能源、npm registry 与代理设置，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；编辑面板改模型、知识库、人设，输入框旁有知识库绑定与模型选择（含智能路由自动选模型）。
