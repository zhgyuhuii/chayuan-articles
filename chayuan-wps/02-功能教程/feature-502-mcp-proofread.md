# 多文档错别字校对（MCP）速查手册：从入口到完成的完整流程

批量校对是察元AI文档助手里使用频率很高的一项能力。它的「多文档错别字校对（MCP）」这样工作：通过本机 MCP 服务的 proofread_run 工具对多个文档执行错别字校对：先 dryRun 预览问题清单，确认后用 proofread_apply_comments 把批注钉到具体错字（含表格单元格），支持异步任务轮询。外部智能体（Claude Code、Codex、Cursor）可直接调用。这篇速查手册从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

通过本机 MCP 服务的 proofread_run 工具对多个文档执行错别字校对：先 dryRun 预览问题清单，确认后用 proofread_apply_comments 把批注钉到具体错字（含表格单元格），支持异步任务轮询。外部智能体（Claude Code、Codex、Cursor）可直接调用。

从任务视角看，它对应的关键词是「批量校对」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 在 Claude Code / Cursor / Codex 中连接本机 MCP 服务 http://127.0.0.1:62588/mcp
2. 调用 proofread_run 发起 dryRun，拿到全量问题清单
3. 人工复核清单后调用 proofread_apply_comments 批量落批注
4. 回 WPS 逐条接受批注修改

## 适用场景

- 整目录标书/合同批量错别字体检
- 科室多份材料的统一校对

## 实用技巧

- dryRun 预览→确认→写回是固定铁律，未确认绝不落盘
- 异步任务用 proofread_job_poll 轮询，长文档不阻塞

## 注意事项与边界

- 本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 和察元AI Office 什么关系？

同属察元AI 产品家族：文档助手是 WPS 加载项形态；察元AI Office 是独立的开源 AI 办公套件（文档/表格/演示/PDF）；两者共享校对理念与领域助手体系。

### 免费额度用完会怎样？

对话超过每日 30 次会提示；MCP 调用返回 LICENSE_REQUIRED 错误码，次日恢复或升级付费。

### 支持哪些 WPS 版本？

WPS 文字 12.x 与 WPS 365（WebView2）桌面端；不支持网页版 WPS。
