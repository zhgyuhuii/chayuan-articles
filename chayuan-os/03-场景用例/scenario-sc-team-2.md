# AI 桌面操作系统：团队AI部署完整走法

团队AI部署这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决团队AI部署。

## 一句话说清定位

团队AI部署是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，团队AI部署是其中面向这类需求的一环。

下面直接进正题。

## 操作步骤详解

从这几步开始：（第 2 个切入角度）

1. 服务器 Docker 部署察元AI工舱云桌面
2. 员工浏览器打开即用，账户隔离
3. 共享模型代理与知识库，配置统一
4. 常驻任务统一跑巡检与日报
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 注意事项与真实边界

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 常见问题

### 团队AI部署要联网吗

文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一，设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，让特定文件类型默认交给智能体处理，双击即用 AI；智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用。以官网 aidooo.com 当前页面为准。
