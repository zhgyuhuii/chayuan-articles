# AI选题新手路线：自媒体/内容创作者场景全拆解

如果你是自媒体/内容创作者，下面这些场景大概率不陌生：选题灵感枯竭。内容人的选题弹药库。这篇新手路线以能力广场为工具，把这个岗位的AI选题工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 选题灵感枯竭
- 素材与数据难找
- 热点跟不上

## 用能力广场怎么解：工作流拆解

1. 排行榜追热点项目
2. 资讯板块找选题
3. 活动板块蹲发布节点

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「排行榜追热点项目」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。内容人的选题弹药库。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 常见问题
### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### 怎么订阅模型活动？

活动板块支持 RSS 订阅，聚合 31 家厂商源的促销与发布动态。
