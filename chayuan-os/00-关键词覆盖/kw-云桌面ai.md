## 什么是云桌面AI

云桌面AI不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 云桌面AI要联网吗

设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力，本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。以官网 aidooo.com 当前页面为准。

### 云桌面AI数据存在哪

首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配。以官网 aidooo.com 当前页面为准。

## 更多操作细节

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 更多操作细节

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏
