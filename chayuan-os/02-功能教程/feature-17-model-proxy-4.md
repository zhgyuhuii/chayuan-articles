# 统一模型代理怎么用：察元OS避坑指南

模型网关是察元AI OS里使用频率很高的一项能力。它的「统一模型代理」这样工作：统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。

从任务视角看，它对应的关键词是「模型网关」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 任意 OpenAI 兼容客户端指向本地代理
2. 按需使用对话/嵌入/重排/语音端点
3. 给外部工具签发虚拟 Key

## 适用场景

- 把本地模型共享给全机软件
- 多协议客户端统一接入

## 进阶技巧

- Anthropic 协议双向换算意味着 Claude 客户端也能用本地模型

## 注意事项与边界

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- Docker/云通道等进阶形态需要一定动手能力
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 常见问题
### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。
