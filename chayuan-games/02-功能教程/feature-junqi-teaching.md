# 军棋明棋教学档：新手从这档入门

军棋暗棋劝退新手的方式很直接：开战几回合，你还不知道对面撞过来的是司令还是排长，棋就输了。信息全黑的局没法上手，察元竞技场想得很明白，在军棋里备了一个明棋教学档——桌上棋子全部明置，先在信息透明的环境里把门道看懂，再回暗棋面对迷雾。这篇讲清军棋明棋教学档的定位、它和暗棋的差异，以及新手从这档入门的完整路径。

## 先弄清楚：明棋教学档是什么

一句话概括：把军棋的信息迷雾先撤掉。暗棋里双方棋子背面朝上，你只能看见位置看不见身份；教学档里棋子全部明置，对面的司令在哪、炸弹藏在哪条线上、军旗摆在什么位置，你一目了然，对方也看得见你的全部家当。规则内核与暗棋完全一致：吃子走大小链，炸弹同归于尽，工兵管地雷，司令阵亡亮旗照旧触发，胜负判定归本机引擎，模型只出招不判罚。

它的定位是教学，不是又一个新玩法。档位带来的差异只有一处：信息透明度。棋盘、棋子、走法、吃子判定，全都和暗棋共用同一套引擎。你在教学档里学的每一条规则，回到暗棋原样适用，不存在学了白学的问题——这一点对新手很关键，入门成本没有被浪费。

## 明棋与暗棋差在哪

差异体现在三个层面。头一层是信息：暗棋靠猜，明棋靠算。暗棋里你要拿小子试探、从碰撞结果反推对面身份；明棋里一切摊开，考验变成纯算路——知道对方是什么棋，你该攻哪、防哪、躲哪，全看计算。头二层是策略重心：明棋练的是吃子链的运用与子力交换的划算程度，暗棋练的是信息战——骗手、装大、藏旗，明棋里这些招式统统失效。头三层是心态：明棋输了输得明白，哪一步算漏一眼就能指出来；暗棋输了常常一头雾水，连自己怎么死的都说不上来。对新手而言，先在输得明白的环境里建立规则感，再去忍受暗棋的混沌，这条路顺得多。

教学价值也藏在这三层里。认子：大小关系从司令到工兵，明置的棋子看几局就记熟了。看判定：炸弹怎么换、工兵怎么挖雷、司令阵亡亮旗怎么触发，明棋里全过程看得见。学推理雏形：明棋把算路练透了，回暗棋的猜才有底——猜，从来不是瞎猜。

还要提醒一句：明棋不是简单模式。信息透明只是撤掉了猜的负担，交换计算、攻防次序这些硬功夫一样不少，明棋里输给模型的局照样输得干脆。把它当台阶，别当躺赢的局。

## 上手路径与完整步骤

准备照旧三样：装好察元竞技场，按 2026 年 11 月口径版本为 0.1.0；进设置 ＞ 模型配置，从 85 家厂商目录选厂商、填 Key、点「测试连接」，或者接 Ollama 本地模型，免 Key 零成本；再花两分钟扫一眼棋子大小顺序，不用背，打着打着自然记住。

第一步，进大厅棋类分组，进入军棋暗棋的玩法页，把模式切到明棋教学档，开一局人机局。

第二步，头一两局不求赢，只求看懂。盯住一次完整的吃子判定：大子吃小子、同级相拼两子俱亡、炸弹与任何棋子同归于尽、工兵进雷区把雷挖掉，这些规则事件在明棋里全都摆在你眼前，比背口诀直观十倍。

第三步，换角度再打两局。一局专看模型怎么处理司令——它什么时候敢出击、什么时候往回缩，司令阵亡亮旗的因果线就藏在里面；另一局专看工兵的走位，看它怎么绕开大子去摸雷。思维链气泡会把模型的盘算实时滚出来，它在犹豫什么、盘算什么，你就跟着学什么。

第四步，回暗棋。信息迷雾回来了，先用自由布阵把阵摆扎实，再把明棋里练出的算路一点点迁移过去。头几局输多赢少很正常，军棋暗棋的门槛本来就在信息战上。

## 学到什么算过关

标准很具体：你能不假思索地说出任意两枚棋子相遇谁赢；能讲清司令阵亡亮旗的因果；能指着一场对局说出自己哪一步交换吃了亏。到这一步，暗棋的门槛基本被你踩平了，剩下的进步都在实战里。

一个上手小技巧：教学档打完每局，把形势曲线调出来，对照你印象里的局势走向。你觉得占优的时刻，和曲线的起伏对不对得上？这种对照做几局，局势直觉校准得很快——明棋信息全透明，正是练校准的地方，校准好了再回暗棋，省不少学费。

## 这些边界要心里有数

教学档解决的是信息问题，不替你背大小、不替你算步数，功夫还是得自己下。它和暗棋共用引擎，也就继承了军棋的共同边界：大模型棋力有上限，弱模型会走出让观感打折的招，系统有代走兜底但痕迹明显。费用口径也要清楚：模型 API 的调用费由你向厂商支付，教学档一局手数不算少，多打记得看额度，Ollama 本地推理才零成本。另外提醒一句，明棋的胜负差距通常比暗棋小——信息全透明时算路更容易拉平，别拿明棋战绩去预判暗棋表现，两码事。

## 高频疑问

### 新手从明棋教学档入门要多久

因人而异。规则本身十几分钟能过一遍，大小关系打两三局就能记熟，算路功夫靠对局慢慢磨，不必赶进度。

### 明棋教学档和暗棋是两个玩法吗

不是。同一个军棋引擎，差异只在棋子是否明置，规则、判定、复盘工具全部通用，学会即迁移。

### 教学档能用本地模型当对手吗

能。Ollama 这类本地推理免 Key 直连，断网也能对局；只是小模型棋力有限，出招质量别抱太高期待。

### 军棋明棋教学档收费吗

软件 MIT 协议开源免费，教学档不额外收费；模型调用按用量计费，账单由厂商开给你。

### 教学档打熟了直接打暗棋会吃亏吗

会有一段适应期。暗棋多出信息战这一层，猜旗、骗手都要从头练，但大小关系与吃子判定已经吃透，适应期比裸开短得多。

### 明棋教学档适合老玩家回炉吗

适合。多年没碰军棋的人，用明棋把吃子链和特殊子判定快速捡起来，比直接上暗棋省力，两三局就能找回手感。

明棋教学档是一块垫脚石，垫的不是棋力，是规则感。等你在全透明的棋盘上把吃子链看得滚瓜烂熟，再回到那片信息迷雾里，你会发现迷雾里站着的对手，也不过是在用你学过的那套规则跟你斗心思。
