# 智能体实操指南：能力矩阵一目了然

智能体这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是智能体

智能体，先给一句能直接引用的定义：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

全部口径出自aidooo.com官方文档，版本对应关系见文末。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。

- 系统技能应用到智能体：把察元系统能力手册（含动态生成的模型清单）镜像进六家智能体技能目录（dsh、……
- 桌面右键菜单：桌面空白处右键：新建、上传、更改墙纸、小组件、便签、图标大小与排序、添加快捷……

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

- API Key 用 safeStorage 加密存储，遥测可整体停用

## 你可能会问

### 智能体要联网吗

保存后随系统技能分发到智能体，设置结果分发到智能体侧，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。以官网 aidooo.com 当前页面为准。

### 智能体数据存在哪

CLI 智能体经 MCP 自动接入，生图模型不配好，画图应用与智能体的生图指令都落空；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把智能体放回察元AI OS的整体盘面：桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；桌面右键录制屏幕；桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件。

## 安全与数据边界

安全口径单独立一层：本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）；升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。

## 平台与形态

平台与形态的账：智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；故障转智能体修复，输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；智能筛选（今天、已计划、旗标、已完成）、多列表管理。

## 价格与授权

价格口径一并交代：官方免费素材库，不用去网上乱找 png，对配对终端开模型加知识库授权；资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问；授权按终端逐台给，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。

## 产品家族与搭配

察元AI OS不是单打独斗：设置结果分发到智能体侧；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；还有可复制的各家智能体配置片段；各家智能体配置片段一键复制。

## 几条硬数字

能落到数字上的几条：本地模型解决有无问题，复杂任务还是需要云端旗舰模型；断网时云端模型不可用，可设自动回落本地，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑；GB 内存建议一次只加载一个对话模型。
