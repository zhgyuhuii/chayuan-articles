# 拆开看工作流画布：Cmd 加 K 唤起任务中心

很多人搜「任务中心在哪里打开」，搜到的多是概念解释，落不到操作。这篇以察元AI文档助手为准，把工作流画布从打开哪个应用讲到看到什么结果。

## 这个功能到底解决什么问题

工作流画布能做的事拆开就这几件：节点化编排，可视化画布；调试运行。对应的界面入口是任务中心与编排

下面直接进正题。

## 原理与设计取舍

设计上的动机值得单独说：把固定流程画成工作流，一次编排反复运行。

能力面拆开看：节点化编排；可视化画布，调试运行。

一个常被问到的问题：调试运行和正式运行有什么区别。调试启动同样产生任务记录，但停在节点执行前等你确认，可单步、跳过、临时改输入，用于排查提示词与上下游传值；正式运行一次跑完，去任务清单看结果即可。

从提问口径看，用户最关心的是任务中心在哪里打开？

## 实操全过程

按最短路径验证一遍：

A. 打开任务中心

1. 经命令面板：在挂有命令面板的页面按 ⌘K（Windows 用 Ctrl+K），弹出搜索框（占位「搜索命令、助手或操作…」），输入「任务中心」，点「打开任务中心」命令（「任务」分组），当前窗口即跳转到 #/task-center。
2. 经功能总览：命令面板输入「功能总览」，点「功能总览(看所有路由 / 命令 / 模块)」进入总览页，「路由可达」页签里点「任务中心」卡片。
3. 页面标题「任务中心」，副标题「所有助手 / 工作流 / 拼写 / 进化任务在此统一管理」；右上按钮：「任务编排」（悬停提示「把多助手 / 工作流串成流水线」）、「时间胶囊」、「成就」、「返回」。

C. 任务编排（工作流画布）

1. 进入：任务中心右上点「任务编排」，进入画布页。首次进入显示欢迎卡「欢迎使用任务编排」——「从右侧工作流清单打开已有工作流，或新建一个工作流开始编排」，点「新建工作流」或「打开最近工作流」。
2. 认识三栏：左侧物料库（页签「工具」「助手」+ 搜索框，按分组折叠列出可拖入的节点）；中间画布（顶部工具栏 + Vue Flow 画布，支持缩放 0.3–1.6、小地图、网格背景）；右侧「工作流清单」（搜索框、全选框，及导入/导出/新建/编辑/删除五个按钮）。
3. 摆节点：在左侧物料库按住节点拖到画布上放下；画布工具栏「基础图元」里有「开始」「结束」两个图元（各自只能有一个，已存在时按钮置灰），同样拖入。
4. 连线：从节点右侧的连接点拖到目标节点左侧完成连线；点一条连线可打开「配置分支条件」，把「执行条件」设为「始终执行 / 条件命中时执行 / 条件未命中时执行」——条件分支来自「条件判断」节点时用它控制 true/false 走向。
5. 配节点：双击节点打开配置弹窗——工具节点是「配置工具节点」（名称、说明等）；助手节点是「配置助手节点」（提示词模板与变量 token、输出格式选 JSON 时可填「JSON 结构约束」、输入预览，以及「调试上游」：粘贴上游节点示例输出模拟本节点输入）。上游输出 JSON 时，下游助手可选择只取其中字段。
6. 校验：点画布工具栏「校验」，检查缺开始/结束节点、孤立节点与循环；存在环时报「工作流存在循环：a -> b -> a」之类的问题清单，按提示拆环后再保存/运行。也可点「模拟分析」做路径分析。
7. 保存：点「保存」写入本地（工作流清单持久化在本机，可重复打开编辑）。点「编辑信息」可改工作流名称与说明。
8. 调试启动：点「调试启动」，画布下方弹出「工作流调试」停靠条，显示状态（运行中/已暂停/已结束）与当前节点；提供「单步」「继续」「跳过当前节点」「停止」「收起」。三张卡：「当前步输入」（暂停时可临时改输入，点「应用输入」生效、「恢复原输入」还原）、「当前步输出」、「变量视图」（可复制 JSON）；有上游输出时还有「上游输入快照」。
9. 正式运行与观察：运行产生一条「工作流」类型任务，每个节点对应一条子任务；可在任务清单的工作流任务树里逐节点看状态、输入输出，也能在那里「停止」（未执行的节点会被取消或跳过）。
10. 导入/导出分享：右侧「工作流清单」点「导入工作流」选择文件，确认汇总后导入——工作流里带的自定义助手与现有助手重名时，可选「保留本系统助手」或覆盖/自动重命名；点「导出工作流」可导出当前/勾选/全部工作流为文件，发给同事导入即可复用。

## 几个容易忽略的细节

边界先摆在桌面上：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- AI 痕迹检查给的是疑似线索，疑似不等于定论

## 高频疑问

### 功能区里找不到「任务编排」按钮？

设计如此：文字端功能区的「任务编排」按钮已注释隐藏（标注「功能待完善」），入口只在任务中心页的「任务编排」按钮和命令面板。

### 在主对话窗格里按 ⌘K 没反应？

命令面板挂在非弹窗页面，主对话窗格等弹窗路由内不显示。先按上文入口从「功能总览」等页面进入，或在任务中心页内使用；也可以直接把任一加载项窗口地址的 #/ 后改成 task-center 跳转。

### 点「重试」/「取消」后任务没立刻变化？

这些操作是「发出请求」：页面提示「重试请求已发出」等 toast，实际状态由对应任务执行器响应后更新。对已结束很久的任务，执行器可能不再响应，此时建议重新发起任务。

### 工作流保存后换台电脑还在吗？

工作流清单保存在本机插件存储（键 workflowDefinitions），不随账号漫游。换机请用「导出工作流」导出文件，在新机器上「导入工作流」。
