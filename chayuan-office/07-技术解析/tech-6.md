# MCP工具面设计的设计取舍：个 CLI 工具的分层与写确认

MCP工具面设计的麻烦不在功能本身，在于信息散。让 Claude Code 这类智能体直接读写你的文档，办公自动化从此有了标准协议。这篇把它收拢成一条能照着走的路径。

## MCP Server是个什么东西

为什么要有MCP工具面设计：让 Claude Code 这类智能体直接读写你的文档，办公自动化从此有了标准协议。MCP Server的定位是壳内 MCP 服务（端口 52588）：把文档操作能力开放成 MCP 工具，外部智能体可直接操作文档；CLI 形态 29 个工具（25 核心加 4 deck）。
