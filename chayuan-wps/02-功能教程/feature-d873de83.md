# 一文打通外发材料脱敏线｜文档脱敏

盘点敏感词、脱敏外发、回流复原的可逆闭环。这套组合工作流把涉密关键词提取→文档脱密→脱密复原串成一条线，在察元AI文档助手里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

盘点敏感词、脱敏外发、回流复原的可逆闭环。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI文档助手的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·涉密关键词提取**：从全文抽取待脱密词并输出结构化 JSON，与文档脱密流程配合使用，是脱密前的第一步盘点（付费功能）。

1. 发起「涉密关键词提取」
2. 核对提取结果（可增删）
3. 转入文档脱密执行占位替换

**第 2 步·文档脱密**：把确认的敏感词替换为占位符并建立密码保护的映射关系，实现可逆脱敏：对外发送脱敏版，内部留存映射可一键复原（付费功能）。

1. 先运行涉密关键词提取并确认词表
2. 发起「文档脱密」，设置复原密码
3. 得到脱敏稿外发，映射加密留存

**第 3 步·脱密复原**：凭密码把脱敏稿一键复原为原文，与文档脱密成对使用（付费功能）。

1. 打开脱敏稿
2. 发起「脱密复原」并输入密码
3. 校对复原结果与原文一致性

## 衔接点与易错处

- 提取结果可保存复用，同类模板文件效率更高
- 复原密码务必留存，丢失后无法还原
- 复原后建议再跑一次保密检查确认边界

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan

## 常见问题
### 能处理多长的文档？

长文分块读取（document_chunks）对百万字级文档友好；校对建议分批确认，避免一次任务过大。

### 察元AI文档助手是什么？

一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。

### 条形码等工具会消耗 AI 次数吗？

不会。工具助手（条形码批量生成、表格/图像/文档批量）不走大模型，确定性执行、无幻觉，也不计入对话额度。
