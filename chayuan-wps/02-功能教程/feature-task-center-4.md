# 自动化工作流排查路径：节点化编排

先说这篇能帮你干什么：读完能在察元AI文档助手里独立完成自动化工作流，路径是月报流程编排。步骤里的每个「」按钮都是界面原文。

## 先定位问题在哪一层

按这个顺序排查自动化工作流通常最快：先确认前置条件（加载项已启用并配置好模型；任务编排里的助手节点执行走助手任务链路，工作流节点执行需要对应能力可用。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 功能区里找不到「任务编排」按钮？

设计如此：文字端功能区的「任务编排」按钮已注释隐藏（标注「功能待完善」），入口只在任务中心页的「任务编排」按钮和命令面板。

## 正确的操作路径

B. 管理任务

1. 过滤：顶部过滤栏一排计数页签：「全部」「进行中」「已收藏」「失败」「已完成」「自动触发」（自动触发指进化/定时/系统发起的任务）；右侧搜索框（占位「搜索任务标题、错误、文档路径…」）、排序下拉（「最新优先 / 最旧优先 / 用时降序 / 用时升序 / 按状态」）、类型下拉（「所有类型 / 助手 / 工作流 / 拼写 / 多模态 / 进化」）。任务列表为虚拟滚动，量大也流畅。
2. 看详情：单击任务行，右侧滑出详情卡：左上角星标按钮（「收藏/取消收藏」），输出区有「复制」「复制为 Markdown」；底部按状态出现操作按钮——失败任务「重试」、已完成任务「再次执行」与「重新写回文档」、运行中/排队任务「取消」（点击后提示「重试请求已发出」等 toast，由对应执行器响应）。
3. 批量操作：按住 Shift 或 Ctrl/⌘ 点击多选任务行，底部浮出批量操作条：「收藏」「归档」（提示「已归档 N 条任务」）、「重跑失败」（选中含失败任务时出现）、「关闭 取消运行中」（选中含运行中任务时出现）、「导出 JSON」、「删除」、「取消选择」。
4. 时间胶囊：点「时间胶囊」，弹窗内生成本月回顾 Markdown（生成中显示「生成中…」），点「复制为 Markdown」复制。
5. 成就：点「成就」，弹窗标题为「成就 (已解锁数 / 8)」式计数，列表共 8 项：青铜/银牌/金牌操盘手（累计完成 10/100/1000 次）、助手启航、编排者、校对师、进化派（各类首次）、极速 10 连（一分钟完成 10 次）；未解锁的置灰。
6. 命令面板里还有几条任务快捷命令：「取消所有运行中的任务」「重跑所有失败的任务」「清理已完成的任务」「查看时间胶囊(本月回顾)」「查看成就」。

## 收尾检查

验证

1. 命令面板执行「打开任务中心」后，窗口地址 hash 应为 #/task-center，页面标题「任务中心」。
2. 新建工作流：拖入「开始」＞ 一个助手节点 ＞ 「结束」并连线，点「校验」无问题后「保存」；刷新或重开画布，右侧「工作流清单」里应能再次打开它。
3. 故意把 A 节点连回 B 节点成环，点「校验」，应报「工作流存在循环」类问题。
4. 「调试启动」后，调试停靠条出现且「当前步输入/输出」随单步推进回填；同时任务清单出现该工作流任务及其子任务。

## 你可能会问

### 工作流保存后换台电脑还在吗？

工作流清单保存在本机插件存储（键 workflowDefinitions），不随账号漫游。换机请用「导出工作流」导出文件，在新机器上「导入工作流」。

### 调试运行和正式运行有什么区别？

调试启动同样产生任务记录，但停在节点执行前等你确认，可单步、跳过、临时改输入，用于排查提示词与上下游传值；正式运行一次跑完，去任务清单看结果即可。

- 命令面板（⌘K / Ctrl+K）挂在非弹窗页面上：可在「功能总览」页或任务中心页按快捷键呼出，主对话窗格等弹窗路由内不显示命令面板。
