# AI搜索工具出问题先看这：单一搜索源挂了就变瞎

AI搜索工具这件事，值不值得专门学一篇，看一个细节就够：默认 DeepSeek 搜索。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 先定位问题在哪一层

排AI搜索工具的错，顺序比速度重要：环境与模型先就位，然后对操作路径，最后核边界。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

让智能体联网查资料

1. 确认已配置至少一路搜索源（或依赖默认）
2. 对话里直接说查一下最新的什么
3. 智能体调用 web_search 返回带来源的结果
4. 断网时该工具自动不可用，不阻塞其他能力

五档降级的实际顺序

1. 默认走 DeepSeek 搜索
2. 不可用时依次尝试 serper、tavily、linkup、searxng
3. 都失败再走 duckduckgo 兜底
4. 拿到结果即停，不重复消耗配额

## 进阶用法与边界

- 默认 DeepSeek 搜索
- 五档自动降级
- 结果带回对话

## 接着回答几个常见问题

### 搜索结果会带来源吗？

会。返回结果带链接与摘要，智能体在回答里引用，群聊场景下还可开启联网开关让讨论带上实时资料。

### 能指定只用某个搜索源吗？

可以，在网络资源配置里只留一路启用的源，工具会优先走它，不可用时才按降级链继续。
