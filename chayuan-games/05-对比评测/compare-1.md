# 察元竞技场和Chatbot Arena有什么区别

问「大模型哪家强」，十个人里有八个会甩给你一个排行榜链接，Chatbot Arena 是其中出现频率很高的那个名字。但它排的是聊天问答的口碑，模型的下棋打牌水平在那个榜上根本照不出来。察元竞技场和Chatbot Arena走的是两条路：一个让模型答题聊天等人投票，一个让模型上桌真打一场完整对局。这篇写给正在两类榜单之间犹豫的人，也写给想弄清楚「排位到底在排什么」的人。

先上一张维度表，把两条路摆在一起看。

| 维度 | Chatbot Arena | 察元竞技场 |
|---|---|---|
| 考察对象 | 对话与问答能力 | 棋牌博弈能力 |
| 对局形式 | 匿名模型两两对比，用户投票 | 11 款玩法的完整对局，打到终局 |
| 裁决者 | 投票结果汇总，规则以其官方页面为准 | 本机纯逻辑裁判，模型无判罚权 |
| 排位算法 | 以其官方页面说明为准 | TrueSkill 天梯，人类挑战者独立分榜 |
| 部署方式 | 网页服务，浏览器即用 | Electron 桌面应用，Windows/macOS/Linux 本机安装 |
| 数据位置 | 服务端，政策以其官方页面为准 | 对局记录与 API Key 只存本机 |
| 开源情况 | 以其官方页面为准 | MIT 开源，版本 0.1.0 |

## 考察方式：聊两句投票，和打满一整局

Chatbot Arena 的思路是匿名盲测：两个模型隐去名字回答同一个问题，你看完两段回答，把票投给更好的一方。海量投票聚起来就是一个大众口碑榜，门槛低，打开网页就能参与。至于它现在覆盖哪些任务类别、票数怎么折算成排名，以其官方页面为准。

察元竞技场换了个考法。它不让模型「说」自己厉害，而是让模型把一盘棋、一副牌打到终局：五子棋要算杀，中国象棋要盘算子力，德州扑克要看牌和诈唬，四川血战麻将要防着点炮。一场打下来，模型的规划、容错、稳定性全被过程照出来，不是一句话的好坏能概括的。

## 裁决与计分：人投票，代码判

投票制榜单里，「哪个回答更好」由人判断。同样的题目，不同的人可能投出相反的结果，盲测机制要靠大样本去对冲这种主观波动。

竞技场这边没有主观票。11 款玩法各配一套纯逻辑裁判引擎，不吃外部输入、不做网络请求，只认规则真值；这一手合不合法、谁赢谁输，全部由代码说了算。计分走微软 TrueSkill 算法，胜平负自动更新段位；你自己下场挑战的战绩单独一个榜，不和模型混排。

## 部署与数据：网页服务和桌面应用

盲测平台是网页服务，浏览器打开就能用，对话数据在服务端，使用政策以其官方页面为准。

察元竞技场是装在你电脑上的 Electron 桌面应用。所有模型请求走本机网关，网关用随机端口加路径令牌鉴权，外部进程够不到；API Key 明文只存本机应用目录，永不上传；棋谱、积分、复盘记录也全落在本地。接上 Ollama 之类的本地推理，整条链路可以完全离线。装完即有暗色的竞技场界面，中英双语，不用注册账号，配好模型就进大厅。

如果你想问「模型会不会耍赖」，答案是不会：它连宣布胜利的机会都没有，规则说输就是输，想复盘哪一手出了问题，回放器和棋谱都在。

## 过程可见度：结论与思考的区别

盲测给你的是结论：哪段回答你更喜欢。竞技场给你的是过程：对局室里每个模型出招都带思维链气泡，实时流式滚出来，旁边标着每手延迟和 token 用量；局势走向有形势曲线，复盘时用？！标注点出妙手与失误，配上 AI 实时解说和赛后整局解说；棋谱能导出成 JSON 文件，协议画像还会统计每个模型的出招习惯。看模型怎么想，比只看它说了什么，信息量大得多。

## 人的角色：裁判、考官与观众

两套系统里人的位置也不一样。盲测榜单里人是裁判：你不知道对面是谁，凭观感投票，裁判权分散在千万投票者手里，最终汇成一个公共榜单。

竞技场里人是考官与观众。机机观战时模型匿名上桌，座位只显示玩家A、玩家B，终局才揭晓身份，免得你先入为主；人机局里你亲自下场，人类的战绩单独记入独立分榜，不和模型混排；锦标赛里你是组织者，选一批模型开循环赛，排程自动生成，积分榜实时刷新。人从「投票的手」变成「设计考卷的手」，考察什么、让谁和谁打、打多少局，全由你定。

## 条件式推荐：你在意什么就选什么

在意「聊天答问谁口碑好」，想动动手指就参与评测，盲测类网页榜单对路，零安装成本，参与感直接来自投票。

在意「下棋打牌谁厉害」，想看完整对局里的算路、诈唬与收官，想自己掌控数据和自己配模型，那么察元竞技场和Chatbot Arena就是两个不同的考场，后者把考场搬到了棋盘和牌桌上，装个桌面应用慢慢打。

两者也不冲突。聊天榜看表达，对局看决策，模型的题库分数和牌桌表现对不上号是常事，两边一起看，画像才完整。

## 实话实说：各自的边界

盲测榜单测不到博弈行为，诈唬、防守、收官这些能力在问答里没有舞台，机制细节以其官方页面为准，这类平台也不方便做私密模型的内部评测。

竞技场的边界同样实在：它只聚焦棋牌，11 款玩法测不了写代码写文章；模型 API 费用由你自己向厂商支付，挂机跑锦标赛烧的是你自己的额度；版本 0.1.0 还在早期，功能会继续调整。

## 你可能会问

### 察元竞技场能替代 Chatbot Arena 吗

不能互相替代，两者考察面不同。一个测对话问答，一个测棋牌博弈，按你要考察的能力选考场，都看更全面。

### 察元竞技场要花多少钱

软件本身 MIT 开源免费。用云端模型时，API 费用由你向厂商支付；用 Ollama 等本地模型则零成本。

### 投票榜单和 TrueSkill 天梯哪个更可信

没有更可信一说，两者量的是不同的东西：一个是大众主观偏好，一个是本机对局的客观胜负。想让模型分高下，后者不由人投票，由代码裁判判定。

### 我的对局数据会上传吗

不会。对局记录、天梯积分、API Key 都只存本机，模型流量全部走本机网关，端口随机加路径令牌鉴权。

### 察元竞技场有哪些玩法

11 款（2026 年 11 月，版本 0.1.0）：棋类有五子棋、中国象棋、围棋、军棋暗棋、军棋翻翻棋；扑克有斗地主、德州扑克、掼蛋；麻将有三款，其中日麻立直在大厅的隐藏入口里。

榜单是别人嚼过的结论，对局是你亲眼看到的过程。看腻了截图式跑分，不如把模型们拉上牌桌，看它们一手一手磨——察元竞技场给的就是这样一双眼睛。
