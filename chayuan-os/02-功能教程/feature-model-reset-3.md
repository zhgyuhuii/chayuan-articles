# 模型服务异常自救：用模型服务修复跑通一个真实场景

很多人搜「删掉的内置模型怎么找回」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把模型服务修复从打开哪个应用讲到看到什么结果。

## 先看看痛点对不对得上

五件套权重文件损坏/缺失（自诊断报「已安装模型权重缺失」），想就地修复；换机/重装后想确认出厂模型齐套；模型服务异常自救；交接机器前清理配置。

## 操作步骤详解

5. 看结果提示

完成后页面顶部出现绿色提示「已重播种 N 件出厂模型（用户改动过的文件未覆盖）」：N = 本次实际补拷的件数（都健在时 N=0，属正常）。

6. 理解「用户改动过的文件未覆盖」

播种前对已存在的权重做校验（大小/时间戳快速比对，不一致再算 sha256）：内容与种子一致的只补登记；内容不同的视为用户改动，跳过不覆盖——所以手工替换过的权重不会被出厂版顶掉。

8. （按需）启动使用

恢复的是安装态，不会自动加载。要立即使用：到对应分类的「我的模型」点「启动」；下次重启应用时预热链也会自动把未豁免的装机模型拉起。

## 关键能力点

- 一键回到出厂模型配置
- 数据文件不受影响

## 几个容易忽略的细节

用之前要认的账：

- 恢复后自定义的模型清单需要重新导入
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

## 常见问题

### 点了之后提示「已重播种 0 件出厂模型」？

两种正常情形：五件套本来都在（只需清删除记录+补登记，无需拷贝）；或本安装形态没带模型包（无种子源，见前置条件）——后者去模型库在线下载同款（对话档 qwen3.5-4b 与装机档同量化）。

### 会把我下载/导入的其他模型删掉吗？

不会。恢复出厂只针对出厂五件套做「补拷+清删除记录」，任何删除动作都不做；你的下载模型、导入登记原样保留。

### 我手工替换过某个内置模型的权重，会被覆盖回出厂版吗？

不会。校验出内容与种子不符的文件按「用户改动过」跳过，提示里也写明「用户改动过的文件未覆盖」。想强制回出厂版：先在该模型行内「删除」权重，再点恢复出厂。

## 更多操作细节

1. 进入设置 ＞ 模型

打开 设置，左栏第一项「模型」。

## 更多操作细节

2. 展开左栏「本地模型」组

该组默认展开，列十一类能力分类；组内自上而下还有「模型代理设置」「统一模型设置向导」两个入口。

## 更多操作细节

3. 找到「恢复出厂模型」按钮

「本地模型」组最底部有一个带边框的小按钮「恢复出厂模型」（在「统一模型设置向导」入口下方）。

## 更多操作细节

4. 点击执行

点「恢复出厂模型」——没有二次确认弹窗，点击即执行：系统先拿种子锁，清除「已删除内置模型」记账，再逐件校验并补拷五件套权重到共享模型目录。

## 更多操作细节

7. 理解它不动什么

恢复出厂只加不减不重置：在线下载的模型、离线路径导入的登记、各模型的启动参数与钉住状态、空闲自动卸载策略、厂商配置全部保持原样；已加载的运行实例也不受影响。

## 更多操作细节

9. （多用户机器）全机生效

权重根是全机共享目录（<数据根>/shared/models/chatop-models/），恢复出厂对本机所有用户生效；若另一会话正在播种/迁移（种子锁被占），会报「另一会话正在操作该模型，请稍后再试」，稍等重试即可。

## 更多操作细节

验证

1. 提示文案出现且 N 与预期一致（删过几件补几件）。
2. 「对话」分类页「我的模型」出现 Qwen3.5-4B Q4_K_M 行（带「装机即用」蓝标）；「嵌入」「重排序」「语音识别」「语音合成」分类各回一件。
3. 让智能体跑自诊断（GET http://127.0.0.1:52584/api/chatop-models/diagnose）：权重缺失项清零。

## 补充答疑

### 这和 设置 ＞ 隐私与存储 的「清除桌面数据」是一回事吗？

不是。「清除桌面数据」清的是桌面状态（用户名/密码/分组/主题等）并恢复默认；「恢复出厂模型」只重播种内置模型权重，不碰任何桌面设置。

### 恢复完模型自己跑起来了吗？

没有。恢复的是安装态；到「我的模型」点「启动」立即加载，或等下次重启应用的预热链自动拉起（手动「停用」过的模型在豁免清单里，不会被预热拉起）。

### 报「另一会话正在操作该模型，请稍后再试」？

恢复出厂与首启播种/权重迁移共用一把种子锁，另一会话正在批量写共享权重目录。等对方完成（通常一两分钟）再点一次即可。

## 动手前再核对一遍

- 安装形态带模型包：出厂种子在安装包的 resources/chatop-models/vendor/models/（或外置 models.zip 解压位）。未带模型包的安装形态没有种子源，恢复出厂重播种 0 件——那种形态请走模型库在线补装。
- 无需联网：种子在本机安装目录。
- 「出厂五件套」= 对话 Qwen3.5-4B Q4_K_M、嵌入 BGE-M3、重排 BGE Reranker v2 M3、语音合成 Piper huayan 中文语音（beta）、语音识别 Whisper Small（q8_0）。
