# 加载项安装问题高频问答：这些疑问一次说清

## 加载项安装问题：结论先行

围绕安装，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI文档助手（版本 6.1.2，aidooo.com）整理。文末附预防清单，多数问题的根子都在那三条里。

### 功能区完全没有察元选项卡？

按顺序排查：① 完全退出 WPS 再打开（安装后必须重启）；② 核对 jsaddons 路径下有没有 chayuan_<版本> 等目录；③ 「开发工具 ＞ 加载项」里确认「察元 / chayuan」为已启用；④ 麒麟 / UOS 专业版执行 /opt/apps/cn.wps.wps-office-pro/files/bin/quickstartoffice restart。

### macOS 升级后选项卡消失或仍显示旧版？

容器权限或 WPS 运行中安装导致注册表（authaddin.json / jsplugins.xml）没更新到新版本目录。完全退出 WPS ＞ 重跑安装包 ＞ 再打开；仍不行时在有完全磁盘访问权限的终端执行 bash scripts/repair-mac-jsaddons-container.sh（会同步注册表并清理 jsapi 缓存）。

### Windows 7 / 8 怎么装？

加载项本体可正常装；本机文档服务用的预编译二进制在 Win7/8 无法运行，需先装 Node.js 16.x x64（14.18+ 亦可；Win7 需 SP1），安装器释放的 start-mcp.cmd 会先试二进制、探活失败自动回落 node server.mjs 运行。排查日志在 %LOCALAPPDATA%\chayuan-wps\mcp\runtime\sidecar-start.log。

### 企业批量部署

安全保密组保密检查（文字端大按钮、表格演示端文档安全下拉）：AI 分块研判八大类风险（密级标识、涉军涉装涉训、组织身份、人员联络、时间地点部署、内部编号、经营商业敏感、军工政企高频线索），高中风险分级加待人工复核；命中片段写成链接批注，完整报告进任务清单（含五卡风险概览）。

要点：报告与概览卡；三端都有入口，八大类风险。

边界：辅助筛查不定密，最终以人工保密审查为准

## 再补几个同主题问答

### 「开发工具 ＞ 加载项」列表里出现多个「察元」条目？

多轮升级的残留：macOS 的登记表（authaddin.json）会累积同名条目，官方安装器每次安装都会自动去重并把条目指向当前版本目录——重跑一次最新安装包即可清理。Windows / Linux 的 WPS 按 jsplugins.xml 加载，安装器只更新本产品条目、并清理旧版本目录；若旧条目指向已删除的目录会导致加载失败或回退旧缓存，同样用重装修复。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找到官方入口，不从二三手教程猜路径
- 模型、权限、依赖这些前置条件先检查一遍再动手
- 边界条款（大小上限、付费范围、平台差异）提前读一遍

遇到与本文口径不一致的情况，以aidooo.com最新文档为准。

## 关于察元AI文档助手

察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。同家族产品：察元AI OS（AI 桌面操作系统）、察元AI Office（开源 AI 办公套件）、察元AI 能力广场（aidooo.com）。官网 aidooo.com。

## 边界速览

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- macOS 安装器没有完全磁盘访问权限时会出现假成功，需要跑修复脚本

## 数字口径

- 文字端 4526 个领域助手、228 个行业领域；表格端 66 个配方；演示端 81 个；翻译 52 语种动态菜单
- 文字端两个选项卡：察元AI助理、察元AI编审；表格/演示端各一个察元AI助理选项卡
- 本机 MCP 服务 http://127.0.0.1:62588/mcp，源码定义 69 个工具、外部实见 53 个，仅监听回环
- 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源

## 校对的执行机制

有选中只查选中，无选中确认后查全文（超 12000 字与 30000 字分档提示）；检查在独立进度窗里分块并发执行，块长默认 6000 字，关窗任务继续，只有点停止任务才中止；结果批注锚定原文，锚不上的不硬挂。

## MCP 写确认纪律

本机 62588 端口的文档智能体服务只监听回环；写操作不带确认标记会被拒绝并要求确认，每次确认写记入审计日志。外部智能体（Claude Code、Codex、Cursor 等）一行配置即可接入，代操作文档但不越权。

## 表格与演示的直达按钮

表格端九大按钮（AI 表格助手、公式助手、数据洞察、一键图表、数据清洗、报表结论、一键美化等）配 66 个配方；演示端从生成 PPT 到口播稿、整套校对、结构诊断齐备，配 81 个配方，课件与习题页生成也在菜单里。

## 额度与付费边界

免费每日额度（对话与助手独立额度池，次日重置）；文档脱密、脱密复原、保密检查、涉密关键词提取四项为付费专属、零免费额度；序列号本地验签激活、绑定设备指纹，离线可用。

## 配图三级降级

第一级模型生图（最多试三个模型），失败走第二级网络搜图（Serper、Tavily、Pexels、SearXNG 免 Key），再不行第三级 SVG 矢量兜底；铁律是上级失败才降级，绝不静默换花钱的来源。

## 脱密的可逆设计

AI 提取涉密关键词加本地 9 类正则兜底（手机号、身份证、邮箱、编号、银行卡、IP、车牌、统一社会信用代码等），确认后替换为 8 位随机占位符；恢复载荷 AES-GCM-256 加密随文件走，凭密码可完整还原，忘记密码没有任何免密通道。
