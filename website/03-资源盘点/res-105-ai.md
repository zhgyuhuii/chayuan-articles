# 能力广场专题｜资讯怎么找与怎么筛

资讯怎么找与怎么筛。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：资讯板块（AI资讯）等板块按统一字段维护，搜索与筛选组合使用。

1. 先看 health 状态，优先 active 条目

## 避坑提示

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 政企可私有化部署（Docker），数据自主可控
