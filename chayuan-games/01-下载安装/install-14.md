# 察元竞技场安装失败怎么办：装不上打不开逐因排查

症状先摆出来：安装包下完了双击没反应；向导跑到一半报错退出；dmg 打开提示应用已损坏；装完了点图标闪退。遇到察元竞技场安装失败，先别急着卸载重装乱试一气——安装期的问题九成落在三个原因上：下载不完整、架构选错、安全拦截。结论先行，逐因排查，每个原因都给你可操作的核对步骤。

## 症状与原因的快速对照

把开头那串症状归到原因上，一张表对号入座：

| 症状 | 优先怀疑 |
|---|---|
| 双击 exe 无反应或向导中途报错 | 下载不完整，其次安全拦截 |
| dmg 打开提示应用已损坏 | 下载不完整 |
| 提示无法验证开发者，问是否打开 | 安全拦截（常规防护） |
| 装完点开闪退或打不开 | 架构选错，其次系统版本 |
| 向导提示磁盘或权限错误 | 空间与权限问题 |

对照表只是排查起点，不是诊断结论，往下逐因走步骤。

## 原因一：下载不完整（最常见的坑）

先查这个，因为它出现频率高且核对成本最低。网络中断、代理抽风、浏览器假死都可能让安装包只下了一半，残缺包在 Windows 上表现为向导启动失败或中途报错，在 macOS 上表现为 dmg 打开报应用已损坏。

核对方法：回到下载页面看官方给出的安装包体积，与你本地文件的体积对比，明显偏小就是残缺。没有体积参照时，直接重新下载一次对比——两次下载体积不一致，说明网络不稳，换一个稳定网络环境再下。处理动作只有一条：删掉残缺文件，从官网 aidooo.com 或开源仓库 github.com/zhgyuhuii/chayuan-games 的 Releases 页面重新下载。不要在残缺包上尝试修复，安装包没有修复的价值。

下载不完整还有一个信号：进度条几秒钟瞬间跑完。正常下载要么匀速要么分段推进，瞬间完成的下载基本可以判定有问题，直接重下，不必抱侥幸。

## 原因二：架构选错（安静失败型）

症状很有辨识度：包看起来正常，安装却装不上或者装上也打不开。多发生在 Mac 与 ARM 设备上——arm64 的包装到了 Intel 机器，或者 x64 的包给了 Apple 芯片。

核对方法：Windows 到系统设置里看系统类型，基于 x64 的处理器选 x64 包，ARM 设备选 arm64 包；macOS 在「关于本机」看芯片，Apple M 系列选 arm64，Intel 处理器选 x64；Linux 终端敲 uname -m，x86_64 对 x64，aarch64 对 arm64。核对完换对应的包重装，换包前把旧的残缺文件删干净，免得回头又拿错。架构选错的代价只是重下一次，不会损坏系统，所以它排在下载完整性之后、安全拦截之前。

## 原因三：安全拦截（提示吓人型）

症状是系统出面拦你：Windows 上双击 exe 弹出安全提示，询问是否运行；杀毒软件把安装包隔离；macOS 上头一回打开提示无法验证开发者。

处理思路分两步。第一步核对来源：这个包是不是从上面两个官方渠道下载的？来源核实了，拦截提示就是常规防护，放行即可——Windows 上按提示选择继续运行，被杀软隔离的先在杀软里恢复并加白名单；macOS 上在应用程序文件夹按住 Control 键点按应用选打开，或按系统提示到设置里允许。第二步，来源核实不了就停手：不要为了绕过拦截去不明站点换个包，那是把小问题换成大问题。

放行的前提再强调一遍：来源可信。官渠道的包被拦属于常规防护，来路不明的包被拦属于防护尽职，两种情况的正确处理完全不同，别混为一谈。

macOS 的「已损坏」提示在原因一里说过，它是下载不完整的典型表现，重新下载即可，不需要动系统安全设置。

## 还有几种少见情况

磁盘空间不足：安装需要足够的剩余空间，模型数据与对局记录还会持续增长，先清出余量再装。系统版本过旧：Electron 应用对系统版本有下限要求，老系统的表现是装完启动无反应，把系统更新到位再试。安装目录权限异常：公司管理的电脑可能限制写入程序目录，换一个你有权限的安装位置。这些情况出现频率低于前面三个原因，排除完三大原因再回头看它们。

## 预防清单：四件事装前做完

照这张清单走，安装失败的概率会小很多：从官方渠道下载，官网 aidooo.com 或仓库 Releases 页面二选一；下载完成核对文件体积再安装；选包前先查自己的系统架构；Windows 首启留意安全提示、macOS 首启备好来源核对结果；把下载来源与版本号记一笔，后续提问、反馈、复盘安装问题时，这些信息都是别人帮你的前提。五件事加起来不到五分钟，比事后排查省一小时。

## 提问前的自查

排查到还没解决，去开源仓库提 issue 之前，把这几样信息备齐：操作系统与版本、CPU 架构、下载渠道、安装包体积、卡在哪一步、报错原文。信息齐的 issue 才有人接得住，空泛的「装不上」三个字谁也帮不了你。版本 0.1.0 还在早期，安装器相关问题也可能随版本更新被修掉，提问前先看看有没有更新版本。

## 你可能会问

### 双击安装包完全没反应怎么办

按顺序查三样：文件体积是否正常（残缺包常无响应）、架构是否选对、安全软件是否静默拦截。三样都排除仍无响应，换一个用户账户或重启后再试一次，仍失败就带着信息去仓库提 issue。

### macOS 提示应用已损坏是中毒了吗

基本不是，这个提示在 macOS 上多与下载不完整相关，镜像没下全导致校验不过。删掉重下，绝大多数情况一次解决，不需要关任何安全机制。

### 杀毒软件报风险是不是包有毒

先核对下载来源是否官方渠道。开源软件的安装包来源可查，官方渠道拿到的包与仓库发版对应；个别杀软对没广泛分发的安装包会有通用提醒，核实来源后自行决定放行与否，判断权在你。

### 重装会丢对局数据吗

安装期失败时对局数据多半还没生成；已正常使用过的电脑重装，对局记录存在应用数据目录里，常规重装不覆盖数据，稳妥起见可以先备份应用数据目录。

### 排查完还是装不上找谁

到开源仓库 github.com/zhgyuhuii/chayuan-games 提 issue，附上系统版本、CPU 架构、下载渠道、安装包体积与报错原文。信息全的问题才有人接得住，空泛的「装不上」三个字谁也帮不了你。

安装期的麻烦说到底是三件事：包是完整的、架构是对应的、来源是可信的。把这三关过了，察元竞技场装好只是时间问题；装好之后配模型开局的路，本系列前面每一篇都铺好了。祝你首局顺利，打出好看的对局。
