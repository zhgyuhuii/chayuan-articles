# 察元OSFAQ：授权与购买 8 问

把授权与购买 8 问相关的高频问题集中回答，一篇看完，省得一个个搜。每个回答都给到可操作的结论。

## 快问快答

**1. 知识库支持什么格式？**

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。

**2. 数据存在哪里？怎么备份？**

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。

**3. 技能和插件有什么区别？**

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

**4. AppImage 双击没反应？**

多为缺 FUSE 2：安装 libfuse2（Ubuntu 24.04 为 libfuse2t64），或使用 --appimage-extract-and-run 解压运行；UOS 环境推荐直接用 deb。

**5. Docker 部署端口冲突？**

默认网页桌面端口 52584，被占用时修改 compose 映射端口；系统各服务端口有统一注册表，改前先查占用。

**6. 察元AI OS 是什么？**

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

## 一条通用排查思路

绝大多数问题出在三层：环境层（安装与版本）、配置层（模型端点与密钥）、用法层（入口与步骤）。先分层再定位，比盲目重装效率高得多。

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- Docker/云通道等进阶形态需要一定动手能力

## 常见问题
### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 智能体（CLI）无法启动？

在应用管理→智能体页检查安装状态并重装；四家 CLI 二进制随安装包分发（约 1.3GB），磁盘空间不足会导致启动失败。

### 其他软件能用本机模型吗？

能。统一模型代理提供 OpenAI 兼容与 Anthropic 协议接口（对话/嵌入/重排/语音），任何支持的客户端指向本地代理即可。
