# MCP 服务与同步进阶技巧：从入口到完成的完整流程

MCP服务器是察元AI OS里使用频率很高的一项能力。它的「MCP 服务与同步」这样工作：系统级 MCP server（stdio `chatop mcp` + 本机 HTTP 52583，回环免 token）；MCP 配置自动传播注入六家智能体（claude-code/opencode/codex/zcode/openclaw/dsh）；设置里有 MCP 分区管理与清单离线导入导出。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

系统级 MCP server（stdio `chatop mcp` + 本机 HTTP 52583，回环免 token）；MCP 配置自动传播注入六家智能体（claude-code/opencode/codex/zcode/openclaw/dsh）；设置里有 MCP 分区管理与清单离线导入导出。

从任务视角看，它对应的关键词是「MCP服务器」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 设置→MCP 添加或导入服务清单
2. 系统自动同步到六家智能体
3. 在任意智能体中使用 MCP 工具

## 实用技巧

- mcp.json 合并导入适合批量配置

## 注意事项与边界

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 常见问题
### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。
