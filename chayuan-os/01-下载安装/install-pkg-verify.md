# 安装包校验安装指南：全平台步骤与验证

直接上干货。安装包校验在察元AI OS里的定位一句话能说清：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。具体怎么操作、有什么讲究，往下看。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：逐文件校验的习惯。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。安装包从官网 aidooo.com 获取。

## 一步步来：从入口到完成

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥，这两件事做完，这台机器就算真正就绪。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 别在这几处栽跟头

边界都在这：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 你可能会问

### 升级会丢数据吗？

不会。覆盖安装与自动更新都保留数据目录；升级前把数据根目录整体备份一份更稳妥。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

## 安装与运行答疑

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

## 一个真实场景

学生与科研人员的典型用法：本地模型零边际成本对话，知识库导入课件论文做引用式问答，知识图谱梳理论文实体关系。零 API 成本的学习与科研工作站。注意：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 顺带了解

检索测试台与引用式问答：右栏检索测试台就是 kb_search 工具的所见即所得：向量加全文加可选重排的混合检索；问答流式输出带编号脚注，点开看出处片段，可跳回原文核对，会话内还能临时换对话模型。

为什么值得看：带出处的回答才敢用：答案来自哪份文件哪一段，脚注点开一目了然。

## 还有这个能力

群内附件与纪要：群聊支持附件自动抽取正文注入、知识库三级优先（消息级大于宠物绑定大于群默认）、讨论中生成的图片视频语音直接在群里放出可另存、一键 AI 纪要、群管理（改名、成员、重跑、清空、解散）。

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 边界速览

- 云端厂商模型调用需自备 API Key

- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness

- 127.0.0.1:52581（OpenAI 兼容统一模型代理）

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 云桌面形态

整套系统可无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离，数据在服务器侧统一管理。默认只监听回环端口，暴露面完全自己控制，适合团队统一供给算力与知识库。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。
