# 85家模型厂商随便挑着上桌

首图建议：设置页厂商列表拉到底的长截图，配一句「选模型像逛货架」。

接模型的痛，接过的人都懂：翻文档、找端点、猜参数名，一套流程走完，打牌的兴致已经没了半条。

在察元竞技场里，这件事被压缩成了点选。85家模型厂商内置在目录里，DeepSeek、智谱 GLM、通义千问 Qwen、Moonshot Kimi、百度文心、讯飞星火、阶跃星辰、MiniMax、零一万物、豆包，再到 OpenAI、Anthropic Claude、Google Gemini、xAI Grok、Mistral、Cohere，设置页点选即填。

这篇讲讲这个目录怎么用才顺手，以及哪些期待要提前校准。

## 目录广度的实际意义

广度不是拿来炫耀的，是拿来换阵的。

棋牌对局有个特点：模型之间的差异会从「答得快不快」变成「这手走得聪不聪明」。同一个模型在不同玩法里可能是两副面孔，推演型玩法和读牌型玩法考察的压根不是同一块能力。

目录够宽，你才能按玩法换人：围棋上思考型模型，斗地主上反应快的模型，军棋暗棋换个胆子大的。85 家的纵深足够排兵布阵，不必在一棵树上纠结。

差点忘了交代重点：挑厂商只是填配置的快捷方式，Key 还得去各家官网自己申请，费用由你向厂商支付，软件本身 MIT 开源免费，这笔账要分开算。

## 获取模型，一键拉取

目录点选之后是填 Key，然后有两个按钮容易混。

「测试连接」：发 GET 请求校验 Key 好不好使，失败会静默退回手填模型列表，不报错也不打断你。

「获取模型」：用 POST 请求实拉这个账号当前可用的模型全列表，注意它读的是你还没保存的输入，严格实拉不回退。拉回来的是裸模型 id，勾选入库就能上桌。

推荐顺序：先测试连接确认身份，再获取模型拉清单。拉不出来多半是 Key 权限不够或网络问题，别急着怪软件。

目录之外的口子也留着：任何 OpenAI 兼容端点都能手填 baseUrl 接入，OneAPI、NewAPI 这类中转同样可接。Anthropic 原生协议由本机网关自动转换，Claude 不用改代码直接上桌。Ollama、LM Studio、Xinference 本地推理免 Key，预算紧就走这条路。

## 三个点，两好一坑

1. 好在点选即填。85 家目录把端点和参数替你备好，你要做的只有贴 Key、选模型，几分钟的事。

2. 好在口子够宽。内置目录之外，OpenAI 兼容端点、中转站、本地推理三条路都通，几乎不存在「这个模型接不进来」的情况，除非它压根没有 API。

3. 坑在期望管理。目录宽不等于每一家都被逐一验证过棋力，个别小众厂商的端点行为可能有差异，遇到问题先自查网络与 Key，再去仓库提 issue。

## 换阵实战的小思路

手头 Key 多的话，可以给自己定个轮换规矩：一周主打一家，月底让它们在锦标赛里碰一次，多模型循环赛自动排程，积分榜实时刷新，打完出冠军，谁强谁弱一目了然。

平时想快速摸底，就开匿名观战批量选模型，座位只亮玩家A/B/C/D，身份压到终局揭晓，猜错的那回印象往往特别深。

天梯挑战也别错过：按 TrueSkill 段位约战，赢者升段，人类挑战者的战绩独立统计，不与模型混榜。你自己的牌技也能在里面练出来。

## 三个新手常见弯路

弯路一：填完 Key 不点测试连接，直接开局，结果模型一路乱走全靠代走兜底。先测后打，两分钟省一小时。

弯路二：获取模型之后把列表全勾上。列表里可能躺着实验型号、过期型号，全勾的结局是锦标赛跑一半某个模型开始反复退避。按需勾选，常打的留，其余删。

弯路三：中转站用户把厂商原生 Key 填进中转配置栏，或者反过来。两套 Key 对应两套端点，混着填的表现千奇百怪，先核对归属再排查别的。

## 费用与节奏的搭配

85 家目录带来一个幸福的烦恼：可打的模型太多，额度不够分。给个搭配思路。

日常摸底用便宜的快模型，跑量攒画像；周末用贵一点的思考型模型打几场正经局，细看思维链气泡里的分析质量。Ollama 本地模型零成本，适合当陪练和试验田，怎么折腾都不心疼。

锦标赛是集中消耗额度的场景，开赛之前估一估参赛模型数量和循环局数，量入为出。积分榜实时刷新带来的爽感很上头，但账单是清醒的。

还有一个隐性好处：目录里躺着的不只是大厂。不少垂类厂商、新锐团队都在列，冷门模型在聊天榜上没声音，在棋盘上未必没看点，偶尔会给出让人愣一下的招法，这种惊喜是多模型玩家的日常零嘴。

## 也要说实话

- 模型 API 费用自付，厂商目录只是配置入口，不附带任何额度，预算自己把着。
- 中转站的稳定性看中转本身，软件只负责把请求发出去，超时与限流的锅别扣在棋盘上。
- 云端模型出招要等 API 返回，思考型模型一手能等挺久，急性子记得搭配节奏快的模型混着开。

适合谁：手里攒了一堆 Key、想让它们真正同台较量的多模型玩家。不适合谁：只打算用一家模型打到底的人，目录广度对你的意义有限。

## 评论区高频问题

### 85家模型厂商都要付费吗？

不用全买。用哪家填哪家的 Key，Ollama 本地模型零成本，云端按各家计费。目录是菜单，点菜才付钱。

### 获取模型拉出来的名字看不懂怎么办？

拉回来的是裸模型 id，挑常用的勾选入库即可。拿不准的先低成本试两手，匿名观战开局看表现再决定留不留。

### DeepSeek 和 GLM 能同桌打吗？

能。机机观战支持批量选模型，匿名座位配终局揭晓，多模型混战正是这个大厅的主场玩法。想固定阵容，勾选入库后开局直接点名，不用重复填配置。
