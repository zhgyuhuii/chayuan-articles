# Win7安装装机指南：三平台安装包

老机器上装察元AI文档助手，卡点通常不在加载项本身，而在本机文档服务：Win7/Win8 跑不了预编译的 MCP 二进制，得靠 Node 16 回落这条路。这篇把 Win7安装从头到尾拆开：装加载项、补 Node 环境、验证服务、认清边界，每一步都给出对应的判断依据。

## 老机器装机前的盘点

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：老系统 Node 16 回落。

安装包认官方渠道这一条来源；镜像站的包来路说不清，老机器上更不要省这一步。Win7 这类机器的问题从来不是装不上，而是装上之后服务起不来——加载项和本机服务是两层东西：选项卡、按钮这些看得见的功能归加载项层，落在 jsaddons 目录；真正干活的本机文档服务归服务层，装的时候顺带完成自注册，还配了看门狗。这篇要处理的核心是第二层。盘点时把几样一次看清：WPS 装没装、安装包对不对、Node 环境有没有着落，齐了再动手，中途折返的概率小得多。

## 四步装上加载项

1. 从官方渠道下载 exe
2. 双击安装，加载项落进 WPS jsaddons 目录，本机服务同时完成自注册并带上看门狗
3. 把 WPS 完全退出后重启
4. 文字端出现那两个选项卡——察元AI助理与察元AI编审，即算成功

单看这四步，Win7 与其他 Windows 机器没有区别：exe 是自解压的，双击等它跑完即可，无需点下一步。差别要到服务真正启动那一刻才显现出来。

## 装完先拿旧文档试批注

装完先开一篇旧文档跑一次校对，批注出得来就说明模型链路是通的；再到察元AI编审选项卡里确认规则管理加载正常，两端都在，加载项才算装实。选旧文档是有讲究的：它没有未保存的新内容，批注结果不受干扰；校对跑通后，再随手点开一个常用功能确认行为正常。

## 两个选项卡就是判据

- 重启 WPS 后文字端出现察元AI助理与察元AI编审两个选项卡
- 没生效的话，先把宿主软件完全退掉再重开一次

两个选项卡同时现身，说明加载项这一层已经落好；它们迟迟不来，多半是宿主没退干净，先彻底退出再启动一次，别急着重装。

## 这条线上的边界

用之前要认的账：

- 脱密占位替换设计成可逆，但免密恢复通道一并被收走，密码忘了就没有任何绕行的办法
- Win7 与 Win8 跑不了 MCP 预编译二进制，服务交给 Node 16 回落
- macOS 安装器拿不到完全磁盘访问权限时会假成功

第三条虽属 mac 那条线，统一给一批机器装插件时难免碰到，一并记在这里。Win7 的正主是第二条：服务的启动环节交给 Node 顶上，加载项本身的功能不受影响——这个设计让老机器不必等二进制适配，也能用上同一套能力。边界不是用来吓退人的，它们决定的是装机方案：机器要处理涉密材料就先规划离线模型，机器承担服务角色就先把 Node 环境备好，剩下的安装动作与其他 Windows 机器完全一样。

## 服务起不来时的回落逻辑

Win7/8 机器上，服务层走的是回落路线：启动脚本先尝试预编译二进制，探活失败就自动改用 Node 方式把服务拉起来。对使用者来说，要做的只有一件事——让机器上有一个能用的 Node 环境，装好后不必改任何配置，服务照样在本机端口上待命，加载项照常连接。Node 装没装好，在终端里跑一次版本查询命令就能确认；确认就绪后重启一次 WPS，看门狗会把服务重新拉起来。分不清当前走的是哪条路时，把加载项重装一遍最省事：安装器会按机器现状把自启重新注册好。

## 这套方案覆盖的三件事

- 三平台安装包，各架构都有对应产物
- macOS 容器写入失败有修复脚本可跑
- 企业里可用 HTTPS 静态部署来做集中更新

对一个还留着 Win7 机器的单位来说，第三条尤其实际：统一升级不必逐台拷包，服务器上换一版产物，各机器重新拉取安装即可。

## 端口、模型与写回的几条口径

有几条口径跟系统新老无关，装在哪台机器上都一样，集中放在这里：

- 本地四类端点各带默认端口
- 凡是让 AI 接手的文档，内容都会整篇送进所配置的模型，涉密稿件先切到本机离线模型再继续
- 这套加载项把「涉密文档不出网也能用 AI」当底线来设计，离线内网模型是优先项，配模型时还有 Ollama 一键安装引导
- 生成结果按助手定义的写回方式落进文档

老系统恰好是离线路线的用武之地：内网机器不触外网，模型配置走本机离线一档，文档处理全程不出域。

## 数据与安全的设计口径

- 凭据走 AES-GCM 设备绑定加密，选 HTTP 类型时把地址指向本机
- 本地数据的落盘位置有说明可查，帮助手册、在线客服与关于页也都找得到

老机器上跑涉密场景，这两条值得在部署文档里写明：加密口径不因系统老旧而打折，数据落点也有据可循。

老系统装这套加载项，真机走一遍比看十遍文章有用，卡住时回到「这条线上的边界」和「服务起不来时的回落逻辑」两节对照。
