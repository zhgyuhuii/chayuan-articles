# 三个场景吃透国产系统AI的用法

被国产系统AI折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI OS为准。

## 先看看痛点对不对得上

1. 麒麟与 UOS 上能用的 AI 软件少
2. 飞腾鲲鹏架构兼容性存疑
3. 政企采购要过信创适配

国产化环境用户这个场景里，信创环境一套完整的 AI 桌面与办公方案。

## 操作步骤详解

把流程串起来：

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程

## 支撑功能的操作细节

流程里桌面环境总览的实际操作：

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 关键能力点

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

## 几个容易忽略的细节

用之前要认的账：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

场景提醒：暂不支持龙芯平台。

## 高频疑问

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

## 能力点备忘

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

## 安装与运行答疑

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

### 检查更新失败？

更新需要联网访问官网接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

## 一个真实场景

开发者的典型用法：应用商店一键安装 17 家 CLI 智能体，模型设置向导一次配置，五家写入自动完成，系统技能镜像让智能体会操作本机。一个桌面管全部编码智能体，模型配置只做一次。注意：智能体二进制加模型权重占磁盘较大，注意预留空间。

## 顺带了解

全局默认模型：11 类任务各选默认模型：对话、嵌入、重排、决策、文生图、图生图、视频生成、图像理解、视频解析、语音合成、语音转文字，可选自动（本地优先）或指定，保存后随系统技能分发到智能体。

为什么值得看：润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱。

## 还有这个能力

遥测与清除数据：遥测开关、清除桌面数据（破坏性操作有警示）。

## 硬口径两三条

- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商

## 如实说不足

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 边界速览

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 应用商店与离线分发

商店对接能力广场（aidooo.com），插件、技能、MCP 插件、智能体、技能包五类内容在线下载并云端推送更新，配排行榜辅助选型。内网环境走 .cop.tgz 离线包导入：导出即依赖闭包，导入逐文件校验，断网也能完成分发。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 灵宠与任务灵宠

每个智能体可以化身桌面灵宠：在壁纸上活动，动作与体型反映记忆负载，头顶流式气泡，双击直开工作台。绑定常驻任务的任务灵宠会在执行期上桌直播输出，结束时气泡显示成败摘要——定时任务从日志文件变成看得见的桌面直播。

整体用下来，桌面环境总览的流程是清楚的：入口集中、步骤有反馈、做完有验证。第一次照着走一遍，后面基本就是肌肉记忆了。卡住就回看常见问题那一节。
