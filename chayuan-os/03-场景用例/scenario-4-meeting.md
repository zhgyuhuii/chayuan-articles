# 写给会议组织者的会议协作指南：完整方案

如果你是会议组织者，下面这些场景大概率不陌生：投屏共享要装第三方软件。从开会到纪要的闭环。这篇完整方案以察元OS为工具，把这个岗位的会议协作工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 投屏共享要装第三方软件
- 会议记录整理慢
- 行动项没人跟

## 用察元OS怎么解：工作流拆解

1. 共享桌面局域网投屏
2. 语音记录边说边出字
3. 便签日历落地行动项

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「共享桌面局域网投屏」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。从开会到纪要的闭环。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 云厂商模型调用需自备 Key，免费额度视厂商政策

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 能多人共用一台设备吗？

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。
