# 行业 AI 落地调研（能力广场速查手册）

场景库→助手目录→技能包的调研三连。这套组合工作流把行业场景库→助手目录→技能包商城串成一条线，在察元AI 能力广场里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

场景库→助手目录→技能包的调研三连。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI 能力广场的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·行业场景库**：20 个行业 × 200 个场景的 AI 应用导航：从行业到场景到对应资源的结构化路径。

1. 进入 /scenarios 选行业
2. 浏览该行业场景列表
3. 进入场景看对应资源与方案

**第 2 步·助手目录**：4526 个内置助手、228 个领域的在线目录：与察元AI文档助手/Office 同源，先在网页端浏览再装到工具里用。

1. 进入 /assistants
2. 按领域浏览
3. 找到需要的助手记住名称

**第 3 步·技能包商城**：311 个买断制技能包、13 大行业两级分类：包详情含解决什么问题/适合谁，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

1. 进入 /skillpacks 按行业浏览
2. 看包详情的 solves/audience
3. 微信/支付宝买断购买

## 衔接点与易错处

- 与助手目录（4526 助手）联动查看
- 228 领域覆盖绝大多数文职岗位
- 免费技能包约占一成，先试免费的

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 资源失效了怎么办？

条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注；发现问题可通过反馈渠道或机器人客服上报。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。
