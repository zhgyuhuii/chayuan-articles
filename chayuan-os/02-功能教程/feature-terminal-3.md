# 从需求到交付：命令行

命令行这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决跑脚本。

## 先看看痛点对不对得上

智能体工作台之外，想手动跑某个 CLI 或验证命令行为；想让终端从某个文件夹直接开始（「在终端中打开」），给智能体演示命令，跑脚本。

## 操作步骤详解

第 1 步 · 打开终端

1. Dock 点「终端」。
2. 窗口顶部标题条从左到右：红绿灯、窗口题名（字典文案「终端 — zsh」，后随当前 shell 名与窗口会话号——macOS/Linux 为 zsh、Windows 为 PowerShell，会话号是本窗口会话的 6 位短标识）；标题条最右是「新建终端窗口」按钮（+ 图标，悬停显示该提示）。
3. 正文首行是欢迎语：「chatop 终端 · 自带 Node/pnpm 工具链 · 输入 chatop plugin list 试试」。

第 5 步 · 从文件夹直接开终端

1. 桌面上文件夹图标右键 ＞「打开方式」＞「在终端中打开」：新开的终端以该文件夹为起始目录（提示符直接是那个目录，不再是 ~）。

第 6 步 · 用自带工具链

1. 终端 PATH 里预置了 chatop 与 pnpm 两个命令（由桌面注入）：chatop plugin list 列插件、pnpm 走察元内置工具链——不需要系统安装 Node.js。

## 关键能力点

- 真实 shell
- 会话持久
- 多标签

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 接着回答几个常见问题

### 浏览器里打开察元，终端怎么用不了？

终端命令要由桌面主进程在本机执行，网页/Docker 形态不提供。窗口会显示「终端由桌面版提供（Web 模式不可用）」，请在桌面形态使用。

### vim / top 这类交互式程序跑起来不对？

本终端是逐行执行模型：每按一次回车跑一条命令并收全输出，命令执行期间不接收键盘输入。全屏交互式程序（vim、top 等）无法正常交互，请在系统终端里跑。

### Ctrl+C 是清行还是中断？

命令运行中按 Ctrl+C 是向当前命令发 SIGINT 中断（配合「运行中… (Ctrl+C 中断)」提示）；没有命令在跑时，Ctrl+C 就是输入框的普通复制快捷键（复制选中文本）。

## 更多操作细节

第 2 步 · 输入命令并执行

1. 底部输入行：绿色提示符为当前目录（家目录折叠显示 ~）+ %。输入命令后回车执行；命令与输出逐行追加到上方滚动区，输出区文本可选中后用系统复制快捷键复制。
2. 工作目录跨行保持：cd 到别处后，下一条命令在新目录执行（每行执行前自动恢复该目录）；执行完返回结果的同时更新提示符。
3. 命令运行期间输入行右侧显示「运行中… (Ctrl+C 中断)」。

## 更多操作细节

第 3 步 · 中断与历史

1. 命令卡住想停：按 Ctrl+C（SIGINT 中断当前命令）。
2. 翻历史： 调出上一条、继续按向上翻更早， 向下翻/清空；选中历史后可直接回车重跑。

## 更多操作细节

第 4 步 · 多开终端

1. 点标题条「新建终端窗口」（+）再开一个终端窗口。每个窗口是独立会话：各自的当前目录与各自的可中断命令互不影响。

## 更多操作细节

验证

1. 打开终端输入 pwd 回车：输出一个完全路径（初始为用户家目录），提示符显示 ~。
2. 依次执行 cd Desktop、pwd：第二条输出的路径落在桌面目录下——目录确实跨行保持。
3. 执行 chatop plugin list：应输出插件清单（欢迎语推荐的第一条命令）。

## 补充答疑

### 多个终端窗口会共享历史吗？

不共享。命令历史按窗口各自记录（/ 只翻本窗口历史），当前目录与正在运行的命令也按窗口隔离。

## 动手前再核对一遍

- 桌面形态（察元AI OS）：终端由桌面主进程执行命令。网页/Docker 形态打开该应用只显示提示「终端由桌面版提供（Web 模式不可用）」，输入框不可用。
- shell 按平台自动选择：macOS/Linux 为 zsh，Windows 为 PowerShell（窗口标题相应显示）。
