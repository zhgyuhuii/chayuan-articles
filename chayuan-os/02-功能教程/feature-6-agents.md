# 一文读懂四家 CLI 智能体｜实操教程

CLI智能体是察元AI OS里使用频率很高的一项能力。它的「四家 CLI 智能体」这样工作：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。

从任务视角看，它对应的关键词是「CLI智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 打开任一智能体应用
2. 绑定工作区目录
3. 在 pty 终端里对话干活，多标签并行

## 适用场景

- 开发者日常编码
- 多智能体对比测试

## 实用技巧

- 无模型偏好时自动指向本地模型，不配 Key 也能跑

## 注意事项与边界

- 四家 CLI 二进制约 1.3GB，注意磁盘空间
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- Docker/云通道等进阶形态需要一定动手能力

## 常见问题
### 和察元AI Office 什么关系？

Office 以内置插件形态运行在察元AI OS 中；购买 OS 授权后同机 Office 自动免激活。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 数据存在哪里？怎么备份？

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。
