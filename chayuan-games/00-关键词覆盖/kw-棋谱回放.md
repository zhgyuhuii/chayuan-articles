# 棋谱回放与复盘：大模型对局的价值沉淀

棋牌圈有句老话：一局棋的价值，一半在下的时候，一半在复盘的时候。职业棋手靠棋谱传艺，研究者靠对局记录找规律，对局的价值要沉淀下来，靠的就是棋谱回放。棋谱回放，说的是把对局全程记录下来、支持事后逐手重演与检视的功能；在察元竞技场里，棋谱回放由回放器承担，可按协议字段筛选关键手，棋谱还能导出成 JSON 文件带走。

模型对局尤其值得回放：每一手背后都有一段推理、一次延迟、一笔 token 开销，这些过程数据散落在时间轴上，回放器把它们重新串起来。这篇拆一拆记录了什么、怎么筛、导出去能干什么。回放的价值常被低估：对局是易耗品，棋谱是耐用品，一道之隔，价值差出数倍。

## 拆词与相近概念辨析

棋谱回放与两个东西容易混。对局直播回看：把时间流原样倒一遍，看的是「发生了什么」。复盘：带着问题回去拆局，看的是「为什么发生」。棋谱回放：介于两者之间的载体——既是完整记录，又提供筛选、标注、导出这些复盘工具。察元竞技场的思路是把回放器做成复盘的底座：先能重演，再能筛选，后能带走。这条链路对应复盘的三个阶段：看过程、找重点、做沉淀，回放器把三个阶段装进了同一个入口。

记录的不止着法。每一手的延迟与 token 用量、局势数据都在对局档案里，回放时随手可查——这是人类棋谱做不到的厚度，也是模型对局独有的价值。

## 回放器与协议筛选

一局棋几十上百手，逐手翻效率太低。回放器支持按协议字段筛选关键手：模型出招走统一的协议格式，每个着法都带着结构化字段，筛选就是把某一类手快速挑出来集中看，筛选逻辑跟着协议字段走。它的价值在于把一局棋从流水账变成重点集锦，复盘效率完全不同。筛选也是定位工具：结合形势曲线锁定可疑区间，再用筛选把区间里的关键手拉出来，两步就到现场。人类玩家的对局同样在回放范围里：人机局的失误被标注出来，比模型的对局更值得自己反复看——你的进步空间比模型大得多，想让进步更快，把人机局的回放固定翻一翻，失误标注会指路。

复盘阶段还有逐手的妙手与失误标注（问叹号标注与叹号标注），配合形势曲线使用：曲线在某一手出现大摆动，点过去看标注，那一手为什么成为转折，前后文全在。

## JSON 导出：把数据带走

棋谱支持导出成 JSON 文件，用途比想象中宽：存档归档，把有价值对局留底；程序分析，写脚本统计出招习惯与胜负规律；做数据集，把对局喂给自己的研究流程；跨工具流转，JSON 是通用格式，谁都能读。数据只在你本机，导出去的文件也归你处置。举两个具体的用法：把某个模型输掉的对局批量导出，统计它常见的败因模式；把跨模型的精彩对局集中归档，攒一份自己的「名局库」，以后做分享或研究都是现成素材。给团队用时更明显：对局数据配上协议画像的统计，一份模型行为报告的原料就齐了；教培场景里，JSON 棋谱转成练习题也是常见的二开思路。

配合着还有两个沉淀工具：协议画像统计每个模型的出招协议习惯——JSON 格式遵守率、平均耗时这些指标逐局累积；开局记忆帮模型避免在同型局面里重复犯错。回放与画像放在一起看，一个模型的成长轨迹与性格底色都能对出来。画像与回放互为注脚：画像告诉你「它常犯什么」，回放告诉你「那次是怎么犯的」，一抽象一具体，凑成完整的认识。

## 一局棋的三遍回放法

给你一个实操节奏。头一遍只看形势曲线，记下大摆动的位置；第二遍按协议字段筛关键手，对着逐手的问叹号标注（妙手）与叹号标注（失误）看转折点；第三遍慢速走一遍棋，重点手的记录细读。三遍下来，一局棋从结果到过程全部吃透，比囫囵看十局收获都大。

三遍法的本质是把「看热闹」和「看门道」拆开：头一遍满足好奇心，后两遍生产认知，顺序反了容易两头都累。

## 从一局棋到一份档案

三步。正常打完一局（人机局或机机观战都行），对局自动入记录；到对局记录里打开回放器，按协议字段筛关键手，对着形势曲线与逐手标注走一遍；需要带走就导出 JSON，存档或喂给外部程序随你。回放不限于自己的对局：机机观战攒下的赛会棋谱同样进记录，别人的对局照样回放，素材越攒越多。

## 三条边界

JSON 面向程序而非人眼：直接打开看是结构化文本，不配合工具读起来费劲，想直观回顾还是先走回放器。

数据只存本机：对局档案不云同步，换电脑要自己搬文件，删了也就真没了，重要棋谱记得备份，导出的 JSON 文件本身就是稳妥的备份形态，备份习惯越早越好。

复盘标注是辅助视角：妙手与失误的判断未必处处精准，把它当线索，别当判决，最终以对局数据为准。拿着标注去质问模型「你为什么犯蠢」，不如去读它当时的思维链，后者才是答案所在。

## 棋谱回放常见疑问

### 复盘标注是怎么来的

系统在复盘阶段逐手给出问叹号标注（妙手）与叹号标注（失误），和形势曲线搭配着看，是检视的线索，不是胜负判词。把标注当路标用：它指路，你走路。

### 导出的JSON能做什么

存档、写程序分析、做数据集、跨工具流转都行。JSON 是通用格式，外部程序读取没有门槛。字段跟着协议走，懂程序的可以按需抽取，不懂的拿去问任何语言模型也能处理。

### 换电脑后棋谱还在吗

棋谱存本机，不随云端同步；换机迁移要手动拷贝数据文件，重要档案建议定期备份，先导出再迁移，流程更短。

### 回放是所有玩法都支持吗

竞技场的对局走统一协议记录，对局记录与回放按对局打开即可，11 款玩法（2026 年 11 月，版本 0.1.0）都走同一套记录体系。

棋谱是棋手的第二生命，对局数据是模型研究者的第二矿场。察元竞技场把回放、筛选、标注、导出做成一条完整的沉淀链，让每一局大模型对局都不白白流走——打完了，价值才刚刚开始兑现。
