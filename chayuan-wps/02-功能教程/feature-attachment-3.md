# AI读文档场景实战：从需求到交付

很多AI读文档的教程只讲是什么，不讲怎么做；或者讲了一半步骤，剩下的让你自己悟。这篇反着来：步骤写全、按钮文案原样引用、每步的界面反馈都说清楚，用的是察元AI文档助手（aidooo.com）。

## 解决什么痛点

关掉感知做通用问答；想把附件在消息里明确指出来（如「按 附件2 的格式改写全文」），附上参考文件让它仿写，想确认 AI「看到」的是哪段选区、哪一页，避免答非所问。

用户常搜的问法：怎么上传文件给 AI 参考？有数量限制吗；消息里的『附件N』是什么意思？怎么打出来。

## 完整操作步骤

1. 添加附件

1. 在哪：输入区工具条上的回形针按钮（悬停提示「选择附件」）。
2. 做什么：点它，在系统文件选择框中选一个或多个文件（可多选）。
3. 看到什么：输入区上方出现附件 chip：回形针图标 +「附件N」+ 文件名（无文件名的极端情况显示「未命名附件」）；每个 chip 后跟一个用途小按钮（默认「对象」，可点击在「对象 / 样例 / 参考」间循环切换，悬停提示「用途:…(点击切换 对象/样例/参考)」）和移除「×」（悬停提示「移除 文件名」）。删除中间某个附件后，剩余附件会按顺序重新编号。
4. 数量上限：5 个。超出的选择会弹「最多只能添加 5 个附件」。
5. 文件大小不设上限；选中只登记引用，解析延迟到发送时按用途进行。

2. 在消息里引用附件

1. 做什么：单击附件 chip 左侧引用区，把「附件N」插入输入框光标处；右键插入完整形式「附件N（文件名）」。
2. 看到什么：chip 下方有提示行「点击附件标签插入“附件N”，右键插入“附件N（文件名）”。」；发出的消息气泡下方也会显示附件 chip，悬停可看引用全文。
3. 发送时按用途提取内容：办公文档（docx/xlsx/pptx/et/dps 等）模板用途直接用原始字节，参考/样例用途提取文本并压缩采样；文本类附件超长（约 12000 字符）自动「头 2/3 + 尾 1/3」压缩保留结构；HTML 自动提取正文；图片/音视频等附件调用已配置的对应识别模型解析出文字（未配置对应模型时以对话模型兜底，识别不出不阻塞发送）。
4. 附件进入模型时带结构化头（形如「附件N：文件名（类型），大小 …」），模型能明确区分每份附件与编号。

3. 查看文档感知面板

1. 在哪：输入区工具条上的眼睛按钮（存在可感知上下文时才显示）。
2. 做什么：点它在「展开文档感知」/「收起文档感知」间切换。
3. 看到什么：输入区下方展开感知面板，最多 6 枚上下文 chip，例如「当前选区」「第 3/10 页」「1234 字」「样式 标题 1」「字体 宋体」等（选区/段落/单元格/范围四类开头），旁边是选中文本预览（超 88 字截断）；右侧圆形箭头按钮「刷新感知」立即重采。已添加附件时，输入区上方一栏还会出现「已选 N 字」小字签（选区/段落/单元格各有措辞），悬停显示选区原文。
4. 发出的消息会标注本轮输入范围：以全文作答显示「全文 N 字」、以选区作答显示「已选 N 字」、只按输入内容作答显示「仅输入内容」，悬停可见「本轮输入范围：…」说明——据此能确认 AI 这次「看的是哪一段」。

4. 利用感知推荐

1. 看到什么：AI 回复末尾可能出现一行「通过感知，你需要」+ 带引号的可点推荐项——依据你当前选区/上下文推荐合适的助手动作。
2. 做什么：点推荐项直接进入对应助手的执行面板。

## 常见问题

### 眼睛按钮不见了？

它只在有可感知上下文（有选区/段落/单元格/范围）时出现。在文档里选中一段内容即可让它出现。

### 附件里的 Word/Excel 内容 AI 真的读了吗？

读了。办公文档在发送时按用途解析：模板用途直接用文件字节，参考/样例用途提取文本；超大文本走压缩采样，不会因文件大而失败。

### 附件数量能放宽吗？

当前固定上限 5 个，超出会提示「最多只能添加 5 个附件」；可分多条消息分别引用。

## 补充答疑

### 图片附件发出去没有识别结果？

图片识别调用已配置的识别模型（视觉类模型，未配置时以对话模型兜底）；没有可用模型或识别失败时附件仍以原始信息进入管线、不影响发送。可在模型设置中确认已配置可用模型。

### 附件会随会话历史保存吗？

会话历史里保存的是附件的名称、大小、类型与已提取的文本内容（发送时已解析的部分），不是原始文件本体；历史恢复后消息气泡下方仍能看到附件 chip 与其信息。

### 附件 chip 上的「对象 / 样例 / 参考」有什么讲究？

这是附件的用途标注，点击即在三档间循环切换；发送时按用途决定解析方式（如模板用途直接用文件字节）。不确定用途时保持默认「对象」即可。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。
