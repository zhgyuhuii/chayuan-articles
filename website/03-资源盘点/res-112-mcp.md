# 开发者常用 MCP 服务器盘点

开发者常用 MCP 服务器盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：MCP 服务器板块（MCP服务器列表）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**MCP 服务器板块**：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

1. 进入 mcp 板块
2. 按功能关键词搜索
3. 复制 JSON 配置片段到客户端

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 投稿有人工审核门槛，重复或低活跃项目会被拒

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 政企可私有化部署（Docker），数据自主可控

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 常见问题
### 智力榜的分数哪来的？

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。

### 支持英文吗？

全站中英双语，资源条目双语展示，英文关键词搜索覆盖更广。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。
