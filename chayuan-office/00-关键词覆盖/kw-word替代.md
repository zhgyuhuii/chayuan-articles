# Word替代是什么：十页签完整功能区

关于Word替代，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI Office的能力面与边界一次说清。

## 什么是Word替代

Word替代，先把定义钉死：察元AI Office（Chayuan AI Office）是一款 Apache-2.0 开源的 AI 办公套件。它把 docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器并入一个应用；AI 校对把批注锚在原文上，修订则生成通用格式的追踪记录；Docs 端装了 4576 个领域助手；模型接入走 BYOK，可连 94 家供应商或本机 Ollama 等本地端点；平台覆盖 Windows/macOS/Linux（含麒麟/UOS），定位本地优先、全程可离线。

文中数字与条目逐项对照官方文档写了，版本时间在尾注交代。

## 平台与形态

平台覆盖：Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；浏览器 SaaS 与 dsh 插件作为另两种形态存在，都是五编辑器（无 HTML）。

## 这套替代落在哪个编辑器

落点在 Docs 功能区总览：十个页签——开始、插入、绘图、设计、布局、引用、邮件、审阅、察元AI、视图，外加表格图片页眉页脚上下文页签；导航窗格、五种视图、拆分、深色页面、首字下沉、域、交叉引用、真图表都在其列。

单列一节的理由：功能面覆盖决定能不能真正替换，十个页签把常用 Word 动作补齐了。

## 最短上手路径

从页签行的规律入手，上手会快很多：

第 1 步 · 认识页签行：固定页签 + 上下文页签 + 密度

1. 固定页签在 macOS 上的顺序是 开始 / 插入 / 绘图 / 设计 / 布局 / 引用 / 邮件 / 审阅 / 察元 AI / 视图；Windows 版最左侧另有「文件」按钮，菜单里是打开（Ctrl+O）、保存（Ctrl+S）、另存为（Ctrl+Shift+S）与四项转换。macOS 没有这一页签，文件动作归系统菜单栏管。
2. 上下文页签按需出现：光标进表格，多出「表格设计」「表格布局」；选中图片，多出「图片格式」；编辑页眉页脚时又多出对应页签。离开对象后它们自动退场，常规页签接回。
3. 功能区密度三档，两处开关如下：
    1. 折叠/展开命令区：macOS 按 ⌥⌘R（Windows 为 Ctrl+F1），双击任意页签或再点一次当前页签也行；折叠后只剩页签行，点任意页签展开该页签内容，状态会被记住。
    2. 紧凑（仅图标）：macOS 按 ⌥⌘K（Windows 为 Ctrl+Alt+K）在完整与紧凑之间切换；悬停当前页签可看到这两条快捷键的提示。

## 落点的能力面

- 十页签完整功能区
- 字节保真往返（未触碰块逐字节写回）
- 修订批注公式墨迹

## 能力面的其余拼图

- 下载安装与首次启动：Windows 用 NSIS 安装器、macOS 用 dmg、Linux 有 deb、rpm 与 AppImage（glibc 2.34 以上）；安装包只从官方渠道拿，镜像站的包来源说不清。
- 主页与文件管理：主页承担最近文件、新建入口与 AI 对话发起；文件管理支持搜索、排序与标签页式多开。
- 新建与打开文件：打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；doc 与 ppt 老格式明确不支持，需要先转成新格式。
- Docs 功能区总览：十个页签：开始、插入、绘图、设计、布局、引用、邮件、审阅、察元AI、视图，
- Sheets 数据工具：基于开源 Univer 核心加自研 Rust 边车（calamine 加 I……
- PDF 转换：开始页签转换下拉五项：PDF 转 Word、Excel、PPT、Markdown、HTML，

## 哪些情况要想清楚再上

- AI 能力以已配置模型为前提（BYOK 或本地端点），模型缺位时只剩传统办公功能
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值

边界条目不拦着日常使用，但选型阶段把它们摆上桌，总比上线后才发现要好。

## 数据与安全设计

- API Key 存本机 ai-settings.json 不上传，支持环境变量引用
- PDF 涂黑生成物理删除的 -redacted.pdf 副本，不是注释遮盖
- 文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代
- 遥测仅匿名统计且可关闭；自建部署可做到零遥测

## 常见疑问逐条答

### 功能区只剩一排页签，命令区去哪了？

被折叠了。点任意页签可临时展开；想恢复常驻，用 ⌥⌘R（Windows Ctrl+F1）或双击页签。折叠状态会记忆，重启后依旧，需要再按一次快捷键切回。

### 图标有了文字没了，怎么恢复？

这是「紧凑（仅图标）」密度在起作用，⌥⌘K（Windows Ctrl+Alt+K）切回完整显示即可。

### 页签行为何时不时冒出「表格设计」之类的页签？

那是上下文页签：光标进表格、选中图片、或编辑页眉页脚时自动出现，离开对象即消失，没有开关需要找。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

## 「开始」页签逐组过一遍

第 2 步 · 「开始」页签：转换 / 剪贴板 / 字体 / 段落 / 样式 / 编辑

1. 最左侧是「转换」组：「转换为 PDF…」「转换为 HTML…」「转换为 Markdown…」「导出为图片…」四项；导出图片先选保存文件夹，再逐页产出 <文件名>-01.png、-02.png…（流程是先转 PDF 再逐页栅格化）。打印不归功能区管：⌘P（应用快捷键清单里的「打印」）调出「打印」对话框，选好范围送打印机。
2. 「剪贴板」组：「粘贴」的右侧箭头藏着「选择性粘贴…」，可按 HTML、无格式 Unicode 文本或图片粘贴；另有「剪切」「复制」与「格式刷」（点一下刷一次，再点取消激活）。
3. 「字体」组：东亚字体与西文字体各占一个下拉，中西文可分别设字体；字号与增大/减小字号；加粗 ⌘B、下划线 ⌘U、倾斜 ⌘I、删除线、上标/下标；「文本突出显示颜色」「字体颜色」提供主题颜色/标准色/其他颜色…；「更改大小写」下拉覆盖句首字母大写/小写/大写/每个单词首字母大写/切换大小写/半角/全角；末尾是「清除所有格式」。
4. 「段落」组：「项目符号」「编号」「多级列表」（支持自定义）、增减缩进量、「显示/隐藏编辑标记」、左/中/右/两端对齐（⌘L/⌘E/⌘R/⌘J）、文字方向（从左到右/从右到左）、「行距」及「行距选项…」、段落底纹、各种框线（下框线/上框线/所有框线/无框线等）。
5. 「样式」组：样式库收着正文、标题 1、标题、强调等；「样式窗格」打开后可查看、应用并修改文档中的全部样式。
6. 「编辑」组收尾：「查找」「替换」「全选」。

Docs 功能区总览读十遍不如上手点一遍，从分清固定页签与上下文页签开始最省力。
