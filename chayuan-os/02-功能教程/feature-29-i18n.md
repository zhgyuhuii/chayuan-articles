# 一文读懂九语言界面｜实操教程

系统语言是察元AI OS里使用频率很高的一项能力。它的「九语言界面」这样工作：中文、English、日本語、한국어、繁體中文、Русский、Español、Français、Deutsch 九种界面语言。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

中文、English、日本語、한국어、繁體中文、Русский、Español、Français、Deutsch 九种界面语言。

从任务视角看，它对应的关键词是「系统语言」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 设置→语言切换
2. 即时生效

## 适用场景

- 多语言团队

## 实用技巧

- 按系统语言自动选择默认

## 注意事项与边界

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。
