# undefined清单式指南：运维/轻运维场景全拆解

如果你是运维/轻运维，下面这些场景大概率不陌生：多台机器远程管理。AI 加持的运维台。这篇清单式指南以察元OS为工具，把这个岗位的undefined工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 多台机器远程管理
- 故障响应要快
- 排障知识散在笔记里

## 用察元OS怎么解：工作流拆解

1. 云通道远程终端
2. 故障一键转智能体修复
3. 排障知识库沉淀

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「云通道远程终端」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。AI 加持的运维台。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
