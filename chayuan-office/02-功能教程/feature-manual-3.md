# 键盘效率场景实战：从需求到交付

很多键盘效率的教程只讲是什么，不讲怎么做；或者讲了一半步骤，剩下的让你自己悟。这篇反着来：步骤写全、按钮文案原样引用、每步的界面反馈都说清楚，用的是察元AI Office（aidooo.com）。

## 解决什么痛点

记不住组合键，想查「收起功能区」「查找替换」按哪个；断网环境查手册；不想翻网页文档，希望软件里自带一份能搜的说明书，系统学一遍快捷键。

用户常搜的问法：应用里有没有说明书？怎么打开；收起/展开功能区的快捷键是什么。

## 操作步骤详解

第 1 步 · 打开手册（两条入口）

1. 在任何标签页（主页、Docs、Sheets、Slides、PDF、Markdown、HTML）按 F1；应用菜单的「帮助」菜单里也有「使用手册」一项（快捷键标注 F1），点它等效。手册以独立标签页打开，不打断当前文档。
2. 说明：主页左上角曾有「使用手册」常驻按钮，当前版本该按钮与「AI 问答」入口一并隐藏，F1 是现役入口。
3. 手册左侧是目录，分四组共 18 个主题——入门：安装 ChaOffice / 快速入门：界面与基本操作 / 主屏（Home）：文件都在哪 / 标签页与窗口管理 / 快捷键一览；应用：Docs：文字处理 / Sheets：电子表格 / Slides：演示文稿 / PDF：阅读、注释与涂黑 / Markdown 编辑器 / HTML 编辑器；AI 能力：AI 助手面板 / AI 模型与设置；文件与设置：字体：系统字体与可下载字体 / 文件操作：重命名、删除、导出 / 设置、语言、主题与 MCP 集成 / 命令行与智能体 / 连接编程助手。点标题切换主题。

第 2 步 · 搜手册、用键盘逛

1. 左上搜索框占位文案「搜索手册…（按 / 聚焦）」：按标题、关键词与正文全文匹配（当前语言与英文都参与），输入后目录只剩命中主题，右侧显示「{n} 个主题」。
2. 键盘操作：/ 把光标聚焦到搜索框；/ 在目录里逐个走主题；正文超过一屏时，文章开头出现「本页目录」（由正文的二级标题生成），点击平滑滚动到对应小节。
3. 正文里的 help:// 链接可跳到另一主题；插图按当前语言配图。某语言缺正文时自动显示英文版（理论上不会出现——18 主题 ×22 语言共 396 篇正文全部随包内置，且有 check:help-langs 校验脚本保证每篇结构与英文源一致）。

第 3 步 · 查快捷键（两种粒度）

1. 全景表：手册目录 ＞ 入门 ＞「快捷键一览」。先读第一节：只有三个入口键是全局的——F1 打开本手册（所有标签页）；⌥⌘R（Windows/Linux Ctrl+F1）收起/展开功能区（所有编辑器）；⌥⌘K（Windows/Linux Ctrl+Alt+K）在全尺寸/紧凑功能区间切换（仅 Docs）。单按 F1 不会收起功能区——两者刻意不共用。之后按 Word / Sheets / Slides / PDF / Markdown / HTML 六节展开，macOS 与 Windows/Linux 两列并排，只对选区生效的键会在「操作」列注明。
2. 可搜索面板（仅 Docs 编辑器）：光标在文档标签页内按 ⌘/（Windows/Linux Ctrl+/），或应用菜单「帮助」＞「键盘快捷键」，弹出「键盘快捷键」对话框：顶部搜索框占位「搜索快捷键」按名称或按键过滤（如输入「保存」或「⌘S」），条目按分组罗列，无命中时显示「没有匹配的快捷键」，点「关闭」退出。其他编辑器没有这个面板——查它们的键位请看手册「快捷键一览」对应小节。

## 你可能会问

### 手册显示的语言和界面语言不一样？

正文优先取当前界面语言，缺失时回退英文；标题同理。若界面语言在 22 种之内却长期显示英文，属异常，请反馈。

### ⌘/ 打开的表和手册「快捷键一览」是什么关系？

⌘/ 面板只覆盖 Docs 的键位——手册「快捷键一览」自己也写明「『键盘快捷键』表只有 Word 有（⌘/），它列出的正是下面那张 Word 表」；而手册那篇是全应用六编辑器 + 全局键的总表。查 Sheets/Slides/PDF 的键位只能看手册。

### 手册里怎么没有某个新功能？

手册的 18 个主题登记在代码内的主题注册表里——一个功能没有手册条目时，是注册表里可见的缺口，而不是搜不到的暗坑。若确有缺失，欢迎到 GitHub 提 issue（关于区有仓库地址）。

## 补充答疑

### Windows 上收起功能区按 F1 怎么没反应？

Windows 的功能区开关键是 Ctrl+F1（macOS 是 ⌥⌘R），单按 F1 是手册。紧凑功能区的切换键相应是 Ctrl+Alt+K（macOS ⌥⌘K），且仅 Docs 支持。

### 按 F1 没反应？

F1 是应用菜单里注册的快捷键，被常驻软件（输入法工具、系统快捷键）占用时会失灵。改走菜单：「帮助」＞「使用手册」。注意 F1 打开的是手册，不是快捷键表。

## 安装与运行答疑

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。

## 一个真实场景

法务与合同岗的典型用法：全文搜索秒级定位条款，AI 修订对比两版差异，对 AI 隐藏商业敏感段后再润色。合同审阅从通读变成查重点。注意：AI 只做辅助，法律责任判断仍需人工。

## 顺带了解

字节保真与格式兼容：未触碰的块逐字节写回；1GB 大 docx 打开不卡（图片按哈希留原文件按需读、zip 条目按存储字节搬运）；ODF 导入保守策略：无法证明正确的公式只保留结果值，不完整保留项进 dropped 清单。

为什么值得看：改一个字不该弄乱整个文件的格式，字节保真是最硬的承诺。
