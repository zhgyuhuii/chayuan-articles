# 离线大模型是什么：模型配置可一键写入五家

把大模型搬到本机跑，动机各不相同，但关心的问题趋同：能跑什么、怎么装、边界在哪。本文以察元AI OS为对象，给出官方口径的答案。

## 什么是离线大模型

离线大模型不是单一功能，而是一整面带入口、步骤与边界的能力：AI 桌面操作系统，把本地大模型、知识库、智能体、宠物群聊收进同一个桌面。

全部说法取自官方文档，数字与版本的对应关系统一放在文末尾注里。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| mcpTools | 86 个 MCP 工具（2026 年 10 月实测） |
| 装机五件套 | Qwen3-4B 对话、BGE-M3 嵌入、BGE 重排、whisper-small 语音识别、piper 中文语音合成 |
| kbPort | 52582（知识库对外服务，固定端口） |
| mcpPort | 52583（本机 MCP HTTP 服务，回环免 token） |

## 平台与形态

支持的系统与形态：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

离线大模型在察元AI OS里的落点是下载本地模型：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），支持断点续传，下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

为什么值得单独说：断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 最短上手路径

先从顶部的状态条认起。

2. 认识状态条（顶部）

1. 健康灯 + 文字：「正常」（绿）/「引擎异常」（黄）/「不可达」（红）/「已停用」（灰）/「引擎缺失」（黄）；
2. 实例计数：「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示「空闲自动卸载策略」）：「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，默认 15 分钟；
4. 「重启全部」「全部关闭」：点击后行内出现红色二次确认条——「重启全部运行中的模型？」/「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，点「好」执行、「取消」收回；
5. 服务被停用时，此处只剩「启动」按钮。

## 装前必看的四条边界

- 8GB 内存的设备，一次加载一个对话模型是安全线，复杂任务别指望太多
- 龙芯暂无版本；视频生成不走本地，靠云端路由兜着
- 云端厂商的调用资格取决于你手里的 API Key
- Docker 云桌面、跨终端互联这类形态偏极客，新手先别碰

边界清楚，预期才不会跑偏；上面几条都不动主线功能的根基。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 断网与下载的常见疑问

### 完全断网 / 所有源都下载失败怎么办？

断点已保留，联网后点「继续下载」从断点续传。彻底离线的机器：在任意联网电脑按帮助中心「离线下载与导入」的直链下载权重文件（U 盘/内网搬运）放到本机，再用「我的模型 ＞ ＋ 添加模型」按路径导入（不复制文件、原路径引用）。

### 标着「关闭」徽标的模型能下载吗？

能——徽标含义明示「仍可下载，加载时会被守卫拦截」。点「启动」时会被内存预算预检拦下，并提示需要多少内存、建议先卸载谁。内存不够就换小参数量模型，或先「停用」部分运行中的模型。

### 模型跑一会儿自己停了？

默认「15 分钟无人使用自动卸载」在释放内存，不是故障。常用对话/嵌入模型点行内「钉住」豁免自动卸载；时限在状态条下拉可调（自动卸载：关 / 5 / 15 / 30 / 60 分钟）。

### 模型加载失败或提示内存不足？

系统有内存预算硬底线（总内存的 45%）保护：先卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

### 检查更新失败？

更新这一步需要联网到官方接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

## 怎么判断它适不适合你

离线大模型这条路走不走，先掂量两件事：你的机器内存宽不宽裕、你对断网的刚性需求大不大。两者都成立，本篇的链路对你就很有价值；缺一个，先把需求想清楚再动。

## 本地模型页的入口

1. 进入本地模型页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）列出十一类导航：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 视频解析 / 生图 / 视频生成 / 语音识别 / 语音合成。进页默认选中「对话」。右栏页面自上而下：状态条 ＞ 服务地址条 ＞ 「模型全机只保留一份」提示 ＞ 「我的模型」（已安装）＞ 「模型库」（未下载）。同一模型只会出现在其中一个分类页。

## 服务地址条说明

3. 服务地址条（第二行）

显示本分类的对外端点，如对话类为 http://127.0.0.1:52581/v1/chat/completions；「复制」（点击后变「已复制」）、「配置帮助」展开 curl 示例。各分类端点：对话/代码补全/图像理解 /v1/chat/completions、嵌入 /v1/embeddings、重排 /v1/rerank、决策 /v1/systemone、语音识别 /inference（生图/视频生成/语音合成走系统内置调用，不显示此条）。底部注：「免 key 直连：本机任意智能体不带 key 即可用（审计归因 anonymous）…」。

离线大模型能不能用好，一半看操作，一半看机器内存给不给余量；前文那条内存安全线，动手前先算清楚。
