# PDF转Excel出问题怎么办：排查手册加进阶技巧

写这篇的起因是群里有人问PDF转Excel，我发现自己也说不完整，索性把察元AI Office里的PDF 转换从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（本地转换（「转换」下拉与文件菜单本地项）：无需登录、不消耗 credits、全程本机。），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

第 1 步 ·「转换」下拉（功能区「开始」页签，本地五项）

1. 在 PDF 标签页切到「开始」页签，点「转换」按钮（悬停提示「将 PDF 转换为 Word / Excel / PPT」），下拉五项：「PDF 转 Word」「PDF 转 Excel」「PDF 转 PPT」「PDF 转 Markdown」「PDF 转 HTML」。
2. 点任一项即开始本地转换：先保存当前 PDF 的未保存修改 ＞ 弹系统保存对话框选输出位置（默认同名换扩展名）＞ 转换进行中系统任务栏（macOS 为程序坞图标）显示进度条 ＞ 完成后结果文档在新标签页打开（Word 进文档标签、PPT 进演示标签、Markdown/HTML 进对应标签）。
3. Markdown / HTML 两项的内部路径：先本地转出 Word（docx），再由应用把 docx 无头导出为 md/html（同 docs 的「导出 PDF」无头通道，见 docs/headless-pdf-export.md）。
4. 转换进行中再次点击会提示「正在转换中，请等待当前导出完成。」；若输出位置的同名文件已在本应用标签页里打开，会先关闭那个旧标签（含未保存修改的正常保存询问），避免旧标签下次保存覆盖转换结果。

第 2 步 · 菜单栏入口与云端/本地双入口现状

1. 菜单栏 文件 有四个导出项，现状（以代码为准）：
    1. 「导出为 Word…」——云端版：未登录时弹「导出为 Word 需要登录 察元AIOffice 账号。」可点「登录」走浏览器授权；已登录时弹确认框「将此 PDF 上传到 察元AIOffice 云端转换为 Word？」「本次转换将消耗 5 credits，文件将上传至云端处理。」「当前余额 {balance} credits。」，点「继续」后选保存位置并上传转换；
    2. 「导出为 Word（本地）…」——与第 1 步「PDF 转 Word」同一条本地管线；
    3. 「导出为 PPT…」「导出为 Excel…」——仅本地版（无云端对应项），与第 1 步「PDF 转 PPT / Excel」相同。
    4. 即：只有 Word 有云端/本地两条入口，PPT、Excel、Markdown、HTML 一律本地。

第 3 步 · 本地转换的扫描件处理（与 O31 同源引擎）

1. 版面分析全本地完成：按几何信息还原段落、表格、列结构，再重建为 docx/pptx/xlsx。
2. 扫描页自动接 OCR（系统引擎，macOS Vision / Windows Windows.Media.Ocr；Linux 无引擎则整页保留位图）。转换完成后应用如实报告：
    1. 整份是扫描件：「检测到扫描件」——「本地转换已按图片保真导出各页，未能识别出可编辑的文本。」
    2. OCR 救回的页：「扫描页已转换为可编辑文本」——「第 {pages} 页为扫描件，已通过本地 OCR 识别为可编辑文字，建议校对识别结果。」
    3. 个别页无法重建：「部分页面已按图片导出」——「第 {pages} 页版面无法可靠重建，已按整页图片保真导出。」
    4. PPT 版口径：每页 PDF 转一张幻灯片；扫描页按图片保真导出并提示「本地转换已按图片保真导出各页，幻灯片中的文字不可编辑。」
    5. Excel 版口径：每页 PDF 转一张工作表；扫描页无法转成单元格，对应工作表写入提示行（「扫描页无法转换为单元格，对应工作表中已写入提示行。」；部分页失败时提示「部分页面未转换为单元格」）。

## 怎么确认做成了

验证

1. 对一份文字版 PDF 点「转换」 「PDF 转 Word」：选好位置后进度推进，完成后自动打开的 docx 里文字可编辑、段落次序与 PDF 一致；全程无网络请求（可离线验证：断网执行同样成功）。
2. 对同一份 PDF 分别走 文件 「导出为 Word…」：未登录时应弹登录提示；登录后确认框明示「消耗 5 credits」「上传至云端处理」——与本地项「导出为 Word（本地）…」可明显区分。
3. 对一份加密 PDF 点本地转换：先弹「输入密码」，输错提示重试，输对后正常转换。

## 进阶用法与边界

- 五种目标格式
- 本机转换零上传
- CLI 可脚本化
- 边界：证书加密 PDF 无法转换
- 边界：扫描页转 PPT 与 Excel 文字不可编辑

## 你可能会问

### 扫描件转出来全是图片，没有文字？

整份扫描且系统未识别出可编辑文本时应用会明确告知（「检测到扫描件」）。确认平台：macOS/Windows 有系统 OCR 能救回文字（完成提示会列出哪些页是机器识别的，记得校对）；Linux 没有系统引擎，扫描页保留整页图片。也可以先在 PDF 里等 O31 的后台识别完成再转换。

### 「导出为 Word…」和「导出为 Word（本地）…」用哪个？

要快、要隐私、不想花 credits：用「（本地）」（或功能区「转换」 「PDF 转 Word」，同一管线）。云端版要登录、上传文件并消耗 5 credits/次；两条管线的转换效果本来就不同源，同一份 PDF 两边各转一次对比选优即可。

### 转 PPT 后每张幻灯片文字选不中？

该页来自扫描页，按图片保真导出（提示里已说明「幻灯片中的文字不可编辑」）。文字版页面转出的幻灯片文字正常可编辑。

## 补充答疑

### 加密 PDF 转换报「该文件使用证书加密或不支持的加密方式」？

打开密码（用户密码）保护的 PDF 输密码即可转；但证书加密（需要证书才能打开）这类应用不支持解密，无法转换。先在能打开它的环境里另存为无密码副本再转。

### Markdown 转出来缺内容？

Markdown 不支持图片与复杂版式：无法可靠重建的页、图片兜底的页在 Markdown 里会缺失，完成提示「Markdown 中缺少部分内容」并列出页码。需要保真请改用 Word/HTML。

### 转换出来的 Word 版面和 PDF 不一样？

本地转换按几何版面分析重建，复杂排版（多栏混排、艺术字、嵌套表格）可能近似还原；无法可靠重建的页会按整页图片保真导出，并在完成提示里点明页码。要求逐像素一致的场景，改用「导出图片」或打印。

## 更多操作细节

第 4 步 · 加密 PDF 与失败提示

1. 加密 PDF 本地转换时弹出「输入密码」对话框：「此 PDF 已加密，请输入打开密码：」；密码错显示「密码不正确，请重试。」可反复重输，「正在验证密码…」期间按钮等待；点「取消」中止本次转换（不消耗任何资源）。
2. 证书加密等不支持的加密方式：报「该文件使用证书加密或不支持的加密方式，无法转换。」；文件损坏：报「文件已损坏或不是有效的 PDF，无法转换。」；失败提示按目标区分——Word 报「导出为 Word 失败」，Markdown/HTML 报「导出为 Markdown / HTML 失败」，均附具体原因。

第 5 步 · 打印与导出图片（同属「把 PDF 拿出去」）

1. Ctrl/⌘+P（或「开始」页签「打印」）打开打印面板：范围「所有页 / 当前页 / 自定义范围」（格式如 1,3,5-8）、打印机（含「系统打印对话框…」）、份数、逐份打印、双面打印（单面/长边翻转/短边翻转）、奇数页/偶数页（范围无匹配页时提示「所选范围内没有符合的页」）。
2. 「开始」页签「导出图片」：将全部页面分别导出为 PNG 到所选文件夹。

整体用下来，PDF 转换的流程是清楚的：入口集中、步骤有反馈、做完有验证。第一次照着走一遍，后面基本就是肌肉记忆了。卡住就回看常见问题那一节。
