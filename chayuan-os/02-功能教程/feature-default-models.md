# 默认模型设置实操教程：从入口到完成每一步都有反馈

写这篇的起因是群里有人问默认模型设置，我发现自己也说不完整，索性把察元AI OS里的全局默认模型从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 先对齐一下概念

在 设置 ＞ 默认模型 里为十一类任务各指定一个默认模型——对话 / 嵌入 / 重排 / 决策 / 文生图 / 图生图 / 视频生成 / 图像理解 / 视频解析 / 语音合成 / 语音转文字，每类可选「自动」（本地优先）或指定某个本地 / 云端模型；保存后系统生成 models.md 随系统技能包自动分发给各智能体，选默认对话模型时还能一键同步写入全部 5 个智能体的配置。

润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱。

按真实界面写，按钮文案原样引用。

## 操作前的准备工作

- 有可选的模型，二选一：本地已安装模型，或已在 设置 ＞ 模型 启用过云端厂商。都没有时每类显示「无可用模型」。
- 指定云端模型时需要模型代理在运行（本机固定 127.0.0.1:52581，随模型服务自启）；代理未运行时保存会报错（见常见问题 Q1）。
- 「默认对话模型」一键同步智能体需桌面形态（浏览器形态见「形态差异」）。

## 完整操作步骤

1. 进入页面

打开 设置，左栏第二项「默认模型」。页面左右两栏：左栏是分类竖栏（十一类 + 「网络资源搜索」，中间有分隔线，后者见清单 M11，本篇不展开）；右栏是当前分类的选择区。进页默认选中「默认对话模型」。

2. 认识左栏的十一类

「默认对话模型」「默认嵌入模型」「默认重排模型」「默认决策模型」「默认文生图模型」「默认图生图模型」「默认视频生成模型」「默认图像理解模型」「默认视频解析模型」「默认语音合成模型」「默认语音转文字模型」。三类特殊口径（源码注释明确）：

1. 重排 / 决策：只列本地模型（决策类为本地专属能力，无云端对应类型）；
2. 图生图 / 视频生成：本地暂无此能力，全部列已启用厂商的对应类型模型。

3. 在右栏选择模型（两种方式）

右栏卡片标题即分类名（如「默认对话模型」），下方说明文字：「选择该分类的默认模型；保存后写入系统技能（models.md）并自动分发到各智能体。云端厂商经本地 52581 代理调用（真实 key 不出凭证库）。」 标题行右侧两个按钮：

也可以直接点选卡片内的选择树：

1. 「管理本地模型…」：跳到 设置 ＞ 模型 的该分类本地模型页（下载 / 导入 / 启动模型用）；
2. 「设置…」（蓝色）：弹出选择弹窗（下一步）。
3. 第一行「自动」单选：右侧灰字实时显示「当前自动使用：{模型}」或「无可用模型」；
4. 「本地模型」分组标题下列出本地该能力模型，等宽字体模型 id，运行中的行尾带绿点（悬停提示「运行中」）；
5. 其下每个已启用厂商一组（组头是厂商名），列出该厂商在 Harness 注册的对应类型模型（等宽字体）；
6. 分类下什么都没有时显示「该分类暂无可用模型。点击右上「设置…」去模型设置启用厂商或安装本地模型。」
7. 点行即选中（单选），此时只是暂存，要点右下角「保存并更新技能」才生效（保存中按钮变「保存中…」，成功后绿色提示「已保存，系统技能已更新并分发到各智能体」）。

4. 「设置…」弹窗（树形选择 + 立即生效）

弹窗标题「选择{分类名}」（如「选择默认对话模型」），副标题「列表 = 本地模型 + 已启用厂商；点「确定」立即生效」。结构：

1. 「自动」选项（含当前回退值灰字）；
2. 「本地模型」可折叠组：组头带本机图标、计数药丸；折叠时组头右侧显示组内选中项；运行中模型行尾绿点；
3. 各厂商组：厂商 logo 图标 + 厂商名 + 计数，同样可折叠；初始自动展开本地组和含当前选中项的厂商组；
4. 「默认对话模型」分类的弹窗底部有蓝色提示条：「确定后将同步为全部智能体（Harness / Codex / OpenCode / OpenClaw）的默认模型」；
5. 选好点「确定」＞（对话分类且非「自动」时）立即保存并同步写入 5 个智能体，成功绿色提示「已设为系统默认，并同步全部 5 个智能体」；其他分类成功提示「已保存，系统技能已更新并分发到各智能体」；
6. 同步中按钮变「正在应用…」；部分智能体写入失败时弹窗保持打开，逐项列出结果行（智能体名 + 已写入 / 具体错误，如「需要桌面形态（配置写入经桌面主进程）」），全绿才自动关闭；
7. 「取消」放弃修改。

5. 保存时系统做了什么（理解行为用）

点「保存并更新技能」或弹窗「确定」后，系统依次：

「自动」的回退规则（源码 autoResolve）：本地第一个可用模型 ＞ 云端第一个匹配类型 ＞ 都没有（无可用模型），即本地优先。

1. 云端选择涉及的厂商自动确保已加入模型代理路由（真实厂商 key 不出凭证库）；
2. 渲染 models.md：十一类「分类 | 默认模型 | 调用（模型名）」表 + 代理调用面（Base URL http://127.0.0.1:52581/v1）+ 已启用的网络搜索平台清单；
3. 落盘 defaults 文档，主进程防抖后把 models.md 作为系统技能（chatop-system）伴随文件镜像进六家智能体技能目录（dsh / Claude Code / ZCode / Codex / OpenCode / OpenClaw）——智能体读技能文档就知道每类默认模型怎么调。

## 做完后的验证

验证

1. 保存后页面出现绿色「已保存，系统技能已更新并分发到各智能体」。
2. 桌面形态下打开任一智能体技能目录核对 models.md 已更新，如 ~/.claude/skills/chatop-system/models.md（ZCode 对应 ~/.zcode/skills/chatop-system/models.md），「分类默认」表里能看到你选的模型。
3. 默认对话模型同步成功后，打开 DeepSeek Harness 对话窗，模型下拉里出现所写模型；指定了云端模型时，浏览器访问 http://127.0.0.1:52581/v1/models（免 key）能看到 <厂商id>/<模型名> 条目。
4. 把「自动」所在行的灰字与预期对照：装了本地对话模型时应显示「本地 · <模型id>」。

## 什么情况下用得上

本地装了嵌入 / 重排模型，想让知识库检索优先走本地、数据不出机；想让知识库问答、新会话、未单独配置模型的智能体统一用一个对话模型，统一团队的任务模型基线，日常轻任务走本地、攻坚任务指云端。

用户常搜的问法：怎么全局设置模型？默认模型在哪里改；『自动』的默认模型到底会用哪一个。

## 它的局限也要说清楚

用之前要认的账：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 指定模型未加载时会按策略自动拉起

## 接着回答几个常见问题

### 保存报「模型代理未运行，无法接入云端厂商（先在模型设置里确认服务状态）」？

代理随本地模型服务自启。到 设置 ＞ 模型 看页面顶部健康灯，服务恢复后回来重新保存；只选本地模型 / 「自动」不受此限。

### 默认语音合成 / 语音转文字模型影响什么？

保存后同样写进 models.md 随技能分发：语音合成对应本地 Piper / 云端 tts 类模型，语音转文字对应本地 Whisper / 云端 asr 类模型，按代理命名空间（local/<id> 或 <厂商id>/<模型>）调用。

### 「自动」到底会用哪个模型？

固定回退顺序：本地第一个可用 ＞ 云端第一个匹配 ＞ 无可用。想让某类明确用某个模型就指定它，不要留「自动」。

### 重排 / 决策为什么选不了厂商模型？

这两类树只列本地模型（决策为本地专属能力）。没有就到 设置 ＞ 模型 ＞ 本地模型 组下载（重排见模型库「重排序」分类）。

默认模型设置的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
