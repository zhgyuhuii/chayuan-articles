# 内容反馈怎么做？内容纠错反馈一次讲清

错误条目与失效链接反馈。本文以「内容纠错反馈」为主题，给出察元AI 能力广场的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：网站首页 https://aidooo.com；产品页 https://aidooo.com/products；教程库 https://aidooo.com/tutorials。系统要求总览：浏览器（桌面与移动）——现代浏览器即可，无需安装客户端；察元AI OS 客户端——安装察元AI OS。

## 通用流程（以 察元AI OS 客户端 为例）

错误条目与失效链接反馈

1. 在察元AI OS 打开「察元智能广场」应用
2. 与网页版同源同账号体系
3. 搜索结果可直接复制安装命令到本机终端执行

## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：重跑安装器即可升级到最新版，配置保留

## 相关报错速查

- 复制了安装命令但装不上？——网站只收录信息与安装命令、不存二进制：命令执行依赖原始仓库可用性；先看条目 health 状态（active/degraded/dead），degraded/dead 的条目建议寻找替代。
- 登录提示验证码错误或会话过期？——验证码区分大小写以页面提示为准；会话过期重新登录即可，收藏与投稿数据都在账号下不会丢失。
- 搜不到想要的资源？——尝试更换关键词（中英双语都试）、放宽筛选；确实未收录的资源可通过投稿页提交，进入人工审核队列；也可询问右下角机器人客服。

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。
