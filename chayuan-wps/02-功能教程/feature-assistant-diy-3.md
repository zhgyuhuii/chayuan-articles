# AI助手制作落地记：提示词自定义

自定义助手怎么新建、哪些字段必填，是问得最多的两件事。这篇按察元AI文档助手的真实界面把 AI助手制作从头走一遍：先看哪些场景值得做，再逐字段填表，最后过一遍创建时的校验与常见疑问，按钮文案原样引用。

## 哪些场景值得做成助手

把公司公文口径做成助手；想让助手固定处理选中文字或全文、固定输出 JSON/Markdown、固定写回方式（批注/替换/追加），给领导讲话稿做个专属助手；有一套自己反复用的提示词（如「按我行公文格式改写」「生成投标风险清单」），想做成一键助手而不是每次粘贴。

## 三段式走完创建流程

第一段，打开创建表单：

1. 打开 AI 助手窗格，在侧栏切到「助手」页签。
2. 点工具栏左侧的「添加助手」加号按钮，产品随之打开设置窗口（标题「助手设置」），定位在「助手设置」页的「创建智能助手」空白表单上；右栏就是配置表单，出厂默认值为：系统提示词「你是一位专业智能助手，请根据用户输入完成任务。」、用户提示词模板「{{input}}」、输出格式 Markdown、文档动作「插入到光标处」、输入范围「优先使用当前选中，无选中时回退全文」。

第二段，逐字段填写，字段含义与默认值见下表：

| 字段 | 说明与默认值 |
|---|---|
| 助手名称 | 必填；不能是「未命名助手」。留空时创建会按描述/提示词自动起名（如「合同审查助手」），重名自动加序号 |
| 助手图标 | 点「当前图标」预览打开选择器；选用外部图片会在选择时转成离线 SVG 数据存进本助手配置，之后同步显示在列表、顶部“更多”菜单和右键菜单 |
| 功能说明 | 一句话用途，显示在侧栏条目描述里 |
| 助手类型 | 分析型（对话模型）/ 图像生成型 / 视频生成型 / 语音生成型；「执行模型」下拉只显示对应类型的模型 |
| 所属分组 | 填写新分组名称即可创建分组；保存后助手显示在对应分组，组内可拖拽排序 |
| 输入范围 | 三档：「优先使用当前选中，无选中时回退全文」（默认）/「仅处理当前选中内容」/「始终处理全文」 |
| 执行模型 | 默认「跟随默认设置」；可展开按厂商分组选一个固定模型。未配置模型时下拉提示先去模型设置 |
| 智能推荐提示词 | 写下想要的能力/语气/输出方式，系统调用已配置的对话模型生成系统提示词、用户提示词模板和推荐设置并自动回填表单，仍需手动保存；创建表单上叫「智能推荐」，编辑已保存的自定义助手时入口叫「智能优化」 |
| 角色设定 | 一句角色描述（如「审校专家」） |
| 系统提示词 | 必填，不能为空 |
| 用户提示词模板 | 必须包含 {{input}}——文档内容在这里注入；可用变量：{{input}}、{{targetLanguage}}、{{assistantName}} |
| 默认目标语言 | 仅「翻译」内置助手显示此字段（如：英文、日文、法文） |
| 输出格式 | 纯文本 / Markdown / 项目符号列表 / JSON |
| 输出报告 | 开关。开启后优先按全文生成结构化报告，可再配「自定义报告类型」「报告格式」（支持 {{reportType}}、{{assistantName}}、{{targetLanguage}} 变量）与「报告提示词」（只对报告输出生效的补充口径） |
| 文档动作 | 九种写回方式，语义详见对应教程 |
| 温度 | 数值框，默认 0.3；保存校验「温度建议在 0 到 2 之间」。需要输出稳定 JSON 的助手建议调低 |
| 多模态输出偏好 | 仅图像/语音/视频类助手显示：画幅比例（如 16:9）、时长（如 30s）、音色风格（语音） |
| 显示位置 | 四个复选：顶部主菜单 / 顶部“更多”菜单 / 右键菜单 / 右键菜单的“更多”菜单；「顶部主菜单」与「顶部“更多”菜单」互斥，右键菜单位置可与任一组合 |
| 显示优先级 | 数值越小越靠前，控制在各菜单中的先后顺序；留空按系统默认顺序 |
| 快捷模板 | 报告类助手创建表单可用的预设面板，按工程、软件、教育、管理、风控、医疗、政府、制造、科研、法务等分组，支持搜索，应用后可继续微调（提示「已应用“X”快捷模板，可继续微调后创建」） |

第三段，创建并确认：

1. 填完点表单底部「创建智能助手」按钮。
2. 校验没过时消息条会写明原因：「助手名称不能为空，也不能是“未命名助手”」「系统提示词不能为空」「用户提示词模板必须包含 {{input}}」「温度建议在 0 到 2 之间」——照着改完再点。
3. 创建成功会有「智能助手已创建，并已同步到顶部“更多”菜单」的提示，左栏自动选中新助手，可直接继续编辑。
4. 后续修改：侧栏点助手条目上的铅笔「编辑助手」，或进助手管理里调，改完点「保存」；删除用垃圾桶「删除助手」（设置页右键「删除」也行）。

## 做好之后你能得到什么

- 提示词完全自定义，语气与口径随业务定
- 九种写回方式按场景挑
- 温度可调，输出的稳定性自己掌控

## 功能之外的几条边界

- 脱密占位替换可逆，但免密恢复没有留任何通道，密码一旦遗失就没有找回的路径
- AI 痕迹检查给的是参考线索，疑似不等于结论，最终判断要靠人
- 助手处理时会按选区或整篇读取文档，并送到所配置的模型；涉密材料先切到本机离线模型

## 创建环节的三个疑问

### 报错说模板必须包含 {{input}}，该写在哪里？

模板里缺了内容注入口。把 {{input}} 放到模板中模型该看到文档内容的位置（惯例是前后用 --- 夹住，参照内置助手的写法），保存即可；整个模板留空会自动回退成「{{input}}」，但写了模板又漏写变量时不会自动补。

### 创建时没起名，助手名字为什么还是有的？

名称为空时，产品会按推荐需求/功能说明/角色/系统提示词的顺序推断一个名字（推断不出就用「智能助手」），并自动去重；创建完随时可以改。

### 在表格或演示端创建助手，字段为何精简了一大截？

表格/演示宿主里创建的是宿主配方助手，字段精简为显示名称、功能说明、配方提示词、触发方式（「点击后立即发送」或「点击后预填输入框，补充要求后发送」），界面上也会提示「自定义助手请在文字（文档）宿主中创建」——要建完整字段的助手，请切到文字文档。

字段看着多，真机填一遍就知道多数保持默认即可；动手走一遍创建流程，比反复读文章快得多。
