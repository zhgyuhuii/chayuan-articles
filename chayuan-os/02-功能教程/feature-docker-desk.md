# 云桌面怎么用：手把手走一遍完整流程

用察元AI OS有段时间了，Docker 云桌面（察元AI工舱）是我用得比较多的一个功能。这篇把我积累的操作顺序和几个关键细节写出来，新手可以照着走，老手可以查漏。

## 它是什么，为谁服务

整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离、数据在服务器侧统一管理，默认只监听回环端口，暴露面自己控。

一台服务器全组使用，运维只管一处，终端零安装。

先把这个定位立住，再看步骤。

## 具体怎么操作

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 谁需要这个功能

培训机房批量部署；团队统一 AI 工位。

## 它的局限也要说清楚

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 接着回答几个常见问题

### 多少人共用一台服务器合适？

取决于是否同时跑本地模型：只做对话与知识库，十几人一台中配服务器可行；要并行跑本地推理，按并发数加内存或改用厂商模型分流。

### 数据存在哪里？

全部落在服务器的数据卷里（含用户空间、知识库、配置），挂载出来后备份一个目录等于备份全组。

### 云桌面和桌面版功能一样吗？

核心能力面一致（对话、知识库、模型、办公），形态差异在：云桌面无本地文件直通、语音输入依赖浏览器权限、部分外设在浏览器里受限。

## 能力点备忘

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 安装与运行答疑

### 检查更新失败？

更新需要联网访问官网接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

## 一个真实场景

资料重度用户的典型用法：知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载，混合检索加可选重排保证命中质量，引用式问答每个观点带编号脚注。私有资料变成可信可溯源的问答库。注意：单文件 48MB 上限，超限拆分后再传。

## 顺带了解

多用户账号管理：管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；每个用户有完全独立的桌面、知识库、记忆与模型配置。

为什么值得看：一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全。

## 还有这个能力

锁屏密码与自动锁屏：设置通用里设改清锁屏密码（留空保存即清除）、自动锁屏时限（需先设密码）、全局唤起对话快捷键、关窗驻留托盘。

## 硬口径两三条

- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商
- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness

## 如实说不足

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 桌面应用与创造模式

任何网页、本机程序、HTML 文件都能封装成桌面应用（web、local、html、file 四种类型），可放桌面快捷方式也能嵌进壁纸当小组件。创造模式更进一步：智能体在运行时定义并挂载新插件，说一句要什么应用，它能把应用造出来挂上桌面。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。

云桌面的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
