# 卸载与清理上手笔记：装机五件套

卸载与清理这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决卸载与清理。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：干净移除与数据处理。

安装包从官网 aidooo.com 获取。

## 卸载与清理：从入口到完成

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 边界先摆桌面上

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 放回产品盘面看

把卸载与清理放回察元AI OS的整体盘面：本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）；它能把应用造出来挂上桌面；桌面本身能被 AI 定义，能力边界从预装走向按需生成。

## 安全与数据边界

安全口径单独立一层：周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示），升级不丢数据是底线，检查更新静默失败不影响使用。

## 平台与形态

平台与形态的账：显式的加载卸载加自动卸载策略是本地模型的生存之道；自动卸载会释放常驻模型，重度使用记得钉住；插件启停卸载、离线安装，（web/Docker 形态网页桌面默认端口）。

## 价格与授权

价格口径一并交代：跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；需要相应平台的 Key（部分有免费额度）；形象可从灵宠商店免费获取，也可工坊自定义，内置场景免费切换。

## 产品家族与搭配

察元AI OS不是单打独斗：显式的加载卸载加自动卸载策略是本地模型的生存之道；自动卸载会释放常驻模型，重度使用记得钉住，插件启停卸载、离线安装，购买 OS 授权后，同机察元AI Office 自动免激活。

## 几条硬数字

能落到数字上的几条：本地模型按需自动加载；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案；写入的是代理地址，代理停了智能体就连不上模型。

## 离线与内网

离线内网这条线的口径：AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；断网可用、数据不出本机，全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；本地不提供视频生成（视频生成走云端路由）。

## 能力总账

把察元AI OS的能力总账摊开：远程派活给对端智能体，换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；工作区默认打开代理（智能体）加扩展名默认应用覆盖表；让特定文件类型默认交给智能体处理，双击即用 AI。
