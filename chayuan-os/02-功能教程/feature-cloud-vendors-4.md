# DeepSeek接入疑难解答：九成问题出在这几处

DeepSeek接入这件事，说简单也简单，说麻烦是真麻烦——麻烦不在功能本身，在于信息散落在各处，拼出一个完整流程要查好几篇资料。这篇文章把它一次讲全：是什么、入口在哪、具体步骤、边界在哪，全部基于察元AI OS的真实界面。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（该厂商的 API Key（厂商卡上有「获取密钥」按钮直达官网 Key 页；「免Key / 免费额度」类厂商可先试）。），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 「获取模型列表」超时或失败？

先核对 API 地址（OpenAI 兼容厂商一般以 /v1 结尾，缺了会自动补）与密钥；国内访问国际平台确认代理可用；20 秒超时提示「该厂商可能不提供模型列表端点」的，换支持 /models 的端点或手填协议重试。清单拉不下来无法启用——启用以「获取到的模型列表」为准，至少勾选一个模型。

## 正确的操作路径

1. 进入页面

打开 设置，左栏第一项「模型」。页面为双栏：左栏厂商目录，右栏选中项的配置表单；右栏顶行有「模型厂商」标签和侧栏开合按钮（窄窗下侧栏收进抽屉）。

2. 在左栏找到厂商

1. 左栏最上方是「本地模型」组；厂商目录在其下方。
2. 厂商按四组折叠排列：「国内平台」「国际平台」「本地与自建」「API 聚合」（默认全部折叠，点组头展开）；此外还有「外部路由」（从 Harness 侧配置进来的）与「自定义」（你自己加的）两组，出现时置顶。
3. 组内排序：已开启 ＞ 已配置密钥 ＞ 其余。行尾标识：已开启 = 实心绿点；已配置密钥未开启 = 绿色「已配」徽标。
4. 顶部两个过滤器：
    1. 免费过滤下拉：「全部 / 免Key / 免费额度」——「免Key」= 完全不需要密钥（绿徽标），「免费额度」= 注册即得或有限度额度（蓝徽标）；
    2. 搜索框（占位文案写的是「搜索 66 家厂商…」，实际内置 85 家——文案数字滞后，以目录实际为准）。

3. 点选厂商卡，看状态行

右侧表单顶部：厂商 logo + 名称 + 状态行（三态）+ 右侧启停开关：

1. 「已开启 · 显示在 Harness 模型下拉框」（绿字，开关已开）；
2. 「已配可用」（绿字，密钥已配置但未开启）；
3. 「未开启」（灰字）。

## 怎么确认做成了

验证

1. 启用后：厂商卡状态行变为「已开启 · 显示在 Harness 模型下拉框」，左栏该厂商行尾出现实心绿点并排到组首。
2. 打开 DeepSeek Harness 对话窗：模型下拉框出现勾选的该厂商模型（实时生效）。
3. 已「加入代理」时：访问 http://127.0.0.1:52581/v1/models（免 key），清单出现 <厂商>/<模型名> 条目。

## 进阶用法与边界

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用
- 边界：云端调用需自备 Key，费用按厂商政策
- 边界：断网时云端模型不可用，可设自动回落本地

## 你可能会问

### 以前在 Harness 里单独配过 DeepSeek 官方 Key，要重新配吗？

不用。打开 DeepSeek 卡时旧 Key 会自动预填进密钥框（回显为空但输入框有值），点一次「保存并启用」即完成迁移到统一卡；迁移后旧官方路由的地址/密钥位自动清理。已配置过的用户状态行照常显示启用。

### 密钥存在哪里？会被写到智能体配置里吗？

密钥只存本机 ~/.dsh/.credentials.yaml（harness 凭据管理）。经模型代理的调用不携带真实厂商密钥（免 key 直连、匿名归因）；只有「直接应用…」的厂商直连路径会按需引用凭证库。

### 厂商上新了模型，下拉框里没有？

模型清单来自「获取模型列表」的快照，不会自动刷新。回到该厂商卡再点一次「获取模型列表」，勾选新模型后「保存更改」即可。

## 补充答疑

### 「停用」会删掉配置吗？

不会。提示「已停用，配置保留可随时恢复」——地址、密钥、模型清单都保留，重新开启即恢复；Harness 下拉框里的该厂商模型即时消失。

### 想先免费试试，选哪家？

免费过滤下拉选「免Key」或「免费额度」；带绿徽标「免Key」的完全不用密钥，蓝徽标「免费额度」的注册即得（如 Agnes：注册即得免费 Key，文本 Flash 与图像生成免费）。

### 开关打开了又弹回去 / 状态行和实际不符？

启停状态优先读 harness 运行时回显；个别旧版本 dsh 网关读回不可达时以本页快照记录的启停动作为准，可能出现显示不准。升级桌面版本后恢复准确。

## 更多操作细节

4. 填表单（逐字段）

1. 「API 地址」：预填该厂商默认地址（如 DeepSeek 为 https://api.deepseek.com），可改。结尾缺 /v1 会自动补全（Anthropic 协议不做该补全）。目录里带文档链接的厂商，字段下方显示「文档: <url>」。
2. 「协议」下拉，三选一：OpenAI Chat Completions（绝大多数厂商）/ Anthropic Messages / OpenAI Responses，按厂商文档选。
3. 「API 密钥」：粘贴 Key。字段标签随状态变化——已配置过显示「API 密钥（已配置 已回显）」，输入框自动回显旧值且占位提示「已回显，修改后保存替换」（不改就不重写，保持文件层原值）；「本地与自建」组的服务（如 Ollama）显示「API 密钥（本地服务可留空）」、占位「本地服务通常无需密钥」。密钥输入框旁：「获取密钥」跳官网 Key 页（有配置的厂商才有）；「显示 / 隐藏」切换明文。

5. 「获取模型列表」

点「获取模型列表」（按钮变「获取中…」）：

1. 成功：绿色提示「已获取 N 个模型」，下方出现模型清单——按类型分组（对话模型 / 图像理解 / 嵌入模型 / 图像生成 / 视频生成 / 语音生成 / 语音识别…），组头「<类型> · 数量」+ 组级「全选 / 取消全选」；对话与图像理解类默认勾选，其余默认不勾。清单顶部有「全选 / 全不选」总开关。获取到的清单立即落本页快照，切走再切回不丢。
2. 失败：红色「获取失败: <原因>」；20 秒无响应提示「获取超时（20s）：该厂商可能不提供模型列表端点」。清单为空时显示「暂无模型 — 填写地址后点击「获取模型列表」」。

6. （可选）「测试连接」

点「测试连接」（按钮变「测试中…」）：通过显示绿色「连接成功，端点可用」；失败显示「连接失败: <原因>」。
