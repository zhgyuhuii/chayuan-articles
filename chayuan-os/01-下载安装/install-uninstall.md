# 卸载与清理上手笔记：装机五件套

卸载这件事的麻烦不在点卸载按钮，在于数据散落几处、删完还留尾巴。这篇按卸载与清理的实际顺序整理一遍：先把数据安置好，再谈干净移除，口径来自察元AI OS。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：干净移除与数据处理，卸载前后的动作都算在内。

安装包仅从官方渠道获取，其它来路的包没有完整性保证。

## 先装上才有得卸：主线步骤

1. 从官方发布渠道按架构下载 exe 安装器，装好后文再试卸载
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 卸载前先安置数据

动手卸载前先想清楚数据去向：数据目录自选的安装，整个系统连同数据都收在你指定的目录里，换机时把目录原样带走即可；确定不要了，先备份知识库、对话记录这类还有用的东西，再执行清除。清除桌面数据是破坏性操作，界面会给警示，看到警示停下来再确认一遍，不亏——误删的目录没有任何后悔药。

## Windows 侧的卸载路径

Windows 下从设置＞应用＞安装的应用里找到对应条目点卸载，NSIS 打包的安装器自带卸载程序，走系统入口触发即可。卸载的是程序本体，数据目录是否保留取决于卸载时的选项，拿不准就先保留，回头确认没遗漏再手动删，这一步的谨慎怎么强调都不过分。

## 残留清理的顺序

清理残留按先目录后启动项的顺序来：先看数据目录、安装目录是否还有剩余，再检查开机启动项里有没有遗留条目。第三方一键清理工具不建议用在这类系统上，误删数据目录的代价远大于省下的那几下点击；注册表项交给系统卸载程序处理，手动改注册表收益小风险大。

## 删干净和删安全的平衡

清理的尺度因场景而异：交接给下一任使用者的机器，数据和配置要删到无法恢复才算干净；只是换台机器自用，数据目录打包拷走比逐项导出省事。公共环境的机器卸载后最好把浏览器侧的会话痕迹也过一眼，云桌面形态里的 wa 会话管理与踢线操作就是为这种场景准备的。

## 插件和模型分开算账

卸载主体程序前，插件和模型是两笔独立的账：插件在系统里启停卸载、支持离线安装，卸载主体前先把还在用的插件列个清单，新机装回去快；本地模型占的空间大，模型文件跟随数据目录走，主体程序卸载不影响它们，重装后按直链目录放置再执行扫描即可重新入库。

## 动手卸载前的几条认知

- Docker 云桌面、跨终端互联这类进阶形态，动手门槛稍高
- 内存 8GB 的设备建议同一时间只加载一个对话模型，复杂任务受限
- 龙芯平台暂无版本；本地不做视频生成，该能力走云端路由
- 云端厂商模型调用要自带 API Key

## 桌面当壳与数据清除

本机算力单薄、远端算力充裕的场合，桌面端退居壳层角色，重活交给远端；遥测有开关，清除桌面数据是带警示的破坏性操作；它还能把应用造出来挂上桌面，桌面本身可被 AI 定义，能力边界从预装走向按需生成。

## 巡检与升级的口径

周期巡检、每天早报、定时盯数据，这类例行差事交给它正合适，第二天早晨直接看结果；升级不会动用户数据，这条是底线，检查更新哪怕静默失败，也不影响手头功能。

## 插件与模型的启停

本地模型要显式地加载与卸载，自动卸载策略在背后托底；自动卸载会释放常驻模型，重度使用记得钉住；插件启停卸载、离线安装；web 和 Docker 两种形态的网页桌面都落在默认端口上。

## DDS 与平台 Key 的口径

跨终端互联（DDS）出厂零共享；云端调用需要相应平台的 Key（部分有免费额度）；形象可从灵宠商店免费获取，也可工坊自定义，内置场景免费切换。

## 虚拟 Key 与调用审计

本地模型按需自动加载；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案；写入的是代理地址，代理停了智能体就连不上模型。

## 断网下的定位

定位上它是一套 AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊都收拢在一个桌面里；断网可用、数据不出本机；全部本地服务默认只对 127.0.0.1 回环地址开放监听。

## 默认应用与远程派活

远程派活给对端智能体；接班的智能体不用从头再做一遍自我介绍，记忆在整机范围内共享；工作区默认开启代理（智能体），扩展名默认应用覆盖表也一并生效；把某类文件类型的默认打开方式指给智能体，双击就进入 AI 处理流程。

卸载与清理做干净的标准是：目录、启动项、数据各归各位，要删的删净、要留的留全，这台机器才算回到清爽状态。
