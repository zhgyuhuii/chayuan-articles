# 认识国产办公软件：它解决什么问题、怎么选

聊国产办公软件之前先划重点：它不是单一功能，而是一套带入口、步骤和验证的完整流程。察元AI Office在这件事上的设计思路是把入口收拢、把步骤做实、把边界说清，理解了这个，操作就顺了。

## 什么是国产办公软件

察元AI Office（Chayuan AI Office）是开源（Apache-2.0）的 AI 办公套件，从官方网站 aidooo.com 或 GitHub Releases 下载安装包，覆盖 Windows、macOS、Linux（含麒麟/UOS 信创环境）。第一次启动会进入主页并自动弹出三页欢迎引导（欢迎 / 社区反馈 / 人人免费），看完或点「跳过」即可开始使用。

放到察元AI Office的语境里：开源 AI 办公套件，六编辑器一体，AI 嵌进每个编辑器，下载安装与首次启动是其中承上启下的一环。

## 先看看痛点对不对得上

开源办公套件能离线装、信创环境能跑，是替换传统办公链路的第一步。

典型使用场景：政企内网批量装机，个人替换订阅制办公软件。

## 常见问题

### 麒麟/UOS 上装哪个包？要联网吗？

选 .AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb。下载一次后可拷贝到内网机器直接安装/运行，应用本体不依赖联网。

### 欢迎引导被我关掉了，想再看一遍怎么办？

引导只出现一次，界面不提供「重看引导」入口。想系统了解产品，按 F1 打开内置图文手册（18 主题，可搜索），见产品内的对应手册。

### 第三方下载站 mirror 的安装包能用吗？

不能保证。官方分发只有 aidooo.com 与本仓库 GitHub Releases 两处，其余站点均非官方分发，存在被篡改风险，请从官方渠道重新下载。

### 90 天试用到期会锁功能吗？要注册账号吗？

不锁功能。到期后每日一次温和提醒（可关闭），不购买也完全不影响使用；购买走离线短序列号，内网无激活服务器也能激活。使用 AI 的云端能力需在设置中配置模型或登录账号，见产品内的对应手册产品内的对应手册。

## 安装与运行答疑

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

## 硬口径两三条

- 六编辑器：docx/xlsx/pptx/真文本 PDF/Markdown/HTML（web/dsh 形态为五编辑器）
- Docs 端 4576 个领域助手、229 个领域包，全库约 4600 个；表格 102、演示 100、PDF 100、Markdown 100、HTML 130

## 如实说不足

- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- web/dsh 形态只有五编辑器（无 HTML），且无购买激活界面
