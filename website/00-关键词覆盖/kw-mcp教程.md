# MCP教程是什么：MCP 板块收录 MCP 服务器资源

MCP教程写过不少，但值得先问一句：断网了这套东西还能干什么。本篇就沿这个问题，把门户的能力面与边界一次说清。

## 什么是MCP教程

MCP教程这个说法对应的产品是察元AI 能力广场：智能体门户，插件、技能、MCP、提示词、大模型资源一站检索与下载。

以上口径整理自官方文档，版本对应关系见文末。

## 在能力广场里落在哪

MCP教程在这个门户里的落点是MCP 板块：MCP 板块收录 MCP 服务器资源，数据来自多源采集（awesome-mcp-servers、Smithery、mcp.so、官方 registry 等 11 个源），去重后统一展示，可按分类与关键词检索，安装方式随详情页说明。

为什么值得单独说：MCP 生态扩张太快，一个持续同步的导航比收藏夹可靠。写 MCP 相关教程时，这一层等于替你把源清单维护好了，跟住板块更新即可。

## 上手六步

上手路径六步：

1. 弄清数据来源：11 个源采集后统一去重
2. 熟悉组织方式：按分类与关键词检索
3. 了解榜单维护：失效资源自动剔除出榜
4. 场景验证：给智能体找数据库 MCP
5. 场景验证：找浏览器自动化 MCP
6. 串联场景：在 MCP 板块完成一次完整检索

## 挑服务器的一些手感

- 先按场景收窄，再看热度：榜单参考 GitHub star 快照排序，但高星不等于适合你。数据库类的要对着自家数据库类型挑，浏览器自动化类的先想清楚你要的是截图、抓取还是页面操控，目标不同候选完全两样
- 详情页的安装配置说明整段读完再动手：配置写进客户端前改一处验一处，出错时才知道是哪一处引起的
- 一轮没找到就换关键词再来：同领域的实现往往不止一个，换个叫法常常多出几个候选，比死磕一个近似的凑合用强

这些算不上秘诀，只是少走弯路的经验。仓库新旧混杂是这个生态的现状，靠导航收窄范围、靠自己验证收尾，比在收藏夹里堆链接踏实得多。

## 哪些人先不必急着用

这个板块不是人人必需，两条边界说在前头：

- 想系统读教程正文的人：教程库只登记元数据和跳转链接，正文仍留在源站，不在广场内展开
- 不想注册的人：下载资源前需要完成登录，站内账号或微信扫码二选一

这两条都不拦着检索主线，提前知道，省得用到一半才发现。

## 收藏、审核与安装包

- 收藏上限 200 条，攒一套常用 MCP 清单够用
- 投稿与需求墙内容，审核通过才上架
- 安装包由管理后台同步生成下载清单，官方分发渠道仅此一处

## 常被问到的三个问题

### 榜单里失效的资源会一直挂着吗

不会。榜单依赖 GitHub star 快照做参考，资源一旦标记 dead 或 archived，会自动从榜里剔除，减少点进去扑空的情况。

### 哪里能看哪些模型有免费额度

厂商页收录已核验的模型厂商与网关，促销与免费额度可以按条件筛，另有免费模型榜可对照；选模型看目录比看宣传稿靠谱，参数和价格能放在一页对比。

### 模型对比最多能同时看几个

最多 6 个并排。模型智力排行按五维度综合评测，每维度 0-100 百分位、总分取五维等权均值，另含改提示词与模型选型指导。对比时把候选模型和自家常用提示词一起测，比只看总分更有参考价值。

## 收尾一句

MCP教程要不要跟进，拿你的实际需求套一遍上面的口径与边界：套得上的，值得花时间；套不上的，跟风没有意义。

## 找一个 MCP 服务的完整走法

1. 进智能广场，点 MCP 板块
2. 输入领域关键词（如 github、搜索、数据库）
3. 看详情页的安装配置说明
4. 复制配置到你的 MCP 客户端

第二步的关键词尽量贴场景，查数据库类就直接写数据库；第四步复制前把字段对一遍，各家客户端的配置格式偶有差异，照详情页说明走最稳。

## 广场上的其他板块

MCP 之外，察元AI 能力广场还有几块拼图。导航上的智能广场分三栏，资源类型装了就用，覆盖智能体、MCP、插件、技能、教程库、提示词、技能包：

- 教程库：另含 4526 篇内置助手教程，按 228 个行业领域分目录，四千多个助手怎么选怎么用，每篇教程就是一份说明书；条目只存元数据与跳转链接、不搬正文，无 GitHub 数据的按本站下载量混排
- 提交作品页：把你的插件、技能、MCP 等资源投给广场上架，填名称、主页地址、图标外链与分类说明
- 技能与智能体应用：技能是智能体的操作手册，装了技能的智能体才会按你的流程干活；智能体应用板块收录可直接使用的形态资源，配合产品使用或独立运行，从工具到成品智能体，拿来即用省去搭建

## 离线部署与购买口径

资源可单独装，也可打包成技能包批量部署；一次购买可装进八款智能体，支持断网离线安装。回到开头那个问题——断网场景下，离线安装这条链路是明确支持的。
