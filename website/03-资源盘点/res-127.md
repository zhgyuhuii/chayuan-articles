# 能力广场专题｜安全类插件盘点

安全类插件盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：Harness 插件板块（Harness插件）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**Harness 插件板块**：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。

1. 首页 ?k=plugin 或导航进入板块
2. 按分类/标签/排序筛选
3. 打开详情复制一行安装命令

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 常见问题
### 智力榜的分数哪来的？

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 怎么订阅模型活动？
