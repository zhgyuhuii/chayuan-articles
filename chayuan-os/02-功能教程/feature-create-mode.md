# 创造模式上手指南：照着做十分钟跑通

这篇文章没有虚的，全是创造模式的实操细节：入口路径、按钮原文、做完后的界面变化，以及我踩过的坑。基于察元AI OS当前版本。

## 它是什么，为谁服务

智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用，它能把应用造出来挂上桌面。

桌面本身能被 AI 定义，能力边界从预装走向按需生成。

按真实界面写，按钮文案原样引用。

## 从打开到做完的每一步

试一次创造模式

1. 打开对话应用进入会话
2. 描述你要的应用：做什么、放哪里、多久更新
3. 智能体定义并挂载插件，权限门确认后生效
4. 桌面出现新应用，可继续让它迭代

迭代与沉淀

1. 对着新应用提修改意见，智能体原地升级插件
2. 满意后保留挂载，不满意右键卸载
3. 把好用的话术存进用户记忆，下次直接复用

## 什么情况下用得上

让 AI 造一个盯竞品的应用，快速原型化内部小工具。

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 适合造什么样的应用？

信息聚合展示类（盯价格、汇总新闻）、简单工具类（倒计时、随手记）最合适；重度数据处理建议走正规插件开发。

### 智能体造应用时要授权吗？

挂载插件属于系统级操作，会过权限门确认；高危动作（跑终端、装依赖）按 T1/T2 分级再确认，全程留审计。

### 创造模式生成的应用稳定吗？

生成的是标准 dsh 插件结构，挂载后与其他插件同等对待：可启停、可卸载、可随会话迭代。复杂逻辑建议拆成多轮对话逐步逼近。

## 能力点备忘

- 运行时定义插件
- 即造即挂载
- 产物可留存复用

## 安装与运行答疑

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

## 一个真实场景

学生与科研人员的典型用法：本地模型零边际成本对话，知识库导入课件论文做引用式问答，知识图谱梳理论文实体关系。零 API 成本的学习与科研工作站。注意：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 顺带了解

桌面小组件：桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件。

为什么值得看：信息上桌，抬眼就看到时间天气日程。

## 还有这个能力

默认应用与打开方式：工作区默认打开代理（智能体）加扩展名默认应用覆盖表；文件右键设为默认。

## 如实说不足

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

- 127.0.0.1:52581（OpenAI 兼容统一模型代理）

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 桌面应用与创造模式

任何网页、本机程序、HTML 文件都能封装成桌面应用（web、local、html、file 四种类型），可放桌面快捷方式也能嵌进壁纸当小组件。创造模式更进一步：智能体在运行时定义并挂载新插件，说一句要什么应用，它能把应用造出来挂上桌面。

## 系统级工具的控制面

实测 86 个 MCP 工具覆盖窗口管理、嵌网页、截图、文件、系统设置与搜索等能力（2026 年 10 月口径）。智能体对一个桌面能做的事，基本等于一个熟练用户能做的事；所有高危动作过三级权限门，审批超时自动拒绝，全程写审计日志。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 云桌面形态

整套系统可无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离，数据在服务器侧统一管理。默认只监听回环端口，暴露面完全自己控制，适合团队统一供给算力与知识库。

## 统一模型代理的用法

全部模型走一个本机回环地址（127.0.0.1:52581）对外服务：OpenAI chat、responses 与 Anthropic messages 协议互转，对话、嵌入、重排、语音端点齐备。智能体和其他软件只需指向这一个地址，本地模型没运行会自动拉起，厂商请求自动转发云端。

创造模式的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
