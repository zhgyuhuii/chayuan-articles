# 表单辅助填报速查手册：从入口到完成的完整流程

智能填报是察元AI文档助手里使用频率很高的一项能力。它的「表单辅助填报」这样工作：编审页签的填报向导：按模板字段逐项引导填报，降低书签字段遗漏率，提交前可预览格式问题。这篇速查手册从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

编审页签的填报向导：按模板字段逐项引导填报，降低书签字段遗漏率，提交前可预览格式问题。

从任务视角看，它对应的关键词是「智能填报」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 打开模板文件进入表单模式
2. 按向导逐字段填写（支持从知识库带出）
3. 提交前用「表单内容预览」检查格式问题

## 适用场景

- 机关报表填报
- 标准格式申报材料填写

## 实用技巧

- 配合规则制作可实现「填完即审」

## 注意事项与边界

- 本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）

## 常见问题
### 察元AI文档助手是什么？

一款 WPS 文字智能加载项（jsaddons），在 WPS 内提供 AI 对话、校对审查、表单填报与正文写回，同时内置本机 MCP 文档智能体服务，可被 Claude Code、Codex、Cursor 等外部智能体调用，支持离线/内网模型。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。

### 什么是 MCP 文档智能体服务？

加载项内置的本机服务（46 工具/15 域），外部 AI 编程工具（Claude Code、Codex、Cursor 等）连上后可直接打开、读取、修改、批注本机 WPS 文档，写操作默认只预览、传 confirmed:true 才落盘。
