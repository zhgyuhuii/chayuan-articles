# 多列表落地记：下午三点提醒跟进

「提醒事项怎么用？怎么建多个列表」——这个问题最近被问了好几次。答案不复杂：多列表在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 解决什么痛点

按项目分列表；任务做完勾掉、定期清已完成项，保持清单干净；想按项目/生活场景分成多个清单（如「工作」「读书」），各自配色和图标，下午三点提醒跟进。

## 实操全过程

5. 任务行操作（悬停出现）

1. 完成/取消完成：点行首圆圈，完成后文字划线变灰；
2. 日期：任务文字下方显示日期标签——今天蓝色、已过期红色、未来橙色；文案为「今天」「明天」或「X月X日」；
3. 悬停任务行右侧出现四个按钮：
    1. 日历图标：「设为今天」（已设为今天时为「从今天中移除」）；
    2. 日历+图标：「安排日期」——打开系统日期选择器改期或清除；
    3. 旗子图标：「旗标」/「移除旗标」（旗标任务计入「旗标」筛选卡）；
    4. 垃圾桶：「删除」——该任务连同其子任务一起删除。

6. 子任务与分区（智能体写入）

任务若带有子任务，行尾出现展开箭头（「显示子任务」/「隐藏子任务」），子任务同样可勾选/删除（「删除子任务」）。应用界面没有添加子任务和分区的入口——它们由智能体经 reminders_create（支持 section 分区参数）等工具写入后自动上屏，界面负责展示与勾销。

7. 重命名列表、搜索与已完成管理

1. 重命名：在列表视图（非筛选视图）点主区大标题（悬停提示「点击以重命名列表」）＞ 标题变输入框，回车或点空白保存，Esc 取消；
2. 搜索：右上「搜索」框按文字即时过滤（跨全部列表，结合当前筛选/列表）；
3. 已完成：标题下方显示「{n} 个已完成」+「清除」链接（清除 = 删掉当前视图的全部已完成任务；筛选视图下清全部列表的已完成，列表视图下只清当前列表）；右上角「隐藏已完成」/「显示已完成」切换显示，旁边大数字为当前未完成数。
4. 边栏开合：侧栏「隐藏边栏」收起后，主区工具栏左侧出现「显示边栏」按钮恢复。
5. 空清单时显示「暂无提醒事项」「添加项目或更改搜索/筛选条件。」。

## 这些坑和边界要知道

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 高频疑问

### 到了日期会弹通知吗？

不会。提醒事项是清单工具，当前版本没有到点通知联动；需要时间点提醒可在日历建事件，或让智能体用常驻任务等方式跟进。

### 列表能改颜色/图标吗？重命名在哪？

新建时的颜色/图标在创建后没有修改入口；名称可以改——在列表视图点主区大标题直接改（提示「点击以重命名列表」）。

### 默认列表「提醒事项」能删吗？

不能，右键它也没有菜单；只有自建列表可删，且删除会连带其中所有任务（有确认框）。删除前想保留内容，先把任务在别处重建。

## 更多操作细节

1. 认识界面

窗口分两栏：左侧边栏（顶部红绿灯 + 「添加新列表」「隐藏边栏」两个圆形按钮，下面是筛选卡与列表）；右侧主区（顶部工具栏：「共享」「新建列表」「添加提醒」按钮组 + 「搜索」框；中间是大标题任务清单；底部是常驻添加栏）。

## 更多操作细节

2. 用智能筛选看任务（五张卡）

左侧边栏 2×3 网格五张卡，点哪张就切换到哪个视图（卡上大数字为计数，选中卡有白圈高亮）：

再点同一张卡不会退出视图；要看某个列表就点下方列表项（自动退出筛选视图）。

| 卡片 | 统计口径 |
|---|---|
| 「今天」 | 未完成且日期 = 今天 |
| 「已计划」 | 未完成且设置了任意日期 |
| 「全部」 | 全部未完成 |
| 「旗标」 | 未完成且打了旗标 |
| 「已完成」 | 已完成 |

## 更多操作细节

3. 新建列表

默认只有一个名为「提醒事项」的蓝色默认列表，不可删除；自建列表行尾悬停出现垃圾桶按钮（提示「删除列表」，确认框「确定要删除列表“XX”吗？」），删除列表会连同其中所有任务一起删掉；右键列表也会弹出「删除列表」菜单项。

1. 点侧栏「添加新列表」按钮（或主区工具栏「新建列表」按钮）＞ 弹出「新建列表」对话框；
2. 「列表名称」必填；「列表颜色」七选一（蓝/红/橙/黄/绿/紫/棕）；「列表图标」八选一（列表/心形/星形/三角形/胡萝卜/书本/太阳/叶子，悬停显示名称）；
3. 点「创建」＞ 列表出现在「我的列表」下并自动选中；点「取消」放弃。

## 更多操作细节

4. 添加提醒（带日期）

在「今天」或「已计划」筛选视图下直接添加时，新任务自动带上今天的日期，且落入默认列表「提醒事项」。

1. 底部添加栏输入框（占位「添加提醒事项…」）输入文字，回车即添加到当前列表；
2. 要带日期：输入前点栏内日历图标（提示「设为今天」）快速定到今天，或点旁边的日历+图标（提示「选择日期」）打开系统日期选择器任选一天（YYYY-MM-DD）；选好后输入框右侧出现日期药丸（今天为蓝色、其他日期为橙色，点 × 清除）；
3. 主区工具栏「添加提醒」＋按钮 = 把焦点聚到底部输入框。
