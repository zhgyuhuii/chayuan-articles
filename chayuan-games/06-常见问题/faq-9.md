# 察元竞技场和察元AIOS什么关系

察元AI 旗下的产品名越攒越多，察元竞技场和察元AIOS的关系就成了高频疑问：一个是独立开源仓库，一个是操作系统里的内置应用，它们是同一个东西的两件马甲，还是两套货色？答案其实是第三种：家族成员，引擎同构，安装独立。这篇按关系、家族、协议、选择四个层次讲，顺带把家族其他成员也点一遍名，帮你建立全景，在只装竞技场和上完整 OS 之间做选择——选错了也不亏，两边都免费；看完全篇，这段关系一张名片就能记住：竞技场，察元AI 出品，OS 里有一个，独立装也有一个。

### 察元竞技场和察元AIOS是什么关系

一句话：察元AI OS 内置了同款竞技场，独立版则是单独打包的桌面应用。两边的引擎层逐字节同构，玩法规则、裁判逻辑、模型接入方式完全一致；差别在载体，一个住在察元AI OS 里跟其他应用作伴，一个单独安装、单独运行。简单说，竞技场从 OS 里长出来，又长出了独立的身体，两边共享同一颗心脏。同构保证的是公平：同一局棋在两边打，过程和结果应该分毫不差。你在哪个里下棋，棋盘对面跑的都是同一套引擎逻辑，胜负判定、容错链、天梯算法都一样；看到这里，「马甲说」可以退休了，它们不是马甲，是同一颗心脏的两次安装。

### 察元AI OS 是什么，这个家族还有谁

察元AI OS 是一个开源的 AI 操作系统，AGPL-3.0 协议，竞技场是它的内置应用之一，你在 OS 里打开的竞技场，和这篇聊的独立版，玩的是同一套东西。家族成员还有几口：察元AI Office，Apache-2.0 协议；察元AI 文档助手，也是 Apache-2.0；察元AI工舱，GPL-2.0；以及察元AI广场 aidooo.com，官方入口，产品介绍和下载都从这里走。竞技场本身是 MIT 协议，开源仓库叫 chayuan-game，Electron 安装后的产品名叫察元AI游戏。这些产品各管一摊场景，名字里都带察元AI，认准后缀就不会认错；各成员的开源协议都写在各自仓库首页，动手前看一眼；办公、文档、工位、门户、棋局，家族里各管一摊，谁也不抢谁的戏。

### 引擎层逐字节同构，是什么意思

字面意思：独立版的引擎代码和察元AI OS 内置版的对应层保持逐字节一致，仓库里有 sync-check 这道护栏专门盯着，每次同步都校验，一旦出现偏差就会被拉回。对你的实际意义是零迁移成本——今天在独立版里玩的玩法规则，明天在 OS 内置版里原样成立，不存在「两个版本规则不一样」的踩坑点；你在社区里讨论棋局时，也不用先确认对方用的是哪个版本。这层保障平时感知不到，出了问题才知道它值钱。同构护的是一致性，不是功能锁，两边的功能照常各自迭代；同构是工程上的硬约束，不是文档里的口头承诺，护栏兜着这件事。

### 不装察元AI OS，能只装竞技场吗

能，这正是独立版存在的意义。安装包从官网 aidooo.com 或开源仓库 github.com/zhgyuhuii/chayuan-games 拿，装完就是完整的竞技场体验，11 款玩法、模型配置、天梯复盘一样不少，不依赖察元AI OS 的任何组件；独立版不注册账号、不绑定设备，装上就是你的；装完打开就是大厅，配好模型直接开局，没有引导性付费环节。反过来，装了察元AI OS 的用户不必再单独装一份，系统里自带。两种形态面向两种需求，互不强求，也互不绑定；判断方法简单：看你要不要 OS 的其他能力，只要棋就独立版。

### 两边的开源协议一样吗

不一样，这是要留意的差别。独立竞技场是 MIT 协议，宽松，允许你自由使用、修改、再分发，拿去做自己的对局服务也在许可范围内；察元AI OS 是 AGPL-3.0，Copyleft 属性强，衍生服务需要按协议开源。MIT 的宽松和 AGPL 的强 Copyleft 是两种哲学，前者求传播，后者求反哺开源社区。玩棋、改棋、自用，两个协议都欢迎；做对外服务，先读协议全文再动手，分享项目给别人的时候也要注明各自的协议，别凭感觉选；如果你只是普通玩家，这一节记住结论就够：都能免费用，都能自己改。

### 独立版和内置版，玩起来有差别吗

玩法层面没有差别，引擎同构保证了这一点。差别在生态位：独立版轻，装得快，适合只想玩棋的人；内置版长在察元AI OS 里，跟系统里其他 AI 能力挨着，能边跑别的边观战，这是载体带来的差别，不是引擎的差别，适合本来就需要一套 AI 操作系统的用户。数据方面也说在前头：两个安装各自记档，别指望自动同步，想把对局带走，用棋谱 JSON 导出自己搬，这是两边通用的格式，搬过去接着分析不费劲；两边的更新节奏可能不同步，以各自仓库的发布为准。

### 我该选独立版还是 OS 内置版

按需求选。只想看大模型下棋打牌、手头机器不想多装东西，独立版，轻装上阵，硬件紧张的机器尤其优先它，OS 全家桶对资源的要求更高；本来就在物色一套开源 AI 操作系统、顺手想玩竞技场，那直接上察元AI OS，竞技场是附赠的场馆。两边都免费，切换成本只有下载时间；拿不定主意就从独立版进，熟悉之后需要 OS 时再上全家桶，进阶路径顺滑。规则同构意味着选择不是站队，以后想换形态，熟悉感也跟着你走，两边都装也不冲突，一个当轻量馆，一个当主场馆；家里多台设备的话，一边一台也是常见摆法，并行不悖。

家族成员、引擎同构、安装独立，三个词概括了这段关系。竞技场借察元AI OS 证明了自己能住进一套操作系统里当场馆，OS 也借竞技场展示了内置应用的成色。至于你，从轻的那头进也好，从重的那头进也好，棋盘是一样大的，规则是一套的，玩就是了。记不住逐字节同构没关系，记住两边玩的是同一个游戏就行；选型的纠结时间，通常不如打一局棋长。
