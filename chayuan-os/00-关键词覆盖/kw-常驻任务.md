# ：常驻任务概念与上手

搜常驻任务的人通常带着两个问题：是不是噱头、值不值得装。这篇不站队，定义、口径、边界三段摆开，你自己对号。

## 什么是常驻任务

常驻任务不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

全部口径出自aidooo.com官方文档，版本对应关系见文末。

## 在察元AI OS里落在哪

常驻任务在察元AI OS里的落点是常驻任务：设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，按每 N 分钟或每天定点执行，每次产出 markdown 报告落盘归档，历史可查，支持立即运行、暂停；配合预授权窗口可夜间自动放行指定工具。

为什么值得单独说：周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 任务失败，通知里只说「失败」，细节哪里看？

三处任选：任务行 悬停状态、「历史」里的错误摘要、~/always-on/ 报告的「失败原因」小节全文。

### 直跑任务报「未配置模型」？

任务没指定模型、且 设置 ＞ 默认模型 里也没有默认对话模型。二选一：在任务表单「指定模型」，或按对应教程配好默认对话模型。

### 智能体方式支持哪些智能体？别的家行吗？

当前仅 Codex / Claude Code / OpenCode 三家支持无人值守执行（表单下拉也只列这三家）。选了不支持的类型任务会直接失败并留报告。

### 卸载会删掉我的数据吗？

卸载程序不移除数据目录，重要数据卸载前自行备份即可；要彻底清理就手动删数据根目录。

### 常驻任务要联网吗

联网环境下内置 web_search 工具默认走 DeepSeek 搜索；设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关；常驻任务倒计时可见。以官网 aidooo.com 当前页面为准。

## 更多操作细节

第 2 步 · 逐字段填新建表单（弹窗标题「新建常驻任务」）

点「保存」；校验不过（名称空/指令空/排程超范围）会在页内提示「名称/指令/排程不合法」。

| 字段 | 是什么 / 怎么填 | 默认值 |
|---|---|---|
| 任务名 | 占位符「任务名（如：每日晨报）」，用于列表、通知与报告文件名 | 空（必填） |
| 任务指令 | 占位符「任务指令（每次运行发给模型的提示词）」，每次运行原样发给模型 | 空（必填） |
| 排程 · 模式 | 下拉二选一：「每 N 分钟」或「每天定时」 | 「每 N 分钟」 |
| 排程 · 数值 | 模式为「每 N 分钟」时填分钟数（1–10080，即最短 1 分钟、最长一周）；「每天定时」时填 HH:MM（切到该模式时自动预填 08:00） | 60 |
| 执行方式 | 下拉「执行方式：选智能体无人值守跑（完整智能体能力），或留空=模型直跑」：留空=「模型直跑（不经过智能体）」，或选 Codex / Claude Code / OpenCode | 「模型直跑（不经过智能体）」 |
| 模型 | 与建宠同款选择器：「自动（本地已装对话模型）」（=用全局默认对话模型）或「指定模型」（厂商＞类型＞模型树） | 「自动（本地已装对话模型）」 |
| 工作区 | 「工作区（智能体在此目录下执行）」下拉：不指定 / 已有工作区列表；旁边「+ 新建工作区」走系统选夹注册新目录。智能体方式=执行目录（不存在会自动创建）；模型直跑=在指令前注入「【工作目录】」提示 | 「不指定工作区」 |
| 知识库 | 「知识库（每次运行先检索相关片段注入）」下拉：不绑定 / 本机各知识库。每次运行按任务指令检索该库，命中片段以「【知识库参考】」块注入提示词 | 「不绑定知识库」 |
| 附件 | 「附件（注入头部样例）（≤3）」：点「+ 添加附件」从系统文件窗选文件（pdf/docx/xlsx/csv/md/txt 等），每个取头部约 3000 字注入；行内可 关闭 移除 | 无 |
| 启用联网搜索 | 勾选框「启用联网搜索（每次运行前检索最新信息）」：运行前按任务指令搜 web（约 6 条结果注入提示词，注明来源） | 不勾 |

如果只记一件事：两种排程（间隔与定点）。剩下的细节，照步骤节走就行。
