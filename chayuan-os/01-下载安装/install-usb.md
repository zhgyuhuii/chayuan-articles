# U盘搬运安装：隔离环境的标准搬运姿势

先说这篇能帮你干什么：读完能在察元AI OS里独立完成U盘搬运安装，路径是U盘搬运安装。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：隔离环境的标准搬运姿势。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

边界先摆在桌面上：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 放回产品盘面看

把U盘搬运安装放回察元AI OS的整体盘面：需要相应平台的 Key（部分有免费额度）；灵宠把后台跑着的 AI 变成桌面上看得见的小生物，右键编辑改配置，删除有两步确认，桌面上的野宠可以收编为正式灵宠建档；定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见。

## 安全与数据边界

安全口径单独立一层：灵宠商店主题页签整套安装：场景背景加 36 图标皮肤加灵宠皮的组合包；设置关于里检查更新、下载并重启安装，一台服务器全组使用，运维只管一处，终端零安装，断网可用、数据不出本机。

## 平台与形态

平台与形态的账：完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入；全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，全新安装选数据目录或导入拷贝根，创建管理员；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。

## 价格与授权

价格口径一并交代：对配对终端开模型加知识库授权；资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问，授权按终端逐台给，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。

## 产品家族与搭配

察元AI OS不是单打独斗：一台服务器全组使用，运维只管一处，终端零安装；购买 OS 授权后，同机察元AI Office 自动免激活；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。

## 几条硬数字

能落到数字上的几条：想换默认模型随时可以在设置里重跑向导，不用重装，本地模型解决有无问题，复杂任务还是需要云端旗舰模型，断网时云端模型不可用，可设自动回落本地；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。

## 离线与内网

离线内网这条线的口径：自动模式本地优先，local 星号开头的本地模型未运行自动加载；本地模型按需自动加载，会话中随时切换模型（本地与已启用厂商热更新）。

## 能力总账

把察元AI OS的能力总账摊开：不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处，三级知识库优先级，知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事。
