# 首次启动场景拆解：开机登录门是进入桌面前的第一道全屏门

首次启动这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决把数据放 D 盘防重装丢失。

## 先看看痛点对不对得上

换电脑/重装系统，想把旧电脑上的全部用户、应用、插件、知识库原样搬过来，新装机第一次打开察元，被「欢迎使用察元」向导拦住，不知道每个框填什么、数据目录要不要改；旧机数据整体搬到新机；把数据放 D 盘防重装丢失。

## 开机登录门与数据目录：从入口到完成

分支三 · 导入拷贝根（从另一台电脑迁移）

1. 入口在向导「数据目录」屏的「从另一台电脑导入」区，说明原文：「已有拷贝过来的 chatop-data 数据文件夹？选择它即可同步全部用户、应用、插件与智能体。」点「选择数据文件夹…」选中旧机拷来的整个数据根文件夹。
2. 校验失败分支：文件夹里没有 registry.json ＞ 「该文件夹不是有效的察元数据目录（缺 registry.json）」；里面没有任何用户 ＞ 「该数据目录里没有任何用户」。
3. 同平台（如 mac＞mac）：不复制数据，整个文件夹原地接管——系统记录重定向并自动重启，直接用它当数据根。
4. 跨平台（如 win＞mac）：把数据复制进本机默认根，复制期间显示「正在导入数据…」，完成后自动重启；平台相关组件下次会话自动重建。若文件夹带共享模型权重（shared/models/chatop-models），先弹「并入模型权重」对话框：「该数据文件夹带有共享模型权重（约数 GB）。」「模型全机只保留一份，并入后本机所有用户共用；不并入则导入后可重新下载。」勾选框「并入模型权重（约 4G，耗时较久）」（默认勾选），按钮「开始导入」/「先不导入了」。
5. 重启后登录门列出导入的全部用户，用原密码照常登录；每个用户的会话数据、应用、插件全部就位。

另：重装检测选择框

在已有用户的机器上重新安装/覆盖安装后首启，会弹「检测到重新安装」，说明原文为：本机已有 {n} 位用户的账号数据（含模型/聊天/设置）。「继续使用现有数据」直接进入原有账号；「全新开始」将重新走安装向导（旧数据整体封存，不删除，可找回）。按钮「继续使用现有数据」（直接进原有账号流程）或「全新开始」（旧数据根整体封存为 chatop-data.backup-<时间戳>，不删除，重走完整向导，之后仍可用「导入」找回）。

## 关键能力点

- 数据目录自选
- 拷贝根导入迁移
- 恢复密钥可选生成

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 常见问题

### 重装后弹「检测到重新安装」，选哪个？

想继续用原来的账号和数据选「继续使用现有数据」；想把机器转手/从头再来选「全新开始」——旧数据被整体封存为带时间戳的备份目录（不删除），反悔了还能通过「导入」找回。

### 导入时提示「该文件夹不是有效的察元数据目录（缺 registry.json）」？

选中的不是完整数据根。要拷的是整个 chatop-data 文件夹（里面有 registry.json、users/ 等），不是其中的某个子目录或安装目录。

### 开机每次都要输密码，能省掉吗？

密码本身不能置空（最短 3 位的硬校验）。默认的「开机登录」已经是最省路径：开机直接落上一位用户的锁屏，只输一次密码即进；在 设置 ＞ 用户 关闭该开关则会落在选人卡片墙。忘了密码看 A2。

## 更多操作细节

验证

1. 默认根：打开「文档」下的 chatop-data/，应能看到 registry.json、users/、shared/ 等条目；建过几个用户，users/ 下就有几个账户目录。
2. 换目录生效：向导里选过新目录并完成后，默认位置的 chatop-data/ 下会出现 .redirect 文件（内容指向新目录），实际数据在新目录里。
3. 导入：导入完成后重启，登录门卡片数量应与旧机用户数一致，用旧密码能登录。
4. 开机落点：开关保持默认（开）时重启，动画结束后应直接落上一位用户的锁屏，输密码即进。

## 动手前再核对一遍

- 桌面形态（察元AI OS）。本篇的向导与登录门只出现在桌面应用；web/docker 形态没有开机门。
- 向导只在「没有任何用户」时出现（全新安装，或重装后选了「全新开始」）。已初始化的系统日常开机直接走登录门。
- 默认数据根：macOS/Linux ~/Documents/chatop-data/，Windows %USERPROFILE%\Documents\chatop-data\；每个账户的数据在其下 users/<账户>/ 目录里。
- 密码最短 3 位；恢复密钥在创建管理员时自动生成一次。

## 放回产品盘面看

把首次启动放回察元AI OS的整体盘面：图片搜索与图库平台支持，需要相应平台的 Key（部分有免费额度）；灵宠把后台跑着的 AI 变成桌面上看得见的小生物，右键编辑改配置，删除有两步确认，桌面上的野宠可以收编为正式灵宠建档。

## 安全与数据边界

安全口径单独立一层：管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；全新安装选数据目录或导入拷贝根，创建管理员；数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力；MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583）。
