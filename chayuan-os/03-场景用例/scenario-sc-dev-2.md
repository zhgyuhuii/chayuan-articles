## 几个容易忽略的细节

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 产品家族与搭配

察元AI OS不是单打独斗：文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，插件、技能、MCP 插件、智能体、技能包五大类。

## 几条硬数字

能落到数字上的几条：重跑入口在设置＞模型＞设置向导；想换默认模型随时可以在设置里重跑向导，不用重装；本地模型解决有无问题，复杂任务还是需要云端旗舰模型，断网时云端模型不可用，可设自动回落本地；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。

## 离线与内网

离线内网这条线的口径：国内/国际/本地/聚合四组厂商目录；下载几个 GB 的权重需要时间与磁盘空间，GGUF、whisper 权重可以按路径直接导入（零拷贝），或按直链目录放置后执行扫描本地放置的模型。

## 能力总账

把察元AI OS的能力总账摊开：账户隔离、数据在服务器侧统一管理，（知识库对外服务，固定端口），建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型；不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处。
