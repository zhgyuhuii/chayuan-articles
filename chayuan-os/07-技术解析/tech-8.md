# 拆开看离线激活加密方案：模型服务异常自救

「删掉的内置模型怎么找回」——这个问题最近被问了好几次。答案不复杂：离线激活加密方案在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 是什么与为什么

离线激活加密方案是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，恢复出厂模型是其中面向这类需求的一环。

下面直接进正题。

## 完整操作步骤

1. 进入设置 ＞ 模型

打开 设置，左栏第一项「模型」。

上手按顺序做：

1. 一键回到出厂模型配置
2. 数据文件不受影响
3. 确认边界：恢复后自定义的模型清单需要重新导入
4. 场景验证：模型服务异常自救
5. 场景验证：交接机器前清理配置
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 这些坑和边界要知道

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- 恢复后自定义的模型清单需要重新导入
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 报「另一会话正在操作该模型，请稍后再试」？

恢复出厂与首启播种/权重迁移共用一把种子锁，另一会话正在批量写共享权重目录。等对方完成（通常一两分钟）再点一次即可。

## 放回产品盘面看

把离线激活加密方案放回察元AI OS的整体盘面：它能把应用造出来挂上桌面，桌面本身能被 AI 定义，能力边界从预装走向按需生成，搜索能力不绑定单一平台，新桌面系统的肌肉记忆速查，五分钟上手。

## 安全与数据边界

安全口径单独立一层：敏感操作全部写审计日志 audit.jsonl，可回放检查，远端调用以远端访客身份过对端权限门并留审计，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。

## 平台与形态

平台与形态的账：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；Dock 是使用频率最高的区域，位置与大小顺眼很影响手感。
