# MCP资源：按榜单找热门 MCP

很多人搜「应用商店里都有什么？技能包和技能有什么区别」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把MCP资源从打开哪个应用讲到看到什么结果。

## 应用商店与智能广场是个什么东西

MCP资源是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，应用商店与智能广场是其中面向这类需求的一环。

先把定位立住，再看步骤。

## 完整操作步骤

按最短路径验证一遍：

第 4 步 · MCP 插件（能力广场目录）

1. 提示行「安装后注册为 MCP 服务器并同步到各智能体」。来源 pills：「察元能力广场」（默认，服务端分页目录——代码注释标注其收录 6600+ 条，界面实际显示「{n} 个 MCP 服务器 / {total}」以服务端返回的总数为准）、「精选目录」（内置种子清单，不走网络）、「＋ 添加目录源」（展开后填「源名称」「目录 JSON URL（https://…）」点「添加」接入自定义目录）。
2. 工具栏搜索框做服务端检索（占位「搜索能力广场，或输入关键词筛选…」），面板内另有本地过滤框「筛选 MCP…」。列表滚动到底自动翻页。
3. 每条：名称/发布者/类型徽标（远端/本地命令/仓库）/描述/标签。按钮二态「安装」/「卸载」；仓库型（无标准化接入配置）只有「查看仓库」跳官方仓库。
4. 安装 = 写入本机 MCP 清单并同步进支持 MCP 的智能体配置，日志「已安装 MCP：{name}（已同步到各智能体）」。限流时提示「察元能力广场限流（HTTP 429），已停止自动加载，稍后可重试。」，点「重试」续页。

第 6 步 · 察元智能广场（在线社区）

1. 打开：应用管理 ＞「应用」＞ 内置应用分区点「察元智能广场」图标（Spotlight 搜「察元智能广场」同样可开；可用右键「固定到任务栏」常驻 Dock）。窗口默认最大化。
2. 窗口内嵌在线能力社区（aidooo.com）：浏览/检索智能体、MCP、插件、技能、提示词、模型厂商等板块与排行榜。右上两个按钮：「刷新」「在浏览器中打开」（交给系统浏览器）。
3. 断网时自动切离线兜底页（已缓存内容仍可看），标题栏出现「离线模式」徽标；联网恢复后点「刷新」回到在线版。
4. 逛中看中的能力，回到应用商店对应页签安装。

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 技能包和技能有什么区别？

技能包 = 按行业打包的一批技能（商城整包免费安装或付费购买，装进技能根目录的技能包子目录，技能列表带 来源徽标）；技能 = 单个技能目录（商店「精选」或 GitHub 技能仓库），解压落 ~/.dsh/skills/。两者装完都在应用管理 ＞「技能」页签可见。

### 付费包扫码付完了，按钮还没变「已购直装」？

支付回调偶有延迟：直购面板关闭后系统还会继续对账约 1 分钟，命中后按钮自动翻成「已购直装」。仍未变化就重开包详情，或确认手机端支付确实完成后再点安装。

### 换电脑后已购的技能包怎么找回？

在包详情底部的 token 输入框粘贴购买时的 skp_… 序列号，点「验证并恢复」即入本机账本。注意设备数上限 3 台（「设备数已满（3/3），请在购后页解绑旧设备或联系客服。」）。

### MCP 广场报「察元能力广场限流（HTTP 429）」？

上游目录限流，自动加载已暂停；稍等片刻点错误行右侧「重试」按当前进度续页，或先用「精选目录」源。

## 更多操作细节

第 1 步 · 打开商店、认识工具栏

Dock 点「应用商店」。顶部工具栏从左到右：视图切换「列表 / ▦ 卡片」、五个类型页签「技能包 / 插件 / MCP 插件 / 智能体 / 技能」、来源切换 pills（随页签变化，见下）、搜索框与「搜索」按钮（技能包按行业浏览不走关键词搜索；智能体页签无搜索框）。窗口底部有安装日志区，成功/失败/跳过原因都滚在这里。

## 更多操作细节

第 2 步 · 技能包（aidooo 技能包商城，含付费）

提示行「aidooo 技能包商城，按行业分组浏览」。

1. 列表：行业 chips（「全部行业」＋各行业）过滤；卡片显示图标、标题、v{版本} · {n} 个技能 · 已售 {n}、免费（绿色「免费」）或价格（¥{价格}，有折扣时原价划线）。
2. 按钮七态：免费安装 / 购买 ¥xx / 等待支付… / 已购直装 / 安装中… / 卸载 / 卸载中…（已装的显示「已装 v{版本}」徽标）。
3. 点卡片进包详情：「＜ 返回列表」；头部 v{版本} · 已售 {n} · {n} {n}；正文分区「解决什么问题」「适合谁」「配套依赖」（依赖可标「可选」）「包内技能（{n}）」——技能卡片可再点进技能详情（「＜ 返回包详情」）。
4. 购买（桌面形态，应用内直购）：点「购买 ¥xx」＞ 弹出直购面板：渠道「微信支付」「支付宝」可切换、显示金额、本地生成二维码（提示「请使用微信扫码支付」/「请使用支付宝扫码，在手机完成支付」；下单中显示「正在生成订单…」）＞ 手机扫码付款 ＞ 面板显示「支付成功」，随后自动关闭并提示「窗口将自动关闭，点击『已购直装』完成安装」＞ 点「已购直装」安装，消息泡「技能包安装完成（{n} 个技能）」。也可「在浏览器打开购买页」。
5. 网页/host 形态：无应用内下单，点购买会在新标签打开购买页；支付完成后回商店点「已购直装」。订单与账本以机器指纹对账——经「在浏览器打开购买页」完成的购买同样绑定本机指纹，支付后自动入本机账本，安装不二次扣费。
6. 换机/网页购买找回：包详情底部「已有序列号 / token（网页购买、换机找回）？粘贴后验证即入本机账本。」＞ 输入 skp_… token 点「验证并恢复」＞「已验证并加入本机账本，可直接安装。」
7. 常见错误文案（直接给出动作）：「内容校验失败（指纹不符），已中止安装。」「磁盘空间不足，请清理后重试。」「设备数已满（3/3），请在购后页解绑旧设备或联系客服。」「授权无效（token 失效或不属于本机），可粘贴 token 恢复。」；异常时可点「复制诊断信息」反馈。后台关闸时显示「商店源已关闭（aidooo 后台 kill-switch）」「商店源暂时关闭，已安装的技能包仍可正常使用。」
8. 列表很长：底部显示「已显示 {shown} / {total} 个技能包」＋「加载更多」，滚动到底自动上屏。
