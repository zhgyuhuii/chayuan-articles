# 需求自动归并：需求墙实操的底层逻辑

需求墙实操的麻烦不在功能本身，在于信息散。生态共建：作者有上架通道，用户有提需求的地方。这篇把它收拢成一条能照着走的路径。

## 一句话说清定位

需求墙实操能做的事拆开就这几件：进展全程公开；需求自动归并；作品投稿审核制；受控标签词表。对应的界面入口是投稿与需求墙

入口、步骤、验证三段看清，这事就顺了。

## 具体怎么操作

按最短路径验证一遍：

投稿你的作品

1. 登录后进提交作品页
2. 填写资源名称、主页或演示地址、图标外链
3. 分类必选，标签从受控词表搜选 2 到 5 个
4. 提交进入人工审核队列，通过后上架展示

在需求墙提需求

1. 进需求墙选产品（五款产品二级菜单）
2. 点「提需求」或唤起提需求机器人
3. 相同诉求会自动归并到已有条目，累计人数
4. 按处理状态过滤盯进展，全程公开

### 投稿后多久上架？

经审核后上架，审核主要看资源真实性与信息完整度；状态可在投稿记录里查。

需求墙是公开的，官方与社区按需求热度排期，obot 客服也会收集对话里的需求进同一个池子。
