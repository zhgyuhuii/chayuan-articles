# 智能体门户落地记：导航智能广场分三栏

先说这篇能帮你干什么：读完能在察元AI 能力广场里独立完成智能体门户，路径是找某类 MCP 服务。步骤里的每个「」按钮都是界面原文。

## 解决什么痛点

看本周热门插件，找某类 MCP 服务。

## 操作步骤详解

逛广场的基本姿势

1. 浏览器打开 aidooo.com，导航点智能广场
2. 按资源类型进对应板块（如 MCP、插件）
3. 关键词检索或按分类浏览
4. 点进详情页查看说明、安装方式与榜单排名

三栏动线怎么走

1. 第一栏按「装了就用」挑资源：插件、技能、MCP 直接进对应市场
2. 第二栏按「查资料」走：模型目录、厂商页、智力榜与免费榜
3. 第三栏按「逛与买」走：榜单发现新品，资讯页看动态
4. 登录后收藏常用条目，下次从我的收藏直进
