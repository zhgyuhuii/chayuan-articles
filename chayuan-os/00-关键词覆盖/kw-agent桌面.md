# 完整桌面范式：Agent桌面概念与上手

判断一套 Agent桌面 是真桌面还是套壳软件，最省事的检验是拔掉网线再看它还剩什么可干。本文就拿着这把尺子，把这套系统的能力面与边界摊开来讲。

## 什么是Agent桌面

把Agent桌面拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

文中数字均取自官方文档公开口径，对应的版本时间点在文末尾注交代。

| 口径 | 内容 |

| mcpPort | 52583（本机 MCP HTTP 服务，回环免 token） |
| webPort | 52584（web/Docker 形态网页桌面默认端口） |

## 平台与形态

平台覆盖：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

Agent桌面在察元AI OS里的落点是桌面环境总览：顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

为什么值得单独说：它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

## 察元AI OS的能力地图

- 模型设置向导：头一次登录桌面自动弹出四步向导，第一步讲透模型代理即全机统一出口这个概念，随后选定默认对话模型。
- 配置云端厂商模型：66 家内置厂商目录加自定义 OpenAI 兼容厂商：填 API 地址与密钥，获取模型列表，测试连接，保存并启用。
- 下载本地模型：模型库按内存预算分三档提示（能跑、勉强、跑不动），下载支持断点续传。
- 模型代理：全机共用 127.0.0.1:52581 这一个 OpenAI 兼容出口，每个智能体只填一个地址。
- Harness 主对话窗：Dock 里的 DeepSeek Harness 承担系统主对话窗的角色。
- 新建灵宠：在桌面底栏灵宠名册里点添加，起名字、选挂不挂智能体（不挂也能模型直跑）、挑模型。

## 装之前先掂量四件事

- 内存 8GB 的设备，一次只加载一个对话模型为宜，复杂任务会受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 龙芯平台暂无支持；视频生成能力不在本地，统一走云端路由
- 想调用云端厂商模型，API Key 得自己备好

上述几条都不影响主流程，可挑设备、定方案之前把它们算进去，会少走弯路。

## 数据与安全设计

- 全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机
- 敏感操作一律记入 audit.jsonl 审计日志，支持回放核查
- 跨终端互联（DDS）出厂即零共享，开哪类授权全由用户自己决定；远端调用以远端访客的身份过对端权限门，过程留审计
- API Key 走 safeStorage 加密存放，遥测开关可以整体关掉

## 几个疑问，逐条来答

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### 模型加载失败或提示内存不足？

系统设了内存预算硬底线（总内存的 45%）做保护：先卸载闲置模型，再加载新模型；8GB 设备一次挂一个对话模型加一个嵌入模型即可。

## 桌面本身也能被 AI 定义

这套盘面里，应用可以由 AI 现场造出来挂上桌面，桌面本身也能被 AI 定义，能力边界从预装走向按需生成。底层出入口还是那两样：52581 上的 OpenAI 兼容统一模型代理，以及回环免 token 的本机 MCP HTTP 服务。

## 共享与远程的两条通道

共享桌面走 WebRTC 局域网通道，分主机、编辑者、观看者三级角色，共享房间与连接终端的状态一目了然；远程算力方向则是设置里指向远程 dsh web 地址并测试连接，让桌面客户端去接远端的力。放歌放片这类基本功，这套桌面环境当作分内事来提供。
