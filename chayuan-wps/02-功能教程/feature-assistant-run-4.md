# 个领域助手按 228 个行业领域组织：行业助手实操的坑与对策

行业助手实操的麻烦不在功能本身，在于信息散。不用写提示词，选对助手点一下就是行业级的处理。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

按这个顺序排查行业助手实操通常最快：先确认前置条件（已在 WPS 中启用加载项，并完成模型配置——助手执行要调用模型。），再核对操作路径，最后看边界限制。

## 正确的操作路径

4. 用功能区固定按钮执行（文字端）

「察元AI助理」选项卡「AI助手」组里的这些按钮本身就是内置助手的一键入口：「拼写与语法检查」「生成摘要」「文本分析」菜单（换种方式重写/扩写/缩写/检查段落序号格式/AI 痕迹检查/批注解释/超链接解释/纠正拼写和语法/提炼关键词）、「翻译」菜单（20 语种）、「文本转图像」「文本转视频」「知识库」菜单。点击后走与侧栏执行相同的任务链。

「AI助手」组里还有 4 个智能助手槽位按钮：你把某助手的「显示位置」勾选了「顶部主菜单」，它就会占一个槽位，按钮文字直接显示助手名；未配置的槽位自动隐藏。点槽位按钮即执行对应助手。

5. 用右键菜单执行

在正文选中一段文字后右键，菜单里有这些察元入口：

表格单元格内右键有对应的一套（「添加到察元AI助手」等）。

1. 「察元AI文本分析」：文本分析类助手子菜单；
2. 「察元AI翻译」：20 语种翻译子菜单；
3. 「察元AI知识库」：「知识库核对本段」「知识库总结本段」「知识库问答本段」；
4. 「智能助手」×4：与功能区槽位同源的右键槽位，显示已配置到右键菜单的助手名，点击即执行；
5. 「更多智能助手」：其余配置到右键的助手；
6. 「添加到察元」：把选中内容作为上下文送进 AI 助手对话（未选中内容会提示「请先选择要添加的内容」）。

## 做完后的验证

验证

1. 侧栏「助手」页签页签名右侧的数字徽标 = 当前可用助手总数；文字端全量加载后应与 4526 + 系统/分析/工具/自定义数量一致（领域组未展开时以组行上的计数显示）。
2. 任意执行一个只读类助手（如「生成摘要」，文档动作默认「仅生成结果，不写回文档」），任务进度窗出现且最终状态为完成，结果可在窗内查看。
3. 把某助手「显示位置」勾选「右键菜单」并保存后，选中正文右键应能看到以该助手命名的菜单项。

## 接着回答几个常见问题

### 表格/演示里怎么找不到那 4526 个领域助手？

助手按宿主分流：文字端显示文档助手全集；表格端只显示 66 个表格配方、演示端只显示 81 个演示配方（侧栏与「察元AI助理」选项卡一键按钮同源）。这是设计行为，避免行业文档助手淹没表格/演示配方。

### 功能区出现 4 个一模一样的「智能助手」按钮？

槽位按钮未配置助手时本应隐藏；若看到重复占位，多半是显示配置刚改过未刷新。到「助手管理」检查各助手的「显示位置」，保存一次触发功能区刷新即可。
