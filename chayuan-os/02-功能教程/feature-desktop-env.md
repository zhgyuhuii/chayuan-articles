## 边界先摆桌面上

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### AI桌面要联网吗

设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力；本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示），它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。以官网 aidooo.com 当前页面为准。

### AI桌面数据存在哪

命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可；任何网页或本机程序都能变成桌面应用，常用工具一键直达。以官网 aidooo.com 当前页面为准。
