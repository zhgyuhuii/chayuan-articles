# 开源吗？

这个问题在被反复问到，这里给一个完整、可执行的回答。

## 直接回答

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

## 背景与原因

理解这个问题的关键，是先知道察元AI OS的整体设计：察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

## 延伸操作

1. 按上文答案定位到对应设置或入口
2. 执行后做一次最小验证
3. 如涉及模型，先确认端点与密钥有效
4. 仍有问题时通过官网渠道反馈并附系统信息

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- Docker/云通道等进阶形态需要一定动手能力

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。
