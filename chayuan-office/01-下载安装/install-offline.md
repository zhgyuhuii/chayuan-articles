# 内网离线安装装机指南：开源办公套件能离线装

内网环境装办公软件，问得最多的就是离线这条路到底怎么走：包从哪来、模型怎么配、断网后哪些能力还活着。这篇把内网离线安装从取包讲到验证结果，一步不跳。

## 安装前确认

- 系统要求：Windows 10 及以上，x64/arm64
- 安装包：NSIS 安装器 exe
- 说明：配合本地模型全离线。

## 离线装机的操作主线

1. exe 从官方发布渠道取回，经内部介质摆渡进内网
2. 双击安装
3. 启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama
4. 开始页新建或打开文档

离线环境的「下载」要换个理解方式：外网机器从官方发布渠道把 exe 取回，经内部审批的介质（U 盘、光盘或摆渡机）带进内网，再分发到各工位。这套流程里最该固化的动作是「取包机器固定、介质登记」，包从哪台机器来、谁带进来的有记录，出了问题才有迹可循。包体本身不依赖联网校验，进内网后双击即装，安装过程与联网环境完全一致。

## 其他平台装法速览

macOS：官方渠道取 dmg；拖入应用程序文件夹启动；设置＞模型设置里接入模型。

## 装完后的第一件事

配置盘活的顺序：先在设置里接好模型（BYOK 或本机端点），新建 docx 请 AI 写一段，随后做一轮全文校对；两个动作都有产出，这套环境便算活了。

模型接入这步在内网要格外讲究顺序：先确认本机或内网服务器上的模型端点已经就绪，再到设置里填地址。端点没起就先配应用，测试连接必然失败，排查时容易把方向搞反——先验端点、后验应用，是内网排障的基本功。

## 做完后的验证

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

验证动作建议全部在断网状态下做一遍：拔掉网线再走流程，能通过的才是真正的离线能力。有些功能在联网时「碰巧」能用，是因为请求走了外部服务；断网验证会把这类隐性依赖全部暴露出来，早暴露比上线后才发现强得多。

## 断网环境的边界

哪些账要先算清：

- web/dsh 形态只带五个编辑器、不含 HTML，也不存在购买与激活界面
- Linux 无系统 OCR 引擎，扫描页保留位图不识别

## 装机形态能力点

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

本地优先、离线可用是这套方案的底色：文档读写、手册查阅、快捷键表都在本机，不因为断网少一块。信创机器能装、内网机器能跑，替换传统办公链路的第一步就是从这里迈出去的。手册离线可读这一点常被低估——新人在隔离网里翻不到搜索引擎，应用内手册就是手边仅有的学习材料，齐全的快捷键表能把上手周期压短不少。免 root 在内网同样关键：装软件不申请管理员权限，信息科的审批链就能短一截，这对推进速度的影响，往往比任何功能特性都直接。

## 转换与识别的边界

加密只读文档仅支持查看；转换全部本机完成（PDFium 字符级提取加纯几何版面分析），证书加密 PDF 无法转换。搜索、数据库、浏览器这些 MCP 能力接进来，AI 面板就不止会改文档——注意这些扩展能力是否可用取决于内网里有没有对应服务，断网环境下按实际部署情况核对。

## 数字与助手规模

Docs 端 4576 个领域助手、229 个领域包，全库约 4600 个；通用对话要自己写提示词，领域助手把行业 knowhow 固化成一键执行；壳内 MCP 服务（端口 52588）把文档操作能力开放成 MCP 工具；支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点。

## 断网时哪些能力活着

AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用；自带 Key 意味着不被单一厂商锁定，国内国际本地端点随切随用；内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型。涉密文档不能出网的场合，本地模型让 AI 校对、AI 改写在隔离环境照常工作——这是内网部署最核心的一条验收项：不是「装上了」，而是「断网后 AI 还能应答」。两种状态的表现差异要分清：没配模型时 AI 入口安静无响应，属于预期行为；配了本地端点却失败，才是排障对象，两者的处理路径完全不同。

## 编程智能体的对接

智能体拿到操作权限后可以直接读写文档、调用文档 API，不必人工翻接口说明；内网自动化脚本可以通过壳内 MCP 端点直接操作文档，这层能力与界面功能同源，断网时同样只依赖本机服务。

## 内网装机的两条实用经验

其一，试点机先行。内网机器的安全策略、补丁版本远比个人电脑杂，先挑策略最严的一台装，跑通全部验证项再批量铺开，返工成本最低。其二，把「断网验收清单」写进交付物：新建六种格式、模型可配置、AI 文本能生成、校对有响应，四项全绿再签收，后续争议少一大半。

链路到这里拆解完毕。装完就在断网状态点一轮全文校对，哪一步没反应，回本文对应小节按序排查即可。
