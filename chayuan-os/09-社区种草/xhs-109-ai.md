# 📌系统技能（chatop-system）隐藏用法｜AI技能一次讲清

用过察元OS的宝子看过来，系统技能（chatop-system）这个功能很多人没用到极致👇

✅ **它能干嘛**

对外能力的权威技能包：启动时自动镜像进六家智能体技能目录，让 Claude Code 等天然会用本机系统能力；设置里可查看/下载/按智能体应用。

🔍 **三步用起来**

1️⃣ 设置→系统技能查看已镜像状态
2️⃣ 在智能体里直接说「换张壁纸」「打开知识库」
3️⃣ 技能更新后自动同步

💡 **什么场景最香**

· 让外部智能体接管本机操作

📌 **避坑提醒**

⚠️ 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

🛠️ **更多它擅长的事**

· **内置应用全家桶**：浏览器、我的电脑、应用管理、应用商店、备忘录、提醒事项、日历、音乐、媒体播放器、文本编辑、PDF 预览、图片查看、文生图（Stable Diffusion）、画图、Markdown 预览、Monaco 代码编辑、废纸篓、帮助中心等 20+ 内置应用。
· **共享桌面**：局域网内多用户桌面共享：权限分主机/编辑者/观看者三级，适合会议室投屏协作与远程指导。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

⚠️ **断网也能用？这点很关键**

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

📝 **免费还是要花钱**

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
