# 云桌面AI入门指南：完整桌面范式

云桌面AI这个词自带一个疑问：桌面上了云，AI 跟不跟上去？这篇把形态、账号、权限、首启向导逐层拆开，看完你能判断它适不适合你的团队。

## 什么是云桌面AI

云桌面AI指以云桌面形态交付的 AI 工作环境：桌面与 AI 能力跑在服务端，终端只负责显示与输入。本文的例子是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，除桌面安装形态外还有 web 与 Docker 云桌面形态。

## 三种形态怎么选

- 桌面安装：完整体验，数据不出本机
- web 形态：浏览器直接用，适合不想装客户端的场景
- Docker 云桌面：整套系统无头跑在 Docker 里作为多用户云桌面，员工浏览器打开即用；网页桌面默认端口 52584，被占用时改 compose 端口映射

web 与 Docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作。还有一条远端算力路线：设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力——本机轻薄、远端肥厚时，桌面只当壳。

云桌面形态交付的不是精简版桌面，而是同一套完整桌面范式：42 张内置壁纸、动态 WebGL 壁纸、窗口四边停靠，一样不少；壁纸分静态库与动态款（vanta、matrix、galaxy 等）。政企用户拿到的是完整的桌面迁移体验，低配的老机关机器上动效也保得住流畅。

选择的依据通常就三条：终端性能、管理半径、数据合规。终端老旧就把算力放服务端；人多就要统一账号与权限；数据不能出机房，就整套留在内网服务器上跑。

## 多用户与权限

- 账号管理：管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录
- 智能体权限门：智能体动系统能力分级确认——T0 只读直放；T1（跑终端、开原生窗）每运行期首问一次，可记忆

云桌面形态下权限门尤其关键：每个用户的智能体能动哪些系统能力，规则是统一的，确认记录可查。这两个机制一个管人、一个管 AI：账号管理决定谁能用、用到什么程度；权限门决定智能体能替用户动到哪一步。迁移到云桌面的团队常低估两件事：链路体验与服务端内存预算，前者影响手感，后者决定能同时开几个模型。

## 智能体能力从哪来

各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。能力不是写死在系统里的，是从商店长出来的，越用越全。对云桌面管理员来说，这意味着给团队补能力是一次商店操作，而不是逐台机器的重复劳动。

## 首次登录的四步向导

首次登录桌面会自动弹出四步向导，第一步先讲清楚「模型代理是全机统一出口」这个概念——很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。OpenAI 风格与阿里百炼风格 API 自动适配，统一出口在 :52581（OpenAI 兼容统一模型代理）。云桌面形态下这个设计的收益被放大：服务端配一次，全部用户的智能体同时生效，不用逐个终端跑一遍配置。

## 桌面基本功

开机建好账户即进桌面；应用从底部 Dock 启动，右键 Dock 可进设置；控制中心与通知中心收在顶部菜单栏右侧；换墙纸、加小组件走桌面右键。窗口支持拖拽、双击标题栏最大化、四边停靠；任务切换、手动与自动锁屏、外接屏的虚拟屏排布，位置都符合直觉。从传统桌面迁过来的用户，这一节的内容基本不用学，肌肉记忆直接沿用。

## 边界先记四条

- 8GB 内存档的机器，建议一次只带一个对话模型，复杂任务会受限
- 龙芯还没进支持名单；视频生成本地做不了，靠云端路由补
- 调云端厂商的模型，自己的 API Key 不能少
- Docker 云桌面、跨终端互联算进阶玩法，动手门槛不低

这些限制对云桌面形态尤其要紧：服务端配置定了，一群用户的体验就跟着定了。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用
- 清除桌面数据是破坏性操作，界面带警示

## 两个疑问的答案

### 云桌面形态下断网会发生什么？

终端与服务端之间的链路断开，会话自然中断，重连后继续；「桌面只当壳」的远端算力模式里，联网本来就是前提。本机桌面形态则不受此影响，本地模型断网可用。

### 用户数据落在服务端还是终端？

云桌面形态下数据集中在服务端：管理员删除用户会抹掉该用户全部数据，也可重置密码、踢下线，管理动作集中、留审计；本机形态则数据不出本机，两头的边界都清楚。

## 一句收束

云桌面AI选型的核心问题是算力放哪：集中到服务端，换来管理与数据的集中；留在本机，换来断网可用与零上传。两种答案都对，区别只在你管的是一群人还是一台机器。细节回看前文「三种形态怎么选」一节。
