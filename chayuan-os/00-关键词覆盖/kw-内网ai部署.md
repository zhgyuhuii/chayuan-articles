# 内网AI部署是什么：AI 桌面操作系统

内网AI部署这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是内网AI部署

把内网AI部署拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

全部口径出自aidooo.com官方文档，版本对应关系见文末。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 恢复密钥管理：设置账号与找回里生成 4 乘 4 恢复码，重新生成需验当前密码，明文只显示一次，
- 安装智能体：三类装法：npm 包一键安装升级（Claude Code、Codex 等 13 家，
- 智能体权限门：智能体动系统能力分级确认：T0 只读直放；T1（跑终端、开原生窗）每运行期首问一次可记忆；
- 应用商店与智能广场：应用商店对接察元AI 能力广场（aidooo.com）：

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 价格口径

- 免费下载使用，购买只停提醒、不锁功能
- 首运行起 90 天完全静默，之后每日首次启动弹一次购买页（可关闭）
- 购买 OS 授权后，同机察元AI Office 自动免激活

## 你可能会问

### 内网AI部署要联网吗

AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网。以官网 aidooo.com 当前页面为准。

### 内网AI部署数据存在哪

Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把内网AI部署放回察元AI OS的整体盘面：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，保存后随系统技能分发到智能体，图片搜索与图库平台支持。

## 安全与数据边界

安全口径单独立一层：本地 AI 出题验证；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理，Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入。

## 平台与形态

平台与形态的账：灵宠把后台跑着的 AI 变成桌面上看得见的小生物，AI 纪要一键生成；AI 面试 3 次失败锁 24 小时，忘记密码时本地 AI 面试官出题。

## 价格与授权

价格口径一并交代：四本日历把生活与工作分开记，AI 能读会写，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；让特定文件类型默认交给智能体处理，双击即用 AI。

## 产品家族与搭配

察元AI OS不是单打独斗：:52581（OpenAI 兼容统一模型代理），很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 几条硬数字

能落到数字上的几条：模型会话中热切换；工具调用过程可视化；无显式模型偏好时自动指向本地模型；配置入口在设置＞默认模型＞网络资源页签。

## 离线与内网

离线内网这条线的口径：本地不提供视频生成（视频生成走云端路由）；本地模型解决有无问题，复杂任务还是需要云端旗舰模型；国内/国际/本地/聚合四组厂商目录，下载几个 GB 的权重需要时间与磁盘空间。
