# 从需求到交付：私有知识库搭建

私有知识库搭建这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决给每个客户建独立资料库。

## 先看看痛点对不对得上

1. 几百份 PDF 与 Word 散落各处检索不动
2. 云知识库要上传敏感资料
3. AI 回答没有出处不敢用

资料重度用户这个场景里，私有资料变成可信可溯源的问答库。

## 把流程串起来

1. 知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载
2. 混合检索加可选重排保证命中质量
3. 引用式问答每个观点带编号脚注
4. 点脚注跳回原文核对并下载源文件

- 秒建秒删

## 几个容易忽略的细节

边界先摆在桌面上：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

场景提醒：单文件 48MB 上限，超限拆分后再传。

## 你可能会问

### 私有知识库搭建要联网吗

知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成；在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么。以官网 aidooo.com 当前页面为准。

### 私有知识库搭建数据存在哪

隐私敏感环境先关遥测再干活，处置设备前清数据，升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）。以官网 aidooo.com 当前页面为准。

## 安全与数据边界

安全口径单独立一层：隐私敏感环境先关遥测再干活，处置设备前清数据；（本机 MCP HTTP 服务，回环免 token）；敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计，API Key 用 safeStorage 加密存储，遥测可整体停用。

## 平台与形态

平台与形态的账：导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成；在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么，对配对终端开模型加知识库授权。

## 价格与授权

价格口径一并交代：授权按终端逐台给，本机 Stable Diffusion 链路出图不联网，隐私与免费兼得，发现加授权让它们互借能力，预授权窗口夜间放行。

## 产品家族与搭配

察元AI OS不是单打独斗：设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 几条硬数字

能落到数字上的几条：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，概念页解释模型代理机制，默认对话模型选择；重跑入口在设置＞模型＞设置向导；想换默认模型随时可以在设置里重跑向导，不用重装。

## 离线与内网

离线内网这条线的口径：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；插件启停卸载、离线安装，装了什么、开了什么，需要一个总账页面，离线环境靠导出导入搬迁；tar 包离线迁移。
