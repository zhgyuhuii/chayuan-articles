# 档案管理行业怎么用察元OS：从痛点到落地

档案管理行业的文档与信息工作有其固有节奏：历史文档数字化程度低，检索与复用困难。察元AI OS在档案管理场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出档案管理行业的完整应用路径。

## 档案管理行业的典型痛点

- 历史文档数字化程度低，检索与复用困难
- 多岗位协作时版本混乱、批注流转低效
- 新人上手慢，经验沉淀在个人手里而非工具里

## 对应的能力组合

- **便签/日历/提醒/联系人**（桌面效率）：系统级个人信息管理四件套：便签贴桌面、日历日程、提醒事项、联系人，全部可被智能体通过控制面读写。
- **技能页签与技能商店**（技能商店）：技能管理页签：启停（改写 SKILL.md 元数据）、打开目录、删除（入废纸篓）、tar.gz 离线导出导入；技能商店可搜索 GitHub 技能仓库一键安装（内置 anthropics/skills 等精选）。
- **插件页签（三源）**（插件市场）：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。
- **察元智能广场**（智能体门户）：内嵌 aidooo.com 能力广场的桌面应用：离线时回落本地页；与网页版同源，检索 2.5 万+ 插件/技能/MCP/提示词/模型资源。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按小内存设备用户场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程

## 常见问题
### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 数据存在哪里？怎么备份？

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
