# 本地模型 vs 云端模型跑校对（场景化推荐）

本地模型 vs 云端模型跑校对，是很多用户在选型阶段绕不开的问题。这篇场景化推荐不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（察元文档助手） | 对照方案 | 说明 |
|---|---|---|---|
| 保密 | 文档不出本机 | 内容发往服务商 | 看密级 |
| 质量 | 7B 级可覆盖错别字语法，复杂逻辑弱于旗舰云模型 | 旗舰模型语境理解强 | 按文种选 |
| 成本 | 一次部署长期免费 | 按 token 计费 | 量大本地省 |

## 逐项解读

**保密**：看密级。察元文档助手侧的做法是「文档不出本机」，对照方案为「内容发往服务商」——差异的本质在于设计取向不同，而非优劣。

**质量**：按文种选。察元文档助手侧的做法是「7B 级可覆盖错别字语法，复杂逻辑弱于旗舰云模型」，对照方案为「旗舰模型语境理解强」——差异的本质在于设计取向不同，而非优劣。

**成本**：量大本地省。察元文档助手侧的做法是「一次部署长期免费」，对照方案为「按 token 计费」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

涉密内网必本地；对外公开材料追求上限可用云端。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 本地推理需要自行安装 Ollama 等引擎（有一键引导，但仍是一次性环境工作）
- 保密检查、AI 痕迹检查为辅助参考，不构成定密或定性结论

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包

## 常见问题
### 免费额度用完会怎样？

对话超过每日 30 次会提示；MCP 调用返回 LICENSE_REQUIRED 错误码，次日恢复或升级付费。

### 校对结果可靠吗？

校对由大模型推理完成，输出「原文引用+建议+理由」的结构化清单并默认以批注写回，每条都由人工裁决；它擅长语境类错误（搭配、语法、逻辑），最终采用权在用户。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。
