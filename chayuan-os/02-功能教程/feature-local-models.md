# 模型配置可一键写入五家：本地大模型实操完整走法

本地大模型实操这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决内网机器补齐模型能力。

## 这个功能到底解决什么问题

本地大模型实操是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，下载本地模型是其中面向这类需求的一环。

先把定位立住，再看步骤。

## 前置条件

- 联网。下载走多源自动轮换：ModelScope（主源，含其 API 通道）＞ hf-mirror.com / hf-mirror.net / aifasthub.com（AI快站）镜像 ＞ HuggingFace 官方垫底，国内网络可直接下载。
- 磁盘空间：下载前自动预检，需要约「模型体积 × 1.05 + 200MB」余量；不足直接报「磁盘不足：还需约 XGB，当前可用 YGB」。
- 权重全机一份：页面上有固定提示「模型全机只保留一份：下载/删除影响本机所有用户」。
- 不想下载？ 完整安装包随机播种的「装机即用」五件套开箱即可加载：Qwen3.5-4B Q4_K_M（对话）、BGE-M3（嵌入）、BGE Reranker v2 M3（重排）、Piper huayan 中文语音（语音合成）、Whisper Small（语音识别）；未带模型包的安装形态，模型库中有同量化的 Qwen3.5-4B 在线档可补装。
- 完全离线的机器不走本教程，用「＋ 添加模型」按路径导入本地权重（导入不复制文件），离线放置与直链下载另见后续教程 M4（离线导入本地模型权重）。

## 完整操作步骤

9. 「＋ 添加模型」（离线导入入口）

「我的模型」标题行右侧「＋ 添加模型」打开导入对话框：填「模型文件路径」（桌面形态有「…」文件选择按钮）＞ 选模型类型（对话/嵌入/重排序/决策/代码补全/图像理解/语音识别）＞ 填「显示名称」与「上下文 (K)」＞ 点「导入并运行」。导入不复制文件，直接引用原路径。详细离线流程见后续教程 M4。

上手按顺序做：

1. 内存预算分层推荐
2. 断点续传与多路换源
3. Qwen3-8B/14B、小内存档 LFM2.5、图像理解 MiniCPM-V 等档位在线下载
4. 确认边界：8GB 内存建议一次只加载一个对话模型
5. 确认边界：下载几个 GB 的权重需要时间与磁盘空间
6. 场景验证：内网机器补齐模型能力

## 如何确认操作生效

验证

1. 「我的模型」列表出现目标模型（模型库对应行消失）。
2. 点「启动」后行首亮绿点，状态条计数 +1（如「1 个模型运行中」）；点「测试」显示「测试通过」。
3. 浏览器或终端访问 http://127.0.0.1:52581/v1/models（免 key）：清单出现 local/<模型id> 条目。
4. 在向导（M1 第 2 步）或灵宠选模型树里，该模型出现在「本地与自建 · local/」组下；运行中带绿色「运行中」标记。

功能归功能，这几个边界先摆清楚：

## 接着回答几个常见问题

### 本地大模型实操要联网吗

模型直跑宠无角色卡也能入群；本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队；换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页。以官网 aidooo.com 当前页面为准。

### 本地大模型实操数据存在哪

账户隔离、数据在服务器侧统一管理；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把本地大模型实操放回察元AI OS的整体盘面：输入框旁有知识库绑定与模型选择（含智能路由自动选模型），双击模型直跑灵宠直达，单个模型有偏好也有盲区；让几个模型围绕同一命题各自作答或接力深化。

## 安全与数据边界

安全口径单独立一层：换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页；对配对终端开模型加知识库授权；生图模型不配好，画图应用与智能体的生图指令都落空，本地出图速度取决于硬件。

## 平台与形态

平台与形态的账：设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态，建宠或编辑宠的表单里选：自动（本地已装对话模型）或指定模型，多个大模型开始围绕它讨论，本地模型多宠同发会排队（本地档 4 路并发上限）。
