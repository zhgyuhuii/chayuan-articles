# 拆开看ODF保守导入：原理、架构与实现细节

ODF保守导入这个话题我被问过三次以上，每次都要重新讲一遍。与其反复口述，不如写成一篇：从字节保真与格式兼容的入口讲到验证，中间的分支也一并说清，基于察元AI Office。

## 这个功能到底解决什么问题

察元AI Office 打开和保存的是真实的 .docx/.xlsx/.pptx 文件，保存时只重新生成你真正编辑过的块，其余内容连同压缩包里的其他部件逐字节原样搬回——所以用 Word/WPS 再打开时，没编辑过的部分版式毫无变化（「打开保存无感」）。本篇讲清「什么时候会变、什么时候绝不变」，并给出几个你自己就能做的验证方法。

改一个字不该弄乱整个文件的格式，字节保真是最硬的承诺。

入口、步骤、验证三段看清，这事就顺了。

5. 什么时候会变、什么时候绝不变（速查表）

| 场景 | 会变的部分 | 绝不变的部分 |
|---|---|---|
| 保存编辑过的 .docx | 你编辑的块重新生成为 OOXML 片段（只引用文档已有样式；缺失的标题级别按 Word 内置定义补进 styles.xml） | 其余块按原文件逐字节拼回；其他 zip 部件原样复制；完全无改动时整文件原字节返回 |
| 大文档（图多/上 GB） | 无 | 图片按 sha256 锚定留在原文件里（渲染时按需供给），保存时把占位符换回原字节；zip 条目按存储字节搬运、不解压不重压，代价只是读 XML 部件 |
| Sheets（.xlsx） | 你编辑的单元格/图表按窄补丁写回 | 未触碰的工作表部件原样保留 |
| Slides（.pptx） | 你编辑的元素重新生成片段 | 没有脏元素时整个条目逐字节写回；其他条目原样复制 |
| ODF 导入 | 转出的是新副本（.docx/.xlsx/.pptx） | 原 .odt/.ods/.odp 文件只读不动；转不了的构造型进 dropped 清单而不是乱转 |
| HTML/Markdown 保存 | 你编辑处的连续片段 | 其余源码逐字保留；BOM/换行风格/末尾换行原样保留 |

6. 背后的机制（一段话版）

打开 docx 时：原文件先按内容哈希归档一份备份（归档件从此不被改动），引擎把 word/document.xml 解析成顶层块树，每个块带着自己在原文件里的字节位置与原始 XML 切片。保存时：被编辑的「脏块」重新生成 OOXML 片段拼接回原位，未触碰的块把原始 XML 逐字节拼回去，再把压缩包里其余条目按存储字节逐一复制进新包。Sheets/Slides 同一哲学：窄补丁、原样搬运。HTML 与 Markdown 编辑器同源：源码补丁/块级拼接 + BOM/CRLF/末尾换行保真。

## 你可能会问

### ODT 里明明有脚注/批注，转过来怎么没了？

ODF 转换按「能证明正确才转」执行：脚注、批注、文本框等构造型当前不完整保留，确认框里逐项写明，转换器内部把它们计入丢弃清单（dropped），不做近似猜测。对格式要求严格的文档，建议转换后核对确认框列出的这几类内容。

### 几百 MB 的 docx 打开很慢吗？图片会全部塞进内存吗？

不会。浏览器可直接解码的图片（png/jpg/gif/bmp/webp/svg）留在磁盘上的原文件里，界面按需读取；保存时再把原字节换回。压缩包条目按存储字节搬运、不解压再压缩，大文档的代价主要是读取 XML 部件。

### PDF 呢？PDF 转换也保真吗？

PDF 是「真文本编辑」（重写内容流、保留原字体，不是注释遮盖）与「全本地 PDF＞Word/PPT/Excel 转换」，与本篇的 OOXML 往返是两条技术线，见对应教程 与 O32。

### 为什么我只改了一个字，git diff 却还有别的变化？

先确认对比的基线：若之前有别的软件保存过该文件，那些归一化不是察元AI Office 造成的。在察元AI Office 内做的一次编辑，未触碰块是逐字节写回的；换行风格、BOM、末尾换行也不改。若仍有意外差异，可以把文件发给我们排查（侧栏「反馈」）。

## 补充答疑

### 保存后的文件真的和 Word/WPS 完全兼容吗？

打开和保存的都是标准 OOXML。设计目标就是「未触碰部分逐字节保留，Word/WPS 打开无感」；你编辑的块按 Word 规范重新生成，且只引用文档里已有的样式，不会引入让 Word 报修复的私有写法。

### HTML 导出 Word 后，为什么图表变成了一张图片？

HTML 页面的视觉（图表、图标、装饰盒）没有等价的 Word 结构，导出时截图保留外观；文字、标题、列表、表格则转成原生 Word 内容可以继续编辑。想要纯文字版，可先在 HTML 编辑器里删掉装饰性视觉再导出。

## 安装与运行答疑

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。
