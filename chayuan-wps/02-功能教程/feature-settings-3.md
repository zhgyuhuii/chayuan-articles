# 从需求到交付：写回动作设置

「察元的设置在哪里？都有哪些配置项」——这个问题最近被问了好几次。答案不复杂：写回动作设置在察元AI文档助手里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 为什么值得了解

想改默认模型、配置厂商、管理助手，但不知道在哪个页签，按习惯改默认写回，团队统一下发配置口径，要接知识库、管理 MCP 服务、改数据落盘路径。

## 完整操作步骤

第 5 步 · 助手设置页

第二列标题「助手设置项」：按分组折叠的助手清单（每组标题行可展开，显示数量；底部提示「可拖拽排序，右键菜单可复制、删除、上移、下移」），工具栏按钮：「导入助手」「新建分组」「从智能空间同步」（宿主助手模式下为「新建助手」）。选中单个助手后右侧编辑其参数。详见对应教程 教程。

第 6 步 · 常规设置 ＞ 数据设置

1. 在哪：左栏「常规设置」＞ 第二列「数据设置」。
2. 看到什么：标题「数据路径设置」，说明原文：「设置后，规则数据（relus.aidooo）、导入的文档模板等本地数据将统一保存到此路径下。留空则规则不写入本地文件。」
3. 做什么：在路径输入框直接填，或点「选择文件夹」；下方显示「默认路径：…」和只读的「错误日志目录（只读）：…」；「使用默认路径」按钮一键还原。页面下方还有「多模态服务端 Fallback」开关与「服务端接口地址 / 接口密钥」输入框（长视频或本地抽帧能力不足时的服务端分析兜底）。改完点窗口底部「保存」。

第 7 步 · 常规设置 ＞ 知识库设置

内嵌完整的知识库设置面板（本机发现与远程连接三鉴权），详见对应教程。

## 关键能力点

- 模型清单管理
- 写回动作默认值
- 网络代理设置

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 你可能会问

### 左栏为什么只有四项？听说还有历史版本 / 评测历史 / 能力审计页？

这三页（历史版本列表、评测历史、能力审计）在代码中属隐藏主菜单：左栏不显示，点击入口会被拦回「模型设置」，带这些页参数的深链打开时也会被重定向。当前版本没有常规入口，属预留页面，日常配置用不到。

### 设置窗口打不开，或点了没反应？

设置是单实例窗口：已有一个设置窗口（可能被挡在后面）时，再点「设置」只是把它带到前台。关掉旧窗口或切换过去即可。

### 数据路径留空会怎样？

按面板原文：「留空则规则不写入本地文件。」错误日志也会落到各系统默认位置，不影响其它功能使用。

## 更多操作细节

第 1 步 · 打开设置窗口

在哪：三个等价入口——

看到什么：弹出独立设置窗口（默认 1120×820，三列布局）。设置窗口是单实例的——已开着时再点「设置」，只会把已有窗口带到前台，不会开第二个。

1. AI 助手窗格侧栏左下角「设置」齿轮按钮（悬停提示「设置」）；
2. 「察元AI编审」选项卡 ＞「察元设置」分组 ＞「设置」按钮；
3. 表格端 / 演示端「察元AI助理」选项卡上的「设置」按钮。

## 更多操作细节

第 2 步 · 左栏四大项（第一列主菜单）

| 菜单项 | 管什么 |
|---|---|
| 「模型设置」 | 打开设置默认落在这页：配置各家模型供应商 |
| 「默认设置」 | 按模型类型设默认模型；网络资源搜索；段落截取 |
| 「助手设置」 | 内置 / 自定义助手的管理与参数 |
| 「常规设置」 | 点开后在第二列出现三个子页：数据设置 / 知识库设置 / MCP 服务管理 |

## 更多操作细节

第 3 步 · 模型设置页

1. 第二列：厂商清单，按「自定义 / 国内平台 / 国际平台 / 本地与自建 / API 聚合」五组折叠分组，顶部「全部 / 免Key / 免费」筛选＋搜索框；每行带「免Key / 免费 / 免费额度」标签与「已开启 / 已配置 / 未配置 / 异常」状态徽标；清单支持拖拽排序，右键「自定义」厂商可编辑 / 删除。
2. 第三列：选中厂商的配置面板——启用开关、「API 密钥」「API 地址」「模型」清单（「刷新模型」「管理」）与检测按钮。详见对应教程。

## 更多操作细节

第 4 步 · 默认设置页

第二列标题「模型设置项」，共六项：前四项为模型分类——「对话模型」「图像生成模型」「视频生成模型」「语音转换模型」，外加「网络资源搜索」「段落截取设置」。选中后在右侧设置：

1. 模型分类项：右侧「默认模型」下拉，按厂商分组选择；提示「仅显示在模型设置中已开启且已配置的对应类型模型（对话/图像/视频/语音）」。
2. 「段落截取设置」：大文档分批处理的参数——「截取长度（字符）」（建议 2000–8000，默认 4000）、「上下重叠长度（字符）」（默认 200）、「分段策略」（按段落 / 按句子 / 按字符），以及「建议复核问题写入批注」开关。
3. 「网络资源搜索」：内嵌网络资源搜索面板。

## 更多操作细节

第 8 步 · 常规设置 ＞ MCP 服务管理

1. 看到什么：标题「MCP 服务管理」＋状态行（形如「本机在线 · Agent 已注册」），右上「刷新」「添加」按钮。
2. 做什么：「刷新」重新探测全部服务状态；「添加」弹出添加 MCP 服务表单（名称 / 地址 / 请求头 / 启用开关）；点列表中的服务条目进详情（在线状态、工具清单、编辑 / 删除）。
