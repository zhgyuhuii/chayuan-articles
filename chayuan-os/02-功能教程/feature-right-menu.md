# 桌面空白处右键：右键菜单完整走法

「桌面右键都有什么功能」——这个问题最近被问了好几次。答案不复杂：右键菜单在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先弄清楚它是什么

右键菜单是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，桌面右键菜单是其中面向这类需求的一环。

入口、步骤、验证三段看清，这事就顺了。

## 先确认这些再开始

- 桌面形态（察元AI OS）、非锁屏状态。菜单只在桌面空白处弹出（右键到图标/窗口上是各自的菜单）。
- 「新建」「上传文件…」等文件项需要桌面文件服务在线（桌面形态默认在线；探测失败的降级环境下「新建」折叠为「新建文件」且无上传项）。
- 「录制屏幕」「语音记录」只在运行环境支持时出现（浏览器录屏 API 可用等）。

## 一步步来

在桌面空白处右键，菜单自上而下（部分项带 子菜单，悬停展开；触屏点按展开）：

文件与工作区

1. 「用智能体打开」：弹出智能体选择（提示「选择智能体（稍后选择工作区）」），先选智能体再选工作区，直接开工。
2. 「新建或选择工作区…」（快捷键 ⌘N）：弹系统对话框选一个本机文件夹（可在对话框里新建），选中即注册为工作区，桌面出现对应图标，与 Harness 侧同源生效。
3. 「新建」 子菜单：「新建文件夹」「新建文本文档」——在桌面真实目录创建并立即进入重命名态。（降级环境下该项为「新建文件」。）
4. 「上传文件…」：弹多选文件框，把本机文件上传到桌面目录。
5. 「粘贴」（快捷键 ⌘V，仅剪贴板里有内容时出现）：把复制/剪切的文件粘到桌面。

信息

1. 「显示简介」（快捷键 ⌘I）：弹出「桌面信息」小窗，显示当前屏幕分辨率（屏幕：宽×高）与用户代理前缀。

## 怎么确认做成了

验证

1. 右键 ＞ 「图标大小」＞ 「大」：桌面图标立即变大，重开菜单「大」前带 。
2. 右键 ＞ 「排序方式」＞ 「大小」：桌面图标按文件大小重排（位置映射随之更新）。
3. 右键 ＞ 「新建」＞ 「新建文件夹」：桌面出现「新建文件夹」图标且名字处于可编辑状态，输入名字回车即建好（可在「我的电脑」桌面目录里看到该文件夹）。

## 谁需要这个功能

右键把文档丢给智能体总结；刚上手，不知道桌面右键里藏了哪些功能，桌面图标太大/太乱、想隐藏图标只看壁纸，或找不到便签入口；想快速新建文件夹、上传文件到桌面、整理图标。

用户常搜的问法：桌面右键都有什么功能；怎么把桌面图标调大/自动排列。

## 它的局限也要说清楚

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 右键出来的菜单比教程里少几项？

菜单按环境裁剪：剪贴板空则无「粘贴」；录屏/录音不支持的环境不显示对应项；文件服务不在线时「新建」折叠、无「上传文件…」。缺哪项先对照上面每项的出现条件。

### 「新建或选择工作区…」点了没反应？

该功能依赖系统文件夹选择对话框（桌面形态支持）。弹窗被别的窗口挡住时先看看屏幕深处；环境不支持会弹提示。

### 录屏提示「无法读取屏幕源…」？

按提示到 系统设置 ＞ 隐私与安全性 ＞ 屏幕录制 给察元授权后重试（macOS 系统权限）。

### 图标拖到一半总是弹回？

开了「自动排列图标」后图标会被网格吸回。先右键取消勾选「自动排列图标」，再自由拖放；摆好后可用「清理」一键对齐。

## 更多操作细节

个性化

1. 「更改墙纸…」：打开「选取墙纸」窗口换壁纸。
2. 「编辑小组件…」：打开「小组件」抽屉添加/管理桌面挂件。
3. 「便签」 子菜单：常驻的便签找回入口——「新建便签」＋全部便签列表（最多列 20 条，前带 的表示在屏，点条目切换上屏/收起）。
4. 「隐藏桌面图标」/「显示桌面图标」（二态互切）：藏起全部桌面图标只留壁纸，再点反向恢复。
5. 「图标大小」 子菜单：「小」「中」「大」三挡（默认「中」），当前挡位带 ；只改显示尺寸，不动图标位置。
6. 「排序方式」 子菜单：「名称」「修改日期」「大小」「种类」四种排序，当前项带 。
7. 「自动排列图标」（勾选态开关）：开启后图标自动贴网格排列、拖动后归位。
8. 「关窗特效」 子菜单：「无」「随机」＋ 19 款英文特效（Broken Glass、Doom、Energize A/B、Fire、Glitch、Hexagon、Incinerate、Matrix、Paint Brush、Pixelate、Pixel Wipe、Portal、RGB Warp、Snap、TeamRocket、T-Rex Attack、TV Effect、Wisps），选中项带 ，关窗时播放对应动画。

## 更多操作细节

录制（按环境出现）

1. 「录制屏幕」/「停止录制」：唤起录制选择器（整屏/页面/区域）开始或停止录屏。
2. 「语音记录」/「停止语音记录」：唤起顶部录音长条，录音转写。

## 更多操作细节

整理与刷新

菜单外常被一起问到的：废纸篓不在桌面右键里，它在 Dock 最右端——左键打开废纸篓应用，右键可选「打开废纸篓/「清倒废纸篓」，把文件拖到它上面即删除进回收站。

1. 「清理」：把散乱的桌面图标按网格就近整理归位。
2. 「在文件管理中打开」：打开「我的电脑」直达桌面目录（/desktop）。
3. 「刷新」（快捷键 ⌘R）：文件服务在线时软刷新（重列桌面目录），否则整页重载。
