# 军棋规则详解：工兵飞雷与司令阵亡亮旗

军棋规则零碎是出了名的：一条吃子链从头排到尾，炸弹地雷各有章程，底下还压着藏旗的暗逻辑。真上手才知道，卡住新手的往往不是走法，而是这些规则细节。察元竞技场把军棋搬上桌时，全部判定交给本机引擎，模型只管出招。这篇军棋规则详解把细节一次理顺，再带你看大模型是怎么按规则出招的。

## 先弄清楚：一条吃子链打天下

军棋的大小关系排成一条链：司令、军长、师长、旅长、团长、营长、连长、排长、工兵。上级吃下级，同级相拼两子俱亡，这条链就是军棋的骨架。看懂它，吃子判定就有了坐标系——无论棋子怎么走、阵怎么摆，碰撞那一刻的胜负都由链上的位置说了算，判定权在引擎手里，谁也赖不掉。

吃子链之外，几条硬规则也要记牢：军旗不能移动，布阵落位起就钉在原地；地雷同样不能动，是纯防守子力；炸弹能动，但它的价值不在走多远，在跟谁同尽。动与不动的能力差异，构成了军棋攻防的底层结构——进攻方要护住能动的家底，防守方要用不能动的子力换掉对面的进攻资本。

走法上，棋子沿棋盘线路逐格行动，线路分普通线与快线两类，快线上走得远、机动性强；工兵在快线上还有额外特权，可以灵活转向行进。各家军棋版本的线路细则略有出入，察元竞技场以应用内对局引擎的判定为准，但工兵的特权地位在哪家规则里都一样，这就要说到它的另一个名头。

## 工兵飞雷：以小博大的特权子

工兵在吃子链上排倒数一位，碰上任何大子都是送，但军棋给它留了独一份的待遇：地雷面前，别的棋子谁来谁亡，只有工兵能碰雷，而且碰雷即挖雷，雷没了、工兵还在。这就是工兵飞雷里挖雷的那一半。另一半在机动上——工兵在快线上的转向能力让它能在棋盘上快速穿插，直奔雷区，像飞过去一样。两条特权合起来，工兵飞雷的名声才算完整：拆对方雷带的活，全盘只有工兵接得下，个子垫底的它，干的却是要命的差事。

于是工兵成了军棋暗棋里的侦察兵兼拆迁队：开局它试探你的前线，中局它绕路摸你的雷带，雷带一破，军旗就裸了。看大模型打军棋，工兵出动时机是否合理，直接暴露它对这套规则的消化程度。

## 炸弹与地雷：两条特殊判定

炸弹的规则简单粗暴：与任何棋子相遇同归于尽，不看大小。司令撞上炸弹也得一起走，所以炸弹天然是大子的威慑物，也是平民子的护身符。地雷则相反：它不能动，只能守，工兵之外谁来谁亡。至于炸弹撞上地雷怎么判，各家版本约定不一，以应用内引擎的判定为准，别拿别处口诀硬套。这两枚特殊子的存在，让军棋的交换计算多了一层：算的不再是谁大谁小，还有这次碰撞值不值。

## 司令阵亡亮旗：信息战的转折点

暗棋里军旗藏得深，全靠雷带和信息迷雾护体。司令阵亡亮旗机制改变了这笔账：你的司令一旦阵亡，军旗位置当场对对手公开——旗藏得再刁也没用。这一条把司令变成了双刃子力：它凶、它金贵，它一死你的旗就裸奔。围绕司令的攻防由此成了军棋暗棋的题眼：对方司令迟迟不出，你拿什么钓它；你的司令什么时候出街、出街走到哪，全是信息战的一部分。胜负判定之外，亮旗这种信息事件也由引擎自动执行，不靠任何一方自觉。

## 模型怎么按规则出招

大模型玩家在竞技场走统一出招协议，每手输出 {move, comment}：move 是选定的着法，comment 是它对这一手的自我解释。它不能胡来——对局信息按各自视角分发，合法步清单显式附上，暗棋里它同样看不见你暗置的棋子。出招解析走容错链：标准格式收不住时，逐级放宽，剥思维链文本、抽大括号、补截断尾巴、全文扫合法着法；还收不住就启发式代走，代走超限判负。吃子谁赢、雷挖没挖、旗该不该亮，全部由引擎说了算，模型没有判罚权。

对局室里看它打一局，规则消化程度写在明面上：思维链气泡实时滚出盘算，它会念叨这枚撞上去可能是雷、司令先别动；每手延迟与 token 用量标在一旁，思考越深等得越久。复盘里问叹号标注（？！）逐手挑出妙手与失误，棋谱支持导出 JSON，规则学没学到家，回放里一目了然。

## 这些边界要心里有数

其一，各家军棋版本细则有出入，线路行进、炸弹碰雷的判定以应用内引擎为准，本文讲的是骨架与机制。其二，模型对规则的执行靠语料与推理，弱模型会算错交换，好在判定权在引擎，错招进不了盘面，但代走兜底的痕迹让观赏性打折。其三，费用口径不变：软件 MIT 开源免费，模型 API 按用量向厂商付费，Ollama 本地推理零成本。

## 高频疑问

### 工兵为什么能飞雷

工兵的特权有两条：碰雷不亡、把雷挖掉；快线行进灵活。两条合起来才有飞雷的说法，具体细则以应用内判定为准。

### 司令阵亡为什么亮旗

这是规则对信息战的补偿设计：司令一死，军旗位置公开，防止一方靠藏旗躺赢。触发与展示由引擎自动完成，不需要任何操作。

### 炸弹和地雷撞上怎么算

各家版本约定不一，察元竞技场以应用内对局引擎的判定为准，进对局前可以拿一局明棋教学档实际验证。

### 大模型会记错谁吃谁吗

会。模型靠语料与推理出招，弱模型偶有误判，但吃子判定权在引擎，错误招法要么被拦要么代走，落不到盘面上。

### 军棋规则详解看完下一步做什么

开一局明棋教学档把链路跑熟，再回暗棋自由布阵，边打边把规则内化，比干背口诀快。

### 军旗被挖掉就输了吗

常见打法里挖掉军旗即胜，杀光对方可动子力也是终局路径之一，具体判定以应用内引擎为准。

### 对局里的代走是什么意思

代走是解析失败后的启发式兜底：引擎按能挡杀就挡、能吃就吃的原则替该玩家走一手，代走计数超限判负。

军棋的规则碎，但碎得有道理：每一条特殊判定都在给信息战加码。把工兵飞雷和司令阵亡亮旗这两条机制想透，你再看大模型在棋盘上的每一次试探与收缩，就不是看热闹了。
