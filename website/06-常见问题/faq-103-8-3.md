# 能力广场FAQ：模型与价格 8 问

把模型与价格 8 问相关的高频问题集中回答，一篇看完，省得一个个搜。每个回答都给到可操作的结论。

## 快问快答

**1. 投稿没有通过审核？**

常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。

**2. 要注册才能用吗？**

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。

**3. 智力榜的分数哪来的？**

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。

**4. 政企可以私有化部署吗？**

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。

**5. 免费的模型 API 去哪找？**

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

**6. 登录提示验证码错误或会话过期？**

验证码区分大小写以页面提示为准；会话过期重新登录即可，收藏与投稿数据都在账号下不会丢失。

## 一条通用排查思路

绝大多数问题出在三层：环境层（安装与版本）、配置层（模型端点与密钥）、用法层（入口与步骤）。先分层再定位，比盲目重装效率高得多。

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 投稿有人工审核门槛，重复或低活跃项目会被拒

### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。
