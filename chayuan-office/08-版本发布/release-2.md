# 察元AI Office 1.0.x 系列

## 1.0.x 系列 更新了什么

察元AI Office在2026-10发布1.0.x 系列。本文把3 项要点逐条过一遍，每条附一个与之相关的常见问题，最后给升级步骤与回退方案。

## 要点逐条看

1. PDF 真文本编辑与涂黑

这项更新直接作用的场景：PDF 真文本编辑与涂黑

2. 扫描件 OCR 自动触发

这项更新直接作用的场景：扫描件 OCR 自动触发

相关常见问题——打开扫描件没有出现「正在识别扫描页」浮条？ 三种可能：①页面其实有文字层（能选中文字就不是扫描件，按定义不过 OCR）；②Linux 平台没有系统识别引擎，应用静默保持原样（没有浮条也不识别）；③扫描页很少且识别瞬间完成，浮条一闪而过自动收起。

3. CLI 17 子命令与 MCP 服务

这项更新直接作用的场景：CLI 17 子命令与 MCP 服务

相关常见问题——stdio 和「本地 MCP 服务」两种形态怎么选？ 助手能自己拉起命令就用 stdio（形态 A）：不需要应用开着、配置只有一条、工具最全（29 个，含 deck 流水线）。想让助手操作你正打开的窗口/标签页（open_documents）、或客户端只能填 URL，才用应用内 HTTP 形态（形态 B）。面板原文也建议：「助手能运行终端命令就用 CLI，不能就用 MCP」。

## 升级步骤

1. 升级前备份：备份用户配置目录后覆盖安装
2. 获取新版：官网 aidooo.com 下载对应平台安装包或 GitHub Releases
3. 覆盖安装，数据目录自动保留
4. 启动后到设置或关于页确认版本号已更新

## 出问题怎么回退

覆盖安装出问题时，重装上一版本安装包即可回退，数据目录兼容。断网环境用离线安装包加逐文件校验的方式升级。

## 安全与数据边界

安全口径单独立一层：改写不丢位置：锚点字符级迁移意味着 AI 改完你光标还在原处；AI 动过的每一处都留痕可审，这是敢让它改正式文件的前提，选区右键对 AI 隐藏：内容替换成占位符再进上下文；报价、身份证号这类片段不想给模型看，隐藏后其他部分照常 AI 处理；对外发文前先扫一遍敏感信息，占位符方案让文档既能给外部 AI 处理又不泄密。
