# 三平台安装包：WPS AI概念与上手

WPS AI 几分成色，断网一测便知：拔掉网线还剩多少可用功能，是虚是实立见分晓。本文以这个标准开头，从能力面讲到边界，对象是察元AI文档助手。

## 什么是WPS AI

把WPS AI拆开看，它指的是这样一类东西：察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。

全部口径对照官方文档逐条核过，版本对应关系见文末。

## 在察元AI文档助手里落在哪

WPS AI在察元AI文档助手里的落点是下载与安装：Windows 自解压 exe、macOS 的 pkg（建议先完全退出 WPS 再装）、Linux 与麒麟 UOS 的 deb（飞腾鲲鹏选 arm64）；安装本质是把加载项放进 WPS 的 jsaddons 目录并注册本机服务自启。

单独拎出来讲的考虑：办公软件不用换、操作习惯不用改，相当于在原有 WPS 上加一个 AI 引擎，迁移成本几乎为零。

## 最短上手路径

照着做，按平台对号：

1. Windows：运行自解压 exe 安装。
2. macOS：先完全退出 WPS，再运行 pkg 安装包。
3. Linux 与麒麟 UOS：安装 deb 包，飞腾鲲鹏选 arm64。
4. 验证：装完完全退出并重启 WPS，文字端出现察元AI助理与察元AI编审两个选项卡即成功。

## 落点的能力面

- 三平台安装包
- macOS 容器写入失败有修复脚本
- 企业可 HTTPS 静态部署集中更新

这三条对应三种处境：个人用户按平台拿对应安装包直接装；macOS 装完若遇到容器写入失败，先跑修复脚本再重启，不必急着重装；企业内网走 HTTPS 静态部署，更新集中管理。

## 察元AI文档助手的能力地图

- 助手管理：助手目录搜索、收藏常用、按领域浏览，形成自己的助手工作台。
- 拼写与语法检查：AI 助手组大按钮拼写与语法检查：有选中只查选中，
- 图像批量操作：6 项图像批量操作：文档内图片的统一处理。
- 表格助手：表格端大按钮：AI 表格助手、公式助手、数据洞察、一键图表、数据清洗、报表结……
- 演示助手：演示端大按钮：AI 演示助手、生成 PPT、整套摘要、美化统一、口播稿、整套……
- 三级生图与网络搜图：配图三级降级链：第一级模型生图（最多试 3 个模型）；

## 四条容易被忽略的限制

- 脱密、复原、保密检查、涉密关键词提取属于付费范围，免费部分不覆盖
- 占位替换可以还原，前提是密码在手；丢了密码，免密恢复的口子一个都没有
- 文档全文会交给所配置的模型处理，涉密材料建议预先切换到本机离线模型
- 痕迹检查的性质是提示疑似，复查之前不要直接下结论

限制认清楚，主线使用并不受牵连；安装之前把账算明白，总好过用一半才发现。

## 数据与安全设计

- 每次确认写操作记入 audit.jsonl 审计日志
- 保密检查只做辅助筛查，关键词命中不等于泄密，不构成定密结论
- 脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原

## 价格口径

- 免费有每日额度（对话与助手独立额度池，次日重置）

## 你可能想问的几件事

### WPS AI断网后还能用吗

看模型放在哪：模型换成 Ollama 这类本机方案，处理过程不出网，涉密文档可以全程不联网；走云端模型的功能才依赖网络。

### WPS AI的每日免费额度是怎么池化的

额度分两池：对话一池、助手一池，互不挤占，过夜刷新；付费侧只有四项——文档脱密、脱密复原、保密检查、涉密关键词提取，零免费额度。

## 一句收束

WPS AI装不装，看你对 AI 进办公文档的接受度：愿意让批注、替换、痕迹检查这些动作发生在 WPS 里的，这个加载项省去换软件的折腾；对 AI 动正文有顾虑的，先把默认动作设成仅生成再慢慢试。

## 装好后的选项卡布局

把WPS AI放回察元AI文档助手的整体盘面：文字端是助理、编审两个选项卡，表格/演示端各一个助理选项卡；自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源；企业环境还可 HTTPS 静态部署集中更新。

## 痕迹检查与脱密的口径

AI 痕迹七维度检查给的是疑似结论，只作人工复核线索；把涉密词换成占位符后，文档就能放心交给 AI 处理或外部流转，需要时凭密码还原；涉密信息提取走 AI 加正则双路。编审选项卡的表单模式：书签转内容控件表单化，书签按名称加 id 加序号命名；智能提取让 AI 从样例文档抽字段自动生成表单规则，再人工微调。

## 写回方式决定信任感

AI 先读懂你的文档再干活，而不是让你复述内容；结果落到文档的方式决定信任感：批注式让你过目，替换式提效率。拼写与语法检查按范围走：有选中只查选中。

## 它跟 MCP 服务的关系

察元AI文档助手不是单打独斗：WPS 三端智能加载项，校对、编审、核对、脱密，一个文档智能体；MCP 服务是外部智能体操作 WPS 文档的桥，开机自启保证随时可用；让 Claude Code 直接操作你正开着的 WPS 文档，编程智能体与办公文档打通；装好就自动接上，资料问答在 WPS 里直接问，不用配地址。

顺带把两个端口说清：62588 是 MCP 文档智能体服务，52582 是本机知识库服务，两个端口各管一摊，排障时别搞混；前者随系统自启，后者在 OS 一侧、由加载项自动发现。

只记一点的话：安装包分三平台，exe 对 Windows、pkg 对 macOS、deb 对 Linux 与麒麟 UOS；架构别选错，飞腾鲲鹏对应 arm64。
