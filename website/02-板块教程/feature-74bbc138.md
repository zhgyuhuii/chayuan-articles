# 为智能体配齐工具箱：速查手册

MCP 配置片段+技能包+智能体应用三步扩容。这套组合工作流把MCP 服务器板块→Skills 技能板块→智能体应用板块串成一条线，在察元AI 能力广场里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

MCP 配置片段+技能包+智能体应用三步扩容。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI 能力广场的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·MCP 服务器板块**：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

1. 进入 mcp 板块
2. 按功能关键词搜索
3. 复制 JSON 配置片段到客户端

**第 2 步·Skills 技能板块**：可装进 Harness 类智能体的大模型技能包目录：SKILL.md 形态技能的发现与安装入口。

1. 进入 skill 板块
2. 按领域或热度筛选
3. 复制安装命令或仓库地址

**第 3 步·智能体应用板块**：智能体应用与自动化方案目录：含安装/使用命令，覆盖各类数字员工与垂直智能体。

1. 进入 agent 板块
2. 按场景筛选
3. 按条目指引安装使用

## 衔接点与易错处

- 配置片段可直接粘贴进客户端 MCP 配置
- 优先选 active 状态条目
- 技能与插件配合使用效果更佳
- 结合行业场景库交叉浏览

## 常见问题
### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。
