# 手机版使用安装指南：全平台步骤与验证

直接上干货。智能广场总览在察元AI 能力广场里的定位一句话能说清：智能体门户，插件、技能、MCP、提示词、大模型资源一站检索与下载。具体怎么操作、有什么讲究，往下看。

## 安装前确认

- 系统要求：现代浏览器
- 安装包：网页服务
- 说明：底部 Tab 导航。

网页端 aidooo.com；桌面产品可从站内下载 Windows/macOS/Linux（含麒麟/UOS）安装包。安装包从官网 aidooo.com 获取。

## 操作步骤详解

1. 浏览器打开 aidooo.com
2. 导航进智能广场或教程库
3. 登录后可收藏、投稿、下载产品安装包
4. 产品下载页按平台与架构给出直链

## 装完后的第一件事

开始页新建一个 docx，在设置模型里接上厂商 API 或本机 Ollama，然后让首页 AI 生成一段测试文本——三步都通，环境就绪。

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 若没有生效，先完全退出宿主软件再重启一次

## 别在这几处栽跟头

- 榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜

## 你可能会问

### 下载安装包需要登录吗？

需要。完成站内账号或微信扫码登录后即可下载，登录后还能收藏资源与管理下载记录。

### 怎么确认下载的是官方安装包？

官网 aidooo.com 是仅有的官方分发入口，下载页直链由管理后台自动同步生成；不要使用第三方站点的镜像包。

## 补充答疑

### 需要注册才能用吗？

浏览与检索免注册；下载安装包、收藏、投稿需要登录，支持站内账号与微信扫码两种方式。

### 移动端能用吗？

可以，移动端有底部导航（广场、榜单、产品、更多、我的），核心浏览与下载流程都适配了。

### 能力广场的资源总量有多少？

站方口径是 10 万以上资源一站检索，覆盖插件、技能、MCP、提示词、智能体应用、大模型、模型厂商与资讯八大板块，另加技能包商城与教程库。

官网教程库另含每个内置助手的使用说明书，按 228 个行业领域分目录：助手干什么、在哪找、怎么用、输出长什么样、怎么改提示词、选哪个模型、如何配合知识库，一篇讲透一个助手，随助手定义更新而再生成。

## 榜单的算法口径

日榜按当日增量，周月季半年年榜按周期内 star 增量；每日同步任务先抓 star 写快照再重算榜单。无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；dead 或 archived 的失效资源自动剔除出榜；快照不足时降级为总量榜并明确标注。

## 技能包的形态

每个技能包含 3 到 6 个互补技能，组成一套岗位工作流（pack.json 清单加逐技能教程）；购买后凭 token 拉取对应平台安装脚本，token 限次限机可吊销。首批配额 300 包，目标是千包规模，已有 310 个以上主题。

## 下载中心的机制

首页产品家族四卡对应察元AI OS、察元AI Office、察元AI文档助手与察元AI工舱，下载清单由管理后台的发布流程自动同步生成（产品、渠道、平台、架构逐级展开），手工编辑会被下次发布覆盖，保证直链始终指向最新版本；带提取码的网盘链接会自动复制提取码。

安装这步别跳验证：装完先确认核心功能可用，再往下配。
