# 减弱动效为什么这样工作：老机器关动效提速

减弱动效要配得对，无非弄清三件事：开关藏在哪、勾上之后发生什么、怎么确认生效。这篇沿察元AI OS 的界面动线把减弱动效从头到尾过一遍，老机器想靠关动效提速的，直接看缩放与动效两节。

## 是什么与为什么

减弱动效在察元AI OS里的形态一句话说清：减弱动效、减弱透明、界面缩放三件套。这几个开关彼此独立，可以单独开也能组合用，按机器状况和眼睛的感受取舍就行。

## 一步步来

按最短路径验证一遍：

第 4 步 · 界面缩放

1. 操作：在「界面缩放」下拉框选一档：「85%」「100%（默认）」「115%」「130%」。
2. 界面反应：整个桌面（含窗口、Dock、菜单栏）按所选比例即时缩放，无需重启。

连带的行为（不用另设开关）

1. 关窗特效：设置 ＞ 显示器 ＞ 窗口动效里若选了 Burn-My-Windows 特效，「减弱动效」开着时特效一律回落普通淡出；
2. Dock：图标放大/弹跳等过渡动画随「减弱动效」一并停（设置页说明原文：「减弱动效关闭 Dock 放大/弹跳与过渡动画」）；
3. 开关机画面：重启/退出时的过渡动画同样听「减弱动效」的；
4. 智能体可代管：这三个键在系统设置工具里可读写，对话里说「帮我把界面放大到 130%」同样能改。

## 注意事项与真实边界

动手之前，这几条限制要心里有数：

- 龙芯机型不在支持之列；视频生成本地拿不到，画面走云端路由生成
- 云端厂商模型不是开箱即用，API Key 需自备
- 内存 8GB 的设备一次挂一个对话模型为宜，任务重了会吃力
- Docker 云桌面、跨终端互联仍属进阶形态，动手门槛不低

## 几个常见的疑问

### 减弱动效开着时关窗特效没反应，算故障吗？

不算故障。优先级上减弱动效更高，关窗特效会自动退成普通淡出，显示器设置的窗口动效卡说明里写明了这一行为；想看特效，先取消「减弱动效」。

### 界面缩放是不是只影响一部分窗口？

只影响一部分窗口的情况不存在。缩放落在整个桌面文档根上（全局 zoom），察元OS 内的应用窗口、Dock、菜单栏一并缩放；智能体打开的原生网页窗等壳外窗口是例外。

### 减弱动效一开 Dock 就不放大了，Dock 出问题了？

Dock 没坏。减弱动效的设定本来就把 Dock 放大/弹跳一并关掉（设置页说明写明）；要放大效果就取消「减弱动效」，Dock 的位置/大小设置不受影响。

### 辅助功能设置在换机器/清浏览器数据后还在不在？

不在。三项配置都放在浏览器本地（localStorage），换机器或清数据后得重新设置；智能体也可以借系统设置工具读写这三个键。

## 第 1 步 · 打开辅助功能设置

1. 在哪里：Dock 中点「设置」应用，左侧栏选「辅助功能」分区。
2. 看到什么：一张「视觉」标题的卡，说明文案：「减弱动效关闭 Dock 放大/弹跳与过渡动画；减弱透明移除玻璃模糊；界面缩放调整整个桌面（远程桌面/低性能环境建议开启前两项）。」

## 第 2 步 · 减弱动效

1. 操作：勾选「减弱动效」复选框。
2. 界面反应：立即生效——全界面注入 animation/transition 全部禁用 的样式，Dock 图标放大/弹跳、窗口过渡动画、锁屏/开关机动画全部停；「关窗特效」就算选了特效也会自动退成普通淡出。
3. 取消勾选即恢复动画。

## 第 3 步 · 减弱透明

1. 操作：勾选「减弱透明」复选框。
2. 界面反应：立即生效——移除全部毛玻璃模糊（backdrop-filter），半透明面板/弹窗变成实底显示。
3. 取消勾选即恢复玻璃质感。

## 配完之后怎么验证

1. 开着「减弱动效」把鼠标扫过 Dock，图标不再放大弹跳；开关一个应用窗口，过渡动画不再出现。
2. 在 设置 ＞ 显示器 ＞ 窗口动效 里把「关窗特效」选成非「无」，再开着「减弱动效」关窗——特效不播放（回落普通淡出）。
3. 「界面缩放」拨到「130%」，桌面元素应声变大；切回「100%」复原。

验证里任何一条不符合预期，先确认对应复选框是否真的勾上了，再看设置页有没有报错提示，最后回到对应步骤小节重走一遍。

## 补充答疑

### 远程桌面用着卡，该怎么配？

建议直接照设置页说明文案来：远程桌面/低性能环境建议开启「减弱动效」+「减弱透明」前两项。

## 开工前过一遍要点

- 无特殊前置：桌面/网页/Docker 任一形态，打开 设置 ＞ 辅助功能 就能配置。
- 三项设置存在浏览器本地（localStorage 键 chatop_reduce_motion / chatop_reduce_transparency / chatop_ui_scale），即时生效、无需重启。
- 这三个键同时是智能体可读写的系统设置键（设置工具 chatop_reduce_motion 等）——直接对话也能让智能体帮你开关。

## 安全与数据的关联项

多人同机时数据按账户隔离，账号归管理员统一管理；在意隐私就把遥测关掉再开工，设备处置前先清数据；本机 MCP HTTP 服务走回环且免 token，敏感操作全量写入审计日志 audit.jsonl，可回放检查；远端调用以远端访客的身份过对端权限门，并留下审计记录。

## 形态差异与适用面

减弱动效、减弱透明、界面缩放三件套在桌面、网页与 Docker 形态下行为一致（web/Docker 形态网页桌面默认端口），低配机与视力需求都被照顾到，动效关掉流畅度立涨。
