## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### AI智能体要联网吗

文件浏览上传、右键用智能体打开、设为默认打开方式，智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明，内置浏览器窗，配合 webwindows 可被智能体驱动。以官网 aidooo.com 当前页面为准。

### AI智能体数据存在哪

整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；账户隔离、数据在服务器侧统一管理；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。以官网 aidooo.com 当前页面为准。
