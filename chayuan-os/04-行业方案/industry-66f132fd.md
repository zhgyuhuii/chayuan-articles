# 法律合规行业怎么用察元OS：从痛点到落地

法律合规行业的文档与信息工作有其固有节奏：文档量大、格式要求严，人工处理占用大量时间。察元AI OS在法律合规场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出法律合规行业的完整应用路径。

## 法律合规行业的典型痛点

- 文档量大、格式要求严，人工处理占用大量时间
- 对外材料有保密与合规要求，外发前自检环节薄弱
- 跨部门数据与引用需要反复核对出处

## 对应的能力组合

- **智能体管理**（智能体管理）：安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。
- **本地知识库**（本地知识库）：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。
- **四家 CLI 智能体**（CLI智能体）：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。
- **macOS 风格桌面**（AI桌面）：菜单栏 + Dock + 可拖拽多窗口的桌面体验：开机动画→锁屏→桌面三阶段，自动锁屏（Ctrl+L）、会话恢复、任务切换器（Alt/⌘+Tab）、通知中心、小组件面板、托盘驻留。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按运维/轻运维场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程

## 常见问题
### 数据存在哪里？怎么备份？

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
