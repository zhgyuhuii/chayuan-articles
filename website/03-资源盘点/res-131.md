# 法务行业技能包盘点：资源怎么找怎么选

法务行业技能包盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：技能包商城（技能包商城）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**技能包商城**：311 个买断制技能包、13 大行业两级分类：包详情含解决什么问题/适合谁，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

1. 进入 /skillpacks 按行业浏览
2. 看包详情的 solves/audience
3. 微信/支付宝买断购买

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标

5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 投稿有人工审核门槛，重复或低活跃项目会被拒

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 投稿有人工审核门槛，重复或低活跃项目会被拒

### 资源失效了怎么办？

条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注；发现问题可通过反馈渠道或机器人客服上报。

### 下载产品从哪个入口？

产品页（/products）集中提供察元AI OS、察元AI Office、察元AI文档助手等的版本说明与各平台安装包入口。

### 和察元产品家族什么关系？

aidooo.com 是家族官网与资源门户：产品下载、激活购买、应用商店目录都在这里；OS 客户端内嵌同源广场。
