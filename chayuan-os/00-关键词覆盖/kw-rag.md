# 怎么新建一个知识库：RAG概念与上手

关于RAG，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是RAG

RAG这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### RAG要联网吗

设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关；最新条目自动投影进各家 CLI 的 AGENTS.md 与 CLAUDE.md；联网环境下内置 web_search 工具默认走 DeepSeek 搜索。以官网 aidooo.com 当前页面为准。

### RAG数据存在哪

全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；最新条目自动投影进各家 CLI 的 AGENTS.md 与 CLAUDE.md。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把RAG放回察元AI OS的整体盘面：桌面系统的基本尊严：能放歌能放片；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。

## 安全与数据边界

安全口径单独立一层：API Key 用 safeStorage 加密存储，遥测可整体停用，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，代理只监听本机回环，跨机访问需要另行打通。

## 平台与形态

平台与形态的账：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；每次产出 markdown 报告落盘归档。

## 价格与授权

价格口径一并交代：官方免费素材库，不用去网上乱找 png，对配对终端开模型加知识库授权；资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问；授权按终端逐台给；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得。

## 产品家族与搭配

察元AI OS不是单打独斗：最新条目自动投影进各家 CLI 的 AGENTS.md 与 CLAUDE.md；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 几条硬数字

能落到数字上的几条：任何网页或本机程序都能变成桌面应用，常用工具一键直达，与知识库、模型联动；共享同一个模型代理；设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

## 离线与内网

离线内网这条线的口径：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；断网时云端模型不可用，可设自动回落本地；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑，完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入，帮助中心离线可读，断网也能查手册。
