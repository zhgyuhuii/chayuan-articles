# 一文分清桌面共享：完整桌面范式

桌面共享这个词常被当成远程会议投屏的同义词，但在本地优先的系统里它另有一层意思：把桌面能力有控制地开放给别的终端。这篇把这层意思讲清。

## 什么是桌面共享

这里的桌面共享，指系统桌面在终端之间的受控开放：出厂默认零共享，开哪类、开给谁，都由使用者显式决定；开多少自己定，这两条合起来就是它的授权观：先给关闭态，再按需打开。做这件事的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

- 8GB 内存设备建议单开对话模型，复杂任务受限

## 桌面共享的两个疑问

### 桌面共享开起来要联网吗

出厂默认零共享，要开也是显式开启；WebRTC 共享走局域网。本机链路能干的活不依赖网络，比如 Stable Diffusion 出图，隐私与免费兼得。

### 桌面共享数据存在哪

升级的底线是不丢数据；检查更新在断网时静默失败，不影响使用。再说一遍形态判断：它不是一个软件窗口，是一整套桌面环境——操作系统形态与工具软件形态的分水岭，数据自然也按整机的目录结构落。

## 一句收束

桌面共享该不该开，回到默认值思考：出厂零共享不是保守，是把开关权留给你的设计；需要时再开，用完就关。

## 桌面五分钟速览

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 窗口与多任务速记

1. 窗口支持拖拽，双击标题栏最大化，拖到屏幕四边触发停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 个性化与右键入口

壁纸是最直接的个性化出口，动态壁纸让桌面活起来；右键是桌面操作的集大成入口：编辑小组件（时钟、天气、照片、日历及玻璃系列、网页挂件）、更改墙纸，用「智能体打开」还能把文件直接交给 AI 处理。设置桌面与 Dock 一栏能调 Dock 位置、自动隐藏、图标放大与大小，还能设开机自动打开 Harness。

## 共享时到底在共享什么

把桌面共享出去，交出去的不是一张截图，而是操作面：观看者看到的是画面，编辑者拿到的是键鼠。这正是三级角色存在的理由——演示给同事看，观看者一档就够；远程协助改配置，才轮到编辑者；主机始终握在你手里，随时能断。比「能不能共享」更该问的是「共享到哪一级」，权限给到刚好的那一档，出事的概率自然小。

## 共享与远端的口径

共享这件事，安全模型比功能列表重要：WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色，共享房间与连接终端状态一目了然，谁只能看、谁能动手，切得清清楚楚；出厂默认零共享，开多少自己定。本机轻薄、远端肥厚时，桌面只当壳：设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力。web 与 docker 形态附带 9 位字母外网后缀的访问链接、wa 会话管理与踢线操作；内置浏览器窗配 webwindows 可由智能体驱动。桌面本身能被 AI 定义，能力边界从预装走向按需生成，任何网页或本机程序都能变成桌面应用、常用工具一键直达。周边再记两条：桌面系统的基本尊严是能放歌能放片；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。
