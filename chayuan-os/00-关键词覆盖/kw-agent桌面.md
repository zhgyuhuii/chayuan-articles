# 完整桌面范式：Agent桌面概念与上手

关于Agent桌面，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是Agent桌面

把Agent桌面拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 平台与形态

平台覆盖：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

Agent桌面在察元AI OS里的落点是桌面环境总览：顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

为什么值得单独说：它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

这些边界不影响主线使用，但选型前知道比不知道强。

## 数据与安全设计

- 全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机
- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- 跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；远端调用以远端访客身份过对端权限门并留审计
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 你可能会问

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### 模型加载失败或提示内存不足？

系统有内存预算硬底线（总内存的 45%）保护：先卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。
