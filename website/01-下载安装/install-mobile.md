# 手机版使用安装：导航智能广场分三栏

手机版使用这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI 能力广场的真实界面顺序走一遍，先解决找某类 MCP 服务。

## 安装前确认

- 系统要求：现代浏览器
- 安装包：网页服务
- 说明：底部 Tab 导航。

安装包从官网 aidooo.com 获取。

## 一步步来

1. 浏览器打开 aidooo.com
2. 导航进智能广场或教程库
3. 登录后可收藏、投稿、下载产品安装包
4. 产品下载页按平台与架构给出直链

## 装完后的第一件事

第一次来建议按三栏动线走：装了就用栏挑一个资源试试检索，模型中心栏看一眼智力榜与免费榜，发现栏扫一遍本周榜单，五分钟对全站有数。

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 若没有生效，先完全退出宿主软件再重启一次

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- 教程库只做元数据导航，正文仍在源站
- 下载前需要完成登录（账号或微信扫码）

## 更多操作细节

逛广场的基本姿势

1. 浏览器打开 aidooo.com，导航点智能广场
2. 按资源类型进对应板块（如 MCP、插件）
3. 关键词检索或按分类浏览
4. 点进详情页查看说明、安装方式与榜单排名

## 更多操作细节

三栏动线怎么走

1. 第一栏按「装了就用」挑资源：插件、技能、MCP 直接进对应市场
2. 第二栏按「查资料」走：模型目录、厂商页、智力榜与免费榜
3. 第三栏按「逛与买」走：榜单发现新品，资讯页看动态
4. 登录后收藏常用条目，下次从我的收藏直进

## 补充答疑

### 能力广场的资源总量有多少？

站方口径是 10 万以上资源一站检索，覆盖插件、技能、MCP、提示词、智能体应用、大模型、模型厂商与资讯八大板块，另加技能包商城与教程库。

### 需要注册才能用吗？

浏览与检索免注册；下载安装包、收藏、投稿需要登录，支持站内账号与微信扫码两种方式。

### 移动端能用吗？

可以，移动端有底部导航（广场、榜单、产品、更多、我的），核心浏览与下载流程都适配了。
