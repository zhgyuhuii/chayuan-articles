# 文档翻译进阶理解：从会用到懂原理

关于文档翻译，网上说法很多，有说简单的有说复杂的。实际用下来，察元AI文档助手的多语种翻译路径是清晰的，只是有些细节不说不知道。这篇按真实操作走一遍，顺带把容易误解的点标出来。

## 先弄清楚它是什么

顶部工具栏「翻译」▾ 按钮下拉出 52 个目标语种（中文、English、日本語、Français、العربية 等，选项直接用对应语言标注），点任一语种即发起后台翻译任务并弹出任务进度窗；默认把选中/全文替换为译文，长文档自动分块逐段安全替换并保护编号与段落样式。

整机文档翻译保持排版不走样，比复制出去翻再贴回来强太多。

下面直接进入正题。

## 机制拆解

整机文档翻译保持排版不走样，比复制出去翻再贴回来强太多。

能力面拆开看：52 语种，逐段替换保格式。

一个常被问到的问题：长文档翻译要多久？为什么分了几批。超过分块长度（默认约 4000 字，可在设置 ＞ 默认设置 ＞ 段落截取设置里调整）会按段落切块、带重叠上下文逐批翻译，批数越多耗时越长。进度窗能看到「第 N 批」推进，中途可「停止处理」。

从提问口径看，用户最关心的是翻译功能支持哪些语言？菜单在哪里？

## 具体怎么操作

按最短路径验证一遍：

1. 展开语种菜单

1. 在哪：顶部工具栏「AI 助手」分组 ＞ 「翻译」▾。
2. 看到什么：菜单内容在点开时动态生成，共 52 个语种按钮，标签用对应语言书写：中文、English、日本語、한국어、Français、Deutsch、Español、Italiano、Português、Русский、العربية、हिन्दी、ไทย、Tiếng Việt、Bahasa Indonesia、Türkçe、Polski、Nederlands、Svenska、Dansk、Norsk、Suomi、Čeština、Magyar、Ελληνικά、עברית、Українська、Română、Български、Hrvatski、Slovenčina、Slovenščina、Lietuvių、Latviešu、Eesti、Bahasa Melayu、Filipino、বাংলা、தமிழ்、తెలుగు、मराठी、ગુજરાતી、ಕನ್ನಡ、മലയാളം、ਪੰਜਾਬੀ、فارسی、اردو、Kiswahili、Afrikaans、Català、Euskara、Galego。

2. 选语种发起任务

1. 做什么：先选中要翻译的文字（推荐），再点目标语种。
2. 看到什么：无选中时弹确认框「当前未选中文档内容，将对全文执行“翻译 - <语种>”。 点击“确定”后开始处理全文。」；确认后弹出任务进度窗，标题「翻译 - <语种>」（如「翻译 - English」），显示分块/批次进度。
3. 翻译要求（内置提示词）：忠实原文、保持结构与编号、专有名词/政策名称/机构名/时间数字优先用标准译法、原文已是目标语言时做忠实润色。

3. 看结果：默认替换为译文

1. 看到什么：翻译助手默认文档动作是「替换文档内容」——选中翻译时选中区域被替换为译文，全文翻译时全文替换。
2. 长文档（超过分块长度，默认约 4000 字/块、块间带重叠）自动分块逐批翻译，写回时逐段安全替换：段落编号前缀保持不动、输出段落数对不上时不硬替换（降级为批注建议）、低质量批次自动改为批注提示。
3. 分块参数在哪调：设置 ＞ 默认设置 ＞ 「段落截取设置」——「截取长度（字符）」（默认 4000，界面建议 2000–8000）、「上下重叠长度（字符）」（默认 200，避免分界处语义断裂）、「分段策略」（按段落/按句子/按字符）。

## 高频疑问

### 点完翻译，原文被译文覆盖了，怎么找回？

默认动作就是替换。刚替换完可立即 Ctrl+Z 撤销；若任务卡勾选了「写回前备份源文件」，用「一键撤销」卡的「撤销本次修改」整体恢复。之后想保留原文，先按第 4 步把文档动作改成「仅生成结果」或「插入到光标处」。

### 长文档翻译要多久？为什么分了几批？

超过分块长度（默认约 4000 字，可在设置 ＞ 默认设置 ＞ 段落截取设置里调整）会按段落切块、带重叠上下文逐批翻译，批数越多耗时越长。进度窗能看到「第 N 批」推进，中途可「停止处理」。

### 菜单里没有我要的语种？

当前内置 52 个语种，菜单为动态生成但语种清单固定，暂无自定义语种入口。可退而在 AI 对话里直接说「把这段翻译成 xx 语」由模型完成。

### 机构名、政策名被译错了怎么办？

内置提示词已要求专有名词优先用标准译法，但模型仍可能出错。建议对术语敏感的文档：先跑一遍后用「重试/用新模型重跑」换模型对比；或在 AI 对话里附上术语表再让翻译（文档智能体链路）。

## 更多操作细节

4. 想保留原文？改写回动作

1. 在哪：设置 ＞ 助手设置 ＞ 「翻译」＞「文档动作」下拉。
2. 翻译助手允许的动作：「替换文档内容」「插入到光标处」「添加批注」「批注 + 替换」「追加到文末」「仅生成结果，不写回文档」。改成「仅生成结果」或「插入到光标处」即可避免覆盖原文。

5. 译文重跑/换模型

1. 在哪：任务进度窗标题栏。
2. 做什么：对译文不满意点「重试」按原参数再跑，或从模型下拉换一个模型点「用新模型重跑」。

## 安装与运行答疑

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。
