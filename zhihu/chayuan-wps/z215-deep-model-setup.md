一层一层看：「检测连接报 401 / 404 是什么意思？」下拉为空时显示「请先在模型设置中配置：开启提供商、填写 API 地址与密钥、刷新模型清单」。「Ollama 已经装好了，察元里怎么连上？」

说到底，工具是拿来用的，不是拿来评测的。
