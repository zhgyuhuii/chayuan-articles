# 从需求到交付：密钥生成

密钥生成这件事，值不值得专门学一篇，看一个细节就够：16 位恢复码。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 先看看痛点对不对得上

想确认恢复密钥到底会不会因为试错被锁；装机后第一件事生成密钥；想主动生成/重新生成恢复密钥，或旧抄本找不到了想换一把新的；定期轮换密钥。

## 一步步来

路径一 · 首装向导第 3 步（新装机）

1. 在哪里：全新安装首次启动，向导创建管理员账号后的第 3 步，标题「抄写你的恢复密钥」。
2. 做什么：页面中央绿色等宽块显示完整密钥；点「复制密钥」（点了变「已复制」）抄到密码管理器，或直接抄在纸上；然后勾选「我已把恢复密钥抄写到安全的地方」。
3. 看到什么：勾选后「完成并进入」按钮亮起，点击进入桌面。也可以点下方链接「暂不抄写，直接进入（可稍后在 设置 ＞ 账号与找回 重新生成）」跳过——跳过不会删除已生成的密钥，只是这串明文不再完整显示，之后可在设置页重新生成一把新的。

路径二 · 设置页生成/重新生成

怎么用它找回密码：见对应教程 三条路之二——锁屏/开机门「忘记密码？」＞「恢复密钥」＞ 输入抄本 ＞ 设新密码。密钥输入框为等宽字体居中显示，边输入边自动转大写并按 4 位一组补横杠；抄写时漏了横杠、大小写不分、0/O 与 1/I/L 手误都能被自动纠正。密钥通道永不锁死：输错只提示「恢复密钥不正确」，不会冷却不会锁账号；验证成功还会顺手清零智能体面试通道的失败计数。

重置成功后系统做了什么（与面试路一致）：新密码立即写入账号（锁屏/登录门/远程访问同步生效）＞ 清零找回失败计数与密码登录退避（保证「重置完立刻用新密码解锁」畅通）＞ 本次操作写入管理员审计日志 ＞ 原地解锁进桌面。

与另外两条找回路的配合：设置 ＞ 账号与找回 分区底部有一张「找回机制说明」卡，原文即三条路总览：「忘记密码时有三条路：①智能体面试——本地 AI 就你的本机使用痕迹出题验证（需开启上方验证画像）；②恢复密钥——离线抄写的 4×4 恢复码，验证后直接重置；③管理员重置——管理员可在 设置 ＞ 用户 为普通用户重置密码。入口在锁屏与开机登录门的『忘记密码？』。该验证可防范远程与陌生接触者，无法防范持有磁盘的专业取证攻击。」密钥是其中仅有「不需要事前数据积累、也不依赖管理员」的自救路——只要抄本还在纸上，随时可用。

1. 在哪里：Dock ＞ 设置 ＞ 左栏「账号与找回」分区，第一张卡标题「恢复密钥」。卡片说明：「忘记密码时的最终保险：一串 4×4 恢复码，验证后可直接重置密码。它不会存明文——只在生成时显示一次，请抄写在纸上或存入密码管理器。密钥通道永不锁死。」
2. 看状态：卡内状态行显示二选一——「已设置恢复密钥」或「尚未设置恢复密钥（建议立即生成）」。
3. 生成（尚未设置时）：
    1. 账号已设密码：状态行右侧有「当前密码（未设过可留空）」输入框 + 「生成恢复密钥」按钮——输入当前账号密码再点按钮；
    2. 点完看到：绿色等宽块显示完整密钥，下方两个按钮「复制密钥」与「已保存」，再下面一行橙色警示「这是仅有一次完整展示。确认已抄写后再点「已保存」。」；
    3. 抄写确认后点「已保存」，密钥块消失，显示绿色提示「恢复密钥已生效，请妥善保管离线副本。」，状态行变为「已设置恢复密钥」。
    4. 重新生成（已设置时）：状态行右侧同样是「当前密码」输入框 + 「重新生成」按钮。重新生成后旧密钥立即作废，只剩最新一把有效——旧抄本丢了就换新的，别心疼。
4. 失败分支：
    1. 当前密码输错 ＞ 红色提示「当前密码不正确」；
    2. 密码连续输错触发退避 ＞ 「尝试过于频繁，请稍后再试」（与登录同一把持久化退避，等一会再试）；
    3. 其他失败 ＞ 「生成失败，请重试」。

## 关键能力点

- 16 位恢复码
- 重新生成需验密
- 密钥通道永不锁死

## 它的局限也要说清楚

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 高频疑问

### 密钥只显示一次，没抄/丢了抄本怎么办？

明文不会再展示（系统只存哈希）。到 设置 ＞ 账号与找回 输当前密码点「重新生成」，换一把新密钥重新抄写；旧密钥随之作废。

### 设置页生成时也要输密码，可我正是怕忘密码才来设保险？

这正是设计：防止有人趁你登录着桌面顺手换掉你的找回保险。生成动作需要你现在还记得密码；真正忘了密码的那一刻，用的是抄本（不需要密码）。所以趁记得密码时把密钥抄好。

### 一直没设密钥也没开验证画像，系统会提醒吗？

会。既没有恢复密钥、又没开启验证画像的账号，每次成功登录后最多每 7 天收到一条通知「设置找回保险」（正文引导到 设置 ＞ 账号与找回），出现在通知中心。
