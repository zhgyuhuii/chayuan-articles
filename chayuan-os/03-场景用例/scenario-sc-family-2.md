# 从入口到验证：家用AI

先说这篇能帮你干什么：读完能在察元AI OS里独立完成家用AI，路径是家用AI。步骤里的每个「」按钮都是界面原文。

## 一句话说清定位

家用AI是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，家用AI是其中面向这类需求的一环。

入口、步骤、验证三段看清，这事就顺了。

## 完整操作步骤

上手按顺序做：（第 2 个切入角度）

1. 多用户各自账户独立空间
2. 语音输入降低打字门槛
3. 桌面灵宠给孩子当玩伴
4. 本地模型不需要付费订阅
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 家用AI要联网吗

本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；AI 面试 3 次失败锁 24 小时；忘记密码时本地 AI 面试官出题。以官网 aidooo.com 当前页面为准。

### 家用AI数据存在哪

整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离、数据在服务器侧统一管理，很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。以官网 aidooo.com 当前页面为准。
