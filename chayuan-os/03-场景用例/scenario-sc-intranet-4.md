# 从需求到交付：物理隔离AI

先说这篇能帮你干什么：读完能在察元AI OS里独立完成物理隔离AI，路径是物理隔离AI。步骤里的每个「」按钮都是界面原文。

## 先看看痛点对不对得上

1. 物理隔离网络用不了云端 AI
2. 数据严禁出域，公有云方案直接出局

断网环境获得与联网几乎等同的 AI 能力面。

## 把流程串起来

1. 本地模型对话、知识库问答、AI 办公全链路离线用
2. 跨终端互联按需开授权，出厂零共享
3. 官网下载全量离线包（含五件套权重，约 4.7GB）

## 支撑功能的操作细节

流程里关键功能的实际操作：

上手按顺序做：（第 4 个切入角度）

1. 官网下载全量离线包（含五件套权重，约 4.7GB）
2. U 盘搬运到内网机器安装，离线包逐文件校验
3. 本地模型对话、知识库问答、AI 办公全链路离线用
4. 跨终端互联按需开授权，出厂零共享
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 这些坑和边界要知道

边界先摆在桌面上：

- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

场景提醒：涉密使用需本单位审批，工具只提供技术可行性。

## 接着回答几个常见问题

### 物理隔离AI要联网吗

四本日历把生活与工作分开记，AI 能读会写，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一。以官网 aidooo.com 当前页面为准。

### 物理隔离AI数据存在哪

桌面本身能被 AI 定义，能力边界从预装走向按需生成；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把物理隔离AI放回察元AI OS的整体盘面：让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复；AI 纪要一键生成，AI 面试 3 次失败锁 24 小时。

## 安全与数据边界

安全口径单独立一层：远端调用走权限门留审计；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳；遥测开关、清除桌面数据（破坏性操作有警示）；升级不丢数据是底线，检查更新静默失败不影响使用。

## 平台与形态

平台与形态的账：忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网，本地 AI 出题验证；一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全。

## 价格与授权

价格口径一并交代：:52581（OpenAI 兼容统一模型代理）；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。

## 产品家族与搭配

察元AI OS不是单打独斗：右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；虚拟屏网格拖拽排布、每屏尺寸与壁纸、取景切换、对齐物理显示器；演示或截图时把窗口摆进虚拟屏再取景，比物理拖窗口稳；Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入。

## 几条硬数字

能落到数字上的几条：我的模型面板管理加载、卸载、删除、钉住，常用模型可钉住常驻；一台 16GB 内存的机器跑两个 8B 模型必然卡死；显式的加载卸载加自动卸载策略是本地模型的生存之道。

## 离线与内网

离线内网这条线的口径：购买 OS 授权后，同机察元AI Office 自动免激活；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；OpenAI 风格与阿里百炼风格 API 自动适配，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。
