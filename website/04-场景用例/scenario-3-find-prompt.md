# 提示词需求者的提示词库方案（完整方案）

- 没有结构化分类
- 复制粘贴体验差

1. prompt 板块按场景筛选
2. 读结构与约束
3. 复制正文直接用

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「prompt 板块按场景筛选」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。高质量提示词的正确打开方式。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用

- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。
