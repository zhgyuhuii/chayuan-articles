# 给政企用户完整的桌面迁移体验：涉密内网AI概念与上手

涉密内网AI这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是涉密内网AI

把涉密内网AI拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 便签：桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件。
- 提醒事项：智能筛选（今天、已计划、旗标、已完成）、多列表管理。
- 日历：日周月年四视图、个人工作家庭学校四本日历。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 涉密内网AI要联网吗

文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一，设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，让特定文件类型默认交给智能体处理，双击即用 AI，内网或特殊网络环境装插件的必经配置。以官网 aidooo.com 当前页面为准。

### 涉密内网AI数据存在哪

恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网，本地 AI 出题验证；需要提前开启并积累足够记忆数据。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把涉密内网AI放回察元AI OS的整体盘面：点击互跳定位原文，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注；共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道。

## 安全与数据边界

安全口径单独立一层：API Key 用 safeStorage 加密存储，遥测可整体停用，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；代理只监听本机回环，跨机访问需要另行打通，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。

## 平台与形态

平台与形态的账：每次产出 markdown 报告落盘归档；markdown 报告归档，断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。

## 价格与授权
