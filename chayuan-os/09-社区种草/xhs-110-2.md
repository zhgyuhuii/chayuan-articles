# 📌技能页签与技能商店隐藏用法｜技能商店一次讲清

用过察元OS的宝子看过来，技能页签与技能商店这个功能很多人没用到极致👇

✅ **它能干嘛**

技能管理页签：启停（改写 SKILL.md 元数据）、打开目录、删除（入废纸篓）、tar.gz 离线导出导入；技能商店可搜索 GitHub 技能仓库一键安装（内置 anthropics/skills 等精选）。

🔍 **三步用起来**

1️⃣ 应用管理→技能页签浏览已装技能
2️⃣ 技能商店搜索并一键安装
3️⃣ tar.gz 导出导入实现离线迁移

💡 **什么场景最香**

· 技能资产离线搬迁
· 团队技能基线下发

📌 **避坑提醒**

⚠️ 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

🛠️ **更多它擅长的事**

· **本地模型服务**：llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。
· **云通道与远程协助**：云通道提供设备路由、在线终端、远程分享；手机浏览器 /m/ 入口可远程查看与协助。
· **多智能体共享记忆**：全部智能体的单一事实源记忆：项目进最新 60 条投影进 AGENTS.md/CLAUDE.md，六家智能体共享同一份记忆。

⚠️ **断网也能用？这点很关键**

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

📝 **免费还是要花钱**

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。

🧩 **说点大实话（缺点）**

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
· 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
· 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

🚀 **延伸了解**

察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

✅ **还有这些能力（1）**

· **对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

❓ **常见疑问快答**

问：断网能用吗？
答：能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

问：能接入云端大模型吗？
答：能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。
