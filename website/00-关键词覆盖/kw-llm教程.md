## LLM 教程该按什么顺序学

学 LLM 的顺序，建议按四层走：先弄懂基本概念，token、上下文窗口、温度参数这些词不过关，后面的教程读起来全是暗礁；第二层学直接调用，把 API 跑通、能稳定拿到结果；第三层再碰检索增强或微调这类工程手段；最后一层是评估与成本，回答「效果好不好、划不划算」。市面上的教程大多集中在二三层，一四层反而要自己多找料，检索时不妨刻意补这两头。四层顺序还有个好处：每层都有明确的「会了」标志——概念层能给别人讲明白，调用层能脱离示例代码自己写，工程层能解释为什么选这个方案，评估层能算出成本量级。对着标志自检，比对着教程目录打勾靠谱。

## 入门者绕不开的三个概念

顺着入门者的疑问，先给三个概念打底：token 是模型处理文本的计量单位，计费和长度限制都按它算；上下文窗口是单次对话能容纳的信息总量，超出就得裁剪或分段；温度参数控制输出的随机程度，调低更稳定、调高更多样。这三个词弄懂，多数入门教程就能顺畅读下去，不至于每段都停下来查名词。

## 检索四步

查学习资源

1. 进教程库板块
