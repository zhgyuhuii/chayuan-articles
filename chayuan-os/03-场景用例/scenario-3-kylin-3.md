# 写给国产化环境用户的国产操作系统指南：效率视角

如果你是国产化环境用户，下面这些场景大概率不陌生：麒麟/UOS 下 AI 软件少。信创环境的 AI 桌面方案。这篇效率视角以察元OS为工具，把这个岗位的国产操作系统工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 麒麟/UOS 下 AI 软件少
- 飞腾/鲲鹏架构兼容性
- 政企要求信创目录

## 用察元OS怎么解：工作流拆解

1. 按架构选 arm64/x64 包
2. deb 安装到麒麟/UOS
3. 本地模型+知识库离线使用

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「按架构选 arm64/x64 包」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。信创环境的 AI 桌面方案。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 常见问题
### 免费吗？怎么收费？

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。

### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
