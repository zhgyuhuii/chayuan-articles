# 政企办公AI方案：AI 桌面操作系统

## 政企办公为什么需要这套方案

政企办公行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把察元AI Office 引用知识库跑通，验证环境与模型可用
2. 流程层：政企办公日常最高频的文档环节（察元AI Office 集成所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 察元AI Office 引用知识库

- 四级自动发现
- 引用带出处插入文档
- 多库可选

### 察元AI Office 集成

- 六编辑器齐全
- 知识库引用写入
- 同代理免重配

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

## 一个行业侧影

国产化环境用户的典型链路：

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程

信创环境一套完整的 AI 桌面与办公方案。

提醒：暂不支持龙芯平台。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 选型核对清单

- 数据边界：全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机
- 付费口径：免费下载使用，购买只停提醒、不锁功能
- 试点建议：先选一个三人以内小组、一个高频场景跑两周再扩大

察元AI OS不是单打独斗：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，写材料时直接问公司知识库，回答带引用插进文档，办公与知识库一条链，整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 离线与内网

离线内网这条线的口径：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。

把察元AI OS的能力总账摊开：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）；让 B 机器的智能体替你跑任务，结果回传，人不用挪窝，远程派活给对端智能体；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。
