# 察元AI文档助手 6.0更新解读：这次改了什么

## 6.0 更新了什么

察元AI文档助手在2026发布6.0。本文把3 项要点逐条过一遍，每条附一个与之相关的常见问题，最后给升级步骤与回退方案。

## 要点逐条看

1. 三端加载项统一

这项更新直接作用的场景：三端加载项统一

相关常见问题——「开发工具 ＞ 加载项」列表里出现多个「察元」条目？ 多轮升级的残留：macOS 的登记表（authaddin.json）会累积同名条目，官方安装器每次安装都会自动去重并把条目指向当前版本目录——重跑一次最新安装包即可清理。Windows / Linux 的 WPS 按 jsplugins.xml 加载，安装器只更新本产品条目、并清理旧版本目录；若旧条目指向已删除的目录会导致加载失败或回退旧缓存，同样用重装修复。

2. 保密检查八大类

这项更新直接作用的场景：保密检查八大类

相关常见问题——点「保密检查」弹出「购买授权」窗口？ 保密检查是付费专属能力，未购买时点击直接拦截并弹「购买授权」窗。按窗口指引购买或输入序列号后重试。

3. 本机 MCP 服务

这项更新直接作用的场景：本机 MCP 服务

相关常见问题——怎么添加其它 MCP server？ 点下拉底部「管理」进设置页的 MCP 服务管理添加；添加后回到下拉勾选即可启用，徽标数字只统计你手动添加且已启用的服务。

## 升级步骤

1. 升级前备份：加载项数据在本机目录，备份配置后直接覆盖安装
2. 获取新版：官网 aidooo.com 下载对应平台安装包
3. 覆盖安装，数据目录自动保留
4. 启动后到设置或关于页确认版本号已更新

## 出问题怎么回退

覆盖安装出问题时，重新安装上一版本安装包即可回退，数据目录兼容。升级失败的常见原因是网络中断或磁盘空间不足，先检查这两项再重试；断网环境用离线安装包加逐文件校验的方式升级。

## 高频疑问

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。

## 关于察元AI文档助手

察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。同家族产品：察元AI OS（AI 桌面操作系统）、察元AI Office（开源 AI 办公套件）、察元AI 能力广场（aidooo.com）。官网 aidooo.com。

## 边界速览

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型

## 数字口径

- 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源
- 保密检查覆盖八大类风险：密级标识、涉军涉装涉训、组织身份、人员联络、时间地点部署、内部编号、经营商业敏感、军工政企高频线索
- 全文校对分块并发，块长默认 6000 字；超过 12000 字分档提示

## 模板编制五段式

发模板文件加一句话需求后：形状级剖析（LOGO 页码水印判为装饰永不改写）、计划卡确认、副本填充（原模板零修改）、三轮质检自愈（上限四轮）、后台生成完成自动打开。红头文件与标书这类强格式文档最适合这条链路。

## 校对的执行机制

有选中只查选中，无选中确认后查全文（超 12000 字与 30000 字分档提示）；检查在独立进度窗里分块并发执行，块长默认 6000 字，关窗任务继续，只有点停止任务才中止；结果批注锚定原文，锚不上的不硬挂。

## 额度与付费边界

免费每日额度（对话与助手独立额度池，次日重置）；文档脱密、脱密复原、保密检查、涉密关键词提取四项为付费专属、零免费额度；序列号本地验签激活、绑定设备指纹，离线可用。

## 脱密的可逆设计

AI 提取涉密关键词加本地 9 类正则兜底（手机号、身份证、邮箱、编号、银行卡、IP、车牌、统一社会信用代码等），确认后替换为 8 位随机占位符；恢复载荷 AES-GCM-256 加密随文件走，凭密码可完整还原，忘记密码没有任何免密通道。

## MCP 写确认纪律

本机 62588 端口的文档智能体服务只监听回环；写操作不带确认标记会被拒绝并要求确认，每次确认写记入审计日志。外部智能体（Claude Code、Codex、Cursor 等）一行配置即可接入，代操作文档但不越权。

## 配图三级降级

第一级模型生图（最多试三个模型），失败走第二级网络搜图（Serper、Tavily、Pexels、SearXNG 免 Key），再不行第三级 SVG 矢量兜底；铁律是上级失败才降级，绝不静默换花钱的来源。

## 表格与演示的直达按钮

表格端九大按钮（AI 表格助手、公式助手、数据洞察、一键图表、数据清洗、报表结论、一键美化等）配 66 个配方；演示端从生成 PPT 到口播稿、整套校对、结构诊断齐备，配 81 个配方，课件与习题页生成也在菜单里。
