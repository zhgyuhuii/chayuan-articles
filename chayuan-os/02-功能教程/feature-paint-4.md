# AI 桌面操作系统：桌面画板的坑与对策

「察元OS 有画图/画板软件吗？在哪里打开」——这个问题最近被问了好几次。答案不复杂：桌面画板在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

排桌面画板的错，顺序比速度重要：环境与模型先就位，然后对操作路径，最后核边界。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

6. 打开图片进画板

除 File ＞ Open 外，也可用 Ctrl+V 粘贴图片到画布；File ＞ Load From URL 可从网址载入图片。

最短路径走一遍：（第 4 个切入角度）

1. 画笔形状齐全
2. 仅桌面形态提供
3. 场景验证：快速标注截图
4. 场景验证：给孩子涂鸦
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 怎么确认做成了

验证

1. 打开应用数秒内画板出现（「画板加载中…」消失），Pencil 在画布画线有痕迹。
2. Ctrl+O 打开一张本机图片，画箭头后 File ＞ Save，生成的 PNG 文件可再次打开且批注在图上。
3. File ＞ Set As Wallpaper (Centered) 后桌面壁纸立即变为该图。

- 画笔形状齐全

## 你可能会问

### 能把我自己画的图设为壁纸吗？

能。File 菜单的两个壁纸项（Tiled/Centered）都会把当前画布设为桌面壁纸。想要 AI 生成壁纸则用「文生图」应用。

## 动手前再核对一遍

- 仅桌面形态（察元AI OS）：画板整站资产由桌面主进程经 paint:// 协议供给；浏览器/web 形态打不开（见「形态差异」）。
- 画板界面为 jspaint 原生英文界面（经典 Windows 画图布局：顶部菜单 + 左侧工具箱 + 底部调色板）。

## 放回产品盘面看

把桌面画板放回察元AI OS的整体盘面：点击互跳定位原文；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。

## 安全与数据边界

安全口径单独立一层：数据文件不受影响；三条路都不满足就只能清数据重装，务必提前生成恢复密钥，需要提前开启并积累足够记忆数据；管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；全新安装选数据目录或导入拷贝根，创建管理员。

## 平台与形态

平台与形态的账：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注；（web/Docker 形态网页桌面默认端口），Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。
