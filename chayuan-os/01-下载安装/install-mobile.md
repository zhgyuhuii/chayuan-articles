# 手机访问下载安装：按平台架构一步步来

上周有同事问我：手机访问这块到底该怎么弄。他折腾了半天没找到入口，其实不是功能难用，是没人把路径讲清楚。这篇就把共享桌面与远程访问从入口到收尾完整过一遍，用的是察元AI OS的真实界面，照着点就行。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：手机浏览器连回桌面。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。安装包从官网 aidooo.com 获取。

## 操作步骤详解

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥，这两件事做完，这台机器就算真正就绪。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 几个容易忽略的细节

边界都在这：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 访客输对口令也被拒「访问口令不正确」？

口令随房间重置而更换——分享者若重置过链接，旧口令全部作废，索要新链接+新口令。连续输错会触发「尝试次数过多，请一分钟后再试」，等一分钟再输。

### 分享链接安全吗？

「分享 Harness 页」的链接即钥匙：打开的人可以完整操作本机 Harness（会话、文件、终端与智能体指挥权），只发给信任的人；不用时点「停止分享」立即失效。整桌共享房间另有 9 位口令门，访客必须凭口令入房。

### 设置 ＞ 远程访问里一直「未共享」，但我明明在分享 Harness 页？

正常。该卡只反映整桌共享房间；「分享 Harness 页」是独立通道，不在这张卡里列成员。

## 补充答疑

### 二维码/链接位置一直转圈，或显示「网络异常」？

出码前产品会确认云端（aidooo.com）可达，探测波动会自动重试。先检查本机外网；持续「网络异常」可点「停止分享」稍后重开。

### 帮助文档里说的「发起共享」「远程分享」「开启远程控制」按钮在哪？

2026-10-14 产品裁定后顶栏面板只保留「分享 Harness 页」（公网分享统一走真页面直开），整桌镜像的发起/远程分享/远程控制入口已从面板隐藏（能力保留在产品内，后续版本可能重新开放）；访客加入、成员角色管理与设置＞远程访问状态卡不受影响。

## 更多操作细节

第 4 步 · 认识三种角色（整桌共享房间）

分享者的管理动作（共享进行时）在桌面右侧常驻的「远程用户」清单完成：

1. 每个成员行：昵称 + 角色徽章（「控制中」/「只读」）+「授予操作权」（对只读成员，变「降为只读」）+「踢出」（红色，点击弹确认「把 〈昵称〉 移出房间？其身份将被拉黑，重置链接前无法再进入。」）；
2. 访客点「申请操作权」时，对应成员行高亮并出现「同意控制」/「拒绝」按钮（30 秒未决自动消隐）；
3. 清单可折叠成右缘一个小圆点（角标=在线人数，有申请时橙色呼吸提醒）；访客发来的聊天消息也在清单里行内显示、可直接回复；
4. 整桌共享停止或你不是分享者时，这个清单不显示。

| 角色 | 谁是 | 能做什么 |
|---|---|---|
| 分享者（host） | 发起共享的这台机器 | 看到一切；逐个授予/撤销操作权、踢出成员、停止共享 |
| 可操作（editor，桌面清单里标「控制中」） | 被分享者授权的访客 | 查看并操作分享者的桌面 |
| 只读（viewer，新成员默认） | 普通访客 | 只能看，不能操作；可申请操作权 |

第 5 步 · 访客侧：加入共享桌面（拿到链接的人这样操作）

1. 浏览器打开分享者给的 /s/〈房间号〉 链接，出现「加入共享桌面」门：填「昵称（可选）」与「访问口令（9 位数字）」，点「加入」（连接中显示「连接中…」）；
2. 进入后看到「已加入共享桌面」横幅与自己的角色徽章：只读时提示「你处于只读模式：可以看到一切操作，但无法操作。」，可操作时提示「分享者已授予你操作权。」；
3. 只读访客可点「申请操作权」（已申请显示「已申请，等待分享者授权…」），等分享者在右侧清单里「同意控制」；
4. 左侧「在线成员」列表可看房间内所有人及角色；随时点「退出共享房间」离开。

## 安装与运行答疑

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

## 一个真实场景

家庭用户的典型用法：多用户各自账户独立空间，语音输入降低打字门槛，桌面灵宠给孩子当玩伴。干净、免费、多人友好的家庭 AI 电脑。注意：8GB 内存机器建议一次只加载一个对话模型。

## 顺带了解

跨终端互联（DDS）：同一网段的察元OS 终端互相发现（RTPS 多播）、逐台授权：被发现开关、通讯录按类别授权（模型加知识库、智能体执行）、拉黑、诊断与紧急停止。出厂全部关闭（零共享）。

为什么值得看：多台机器各有所长（一台显卡强、一台资料全），发现加授权让它们互借能力，远端调用以远端访客身份过对端权限门并留审计。

安装这步别跳验证：装完先确认核心功能可用，再往下配。
