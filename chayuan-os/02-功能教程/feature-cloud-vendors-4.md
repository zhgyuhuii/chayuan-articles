# DeepSeek接入：模型配置可一键写入五家，别再瞎试

DeepSeek接入这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决给智能体接 DeepSeek、Kimi 这类国产 API。

## 先定位问题在哪一层

按这个顺序排查DeepSeek接入通常最快：先确认前置条件（该厂商的 API Key（厂商卡上有「获取密钥」按钮直达官网 Key 页；「免Key / 免费额度」类厂商可先试）。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 「获取模型列表」超时或失败？

先核对 API 地址（OpenAI 兼容厂商一般以 /v1 结尾，缺了会自动补）与密钥；国内访问国际平台确认代理可用；20 秒超时提示「该厂商可能不提供模型列表端点」的，换支持 /models 的端点或手填协议重试。清单拉不下来无法启用——启用以「获取到的模型列表」为准，至少勾选一个模型。

## 正确的操作路径

7. 「保存并启用」

点蓝色主按钮「保存并启用」：

1. 成功：绿色「已开启，模型下拉框即刻可见」——勾选的模型实时出现在 DeepSeek Harness 窗口的模型下拉框，无需重启；主按钮此后变为「保存更改」，旁边出现红色「停用」。
2. 启用时的校验与兜底：没填地址报「请先填写 API 地址」；没填密钥报「请先填写 API 密钥」（免密钥厂商除外）；清单为空会先自动拉一次最新清单再启用（拉取失败则报错、不启用）；清单里一个都没勾报「请先获取模型列表并勾选至少一个模型」。
3. 「停用」：提示「已停用，配置保留可随时恢复」——地址、密钥、清单都保留，重新打开开关即恢复。
4. 表单底部固定说明：「开启后仅勾选的模型出现在 DeepSeek Harness 窗口的模型下拉框（实时生效）。密钥保存在 ~/.dsh/.credentials.yaml，由 harness 凭据管理。」

8. （可选）接入模型代理 / 直接应用

1. 「加入代理」：把本厂商勾选的模型注册进模型代理路由，提示「厂商已加入代理」，按钮变「从代理中移除」。此后任意智能体可用 <厂商>/<模型名> 经 http://127.0.0.1:52581 免 key 调用（向导第 2 步、灵宠选模型的厂商树即以此为数据面）。
2. 「直接应用…」：弹应用对话框，把该厂商模型直接写入选中智能体的配置。

## 怎么确认做成了

验证

1. 启用后：厂商卡状态行变为「已开启 · 显示在 Harness 模型下拉框」，左栏该厂商行尾出现实心绿点并排到组首。
2. 打开 DeepSeek Harness 对话窗：模型下拉框出现勾选的该厂商模型（实时生效）。
3. 已「加入代理」时：访问 http://127.0.0.1:52581/v1/models（免 key），清单出现 <厂商>/<模型名> 条目。

## 进阶用法与边界

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用
- 边界：云端调用需自备 Key，费用按厂商政策
- 边界：断网时云端模型不可用，可设自动回落本地

## 常见问题

### 开关打开了又弹回去 / 状态行和实际不符？

启停状态优先读 harness 运行时回显；个别旧版本 dsh 网关读回不可达时以本页快照记录的启停动作为准，可能出现显示不准。升级桌面版本后恢复准确。

### 「停用」会删掉配置吗？

不会。提示「已停用，配置保留可随时恢复」——地址、密钥、模型清单都保留，重新开启即恢复；Harness 下拉框里的该厂商模型即时消失。

### 想先免费试试，选哪家？

免费过滤下拉选「免Key」或「免费额度」；带绿徽标「免Key」的完全不用密钥，蓝徽标「免费额度」的注册即得（如 Agnes：注册即得免费 Key，文本 Flash 与图像生成免费）。

## 更多操作细节

1. 进入页面

打开 设置，左栏第一项「模型」。页面为双栏：左栏厂商目录，右栏选中项的配置表单；右栏顶行有「模型厂商」标签和侧栏开合按钮（窄窗下侧栏收进抽屉）。

## 更多操作细节

3. 点选厂商卡，看状态行

右侧表单顶部：厂商 logo + 名称 + 状态行（三态）+ 右侧启停开关：

1. 「已开启 · 显示在 Harness 模型下拉框」（绿字，开关已开）；
2. 「已配可用」（绿字，密钥已配置但未开启）；
3. 「未开启」（灰字）。

## 更多操作细节

6. （可选）「测试连接」

点「测试连接」（按钮变「测试中…」）：通过显示绿色「连接成功，端点可用」；失败显示「连接失败: <原因>」。

## 更多操作细节

9. 自定义 OpenAI 兼容厂商（目录里没有的）

左栏底部「＋ 添加供应商」＞ 弹窗「添加供应商」两个必填字段：「供应商名称」「API 地址（OpenAI 兼容）」（占位 https://…/v1）＞ 点「添加」（回车等同确认，Esc 关闭）。校验：名称空报「请输入供应商名称」，地址空报「请输入 API 地址」。新卡出现在「自定义」组并被选中，之后流程与内置厂商完全一致（第 4–8 步）。

## 更多操作细节

10. 「本地与自建」组的 Ollama 卡（一键安装面板）

「本地与自建」组里的 Ollama 卡比普通厂商卡多一个安装面板，状态行四态：

1. 「检测本地服务…」＞「本地服务运行中 · v<版本>」（绿点）：可直接走第 4–7 步（密钥留空）；面板下方出现「拉取模型」区——快捷 chips（qwen3:8b、deepseek-r1:8b、qwen2.5-coder:7b、llama3.2:3b、gemma3:4b）或输入框「模型名，如 qwen3:8b」+「拉取」，进度条可「取消」，完成提示「拉取完成：<模型>」；提示「拉取完成后点「获取模型列表」勾选启用」。
2. 「已安装，服务未运行」（黄点）：显示「启动服务」（＞「启动中…」），启动超时提示「启动超时，请手动启动后点「重测」」。
3. 「未检测到本地安装」（红点）：mac/Linux 显示「一键安装」（＞「安装中…」，完成提示「安装完成，服务已启动」；失败提示具体原因，需要管理员密码时提示在终端执行对应命令）；Windows 显示「前往下载」跳 ollama.com。
4. 行尾「重测」随时可重新探测；「镜像源：官方直连 / 自定义」可给安装/拉取配国内镜像基址。
