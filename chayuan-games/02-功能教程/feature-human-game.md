# 人机局全流程教程：你与大模型同桌过招

看了几天机机观战，手痒了吧。光看模型互相打，终究隔着一层；想真刀真枪地跟大模型过招，人机局才是你的主场。这篇按人机局全流程走一遍：从开局配置，到你和模型轮流出招，再到终局结算落账，一条链不缺环。照着做一遍，你就能和大模型同桌掰手腕了。

## 先弄清楚它是什么

人机局是你亲自下场、对面坐着大模型的对局模式。你走一手，模型走一手，规则由对局引擎执行，胜负判定完全归代码裁判——11 款玩法各有一套纯逻辑裁判引擎，只认规则真值，模型只出招、不判罚。换句话说，你输给它，是规则盖章的输；你赢它，它也没法赖账。

它和机机观战的差别在于参与感：观战是看戏，人机局是演戏。你落下的每一手都会被引擎评估，复盘时逐手标注一视同仁，你的妙手和失误都会被指出来。想检验自己的棋感、或者单纯体验一把「我赢了 GPT」的快感，这个模式就是为此准备的。

还有一层常被忽略的价值：人机局是对局节奏的节拍器。模型长考时你可以慢悠悠盘算，你犹豫时它的思维链气泡正在旁边滚动——跟大模型同桌的乐趣，一半在胜负，一半在这份对视感。

## 动手前要备好什么

准备三样。其一，装好察元竞技场（版本 0.1.0），软件 MIT 开源免费。其二，配好对手：进设置 ＞ 模型配置，从 85 家厂商目录点选厂商，填上你自己的 API Key，点「测试连接」验证；拿不准就用「获取模型」把该账号可用模型全列表实拉下来挑。想零成本，配 Ollama 本地模型，免 Key、断网也能打。其三，挑一款玩法：新手从五子棋起步最顺，想玩扑克类先弄清牌型，想碰军棋先花十分钟学规则。

模型怎么挑，给个参考：日常练手选响应快的模型，节奏轻快；想见识高质量推理，上思考型模型，代价是每手等待更久、额度消耗更大。别一上来就挑战牌桌上的全明星阵容，先从够得着的对手打起，输了也不心疼。

## 完整流程走一遍

第一步，开局配置。从大厅点选玩法卡，进入人机局配置：选一个你配好的模型当对手，按需调整对局参数。配置页能对上的选项一目了然，拿不准的保持默认即可。

第二步，落座开打。开局后你和模型轮流出招，你这边按玩法规则落子或出牌，模型那边每手都有思维链气泡实时滚动，名牌上挂着这一手的延迟与 token 用量。它想它的，你谋你的，互不干扰。

第三步，利用中途手段。打到一半临时有事，局面又不好看，可以用认输体面收尾，这局照常留档；或者把这一手交给 AI 接手，让它替你续几手，想回来随时人工接管，切换下一手生效——这套双向切换另有专文详解，这里知道有这个手段就行。

第四步，走到终局。胜负落定，终局结算启动：结果由裁判引擎给出，终局卡呈现结果与去向；这一局进入对局记录留档，天梯按结算规则更新，你作为人类挑战者的战绩独立统计，不与模型混榜。

第五步，收尾去向。想接着打就点再来一局，配置沿用当前对局；想复盘就去回放，逐手标注与形势曲线都等着你；想细看模型这局的表现，赛后解说能给你一份完整讲解。

## 做完后的验证

一条链走完，三处核对：对局记录里找得到这局（留档成功）；回放能进、逐手可看（数据完整）；天梯里人类挑战者的统计有更新（结算生效）。三样都在，人机局全流程就算通了。以后每局都走这条链，区别只在玩法和对手。

## 这些边界要心里有数

费用方面，软件免费，但对手若是云端模型，每一手都在消耗你向厂商付费的 API 额度，长局与高频对局开销要有数，Ollama 本地模型零成本。棋力方面，大模型靠语料与推理出招，不做深度搜索，下不过专用引擎是正常的，它给你的对手体验有上限，也有惊喜，打几局自见分晓。你的棋谱同样会被逐手标注，被标了叹号别沮丧：被认定失误的每一手，都值得停下来看一眼正确方向，那才是这一局付过的学费。另外人机局的结算按终局结果走，中途退出不体面，用认输把要收的局收干净。

## 高频疑问

### 人机局需要配置几个模型

一个就够。对手模型选一个即可；如果你打算中途用 AI 接手替你续手，相关指派按应用内配置项走，具体以 0.1.0 的开局界面为准。

### 人机局收费吗

软件本身 MIT 开源免费，人机局不额外收费。对手模型是云端服务时，API 费用由你向厂商支付；配 Ollama 本地模型则零成本。

### 断网能打人机局吗

能，前提是对手是 Ollama 这类本地推理模型，整条链路完全离线。对手是云端模型时，联网是硬条件。

### 打不过模型很丢人吗

不丢人，这是设计使然。大模型的棋力来自语料与推理，很多玩法里它有真实的对抗能力；同时它不做深度搜索，也有明显短板。把它当陪练而不是当考官，心态就顺了。

### 中途退出对局会怎么样

对局以引擎的终局判定为准，异常退出后的留存状态以记录页实际为准。建议用认输正规收尾，留档、回放、结算都不缺环。

人机局全流程走通一遍，你就从观众席挪到了牌桌上。跟大模型同桌过招这事，文章写得再细，也不如你自己落一手试试——它会长考，会犹豫，会下出让你愣住的一手，也会犯你一眼就能看穿的错。这种活生生的对手，值得你亲手会一会。
