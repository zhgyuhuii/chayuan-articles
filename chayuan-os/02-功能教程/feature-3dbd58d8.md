# 家庭多人共机：速查手册

账户隔离+各自助手的家用方案。这套组合工作流把多用户体系→便签/日历/提醒/联系人→macOS 风格桌面串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

账户隔离+各自助手的家用方案。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·多用户体系**：管理员/普通账户体系：账户管理、头像、切换用户、锁屏密码找回；家庭与共用设备场景友好。

1. 管理员创建账户
2. 各用户独立数据空间
3. 锁屏界面快速切换

**第 2 步·便签/日历/提醒/联系人**：系统级个人信息管理四件套：便签贴桌面、日历日程、提醒事项、联系人，全部可被智能体通过控制面读写。

1. Dock 打开对应应用
2. 手动或让 AI 添加日程提醒
3. 智能体可读取作为上下文

**第 3 步·macOS 风格桌面**：菜单栏 + Dock + 可拖拽多窗口的桌面体验：开机动画→锁屏→桌面三阶段，自动锁屏（Ctrl+L）、会话恢复、任务切换器（Alt/⌘+Tab）、通知中心、小组件面板、托盘驻留。

1. 启动进入锁屏，解锁进入桌面
2. Dock 点击启动应用，拖拽调整位置
3. Ctrl/⌘+Tab 切换任务，Ctrl+L 手动锁屏

## 衔接点与易错处

- 管理员可统一管理技能与插件基线
- 「帮我明早九点提醒开会」一句话落地
- 会话恢复保留窗口布局，重启不乱

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 免费吗？怎么收费？

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。
