# 企业批量装机：批量安装与配置基线

企业批量装机这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决企业批量装机。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：批量安装与配置基线。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 它的局限也要说清楚

如实说明，它不是万能的：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 放回产品盘面看

把企业批量装机放回察元AI OS的整体盘面：右键编辑改配置，删除有两步确认，桌面上的野宠可以收编为正式灵宠建档，定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见，可选群分区（桌面出图标双击进群）；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。

## 安全与数据边界

安全口径单独立一层：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，数据文件不受影响；三条路都不满足就只能清数据重装，务必提前生成恢复密钥。

## 平台与形态

平台与形态的账：列表与卡片两种视图，搜索排序，批量加载、取消、下载、删除；库会越攒越乱，批量管理与干净删除是长期使用的底气；（web/Docker 形态网页桌面默认端口），Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 价格与授权

价格口径一并交代：库会越攒越乱，批量管理与干净删除是长期使用的底气；购买 OS 授权后，同机察元AI Office 自动免激活；免费下载使用，购买只停提醒、不锁功能；四档价格：149/359/599/1049 元。

## 产品家族与搭配

察元AI OS不是单打独斗：列表与卡片两种视图，搜索排序，批量加载、取消、下载、删除；库会越攒越乱，批量管理与干净删除是长期使用的底气；购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 几条硬数字

能落到数字上的几条：AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，:52581（OpenAI 兼容统一模型代理）；（知识库对外服务，固定端口）；（web/Docker 形态网页桌面默认端口）。

## 离线与内网

离线内网这条线的口径：扫描本地放置的模型，whisper 语音权重同样支持；显式的加载卸载加自动卸载策略是本地模型的生存之道；可选自动（本地优先）或指定。

把察元AI OS的能力总账摊开：编辑面板改模型、知识库、人设，输入框旁有知识库绑定与模型选择（含智能路由自动选模型），检索引用知识库内容并带出处写进文档；在 WPS 里检索引用知识库内容。
