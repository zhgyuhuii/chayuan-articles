# 赛后解说与整局复盘：让AI给你讲完整局

实时解说看着热闹，可一局打完，那些一条条的点评散在几十手里，拼不出一个完整的故事。哪一手埋了伏笔，哪一手定了乾坤，隔天再看曲线，只剩下一堆自己都看不懂的起伏。赛后解说就是补这一环的：整局结束后，让AI给你从头讲到尾。这篇讲清赛后解说怎么用、怎么和复盘工具搭着看，以及它的边界在哪。

## 先弄清楚它是什么

赛后解说是整局结束后生成的完整讲解：对局留档之后，由模型把这一局从头到尾串讲一遍——开局怎么铺、中盘怎么斗、胜负在哪一带定型，一份讲解说全。它与实时解说分工明确：实时解说一手一评，服务当下的观感；赛后解说整局连讲，服务事后的理解。前者是球赛解说，后者是赛后战术分析。

它为什么值得单独讲一篇？因为复盘是竞技场里容易被浪费的环节。大多数人的复盘是拉一遍回放，匀速划完进度条，看完什么也没留下。赛后解说把「看回放」升级成「听课」：它替你把几十手的散点串成一条因果链，你负责验证与消化，省下的是自己摸索的时间。

它解决不了的问题也要先说清：解说是模型的一家之言。它读得到对局进程与着法，读不到各家的心思；它对局面的判断可能与你、与问叹号标注的结论不完全一致。把它当一位棋友的复盘意见，而不是当判决书，心态就对了。

## 什么时候值得生成一份

不是每局都需要赛后解说，三类场景收益高。一是关键局：你输得不服的那局、赢得惊险的那局，值得请解说员把胜负手掰开讲透。二是看不懂的局：机机观战里模型们的操作让你一头雾水，事后一份整局解说比实时点评更能把逻辑补全。三是长局：手数多的对局，自己从头复盘费时费力，让解说员带着走一遍，效率高得多。日常三五分钟的小对局，翻翻标注就够了，不必每局都劳师动众。

## 具体怎么操作

第一步，确认对局已留档。打完的对局（人机局、机机观战、锦标赛里跑出来的都算）在记录页里找得到，留档是赛后解说与一切复盘动作的地基。

第二步，进复盘场景。从记录页打开目标对局进入回放，逐手过程、形势曲线都在。解说相关的入口跟着复盘场景走，具体按钮位置以 0.1.0 应用内实际界面为准，进了回放一眼就能对上号。

第三步，生成整局解说。选好担任讲解的模型，生成后从开局手开始听。解说是逐手连讲的，配合回放的推进节奏看，它讲到哪手，画面停在哪手。

第四步，配合问叹号标注食用。这是这篇的核心技巧：复盘标注里的问叹号（妙手）与叹号（失误）已经替你把关键手圈了出来，解说的整局串讲把来龙去脉讲了出来，两样叠在一起，标注指位置、解说讲原因。听到与标注结论相左的地方，停下来自己琢磨——分歧点往往就是理解加深的地方。

第五步，叠加形势曲线验证。解说讲到某手「局势逆转」时，扫一眼曲线：曲线确实在那附近拐了头，说明讲解与数据对得上；对不上的，多留个心眼。三种信息源互相咬合，这一局的复盘才算扎实。

第六步，带走你的结论。棋谱导出随时可用，想把自己的笔记与解说要点记下来，借导出的数据在自建分析里做，比口头感慨管用。

## 做完后的验证

一份赛后解说听得值不值，有个硬标准：听完你能用三五句话向别人复述这局——胜负在哪定型、转折是什么、双方的思路各是什么。复述得出来，说明解说与标注真进了脑子；复述不出来，要么是这局本身平平，要么是你只是听了个响。

## 这些边界要心里有数

生成要花钱花时间：整局解说是一次不小的模型调用，云端模型按你的用量向厂商支付额度，局越长、模型越大，开销与耗时越明显；本地小模型零成本，但讲解深度有限，这个取舍要自己掂。解说有立场偏差：它可能把一手失误讲成合理试探，把妙手讲成常规操作，与问叹号标注打架时，别急着站队，回到棋盘自己验。它也不能代替你动脑：复盘的收益来自你自己琢磨，解说员讲得再好，替不了你想。另外，解说的生成入口与颗粒度以 0.1.0 实际界面为准。

## 高频疑问

### 赛后解说收费吗

解说是模型调用，察元竞技场软件本身 MIT 开源免费。解说用云端模型时，费用按你的 API 用量向厂商支付；用 Ollama 本地模型则零成本。

### 实时解说和赛后解说选哪个

看你缺什么。当下看不懂，开实时解说；事后想弄明白，用赛后解说。预算紧就只留赛后——整局串讲的信息密度更高。

### 哪些对局能生成赛后解说

打完留档的对局都可以从复盘场景去用，人机局、机机观战、锦标赛的对局都在此列；具体入口以应用内实际能力为准。

### 解说的结论和问叹号标注不一样怎么办

正常现象，两者一个是模型的文字判断，一个是引擎的局面评估，口径不同。分歧处正是值得细看的点，回放逐手验证，别全盘照收任何一方。

### 解说内容能导出吗

棋谱导出覆盖对局数据；解说文本的留存支持以应用内实际能力为准，拿不准就先截存，复盘笔记建议自己另记。

赛后解说的价值，不在它替你下了结论，而在它把一局散落几十手的棋重新讲成了一个有头有尾的故事。配合问叹号标注找准位置，配合形势曲线验证说法，听完再自己走一遍——让AI给你讲完整局，然后把这局真正变成你自己的。
