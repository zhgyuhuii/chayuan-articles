# 智能体常见问题高频问答：家外部 CLI 智能体

## 智能体常见问题：结论先行

围绕智能体，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI OS整理。

## 再补几个同主题问答

### 密码忘了能像桌面版那样用恢复密钥/智能体面试找回吗？

不能。恢复密钥与验证画像找回体系仅桌面形态。web/docker 形态找管理员：在 设置 ＞ 用户 点该用户的「重置密码」生成新密码即可。

### 向导里选了厂商模型，但智能体调用报未知模型？

向导保存时会自动确保该厂商的代理路由可用；若你之后在 设置 ＞ 模型 停用了该厂商，路由随之移除。重新开启厂商或换一个默认模型即可。

### 勾选清单里只有一部分智能体，另外装的（Gemini CLI 等）是灰的？

灰显 = 该智能体当前没有模型配置写入面（行尾标「暂不支持自动写入模型配置」），只能走各家自己的账号配置。五家（Harness/Claude Code/Codex/OpenCode/OpenClaw）之外暂不支持自动写入。

### 模型直跑灵宠双击怎么没开智能体工作台？

模型直跑（不挂智能体）本来就没有工作台：双击打开的是它自己的「灵宠对话」直聊窗，用建宠时选的模型直接回答。

### 任务选了智能体方式，为什么运行失败？

无人值守执行当前仅支持 Codex / Claude Code / OpenCode 三家（表单下拉也只列这三家）。失败会留痕：任务行 、「历史」里可看错误，报告文件的「错误」小节有详情。

## 背景速览

察元AI OS（aidooo.com）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找官方入口
- 模型、权限、依赖先检查一遍
- 大小上限、付费范围、平台差异提前读一遍

遇到与本文口径不一致的情况，以aidooo.com最新文档为准。

安全口径单独立一层：设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；工作区默认打开代理（智能体）加扩展名默认应用覆盖表，让特定文件类型默认交给智能体处理，双击即用 AI。
