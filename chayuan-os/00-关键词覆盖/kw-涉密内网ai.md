# 给政企用户完整的桌面迁移体验：涉密内网AI概念与上手

搜涉密内网AI的人不少，可它具体指哪类东西、跟装个工具软件有什么本质差别，网上说法相当混乱。下文按官方口径给出定义、数字与边界，产品对象是察元AI OS。

## 什么是涉密内网AI

把涉密内网AI拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）——一个 AI 桌面操作系统，壳是完整的桌面环境，里面装着本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面；Windows/macOS/Linux（银河麒麟、统信 UOS）以及 Docker 云桌面形态都支持，断网可用，数据不出本机。

文中数字与版本基线均核对自官方文档，具体截止时间见文末。

## 察元AI OS的能力地图

- 知识图谱：打开知识库应用的知识图谱页签，文档与实体的二部图会自动生成出来
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：走自动那条路，一键把代理地址连同模型写进五家配置，写之前有备份、可回退
- 便签：桌面独立小窗便签：新建、置顶、折叠、换色、贴图片视频附件。
- 提醒事项：按今天、已计划、旗标、已完成智能筛选，多列表管理。
- 日历：日/周/月/年四种视图，个人、工作、家庭、学校四本日历分开记。

## 哪些机器和场景要掂量

- 8GB 内存的设备，一次只加载一个对话模型为宜，复杂任务会受影响
- 龙芯暂不在支持列表里；本地不做视频生成，视频生成由云端路由承担
- 调用云端厂商模型时，API Key 需要自行准备
- Docker 云桌面与跨终端互联属于进阶形态，得有点动手能力再上

这几条边界都不影响主线功能，选型前弄清楚更稳妥。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 内网用户常问的两件事

### 涉密内网AI离开网络还能干什么

内网恰恰是这套东西的主场。文件管理器里右键即可把文件交给智能体，这是最顺手的 AI 入口之一；常驻任务里写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，一次设好长期复用；还可以让特定文件类型默认交给智能体处理，双击即用 AI。内网或特殊网络环境下安装插件要走的配置，也都在这条链路上。

### 密码找不着了走哪条路

恢复密钥丢了、管理员也帮不上忙时，还有 AI 面试这第三条路：由本地 AI 出题验证，全程不出网。这条路需要提前开启并积累足够的记忆数据，临时抱佛脚来不及。

## 最后给一个判断

涉密内网AI要不要上，把前文的口径与边界对着自己的环境捋一遍：匹配就往下推进，不匹配不必勉强。

## 五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键可以更改墙纸与小组件

## 窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 引用不到知识库怎么排查

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查能定位到具体是哪一层出的问题；知识图谱页签里点条目可以互跳、定位回原文，验证链路是否通。

## 锁屏与密码找回

共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先的系统没有厂商服务器替你重置密码，三路找回就是最后的依靠。

## 安全机制的细账

模型库按本机内存预算分层推荐，能跑、勉强、跑不动三档标记；代理只监听本机回环，跨机访问需要另行打通；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。

## 无头部署与内网落地

断网环境、涉密内网、不想为调 API 付费，这三类需求最终都指向同一件事：把模型放在自己机器上跑。整套系统也可以无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态），员工浏览器打开即用；每次产出的 markdown 报告都会落盘归档。

## 代理端口与内网导入

模型代理固定在 52581 端口，OpenAI 兼容。很多人卡在第一步不是不会用 AI，而是被各家智能体各配一遍模型劝退，这里 OpenAI 风格与阿里百炼风格 API 可以自动适配。完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。

要把住重点的话，盯住完整桌面范式这一条就够了；其余细节按前面的步骤小节对号入座。
