# 软配置面板深度解析：机制、设计与取舍

聊软配置面板之前先划重点：它不是单一功能，而是一套带入口、步骤和验证的完整流程。察元AI文档助手在这件事上的设计思路是把入口收拢、把步骤做实、把边界说清，理解了这个，操作就顺了。

## 是什么与为什么

「控制台」（/control）把产品的全部「软配置」收进一个六页签面板：Feature Flags 实验开关、自动安装助手管理、授权状态与激活、个性化记忆、遥测同意、推荐徽章——改动立即生效、可还原。这是面向开发者/运营与进阶用户的页面，日常使用不需要动它。

散在各处的配置收进一个面板，运维不用翻菜单。

下面直接进入正题。

## 往深了说一层

散在各处的配置收进一个面板，运维不用翻菜单。

能力面拆开看：软配置管理；集中配置。

一个常被问到的问题：Feature Flags 开关和设置页有什么区别。设置页是产品正式功能配置；控制台的 Feature Flags 是实验/灰度开关，多数默认关闭、需业务方主动启用才生效。不确定时保持默认即可。

从提问口径看，用户最关心的是控制台在哪里？Feature Flags 是干什么的？

## 一步步来：从入口到完成

按最短路径验证一遍：

1. 打开控制台：按 ⌘K/Ctrl+K 打开命令面板，输入「控制台」，点「打开控制台(Feature Flags / 助手安装 / License / 个性记忆 / 遥测)」（「帮助」分组）；窗口跳转到 #/control。页面标题「控制台」，副标题「所有软配置在此一站式调整 — 立即生效,可还原」，右上「返回」。
2. 页签一「Feature Flags」：列出全部实验开关，页首提示「这些 flag 默认 关闭,启用后业务方主动调用相应模块时才生效。」共 8 个开关，其中 7 个默认关：enhancedSend（enhancedSend 高置信短路 + 乐观流式）、shadowDoubleRun（chatCompletion 同步触发影子运行）、parallelChunksAuto（默认开启 parallelChunks=4）、rolloutBucketing（5%＞25%＞50%＞100% 灰度分桶）、personalMemoryInject（把个性化记忆注入 system prompt）、rateLimiter（LLM 调用 token bucket 限流）、experimentalAbortV2（改进的中断链路）；kbRemoteIntegration（远程知识库集成）默认开。每项显示 flag 名、说明、「默认:开/关」和一个开关；切换后弹 toast「<flag名> 已启用/已关闭」。
3. 页签二「自动安装助手」：顶部两张统计卡「已自动安装」数与「总可安装数」（18）。说明文字：18 个新助手（P3 extra 8 + P5 领域 8 + P5+ 补 2）在首次启动时自动注入到自定义助手。三个按钮：「立即安装(force=true)」（重装全部，toast 显示「已注入 N 个助手 / 跳过 M 个(已存在)」）、「全部卸载」、「清理卸载标记(允许重新安装)」；下方「已安装清单」逐条列出图标、id、名称与安装日期。卸载过的助手不会随启动「复活」，除非清理卸载标记。
4. 页签三「License」：授权态卡片显示当前套餐（免费/已激活/已过期——过期显示「授权已过期或次数已耗尽」）与授权详情（模块、到期时间、剩余次数）。已购提示「已购买授权,执行助手不限次数,脱密/脱密还原等高级功能已解锁。」；未购提示「每日均可免费使用对话与执行助手。购买授权后不限次数,并解锁脱密/脱密还原。」并附「支持我们」区块：购买二维码（148×148）、本机指纹、「用手机扫码支持我们，或」与「在浏览器中打开」链接。下方激活区：输入框（占位 XXXXX-XXXXX-XXXXX-XXXXX-X）+「激活」（验证中显示「验证中…」）；已激活时按钮区多一个「取消激活」。激活成功提示「激活成功!授权已生效。」，失败显示红色原因，与 W42 的验签提示一致。
5. 页签四「个性化记忆」：提示「个性化记忆会拼到所有助手 system prompt 后,让模型尊重你的偏好。」表单项：「偏好语气」下拉（(不指定)/口语化/正式书面/学术严谨）、「长度倾向」滑杆（-1 更短 ~ +1 更长，实时显示倾向文案）、「避免黑话」开关、「个人备注」多行输入（占位示例「如:我是法律领域从业者,请优先用术语」）。下方「个人术语表」：输入术语与解释（≤ 200 字）点「添加」，列表可逐条删除。展开「预览注入到 system prompt 的内容」可看到实际拼接的提示词。注意：要让记忆真正注入助手，还需打开页签一的 personalMemoryInject 开关。
6. 页签五「遥测同意」：提示「遥测默认关闭。只有你明确同意,产品才会上报匿名指标(无原文,只 hash)。」状态卡显示「已同意 / × 未同意」与缓冲条数。按钮：「同意上报」/「撤回同意」、「导出我的数据」、「删除我的数据」。
7. 页签六「推荐徽章」：一张徽章卡，显示当前徽章图标与名称（无则「暂无徽章」）和「已分享 N 次」及下一档进度提示。

## 几个容易忽略的细节

用之前要认的账：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 你可能会问

### 卸载了自动安装助手，重启后又回来了？

卸载会写「卸载标记」，正常不会复活。若你点过「清理卸载标记(允许重新安装)」，下次触发安装时会重新注入；不想用就再次「全部卸载」，不要清理标记。

### 在控制台改的东西会立即生效吗？重启后还在吗？

各页签改动即时写本机存储并立即生效（flags 切换即写、记忆与术语表失焦/点击即存、遥测同意即切换），重启后保持；想还原时把开关切回「默认:开/关」标注的状态即可。

### Feature Flags 开关和设置页有什么区别？

设置页是产品正式功能配置；控制台的 Feature Flags 是实验/灰度开关，多数默认关闭、需业务方主动启用才生效。不确定时保持默认即可。

### 遥测会传我的文档内容吗？

不会。产品口径是匿名指标、无原文只 hash，且默认关闭；不放心可保持「未同意」，或用「导出我的数据 / 删除我的数据」管理已收集内容。

## 补充答疑

### 个性化记忆填了但助手不生效？

记忆注入受 personalMemoryInject 开关控制（默认关）。到「Feature Flags」页签打开它；展开「预览注入到 system prompt 的内容」可确认拼接结果。

### 控制台里的激活和「购买授权」窗里的激活一样吗？

同一套本地验签激活链路（licenseStore.activate），只是入口不同；失败原因文案一致，详见对应教程。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。
