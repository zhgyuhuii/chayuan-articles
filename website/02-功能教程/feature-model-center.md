# 大模型目录实操实操教程：从入口到完成每一步都有反馈

写这篇的起因是群里有人问大模型目录实操，我发现自己也说不完整，索性把察元AI 能力广场里的模型中心从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 它是什么，为谁服务

模型中心含大模型目录、模型厂商页与模型对比页：模型按厂商、能力、价格维度查询对比，厂商页收录已核验的模型厂商与网关。

选模型看目录比看营销稿靠谱，参数价格一页对比。

先把这个定位立住，再看步骤。

## 具体怎么操作

对比两个模型

1. 进模型中心大模型目录
2. 勾选要对比的模型
3. 查看能力、上下文、价格维度对比表
4. 进厂商页看接入方式

## 什么情况下用得上

对比两家厂商的定价；为新项目选模型。

## 高频疑问

### 模型目录的数据准吗？

目录与厂商页由数据采集链路持续同步（OpenRouter、models.dev、Ollama 等源），参数与价格随厂商更新。

### 能对比几个模型？

模型对比页支持多选对比，维度覆盖能力、上下文长度与价格。
