# Office Linux安装下载安装：按平台架构一步步来

如果你正在琢磨Office Linux安装，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI Office的下载安装与首次启动时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 安装前确认

- 系统要求：deb/rpm/AppImage；AppImage 需 glibc 2.34+
- 安装包：deb/rpm/AppImage（x64/arm64）
- 说明：deb rpm AppImage 三形态。

Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；另有浏览器 SaaS 与 dsh 插件形态（五编辑器，无 HTML）。安装包从官网 aidooo.com 获取或 GitHub Releases，其他站点均非官方渠道。

## 实操全过程

1. 官网下载对应包
2. deb 用 dpkg -i，AppImage 加执行权限直接运行
3. 麒麟/UOS 走 AppImage 加 deb，免 root
4. 配合本地模型端点可实现离线办公

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

开始页新建一个 docx，在设置模型里接上厂商 API 或本机 Ollama，然后让首页 AI 生成一段测试文本——三步都通，环境就绪。

## 收尾检查

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx

## 高频疑问

### 第三方下载站 mirror 的安装包能用吗？

不能保证。官方分发只有 aidooo.com 与本仓库 GitHub Releases 两处，其余站点均非官方分发，存在被篡改风险，请从官方渠道重新下载。

### 麒麟/UOS 上装哪个包？要联网吗？

选 .AppImage（免 root、离线友好，要求 glibc 2.34+）或 .deb。下载一次后可拷贝到内网机器直接安装/运行，应用本体不依赖联网。

### 90 天试用到期会锁功能吗？要注册账号吗？

不锁功能。到期后每日一次温和提醒（可关闭），不购买也完全不影响使用；购买走离线短序列号，内网无激活服务器也能激活。使用 AI 的云端能力需在设置中配置模型或登录账号，见产品内的对应手册产品内的对应手册。

## 补充答疑

### 欢迎引导被我关掉了，想再看一遍怎么办？

引导只出现一次，界面不提供「重看引导」入口。想系统了解产品，按 F1 打开内置图文手册（18 主题，可搜索），见产品内的对应手册。

## 安装与运行答疑

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

## 一个真实场景

财务与数据岗的典型用法：Sheets 导入多源 xlsx（Rust 边车保真往返），数据透视表与切片器做汇总，公式追踪与监视窗口排查错误。免费开源套件覆盖财务日常表格工作。注意：ODF 格式导入采取保守策略，复杂公式只保结果值。

## 顺带了解

PDF 签名与页面操作：手绘、图片、证书（p12 与 pfx）三种签名；页面页签：旋转、重排、拆分、合并、Bates 编号、打印。

为什么值得看：证书签名带验证链，盖章归档一条链完成。

## 还有这个能力

打印与自动保存：六编辑器统一打印链路；30 秒自动保存，关闭时询问未保存项。

## 硬口径两三条

- 22 种界面语言
- 六编辑器：docx/xlsx/pptx/真文本 PDF/Markdown/HTML（web/dsh 形态为五编辑器）

## 如实说不足

- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值
- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 定位与家族

察元AI Office（Chayuan AI Office）是一款 Apache-2.0 开源的 AI 办公套件，把 docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器装进一个应用，AI 校对以批注锚定原文、修订追踪生成通用修订，Docs 端内置 4576 个领域助手，支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点，覆盖 Windows/macOS/Linux（含麒麟/UOS），本地优先、离线可用。同家族产品：察元AI OS（AI 桌面操作系统）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 边界速览

- web/dsh 形态只有五编辑器（无 HTML），且无购买激活界面

## 数字口径

- Docs 端 4576 个领域助手、229 个领域包，全库约 4600 个；表格 102、演示 100、PDF 100、Markdown 100、HTML 130
- 94 家模型供应商目录（国内 29/国际 34/本地 9/聚合 22）、28 个适配器，4 种可选协议
- chaoffice 命令行 17 个子命令；壳内 MCP 服务端口 52588
- 知识库五级自动发现，注册表端口 52584，检索上下文预算默认 12000 字

## CLI 与自动化

chaoffice 命令行有 17 个子命令，转换、创建、渲染、搜索、图像等都能脚本化；配合壳内 MCP 服务（29 个 CLI 工具），外部智能体可以直接操作文档，办公自动化有了标准协议入口。

## BYOK 的接法

设置里 94 家供应商目录分国内、国际、本地、聚合四组，28 个适配器归一化接口；模型列表实时拉取，Key 存本机不上传。本地端点支持 Ollama、LM Studio、Xinference 等八类，内网离线全可用。

## 知识库联动

AI 面板与首页输入框下方可多选本机察元OS 知识库，每轮回答前并行检索（每库前 6 条），答案带编号引用角标，点开看来源与下载原文；上下文预算 8000 到 32000 字四档可调，检索失败不阻塞发送。

## PDF 能力链

阅读侧有选区标注浮条与便签线程；编辑侧改的是页面内容流本身（保留原字体，不是贴白块遮盖），涂黑生成物理删除的新文件；转换侧 PDF 转 Word、Excel、PPT、Markdown、HTML 全部本机完成，扫描件经系统 OCR 自动识别后可搜索可引用。
