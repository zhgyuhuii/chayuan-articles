# 数据存储位置怎么做：数据路径透明

数据存储位置这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI文档助手的真实界面顺序走一遍，先解决备份前找数据目录。

## 先弄清楚它是什么

为什么要有数据存储位置：知道自己数据在哪，才有安全感；出问题有客服入口。数据路径与帮助反馈的定位是本地数据落盘位置说明、帮助手册、在线客服与关于页。

入口、步骤、验证三段看清，这事就顺了。

## 前置条件

- 打开 AI 助手窗格（侧栏在其左侧）；数据路径的写入依赖 WPS 提供的文件能力，路径需本机可写。

## 数据路径与帮助反馈：从入口到完成

A. 数据路径设置

1. 进入：AI 助手窗格侧栏底部点「设置」齿轮按钮打开设置窗；左导航点「常规设置」＞ 子菜单「数据设置」，右侧进入「数据路径设置」面板。
2. 读说明：页面说明原文——「设置后，规则数据（relus.aidooo）、导入的文档模板等本地数据将统一保存到此路径下。留空则规则不写入本地文件。」
3. 填路径：在输入框（占位「请选择或输入数据目录，规则将保存为 relus.aidooo」）直接输入目录，或点「选择文件夹」用系统对话框选择；下方显示「默认路径：<系统默认目录>」（Windows 为 C:\Users\<用户>\AppData\Roaming\chayuan，macOS 为 ~/Library/Application Support/chayuan，Linux 为 ~/.config/chayuan）。可点「使用默认路径」一键回填默认目录。
4. 看错误日志位置：面板同时说明「全局错误会写入下方目录中的按日日志文件（如 2026-3-30.log）。留空数据路径时使用各系统默认日志位置。」，并只读显示「错误日志目录（只读）：<目录>」；还有一条兜底提示：若该目录下没有生成 .log，多为路径不可写或相对路径未被接受，此时最近错误缓存在插件存储键 NdErrorLogFallback（进程闪退时磁盘上可能仍没有文件）。
5. 保存：点设置窗底部「保存」。数据路径实际保存在 WPS 插件存储（键 NdDataPath，localStorage 备用）；留空保存表示不写入本地文件。同页还有「多模态服务端 Fallback」配置（服务端视频分析兜底开关、接口地址与密钥），按需配置。

B. 帮助手册

1. AI 助手窗格侧栏底部点「帮助」，弹出「帮助 · 用户手册」窗口，副标题「察元 AI 文档助手 · v<版本号>」。
2. 顶部常驻一条「MCP 服务地址」（默认 http://127.0.0.1:62588/mcp）：点「复制」复制地址，点「MCP 管理」跳到设置里的 MCP 服务管理。
3. 左侧章节目录点击跳转，右侧渲染用户手册正文（本地打包的 user-manual.zh-CN.md，离线可读）。

C. 反馈及建议（在线客服）

1. 侧栏底部点「反馈及建议」，弹出「在线客服 · 察元AI」窗口（400×600）。
2. 打开时先探测官网可达性（探测 aidooo.com/favicon.ico，约 4.5 秒超时）：可达时内嵌官网同款聊天页（aidooo.com/bot/chat）；显示「正在连接在线客服…」后进入对话。
3. 离线/不可达时自动兜底：显示本地打包的微信公众号二维码，文案「当前网络不可用，无法打开在线客服」「请用微信扫码关注公众号，与我们联系」。

## 如何确认操作生效

验证

1. 设置一个本机可写目录并点「保存」，重开设置窗：输入框应保留该路径，「默认路径」行显示系统默认目录。
2. 按 A-4 的说明核对日志位置：触发一次错误后到「错误日志目录（只读）」所示目录找按日命名的 .log 文件。
3. 断网后点「反馈及建议」：应显示公众号二维码兜底页而不是白屏；恢复网络重开则进入在线聊天。
4. 点「关于察元」：应弹出近全屏深色窗口并能看到架构拓扑图与「北京智灵鸟科技中心」署名。

## 什么情况下用得上

想了解产品由谁开发、版本与官网信息，出错后想找日志文件、查用户手册、或直接联系客服；提工单前收集版本信息，规则/模板数据想集中放到指定目录（便于备份或内网管控）。

用户常搜的问法：规则数据存在哪里？怎么改保存路径；错误日志在哪里找。

## 几个容易忽略的细节

如实说明，它不是万能的：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 你可能会问

### 设置了数据路径，目录里却没有 relus.aidooo？

先确认三点：设置后点过底部「保存」；路径本机可写（公司管控目录可能只读）；且确实执行过会产出规则数据的操作。仍无文件时看 Q2 的日志定位。

### 错误日志目录里没有 .log 文件？

多为路径不可写或相对路径未被 WPS 接受；此时最近错误缓存在插件存储键 NdErrorLogFallback。换一个确定可写的目录重新保存，或把相对路径改为完全路径。进程闪退、原生崩溃可能在落盘前终止，磁盘上仍可能没有文件。

### 在线客服一直「正在连接在线客服…」？

约 4.5 秒探测超时后会自动切到公众号二维码兜底页；若长时间停留，多为网络受限（内网防火墙拦 aidooo.com），可离线扫码走微信联系。

### 帮助手册里的 MCP 地址和我本机不一致？

手册顶部默认展示 http://127.0.0.1:62588/mcp；以你本机 MCP 服务的实际地址为准。

### 换电脑后数据路径要重新设吗？

要。该设置保存在本机 WPS 插件存储中，不随文档或账号漫游；新机器按 A 节重新设置一次即可。
