# 运行时挂载插件：智能体可以在运行时定义并挂载新插件，别再瞎试

先说这篇能帮你干什么：读完能在察元AI OS里独立完成运行时挂载插件，路径是让 AI 造一个盯竞品的应用。步骤里的每个「」按钮都是界面原文。

## 先定位问题在哪一层

运行时挂载插件的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把环境与模型这两件事核一遍，再查路径。

## 正确的操作路径

试一次创造模式

1. 打开对话应用进入会话
2. 描述你要的应用：做什么、放哪里、多久更新
3. 智能体定义并挂载插件，权限门确认后生效
4. 桌面出现新应用，可继续让它迭代

迭代与沉淀

1. 对着新应用提修改意见，智能体原地升级插件
2. 满意后保留挂载，不满意右键卸载
3. 把好用的话术存进用户记忆，下次直接复用

## 常见问题

### 创造模式生成的应用稳定吗？

生成的是标准 dsh 插件结构，挂载后与其他插件同等对待：可启停、可卸载、可随会话迭代。复杂逻辑建议拆成多轮对话逐步逼近。

### 智能体造应用时要授权吗？

挂载插件属于系统级操作，会过权限门确认；高危动作（跑终端、装依赖）按 T1/T2 分级再确认，全程留审计。

### 适合造什么样的应用？

信息聚合展示类（盯价格、汇总新闻）、简单工具类（倒计时、随手记）最合适；重度数据处理建议走正规插件开发。
