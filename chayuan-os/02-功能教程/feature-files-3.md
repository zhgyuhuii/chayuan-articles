# 用智能体打开文件解决实际问题：场景化用法全记录

上周有同事问我：智能体打开文件这块到底该怎么弄。他折腾了半天没找到入口，其实不是功能难用，是没人把路径讲清楚。这篇就把我的电脑从入口到收尾完整过一遍，用的是察元AI OS的真实界面，照着点就行。

## 先看看痛点对不对得上

批量整理下载目录，想浏览、上传、整理文件，或把本机文件放进察元让智能体/应用处理，双击文件想控制它用哪个应用打开（文本/图片/PDF/音视频/代码/Office）；选中年报让 AI 总结。

用户常搜的问法：我的电脑里怎么看不到我 Mac/Windows 硬盘上的文件；怎么把文件上传到察元OS？上传到哪儿了。

## 具体怎么操作

第 1 步 · 打开与界面布局

1. Dock 点「我的电脑」，打开文件管理窗口。窗口标题随当前目录走（根目录显示「我的电脑」，进入子目录后显示目录名）。
2. 窗口分三块：顶部工具栏（导航 + 视图 + 新建/上传按钮）、左侧边栏、底部状态栏（显示「{n} 个项目」，选中后追加「已选择 {n} 项」；有传输时追加待完成计数）。
3. 工具栏最左是窗口红绿灯；红绿灯右侧有边栏折叠按钮，可收起/展开左侧边栏。

第 2 步 · 浏览与导航

1. 边栏四项：「我的电脑」（根目录）、「桌面」（Desktop 目录）、「工作区」（Workspaces 目录）、「废纸篓」（点击打开废纸篓应用）。
2. 工具栏导航按钮（鼠标悬停显示名称，无可用操作时置灰）：「返回」「前进」「上移一级」「刷新」。
3. 地址栏是面包屑：起点「我的电脑」，之后每层目录一段，点任一段直接跳到该层。
4. 双击文件夹进入；应用的替身文件（.url）双击即打开对应应用。

第 3 步 · 切换视图

工具栏中部四个视图按钮：「图标」（默认）、「列表」、「详情」、「以画廊显示」。「详情」视图按列显示「名称」「种类」「大小」「修改日期」（文件夹大小列显示 --）；种类标签包括 文件夹/图像/视频/PDF/文档/音频/代码/Markdown/替身/文件。

第 4 步 · 新建文件与文件夹

1. 工具栏右侧三个按钮：「新建文件夹」「新建文本文档」「上传文件…」；空白处右键菜单也有「新建文件夹」「新建文本文档」（外加「上传文件…」与「粘贴」）。
2. 新建后立即进入行内重命名态（输入框），回车确认、Esc 取消；同名自动避让，追加序号如 新建文件夹 (2)。

第 5 步 · 上传与下载

1. 上传两条路：点「上传文件…」（弹系统多选文件框），或把电脑里的文件直接拖进窗口。文件落到当前目录。
2. 上传过程中右下角出现传输面板：每行显示类型（「上传」/「转换」）、文件名、进度条与百分比；行尾 × 可取消，完成后变绿色 （取消显示「已取消」，失败显示 关闭），再点 × 收起该行。同名文件由服务端自动加序号，不覆盖。
3. 下载：右键文件 ＞「下载」，经浏览器下载把文件取回本机。

第 6 步 · 选中与快捷键

1. 鼠标：单击选中；⌘/Ctrl+单击增减多选；空白处按住拖动框选。条目也可以直接拖到文件夹图标上移动进去（目标文件夹亮蓝框后松手）。
2. 键盘（窗口前置、未聚焦输入框时）：⌘/Ctrl+A 全选；⌘/Ctrl+C 拷贝、⌘/Ctrl+X 剪切（移动）、⌘/Ctrl+V 粘贴到当前目录；Delete 移到废纸篓；F2 重命名；Enter 打开选中项；Backspace 上移一级；Esc 清空选择。
3. 剪贴板跨窗口可用：在「我的电脑」复制/剪切后，可粘贴到桌面右键「粘贴」（反之亦然）。

第 7 步 · 文件/文件夹右键菜单（逐项）

右键某个条目：

1. 「打开」：等同双击（目录进入、文件按关联表打开）。
2. 「重命名」：进入行内重命名态。
3. 「剪切（移动）」/「拷贝」：写入剪贴板（对整个当前多选生效）。
4. 「下载」（仅文件）：下载到本机。
5. 「转换为…」（仅可转格式文件）：子菜单按类型给目标格式——图片转 PNG/JPEG/WEBP；音频转 MP3/WAV/M4A/OGG；视频转 MP4/WEBM；表格转 XLSX/CSV（当前格式不重复出现）。点目标格式后右下角传输面板显示「转换 ＞ 目标格式」进度，产物以替换扩展名后的新文件写回当前目录。
6. 「简介」：弹出属性对话框，显示「大小」（文件夹显示「{n} 个项目」）、「位置」（根相对路径）、「修改日期」；图片额外有「照片信息」区（相机/拍摄时间/快门/光圈/ISO/焦距/尺寸等 EXIF，读取中显示「读取中…」）。
7. 「移到废纸篓」（红色）：删除选中项（对整个多选生效），文件进 .Trash 可恢复。

第 8 步 · 双击文件按什么打开（关联表）

双击普通文件后由关联表决定：

1. .docx .xlsx .pptx .md .markdown .html .htm .pdf ＞ 察元AI Office；
2. 文本类（.txt .csv .log .ini .cfg .conf .env .properties）＞ 文本编辑；图片 ＞ 图片查看；音视频 ＞ 媒体播放器；代码文件（.js .py .json 等）＞ 代码编辑；其余未知类型 ＞ 文件查看（兜底，给下载出口）。

第 9 步 · 与智能体联动

1. 「工作区」目录是智能体的作业区：把项目文件放进 Workspaces 下的分区，即可被各智能体作为工作区打开。
2. 双击桌面上的工作区图标：给该工作区钉过默认智能体就用它打开；没钉过则用文件管理器打开，并首次提示一次「已用文件管理器打开分区；右键 ＞ 打开方式 可选择智能体并记住」。工作区图标右键「打开方式」的候选是已安装的 DeepSeek Harness / Codex / OpenCode / OpenClaw（当前默认带「默认」徽标，底部「设为默认」按工作区钉住）。
3. 「我的电脑」窗口内的右键菜单不含「打开方式」；想改某类文件的默认打开应用，走 设置 ＞ 默认应用（扩展名默认覆盖表，与桌面图标右键「打开方式 ＞ 设为默认」同一张表），或对桌面目录里的文件直接用桌面图标右键设置。

## 关键能力点

- 双栏浏览
- 右键交 AI
- 默认打开方式

## 它的局限也要说清楚

边界都在这：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 高频疑问

### 想把某个文件交给 Claude Code / Codex 处理，怎么操作？

把它放进一个工作区分区（Workspaces 下），然后桌面空白右键 ＞「用智能体打开」＞ 选智能体 ＞ 选该工作区；或在桌面双击该工作区图标（想默认用某家智能体，在工作区图标右键「打开方式 ＞ 设为默认」钉住 Codex/OpenCode/OpenClaw，不钉则用文件管理器打开）。

### 删除的文件还能找回来吗？

能。删除进的是真实 .Trash 目录：Dock 最右端废纸篓左键打开废纸篓应用可查看/恢复，右键可「清倒废纸篓」彻底删除。

### 为什么看不到我电脑硬盘（如 D 盘、~/Documents）里的文件？

「我的电脑」管的是察元文件系统——一个独立沙箱根目录，不挂载整机磁盘。把要处理的文件用「上传文件…」或拖拽传进来即可；想把某个本机目录变成作业区，用桌面右键「新建或选择工作区…」注册。
