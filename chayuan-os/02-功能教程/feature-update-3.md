# 在线检查更新：用版本升级跑通一个真实场景

版本升级的麻烦不在功能本身，在于信息散。升级不丢数据是底线，检查更新静默失败不影响使用。这篇把它收拢成一条能照着走的路径。

## 解决什么痛点

定期升级；检查更新报错，想知道手动下载安装包的渠道；想知道当前装的察元OS 是什么版本、有没有新版；听说发了新版本，想升级到最新。

## 具体怎么操作

从这几步开始：（第 3 个切入角度）

1. 在线检查更新
2. 重启安装
3. 数据保留
4. 场景验证：定期升级
5. 场景验证：手动装包升级
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 关键能力点

- 在线检查更新
- 重启安装
- 数据保留

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 版本升级要联网吗

断网时联网搜索自然不可用；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。以官网 aidooo.com 当前页面为准。

### 版本升级数据存在哪

一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全，全新安装选数据目录或导入拷贝根，创建管理员，数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把版本升级放回察元AI OS的整体盘面：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；以完整桌面环境为壳，（web/Docker 形态网页桌面默认端口）；暂不支持龙芯平台。

## 安全与数据边界

安全口径单独立一层：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，数据文件不受影响；三条路都不满足就只能清数据重装，务必提前生成恢复密钥，需要提前开启并积累足够记忆数据。

## 平台与形态

平台与形态的账：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness，Dock 是使用频率最高的区域，位置与大小顺眼很影响手感，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 价格与授权

价格口径一并交代：提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件，装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平；升级不丢数据是底线，检查更新静默失败不影响使用；服务链自愈：崩溃退避重启、配置异常回滚上一可用版本、端口被占自动顺延并让消费方重新发现。

## 产品家族与搭配

察元AI OS不是单打独斗：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；购买 OS 授权后，同机察元AI Office 自动免激活；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。

## 几条硬数字

能落到数字上的几条：设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关；它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，默认只监听回环端口，联网环境下内置 web_search 工具默认走 DeepSeek 搜索。

## 离线与内网

离线内网这条线的口径：完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入，帮助中心离线可读，断网也能查手册；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面；断网可用、数据不出本机。

## 能力总账

把察元AI OS的能力总账摊开：知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库，导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成，在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么。
