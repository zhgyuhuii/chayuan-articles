# MCP服务问题常见问题合集：答案结论先行

## MCP服务问题：结论先行

围绕MCP，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI文档助手（版本 6.1.2，aidooo.com）整理。文末附预防清单，多数问题的根子都在那三条里。

### 想停掉服务怎么办？

前台方式启动的在终端按 Ctrl+C；找不到终端就结束 chayuan-mcp（二进制）或 node server.mjs 进程。设置页在端口冲突时也会提示：「请在运行 sidecar 的终端按 Ctrl+C 停止，或结束 chayuan-mcp / node server.mjs 进程。」设了自启的先卸载自启（autostart 脚本 /uninstall 或删对应 LaunchAgent/服务），否则看门狗会再拉起来。

### 外部智能体（如 Claude Code）能做脱密复原吗？

可以。本机 MCP 文档智能体服务提供同能力的 declassify_restore 工具（需 confirmed 确认与密码两个参数；工具说明明确无密码必然失败，请勿尝试暴力破解），另有 declassify_status/declassify_preview/declassify_apply 配套，接入方式见对应教程。

### 和「文档脱密」是什么关系？

保密检查是「查」——只读分析、批注标注；文档脱密是「盖」——把确认要遮盖的关键词替换为占位符。常见流程是先保密检查摸清风险点，再用文档脱密统一遮盖。

### 审计会改我的文档吗？

审计本身只读；仅有会写文档的动作是按助手写回动作给书签加批注（内容为「【文档审计】」+ 审计意见），不改正文。不想要批注，把助手的写回动作设为「无」即可。

## 再补几个同主题问答

### 怎么添加其它 MCP server？

点下拉底部「管理」进设置页的 MCP 服务管理添加；添加后回到下拉勾选即可启用，徽标数字只统计你手动添加且已启用的服务。

### Windows 安装报「ERROR: failed to copy the MCP sidecar binary. A chayuan-mcp process may still be running」？

旧的本机文档服务进程仍占用文件锁。按报错提示结束进程（taskkill /F /IM chayuan-mcp-windows-x64.exe）后重跑安装器；安装器自身也会先停计划任务再尝试最多 3 次结束旧进程。

### 帮助手册里的 MCP 地址和我本机不一致？

手册顶部默认展示 http://127.0.0.1:62588/mcp；以你本机 MCP 服务的实际地址为准。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找到官方入口，不从二三手教程猜路径
- 模型、权限、依赖这些前置条件先检查一遍再动手
- 边界条款（大小上限、付费范围、平台差异）提前读一遍

遇到与本文口径不一致的情况，以aidooo.com最新文档为准。

## 边界速览

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 数字口径

- 文字端 4526 个领域助手、228 个行业领域；表格端 66 个配方；演示端 81 个；翻译 52 语种动态菜单

- 本机 MCP 服务 http://127.0.0.1:62588/mcp，源码定义 69 个工具、外部实见 53 个，仅监听回环
- 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源

## 模板编制五段式

发模板文件加一句话需求后：形状级剖析（LOGO 页码水印判为装饰永不改写）、计划卡确认、副本填充（原模板零修改）、三轮质检自愈（上限四轮）、后台生成完成自动打开。红头文件与标书这类强格式文档最适合这条链路。

## MCP 写确认纪律

本机 62588 端口的文档智能体服务只监听回环；写操作不带确认标记会被拒绝并要求确认，每次确认写记入审计日志。外部智能体（Claude Code、Codex、Cursor 等）一行配置即可接入，代操作文档但不越权。

## 校对的执行机制

有选中只查选中，无选中确认后查全文（超 12000 字与 30000 字分档提示）；检查在独立进度窗里分块并发执行，块长默认 6000 字，关窗任务继续，只有点停止任务才中止；结果批注锚定原文，锚不上的不硬挂。

## 知识库端口梯

自动发现本机察元OS 知识库走固定端口 52582，失败时按端口梯并行探测；指纹校验通过后库列表实时同步，OS 侧增删库无需 WPS 重配。回答按编号标注出处，来源卡含可信度、章节路径与原文下载。

## 配图三级降级

第一级模型生图（最多试三个模型），失败走第二级网络搜图（Serper、Tavily、Pexels、SearXNG 免 Key），再不行第三级 SVG 矢量兜底；铁律是上级失败才降级，绝不静默换花钱的来源。

## 保密检查的口径

AI 分块研判八大类风险（密级标识、涉军涉装涉训、组织身份、人员联络、时间地点部署、内部编号、经营商业敏感、军工政企高频线索），高中风险分级加待人工复核；判据是语义与上下文，关键词只是线索而非结论，完整报告进任务清单。
