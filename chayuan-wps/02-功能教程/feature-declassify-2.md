# 拆开看脱敏工具实操：脱密占位替换是可逆设计

脱敏工具实操这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI文档助手的真实界面顺序走一遍，先解决把内部报告脱密后发外部评审。

## 文档脱密是个什么东西

脱敏工具实操能做的事拆开就这几件：AI 加正则双路提取，占位符可逆；加密载荷随文件走。对应的界面入口是文档脱密

先把定位立住，再看步骤。

## 文档脱密：从入口到完成

| 本地正则识别的格式 | 类别 | 风险级别 |

|---|---|---|

| 手机号 | 联系方式 | 高 |

| 身份证号（18 位） | 证件信息 | 高 |

| 邮箱 | 联系方式 | 高 |

| 字母编号（如 AB-123） | 编号标识 | 中 |

| 长数字编号（6 位及以上） | 编号标识 | 中 |

| 银行卡号（16 或 19 位） | 金融账户 | 高 |

| IPv4 地址 | 网络信息 | 高 |

| 车牌号 | 车辆信息 | 高 |

| 统一社会信用代码 | 单位信息 | 高 |

1. 打开要脱密的文档，在 Ribbon「察元AI助理」选项卡 ＞「安全保密」组点「文档脱密」。未购买授权时此处弹「购买授权」窗，购买后重试。
2. 弹出「文档脱密」窗口（约 860×720），副标题说明流程：「自动提取涉密关键词，确认后将原文替换为占位符，并把恢复载荷加密保存到当前文档。」窗口首先显示「正在调用“涉密关键词提取”助手...」（提示「请稍候，系统正在分析全文并生成关键词与占位符映射。」），系统做两件事：
    1. 调用内置助手「涉密关键词提取」分析全文，返回关键词清单；
3. 合并本地正则兜底扫描，共 9 类敏感格式（各带类别与风险级别）：
4. 进入确认页，顶部三张摘要卡：「命中关键词」「占位替换次数」「未命中关键词」。中间是「涉密关键词确认」表，提示「可修改、追加、删除关键词和占位符。」，逐列说明：
    1. 关键词：要遮盖的词，可直接改（输入框示例「如：解放军」）；容忍全角空格等对齐字符（如「张 辉」也能命中）；
    2. 占位符：替换用的 §…§ 随机码。系统为每行预生成随机占位符，输入框留空则执行时自动生成；模型建议的占位符会被丢弃、统一换成系统随机码，避免占位符可预测；重复或与正文冲突的占位符会自动重新生成保证仅有；
    3. 类别 / 风险级别：类别为文本框、可改；风险级别下拉可选 高/中/低；
    4. 操作：「删除」本行；右上「添加关键词」可追加新行。
    5. 核对两块反馈：「命中预览」逐词显示「命中 N 次」及上下文片段；有词没命中时出现黄色提示「下列关键词当前未在文档中命中，将不会参与替换：」——未命中的词不会参与替换，可删除或改写。
    6. 设置复原密码：在「保存密码」「确认密码」两个输入框输入同一密码（在确认密码框按回车等同点「确定脱密」）。密码规则提示原文：「密码规则：至少 8 位，必须同时包含大写字母、小写字母、数字和特殊字符。」不符合时错误显示在密码框下方（如「密码长度不能少于 8 位」「两次输入的密码不一致」）。
    7. 点「确定脱密」（执行中按钮显示「正在脱密...」）。系统把文档中所有命中的关键词按位置替换为对应占位符，并把含原文、关键词清单、替换位置表的恢复载荷用密码加密（AES-GCM-256，密钥经 PBKDF2-SHA-256 派生）写入当前文档的文档变量中随文件保存。
    8. 完成后窗口显示绿色结果：「已完成占位符脱密，共替换 N 处，涉及 M 个关键词。」及提示「当前文档已标记为脱密状态，可通过“密码复原”输入密码恢复原文。」，点「关闭」收窗。

最短路径走一遍：（第 2 个切入角度）

1. AI 加正则双路提取
2. 占位符可逆
3. 加密载荷随文件走
4. 确认边界：仅文字端提供，且属于付费专属能力（零免费额度）
5. 确认边界：忘记密码没有任何免密恢复通道
6. 场景验证：把内部报告脱密后发外部评审

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- 仅文字端提供，且属于付费专属能力（零免费额度）
- 忘记密码没有任何免密恢复通道
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 你可能会问

### 提示「智能助手提取失败」或「智能助手未识别到明确涉密关键词」？

模型调用失败或没识别出词时，弹窗会提示你仍可手工补充关键词后继续——点「添加关键词」逐个填入即可，本地正则扫到的 9 类敏感格式已在列表里。若提示「涉密关键词提取助手已被关闭，请先在设置中启用」，到 设置 ＞ 助手设置 启用；提示「未找到可用模型」则先按对应教程配好模型。

### 忘记密码怎么办？

恢复载荷是 AES-GCM 加密密文，复原必须用当初设置的密码解密；当前代码没有任何免密码的恢复通道，密码遗失即无法通过「脱密复原」还原原文。设置密码时请妥善保管。

### 脱密后的文档可以直接外发吗？

注意边界：占位替换是明文替换，且加密的恢复载荷保存在当前文档里随文件走——任何拿到文件的人只要知道密码就能复原。「密码可复原」是本功能的设计目标而非缺陷，外发前请确认这符合你的保密要求；若要求不可恢复的遮盖，本功能不适用。

### 对已脱密的文档又点了「文档脱密」？

按钮此时是置灰的；若从其他入口打开脱密窗口，会提示「当前文档已经处于脱密状态，请使用“密码复原”恢复后再操作」。先复原再重新脱密。

脱敏工具实操能不能用好，一半看操作，一半看你认不认边界：仅文字端提供，且属于付费专属能力（零免费额度）。
