## 什么是信创AI

把信创AI拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 在察元AI OS里落在哪

信创AI在察元AI OS里的落点是桌面环境总览：顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

为什么值得单独说：它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

### 信创AI要联网吗

工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复；断网时联网搜索自然不可用，灵宠把后台跑着的 AI 变成桌面上看得见的小生物。以官网 aidooo.com 当前页面为准。

### 信创AI数据存在哪

管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录，一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全；全新安装选数据目录或导入拷贝根，创建管理员。以官网 aidooo.com 当前页面为准。
