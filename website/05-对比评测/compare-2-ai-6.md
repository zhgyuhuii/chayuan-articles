# AI教程决策指南：教程库 vs 视频平台直接搜教程

教程库 vs 视频平台直接搜教程，是很多用户在选型阶段绕不开的问题。这篇场景化推荐不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（能力广场） | 对照方案 | 说明 |
|---|---|---|---|
| 覆盖 | 2.1 万+ 条七类型聚合（论文/仓库/视频/课程/书） | 单一平台单一类型 | 结构化优势 |
| 筛选 | 主题×类型双维筛选 | 靠平台推荐算法 | 学习路线可控 |
| 深度 | 含 arxiv 论文与 github 仓库 | 娱乐向内容稀释 | 研究型学习友好 |

## 逐项解读

**覆盖**：结构化优势。能力广场侧的做法是「2.1 万+ 条七类型聚合（论文/仓库/视频/课程/书）」，对照方案为「单一平台单一类型」——差异的本质在于设计取向不同，而非优劣。

**筛选**：学习路线可控。能力广场侧的做法是「主题×类型双维筛选」，对照方案为「靠平台推荐算法」——差异的本质在于设计取向不同，而非优劣。

**深度**：研究型学习友好。能力广场侧的做法是「含 arxiv 论文与 github 仓库」，对照方案为「娱乐向内容稀释」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

打基础走教程库结构化路线；放松看视频平台无妨。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 投稿有人工审核门槛，重复或低活跃项目会被拒

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 常见问题
### 客服机器人能干什么？

右下角悬浮窗：基于 RAG 回答产品与资源问题、推荐相关内容、收集需求反馈。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。
