# 认识GGUF：它解决什么问题、怎么选

GGUF是什么、怎么用，一篇讲清楚。AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。下面进入正题：先概念，再步骤，最后是边界与常见问题，基于察元AI OS整理。

## 什么是GGUF

从内置「模型库」把本地大模型权重下载到本机：每行按本机内存预算给出 /△/关闭 分层推荐；下载走多源自动换源（ModelScope 主源 ＞ hf-mirror / AI快站 镜像 ＞ HuggingFace 官方垫底）、支持断点续传；下载完进「我的模型」，点「启动」加载进内存即可被对话 / 知识库 / 智能体使用，数据不出本机、断网可用。

放到察元AI OS的语境里：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，下载本地模型是其中承上启下的一环。

## 先看看痛点对不对得上

断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

典型使用场景：按内存挑合适的模型档位，内网机器补齐模型能力。

## 在察元AI OS里怎么用

入口与核心步骤：

1. 进入本地模型页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）列出十一类导航：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 视频解析 / 生图 / 视频生成 / 语音识别 / 语音合成。进页默认选中「对话」。右栏页面自上而下：状态条 ＞ 服务地址条 ＞ 「模型全机只保留一份」提示 ＞ 「我的模型」（已安装）＞ 「模型库」（未下载）。同一模型只会出现在其中一个分类页。

2. 认识状态条（顶部）

1. 健康灯 + 文字：「正常」（绿）/「引擎异常」（黄）/「不可达」（红）/「已停用」（灰）/「引擎缺失」（黄）；
2. 实例计数：「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示「空闲自动卸载策略」）：「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，默认 15 分钟；
4. 「重启全部」「全部关闭」：点击后行内出现红色二次确认条——「重启全部运行中的模型？」/「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，点「好」执行、「取消」收回；
5. 服务被停用时，此处只剩「启动」按钮。

3. 服务地址条（第二行）

显示本分类的对外端点，如对话类为 http://127.0.0.1:52581/v1/chat/completions；「复制」（点击后变「已复制」）、「配置帮助」展开 curl 示例。各分类端点：对话/代码补全/图像理解 /v1/chat/completions、嵌入 /v1/embeddings、重排 /v1/rerank、决策 /v1/systemone、语音识别 /inference（生图/视频生成/语音合成走系统内置调用，不显示此条）。底部注：「免 key 直连：本机任意智能体不带 key 即可用（审计归因 anonymous）…」。

## 怎么判断适不适合你

适合你的情况：日常就是内网机器补齐模型能力，希望流程固定、结果可验证。

不必勉强的情况：8GB 内存建议一次只加载一个对话模型。察元AI OS的思路是把边界写明白，条件式地推荐。

## 接着回答几个常见问题

### 下载前要预留多少磁盘？

系统自动预检：模型体积 × 1.05 + 200MB；不足时报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 完全断网 / 所有源都下载失败怎么办？

断点已保留，联网后点「继续下载」从断点续传。彻底离线的机器：在任意联网电脑按帮助中心「离线下载与导入」的直链下载权重文件（U 盘/内网搬运）放到本机，再用「我的模型 ＞ ＋ 添加模型」按路径导入（不复制文件、原路径引用）。

### 怎么删掉下错的模型？

「我的模型」行内「删除」＞ 确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」运行中的模型要先「停用」再删。注意权重全机一份，删除影响本机所有用户；「装机即用」五件套权重随安装包分发、不占额外磁盘，无需删除。

### 模型跑一会儿自己停了？

默认「15 分钟无人使用自动卸载」在释放内存，不是故障。常用对话/嵌入模型点行内「钉住」豁免自动卸载；时限在状态条下拉可调（自动卸载：关 / 5 / 15 / 30 / 60 分钟）。

## 补充答疑

### 启动报「二进制缺失 / 引擎缺失」？

推理引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；恢复方法详见帮助中心「引擎二进制」。

### 关闭 徽标的模型能下载吗？

能——徽标含义明示「仍可下载，加载时会被守卫拦截」。点「启动」时会被内存预算预检拦下，并提示需要多少内存、建议先卸载谁。内存不够就换小参数量模型（参考 档），或先「停用」部分运行中的模型。

## 更多操作细节

4. 按 /△/关闭 挑模型（模型库区）

「模型库」标题旁有图例：「本机推荐 · △ 可跑，内存吃紧 · 关闭 超出本机内存（仍可下载，加载时会被守卫拦截）」。每行结构：

1. 行首彩色徽标： 绿 / △ 黄 / 关闭 红（判定规则：模型内存 + 2GB 余量 ≤ 当前可用内存 = ；不超过物理内存 − 2GB 系统保留 = △；超出 = 关闭）；
2. 模型名（beta 模型带黄色 beta 标）；
3. 第二行参数：「参数量 · 上下文 · 下载体积 · 运行内存」，如 4B · 32K · 2.6GB · 3.3GB RAM；
4. 行尾动作按钮（见下一步）。

5. 开始下载

点行尾「下载 <体积>」（如「下载 1.6GB」）：

1. 进行中：按钮变「取消下载」，行下出现进度条，右侧显示「排队中…」或「<源站名> 百分比」（如 ModelScope 37%）；下载中页面约 1.5 秒自动刷新一次进度；
2. 点「取消下载」：断点保留，之后可续传。

6. 失败自动换源、断点续传

1. 单个源 404 / 超时 / 中断：自动切换下一源重试，顺序 = ModelScope（含 API 通道）＞ hf-mirror.com ＞ hf-mirror.net ＞ aifasthub.com ＞ HuggingFace 官方（整体垫底）；
2. 连接中断：报「连接提前中断（断点已保留，可续传）」，按钮变「继续下载」；手动暂停同理；
3. 所有源都失败：报「所有 N 个源均失败（断点已保留，可重新下载续传）」，按钮变「重试下载」，行内显示具体错误；
4. 断点保留意味着任何中断都不用从头重下。

## 安装与运行答疑

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。
