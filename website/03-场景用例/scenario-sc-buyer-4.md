# 私有化部署选型实战：一个真实场景的完整工作流

内网机器要找某类 MCP 服务，过去要折腾好几个工具拼起来。现在察元AI 能力广场把这件事做成了一个功能：智能广场总览。下面按我实际操作的顺序走一遍，包括容易踩的坑。

## 为什么值得了解

1. 产品能力与价格信息分散
2. 国产化适配要逐一确认
3. 发票与订单流程要合规

企业采购人这个场景里，选型到采购一条线完成。

## 一步步来：从入口到完成

把流程串起来：

1. 产品页看四产品家族卡
2. 适用场景页按业务对号
3. 行业页看落地方案
4. 购买授权页下单、查询页核单、发票页开票

## 支撑功能的操作细节

流程里智能广场总览的实际操作：

逛广场的基本姿势

1. 浏览器打开 aidooo.com，导航点智能广场
2. 按资源类型进对应板块（如 MCP、插件）
3. 关键词检索或按分类浏览
4. 点进详情页查看说明、安装方式与榜单排名

## 关键能力点

- 八大板块聚合检索
- 三栏动线设计

## 这些坑和边界要知道

如实说明，它不是万能的：

- 榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜

## 一个真实场景

智能体应用开发者的典型用法：能力广场 MCP 板块检索，看周榜 star 增量判断活跃度，失效资源已被自动剔除出榜。选型有数据依据，避开僵尸项目。注意：榜单反映热度不等于适配你的场景，还要实测。

## 榜单的算法口径

日榜按当日增量，周月季半年年榜按周期内 star 增量；每日同步任务先抓 star 写快照再重算榜单。无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；dead 或 archived 的失效资源自动剔除出榜；快照不足时降级为总量榜并明确标注。
