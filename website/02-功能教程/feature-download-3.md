## 操作步骤详解

下载正确安装包

1. 打开 aidooo.com 进产品页
2. 确认本机系统与 CPU 架构（uname -m 可查）
3. 点对应下载按钮获取直链
4. 登录后开始下载，按平台安装指引执行

下载渠道怎么认

1. 官网 aidooo.com 是仅有的官方分发入口
2. 下载清单由管理后台发布流程自动生成，不做手工第三方链接
3. 网盘直链带提取码的会自动复制，粘贴即用
4. 第三方站点的镜像包一律不认
