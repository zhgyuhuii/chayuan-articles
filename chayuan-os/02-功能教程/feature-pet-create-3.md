# 新建灵宠落地记：形象可从灵宠商店免费获取

先说这篇能帮你干什么：读完能在察元AI OS里独立完成新建灵宠，路径是给不同任务养不同的宠。步骤里的每个「」按钮都是界面原文。

## 解决什么痛点

想给宠物群聊添加新成员；想让某个智能体（如 Claude Code）在桌面上有一只「化身」，扫一眼桌面就知道它在干活还是待命，想给常驻定时任务配一只「任务灵宠」，任务执行时自动上桌流式展示输出；把常驻任务绑给专门的宠。

## 实操全过程

第 1 步 · 打开建宠弹窗

两个入口任选：

弹出深色建宠弹窗，桌面名册入口的标题为「建宠物」。

1. 桌面底栏名册：点桌面左下角底栏的「灵宠」文字按钮（与「场景」「动态」并列），弹出灵宠名册面板 ＞ 点面板右上角蓝色「添加灵宠」按钮；
2. 宠物群聊应用：Dock 打开「宠物群聊」＞ 左栏顶部蓝色「建宠物」按钮。

第 2 步 · 逐字段填写（桌面名册入口的完整表单）

「名字」（文本输入，必填）

桌面上与群聊里的称呼。留空时「创建」按钮置灰无法提交；保存时超长名字自动截断到 20 字。

「智能体」（下拉选择，默认第一项「模型直跑（不经过智能体）」）

决定这只灵宠干活用哪家 CLI。两种模式：

「模型」（按钮组，默认「自动（本地已装对话模型）」）

「知识库（可选）」（下拉，默认「不绑定」）

绑定一个已有知识库后，这只灵宠在群聊发言时会自动检索该库片段作为上下文。字段下方提示原文：「群未挂库时生效：该宠物发言时自动检索知识库片段作为上下文；群挂库后以群库为准」。

「分区（工作区）」（下拉，默认「默认（HOME）」）

智能体派活的工作目录。三个选择：保持「默认（HOME）」；从下拉选一个已有分区；或点「+ 选择文件夹…」按钮弹系统对话框现场选/新建文件夹（仅桌面形态提供）。表单里留空时，双击灵宠开工作台会自动给它配一个专属分区 Workspaces/.pet/pets/<灵宠名>。

「绑定常驻任务（任务灵宠）」（下拉，默认「不绑定（普通灵宠）」）

从已建的常驻任务清单里选一个绑定，绑定后该任务执行时这只灵宠自动上桌、头顶气泡流式显示输出（结束显示成功/失败摘要）。没有常驻任务时下拉只有默认项。

「钉住常驻桌面（不受在场规则约束）」（勾选框，新建默认勾选）

勾选=创建后立即且常驻桌面；去勾选=灵宠收进名册，只有双击启动、任务执行中或工作台开窗时才上桌。

「形象」（图卡点选，默认「茶茶」）

内置「茶茶」「小猫」两张卡，加上灵宠商店已下载的形象卡；「自定义」卡可上传本机图片当形象（名称取文件名去扩展名的前 8 个字）；末尾「···（更多）」卡直达灵宠商店的形象页签，获取后卡组自动刷新。

「人设（一句话）」（文本输入，可空，占位符「可选」）

决定它在群聊里的说话风格，如「严谨的架构师，说话简短」；保存时截断到 60 字。

1. 模型直跑（默认）：不挂任何 CLI，纯模型人设。它没有智能体工作台，双击它打开的是「灵宠对话」直聊窗（窗口标题=灵宠名），群聊发言直接经本地模型代理出答案；保存时不做模型注入。
2. 挂智能体：下拉列出产品支持的 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、Aider、Goose、Crush、CodeBuddy 等，以注册表上架集为准）。双击灵宠直开该智能体的工作台窗口，干活时它的灵宠「上岗」。
3. 「自动（本地已装对话模型）」：运行时自动挑一个本地已装的对话模型；
4. 「指定模型」：点击弹出「选择模型」树形弹窗（同一棵统一模型树：本地已装 + 已配置厂商，厂商 logo 可读，树内单选高亮），左下回显所选短名，点「确定」关闭并回显到表单（等宽字体引用串，如 glm-4-flash）；未选中时提示「未选择模型（点列表项选择）」且不能确定。树为空时提示「暂无可用模型：可在模型设置中配置厂商模型或安装本地模型」。
5. 「自动」档下方有一行说明：「经本地模型代理直答；本地与已配置厂商模型均可选，真实厂商 key 不出凭证库」。

第 3 步 · 创建

点右下「创建」（提交中显示「…」；名字为空或模型未选时按钮置灰），「取消」放弃。保存时发生三件事：

宠物群聊入口的「建宠物」表单与上面基本一致，差别：智能体下拉按本机已检测安装过滤（未装的不列）；没有「绑定常驻任务」「钉住」两项（创建同样默认钉住上桌）；没有「自定义」上传形象卡；人设占位符是示例文案「如：严谨的架构师，说话简短」。

1. 档案写入本机（os-data pet_profiles），默认钉住上桌；
2. 挂了智能体且选了「指定模型」（命名空间引用串）时，保存即注入：把「模型代理地址 + 模型名」写进该智能体的持久配置（幂等，同值重写无副作用），并结束该智能体的旧终端会话让新配置下次生效；「自动」档不注入。注入失败会弹「模型注入智能体失败：<原因>」，宠物档案仍然保留，只是模型没写进去；
3. 弹窗关闭，新灵宠出现在桌面（新建默认钉住）。

## 关键能力点

- 模型直跑模式无需角色卡
- 形象与人设自定义
- 创建即上桌

## 几个容易忽略的细节

用之前要认的账：

- 形象可从灵宠商店免费获取，也可工坊自定义
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

## 高频疑问

### 创建按钮是灰的点不动？

两个必填没满足：名字为空，或模型停在「指定模型」但没在树里选中任何一个。填上名字、或把模型切回「自动（本地已装对话模型）」/在树里选定一个即可。

### 智能体下拉里没有我想要的那家？

宠物群聊入口只列本机已检测安装的 CLI；先到 应用商店 ＞ 智能体 安装（Aider、Goose 等需自行安装后自动探测上架）。桌面名册入口的下拉列出上架全集（与是否已安装无关），建议先安装再建。

### 「模型注入智能体失败」报错会丢宠物吗？

不会。注入失败只弹提示，档案已保存；按提示到 设置 ＞ 模型 检查模型服务/代理状态后，在「编辑灵宠」里重选模型再保存一次即可（保存即注入，幂等）。
