# 统信UOS安装是什么：家外部 CLI 智能体

统信 UOS 上装这套系统，路径和 Windows 完全不同：包格式、架构判断、依赖处理各有一套。这篇把统信UOS安装从选包到首启验证完整走一遍，基于察元AI OS 的 deb 形态。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：UOS 20 用 deb 的原因与步骤。

deb 包同样只从官方渠道获取，来源不明的包在国产系统上更难验真。

## deb 安装的四步

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 为什么 UOS 20 推荐 deb

UOS 20 的软件生态以 deb 包为主，系统自带的安装链直接可用，不需要引入别的包格式；与银河麒麟 V10 同走 deb 形态，两个发行版的差异主要落在架构组合上。deb 装完从应用菜单启动，不用自己建启动项。

## dpkg 报错怎么读

`sudo dpkg -i` 最常见的报错是依赖缺失，提示里会列出缺哪些包，按提示补齐再重跑一遍命令即可；架构不符时会直接拒绝安装，回到选包那一步用 `uname -m` 核对。报错文本原样留着，需要求助时贴出来最省沟通成本。

## 麒麟和 UOS 的差别记两条

两个发行版装法几乎一致，差别记两条就够：架构判断都按 CPU 来，飞腾/鲲鹏与兆芯/海光的选包口径在两边通用；开了权限管控的内网机器上，安全软件可能拦安装器的执行，装之前把执行权限放行，比装到一半被拦再回头查省事。装完的应用菜单入口两边位置一致，操作习惯不用重养。

## 其他平台装法速览

Windows：从官方渠道下载对应架构的 exe 安装器；双击安装，零额外依赖；首次启动创建本机账户，进入桌面。

macOS：官方渠道下载 dmg 并打开；把察元AI OS 拖入应用程序文件夹；启动后创建账户进入桌面。

## 国产平台要点

银河麒麟 V10 的 x64 机型（兆芯、海光）选 x64 包，arm64 机型（飞腾、鲲鹏）选 arm64 包；统信 UOS 20 用 deb 形态，arm64 真机已实测。暂不支持龙芯，选包前用 uname -m 确认架构。

## 装完后的第一件事

装完先干两件事：一是让模型设置向导跑完，把默认模型应用到各家智能体；二是试一次断网对话，确认本地模型链路通了。恢复密钥也顺手生成，忘了密码时它是仅有自助路径，这一步千万别省。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 认下三条边界

- 8GB 内存的机器，同一时间载入一个对话模型为宜，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态要费些手脚
- 云端厂商模型的调用得自备 API Key

三条都过目后再动手，真遇到情况也不至于措手不及，照着条目对就行。

## 锁屏与数据目录

内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注；共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道；数据目录可指到别处，系统便落户非系统盘，换新机器时整目录一搬即告迁移。

## 安装包体积与权重

全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，与察元OS 同库同源；哪家智能体支持一键安装、能不能写入模型、收不收系统技能、接不接 MCP、记忆采集开不开，翻能力矩阵便知；装智能体时最容易栽在 Node 版本与镜像源上，一键安装把这两处坑直接填平。

## 工舱与桌面细节

工舱这边，整套系统以无头方式部署进 Docker，成为多用户云桌面（察元AI工舱形态），员工浏览器直达；Dock 的文生图应用接提示词与负面提示词，出图后可指定为壁纸，或让它每 30 分钟自动更换；dock 应用能隐藏、能归入新建分组，自定义网页、本地程序、HTML、文件四类都可封装成桌面应用；桌面与 Dock 的位置、自动隐藏、图标放大与大小、开机自动打开 Harness 均可在设置中调整。

## 更新与 Office 入口

更新走设置的关于页：检查更新后下载重启即装好；服务端一台机器供全组共用，运维只需照看一处，各终端无需另装东西；内置的察元AI Office 在 Dock 里点开，文档、表格、演示都能在线编辑。

## 知识库与索引运维

换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页；kb_search、kb_list、kb_read_doc 工具链自然语言触发，对配对终端开模型加知识库授权。

## 并发与生图的数字口径

本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队，本地模型多宠同发同样排队；文生图与图生图在设置默认模型里各挑自动或指定一项（本地已装生图模型或已启用厂商），首次下载约 2GB 权重。

## 远程协作的记忆口径

把任务远程派给对端智能体，B 机器跑完把结果送回来，人留在原位就行；接手的智能体无需重新自我介绍，记忆全机打通，接续感是系统给足的；工作区开起来即带代理（智能体），扩展名默认应用覆盖表也默认就位。

国产系统上跑通这套流程后，回头再看选包、装包、验证三段，每段都有据可查，排错也就有了章法，换麒麟机器同样适用。
