# 创业团队行业怎么用察元OS：从痛点到落地

创业团队行业的文档与信息工作有其固有节奏：对外材料有保密与合规要求，外发前自检环节薄弱。察元AI OS在创业团队场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出创业团队行业的完整应用路径。

## 创业团队行业的典型痛点

- 对外材料有保密与合规要求，外发前自检环节薄弱
- 临时性、突击性材料多，加班赶稿是常态
- 文档量大、格式要求严，人工处理占用大量时间

## 对应的能力组合

- **四家 CLI 智能体**（CLI智能体）：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。
- **.cop.tgz 离线插件包**（离线插件包）：插件依赖闭包打包导出为 .cop.tgz，离线直拷导入（校验路径穿越、零网络），支持多选批量安装。
- **统一模型代理**（模型网关）：统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。
- **插件页签（三源）**（插件市场）：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按资料重度用户场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 常见问题
### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。
