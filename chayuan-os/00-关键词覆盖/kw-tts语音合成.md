# TTS语音合成：会议全程记录

关于TTS语音合成，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是TTS语音合成

TTS语音合成这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

## 在察元AI OS里落在哪

TTS语音合成在察元AI OS里的落点是录屏与语音记录：桌面右键录制屏幕；语音记录是录音加转写加保存位置设置，贴顶长条边说边出字。

为什么值得单独说：本地转写不上传录音，会议速记两件事一次做完。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 安全与数据边界

安全口径单独立一层：任何网页或本机程序都能变成桌面应用，常用工具一键直达；远端调用走权限门留审计，周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。
