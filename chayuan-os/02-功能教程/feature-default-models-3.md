# 智能路由实战：怎么全局设置模型

先说这篇能帮你干什么：读完能在察元AI OS里独立完成智能路由，路径是日常轻任务走本地、攻坚任务指云端。步骤里的每个「」按钮都是界面原文。

## 先看看痛点对不对得上

本地装了嵌入 / 重排模型，想让知识库检索优先走本地、数据不出机；想给文生图 / 图生图 / 语音等能力各指定一个默认模型，让智能体按类别直接调用，想让知识库问答、新会话、未单独配置模型的智能体统一用一个对话模型，日常轻任务走本地、攻坚任务指云端。

## 实操全过程

1. 进入页面

打开 设置，左栏第二项「默认模型」。页面左右两栏：左栏是分类竖栏（十一类 + 「网络资源搜索」，中间有分隔线，后者见清单 M11，本篇不展开）；右栏是当前分类的选择区。进页默认选中「默认对话模型」。

4. 「设置…」弹窗（树形选择 + 立即生效）

弹窗标题「选择{分类名}」（如「选择默认对话模型」），副标题「列表 = 本地模型 + 已启用厂商；点「确定」立即生效」。结构：

1. 「自动」选项（含当前回退值灰字）；
2. 「本地模型」可折叠组：组头带本机图标、计数药丸；折叠时组头右侧显示组内选中项；运行中模型行尾绿点；
3. 各厂商组：厂商 logo 图标 + 厂商名 + 计数，同样可折叠；初始自动展开本地组和含当前选中项的厂商组；
4. 「默认对话模型」分类的弹窗底部有蓝色提示条：「确定后将同步为全部智能体（Harness / Codex / OpenCode / OpenClaw）的默认模型」；
5. 选好点「确定」＞（对话分类且非「自动」时）立即保存并同步写入 5 个智能体，成功绿色提示「已设为系统默认，并同步全部 5 个智能体」；其他分类成功提示「已保存，系统技能已更新并分发到各智能体」；
6. 同步中按钮变「正在应用…」；部分智能体写入失败时弹窗保持打开，逐项列出结果行（智能体名 + 已写入 / 具体错误，如「需要桌面形态（配置写入经桌面主进程）」），全绿才自动关闭；
7. 「取消」放弃修改。

5. 保存时系统做了什么（理解行为用）

点「保存并更新技能」或弹窗「确定」后，系统依次：

「自动」的回退规则（源码 autoResolve）：本地第一个可用模型 ＞ 云端第一个匹配类型 ＞ 都没有（无可用模型），即本地优先。

1. 云端选择涉及的厂商自动确保已加入模型代理路由（真实厂商 key 不出凭证库）；
2. 渲染 models.md：十一类「分类 | 默认模型 | 调用（模型名）」表 + 代理调用面（Base URL http://127.0.0.1:52581/v1）+ 已启用的网络搜索平台清单；
3. 落盘 defaults 文档，主进程防抖后把 models.md 作为系统技能（chatop-system）伴随文件镜像进六家智能体技能目录（dsh / Claude Code / ZCode / Codex / OpenCode / OpenClaw）——智能体读技能文档就知道每类默认模型怎么调。

## 关键能力点

- 11 类任务独立设置
- 自动模式本地优先
- 设置结果分发到智能体侧

## 注意事项与真实边界

用之前要认的账：

- 指定模型未加载时会按策略自动拉起
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 常见问题

### 保存报「模型代理未运行，无法接入云端厂商（先在模型设置里确认服务状态）」？

代理随本地模型服务自启。到 设置 ＞ 模型 看页面顶部健康灯，服务恢复后回来重新保存；只选本地模型 / 「自动」不受此限。

### 「自动」到底会用哪个模型？

固定回退顺序：本地第一个可用 ＞ 云端第一个匹配 ＞ 无可用。想让某类明确用某个模型就指定它，不要留「自动」。

### 在页面上直接点选后忘了保存，生效吗？

不生效。直接点选只是暂存，必须点右下「保存并更新技能」；弹窗「设置…」的「确定」则是立即保存。

## 更多操作细节

验证

1. 保存后页面出现绿色「已保存，系统技能已更新并分发到各智能体」。
2. 桌面形态下打开任一智能体技能目录核对 models.md 已更新，如 ~/.claude/skills/chatop-system/models.md（ZCode 对应 ~/.zcode/skills/chatop-system/models.md），「分类默认」表里能看到你选的模型。
3. 默认对话模型同步成功后，打开 DeepSeek Harness 对话窗，模型下拉里出现所写模型；指定了云端模型时，浏览器访问 http://127.0.0.1:52581/v1/models（免 key）能看到 <厂商id>/<模型名> 条目。
4. 把「自动」所在行的灰字与预期对照：装了本地对话模型时应显示「本地 · <模型id>」。

## 补充答疑

### 改了默认对话模型，Claude Code / Codex 里的模型会变吗？

会——但仅通过「设置…」弹窗的「确定」（对话分类、非「自动」），它会把代理地址 + 模型名写入全部 5 个智能体（DeepSeek Harness / Claude Code / Codex / OpenCode / OpenClaw，写入前自动备份）。只在页面上点选再「保存并更新技能」的话，只更新 models.md 技能文档，不改各智能体配置文件。

### 图生图 / 视频生成分类里为什么没有本地模型？

本地引擎暂无这两类能力（本地 SD 仅文生图；视频生成模型尚未开放下载），这两类全部列已启用厂商的图像生成 / 视频生成模型。想用就先配一家支持该能力的厂商。

### 重排 / 决策为什么选不了厂商模型？

这两类树只列本地模型（决策为本地专属能力）。没有就到 设置 ＞ 模型 ＞ 本地模型 组下载（重排见模型库「重排序」分类）。

### 默认语音合成 / 语音转文字模型影响什么？

保存后同样写进 models.md 随技能分发：语音合成对应本地 Piper / 云端 tts 类模型，语音转文字对应本地 Whisper / 云端 asr 类模型，按代理命名空间（local/<id> 或 <厂商id>/<模型>）调用。
