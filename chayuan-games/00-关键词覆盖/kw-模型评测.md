# 模型评测新思路：用完整对局代替题库打分

题库打分这件事，正在被越来越多人重新审视：分数年年涨，实战掉链子的例子也隔三差五出现。模型评测，就是指用系统化的任务与指标衡量大模型能力的过程；察元竞技场给出的新思路是——用完整棋牌对局代替题库打分，让算力、诈唬、防守、收官这些素质直接在对局里现形。

这不是对题库的全盘否定，而是补上它够不着的那半边。这篇先拆两类评测的分野，再把对局评测的维度逐个摊开。看完这篇你会拿到一份可以直接照做的评测方案，外加它的适用边界。

## 拆词与相近概念辨析

题库评测：给模型出题、对答案、算分，科目覆盖知识问答、数学、代码等，产出快、可复现，是过去几年模型评测的主流形态。它的长处是便宜、快、可复现，短板是任务静态，考不出临场博弈。人类盲测：让人类对两个模型的匿名输出投票，票数换算排名，考的是聊天讨喜度。它的长处是贴近真实使用，短板是标准主观，也容易被风格带偏。对局评测：让模型在游戏规则下真刀真枪对弈，胜负由代码裁判判定——察元竞技场属于这一类，11 款棋牌玩法、本机裁判、TrueSkill 天梯记账。

三者的根本差异在任务形态：题库是静态题，答案固定；盲测是开放式问答，标准在人心；对局是动态博弈，对手在变、局势在变、每一手都影响后面几十手。博弈素质在静态题里无从安放，这正是对局评测存在的理由。顺带拆清一个误会：对局评测不排斥大模型的基础能力，恰恰相反，语言理解是它入场的前提——读不懂规则描述的模型，连出招都成问题，博弈考场其实同时在考语言底子。小众玩法还有独特的区分度：模型靠语料记忆讨巧的空间更小，考的越偏临场推理，军棋、麻将这类玩法因此值得单独跑几轮。

## 对局评测的四个维度

四个维度不是并列口号，各有各的考场与检视工具。算力，指完全信息玩法里的推演能力：五子棋、象棋、围棋里模型看得见全部棋子，能不能算出几步之后的攻防，棋盘不说谎。而且它骗不了人：一步算漏，下一手立刻付出代价，因果链短得残酷。

诈唬，指不完全信息下的虚实表达：德州扑克桌上敢不敢用弱牌加注、能不能识破对手的表演，这是表达与反操纵的双重考验。读对手要靠行为历史，竞技场把对手的出招记录喂给它，怎么用这些信息，是另一层功夫。

防守，指劣势与危险局面下的止损：麻将血战里留安全牌不点炮，斗地主里顶住地主的节奏，会进攻的模型常见，会防守的模型难得。防守考验的是克制：明知能吃却该忍，判断的是风险而不是收益，这种反直觉的决策特别能拉开差距。

收官，指残局与终盘决策：优势怎么转化成胜势、劣势怎么拖到机会，很多模型前半局像模像样，收官阶段开始送分——收官质量是长对局里区分模型稳定性的标尺。复盘标注给收官质量提供了现成检视工具，最后几十手的妙手与失误一翻便知。

## 过程可见：评测的第二层证据

对局评测比题库多给一层东西：过程。思维链气泡实时展示每手的推理，延迟与 token 用量逐手记录，形势曲线画出局势走向，复盘阶段逐手给出妙手与失误标注（问叹号标注与叹号标注）。还有一个容易被忽视的评测面——协议画像：统计每个模型的出招协议习惯，JSON 格式遵守率、平均出招耗时这些工程指标都算在内。一个模型棋下得如何是一回事，指令遵守与输出稳定性如何是另一回事，两份数据合起来才是完整画像。过程数据还有跨局价值：单局看发挥，多局看习惯，习惯才是模型的稳定属性。

## 结果可信靠什么托底

对局评测的公信力靠工程托底。胜负判定百分之百归本机代码裁判，模型只出招不判罚，谁也不能自己宣布赢；机机观战默认匿名，看的人不被品牌带偏；模型出招走解析容错链，出了废招有代走兜底、超限判负，一场对局不会被 API 抖动毁掉。这些机制在幕后，却是「评测可信」三个字的全部来处。

托底的另一面是边界：裁判保证公平，不保证精彩；匿名保证干净，不保证样本。公平是底盘，样本与玩法设计才决定评测的区分度，两层都要自己经营。

## 三条边界

对局评测没有官方统一结论，本机跑出来的座次只在你设定的条件下成立，外推要谨慎。

运气与样本是绕不开的变量：单局爆冷是常态，结论要建立在足够局数上，锦标赛与多轮对局是必要的。

棋牌表现不等于聊天与编码能力，两个维度分开看；评测费用也心里有数，模型 API 费用自付，本地 Ollama 才零成本。评测预算先定后花，别在跑了一半时才发现额度见底。

## 模型评测常见疑问

### 对局评测能代替题库评测吗

不能完全代替，二者互补。题库测静态知识与答题，对局测动态博弈与工程稳定性，选模型时两类证据都要看。

### 怎么保证对局评测的公平

胜负判定百分之百归本机代码裁判，模型只出招不判罚；机机观战默认匿名，排除先入为主；所有模型遵守同一套规则与出招协议，规则与协议都在开源仓库里，谁都可以查验。

### 一次靠谱的评测要打多少局

没有固定数，十几局能让 TrueSkill 评分大致收敛；想要稳定结论，建议锦标赛量级的循环对局，玩法多选几款防偏科。预算紧张就减玩法不减局数，单玩法的结论只在该玩法内成立。

### 评测数据能拿走吗

能。棋谱支持 JSON 导出，协议画像与积分都在本机，自己写程序分析、做报告都行。数据在手上，评测才是你的评测，这点与托管服务有本质区别。

评测的意义不在给模型贴标签，而在让证据说话。察元竞技场把「完整对局」这套新思路做成了人人可跑的本机考场：过程可见、胜负可查、数据可带走——下一份模型评测报告，也许就该从一张牌桌开始。
