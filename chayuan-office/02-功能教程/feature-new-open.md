# 文档打开实操教程：从入口到完成每一步都有反馈

接手别人的察元AI Office环境时，我在文档打开上卡了半小时——不是功能难，是没人告诉我完整的操作链。这篇就是当时想找而没找到的那篇文章。

## 这个功能到底解决什么问题

六类文件（文档 .docx / 表格 .xlsx / 演示 .pptx / Markdown .md / HTML .html / PDF .pdf）都可以从主页「新建」宫格、菜单或标签条「+」一键新建；打开支持双击系统文件、菜单「打开…」（⌘O）和把文件直接拖进窗口，.odt/.ods/.odp 等 ODF 格式打开时经本机转换成 OOXML 副本。新建的空白文档在首次保存前不会写进你的工作目录。

格式兼容是办公软件的生死线，明确支持什么、不支持什么，比含糊其辞负责任。

按真实界面写，按钮文案原样引用。

## 开工前检查这几样

- 桌面壳形态（web/dsh 形态无 HTML 编辑器，其余五类可用）。
- 新建文件的默认落点：若左树「文件夹」里选中了某个文件夹，新文件优先落在该文件夹；否则落默认保存位置。

## 从打开到做完的每一步

1. 新建：三个入口

1. 主页左栏「新建」宫格：六格瓦片，悬停显示名称与扩展名——「新建文档 (.docx)」「新建表格 (.xlsx)」「新建演示稿 (.pptx)」「新建MD文档 (.md)」「新建HTML (.html)」「新建PDF文档 (.pdf)」，点击即在新标签页打开对应编辑器；
2. 菜单「文件 新建」：macOS 在顶部菜单栏，Windows/Linux 点标签条左侧「菜单」按钮；「新建」分节下是「文档」（快捷键 ⌘N）「表格」「演示稿」「MD文档」「HTML文档」「PDF文档」；
3. 标签条「+」（提示「新建标签页」）：弹出同样六项 + 「打开…」。

2. 新建后文件在哪？——首次保存才落盘

1. 文档/演示/Markdown/HTML：打开的是内存空白文档，标签标题为「未命名文档」「未命名演示文稿」「未命名 Markdown」「未命名 HTML」；在编辑器里第一次「保存」时才让你选位置写盘，之后自动保存接管；
2. 表格：新建时会在本机临时区先备好一份空白 .xlsx 底稿（保存管线需要磁盘工作簿），首次「另存为」时从预定名「未命名表格.xlsx」起步，定名后才是你的文件；
3. PDF：新建的是临时区的隐藏草稿，你看到的 PDF 文件只在首次保存（走另存为）时写出；
4. 未保存的空白文档不进「最近」列表、不占项目；新建表格与新建 PDF 这类带本机临时底稿的未保存文档，若带着退出或崩溃，下次启动主页顶部出现横幅「上次有 {count} 个未保存的文档」，点「恢复全部」找回或「全部放弃」丢弃（横幅只覆盖表格与 PDF 这两类）；

3. 打开：四个入口

1. 主页左栏「打开本地文件」：弹出文件对话框，类型筛选「支持的文件」，可一次多选（多选会一次开多个标签页）；
2. 菜单「文件 打开…」（快捷键 ⌘O）；
3. 拖拽：把文件从系统拖进窗口，主页出现「松开以打开文件」覆盖层（下方列出支持的扩展名清单），松开即打开；
4. 系统双击：Windows 安装时注册了 docx/xlsx/pptx/pdf/md/html 文件关联，在资源管理器双击即可用察元AI Office 打开；macOS 可用「打开方式」。

4. 支持的格式与打开路由

不在此列的扩展名会弹提示「暂不支持 .{ext} 类型」（打开对话框刻意列出 .doc/.ppt 等老格式，就是为了选中后给出这条明确提示，而不是让按钮灰掉）。

| 扩展名 | 打开到 |
|---|---|
| .docx / .odt / .ott | 文档（Docs） |
| .xlsx / .xlsm / .xls / .csv / .tsv / .ods / .ots | 表格（Sheets） |
| .pptx / .odp / .otp | 演示（Slides） |
| .pdf | PDF 编辑器 |
| .md / .markdown / .txt / .json | Markdown 编辑器 |
| .html / .htm | HTML 编辑器 |

5. ODF 导入（.odt/.ods/.odp）：转换成副本打开

应用只编辑 OOXML 格式，ODF 文件打开时先弹确认框（按钮「转换并打开」/「取消」）：

转换全部在本机完成（不上传）。转换器按「无法证明可正确转换的构造型计入 dropped、不近似猜测」的规则实现——宁可不转也不转错。

1. 文档（.odt/.ott）：弹「转换 .odt 文档？」，说明「正文、标题、列表、表格和图片会转换过来；脚注、批注和文本框不会完整保留。原文件不会被修改，转换出的 .docx 是一份独立副本，之后的保存都写入它。」确认后弹出另存为选副本位置（默认与原文件同目录、同名 .docx），本机完成转换后打开副本；
2. 表格（.ods/.ots）：弹「转换 .ods 工作簿？」，说明「数值、公式和日期会被转换过来（公式改写为 Excel 语法，无法安全改写的只保留它的当前结果）；样式、列宽和图表不会保留。原文件不会被修改，转换出的副本首次保存时另存为 .xlsx。」；
3. 演示（.odp/.otp）：同样先确认后转换成 .pptx 副本打开。

6. 重复打开同一文件

已经打开的文件再次打开（双击、菜单、拖拽都一样），会聚焦到已有标签页，不会开出第二份拷贝。

## 如何确认操作生效

验证

1. 点「新建」宫格第一格：出现「未命名文档」标签；点「新建表格」后不保存直接关掉，重启应用后主页顶部出现「上次有 1 个未保存的文档」，点「恢复全部」能找回这份表格。
2. 把一个 .md 文件拖进窗口：出现「松开以打开文件」覆盖层，松开后 Markdown 编辑器打开该文件。
3. 打开一个 .odt：先出现「转换 .odt 文档？」确认框，点「转换并打开」并选好位置后，打开的是同名 .docx 副本，原 .odt 内容与修改时间不变。

## 什么情况下用得上

想新建一份空白文档/表格/演示，但不确定该点哪里、文件会存到哪；新建的文件没保存就关了，想找回；接手历史存档文件，手头有 .docx/.xlsx/.csv/.md/.odt 等文件，想确认能不能打开、会用哪个编辑器打开。

用户常搜的问法：新建的文档存到哪里了？没保存就关了还能找回吗；能打开 .odt/.ods/.odp 吗？打开会不会改动原文件。

## 几个容易忽略的细节

如实说明，它不是万能的：

- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 你可能会问

### .doc/.ppt 老格式打不开？

应用只编辑 OOXML（.docx/.xlsx/.pptx）。请先用 Word/WPS/PowerPoint 把老格式另存为对应 OOXML 格式再打开；直接拖进来会明确提示「暂不支持 .doc 类型」。

### 新建的文件「消失」了？

未保存的空白文档不落盘、不进「最近」，属正常设计；退出后的恢复横幅只覆盖新建表格与新建 PDF（它们有本机临时底稿）。养成首次编辑后就 ⌘S/Ctrl+S 定名保存的习惯，之后自动保存接管。

### .csv/.tsv/.txt/.json 也能开？

能。.csv/.tsv 路由到表格编辑器，.txt/.json 与 .md/.markdown 一样进 Markdown 编辑器。

### .odt 打开后让我先转换，原文件会被改吗？

不会。ODF 打开一律转出独立副本（.docx/.xlsx/.pptx），原文件只读不动；之后所有保存都写入副本。哪些内容能转、哪些不保留，确认框里有逐项说明。

文档打开的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
