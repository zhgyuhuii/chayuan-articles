# 拆开看Docker无头架构：原理、架构与实现细节

Docker无头架构是什么、怎么用，一篇讲清楚。AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。下面进入正题：先概念，再步骤，最后是边界与常见问题，基于察元AI OS整理。

## 是什么与为什么

整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离、数据在服务器侧统一管理，默认只监听回环端口，暴露面自己控。

一台服务器全组使用，运维只管一处，终端零安装。

按真实界面写，按钮文案原样引用。

## 机制拆解

桌面系统跑进容器：多用户隔离与回环暴露面。

一台服务器全组使用，运维只管一处，终端零安装。

能力面拆开看：浏览器即用；数据集中管理；端口暴露面自控，账户隔离。

## 实操全过程

按最短路径验证一遍：

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 别在这几处栽跟头

边界都在这：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 多少人共用一台服务器合适？

取决于是否同时跑本地模型：只做对话与知识库，十几人一台中配服务器可行；要并行跑本地推理，按并发数加内存或改用厂商模型分流。

### 数据存在哪里？

全部落在服务器的数据卷里（含用户空间、知识库、配置），挂载出来后备份一个目录等于备份全组。

### 云桌面和桌面版功能一样吗？

核心能力面一致（对话、知识库、模型、办公），形态差异在：云桌面无本地文件直通、语音输入依赖浏览器权限、部分外设在浏览器里受限。

## 能力点备忘

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 安装与运行答疑

### 模型加载失败或提示内存不足？

系统有内存预算硬底线（总内存的 45%）保护：先卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

## 一个真实场景

国产化环境用户的典型用法：按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64，deb 包安装到银河麒麟 V10 或统信 UOS 20，本地五件套模型离线即用。信创环境一套完整的 AI 桌面与办公方案。注意：暂不支持龙芯平台。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 灵宠与任务灵宠

每个智能体可以化身桌面灵宠：在壁纸上活动，动作与体型反映记忆负载，头顶流式气泡，双击直开工作台。绑定常驻任务的任务灵宠会在执行期上桌直播输出，结束时气泡显示成败摘要——定时任务从日志文件变成看得见的桌面直播。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。
