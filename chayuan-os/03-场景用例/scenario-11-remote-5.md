# 出差/远程办公者提效实录路线：远程办公这样落地

如果你是出差/远程办公者，下面这些场景大概率不陌生：外面连不回公司机器。手机连回你的 AI 工作站。这篇清单式指南以察元OS为工具，把这个岗位的远程办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 外面连不回公司机器
- 手机上没桌面环境
- 临时要处理文件

## 用察元OS怎么解：工作流拆解

1. 云通道连接设备
2. 手机浏览器 /m/ 入口
3. 远程查看与操作

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「云通道连接设备」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。手机连回你的 AI 工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 需提前配置云通道
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 常见问题
### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。
