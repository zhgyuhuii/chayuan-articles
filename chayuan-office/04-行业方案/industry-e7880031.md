# 制造业行业怎么用察元Office：从痛点到落地

制造业行业的文档与信息工作有其固有节奏：临时性、突击性材料多，加班赶稿是常态。察元AI Office在制造业场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出制造业行业的完整应用路径。

## 制造业行业的典型痛点

- 临时性、突击性材料多，加班赶稿是常态
- 专业术语与口径需要全篇一致，人工核对容易漏
- 对外材料有保密与合规要求，外发前自检环节薄弱

## 对应的能力组合

- **浏览器 SaaS 形态**（在线办公）：除桌面版外提供浏览器 SaaS 形态（Fastify BFF + Docker：Postgres + MinIO），团队可私有化部署网页版。
- **母版与版式**（PPT母版）：演示母版与版式体系：全局字体配色一次设定，整套幻灯统一。
- **首页 AI 对话**（一句话生成文档）：首页对话框直驱文档生产：写文档、做表格、生成演示，能就地修改已打开的文档，结果直接落成工程文件；agent 内置网页/图片搜索、生图、媒体分析工具。
- **数据透视表与切片器**（数据透视表）：表格分析利器：透视表多维度汇总、切片器交互筛选、条件格式与公式追踪配套。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按教师场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- AI 能力需自配模型（云端 Key 或本地端点），不配置时 AI 功能不可用
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

文档编辑与格式转换完全本地化：打开、编辑、保存不出机器；PDF 转 Word/PPT/Excel 由内置 PDFium 引擎做字符级提取与几何版面分析，全程离线、无云端参与，扫描件 OCR 也走系统本地引擎（macOS 用 Vision，Windows 用系统 OCR），适合对数据敏感的政企与个人用户。

## 数据安全与隐私边界

- PDF→Word/PPT/Excel 转换与 OCR 均为本地引擎，扫描件不上传
- 开源 Apache-2.0 可审计（企业模块另有例外许可）
- 安全工程：全窗口 contextIsolation + sandbox、IPC schema 校验、外链协议白名单、无硬编码密钥
- 遥测仅匿名统计且可一键关闭，永不收集文档内容与身份信息

## 费用与授权的边界（如实说明）

开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。付费部分：试用期满后每日一次购买提醒弹窗（可手动关闭）+ 主页每 30 分钟温和提醒；离线 HMAC 短序列号激活，绑定机器指纹本地验证，无需联网激活服务器

## 常见问题
### 升级会丢数据吗？

不会。覆盖安装/更新不触碰用户文稿目录；更新通道为官网检查+安装包下载双通道。

### 数据存在哪里？隐私如何？

文档保存在本机（默认「文稿/ChayuanAIOffice」）；官方包默认匿名统计且可一键关闭，不收集文档内容、文件名、路径与身份。

### 有自己的命令行吗？

有：chaoffice CLI 支持 headless 格式转换、结构化编辑、逐页渲染 PNG，并内置 MCP server，可让 Claude Code 等智能体直接操作 Office 文件。
