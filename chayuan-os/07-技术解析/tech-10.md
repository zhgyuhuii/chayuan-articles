# Docker无头架构的设计取舍：团队统一 AI 工位

Docker无头架构这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决团队统一 AI 工位。

## 概念先对齐

Docker无头架构是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，Docker 云桌面（察元AI工舱）是其中面向这类需求的一环。

先把定位立住，再看步骤。

## 机制拆解

桌面系统跑进容器：多用户隔离与回环暴露面。

能力面拆开看：账户隔离；端口暴露面自控，数据集中管理；浏览器即用。

## Docker 云桌面（察元AI工舱）：从入口到完成

上手按顺序做：

1. 浏览器即用
2. 账户隔离
3. 数据集中管理
4. 端口暴露面自控
5. 场景验证：团队统一 AI 工位
6. 场景验证：培训机房批量部署

## 这些坑和边界要知道

用之前要认的账：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 高频疑问

### Docker无头架构要联网吗

GGUF、whisper 权重可以按路径直接导入（零拷贝）；whisper 语音权重同样支持，local 星号开头的本地模型未运行自动加载。以官网 aidooo.com 当前页面为准。

### Docker无头架构数据存在哪

docx/xlsx/pdf/csv/html 与扫描件 OCR，单文件不超过 48MB；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；GGUF、whisper 权重可以按路径直接导入（零拷贝）。以官网 aidooo.com 当前页面为准。

## 更多操作细节

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

## 更多操作细节

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 离线与内网
