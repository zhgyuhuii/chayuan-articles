# 察元OS v桌面体验整改 更新解读：桌面体验 28 项整改闭环（真机走查+CDP 截图）

v桌面体验整改（2026-09-23/24）带来了 2 项主要更新。这篇解读把每项更新「翻译」成使用层面的变化，并给出升级建议。

## 本版主要更新

- 桌面体验 28 项整改闭环（真机走查+CDP 截图）
- 商店 M1 真机验收

## 值得展开说的一处

以「桌面体验 28 项整改闭环（真机走查+CDP 截图）」为例：它解决的是此前用户反馈集中的场景。升级后建议第一时间验证这个场景——如果它正是你的痛点，这一版就值得升；如果你的工作流不涉及，也可以观望一个补丁版本再升。

## 升级建议

1. 升级前备份用户数据目录（各产品数据目录见官方文档）
2. 从官网 https://aidooo.com 或对应发布渠道获取新版安装包
3. 覆盖安装，完成后验证常用链路
4. 如有问题，用备份目录回滚到旧版

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 升级会丢数据吗？

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。
