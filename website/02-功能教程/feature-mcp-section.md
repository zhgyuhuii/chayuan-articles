找一个 MCP 服务

3. 看详情页的安装配置说明
4. 复制配置到你的 MCP 客户端

判断一个 MCP 还活着吗

1. 看条目的仓库地址与最近更新时间
2. 无 GitHub 数据的条目看本站下载量参照
3. 失效（dead 或 archived）资源会被自动剔出榜单，榜单里能搜到的都是活跃条目
4. 拿不准就点仓库地址去源站确认

### 怎么判断一个 MCP 服务还活着？

榜单机制会自动剔除标记为 dead 或 archived 的失效资源；点进详情页看最近更新时间与 star 走势也能判断。
