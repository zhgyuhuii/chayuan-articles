# 竞技场接入国际厂商：OpenAI、Claude、Gemini配置

手里只有 OpenAI、Claude、Gemini 的 Key，能不能上桌？能，而且操作上与国内厂商没有本质差别。这篇讲竞技场接入国际厂商的三件事：三家各自去哪拿 Key、配置动作怎么做、Claude 的协议自动转换是怎么回事。网络与合规的部分也提前说清，不藏着。

## 三家的 Key 来源

OpenAI：到 OpenAI 的开发者平台注册账号，在控制台里创建 API Key。平台有独立的使用计费体系，创建前按其指引绑好支付方式。

Claude：到 Anthropic 的开发者控制台注册，创建 API Key。同样有平台自己的计费与额度规则。

Gemini：到 Google 的 AI Studio 及相关开发者平台获取 Key，入口与计费规则以 Google 官方页面为准。

三家都是各自平台的公开流程，本文不代述细节，以各家文档为准。费用口径统一说明：软件 MIT 开源免费，三家模型的调用按各自平台计费，多为美元计价，由你直接向厂商支付。

## 配置动作：同一入口走三遍

进设置 ＞ 模型配置，85 家厂商目录里三家都在。每家的动作一样：点选厂商、粘贴 Key、点「获取模型」实拉该账号可用模型列表、勾选入库、回大厅开局验证。目录厂商的接口地址都内置好了，你不需要手填端点。

逐家验证：开一局人机局或机机观战，看对局室里思维链气泡流式滚出、每手延迟与 token 用量正常标注。哪一家不通就回哪一家的配置核对，三家互不影响。

三家拉出来的模型清单各不相同，勾选时注意一点：同一家的不同档位模型，棋力与速度差异可能很大。先各勾一两个，对局里试过再调整阵容，比一次勾满更有效率。三家各自独立成档，之后想增删型号，回到对应厂商的表单重新实拉即可。

## Claude 的协议转换：你不用做任何事

这里有一处与其他产品不同的机制值得单独讲。Anthropic 的原生接口协议与 OpenAI 兼容协议不是一套格式，很多工具接 Claude 要改代码或换适配层。竞技场的做法是：Claude 的原生协议由本机网关自动转换，对上的一切请求格式由网关处理，对下 Claude 直接原生对话。

落到你的操作上就一句话：像配其他厂商一样配 Claude，点选、填 Key、拉列表、开局，没有任何额外设置，也不用改任何代码。协议差异被网关消化在本机内部，你在对局室里看到的出招、思维链气泡、token 用量与其他厂商完全一致。

## 三家的差异怎么观察

不给结论，给观察角度。三家模型同台时，这些地方最容易看出差别。

出招格式：协议画像会统计每个模型的 JSON 格式遵守率与平均出招耗时，谁的出招更规整、谁更磨蹭，数据替你记着。思维链风格：对局室里气泡滚出来的推理，有的铺得开、有的直给，多看几局自然有感觉。牌桌性格：德州扑克里谁下注激进、谁防守保守，机机观战的匿名机制让这类观察不受品牌印象干扰。

这些观察没有标准答案，你的局数就是你的数据，攒够了再下结论，小样本看不出真差异。观察本身不花额外的钱，对局打着打着，材料就攒下来了。

## 费用现实：把账算在前面

国际厂商的账单有两点与国内厂商不同，提前想清楚。

计价多为美元，汇率波动会体现在实际支出里；模型档位多、能力梯度大，思考型模型每手消耗的 token 往往更高，锦标赛这种连续对局的玩法会放大消耗。

两个控制手段：先用人机局小规模试节奏，看对局室里的 token 用量标注再决定要不要挂机；厂商平台若支持用量上限，设一道，把意外支出的可能性掐掉。具体价格本文一律不转述，以各平台页面为准。

## 网络与合规：先把话说在前头

国际厂商的接口在国内网络环境下不一定直连可达，可达性由你自己的网络环境决定；能否使用这些服务，还涉及各厂商的区域政策与你所在地的法规要求，这两条都要自行确认。竞技场是本地应用，它只负责向你在配置里填写的地址发起请求，不替你解决网络路径，也不对合规性背书。这部分想清楚再动手，比配置失败后排查省力得多。

顺序再强调一遍：先确认网络与合规，再动手配置。配置失败的表现（验证不过、列表拉不到）与网络不可达的表现高度重合，顺序反了会把环境问题误判成配置问题，来回折腾。合规层面同理，服务可用性随政策变动，动手前查一眼厂商的区域说明。

## 边界与实话

三条说在前面。美元计价叠加汇率与网络成本，三家一起挂机跑锦标赛的账单不容小觑，额度与预算自己盯紧。响应速度受网络链路影响，跨境请求的延迟波动比国内厂商明显，对局节奏可能忽快忽慢，这不是配置错误。区域与政策随时可能调整，服务可用性以厂商当时的政策为准，本文无法替任何地区的人承诺可用。

## 你可能会问

### Claude 需要特殊的适配设置吗

不需要。原生协议由本机网关自动转换，配置动作与目录里其他厂商完全一致，点选、填 Key、获取模型、开局即可。

### 三家全配会冲突吗

不会。每家独立配置、独立验证，机机观战里还能让它们互相打。观战默认匿名，座位显示玩家A、玩家B，终局才揭晓谁是谁，正好抛开品牌滤镜看真实表现。放进同一轮锦标赛也可以，排程自动生成，你只管看积分榜。

### 国际厂商的模型清单怎么确认

用「获取模型」实拉，返回什么就是什么，以你账号实际可用的清单为准。厂商的模型阵容更新频繁，凭印象猜名字不可靠。

### 网络不通时配置会怎样

验证环节会反馈失败。先自行确认网络可达性与合规前提，再回来重试配置，顺序不要反。

### 已经有 ChatGPT 会员，能直接用吗

网页订阅与 API 是两套体系。竞技场调用的是模型接口，需要的是开发者平台创建的 API Key，两者账号可以相同，凭证不通用，按各平台说明办理。

### 三家必须都配齐吗

不必。哪家的 Key 到手就先接哪家，配齐是锦上添花。目录里三家并存，随时可以补，配置动作完全一致，学会一家等于学会三家。

国际厂商接入的关键不在操作——操作与任何一家相同——而在前提：Key 合法取得、网络与合规自行确认。把前提理顺，三家的 Key 都能让它们上桌同台。下一篇换个思路：一分钱不花，让本地模型上桌。
