# 教程库只做元数据导航：AI教程导航概念与上手

看AI教程导航这个词，先立一把筛子：断网了它还能干什么。这篇按这个标准，把察元AI 能力广场的能力面与边界讲清楚。

## 什么是AI教程导航

AI教程导航指的是围绕教程检索建起来的那套入口和规则，载体是察元AI 能力广场这个智能体门户，插件、技能、MCP、提示词、大模型资源都能一站检索、一站下载。

各项数字取自官方文档，截止时间统一标在文末尾注。

## 在哪能用

支持的形态：网页端打开即用；桌面安装包（Windows/macOS/Linux，含麒麟/UOS）从站内获取。

## 教程库的账面

教程库在手头的存量是 21291 条学习资源：arXiv 占 13037、GitHub 占 7309、B 站 783、Awesome 106、精选 56；视频、文章、课程、电子书、文档五种形态都在列；条目只挂元数据和跳转链接，新窗口开原站、不内嵌不转载；免费部分全量开放，深度内容按 token 门控并绑设备。

单独拿出来说的理由：AI 学习素材分散在五类站点，按主题聚拢的导航库把检索效率提了一倍。元数据优先的设计，好处和代价都清楚：好处是链接永远指向源头，作者更新你就能看到；代价是内容都长在源站那头，自己的网络环境直接影响阅读体验。把它当索引用的人无所谓，指望缓存整库的人要绕行。

## 最短上手路径

动手顺序如下：

查学习资源

1. 从教程库板块进
2. 来源类型或关键词当筛子
3. 沿跳转链接到源站读正文
4. 登录后把常用条目收进收藏

## 机制四条

- 来源五处，合计 21291 条
- 只存元数据，不搬正文
- 简介由 AI 翻译生成
- 配侵权投诉避风港机制

四条机制拧在一起看，指向同一个取向：把版权和同步问题放在功能前面。这在资源站里不算多数派，但恰好是能长期用的前提。

## 检索词怎么写才给力

在聚合库里找教程，检索词的颗粒度决定结果质量。只输「机器学习」会得到一屏泛泛之作；换成「决策树 python 实现」这类带动作和技术栈的词组，命中会准很多。另一个技巧是先用来源类型收窄：要动手就筛仓库类，要补概念就筛文章和文档类，视频留给实在看不进文字的时候。

## 先泼盆冷水

- 导航不搬运内容，正文始终在源站那头

冷水泼完，适不适合自己掂量。还有种情况值得说破：如果你的学习习惯是下载整套资料离线慢慢看，这种「只给入口」的模式会让你别扭，趁早知道比装了再卸强。

## 答疑

### 教程库为什么不直接放正文？

只存元数据与跳转链接，正文留在 arXiv、GitHub、B 站等源站，既尊重版权也保证内容与源头同步。

### 教程库收费吗？

全量浏览不收费；深度内容另走付费 token 门控，设备可解绑。

### AI教程导航要注册吗

检索导航无需账号，收藏、投稿、下载要登录。智能广场三栏排布，装了就用的资源类型有智能体、MCP、插件、技能、教程库、提示词、技能包七种，涉及产品线的入口细节以官方文档为准。

### AI教程导航资源免费吗

MCP 板块收的是 MCP 服务器资源；生态扩张快、收藏夹跟不动，持续同步的导航才靠得住；失效资源会被自动剔除出榜。

## 一句收束

把「教程导航」当词典用而不是课本：查的时候进来，查完就走，黏性不需要强，查得快就是全部价值。把它错当学习平台来要求，失望是早晚的事。

## 深度内容的取用规则

深度内容怎么取

1. 免费条目直接看完整简介与跳转
2. 付费深度内容购买后凭 token 解锁
3. 解锁与设备绑定，换设备按 token 规则迁移
4. 遇到版权问题用详情页的侵权投诉通道（说明权利归属、具体内容与诉求）

token 门控这套规则初次接触会觉得繁琐，其实就两个要点：解锁跟设备走，换设备按规则迁移；至于免费条目，全程不受影响。

## 商店与门户的关系

OS 应用商店同源可直装，系统装什么能力从插件开始，分类导航降低选择成本。这条链路对教程读者的意义在于：学到要动手装的环节，插件和技能在同一门户里就能找到，不用切换到别处再搜一轮。

还有一条使用建议：给收藏定个复查周期，比如每季度清一遍，留仍在用的、删已经吃灰的。导航库替你管发现，收藏夹还得自己管。教程库这套东西拆到这里，剩下的坎多半能在答疑小节里找到答案。
