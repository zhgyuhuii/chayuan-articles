# 一文分清Qwen3本地部署：模型配置可一键写入五家

Qwen3本地部署这件事，卡点通常不在「装不上」，而在下载中断、内存预算、架构匹配这些琐碎处。这篇按实际操作顺序把它们串起来，顺带交代清楚边界，术语和按钮文案都按界面原文引用。

## 什么是Qwen3本地部署

把Qwen3本地部署这个词落到实处，就是在这套系统里把对话模型下载、加载、管起来这件事，载体是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 下载这条链路的容错规则

下载失败的处理基本是全自动的，规则摆在这里：

- 单个源 404 / 超时 / 中断时，自动切换下一源重试，顺序是 ModelScope（含 API 通道）优先，两个 hf-mirror 镜像随后，再到 aifasthub，HuggingFace 官方源整体垫底
- 连接中断时报「连接提前中断（断点已保留，可续传）」，按钮变「继续下载」；手动暂停同理
- 所有源都失败时报「所有 N 个源均失败（断点已保留，可重新下载续传）」，按钮变「重试下载」，行内显示具体错误
- 断点保留意味着任何中断都不用从头重下

换源与续传都由系统接手，人工要做的只是偶尔点一下「重试下载」。

## 装之前要认下的几条限制

- 8GB 内存的设备，建议同时只挂一个对话模型，复杂任务会受限
- 龙芯芯片的机器还上不了；视频生成不在本地完成，由云端路由承担
- 云端厂商的模型要调用，API Key 自行准备
- Docker 云桌面、跨终端互联这类进阶玩法，需要一定的动手能力垫底

这几点都不影响主干流程，只是动手前掂量一下更踏实。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 从挑模型到启动的完整走法

以下流程按真实点击顺序整理：

1. 按 /△/关闭 挑模型（模型库区）。「模型库」标题旁有图例：「本机推荐 · △ 可跑，内存吃紧 · 关闭 超出本机内存（仍可下载，加载时会被守卫拦截）」。每行结构：

   1. 行首彩色徽标： 绿 / △ 黄 / 关闭 红（判定规则：模型内存 + 2GB 余量 ≤ 当前可用内存 = ；不超过物理内存 − 2GB 系统保留 = △；超出 = 关闭）；
   2. 模型名（beta 模型带黄色 beta 标）；
   3. 第二行参数：「参数量 · 上下文 · 下载体积 · 运行内存」，如 4B · 32K · 2.6GB · 3.3GB RAM；
   4. 行尾动作按钮（见下一步）。

2. 开始下载。点行尾「下载 <体积>」（如「下载 1.6GB」）：

   1. 进行中：按钮变「取消下载」，行下出现进度条，右侧显示「排队中…」或「<源站名> 百分比」（如 ModelScope 37%）；下载中页面约 1.5 秒自动刷新一次进度；
   2. 点「取消下载」：断点保留，之后可续传。

3. 下载完成 ＞ 启动加载：

   1. 下载完成后模型自动从「模型库」进入上方「我的模型」列表；
   2. 点该行「启动」：提示「已发起启动（后台预热）」——系统先做内存预算预检，再拉起引擎进程、健康检查，大模型首次加载可能需要十几秒；
   3. 预检不过会明确报错：「内存预算不足：加载需要约 XGB，当前预算 YGB 已被运行中的模型占用。请先在模型管理中卸载：<名单>」，或「此机器内存不足以加载该模型…请选择更小的模型」；
   4. 加载成功：行首亮绿点（运行中）；黄点 = 「运行中·探针验证中」（探针尚未确认）。顶部计数 +1；
   5. 点「测试」验证链路：通过显示「测试通过 · <耗时>ms」（嵌入模型附维度、对话模型附样例回复），失败显示「关闭 测试失败 · <原因>」。

4. （可选）我的模型行内其他操作。每行按钮（悬停有说明）：「停用」（卸载运行中的模型，立即释放内存）/「钉住」（悬停「钉住：空闲自动卸载豁免」，钉住后行内显示 ；「取消钉住」恢复参与自动卸载）/「设置」（启动参数：省内存·均衡·性能三档与高级覆盖，见后续教程 M5）/「删除」——行内二次确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」点「好」执行、「取消」收回。手工放置过、与内置目录疑似同款的权重行会出现「认领」/「已认领（撤销）」。

另外，设置＞模型＞本地分组里有「恢复出厂」：本地模型配置整体回到出厂状态，配置改乱时用它兜底。

## 出问题的时候怎么办

下面这几个问题覆盖了最常见的几种翻车场景：

### 怎么删掉下错的模型？

「我的模型」行内「删除」＞ 确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」运行中的模型要先「停用」再删。注意权重全机一份，删除影响本机所有用户；「装机即用」五件套权重随安装包分发、不占额外磁盘，无需删除。

### 下载前要预留多少磁盘？

系统自动预检：模型体积 × 1.05 + 200MB；不足时报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 启动报「二进制缺失 / 引擎缺失」？

推理引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；恢复方法详见帮助中心「引擎二进制」。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

Qwen3本地部署能不能用好，一半看操作，一半看边界认得清不清。内存、架构、磁盘这三项提前核对完，剩下的就是等进度条走完。
