# Claude Code是什么：察元OS 都支持哪些智能体

把 Claude Code 放进一套桌面系统里用，和单独在终端里裸用，是两种体验。这篇以它在多智能体环境里的位置为主线，把能干什么、边界在哪讲透。

## 什么是Claude Code

先给定义：Claude Code 是命令行 AI 编程智能体中的一员；承载它的察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

单用 Claude Code，你得自己管 API、管配置、管权限；放进这套系统，模型代理、配置注入、技能镜像都由系统代管，它从一件独立工具变成桌面能力的一部分。

各项口径有官方文档背书，对应版本见文末尾注。

## 最短上手路径

最短路径走一遍：

1. 先认清单：17 家外部 CLI，外加内置 Harness
2. 打开能力矩阵，各家长处一屏看完
3. 新装的智能体约 5 秒被自动感知
4. 官方品牌图标自动拉取到位
5. 场景验证：同一代码任务交给不同智能体比质量
6. 场景验证：再按项目性质定人选

这套路径的重点在第 5、6 步：前四步是认识环境，后两步才是做决策——质量对比给你客观数据，项目匹配给你主观手感，两样都过再定主力不迟。

## 落点的能力面

能力面四件事环环相扣：名单、矩阵、自动感知、图标拉取，合起来就是一台机器管十几家智能体的底座。矩阵把「哪家擅长什么」从传闻变成表格，自动感知省掉登记环节——Claude Code 装好即入列，与其它智能体同台比较，强弱一望便知。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图。
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路，自动那条一键把代理地址加模型写入五家，备份可回退。

## 边界与门槛

- 内存 8GB 设备一次只加载一个对话模型，复杂任务受限
- 龙芯平台暂缺支持；本地无视频生成，视频生成经云端路由实现
- 云端厂商模型调用，API Key 自备
- Docker 云桌面、跨终端互联这类进阶形态，需要些动手投入

这几条边界了解即可，不影响主流程，但动手前值得过一遍。

## 数据与安全设计

- 敏感操作全记录进 audit.jsonl 审计日志，可回放核查
- API Key 经 safeStorage 加密保存，遥测可整体停用

## 常被问到的两点

### 不联网 Claude Code 就废了吗

要看模型在哪端：本机 Stable Diffusion 链路出图不联网；常驻任务可配联网开关，联网环境下内置 web_search 工具默认走 DeepSeek 搜索；云端厂商模型则要联网加自备 Key。

### 它操作的数据落在哪里

知识库数据按库独立存储，左栏输入库名即建，系统缺省带一个 default 库；整套系统断网可用、数据不出本机；敏感操作另记入 audit.jsonl，可回放核查。

## 一句收束

Claude Code 用不用得好，环境比技巧重要：模型代理、知识库、权限门这三层配顺了，它在你机器上才像一名常驻工程师而不是客人。

## 定时任务与知识图谱

定时任务的进度从日志文件变成桌面上的实时直播，跑没跑、成没成一眼可见；群分区可选，桌面出图标、双击进群；知识图谱页签自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成。

## 胖瘦终端与升级底线

本机轻薄、远端肥厚时，桌面只当壳；账户隔离、数据在服务器侧统一管理；遥测可关，清除桌面数据有警示；升级不丢数据是底线，检查更新静默失败不影响使用。

## 平台与形态

web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作；内置浏览器窗配合 webwindows 可被智能体驱动；整套系统可无头跑在 Docker 里作多用户云桌面（工舱形态），员工浏览器打开即用；Dock 文生图应用支持提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。

## 跨机授权与本地出图

跨机问答的场景：资料躺在 A 机器、人守着 B 机器，授权一次即可跨机提问，授权粒度是按终端逐台；出图这块走本机 Stable Diffusion 链路，不联网，隐私与免费两头都占。两条口径一个面向协作、一个面向本机，互不干扰。

## 模型下载源的兜底

下载源会在 ModelScope、hf-mirror、HuggingFace 之间自动切换；Dock 直开内置的办公套件，文档、表格、演示在线编辑。

## 配对授权与生图默认模型

对配对终端可开模型加知识库授权；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）——生图模型不配好，画图应用与智能体的生图指令都落空。

## 自愈机制

本地服务多，全靠人盯不现实，自愈机制让小故障无感恢复。对 Claude Code 这类一跑就是长任务的智能体来说，宿主环境的稳定度，直接决定你敢不敢把任务放着不管。

记不住全部没关系，抓住一条主线：这台桌面同时收编 17 家外部 CLI 与内置 Harness，Claude Code 只是其中一席。
