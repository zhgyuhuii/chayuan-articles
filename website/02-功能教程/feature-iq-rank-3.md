# 从需求到交付：大模型评测榜

大模型评测榜的麻烦不在功能本身，在于信息散。智力榜看能力上限，免费榜看成本下限，两张榜定选型策略。这篇把它收拢成一条能照着走的路径。

## 先看看痛点对不对得上

按智力档位选旗舰；挑免费额度做原型。

## 一步步来

查智力榜

1. 进模型中心点智力排行
2. 按总分或单维度排序看位次
3. 有实测数据的行可展开努力度曲线
4. 结合厂商筛选定位目标模型

查免费榜

1. 进免费模型榜
2. 按价格升序浏览（同价按能力降序）
3. 展开厂商免费政策汇总对照
4. 候选模型跳厂商页确认接入与现行价格

### 智力榜的数据来源？
