# 大模型斗地主玩法详解：叫地主与完整牌型

一副牌五十四张，三个人落座，叫地主的声音一响，牌局立刻分出阵营——斗地主的国民度不需要论证。可你见过大模型打斗地主吗：谁叫地主、怎么拆牌、两个农民会不会打配合？察元竞技场按三人叫地主与完整牌型把斗地主搬上桌，让各家大模型真刀真枪过招。这篇大模型斗地主玩法详解，从叫牌规则讲到牌型链，再看农民配合在模型这里怎么落地。

## 先弄清楚：三人叫地主的规矩

斗地主是三人不完全信息博弈。发牌后每人先拿十七张，留三张底牌，随后进入叫地主环节：按座次依次表态，叫中的人当地主，底牌归入其手，共二十张；两位农民各十七张，结成同盟对抗地主。地主先出，出牌按轮次进行，谁先打完手牌谁赢。地主要一个打两个，农民要互相喂牌、互相接力，身份与目标从叫牌那一刻就定了。

叫地主不是走过场。手牌好叫地主是常规操作，手牌差也可能战术性抢地主，这层博弈在模型之间同样存在：思维链气泡里能看见它掂量手牌、评估炸弹数量的过程。察元竞技场里叫地主由引擎主持，谁叫中、底牌给谁，判定全归代码，模型只表态不判罚。

## 完整牌型：一条链管全场

斗地主的出牌体系可以理成一条链。基础牌型：单张、对子、三张。带牌型：三带一、三带二。顺子型：五张以上的连续单牌、连续对子（连对），连续三张（飞机，可带同数量的单牌或对子）。压制型：四带二。炸弹型：四张同点炸弹，压一切非炸弹牌型；双王合体为王炸，压一切。同牌型之间比点数，牌型之间按压制关系走，炸弹与王炸是秩序外的存在。

对新手观众，认全牌型是看懂模型对局的前提；对模型本身，牌型是硬约束——出招只能从引擎附上的合法动作清单里挑，想出一张不存在的牌型，解析容错链会拦住，实在不行启发式代走。所以你在桌上看到的每一手，都是合法牌型，没有赖账空间。

牌型之外还有几条桌规值得记住：炸弹之间比点数，王炸之外无物可压；出牌要么压过上家，要么选择过牌，一轮之内无人再压，出牌权归上一手的一方；不存在凑数出牌这种事。这些桌规看着琐碎，看模型对局时都用得上——它什么时候过牌、什么时候用小牌型接轮次，都是节奏的一部分。

## 农民配合附合作上下文：工程上的巧思

农民配合是斗地主的灵魂，也是大模型打牌的难点：模型只看得见自己手里的牌，怎么知道队友要什么？察元竞技场的做法是对局信息里附上合作上下文——喂给农民模型的信息里，带着它与同伴的对局关系与已知事件，比如谁出过什么、谁在顺牌、谁在顶地主。模型不是靠读心，是靠这些公开的对局事件做配合推理：同伴放了小对子，它接不接；地主快跑完，它压不压。

看两个模型当农民，配合质量是头号看点。好的配合长这样：农民不抢同伴的牌路，地主出单它顶大、同伴放风它跟牌，地主的节奏被打乱。差的配合也很有观赏性：两个农民互相拆台，同伴的顺子它一接就断。这些差异在同一桌上一目了然，也是不同模型棋风画像的一部分。

配合之外，农民还有一手报牌的学问：手里剩牌越少越要让同伴知道，护送才有准备。模型侧的等效机制是对局信息里剩牌数量公开，谁剩几张都摆在台面上，配合的紧迫感由此而来。地主同样看得见这些数字，收官阶段的博弈因此成了明牌数量加暗牌身份的混合推理，观察价值很高。

## 模型出招怎么落地

大模型玩家走统一出招协议 {move, comment}：move 是选定的出牌动作，comment 是它对这一手的解释。对局信息按各自视角分发，地主看自己的二十张，农民各看十七张，合法动作清单显式附上。出招解析有容错链兜底：剥思维链、抽大括号、补截断、扫合法动作，层层放宽；还失败就启发式代走，代走超限判负，一个模型 API 抽风卡不死整局，429 限流还会自动退避。对局室里每手的延迟与 token 用量标注在旁，复盘里形势曲线画走向，问叹号标注（？！）逐手挑妙手与失误，棋谱支持导出 JSON。

## 这些边界要心里有数

模型的记牌能力有上限：完整牌型下的长局里，弱模型会忘记出了什么、压错关键牌，配合质量随模型档次浮动明显。叫地主的风格也因模型而异，激进派抢得勤、保守派让得多，没有标准答案。费用口径照旧：软件 MIT 开源免费，模型 API 按用量向厂商结算，Ollama 本地推理零成本；斗地主一局手数适中，适合拿来试水不同模型的牌风。另外，叫地主环节的风格差异会让同一家模型在不同局里角色不同，观察它的表现要把地主局与农民局分开统计，混在一起看会失真。

## 高频疑问

### 斗地主怎么叫地主

发牌后按座次轮流表态，叫中者当地主并拿三张底牌共二十张；两位农民结盟对抗。引擎主持流程，模型与人类玩家都只做表态。

### 农民之间怎么配合

靠公开对局事件推理：跟同伴的牌路、顶地主的节奏、关键时刻接力。竞技场把合作上下文附进模型的对局信息，配合不靠读心靠信息。

### 模型看得见别人的牌吗

看不见。对局信息按各自视角分发，每人只看得见自己的手牌与公开事件，暗牌就是暗牌。

### 大模型斗地主玩法支持哪些牌型

单张、对子、三张、三带一、三带二、顺子、连对、飞机、四带二、炸弹、王炸，完整牌型链，出招只能从合法清单里挑。

### 王炸和炸弹谁大

双王王炸压一切，四张同点炸弹压一切非炸弹牌型，炸弹之间比点数。判定归引擎，没有争议空间。

### 地主先出牌有什么好处

节奏主导权在手，可以按自己的牌型规划每一轮走向；代价是一打二的信息劣势，农民的合作上下文它拿不到。

### 一局斗地主多少手能打完

取决于节奏，牌顺时几十手内收官，僵持时更长；判定归引擎，谁先出完谁赢。

斗地主把三个人拽进一场信息不对称的联盟战，叫地主是一切的分水岭。大模型坐上牌桌，你看到的每手牌背后都有一段公开的盘算——牌型是死的，配合是活的，活的这部分才值得看。
