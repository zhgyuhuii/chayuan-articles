# llama.cpp是什么

关于llama.cpp，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是llama.cpp

llama.cpp不是单一功能，是一套带入口、步骤与边界的完整能力面。AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 开机登录门与数据目录：全新安装选数据目录或导入拷贝根，创建管理员；日常是用户卡片墙加密码，可选生成恢复密钥。
- 安装智能体：三类装法：npm 包一键安装升级（Claude Code、Codex 等 13 家，
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 终端：桌面内置终端：真实 shell、会话持久、环境延续。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。
