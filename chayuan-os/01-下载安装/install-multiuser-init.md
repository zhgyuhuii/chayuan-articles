# 多用户初始化安装指南：全平台步骤与验证

内网机器要家庭共用一台电脑，过去要折腾好几个工具拼起来。现在察元AI OS把这件事做成了一个功能：多用户账号管理。下面按我实际操作的顺序走一遍，包括容易踩的坑。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：管理员建户与权限划分。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。安装包从官网 aidooo.com 获取。

## 一步步来：从入口到完成

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥，这两件事做完，这台机器就算真正就绪。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

用之前要认的账：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 常见问题

### 普通用户自己能改密码吗？

能，不用找管理员：设置 ＞ 用户 ＞ 「我的账号」卡，输当前密码+新密码点「修改密码」。管理员重置是给「用户自己也进不去」时用的兜底。

### 重置密码后，那个用户手机/浏览器上开着的远程桌面会怎样？

会立即失效：改密会话版本号 +1，其所有已签发的远程会话（wa_sess）全部作废，需用新密码重新登录。

### 踢下线和停用有什么区别？

踢下线只结束当前会话（窗口关闭、需重新登录），账号一切照旧；停用是封住账号（登录门不再显示、密码登录被拒），但保留其会话之外的全部数据，可随时启用恢复。

## 补充答疑

### 管理员能被停用或删除吗？能增加第二个管理员吗？

都不能。主进程对管理员角色有硬保护（停用/删除直接拒绝），界面也不提供这两个按钮；新建用户一律是普通用户角色，目前没有提权/移交管理员的入口。

### 删除用户后反悔了，数据还能找回吗？

不能。确认框里「不可恢复」是实义：该用户的 profile、home、找回画像被整目录删除，无回收站。建议删除前先「停用」观察；确要保留备份，先把整个 chatop-data 目录拷贝一份。

### 为什么我看不到「用户列表」「开机登录」这些卡？

两种可能：当前登录的不是管理员（普通用户只有「我的账号」和底部「远程访问」卡）；或当前是 web/docker 形态——那边没有桌面账号体系，显示的是另一套管理面。

## 更多操作细节

第 4 步 · 停用 / 启用

1. 普通用户行点「停用」（管理员行没有此按钮，管理员不可被停用）。该行立即出现红色「已停用」标记与「启用」按钮。
2. 停用效果：登录门/锁屏不再显示该用户的卡片，其密码登录一律返回「该账号已停用」；数据原样保留，随时点「启用」恢复。

第 5 步 · 踢下线

在线用户（行内有绿色「在线」标记且不是你自己）行内点「踢下线」＞ 提示「已结束该用户会话」。效果：该用户的桌面全部窗口被关闭、后台会话结束；账号、密码、数据都不动，其重新登录即可恢复使用。

第 6 步 · 删除用户（不可恢复的危险操作）

「用户列表」卡自身的说明就写明：「删除用户会抹掉其全部数据（桌面布局、聊天记录、文档）且不可恢复。所有管理操作写入审计。」

1. 普通用户行点红色「删除」按钮，弹出系统确认框，原文：「删除用户「{用户名}」会抹掉其全部数据且不可恢复，确定删除？」——在确认框里点确认后才执行。
2. 确认后系统依次做这些事（以主进程代码为准）：
    1. 从账号注册表移除该用户；
    2. 若其在线，先拆除其正在运行的会话（全部窗口关闭）；
    3. 整个删除其用户数据目录 users/<用户id>/profile/（该用户的 dsh-home、os-data、var——桌面布局、聊天记录、文档、知识库等全部用户数据）与 users/<用户id>/home/（其终端/智能体 CLI 使用的假 $HOME）；
    4. 删除其找回画像文件（recovery/<用户id>.json，验证画像随账户一起消失）；
    5. 向管理员审计日志写入一条 delete-user 记录。
    6. 没有回收站、无法恢复。拿不准就先「停用」观察一段时间再删。管理员角色本身不可删除（主进程拒绝且界面无此按钮）。

## 安装与运行答疑

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。

### AppImage 双击没反应怎么办？

多为缺 FUSE 2：安装 libfuse2（Ubuntu 24.04 为 libfuse2t64），或用 --appimage-extract-and-run 解压运行；统信 UOS 环境推荐直接用 deb 包。
