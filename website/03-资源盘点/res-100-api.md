# 能力广场专题｜免费大模型 API 盘点

免费大模型 API 盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：免费榜（免费大模型）、API 价格页（API价格）、模型厂商板块（模型厂商）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**免费榜**：零成本与极低价大模型榜单：配合厂商免费额度标记，白嫖党的选型入口。

1. 进入 /rank/free
2. 看免费条目与额度说明
3. 跳转厂商接入

**API 价格页**：40 家厂商 201 个模型条目的静态价目表：人工整理、结构化展示。

1. 进入 /pricing
2. 按厂商/价格排序
3. 跳转厂商官网核实

**模型厂商板块**：全球厂商与聚合平台目录，按「一线厂商→国产→聚合平台→本地部署→更多」分层，标注免费/免Key/本地标记与价格参考。

1. 进入 vendor 板块
2. 按分层浏览或搜索
3. 进厂商详情看模型列表

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 要注册才能用吗？

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。

### 和察元产品家族什么关系？

aidooo.com 是家族官网与资源门户：产品下载、激活购买、应用商店目录都在这里；OS 客户端内嵌同源广场。

### 手机能用吗？

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。
