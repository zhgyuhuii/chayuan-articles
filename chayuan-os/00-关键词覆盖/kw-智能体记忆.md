# 一文分清智能体记忆：命令行 AI 编程智能体一茬茬冒

智能体记忆这个词听起来玄，落点其实很具体：哪家智能体有记忆文件、系统能不能收拢它们、收上来干什么用。这篇按定义、口径、边界三段展开，结论自己下。

## 什么是智能体记忆

智能体记忆，指智能体长期使用中积累的偏好、约定与项目上下文，多以声明式记忆文件形式存在（如 ~/.claude/CLAUDE.md）。这套系统能识别哪些智能体带记忆声明，并把可用的记忆采集进统一入口。承载它的平台是察元AI OS（Chayuan AI OS，简称察元OS）——一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

版本与数字的截止情况统一放文末尾注，正文不再重复标注。

## 在察元AI OS里落在哪

智能体记忆在察元AI OS里的落点是记忆采集：带声明式记忆文件的智能体（Claude Code / ZCode / Codex / OpenCode / OpenClaw 五家）可被采集进「设置 ＞ 记忆」的待确认队列；支持的智能体总览里，「记忆采集」一列标明各家支持与否。

为什么值得单独说：记忆散在各家智能体的家目录里，格式不一、位置不一，系统能把它们收进一个待确认队列，相当于给十几位助手配了统一的档案柜。

5. MCP = mcp 非空：同样的 13 家外部 CLI 会被 mcp-sync 全量合并 MCP 清单（控制面 chatop 与知识库 chatop-kb 两个托管条目自动随行）；Gemini CLI / Aider / Goose / Qwen Code 不传播。
6. 记忆采集 = memory.supported：Claude Code / ZCode / Codex / OpenCode / OpenClaw 五家有声明式记忆文件（如 ~/.claude/CLAUDE.md、~/.codex/AGENTS.md），可被采集进「设置 ＞ 记忆」的待确认队列。

## 先把边界交代清楚

- 设备内存 8GB 时建议单对话模型运行，复杂任务受限
- 龙芯平台未支持；本地无视频生成，视频生成经云端路由
- 调用云端厂商模型，API Key 需要自备
- Docker 云桌面、跨终端互联这类进阶形态要费些手工

## 记忆相关的几个疑问

### 智能体装好后在这里能额外调用什么？

探测到的智能体自动获得：系统技能镜像（上表「系统技能」列）、MCP 清单合并（含知识库 MCP——对话里可直接用 kb_search 等查知识库）、运行在真实终端（pty）里可执行 shell 与读写文件；带记忆声明的五家还可被采集记忆。

### 网页形态打开后智能体列表是空的？

探测与安装管理仅桌面形态可用，网页/Docker 形态的相关页面只显示「智能体探测仅在桌面版（Electron）可用。」。

### 能和原有系统共存吗？

能。察元OS 是独立桌面应用，不动原有系统；不需要重装系统或分区，装完即用，不想用直接卸载。

### 卸载会删掉我的数据吗？

卸载程序不会动数据目录，要留的数据先自己备份；想清干净，就手动把数据根目录删掉。

### 记忆采集需要联网吗

采集本身在本机完成：从记忆、便签、日程等抽取事实卡（不足 3 张判不可用）；只有涉及云端模型的环节才需要网络。

## 应用管理里的识别结果怎么看

第 2 步 · 应用管理看本机识别结果

1. Dock 点「应用管理」＞ 顶部页签「智能体」。
2. 默认只列已识别的智能体，顶部计数「本机智能体 · {n} 型」；勾选「显示未安装」（勾选状态会记住）可看全量排查视图。
3. 每行：图标 ＞ 能力徽标 ＞ 名称（被隐藏过的带「已隐藏」徽标；未识别的标灰「未检测到」）＞ 状态行：
    1. 已识别：「已检测（managed）· 版本 {x.y.z}」——managed = 察元管理态（商店安装/升级版或安装包内置版）；homeDir = 家目录探针命中（自己装的）；path = PATH 里找到命令；
    2. 未识别：「未检测到安装迹象（装好后自动上架/恢复）」。
    3. 行尾按钮：「隐藏」/「恢复」（控制 Dock 上架）与「删记录」；顶部的「重新扫描」（扫描中显示「扫描中…」）随时重测，装完新 CLI 后点它即可，无需重启。
    4. Dock 上架规则：未识别或被隐藏的智能体不显示；识别到的自动上架成正常应用图标。

智能体这条线到这里理完了；记忆队列有异常，先看上面几问。
