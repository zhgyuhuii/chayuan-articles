# Docker桌面：AI 桌面操作系统

Docker桌面这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决团队统一 AI 工位。

## Docker 云桌面（察元AI工舱）是个什么东西

Docker桌面在察元AI OS里的形态一句话说清：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离、数据在服务器侧统一管理，默认只监听回环端口，暴露面自己控。

概念一分钟，操作十分钟，这篇都覆盖。

## 具体怎么操作

按最短路径验证一遍：

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 边界先摆桌面上

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 高频疑问

### 云桌面和桌面版功能一样吗？

核心能力面一致（对话、知识库、模型、办公），形态差异在：云桌面无本地文件直通、语音输入依赖浏览器权限、部分外设在浏览器里受限。

### 多少人共用一台服务器合适？

取决于是否同时跑本地模型：只做对话与知识库，十几人一台中配服务器可行；要并行跑本地推理，按并发数加内存或改用厂商模型分流。

### 数据存在哪里？

全部落在服务器的数据卷里（含用户空间、知识库、配置），挂载出来后备份一个目录等于备份全组。

## 放回产品盘面看

把Docker桌面放回察元AI OS的整体盘面：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。

## 安全与数据边界

安全口径单独立一层：首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；GGUF、whisper 权重可以按路径直接导入（零拷贝）；whisper 语音权重同样支持，local 星号开头的本地模型未运行自动加载。

## 平台与形态

平台与形态的账：本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）；它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭，它能把应用造出来挂上桌面。

## 价格与授权

## 几条硬数字

能落到数字上的几条：无显式模型偏好时自动指向本地模型；配置入口在设置＞默认模型＞网络资源页签；默认内置 web_search 工具多档兜底，设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态。

## 离线与内网

离线内网这条线的口径：离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签），全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，断网时云端模型不可用，可设自动回落本地；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。
