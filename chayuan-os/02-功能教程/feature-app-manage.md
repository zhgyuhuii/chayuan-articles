# 应用管理怎么用：手把手走一遍完整流程

很多应用管理的教程只讲是什么，不讲怎么做；或者讲了一半步骤，剩下的让你自己悟。这篇反着来：步骤写全、按钮文案原样引用、每步的界面反馈都说清楚，用的是察元AI OS（aidooo.com）。

## 是什么与为什么

应用管理的「应用」页签是桌面应用中心（Launchpad 式）：内置应用隐藏/恢复、分组文件夹整理图标、新建网页 / 单机 / HTML / 文件四类自定义应用，并可固定到任务栏、发送桌面快捷方式、把网页应用添成桌面挂件。

任何网页或本机程序都能变成桌面应用，常用工具一键直达。

入口、步骤、验证三段看清，这事就顺了。

## 前置条件

- 桌面形态（察元AI OS）体验完整。网页/Docker 形态应用管理也能打开（由 dsh 插件 host 提供），但本地路径类字段点「浏览…」会提示「选择本地文件仅桌面版可用」（可手填路径）、「Electron 独立窗口」打开方式置灰、单机应用打开时报「单机应用仅在桌面版（Electron 形态）可用。」。
- 应用管理窗口共五个页签：应用 / 智能体 / 插件 / 技能 / MCP，默认落在「应用」。本篇只讲「应用」页签：智能体页签见对应教程/G2，插件与技能页签见对应教程。

## 具体怎么操作

第 1 步 · 打开应用中心

Dock 点「应用管理」＞ 顶部页签停在「应用」。标题行右侧计数「dock 应用 · 内置 + 自定义」；工具栏有视图切换（「图标视图」/「列表视图」，选择会记住）、搜索框「搜索应用…」、按钮「＋ 新建分组」（图标视图才有）「＋ 新建应用」「智能创造」（AI 造物管线展示窗与联系开发商入口，非本篇重点）。

第 2 步 · 图标视图（默认）：整理与分组

说明行「点击图标打开 · 拖拽排序 / 拖到文件夹入组 / 拖到 dock」。

1. 点图标 = 打开；已隐藏的应用图标半透明（悬停显示「{name}（已从 dock 隐藏）」），点击仍可打开。
2. 新建分组：点「＋ 新建分组」（或网格空白处右键 ＞「新建分组」）＞ 出现名为「分组 {n}」的文件夹 tile（显示前 4 个成员的小图标与「{count} 项」），随即进入内联重命名；空分组提示「空分组 · 关闭后拖应用图标到文件夹即可加入」。
3. 拖拽：拖应用图标排序；拖到文件夹 tile 上（文件夹出现高亮描边）即入组；自定义应用可拖到 Dock 排序。触屏设备长按后拖动（图标 ghost 跟手），落点逻辑与鼠标拖拽一致。
4. 点文件夹 tile 打开分组浮层（居中卡片）：点组名重命名、组内拖拽排序、把成员拖到压暗区域移出分组、底部显示「{count} 个应用 · 拖到压暗区域移出分组」与红色「解散分组」按钮（成员回网格）；按 Esc 或点卡片外收起。
5. 右键菜单：
    1. 应用图标：「打开」「桌面快捷方式」「添加为桌面网页挂件」（仅网页/HTML 自定义应用）「固定到任务栏 / 取消固定任务栏」「加入分组」（子菜单列出各分组＋「＋ 新建分组并加入」）「移到最前」「移到最后」；自定义应用额外有「编辑…」「删除…」；
    2. 文件夹 tile：「打开分组」「重命名…」「移到最前」「移到最后」「解散分组」；
    3. 网格空白：「新建分组」「新建应用」。
    4. 固定到任务栏会同时解除该应用的隐藏（否则固定图标不会出现在 Dock）。

第 3 步 · 列表视图：隐藏与管理

说明行「内置不可卸载可隐藏 · 自定义可增删改 · 拖到 dock 排序」。列表按分区组织：

1. 「内置应用（{count}）」·「系统与插件自带 · 不可删除，可隐藏」：每行显示图标、名称、标签「系统」或「插件」、状态「在 dock 显示」/「已从 dock 隐藏」，行尾按钮「桌面快捷方式」与「显示中」——点「显示中」即从 Dock 隐藏（按钮变「已隐藏」），再点恢复显示。
2. 自定义应用按类型四区：「网页应用（{count}）」「单机应用（{count}）」「HTML 应用（{count}）」「文件应用（{count}）」。每行：名称（智能体创建的带紫色「智能体」徽标）＋类型摘要（网页应用显示网址、单机应用显示路径、HTML 应用显示「HTML 源码」或文件路径、文件应用显示文件路径；网页/HTML 再追加分隔点＋打开方式），行尾「快捷方式」「挂件」（网页/HTML）「显示中/已隐藏」「编辑」「删除」。
3. 行右键菜单：「桌面快捷方式」「固定到任务栏 / 取消固定任务栏」（已固定打 ）＋该行的编辑/挂件/隐藏/删除。
4. 搜索框「搜索应用…」按名称过滤；空态提示「还没有自定义应用。点『＋ 新建应用』添加网页、单机、HTML 或文件应用。」

第 4 步 · 新建自定义应用（四类型逐字段）

点「＋ 新建应用」弹出表单（标题「新建应用」；右键已有应用 ＞「编辑…」打开同一表单，标题「编辑应用」）：

1. 「名称」：输入框，占位「应用名称」。必填。
2. 「类型」：四个按钮单选——
3. 网页应用：字段「网址」（占位 https://…，必须以 http/https 开头，否则无法创建）；
4. 单机应用：字段「可执行文件路径（仅桌面版）」＋「浏览…」（系统文件选择；占位 C:\…\app.exe）。点图标即启动该程序；
5. HTML 应用：先选「内容来源」——「HTML 源码」（多行文本框直接贴代码，占位 <html>…</html>）或「本地 .html 文件」（字段「HTML 文件（仅桌面版）」＋「浏览…」）；
6. 文件应用：字段「文件（仅桌面版）」＋「浏览…」，下方提示「按类型打开：pdf/txt/md/图片 ＞ 内置查看器；未知类型 ＞ 系统默认程序」。
7. 「打开方式」（仅网页/HTML 应用）：三选一「桌面内窗口」（默认，开在察元窗口里）、「Electron 独立窗口」（单独原生窗口；网页形态此选项置灰并提示「仅桌面版（Electron 形态）可用」）、「系统浏览器」（交给系统默认浏览器打开）。
8. 「图标」四渠道（右侧实时预览）：网页应用多一项「自动 favicon」（取站点 /favicon.ico，失败回退占位图）；其余为「本地图片…」「图标库」（emoji 库，选中后展开宫格）「默认占位」。
9. 底部「取消」「创建」（编辑时为「保存」）。任一必填项不合法时创建/保存按钮置灰；保存失败提示「保存失败：字段不合法」。成功后提示「已创建『{name}』」（编辑为「已保存『{name}』」），应用出现在对应类型分区；Dock 显示「固定 + 运行中」两类图标，新应用打开后即在 Dock 出现，想常驻可拖到 Dock 或右键「固定到任务栏」。

第 5 步 · 删除自定义应用

行尾「删除」或右键「删除…」＞ 确认弹窗标题「删除『{name}』？」，正文「将删除应用本体及其全部桌面快捷方式与挂件。此操作不可撤销。」＞ 点「删除」＞ 提示「应用已删除（其桌面快捷方式与挂件一并清理）」。内置应用没有删除入口，只能隐藏。

## 做完后的验证

验证

1. 新建一个网页应用后：应用管理「应用」出现该图标；点图标按所选打开方式打开该网址，Dock 同时出现运行图标；右键「固定到任务栏」后常驻。
2. 在内置应用行点「显示中」：按钮变「已隐藏」、副文案变「已从 dock 隐藏」、Dock 图标消失、图标视图里该图标半透明；再点一次恢复。
3. 把两个应用拖进新建的分组：文件夹 tile 显示 2×2 小图标与「2 项」，点开浮层可改名、拖出成员、解散分组。

## 谁需要这个功能

智能体帮忙创建的应用（图标旁带「智能体」徽标）想改名、改配置或删掉，想把常用网站（如公司 OA）做成桌面应用，或把本机程序、某个文件放进察元当应用打开，把公司后台系统钉上桌面；Dock 与应用列表太乱，想把不常用的应用隐藏、把同类应用归进一个文件夹。

用户常搜的问法：怎么把不想用的应用从 Dock 隐藏；能把几个应用放进一个文件夹分组吗。

## 别在这几处栽跟头

用之前要认的账：

## 接着回答几个常见问题

### 单机应用点了没反应？

启动失败会弹出该应用的错误卡，显示「启动失败：{原因}」。先回编辑表单核对可执行文件路径是否正确；错误卡上有「去应用管理编辑」按钮，点它直接跳到应用管理并打开该应用的编辑表单。

### 网页应用打开后提示「该网站拒绝在内嵌框架中显示，可改用独立窗口或系统浏览器打开。」怎么办？

这是站点禁止内嵌（X-Frame-Options）的正常表现。按提示条上的「用独立窗口重开」临时换窗口，或点「以后都用独立窗口」记住选择；也可以「在系统浏览器打开」，或到应用管理把该应用的打开方式改为「Electron 独立窗口」/「系统浏览器」。

### 固定到任务栏了，Dock 上还是没有图标？

固定动作会自动解除历史隐藏；若仍不显示，在列表视图找到该行看状态是否「已从 dock 隐藏」，点「已隐藏」恢复显示即可。

### 「隐藏」和「删除」有什么区别？

隐藏只影响 Dock 显示——应用仍在应用中心，随时可打开或恢复，内置应用也只能隐藏；删除仅对自定义应用可用，会连同它的桌面快捷方式与挂件一起清掉，且不可撤销。

应用管理的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
