# 信创AI办公场景拆解：AI 桌面操作系统

信创AI办公的麻烦不在功能本身，在于信息散。它不是一个软件窗口，是一整套桌面环境，这篇把它收拢成一条能照着走的路径。

## 解决什么痛点

1. 麒麟与 UOS 上能用的 AI 软件少
2. 飞腾鲲鹏架构兼容性存疑
3. 政企采购要过信创适配

国产化环境用户这个场景里，信创环境一套完整的 AI 桌面与办公方案。

## 把流程串起来

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程

## 支撑功能的操作细节

流程里桌面环境总览的实际操作：

上手按顺序做：

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程
5. 完整桌面范式
6. 42 张内置壁纸

## 关键能力点

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

## 它的局限也要说清楚

边界先摆在桌面上：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

场景提醒：暂不支持龙芯平台。

## 你可能会问

### 信创AI办公要联网吗

共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；AI 面试 3 次失败锁 24 小时；忘记密码时本地 AI 面试官出题。以官网 aidooo.com 当前页面为准。

### 信创AI办公数据存在哪

Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，写材料时直接问公司知识库，回答带引用插进文档，办公与知识库一条链；文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一。以官网 aidooo.com 当前页面为准。

## 更多操作细节

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 更多操作细节

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 价格与授权

价格口径一并交代：Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入，键盘党的启动器：一个快捷键管启动、找文件、直接问 AI 三件事；问 AI 直答卡，四本日历把生活与工作分开记，AI 能读会写，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 产品家族与搭配

察元AI OS不是单打独斗：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，:52581（OpenAI 兼容统一模型代理）；很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的。

## 几条硬数字

能落到数字上的几条：或按直链目录放置后执行扫描本地放置的模型；扫描本地放置的模型；我的模型面板管理加载、卸载、删除、钉住；常用模型可钉住常驻。

## 离线与内网

离线内网这条线的口径：断网时云端模型不可用，可设自动回落本地，断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入；帮助中心离线可读，断网也能查手册。
