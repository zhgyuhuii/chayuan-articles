# 离线插件包入门指南：应用商店对接察元AI 能力广场

内网机器想要插件，靠的不是玄学，是离线包。这篇围绕离线插件包把定义、口径、边界讲齐，产品以察元AI OS为载体。

## 什么是离线插件包

离线插件包依附的产品是察元AI OS（Chayuan AI OS）：一套 AI 桌面操作系统，把本地大模型、知识库、智能体、宠物群聊收进同一个桌面。

数字与版本的出处是官方文档，文末尾注给出截止时间。

| storeCats | 插件、技能、MCP 插件、智能体、技能包五大类 |

## 在察元AI OS里落在哪

离线插件包在察元AI OS里的落点是应用商店与智能广场：应用商店对接察元AI 能力广场，插件、技能、技能包、MCP 插件、智能体五类内容在线下载与云端推送更新，聚合全球生态资源并配排行榜；内网环境走离线包导入。

为什么值得单独说：能力不是写死在系统里的，是从商店长出来的，越用越全。

这四项彼此咬合：前两项管发现，后两项管分发，联网与内网环境都照顾到了。

## 察元AI OS的能力地图

- 知识图谱：知识库应用里有个知识图谱页签，进去就是自动生成的文档实体二部图
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路里选自动，代理地址加模型一键写入五家，动手前自动备份、可回退
- 插件与技能管理：插件启停卸载、离线安装；项目与用户技能清单管理、离线导出导入。
- 察元AI Office 集成：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，与知识库、模型联动，共享同一个模型代理。
- 跨终端聊天与远程执行：和配对终端互发消息附件、请对方智能体干活，消息可离线暂存后送达，武力值徽标显示信号格与等效算力。

## 先泼四盆冷水

- 8GB 内存的设备，同时只装载一个对话模型，复杂任务的空间就被压缩了
- 龙芯处理器版本仍在等待；视频生成本地无法提供，由云端路由负责
- 没有自备的 API Key，云端厂商模型无从调用
- Docker 云桌面、跨终端互联是进阶玩家的领地，新手不建议贸然进入

冷水泼完，主线功能其实稳得很；这些只是适用条件，不是劝退名单。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 关于离线分发的两个疑问

### 断网环境下插件怎么进来

靠离线包导入，这正是它存在的意义；消息与任务链路也不因断网停摆：与配对终端互发消息附件、让对方智能体执行任务都支持离线暂存后送达。常驻任务那边，写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，一次设好即可长期跑。

### 插件源可以自己配吗

可以。内置插件源有开关，社区源与技能源支持自定义，npm registry 与代理都能设置；内网或特殊网络环境下装插件，这套配置是必经之路。

## 结语怎么下

离线插件包的核心价值在内网：外部网络进不来，能力靠包搬运。你的环境若不受此限，在线商店那条路更省事；若受此限，这篇就是操作底稿。

## 装机清单再过目

- 网络：技能包商城目录、MCP 察元能力广场、GitHub 技能仓库都需要联网；断网时技能包页显示「目录来自离线缓存，联网后自动刷新」，智能广场切离线兜底页。
- 智能体页签的安装/升级仅桌面版可用；技能包的获取在网页/host 形态有网页兜底通道。
- 装完的东西分别落在：插件 ＞ 应用管理「插件」页签；技能 ＞ ~/.dsh/skills/（应用管理「技能」页签可见）；MCP ＞ 本机 MCP 清单并同步到支持 MCP 的智能体；管理操作见对应教程。

## 生态与管理的全景

装了什么、开了什么，需要一个总账页面；离线环境靠导出导入搬迁，插件走全生命周期管理，tar 包也能做离线迁移。周期巡检、每天早报、定时盯数据这类活可以交给常驻任务，早上来收报告即可。

## 本机安全的几层设计

数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；智能体要是不清楚自己有哪些本机工具，有也等于没有，技能手册镜像让它们开箱就会用系统能力；MCP 服务清单支持增删改（stdio、HTTP、SSE、本机 52583）。敢让 AI 碰电脑，先得能管住它：分级确认、超时拒绝、审计，三道锁一道不能少；审计日志全量记录。

## Dock 与桌面手感

设置里可调桌面与 Dock 的位置、自动隐藏、图标放大与大小，还能设开机自动打开 Harness。Dock 是使用频率最高的区域，位置与大小顺不顺眼很影响手感；从这里直开内置的察元AI Office，文档、表格、演示在线编辑，每次产出的 markdown 报告都会落盘归档。

五个大类记牢——插件、技能、技能包、MCP 插件、智能体；其余细节顺着最短上手路径往下走即可。
