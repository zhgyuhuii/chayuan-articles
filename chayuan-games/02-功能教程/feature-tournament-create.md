# 锦标赛创建教程：多模型循环赛怎么开

看两三个模型对打已经不解渴了？想让一整排模型同场竞技、拼出个高低座次？锦标赛就是竞技场里的联赛模式：选一批参赛模型，循环赛自动排程，积分榜实时刷新，打完出冠军。这篇按锦标赛创建的完整流程走一遍，从挑人到开赛，让你把一届模型联赛顺利办起来。

## 先弄清楚它是什么

锦标赛是多模型循环赛模式。你确定参赛名单，排程由系统自动生成——循环赛的赛制意味着每位选手都会与其他选手轮番交手，不存在抽签运气，名次靠每一场的真刀真枪拼出来。对局过程中积分榜实时刷新，谁涨谁跌一目了然；全部轮次跑完，按积分排定座次，冠军产生。

它与机机观战的差别在于「赛」字：观战看的是一场一局的单点热闹，锦标赛看的是一张积分榜的整体故事——爆冷的、连胜的、后程发力的，全在这张榜上展开。而它与天梯的差别在于规模：天梯记录长期累积的排位，锦标赛是一届一届的短跑赛，办完一届是一届。

办锦标赛省下的是你的组织成本。人肉组织一场多模型联赛要排赛程、盯场次、记比分，挂机模式下这些活全归系统，你只管睡前点一次开赛。这也是很多人把锦标赛当「睡前仪式」的原因：挂一晚上，早上收战报。

## 动手前要备好什么

参赛选手是锦标赛的本体，先把手续办齐。进设置 ＞ 模型配置，从 85 家厂商目录点选厂商、填上你自己的 API Key，点「测试连接」验证；「获取模型」实拉该账号的模型全列表勾选入库；Ollama 本地模型免 Key 接入。没配好的模型进不了参赛名单，这是前置不是刁难。

名单怎么搭，两个思路。求热闹：跨厂混编，思考型与响应型同场，风格差异越大看点越多。求效率：优先选格式稳、少触发容错兜底的模型当主力，弱模型可以进名单凑数，但要接受它们拖慢节奏、拉低单局观感。名单长短量力而行——循环赛的场数随人数增长，八个选手打一轮比四个多出一倍不止，费用与时长都要翻着算。

费用预期立在开赛之前：云端模型每一场都在消耗你向厂商付费的额度，规模越大烧得越快；想低成本办大赛，本地模型多安排几个。

## 锦标赛创建的完整步骤

第一步，进模式。从大厅进入锦标赛的创建流程，起点同样是选参赛模型。

第二步，确定参赛名单。选人环节支持批量选模型：想办大混战，把配好的模型一批勾上；想办精英赛，挑三五个主力。名单即赛事，勾完这一步，这届锦标赛的故事线就定了。

第三步，确认开赛。名单定了之后，循环赛排程自动生成，不用你排轮次、不用你配对——这是锦标赛创建里省心的部分。确认开赛，系统按排程逐场推进。

第四步，挂机与看榜。开赛后进入挂机节奏：对局一场接一场，积分榜实时刷新。你可以随时凑过来看两眼当前名次，也可以完全不管，等它自己跑完。

第五步，收战报。全部轮次结束，积分定格，冠军出炉。每一场对局都留档在记录页，哪场爆了冷、哪场打满了全程，回放随时可查。

## 做完后的验证

开赛前核对名单：参赛模型与你勾选的一致、一个不多一个不少；开赛后看两处：排程是否按循环赛逻辑展开（每位选手都有场次）、积分榜是否随对局结果在动；跑完看座次：积分榜排定的名次与各场胜负对得上账。三处都正常，这届锦标赛就办得干净利落。

## 这些边界要心里有数

规模即成本：循环赛的场数随参赛人数膨胀，云端模型的额度消耗同步膨胀，睡前开赛的仪式感很美，早上的账单要认。弱选手拖节奏：废招多、延迟高的模型会拖慢整届赛程，单场观感也打折，名单宁缺毋滥。中途干预空间有限：排程定了就自动推进，想中途换人、调赛制，以应用内实际支持为准，稳妥做法是开赛前把名单一次配齐。积分榜反映的是这一届名单内的相对成绩，不能直接外推成「某模型全面强于某模型」——换批选手、换个玩法，座次可能重排。

## 高频疑问

### 锦标赛收费吗

软件 MIT 开源免费。参赛的云端模型按 API 用量向厂商付费，规模越大消耗越多；Ollama 本地模型参赛则零成本。

### 一届锦标赛要跑多久

取决于参赛模型数、玩法类型与各家的出招延迟，人数翻倍时长翻倍不止，思考型模型多的名单更要留足时间。睡前开赛、早上收报是个被验证过的节奏。

### 两个模型能办锦标赛吗

循环赛两人就是单场对决，办起来意义不大；锦标赛的乐趣随人数展开，建议三五个起步，多人牌类玩法按玩法要求凑桌。

### 可以中途加模型吗

开赛前配齐名单是稳妥姿势；中途调整能不能支持，以 0.1.0 应用内实际能力为准。名单是赛事的地基，动地基不如重开一届。

### 积分榜的积分怎么算

按各场对局结果累计，具体计分细则以应用内呈现为准；榜单实时刷新这一点是确定的，名次变化随每场结果即时可见。

锦标赛创建的全部动作，浓缩起来就是：把人配齐、把名单勾好、按下开赛。循环赛自动排程接手了所有繁琐的组织活，积分榜实时刷新接手了所有的记分活——你要做的只剩两件事：决定让谁上桌，以及睡前别忘了点那一下。
