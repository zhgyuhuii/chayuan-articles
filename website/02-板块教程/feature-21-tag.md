# 一文读懂标签聚合页｜实操教程

标签聚合是察元AI 能力广场里使用频率很高的一项能力。它的「标签聚合页」这样工作：受控词表的标签聚合页：同一主题跨板块资源汇总（≥20 条资源的标签才进 sitemap）。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

受控词表的标签聚合页：同一主题跨板块资源汇总（≥20 条资源的标签才进 sitemap）。

从任务视角看，它对应的关键词是「标签聚合」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 点击任意标签进入聚合页
2. 浏览同主题资源
3. 配合筛选细化

## 适用场景

- 主题式研究

## 实用技巧

- 标签页是按主题找资源的捷径

## 注意事项与边界

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 政企可私有化部署（Docker），数据自主可控

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。
