# ✨Dock 与窗口管理隐藏用法｜Dock栏一次讲清

用过察元OS的宝子看过来，Dock 与窗口管理这个功能很多人没用到极致👇

✅ **它能干嘛**

Dock 支持位置/自动隐藏/放大效果/图标三挡大小、分组（徽章+溢出计数）、Windows 式最小化磁贴；多窗口可拖拽、多屏切换。

🔍 **三步用起来**

1️⃣ 拖应用到 Dock 固定
2️⃣ 右键调整 Dock 设置
3️⃣ 多窗口自由排布或磁贴收纳

💡 **什么场景最香**

· 多应用并行的重度使用

📌 **避坑提醒**

⚠️ 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

🛠️ **更多它擅长的事**

· **壁纸库与主题**：205 张 HD 壁纸库（含明暗与主题元数据）+ 动态壁纸/视频壁纸设置，深浅主题切换、界面缩放 85%-130%。
· **终端与文件管理**：zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

⚠️ **断网也能用？这点很关键**

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
