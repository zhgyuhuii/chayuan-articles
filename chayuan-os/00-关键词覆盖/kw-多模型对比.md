# 模型配置可一键写入五家：多模型对比概念与上手

同一个问题分别问两个模型，答案常常不一样——多模型对比要的就是这个「不一样」。这篇把宠物群聊里的多模型讨论机制讲透：建群三步、两种协同方式、节奏控制与常见坎。

## 什么是多模型对比

多模型对比指让多个模型围绕同一命题各自作答或接力深化，再对照着看分歧与共识。落到产品上，察元AI OS（Chayuan AI OS，简称察元OS）提供了现成场地的宠物群聊：这套 AI 桌面操作系统以完整桌面环境为壳，本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论、系统级 MCP 控制面收在壳内，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）与 Docker 云桌面形态，断网可用、数据不出本机。

## 在察元AI OS里落在哪

多模型对比在察元AI OS里的落点是宠物群聊（多模型讨论）：群名加勾选至少两只成员，选协同方式，可选群分区（桌面出图标双击进群），发一条命题，多个大模型开始围绕它讨论。

单个模型有偏好也有盲区，让几个模型各自作答或接力深化，做方案对比、头脑风暴、交叉验证都直观。

## 第一步：打开应用

点 Dock 上的「宠物群聊」图标：

1. 左栏：顶部两个按钮——蓝色「建宠物」和「建群」；其下是群列表（一个群都没有时显示「还没有群，点上方「建群」」）；栏底显示「宠物 {n} 只」计数；
2. 主区（未选群时）：中央提示「建两只宠物、建一个群，发一个命题，看它们讨论」。

## 第二步：打开建群表单

点「建群」，弹出标题为「建群」的表单弹窗。自上而下五个字段：

| 字段 | 说明 | 默认值 |
|---|---|---|
| 「群名」 | 群聊显示名；留空创建时自动用「宠物群」，超长按 24 字截断 | 空 ＞ 「宠物群」 |
| 「协同方式」 | 两个按钮：「并行」「串行」——选中者蓝底白字。选「串行」时下方出现说明「按顺序逐个接力发言（后手看得到前手输出）；一轮完成自动开下一轮，无休止讨论直到「结束讨论」或关闭接力」 | 「并行」 |
| 「群分区」 | 下拉：第一项「自动（推荐）」+ 已有分区列表；旁边「+ 选择文件夹…」按钮（桌面形态支持时显示）可现场挑/建文件夹。选定后表单出现提示「已选定分区：桌面将出现该分区图标，双击可打开群聊」 | 「自动（推荐）」 |
| 「群默认知识库」 | 下拉：「不绑定」+ 本机知识库列表；下方提示「成员发言时自动检索；群库优先级最高（挂了群库全员都用群库），未挂时用各宠物绑定库」 | 「不绑定」 |
| 「选择成员」（≥2） | 灵宠复选卡组（头像+名字），勾中的卡片蓝框高亮 | 无勾选 |

## 第三步：选分区（可选，决定桌面图标）

1. 保持「自动（推荐）」：引擎把群分区收进隐藏目录（Workspaces/.pet/groups/<群名>-<短码>，附件也落这里），桌面不出现分区图标；
2. 从下拉选一个已有分区，或点「+ 选择文件夹…」在系统对话框里选/新建文件夹：
    1. 该分区成为群的可见工作区，桌面出现这个分区的图标；
    2. 双击桌面上的分区图标 = 直接打开宠物群聊并定位到这个群；
    3. 事后在群管理面板也能换分区。

## 落点的能力面

- 模型直跑宠无角色卡也能入群
- 群分区桌面直达
- 成员随时增减

## 讨论模式与节奏控制

- 串行讨论：串行模式按灵宠档案创建顺序逐个接力，上一只说完下一只才开口，后手锚定前手发言接着说
- 并行讨论：并行模式下全员同轮各自作答、互不等候，各自的思考中状态条与流式气泡同时出现
- 群聊讨论控制：控制条管理讨论节奏——自动接力（带停滞保护）、共识模式（达成一致自动停）、视角讨论等

## 建群前把边界过一眼

- 设备内存 8GB 时，同时只开一个对话模型，复杂任务受限
- 龙芯平台还不在支持之列；本地不做视频生成，视频生成交给云端路由
- 调云端厂商模型前，把自己的 API Key 准备齐全
- Docker 云桌面、跨终端互联这类进阶形态，多少要会点折腾

群聊是多模型场景，内存账要按同时在跑的模型数算，这四条先核再建群。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 建群路上的五个坎

### 「创建」按钮点不动？

两个原因：勾选成员少于 2 只（表单字段名写明「选择成员（≥2）」），或一只灵宠都没有（先点左栏「建宠物」）。

### 勾了七八只成员，为什么群里只有 6 只？

引擎建群时成员最多取前 6 只（按勾选顺序）。想让特定灵宠进群，先勾它；建群后在 群管理 ＞ 「+ 添加成员」 里补加不受这个 6 只上限约束。

### 桌面上没看到分区图标？

分区选「自动（推荐）」时不产生桌面图标（目录收在隐藏根里，附件照常落盘）。想桌面可见：打开群管理面板，把「群分区」从「自动（推荐）」换成具体文件夹。

### 8GB 内存能装吗？

能。装轻量包，一次只加载一个对话模型；重活交给云端模型（需自备 Key），日常对话与知识库检索本地跑得动。

### 能和原有系统共存吗？

能。察元OS 是独立桌面应用，不动原有系统；不需要重装系统或分区，装完即用，不想用直接卸载。

## 一句收束

多模型对比的价值不在「多」，而在「对照」：同一命题下的分歧与共识，比任何单模型的自信回答都值得看。建群细节回看前文三步；翻车现场先查「建群路上的五个坎」，多数问题一查一个准。
