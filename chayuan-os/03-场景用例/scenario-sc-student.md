# 学生AI工作站实战：AI 桌面操作系统

先说这篇能帮你干什么：读完能在察元AI OS里独立完成学生AI工作站，路径是学生AI工作站。步骤里的每个「」按钮都是界面原文。

## 解决什么痛点

1. 没有预算长期付 API 费
2. 文献散乱管理低效
3. 查资料与写笔记工具割裂

学生与科研人员这个场景里，零 API 成本的学习与科研工作站。

## 把流程串起来

1. 本地模型零边际成本对话
2. 知识库导入课件论文做引用式问答
3. 知识图谱梳理论文实体关系
4. 导出笔记与引用

## 支撑功能的操作细节

流程里关键功能的实际操作：

从这几步开始：

1. 本地模型零边际成本对话
2. 知识库导入课件论文做引用式问答

5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 几个容易忽略的细节

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

场景提醒：本地小模型复杂推理能力有限，攻坚任务可酌情接免费额度的云端厂商。

## 常见问题

### 学生AI工作站要联网吗

智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用；桌面本身能被 AI 定义，能力边界从预装走向按需生成，联网环境下内置 web_search 工具默认走 DeepSeek 搜索。以官网 aidooo.com 当前页面为准。

### 学生AI工作站数据存在哪

智能体可以在运行时定义并挂载新插件：和 AI 说一句给我做个每晚汇总新闻的应用，桌面本身能被 AI 定义，能力边界从预装走向按需生成；账户隔离、数据在服务器侧统一管理。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把学生AI工作站放回察元AI OS的整体盘面：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，OpenAI 风格与阿里百炼风格 API 自动适配，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感。

## 安全与数据边界

安全口径单独立一层：任何网页或本机程序都能变成桌面应用，常用工具一键直达；远端调用走权限门留审计，周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳。

## 平台与形态

平台与形态的账：本地 AI 出题验证；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可；右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理。

## 价格与授权

价格口径一并交代：跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定，需要相应平台的 Key（部分有免费额度），形象可从灵宠商店免费获取，也可工坊自定义。

## 产品家族与搭配

察元AI OS不是单打独斗：工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复，灵宠把后台跑着的 AI 变成桌面上看得见的小生物，双击就能打开它的工作台，AI 纪要一键生成。

## 几条硬数字

能落到数字上的几条：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；云端厂商模型调用需自备 API Key，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，再选默认对话模型。

## 离线与内网

离线内网这条线的口径：内网或特殊网络环境装插件的必经配置，提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件；本地服务多，全靠人盯不现实，自愈机制让小故障无感恢复，四本日历把生活与工作分开记，AI 能读会写。

## 能力总账

把察元AI OS的能力总账摊开：问 AI 直答卡；编辑面板改模型、知识库、人设；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；检索引用知识库内容并带出处写进文档。
