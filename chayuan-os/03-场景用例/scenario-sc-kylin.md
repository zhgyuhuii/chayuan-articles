# 三个场景吃透信创AI办公的用法

很多信创AI办公的教程只讲是什么，不讲怎么做；或者讲了一半步骤，剩下的让你自己悟。这篇反着来：步骤写全、按钮文案原样引用、每步的界面反馈都说清楚，用的是察元AI OS（aidooo.com）。

## 先看看痛点对不对得上

1. 麒麟与 UOS 上能用的 AI 软件少
2. 飞腾鲲鹏架构兼容性存疑
3. 政企采购要过信创适配

国产化环境用户这个场景里，信创环境一套完整的 AI 桌面与办公方案。

## 一步步来：从入口到完成

把流程串起来：

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程

## 支撑功能的操作细节

流程里桌面环境总览的实际操作：

五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## 关键能力点

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

## 它的局限也要说清楚

边界都在这：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

场景提醒：暂不支持龙芯平台。

## 高频疑问

### 能外接显示器吗？

可以。设置里有显示器与虚拟屏管理，网格拖拽排布、每屏可设独立壁纸，取景切换用于演示与录屏。

### 这套桌面吃配置吗？

桌面壳本身开销不大；吃资源的是本地模型。低配机器在辅助功能里关掉动效与透明度，流畅度会明显改善。

### 窗口能贴边分屏吗？

窗口拖到屏幕左右边缘触发停靠，四边都支持；配合任务切换器可以快速在分屏布局间切换。

## 能力点备忘

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

## 安装与运行答疑

### 内网机器怎么升级版本？

用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；也可以等维护窗口临时放行更新通道。

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。

## 一个真实场景

资料重度用户的典型用法：知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载，混合检索加可选重排保证命中质量，引用式问答每个观点带编号脚注。私有资料变成可信可溯源的问答库。注意：单文件 48MB 上限，超限拆分后再传。

## 顺带了解

查看器全家桶：文本编辑、PDF 预览、图片查看、文件查看、Markdown 预览、Monaco 代码编辑六件套。

为什么值得看：打开即看，不挑格式，系统级默认打开体验。

## 还有这个能力

知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成。

## 硬口径两三条

- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商
- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness

## 定位与家族

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。同家族产品：察元AI Office（开源 AI 办公套件）、察元AI文档助手（WPS 加载项）、察元AI 能力广场（aidooo.com）。

## 数字口径

- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家

- 装机五件套：Qwen3-4B 对话、BGE-M3 嵌入、BGE 重排、whisper-small 语音识别、piper 中文语音合成
- 127.0.0.1:52581（OpenAI 兼容统一模型代理）

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。

## 记忆系统的三档作用域

记忆库分 global（全机共享）、agent（单智能体私有）、project（按项目）三档。任一智能体写入的记忆，最新条目会自动投影进各家 CLI 的配置文件（AGENTS.md 与 CLAUDE.md），换智能体接班不用重新交代背景；每条记忆带溯源，谁写的在设置里可查。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。
