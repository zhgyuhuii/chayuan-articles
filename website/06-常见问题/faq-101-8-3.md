# 能力广场FAQ：搜索与筛选 8 问

把搜索与筛选 8 问相关的高频问题集中回答，一篇看完，省得一个个搜。每个回答都给到可操作的结论。

## 快问快答

**1. 怎么订阅模型活动？**

活动板块支持 RSS 订阅，聚合 31 家厂商源的促销与发布动态。

**2. 搜不到想要的资源？**

尝试更换关键词（中英双语都试）、放宽筛选；确实未收录的资源可通过投稿页提交，进入人工审核队列；也可询问右下角机器人客服。

**3. 资源数量有多少？**

能力广场总条目 2.5 万+（站方口径，页面实时计数展示）；教程库 2.1 万+ 条；技能包 311 个；助手目录 4526 个助手/228 个领域；API 价格表 40 厂商 201 个模型条目。

**4. 模型价格信息准吗？**

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。

**5. 手机能用吗？**

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。

**6. 网站技术栈是什么？**

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

## 一条通用排查思路

绝大多数问题出在三层：环境层（安装与版本）、配置层（模型端点与密钥）、用法层（入口与步骤）。先分层再定位，比盲目重装效率高得多。

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 政企可私有化部署（Docker），数据自主可控
- 网站不存任何二进制文件，安装一律跳转原始地址
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 常见问题
### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。
