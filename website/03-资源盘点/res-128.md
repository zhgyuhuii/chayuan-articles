# 能力广场专题｜插件与技能怎么搭配

插件与技能怎么搭配。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：Harness 插件板块（Harness插件）、Skills 技能板块（Skills技能）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**Harness 插件板块**：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。

1. 首页 ?k=plugin 或导航进入板块
2. 按分类/标签/排序筛选
3. 打开详情复制一行安装命令

**Skills 技能板块**：可装进 Harness 类智能体的大模型技能包目录：SKILL.md 形态技能的发现与安装入口。

1. 进入 skill 板块
2. 按领域或热度筛选
3. 复制安装命令或仓库地址

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 政企可以私有化部署吗？

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。
