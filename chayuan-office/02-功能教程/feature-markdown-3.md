# 三个场景吃透知识图谱实操的用法

上周有同事问我：知识图谱实操这块到底该怎么弄。他折腾了半天没找到入口，其实不是功能难用，是没人把路径讲清楚。这篇就把Markdown 编辑从入口到收尾完整过一遍，用的是察元AI Office的真实界面，照着点就行。

## 先看看痛点对不对得上

笔记里要贴大量截图，希望图片自动传到自己的对象存储/图床，而不是堆一堆本地文件；用 Markdown 记笔记，想让笔记之间像 Wiki 一样互相链接、跳转，并看清整张知识网络，笔记是纯文本，担心编辑器「重新排版」把没动过的段落格式改乱（列表符号、转义符被改写），或担心 git diff 一片红；个人知识库。

用户常搜的问法：Markdown 里输入两个左中括号弹出的菜单是干什么的？能不能像 Obsidian 一样双链；反向链接和关系图谱在哪里打开。

## 从打开到做完的每一步

1. 认识工具条（编辑器顶部两行）

1. 快捷行：保存（⌘S）、「另存为…」、撤销、重做、「查找和替换 (⌘F)」、「自动保存」开关（悬停提示「自动保存(每 30 秒及窗口失焦时)」）；
2. 样式下拉：正文/标题 1～标题 6/引用/代码块；
3. 行内格式：「加粗」「斜体」「删除线」「高亮」「行内代码」「链接」（弹出「输入链接地址」输入框 + 「应用」按钮）、「复制块链接」；
4. 列表：无序列表/有序列表/任务列表；
5. 插入：「插入表格」「插入图片」「图床设置」「分隔线」；
6. 右侧一组：「属性」（文档属性/front matter）、「大纲」、「源码」、「文档主题」（默认（跟随文档主题）/Notion Light/Notion Dark/Drake Dark/Blubook/Nord/Newsprint）、「反向链接」、「标签」、「关系图谱」、「拼写检查」、「选中文字后右键，即可对 AI 隐藏。」。注：「源码」按钮当前版本点击后仅切换按钮自身状态，原始 Markdown 文本面板尚未在主界面呈现。
7. 工具条可「折叠功能区」/「展开功能区」。

2. 斜杠菜单与块操作

1. 空行输入 /：弹出斜杠菜单，可按关键词过滤（如输入 mermaid），项包括：正文、标题 1～3、无序/有序/任务列表、引用、代码块、插入表格、分隔线、公式（LaTeX）、图表（mermaid）、时序图（wavedrom）、脚注、插入图片（插入图片仅已保存的文档有此项）；
2. 每个块左侧的拖拽手柄：「拖拽移动，点击打开菜单」——菜单含「在下方添加」「复制块」「上移」「下移」「删除」；
3. 表格上右键/菜单：「上方插入行」「下方插入行」「删除行」「左侧插入列」「右侧插入列」「删除列」「切换表头行」「删除表格」；
4. 双击图片打开图片查看器（放大/缩小/实际大小/适应窗口/图片另存为…）。

3. 双链（Wiki 链接）

1. 输入 [[：弹出笔记建议菜单，列出笔记库中的笔记，方向键选择、Enter 补全；支持 [[笔记]]、[[笔记|别名]]（正文只显示别名）、[[笔记#标题]]（落到指定标题）、[[笔记#^块id]]（落到指定块）；
2. ![[ 开头是嵌入：把目标笔记/图片整块嵌进当前页；
3. 建议菜单里没有匹配项时，会出现「新建笔记」——点击后按输入的名字建文件并把链接补全成能解析的写法（目录会保留，如 [[文件夹/笔记]]）；
4. 指向不存在文件的链接会标注「找不到 {target} 对应的文件」；
5. 选中一个块后点工具条「复制块链接」，剪贴板得到形如 [[笔记#^id]] 的链接（提示「已复制 {链接}」）；光标处没有可链接的块时提示「此处没有可链接的块」。

4. 反向链接、标签、大纲

1. 点工具条「反向链接」：左栏列出「链接到当前笔记」的笔记，点击行打开对应笔记；笔记在别处被改动后点窗格头部的「刷新反向链接」重扫；
2. 点「标签」：左栏列出笔记库里的 #标签 及各自关联的笔记（库里还没有标签时显示「知识库里还没有 #标签」）；
3. 点「大纲」：左栏列出本文标题，点击跳转对应段落（无标题时按钮置灰）。

5. 关系图谱

1. 点工具条「关系图谱」：整库链接关系画成一张力导向图——当前笔记高亮；拖动节点挪位置、拖背景平移、滚轮缩放、单击节点打开该笔记；「关闭图谱」退出；
2. 图谱只读，不改动笔记文件；笔记非常多时提示「笔记太多，图谱只画出了前 {shown} / {total} 篇。」（最多画 400 个节点；库索引上限 2000 篇）。

6. 文档属性（front matter）

1. 点工具条「属性」：文档顶部出现属性面板，直接编辑 --- 围栏之间的 YAML 原文（占位符 key: value）；打开带 front matter 的文件时面板自动展开。属性按原文保存，不做解析改写。

7. 图片与图床

1. 粘贴或拖入图片：配置了图床时先上传到图床（成功后正文里写图床 URL）；上传失败或未配置时改存到文档同目录的 assets/ 文件夹并插入相对路径（toast 提示「图床上传失败，已改存本地：{错误}」）；
2. 点工具条「图床设置」打开设置对话框：「服务类型」三选——「S3 兼容（R2 / OSS / COS / MinIO）」（填 Endpoint/Region/Bucket/Access Key ID/Secret Access Key/路径前缀/公开访问域名）、「SM.MS」（填 API Token）、「GitHub」（填 API Token/Owner/Repo/分支/目录/CDN base URL）；「保存」前校验完整性，缺项提示「配置不完整，无法保存」；
3. 工具条「插入图片」从本机选图，插入相对路径引用（不走图床上传）。

8. AI 辅助

1. 选中一段文字：浮出「AI 修改」入口——写一句「描述想要的修改…」，或点预设条（润色这段文字/精简这段文字/扩写这段内容/修正语法和错别字；表格/任务列表另有专属条），「立即发送」马上执行，「加入队列」先攒着（「待发送的修改」里可定位原文、编辑、清空，「发送 {n} 条修改」一次批量执行）；
2. AI 面板（多会话）见对应教程：可对全文总结/润色/排版、生成思维导图、图片搜索、生成配图、联网搜索；面板会读写文档属性（front matter）。

9. 保存：字节级忠实

1. 「自动保存」按「每 30 秒及窗口失焦时」执行；开关默认跟随 设置＞通用 的自动保存总开关，可在本编辑器单独覆盖；
2. 保存按块拼接：没被编辑的块按打开时的原文逐字写回（列表符号、强调写法、转义、空行、引用式链接/脚注定义、原始 HTML 块都不被重新改写）；换行风格、BOM、front matter、文件末尾换行原样保留——适合把笔记放进 git；
3. 文件被外部程序改过时顶部出横幅「这个文件已被其他程序修改。」/「这个文件在磁盘上已被修改，保存会覆盖那些改动。」，可选「重新载入」「保留我的」「仍然覆盖」。

10. 导出

菜单「文件」（macOS 在系统菜单栏，Windows/Linux 点标签条左侧「菜单」按钮）：

1. 「导出为 Word…」：转成 .docx 保存；
2. 「导出为 PDF…」：按打印排版输出 PDF；
3. 「导出为图片…」：逐页导出 PNG（192 DPI，状态栏显示「正在导出 {count} 张图片…」/「已导出 {count} 张图片到 {目录}」）；
4. 「转换为 Docs 文档并打开」：转成 Docs（docx）编辑器标签直接继续编辑；
5. 「打印」（⌘P）。

## 关键能力点

- 双链与反链
- 关系图谱
- 三图床上传

## 几个容易忽略的细节

用之前要认的账：

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx

## 你可能会问

### 图床上传失败，图片会丢吗？

不会。上传失败时自动改存到文档同目录 assets/ 文件夹并 toast 提示失败原因，笔记保持自包含；修好图床配置后新图片才走上传。

### 粘贴图片提示「请先保存文档，再粘贴图片」？

未保存的草稿没有所在文件夹，图片无处落盘。先 ⌘S 定名保存一次，之后粘贴/拖入的图片会存进文档旁的 assets/ 文件夹（或上传图床）。

### 图谱和反向链接的数据存在哪？要不要手动建索引？

都是派生索引，不在笔记库里写任何文件；打开窗格/图谱时从库里的 [[…]] 链接现算。库在外部被改动后，用反向链接窗格的「刷新反向链接」重扫即可。

知识图谱实操的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
