# 一文读懂云厂商目录（89 家）｜避坑指南

大模型厂商是察元AI OS里使用频率很高的一项能力。它的「云厂商目录（89 家）」这样工作：内置 89 家云厂商与聚合平台目录（国内/全球/聚合/本地四组，含免费额度标记）：DeepSeek、Moonshot、阿里百炼、智谱、火山、OpenAI、Anthropic、Gemini、OpenRouter、Ollama 等。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

内置 89 家云厂商与聚合平台目录（国内/全球/聚合/本地四组，含免费额度标记）：DeepSeek、Moonshot、阿里百炼、智谱、火山、OpenAI、Anthropic、Gemini、OpenRouter、Ollama 等。

从任务视角看，它对应的关键词是「大模型厂商」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 设置→模型供应商目录
2. 按免费额度/价格筛选
3. 填 Key 接入

## 适用场景

- 选型比价
- 薅免费额度

## 进阶技巧

- 免费额度标记帮助零成本试用

## 注意事项与边界

- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 常见问题
### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 免费吗？怎么收费？

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。
