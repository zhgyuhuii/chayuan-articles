# 校对结果问题高频问答：这些疑问一次说清

## 校对结果问题：结论先行

围绕校对，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI文档助手（版本 6.1.2，aidooo.com）整理。文末附预防清单，多数问题的根子都在那三条里。

### 检测报「连接失败： 401 / 403 / 404 …」怎么处理？

- 「401 未授权：请检查 API 密钥是否正确、是否已过期，或该密钥是否有访问权限」＞ 核对 / 重贴密钥；
- 「403 禁止访问：API 密钥可能无权限访问此接口」＞ 检查该 Key 的接口权限；
- 「404 未找到接口（探测 <地址>）：请确认服务已启动、地址正确」＞ 地址写错（多 / 少了 /v1）或本地服务没启动。
失败后该厂商清单行会挂「异常」徽标（悬停显示「最近检测失败：<原因>」）；修复后重新检测成功即自动清除。

### 长文档检查很慢，能提速吗？

检查按块分片进行，默认块长约 6000 字。从工具栏发起的检查要边查边写批注，逐块串行执行；通过文档智能体发起的校对（先出预览、你确认后再落笔）按并发设置执行（默认并发 3，可调 1–8，当前版本这两个参数暂无设置界面）。最有效的提速是给检查指定一个更快的「拼写与语法检查模型」。

### 怎么让校对「只挑问题、我确认后再写批注」？

直接说：「先 proofread_run dryRun 汇总问题，不要改正文；我确认后再写成批注。」dryRun 默认只出问题清单；写批注必须 confirmed:true，钉在具体文字上（含表格内）。

### 重启 WPS 后模型变回第一个了？

选择按复合 id 记忆并校验存在性：若该厂商被停用或模型清单里已无此模型，会回落到列表第一个。恢复启用该厂商即可找回原选择。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找到官方入口，不从二三手教程猜路径
- 模型、权限、依赖这些前置条件先检查一遍再动手
- 边界条款（大小上限、付费范围、平台差异）提前读一遍

## 模板编制五段式

发模板文件加一句话需求后：形状级剖析（LOGO 页码水印判为装饰永不改写）、计划卡确认、副本填充（原模板零修改）、三轮质检自愈（上限四轮）、后台生成完成自动打开。红头文件与标书这类强格式文档最适合这条链路。

## 配图三级降级

第一级模型生图（最多试三个模型），失败走第二级网络搜图（Serper、Tavily、Pexels、SearXNG 免 Key），再不行第三级 SVG 矢量兜底；铁律是上级失败才降级，绝不静默换花钱的来源。

## 校对的执行机制

有选中只查选中，无选中确认后查全文（超 12000 字与 30000 字分档提示）；检查在独立进度窗里分块并发执行，块长默认 6000 字，关窗任务继续，只有点停止任务才中止；结果批注锚定原文，锚不上的不硬挂。

## 表格与演示的直达按钮

表格端九大按钮（AI 表格助手、公式助手、数据洞察、一键图表、数据清洗、报表结论、一键美化等）配 66 个配方；演示端从生成 PPT 到口播稿、整套校对、结构诊断齐备，配 81 个配方，课件与习题页生成也在菜单里。

AI 分块研判八大类风险（密级标识、涉军涉装涉训、组织身份、人员联络、时间地点部署、内部编号、经营商业敏感、军工政企高频线索），高中风险分级加待人工复核；判据是语义与上下文，关键词只是线索而非结论，完整报告进任务清单。
