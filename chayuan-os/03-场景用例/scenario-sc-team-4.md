# 从需求到交付：云工位

云工位这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决云工位。

## 为什么值得了解

1. 每人配一套 AI 工具成本高且不统一
2. 资料分散在个人电脑

一台服务器全组使用，配置与数据集中管理。

## 把流程串起来

1. 共享模型代理与知识库，配置统一
2. 常驻任务统一跑巡检与日报
3. 服务器 Docker 部署察元AI工舱云桌面

## 支撑功能的操作细节

流程里关键功能的实际操作：

上手按顺序做：（第 4 个切入角度）

1. 服务器 Docker 部署察元AI工舱云桌面
2. 员工浏览器打开即用，账户隔离
3. 共享模型代理与知识库，配置统一
4. 常驻任务统一跑巡检与日报
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

场景提醒：需要一台性能尚可的服务器与基本的 Docker 能力。

## 接着回答几个常见问题

### 云工位要联网吗

设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，联网环境下内置 web_search 工具默认走 DeepSeek 搜索，断网时联网搜索自然不可用。以官网 aidooo.com 当前页面为准。

### 云工位数据存在哪

升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离、数据在服务器侧统一管理，断网可用、数据不出本机；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把云工位放回察元AI OS的整体盘面：智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，智能体动系统能力分级确认：T0 只读直放，任何网页或本机程序都能变成桌面应用，常用工具一键直达；能力不是写死在系统里的，是从商店长出来的，越用越全；壁纸是最直接的个性化出口，动态壁纸让桌面活起来。

## 安全与数据边界

安全口径单独立一层：远端调用以远端访客身份过对端权限门并留审计，API Key 用 safeStorage 加密存储，遥测可整体停用，模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址。

## 平台与形态

平台与形态的账：每次产出 markdown 报告落盘归档；markdown 报告归档；（web/Docker 形态网页桌面默认端口）；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 价格与授权

价格口径一并交代：预授权窗口夜间放行；提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件，购买 OS 授权后，同机察元AI Office 自动免激活；免费下载使用，购买只停提醒、不锁功能。

## 产品家族与搭配

察元AI OS不是单打独斗：购买 OS 授权后，同机察元AI Office 自动免激活；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 几条硬数字

能落到数字上的几条：local 星号开头的本地模型未运行自动加载；让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；本地模型按需自动加载，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。

## 离线与内网

离线内网这条线的口径：本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队；本地模型多宠同发会排队（本地档 4 路并发上限）；设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商）；首次下载约 2GB 权重，本地出图速度取决于硬件。

## 能力总账

把察元AI OS的能力总账摊开：保存后随系统技能分发到智能体；设置结果分发到智能体侧，本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，还有可复制的各家智能体配置片段。
