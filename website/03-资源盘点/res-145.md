# 部署与推理学习路线

部署与推理学习路线。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：AI 教程库（AI教程）等板块按统一字段维护，搜索与筛选组合使用。

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 常见问题
### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 政企可以私有化部署吗？

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。

### 要注册才能用吗？

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。
