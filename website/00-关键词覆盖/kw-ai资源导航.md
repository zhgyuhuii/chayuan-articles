# AI资源导航入门指南：万+ 资源一站检索

AI资源导航这个词，先拿一个筛子过一遍：断网了它还能干什么。这篇顺着这个标准，把察元AI 能力广场的能力面与边界摊开说。

## 什么是AI资源导航

AI资源导航指向的产品是察元AI 能力广场：插件、技能、MCP、提示词、大模型资源在一个门户里检索与下载。

文中数字与版本信息核对自官方文档，尾注标了截止时间。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| 八大板块 | Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型、模型厂商、资讯；另有技能包商城 |
| total | 10 万+ 资源一站检索（站方口径） |
| tutorials | 教程库收录 21291 条学习资源（arXiv 13037、GitHub 7309、B站 783、Awesome 106、精选 56），只存元数据与跳转链接不搬正文 |
| assistantGuides | 4526 篇内置助手教程，按 228 个行业领域分目录 |

表格里的两类口径要分开读：总量是站方说法，教程库那 21291 条是可拆解到来源的明细——前者看盘子，后者看功课，后者往往更能说明问题。

## 能跑在哪些端

网页端直接访问；桌面产品可从站内下载 Windows/macOS/Linux（含麒麟/UOS）安装包。

## 智能广场总览

AI资源导航的落点是智能广场总览，三栏走法：资源类型装了就用（智能体、MCP、插件、技能、教程库、提示词、技能包）；模型中心查资料（大模型目录、模型厂商、模型智力排行、免费模型榜）；发现逛与买（开源榜单、资讯、折扣活动）；站方口径 10 万以上资源一站检索。

生态分散在 GitHub、npm、各家市场，带排行榜的聚合入口能省下大半翻找时间，这是它存在的理由。

## 最短上手路径

照下面四步走：

逛广场的基本姿势

1. 浏览器进门户，导航里点智能广场
2. 按资源类型进对应板块（如 MCP、插件）
3. 关键词检索或按分类浏览
4. 点进详情页查看说明、安装方式与榜单排名

## 三个设计要点

- 八大板块聚合检索
- 三栏动线设计
- 移动端底部 Tab 适配

三条设计里最容易被低估的是移动端适配：查资源常常发生在通勤路上，底部 Tab 把常用入口压到拇指可及的位置，核心浏览与下载流程在手机上是完整的。

## 各板块的底细

- 智能广场总览：三栏动线，见上一节
- MCP 板块：收录 MCP 服务器资源，数据来自多源采集
- 插件板块：对齐 DeepSeek Harness 插件市场的官方分类
- 技能板块：收录 SKILL.md 形式的智能体技能，采集自社区精选与技能仓库
- 提示词板块：聚合多源提示词（AiShort、prompts.chat 等，中英去重），按用途分类检索
- 智能体应用板块：收录可直接使用的形态资源，配合产品使用或独立运行

板块虽多，日常真正用得勤的往往就两三个。建议先在每个板块都点一圈，找到自己的高频板块后再深挖，比平均用力划算；判断标准很简单——哪一栏你一周内主动进了三次以上，它就是你的主阵地。

## 边界放在明处

- 榜单基于 GitHub star 快照，失效（dead/archived）条目自动出局
- 教程类条目只当目录，正文在源站
- 安装包下载以登录为前提，账号或微信扫码

三条都不致命，但先用先知道。多说一句榜单快照：star 数反映的是关注量而非质量，小众但好用的项目可能沉在榜尾，翻榜单别只盯着头部。

## 账号与内容治理

- 站内账号、微信扫码两种登录方式，收藏上限 200 条
- 投稿与需求墙内容先审后上
- 安装包清单由管理后台同步生成，官方分发渠道之外不认

## 高频问答

### 能力广场的资源总量有多少？

站方口径是 10 万以上资源一站检索，覆盖插件、技能、MCP、提示词、智能体应用、大模型、模型厂商与资讯八大板块，另加技能包商城与教程库。

### 需要注册才能用吗？

浏览与检索免注册；下载安装包、收藏、投稿需要登录，支持站内账号与微信扫码两种方式。

### 移动端能用吗？

可以，移动端有底部导航（广场、榜单、产品、更多、我的），核心浏览与下载流程都适配了。

### 下载安装包需要登录吗？

需要。完成站内账号或微信扫码登录后即可下载，登录后还能收藏资源与管理下载记录。

### 怎么确认下载的是官方安装包？

下载页直链由管理后台自动同步生成，官方分发入口就这一处；第三方站点的镜像包不建议使用。

## 一句收束

导航站好不好，拿「找东西的次数」衡量：十次有八次直达，它就配当首页；一半都在绕路，趁早换。

## 三栏动线怎么走

1. 先走「装了就用」那栏挑资源：插件、技能、MCP 直接进对应市场
2. 再走「查资料」栏：模型目录、厂商页、智力榜与免费榜
3. 最后逛「逛与买」栏：榜单发现新品，资讯页看动态
4. 登录后收藏常用条目，下次从我的收藏直进

三栏的分工其实是三种心态：带着明确目的直奔装了就用那栏，做功课去查资料栏，闲下来才去逛与买。把三种状态分开，才不会在查资料的时候被折扣信息带偏。

## 退后一步看全局

MCP 板块装的是 MCP 服务器资源；这类生态更新频繁，靠收藏夹追不动，持续同步加自动剔除失效，才跟得上节奏；OS 应用商店同源可直装，同源的含义就是商店里的资源与广场收录保持同一来源口径，直装走的是这条路。

智能广场总览这件事，真机走一遍比读十遍文章记得牢，何况走一遍只要几分钟，四步清单就是为此准备的。
