# Office Linux安装装机指南：三平台五形态安装包

Office Linux安装的麻烦不在功能本身，在于信息散。deb、rpm、AppImage 三种形态各有适用场合，离线装机与信创适配的口径也散落在各处；这篇文章把散的信息收拢到一条可以照着走的路线上。

## 安装前确认

- 系统要求：deb/rpm/AppImage；AppImage 需 glibc 2.34+
- 安装包：deb/rpm/AppImage（x64/arm64）
- 说明：deb rpm AppImage 三形态。

包文件只从官方发布渠道取；第三方下载站的包无法保证与官方一致。

## 一步步来

1. 官方渠道下载对应包
2. deb 用 dpkg -i，AppImage 加执行权限直接运行
3. 麒麟/UOS 走 AppImage 加 deb，免 root
4. 配合本地模型端点可实现离线办公

三形态怎么挑，可以按机器的「归谁管」来分：走统一运维、依赖包管理器记账的，deb 装进系统由 dpkg 管理，升级卸载都有据可查；rpm 同理，适合 Fedora 系；AppImage 则是单文件自包含，拷到哪台同架构机器上给个执行权限就能跑，系统里不注册条目，特别适合共享目录分发或临时替某台机器补装。x64 与 arm64 两种架构都有对应包，下载前先 uname -m 确认架构，这是 Linux 装机里最常见也最冤的一种返工。

## 其他平台装法速览

Windows：官方入口下载 exe；双击安装；启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

验证新装环境跑一次最小闭环：模型设置里接厂商 API 或本机 Ollama，随后在开始页建一个 docx 让 AI 输出一段文字；闭环走通，环境即告就绪。

走 AppImage 路线的机器，第一次运行前记得确认执行权限真的加上了：文件管理器里右键属性能看，终端里 ls 也能看。权限没加到位时双击没反应，看起来像「装不上」，实际只差一步 chmod，别急着删包重下。

## 做完后的验证

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

Linux 桌面环境五花八门，个别发行版的窗口管理器对外壳渲染有自己的偏好；遇到界面显示异常，先换一台主流发行版的机器交叉验证，能快速分清是包的问题还是桌面环境的问题，这个定位思路在排障时最省时间。

## 注意事项与真实边界

装包之前把这几条认下来：

- web/dsh 形态只打包五个编辑器、没有 HTML，购买与激活的入口也不在里面

## 常见问题

### 头回启动的三页引导错过了还能调出来吗？

调不出来。引导只在首次启动出现，没有重看入口；想系统摸清功能，F1 的应用内手册（18 主题、可搜索）信息量远大于引导页。

## 各平台的启动方式

第 2 步 · 安装并启动

1. macOS：挂载 dmg，把应用图标拖入 Applications，首次从启动台/应用程序打开；
2. Windows：运行 .exe 安装向导，按提示选择目录完成安装，从开始菜单/桌面打开；
3. Linux：按上表命令安装，或对 .AppImage 加执行权限后直接运行（无需安装、无需 root）。

## 动手前的环境自查

- 操作系统：Windows 10+、macOS 11+、Linux（含麒麟/UOS，AppImage 要求 glibc 2.34+）。
- 能在官方发布页与仓库发布区取到的才算官方包，其余站点的产物一律按来源不明处理。

## 装包形态能力点

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

免 root 在 Linux 上不只是一个权限话题：很多单位的普通账号连 sudo 都没有，软件能不能装、要不要找管理员，直接决定推广阻力大小。这套包型设计把安装动作压缩到普通用户权限内完成，信创环境里「装机不求人」这一点，往往比功能列表更能决定软件铺不铺得开。

## 转换与识别的边界

开始页签的转换下拉共五项：PDF 转 Word、Excel、PPT、Markdown、HTML；扫描页转 PPT 与 Excel 后文字不可编辑；Linux 没有系统 OCR 引擎，扫描页保留位图不识别。转换全部本机完成（PDFium 字符级提取加纯几何版面分析），证书加密 PDF 无法转换。这些限制写在明处，装机前把存量扫描件的需求盘一遍，别装完才发现某类文件转不动。

## 端口与命令行备忘

壳内 MCP 服务端口 52588，把文档操作能力开放成 MCP 工具；知识库五级自动发现，注册表端口 52584，检索上下文预算默认 12000 字；chaoffice 命令行有 17 个子命令，终端里能覆盖不少批量操作。

## 密钥与数据的存放

API Key 存本机 ai-settings.json，不上传，支持环境变量引用；AI 挂了会自动降 9 类本地正则兜底，不至于整个停摆。本地转换意味着合同不出机器，这是与在线转换服务的本质区别。

## 什么情况下还会用到

个人替换订阅制办公软件，政企内网批量装机。

### Linux 机器断网之后还能正常用吗

装包与运行都不依赖联网，配合本地模型端点可以实现整套离线办公；要是模型档案配的是云端厂商，那一路的调用自然要走网络，这是配置决定的事，不是安装形态决定的。

### 它能吃下哪些文档格式

编辑器覆盖六种格式，开始页新建文档时一目了然；转换入口在开始页签，下拉里是 PDF 转 Word、Excel、PPT、Markdown、HTML 五项。扫描件属于位图，转不出可编辑文字，这类文件要提前想好替代流程。

## 一句话压缩

全部要点里最该记住的是「三平台五形态安装包」：先按发行版选对包型，其余步骤都是顺水推舟，各节细节按需要回头查。
