# 一文分清大模型目录：模型多维对比

查模型参数最怕两个坑：信息散、口径旧。大模型目录要解决的就是这两件事——把分散的模型信息收进一份持续同步的目录。这篇讲它管什么、数据从哪来、边界在哪。

## 什么是大模型目录

目录挂靠的主体是察元AI 能力广场：插件、技能、MCP 服务器、提示词、智能体应用、大模型目录、模型厂商、资讯八个板块在线检索，日、周、月、季、半年、年六档榜单配模型智力榜；察元AI OS、察元AI Office、察元AI文档助手、察元AI工舱四条产品线的入口也在此；微信扫码登录、收藏、投稿一样不缺。网页端开浏览器即用，桌面端可从站内下 Windows/macOS/Linux（含麒麟/UOS）安装包。

本文口径整理自官方文档，版本对应关系见文末。

## 三件套的分工

模型中心由大模型目录、模型厂商页、模型对比页组成：目录负责把模型按厂商、能力、价格维度收进可查询的列表；厂商页收录已核验的模型厂商与网关，管定价与接入；对比页支持最多 6 个并排，对比结果链接可直接分享。查参数用目录、核价格用厂商页、做横评用对比页，各走各的门，不用在站点之间来回切换。

## 对比页的四个动作

1. 进入模型中心的大模型目录
2. 勾选参比模型，6 个封顶
3. 打开对比表，能力、上下文、价格尽收一页
4. 对比页链接可复制，随手分享给同事

## 厂商页的四个动作

1. 从厂商名录入手，看哪些厂商与网关通过了核验
2. 以接入方式收窄范围：OpenAI 兼容、网关转发
3. 进到厂商页，看清模型清单与定价口径
4. 选定后按厂商页说明接入

## 用目录时的边界

- 想把资料正文都留在站内的人：教程类条目只到元数据与出处链接，阅读跳回源站
- 想免登录的人：收藏、下载之前需要注册，站内账号或微信扫码皆可，两条路权限一样

边界不复杂，提前知道省得来回折腾；把它当成查资料的规则背下来，后面就不再占用注意力。

## 账号、支付与渠道

- 收藏上限 200 条
- 投稿和需求墙的内容，一律先审后展
- 服务版/至臻版授权在购买授权页统一下单，扫码支付；免费榜按输入价门槛专列
- 官方安装包只放一个入口，直链按平台架构区分，想下错都难；清单由管理后台同步生成

## 目录使用问答

### 目录的数据准吗

目录与厂商页由数据采集链路持续同步，来源含 OpenRouter、models.dev、Ollama 等，参数与价格随厂商更新；拿目录数据做决策前，重要条目建议再核一眼厂商当前口径。

### 手机能逛广场吗

能。移动端底部导航分广场、榜单、产品、更多、我的五栏，检索、榜单、下载与收藏核心动线都做了适配。

### 微信扫码和账号密码登录有区别吗

没有功能差异，同一账号体系；扫码走微信开放平台授权，账号密码走图形验证码，登录后权限一致。

### 智力榜怎么配合目录用

智力排行用五个维度综合打分，单维 0-100 百分位、总分为五维等权均值，配套改提示词与模型选型指导；智力榜看能力上限，免费榜看成本下限，榜单圈范围、目录核细节，配合着用最省事。

## 目录之外值得逛的

- 提示词板块：聚合多源提示词（AiShort、prompts.chat 等，中英去重），按用途分类检索
- 智能体应用板块：可直接使用的应用形态，既能配合产品也能独立运行
- 资讯板块追着模型厂商动态与生态圈消息跑；活动页汇总全球范围的模型折扣；价格变动与新品发布频繁，资讯页是个省心的追踪口
- 榜单排序上，无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先，两类口径并存

## 目录页该怎么读

拿到一份模型目录，读的顺序有讲究：

- 先看维度设计：厂商、能力、价格三类维度决定了筛选自由度，摸清维度再查，不会漏掉冷门但合适的候选
- 再看更新机制：目录的价值一半在及时，数据源持续同步的目录才敢当决策依据
- 最后看联动出口：查到的模型能不能直接跳厂商页、进对比页，联动顺不顺决定你查一次要开几个标签页

这套读法对任何模型目录都通用，不限于本篇介绍的这个。

## 目录能替你做什么、不能做什么

能做的三件：收拢分散的模型信息、统一参数与价格的口径、把对比过程留成可分享的痕迹。

不能做的三件：替你判断任务匹配度、替你实测效果、替你承担长期选型的责任。

三能三不能摆清楚，对目录的期待就落了地——它压缩的是检索成本，不是决策成本；决策那一步，永远要带着自己的任务去做。

## 目录使用的两条心得

- 参数要连着任务看：上下文再长、能力再全，对不上你的任务形态都是摆设，先写需求再查目录
- 查完就留痕：中意的模型记进对比表，链接可分享，过两周模型换代时，有记录的人不用从头再来

目录是工具，判断还在人。把「查—比—记」三步走顺，目录的价值才算吃到位；三步里最容易偷懒的是最后一步，也恰恰是拉开差距的一步。
