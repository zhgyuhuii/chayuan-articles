# 从入口到验证：Harness插件

Harness插件的麻烦不在功能本身，在于信息散。系统装什么能力从插件开始，分类导航降低选择成本。这篇把它收拢成一条能照着走的路径。

## 先弄清楚它是什么

Harness插件在察元AI 能力广场里的形态一句话说清：插件板块对齐 DeepSeek Harness 插件市场的官方分类（AGI 架构探索、UI 增强、用量与计费等），插件按分类浏览与检索，察元AI OS 应用商店同源可直装。

概念一分钟，操作十分钟，这篇都覆盖。

## 实操全过程

挑一个插件

1. 进插件板块按分类筛选
2. 对比下载量与榜单位置
3. 在 OS 应用商店搜索同名插件一键安装
4. 或按详情页说明手动安装

插件装到哪

1. 察元AI OS 用户走应用商店在线安装，与广场同源
2. 内网机器用 .cop.tgz 离线包导入，断网也能装
3. 装完在 OS 桌面或对应宿主里启用
4. 不想要了在商店里停用或卸载
