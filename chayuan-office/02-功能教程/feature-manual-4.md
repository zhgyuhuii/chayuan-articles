# 办公技巧：手册内搜索，别再瞎试

办公技巧这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI Office的真实界面顺序走一遍，先解决断网环境查手册。

## 先定位问题在哪一层

办公技巧的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把无。手册与快捷键面板都随应用内置，离线可用；手册正文按当前界面语言渲染（缺该语言时回退英文，核一遍，再查路径。

## 正确的操作路径

最短路径走一遍：（第 4 个切入角度）

1. 离线手册
2. 全键位表
3. 手册内搜索
4. 场景验证：断网环境查手册
5. 场景验证：系统学一遍快捷键
6. 串联场景：Docs 写正文，察元AI 页签全文校对出批注

## 怎么确认做成了

验证

1. 把界面语言切到 English（设置 通用 语言）再按 F1：手册目录与正文应整体变英文；切回「简体中文」即恢复中文。
2. 在手册搜索框输入「涂黑」：目录应只剩 PDF 相关主题；清空搜索框恢复全部 18 个主题。
3. 在 Docs 编辑器按 ⌘/：弹出「键盘快捷键」面板；切换到 Sheets 等其他编辑器标签页：没有这个面板（该入口仅 Docs 有）。
4. 在任意编辑器按 ⌥⌘R（Windows/Linux Ctrl+F1）：功能区收起，再按一次展开。
