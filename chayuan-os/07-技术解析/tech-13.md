# 拆开看系统技能镜像：六家智能体镜像

系统技能镜像的麻烦不在功能本身，在于信息散。智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。这篇把它收拢成一条能照着走的路径。

## 是什么与为什么

系统技能镜像在察元AI OS里的形态一句话说清：把察元系统能力手册（含动态生成的模型清单）镜像进六家智能体技能目录（dsh、Claude Code、ZCode、Codex、OpenCode、OpenClaw），可统一应用或逐家更新。

入口、步骤、验证三段看清，这事就顺了。

能力面拆开看：六家智能体镜像；统一应用与逐家更新双模式，模型清单动态生成。

## 完整操作步骤

从这几步开始：

1. 六家智能体镜像
2. 模型清单动态生成
3. 统一应用与逐家更新双模式
4. 场景验证：让 Claude Code 直接说换壁纸就换
5. 场景验证：新智能体装完补发技能
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 它的局限也要说清楚

边界先摆在桌面上：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 常见问题

### 应用失败、行下有红色原因？

失败按目标隔离（权限不足、磁盘错误等），其余目标不受影响。按行内提示处理后对该行单独重试「应用」。

## 动手前再核对一遍

- 桌面形态（察元AI OS）：设置 ＞ 系统技能 的管理面依赖桌面桥，网页/开发形态只显示「系统技能管理仅在察元AI OS 内可用（网页/开发形态不提供）。」
- 行内可应用/更新的前提是该智能体已被识别为已安装（未安装的行灰显、按钮不可点，不给没装的 CLI 写孤儿目录）——安装见对应教程。
- 无需手动操作的部分：主进程在启动/切换用户时自动把技能镜像进所有已安装且声明了技能目录的智能体（覆盖面见步骤 5，不止面板上的六家）。

## 放回产品盘面看

把系统技能镜像放回察元AI OS的整体盘面：首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；图片搜索与图库平台支持；需要相应平台的 Key（部分有免费额度），灵宠把后台跑着的 AI 变成桌面上看得见的小生物。

## 安全与数据边界

安全口径单独立一层：远端调用以远端访客身份过对端权限门并留审计；API Key 用 safeStorage 加密存储，遥测可整体停用；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，代理只监听本机回环，跨机访问需要另行打通。

## 平台与形态

平台与形态的账：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作，内置浏览器窗，配合 webwindows 可被智能体驱动；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。

## 价格与授权

价格口径一并交代：数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一，装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平，智能体动系统能力分级确认：T0 只读直放。

## 产品家族与搭配

察元AI OS不是单打独斗：智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

## 几条硬数字

能落到数字上的几条：润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱，指定模型未加载时会按策略自动拉起；local 星号开头的本地模型未运行自动加载，让全机所有 AI 软件共用一套模型配置的关键设计：地址只有一个，模型随便换，客户端无感；本地模型按需自动加载。

## 离线与内网

离线内网这条线的口径：能力不是写死在系统里的，是从商店长出来的，越用越全；技能清单双域（项目/用户）；新桌面系统的肌肉记忆速查，五分钟上手；打开即看，不挑格式，系统级默认打开体验。

## 能力总账

把察元AI OS的能力总账摊开：导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成；在 dsh 会话、灵宠或群聊里说一句查一下知识库里的什么，CLI 智能体经 MCP 自动接入。
