# 能力广场专题｜政务行业 AI 场景导航

政务行业 AI 场景导航。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：行业场景库（行业AI方案）、助手目录（AI助手目录）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**行业场景库**：20 个行业 × 200 个场景的 AI 应用导航：从行业到场景到对应资源的结构化路径。

1. 进入 /scenarios 选行业
2. 浏览该行业场景列表
3. 进入场景看对应资源与方案

**助手目录**：4526 个内置助手、228 个领域的在线目录：与察元AI文档助手/Office 同源，先在网页端浏览再装到工具里用。

1. 进入 /assistants
2. 按领域浏览
3. 找到需要的助手记住名称

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 政企可私有化部署（Docker），数据自主可控
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
