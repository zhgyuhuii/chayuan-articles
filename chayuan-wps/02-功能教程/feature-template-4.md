# 模板库排查路径：全院统一公文模板下发

先说这篇能帮你干什么：读完能在察元AI文档助手里独立完成模板库，路径是全院统一公文模板下发。步骤里的每个「」按钮都是界面原文。

## 先定位问题在哪一层

按这个顺序排查模板库通常最快：先确认前置条件（WPS 文字端，「察元AI编审」选项卡（表格/演示端另有「从模板新建」入口按钮，对话框内按宿主过滤模板）；加载项已启用；），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 模板登记信息存在哪？换机器会丢吗？

模板清单存在本机，不随文档走。换机器请重新「导入模板」登记一次，规则集用「导出规则/规则导入」迁移。

## 正确的操作路径

4. 「下载模板」：把库中模板拷出去

1. 在哪：点「下载模板」。
2. 看到什么：弹窗「下载模板」（420×500），说明「从列表中选择一个模板，点击确定后选择保存位置」；清单即本地模板库（与「导入模板」同一份），空时提示「暂无模板，请先在「导入模板」中添加 .aidocx 模板」。
3. 做什么：选中模板 ＞ 点「确定」（执行中「下载中...」）＞ 弹系统另存对话框（筛选「Word文档 (*.docx)」，默认名 = 模板名 + .docx）＞ 模板文件被复制到你选的位置。取消另存则不做任何事。

5. 「导出规则」：规则集存成 .aidooo 文件

1. 在哪：「规则管理」组点「导出规则」。
2. 看到什么：弹窗「导出规则」（420×480）：顶部搜索框（占位「按名称、标签搜索...」）、「全选」勾选框与「已选 N 项」计数、规则清单（每行名称 + 标签）；底部「保存文件名：」输入框（默认 chayuan_template_年-月-日.aidooo，尾注「（将保存为 .aidooo 格式）」）。
3. 做什么：勾选要共享的规则（可搜索过滤）＞ 点「确定导出」（执行中「导出中...」，未勾选时置灰）＞ 另存对话框（筛选「察元规则 (*.aidooo)」）。文件为带 format: aidooo 头的 JSON。库为空时显示「暂无规则项，请先在规则制作中添加」。

## 做完后的验证

验证

1. 「导出模板」后打开「导入模板」：清单里出现刚另存的文件名；
2. 点「从模板新建」选它 ＞ 新窗口打开同款文档，点保存弹出另存为；「规则制作」里规则齐全（规则随文档走）；
3. 「导出规则」的 .aidooo 文件发给同事，对方「规则导入」后显示「成功：N 项」，其「规则制作」列表多出这些规则。

## 高频疑问

### 「规则导入」说我文件格式无效？

「规则导入」只认 .aidooo 规则文件（JSON，含 rules 数组）。.aidocx 模板文件请走「导入模板」；想看规则内容，.aidooo 本质是 JSON，文本编辑器可直接打开。

## 更多操作细节

6. 「规则导入」：把 .aidooo 文件并回规则库

1. 在哪：点「规则导入」。
2. 看到什么：弹窗「规则导入」（400×320），说明「选择 .aidooo 格式的规则文件，将导入其中的规则项。ID 与现有规则重复的项将被跳过。」
3. 做什么：点「从本机选择文件」（执行中「导入中...」）选 .aidooo（或 JSON）文件。完成后显示「导入完成」：「成功：N 项」「失败（ID重复跳过）：M 项」。文件格式不对时提示「文件格式无效，请选择正确的 .aidooo 规则文件」。导入的规则立即出现在「规则制作」列表里。
