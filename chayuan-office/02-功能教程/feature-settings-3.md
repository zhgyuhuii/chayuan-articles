# 三个场景吃透主题设置的用法

主题设置这件事，说简单也简单，说麻烦是真麻烦——麻烦不在功能本身，在于信息散落在各处，拼出一个完整流程要查好几篇资料。这篇文章把它一次讲全：是什么、入口在哪、具体步骤、边界在哪，全部基于察元AI Office的真实界面。

## 为什么值得了解

分不清某个设置在哪一区（端口、技能、远程存储…），个性化外观，关掉匿名统计、改批注作者名、把应用设为 .docx 默认打开方式；想把界面换成英文/日文等，或觉得深色模式护眼。

用户常搜的问法：界面语言支持哪些？切换要重启吗；应用主题和文档页面主题有什么区别。

## 完整操作步骤

第 1 步 · 打开设置

1. 主页左下角是账号行，行上有一个齿轮图标的按钮（悬停提示「设置」），点击直接打开设置弹窗——标题「设置」，左栏分区导航 + 右栏内容；按 Esc 或点弹窗外遮罩关闭。
2. 首页对话里出现「还未配置 AI 模型」引导卡时，点「打开 AI 设置」打开的也是这个弹窗（落在「模型设置」区）。
3. 十个分区自上而下：模型设置 / 默认模型 / 生图、媒体与搜索 / 本机文件搜索 / 远程存储 / 通用 / 集成 / MCP 管理 / 技能 / 关于。不指定落地分区时默认停在「模型设置」。各专项教程：模型接入见对应教程，本机文件搜索见对应教程，远程存储见对应教程，集成与 MCP 见对应教程/O39/O40。

第 2 步 · 「通用」区逐项（右栏从上到下）

1. 语言——下拉 22 种：العربية / Čeština / Deutsch / English / Español / Français / עברית / हिन्दी / Bahasa Indonesia / Italiano / 日本語 / 한국어 / Bahasa Melayu / Nederlands / Polski / Português / Русский / ไทย / Türkçe / Tiếng Việt / 简体中文 / 繁體中文。即时生效，无需重启：语言先写盘、成功后才切换；主进程随即重建主页菜单与程序坞菜单，并向所有窗口广播语言变更。
2. 主题——「跟随系统」（默认）/「浅色」/「深色」；选跟随系统时不写入固定值，随操作系统外观走。
3. 文档页面主题——「跟随应用主题」（默认）/「浅色」/「深色」：编辑器画布/纸面的用色。想保持纸面永远是白纸黑字，就固定选「浅色」，与界面深色互不影响。
4. AI 侧边栏位置——「左侧」（默认）/「右侧」。
5. AI 面板文字大小——「默认」/「大」/「特大」/「自定义」；选「自定义」出现 px 数字框（失焦或回车提交，超范围自动夹紧）。
6. 用户名——文本框，说明原文「作为批注和修订的作者显示在 Docs、Sheets、Slides 中。留空则使用电脑账户名。」；最长 120 字符，失焦或回车保存，占位符即电脑账户名。
7. AI 对话拼写检查——开关，默认开；「在 AI 对话输入框中输入时标出拼写错误的单词。」
8. 显示 AI 侧栏——开关，默认开；关闭后编辑器隐藏 AI 侧栏和侧边按钮，功能区/菜单里的 AI 操作仍能打开面板，新文档也不再自动打开。
9. 新文档中打开 AI 面板——开关，默认开；关闭后新打开的文档默认收起 AI 面板。
10. 设为 Office 文档默认程序——按钮「设为默认」（Windows 上为「打开系统设置」，由系统面板完成）；说明「双击 .docx、.xlsx、.pptx 文件时用 察元AIOffice 打开。」；已是默认时显示「察元AIOffice 已是默认程序。」，被别的程序占用时显示「当前默认程序：{app}」。
11. 默认保存位置——显示当前文件夹（未设时显示「—」），右侧「更改」按钮选择新目录。
12. 所有文档自动保存——开关，默认关；「在每个编辑器中默认开启自动保存，仍可在单个窗口中关闭。」
13. 启动时重新打开上次的文档——开关，默认关；「关闭 ChaAI Office 时打开的文档会在下次启动时自动重新打开。」
14. 休眠不活跃的标签页——开关，默认开；「标签页多到一定数量后，长时间没有查看的会释放内存；回到它时会重新打开文件。有未保存修改或已固定的标签页不会休眠。」
15. 发送匿名使用统计——开关，默认开；「该功能默认开启，可随时在"设置 ＞ 常规"中关闭。使用 Google Analytics 4；Google 会接收您的公网 IP 地址和传输元数据，但绝不收集文档内容或文件名。」

第 3 步 · 「关于」区（版本与更新）

1. 版本：显示当前版本号。
2. 可用更新：发现新版本时出现按钮「更新到 {version}」，下载中变为「正在下载更新（{percent}%）」，完成后「重启并安装」。
3. 更新通道——「稳定版」（默认）/「Beta 版」。
4. 自动检查更新——开关，默认开；关闭后「启动时和后台都不再检查新版本；仍可在"帮助 › 检查更新"中手动检查。」
5. 开源项目：显示 github.com/zhgyuhuii/ChayuanAIOffice 与 Star 数，按钮「去 GitHub 点 Star」。

## 几个容易忽略的细节

功能归功能，这几个边界先摆清楚：

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx

## 常见问题

### 「设为 Office 文档默认程序」按钮不见了？

该按钮只在平台支持时渲染（不支持的平台整项隐藏）；Windows 上按钮变为「打开系统设置」，由系统面板完成；若设置失败会提示「设置失败，请在系统设置中手动更改。」。

### 主题和文档页面主题会不会互相打架？

不会。「主题」管界面外壳，「文档页面主题」管编辑器纸面；「跟随应用主题」只是让纸面跟随外壳，一旦手动固定纸面，外壳怎么变纸面都不动。

### 切换语言后个别地方还是旧语言？

切换链路是「先写盘＞再切换＞重建主页菜单＞广播全部窗口」，主页与菜单即时生效；若某个已打开的编辑器标签页仍有残留，重开该标签页即可（编辑器在载入时读取当前语言）。

## 补充答疑

### 「所有文档自动保存」默认是开的吗？

不是，默认关。这是「每个编辑器的自动保存默认值」的总开关，打开后仍可在单个窗口里关掉；不打开则按各编辑器自己的保存流程（Ctrl/⌘S、关闭前询问）。

### 语言列表里有 22 种还是 21 种？

以本篇为准 22 种（含 Türkçe 土耳其语），与 README 写的 21 不一致时以 22 为准——语言下拉里可逐一数出。

## 安装与运行答疑

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。
