# 桌面级录屏：语音记录的底层逻辑

语音记录这件事，值不值得专门学一篇，看一个细节就够：桌面级录屏。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 这个功能到底解决什么问题

为什么要有语音记录：本地转写不上传录音，会议速记两件事一次做完。录屏与语音记录的定位是桌面右键录制屏幕；语音记录是录音加转写加保存位置设置，贴顶长条边说边出字。

入口、步骤、验证三段看清，这事就顺了。

## 一步步来

按最短路径验证一遍：

第 5 步 · 语音记录：录音长条

1. 在哪里：桌面空白处右键 ＞「语音记录」。顶部展开录音长条（左：麦克风图标+波形；中：计时；右侧：设置齿轮、「开始」/「停止」、关闭钮）。
2. 做什么：点「开始」（蓝色）开始说话。状态文案「录音中 · 说话即可」；开了实时转写时同步显示「已转 {n} 字」，转写文字实时出现在下方展开区（录音中只读）。
3. 点「停止」（红色）：先「转写中…」再「正在保存音频…」，完成后提示「已保存到 {目录}」；下方文字区变为可编辑，可「复制」「已复制」；生成文字文件后编辑会自动同步到文件（状态「同步中…」＞「已同步到文件」）。
4. 录音中点关闭钮会确认「停止并放弃本次录音？」。
5. 产物：音频 语音记录 YYYY-MM-DD HHmmss.wav（16k 单声道 PCM）；按设置生成同名 .txt（纯转写）或 .md（带时长/识别语言/生成方式头的文档）；保存成功提示「语音已保存：{目录}/{文件名}」「转写文字已保存：{文件名}」。

第 6 步 · 语音转文字设置（齿轮）

点长条右侧齿轮（悬停提示「语音转文字设置」）展开设置小窗，逐项：

1. 「识别语言」：自动检测（默认）/ 中文 / English；
2. 「实时转写」：开（默认）/ 关；开着时多出「切分灵敏度」：低 / 中（默认）/ 高（决定分段上屏节奏）；
3. 「保存位置」：当前文件夹（默认——取录音开始时最近浏览的文件夹，如我的电脑当前目录；取不到回落桌面 Recordings）/ 桌面 Recordings（固定 我的电脑 ＞ 桌面 ＞ Recordings）；
4. 「文字文件」：txt 文本（默认）/ md 文档 / 不生成（不生成时转写只在面板里展示，提示「文字文件已关闭，转写仅在下方展示」）;
5. 「语音模型」：显示每个已装语音模型及「运行中」/「未加载」状态；没装显示「未安装语音模型，请在模型服务中下载」；「打开模型服务」按钮直达 设置 ＞ 模型 的语音识别分类。

## 注意事项与真实边界

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 你可能会问

### 录屏文件去哪了？

固定存 我的电脑 ＞ 桌面 ＞ Recordings（文件系统根 Desktop/Recordings/），文件名 Screen Capture 日期-时间.webm；保存成功的绿色提示里带完整相对路径。浏览器无后端形态会改为直接下载到浏览器下载目录。

### 录屏没有声音？

当前版本音频默认不录（设计共识），只有画面；需要声音可在后期配音或用语音记录同步纪要。

### macOS 点了目标却提示「没有屏幕录制权限」？

系统隐私授权未给：按弹窗引导点「打开系统设置」，在 隐私与安全性 ＞ 屏幕录制 勾选察元，重启应用后再录。

### 语音转写报「转写失败」？

提示原文会建议「请在「模型服务」中安装并加载语音模型（如 Whisper Small）后重试」：到 设置 ＞ 模型 安装/加载语音识别模型，然后在录音长条上点「重试转写」；录音本身已保存，不用重录。

## 更多操作细节

第 1 步 · 录屏：唤起录制选择器

1. 在哪里：桌面空白处右键 ＞「录制屏幕」。录音/录屏进行中时该菜单项变为「停止录制」。
2. 看到什么：屏幕中上部弹出「录制屏幕」选择器，分四段：
    1. 「整屏」：桌面形态逐台列出物理显示器（单屏显示「主屏幕」，多屏显示「显示器 1」「显示器 2…」并标注分辨率）；浏览器形态显示「选择要录制的内容…」（提示「浏览器将弹出系统选择框」）；
    2. 「页面（本系统窗口）」：列出当前打开的察元OS 应用窗口（提示「录制中拖动窗口裁剪跟随」——录的是窗口区域，拖动窗口画面跟着走）；没有窗口时显示「当前没有打开的窗口」；
    3. 「其他应用窗口」（仅桌面形态有）：以缩略图网格列出系统里其他应用的窗口，点缩略图整窗录；
    4. 「区域」：「拖拽选择区域…」（提示「松开鼠标即开始录制」）。
    5. 点任意目标立即开始录制，选择器关闭。

## 更多操作细节

第 2 步 · 框选区域（区域模式）

1. 做什么：点「拖拽选择区域…」后全屏变为十字光标遮罩，顶部提示「拖拽框选录制区域，Esc 取消」（也可点「取消」）；按住鼠标拖出蓝色矩形。
2. 看到什么：松开即开录；拖出的框太小（小于 12×12 像素）视为误触，不启动。

## 更多操作细节

第 3 步 · 录制中与停止

1. 看到什么：录制中屏幕底部居中悬浮胶囊（红点脉动 + 秒数），点击胶囊即停止；也可以桌面右键 ＞「停止录制」。
2. 停止后：桌面弹出绿色提示「录屏已保存：Desktop/Recordings/{文件名}」，「我的电脑」里的目录自动刷新。
3. 产物：文件名形如 Screen Capture 2026-10-29-08-30-00.webm（日期-时间戳；webm 优先，Safari 环境回退 mp4），存放在文件系统根的 Desktop/Recordings/ 目录（即 我的电脑 ＞ 桌面 ＞ Recordings）；录制期间每秒增量落盘，中途断电也会留下可播放的部分文件。

## 更多操作细节

第 4 步 · 录屏权限引导（macOS 未授权时）**

1. 选择器打开即检测权限：未授权时显示「无法读取屏幕：请在 系统设置 ＞ 隐私与安全性 ＞ 屏幕录制 中勾选察元，然后重启应用」，配「打开系统设置」（直达系统面板）与「关闭」两个按钮；按引导授权并重启应用后可录。
