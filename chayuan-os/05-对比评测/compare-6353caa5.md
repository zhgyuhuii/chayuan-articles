# 技能商店 vs 手动管理技能：深度对比与条件式建议

技能商店 vs 手动管理技能，是很多用户在选型阶段绕不开的问题。这篇深度对比不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（察元OS） | 对照方案 | 说明 |
|---|---|---|---|
| 发现 | 搜索 GitHub 技能仓库+精选 | 自己满网找 | 发现成本差异大 |
| 安装 | 一键解包进技能目录 | 手动克隆复制 | 标准化省心 |
| 迁移 | tar.gz 导出导入 | 手动搬目录 | 离线迁移友好 |

## 逐项解读

**发现**：发现成本差异大。察元OS侧的做法是「搜索 GitHub 技能仓库+精选」，对照方案为「自己满网找」——差异的本质在于设计取向不同，而非优劣。

**安装**：标准化省心。察元OS侧的做法是「一键解包进技能目录」，对照方案为「手动克隆复制」——差异的本质在于设计取向不同，而非优劣。

**迁移**：离线迁移友好。察元OS侧的做法是「tar.gz 导出导入」，对照方案为「手动搬目录」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

个人装技能用商店；团队统一下发用离线包。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
