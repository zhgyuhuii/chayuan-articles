# Prompt教程：教程库收录 21291 条学习资源

写Prompt教程的人常被一个问题问住：断网了这套资源还能不能用。本篇就按这个标准，把能力广场能做什么、做不到什么一次摊开。

把Prompt教程拆开看，它指的是这样一类东西：察元AI 能力广场是官方门户兼资源广场，插件、技能、MCP 服务器、提示词、智能体应用、大模型目录、模型厂商、资讯八大板块在线检索，配日、周、月、季、半年、年六档榜单与模型智力榜，四条产品线（察元AI OS、察元AI Office、察元AI文档助手、察元AI工舱）的安装包也从这里下载，支持微信扫码登录、收藏与投稿。

## 教程库板块长什么样

Prompt教程的落点在教程库板块：学 AI 的资料散在五类站点，这个导航库把它们按主题聚起来，五个来源共收 21291 条学习资源，支持按主题检索。与其在浏览器书签里越攒越乱，不如让一个检索入口替你收口。

## 从哪一步开始上手

上手次序照下面来：

1. 先摸清家底：条目聚合自五个来源
2. 看条目构成：元数据加出处链接
3. 简介从哪来：AI 翻译生成，供快速判断
4. 场景验证：按主题找一篇论文
5. 场景验证：找某个框架的入门仓库

这套次序的目的地是末尾两步：前面几步都在为场景验证做铺垫，跑通一次完整的检索闭环，剩下的只是熟练度问题。

## 搜出来的资源怎么消化

资源到手只是半程，Prompt 学习真正见效在动手改：

- 先跑原版：拿到一份提示词，原样跑一遍，记下输出基线
- 再动变量：一次只改一处措辞或格式，对比两次输出的差别，比连改几处再猜原因高效得多
- 记录沉淀：把验证过的提示词连同适用场景一起记下来，下次直接复用，不必从零再调
- 间隔回看：隔段时间把旧提示词重跑一遍，模型更新后效果可能漂移，旧结论要重新核对

教程看几篇就够开跑，剩下的差距靠自己的对比实验补。这是提示词学习和普通编程学习很不一样的地方：反馈来得快，试错的代价低，勤动手的人攒经验最快。

## 三问三答

### 教程正文能在库里直接读吗

不能。阅读要顺着跳转链接回源站，库那边的页面负责让你判断值不值得跑这一趟；跳之前扫一眼简介，主题对不对口一眼可辨，省得空跑。

### 发现侵权内容怎么投诉

站方设了侵权投诉避风港机制，权利人有正式的投诉通道，这套机制是写在明面上的。

### 教程库收费吗

免费全量浏览；部分深度内容走付费 token 门控，绑定设备可解绑。

## 收个尾

要不要把教程库当常驻检索入口，不用问别人：把你手头正在找的资料丢进来搜一轮，省下的翻找时间会替你做决定。提示词的写法迭代很快，与其囤讲义，不如把常用来源收藏好，新东西顺着来源追。

## 查资料的完整流程

1. 进教程库板块
2. 按来源类型或关键词筛选
3. 点跳转链接去源站阅读
4. 登录后可收藏常用条目

筛选建议先窄后宽，关键词打不中就换同义词再试一轮；收藏夹当周转书签用，隔段时间清一次，触顶之前先动手整理。按来源类型筛是另一条路：同一家来源的资料风格连贯，顺着读比东一篇西一篇拼凑着读更成体系。
