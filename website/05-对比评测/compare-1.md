# 资源导航对比评测：教程库只做元数据导航

## 能力广场与直接去 GitHub 找资源

这篇对比不站队：维度摆开、结论按条件给。能力广场与直接去 GitHub各有成立的场景，先看表，再对照自己的条件下结论。

## 维度对照

| 维度 | 能力广场 | 直接去 GitHub |
|---|---|---|
| 发现 | 分类、检索、榜单聚合 10 万以上资源 | 要自己知道关键词与仓库 |
| 质量判断 | star 增量榜与失效剔除机制 | 要逐个点进仓库判断 |
| 配套 | 教程库与助手教程就近参考 | 文档散在各仓库 |

## 逐维度展开

发现：能力广场这边是分类、检索、榜单聚合 10 万以上资源；直接去 GitHub那边是要自己知道关键词与仓库。把发现代入自己的实际情况打分，比看评测结论更可靠。

质量判断：能力广场这边是star 增量榜与失效剔除机制；直接去 GitHub那边是要逐个点进仓库判断。把质量判断代入自己的实际情况打分，比看评测结论更可靠。

配套：能力广场这边是教程库与助手教程就近参考；直接去 GitHub那边是文档散在各仓库。配套维度上，能力广场的优势场景是教程库与助手教程就近参考；反过来直接去 GitHub的场景是文档散在各仓库。没有全胜的一方。

## 条件式结论

明确知道自己要什么去 GitHub 直达也行；调研选型、按榜单发现优质资源用能力广场效率高得多。

## 上手成本与并存策略

并存策略：直接去 GitHub先留着，能力广场按场景切进去。不装任何东西也能先用网页版。
