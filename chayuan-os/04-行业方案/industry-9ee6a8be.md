# 能源电力行业怎么用察元OS：从痛点到落地

能源电力行业的文档与信息工作有其固有节奏：跨部门数据与引用需要反复核对出处。察元AI OS在能源电力场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出能源电力行业的完整应用路径。

## 能源电力行业的典型痛点

- 跨部门数据与引用需要反复核对出处
- 文档量大、格式要求严，人工处理占用大量时间
- 多岗位协作时版本混乱、批注流转低效

## 对应的能力组合

- **九语言界面**（系统语言）：中文、English、日本語、한국어、繁體中文、Русский、Español、Français、Deutsch 九种界面语言。
- **系统控制面（80+ 工具）**（系统MCP）：MCP/HTTP/CLI 三通道的系统能力开放：桌面（壁纸/主题/Dock/锁屏/关机）、窗口与 webwindows（智能体开真实窗口、嵌网页、截图）、应用管理、终端、便签/笔记/日历/提醒/联系人、共享记忆、桌面截图、设置读写。
- **便签/日历/提醒/联系人**（桌面效率）：系统级个人信息管理四件套：便签贴桌面、日历日程、提醒事项、联系人，全部可被智能体通过控制面读写。
- **四家 CLI 智能体**（CLI智能体）：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按家庭用户场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 常见问题
### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 升级会丢数据吗？

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。
