# 效率类 Harness 插件盘点

效率类 Harness 插件盘点。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：Harness 插件板块（Harness插件）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**Harness 插件板块**：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。

1. 首页 ?k=plugin 或导航进入板块
2. 按分类/标签/排序筛选
3. 打开详情复制一行安装命令

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 政企可私有化部署（Docker），数据自主可控
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 政企可以私有化部署吗？

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。
