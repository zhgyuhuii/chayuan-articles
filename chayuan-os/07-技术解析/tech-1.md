# 模型代理协议互转为什么这样工作：把本地模型共享给全机软件

模型代理协议互转这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决把本地模型共享给全机软件。

## 模型代理是个什么东西

模型代理协议互转是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，模型代理是其中面向这类需求的一环。

先把定位立住，再看步骤。

## 实操全过程

上手按顺序做：

1. OpenAI chat/responses 与 Anthropic messages 协议互转
2. 对话、嵌入、重排、语音端点齐备
3. 本地模型按需自动加载
4. 确认边界：代理只监听本机回环，跨机访问需要另行打通
5. 场景验证：把本地模型共享给全机软件
6. 场景验证：Claude 客户端协议直连本地模型

## 几个容易忽略的细节

用之前要认的账：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- 代理只监听本机回环，跨机访问需要另行打通

## 常见问题

### 模型代理协议互转要联网吗

自动卸载会释放常驻模型，重度使用记得钉住，润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱；指定模型未加载时会按策略自动拉起。以官网 aidooo.com 当前页面为准。

### 模型代理协议互转数据存在哪

常用模型可钉住常驻；一台 16GB 内存的机器跑两个 8B 模型必然卡死，显式的加载卸载加自动卸载策略是本地模型的生存之道。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把模型代理协议互转放回察元AI OS的整体盘面：想换默认模型随时可以在设置里重跑向导，不用重装；本地模型解决有无问题，复杂任务还是需要云端旗舰模型，断网时云端模型不可用，可设自动回落本地；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 安全与数据边界

安全口径单独立一层：生图模型不配好，画图应用与智能体的生图指令都落空；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；自动路省心，手动路适合有特殊偏好的玩家，两条路都通向同一个代理，模型清单动态生成。

## 平台与形态

平台与形态的账：会话中随时切换模型（本地与已启用厂商热更新），模型会话中热切换；无显式模型偏好时自动指向本地模型；配置入口在设置＞默认模型＞网络资源页签。

## 价格与授权
