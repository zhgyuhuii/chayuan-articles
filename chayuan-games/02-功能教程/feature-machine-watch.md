# 机机观战全流程教程：选好模型坐等开局

有一种玩棋牌的姿势什么都不用干：选好人，坐下，看它们打。机机观战就是察元竞技场给这种姿势准备的入口——两个或多个模型上桌对打，你捧着茶旁观，从落座看到终局揭晓。这篇按机机观战全流程走一遍，从选模型到散场，让你把「看戏」这件事看得明明白白。

## 先弄清楚它是什么

机机观战是模型对打、人类旁观的模式。你负责的事只有一件：定下谁上场。剩下的出招、判罚、结算全部由对局引擎完成——胜负判定百分之百归代码裁判，模型只出招不判罚，你想掺和都掺和不进去。

它的观赏价值来自两点。一是多样性：完全信息玩法里看模型拼算路，不完全信息玩法里看它们互相诈唬、互相防着点炮，同一批选手换个玩法就是另一种戏。二是匿名：观战默认匿名观战，座位只显示玩家A、玩家B、玩家C、玩家D，谁是谁的真身，要到终局才由对局引擎揭晓。这个设计有讲究——如果你一开始就知道某座位坐着哪家模型，看它的每一手都会带着滤镜；隐去名字，你只能靠行棋风格猜，诈唬像谁、长考像谁、防守像谁，猜谜的乐趣贯穿整局。

人数上它很灵活：两个模型单挑，三四个模型打牌桌，都能安排。配合批量选模型，人多的局也是一次勾选的事。

## 动手前要备好什么

先解决「有人可看」。进设置 ＞ 模型配置，从 85 家厂商目录点选厂商，填上你自己的 API Key，点「测试连接」验证可用；「获取模型」能实拉该账号的模型全列表勾选入库；Ollama 本地模型免 Key 接入，零成本观战。

然后想一下「看谁打谁」。阵容怎么搭，取决于你想看什么戏：看反差，思考型与响应型混搭，保守派与激进派同桌；看厮杀，选棋力相近的对手打棋类，胜负悬念保持到收官；看人数，斗地主三人、掼蛋四人，按玩法要求凑桌。没配置好的模型进不了名单，观战选人只认你已接入的模型。

费用预期也要备好：云端模型每手都在烧你的 API 额度，看一晚上戏的账单是你付的；想零成本长看，用 Ollama 本地模型压阵。

## 完整流程走一遍

第一步，进模式选模型。从大厅进入机机观战的选人环节，勾选参赛模型：单挑勾两个，牌桌按玩法人数勾。人多用批量选模型，一次勾齐，不用逐个点。

第二步，匿名落座。开打后座位按匿名观战显示玩家A、玩家B、玩家C、玩家D，各家模型隐去真名入座。你此刻的功课是记座位：哪个座位的行棋风格像谁，心里先立个牌位，终局揭晓时来对答案。

第三步，旁观对局。对局室里该有的都有：思维链气泡实时滚动着每个座位的盘算，名牌上挂着每手的延迟与 token 用量，局势区的形势曲线标着局势走向。看戏姿势自选——逐手读气泡是精看，扫曲线等翻盘是粗看，都行。

第四步，按需开解说。局面看不懂的时候，解说开关用得上：AI 实时解说的开与关在观战里随手控制，开了它，每一手有人给你讲；关了它，清净看棋。解说怎么配置，另有一篇专文，这里知道有这个开关即可。

第五步，等终局揭晓。胜负落定，终局由对局引擎揭晓身份：玩家A、玩家B到底是谁家模型，此刻翻牌。你整局攒下的猜测一次性兑现，猜得准不准，是观战之外的另一场小比赛。

第六步，散场去向。对局已留档，想回味就走回放，逐手标注与形势曲线都在；想换一桌就再开一局，名单现成。

## 做完后的验证

全流程跑通后核对三处：座位数与你的勾选数一致（选手全到齐）；对局记录里找得到这局（留档正常）；终局揭晓的名单与配置的模型对得上（引擎没张冠李戴）。三处都对，以后每场观战放心开。

## 这些边界要心里有数

匿名是把双刃剑：它保住了猜谜乐趣，也意味着你中途没法确认某座位是谁，想针对性围观某家模型的打法，匿名观战做不到点名，身份留到终局。弱模型上桌，废招会多，代走兜底虽然能让对局不卡死，观感却打折——阵容筛选花的那几分钟，值得。云端观战的时间成本与费用都随模型数量上涨：四个模型打一晚比两个贵一倍不止，挂机前掂量额度。另外座位分配规则、揭晓的呈现形式，以 0.1.0 版本实际界面为准。

## 高频疑问

### 观战中途能提前揭晓身份吗

不能。匿名观战的揭晓时机就是终局，由对局引擎统一翻牌，中途不剧透。想提前知道谁是谁，只能关掉这局换非匿名的玩法——那猜谜的乐趣也就没了。

### 机机观战花钱吗

软件 MIT 开源免费。云端模型按你的 API 用量向厂商付费，看一晚的账单与对局数、模型数、每手 token 用量挂钩；Ollama 本地模型零成本。

### 一次最多看几个模型打

以玩法要求的座位数为准，选人环节支持批量选模型凑桌。人越多戏越热闹，费用与时长也水涨船高，量力而行。

### 能边看边自己下场吗

观战就是观战，中途下场请改开人机局；人机局里想歇手，用 AI 接手与人工接管的切换腾挪，两个模式各有各的姿势。

### 错过了终局还能知道身份吗

能。对局留档在记录页，回放与终局信息随时可查，揭晓不会因为你打了个瞌睡就作废。

机机观战全流程走通，你就解锁了竞技场里成本轻、乐趣密度不低的姿势：不用动手，不用动脑，动嘴猜一猜就行。选好模型，坐等开局，看玩家A和玩家B斗智斗勇——至于他们到底是谁，终局见分晓。
