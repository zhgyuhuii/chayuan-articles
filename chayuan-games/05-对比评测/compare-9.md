# 开源LLM游戏有哪些：同类项目形态速览

大模型除了聊天还能干什么？开源社区这几年交出的答案比想象中多：有人让模型玩文字冒险，有人拿它们下棋，还有人干脆搭起了竞技场。开源LLM游戏大致能分成几个形态，每个形态考察模型的能力侧重不同，自建成本也差得远。这篇做个速览，帮你想清楚自己要哪一类，以及哪一类可以不用自己造轮子。

四个形态先列一张总表。

| 形态 | 代表玩法 | 考察重点 | 自建要做什么 |
|---|---|---|---|
| 文字游戏类 | 文字冒险、剧本对局 | 语境理解与叙事连贯 | 写剧情状态机、提示词与存档逻辑 |
| 对话博弈类 | 多角色桌游、社交推理 | 表达、欺骗与识破 | 设计角色卡、轮次与胜负条件 |
| 棋类对弈类 | 让 LLM 下棋的脚本项目 | 着法合法性与推理 | 接棋类规则引擎、做出招解析 |
| 竞技场平台类 | 察元竞技场这类 | 完整对局、判罚与排位 | 装好即用，MIT 开源 |

## 文字游戏类：考叙事，不考判罚

文字冒险和剧本对局是门槛较低的一类：模型读剧本、演角色，靠语言推进剧情。它考察语境理解和叙事能力，但几乎没有客观判罚——剧情走没走偏要靠人看，评价偏主观。自建这类项目，主要工作量在剧情状态机和提示词工程上，规则引擎不用写，可复现性也弱一些。顺带说个观察：这类项目里模型的角色是演员，考的是「演得像不像」而不是「决策对不对」，两类考察结果的用法完全不同。

## 对话博弈类：语言就是武器的牌桌

多角色桌游、社交推理这类玩法，让多个模型分饰角色互相试探，语言就是武器。它考表达、欺骗与识破，观赏性强，社区里常见这类演示。自建成本中等偏上：角色卡、轮次逻辑、胜负条件都要自己定，还要处理模型长对话跑偏的问题；判罚也是绕不开的坎，语言博弈没有天然胜负规则，谁赢谁输要么靠人评，要么把规则写死，两种做法成本都不低。同类开源项目形态各异，具体以其官方页面为准，这里只说共性。

## 棋类对弈类：合法着法是头一道坎

不少研究型项目让大模型下棋，做法通常是接一套棋类规则引擎，再想办法把模型的输出变成合法着法。难点恰恰在这里：模型常常写出不合规则的串，解析容错要自己写。自建单个棋种尚可，铺开多款玩法就是工程量的层层加码——这也是很多项目停在演示阶段的原因。评判这类项目的成熟度有个简单办法：看它怎么处理模型输出不合法的时刻，有容错链、有代走兜底的，说明作者真跑过大量对局；只做理想路径的，跑两局就会散架。

## 竞技场平台类：把上面的事全做好

察元竞技场属于这类：把裁判、对局引擎、出招解析、排位、复盘做成一整套。11 款玩法各配纯逻辑裁判，胜负判定 100% 归代码，模型无判罚权；解析容错链兜住模型输出的千奇百怪；TrueSkill 天梯管排位，锦标赛管循环赛；对局室里有思维链气泡、延迟与 token 用量，复盘有形势曲线、？！标注和 AI 解说，棋谱 JSON 导出，协议画像记录出招习惯，开局记忆防止同型局面重复犯错。85 家厂商目录点选即填，Ollama 本地免 Key，Electron 桌面应用，三大桌面系统各有安装包，按架构选装。

自建成本在这类形态里是低的：MIT 开源，装完即用，你要做的只有配 Key 和选玩法。

## 四种对战模式：竞技场的成品答案

平台类省掉了多少自建工作，看对战模式就清楚。人机局：你亲自下场，AI 接手与人工接管随时双向切换，下一手生效；机机观战：批量勾选模型互相打，默认匿名观战，座位只显示玩家A、玩家B，终局揭晓身份；锦标赛：多模型循环赛自动排程，积分榜实时刷新，打完出冠军；天梯挑战：按 TrueSkill 段位约战，赢者升段。

这四种模式每一种背后都是一堆工程：排程器、匿名化、段位算法、战绩独立统计。自建的话每一项都是周级别的活，用现成的就是安装包里自带。另有一个容易被忽略的成品件：开局记忆，它帮模型记住同型局面的教训，避免反复踩同一个坑，这类细节自建项目通常想不到要做。

## 自建还是现成：算三笔账

想清楚三笔账。开发账：文字类几周能出雏形，棋类要啃规则与解析，竞技场类直接装。维护账：模型接口变动、规则修订，自建项目都要自己扛，开源项目有社区分担。观察账：自建脚本能记录的信息有限，竞技场把思维链、延迟、token 用量、画像数据都做进去了，考察深度不一样。

还有第四笔账：数据账。自建项目的对局记录格式自己定，未来想换工具就有一笔迁移成本；竞技场的棋谱 JSON 导出、协议画像都按固定协议落盘，复用起来不用二次解析。

## 条件式推荐

兴趣在叙事与角色扮演，能接受主观评价，选文字游戏类自玩，工程量小见效快。

兴趣在博弈行为的客观考察，想要判罚公正、结果可复现，选竞技场平台类，察元竞技场装完即用，不用造轮子。

想研究某一款棋的模型表现，轻量脚本通常够用，规则与解析都有开源件可借；想横向比较多款玩法多个模型，直接上竞技场，省下的时间拿去看对局。介于两者之间的，先把竞技场装上跑几局，缺什么再补什么，方向感更清楚。

## 实话实说：三条边界

开源项目质量参差，动手前看它的更新频率与社区反馈，具体以其官方页面为准；察元竞技场聚焦棋牌，文字冒险类玩法它不做；版本 0.1.0 还在早期，玩法清单和功能会随版本调整。

## 你可能会问

### 开源LLM游戏和普通棋牌游戏有什么区别

对手不同。前者桌上坐的是大模型，考察的是模型博弈能力；后者是人与人娱乐，胜负之外没有考察目的。

### 自己搭一个要多久

看形态。文字类通常几周能出雏形，棋类要处理规则与解析，周期以月计；用现成竞技场则当天就能开局。

### 察元竞技场开源在哪

MIT 协议，仓库 github.com/zhgyuhuii/chayuan-games，安装包见官网 aidooo.com。

### 竞技场会一直免费吗

会。MIT 协议锁定开源身份，软件本身没有收费设计，成本只在模型 API 侧，用本地模型则为零。

轮子已经有人造好了，还是开着的。想看模型博弈，自己从状态机写起不如先把现成竞技场装上，跑几局锦标赛再决定要不要折腾——大多数时候你会发现，该有的它都有了。
