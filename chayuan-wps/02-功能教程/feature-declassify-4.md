# 占位符脱敏排查路径：付费四项（脱密、复原

「文档怎么脱密」——这个问题最近被问了好几次。答案不复杂：占位符脱敏在察元AI文档助手里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

占位符脱敏的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把文字端功能：仅 WPS 文字的「察元AI助理」选项卡提供「文档脱密」按钮（表格/演示端无此入口）；核一遍，再查路径。

## 高频故障与对策

### 脱密执行中途出错了会弄坏文档吗？

替换写回失败时系统会用原文整体回写，避免文档停留在半替换状态；具体失败原因显示在弹窗错误条中，可修正后重试。若所选关键词在文档中一个都没命中，执行会被拦下并提示「所选关键词未在当前文档中命中，无法执行占位符脱密」。

## 正确的操作路径

最短路径走一遍：（第 4 个切入角度）

1. AI 加正则双路提取
2. 占位符可逆
3. 加密载荷随文件走
4. 确认边界：仅文字端提供，且属于付费专属能力（零免费额度）
5. 确认边界：忘记密码没有任何免密恢复通道
6. 场景验证：把内部报告脱密后发外部评审

## 做完后的验证

验证

1. 回到正文：原关键词位置已变成 §8 位随机码§ 形式的占位符，格式排版不变；
2. Ribbon 状态翻转：「文档脱密」按钮置灰，「脱密复原」按钮亮起；
3. 打开任务清单（「察元AI编审」＞「察元设置」＞「任务清单」）：能看到「涉密关键词提取」「占位符脱密」两条任务；点开涉密关键词任务详情，有「序号 / 原文关键词 / 占位符 / 分类 / 风险 / 脱密原因」表格，任务条目显示「共 N 个涉密关键词」。

## 你可能会问

### 对已脱密的文档又点了「文档脱密」？

按钮此时是置灰的；若从其他入口打开脱密窗口，会提示「当前文档已经处于脱密状态，请使用“密码复原”恢复后再操作」。先复原再重新脱密。

### 检查涉及把全文发给模型，涉密文档安全吗？

关键词提取会把文档内容送给你选定的模型服务。涉密程度高的文档，建议先在设置里切换到本机离线模型再执行脱密。

- 文字端功能：仅 WPS 文字的「察元AI助理」选项卡提供「文档脱密」按钮（表格/演示端无此入口）；
- 已配置可用的对话模型：关键词提取要调用模型，解析顺序为该助手单独配置的模型 ＞ 第一个可用对话模型；
- 付费能力：文档脱密属付费专属能力，未购买时点击按钮直接弹「购买授权」窗；
- 当前文档未处于脱密状态：已脱密的文档「文档脱密」按钮置灰，需先「脱密复原」；

## 安全与数据边界

安全口径单独立一层：不会写公式就按公式助手，不会分析就按数据洞察，表格工作的台阶被垫平，凭据 AES-GCM 设备绑定加密，选 HTTP 类型指向本机地址；本地数据落盘位置说明、帮助手册、在线客服与关于页。

## 平台与形态

平台与形态的账：脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道；macOS 安装器没有完全磁盘访问权限时会出现假成功，需要跑修复脚本，macOS 容器写入失败有修复脚本；macOS 安装器无完全磁盘访问权限会假成功。
