# 国产CPU适配：完整桌面范式

国产CPU适配这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是国产CPU适配

把国产CPU适配拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 国产CPU适配要联网吗

设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关；联网环境下内置 web_search 工具默认走 DeepSeek 搜索，MCP 配置自动传播 13 家。以官网 aidooo.com 当前页面为准。

### 国产CPU适配数据存在哪

MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583），启停即同步写入支持 MCP 的 13 家智能体；MCP 是智能体的手，一处配置全家生效，改之前能验证连接省得排错。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把国产CPU适配放回察元AI OS的整体盘面：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入；保存后随系统技能分发到智能体。

## 安全与数据边界

安全口径单独立一层：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；代理只监听本机回环，跨机访问需要另行打通，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询。

## 平台与形态

平台与形态的账：Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸，应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness；Dock 是使用频率最高的区域，位置与大小顺眼很影响手感。

## 价格与授权

价格口径一并交代：四档价格：149/359/599/1049 元；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签），跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定，需要相应平台的 Key（部分有免费额度）。

## 产品家族与搭配

察元AI OS不是单打独斗：插件、技能、MCP 插件、智能体、技能包五大类；OpenAI 风格与阿里百炼风格 API 自动适配，CLI 智能体经 MCP 自动接入；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集。
