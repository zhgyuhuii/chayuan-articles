# MCP 安全风险自查清单

MCP 安全风险自查清单。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：MCP 服务器板块（MCP服务器列表）、资源健康与风险标注（资源失效）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**MCP 服务器板块**：Model Context Protocol 服务器目录：每条含功能简介与 MCP JSON 配置片段，附 scopes 风险分级（0-3）与 health 状态。

1. 进入 mcp 板块
2. 按功能关键词搜索
3. 复制 JSON 配置片段到客户端

**资源健康与风险标注**：条目级 health 状态机（active/degraded/dead/archived）与 MCP scopes 风险分级（0-3 级）：资源可用性与权限风险透明可见。

1. 看条目上的状态标签
2. MCP 条目查看 scopes 等级
3. 优先使用 active 低风险条目

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 网站本身需要网络访问（内网场景走私有化部署方案）
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
