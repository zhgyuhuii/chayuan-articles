# 一文读懂模型接入（30+ 供应商）｜实操教程

大模型接入是察元AI文档助手里使用频率很高的一项能力。它的「模型接入（30+ 供应商）」这样工作：设置内可配 30+ 模型供应商：OpenAI、Claude、Gemini、DeepSeek、豆包、阿里百炼、百度千帆、智谱 GLM、Kimi、零一万物、MiniMax、阶跃、百川、书生·浦语、ModelScope、OpenRouter 等，加本地 Ollama/LM Studio/Xinference/One API/FastChat/Custom OpenAI；模型分对话/嵌入/图像/语音/视频五类。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

设置内可配 30+ 模型供应商：OpenAI、Claude、Gemini、DeepSeek、豆包、阿里百炼、百度千帆、智谱 GLM、Kimi、零一万物、MiniMax、阶跃、百川、书生·浦语、ModelScope、OpenRouter 等，加本地 Ollama/LM Studio/Xinference/One API/FastChat/Custom OpenAI；模型分对话/嵌入/图像/语音/视频五类。

从任务视角看，它对应的关键词是「大模型接入」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入设置→模型
2. 填入供应商密钥或本地端点
3. 为五类任务分别指定默认模型
4. 对话测试连通

## 适用场景

- 按保密等级选择云端或本地模型
- 不同任务用不同模型控制成本

## 实用技巧

- 内网环境把所有端点指到 One API 网关统一管理

## 注意事项与边界

- 仅支持 WPS 桌面端（12.x/365），不支持网页版 WPS 与其他办公软件
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 开源 Apache-2.0，全部代码可审计，政企可自行审阅后离线打包
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 和 WPS 自带的 AI 有什么区别？

本产品是独立的开源加载项，特色在结构化校对批注写回、保密/脱密工具链、本机 MCP 服务与离线内网支持；两者可并存使用。

### 支持国产化环境吗？

支持麒麟、UOS 等国产化环境（arm64/x64），真机验证过 Ubuntu arm64 + WPS Office 12.1 组合。

### 什么是 MCP 文档智能体服务？

加载项内置的本机服务（46 工具/15 域），外部 AI 编程工具（Claude Code、Codex、Cursor 等）连上后可直接打开、读取、修改、批注本机 WPS 文档，写操作默认只预览、传 confirmed:true 才落盘。
