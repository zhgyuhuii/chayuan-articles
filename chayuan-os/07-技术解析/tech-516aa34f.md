# 技术解析：HMAC 离线激活的密码学

这是「察元OS技术解析」系列的一篇。HMAC 离线激活的密码学是理解这款产品设计哲学的关键切面——看完你会明白它为什么这样设计、这样设计换来了什么、代价是什么。

## 一句话结论

购买激活完全离线：短码用 Crockford base32 编码 + mod-37 校验位 + HMAC tag，绑定 16 位机器指纹（sha256(IOPlatformUUID)[:16]，win 用 MachineGuid、linux 用 /etc/machine-id），本地验签、时长=激活日+天数；模块位（bit10 技能包/bit11 OS/bit12 Office）让一个短码管全家产品。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 对使用者意味着什么

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 相关能力以官网 https://aidooo.com 最新版本为准

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 常见问题
### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。
