# Harness 插件板块速查手册：从入口到完成的完整流程

Harness插件是察元AI 能力广场里使用频率很高的一项能力。它的「Harness 插件板块」这样工作：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。这篇速查手册从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。

从任务视角看，它对应的关键词是「Harness插件」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 首页 ?k=plugin 或导航进入板块
2. 按分类/标签/排序筛选
3. 打开详情复制一行安装命令

## 适用场景

- 给 AI 桌面系统扩功能
- 发现高星插件

## 实用技巧

- 安装命令格式对 dsh 生态通用

## 注意事项与边界

- 命令执行依赖原始仓库可用
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 政企可私有化部署（Docker），数据自主可控

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用
