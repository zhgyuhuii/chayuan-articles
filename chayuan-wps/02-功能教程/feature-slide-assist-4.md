# 口播稿疑难解答：九成问题出在这几处

写这篇的起因是群里有人问口播稿，我发现自己也说不完整，索性把察元AI文档助手里的演示助手从头到尾走了一遍，把每一步的界面反馈都记下来。现在这份笔记可以直接当教程用。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（已在 WPS 演示中启用加载项，Ribbon 出现「察元AI助理」选项卡；），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 一键钮点了没反应？

面板正在执行回合时不会被打断（等回合结束再点）；面板打开失败会弹「AI 助手面板打开失败（原因）」提示；模型未配置先完成对应教程。同表格端机制，见对应教程 常见问题 Q1。

## 正确的操作路径

入口都在演示端 Ribbon「察元AI助理」选项卡 ＞「AI助手」组（大按钮一排 ＞「文档安全」▾ ＞「更多演示助手」▾ ＞「设置」）。

1. 「AI演示助手」：单开对话面板

1. 点「AI演示助手」：打开 AI 助手对话面板（单实例，已开则聚焦不重复开窗，形态按上次记忆）。

2. 「生成PPT」：从主题到整套片子

1. 点「生成PPT」：面板打开，输入框预填「请为我生成一套演示稿：先给出大纲（页码+每页标题+要点），等我确认后逐页生成。主题与要求：」，在末尾补充主题、受众、页数、风格后发送；
2. 智能体先给大纲，你回复「确认」或提修改意见，然后逐页生成（版式/标题/正文/演讲备注），写回走预览确认闸门；
3. 需要配图时在要求里注明：配图走三级图源；在 PPT 宿主里生图会自动按当前页面宽高比选 16:9/9:16，无需手动指定比例；
4. 单位有统一模板时，不用本按钮：改走对话模板编制——在对话里直接给模板文件+要求，按模板版式出片（见对应教程「对话生成整套文档（模板编制）」）；
5. 侧栏还有面板专属的「文档转 PPT」（读 Word 提炼大纲逐页生成）、「大纲调整」「数据页」「项目进度汇报」「校对修复执行」「汇报压缩」「答辩问答预案」等。

## 收尾检查

验证

1. 点「生成PPT」并发送主题：先收到大纲（页码+每页标题+要点）而不是直接出片；回复确认后逐页生成；
2. 点「整套校对」：自动发送，对话返回只读问题清单且原稿文字未被改动；
3. 点「加密演示稿」并发送：智能体先问你要密码；加密后报告保存路径；
4. 打开侧栏「助手」页签：只看到演示配方（看不到文字/表格端助手），组名右侧有数量角标。

## 你可能会问

### 「美化统一」会不会把表格样式也改了？

不会。配方明确「表格形状跳过」，只统一字体字号；表格样式可用侧栏「表格样式统一」配方单独处理。

### 生成的 PPT 里图片比例不对/铺不满页面？

PPT 宿主生图会自动按页面宽高比选 16:9/9:16（生图模型默认 1:1 才会铺不满）。若仍异常，检查是否在对话里手动指定了比例；配图链路本身的问题见对应教程。

### 「整套翻译」翻到一半停了/个别页没翻？

整套翻译逐页读取后用文本替换写回（数字、专有名词保持原样）；页数多时耗时长，可让模型从指定页继续。写回走预览确认闸门，可在任务进度窗核对每处替换。

## 补充答疑

### 点了「生成PPT」没先给大纲就开始逐页出片？

配方的设计是大纲先行——按钮预填的提示词原文就要求「先给出大纲（页码+每页标题+要点），等我确认后逐页生成」。若某次模型没有遵守，重新点一次「生成PPT」，在补充要求里明确「先出大纲等我确认再生成」再发送即可。

### 侧栏怎么没有「添加助手」入口？

演示端侧栏展示的是内置演示配方 + 演示宿主自定义助手；创建入口与字段说明见对应教程（表格/演示宿主的自定义配方存宿主分桶，编辑走设置 ＞ 助手设置）。

## 更多操作细节

3. 一键直达钮：整套摘要 / 美化统一 / 口播稿 / 整套校对 / 结构诊断

1. 这五个全部是立即执行型（点完自动发送，无需补充）：
    1. 「整套摘要」：通读全部页面，在第 1 页后新增一页「核心要点」摘要页（3-5 条要点）；
    2. 「美化统一」：全部页面中文字体统一为微软雅黑、标题 28 号、正文 18 号，表格形状跳过，完成后报告触及页数与形状数；
    3. 「口播稿」：逐页生成口语化演讲者备注（每页 3-5 句）写入对应页备注；
    4. 「整套校对」：只读校对错别字/重复词/占位符文本（Lorem/TODO/示例）/标点问题，输出「页码+原文+修改建议」清单，不改文字；确认后想批量改，用侧栏「校对修复执行」；
    5. 「结构诊断」：只读诊断故事线连贯性、单页要点数、封面/目录/过渡/结尾页缺失，给 3-5 条调整建议。

4. 「文档安全」▾：保密检查 / 加密演示稿 / 解密演示稿

1. 「保密检查」：立即执行型，逐页只读检查敏感词/密级表述/内部代号/客户名与金额，输出「页码+内容摘要+风险级别」清单；
2. 「加密演示稿」：预填型，智能体先在对话里向你询问密码，再用演示稿工具 security_encrypt_save 完成加密并报告保存路径；密码遗忘无法找回；
3. 「解密演示稿」：预填型，先提醒备份，确认后 security_decrypt_save 移除打开密码。

5. 「更多演示助手」▾：高频带参配方

1. 菜单项：结构件补齐（立即执行型：缺封面/目录/过渡/结尾页自动补齐并列出新页码）/ 整套翻译 / 转讲义文档 / 页码页脚 / 数据战报页 / 课件生成 / 习题互动页，除「结构件补齐」外均预填补充型；
2. 「转讲义文档」需在 WPS 文字里打开目标文档（逐页整理成「页码+标题+要点」写入 Word）；「数据战报页」跨宿主读取打开的工作簿数据提炼大数字出战报页组；
3. 菜单底部与分隔线后各有一个「设置」，都打开与文字端同一个设置窗口。

## 安装与运行答疑

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

如果只记一件事：九大按钮。剩下的细节照步骤节走就行。
