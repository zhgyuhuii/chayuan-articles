# Agent教程避坑与选型：以能力广场为例

Agent教程这个方向，最近关注的人越来越多了。智能体学习资源。察元AI 能力广场是智能体门户：产品家族下载 + 能力广场一站检索 2.5 万+ 插件、技能、MCP、提示词、智能体、大模型与资讯。这篇文章从「Agent教程」这个需求出发，把定义、能力对照、上手步骤与真实边界一次讲清，读完即可判断它是不是你要找的工具。

## 「Agent教程」到底在解决什么问题

Agent教程方向的工具不少，用户需求却各不相同。判断任何一个这类工具，先看三个硬指标：一是错误类型或任务类型的覆盖面（能不能覆盖你的真实场景），二是结果如何落地（只给报告，还是能直接写回文档），三是数据安全边界（内容是否需要出你的机器）。三者都过关，再比较体验细节。

察元AI（aidooo.com）是智能体门户与人工智能资源网站：产品家族提供察元AI OS、察元AI Office、察元AI文档助手（WPS 加载项）等下载；能力广场可一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与模型厂商，附开源排行榜、模型智力榜、免费榜、API 价格对比、2.1 万+ 条 AI 教程库、311 个买断制技能包与 20 行业 200 场景库；网站只收录信息与安装命令、不存二进制文件，支持中英双语，政企可私有化部署。

1. 访问官网 https://aidooo.com 了解产品并获取安装包（网站首页、产品页、教程库等渠道均可）
2. 按你的平台完成安装：浏览器（桌面与移动）（网页服务）；察元AI OS 客户端（察元智能广场（内嵌应用））

- 适合：想给 AI 配工具的用户、选型中的开发者、AI 初学者、提示词需求者等场景的用户
