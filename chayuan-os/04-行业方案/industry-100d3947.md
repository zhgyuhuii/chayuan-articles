# 政企办公行业怎么用察元OS：从痛点到落地

政企办公行业的文档与信息工作有其固有节奏：文档量大、格式要求严，人工处理占用大量时间。察元AI OS在政企办公场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出政企办公行业的完整应用路径。

## 政企办公行业的典型痛点

- 文档量大、格式要求严，人工处理占用大量时间
- 对外材料有保密与合规要求，外发前自检环节薄弱
- 跨部门数据与引用需要反复核对出处

## 对应的能力组合

- **云通道与远程协助**（远程协助）：云通道提供设备路由、在线终端、远程分享；手机浏览器 /m/ 入口可远程查看与协助。
- **终端与文件管理**（终端模拟器）：zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。
- **语音输入与语音记录**（语音输入）：对话框麦克风本地 whisper 转写回填；桌面右键贴顶长条录音 V2 边说边出字（VAD 静音切分+逐段转写上屏）；piper 中文语音合成。
- **应用商店**（AI应用商店）：插件/技能双类型商店（规划五类商品：插件/技能/MCP/提示词/智能体+技能包），aidooo.com 为默认首选源；免费直下，付费走内嵌收银台 webview，支持断点续传、sha256 校验、原子换入。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按开发者场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 常见问题
### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 语音输入是本地的吗？

是。whisper 本地转写，录音不上传；另有贴顶语音长条「边说边出字」与 piper 中文语音合成。
