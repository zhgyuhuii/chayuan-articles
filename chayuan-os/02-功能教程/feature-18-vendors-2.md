# 大模型厂商攻略：云厂商目录（89 家）的关键点拆解

大模型厂商是察元AI OS里使用频率很高的一项能力。它的「云厂商目录（89 家）」这样工作：内置 89 家云厂商与聚合平台目录（国内/全球/聚合/本地四组，含免费额度标记）：DeepSeek、Moonshot、阿里百炼、智谱、火山、OpenAI、Anthropic、Gemini、OpenRouter、Ollama 等。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

内置 89 家云厂商与聚合平台目录（国内/全球/聚合/本地四组，含免费额度标记）：DeepSeek、Moonshot、阿里百炼、智谱、火山、OpenAI、Anthropic、Gemini、OpenRouter、Ollama 等。

从任务视角看，它对应的关键词是「大模型厂商」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 设置→模型供应商目录
2. 按免费额度/价格筛选
3. 填 Key 接入

## 适用场景

- 选型比价
- 薅免费额度

## 进阶技巧

- 免费额度标记帮助零成本试用

## 注意事项与边界

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 手机能用吗？

手机浏览器通过云通道 /m/ 入口远程查看与协助；另有 Capacitor 安卓壳方案。
