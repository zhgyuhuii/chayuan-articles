# 察元竞技场macOS安装：dmg拖装与权限处理

dmg 这种格式在 Mac 上装起来其实很快：打开镜像、拖进应用程序文件夹，两下就完事。真正的麻烦往往出在头一回启动——系统弹出一个安全提示，不少人到这一步就慌了。这篇把察元竞技场macOS安装的全过程写完整：选对 dmg、拖装、首启提示逐个处理，照做即可。

## 它在 Mac 上是什么形态

察元竞技场是察元AI 家族的开源大模型棋牌竞技场，MIT 协议，11 款棋牌玩法，让各家大模型同桌对弈。macOS 版以 dmg 镜像分发，提供 arm64 与 x64 双架构，分别对应 Apple 芯片与 Intel 芯片的 Mac。

名字上有个细节要先知道：它的 Electron 产品名叫「察元AI游戏」，安装包文件名与装好后的应用名里都是这几个字。装完后在启动台或应用程序文件夹里，你看到的应用叫「察元AI游戏」，这不是下错了东西。当前版本 0.1.0（2026 年 11 月口径）。

## 选对 dmg：看芯片不猜型号

点屏幕左上角的苹果菜单，进「关于本机」，看芯片一栏：显示 Apple M 系列（M1、M2、M3 及后续型号）的，下载 arm64 的 dmg；显示 Intel 处理器的，下载 x64 的 dmg。2020 年之后购买的 Mac 基本都是 Apple 芯片，也就是 arm64 那一份。

两个架构的包不通用，arm64 的 dmg 在 Intel 机器上装不上，反过来也不行。dmg 从官网 aidooo.com 或开源仓库 github.com/zhgyuhuii/chayuan-games 的 Releases 页面获取，第三方下载站不要碰。

## 拖装步骤：两下完事

下载完成后双击 dmg 文件，系统会挂载这个镜像并弹出一个窗口，窗口里通常一边是应用图标，一边是应用程序文件夹的快捷入口。你要做的就是把应用图标拖到应用程序文件夹里，等复制进度结束，这一步的实质是把应用拷贝进系统。

拷贝完成后可以在镜像窗口里选择推出（弹出）dmg，桌面上的镜像盘符随之消失，这是正常现象，应用本体已经进了应用程序文件夹。之后从启动台或应用程序文件夹里找到「察元AI游戏」，单击打开。

头一回用 dmg 的人容易在一个地方愣住：镜像窗口打开后找不到「安装」按钮，其实没有按钮，拖就是安装。把窗口里的应用图标按住不放，拖到旁边的应用程序文件夹图标上松手，复制动作开始就成功了。这个交互是 macOS 应用分发的传统姿势，各类软件通用，熟悉一次终身受用。

顺带回答一个常见疑问：dmg 文件在拖装完成后就没有用了，留着只占空间，确认应用能正常启动后可以把 dmg 删掉，以后重装再重新下载即可。

## 首启安全提示：逐个说清

头一回打开应用时，macOS 的安全机制可能出面，常见情况有几种，处理方式各不相同。

情况一：提示无法验证开发者，问你是否打开。这类提示说明应用没有经过 macOS 的公证流程（常见于独立开发者与开源软件的安装包），如果你确认这个包来自上面两个官方渠道，可以在应用程序文件夹里按住 Control 键点按应用图标选打开，或者按提示的指引到系统设置里允许打开。确认来源之后放行即可，来源不明就不要放。

情况二：提示应用已损坏，建议移到废纸篓。这个提示九成与下载不完整有关，镜像没下全，解出来的应用自然是坏的。直接把应用删掉，重新下载 dmg 再装一遍，问题通常就消失了，不需要研究任何绕过技巧。

情况三：什么提示都没有，直接打开了。那更好，说明系统认定这个包没有需要拦截的因素，正常用即可。

Electron 应用本身不需要额外的系统权限，模型通信走的是应用自己进程的网络请求，不会频繁向你索要麦克风、摄像头这类敏感授权。遇到索要无关敏感权限的应用，反倒要回头核对安装来源。

## 装完后的三处快速检查

拖装完成不等于万事大吉，三处各看一眼，一分钟的事。

第一处，应用程序文件夹里有没有「察元AI游戏」。有，说明拷贝成功；没有，说明拖装没完成，重新打开 dmg 再拖一次即可。

第二处，首启有没有安全提示。有就按上一节的办法处理，核心是先核实来源再放行；没有提示直接进入应用更好。

第三处，界面与目录是否正常。打开后看到暗色竞技场界面与大厅，再进设置 ＞ 模型配置看 85 家厂商目录能否正常列出。两样都在，应用本体就没有问题了。

## 验证：装成什么样算成功

打开应用后看到暗色的竞技场界面，首屏是大厅，11 款玩法按棋类、扑克、麻将三组排开，这就说明界面层正常。再进设置 ＞ 模型配置，看内置的 85 家厂商目录能否正常列出，选一家你手上有 Key 的填进去，点「测试连接」有反馈，模型网关也就通了。回大厅开一局人机局，看到对局室里的思维链气泡随模型出招流出来，整条链路闭环。

M 系列芯片的 Mac 跑这类桌面应用通常很轻松，本地界面部分不吃配置，真正决定流畅度的是你配的云端模型的响应速度，或者本地模型的硬件需求。

## 边界与实话

三条说在前面。dmg 拖装没有一路下一步的向导，需要你手动拖一次、首启确认一次，比 Windows 的向导式安装多了两下手工操作，这是 macOS 的习惯，不是软件的问题。版本 0.1.0 还在早期，未做公证流程的安装包在系统严格的安全策略下提示会显得吓人，处理方式上文已给，核心只有一条：认准官方渠道再放行。另外，软件 MIT 开源免费，云端模型的 API 费用由你自己向厂商支付，Mac 上挂机跑锦标赛同样烧自己的额度。

## 你可能会问

### 安装需要输入管理员密码吗

把应用拖入系统的应用程序文件夹时，多数个人 Mac 的当前用户就有写入权限，不需要密码；个别受管理的电脑权限收紧时，系统会要求授权，输入你的账户密码确认即可。

### 装到哪个目录了

拖装的目标就是应用程序文件夹，也就是 Applications。想换位置可以拖到其他本地目录，但从启动台点开还是默认位置最省事。

### 想卸载怎么办

打开应用程序文件夹，把「察元AI游戏」拖到废纸篓就完成了主体卸载。配置与对局数据存在你的用户资料目录里，彻底清理时可以一并删除对应的应用数据文件夹。

### Intel Mac 会一直被支持吗

当前版本明确提供 x64 架构的 dmg，Intel 机器可以正常安装使用。后续版本的架构支持以官方发版说明为准，Releases 页面里挂着哪些包，就是支持哪些。

### dmg 下载速度不理想怎么办

官网 aidooo.com 与 GitHub Releases 两个渠道都可以拿包，哪个通畅用哪个，同一版本内容一致。反复中断就换个网络环境再下，残缺镜像会带来「已损坏」提示，白折腾一轮。

Mac 这边真正需要动脑的只有两处：看芯片选包、首启认提示。把这两处过掉，剩下的拖装动作没有任何悬念。装好就去配模型开局，看大模型在你屏幕上打一手德州扑克，比十篇文章都直观。
