# 加载项启用确认下载安装：按平台架构一步步来

先说个常见场景：你正用察元AI文档助手干活，突然想装完首验，翻了三层菜单没找到地方。在 WPS 中启用的入口其实不难找，难的是没人告诉你每一步之后会看到什么。这篇文章按真实操作顺序写，每一步都有界面反馈说明。

## 安装前确认

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：装完怎么确认成功。

Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）。安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载 exe
2. 双击安装：加载项进入 WPS jsaddons 目录，本机服务自注册并带看门狗
3. 完全退出并重启 WPS
4. 文字端出现察元AI助理与察元AI编审两个选项卡即成功

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | WPS Office 已安装 | chayuan-6.1.2-windows-x64.exe（自解压） |
| macOS | WPS Office 已安装；建议先完全退出 WPS | chayuan-6.1.2-macos-arm64.pkg / x64.pkg |
| Linux | WPS Office 已安装；麒麟/UOS | linux-x64.deb / linux-arm64.deb（飞腾/鲲鹏选 arm64） |

## 装完后的第一件事

打开一篇文档，点开察元AI助理选项卡跑一次拼写与语法检查，确认模型链路通畅；再到设置里过一遍写回动作默认值，按团队口径定好批注式还是替换式。

## 怎么确认做成了

- 重启 WPS 后文字端出现察元AI助理与察元AI编审两个选项卡
- 若没有生效，先完全退出宿主软件再重启一次

## 这些坑和边界要知道

边界都在这：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 高频疑问

### macOS 升级后选项卡消失或仍显示旧版？

容器权限或 WPS 运行中安装导致注册表（authaddin.json / jsplugins.xml）没更新到新版本目录。完全退出 WPS ＞ 重跑安装包 ＞ 再打开；仍不行时在有完全磁盘访问权限的终端执行 bash scripts/repair-mac-jsaddons-container.sh（会同步注册表并清理 jsapi 缓存）。

### 「开发工具 ＞ 加载项」列表里出现多个「察元」条目？

多轮升级的残留：macOS 的登记表（authaddin.json）会累积同名条目，官方安装器每次安装都会自动去重并把条目指向当前版本目录——重跑一次最新安装包即可清理。Windows / Linux 的 WPS 按 jsplugins.xml 加载，安装器只更新本产品条目、并清理旧版本目录；若旧条目指向已删除的目录会导致加载失败或回退旧缓存，同样用重装修复。

### 文字端菜单正常，表格 / 演示端却显示了文字端的菜单（或两菜单错乱）？

三个宿主的 Ribbon 配置文件放错位所致（历史上手动拷贝 / 共用目录部署时出现过）。用官方安装包重装一次即可——安装器会按宿主分别放入 chayuan_<版本>、chayuan-et_<版本>、chayuan-wpp_<版本> 并放对各自的 ribbon 配置。

## 补充答疑

### 安装时没注意，WPS 一直开着有没有影响？

macOS 有明确影响：WPS 退出时会用内存里的旧注册状态覆写登记文件，本次安装等于白装（安装器检测到会打印警告）。完全退出 WPS 后重跑一次安装包即可；Windows/Linux 装完后重启 WPS 生效。

### 首次加载时 WPS 弹出「已被修改」类提示？

首次加载察元插件时 WPS 可能弹出该提示，点「确定」继续即可（察元官方部署脚本的既定口径）。

### 功能区完全没有察元选项卡？

按顺序排查：① 完全退出 WPS 再打开（安装后必须重启）；② 核对 jsaddons 路径下有没有 chayuan_<版本> 等目录；③ 「开发工具 ＞ 加载项」里确认「察元 / chayuan」为已启用；④ 麒麟 / UOS 专业版执行 /opt/apps/cn.wps.wps-office-pro/files/bin/quickstartoffice restart。

## 更多操作细节

第 4 步 · 文字端右键菜单入口（辅助确认）

在正文 / 标题 / 表格单元格上点右键：出现「添加到察元」与动态菜单「察元AI文本分析」等察元条目，说明右键注入也已生效。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。

## 一个真实场景

出版社编辑的典型用法：分块并发校对长书稿，术语一致性核对统一叫法，批注式结果逐条确认。编校效率与留痕规范兼得。注意：超长文档分轮处理，每轮按块长 6000 字并发。

## 顺带了解

表单内容预览与文档审计：表单内容预览逐书签查填报情况；文档审计按规则逐书签出风险分级报告。

为什么值得看：收上来的表单先审计再入库，缺项错项一目了然。

## 还有这个能力

连接远程知识库：远程知识库走 chayuan-server 三鉴权（JWT、HMAC、none），凭据 AES-GCM 设备绑定加密。

## 硬口径两三条

- 文字端两个选项卡：察元AI助理、察元AI编审；表格/演示端各一个察元AI助理选项卡
- 本机 MCP 服务 http://127.0.0.1:62588/mcp，源码定义 69 个工具、外部实见 53 个，仅监听回环

## 如实说不足

- macOS 安装器没有完全磁盘访问权限时会出现假成功，需要跑修复脚本
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型

## 定位与家族

察元AI文档助手（Chayuan AI Document Assistant）是一款装在 WPS Office 里的智能加载项，覆盖文字、表格、演示三端：文字端内置 4526 个领域助手（228 个行业领域），提供拼写与语法检查、AI 痕迹检查、保密检查、文档脱密、模板编制等能力，同时在本机 62588 端口开放 MCP 文档智能体服务，支持 Ollama 等离线模型，涉密文档可以全程不出网。同家族产品：察元AI OS（AI 桌面操作系统）、察元AI Office（开源 AI 办公套件）、察元AI 能力广场（aidooo.com）。

## MCP 写确认纪律

本机 62588 端口的文档智能体服务只监听回环；写操作不带确认标记会被拒绝并要求确认，每次确认写记入审计日志。外部智能体（Claude Code、Codex、Cursor 等）一行配置即可接入，代操作文档但不越权。
