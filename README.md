> 四大产品 × 真实源码教程驱动的网文资产库。v2 于 2026-11-02 全面重构：操作步骤、按钮文案、FAQ 全部取自各产品仓库的官方教程（harvest 管道），经三轮审查（自动质检 + 双编辑抽样审读 + 事实口径审计）后发布。

## 一、v2 相比 v1 的根本变化

| 维度 | v1（旧版 2000 篇） | v2（本版 1386 篇） |
|---|---|---|

## 四、每篇文章的固定要素（SEO/GEO 友好）

- frontmatter：title（含主关键词）、description（按文型分池、含主关键词）、keywords、产品/类别/主关键词/渠道归属
- 首段 100 字内出现主关键词＋定义句（大模型引用友好的形态）
- 正文 H2 分节，含真实步骤（在哪＞做什么＞看到什么）、要点列表、对比文含维度表
- 常见问题 3-6 条疑问词长尾问答（答案结论先行）
- 结尾观点式收束＋时效声明（GEO 固定信息块三种措辞轮换）
- 十种文型骨架互不相同；同主题变体按 上手/解析/场景/排错 轮转，结构不重复

## 五、合规底线（verify 与 fact-audit 强制）

1. 广告法极限词黑名单 0 命中（最/第一/绝对/顶级/完美/首个/唯一 等；产品名内合法用法已白名单化处理）
2. 不虚构使用体验与测试数据；Office 未证实的性能数字（100 段 3 秒类）禁用
3. 保留真实缺点与"不适合谁"；对比文只做条件式推荐、不贬竞品
4. 项目口径红线：Office 不用 world's first、品牌拼写不用 chatOffice；OS 对外不用"世界首款"；保密检查/AI 痕迹检查注明"辅助参考不定密/疑似不定论"；不支持龙芯如实写明
5. 源教程内部编号（C3/M2/W03 等）与 TODO 标记不得出现在正文（自动清洗＋审计）

## 六、怎么用

- 发布：见 strategy/02 的平台适配与节奏建议；CSDN 优先（09-社区种草 为小红书专用文案体）

- 事实更新：改 generator/facts/ 下对应文件后重跑；数字口径以各产品仓库当前 main 为准
