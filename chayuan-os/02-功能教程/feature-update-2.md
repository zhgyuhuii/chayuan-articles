# 拆开看应用更新：设置关于里检查更新、下载并重启安装

应用更新的麻烦不在功能本身，在于信息散。升级不丢数据是底线，检查更新静默失败不影响使用。这篇把它收拢成一条能照着走的路径。

## 先弄清楚它是什么

应用更新是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，检查更新是其中面向这类需求的一环。

入口、步骤、验证三段看清，这事就顺了。

## 操作步骤详解

上手按顺序做：（第 2 个切入角度）

1. 在线检查更新
2. 重启安装
3. 数据保留
4. 场景验证：定期升级
5. 场景验证：手动装包升级
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 它的局限也要说清楚

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 常见问题

### 更新会丢数据吗？

不会。安装包只更新程序文件，你的数据根目录不动（帮助中心 ＞ 参考 ＞ 常见问题 FAQ 同口径）。

### 点「检查更新…」却打开了一个网页？

那是网页（浏览器）形态：没有桌面更新桥，按钮降级为打开官方站点页。完整的检查-下载-安装流程需要桌面安装版（察元AI OS 桌面应用）。

### 下载进度一直不动 / 下载中断了？

重新打开关于面板看状态行；若已报错会显示失败原因（网络断续常见），网络恢复后再点一次「检查更新…」重新下载即可。

### 为什么从来不弹更新提醒？

产品采用手动检查模式：不静默检查、不强更。想升级时到 设置 ＞ 关于 点一次「检查更新…」。

## 更多操作细节

验证

1. 升级完成后重新打开 设置 ＞ 关于，等宽版本号应显示为新版本号。
2. 下载过程中可以关掉设置页去干别的；重新打开关于面板会拉取当前更新状态（进度/已下载/出错都会照常显示）。

## 安全与数据边界

安全口径单独立一层：给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，数据文件不受影响；三条路都不满足就只能清数据重装，务必提前生成恢复密钥，需要提前开启并积累足够记忆数据。

## 平台与形态
