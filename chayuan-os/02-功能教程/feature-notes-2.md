# 富文本笔记：备忘录在哪里

富文本笔记的麻烦不在功能本身，在于信息散。比便签正式、比文档轻量，随手记的中庸之选。这篇把它收拢成一条能照着走的路径。

## 先弄清楚它是什么

为什么要有富文本笔记：比便签正式、比文档轻量，随手记的中庸之选。备忘录的定位是富文本笔记应用，图文混排。

下面直接进正题。

## 原理与设计取舍

设计上的动机值得单独说：比便签正式、比文档轻量，随手记的中庸之选。

能力面拆开看：快速检索，富文本。

从提问口径看，用户最关心的是备忘录在哪里？怎么新建一条笔记？

## 完整操作步骤

按最短路径验证一遍：

1. 新建备忘

窗口分两栏：左侧列表栏（顶部「新建」按钮 +「搜索…」框，下面是笔记列表）；右侧编辑区（标题 + 正文 + 底部字数）；窗口标题行有红绿灯和侧栏开合按钮，窄窗口时列表栏收进侧栏槽（用开合按钮切换）。

点左栏顶部琥珀色「新建」按钮 ＞ 列表最上方出现一条新笔记（默认标题「新备忘录」），右侧编辑区自动选中它，光标在标题框。

4. 删除备忘

选中笔记后点编辑区标题行右侧的垃圾桶按钮（悬停提示「删除」）＞ 该笔记从列表移除，自动切到相邻的一条（没有其他笔记时编辑区显示空态图标）。

## 注意事项与真实边界

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 你可能会问

### 备忘录支持富文本吗（加粗/列表/贴图）？

不支持。正文是纯文本编辑器；需要格式和插图请用文档编辑（双击 .docx 用察元AI Office 打开），需要贴图片/视频用便签。

### 删除能撤销吗？

不能。删除即时生效且没有回收站，删前确认内容不再需要。

### 能让 AI 帮我记吗？

可以。智能体经 notes_list / notes_get / notes_create / notes_update / notes_delete 工具直接读写备忘录，与应用同一数据源、实时同步——对它说「记一条备忘」即可。

### 备忘录、便签、Office 文档该用哪个？

纯文字速记且要常驻眼前 ＞ 便签（桌面贴纸，可贴图）；纯文字速记但不需常驻 ＞ 备忘录；需要格式（加粗/表格/插图）或正式成文 ＞ 双击 .docx 用察元AI Office 编辑。

## 更多操作细节

2. 编辑内容

右侧编辑区自上而下三块：

每条笔记自动保存（停止输入约 0.4 秒后落盘），无需手动保存。

1. 标题输入框：占位「标题」；
2. 正文输入区：占位「开始书写…」，纯文本多行输入（不支持富文本——加粗、插图等格式功能没有，需要富文本请用文档编辑器）；
3. 底部字数：显示「{n} 字」（正文字符数）。

## 更多操作细节

3. 列表与搜索

1. 左栏列表每行显示：笔记标题（空标题显示「无标题」）、更新时间（月/日 时:分）和正文前 18 字预览；点行切换到该笔记；
2. 顶部「搜索…」框输入关键词，按标题+正文即时过滤；没有结果或没有笔记时显示「暂无备忘录」。

## 更多操作细节

验证

1. 点「新建」＞ 输入标题和几行正文 ＞ 切到别的笔记再切回来，内容还在（自动保存生效）；关闭窗口重开「备忘录」，笔记仍在；
2. 在「搜索…」里输入正文中的关键词 ＞ 列表只剩匹配的笔记；
3. 对智能体说「帮我记一条备忘录：路由器管理密码是 xxx」＞ 备忘录列表实时出现该笔记。

## 放回产品盘面看

把富文本笔记放回察元AI OS的整体盘面：以完整桌面环境为壳，（web/Docker 形态网页桌面默认端口）；暂不支持龙芯平台；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 安全与数据边界

安全口径单独立一层：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址；代理只监听本机回环，跨机访问需要另行打通；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 平台与形态

平台与形态的账：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，每次产出 markdown 报告落盘归档，markdown 报告归档，富文本笔记应用，图文混排。

## 价格与授权

价格口径一并交代：离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）；跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；需要相应平台的 Key（部分有免费额度），形象可从灵宠商店免费获取，也可工坊自定义；内置场景免费切换。

## 产品家族与搭配

察元AI OS不是单打独斗：购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，富文本笔记应用，图文混排；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 几条硬数字

能落到数字上的几条：很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，概念页解释模型代理机制，默认对话模型选择；重跑入口在设置＞模型＞设置向导，想换默认模型随时可以在设置里重跑向导，不用重装。
