# 模型加载失败或内存不足？

这个问题在被反复问到，这里给一个完整、可执行的回答。

## 直接回答

系统有内存预算线（总内存的 45%）保护：卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

## 背景与原因

理解这个问题的关键，是先知道察元AI OS的整体设计：察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 如实说说它的不足

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 常见问题
### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。
