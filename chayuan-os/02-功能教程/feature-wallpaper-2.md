# 桌面壁纸为什么这样工作：静态壁纸库、动态壁纸

桌面壁纸这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决深色主题配暗壁纸。

## 换壁纸是个什么东西

为什么要有桌面壁纸：壁纸是最直接的个性化出口，动态壁纸让桌面活起来。换壁纸的定位是静态壁纸库、动态壁纸（vanta、matrix、galaxy 等）、在线壁纸、灵宠工坊场景联动；入口在桌面右键更改墙纸或设置壁纸页。

下面直接进正题。

## 具体怎么操作

按最短路径验证一遍：

入口一：桌面右键（推荐）

「灵宠工坊」——内置主题包场景（当前内置「星穹工坊」「晶核庭园」）加已从商店安装的场景。点选后桌面整体切进该场景世界：背景换为场景视频/大图，图标配色、灵宠皮肤随包联动。

「动态壁纸」——11 款 GPU 实时渲染的动画壁纸：「Matrix 数字雨」「Matrix 3D」「Hexells」「Vanta Waves」「Vanta 线框」「Milky Way 银河」「粒子星云」「北极光」「烟花」「星际穿梭」「流体渐变」。点选即挂载，其中「Milky Way 银河」还带鼠标移动视差。

「静态壁纸」——这一组放两张特殊卡：「视频壁纸」（弹文件选择器选本机视频，视频存入本地库后循环播放铺满桌面）和「轮播壁纸」（把内置壁纸集随机洗牌轮换，每 30 秒自动换一张）。

「在线壁纸」——4 个在线图源，按各自节奏自动取新图：「NASA 每日天文」（每天一换）、「芝加哥艺术博物馆」「大都会艺术博物馆」（名画随机，每小时一换）、「Lorem Picsum」（随机照片，每小时一换）。断网时保持当前壁纸不动。

「壁纸库」——42 张内置注册表壁纸，按「主题 · 名称」命名（察元二十景：星夜卷/晴日卷/山海卷/前沿卷，加 screen 精选）。缩略图右上角带「在线」徽标的条目本机不带高清原图，点选后经服务器拉取高清（离线时显示内嵌压缩版）。出厂默认壁纸为「晴日卷 · 星穹工坊」（cy-starforge）。

1. 在桌面空白处（不要点在图标/挂件上）点鼠标右键，选「更改墙纸…」。
2. 弹出「选取墙纸」窗口，从上到下分五个分组，点任一缩略图立即生效并关闭窗口：
    1. 想用自己电脑里的图片：点窗口底部「从文件选取…」按钮，选一张图片。超大图片会自动压缩到不超过 1920×1080 再保存；仍存不下时弹出「图片过大，无法设为墙纸。请尝试较小的文件。」。
    2. 点「取消」放弃修改；按 Esc 先关掉壁纸窗、再按一次收起右键菜单。

入口二：设置 ＞ 通用

从场景世界切回普通壁纸：在任一入口选一张普通壁纸即可——选普通图片时灵宠场景联动自动退出，桌面回到纯壁纸形态。

顺带：文生图应用生成图片后可直接「设为壁纸」；智能体也能替你换壁纸（系统技能里的 system_list_wallpapers / system_set_wallpaper 工具，按壁纸库名单寻址）。

1. Dock 点「设置」，进左栏「通用」分区。
2. 「壁纸」卡是 4 列缩略图网格（与右键选择器的「壁纸库」同源，42 张），当前壁纸带蓝色边框高亮，点任意缩略图即切换。

## 边界先摆桌面上

用之前要认的账：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 接着回答几个常见问题

### 动态壁纸点了一点反应都没有？

动态壁纸依赖 WebGL，且在 设置 ＞ 辅助功能 开了「减弱动效」后不再可用（自动回落静态壁纸）。到 设置 ＞ 辅助功能 关掉「减弱动效」再试；仍不行多为显卡驱动/虚拟机不支持 WebGL。

### 带「在线」徽标的壁纸选中后是模糊的？

这类条目本机只有压缩缩略图，高清原图要从服务器拉。联网后重新选中一次即可拉到高清；离线状态下就用内嵌压缩版显示。

### 在线壁纸一直不换图？

在线壁纸按图源节奏换图（NASA 每日、其余每小时），且断网时静默保持当前壁纸。确认网络可用；也可以先切到别的壁纸再切回该图源，触发立即取图。

### 视频壁纸选完视频后没生效？

视频文件存本地索引库（IndexedDB），浏览器隐私/无痕模式下可能写入失败，此时保持原壁纸不变。换用桌面形态、正常模式重试。

## 更多操作细节

验证

1. 任一入口点选壁纸后，桌面背景立即变化（动态壁纸可见动画开始播放）。
2. 打开 设置 ＞ 通用 ＞ 「壁纸」卡：蓝色边框应停在新选的壁纸缩略图上。
3. 切换到「在线壁纸」任一图源后，等其刷新周期（如 Lorem Picsum 1 小时）到点，壁纸自动换成新图（保持不变说明取图失败、正沿用旧图）。

## 补充答疑

### 选了灵宠工坊的场景后桌面图标颜色也变了？

这不是 bug：主题包场景会联动图标配色与灵宠皮肤（整套变装）。只想换背景不想要联动，见对应教程 的「选场景时一并切换」开关。

## 动手前再核对一遍

- 桌面形态（察元AI OS）。右键壁纸选择器与设置壁纸卡都是桌面能力。
- 动态壁纸需要 WebGL 可用，且未开启「减弱动效」（设置 ＞ 辅助功能 ＞ 「减弱动效」开启后动态壁纸不可用）。
- 在线壁纸、壁纸库中带「在线」徽标的条目需要联网；取图失败时静默保持当前壁纸，不报错不闪屏。
