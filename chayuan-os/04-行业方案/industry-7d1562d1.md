# 咨询调查行业怎么用察元OS：从痛点到落地

咨询调查行业的文档与信息工作有其固有节奏：对外材料有保密与合规要求，外发前自检环节薄弱。察元AI OS在咨询调查场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出咨询调查行业的完整应用路径。

## 咨询调查行业的典型痛点

- 对外材料有保密与合规要求，外发前自检环节薄弱
- 临时性、突击性材料多，加班赶稿是常态
- 文档量大、格式要求严，人工处理占用大量时间

## 对应的能力组合

- **本地知识库**（本地知识库）：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。
- **壁纸库与主题**（桌面美化）：205 张 HD 壁纸库（含明暗与主题元数据）+ 动态壁纸/视频壁纸设置，深浅主题切换、界面缩放 85%-130%。
- **webwindows 智能体开窗**（智能体窗口）：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。
- **技能页签与技能商店**（技能商店）：技能管理页签：启停（改写 SKILL.md 元数据）、打开目录、删除（入废纸篓）、tar.gz 离线导出导入；技能商店可搜索 GitHub 技能仓库一键安装（内置 anthropics/skills 等精选）。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按出差/远程办公者场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 常见问题
### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。
