# 按项目选趁手的智能体：智能体管理概念与上手

智能体管理要管什么？说到底是三件事：装得上、配得对、管得住。这篇按定义、口径、边界的顺序逐段展开，结论自己下。

## 什么是智能体管理

智能体管理，指对机器上多家 CLI 智能体的安装、配置与权限统一打理。这套 AI 桌面操作系统把本地大模型、知识库、智能体、宠物群聊装进一个桌面，管理入口就在系统层。三件事拆开说：装得上，指一键完成安装与升级、装完自动进入管理视野；配得对，指模型地址、密钥、技能同步一次下发；管得住，指权限有分级、操作有审计，谁干了什么查得到。

## 按项目选智能体的思路

选型思路很朴素：先用能力矩阵筛出支持所需能力的几家，再拿同一个真实任务各跑一遍，对比产出与耗时，最后看记忆与配置迁移的成本。能力矩阵一目了然、新装约 5 秒自动感知，这些机制把第一步的成本压到几乎为零。别迷信单一「最强智能体」的说法——不同家在代码质量、工具调用、记忆采集上的强弱项错着位，项目类型一变，排名就可能重排。矩阵只是初筛，最终拍板还得靠你自己项目里的两三次实测。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 应用管理：应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌。
- 插件与技能管理：插件启停卸载、离线安装；项目与用户技能清单管理、离线导出导入。
- 桌面右键菜单：桌面空白处右键：新建、上传、更改墙纸、小组件、便签、图标大小与排序、添加快捷……

## 先确认自己不受这几条限制

- 8GB 内存的机器，一次加载一个对话模型为宜，复杂任务会受限
- 龙芯平台还没适配；本地不做视频生成，视频生成由云端路由
- 云端厂商模型要调，得自备 API Key
- Docker 云桌面、跨终端互联属于进阶形态，需要些动手功夫

这些边界不妨碍日常使用，选型前过一遍，心里更有底。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 智能体管理的两个高频问题

### 智能体管理离线还能做吗

管理动作大多在本机完成；web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作，插件走全生命周期管理，账户隔离、数据在服务器侧统一管理。

### 智能体管理数据存在哪

数据目录自选，整个系统可以装在非系统盘，换机迁移就是拷目录。

## 一句收束

智能体管理有没有必要上系统层，看你机器上智能体的数量：一两家无所谓，七八家开始，统一管理就是刚需。

## 让智能体用上系统能力

它能把应用造出来挂上桌面，桌面本身能被 AI 定义，能力边界从预装走向按需生成；搜索能力不绑定单一平台。文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一。配置上，本机统一 OpenAI 兼容出口（127.0.0.1:52581），智能体只配一个地址。智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。入口统一之后，批量升级、权限回收这类事才能一次做完。排障口径：Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 桌面、跨机与兜底

Dock 是使用频率最高的区域，位置与大小顺眼很影响手感；设置桌面与 Dock 可调位置、自动隐藏、图标放大与大小、开机自动打开 Harness，Dock 也能直开内置的察元AI Office，文档、表格、演示在线编辑。内置浏览器窗配合 webwindows 可被智能体驱动，不装第三方浏览器也能完成网页操作。跨机协作：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力），让 B 机器的智能体替你跑任务，结果回传，人不用挪窝。兜底两条：联网搜索的配置入口在设置＞默认模型＞网络资源页签，默认内置 web_search 工具多档兜底；设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态——模型配置改乱了、服务起不来，回到出厂态是最干净的自救手段。遥测可整体开关；清除桌面数据属破坏性操作，界面带警示。
