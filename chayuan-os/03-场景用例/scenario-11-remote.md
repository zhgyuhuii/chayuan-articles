# 出差/远程办公者的远程办公方案（完整方案）

如果你是出差/远程办公者，下面这些场景大概率不陌生：外面连不回公司机器。手机连回你的 AI 工作站。这篇完整方案以察元OS为工具，把这个岗位的远程办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 外面连不回公司机器
- 手机上没桌面环境
- 临时要处理文件

## 用察元OS怎么解：工作流拆解

1. 云通道连接设备
2. 手机浏览器 /m/ 入口
3. 远程查看与操作

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「云通道连接设备」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。手机连回你的 AI 工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 需提前配置云通道
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- API Key safeStorage 加密存储，仅注入子进程

## 常见问题
### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。
