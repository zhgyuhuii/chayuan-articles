# 察元OS插件页签（三源）使用指南（插件市场）（细节版）

插件市场是察元AI OS里使用频率很高的一项能力。它的「插件页签（三源）」这样工作：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。

从任务视角看，它对应的关键词是「插件市场」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 应用管理→插件页签
2. 切换源与分类筛选
3. 一键安装/卸载/排序

## 实用技巧

- 国内网络切 npmmirror 源更顺

## 注意事项与边界

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 云厂商模型调用需自备 Key，免费额度视厂商政策

## 常见问题
### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 和察元AI Office 什么关系？

Office 以内置插件形态运行在察元AI OS 中；购买 OS 授权后同机 Office 自动免激活。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
