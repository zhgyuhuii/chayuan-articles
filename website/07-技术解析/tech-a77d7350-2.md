# Docker 私有化部署形态（实操要点）

这是「能力广场技术解析」系列的一篇。Docker 私有化部署形态是理解这款产品设计哲学的关键切面——看完你会明白它为什么这样设计、这样设计换来了什么、代价是什么。

## 一句话结论

整套门户支持 Docker + nginx 私有化部署：SQLite 数据目录挂载持久化、SSR 快照层随容器更新、rsync 生产同步方案有完整文档。政企拿到的是「自己的 aidooo.com」——数据、升级、审计全自主。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。
