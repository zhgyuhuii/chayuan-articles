# 语音开会记录神器：桌面级录屏，说实话

边说边出字还不联网。用了两周，认真说说感受，好的坏的都讲。

先交个底：语音开会记录神器在察元AI OS里的形态一句话说清：桌面右键录制屏幕；语音记录是录音加转写加保存位置设置，贴顶长条边说边出字。

## 我的使用顺序

1. 在哪里：桌面空白处右键 ＞「录制屏幕」。录音/录屏进行中时该菜单项变为「停止录制」。
2. 看到什么：屏幕中上部弹出「录制屏幕」选择器，分四段：
3. 「整屏」：桌面形态逐台列出物理显示器（单屏显示「主屏幕」，多屏显示「显示器 1」「显示器 2…」并标注分辨率）；浏览器形态显示「选择要录制的内容…**」（提示「浏览器将弹出系统选择框」）；
4. 「页面（本系统窗口）」：列出当前打开的察元OS 应用窗口（提示「录制中拖动窗口裁剪跟随」——录的是窗口区域，拖动窗口画面跟着走）；没有窗口时显示「当前没有打开的窗口」；

## 也要说实话

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

适合谁：会议全程记录、口述灵感收集这类需求的人。不适合谁：上面几条缺点正好戳中的场景，别硬上。

## 评论区高频问题

### 点「开始」没反应/弹「无法访问麦克风」？

检查系统与浏览器麦克风权限（弹「无法访问麦克风：请检查系统与浏览器麦克风权限」）；语音记录同一时间只允许一个录音任务，前一段还没结束就再点开始会提示「已有录音任务进行中」。

### 语音记录存哪由什么决定？

设置小窗「保存位置」：选「当前文件夹」时存到录音开始那一刻最近打开的文件夹（如我的电脑正浏览的目录），取不到回落桌面 Recordings；选「桌面 Recordings」则固定存 Recordings 目录。录屏不受此设置影响，永远存 Desktop/Recordings。
