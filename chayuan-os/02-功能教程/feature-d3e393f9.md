# 开发者的一站式工作站：速查手册

四家 CLI 并行、配置集中管理。这套组合工作流把四家 CLI 智能体→智能体管理→终端与文件管理串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

四家 CLI 并行、配置集中管理。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·四家 CLI 智能体**：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。

1. 打开任一智能体应用
2. 绑定工作区目录
3. 在 pty 终端里对话干活，多标签并行

**第 2 步·智能体管理**：安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。

1. 应用管理→智能体
2. 安装或更新四家 CLI
3. 切换供应商档案并测试连通

**第 3 步·终端与文件管理**：zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。

1. Dock 打开终端/我的电脑
2. 日常文件与命令行操作
3. 配套编辑器查看各类文件

## 衔接点与易错处

- 无模型偏好时自动指向本地模型，不配 Key 也能跑
- 配置备份还原适合重装与多机同步
- 终端会话持久，重开不丢历史

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- Docker/云通道等进阶形态需要一定动手能力

## 常见问题
### 升级会丢数据吗？

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。

### 手机能用吗？

手机浏览器通过云通道 /m/ 入口远程查看与协助；另有 Capacitor 安卓壳方案。

### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。
