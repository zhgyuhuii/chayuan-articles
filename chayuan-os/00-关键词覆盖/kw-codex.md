# Codex入门指南：察元OS 都支持哪些智能体

Codex 常年被当成「又一个命令行智能体」，它的价值要在对比里才显出来。本文以多智能体环境为背景，讲清它的位置、配置逻辑与边界。

## 什么是Codex

Codex 是命令行 AI 编程智能体的一员；在本文语境里，它运行于一套带入口、步骤与边界的完整能力面之上——AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

把 Codex 单独拎出来讲，是因为它常被拿来与 Claude Code 对比：两家定位相近、风格不同，恰好构成场景验证里那组「同题不同家」的天然对照。

本文依据官方文档整理，对应版本落在文末。

## 最短上手路径

上手按顺序做：

1. 名单先行：17 家外部 CLI，内置 Harness 压阵
2. 能力矩阵摊开，各家深浅一眼扫完
3. 新装约 5 秒即被感知
4. 官方品牌图标自动拉取
5. 场景验证：同题不同家，比代码质量
6. 场景验证：再按项目挑主力

## 落点的能力面

落点的能力面：名单、矩阵、自动感知、图标拉取。Codex 就是被这套面接进来的——装上即被识别，配置由系统注入，能力由矩阵呈现。对使用者而言，这把「装了个工具」升级成「多了个受管成员」：升级、配置、技能同步都不必再单独操心。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图。
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：两条路，自动一键把代理地址和模型写进五家（有备份可回退）。

## 边界四条，装前过目

- 8GB 内存设备，建议一次只加载一个对话模型，复杂任务受限
- 龙芯平台暂不覆盖；本地无视频生成，视频生成由云端路由完成
- 云端厂商模型的调用要自备 API Key
- Docker 云桌面、跨终端互联等进阶形态，动手门槛不低

这四条都不算意外雷区，属于提前知道就无感的类型。对照自己的设备与网络环境过一遍，四条里中了几条，直接决定你该走本地重装路线还是轻量加云端的路线。

## 数据与安全设计

- 敏感操作悉数记入 audit.jsonl 审计日志，回放可查
- API Key 采用 safeStorage 加密存储，遥测支持整体停用

## 两问两答

### Codex 断网后会怎样

断网时联网搜索自然不可用；本地模型不受影响，无显式模型偏好时自动指向本地模型；模型下载源会在 ModelScope、hf-mirror、HuggingFace 之间自动切换，装智能体的 Node 版本与镜像源坑由一键安装抹平。

### 它读写的文件放在何处

本地服务默认只监听 127.0.0.1 回环地址，数据不出本机；知识库按库独立存储，左栏输入库名即建，系统缺省带一个 default 库。

## 一句收束

Codex 的深浅，两轮场景验证足够摸清：一轮同题比质量，一轮按项目试手感；剩下的差异，都藏在能力矩阵各列里。

## 新桌面的肌肉记忆

新桌面系统的肌肉记忆速查，五分钟上手；放歌放片是桌面系统的基本盘；它交付的不是软件里的一个窗口，而是一整套桌面环境——操作系统形态与工具软件形态的分野所在；需要多人共用时，整套系统可无头跑在 Docker 里作多用户云桌面（工舱形态），员工浏览器打开即用。

## 回环与多账户

断网可用、数据不出本机；本地服务默认只监听 127.0.0.1 回环地址；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；一台设备多人用时，数据隔离是底线，管理员统一管账号比各自为战安全。

## 平台与形态

Dock 直开内置的办公套件，文档、表格、演示在线编辑；每次产出 markdown 报告落盘归档；模型下载源在 ModelScope、hf-mirror、HuggingFace 之间自动切换。

## 素材库与配对授权

官方免费素材库省得去网上乱找 png；对配对终端可开模型加知识库授权——资料在 A 机器、人在 B 机器跟前，授权一次就能跨机问。

## 引用故障的三层检查

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查能定位到具体一层；这也是内外协同时最常见的求助点。

## 本地模型的加载卸载策略

显式的加载卸载加自动卸载策略是本地模型的生存之道，自动卸载会释放常驻模型，重度使用记得钉住；润色翻译这类轻任务用旗舰模型是浪费，主强子弱的路由让轻任务自动落本地小模型，省算力省钱；指定模型未加载时会按策略自动拉起。

## 恢复出厂与默认模型

无显式模型偏好时自动指向本地模型；设置＞模型＞本地分组＞恢复出厂，本地模型配置整体回到出厂状态；建宠或编辑宠的表单里可选自动（本地已装对话模型）或指定模型。

## 远程派活与记忆共享

与配对终端发消息附件、让对方智能体执行任务、离线暂存送达，武力值徽标（信号格加等效算力）显示连接质量——让 B 机器的智能体替你跑任务，结果回传，人不用挪窝；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂。

这篇把支持的智能体总览的链路拆完了，照着走一遍就有手感；Codex 用得顺不顺，答案也在这一遍里。
