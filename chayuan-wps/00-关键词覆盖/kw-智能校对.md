# 智能校对入门指南：全文校对分块并发

搜智能校对的人，多半在两件事上犹豫：这玩意是不是噱头、装了值不值。这篇不替你站队，定义、口径、边界依次摆开，你自己对号入座。

## 什么是智能校对

智能校对这个说法对应的产品是察元AI文档助手（Chayuan AI Document Assistant）：WPS 三端智能加载项，校对、编审、核对、脱密，一个文档智能体。

写作时对照的是官方说明与源码教程，核对的截止时间放文末尾注。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| assistants | 文字端 4526 个领域助手、228 个行业领域；表格端 66 个配方；演示端 81 个；翻译 52 语种动态菜单 |
| 文字端两个选项卡 | 察元AI助理、察元AI编审；表格/演示端各一个察元AI助理选项卡 |
| mcp | 本机 MCP 服务监听 62588 端口（回环地址，路径 /mcp），源码定义 69 个工具、外部实见 53 个 |
| kb | 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源 |
| proofread | 全文校对分块并发，块长默认 6000 字；超过 12000 字分档提示 |

## 平台与形态

平台覆盖：Windows（x64/arm64）、macOS（arm64/x64）、Linux deb（x64/arm64，麒麟/UOS 支持飞腾/鲲鹏）。

## 在察元AI文档助手里落在哪

智能校对在察元AI文档助手里的落点是拼写与语法检查：AI 助手组的大按钮，有选中只查选中，无选中弹确认框对全文执行（超 12000 字与 30000 字分档提示）；独立进度窗分块并发（块长默认 6000 字），关窗任务继续；结果批注写明「错别字建议改为某词」，锚不到原文不硬挂。

为什么值得单独说：分块并发让长文档校对不再超时，批注式结果方便逐条确认。

## 最短上手路径

试一遍就明白，先读进度窗：

1. 看到什么：独立提示窗，标题「拼写与语法检查」（选区模式为「拼写与语法检查（选中）」），标题旁状态徽章：准备中 / 进行中 / 已完成 / 失败 / 异常结束 / 已停止。
2. 副标题固定一行：「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」
3. 进度区：「正在检查：第 x / y 段」+ 百分比进度条 +「当前检查内容」卡显示正在检查的原文片段。
4. 右上按钮：「停止任务」（仅任务运行中显示）和「关闭」。
5. 完成时显示「已完成，共添加 N 处批注」，随后提示「即将自动关闭」并自动关窗；停止后显示「任务已停止」。
6. 底部提示：「可在「任务清单」中查看详细进度；关闭此提示窗不会停止任务。」

## 落点的能力面

- 选区全文两档
- 分块并发
- 批注锚定

## 能力地图：从下载到跑起来

- 下载与安装：Windows 自解压 exe、macOS 的 pkg（建议先完全退出 WPS 再装）。
- 在 WPS 中启用：装完完全退出并重启 WPS，文字端出现察元AI助理与察元AI编审两个选项卡。
- 首次配置接上模型：欢迎页立即配置模型：默认开启 OpenAI、Ollama、DeepSeek、百度云千帆、阿里百炼五家，本地默认端口 Ollama 11434、LM Studio 1234、Xinference 9997、FastChat 8000，带 Ollama 一键安装引导。
- 拼写与语法检查：AI 助手组的那个大按钮，有选区就只查选区。
- 智能提取字段：智能提取让 AI 从样例文档抽字段自动生成表单规则，再人工微调。
- 启动本机 MCP 服务：跑在回环地址的 62588 端口，随加载项启动。

## 不急着装的理由

- 脱密、复原、保密检查、涉密关键词提取四项收付费，免费额度一点没有
- 占位替换可以还原，代价是密码必须记得；密码一丢，免密恢复不存在
- 全文要送到所配置的模型手上，涉密文档建议先切到本机离线模型
- macOS 安装器缺完全磁盘访问权限时会假成功，要跑修复脚本才能装进去

这些都不动主线功能，装之前心里有这份清单，选型时就不被动。

## 数据与安全设计

- MCP 服务只监听 127.0.0.1，写操作不带 confirmed 标记会被拒绝并要求确认
- 凡是确认过的写操作，audit.jsonl 审计日志逐条记录
- 保密检查是辅助筛查：关键词命中既不等于泄密，也不构成定密结论
- 脱密恢复载荷以 AES-GCM-256 加密后随文件存放，凭密码还原原文

## 价格口径

- 免费额度每日发放，对话、助手各自一个池，次日重置
- 文档脱密、脱密复原、保密检查、涉密关键词提取四项为付费专属、零免费额度；时间授权与次数授权两种形态，序列号本地验签激活、绑定 16 位设备指纹

## 五问五答

### 关闭进度窗后任务还在跑吗？

在跑。副标题写明「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」关窗不影响检查；只有点「停止任务」（或任务清单里的停止）才会中止。

### 为什么有些“病句”没被报出来？

检查提示词只报「明确可证实的错别字、语法错误、标点误用、固定词误写、搭配错误」，明确排除风格偏好、口语化、语气优化等主观润色项，避免误报。需要文风润色请用「文本分析 ▾」里的相关功能。

### 长文档检查很慢，能提速吗？

检查按块分片进行，默认块长约 6000 字。从工具栏发起的检查要边查边写批注，逐块串行执行；通过文档智能体发起的校对（先出预览、你确认后再落笔）按并发设置执行（默认并发 3，可调 1–8，当前版本这两个参数暂无设置界面）。最有效的提速是给检查指定一个更快的「拼写与语法检查模型」。

### 装完选项卡不出现？

按三步排查：确认 jsaddons 目录里有察元文件；完全退出 WPS（含后台进程）再重启；开发工具的加载项列表里确认察元已启用。

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

## 一句收束

智能校对值不值得用起来，就看你手头的文档量与出错率：经常整篇长文要过一遍的，分块并发这一项就值回注意力；偶尔改几个字的，先别折腾。
