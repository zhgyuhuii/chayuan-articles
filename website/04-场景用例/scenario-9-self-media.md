# 写给自媒体/内容创作者的AI选题指南：完整方案

如果你是自媒体/内容创作者，下面这些场景大概率不陌生：选题灵感枯竭。内容人的选题弹药库。这篇完整方案以能力广场为工具，把这个岗位的AI选题工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 选题灵感枯竭
- 素材与数据难找
- 热点跟不上

## 用能力广场怎么解：工作流拆解

1. 排行榜追热点项目
2. 资讯板块找选题
3. 活动板块蹲发布节点

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「排行榜追热点项目」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。内容人的选题弹药库。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
