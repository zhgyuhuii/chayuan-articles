# 聚焦搜索怎么用：键盘党的启动器

聚焦搜索这件事，值不值得专门学一篇，看一个细节就够：三类对象混合搜。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 为什么值得了解

有个问题想快速问一下自己的知识库，不想专门开知识库应用，应用装多了找不到入口，想敲两个字母就打开应用，记得某个文件名片段、或只记得文档里的某句话，想全文搜出来直接打开；不确定文件在哪全盘搜。

## 具体怎么操作

第 1 步 · 唤起与关闭

1. 做什么：按 ⌘K（macOS）/ Ctrl+K（Windows/Linux），或点菜单栏右侧的放大镜按钮（悬停提示「聚焦搜索」）。
2. 看到什么：屏幕中上部弹出居中搜索面板，输入框占位符「搜索应用、文件与内容…」，输入框右侧是麦克风按钮和 esc 键位标注；再按一次 ⌘K/Ctrl+K、按 Esc 或点面板外深色遮罩即关闭。

第 4 步 · 语音输入

1. 在哪里：输入框右侧麦克风按钮（悬停提示「语音输入」）。
2. 做什么：点一下开始说话（按钮变红方块、脉动闪烁）；说完再点一下（方块）结束，最长 30 秒自动截止。
3. 看到什么：录音经本机语音模型（whisper 类 audio-stt）转写，识别文字自动追加到搜索框里（与已有内容以空格拼接）并保持输入焦点；转写失败弹出错误提示。

第 5 步 · 剪贴板里的「问 AI」直达

1. 在剪贴板面板等入口选择「问 AI」时，Spotlight 会带该文本自动打开并直接发起知识库直答（同一张答案卡），无需再输入。

## 关键能力点

- 三类对象混合搜
- 问 AI 直答卡
- 语音输入入口

## 边界先摆桌面上

边界先摆在桌面上：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

## 高频疑问

### 「内容」段一直不出结果？

正文搜索要求关键词 ≥2 个字符，且走宿主文件系统扫描（约 450ms 防抖）；无文件系统后端的形态（部分网页部署）只有「应用」段可搜。文件名搜索则 1 个字符就起。

### 按 Tab 没反应？

Tab 直答同样要求输入 ≥2 个字符（「问 AI」行动行出现时才生效）；答案卡显示期间键盘导航被停用，此时只能点按钮或按 Esc 关闭。

### 「问 AI」报错？

直答依赖知识库服务与默认库 default：先到知识库应用确认库里有已「加载」的文档、知识库服务正常；报错只影响直答，应用/文件/内容搜索照常可用。

## 更多操作细节

第 2 步 · 搜应用 / 文件 / 内容

1. 做什么：输入关键词（1 个字符起即搜应用与文件名；≥2 个字符才追加正文内容搜索）。
2. 看到什么：结果按分段标题分组，顺序为「应用」（最多 6 条，前缀命中优先，行尾显示「打开应用」）＞「文件」（最多 8 条，行尾显示文件路径）＞「内容」（最多 6 条正文命中，行尾显示「路径 : 行号」）；命中关键词黄色高亮。搜索中输入框旁显示「搜索中…」；没有结果时显示「无结果」；目录太大被截断时底部提示「结果已截断（目录过大）」。
3. 键盘操作： 移动选中行（蓝底高亮），Enter 打开选中项——应用行直接开应用，文件/内容行按系统默认方式打开该文件。
4. 行为细节：文件名搜索约 150ms 防抖、正文搜索约 450ms 防抖后发出，由宿主在真实文件树上扫描。

## 更多操作细节

第 3 步 · 「问 AI」知识库直答

1. 做什么：输入 ≥2 个字符的问题后，结果顶部会出现一条带星光的「问 AI」行动行（行尾提示「知识库直答 · Tab」）。对其按 Enter、Tab 或鼠标点击。
2. 看到什么：结果区切换为答案卡——问题发给知识库问答引擎，答案流式打出（生成中显示「回答生成中…」），来源文档以 [编号] 文档名 小标签列出；生成完毕下方一排按钮：
    1. 「继续对话」：问题复制进剪贴板（提示「问题已复制，粘贴到会话继续」）并打开 DeepSeek Harness 会话窗，粘贴即可继续追问；
    2. 「知识库详情」：打开知识库应用；
    3. 「朗读」/「停止朗读」：语音朗读答案（系统 TTS）；
    4. 「返回搜索」：回到搜索结果列表。
    5. 分支：知识库不可用时答案卡显示红色错误信息——搜索功能不受影响；答案卡显示期间键盘导航停用（Esc 仍可关面板），关闭后重新打开面板会回到干净的搜索状态。

## 更多操作细节

验证

1. 按 Ctrl+K（或 ⌘K）面板弹出、再按一次关闭——两次按键即完成开合。
2. 输入一个已装应用名的前两个字母，「应用」段应出现该应用，Enter 直接打开。
3. 输入一个知识库文档里出现过的词组，按 Tab——答案卡流式打出答案并带 [1] 文档名 出处标签。

## 补充答疑

### 语音输入点了没反应/报错？

语音输入走本机 audio-stt 模型服务：没装语音模型或模型未加载时会转写失败并弹错误提示，到 设置 ＞ 模型 安装并加载语音识别模型后重试；另请检查系统麦克风权限。

### 搜索结果里的文件能直接打开吗？

能。Enter（或点击）文件行、内容行都会以系统默认打开方式打开该文件；内容行还会带你命中的那一行上下文（行尾「路径 : 行号」）。

## 动手前再核对一遍

- 桌面形态（察元AI OS）或可用的 web 形态；任何形态都能搜应用，文件/内容搜索需要宿主文件系统后端（无后端形态只搜应用）。
- 「问 AI」直答依赖知识库服务（/api/chatop-kb/ask）与默认知识库 default：知识库没启用或没加载文档时会显示错误（不影响搜索本身）。
- 语音输入依赖本机语音模型服务（audio-stt 转写接口）；没装语音模型时按钮会报错提示。
