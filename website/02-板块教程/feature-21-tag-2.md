# 标签聚合页怎么用：能力广场新手入门

标签聚合是察元AI 能力广场里使用频率很高的一项能力。它的「标签聚合页」这样工作：受控词表的标签聚合页：同一主题跨板块资源汇总（≥20 条资源的标签才进 sitemap）。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

受控词表的标签聚合页：同一主题跨板块资源汇总（≥20 条资源的标签才进 sitemap）。

从任务视角看，它对应的关键词是「标签聚合」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 点击任意标签进入聚合页
2. 浏览同主题资源
3. 配合筛选细化

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。
