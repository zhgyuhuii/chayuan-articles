# 内网AI部署是什么：AI 桌面操作系统

内网里跑 AI，难点从来不是装不上，而是处处默认你联着网：下载、激活、更新、找回账号，每一步都为公网设计。这篇把一条完全离线的部署路径拆开讲，物料、边界、找回一次说清。

## 什么是内网AI部署

内网AI部署指的是在隔离网络里把 AI 能力装起来、跑起来、管起来的全过程。参照产品察元AI OS（Chayuan AI OS，简称察元OS）是 AI 桌面操作系统：以完整桌面环境为壳，本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论、系统级 MCP 控制面都收在里面；支持 Windows/macOS/Linux（银河麒麟、统信 UOS）与 Docker 云桌面形态；断网可用、数据不出本机。

## 离线路径与物料清单

- 安装物料：全量离线包含五件套权重，约 4.7GB；轻量包约 1GB，完整离线能力需要额外下载权重，从官方渠道获取
- 权重进网：完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统支持零拷贝导入，放在原地即可纳入管理
- 版本更新：用轻量安装包加模型压缩包的组合，逐文件校验后离线覆盖安装；或者赶维护窗口临时放行更新通道，装完即关
- 手册：帮助中心离线可读，断网也能查文档

这套物料逻辑背后的思路是「外网准备、内网安装」：所有需要下载的东西都在有网的机器上办好，进内网的只有文件与校验。逐文件校验这一步别省——U 盘拷贝偶尔会静默损坏，校验能当场暴露问题，比装到一半报错省事得多。

## 网络边界与账号找回

- 全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机，敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用
- 智能体权限门按档位放行：T0 档只读直放；T1 档（跑终端、开原生窗）每个运行期先问一次，可记住选择
- 恢复密钥管理：设置账号与找回里生成 4 乘 4 恢复码，重新生成需验当前密码，明文只显示一次
- AI 面试找回：忘记密码时本地 AI 面试官出题验证身份，3 次失败锁 24 小时；恢复密钥丢了、管理员也找不到时，这条全程本地不出网的路是兜底

## 模型从哪来

- 厂商目录分国内、国际、本地、聚合四组，下载几个 GB 的权重需要时间与磁盘空间，内网机器记得先在能上网的机器上备好
- 本地模型解决有无问题，复杂任务还是需要云端旗舰模型；云端模型在断网时用不了，可设置自动回落到本地
- 模型会话中支持热切换；工具调用过程可视化；无显式模型偏好时自动指向本地模型，配置入口在设置＞默认模型＞网络资源页签

四组目录的划分对内网用户有个实际意义：本地组不依赖任何账号，优先从它开始；厂商组等放行窗口期再补齐。

回环监听这条在内网里的价值被放大：交换机上扫不出多余的对外端口，安全部门那边省掉一轮沟通；部署完用浏览器或 curl 探一下 127.0.0.1 的各服务端口，链路是否健康当场可知。

## 一台机器管十几家智能体

命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一：智能体支持 npm 包一键安装升级（Claude Code、Codex 等 13 家），模型配置经 :52581 的 OpenAI 兼容统一代理分发给全机，OpenAI 风格与阿里百炼风格 API 自动适配——很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的，首次登录的四步向导会先把这个概念讲清楚。日常入口上，Ctrl 或 Cmd 加 K 唤起的搜索能搜应用、文件、内容，还带问 AI 知识库直答与语音输入。对内网运维来说，统一出口还意味着换模型只改一处配置，十几家智能体同步生效。

## 部署前对一遍硬件边界

- 内存 8GB 的机器，对话模型适合一次装一个，复杂任务受限
- 龙芯机型暂不在这批支持里；本地没有视频生成，云端路由代跑
- 要动云端厂商的模型，先有自己的 API Key
- Docker 云桌面、跨终端互联是进阶项，动手能力不够会累

内网部署的每一步都比公网多一层约束，这些边界在内网里会被放大，先核再装。

## 两个疑问的答案

### 隔离网里这套东西怎么活下来？

靠三件东西：离线安装物料（全量包约 4.7GB，含五件套权重）、U 盘零拷贝导权重、帮助中心离线可读。账号找回也不依赖外网：恢复密钥或本地 AI 面试都能闭环，AI 面试 3 次失败锁 24 小时，安全与可用都顾到。

### 数据边界划在哪里？

本地服务只监听 127.0.0.1 回环，数据不出本机；需要出网的只有云端厂商模型调用，那部分自备 API Key。审计日志记录敏感操作，内网合规检查时可以直接回放。

## 一句收束

内网AI部署没有捷径，但有现成路径：物料用离线包、权重走 U 盘、找回靠本地验证、更新走校验覆盖。把这几条串起来，隔离网里的 AI 就不是「能不能」的问题，而是「什么时候开始」的问题。哪个环节卡住，先翻上面「隔离网里这套东西怎么活下来」那一问。
