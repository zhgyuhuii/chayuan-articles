# 提示词助手：自定义助手

提示词助手这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI文档助手的真实界面顺序走一遍，把公司公文口径固化成助手的过程完整铺开。

## 自定义助手由哪些东西构成

提示词助手在察元AI文档助手里的形态一句话说清：自定义助手：名字、提示词、输入源（选区或全文）、写回方式、温度，全部可配。

概念和操作都不复杂，这篇一次覆盖。

## 最短路径走一遍

按最短路径验证一遍：

1. 打开 AI 助手窗格，侧栏切到「助手」页签。
2. 点工具栏左侧的「添加助手」加号按钮。产品会打开设置窗口（标题「助手设置」）并定位到「助手设置」页的「创建智能助手」空白表单；右栏即助手配置表单，默认值：系统提示词「你是一位专业智能助手，请根据用户输入完成任务。」、用户提示词模板「{{input}}」、输出格式 Markdown、文档动作「插入到光标处」、输入范围「优先使用当前选中，无选中时回退全文」。
3. 逐字段填写，字段含义见后面那张表。
4. 填完点表单底部「创建智能助手」按钮。
5. 校验不通过会在消息条报具体原因：「助手名称不能为空，也不能是“未命名助手”」「系统提示词不能为空」「用户提示词模板必须包含 {{input}}」「温度建议在 0 到 2 之间」——按提示改完再点。
6. 成功后提示「智能助手已创建，并已同步到顶部“更多”菜单」，左栏自动选中新助手，可继续编辑。
7. 修改已有自定义助手：侧栏点该助手条目上的铅笔「编辑助手」，或到助手管理里改；改完点「保存」。删除走垃圾桶「删除助手」（或设置页右键「删除」）。

## 先说清这套能力的边界

这套能力有明确的适用范围，先摆出来：

- 助手拿到的输入要么是选区要么是全文，整份内容都会送到所配置的模型；涉密文档处理前先换到本机离线模型
- AI 痕迹检查的结论属于参考性质，列出的都只是疑似，需要人再做判断
- 脱密功能的占位替换可逆，但免密恢复的口子没留，密码丢失后没有找回的路子

## 创建过程中的高频疑问

### 创建时被提示模板缺 {{input}}，怎么补？

模板里少了内容注入口。把 {{input}} 写进模板中模型该看到文档内容的位置（惯例是前后用 --- 夹住，如内置助手的写法），保存即可。整个模板留空会自动回退为「{{input}}」，但写了模板又漏写变量时不会自动补。

### 没填名字就点创建，助手名是从哪来的？

创建时若「助手名称」为空，产品会从推荐需求/功能说明/角色/系统提示词里推断一个名字（推断不出用「智能助手」），并自动去重；创建后可随时改名。

### 表格、演示端里点「添加助手」，字段怎么和文字端对不上？

表格/演示宿主创建的是宿主配方助手，字段只有显示名称、功能说明、配方提示词、触发方式（「点击后立即发送」或「点击后预填输入框，补充要求后发送」），并有提示「自定义助手请在文字（文档）宿主中创建」。完整字段的自定义助手请切到文字文档里创建。

### 明明只想让助手处理选中的文字，为什么总连全文一起读？

检查「输入范围」：选「仅处理当前选中内容」则只处理选区；「优先使用当前选中，无选中时回退全文」在没有选区时会处理全文并触发「处理全文」确认；「始终处理全文」永远读全文档。

## 逐字段说明与默认值

| 字段 | 说明与默认值 |
|---|---|
| 助手名称 | 必填；不能是「未命名助手」。留空时创建会按描述/提示词自动起名（如「合同审查助手」），重名自动加序号 |
| 助手图标 | 点「当前图标」预览打开选择器；选用外部图片会在选择时转成离线 SVG 数据存进本助手配置，之后同步显示在列表、顶部“更多”菜单和右键菜单 |
| 功能说明 | 一句话用途，显示在侧栏条目描述里 |
| 助手类型 | 分析型（对话模型）/ 图像生成型 / 视频生成型 / 语音生成型；「执行模型」下拉只显示对应类型的模型 |
| 所属分组 | 填写新分组名称即可创建分组；保存后助手显示在对应分组，组内可拖拽排序 |
| 输入范围 | 三档：「优先使用当前选中，无选中时回退全文」（默认）/「仅处理当前选中内容」/「始终处理全文」 |
| 执行模型 | 默认「跟随默认设置」；可展开按厂商分组选一个固定模型。未配置模型时下拉提示先去模型设置 |
| 智能推荐提示词 | 写下想要的能力/语气/输出方式，系统调用已配置的对话模型生成系统提示词、用户提示词模板和推荐设置并自动回填表单，仍需手动保存；创建表单上叫「智能推荐」，编辑已保存的自定义助手时入口叫「智能优化」 |
| 角色设定 | 一句角色描述（如「审校专家」） |
| 系统提示词 | 必填，不能为空 |
| 用户提示词模板 | 必须包含 {{input}}——文档内容在这里注入；可用变量：{{input}}、{{targetLanguage}}、{{assistantName}} |
| 默认目标语言 | 仅「翻译」内置助手显示此字段（如：英文、日文、法文） |
| 输出格式 | 纯文本 / Markdown / 项目符号列表 / JSON |
| 输出报告 | 开关。开启后优先按全文生成结构化报告，可再配「自定义报告类型」「报告格式」（支持 {{reportType}}、{{assistantName}}、{{targetLanguage}} 变量）与「报告提示词」（只对报告输出生效的补充口径） |
| 文档动作 | 九种写回方式，语义详见对应教程 |
| 温度 | 数值框，默认 0.3；保存校验「温度建议在 0 到 2 之间」。需要输出稳定 JSON 的助手建议调低 |
| 多模态输出偏好 | 仅图像/语音/视频类助手显示：画幅比例（如 16:9）、时长（如 30s）、音色风格（语音） |
| 显示位置 | 四个复选：顶部主菜单 / 顶部“更多”菜单 / 右键菜单 / 右键菜单的“更多”菜单；「顶部主菜单」与「顶部“更多”菜单」互斥，右键菜单位置可与任一组合 |
| 显示优先级 | 数值越小越靠前，控制在各菜单中的先后顺序；留空按系统默认顺序 |
| 快捷模板 | 报告类助手创建表单可用的预设面板，按工程、软件、教育、管理、风控、医疗、政府、制造、科研、法务等分组，支持搜索，应用后可继续微调（提示「已应用“X”快捷模板，可继续微调后创建」） |

这篇的核心就一件事：把 {{input}} 放到模板里正确的位置、把写回方式按需选对；字段层面的细节拿不准时，回「逐字段说明与默认值」那张表逐行对照。
