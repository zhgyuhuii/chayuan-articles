# 模型清单：设置面板一站式，别再瞎试

「察元的设置在哪里？都有哪些配置项」——这个问题最近被问了好几次。答案不复杂：模型清单在察元AI文档助手里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

模型清单的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把已启用加载项；模型配置的具体操作见对应教程，本篇只讲地图不展开。核一遍，再查路径。

## 高频故障与对策

### 设置窗口打不开，或点了没反应？

设置是单实例窗口：已有一个设置窗口（可能被挡在后面）时，再点「设置」只是把它带到前台。关掉旧窗口或切换过去即可。

## 正确的操作路径

第 7 步 · 常规设置 ＞ 知识库设置

内嵌完整的知识库设置面板（本机发现与远程连接三鉴权），详见对应教程。

第 8 步 · 常规设置 ＞ MCP 服务管理

1. 看到什么：标题「MCP 服务管理」＋状态行（形如「本机在线 · Agent 已注册」），右上「刷新」「添加」按钮。
2. 做什么：「刷新」重新探测全部服务状态；「添加」弹出添加 MCP 服务表单（名称 / 地址 / 请求头 / 启用开关）；点列表中的服务条目进详情（在线状态、工具清单、编辑 / 删除）。

## 如何确认操作生效

验证

1. 逐项点过左栏四项：每项的第二列清单与第三列表单都能正常显示（第一屏加载失败会显示「加载失败：…」与「请刷新或重新打开设置」）。
2. 在「数据设置」改路径 ＞ 点「保存」＞ 关闭重开设置，路径保持。
3. 已配置过模型时，「模型设置」里对应厂商行显示「已开启」或「已配置」徽标。

## 高频疑问

### 数据路径留空会怎样？

按面板原文：「留空则规则不写入本地文件。」错误日志也会落到各系统默认位置，不影响其它功能使用。

### 模型设置 / 默认设置里看到的模型对不上？

「默认设置」的下拉只列「已开启且已配置」的对应类型模型；模型下拉是空的先回「模型设置」完成供应商配置与「刷新模型」。
