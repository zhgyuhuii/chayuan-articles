# Office首次配置下载安装：按平台架构一步步来

如果你正在琢磨Office首次配置，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI Office的模型供应商 BYOK时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 安装前确认

- 系统要求：Windows 10 及以上，x64/arm64
- 安装包：NSIS 安装器 exe
- 说明：装完先配模型。

Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；另有浏览器 SaaS 与 dsh 插件形态（五编辑器，无 HTML）。安装包从官网 aidooo.com 获取或 GitHub Releases，其他站点均非官方渠道。

## 一步步来：从入口到完成

1. 官网 aidooo.com 或 GitHub Releases 下载 exe
2. 双击安装
3. 启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama
4. 开始页新建或打开文档

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |
| Linux | deb/rpm/AppImage；AppImage 需 glibc 2.34+ | deb/rpm/AppImage（x64/arm64） |

## 装完后的第一件事

开始页新建一个 docx，在设置模型里接上厂商 API 或本机 Ollama，然后让首页 AI 生成一段测试文本——三步都通，环境就绪。

## 怎么确认做成了

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

## 这些坑和边界要知道

功能归功能，这几个边界先摆清楚：

- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- 内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型
- AI 功能依赖已配置模型
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 常见问题

### 获取模型列表成功，保存却报「协议验证失败」？

保存动作会用你当前选的协议再探一次接口，两者不一致（比如把 Gemini 原生厂商选成 Chat 协议）就会拦下。按厂商原生协议改回下拉预选项再保存；自定义网关按它实际支持的协议选。

### 一家供应商配了一半（只有 Key 没选模型）会怎样？

不勾选模型就无法通过保存校验（「至少勾选一个模型」）；未保存的草稿不生效，已启用列表不受影响。

### 之前配的模型突然报错说不存在？

厂商下架的旧 id 会在加载设置时按退役表自动改写到现役 id（见第 6 步末条），多数情况无感；若厂商整条路由变更，重新「获取模型列表」勾选新模型即可。

## 补充答疑

### 我的 Key 会被上传吗？

不会。Key 只存本机 ai-settings.json，请求直发你填的 API 地址；匿名统计只收应用事件，不含文档内容与密钥。介意明文落盘就用第 6 步的 apiKeyEnv 环境变量间接引用。

### 模型列表是空的或「未解析到任何模型」？

产品不内置名单，接口给什么显示什么。先确认服务在线、地址端口正确，再点「获取模型列表」重试。

## 更多操作细节

第 4 步 · 连接测试

1. 表单动作区点「测试连接」：对同一地址、协议、密钥发起一次模型列表调用，成功显示绿色「连接成功」，失败显示红色「测试失败：<原因>」（密钥错、地址错、网络不通都会在这里现形）。

第 5 步 · 三区分工：按能力选默认模型

1. 「模型设置」区（本篇第 3-4 步）：管「哪家供应商 + 勾了哪些模型」。
2. 「默认模型」区：七类默认各一个下拉——对话 / 页面生成 / 质检（视觉审稿）/ 生图 / 视频生成 / 语音合成 / 语音识别，未设置时「自动（使用识别到的第一个可用模型）」；另有「图片来源默认」（自动/网络图片搜索/AI 生图模型/本地图片文件夹/矢量图形）与「单次输出上限（tokens）」（默认 32768，范围 1024–131072）。
3. 「生图、媒体与搜索」区：左侧能力树八组——网络搜索 / AI 生图 / 视频生成 / 图片解析 / 视频解析 / 语音合成 / 语音识别 / SVG 图像生成。模型类组从已启用厂商里投影出「支持该能力的模型」，可「刷新模型列表」、点选一个「设为默认」（或「恢复自动」）；「网络搜索」组按平台配 API Key（带「测试」按钮，主进程执行、Key 未保存也可测）。未启用的厂商给「去模型设置启用」直达链接。

第 6 步 · 密钥存哪、怎么更安全

1. Key 明文保存在本机应用数据目录的 ai-settings.json（macOS 为 ~/Library/Application Support/ChaAI Office/ai-settings.json），不上传；界面回显用占位符（__keep__），重存不会泄旧值。
2. 写入前经主进程 schema 校验：密钥截断到 8192 字符、模型名 256、Base URL 必须是合法 http(s)，非法字段丢弃而不是整包拒绝。
3. 安全替代（进阶）：自定义端点的 profile 支持 apiKeyEnv——设置文件只存环境变量名，真实密钥放在启动应用的环境里（内联 Key 优先，二者都无则不注入），适合需要同步/共享配置文件的场景。
4. 厂商停止服务的旧模型 id 会自动改写：加载设置时按内置退役表替换（如 DeepSeek deepseek-chat/deepseek-reasoner＞deepseek-flash，智谱 glm-5-turbo＞glm-5.3-flash，内置账号的 gemini 系旧 id＞claude 系），旧配置文件直接可用。

## 安装与运行答疑

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

## 一个真实场景

财务与数据岗的典型用法：Sheets 导入多源 xlsx（Rust 边车保真往返），数据透视表与切片器做汇总，公式追踪与监视窗口排查错误。免费开源套件覆盖财务日常表格工作。注意：ODF 格式导入采取保守策略，复杂公式只保结果值。

## 顺带了解

PDF 转换：开始页签转换下拉五项：PDF 转 Word、Excel、PPT、Markdown、HTML，全部本机完成（PDFium 字符级提取加纯几何版面分析）；文件菜单的导出为 Word 是云端版（需登录、消耗 5 credits）；CLI 同样全本地转换。

为什么值得看：本地转换意味着合同不出机器，这是与在线转换服务的本质区别。

## 还有这个能力

本地模型接入：支持 Ollama（11434 端口，带启动服务按钮、20 秒超时）、LM Studio、Xinference、OneAPI、NewAPI、GPUStack、FastChat 与 openai-compatible 免 Key 家族，内网与离线全可用。

## 硬口径两三条

- 22 种界面语言
- 六编辑器：docx/xlsx/pptx/真文本 PDF/Markdown/HTML（web/dsh 形态为五编辑器）

## 如实说不足

- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值
- web/dsh 形态只有五编辑器（无 HTML），且无购买激活界面

安装这步别跳验证：装完先确认核心功能可用，再往下配。
