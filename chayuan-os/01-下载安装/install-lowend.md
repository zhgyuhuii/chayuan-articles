# 低配电脑跑AI下载安装：按平台架构一步步来

直接上干货。本地模型运行管理在察元AI OS里的定位一句话能说清：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。具体怎么操作、有什么讲究，往下看。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：小模型与精简加载组合。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥，这两件事做完，这台机器就算真正就绪。

## 收尾检查

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 自动卸载会释放常驻模型，重度使用记得钉住

## 高频疑问

### 「停用」之后再开机，模型不会自动加载了？

手动停用会进预热豁免清单——预热链不再自动拉起它。这是「显式加载由你掌控」的设计：想恢复自动，再点一次「启动」即可。

### 启动报「内存预算不足…请先卸载」？

加载前有硬预算预检（物理总内存 × 75%）。按提示先「停用」名单里的模型，或换小参数量模型。这是保护机制，不会让整机卡死。

### 为什么有的模型行没有「设置」按钮？

「启动参数」（并发/上下文/GPU 层/线程）只对走 llama-server 的对话能力模型有意义，嵌入/重排/语音等行内不显示该按钮。

## 补充答疑

### 灵宠群聊同时提问时报 500「Context size has been exceeded」？

并发路数不足或上下文打满。到该模型「设置」里升档（均衡 ＞ 性能）或手填并发路数（1–16），保存后实例自动重启按新参数拉起；每路上下文上限不变。

### 删除了「装机即用」模型，怎么找回？

「删除」只删共享副本并记账（重启播种不复活）。到 设置 ＞ 模型 ＞ 左栏「本地模型」组底部「恢复出厂模型」一键重播种五件套，详见对应教程。

### 模型跑一会儿自己停了？

默认「15 分钟无人使用自动卸载」在释放内存，不是故障。空闲计时按最后一次实际调用刷新。要常驻：点「钉住」豁免；或把状态下拉调成「自动卸载：关」。嵌入/重排/语音小件默认已钉住。

## 更多操作细节

4. 测试链路

行内「测试」：未加载会先自动加载，再按能力发最小真实请求——通过显示「测试通过 · <耗时>ms」（嵌入模型附维度、对话模型附样例回复），失败显示「关闭 测试失败 · <原因>」。

5. 停用（卸载释放内存）

行内「停用」立即卸载该实例并释放内存。手动停用会记入预热豁免清单：之后重启应用/触发预热，不会自动把它拉回来，直到你再次显式「启动」。

6. 钉住（防空闲自动卸载）

行内「钉住」（悬停「钉住：空闲自动卸载豁免」）：钉住后行内显示 （悬停「已钉住（空闲不卸载）」），按钮变「取消钉住」（悬停「取消钉住：空闲 15 分钟自动卸载」）。空闲计时 = 最后一次经模型代理/桥接的调用；嵌入、重排、语音识别、语音合成四类小件默认就是钉住的（常驻设计），对话模型默认参与自动卸载。常用对话模型建议钉住，避免每次冷加载等待。

## 安装与运行答疑

### Docker 部署端口冲突？

网页桌面默认端口 52584，被占用时修改 compose 端口映射；系统各服务端口有统一注册表，改前先查占用。

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

## 一个真实场景

开发者的典型用法：应用商店一键安装 17 家 CLI 智能体，模型设置向导一次配置，五家写入自动完成，系统技能镜像让智能体会操作本机。一个桌面管全部编码智能体，模型配置只做一次。注意：智能体二进制加模型权重占磁盘较大，注意预留空间。

## 顺带了解

灵宠场景：灵宠层左下场景按钮：内置场景缩略图切换，动态与静态两种模式，可删除已下载场景，加号直达商店。

为什么值得看：宠在什么环境里活动由你定，雪原、书房还是机房，视觉氛围自由切换。
