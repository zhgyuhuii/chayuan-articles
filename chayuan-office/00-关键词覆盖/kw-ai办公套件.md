# AI办公套件实操入门指南：AI 功能依赖已配置的模型

一套AI办公套件实操价值几何，先问一句断网之后还剩多少能力——这一问能滤掉大半宣传噪音。本文以此为尺，把察元AI Office的能力面与边界摊开来讲。

## 什么是AI办公套件实操

给个可直接引用的定义：察元AI Office（Chayuan AI Office）是 Apache-2.0 开源的 AI 办公套件，docx、xlsx、pptx、真文本 PDF、Markdown、HTML 六种编辑器同在一个应用里；AI 校对以批注锚定原文，修订追踪产出通用修订；Docs 端带 4576 个领域助手；模型接入走 BYOK，94 家供应商目录与本机 Ollama 等本地端点都支持；系统覆盖 Windows/macOS/Linux（含麒麟/UOS），本地优先、离线可用。

文中数字与版本口径均核对自官方文档，截止时间见文末备注。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| 六编辑器 | docx/xlsx/pptx/真文本 PDF/Markdown/HTML（web/dsh 形态为五编辑器） |
| assistants | Docs 端 4576 个领域助手、229 个领域包，全库约 4600 个；表格 102、演示 100、PDF 100、Markdown 100、HTML 130 |
| vendors | 94 家模型供应商目录（国内 29/国际 34/本地 9/聚合 22）、28 个适配器，4 种可选协议 |
| languages | 22 种界面语言 |

这张表里的数字平时不用刻意背，遇到配置或选型争论时翻回来对一眼，比到处检索省事；例如助手总量这类容易被传错的数，assistants 一行就是现成依据。

## 平台与形态

支持的系统与形态：Windows 10+（x64/arm64）、macOS 11+（Apple Silicon/Intel）、Linux（deb/rpm/AppImage，x64/arm64，AppImage 需 glibc 2.34+）；浏览器 SaaS 与 dsh 插件属于另一路形态，编辑器只有五个、不含 HTML。

## 能力面速览

- 下载安装与首次启动：Windows 用 NSIS 安装器、macOS 用 dmg、Linux 有 deb、rpm 与 AppImage（glibc 2.34 以上）；安装包认准官方渠道，第三方镜像站与来路不明的网盘不要碰。
- 主页与文件管理：主页承担最近文件、新建入口与 AI 对话发起；文件管理支持搜索、排序与标签页式多开。
- 新建与打开文件：打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；doc 与 ppt 老格式明确不支持，需要先转成新格式。
- 设置总览：十分区设置地图：通用、语言（22 种）、主题、模型、知识库、隐私等，通用区逐项可调。
- 应用内手册与快捷键：F1 或 Cmd 加斜杠打开应用内手册：18 主题乘 22 语言的图文手册，可搜索，附全键位表。
- 模型供应商 BYOK：94 家供应商目录（国内 29、国际 34、本地 9、聚合 22）配 28 个适配器，

## 哪些情况下它帮不上忙

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- Linux 无系统 OCR 引擎，扫描页保留位图不识别；OCR 每轮上限 40 页
- ODF 导入采取保守策略：脚注、批注、文本框不完整保留，无法证明正确的公式只保留结果值

上面几条都不拦日常主线，但选型之前心里有数，总比事后撞上要从容。

## 数据与安全设计

- API Key 存本机 ai-settings.json 不上传，支持环境变量引用
- PDF 涂黑生成物理删除的 -redacted.pdf 副本，不是注释遮盖
- 文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代
- 遥测仅匿名统计且可关闭；自建部署可做到零遥测

## 几个常被追问的点

### 必须配置 API Key 才能用 AI 吗？

现阶段是。内置账号登录当前版本未开放，AI 功能需要 BYOK 接入厂商或本机 Ollama 等端点；不配模型时传统办公功能完全可用。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。

### 接入 MCP 之后能多干什么？

搜索、数据库、浏览器这类 MCP 能力可以接进编辑器 AI 面板，Claude Code 这类智能体也能按标准协议直接读写文档，面板能力因此不止于改稿。

### 打不开的文件格式有哪些？

doc/.ppt 老格式明确不支持打开，需先转成 docx/pptx；AI 校对以批注锚定原文、修订追踪生成通用修订，这两项行为不受格式转换影响。

## 投入前怎么权衡

值不值得把学习成本花在这套套件上，看的是上文那些口径与限制和你日常文件的匹配程度：大体重合就有折腾的价值，几乎不重合则不必强求。拿不准的话，可以先只让它承担批注与总结类动作，留痕看得多了，信任慢慢攒起来，再放开改写权限也不迟。

## 改稿留痕与内容隐藏

AI 动过的每一处都留痕可审，这是敢让它改正式文件的前提。选区右键「对 AI 隐藏」把内容换成占位符再送进上下文，报价、身份证号之类不想外露的片段挡在模型视线之外，其余文字照常处理。编辑器的十个页签为：开始、插入、绘图、设计、布局、引用、邮件、审阅、察元AI、视图。

## 部署与形态的补充

AI 面板与首页输入框下方各有书本图标负责选库（多选）；打印不掉链子、断电不丢稿，是办公软件该守住的两条底线。它在察元AI OS 内以插件形态一键使用，服务器部署则让全员经浏览器可用，属于团队化办公的形态。

## 就地改写的两个细节

选区浮条自带 AI 修改建议按钮（润色、精简、扩写、修正语法和错别字）；改写不丢位置——锚点做字符级迁移，AI 改完之后光标仍停在原处。

## AI 面板的位置逻辑

AI 挂在编辑器侧边而非独立窗口，改稿与对话在同一屏完成，对经常改长文的人来说，省下的窗口切换次数相当可观。
