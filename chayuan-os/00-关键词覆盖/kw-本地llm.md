# 本地模型去哪里下载：本地LLM概念与上手

本地LLM 这几年从极客玩具变成了普通机器也能碰的东西，但真要上手，定义、口径、边界还是得先厘清，产品以察元AI OS为例。

## 什么是本地LLM

本地LLM，指部署在本机、推理不依赖云端服务的大语言模型。这套系统把它做成一等公民：模型下载、加载、端点服务都在系统层完成。承载平台是察元AI OS：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

本文引用的数字均对应特定版本，截止时间见文末尾注。

## 平台与形态

平台覆盖：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

本地LLM在察元AI OS里的落点是模型库：按本机内存预算分三档推荐（能跑/勉强/跑不动），下载支持断点续传，源会在 ModelScope、hf-mirror、HuggingFace 之间自动切换。

为什么值得单独说：断网、涉密内网、不愿为 API 调用花钱，三类需求殊途同归——模型就得在自己机器上跑。

## 最短上手路径

先看模型库的标尺：

按 /△/关闭 挑模型（模型库区）

「模型库」标题旁有图例：「本机推荐 · △ 可跑，内存吃紧 · 关闭 超出本机内存（仍可下载，加载时会被守卫拦截）」。每行结构：

1. 行首彩色徽标： 绿 / △ 黄 / 关闭 红（判定规则：模型内存 + 2GB 余量 ≤ 当前可用内存 = ；不超过物理内存 − 2GB 系统保留 = △；超出 = 关闭）；
2. 模型名（beta 模型带黄色 beta 标）；
3. 第二行参数：「参数量 · 上下文 · 下载体积 · 运行内存」，如 4B · 32K · 2.6GB · 3.3GB RAM；
4. 行尾动作按钮（见下一步）。

## 落点的能力面

能力面集中在三处：按内存预算分层推荐、断点续传加多路换源，以及 Qwen3-8B/14B、小内存档 LFM2.5、图像理解 MiniCPM-V 这些档位的在线下载。

## 察元AI OS的能力地图

- 离线导入模型权重：GGUF、whisper 权重可以按路径直接导入（零拷贝），或按直链目录放置后执行扫描本地放置的模型。

## 先掂量机器再装

- 内存 8GB 的设备同时只跑一个对话模型为宜，复杂任务受限
- 龙芯平台目前不支持；本地没有视频生成，视频生成经云端路由
- 云端厂商模型调用时，API Key 要自己备好
- 进阶形态如 Docker 云桌面、跨终端互联，动手能力弱会吃力

这些边界不碍主线，装前心里有数即可。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 模型下载与运行的疑问

### 怎么删掉下错的模型？

「我的模型」行内「删除」＞ 确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」运行中的模型要先「停用」再删。注意权重全机一份，删除影响本机所有用户；「装机即用」五件套权重随安装包分发、不占额外磁盘，无需删除。

### 下载前要预留多少磁盘？

系统自动预检：模型体积 × 1.05 + 200MB；不足时报「磁盘不足：还需约 XGB，当前可用 YGB」，不会下到一半才失败。

### 启动报「二进制缺失 / 引擎缺失」？

推理引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；恢复方法详见帮助中心「引擎二进制」。

### 检查更新失败？

检查更新这项功能要连官方接口，断网就安静失败、不碍事；想升级也可以自己下新版安装包覆盖安装，数据目录不动。

### 安装时提示架构不符？

终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾与鲲鹏设备均为 arm64。

## 一句收束

本地LLM 值不值得折腾，先回答一个问题：你的需求里有没有断网或数据不出本机这条硬约束——有，它就不是可选项。

## 状态条上的信息

认识状态条（顶部）

1. 健康灯 + 文字：「正常」（绿）/「引擎异常」（黄）/「不可达」（红）/「已停用」（灰）/「引擎缺失」（黄）；
2. 实例计数：「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示「空闲自动卸载策略」）：「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，默认 15 分钟；
4. 「重启全部」「全部关闭」：点击后行内出现红色二次确认条——「重启全部运行中的模型？」/「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，点「好」执行、「取消」收回；
5. 服务被停用时，此处只剩「启动」按钮。

## 服务地址条是什么

服务地址条（第二行）

这里显示当前分类的对外端点，对话类是 http://127.0.0.1:52581/v1/chat/completions；「复制」点了变「已复制」，「配置帮助」会展开 curl 示例。各分类的端点分别是：对话/代码补全/图像理解 /v1/chat/completions、嵌入 /v1/embeddings、重排 /v1/rerank、决策 /v1/systemone、语音识别 /inference；生图/视频生成/语音合成走系统内置调用，不显示这条。底部还有一行注：「免 key 直连：本机任意智能体不带 key 即可用（审计归因 anonymous）…」。

全篇压缩成一句：跟着内存预算的分层标记走，选型就不会跑偏；更细的字段看上面两节。
