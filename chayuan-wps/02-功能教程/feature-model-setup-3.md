# 全文会发送给所配置的模型：用离线模型配置跑通一个真实场景

先说这篇能帮你干什么：读完能在察元AI文档助手里独立完成离线模型配置，路径是内网环境配 Ollama。步骤里的每个「」按钮都是界面原文。

## 为什么值得了解

个人配 DeepSeek API，内网 / 涉密环境没有公网 API Key，想用本机 Ollama、LM Studio 等离线端点，内网环境配 Ollama，配了密钥但「检测连接」报错、或模型下拉是空的。

## 首次配置接上模型：从入口到完成

第 4 步 · 离线路线：连接本机 Ollama / LM Studio

1. 在哪：同上面板，选中 Ollama（或 LM Studio）后，配置面板顶部多出一条本地引擎状态条。
2. 看到什么（状态条自动探测，三种结果）：
    1. 「Ollama 已安装并运行（<版本>）」；
    2. 「未检测到 Ollama（未安装或未启动）」＋「一键安装」按钮——点击后自动择优打开 Ollama 官网或 ModelScope 镜像的下载页（按钮变为「正在打开…」；macOS / Linux 还会把官方安装命令复制到剪贴板备用），装好启动后回到此页即自动识别；
    3. 「⏳ 正在检测 Ollama…」。
    4. 做什么：选中 Ollama 后「API 地址」已预填默认地址 http://localhost:11434，一般无需手填；若该框被清空且探测到服务在运行，状态条会提示「检测到本地服务运行于 127.0.0.1:11434，点击「填入地址」自动完成配置。」并出现「填入地址」按钮——点击一键补回默认地址。
    5. 看到什么：补填后提示「已填入 Ollama 默认地址 http://localhost:11434，可点击「刷新模型」获取本地模型列表」。LM Studio 同理（默认地址 http://localhost:1234，预填形式 http://localhost:1234/v1）。地址已配好时，状态条改为显示拉取模型的网络提示（如建议从 ModelScope 下载 GGUF 导入或配置国内镜像加速）。
    6. 收尾：点「刷新模型」列出本机已拉取的模型。

第 5 步 · 设为默认对话模型

1. 在哪：设置窗口左栏「默认设置」＞ 第二列「模型设置项」＞「对话模型」。
2. 做什么：右侧「默认模型」下拉里选一个刚配好的模型。下拉为空时显示「请先在模型设置中配置：开启提供商、填写 API 地址与密钥、刷新模型清单」；提示「仅显示在模型设置中已开启且已配置的对应类型模型（对话/图像/视频/语音）」。

第 6 步 · 用第一条回复确认连通

回到助手窗格，输入一句话发送。以对话第一条回复成功为准判断连通——WPS 沙箱的网络策略与 curl 探活结果未必一致（用户手册 FAQ 口径），检测通过不代表对话链路必通，反之检测失败也可按报错修正后以对话验证。

## 这些坑和边界要知道

如实说明，它不是万能的：

- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 高频疑问

### 检测时提示「请先填写 API 地址」/「请先填写 API 密钥」？

检测依赖地址＋密钥：地址必填；密钥对 Ollama 类免密钥供应商可空，云端厂商必填。补齐后再点检测图标。

### 检测报「连接失败： 401 / 403 / 404 …」怎么处理？

- 「401 未授权：请检查 API 密钥是否正确、是否已过期，或该密钥是否有访问权限」＞ 核对 / 重贴密钥；
- 「403 禁止访问：API 密钥可能无权限访问此接口」＞ 检查该 Key 的接口权限；
- 「404 未找到接口（探测 <地址>）：请确认服务已启动、地址正确」＞ 地址写错（多 / 少了 /v1）或本地服务没启动。
失败后该厂商清单行会挂「异常」徽标（悬停显示「最近检测失败：<原因>」）；修复后重新检测成功即自动清除。

### 模型下拉一直是空的？

三个条件缺一不可：供应商开关已启用、API 地址与密钥已配置、点过「刷新模型」。另外下拉按类型过滤——只有「对话」类型模型会出现在对话下拉中，图像 / 视频 / 语音模型要在对应助手里选。

## 更多操作细节

验证

1. 输入区模型下拉能展开并看到刚刷新的模型（按厂商分组显示）。
2. 发送一句话收到流式回复；输入区占位文案从「请先配置模型后再开始对话」恢复为「输入消息，Enter 发送，Ctrl+Enter 或 Alt+Enter 换行」。
3. 供应商面板检测图标点击后提示「连接成功，API 可用」，且该厂商清单行状态徽标正常（不再出现「异常」）。

## 动手前再核对一遍

- 已启用加载项并打开 AI 助手窗格。
- 云端路线：能访问所选供应商并已有 API Key（设置内「获取秘钥」链接直达各家密钥管理页）。
- 离线路线：本机已安装并启动 Ollama（默认端口 11434）或 LM Studio（默认端口 1234）；没装也可在设置内点「一键安装」引导。
