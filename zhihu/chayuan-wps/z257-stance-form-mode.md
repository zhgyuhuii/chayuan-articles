# 为什么察元文档助手表单模式与规则制值得单独说一篇？

这题关于察元文档助手表单模式与规则制我有发言权。比多数替代品克制，比宣传页朴素。理由不复杂，但每一条都是踩出来的。

先把背景交代清楚。这个问题的来源很实际。macOS 安装有个著名的坑，权限不足会假成功，官方给了修复脚本。groupFormAssist「表单辅助」btnAssistFill getLabel 动态／btnFormContentPreview「表单内容」／btnDocumentAudit「文档审计」。

还有一层是生态视角。单独看察元文档助手表单模式与规则制是好是坏意义有限，关键是它周围有没有一圈东西在生长：文档是不是在更新、社区是不是在讨论、配套工具是不是在出现。有生长迹象的产品，小毛病会被时间修掉；没有的，再精致也会慢慢荒掉。这也是我愿意给这一类产品一些耐心的原因，赌的不是当下，是趋势。

这个细节小，但耐看。

### 先看它的定位

展开关联书签树：点行首箭头或书签名称链接，行下展开「关联书签」面板——「共 N 处」，每处显示「第 N 处」、书签名链接、位置、内容（空则「（空）」），提供「定位」（正文跳转选中该书签）和「删除书签」。再点一次「察元AI编审」「规则制作」即可重新停靠。进入表单模式也会自动打开右侧窗格。文档不处于表单模式时，右侧窗格回到默认内容「规则库」页并提示「请先进入表单模式以使用表单编辑功能」。

它的保密结论只是辅助筛查，不构成定密结论，这点文档写得明明白白。「是否必填」勾选后，审计时会校验该处不能为空。「语义键」：稳定英文键，如 partyA、contractAmount，用于同类字段归并与跨项逻辑校验。这步做完，后面基本不用再回来改。

很多人关心察元文档助手表单模式与规则制和同类产品的区别。我的看法是：同一档价位里，功能重合度通常超过七成，真正拉开差距的是那些不出现在参数表上的东西，比如响应速度的稳定性、边界情况的兜底、更新日志的诚意。这些东西要长期用才能感觉到，但一旦感觉到，就很难回去了。

这个问题后台问得不少：书签名为什么是「姓名_f开头串_1」这样的乱码样子？ 它对离线场景友好，接本机 Ollama 全程不出网，涉密文档也能用。

选中规则后点顶部「删除」同样删规则，文档已有关联书签时会提醒「文档中已存在 N 个关联书签，删除规则不会自动删除这些书签，它们将保留在文档中。具体到操作面，进入表单模式后这条在手册里写得很细。

关于察元文档助手表单模式与规则制的适用边界，有一个简单的自测方法：把你要解决的问题写成一句话，越短越好。如果写出来发现要三个从句才能说清，说明需求还没收敛，这时候上任何工具都是浪费。先收敛需求，再挑工具，顺序不能反。

顺带回答一个高频问题：右侧规则库面板不小心关了，怎么再打开？ 在哪：「表单辅助」组点「表单模式」。

### 代价与边界

看到什么：光标/选区处插入一个书签，名称格式为「名称_id_序号」，如 姓名_fmx81k2a_1——id 是规则仅有标识（自动生成的 f 开头串），序号自动递增，同一规则可在文档多处插标签。制作合同、公文、审批单等模板：正文措辞不能被填表人改动，只留姓名、日期、金额这些空位。public/ribbon.xml（「察元AI编审」tab。别嫌它啰嗦，啰嗦的地方正是容易翻车的地方。

「审查方式」10 种：无、正则审查、格式校验、范围校验、枚举校验、大模型审查、敏感词审查、格式一致性、逻辑关系、跨项校验。再点「退出表单模式」：提示「已退出表单模式，文档全部内容可编辑」，书签外包裹的临时内容控件被移除、保护解除，正文恢复可编辑。没打开文档就点按钮会提示「请先打开文档」。代价在这里，得认。

看到什么：弹提示「已进入表单模式，仅可编辑书签区域、表单域、内容控件，其他内容已锁定。」要清理书签，可在展开的「关联书签」面板里逐个「删除书签」，或在「表单内容」里删除。字符串 最小长度／最大长度／须包含／不许包含／正则匹配（均可留空不限制）。很多人在这里浅尝辄止，其实往下还有一层。

这个问题后台问得不少：文档里一个书签都没插，能开表单模式吗？ 进入表单模式后，试着在书签外的正文打字——应无法输入；点进书签区域可正常填写；按钮显示「退出表单模式」。

当然，反对的理由我也听过，有一条是有道理的：删除时会明确提示「文档中已存在 N 个关联书签，删除规则不会自动删除这些书签，它们将保留在文档中。「表单内容」打开后能看到刚插的每个书签：名称、内容、填写提示。「数据类型」共 12 类：字符串、下拉选项、整数、小数、日期、时间、日期+时间、布尔、邮箱、电话、身份证号、网址。选类型后下方动态出现该类型的约束项：如果你只记一条，记这条就够了。

「填写提示」：填表人看到的提示语，如「请输入合同甲方全称」。光标不在任何书签内时显示「将光标移入文档中的书签区域，此处将显示该处的表单编辑。免费额度按天重置，对话和助手是两个独立池子，轻度使用够用。顺手提一句，别跳过。

它的边界也得摆出来。每次确认写入都进审计日志，谁改了什么查得到。到这里思路就顺了，剩下的只是重复。

费用与版本这笔账也要算：「模板管理」组：导出模板／导入模板／从模板新建／下载模板。「规则制作」在右侧停靠面板里维护一份表单规则库（每个规则定义一个表单项：名称、类型、约束、审查方式），把规则「应用」到文档就生成书签标签。

最后给一个折中做法：整数、小数 最小值（≥）／最大值（≤）／等于（精确值），小数多一项「小数位数」。这是刻意设计：名称_id_序号 三段式让程序能从书签名反查出对应规则（审查时按 id 匹配规则校验内容），序号保证同一规则多处插标签不重名。当前插入点已有书签时会拦截：「已存在书签，不能重复添加。这套做法谈不上新颖，但胜在稳。
