# 首次启动感觉「卡住」了？

这个问题在被反复问到，这里给一个完整、可执行的回答。

## 直接回答

首启要初始化数据目录并加载模型服务，5-30 秒属正常范围；期间无需干预，完成后自动进入桌面。

## 背景与原因

理解这个问题的关键，是先知道察元AI OS的整体设计：察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

## 延伸操作

1. 按上文答案定位到对应设置或入口
2. 执行后做一次最小验证
3. 如涉及模型，先确认端点与密钥有效
4. 仍有问题时通过官网渠道反馈并附系统信息

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。
