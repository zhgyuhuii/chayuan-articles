# 能力广场专题｜Skills 技能怎么找与怎么筛

Skills 技能怎么找与怎么筛。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：Skills 技能板块（Skills技能）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**Skills 技能板块**：可装进 Harness 类智能体的大模型技能包目录：SKILL.md 形态技能的发现与安装入口。

1. 进入 skill 板块
2. 按领域或热度筛选
3. 复制安装命令或仓库地址

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。
