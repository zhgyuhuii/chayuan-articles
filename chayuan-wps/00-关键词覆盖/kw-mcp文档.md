# 一文分清MCP文档：MCP 都有哪些工具

MCP文档的搜索热度上来了，含义却没跟着收敛：协议、服务、工具集几种说法混着用。本文固定一种口径——以察元AI文档助手为实例，定义、数字、边界分节给出。

## 什么是MCP文档

MCP文档这个说法对应的产品是察元AI文档助手（Chayuan AI Document Assistant）：WPS 三端智能加载项，校对、编审、核对、脱密，一个文档智能体。

文中口径全部对照官方文档整理，版本对应关系见文末。

## 在察元AI文档助手里落在哪

MCP文档在察元AI文档助手里的落点是MCP 工具面总览：源码定义 69 个工具（外部实见 53 个）：主机健康 2、文档 13、格式 5、17 个域聚合工具（批注、修订、目录、书签、表格 12 动作、水印、导出等加表格 23 动作、演示 23 动作）、校对 3、脱密 4（仅本机可信通道可调）、知识库检索、助手检索、图搜图生成、模板生成、文件解析；写操作不带确认标记返回预览或报错要求确认，每次确认写记入审计日志。

值得展开讲的原因：几十个工具按域收拢之后好记也好用，而写操作必须显式确认这条纪律，挡住了外部智能体悄悄改文档的可能。

## 最短上手路径

最短路径走一遍：

1. 69 工具全景
2. 域聚合设计
3. 写确认加审计
4. 场景验证：智能体代操作文档前了解权限边界
5. 场景验证：自动化脚本选工具
6. 串联场景：WPS 里打开文稿

六步由浅入深：前两步看工具怎么分组，第三步看写操作的闸门，四、五两步对应两类典型来客——让智能体代操作文档前摸清权限边界的，和写自动化脚本要挑工具的，第六步落到一个最小闭环场景里串起来。

## 落点的能力面

- 69 工具全景
- 域聚合设计
- 写确认加审计

这三个词连起来才是完整的使用逻辑：域聚合把同类操作收进一个入口，表格域同时容纳 12 动作与 23 动作两组操作，演示域 23 动作，调用时不必在几十个细粒度工具里翻找；写确认与审计负责兜底，外部智能体每次要改文档，先拿到你的确认，确认记录进审计日志，事后翻得到。

## 察元AI文档助手的能力地图

- 助手管理：助手目录搜索、收藏常用、按领域浏览，形成自己的助手工作台。
- 拼写与语法检查：AI 助手组大按钮拼写与语法检查：有选中只查选中，
- 图像批量操作：6 项图像批量操作：文档内图片的统一处理。
- 模板四件套与规则共享：导出模板、导入模板、从模板新建、下载模板四件套；规则同样可导入导出共享。
- 启动本机 MCP 服务：本机 MCP 服务跑在 127.0.0.1:62588：
- 外部智能体接入 MCP：外部智能体一行配置接入：Claude Code 用 claude mcp add 命令、Codex 改 config.toml、Cursor 写 mcp.json，选 HTTP 类型指向本机地址；Inspector 可验证连通。

## 动手前值得掂量的四件事

- 脱密、复原、保密检查、涉密关键词提取四个项目走付费授权，免费额度为零
- 占位替换本身可逆，但密码一旦丢失，不存在绕过密码取回原文的通道
- 文档全文会被送去当前配置的模型处理，涉密场景先切换到本机离线模型再动手
- 痕迹检查给出的只是疑似线索，别把疑似当成结论

上面几条都不动主线功能，可决定装不装之前把它们算进去，比事后补救划算。

## 数据与安全设计

- 每次确认写操作记入 audit.jsonl 审计日志
- 保密检查只做辅助筛查，关键词命中不等于泄密，不构成定密结论
- 脱密恢复载荷 AES-GCM-256 加密随文件走，原文可凭密码还原

## 价格口径

- 免费有每日额度（对话与助手独立额度池，次日重置）

## 两个常被问到的问题

### MCP文档离线能跑吗

取决于模型放在哪：文档全文会送往当前配置的模型处理，涉密材料动手前先切到本机离线模型；把离线内网模型放在优先位置是这套加载项的立场——涉密文档不出网也能用上 AI。

### MCP文档的免费额度是怎么定的

对话和助手分开算，各自一个每日额度池，隔天重置；文档脱密、脱密复原、保密检查、涉密关键词提取这四项是付费专属，免费额度为零。

## 一句收束

值不值，看你让外部智能体碰文档的频率：经常要 Claude Code、Codex 这类工具代操作 WPS，这套 69 工具加写确认的面就派得上用场；一年碰不了几次文档自动化，先不装也不亏。

## 对话历史怎么与文档对应

把MCP文档放回察元AI文档助手的整体盘面看，还有一处设计跟工具面配套：对话窗格是多会话页签结构，历史按文档隔离，换一份文档就是一套全新的会话上下文；A 文档聊过的内容不会渗进 B 文档。

## 模板与配方生成

红头文件、标书这类强格式文档，用模板加 AI 填充是最稳的生成方式，原模板零修改；加结构件补齐、整套翻译、转讲义文档、课件生成、习题互动页等 81 个配方按场景备好，配图不用出软件，写好提示词就地生成。

## 平台与形态

macOS 容器写入失败有修复脚本，macOS 安装器无完全磁盘访问权限会假成功；同时在本机 62588 端口开放 MCP 文档智能体服务，MCP 服务是外部智能体操作 WPS 文档的桥，开机自启保证随时可用，编程智能体与办公文档就此打通。

## 写回方式决定信任感

AI 先读懂你的文档再干活，而不是让你复述内容；结果按助手定义的写回方式落进文档。批注式让你过目，替换式提效率；整机文档翻译保持排版不走样，比复制出去翻再贴回来强太多。

69 个工具、域聚合、写确认三块到这里讲完，有疑问回看前面的问答小节，答案基本齐了。
