# 多用户云桌面实战：团队统一 AI 工位

先说这篇能帮你干什么：读完能在察元AI OS里独立完成多用户云桌面，路径是团队统一 AI 工位。步骤里的每个「」按钮都是界面原文。

## 为什么值得了解

培训机房批量部署，团队统一 AI 工位。

## 一步步来

起一个云桌面

1. 服务器上准备 docker compose 配置
2. docker compose up -d 启动工舱
3. 按需暴露端口（默认回环，外网访问自行映射）
4. 员工浏览器打开地址，各自账户登录使用

上线前检查清单

1. 默认端口 52584 是否被占用（compose 映射可改）
2. 按团队人数评估内存：每并发一个本地模型约吃数 GB
3. 数据卷挂载出来，升级与备份都靠它
4. 管理员账户先建好，再开放普通用户注册

## 关键能力点

- 浏览器即用
- 账户隔离
- 数据集中管理
- 端口暴露面自控

## 这些坑和边界要知道

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 常见问题

### 多用户云桌面要联网吗

设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力，本机轻薄、远端肥厚时，桌面只当壳；遥测开关、清除桌面数据（破坏性操作有警示），它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。以官网 aidooo.com 当前页面为准。

### 多用户云桌面数据存在哪

断网可用、数据不出本机，（web/Docker 形态网页桌面默认端口）；全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。以官网 aidooo.com 当前页面为准。

安全口径单独立一层：智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明，管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；任何网页或本机程序都能变成桌面应用，常用工具一键直达，本机轻薄、远端肥厚时，桌面只当壳。
