# 离线部署五步法安装：政企内网的标准部署路径

离线部署五步法这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决离线部署五步法。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：政企内网的标准部署路径。

安装包从官网 aidooo.com 获取。

## 实操全过程

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 这些坑和边界要知道

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 放回产品盘面看

把离线部署五步法放回察元AI OS的整体盘面：tar 包离线迁移，与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力），离线消息暂存后送达，提交反馈、购买授权中心、产品内帮助中心（六节手册加搜索、离线可读）、关注我们二维码挂件。

## 安全与数据边界

安全口径单独立一层：周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，本机轻薄、远端肥厚时，桌面只当壳；遥测开关、清除桌面数据（破坏性操作有警示），升级不丢数据是底线，检查更新静默失败不影响使用。

## 平台与形态

平台与形态的账：web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作；内置浏览器窗，配合 webwindows 可被智能体驱动；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸。

## 价格与授权

价格口径一并交代：需要相应平台的 Key（部分有免费额度）；形象可从灵宠商店免费获取，也可工坊自定义；内置场景免费切换；场景、形象、元素、主题包四个页签，全部免费获取，带下载进度与失败重试。

## 产品家族与搭配

察元AI OS不是单打独斗：Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；购买 OS 授权后，同机察元AI Office 自动免激活；Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）。

## 几条硬数字

能落到数字上的几条：默认对话模型选择；重跑入口在设置＞模型＞设置向导；想换默认模型随时可以在设置里重跑向导，不用重装；本地模型解决有无问题，复杂任务还是需要云端旗舰模型。

## 离线与内网

离线内网这条线的口径：或按直链目录放置后执行扫描本地放置的模型，扫描本地放置的模型；whisper 语音权重同样支持，显式的加载卸载加自动卸载策略是本地模型的生存之道。

## 能力总账

把察元AI OS的能力总账摊开：三级知识库优先级；知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库；导入零门槛是知识库能不能被用起来的第一道坎，拖进去点加载两步完事，知识库应用的知识图谱页签：自动生成文档与实体的二部图，点实体或文档互跳、定位来源、可重新生成。
