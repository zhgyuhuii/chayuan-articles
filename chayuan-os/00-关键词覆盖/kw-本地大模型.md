# 本地大模型入门指南：按内存挑合适的模型档位

「本地大模型」四个字，一半人关心能干什么，一半人关心自己的机器跑不跑得动。这篇两头都答：定义给足，档位与边界也给足。

## 什么是本地大模型

本地大模型，就是把数十亿参数量级的大语言模型装到自己机器上跑。察元AI OS（Chayuan AI OS，简称察元OS）就是这么一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

材料取自官方文档并逐条核过，版本对应关系见文末。

## 核心口径一张表

| 口径 | 内容 |

## 平台与形态

可安装的平台：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测），以及 Docker 服务器形态。

## 在察元AI OS里落在哪

本地大模型在察元AI OS里的落点是模型管理页：模型库会按你的内存预算给出能跑、勉强、跑不动三档标记，下载断了能续，源在 ModelScope、hf-mirror、HuggingFace 三个之间自动倒换。

为什么值得单独说：内网保密、断网作业、算不起 API 账单，这三类场景最后都落到同一句话上——模型放本机，心里踏实。

## 最短上手路径

两分钟走一遍：

进入本地模型页

从 设置 ＞ 模型 进入，左栏「本地模型」组默认展开，十一类导航依次是：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 视频解析 / 生图 / 视频生成 / 语音识别 / 语音合成，进页默认停在「对话」。右栏从上到下：状态条、服务地址条、「模型全机只保留一份」提示、「我的模型」（已安装）、「模型库」（未下载）；同一个模型只会出现在其中一个分类页。

## 落点的能力面

能力集中在三处：推荐按内存预算分层、下载断点可续且多路换源，Qwen3-8B/14B、小内存档 LFM2.5、图像理解 MiniCPM-V 等档位都能在线下载。

## 察元AI OS的能力地图

- 离线导入模型权重：GGUF、whisper 权重可以按路径直接导入（零拷贝），或按直链目录放置后执行扫描本地放置的模型。
- 本地模型运行管理：我的模型面板管理加载、卸载、删除、钉住，可调启动参数（省内存、均衡、性能、自定义），
- 全局默认模型：11 类任务各选默认模型：对话、嵌入、重排、决策、文生图、图生图、视频生成、……
- 模型代理：本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，
- 模型代理进阶：进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询，
- 模型应用到智能体：把代理地址加模型名一键写进 Harness、Claude Code、Codex、OpenCode、OpenClaw 五家配置，写入前自动备份、可回退，真实厂商密钥不出凭证库。

## 动手前先对齐预期

- 设备内存 8GB 的话，一次加载一个对话模型就好，复杂任务受限
- 龙芯不在支持之列；本地没有视频生成，走云端路由
- 要调云端厂商模型，先备好自己的 API Key
- Docker 云桌面、跨终端互联这类进阶形态，得有动手的耐心

边界摆在明处，主线功能照常，装不装自己权衡。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 模型页常见疑问

### 一个源都连不上时怎么把模型弄进机器？

联网恢复后点「继续下载」，断点还在。彻底离线的机器换个思路：找台能上网的电脑，按帮助中心「离线下载与导入」的直链把权重下下来（U 盘或内网搬运到本机），再走「我的模型 ＞ ＋ 添加模型」按路径导入，文件不复制、原路径引用。

### 标了关闭的模型还值得下载吗？

可以下，徽标写明「仍可下载，加载时会被守卫拦截」。真点「启动」时，内存预算预检会拦下并告诉你缺多少内存、建议先卸载谁；要么换小参数量模型，要么先「停用」几个在跑的。

### 模型自己停了是不是坏了？

不是，默认的「15 分钟无人使用自动卸载」在腾内存。常用模型用行内「钉住」可豁免；时限能在状态条下拉里改（关 / 5 / 15 / 30 / 60 分钟）。

### 提示内存不足该怎么处理？

内存预算有硬底线（总内存的 45%）兜底：先卸载不用的再加载新的；8GB 设备建议一个对话模型加一个嵌入模型为上限。

### 更新检查没反应？

这一步要连官方接口，断网时静默失败、不影响使用；也可以手动拿新版安装包覆盖安装，数据目录保留。

## 一句收束

本地大模型挑哪个档位，答案不在模型排行榜里，而在你的内存条上：预算定档位，剩下的都是细节。

## 顶部状态条逐项读

认识状态条（顶部）

1. 最左是健康灯与文字，五种状态：「正常」（绿）、「引擎异常」（黄）、「不可达」（红）、「已停用」（灰）、「引擎缺失」（黄）；
2. 实例计数显示「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示同名）：可选「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，出厂默认 15 分钟；
4. 「重启全部」「全部关闭」两个按钮点了会弹红色二次确认条——「重启全部运行中的模型？」或「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，「好」执行、「取消」收回；
5. 服务停用时这里只剩一个「启动」按钮。

下载本地模型的链路到此走完，遇到坎先回模型页常见疑问那一节。
