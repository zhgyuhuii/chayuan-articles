# 画图工具实操教程：从入口到完成每一步都有反馈

画图工具这个话题我被问过三次以上，每次都要重新讲一遍。与其反复口述，不如写成一篇：从画图应用的入口讲到验证，中间的分支也一并说清，基于察元AI OS。

## 先对齐一下概念

「画图」是内置的本地画板（开源 jspaint，画笔/形状/文字/取色/填充等经典工具），在画布上涂鸦或给图片批注，可保存为 PNG、把作品一键设为桌面壁纸。画板资产由桌面主进程 paint:// 协议本地供给，仅桌面形态可用。

顺手截个图标两笔，不用再装第三方画板。

按真实界面写，按钮文案原样引用。

## 先确认这些再开始

- 仅桌面形态（察元AI OS）：画板整站资产由桌面主进程经 paint:// 协议供给；浏览器/web 形态打不开（见「形态差异」）。
- 画板界面为 jspaint 原生英文界面（经典 Windows 画图布局：顶部菜单 + 左侧工具箱 + 底部调色板）。

## 一步步来：从入口到完成

1. 打开应用

「画图」是内置应用：Spotlight（⌘/Ctrl+K）搜「画图」打开；或在 应用管理 ＞ 应用 里点「画图」图标。该应用默认不固定在 Dock——打开后图标会出现在 Dock（运行中），右键 Dock 图标选「固定在 Dock」可常驻。窗口标题条显示「画图」（左上红黄绿窗口灯），窗体是整幅画板。打开时若画板资产加载中，画布中央显示「画板加载中…」。

2. 认识画板界面（jspaint 英文界面）

1. 顶部菜单栏：File / Edit / View / Image / Colors / Help / Extras；
2. 左侧工具箱（自上而下）：Free-Form Select（自由选择）、Select（矩形选择）、Eraser/Color Eraser（橡皮/颜色橡皮）、Fill With Color（填充）、Pick Color（取色）、Magnifier（放大镜）、Pencil（铅笔）、Brush（刷子）、Airbrush（喷枪）、Text（文字）、Line（直线）、Curve（曲线）、Rectangle（矩形）等形状工具；每个工具在工具箱下方有附加选项（粗细/形状变体）；
3. 底部调色板：左键选前景色、右键选背景色。

3. 涂鸦/批注

1. 选 Pencil 或 Brush 在画布拖动绘制；选 Line/Rectangle 等形状工具拖出直线/矩形，工具箱下方可切换粗细等变体；
2. 给图片批注：菜单 File ＞ Open（快捷键 Ctrl+O）打开本机图片（或 Ctrl+V 直接粘贴剪贴板里的截图），再用 Line 画箭头线、Text 点画布输入文字（输入完在框外点击应用）；
3. 画错用 Edit ＞ Undo（Ctrl+Z）回退；Image ＞ Invert Colors 反色、Flip/Rotate 翻转旋转等整图操作在 Image 菜单。

4. 保存作品

菜单 File ＞ Save（Ctrl+S）或 File ＞ Save As（Ctrl+Shift+S）：画布导出为 PNG 文件（文件名取当前文档名，无则用 art.png），经桌面保存链落盘到本机（保存桥缺席时退化为浏览器下载）。每次保存的作品同时被记住，下次打开应用时右上角出现浮动按钮「打开上次作品」，点击直接载入上次保存的画布。

5. 设为壁纸

菜单 File ＞ Set As Wallpaper (Tiled) 或 Set As Wallpaper (Centered)：把当前画布设为桌面壁纸（立即生效）。两个菜单项当前行为一致——都按画布原图设置，不做平铺/居中差异处理。

6. 打开图片进画板

除 File ＞ Open 外，也可用 Ctrl+V 粘贴图片到画布；File ＞ Load From URL 可从网址载入图片。

## 做完后的验证

验证

1. 打开应用数秒内画板出现（「画板加载中…」消失），Pencil 在画布画线有痕迹。
2. Ctrl+O 打开一张本机图片，画箭头后 File ＞ Save，生成的 PNG 文件可再次打开且批注在图上。
3. File ＞ Set As Wallpaper (Centered) 后桌面壁纸立即变为该图。

## 什么情况下用得上

需要一个不联网、开箱即用的画板工具；快速涂鸦、画示意图、给截图或照片加箭头/文字批注；想自己画一张桌面壁纸，给孩子涂鸦。

用户常搜的问法：察元OS 有画图/画板软件吗？在哪里打开；怎么在图片上画箭头、加文字批注。

## 它的局限也要说清楚

边界都在这：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 高频疑问

### 图片能从文件管理器右键「打开方式」进画图吗？

当前「打开方式」候选为文本编辑/图片查看/媒体播放/PDF/文件查看等查看器，不含「画图」；在画板内用 File ＞ Open 打开图片即可（等效路径）。

### 界面是英文的，能换中文吗？

当前内置的 jspaint 资产包未携带语言文件，界面保持英文；各菜单/工具功能与经典画图一致，对照本教程第 2-5 步的中文说明使用即可。

### 保存的文件在哪里？下次怎么继续画？

File ＞ Save 经桌面保存链选择位置保存 PNG；每次保存内容会被记住，重开应用点右上角「打开上次作品」即可载入上次画作继续编辑。

### 画板一直「画板加载中…」或者报「画板加载失败」？

加载 10 秒未完成即转错误态，提示「画板需要桌面应用形态（paint:// 协议供给本地资产）。如果你在浏览器里打开，请在桌面应用中重试；如果就在桌面应用中，可点重试再拉一次。」——浏览器形态请改在桌面应用里打开；桌面形态点「重试」重新拉取资产。

## 补充答疑

### 能把我自己画的图设为壁纸吗？

能。File 菜单的两个壁纸项（Tiled/Centered）都会把当前画布设为桌面壁纸。想要 AI 生成壁纸则用「文生图」应用。

## 安装与运行答疑

### 首次启动感觉卡住了？

首启要初始化数据目录并加载模型服务，5 到 30 秒属正常范围，期间无需干预，完成后自动进入桌面。

### 检查更新失败？

更新需要联网访问官网接口；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

## 一个真实场景

资料重度用户的典型用法：知识库应用建库，拖入 docx、pdf、xlsx 等文件点加载，混合检索加可选重排保证命中质量，引用式问答每个观点带编号脚注。私有资料变成可信可溯源的问答库。注意：单文件 48MB 上限，超限拆分后再传。
