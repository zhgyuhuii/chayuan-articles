# 写给开发者的开发者工具指南：深度复盘

如果你是开发者，下面这些场景大概率不陌生：AI 编程工具装一堆、配置各一套。把工具链收进一个桌面。这篇深度复盘以察元OS为工具，把这个岗位的开发者工具工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- AI 编程工具装一堆、配置各一套
- 本地模型与云端模型来回切
- 系统操作与编码上下文割裂

## 用察元OS怎么解：工作流拆解

1. 安装后四家 CLI 开箱即用
2. 智能体管理统一供应商档案
3. 系统技能让智能体能操作系统
4. MCP 一次配置六家同步

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「安装后四家 CLI 开箱即用」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。把工具链收进一个桌面。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 四家 CLI 约 1.3GB，注意磁盘
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 云厂商模型调用需自备 Key，免费额度视厂商政策

## 常见问题
### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。

### 能多人共用一台设备吗？

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。
