# 远程办公新手路线：出差/远程办公者场景全拆解

如果你是出差/远程办公者，下面这些场景大概率不陌生：外面连不回公司机器。手机连回你的 AI 工作站。这篇新手路线以察元OS为工具，把这个岗位的远程办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 外面连不回公司机器
- 手机上没桌面环境
- 临时要处理文件

## 用察元OS怎么解：工作流拆解

1. 云通道连接设备
2. 手机浏览器 /m/ 入口
3. 远程查看与操作

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「云通道连接设备」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。手机连回你的 AI 工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 需提前配置云通道
- Docker/云通道等进阶形态需要一定动手能力
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### 升级会丢数据吗？

不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。

### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。
