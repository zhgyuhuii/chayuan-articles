# 智能体实操指南：能力矩阵一目了然

命令行智能体这两年一茬接一茬，机器上装七八家是常态，配置打架、出口混乱才是真痛点。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是智能体

智能体在这里特指命令行 AI 编程智能体：能读代码、跑命令、自己拆解任务的那类程序。承载它们的是察元AI OS（Chayuan AI OS，简称察元OS）——一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

所有数字与说法都能在官方文档里找到对应，版本关系见文末。

## 管好十几家智能体图什么

价值不在数量，而在对比：同一个任务丢给两三家，产出差异立见高下，选型就有了依据。这也是能力矩阵存在的意义——不用挨个翻文档，一张表看清谁会什么；新装约 5 秒自动感知、官方品牌图标自动拉取，这些小细节保证清单始终是新鲜的。

- 桌面右键菜单：桌面空白处右键：新建、上传、更改墙纸、小组件、便签、图标大小与排序、添加快捷……

## 上手前要心里有数的几条

- 机器内存 8GB 的话，同时只跑一个对话模型，复杂任务吃不消
- 龙芯眼下没适配；视频生成本地没有，得靠云端路由
- 云端厂商模型要调用，API Key 自己提前备好
- Docker 云桌面、跨终端互联这些进阶形态，折腾劲头不够能劝退

边界先知道，主线照样用，选择权在你。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 用智能体时常撞见的疑问

### 这些智能体都要联网才能干活吗

分情况：智能体接云端模型时依赖网络，断网时云端模型不可用，可设自动回落本地；跑本地模型的活不受影响。配置上有个省事的设计——本机统一 OpenAI 兼容出口（127.0.0.1:52581），智能体只配一个地址，保存后设置结果分发到智能体侧。

### 智能体数据存在哪

CLI 智能体经 MCP 自动接入，配置与状态都在本机管理；生图模型不配好的话，画图应用与智能体的生图指令都会落空。

## 一句收束

智能体这套东西适不适合你，把上文的能力清单和边界放到自己的项目里掂一掂，比看任何导购都有用。

## 桌面这一层还有什么

管智能体之余，桌面本身也不空：右键能编辑小组件（时钟、天气、照片、日历及玻璃系列、网页挂件）；设置桌面与 Dock 可调位置、自动隐藏、图标放大与大小、开机自动打开 Harness；桌面右键还能录制屏幕；独立小窗便签支持新建、置顶、折叠、换色、贴图片视频附件。

## 模型怎么配、数据在哪

本机轻薄、远端肥厚时，桌面只当壳。遥测有开关，清除桌面数据是破坏性操作、界面带警示；升级从不丢数据，检查更新断网时静默失败、不碍事；账户隔离，数据在服务器侧统一管理。模型选择上，本地模型解决有无问题，复杂任务还是需要云端旗舰模型；模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记）。断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。各家智能体的配置片段可以一键复制，省得手抄。

## 运行时的几个巧功能

智能体可以在运行时定义并挂载新插件，和 AI 说一句「给我做个每晚汇总新闻的应用」就行；故障转智能体修复，输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；任务管理带智能筛选（今天、已计划、旗标、已完成）与多列表管理。
