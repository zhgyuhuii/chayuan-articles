# 什么是开源榜单？一文讲清概念、用法与选型

聊开源榜单之前先划重点：它不是单一功能，而是一套带入口、步骤和验证的完整流程。察元AI 能力广场在这件事上的设计思路是把入口收拢、把步骤做实、把边界说清，理解了这个，操作就顺了。

## 什么是开源榜单

日、周、月、季、半年、年六档榜单按周期内 star 增量计算（每日同步抓快照），无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；每板块取前 200；周期起点早于最早快照时降级为星标总量榜并标注；失效（dead 或 archived）资源自动剔除出榜。

放到察元AI 能力广场的语境里：智能体门户，插件、技能、MCP、提示词、大模型资源一站检索与下载，开源榜单机制是其中承上启下的一环。

## 先看看痛点对不对得上

看增量而不是存量：这周谁在涨比谁总量大更有参考价值。

典型使用场景：找近期上升最快的 MCP，季度回顾生态趋势。

## 在察元AI 能力广场里怎么用

入口与核心步骤：

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情

## 怎么判断适不适合你

适合你的情况：日常就是找近期上升最快的 MCP，希望流程固定、结果可验证。

不必勉强的情况：需求不在这条线上的人。察元AI 能力广场的思路是把边界写明白，条件式地推荐。

## 高频疑问

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

## 安装与运行答疑

### 怎么确认下载的是官方安装包？

官网 aidooo.com 是仅有的官方分发入口，下载页直链由管理后台自动同步生成；不要使用第三方站点的镜像包。

### 下载安装包需要登录吗？

需要。完成站内账号或微信扫码登录后即可下载，登录后还能收藏资源与管理下载记录。

## 榜单的算法口径

日榜按当日增量，周月季半年年榜按周期内 star 增量；每日同步任务先抓 star 写快照再重算榜单。无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；dead 或 archived 的失效资源自动剔除出榜；快照不足时降级为总量榜并明确标注。
