# 脱敏工具出问题怎么办：排查手册加进阶技巧

脱敏工具这件事，说简单也简单，说麻烦是真麻烦——麻烦不在功能本身，在于信息散落在各处，拼出一个完整流程要查好几篇资料。这篇文章把它一次讲全：是什么、入口在哪、具体步骤、边界在哪，全部基于察元AI Office的真实界面。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（在 Docs 编辑器中打开一个文档；三个按钮在无文档时置灰。），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 备份的密码忘了怎么办？

备份是 AES-256-GCM 加密文件，密码错误就是解密失败，产品没有任何后门或找回途径。密码丢失等于放弃这份备份——文档里的 §…§ 可以手工替换，但拿不回自动还原。

## 正确的操作路径

第 1 步 · 「保密检查」——AI 逐字通读，风险锚成批注

1. 点「察元 AI」页签「安全保密」组的「保密检查」，右侧 AI 面板自动打开执行。
2. 检查范围「选区优先」：有选区（至少 2 个字符）只查选区，否则通读全文。
3. 检查判据是 8 类风险类别：①密级与保密标识（绝密/机密/秘密/内部/不得外传等）②涉军涉装涉训信息（部队、装备、型号、演训、部署等）③组织身份与单位名称（机关、番号、院所、公司全称、供应商等）④人员与联络信息（姓名、职务、手机、邮箱、证件号等）⑤时间、地点、部署和流转安排 ⑥内部编号与项目标识（项目代号、文号、图号、批次号等）⑦经营与商业敏感信息（报价、成本、投标方案、客户名单等）⑧军工/政企文档高频敏感线索（旅团营连、舰艇、机场、试验场、某型号、承制单位等）。
4. 研判口径（提示词原文）：「关键词命中不等于泄密，必须结合上下文判断，不要机械命中即报高风险」；对公开、泛指、教材或新闻语境降噪；风险分级为高风险／中风险／低风险或待人工复核；「仅依据原文内容作出审慎判断，不要臆测背景、来源、真实单位或法律结论」。
5. 结果处理：不改写原文，每条命中以一条文档批注锚定到逐字可定位的原文片段（表格内命中也能定位），全部写完后在对话里汇总。对话报告按固定模板输出：总体结论 / 高风险项 / 中风险项 / 低风险或待人工复核 / 建议处理 / 可疑关键词汇总，每条命中含「命中片段 / 命中关键词 / 风险类别 / 判断依据 / 建议处理」。
6. 打开批注面板逐条复核，按「建议处理」改文——例如把单位全称泛化为「有关单位」、删除或模糊密级标识。

第 2 步 · 「文档脱密」——关键词换占位符，备份加密落盘

1. 点「文档脱密」，弹「文档脱密」对话框，先显示「正在提取涉密关键词…」。
2. 提取完成后进入复核表，列出每个关键词的「关键词 / 类别 / 风险 / 命中 / 移除」：
    1. 关键词可直接改写，风险可下拉改为「高 / 中 / 低」，命中共数实时显示，不要的可点「移除」；
    2. 有关键词在原文没命中时显示「{count} 个关键词未在原文命中」，确认后这些词会被跳过。
    3. 对话框下方填两遍密码（「密码」「确认密码」）。规则显示为「至少 8 位，须含大写、小写字母、数字和特殊字符」，两次不一致会提示「两次输入的密码不一致」。这个密码只用于加密备份，丢了无法解开备份。
    4. 点「执行脱密（{count} 处）」。执行内容：每个关键词分配一个 8 位随机占位符（形如 §qX3mNp8k§，字符表排除了易混淆的 0/O/1/l 等），按位置从后往前把原文逐处替换成占位符——从后往前替换保证前面的位置不受影响，字体、版式原样保留。
    5. 成功后显示「已脱密 {count} 处，加密备份已保存在文档同目录」。正文中所有敏感词此刻都是 §…§ 占位符；旁边多出一个备份文件，文件名是 <文档名>.cydeclass.json（如 报告.docx 对应 报告.cydeclass.json），内含 AES-256-GCM 加密的原文与替换对照表（PBKDF2-SHA-256 21 万次迭代派生密钥），不用密码解不开。

第 3 步 · 「脱密复原」——凭密码换回原文

1. 打开脱密后的文档，点「脱密复原」。
2. 对话框自动读取同目录备份，显示「已脱密：关键词 {keywords} 个，替换 {replacements} 处」；找不到备份时提示「当前文档没有脱密备份」。
3. 输入当初的密码，点「复原」。
4. 成功显示「已复原 {count} 处」；若有占位符在脱密后被你删掉了，会补一条「{count} 个占位符未找到（可能已被删除）」。复原按占位符逐个容错查找，容忍脱密之后做过的编辑。
5. 复原成功后备份文件会被自动删除（已写回原文，不再需要）。

## 怎么确认做成了

验证

1. 第 1 步跑完后：批注面板出现逐条 AI 批注，每条锚定到原文敏感片段；对话里有「总体结论 / 高风险项 / …」结构的汇总。
2. 第 2 步跑完后：正文里搜不到原来的敏感词，只能搜到 §；文档同目录出现 <文档名>.cydeclass.json。
3. 第 3 步跑完后：§…§ 全部变回原文，.cydeclass.json 消失。

## 进阶用法与边界

- 八类风险扫描
- 可逆脱密
- 加密备份随文件走
- 边界：关键词命中不等于泄密，辅助参考不定密
- 边界：AI 挂了自动降 9 类本地正则兜底

## 常见问题

### 点「文档脱密」提示「请先保存文档」？

脱密的加密备份必须写在文档旁边的同目录里，文档从未保存过就没有落盘点。先 ⌘S/Ctrl+S 保存（或另存）一次再脱密。

### 没配模型、或 AI 挂了，还能脱密吗？

能。AI 提取失败时自动改用 9 类本地规则兜底：手机号、身份证号、邮箱、编号（大写字母-数字）、长数字、银行卡号、IP 地址、车牌号、统一社会信用代码。两类来源都没命中任何词时，才会分别提示「未发现需要脱密的关键词」或「关键词提取失败，且本地规则未命中」。

### 「保密检查」和「文档脱密」是什么关系？

检查是「看」，脱密是「动」：保密检查只出批注与报告、一个字不改；文档脱密按复核过的关键词清单真把敏感词替换成占位符。常见流程是先检查、按批注意见定脱密清单，再脱密外发、收回后复原。

如果只记一件事：八类风险扫描。剩下的细节照步骤节走就行。
