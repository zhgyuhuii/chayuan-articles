# 扫描件转Word入门指南：从 Word 无痛迁移

扫描件转Word是文档数字化的高频动作：纸面合同、盖章页、老档案进了电脑就是一张张图，改不了一个字。这篇把这件事在开源办公套件里的入口、能力与坑位一次讲完，顺带说清转出来之后的编辑体验。

## 什么是扫描件转Word

扫描件转Word指的是把扫描得到的 PDF 页面转成可编辑的 Word 文档。它不是单一功能，而是一套带入口、步骤与边界的完整链路：转换入口、转出后的编辑器、识别不了的兜底提示，环环都得在。这篇的口径整理自官方文档，版本对应关系见文末。

先分清两种 PDF：一种导出时就是文字层完整的「活」PDF，一种扫描仪吐出来的整页位图。后者才叫扫描件，肉眼看着有字，机器眼里只有图，转 Word 的全部难度都在把图里的字变回文字对象。搞不清手上文件是哪种，先把光标放进正文里试着选中一段，能选中就是活 PDF，选不中多半是扫描件。

## 判断扫描件值不值得转

来源质量决定转出质量：打印清晰、版面规整的合同纸本，转出来基本能用；斜拍的照片、糊掉的红章、手写批注混排的老档案，转出效果就要打折扣，转完逐段核对是必做的动作。另一条判断是量：单份材料随手转就行，整柜档案要批量处理，就先把 OCR 边界、平台限制摸清楚再排计划，别转了一半发现某类页全部保留位图。

## 转换入口在哪个页签

入口在 Docs 编辑器的开始页签：转换下拉五项——PDF 转 Word、Excel、PPT、Markdown、HTML，扫描件转Word正是其中一路。转出来接着编辑也不换软件：十个页签的功能区覆盖开始、插入、绘图、设计、布局、引用、邮件、审阅、察元AI、视图，再加表格图片页眉页脚的上下文页签；导航窗格、五种视图、拆分、深色页面、首字下沉、域、交叉引用、真图表都在。功能面覆盖决定能不能真正替换，常用 Word 动作这十个页签基本补齐了。有个小细节：大部分按钮在无文档时置灰，绘图、视图的部分开关（如深色模式）不受此限，装好后空窗口别误以为功能缺失。

## 转出来之后还认得原稿吗

认得。这套 Docs 引擎做字节保真往返：你没动过的内容块逐字节写回，修订、批注、公式、墨迹也都在转出稿里保留。日常公文写作里最常见的需求——改一段、留批注、套公式——转完接着做，不用从头重排。从 Word 无痛迁移这个场景也靠它撑着：老文档进来什么样，没改的区域出去还是什么样。

## 扫描件的几条边界，先记牢

- Linux 无系统 OCR 引擎，扫描页保留位图不识别，想识别得换有 OCR 的环境。
- 扫描页转 PPT 与 Excel 后文字不可编辑，来源是图，结果也带不动可编辑文字。
- 加密只读文档仅支持查看，转不了。
- 仅桌面形态提供 HTML 编辑器。

这些边界不影响主线使用，但决定你的扫描件能不能走通这条路，动手前先对号。

## AI 在这条链上的位置

AI 挂在编辑器侧边而不是独立窗口，改稿与对话在同一屏完成，这是六端通用的 AI 面板，打开 AI 助手按钮进面板。报价、身份证号这类片段不想给模型看，隐藏后其他部分照常 AI 处理；涉密文档不能出网时，切本地模型，AI 校对、AI 改写在隔离环境照常工作。模型侧可用 BYOK 方式接 94 家供应商，本机 Ollama 等本地端点同样在支持之列；注意内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型。外部智能体也可接入，写材料引用内部资料且带出处，写作与知识库一条链打通；Claude Code 这类编码智能体还能按 MCP 协议直接驱动文档读写，批量化处理有章可循。

## 顺手的周边能力

- 文件名与正文双路搜索：索引启动约 4 秒后首轮扫描。
- 命令行：chaoffice 带 17 个子命令，批量处理走这条入口。
- Agent Skill 安装器：把察元AI Office 的操作手册以 SKILL.md 技能包形式装进 7 家编码智能体（Claude Code、Codex CLI、Cursor、Gemini CLI、Copilot CLI、OpenCode、Windsurf）。
- 远程存储：S3 兼容与阿里云 OSS 作为远程存储，可设默认保存位置。
- API Key 存本机 ai-settings.json 不上传，支持环境变量引用；文档脱密用 AES-256-GCM 加密备份，PBKDF2-SHA-256 21 万次迭代。

## 常见疑问

### 断网状态下，扫描件转Word还能做吗

本地优先、离线可用，内网与离线全可用，转换这条主线不依赖网络；Linux 上扫描页保留位图不识别是系统层限制，与联网与否无关。

### 转换下拉里除了 Word 还能转去哪儿

五个方向：Word、Excel、PPT、Markdown、HTML，扫描件按需选出口，转 Word 只是使用频率最高的那一路；要进表格流程就选 Excel，要做汇报就选 PPT，去向想清楚再点，省得转完再倒一手。

### 转出来的 Word 会不会悄悄变了样

不会。未触碰的内容块逐字节写回，改动只落在你动过的地方，转出稿与原稿的差异可控可查，做完自己再通读一遍核对图和章的位置就够。

### 手写批注混在扫描页里，转得出吗

手写内容本来就是识别难点，转出后重点核对这类区域；实在拿不准的页，保留原扫描页做底，转出稿只当工作副本用。
