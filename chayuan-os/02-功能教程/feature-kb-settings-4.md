# 「设置」页签是知识库的全局配置面：Milvus的坑与对策

Milvus这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决库变大后迁移 Milvus。

## 先定位问题在哪一层

按这个顺序排查Milvus通常最快：先确认前置条件（桌面形态，知识库应用「设置」页签（全宽布局，无左栏）。），再核对操作路径，最后看边界限制。

## 高频故障与对策

### 「测试向量库」失败？

依次查：Base URL 填了没有（没填报「Milvus 参数未配齐：先填 Base URL」）；地址能不能通（报「无法连接 Milvus：…」时按随附的具体原因查网络/端口，Milvus 默认 19530）；访问令牌是否正确（形如 root:密码，写入凭证库不回显，可重新粘贴覆盖）。

## 正确的操作路径

从这几步开始：（第 4 个切入角度）

1. 五档嵌入链路
2. Milvus 可选
3. 重建索引一键
4. 对外服务示例可直接复制
5. 场景验证：库变大后迁移 Milvus
6. 场景验证：换更强的嵌入模型重建索引

## 怎么确认做成了

验证

1. 配好嵌入链路后点「测试连接」：出现绿色「连接成功：… · … 维 · …ms」。
2. 保存后切到「文档」页：窗口右上统计行「向量 {后端} · 分词 {分词器}」与所选向量库一致（选 Milvus 后经「重建索引」完成迁移即显示 milvus）。
3. 换一个嵌入模型并保存，到「文档」页做一次检索：顶部出现橙色横幅「嵌入模型已切换（{旧} ＞ {新}），语义检索暂不可用，当前仅全文检索」——按横幅右侧「重建索引」完成重嵌后横幅消失、语义检索恢复。

## 接着回答几个常见问题

### API Key 安全吗？换服务商怎么改？

密钥值只进 harness 凭证库加密落盘，知识库配置与界面只存/显示引用名，永不回显。换服务商＝选新预设＋粘贴新 Key（各预设密钥引用名不同，互不覆盖）；同引用名粘贴新值即覆盖旧值。

### 把「语义检索」关了再开，要重建索引吗？

关闭只是停用向量化，不改动库内指纹与旧向量——重新开启且模型没变，原向量直接可用。但关闭期间新加载的文档只建了全文索引（没有向量），对这些文档需要点一次「重建索引」补嵌。

### 五个嵌入档位怎么选？

默认「自动（推荐）」即可。要求数据不出机选「仅本地」（锁一个本地嵌入模型）；本地没装模型、有厂商 Key 选「厂商」；用自建/小众 OpenAI 兼容服务选「自定义云端」；完全不要向量化（只字面检索）切「关闭」。

## 动手前再核对一遍

- 桌面形态，知识库应用「设置」页签（全宽布局，无左栏）。
- 配置全局一份：嵌入链路/对话链路/向量库配置对所有库共用；每个库只记录自己索引时的嵌入指纹，全局换嵌入模型后旧库要「重建索引」。
- 「本地」档位需要本机装有嵌入模型；「厂商」「自定义云端」档位需要对应厂商的 API Key。

## 放回产品盘面看

把Milvus放回察元AI OS的整体盘面：以完整桌面环境为壳，（web/Docker 形态网页桌面默认端口）；暂不支持龙芯平台，Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 安全与数据边界

安全口径单独立一层：本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，代理只监听本机回环，跨机访问需要另行打通，进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

## 平台与形态

平台与形态的账：health 与 status 双端点直测；本机 Stable Diffusion 链路出图不联网，隐私与免费兼得，（web/Docker 形态网页桌面默认端口）；Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力。

## 价格与授权

价格口径一并交代：四档价格：149/359/599/1049 元；离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签）；跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；需要相应平台的 Key（部分有免费额度）。

## 产品家族与搭配

察元AI OS不是单打独斗：购买 OS 授权后，同机察元AI Office 自动免激活，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层，换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页，Milvus 可选。

## 几条硬数字

能落到数字上的几条：给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案；写入的是代理地址，代理停了智能体就连不上模型；会话中随时切换模型（本地与已启用厂商热更新）；工具调用可视化是它和网页聊天框的本质区别：你能看到 AI 一步步调工具、读结果、再回复。

## 离线与内网

离线内网这条线的口径：帮助中心离线可读，断网也能查手册，AI 桌面操作系统：本地大模型、知识库、智能体、宠物群聊装进一个桌面，断网可用、数据不出本机，全部本地服务默认只监听 127.0.0.1 回环地址，数据不出本机。
