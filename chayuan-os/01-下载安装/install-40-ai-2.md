# 升级注意事项（察元OS）

版本号规则与升级前备份。本文以「升级注意事项」为主题，给出察元AI OS的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：官网 aidooo.com https://aidooo.com；GitHub Releases https://github.com/zhgyuhuii/chayuan-harness。系统要求总览：Windows——Windows 10/11（x64）与 Windows on ARM（arm64）；macOS——Apple Silicon / Intel；Linux（deb 系）——x64/arm64；UOS 20 推荐 deb；银河麒麟 V10（飞腾/鲲鹏/兆芯/海光）有专门适配章节；Linux（通用）——x64/arm64，FUSE 2；服务器/Docker——任意可跑 Docker 的服务器。

## 通用流程（以 Windows 为例）

版本号规则与升级前备份

1. 从官网或 GitHub Releases 下载 ChaAIOS-<版本>-x64.exe
2. 双击 NSIS 安装器完成安装（零额外依赖）
3. 启动后数秒进入桌面（初始化数据目录约 5-30 秒）
4. 对话应用里选择本地模型即可开聊（无需联网）

## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：升级采用覆盖安装方式，用户数据目录不受影响

## 相关报错速查

- 安装提示架构不符？——终端执行 uname -m 确认架构：aarch64 选 arm64 包，x86_64 选 x64 包；飞腾/鲲鹏设备均为 arm64。
- 首次启动感觉「卡住」了？——首启要初始化数据目录并加载模型服务，5-30 秒属正常范围；期间无需干预，完成后自动进入桌面。
- 语音输入没反应？——检查系统麦克风权限与默认输入设备；确认 whisper 语音识别模型已加载；嘈杂环境建议使用外接麦克风。

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

## 常见问题
### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 智能体（CLI）无法启动？

在应用管理→智能体页检查安装状态并重装；四家 CLI 二进制随安装包分发（约 1.3GB），磁盘空间不足会导致启动失败。

### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。
