# 图片整理场景实战：从需求到交付

被图片整理折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI文档助手为准。

## 为什么值得了解

论文/报告里所有图要按「图1、图2…」自动编号加题注，或清掉旧题注重排；报告插图统一压缩，要把文档里的图整体打包交付（导出成图片文件），或整篇删图留文字；领导要求全文几十张插图统一宽度、统一加边框、统一居中，一张张手调太慢。

用户常搜的问法：怎么把文档里的图片全部导出来；统一图像格式都能统一哪些东西。

## 从打开到做完的每一步

入口：顶部「察元AI助理」选项卡 ＞ 「批量操作」分组 ＞ 「图像批量操作」▾，下拉共 6 项，按菜单顺序说明如下。

1. 「导出全部图像」

1. 做什么：点击后先弹文件夹选择框（标题「请选择要保存图像的文件夹」，默认定位到文档所在目录），选中保存文件夹。
2. 看到什么：全部嵌入式与浮动型图片导出为 PNG 文件，命名「嵌入式图片_N.png」「浮动型图片_N.png」（N 为序号）。成功弹「成功导出 N 张图片！ 保存路径：<文件夹>」并尝试自动打开该文件夹；部分失败弹「找到 N 张图片，成功导出 X 张，失败 Y 张」并列错误详情；一张都没有弹「未在文档中找到任何图片！」及类型提示。

2. 「删除全部图像」

1. 做什么：点击即执行，无确认弹窗；先删嵌入式图片，再删浮动型图片。
2. 看到什么：完成弹「已删除 N 个图像」；本来就没有图片弹「文档中没有图片」。

3. 「统一图像格式」

点「确定」（执行中按钮显示「处理中…」）。

1. 做什么：点击弹出「统一图像格式」窗口，副标题「设置将应用到文档中所有图片（嵌入式与浮动型）。留空项不修改。」。四个分区按需填写：
    1. 「尺寸（磅）」：「宽度」「高度」（1～2000，留空不修改）；勾选「锁定纵横比」时「仅填宽度或高度时，按原图比例计算另一边」；
    2. 「描边」：勾选「显示描边」后可设「线宽（磅）」（0.25～20，默认 1）与「颜色」下拉（黑色/灰色/银色/深蓝/藏青，默认黑色）；不勾选则清除描边显示；
    3. 「图像效果」：「亮度（-100～100）」「对比度（-100～100）」，留空不修改；
    4. 「对齐方式」：单选「不修改」（默认）/「左对齐」/「居中」/「右对齐」，提示「仅影响嵌入式图片所在段落的对齐」。
    5. 看到什么：校验不过红字提示（如「宽度须在 1～2000 磅之间」「描边线宽须在 0.25～20 磅之间」「请至少设置一项」）；有图片被处理则显示「已处理 N 张图片（嵌入式 X，浮动型 Y）」并自动关窗；没找到可处理的图片显示「文档中未找到可处理的图片」，窗口留着可改。

4. 「清除图像格式」

1. 做什么：点击后不执行任何格式操作。
2. 看到什么：弹窗标题「功能暂未上线」，正文「「清除图像格式」目前为占位入口,将在后续版本提供。 替代方案:可使用「统一图像格式」对话框设置统一规则。」——按提示用「统一图像格式」替代。

5. 「删除图像题注」

1. 做什么：点击即执行，无确认弹窗。定位紧贴每张图上/下方（间隔 1～80 字符）且长得像图题注/标签的段落（「图1」「Figure 1」「附图」等模式）删除；按位置没找到时再全文档按图题注模式扫一遍。
2. 看到什么：成功弹「已删除 N 个图像题注（含标签）」；没有可删的弹「文档中没有找到图像题注」。

6. 「添加图像题注」

点「确定」。

1. 做什么：点击弹出「添加或修改题注」窗口（与表格题注共用，副标题变为「在正文中图像的上一行或下一行插入题注，居中显示」）。逐项填写：
    1. 「标签」：图像模式下默认「图」，提示「题注序号自动生成：图1、图2、图3…」；
    2. 「题注内容（可选）」：接在序号后，无空格；
    3. 位置单选「上方」（默认）/「下方」。
    4. 看到什么：按图片在文中的先后顺序生成「图1」「图2」…（嵌入式与浮动型一起排序编号），空白段被利用或插入新段，题注居中；成功后窗口自动关闭、无弹窗提示；文档没有图片时窗口内红字提示「文档中没有图片」。

## 关键能力点

- 6 项图像动作

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 接着回答几个常见问题

### 导出的图片在哪个文件夹、叫什么名字？

导出前弹的文件夹选择框里选哪个就是哪个，完成后弹窗显示「保存路径」。文件名固定为「嵌入式图片_N.png」「浮动型图片_N.png」；若个别图导出失败，结果弹窗会列出失败张数与前几条错误详情。

### 删错图了怎么办？

「删除全部图像」无确认弹窗，加载项本身也没有撤销入口。立刻试 WPS 自带撤销（Ctrl+Z）；批量删图前建议先另存副本。题注删除同理。

### 统一图像格式填了亮度 50，图片为什么只是略微变亮？

亮度/对比度输入范围是 -100～100，内部按线性关系映射到图片引擎的 0～1 档位（0 为默认值），50 约到四分之三档。想更亮就继续加大数值，上限 100。

## 补充答疑

### 「清除图像格式」什么时候能用？

它当前是占位入口，点了只弹「功能暂未上线」提示，不改任何图片。要把图片恢复统一外观，用「统一图像格式」按需设置尺寸、描边、亮度对比度即可。

### 添加图像题注后编号和图的顺序对不上？

编号按图片在文档中的位置先后自动生成（嵌入式与浮动型统一排序）。若先手动加过一次题注又再加一次，会出现两套题注——先用「删除图像题注」清干净再重新添加。
