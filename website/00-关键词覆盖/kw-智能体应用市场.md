# 智能体应用市场入门指南：智能体门户

想了解智能体应用市场的人，多半卡在两个疑问上：它是不是换皮的软件列表、装了到底能省多少事。这篇把定义、口径、边界分层摊开，结论自己拿。

## 什么是智能体应用市场

智能体应用市场，先把定义立住：察元AI 能力广场是察元AI 的官方门户与资源广场，智能体应用、插件、技能、MCP 服务器、提示词、大模型目录、模型厂商、资讯八大板块在线检索，榜单按日、周、月、季、半年、年六档滚动，配模型智力榜；下载入口一侧承担四条产品线——察元AI OS、察元AI Office、察元AI文档助手、察元AI工舱；微信扫码登录、收藏与投稿也都支持。

定义部分的出处是官方文档，版本对应关系放在文末说明。

## 在门户里落在哪

落点很明确：门户把这类资源单独归进智能体应用板块，收的都是拿来即用的应用形态资源，既能配合桌面产品运行，也能独立跑。与零散工具相比，它的价值就落在成品化这一点上。

理解这个板块的钥匙是「形态」二字。同样想完成一件事，散装路线是自己找工具、写指令、接协议，一件一件凑；成品路线是别人已经把角色、流程、工具配好打包，你只做两件事：挑一个对的，按说明跑起来。省下的搭建时间是真的，代价是灵活性让渡——成品管到哪一步，你就在哪一步接手，想换个姿势得自己动手改。

## 最短上手路径

1. 进智能体板块
2. 看榜单或检索
3. 进详情页看运行方式
4. 按说明部署或安装

第三步值得多说一句：详情页里写的运行方式决定了后面所有动作。标注配合产品运行的应用，要先装好对应桌面产品再装应用；标注独立运行的，按页面给的步骤单独部署即可。形态挑错、装完跑不起来是最常见的卡点，回头排查这个的成本比选型本身高得多。

## 同门户里的相邻资源

- 模型中心：目录、厂商页、对比页三件套齐全，厂商页只收已核验的厂商与网关；对比一次并排至多 6 个；智力排行把五个维度各测一遍，单维出 0-100 百分位，总分是五维等权的平均
- 教程库：另有 4526 篇内置助手教程，目录按 228 个行业领域划分，找某个行业的用法先翻对应目录
- 技能包商城：按行业与场景给包归类，教育、IT、科研论文、法律、金融几个方向都有现成的包主题
- 技能板块：收 SKILL.md 形式的技能文件，采集自社区精选与技能仓库，装上后智能体会按里面写的流程做事

## 几种可以缓一缓的情况

- 想在网页里一次读完教程的会落空：教程库一侧只放条目索引，正文全部留在源站
- 想匿名取包的行不通：下载与收藏都要先过登录这一关
- 榜单的热度口径要留意：没有 GitHub 数据可依时，排序会掺入站内下载量，参考即可，别当成质量定论

这几条都不挡主线，知道位置在哪就行，真撞上时不用回头翻文档。

## 数据与安全设计

- 登录可选站内账号或微信扫码，收藏容量 200 条
- 投稿与需求墙的内容都要过一道审核，通过才可见
- 包的下载清单由后台统一生成同步，取包走门户内下载页，别处递来的安装包不做保证

这层设计对使用者的意义在预期管理：审核机制意味着从投稿到上架有等待期，别把「投了怎么还没显示」当故障；清单统一生成意味着同一入口拿到的包内容一致，真出问题也容易定位来源。拿不准的地方，详情页的说明就是第一参考。

## 几个高频疑问

### 智能体应用和插件怎么区分？

智能体应用是配好角色、拿来即用的 agent 形态资源；插件是往桌面系统里加装能力模块的。两者在广场各归各的板块。

### 智能体应用市场要注册吗？

纯浏览不用。检索、看详情、翻榜单都开放；要把应用存进收藏或下载安装包，才需要登录。

### 智能体应用市场资源免费吗？

板块里的条目免费付费都有，单个应用收不收费看资源页的标注；列表页设了促销与免费额度的筛选，只想先看免费的部分，勾一下就能过滤出来。

## 和桌面产品怎么配合

这个门户不只是网页检索：察元AI OS 的应用商店与门户共用一套数据，系统里装了 OS 的机器可以直装这里收的应用；其他桌面产品从站内取 Windows/macOS/Linux 安装包，Linux 侧含麒麟与 UOS，装国产系统的机器照样有包可取。付费应用一次购买可装进八款智能体，安装支持断网离线完成，内网机器也用得上。网页端负责检索与收藏，桌面端负责跑应用，两端分工清楚。
