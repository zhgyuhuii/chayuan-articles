# ⭐Markdown 编辑器隐藏用法｜Markdown编辑器一次讲清

用过察元Office的宝子看过来，Markdown 编辑器这个功能很多人没用到极致👇

✅ **它能干嘛**

Tiptap 块编辑器：标题、列表、表格、图片、代码块所见即所得，存储仍是纯 Markdown 文本。

🔍 **三步用起来**

1️⃣ 新建 .md 文件
2️⃣ 块编辑或源码模式切换
3️⃣ 保存为纯 Markdown 兼容 Git 工作流

💡 **什么场景最香**

· 技术文档与笔记
· README 编写

📌 **避坑提醒**

⚠️ 重度宏（VBA/宏表）与部分深度排版长尾功能与微软 Office 存在差距，复杂场景可能仍需商业套件兜底

🛠️ **更多它擅长的事**

· **多标签与主页**：多标签宿主：多份文档标签页并开，主页统一管理最近文件、对话与项目。
· **PDF 编辑器**：pdf.js + pdf-lib 之上的真文本编辑：段落选中、块内重排、对齐还原、原字体保留——经 PDFium wasm 重写页面内容流，而非遮盖式注释；另有批注、表单、书签、印章、签名、页面操作与打印。
· **Docs 文字编辑器**：docx 编辑器：字节保真往返（只重生成改动过的段落，未触碰部分逐字节保留，Word 打开无感）、Word 级分页复现、修订（tracked changes）、批注、样式、公式、墨迹。

⚠️ **断网也能用？这点很关键**

文档编辑与格式转换完全本地化：打开、编辑、保存不出机器；PDF 转 Word/PPT/Excel 由内置 PDFium 引擎做字符级提取与几何版面分析，全程离线、无云端参与，扫描件 OCR 也走系统本地引擎（macOS 用 Vision，Windows 用系统 OCR），适合对数据敏感的政企与个人用户。

🎯 **数据安全要知道的**

· 文档打开/编辑/保存全程本机完成，不经任何服务器
· PDF→Word/PPT/Excel 转换与 OCR 均为本地引擎，扫描件不上传
· AI 默认不启用：配了 Key 或本地端点才会把对话内容发往所配服务商

📝 **免费还是要花钱**

开源 Apache-2.0 + 可选授权支持（桌面版 90 天免费试用后温和提醒）。免费部分：apps 编辑器本身免费开源、可自行构建；官方安装包提供 90 天免费试用期。

🧩 **说点大实话（缺点）**

· AI 能力需自配模型（云端 Key 或本地端点），不配置时 AI 功能不可用
· 重度宏（VBA/宏表）与部分深度排版长尾功能与微软 Office 存在差距，复杂场景可能仍需商业套件兜底
· 官方安装包 90 天试用后会有每日一次的购买提醒（不锁功能、可关闭）
