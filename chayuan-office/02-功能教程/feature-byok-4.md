# 大模型接入办公出问题先看这：开源 AI 办公套件

大模型接入办公的麻烦不在功能本身，在于信息散。自带 Key 意味着不被单一厂商锁定，国内国际本地端点随切随用。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

大模型接入办公的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把主页可打开设置弹窗（入口见第 1 步）；不指定落点时弹窗默认停在「模型设置」区。核一遍，再查路径。

## 正确的操作路径

最短路径走一遍：（第 4 个切入角度）

1. 94 家目录
2. 按能力分设默认模型
3. Key 不出本机
4. 确认边界：AI 功能依赖已配置模型
5. 确认边界：内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型
6. 场景验证：公司统一采购的 API 接入

## 接着回答几个常见问题

### 大模型接入办公要联网吗

打印别掉链子、断电别丢稿，这是办公软件的两条底线；服务器部署全员浏览器可用，是团队化办公的形态；支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点。以官网 aidooo.com 当前页面为准。

### 大模型接入办公支持哪些格式

打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；老格式给出明确提示，十分区设置地图：通用、语言（22 种）、主题、模型、知识库、隐私等，通用区逐项可调。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把大模型接入办公放回察元AI Office的整体盘面：Linux 无系统引擎不识别，仅桌面形态提供 HTML 编辑器；支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点，AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用。

## 安全与数据边界

安全口径单独立一层：开源办公套件能离线装、信创环境能跑，是替换传统办公链路的第一步；格式兼容是办公软件的生死线，明确支持什么、不支持什么，比含糊其辞负责任，按能力分设默认模型；AI 功能依赖已配置模型。

## 价格与授权

价格口径一并交代：报价、身份证号这类片段不想给模型看，隐藏后其他部分照常 AI 处理，D 模型直接进 pptx 且往返保真，这是多数在线编辑器做不到的，glb 3D 模型；让 Claude Code 这类智能体直接读写你的文档，办公自动化从此有了标准协议。
