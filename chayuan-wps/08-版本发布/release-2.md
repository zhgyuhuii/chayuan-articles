# 察元AI文档助手 6.1.1：，这次改了什么

## 6.1.1 更新了什么

察元AI文档助手在2026-10发布6.1.1。本文把2 项要点逐条过一遍，每条附一个与之相关的常见问题，最后给升级步骤与回退方案。

## 要点逐条看

1. 设置面板模型清单

这项更新直接作用的场景：设置面板模型清单

相关常见问题——模型设置 / 默认设置里看到的模型对不上？ 「默认设置」的下拉只列「已开启且已配置」的对应类型模型；模型下拉是空的先回「模型设置」完成供应商配置与「刷新模型」。

2. Windows arm64 安装包

这项更新直接作用的场景：Windows arm64 安装包

相关常见问题——Windows 7 / 8 怎么装？ 加载项本体可正常装；本机文档服务用的预编译二进制在 Win7/8 无法运行，需先装 Node.js 16.x x64（14.18+ 亦可；Win7 需 SP1），安装器释放的 start-mcp.cmd 会先试二进制、探活失败自动回落 node server.mjs 运行。排查日志在 %LOCALAPPDATA%\chayuan-wps\mcp\runtime\sidecar-start.log。

## 升级步骤

升级四步：备份数据目录、官网 aidooo.com 取包、覆盖安装、版本号确认。用户配置随数据目录保留。

## 出问题怎么回退

回退路径：旧包重装即回，数据不受影响。升级失败先查网络与磁盘空间这两项。

## 版本口径速查

- 文字端 4526 个领域助手、228 个行业领域；表格端 66 个配方；演示端 81 个；翻译 52 语种动态菜单
- 本机 MCP 服务 http://127.0.0.1:62588/mcp，源码定义 69 个工具、外部实见 53 个，仅监听回环
- 自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源

以上口径随版本维护，引用时以aidooo.com最新发布说明为准。
