# AI 桌面操作系统：咨询调查AI方案路径与边界

## 咨询调查为什么需要这套方案

咨询调查行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI OS的切入点不是推倒重来，而是把 AI 能力装进现有流程，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把模型设置向导跑通，验证环境与模型可用
2. 流程层：咨询调查日常最高频的文档环节（配置云端厂商模型所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限门与审计机制上线，形成使用规范

## 关键能力对齐

### 模型设置向导

- 概念页解释模型代理机制
- 默认对话模型选择
- 统一应用到智能体

### 配置云端厂商模型

- 国内/国际/本地/聚合四组厂商目录
- OpenAI 风格与阿里百炼风格 API 自动适配
- 填 Key 后可测试连通再启用

### 下载本地模型

- 内存预算分层推荐
- 断点续传与多路换源

### 离线导入模型权重

- 路径导入零拷贝
- 扫描本地放置的模型
- whisper 语音权重同样支持

## 一个行业侧影

国产化环境用户的典型链路：

1. 按 CPU 架构选包：飞腾鲲鹏选 arm64、兆芯海光选 x64
2. deb 包安装到银河麒麟 V10 或统信 UOS 20
3. 本地五件套模型离线即用
4. 配合察元AI Office 完成公文写作全流程

信创环境一套完整的 AI 桌面与办公方案。

提醒：暂不支持龙芯平台。

## 合规与边界

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

行业落地最容易翻车的不是技术，是把边界讲清楚。

## 安全与数据边界

安全口径单独立一层：代理只监听本机回环，跨机访问需要另行打通；进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案，数据文件不受影响；三条路都不满足就只能清数据重装，务必提前生成恢复密钥。
