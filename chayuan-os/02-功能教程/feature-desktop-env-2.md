# 桌面环境为什么这样工作：给政企用户完整的桌面迁移体验

桌面环境这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决给政企用户完整的桌面迁移体验。

## 概念先对齐

桌面环境在察元AI OS里的形态一句话说清：顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达（废纸篓与快捷方式）、桌面小组件、通知中心、深浅色主题、42 张内置壁纸库（本地高清加在线流式）与动态 WebGL 壁纸、中英文界面；所有窗口是桌面内虚拟窗，可拖拽、最大化、停靠四边。

概念一分钟，操作十分钟，这篇都覆盖。

## 这些坑和边界要知道

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 高频疑问

### 桌面环境要联网吗

首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑，断网时联网搜索自然不可用。以官网 aidooo.com 当前页面为准。

### 桌面环境数据存在哪

装了什么、开了什么，需要一个总账页面，离线环境靠导出导入搬迁；壁纸是最直接的个性化出口，动态壁纸让桌面活起来；桌面右键编辑小组件：时钟、天气、照片、日历及玻璃系列、网页挂件。以官网 aidooo.com 当前页面为准。

## 更多操作细节

窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏
