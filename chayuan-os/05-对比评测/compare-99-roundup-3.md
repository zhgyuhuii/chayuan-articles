# 察元OS全部对比议题总览：怎么按场景选

选型前先看全景。察元AI OS相关的常见对比议题有 8 组，本文把它们汇总成一张决策地图：每个议题一句话结论，再链接到各自的深度对比。

## 决策地图

- **AI 桌面系统 vs 普通 AI 聊天软件**：只聊天装聊天软件；要智能体+本地模型+系统联动，选 AI 桌面系统
- **本地模型 vs 云端模型日常使用**：日常+敏感本地跑，攻坚任务切云端，本系统支持一键切换
- **四家 CLI 智能体怎么选**：都装上同题对比，按任务留用顺手的；管理成本已被系统抹平
- **技能商店 vs 手动管理技能**：个人装技能用商店；团队统一下发用离线包
- **本地知识库 vs 云端知识库服务**：敏感资料本地库；公开协作场景云端服务也可
- **Docker 服务器形态 vs 桌面安装**：个人桌面版；团队/服务器资源复用上 Docker
- **免费使用与购买的关系**：先免费用满 90 天，觉得值再购；购 OS 送 Office 免激活
- **系统级 MCP vs 普通单应用 MCP**：要让智能体操作整台电脑，选系统级 MCP；单一应用自动化用应用自带即可

## 统一的选择原则

- 数据敏感度优先：涉密与商业敏感场景一律本地/离线方案
- 任务频率其次：高频任务值得为体验付费，低频任务免费额度即可
- 能力边界第三：工具擅长的交给工具，责任节点留给人

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。

### 和察元AI文档助手什么关系？

同家族：文档助手装在 WPS 里做校对编审；OS 是完整桌面系统，两者可通过 MCP/技能协作。

### 免费吗？怎么收费？

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。
