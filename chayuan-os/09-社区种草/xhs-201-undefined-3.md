# ⭐开发者的一站式工作站，一篇给你说透

四家 CLI 并行、配置集中管理。这条组合工作流的思路分享，建议先收藏再看📌

✅ **工作流拆解**

1️⃣ 四家 CLI 智能体：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随…
2️⃣ 智能体管理：安装/更新/供应商档案一键切换（cc-Switch 式）、连通性测试、配置备份还原。…
3️⃣ 终端与文件管理：zsh 持久会话终端、我的电脑文件管理器，以及文本编辑、Monaco 代码编辑、Markdown 预览、PDF 预览、图片查看、媒体播放器等内置应用全家桶。…

🔍 **衔接要点**

· 无模型偏好时自动指向本地模型，不配 Key 也能跑
· 配置备份还原适合重装与多机同步
· 终端会话持久，重开不丢历史

💡 **适合谁 / 先别冲**

✅ 适合：学生
❌ 先别冲：云厂商模型调用需自备 Key，免费额度视厂商政策

📌 **更多它擅长的事**

· **壁纸库与主题**：205 张 HD 壁纸库（含明暗与主题元数据）+ 动态壁纸/视频壁纸设置，深浅主题切换、界面缩放 85%-130%。
· **webwindows 智能体开窗**：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。
· **插件页签（三源）**：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。

🛠️ **断网也能用？这点很关键**

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

⚠️ **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

🎯 **免费还是要花钱**

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。

📝 **说点大实话（缺点）**

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
· 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
· 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

🧩 **延伸了解**

察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

❓ **常见疑问快答**

问：能多人共用一台设备吗？
答：能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

问：升级会丢数据吗？
答：不会。覆盖安装/自动更新保留数据目录；升级前备份 dsh-home 更稳妥。
