# 学生学习AI清单式指南：学生场景全拆解

如果你是学生，下面这些场景大概率不陌生：没有预算买云端 API。零 API 成本的学习工作站。这篇清单式指南以察元OS为工具，把这个岗位的学生学习AI工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 没有预算买云端 API
- 资料检索与笔记分散
- 写论文需要参考管理

## 用察元OS怎么解：工作流拆解

1. 本地模型零成本对话
2. 知识库导入课件论文资料
3. 导出笔记与引用

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「本地模型零成本对话」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。零 API 成本的学习工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 常见问题
### 能多人共用一台设备吗？

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

### 内存小能跑吗？

8GB 内存可用：建议一次加载一个对话模型+一个嵌入模型；系统有总内存 45% 的预算硬底线防卡死。

### 手机能用吗？

手机浏览器通过云通道 /m/ 入口远程查看与协助；另有 Capacitor 安卓壳方案。
