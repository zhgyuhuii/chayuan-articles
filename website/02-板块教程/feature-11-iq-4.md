# 模型智力榜避坑指南：从入口到完成的完整流程

模型智力榜是察元AI 能力广场里使用频率很高的一项能力。它的「模型智力榜」这样工作：五维模型评测榜：推理/编码/数学/通用/Agent 五个维度聚合展示，帮助按任务选模型。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

五维模型评测榜：推理/编码/数学/通用/Agent 五个维度聚合展示，帮助按任务选模型。

从任务视角看，它对应的关键词是「模型智力榜」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 /rank/iq
2. 按维度排序
3. 结合免费榜与价格页决策

## 适用场景

- 选编码模型、选推理模型

## 进阶技巧

- 按任务看对应维度而非总分

## 注意事项与边界

- 分数来自公开评测源聚合
- 投稿有人工审核门槛，重复或低活跃项目会被拒

## 常见问题
### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### 怎么订阅模型活动？

活动板块支持 RSS 订阅，聚合 31 家厂商源的促销与发布动态。
