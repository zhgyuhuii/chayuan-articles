# 银河麒麟安装：麒麟 V10 多架构选包要点

银河麒麟安装的第一道坎不是装，是选包：V10 底下既有 x64 机型也有 arm64 机型，包选错了后面全白搭。这篇把选包、安装、验证一条龙讲完，环境是察元AI OS。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：麒麟 V10 多架构选包要点。

deb 安装包从官方渠道获取，内网机器先经介质摆渡再装。

## 一步步来

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

第 2 步的 dpkg 是 deb 的标准装法，麒麟与 UOS 通用；第 4 步不是可选项——信创环境的机器多半连不了外网，装完第一件事就是确认本地模型能跑，本地链路一通，这台机器在日常使用里就不依赖公网。

## 其他平台装法速览

macOS：取 dmg 安装镜像打开，把察元AI OS 拖入应用程序文件夹；启动后创建账户进入桌面。

Windows：对应架构的 exe 安装器双击即装，无额外依赖，首启建好本机账户就进桌面。

## 国产平台要点

兆芯、海光这类 x64 机型拿 x64 包，飞腾、鲲鹏这类 arm64 机型拿 arm64 包；统信 UOS 20 走 deb 形态，arm64 真机已实测。选包前用 uname -m 核对架构再动手。麒麟 V10 是一套系统名，底下跑的 CPU 却分属两个阵营，采购单上写的都是「麒麟 V10」，拿到实机别靠猜，一条 uname -m 就出结论。

## 装机前的台账准备

信创装机讲究留痕。动手前建一张简表：机器编号、CPU 型号、uname -m 输出、所选安装包文件名、装机日期。这张表在两处发挥作用：一是后续批量升级时按架构分发安装包不会发错；二是某台机器出问题时，能立刻查到它当初装的是哪个包、哪天装的。

## 装完后的第一件事

装完先干两件事：一是让模型设置向导跑完，把默认模型应用到各家智能体；二是试一次断网对话，确认本地模型链路通了。恢复密钥也顺手生成，忘了密码时它是仅有的自助路径。这两件事都在装机当天做完，拖到有人开始用机器再补，就要打乱别人的工作了。

## 如何确认操作生效

- 桌面能进、对话应用选本地模型能对话，这两点成立才算装成
- 初始化耗时在 5 到 30 秒之间都属正常，交给系统自己走完

这半分钟里别反复点启动图标，耐心等它自己走完；初始化完再动其他设置，观察起来也更准。麒麟机器上把这套顺序走顺了，后续同类机型的复制就省心。

## 注意事项与真实边界

几条边界先说明白，免得装机后落空：

- 8GB 内存的设备一次只载一个对话模型，别让复杂任务同时压上来
- Docker 云桌面与跨终端互联属于进阶形态，动手门槛摆在那里
- 云端厂商模型的调用前提：API Key 由使用方自行准备
- 龙芯平台暂未适配；视频生成不走本地，统一交云端路由

## 信创环境里的密码找回三条路

本地优先的系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道：忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网，由本地 AI 出题验证。信创内网机器往往没有外网出口，找回机制是否依赖云端服务是选型时的关键问法——这套系统的三条找回路径全部落在本地，断网环境照样走得通。

## 多人共用一台麒麟机的口径

政企场景的麒麟机器常是一机多人。这种用法下数据隔离是底线，管理员统一管账号比各自为战安全：每个使用者有独立账户与独立空间，离职交接时收账户即可，不必整机清空重装。装机时就把管理员账户与使用账户分开建，日常操作走普通账户，管理动作才切管理员，审计日志里也分得清是谁做的。

## 麒麟机器的升级与补装

升级和首次安装是同一个动作：拿到新版 deb，sudo dpkg -i 覆盖安装，数据目录不受影响。插件与权重的补装同理，文件经介质摆渡进来后离线完成。信创环境最忌讳不可控的在线自动更新，升级时机由管理员自己定，把变更窗口安排在业务低谷，出问题也只在最小范围内影响使用。

## 遥测与审计的默认姿态

涉密与半涉密环境装机，先看遥测：隐私敏感环境先关遥测再干活，处置设备前清数据。敏感操作全部写审计日志 audit.jsonl，可回放检查，事后追责有据可查。本机 MCP HTTP 服务在回环上免 token，不给外部留调用面。这几条对着麒麟机器的等保检查项一条条过，验收材料里也能直接引用。

## deb 包文件名的读法

ChaAIOS-版本-架构.deb 的命名本身就是核对工具：中间一段是版本号，末尾一段是架构。摆渡安装包进内网时，按台账里记的架构字段核对文件名末尾，末尾对得上再装。版本号一段也别略过——升级窗口装错旧包，是信创运维里最常见的返工原因之一。
