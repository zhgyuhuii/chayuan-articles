# 能力广场助手目录使用指南（AI助手目录）

AI助手目录是察元AI 能力广场里使用频率很高的一项能力。它的「助手目录」这样工作：4526 个内置助手、228 个领域的在线目录：与察元AI文档助手/Office 同源，先在网页端浏览再装到工具里用。这篇实操教程从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

4526 个内置助手、228 个领域的在线目录：与察元AI文档助手/Office 同源，先在网页端浏览再装到工具里用。

从任务视角看，它对应的关键词是「AI助手目录」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 /assistants
2. 按领域浏览
3. 找到需要的助手记住名称
4. 在客户端同领域使用

## 适用场景

- 预览助手生态
- 按岗位找助手

## 实用技巧

- 228 领域覆盖绝大多数文职岗位

## 注意事项与边界

- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 下载产品从哪个入口？

产品页（/products）集中提供察元AI OS、察元AI Office、察元AI文档助手等的版本说明与各平台安装包入口。

### 察元AI 能力广场是什么网站？

aidooo.com 是智能体门户与人工智能资源网站：一站检索 2.5 万+ Harness 插件、Skills 技能、MCP 服务器、提示词、智能体应用、大模型与厂商资讯，并提供察元产品家族下载；只收录信息与安装命令，不存二进制文件。
