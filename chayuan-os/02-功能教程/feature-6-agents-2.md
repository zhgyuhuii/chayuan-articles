# 一文读懂四家 CLI 智能体｜新手入门

CLI智能体是察元AI OS里使用频率很高的一项能力。它的「四家 CLI 智能体」这样工作：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。

从任务视角看，它对应的关键词是「CLI智能体」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 打开任一智能体应用
2. 绑定工作区目录
3. 在 pty 终端里对话干活，多标签并行

## 适用场景

- 开发者日常编码
- 多智能体对比测试

## 进阶技巧

- 无模型偏好时自动指向本地模型，不配 Key 也能跑

## 注意事项与边界

- 四家 CLI 二进制约 1.3GB，注意磁盘空间
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 开源吗？

仓库协议 AGPL-3.0，策略为「开源核心+企业版」方向；当前以免费可用的发布包为主。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。
