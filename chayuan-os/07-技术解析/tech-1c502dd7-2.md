# 察元OS架构课｜Docker 网页桌面与云通道（细节版）

这是「察元OS技术解析」系列的一篇。Docker 网页桌面与云通道是理解这款产品设计哲学的关键切面——看完你会明白它为什么这样设计、这样设计换来了什么、代价是什么。

## 一句话结论

docker compose up -d 即可在浏览器（52584）得到完整网页桌面；云通道 relay（可自建）提供设备路由、在线终端与远程分享，手机浏览器 /m/ 入口即远程 viewer——「工作站跑在服务器、交互发生在任何屏幕」。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 常见问题
### 和察元AI Office 什么关系？

Office 以内置插件形态运行在察元AI OS 中；购买 OS 授权后同机 Office 自动免激活。

### 能接入云端大模型吗？

能。内置 89 家厂商目录（DeepSeek、OpenAI、Anthropic、Gemini、OpenRouter 等，含免费额度标记），填 Key 即用；本地与云端一键切换。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。
