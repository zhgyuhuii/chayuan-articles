# AI下象棋给长辈看：家庭客厅的新节目

长假回家，你会发现长辈的娱乐清单比你想的还要短：电视翻来覆去那几个频道，短视频刷多了眼也花，想找个人下盘象棋，老棋友又未必随叫随到。这时候笔记本往客厅茶几上一放，让两个大模型当面下象棋，AI 在旁边讲棋——AI下象棋给长辈看，听着新鲜，接受度却出奇地好：长辈看得懂象棋，就看得了这场对弈。

## 这件事原来的难处

想让长辈接触点新东西，卡点从来不在长辈这边，在你这边。

长辈不会配 AI。让他们注册账号、申请 API Key、填参数，比教他们用智能手机还难，多半试一次就放弃。所以配置的活必须你来干，而且干一次之后不能再有第二道坎。

普通棋类软件不对味。人机软件里电脑秒出招，噼里啪啦下完一局，长辈连棋都没看清；而且没有讲棋的人，为什么这么走、亏在哪，没人说，看着枯燥。

电视上下棋节目倒是有人讲，但播什么看什么，没有参与感。长辈真正喜欢的是那种慢悠悠、有说有讲、还能搭话的氛围，这恰恰是大多数产品没考虑的。

更深一层的难处是陪伴的缺口。长辈缺的往往不是节目，是有人陪着一起看、一起说。大多数科技产品给长辈的是工具，没人陪就吃灰；能变成一家人共同话题的东西，才真正留得住。

## 用察元竞技场怎么做

准备工作由你一次性做完。在这台客厅用的电脑上装好察元竞技场，进设置 ＞ 模型配置，从 85 家厂商目录里点选一家，填上你的 API Key，点「测试连接」确认能用；顺手点「获取模型」把可用模型全列表拉下来，挑两个棋风稳健的模型入库。这一步做完，以后就不用再碰了。

日常观看只有两个动作。打开应用，进大厅选中国象棋（楚河汉界完整规则），开局模式选机机观战，点选两个模型开打。从打开应用到看见第一手棋，也就是点几下的功夫，长辈自己学一遍也会了。

画面上的关键开关是 AI 实时解说。打开之后，每一手棋旁边都有大白话讲解：这一步为什么要拱卒、那一步卧槽马威胁在哪。对长辈来说，这个解说就是坐在旁边的棋友，把机器的对弈讲成人话。一局打完还有赛后解说，整局的得失用几分钟复盘一遍，相当于免费听了一堂讲棋课。

选中国象棋当主场玩法还有层情感账：楚河汉界长辈熟，规则不用教，解说里蹦出来的「当头炮」「马后炮」都是他们年轻时听过的词，亲切感是别的玩法给不了的。

设备上也不用讲究。一台普通笔记本就行，接不接电视随你；解说以文字滚动为主，长辈眼神好直接看字，眼神差的你念给他们听——念解说这活，本来就是陪着看的一部分。

节奏是天然的慢。模型思考要走几秒到十几秒，遇到复杂局面还会长考，这个速度对年轻人嫌磨叽，对长辈刚刚好——正好抿口茶、评论一句「这步走得稳」，跟老伴唠两句，棋局自己往下走。你想添点互动，就利用默认的匿名观战：座位上只显示玩家A、玩家B，让长辈猜哪边是哪家模型，终局揭晓对上答案，小分数记下来，一下午就有得玩了。

想让他们也摸摸棋子，就开人机局：长辈执红棋走，走崩了把控制权交给 AI 接手续几手，缓过来再人工接管，下一手生效，输赢都不会太难看。

一晚上的节目单也好排。先来一局象棋热场，解说全程开着；中段插一局麻将或斗地主换换口味，四川血战、广东推倒胡都在玩法清单里；收尾放赛后解说当今日复盘，再让长辈猜一轮座位身份。节奏跟着茶水零食走，不必赶进度。

## 适合谁、不适合谁

适合：家里有象棋底子的长辈、想找祖孙两代共同话题的人、周末与长假的家庭聚会。这套玩法的前提是家里有台电脑或能接大屏的设备，你提前花二十分钟配好。再补一句实话：讲棋的水平取决于你配的模型档位，便宜的小模型解说也打折扣，配置时多试两家再定。

不适合：完全不懂象棋的长辈——解说得再白，也得认识车马炮才有乐趣；以及指望它替代棋类教学的人，模型棋力有上限，下不过专用象棋引擎是正常现象，图的是过程热闹，不是观赏国手对局。

## 常见疑问

### 长辈自己能操作吗

配置完成后能。日常就是打开应用、选玩法、点机机观战三步，不碰命令行、不填参数。第一次配置由家里年轻人做完即可。

### 一直开着看要花多少钱

软件本身 MIT 开源免费；用云端模型对弈消耗你的 API 额度，一下午的量通常不大，但挂机越久花得越多，心里要有数。预算敏感就接 Ollama 本地模型，零成本断网可玩，代价是本地小模型棋力与解说水平都打个折扣。

### 解说会不会讲错

有可能。解说由模型生成，偶尔会说岔或者事后诸葛，长辈较真的话你就笑着圆过去，别把它当权威讲棋。真要论规则，胜负是对局引擎按规则判的，解说只是锦上添花，说错了也不影响棋局。图个乐子与氛围，是这个场景的正确打开方式。

### 能不能在电视上看

可以想办法。应用是普通桌面窗口，电脑接电视或者系统投屏都行，画面按全屏给。具体投屏方式取决于你的设备，应用本身没有特殊的电视适配要求。字太小就把系统缩放调大一档，长辈看得舒服比画面精致更重要。

### 除了象棋还有什么可看

麻将、斗地主、军棋都在 11 款玩法清单里，长辈要是会打四川血战，看模型打麻将可能比象棋还热闹；军棋翻翻棋节奏快、运气成分足，悬念感对不熟规则的人也友好。日麻立直是大厅隐藏入口，懂行的长辈会心一笑。第一次配置时不妨几个玩法都试一局，看长辈对哪样上头，就定哪个当主场。

客厅里最难得的不是节目多精彩，是一家人终于对着同一块屏幕有说有笑。两个模型慢慢下棋，AI 在旁边讲棋，长辈在旁边评棋，你负责续茶。这个晚上花不了几个钱，却可能成为假期里被提起很多次的记忆。
