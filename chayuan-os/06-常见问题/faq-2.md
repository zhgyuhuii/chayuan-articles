# 察元OS配置要求高频问答：这些疑问一次说清

## 察元OS配置要求：结论先行

围绕硬件与平台，这些是问得最多的问题。每个回答先给结论再给动作，基于察元AI OS（版本 3.1.15，aidooo.com）整理。文末附预防清单，多数问题的根子都在那三条里。

### 最低内存要求

模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），支持断点续传，下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

要点：断点续传与多路换源，Qwen3-8B/14B、小内存档 LFM2.5、图像理解 MiniCPM-V 等档位在线下载；内存预算分层推荐。

边界：8GB 内存建议一次只加载一个对话模型

### 局域网地址怎么用？

「局域网」行的地址已内嵌 token，直接点「复制」发给外部设备配置即可；回环的「本机」地址免 token。端口固定 52583（统一端口注册表，一号一口写死）。

### 智能体方式支持哪些智能体？别的家行吗？

当前仅 Codex / Claude Code / OpenCode 三家支持无人值守执行（表单下拉也只列这三家）。选了不支持的类型任务会直接失败并留报告。

### 网页/Docker 形态里建不了本地类应用？

「可执行文件路径」「HTML 文件」「文件」字段的「浏览…」在无桌面桥时提示「选择本地文件仅桌面版可用」，可以手填完全路径保存；但单机应用的启动、未知类型文件交给系统打开这些动作仅桌面版可用。

## 背景速览

察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。提前知道的边界：8GB 内存设备建议一次只加载一个对话模型，复杂任务受限。

## 预防清单

这类问题的共同根源通常有三条：入口不熟、前置没做、边界不清。对应的动作：

- 用任何功能前先找到官方入口，不从二三手教程猜路径
- 模型、权限、依赖这些前置条件先检查一遍再动手
- 边界条款（大小上限、付费范围、平台差异）提前读一遍

## 边界速览

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key

## 数字口径

- 17 家外部 CLI 智能体（Claude Code、Codex、OpenCode、OpenClaw、ZCode、Gemini CLI、Qwen Code、Kimi Code、Cursor CLI、Copilot CLI、Droid、Amp、Grok Build、CodeBuddy、Crush、Aider、Goose）加内置 DeepSeek Harness
- 模型配置可一键写入五家（Harness/Claude Code/Codex/OpenCode/OpenClaw），MCP 配置自动传播 13 家
- 66 家内置云端厂商目录加自定义 OpenAI 兼容厂商
- 86 个 MCP 工具（2026 年 10 月实测）

## 统一模型代理的用法

全部模型走一个本机回环地址（127.0.0.1:52581）对外服务：OpenAI chat、responses 与 Anthropic messages 协议互转，对话、嵌入、重排、语音端点齐备。智能体和其他软件只需指向这一个地址，本地模型没运行会自动拉起，厂商请求自动转发云端。

## 远程访问的形态

WebRTC 局域网共享桌面分主机、编辑者、观看者三级角色；公网远程走出站云中继（支持自建），还能生成限时云链接把对话页分享给外部设备，停止即失效。手机浏览器可直接镜像桌面，另有安卓壳应用。

## 常驻任务的排程细节

按每 N 分钟或每天定点执行，可选模型直跑或调度无头智能体，每次运行产出 markdown 报告落盘归档，历史可查可重跑。配合预授权窗口，夜间时段自动放行指定工具，早上来收报告即可。

## 跨终端互联的安全设计

同一网段的多台终端经 RTPS 多播互相发现，配对后按类别授权（模型加知识库、智能体执行）。远端调用以远端访客身份通过对端权限门并留审计；出厂默认零共享，开哪类授权完全由用户决定。

## 模型服务的实际构成

装机自带的五件套覆盖完整离线链路：Qwen3-4B 负责对话、BGE-M3 做嵌入、BGE 重排提升检索精度、whisper-small 跑语音识别、piper 做中文语音合成。模型中心里还能在线补更强档位（Qwen3-8B/14B、小内存档 LFM2.5、图像理解的 MiniCPM-V 等），下载源多路自动换。内存仪表实时显示每个模型的占用，空闲 15 分钟自动卸载，常用模型可钉住常驻。

## 知识库的检索机制

导入 docx、xlsx、pdf、csv、html 与扫描件（本地 OCR）后，检索走向量加全文的混合链路，可选本地重排精排；问答以流式输出并带编号引用，点开脚注能看到出处片段与源文件。另配知识图谱页签，把文档实体与跨文档关系画成二部图。全部索引与原文留在本机。

## 灵宠与任务灵宠

每个智能体可以化身桌面灵宠：在壁纸上活动，动作与体型反映记忆负载，头顶流式气泡，双击直开工作台。绑定常驻任务的任务灵宠会在执行期上桌直播输出，结束时气泡显示成败摘要——定时任务从日志文件变成看得见的桌面直播。

## 云桌面形态

整套系统可无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用，账户隔离，数据在服务器侧统一管理。默认只监听回环端口，暴露面完全自己控制，适合团队统一供给算力与知识库。
