# 智力榜的五维评测口径（原理解析）

这是「能力广场技术解析」系列的一篇。智力榜的五维评测口径是理解这款产品设计哲学的关键切面——看完你会明白它为什么这样设计、这样设计换来了什么、代价是什么。

## 一句话结论

模型智力榜按推理/编码/数学/通用/Agent 五维组织公开评测源的聚合数据：总分意义有限、维度才有决策价值——选编码模型看编码维、选 Agent 底座看 Agent 维。分数透明标注来源，鼓励用户决赛圈实测。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。
