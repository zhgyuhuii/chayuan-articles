# 思维链气泡实现：流式输出与思考块剥离

看模型对弈的乐趣，一半在棋盘上，一半在它的自言自语里。对局室里的思维链气泡实时流式滚动，模型盘算这步棋的完整过程在你眼前逐句长出来，旁边还挂着每手延迟与 token 用量。让这件事稳定跑起来，背后是三个工程问题：流怎么送到界面，思考块怎么从答案里剥出去，答案段又怎么在长输出里被定位。这篇把思维链气泡实现的流式管道、思考块剥离与答案段定位拆开讲。

## 流式管道：从厂商端点到气泡

模型不是答完才回话的，流式输出让它边生成边推送增量片段。对局室要的正是这个：一手的等待动辄数十秒，等整段输出齐了再展示，气泡就失去了「看它想」的直播感，只剩回放感。

管道沿途每一站都有活干。请求从引擎层经主进程网关发往厂商端点，回程的流式事件逐段翻回应用内部的统一格式——接 Anthropic 原生协议的 Claude 时这一步尤其要紧，原生协议的事件形状与 OpenAI 兼容格式对不上号，翻译保住了事件流的时序与分段，气泡在 Claude 身上才照样逐句滚动。事件进到界面层，对局室把它画成气泡；同一路数据里还捎带着计时的起点与 token 计数，每手延迟与用量两个数字就是从这条流上记下来的。

一次请求，两份价值：界面拿它做直播，解析拿它做原料。这个「同流分用」是整套实现的轴心，后面两个机制都长在它上面。

断流的处置也归这条管道管：厂商中途掐断连接、流式事件缺了尾巴，管道把已经收到的部分交给解析链照常处置——剥块、清洗、回捞各走各的，救得回来就出招，救不回来再走重试与兜底。流断了，对局的处理流程不断。

## 思考块剥离：展示与解析分道

麻烦从模型那边来。推理型模型常把思维链直接拼进正文，包在 think 块里，答案混在几百字的自我辩论后面。同一份文本，对展示是宝贝，对解析是杂质：解析链要从里面抠出一步合法招法，先撞上的却是满屏推理。

处理办法是分道。展示侧照单全收，think 块的内容正是气泡的主角；解析侧先剥离——把思维链块整体摘掉，只留答案部分，再进入后续的清洗工序。剥离只发生在解析路径上，你看得到的照样看得到，模型一点不亏。这道工序在解析容错链里排在头一档：先剥思维链，再剥代码围栏、抽大括号，一路往下。

剥离是文本操作就有误伤的可能：极端情况下正文里混进与标签同形的字样，边界怎么切属于实现细节，以仓库为准。原则倒是不变的：宁可解析失败走兜底，也不让思考文本混进动作判定。

## 答案段定位：让解析不等流结束

流式带来一个时间差问题：输出还在滚动，解析要不要等？全等，出招节奏被拖慢；不等，拿半截文本解析又容易错。竞技场的解法是给答案段定位：强模型支持两段思考，「分析：」放开推演，「答案：{json}」收束落子，流式输出里一出现答案段标记，解析就在那一段上先行启动——模型的分析还在气泡里滚动，落子判定已经在排队。

段结构越明确，定位越稳。深度思考档的三段输出更进一步：分析段推演三条候选着法线，其中至少一条吃子线、一条防守线；结论段一句话定板；答案段交 JSON。对解析器来说，三段就是三个路标，答案段的边界清楚，先行解析的启动点就准。

答案段定位与思考块剥离是一对配合：剥离保证解析器拿到的是干净文本，定位保证它拿得早。两个机制合起来，出招等待里「模型思考」的那一大截，被压缩出了重叠空间。

## 设计取舍

为什么展示与解析共用同一路流，而不是各发各的请求？再发一路等于双倍费用双倍延迟，而且两边的需求本来就该同源——观众看到的思考与裁判收到的答案，理应是同一次思考的两个投影，分开反而不诚实。

为什么先剥 think 块再走清洗，而不是让清洗各级自己兼容思考文本？链路的每一级都该有单一职责：剥离管「去掉什么」，清洗管「修复什么」。混在一起，每一级都要重复处理思考文本，出错面翻倍。

为什么把思考块当内容而不是垃圾？观赏性是这款产品的招牌之一，模型的自我辩论本身就是看点。同一份思维链，解析侧嫌弃，展示侧当宝，一份文本两种态度，各取所需。

## 边界

三条实话。气泡的饱满程度取决于厂商：有的推理模型把思考放在独立通道，正文里未必有可供剥离与展示的块，这类模型的气泡就瘪一些——可看性受制于厂商是否吐思考，产品侧无解。深度思考档的输出长，流式时间与 token 费用同步上涨，一晚锦标赛全开深度档，账单与时长都要有数。剥离与定位都是文本启发式，遇到极端格式（嵌套标签、答案段标记被模型写歪）可能失手，失手之后由容错链与兜底接住，对局不断，但那一手的解析质量打折。

### 思维链气泡实现会拖慢出招吗

流式本身不拖慢出招，反而帮忙：答案段定位让解析先行启动，不必等整条输出流完。气泡展示与解析共用同一路流，没有额外请求开销。

### 思考块剥离会不会误删正文

剥离按块边界操作，正常格式下不会动到答案部分。极端畸形输出存在误伤可能，代价由容错链兜住：解析失败还有回捞与重试，对局不中断。

### 看不到思维链是不是模型接错了

多半是厂商没吐思考。有的推理模型不把思维链放进正文，气泡自然瘪；出招照常工作，只是可看性打折。换一家愿意回传思考的模型，直播感就回来了。

### 深度思考档的气泡为什么那么长

因为协议要求的三段输出本身就长：分析段要推演三条候选线，结论与答案各占一段。长度是设计出来的，不是故障；它换的是推理骨架的清晰可读。

思维链气泡实现把一件消费品拆到了物理层：模型的思考是流，流上有杂质，杂质里有答案。展示接住流，剥离滤掉杂，定位抢出时间——三道工序各干各的，你在对局室里看到的每一句自言自语，背后都是这条管道的分工。
