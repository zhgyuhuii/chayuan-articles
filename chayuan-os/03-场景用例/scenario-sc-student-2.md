# 科研AI工具：AI 桌面操作系统

科研AI工具这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决科研AI工具。

## 概念先对齐

科研AI工具是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，科研AI工具是其中面向这类需求的一环。

入口、步骤、验证三段看清，这事就顺了。

## 科研AI工具：从入口到完成

从这几步开始：（第 2 个切入角度）

1. 本地模型零边际成本对话
2. 知识库导入课件论文做引用式问答
3. 知识图谱梳理论文实体关系
4. 导出笔记与引用
5. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）
6. 串联场景：应用商店一键安装 17 家 CLI 智能体

## 它的局限也要说清楚

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 高频疑问

### 科研AI工具要联网吗

命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力；让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可。以官网 aidooo.com 当前页面为准。

### 科研AI工具数据存在哪

文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，让特定文件类型默认交给智能体处理，双击即用 AI。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把科研AI工具放回察元AI OS的整体盘面：WebRTC 局域网共享桌面：主机、编辑者、观看者三级角色，共享房间与连接终端状态；换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂；设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力；本机轻薄、远端肥厚时，桌面只当壳。

## 安全与数据边界

安全口径单独立一层：问 AI 直答卡，四本日历把生活与工作分开记，AI 能读会写；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑，文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；让特定文件类型默认交给智能体处理，双击即用 AI。

## 平台与形态

平台与形态的账：灵宠把后台跑着的 AI 变成桌面上看得见的小生物；AI 纪要一键生成，右栏检索测试台就是 kb_search 工具的所见即所得：向量加全文加可选重排的混合检索，三个 KB 工具自然语言触发。

## 价格与授权

价格口径一并交代：忘记密码时本地 AI 面试官出题；恢复密钥丢了、管理员也找不到，AI 面试是第三条路，而且全程本地不出网；本地 AI 出题验证；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。

## 产品家族与搭配

察元AI OS不是单打独斗：联网环境下内置 web_search 工具默认走 DeepSeek 搜索，Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层；Dock 直开内置的察元AI Office：文档、表格、演示在线编辑；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用。

## 几条硬数字

能落到数字上的几条：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，云端厂商模型调用需自备 API Key，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，再选默认对话模型。

## 离线与内网

离线内网这条线的口径：任何网页或本机程序都能变成桌面应用，常用工具一键直达；右键是桌面操作的集大成入口，用智能体打开把文件直接交给 AI 处理；Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入；键盘党的启动器：一个快捷键管启动、找文件、直接问 AI 三件事。
