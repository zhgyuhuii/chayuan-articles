# 围棋复盘教程：形势曲线里的攻杀转折

围棋的复盘传统比围棋本身还讲究：高手复盘能摆到深夜，一手一手还原当时的心思。普通人没这个工夫，看大模型对弈更没必要手工摆谱——围棋复盘在察元竞技场里是自动的：形势曲线画好走势，问叹号标注圈出关键手，棋谱随手导出。这篇带你把小盘围棋的复盘链路走一遍，专攻大杀局里的转折点。

## 复盘链路各管一段

工具就几件，各有分工。形势曲线：自动画好的局势走向图，攻杀得手与失手在曲线上动静最大。问叹号标注：妙手挂问叹号（？！），失误挂叹号（！），逐手都有记号可查。回放：逐手推进还原现场，每手带着模型 comment 与思维链气泡。棋谱导出：JSON 格式带走，自建分析随你。四件套串成一句话：曲线指段落、标注点那一手、回放还原过程、导出留档。这套链路对棋类与牌类通用，但围棋的曲线跳变最凶——死活一决，曲线当场改道，观感冲击力拉满。

## 动手前要备好什么

一局打完的围棋对局即可，9 路、13 路都行，人机局与机机观战的产出都能复盘。装好察元竞技场（版本 0.1.0），从记录页找到这局、走回放入口。复盘功能不另外收费，软件 MIT 开源免费；打局消耗的模型 API 费用照常自理，接 Ollama 本地模型零成本。选局同样有讲究：想练转折定位，选手数适中、曲线大起大落的局；想攒案例库，把不同模型的攻杀局分开存档、标明来源，日后好检索。

## 完整步骤：从大杀局到转折点

第一步，找出大杀局。小盘围棋攻杀密集，打开形势曲线，挑波动最剧烈的段落——提子频发的攻杀局都在那里，转折点十有八九藏在其中。小盘的优势在这里显出来：手数短，曲线的剧烈段好找，不像长局那样转折散落全场，几分钟就能锁定候选段落。

第二步，定位攻杀转折。提子发生的时刻曲线跳动明显：被提一方若曲线应声塌下去，这里就是转折；若曲线只是抖一下又回来，说明那块棋丢了不致命。判断转折点的要领是看曲线塌下去之后回不回得来。提子规模也影响判断：提两三子的小摩擦，曲线抖一下就回来；提一条大龙的瞬间，曲线直接改道。按塌陷幅度给转折分级，复盘时先看大的。

第三步，逐手标注对照。转折点附近的标注最值得细读：做杀得手的那手常挂问叹号，该补不补的那手常挂叹号。把标注与思维链气泡对读——模型当时算到了什么、漏了什么，一目了然。读标注时留个心眼：同一手在不同模型嘴里意义不同，一方眼中的妙手，可能正是另一方看漏的铁证，标注配着双方的气泡读，才读得出攻防两边的账。

第四步，回放还原全过程。从转折前几手开始放慢速度逐手过：攻方怎么收紧网口，守方怎么长气、怎么弃子，看着看着你就明白败局是从哪一口气开始漏的。

第五步，棋谱导出存档。JSON 带走，攻杀片段单独留存；想反复研究的转折局，攒成自己的小库，比零散记忆可靠。存档时顺手记一行当时最打动你的那手棋，日后翻库，这一行就是现成的索引。

## 三种读法：粗读、精读、对照读

同一局复盘有三种打开方式。粗读，只看形势曲线，五分钟摸清整体走向，哪段激烈哪段平淡，心里有张地图。精读，进回放逐手过标注，专攻转折点前后的手数，把每条记号的来龙去脉搞清。对照读，把思维链气泡与标注并排看：模型说它要攻，标注却给了个失误记号，这种「说一套走一套」的时刻信息量巨大——它是真算错还是嘴硬，多看几处就有判断。三种读法轮着用，同一局棋能榨出三层价值。顺序没有标准答案，赶时间粗读，有兴致精读，存疑处对照读，随局调整，不必每次都用全套。值得反复看的转折局不多，遇到就存档：一遍看胜负，二遍看选择，三遍看气泡里的心思变化，好局不厌百回看。

## 做完后的验证

一句话检验：你能指出这局的攻杀转折发生在第几十手、转折前后双方各走错了什么。说得出，这局棋的价值就被你榨干了；说不出，回到曲线，看塌下去的那一段前后各五手，答案就在那十手里。验证过的转折，记得回曲线再看一眼全貌，局部因果放进全局才站得稳。

## 这些边界要心里有数

曲线是引擎的即时评估快照，不是预言，小盘围棋里一块大龙的死活就能让曲线跳崖，但胜负要等终局才算数，别中途下结论。标注是自动口径，与人类棋评未必一致，保留自己的判断。模型不做深度搜索，死活算漏常见，复盘看懂它的错误即可，不必苛责。导出的 JSON 想变成漂亮的分析图表，得靠你自己的工具链，竞技场负责把数据给全。还有个使用频率上的实话：复盘是慢功夫，别指望一天精读十局，一天吃透一两局的转折，一个月下来就是几十场的攻杀案例库。

## 高频疑问

### 围棋复盘和象棋复盘有什么区别

链路一致：曲线、标注、回放、导出都有；差别在内容，围棋看死活与大龙，象棋看子力与将帅安全，转折的读法各自不同。

### 转折点不止一处怎么办

小盘对局攻杀多，多处转折正常。按曲线塌陷幅度排优先级，塌得最狠的那处先看，其余扫过即可。

### 导出的棋谱能喂给分析工具吗

能，JSON 格式的棋谱就是为带走分析准备的，自己写脚本、接入自建工具都随你，数据在本机。

### 复盘要额外付费吗

不收，复盘链路属于软件本体，MIT 开源免费；模型 API 费用只发生在打对局时，Ollama 本地模型零成本。

### 模型的败着下次还会犯吗

同型局面下的旧错，开局记忆会帮它压住；全新局面的新错，它照样会犯——模型的成长你看得到，但上限也在那里。

### 9 路和 13 路的复盘读法一样吗

链路一样，侧重不同。9 路局数短转折集中，逐手精读不费时；13 路层次多，先用曲线粗读再挑重点段落精读，效率更高。

大杀局是围棋对局里火焰最旺的一段，复盘就是把这段火焰拆成一颗颗火星给你看：哪一秒点着的，哪一手浇灭的，曲线与标注都替你记着。看懂一场攻杀的来龙去脉，比泛泛看十局都有用——这大概就是复盘这件事，古今通用的道理。
