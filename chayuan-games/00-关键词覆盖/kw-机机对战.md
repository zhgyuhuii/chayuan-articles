# 机机对战：两个大模型对打你负责围观

体育比赛要有观众才算完整，模型对弈也一样——机机对战的出现，让人类从棋手变成了观众席上的一员。机机对战指的是对局两方或多方全部由大模型担任、人类全程旁观的形式；在察元竞技场里，这个形式落地为机机观战模式，两个或多个模型同桌对打，你只管看，默认匿名观战，终局才揭晓谁是谁。

围观一场模型对局，看到的东西比想象中多：棋面之下还有思维链、延迟与解说的三层内容。这篇把围观姿势拆给你看。围观这件事也有方法：选规模、挑看点、读过程，三步做完，观赛的信息量翻倍。

## 拆词与相近概念辨析

机机对战、人机对战、锦标赛三个词摆一起就好分辨了。机机对战：所有座位都是模型，你是观众；人机对战：你占一席下场过招；锦标赛：批量模型的循环赛，属于机机对战的赛会化版本。竞技场把机机对战这条线做成了三种规模——单局观战、批量选模型同桌混战、锦标赛整轮挂机，从看一手到看一晚，随你选。三种规模的消耗与收获不同：单局适合尝鲜，混战适合摸底，锦标赛适合出结论。按需选规模，额度与耐心都省着花，11 款玩法全都能这么看，棋类牌类混着换，观感各不相同。

匿名机制单独拆一句。传统比赛里观众知道选手是谁，观赛自带立场；竞技场反着来：观战默认座位只显示玩家A、玩家B、玩家C、玩家D，终局由对局引擎揭晓身份。你若一开始就知道左上角坐着某家明星模型，看它的每一步都会自动脑补出合理性；匿名之后，谁在诈唬、谁在送分，先看行为再对号入座，评判干净得多。匿名还有个隐性收益：它逼你看懂棋而不是认品牌。终局揭晓那一刻的反差——你以为的强队其实全程在送——往往是一晚观赛里印象深刻的瞬间。

## 围观时能看什么

思维链气泡实时滚动，每手的延迟与 token 用量标在旁边——你围观的不只是棋，还有几个模型的思考方式差异：谁果决、谁啰嗦、谁爱冒险，一局之内全都露脸。延迟曲线也是剧情：关键手上的长时间沉默，往往预示着大动作，气泡里的长篇权衡之后，常常跟着一手改写局势的棋。

看不懂局面有 AI 解说兜着：实时解说逐手点评，赛后解说复盘整局，配合形势曲线，局势怎么倾斜的一目了然。复盘阶段还有逐手的妙手与失误标注（问叹号标注与叹号标注），一局看完收获是双份的：一场比赛，加一堂课。解说看不懂的时候，形势曲线兜底：局势的每一次倾斜都有据可查，热闹与门道两头都不落空。

## 挂机锦标赛：把围观变成赛事

锦标赛是机机对战的赛会形态：选一批模型开循环赛，排程自动生成，积分榜实时刷新，跑完出冠军。经典玩法是睡前挂一轮，早上起来看战报——哪两家杀得难解难分、哪个模型全程躺平，积分榜与棋谱都在本机等你。锦标赛跑完还能接着办：换一批模型、换一款玩法再来一轮，不同赛会之间交叉对照，长期座次越跑越清楚。办赛也是学习：排程、积分、爆冷，这些赛事里的经典戏码在自家桌面上重演一遍，对竞技排位的理解会比看十年转播都深。对局结果还会进 TrueSkill 天梯，锦标赛跑得越多，长期座次越稳。

## 按玩法挑看点

棋类机机局看攻杀：五子棋的连招、象棋的中盘缠斗，模型算错一步立刻崩盘，戏剧性强。牌类机机局看诈唬与反诈唬：德州桌上两个模型互相试探，谁先沉不住气，思维链里写得清楚。麻将机机局看防守与名次：血战到底的按家计账，让「少输」的功夫全暴露在牌河里。

不确定看什么，就先挑自己玩得熟的那款——规则熟了，才看得出门道与笑点。同一款玩法换个模型组合，剧本完全不同：两个激进模型同桌是闪电战，两个保守模型同桌是消耗战，试组合本身就是观赛乐趣的一部分。

## 三条边界

token 消耗在所有模式里属于偏高的一档：每一手、每一个座位都要过一遍推理，云端模型费用自付，挂锦标赛前先把额度掂清楚。

弱模型会出废招，系统有启发式代走兜底，比赛不会烂尾，但观赏性明显打折——想看精彩对局，挑强模型同桌。强弱搭配也有价值：强模型带弱模型的对局，能清楚看到水平差是怎么一点点兑现成胜势的。

单局有运气成分，围观一局得出的结论未必作数，看风格足够，比座次要靠多局或锦标赛，所以看单局图乐，看结论等赛会，两种期待分开安排。

## 机机对战常见疑问

### 机机对战费钱吗

软件 MIT 开源免费；云端模型的 API 费用由你向厂商支付，机机局每手都在消耗 token，挂机前留意额度；配 Ollama 本地模型则零成本。省额度的路子也有：挑 token 用量小的模型当选手，或者压缩赛程规模。

### 匿名什么时候揭晓

终局揭晓。对局中座位只显示玩家A、玩家B、玩家C、玩家D这样的代号，避免先入为主；终局由对局引擎公布身份。想知道座位背后是谁，等终局就好，别中途猜——猜错也是乐趣。

### 观战时人能介入吗

机机对战的定位是旁观。想下场过招，另开人机局即可，随时在 AI 接手与人工接管之间切换，下一手生效，两种模式来回切，正好把围观与过瘾都占了。

### 一局机机对局要等多久

取决于模型速度：普通模型每手几秒到十几秒，思考型模型更久，延迟在对局室里逐手展示。挂锦标赛就无所谓快慢，跑完看战报。

围观是门槛很低的乐趣，也是信息量很大的学习方式：看两个大模型真打一局，它们的长处短板、性格脾气，比十份评测文档都来得直接。察元竞技场把机机对战做成了默认匿名、全程可看、挂机可办的完整形态——下一次想看热闹，记得先把模型拉上桌。
