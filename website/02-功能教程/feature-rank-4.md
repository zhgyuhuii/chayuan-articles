# 资源排行：万+ 资源一站检索，别再瞎试

先说这篇能帮你干什么：读完能在察元AI 能力广场里独立完成资源排行，路径是找近期上升最快的 MCP。步骤里的每个「」按钮都是界面原文。

## 先定位问题在哪一层

资源排行的问题一般藏在三层里：前置条件没满足、操作路径走岔、边界条件踩线。先把环境与模型这两件事核一遍，再查路径。

## 正确的操作路径

从这几步开始：（第 4 个切入角度）

1. 热门/新品/趋势三维度
2. 六档周期榜单
3. star 增量优先
4. 降级透明标注
5. 场景验证：找近期上升最快的 MCP
6. 场景验证：季度回顾生态趋势

## 进阶用法与边界

- 热门/新品/趋势三维度
- 六档周期榜单
- star 增量优先
- 降级透明标注

## 常见问题

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

## 更多操作细节

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

## 能力面再摊开一层

- 热门/新品/趋势三维度
- 六档周期榜单
- star 增量优先
- 降级透明标注

## 放回产品盘面看

把资源排行放回察元AI 能力广场的整体盘面：智能体门户：插件、技能、MCP、提示词、大模型资源一站检索与下载；万+ 资源一站检索（站方口径），榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜；导航智能广场分三栏：资源类型装了就用（智能体、MCP、插件、技能、教程库、提示词、技能包）。

## 安全与数据边界

安全口径单独立一层：一个带排行榜的聚合入口能省掉大半检索时间，MCP 板块收录 MCP 服务器资源，失效资源自动剔除出榜，智能体应用板块收录可直接使用的智能体应用形态资源，配合产品使用或独立运行。

## 平台与形态

平台与形态的账：提交作品页把你的插件、技能、MCP 等资源投给广场上架：填名称、主页地址、图标外链与分类说明，桌面产品可从站内下载 Windows/macOS/Linux（含麒麟/UOS）安装包；智能体门户：插件、技能、MCP、提示词、大模型资源一站检索与下载，万+ 资源一站检索（站方口径）。

## 价格与授权

价格口径一并交代：智力榜看能力上限，免费榜看成本下限，两张榜定选型策略；免费榜按输入价门槛专列，购买授权页统一下单（扫码支付）；模型价格与新品节奏变化快，资讯页盯动态不吃亏。
