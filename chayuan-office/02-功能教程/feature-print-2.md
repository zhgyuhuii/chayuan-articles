# 拆开看自动保存：原理、架构与实现细节

关于自动保存，网上说法很多，有说简单的有说复杂的。实际用下来，察元AI Office的打印与自动保存路径是清晰的，只是有些细节不说不知道。这篇按真实操作走一遍，顺带把容易误解的点标出来。

## 它是什么，为谁服务

六个编辑器各有打印链路：Docs/Sheets/Slides 先排版出分页预览再进 Word/Excel 式打印对话框，PDF 有带页范围与份数的打印对话框，Markdown/HTML 直达系统打印。自动保存每 30 秒与窗口失焦时静默落盘（原子写，断电不截断），关闭/退出前对每个未保存文档逐个询问；另有启动恢复上次文档与标签休眠两道保险。

打印别掉链子、断电别丢稿，这是办公软件的两条底线。

下面直接进入正题。

## 原理与设计取舍

打印别掉链子、断电别丢稿，这是办公软件的两条底线。

能力面拆开看：30 秒自动保存；六端打印。

一个常被问到的问题：为什么关闭时有的文档询问、有的直接关了。干净文档（无未保存修改）与已自动保存落盘的文档直接关，不打扰；只有真正有未落盘修改的标签才进逐个询问流程。新文档从未保存过时一定会问。

从提问口径看，用户最关心的是Docs 打印时怎么只打印第 3 到 5 页？

## 操作步骤详解

按最短路径验证一遍：

第 1 步 · Docs 打印（Word 式预览 + 对话框）

1. 在 Docs 标签按 ⌘P / Ctrl+P（或菜单「打印…」）。应用先在后台排版挂载分页预览（每个打印页 = 编辑器里的一页，所见即所印），随后弹出「打印」对话框：
    1. 左侧实时页面预览：一次一页，「‹ / ›」翻页，显示「当前页 / 总页数」；分页未完成时显示「正在生成预览…」；
    2. 右侧「打印机」组：下拉选「默认打印机」/ 具体打印机 /「系统打印对话框…」；份数 1–999；「逐份打印」（2 份以上可选）；「双面打印」三档：单面 / 双面（长边翻转）/ 双面（短边翻转）；
    3. 「打印范围」组：「所有页」/「当前页」/「自定义范围」+ 输入框（占位「如:1,3,5-8」，格式非法时红框）；下方显示「共 {n} 页」；
    4. 点「打印」：未选中的页被隐藏后交给系统打印；取消系统对话框则保持本对话框打开。选「系统打印对话框…」时份数/双面等由 OS 面板接管（本对话框相应置灰）。

第 2 步 · PDF 打印（页范围 / 奇偶 / 份数）

1. 在 PDF 标签按 ⌘P / Ctrl+P（或菜单「打印…」），对话框选项：打印机（默认打印机 / 打印机列表 /「系统打印对话框…」）、份数、逐份打印、双面打印（单面/长边/短边）、「打印范围」（所有页 / 当前页 / 自定义范围「如:1,3,5-8」），再加一组「打印」筛选：全部页 / 奇数页 / 偶数页（范围内无匹配页时提示「所选范围内没有符合的页」）。
2. 打印前自动先保存：标注、表单填写、页面操作全部写入文件后重新载入再打印，所见页序即文件页序。长文档栅格化有像素预算：约 40 页以内按 200 DPI 全质量打印，更长文档自动向 150 DPI 基线降档防内存耗尽；「准备打印…」期间重复按 ⌘P 不会重复出纸。

第 3 步 · Sheets 打印（Excel 式设置 + 分页预览）

1. 在 Sheets 标签按 ⌘P / Ctrl+P（或菜单「打印…」）：左侧是打印设置（方向、纸张 Letter/Legal/Tabloid/Executive/A3/A4/A5/B4/B5、页边距、缩放策略、是否打印网格线与标题行），右侧是分页预览（一页一个纸盒，逐页查看）；预览页即打印与导出 PDF 收到的同一份 HTML。

## 它的局限也要说清楚

用之前要认的账：

- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx

## 你可能会问

### 自动保存开着还会丢内容吗？

最坏丢最近 30 秒内的输入（失焦时也会触发一次）。另外注意首次落盘前的空窗：新建文档要先手动 Ctrl/⌘S 存一次，之后自动保存才接管。

### 打印出来的字发虚？

多发生在超长 PDF：为防内存溢出，整档超过约 40 页时打印密度从 200 DPI 逐级降到 150 DPI 基线。只打印需要的页范围即可回到全质量（预算按所选页计算）。

### 为什么关闭时有的文档询问、有的直接关了？

干净文档（无未保存修改）与已自动保存落盘的文档直接关，不打扰；只有真正有未落盘修改的标签才进逐个询问流程。新文档从未保存过时一定会问。

### ⌘P 没弹对话框、直接出了系统打印框？

这是正常的：Docs 与 PDF 的打印对话框在 macOS 上默认选中「系统打印对话框…」（mac 系统面板自带份数/双面/纸张）；Sheets、Slides 默认走系统默认打印机直接出纸，其它编辑器选了「系统打印对话框…」的行才会转交系统面板。

## 补充答疑

### 标签页变空白/重新加载了，内容丢了吗？

那是标签休眠（释放后台标签内存），不是丢内容：回到该标签时自动从文件重新打开；有未保存修改的标签从一开始就不会被休眠。

## 更多操作细节

第 4 步 · Slides 打印

1. 在 Slides 标签按 ⌘P / Ctrl+P（或菜单「打印…」）：PowerPoint 式对话框，左侧实时页面预览，右侧范围/版式/方向选项，打印时把组装好的页面交给系统打印。

第 5 步 · Markdown / HTML 打印

1. 两个编辑器按 ⌘P / Ctrl+P（或菜单「打印…」）直接走系统打印：Markdown 先把当前文档组装成打印用 HTML（隐藏 iframe 渲染）再调系统打印；HTML 编辑器有防重入门，系统打印框开着时再按 ⌘P 不会打出两份。

第 6 步 · 自动保存

1. 每个编辑器界面内有自己的「自动保存」开关（Docs 中悬停提示「自动保存(每 30 秒及窗口失焦时)」）；设置 ＞ 通用 ＞ 「所有文档自动保存」是全局默认值总开关（默认关）。
2. 生效条件：文档已落盘（首次保存过、有真实路径）。新文档在第一次 Ctrl/⌘S 或「保存」落盘之前不会被自动保存。
3. 落盘用原子写（临时文件 + 原子替换），断电/崩溃不会留下截断的半个文件；自动保存成功后状态提示「已自动保存 ({时间})」。

## 安装与运行答疑

### Linux 上扫描件 OCR 没生效？

Linux 无系统 OCR 引擎，扫描页保留位图不识别；macOS 与 Windows 走系统引擎自动识别。

### 老格式 doc 文件打不开？

明确不支持 doc 与 ppt 老格式，先转成 docx 或 pptx 再打开；odt 等 ODF 格式可导入但采取保守策略。
