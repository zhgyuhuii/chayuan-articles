# RAG本地部署：知识库应用左栏输入库名即建

RAG本地部署这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是RAG本地部署

把RAG本地部署拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

全部口径出自官方文档，版本对应关系见文末。

## 在察元AI OS里落在哪

RAG本地部署在察元AI OS里的落点是「新建知识库」：左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。

这一节值得先讲清楚：按项目或按类别分库，检索范围可控，回答不会被无关资料污染。

## 建库操作全流程

操作路径不长，走一遍就熟：

窗口较窄时中栏文档列表会收进左上角的「文档(N)」浮层按钮，点按钮弹出面板操作——建库在左栏，不受影响。

创建是幂等的：输入一个已存在的库名再点「创建」，不会报错、不会清空数据，等于直接切换到那个库。

创建请求只走本机（无需网络）；万一失败，窗口顶部会出现红色提示条显示错误原因，输入框保留可重试。

1. 打开应用：点击 Dock 中的「知识库」图标。窗口标题栏中间是三个页签「文档」「知识图谱」「设置」，默认停在「文档」页。
2. 认识文档页的三栏布局：
    1. 左栏＝知识库列表（可拖宽）：顶部「知识库」标题，中间每行一个库（数据库图标 + 库名 + 行尾的文档计数），底部是通栏按钮「新建知识库」（加号图标）；
    2. 中栏＝当前库的文档列表；
    3. 右栏＝检索/问答测试台。
    4. 切换库：点左栏任意一行即切到该库（选中行高亮、图标变主题色），中栏文档列表与右栏检索/问答随之全部切换到这个库——左栏当前选中的库就是后续上传、检索、问答的目标库。
3. 点「新建知识库」：左栏底部按钮切换为一个输入框加两个小按钮：
    1. 输入框占位符「新知识库名称」，自动聚焦；
    2. 「创建」主按钮（输入为空或纯空格时置灰）、「取消」；
    3. 键盘等价：输入框内按 Enter＝点「创建」，按 Esc＝点「取消」。
4. 输入库名，点「创建」。库名会被自动归一化为存储目录名，规则：
    1. 字母、数字、下划线、中文字符、连字符 - 原样保留；
    2. 其余字符（空格、斜杠、点、冒号等）替换成 -（连续多个不合法字符合并为一个 -）；
    3. 超长截断到 120 个字符；归一化后为空（比如只输入了符号）时回落为 default；
    4. 举例：输入「产品 资料」最终库名是「产品-资料」。
    5. 看到什么：创建成功后输入框收起，左栏出现新库（行尾计数 0），中栏显示空文档列表（大图标 + 「还没有文档」+ 提示「把资料拖进来，或点击上方上传区；解析与向量化进度会实时显示在这里。」）。输入的库名没有被归一化改动（不含空格等待替换字符）时会自动选中并高亮；名字被替换过时不会自动选中，在左栏点一下新库即可切换。
    6. 库的本体：磁盘上就是 <数据根>/storages/chatop-kb/<归一化库名>/ 一个目录，内含 kb.db（文档档案、分块、全文索引、向量）与 files/（原始文件）。系统按该目录扫描库清单，新库此后的一切数据都写在这里，与其他库完全隔离。整机迁移时把整个 storages 目录拷走即可带走全部库。
    7. 多库与智能体：智能体工具按库名指定目标——kb_list 列出本机全部库；kb_search / kb_read_doc 可带 kbId 参数查指定库，不带时默认查 default。在应用里检索/问答则始终只针对左栏当前选中的库。
    8. 建库之后的完整链路：新库建好即可走完整流程——上传文档并「加载」到「就绪」＞ 中栏管理文档＞ 右栏检索/问答验证＞ 在对话里说「查一下〈库名〉里关于…的内容」让智能体使用它（见教程对应教程《在对话中使用知识库》）。

## 落点的能力面

- 多库并存
- 独立存储互不干扰
- 秒建秒删

## 围绕知识库的配套能力

- 上传文档与加载索引：拖拽上传 txt、md、html、docx、xlsx、pdf，单文件不超过 48MB，自动去重；上传后点加载才开始解析与向量化，进度可取消，崩溃后可恢复
- 检索测试台与引用式问答：右栏检索测试台就是 kb_search 工具的所见即所得，向量、全文加可选重排的混合检索

## 装机条件与几条边界

- 内存 8GB 档的设备，同一时间跑一个对话模型就好，复杂任务会受影响
- 龙芯平台尚未支持；视频生成本地不提供，经由云端路由完成
- 调云端厂商模型的前提是自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态，动手能力弱会有些吃力

这些条目不是劝退清单，只是把账先算明白。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 建库疑问逐条答

### 库名里能写中文、空格、斜杠吗？

中文可以（中文字符在保留清单里）；空格、斜杠等会被自动替换成 -，例如「我的 资料/2026」最终是「我的-资料-2026」。左栏显示的就是归一化后的名字。

### 建错了库，怎么删除？

当前版本应用界面没有删除知识库的入口。库＝目录：把 <数据根>/storages/chatop-kb/<库名>/ 整个目录移走或删除，重启应用后该库即从左栏消失。动手前先确认库内没有还要的资料（可在文档页先把文档「下载」备份）。

### default 库是什么？

系统缺省自带的库（知识库服务启动时自动创建），所有不指定库的操作默认落在它上面——例如在对话里让智能体检索知识库（kb_search 不带 kbId 时）查的就是 default。它与其他库地位相同，可正常使用，也可不往里放任何东西。

### 锁屏密码忘了怎么找回？

三条路：恢复密钥直接重置；开启过验证画像的走 AI 面试找回；多用户环境找管理员重置。提前生成恢复密钥是最稳的。

### 知识库导入失败？

单文件上限 48MB，支持 PDF、docx、xlsx、csv、html 与扫描件 OCR；超限文件拆分后再传，格式不识别时转成支持格式重试。

## 一句收束

RAG本地部署的决策点其实就一条：你的资料敏不敏感、检索范围要不要隔离。这两问有了答案，剩下的只是照着流程把库建起来。细节记不全也没关系，核心就三件事：库是目录、数据互不混、迁移即拷贝；流程忘了就翻回上文「建库操作全流程」。
