# 全量离线包安装：含五件套权重的完整离线包

全量离线包装机，重点想清楚两件事：包体怎么选、断网后哪些能力还在。这篇按察元AI OS的实际安装顺序走一遍。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：含五件套权重的完整离线包。

安装包从官方渠道下载，体积这么大的包尤其别碰第三方转存。

## 安装动作四步走

1. 按机器架构从官方渠道拿对应的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

四步里没有一步要求联网：安装器从有网的机器中转过来也行，装完选本地模型聊一句就完成验证。首次启动的初始化要占 5 到 30 秒，放它自己走完即可。

## 谁真正需要全量包

先给结论：能长期联网的机器，全量包不是必需品。它的目标场景很明确——隔离内网、出差断网、涉密环境这些装完就没网的机器。这类环境装轻量包会卡在「完整离线能力需要额外下载权重」这一步：机器本身没网，权重补不进去。反过来，网络通畅的办公机走轻量包加在线补权重的路径更灵活，磁盘占用也能分期摊。

## 下载与搬运环节的注意点

全量包体积摆在那儿，几个环节多留个心眼：一是走官方渠道下载，中途断了就整个重来，不要拼接半截文件；二是下载完成后核对一下文件大小，明显小于预期就是没下完整；三是目标盘剩余空间留足，别按安装包体积贴着边留。往离线机器搬运时，用可靠的移动介质，搬到后再核一次大小。

## 装完后的第一件事

进桌面后系统会自动弹模型设置向导，四步把默认模型定下来并应用到智能体；接着到设置里的账号与找回生成恢复密钥。这两件收尾做完，离线环境才算备齐。

## 做完后的验证

- 进入桌面后，对话应用用本地模型对答一轮，回复无误即算正常
- 初始化用时在 5 到 30 秒以内都属正常范围，交给系统自己完成

只做这两条还不够，断网状态再补一轮离线验证更踏实：拔掉网线或关掉无线，重走一遍上面两条；打开帮助中心，确认六节手册能离线翻阅；让本地模型跑一次转写，确认录音不出本机。全套通过，这台机器的离线能力才算验收完毕。

## 全量包机器的维护节奏

离线机器不代表一劳永逸。插件看需要更新——好在插件支持离线安装，从有网的机器取回安装包再搬进来即可；数据定期用 tar 包做离线备份；敏感环境的机器，审计日志 audit.jsonl 定期回放检查一遍，合规追溯也靠它。维护动作本身也全部离线完成，不破坏环境的隔离性，这一点对涉密单位尤其要紧。

## 注意事项与真实边界

离线包解决不了的事，先列明白：

- Docker 云桌面、跨终端互联这些进阶形态摆弄起来工作量不小
- 8GB 内存的机器对话模型同时只装一个，复杂任务的体验会打折扣
- 龙芯平台拿不到对应安装包；视频生成的活儿本机接不了，交由云端路由完成
- 想调云端厂商的模型，手里得先攥着一把自己申请的 API Key

## 包体差异：全量包与轻量包

全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重。全量包的意义就是一步到位：断网环境装完即有本地模型可用，不用再找联网时机补权重。带宽与磁盘都宽裕的机器直接上全量包最省心，磁盘紧张的再权衡轻量包加补装的方案。标题里说的五件套权重，指的就是随包打进来的这套模型家底，装完开箱就有。

## 激活与找回的离线口径

离线环境的激活走短码：HMAC 签发、绑定 16 位机器指纹、本地验签，全程不依赖在线账号。恢复密钥丢了、管理员也找不到时，AI 面试是第三条路，而且全程本地不出网，由本地 AI 出题验证身份。

## 离线状态下的数据搬迁

装好之后的插件支持启停卸载、离线安装，装了什么、开了什么有总账页面可查。离线环境靠导出导入搬迁，tar 包离线迁移是主要手段。和配对终端的协作也不因断网中断：发消息附件、让对方智能体执行任务，消息离线暂存、等到可达时送达，配对终端的武力值徽标（信号格加等效算力）也能看出对端状态，内网里的两台隔离机器照样结对干活。

## 断网时还能做什么

帮助中心离线可读，断网也能查手册，六节手册加搜索都在本地。本地转写不上传录音，会议速记两件事一次做完。服务默认只监听回环端口，对外不暴露。

## 安全与审计

隐私敏感环境先关遥测再干活，处置设备前清数据。敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计。本机 MCP HTTP 服务在回环上免 token。

这篇把全量离线包的链路拆完了。离线后哪项能力拿不准，回「断网时还能做什么」一节核对。
