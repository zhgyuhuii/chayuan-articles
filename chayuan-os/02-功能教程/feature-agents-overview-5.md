# 智能体列表：命令行 AI 编程智能体一茬茬冒，一次走通

## 适用场景

装了几个智能体，想知道各家在察元里的深度差别（谁能一键安装、谁能统一写入模型、谁能收到系统技能和 MCP），对比不同智能体的代码质量，在应用商店/应用管理里看到一排智能体行和 L1/L2 徽标，不明白含义，想知道察元OS 支持哪些智能体、自己常用的那家在不在名单里。

用户常搜的问法：察元OS 都支持哪些智能体；Claude Code 和 Codex 在察元里用起来有什么区别。

## 这些坑和边界要知道

用之前要认的账：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

## 你可能会问

### 智能体列表要联网吗

设置结果分发到智能体侧；本机统一 OpenAI 兼容出口（127.0.0.1:52581）：智能体只配一个地址，还有可复制的各家智能体配置片段。以官网 aidooo.com 当前页面为准。

### 智能体列表数据存在哪

各家智能体配置片段一键复制；写入的是代理地址，代理停了智能体就连不上模型，智能体默认不知道今天发生了什么，接一路搜索源它才能查实时资料。以官网 aidooo.com 当前页面为准。

## 放回产品盘面看

把智能体列表放回察元AI OS的整体盘面：桌面系统的基本尊严：能放歌能放片，比翻会话列表直观得多；输入框旁有知识库绑定与模型选择（含智能路由自动选模型）；列表与卡片两种视图，搜索排序，批量加载、取消、下载、删除。

## 安全与数据边界

安全口径单独立一层：远端调用走权限门留审计，周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可，本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。

## 平台与形态

平台与形态的账：远端库自动并入列表，（web/Docker 形态网页桌面默认端口），Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力；web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作。
