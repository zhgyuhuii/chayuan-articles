# 不完全信息博弈观察：模型会诈唬也会怂吗

扑克桌上有个永恒的问题：他这把到底有没有货？人类玩家会虚张声势，也会见好就收。换成大模型呢——不完全信息博弈这件事，模型到底玩不玩得转？它看得见的牌和对手不一样，它敢不敢在信息不全时下重注，怂的时候又怂得有没有道理？察元竞技场把完全信息与不完全信息的玩法摆在同一个大厅里，正好做一场对照观察。这套流程普通人也能执行，不写代码、不跑脚本，一台电脑加几个晚上就够。

## 同一款模型，两副面孔

信息集是这一切的分水岭。五子棋、象棋、围棋是完全信息：棋盘全透明，大家看到的一样多；斗地主、德州扑克、掼蛋、军棋、麻将是不完全信息：你只看得见自己的牌，对手的底与墙里的牌全是黑盒。

同款模型在两种信息集下的表现，经常判若两模。棋类里它步步有依据，牌类里它可能乱打一气——不是性格分裂，是任务性质变了：前者考推演，后者考在迷雾里做决定。

这个现象值得观察，因为聊天评测照不出来。让模型答「你会怎么诈唬」，它能给你背一段教科书；真坐上牌桌，它的一举一动才是真实水平。知行是否合一，只有对局能验证。

这里还有个评测盲区。问卷式提问测的是「模型知道什么」，测不出「模型在压力下怎么做」；信息集一变，模型的真实底色才露出来——这正是跑分榜单照不到的角落。

## 对比观察的做法

第一步，定选手。设置 ＞ 模型配置里从 85 家厂商目录点出你要观察的模型，填好 Key 点「测试连接」——就它一个当主角，别掺第二家，变量越少越干净。

第二步，跑棋类线。让它在完全信息玩法里打几局：五子棋看算路，中国象棋看攻防。开着思维链气泡，记下它的推理风格——此时它看得到全局，胆子与算力都摆在明处。

第三步，跑牌类线。切到不完全信息：德州扑克看下注风格，斗地主看配合与拆牌。同样开气泡，重点看它在信息缺失时说什么——是老老实实承认「看不见对手的牌，按概率走」，还是煞有介事地编故事。特别留意它输牌之后的反应：有的模型连输后下注立刻变形，有的越挫越稳，这份差别在聊天窗口里永远看不到。

第四步，对照三组差异。一比决策质量：棋类是否步步有理、牌类是否被便宜下注骗走底池；二比风格摆动：信息越少它越激进还是越保守——两个方向都会出现，「怂」本身也是观察结论；三比翻车方式：棋类输在算错，牌类输在信错，翻车点不同，能力边界就不同。把气泡原句抄进笔记，结论才不会漂：断言「它怂」之前，先找出它当时写了什么。

第五步，攒样本下小结论。单局说明不了什么，两条玩法线各跑十几局，把观察写成对照笔记：它在哪类信息集下稳、哪类乱。笔记用双栏：左栏记行为，右栏记你的解释，月底回看时左右对照，直觉与证据的差距一目了然。结果只对你测的这些局成立，写出来时带上条件。

## 两条线之外还能怎么加码

加码一，换档位再跑。同一模型换提示档位各打一轮，看决策风格稳不稳——风格随配置大幅漂移的模型，接进业务前要多掂量，排班时也留个心眼。

加码二，混入对照组。把两三个不同厂商的模型拉进同一场锦标赛，强弱与风格差异立刻有了参照系，单模型的怪癖也更显眼。

加码三，观察开局记忆。完全信息线里模型吃过亏会换走法；牌类线里它会不会吸取教训、还是反复在同一个坑里翻车，两条线的学习能力差距，本身就是有意思的发现。掼蛋与军棋暗棋也可以排进加码名单：前者有配合，看它怎么处理队友信号；后者是双层信息，看它怎么管理「未知的未知」。

## 这路观察适合谁

适合：研究模型行为的爱好者与作者，这是比问卷靠谱得多的行为实验场；做智能体设计的工程师，你的智能体迟早要在信息不全的世界里做决定，先看看模型的底色；普通玩家，围观一款模型在两种棋桌上的两副面孔，本身就是乐子。想搞懂「为什么模型答题很聪明、做事不靠谱」的人也该来，答案往往就藏在信息集里；这套观察法随时能捡起来，一个周末就能跑一轮。不适合：想得出普适结论的研究者——个人样本撑不起论文；也接不住只有零散时间的观察者，样本不够时，看到的「怂」与「诈」都可能是噪声。

## 常见疑问

### 模型知道自己在玩不完全信息吗

规则与可见信息会随对局喂给它，它「知道」规则，但知道规则与用好规则是两回事。气泡里它经常引用概率与对手行为做推断，也可能完全忘了信息差这回事——这个落差本身就是观察重点。

### 牌类表现差是能力问题吗

多半是。大模型靠语料与推理出招，不做深度搜索，牌类任务对它天然更难：要记牌、要建模对手、要在噪声里决策，每一项都在它的舒适区外。表现差不是装出来的；把它的翻车现场当教学案例，比教材生动。

### 匿名观战对这种观察有意义吗

有。机机观战默认匿名，座位只显示玩家A、玩家B，终局才揭晓身份——你不知道谁是谁，记录时才不会被品牌印象带偏。先入为主是行为观察的大敌。

### 观察记录怎么留

对局自动留档，棋谱支持 JSON 导出，回放器能按协议字段筛选关键手。建议再配一份自己的笔记，把气泡里的关键发言抄进去——导出的是数据，你记的是观点，两样凑齐才是完整的观察档案，隔段时间回翻还有新收获。

### 需要多久能看到差异

棋类线一晚、牌类线一晚就有轮廓，两周攒下的样本足够写出像样的对照笔记。想快，就压缩单局长度提高场次，短局多打比长局死磕效率高。费用顺带说一句：两条线都是真实 API 调用，由你向厂商支付，Ollama 本地模型能当低成本的替补选手。

模型会不会诈唬、会不会怂，问出这个问题，你就已经站在了比跑分更高的视角。信息集像一面镜子：棋类照出算力，牌类照出胆色。至于你观察到的那个它像谁，答案在你自己的对照笔记里。
