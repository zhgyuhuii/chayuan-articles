# 功能演进总览：从批量工具到文档智能体（察元文档助手演进笔记）

功能演进总览：从批量工具到文档智能体。版本号背后是产品重心的迁移，这篇笔记沿着时间线梳理这条演进线索，帮你判断「现在上车」处在什么阶段。

- **v1.0.1（2026-04）**：初版发布：察元 AI 助理 + 察元 AI 编审两个 Ribbon 页签；批量表格/图像/文档处理、文档脱密、编审表单
- **v2.0.0（2026 年中）**：政企文档生产场景重大重构；助手对话框、模型分类体系、任务系统；从功能堆叠走向可治理平台

- **v4.1.0（2026-08-13）**：表格结构写回（12 action：插行/列、合并单元格）；工具目录 26→46；wps-skill-chayuan 技能双向自启

## 演进主线

从时间线可以看出，察元文档助手的重心在「能力广度→工程深度→规模化形态」之间稳步推进：早期铺功能，中期补安全与体验，近期重心在部署形态与生态联动。这也意味着现在的版本进入相对成熟区间，适合作为主力工具评估。

- 每次升级阅读更新说明中的行为变化
- 重要节点（大版本）升级前做全量备份

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 常见问题
### 企业能内部署吗？

可以。官网提供四档形态：加载项（个人）、桌面版（单机断网）、服务版（Docker 全科室共用）、至臻版（数百到上万人网络版）。

### 外部智能体怎么连接？

在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。

### 和 WPS 自带的 AI 有什么区别？

本产品是独立的开源加载项，特色在结构化校对批注写回、保密/脱密工具链、本机 MCP 服务与离线内网支持；两者可并存使用。
