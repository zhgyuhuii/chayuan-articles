# 找不到资源怎么办：资源查找完整指引

换词、投稿催收录、机器人客服。本文以「找不到资源怎么办」为主题，给出察元AI 能力广场的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：网站首页 https://aidooo.com；产品页 https://aidooo.com/products；教程库 https://aidooo.com/tutorials。系统要求总览：浏览器（桌面与移动）——现代浏览器即可，无需安装客户端；察元AI OS 客户端——安装察元AI OS。

## 问题定位与处理

安装类问题九成出在三个环节：安装包与系统架构不匹配、安装目录权限不足、安全软件拦截。先按这三条排查，再进入具体问题处理。

1. 症状确认：投稿没有通过审核？
2. 按官方口径处理：常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。
3. 处理后在干净环境复现验证一次
4. 仍失败时收集系统版本与报错截图，通过官网支持渠道反馈

## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：重跑安装器即可升级到最新版，配置保留

## 相关报错速查

- 登录提示验证码错误或会话过期？——验证码区分大小写以页面提示为准；会话过期重新登录即可，收藏与投稿数据都在账号下不会丢失。
- 复制了安装命令但装不上？——网站只收录信息与安装命令、不存二进制：命令执行依赖原始仓库可用性；先看条目 health 状态（active/degraded/dead），degraded/dead 的条目建议寻找替代。
- 投稿没有通过审核？——常见原因：与已收录条目重复、信息不完整（缺安装命令或官网地址）、或项目活跃度不足；补全信息后可再次提交，审核状态在「我的」页查看。

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- 政企可私有化部署（Docker），数据自主可控

## 常见问题
### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。

### 智力榜的分数哪来的？

来自公开评测源的聚合整理，按推理/编码/数学/通用/Agent 五维展示；榜单帮助缩小范围，最终选型建议自行实测。

### 复制了安装命令但装不上？

网站只收录信息与安装命令、不存二进制：命令执行依赖原始仓库可用性；先看条目 health 状态（active/degraded/dead），degraded/dead 的条目建议寻找替代。
