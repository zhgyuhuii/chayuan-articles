# Windows安装：NSIS 安装器零依赖装机

先说这篇能帮你干什么：读完就能在察元AI OS 里独立完成 Windows 安装，从取包到进桌面一遍走通。装不上、装完起不来、装完不确定是否算成功，各自对应下文的排查、验证与收尾小节，按顺序对号入座即可。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：NSIS 安装器零依赖装机。

安装包请走官方渠道，来路不明的转载链接别点。

## 实操全过程

1. 从官方发布渠道取对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 其他平台装法速览

Docker 服务器：获取 docker-compose.yml；docker compose up -d 启动；浏览器访问默认 52584 端口得到多用户网页桌面。

macOS：官方渠道取 dmg 打开，拖进应用程序文件夹完成安装；启动后创建账户进入桌面。

这几条是给多机环境备的速记，本篇主线仍是 Windows 桌面安装，细节以各自平台文章为准。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

开机进桌面后，先在对话应用里用本地模型聊一句，再打开应用商店看插件列表能不能加载——两个都通，说明模型服务与网络链路都就绪。这步别跳过：往后遇到问题，先靠它分清是安装没成还是配置不对，能省掉不少绕路。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。这张表最大的用处是杜绝「顺手抓一个包就装」：架构一旦错配，报错多半出现在装完之后，回头重来的成本比装前多看一眼高得多。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

两项都过，安装本身就算落定；之后再遇到状况，先别回头怀疑安装包，往配置和环境那边查更有效率。

## 它的局限也要说清楚

用之前要认的账：

- 内存只有 8GB 时一次载入一个对话模型即可，再复杂就吃紧
- Docker 云桌面与跨终端互联是进阶形态，多少要些折腾功夫
- 云端厂商模型的调用前提：API Key 自理
- 龙芯平台还得再等等；视频生成本地做不了，这条链路通向云端路由

这些账先认下，装不装、装在哪台机器，判断起来就少了很多纠结。

## 装完首次登录会发生什么

头一回登录桌面，系统会自动带出一份四步向导，开篇先把「模型代理是全机统一出口」这件事说明白；完全断网的内网取不到在线资源，权重文件靠 U 盘搬运，系统备了零拷贝导入承接；向导里保存的配置会随系统技能分发到各智能体；图片搜索与图库平台支持也随附其中。

## 安全这条线怎么守

账户彼此隔离，数据在服务器侧统一看管；内嵌的浏览器窗经 webwindows 机制可交由智能体接手；任务跑完，markdown 报告逐份落盘归档备查。多人共用的机器，这几条就是数据互不打扰的底子。

## 平台支持与智能体接入

一键安装与否、可否写入模型、收不收系统技能、接不接 MCP、记忆采集开没开，各家的能力矩阵里都有标注；装智能体时 Node 版本与镜像源是最常见的坑，一键安装把它们一并抹掉；插件可启停、可卸载，也支持离线安装。

## 桌面与应用的组合方式

dock 应用可隐藏、可归入新建分组，自定义网页、本地程序、HTML、文件四类对象都能封装成桌面应用；灵宠商店的主题页签将场景背景、36 图标皮肤与灵宠皮合成套装整体安装；察元AI OS 并非孤军作战，周边组件各自补位。

## 断网内网场景的模型来源

模型可以从直链目录放置后执行扫描入库，本地放置的模型由此进入列表；whisper 语音权重也在可导入之列；显式加载与卸载、外加自动卸载策略，是本地模型驻留的基本方式。装完先不联网试一遍对话，断网可用的底气就是从这里来的。

## 智能体在桌面上的权限面

工作区打开时代理（智能体）默认在场，扩展名到默认应用的覆盖表也一并配好；指定某类文件交给智能体当默认打开方式后，双击即触发 AI；智能体本身可担任默认代理；它还能在运行时定义并挂载新插件——对 AI 说一句「给我做个每晚汇总新闻的应用」就能落地。

## 边角但常用的几项

web 与 docker 形态可生成 9 位字母外网后缀的访问链接，wa 会话管理与踢线操作在管理侧完成；全新安装时可指定数据目录或导入拷贝根，建好管理员即可开工；内置 jspaint 画板（仅桌面形态）承担涂鸦、批注与简单标注；知识库问答由自然语言触发 kb_search、kb_list、kb_read_doc 工具链完成。这些入口都收在设置与桌面菜单里，用时按名字找即可。
