# 一文分清UOS AI软件：完整桌面范式

UOS AI软件这个搜索词背后，是国产 Linux 桌面用户的现实需求：系统换过来了，AI 这块还空着。这篇把一套支持统信 UOS 的 AI 桌面操作系统讲清楚，功能、形态、边界都摆到桌面上。

## 什么是UOS AI软件

宽泛地讲，UOS AI软件指跑在统信 UOS 这类国产 Linux 桌面上的 AI 应用。国产桌面这几年的短板不在窗口和图标，而在生态：日常办公软件补齐之后，AI 应用迟迟跟不上，用户要么开网页版，要么想办法在别处跑。以完整桌面环境为壳做 AI，等于把这块拼图补在系统层——AI 不再是「装了个软件」，而是桌面本身的能力。本文说到的这套是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

各处口径以官方文档为底本，版本对应关系见文末。

## 落点的能力面

- 完整桌面范式
- 42 张内置壁纸
- 动态 WebGL 壁纸
- 窗口四边停靠

它不是一个软件窗口，是一整套桌面环境，这是操作系统形态与工具软件形态的分水岭。两个场景最有说服力：政企用户能拿到完整的桌面迁移体验；低配的老机关机器上，动效依旧保得住流畅。

## 五分钟摸清桌面

1. 开机动画后创建账户进入桌面
2. 底部 Dock 点击启动应用，右键可调设置
3. 顶部菜单栏右侧是控制中心与通知中心
4. 桌面右键试试更改墙纸与小组件

## 窗口与多任务

1. 窗口可拖拽、双击标题栏最大化、拖到屏幕四边停靠
2. Alt 加 Cmd 加 Tab 呼出任务切换器
3. Ctrl 加 L 手动锁屏，支持自动锁屏时限
4. 外接显示器后在设置里排布虚拟屏

## AI 与桌面的咬合点

文件管理器右键直接把文件交给智能体，是最顺手的 AI 入口之一；还能让特定文件类型默认交给智能体处理，双击即用 AI。智能体可以在运行时定义并挂载新插件：和 AI 说一句「给我做个每晚汇总新闻的应用」就行。灵宠把后台跑着的 AI 变成桌面上看得见的小生物；AI 纪要一键生成，与察元OS 同库同源。让全机所有 AI 软件共用一套模型配置的关键设计是：地址只有一个，模型随便换，客户端无感。

这几处设计决定了 AI 是「长在桌面上」还是「贴在桌面上」：长上去的，入口随文件走，双击就是处理动作；贴上去的，永远隔一层窗口，多一步搬运。评价一套桌面 AI，先看它的入口是不是顺路，再谈模型强弱。

## 政企视角的几个关注点

- 数据边界：本地服务默认只监听 127.0.0.1 回环地址，数据不出本机，涉密场景先看这一条
- 可追溯：敏感操作全部写审计日志 audit.jsonl，可回放检查
- 上手成本：Dock、控制中心、通知中心这些构件都是熟悉的形态，迁移的学习成本低

## 桌面个性化这条线

Dock 文生图应用里提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签支持自定义网页、本地程序、HTML、文件四类应用封装上桌，dock 应用可隐藏、可新建分组；桌面与 Dock 的位置、自动隐藏、图标放大与大小都能调，还可设开机自动打开 Harness。Dock 属于高频区域，位置和尺寸合不合手感，天天用的人最清楚。壁纸这块多说一句：42 张内置壁纸覆盖常用风格，动态 WebGL 壁纸在低配机器上也能保住流畅，这正是前文「低配机关动效保流畅」场景的落点。

## 桌面自带的效率小件

- 便签：桌面独立小窗，新建、置顶、折叠、换色、贴图片视频附件
- 提醒事项：智能筛选（今天、已计划、旗标、已完成）、多列表管理
- 日历：日周月年四视图、个人工作家庭学校四本日历；四本日历把生活与工作分开记，AI 能读会写

这三个小件看着不起眼，却是桌面黏性的来源：打开率高、切换成本低；AI 能读会写之后，日历与提醒就从记录工具变成了协作对象。

## 装机前的边界说明

- 8GB 内存档设备一次只载一个对话模型，复杂任务会受影响
- 龙芯平台还没轮到；本地不出视频生成，走云端路由
- 云端厂商模型那边，API Key 自己备
- 进阶的 Docker 云桌面、跨终端互联，得会折腾才行

这些边界与桌面体验无关，限制的只是 AI 部分的上限。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 几个疑问的正面回答

### 这套桌面断网还能用吗？

能。桌面本身与本地模型这条主干断网可用、数据不出本机；真正需要联网的是云端厂商模型与联网搜索，那部分自备 API Key 即可。换句话说，纯内网环境里它照样是个完整的桌面，而不是半残的演示品。

### 机器换成国产平台行不行？

银河麒麟、统信 UOS 都在支持列表里，安装时按架构选对安装包即可：终端执行 uname -m，aarch64 选 arm64 包，x86_64 选 x64 包；龙芯平台暂时除外，选型前先确认硬件。
