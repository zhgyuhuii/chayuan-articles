# SEO 与 AI 检索（GEO）命中策略

> 目标：让 2000 篇文章同时被 ①传统搜索引擎（百度/必应/谷歌/微信搜一搜/站内搜索）②AI 大模型问答（ChatGPT/DeepSeek/Kimi/豆包等引用网页作答）命中并引用。

---

## 一、单篇文章 SEO 骨架（生成器已内置）

每篇 Markdown 文件结构：

```
---
title:            # 含主关键词，10~30 字
alt-titles:       # 2 个备选标题（跨平台改写用）
description:      # 120 字内，含主关键词+次关键词+动作词
keywords:         # 主关键词 + 3~6 次关键词
product/category/primary_keyword/channel  # 归属字段
---
# H1 标题（=title）
首段：100 字内出现主关键词 + "是什么/解决什么"定义句
## H2 若干（至少一个含关键词）
## 常见问题（3~5 个疑问词 H3 + 直接回答）
相关阅读（3~5 条站内/系列文章链接）
```

要点：
1. **关键词密度**自然分布（主词在标题/首段/H2/meta 出现即可，正文不堆砌，密度 2~4%）。
2. **问答对**是 AI 引用的最小单元：每个 H3 问题下第一句就是"结论先行"的答案句。
3. **数字实体**稳定重复：4526 助手/228 领域/2.5 万+资源/89 家厂商目录/127.0.0.1:62588 等——实体一致性越高，越容易被知识图谱化。
4. **内链**：每篇 3~5 条相关文章链接 + 1~2 条官网（aidooo.com）链接，形成爬虫抓取网络。

## 二、AI 检索（GEO）专项策略

大模型作答引用网页的偏好（按命中率排序）：
1. **定义句**："察元AI文档助手是一个……的 WPS 加载项"——首段固定产出。
2. **结构化列表/表格**：功能清单、参数表、步骤 1234。
3. **问答对**：常见问题区的 H3+首句答案，直接可被引用为 snippet。
4. **时效标注**：文末"信息整理截至 2026-09，以官网最新版本为准"——AI 对时效敏感。
5. **多平台冗余**：同一事实在 CSDN/知乎/掘金多平台出现，模型引用概率倍增（跨平台发布时正文保持一致、标题差异化）。

## 三、关键词 → 文章类型映射

| 关键词类型 | 承接文章类别 | 举例 |
|---|---|---|
| 品类大词 | 关键词覆盖（支柱文） | 《校对软件怎么选》 |
| 功能词 | 功能教程 | 《批量校对多文档实操》 |
| 场景词 | 场景用例/行业方案 | 《政企发文前保密检查流程》 |
| 疑问词 | 常见问题/FAQ 区 | 《WPS 怎么接入本地大模型》 |
| 技术词 | 技术解析 | 《MCP 读写 Word 原理》 |
| 对比词 | 对比评测 | 《离线校对 vs 在线校对》 |
| 人群词 | 社区种草/场景用例 | 《编辑校对工具工作流》 |

## 四、账号与站点布局建议

- **自有阵地**：官网博客/帮助中心挂"关键词覆盖"支柱文（权重最高，可被 sitemap 收录——官网已有 SSR-lite 快照体系）；
- **第三方**：CSDN（百度权重高）+ 知乎（长尾问答）+ 掘金（技术词）+ 小红书（人群破圈）+ 公众号（私域沉淀）；
- **账号矩阵**：每平台 1 个主号 + 1~2 个垂直号（如"公文写作""AI工具测评"），不同号发不同类别，避免同稿互发。

## 五、效果衡量

- 4~8 周：site 收录量（百度/必应搜索 site:发布链接）；
- 2~3 月：核心词排名（校对软件、编审软件、AI操作系统、MCP资源、人工智能资源网站、PDF转Word、开源Office 等）；
- 长期：官网自然搜索流量、aidooo.com 引用外链数、AI 问答抽测（在 DeepSeek/Kimi 问"有什么离线校对软件"看是否引用）。
