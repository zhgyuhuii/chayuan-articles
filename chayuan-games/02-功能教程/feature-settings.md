# 察元竞技场设置页全解：模型、界面与语言

不少人装完新应用都有个习惯：先逛一圈设置页，把地盘摸清楚再用。察元竞技场的设置页值得这么逛一遍——模型接不接得上、界面顺不顺手、语言合不合胃口，都从这里定。这篇把察元竞技场设置逐块讲清：模型配置区怎么填，界面偏好怎么调，中英双语怎么切。

## 先弄清楚它是什么

设置页是竞技场的控制台，集中管三件事。

模型配置区：决定谁有资格上桌。内置 85 家厂商目录，DeepSeek、智谱 GLM、通义千问、Moonshot Kimi、OpenAI、Anthropic Claude、Google Gemini 都在列；全部走 OpenAI 兼容协议，Claude 的原生协议由本机网关自动转换，不用改代码；任何 OpenAI 兼容端点可以手填 baseUrl 接入，OneAPI、NewAPI 这类中转同样能接。

厂商目录的意义在于把「填什么」替你想好：点选厂商，地址与协议细节自动就位，你只需要填 Key。手填端点的自由度留给进阶用户，两条路都通向同一张桌。

界面偏好：决定桌子的观感。竞技场是暗色竞技场 UI，界面观感相关的偏好项集中在设置页里，按个人习惯调整。暗色是竞技场的主基调，长时间观战不刺眼；偏好项让你在既有骨架里微调到顺眼为止，指望它变成另一个应用不现实，它的风格自成一派。

语言：决定你看哪种文字。中英双语界面，中文与 English 随你切。

三块各管一摊，但重要程度不一样——模型配置区是硬门槛，没配好模型一切都无从谈起；界面与语言是软体验，顺手就好。

入口关系也顺带交代：设置页不是日常入口，配置完可以很久不进；但大厅与对局室的顺畅程度，全靠它打底。把它当装修里的水电工程——验收一次，长期受益。

## 动手前要备好什么

配模型是设置页的重头戏，动手前备好两样：一是你想用的厂商账号与 API Key——Key 从厂商自己的控制台申请，竞技场只管存放与调用；二是想好用哪家——拿不准的话，先配你手头有 Key 的那家，跑通流程再加新选手。

本地玩家另有一条路：Ollama、LM Studio、Xinference 这类本地推理免 Key，装好就能接，断网也能玩，整条链路可以完全离线，配置过程比云端还短。

## 具体怎么操作

模型配置区分四步走。

第一步，选厂商。在设置 ＞ 模型配置里，从 85 家厂商目录点选你要用的那一家。

第二步，填 Key 并验证。把你自己的 API Key 填进去，点「测试连接」校验这把 Key 能不能用。这里有个容易混淆的点：测试连接失败时会静默回退到手填模型列表，界面不会大张旗鼓地报错——所以模型可选不代表连接一定验证成功，填完顺手确认一下验证结果。

多备几个 Key 也是常见做法：主力厂商之外配一两家备胎，主力限流或者故障时切换不慌；机机观战挂到一半断了重配，观感大打折扣。

第三步，拉模型清单。点「获取模型」，它会用你当前输入的配置实拉这个账号可用的模型全列表，返回裸模型 id 供你勾选入库。注意「获取模型」与「测试连接」脾气不同：前者严格实拉、失败不回退，而且用的是当前未保存的输入——所以填完先获取、再保存，顺序别反。

拉回来的清单里都是裸模型 id，勾选入库后就出现在选模型环节。清单是账号真实可用的，这一步的价值就是把「猜模型名」变成「看着选」。

第四步，接本地模型与中转。用 Ollama 的，免 Key 直接接；有中转端点的，手填 baseUrl 即可，协议兼容就通。四种路径覆盖了从云端到本地的全部接法，你在哪家有 Key，就走哪条。

界面偏好与语言各一步：界面观感项按习惯调整；语言项在中文与 English 之间选择，整套界面文案随所选语言切换。

## 做完后的验证

模型配置完，回大厅开一局试试水：模型出现在可选名单里、能正常出招，就是接通了。语言切换后，界面文案变成你选的那种，菜单与按钮的布局位置不变。两样都过，设置页这一圈就没白逛。

本地模型单独验一条：接 Ollama 的，断网再开一局试试——还能正常对弈，说明整条链路真的离线可用，这份踏实是云端模型给不了的。到这里，模型、界面、语言三块就全部验收完毕。

## 这些边界要心里有数

Key 的存放方式要知情：API Key 明文只存本机应用数据目录（arena/config.json），加密升级位已预留，永不上传；对局数据同样落在本机。放心是本机给的，不是云给的。

「获取模型」严格实拉不回退，填错 Key 或者网络不通就会失败，这是特性不是故障；它的价值在于拉回来的列表真实可用，不用你凭记忆猜模型名。

设置是本机的，不云同步。换设备要重新配一遍，介意的话把配置清单记下来。

明文存储这一点要正视：本机磁盘被别人接触到，Key 就是可读的。共享电脑的用户建议用完锁好系统账户，或者干脆只在自己专用的机器上配 Key。

设置项会随版本演进，本文按 0.1.0（2026 年 11 月）口径写，后续版本以实际界面为准。

## 高频疑问

### 我的 API Key 安全吗

Key 只存本机应用数据目录，永不上传；模型流量走本机网关，配置写入带写锁。数据不出本机是这款应用的基本设计。

### 测试连接和获取模型有什么区别

测试连接校验 Key 能不能用，失败静默回退手填模型列表；获取模型用当前未保存的输入实拉该账号可用模型全列表，严格实拉不回退。一个管验证，一个管清单。

### 中转服务能接进来吗

能。任何 OpenAI 兼容端点手填 baseUrl 就能接入，OneAPI、NewAPI 这类中转同样可接；Claude 走本机网关自动转换，不用改代码。

### 设置能迁移到另一台电脑吗

设置与数据都落本机，没有云同步；换设备需重新配置，数据迁移靠自己备份应用数据目录。

### 不想用云端模型可以吗

可以。Ollama、LM Studio、Xinference 这类本地推理免 Key 接入，配置好后断网也能对弈，零 API 成本；代价是本地模型的棋力受模型本身限制。

### 配置错了会影响已打完的对局吗

不会。历史对局已经留档，配置只影响之后新开的对局，老记录、老数据安然无恙。设置项找不到想调的，先确认版本：0.1.0 的功能以实际界面为准，界面上没有的说明当前版本不支持。

设置页是一个应用里最诚实的地方：宣传的部分不在这里，能落地的部分都从这里开始。把模型配置区跑通、界面调顺手、语言切明白，竞技场这张桌子才算真正属于你。配置一次管长远，这十分钟值得花。
