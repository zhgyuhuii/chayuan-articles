# SSR 快照与 sitemap 上线解读（能力广场演进笔记）

SSR 快照与 sitemap 上线解读。版本号背后是产品重心的迁移，这篇笔记沿着时间线梳理这条演进线索，帮你判断「现在上车」处在什么阶段。

## 时间线

- **v门户上线（2026 上半年）**：能力广场八大板块与产品家族页；开源排行榜与标签聚合
- **v内容护城河建设（2026 年中）**：教程库采集 2.1 万+ 条（arxiv/github/B 站等）；技能包商城 311 包 13 行业；20 行业 200 场景库与 4526 助手目录
- **vSSR 快照 SEO 层（2026 年内）**：SSR-lite 服务端首屏快照与动态 sitemap；爬虫可见资源总数进首屏；模型智力榜/免费榜/对比页完善
- **v商业化闭环（2026-06 起）**：技能包买断制商城（token 限 3 设备）；序列号签发与离线核销对齐桌面端；察元机器人客服（RAG+需求收集）

## 演进主线

从时间线可以看出，能力广场的重心在「能力广度→工程深度→规模化形态」之间稳步推进：早期铺功能，中期补安全与体验，近期重心在部署形态与生态联动。这也意味着现在的版本进入相对成熟区间，适合作为主力工具评估。

## 升级与版本策略建议

- 生产环境跟随稳定版，滞后一两个小版本
- 每次升级阅读更新说明中的行为变化
- 重要节点（大版本）升级前做全量备份

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 常见问题
### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。
