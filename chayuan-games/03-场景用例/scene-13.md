# AI选题从哪来：棋评与对局拆解写作

写棋评的人对着空白文档干坐半晚，这种经历不稀奇。写棋牌拆解、写模型观察、写博弈科普，统统卡在同一个地方：没棋可写。AI选题这条素材路子，很多人还没试过——让大模型自己下棋给你写，素材管够，还自带思考过程。察元竞技场就是这台素材机器：模型对弈全程留痕，思维链、曲线、标注、棋谱一样不缺，这篇把从攒棋到成文的素材链走一遍。

## 棋评这行当的三个缺口

找不到棋。名人棋谱版权与授权麻烦，热点棋评一窝蜂全在写，你动笔时话题已经凉了；冷门棋局倒是没人抢，可你又得先解释它为什么值得看。这三个缺口，各堵各的路：找棋靠批量产料，拆棋靠标注台阶，引用靠导出文件——下面这条素材链就是对着它们设计的。

拆不动棋。真想拆一局棋，你得会摆谱、会算路、会讲人话。功力不够就只能复述结果，读者两眼一黑，划走了事。

引不了用。棋评讲究引用：这手棋在第几回合、局势从哪开始倾斜、某类开局出现得多不多。这些数据靠手工抄，又慢又容易错，读者较真起来，你拿不出处。

数据对不上。今天看到的对局信息，明天换个渠道口径就变；写进文章的每个数字都要能复现，否则评论区一个较真的读者，就能让你下不来台。

## 从攒棋到成文的素材链

第一环，攒棋。机机观战是素材车间：选两个或多个模型对打，你在旁观；批量选模型建一场锦标赛，循环赛自动排程，睡一觉起来一库素材。玩法按文章方向定：写计算类棋评挑象棋、围棋，写心理类挑德州扑克，写运气与决策挑麻将。同一批模型换玩法再跑一轮，素材马上翻倍，角度也跟着换。

第二环，找点。一局棋几十上百手，全写没人看。形势曲线先把整局画成一条线，拐点在哪一眼可见；逐手的妙手与失误标注帮你缩小范围；回放器还能按协议字段筛选关键手，定位比翻录像快得多。先定文章主线再找点：写反转就看曲线急坠处，写性格就看失误集中段——点为题服务，别让点牵着题走。拐点加标注，就是一篇棋评的骨架。

第三环，抓金句。模型每手棋的思考过程在思维链气泡里实时外放，常有出人意料的话：明明占优却主动求稳，明明能吃子却按兵不动。这些话直接引就是段落素材，比你自己编内心戏实在；引用气泡原文时注明是模型生成内容，别让读者误以为是人写的内心戏。

第四环，取引用。棋谱支持 JSON 导出，着法与对局信息都在文件里，回合一查便知，写进文章的数据有据可查。协议画像里的 JSON 格式遵守率与平均耗时，给「模型性格」类拆解文提供硬数据。引用别贪多，一篇文章三五个出处足够；数据引用宁少勿错，一个错误出处就能带垮整篇的可信度。

第五环，成文与标注。AI 赛后解说可以当底稿，但必须改写——照抄解说文字等于交机器作业，读者也读得出机器味。篇幅看载体：长文两千字上下讲透一局，短内容三百字只切一个拐点，同一份原料可以伸缩。成文时把条件写全：对局用的什么模型、什么玩法、多少局，AI 生成的部分按平台要求标注。发布前回头核对一遍数据：回合数、对手、结果，三处对得上再发。你的价值在观点：机器给过程，你给判断。

## 三个容易踩的坑

坑一，把解说当权威。AI 赛后解说与实时解说都是模型生成的观点，可能说岔，胜负判定永远归对局引擎——解说错了不影响棋局，照抄进文章就会以讹传讹。

坑二，拿小样本写大结论。三五局就说「某某模型不行」，评论区会替读者问你样本在哪。对局数据再方便，也救不了样本量不足的硬伤——先把局数攒到能说服自己，再谈说服读者。

坑三，漏写对局条件。模型档位、玩法、局数、写作时的应用版本（当前为 0.1.0），这四样写全，你的结论才有边界，读者才谈得上复现。

## 这条素材链适合谁

适合：写棋类内容的作者、做模型观察的科技博主、想练拆解但功力不足的爱好者——标注与解说就是台阶，扶着往上走比硬啃棋谱快。也适合编辑与策划，把对局素材当选题池，开选题会前先扫一眼积分榜。高校棋牌社与棋类课堂同样用得上：把对局当公开课素材，标注就是现成的提问点。

不适合：追突发热点的快讯号——对局素材是慢热型，抢不了时效；也不适合想纯搬运的号——素材要自己跑、观点要自己立，这条链省的是体力，不是脑子。

## 常见疑问

### 素材能直接当文章发吗

不能直接发。解说与气泡文字要改写、要核对，棋谱数据要注明来源；按平台规则标注 AI 参与，这既是合规也是对读者负责。素材链给的是原料，成品还得你亲手出。

### 棋谱 JSON 里都有什么

着法序列与对局信息，够你查回合数、复盘关键手，具体字段以导出文件为准。想程序化处理的话，JSON 格式对接脚本很方便；引用时注明对局条件与应用版本，数据才算立得住。

### 会不会和别人撞素材

公共玩法谁都能跑，撞局难免。但你的模型组合、玩法搭配、切入角度是私货，三样凑齐就不容易重样。同一局棋，写心理的、写计算的、写性格的，是三篇文章；真撞了也不慌，解读权在你手里，角度即差异。

### 跑素材要花多少钱

软件 MIT 开源免费；云端模型对局消耗的是你向厂商支付的 API 额度，挂机越多花得越多，预算要心里有数。用 Ollama 本地模型跑素材零成本，代价是本地小模型棋力有限，对局精彩程度打折，成文时也得诚实交代这一层。

### 新手看不懂棋怎么办

从看标注和曲线开始。妙手失误标注告诉你哪里有事发生，形势曲线告诉你哪一段重要，AI 赛后解说把因果讲成话——三样凑齐，不懂棋的人也能写出合格的拆解文，写着写着棋力也跟着涨。

选题荒的解法不是苦想，是找一台会自己产料的机器。模型对局自带悬念、自带金句、自带数据，你负责把它们组织成读者爱看的文章。下回选题会再冷场，就开一局机机观战——素材这东西，可以让模型替你下出来。今晚就开一局，选题攒着攒着就有了。
