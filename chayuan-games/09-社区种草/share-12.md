# Key不出本机的安全感：密钥留在自己电脑

首图建议：一枚实体钥匙放在笔记本电脑的触控板上，屏幕虚化，配一句「填 Key 之前，先看它存哪了」。

让大模型下棋，绕不开填 API Key。很多人兴致勃勃装好软件，到了这一步突然犹豫：这串 Key 填进去，到底存在哪，会不会被传到不知什么地方？

这份犹豫很正常。Key 绑着你的钱包，谁都想搞明白再动手。

今天把察元竞技场的密钥机制用大白话拆一遍。核心就一句话：Key不出本机，密钥留在自己电脑上，软件不帮你往外寄。怎么做到的、边界在哪，往下看。

## 机制白话版

拆成三段讲。

存储位置：Key 明文只存本机用户数据目录下的 arena/config.json，属于你电脑上的本地文件，不进任何云端。加密升级位已经预留，后续动向可以盯仓库。

写入过程：配置写入带写锁。白话讲就是同一时刻只放行一个写入动作，避免你这边改配置、那边对局正在读，两边打架把文件写坏。

运行过程：运行时热读取。改完配置不用重启软件，下一手对局就用上新设置。这两条听着是工程细节，其实是「数据由本机说了算」这个原则落在代码里的样子。

另外提一句，接 Anthropic 的 Claude 不用改协议，本机网关会自动做协议转换，请求从你电脑直发厂商，软件不当中转站。

想亲眼看它存哪：配置文件就在用户数据目录下，不同系统的路径不同，仓库文档里有说明。文件是普通 JSON，文本编辑器打开就能核对里面有没有你填的 Key，看完关掉就行，这个笨办法听着糙，但管用。

## 三个点，两好一坑

1. 好在密钥不出门。没有上传动作，你填完的那一刻它就躺在你的电脑里，数据流向一张纸就能画清楚。

2. 好在有免 Key 路线。Ollama、LM Studio、Xinference 这类本地推理免 Key，模型跑在你自己的机器上，断网也能打，预算焦虑直接归零。

3. 坑在明文落盘。现阶段 Key 以明文存在本机文件里，加密属于预留能力。自己的电脑自己看好：别把配置文件随手发人，公共电脑上用完记得清理。

## 和厂商的关系要说清

软件不碰你的请求了吗？不是。发起对局时，请求带着 Key 发往对应厂商的服务器，这是调用 API 的正常链路。

所以准确的说法是：密钥存储不出本机，调用链路直连厂商。厂商侧能看到你的请求内容，这是所有 API 产品的共性，与软件无关。介意的话，把棋牌对局这类场景整个交给本地模型就好。

设置页里有两个容易搞混的按钮。「测试连接」发 GET 请求校验 Key 好不好使，不通就静默退回手填模型列表；「获取模型」用 POST 实拉你这个账号可用的模型全列表，读的是你还没保存的输入，严格实拉不回退。前者验身份，后者拉清单，先测后拉，顺序记住。

顺手提个坑：如果你接的是中转站，用的是中转发给你的那把 Key，不是厂商原生的那把，两回事别混填。混填的表现通常是测试连接能过、获取模型拉不到东西，或者反过来，这时候先核对 Key 归属再排查别的。

顺带说路径令牌这类东西也在本机配置这一侧管理，不单独走云端，具体以仓库文档为准。

## 断网的机器怎么进这个局

家里有台不联网的旧电脑，也能玩起来。

路线是 Ollama 这类本地推理：软件里端点指向本机服务，模型在自己机器上跑，全程不碰外网，也不用填任何 Key。断网对局、隐私敏感场景、给孩子的旧机器，都适合这条路。

代价说在前面：本地小模型棋力有限，出招质量看模型大小，429 限流这类云端烦恼倒是彻底没有了。想热闹安稳兼顾，可以让云端模型打表演赛，本地模型打日常局，两条线并行不耽误。

## 三个常见误解

误解一：填了 Key 就等于把模型能力授权给了软件。不是。Key 只是调用凭证，走的是你与厂商之间的直连，软件没有替你保管或转授任何东西。

误解二：对局记录会同步到云端。软件侧的存档是本机 JSON 文件，带写锁、热读取，去向就是你的磁盘。

误解三：本机网关会把请求转发给官方服务器。也不是。网关跑在你电脑上，做的是协议转换，把不同厂商的协议口径捋顺，请求目的地仍然是厂商本身。

三个误解拆完，这张信任清单其实很短：Key 在本机，存档在本机，网关在本机，出网的只有发往厂商的调用请求。

## 也要说实话

- 明文存储是现状，特别介意的人要么等加密能力落地，要么只走 Ollama 本地路线，云端 Key 少填为妙。
- 厂商侧的请求可见性是 API 常态，软件管不了那一截，别把「Key不出本机」理解成「请求也无人可见」。
- 本机文件安全取决于你的电脑安全，中招窃密木马的场景软件帮不了你，基础安全习惯不能省。

适合谁：对密钥去向敏感、想搞清数据流向再填 Key 的人。不适合谁：指望软件替自己包办一切安全的人，安全永远是用户和软件一起做的题。

## 评论区高频问题

### 会不会偷偷把我的 Key 传到你们服务器？

不会。Key 明文只存本机用户数据目录，永不上传，机制就是这么设计的。仓库开源，不放心的可以自己抓包验证。

### 换电脑或重装系统，Key 要重填吗？

配置文件在本机，换环境就是新的一份。照着设置页重新填一遍即可，两分钟的事；旧机器记得清理干净。

### Ollama 真的不用填 Key？

真的。本地推理免 Key，模型在你自己机器上推理，费用为零，代价是棋力上限受本地模型大小限制。
