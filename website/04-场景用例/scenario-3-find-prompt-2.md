# 提示词需求者的提示词库方案（新手路线）

如果你是提示词需求者，下面这些场景大概率不陌生：网上提示词质量参差。高质量提示词的正确打开方式。这篇新手路线以能力广场为工具，把这个岗位的提示词库工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 网上提示词质量参差
- 没有结构化分类
- 复制粘贴体验差

## 用能力广场怎么解：工作流拆解

1. prompt 板块按场景筛选
2. 读结构与约束
3. 复制正文直接用

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「prompt 板块按场景筛选」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。高质量提示词的正确打开方式。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 网站不存任何二进制文件，安装一律跳转原始地址
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
