# 军棋暗棋布阵教程：自由布阵两击与拖拽

小时候玩陆战棋，摆棋子的工夫常常比开打还长：阵摆松了，一开战就被人捅穿后防；摆得太死，自己又动弹不得。察元竞技场把军棋搬上桌之后，这道工序原样保留——军棋暗棋走自由布阵，棋子怎么排全由你定，落子支持两击与拖拽两种操作。这篇军棋暗棋布阵教程，把布阵交互、阵型思路、开局检验三件事一次讲清，让你在对局开始前就把功课做足。

## 先弄清楚：自由布阵自由在哪

不少棋牌应用图省事，塞给你几个现成阵型模板一键套用。察元竞技场没走这条路：军棋暗棋的布阵阶段不锁模板，司令、军长、师长、炸弹、地雷、军旗这一整套棋子，每一枚摆在哪一格都由你自主决定，这就是自由布阵。自由是双刃剑——它给了你藏心思的空间，也给了你摆烂的空间，阵摆成什么样，对局就得吃什么果。

操作层面给了两条路。两击式：先点选棋子，再点目标格，棋子落位，适合一格一格精调；拖拽式：按住棋子直接拖到想去的位置松手即可，适合大范围调换。两种方式效果完全一致，布阵过程中随时可以混用，顺手就行。摆错了也不用心慌，重新选子再放一次即可，布阵阶段怎么折腾都行，进了对局才真正定格。

两种方式怎么选？没有高下之分，看场景。零星调整几个位置，两击更稳，落点精确，不容易手滑；整排棋子要换防区，拖拽更快，一把到位。也有人喜欢先用拖拽铺出大框架，再用两击精调细节，两道工序分层做，效率更高。布阵界面不消耗任何资源，多摆几遍就有手感，工具顺不顺手，用过才知道。

还有一点容易忽略：布阵从来不是你一个人的事。对面的大模型同样要走这道工序，它也面对一张空阵位图自己排兵布阵。你在藏什么、它在藏什么，从开局前就已经较上劲了——这也是军棋暗棋和别的棋不一样的地方，胜负的一半在落座之前就埋下了。

## 阵型思路：几条通用原则

具体格位没有标准答案，但有几条通用原则值得参考。其一，头牌别冒进。司令是全军牌面，开局就顶上火线，一旦撞上炸弹，司令阵亡亮旗，军旗位置当场曝光，亏到姥姥家。其二，炸弹是制衡子，不完全是进攻子。它跟谁相遇都是同归于尽，藏在中后段要道上，等对方大子来犯再启用，划算得多。其三，地雷负责封路，工兵负责拆雷。地雷摆得越刁，对面拆雷的成本越高；而工兵是己方手里能碰雷的独一份子力，布阵时给它留好机动路线，别让自家阵型把它困死在角落。其四，军旗要藏得有层次，别摆成一眼望穿的明牌局。其五，前后呼应：大子压阵、小子巡线，任何一个方向被突破都得有第二梯队补位，别把全部家当押在一侧。

这些原则不是铁律。军棋的乐趣之一恰恰在于反着来也能赢，有人就爱用司令当诱饵钓对面的炸弹。布阵思路本就没有标准答案，原则之外，全看你想把对面那个大模型往哪个坑里带。

## 布阵三步与开局检验

第一步，进大厅，在棋类分组里选军棋暗棋，开一局人机局，你落座后即进入布阵阶段。

第二步，摆阵。用两击或拖拽把整套棋子归位，边摆边对照上面几条原则自查：司令是后置压阵还是前置抢攻、炸弹藏在哪条要道、地雷封了哪些口、工兵有没有活路、军旗埋得多深。摆完再整体扫一眼，确认没有棋子悬在半路，也确认自己记得住哪个位置摆的什么——布阵混乱的阵，自己先记不住，吃亏的还是自己。

第三步，进对局。开局头几个回合别急着吃子，先观察对面模型怎么试探你的阵：它拿小子撞线，是在摸你前线的斤两；它工兵早早出动，多半在找你的地雷带。你的阵牢不牢，几个回合就能试出来。中途局面不好办，随时可以把控制权交给 AI 接手，下一手生效，让它替你续几手看看思路。

打完一局还有后手验证：进回放，逐手看阵型在哪一格被打穿，问叹号标注（？！）会把妙手与失误逐手挑出来，形势曲线画出局势走向。布阵欠的账，回放里算得明明白白，比你自己拍大腿管用。

## 这些边界要心里有数

模型的布阵质量参差：思考型模型布阵讲究章法，弱一点的模型可能摆出明显破绽阵；遇上解析失败，系统按启发式代走兜底，军棋局里这份代走的痕迹比棋类更明显，观感会打折。军棋的学习曲线也客观存在：光会布阵不够，吃子链、炸弹、地雷、亮旗的规则得一起学，新手建议先去明棋教学档把大小关系练熟，再回暗棋摆阵。还有老生常谈的费用问题：模型 API 的费用由你向厂商支付，军棋一局手数不少，挂机连打更要看紧自己的额度。

## 高频疑问

### 布阵时两击和拖拽能混用吗

能。两种落子方式效果完全一致，布阵阶段随时切换，按手感来；摆错了重新选子再放一次即可，布阵阶段不受任何限制。

### 模型看得见我的布阵过程吗

看不见。军棋暗棋的对局信息按各自视角分发，你的棋子在它那边是暗置的。它只能从对局中的碰撞与吃子结果反推你的阵，布阵阶段的心思它偷不走。

### 有没有推荐阵型可以直接套用

没有现成模板，自由布阵就是把主意还给你自己。文中的几条通用原则可以当自查清单用，阵型本身还得靠你在对局里边打边磨。

### 军棋暗棋布阵相关功能要花钱吗

软件开源免费，MIT 协议；布阵、对局、回放都不额外收费，只有模型调用按用量向厂商结算。

### 布阵到一半能临时改主意吗

能。布阵阶段棋子随便挪，两击与拖拽都支持反复调整，确认进入对局之后阵型才锁定。

### 布阵阶段有思考时间限制吗

没有。布阵由你掌控节奏，慢慢排兵也行；进对局后每手的节奏由出招方决定，模型的延迟在对局室里有标注，等待属于正常现象。

布阵是军棋暗棋的私房功夫。两击也好、拖拽也罢，落到盘上的每一枚棋子都是你递出去的信息——对面那个大模型会怎么读它，摆一局就知道了。
