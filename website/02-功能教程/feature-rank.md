# 开源榜单实操怎么用：手把手走一遍完整流程

用察元AI 能力广场有段时间了，开源榜单机制是我用得比较多的一个功能。这篇把我积累的操作顺序和几个关键细节写出来，新手可以照着走，老手可以查漏。

## 它是什么，为谁服务

日、周、月、季、半年、年六档榜单按周期内 star 增量计算（每日同步抓快照），无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；每板块取前 200；周期起点早于最早快照时降级为星标总量榜并标注；失效（dead 或 archived）资源自动剔除出榜。

看增量而不是存量：这周谁在涨比谁总量大更有参考价值。

下面直接进入正题。

## 从打开到做完的每一步

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

## 谁需要这个功能

找近期上升最快的 MCP；季度回顾生态趋势。

## 它的局限也要说清楚

用之前要认的账：

- 榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜
- 教程库只做元数据导航，正文仍在源站

## 常见问题

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。
