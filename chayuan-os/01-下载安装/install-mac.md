# macOS安装装机指南

先说这篇能帮你干什么：读完能在察元AI OS里独立完成 macOS 安装——dmg 拖装、首启建户、五件套自动加载，要点哪些按钮、做完怎么验证，下面按顺序交代。动手前唯一要先想清楚的是机器芯片属于哪一系，选什么包全看它。

## 安装前确认

- 系统要求：Apple Silicon 或 Intel
- 安装包：dmg（ChaAIOS-版本-arm64.dmg / x64.dmg）
- 说明：dmg 拖装与首次启动。

dmg 从官方渠道下载，下载站二次打包的不要用。

## 一步步来

1. 从官方渠道下载 dmg 并打开
2. 把察元AI OS 拖入应用程序文件夹
3. 启动后创建账户进入桌面
4. 模型服务自动加载装机五件套

四步里没有命令行，全程图形界面：dmg 打开后是标准的 macOS 拖装窗口，把图标拖到应用程序文件夹快捷方式上就完成复制；之后的首启初始化与账户创建都在界面里完成。装完的磁盘占用以拖入后的实体为准，安装镜像用完可以推出并删除，能立刻回收一份空间。

## 其他平台装法速览

Linux（AppImage）：chmod +x 加执行权限后直接运行；缺 FUSE 就补装 libfuse2，或改走 --appimage-extract-and-run 参数；免安装的形态适合没有 root 权限与便携的场景。

Windows：双击运行对应架构的 exe 安装器即可，不带额外依赖，首次启动建本机账户后进桌面。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

开机进桌面后，先用本地模型在对话应用里应一句，再打开应用商店刷一下插件列表——两处都正常，模型服务与网络链路就算都通了。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

终端里跑一遍 uname -m，看到 aarch64 就选 arm64，看到 x86_64 就选 x64。Intel 芯片的 Mac 取 x64 的 dmg，Apple Silicon 取 arm64 版，两者不要混装。

## 收尾检查

- 桌面开出来后，对话应用选本地模型问一句，回复无误即为成功
- 首启初始化耗时 5 到 30 秒都属正常，等它结束再操作

若桌面迟迟出不来，先核对 dmg 的架构字段与芯片是否一致（对照上一节速查表），再考虑重装。

## 注意事项与真实边界

mac 这条线要认的边界如下：

- 8GB 内存的 Mac 一次只加载一个对话模型，复杂任务会受限
- 龙芯不在支持范围；视频生成本机不做，交给云端路由
- Docker 云桌面、跨终端互联这类进阶形态，得自己动手折腾
- 云端厂商模型的 API Key 各自准备，装包里没有

## 桌面右键与小组件

mac 装好后，桌面有几处值得先摸一遍：右键可编辑小组件——时钟、天气、照片、日历及玻璃系列、网页挂件都在列；右键也是桌面操作的集大成入口，「用智能体打开」能把文件直接交给 AI 处理，录屏同样从这里发起。桌面与 Dock 的设置里可调位置、自动隐藏、图标放大与大小，以及开机自动打开 Harness。

## 用户管理与数据目录

记忆能力需要提前开启、积累足够的记忆数据。管理员可建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。智能体若不知道手头有哪些本机工具，就等于没有这些工具；技能手册镜像让它们开箱就会用系统能力。

## 包体大小与智能体安装

包体口径先交代：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重。装机五件套随 dmg 分发，装完即可用，不占额外下载量。智能体安装方面，各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。插件可以启停、卸载，也走离线安装。

## 跨机授权与本机出图

资料在 A 机器、人在 B 机器跟前时，授权一次就能跨机问；授权按终端逐台给。本机 Stable Diffusion 链路出图不联网，隐私与成本都更可控。

## 本地模型的三类适用场景

本地模型的适用定位可以说清：它解决有无问题，复杂任务还是需要云端旗舰模型；云端模型断网即不可用，可设置自动回落到本地。模型库会按本机内存预算分层推荐，三档标记（能跑/勉强/跑不动）直接标在推荐列表里。断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

## 离线搬迁与桌面封装

离线侧的口径：清单可离线导入导出，离线环境靠导出导入搬迁，tar 包离线迁移是主要手段；装了什么、开了什么有总账页面可查。应用页签支持隐藏 dock 应用、新建分组，还能把自定义网页、本地程序、HTML、文件四类应用打包放上桌面。

## 模型配置与协作形态的补充

补充几处分散的入口与形态：检查更新的入口在 设置＞关于，有新版时下载并重启安装；一台服务器全组使用时，运维只管一处、终端零安装；编辑面板里模型、知识库、人设都能改；输入框旁边就是知识库绑定与模型选择，智能路由会自动选模型。
