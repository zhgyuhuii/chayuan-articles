# 模型接入（30+ 供应商）怎么用：察元文档助手新手入门

大模型接入是察元AI文档助手里使用频率很高的一项能力。它的「模型接入（30+ 供应商）」这样工作：设置内可配 30+ 模型供应商：OpenAI、Claude、Gemini、DeepSeek、豆包、阿里百炼、百度千帆、智谱 GLM、Kimi、零一万物、MiniMax、阶跃、百川、书生·浦语、ModelScope、OpenRouter 等，加本地 Ollama/LM Studio/Xinference/One API/FastChat/Custom OpenAI；模型分对话/嵌入/图像/语音/视频五类。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

设置内可配 30+ 模型供应商：OpenAI、Claude、Gemini、DeepSeek、豆包、阿里百炼、百度千帆、智谱 GLM、Kimi、零一万物、MiniMax、阶跃、百川、书生·浦语、ModelScope、OpenRouter 等，加本地 Ollama/LM Studio/Xinference/One API/FastChat/Custom OpenAI；模型分对话/嵌入/图像/语音/视频五类。

从任务视角看，它对应的关键词是「大模型接入」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入设置→模型
2. 填入供应商密钥或本地端点
3. 为五类任务分别指定默认模型
4. 对话测试连通

## 适用场景

- 按保密等级选择云端或本地模型
- 不同任务用不同模型控制成本

## 进阶技巧

- 内网环境把所有端点指到 One API 网关统一管理

## 注意事项与边界

- 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

## 数据安全与隐私边界

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 知识库功能怎么用？

设置中绑定知识库服务（JWT/HMAC 认证），即可对选中文字做核对、总结、问答，结果带引用并可下载原文。

### 能在完全断网的环境用吗？

能。配置 Ollama 或任意 OpenAI 兼容内网网关后全部功能可离线使用；安装包内嵌 sidecar 二进制并注册自启，适配离线与内网部署。

### 我的文档会上传到云端吗？

不会强制上传。使用本地/内网模型时文档不出本机；MCP 服务只监听 127.0.0.1:62588 回环地址；只有你主动配置云端模型时，对话内容才会发往对应服务商。
