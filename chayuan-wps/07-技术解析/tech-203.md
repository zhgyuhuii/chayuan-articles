# 跨平台打包与自启注册：察元文档助手的实操要点

跨平台打包与自启注册常被用户问到。这篇实操要点从察元AI文档助手的实际实现出发，讲清楚设计取舍与使用层面的意义。

## 一句话结论

交付形态覆盖：Windows（自解压 exe（约 35MB，带 .sha256 校验文件））；macOS（pkg 安装包（约 35MB））；Linux（deb 安装包（约 35MB））。跨平台打包的难点在架构矩阵与依赖就位，而不是功能本身——每个平台的安装步骤都在官方文档有逐条说明。

## 为什么这样设计

这个设计的动机可以概括为三点：把风险控制在机制而不是纪律里（靠制度约束人的行为总会失效，靠架构约束才稳定）；把复杂度封装起来（用户不需要理解内部实现，只需要理解行为边界）；把可验证性留给用户（声明的能力都能在产品里实际验证）。软件工程里没有免费的设计——每一条这样的取舍都是在「体验、安全、性能、成本」之间做的显式权衡，约束变了，结论就可能反转。

## 对使用者意味着什么

- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改
- 数据目录可配置：Windows %AppData%\chayuan、macOS ~/Library/Application Support/chayuan、Linux ~/.config/chayuan
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 相关能力以官网 https://aidooo.com 最新版本为准

## 离线运行与部署形态

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

## 数据安全与隐私边界

- MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
- 匿名指标上报默认关闭（opt-in），不采集文档内容
- 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
- 发布包逐源 sha256 强校验（Gitee→aidooo→GitHub 多源回退），防供应链篡改

## 费用与授权的边界（如实说明）

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。付费部分：文档脱密、脱密复原、涉密检查、涉密关键词提取为付费功能，购买后不限次数；序列号（授权码）与本机设备指纹绑定，仅限本机，支持离线激活验证

## 常见问题
### 升级会丢配置吗？

不会。重跑安装器或一行命令 -Fetch 覆盖升级，模型配置、知识库凭据与规则文件保留在独立数据目录。

### 遇到问题去哪反馈？

邮箱 support@aidooo.com，或 GitHub/Gitee 仓库提 issue；发版前有 154 项 doctor 自检与 123 条 smoke 断言保障质量。

### 序列号能换机使用吗？

序列号与本机设备指纹绑定，仅限本机；换机需联系支持（support@aidooo.com）转移。
