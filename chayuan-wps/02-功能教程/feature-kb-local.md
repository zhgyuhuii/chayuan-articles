# WPS知识库实操实操，WPS 插件怎么连本机知识库

「WPS 插件怎么连本机知识库？要填地址吗」——这个问题最近被问了好几次。答案不复杂：WPS知识库实操在察元AI文档助手里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先弄清楚它是什么

WPS知识库实操在察元AI文档助手里的形态一句话说清：自动发现本机察元AI OS 知识库：固定端口 52582 三级发现链（手动指定、上次缓存、并行端口梯），指纹校验通过后提示已自动接入并发现 N 个库；库列表运行时实时拉取，察元OS 侧增删库无需 WPS 重配。

下面直接进正题。

## 准备清单

- 已启用加载项，并已配置对话模型——知识库只负责检索注入，回答由所配模型生成；
- 本机察元OS（chatop）在运行：知识库对外服务固定 127.0.0.1:52582（仅回环监听、免密钥），不在运行时连不上；
- 察元OS 侧已有建好的知识库和「就绪」文档（见察元OS 教程《新建知识库》《上传文档与加载索引》）。

## 操作步骤详解

1. 打开知识库设置面板

1. 在哪：AI 助手窗格右上角「设置」＞ 主菜单「常规设置」＞ 子项「知识库设置」。
2. 看到什么：面板打开时静默自动扫描本机一次。若顶部出现黄色横幅「远程知识库集成当前已通过功能开关 kbRemoteIntegration 关闭……发送消息时不会触发知识库检索」，点横幅里的「立即启用」（默认就是开启的，一般不会遇到）。

2. 本机自动接入（通常零操作）

1. 发现成功：绿色提示「已自动接入本机察元 Harness 知识库(127.0.0.1:52582,发现 N 个)」，左栏「知识库连接」列表出现「察元 Harness 本机知识库」（模式标「Harness 本机」），右栏「可访问知识库」列出各库目录。
2. 手动重扫：点连接列表标题行的 ⌖ 按钮（悬停提示「自动发现本机察元 Harness 知识库」，扫描中显示「正在扫描本机服务…」）；已连接时提示「本机 Harness 已连接(…,N 个知识库)」，地址迁移过则提示「本机 Harness 地址已更新(…,N 个知识库)」。
3. 没发现时：红色提示「未发现本机察元 Harness 知识库服务(默认端口 52582),请确认 chatop 已启动」——先启动察元桌面版再回来扫。

3. 没检测到察元桌面版时的两条出路

1. 在对话输入区点书本按钮（悬停提示「选择知识库」），弹窗顶部出现引导卡「未检测到本机「察元桌面版」」：
    1. 点「前往官网下载桌面版」装好后，点「已安装？重新检测」；
    2. 或点「或前往设置手动配置远程连接」改连远程知识库。

## 怎么确认做成了

验证

1. 浏览器或终端访问本机服务（察元桌面版在运行时）：
    1. curl http://127.0.0.1:52582/health ＞ 返回 {"ok":true,"service":"chatop-kb",…}；
    2. curl http://127.0.0.1:52582/kbs ＞ 返回 {"ok":true,"kbs":[…]}，kbs 数组即本机库清单。
    3. WPS 侧：设置 ＞ 常规设置 ＞ 知识库设置，连接「察元 Harness 本机知识库」在列且标「Harness 本机」，选中后右栏能列出本机各库。
    4. 对话输入区点书本按钮，「选择知识库」弹窗左侧出现「察元 Harness(本机)」分组并列出各库。

## 谁需要这个功能

公文写作引用内部制度库；察元桌面版重启过/换过端口，想知道 WPS 侧要不要重新配置，打开「选择知识库」弹窗看到「未检测到本机『察元桌面版』」引导卡，不知道该怎么办；技术文档查询规范库。

用户常搜的问法：WPS 插件怎么连本机知识库？要填地址吗；为什么提示未发现本机知识库服务(默认端口 52582)。

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- AI 痕迹检查给的是疑似线索，疑似不等于定论
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 全文会发送给所配置的模型，涉密文档建议先切到本机离线模型

## 你可能会问

### 提示「未发现本机察元 Harness 知识库服务(默认端口 52582)」？

按序排查：① 察元桌面版是否已启动（没装见步骤 3 的下载引导）；② 浏览器开 http://127.0.0.1:52582/health 应返回 {"ok":true,"service":"chatop-kb",…}——打不开就是服务侧没起或端口被占（chatop-kb 端口被占时拒绝启动，去察元OS 侧看服务状态）；③ 能打开但 WPS 仍报错，点 ⌖ 扫描按钮重扫一次。

### 察元OS 里新建/删除了知识库，WPS 侧要重配吗？

不用。发现连接的库列表运行时实时拉取，重新打开「选择知识库」弹窗（或知识库设置右栏点「刷新」）即可看到最新库清单；服务地址变了也由发现链自动跟随（「本机 Harness 地址已更新」提示）。

### 本机连的是 52582，为什么扫描时还探测 52601、3080 这些端口？

那是端口梯的兼容尾巴：给「顺延时代」的旧装机和 dsh 会话形态留的兜底候选。新装机 52582 固定必中，后面的候选只是并行扫一遍不命中即弃，不影响使用。

### 知识库设置顶部出现黄色横幅说功能开关已关闭？

点横幅里的「立即启用」，提示「已启用远程知识库集成」即可。该开关关闭时连接和绑定仍可配置，但发送消息不会触发知识库检索。

### 删掉这条连接会怎样？

点垃圾桶图标「删除连接」＞ 确认卡「确认删除连接「…」？此操作不可恢复。」＞「删除」。删后再点 ⌖ 扫描按钮，发现链会重新把它建回来。

## 更多操作细节

4. 点「测试连通」看三步体检（可选但推荐）

1. 在哪：左栏点选「察元 Harness 本机知识库」连接，点闪电图标按钮（悬停「测试连通」）。
2. 看到什么：三步逐条打 /关闭 并带耗时——「服务地址」（GET /health）＞「本机服务」（GET /status，校验 chatop-kb 指纹）＞「知识库通路」（GET /kbs，末尾显示「N 个」）。任一步 关闭 时下方给对应提示：
    1. 第 1 步失败：「本机 Harness 服务不可达:请确认 chayuan-harness(chatop)已启动(默认端口 52582)」；
    2. 第 2 步失败：「端口有响应但不是 chatop-kb 服务,请重新自动发现」；
    3. 第 3 步失败：「服务在线但拿不到库列表,请检查 harness 侧 chatop-kb 插件状态」。

如果只记一件事：自动发现免配置。剩下的细节，照步骤节走就行。
