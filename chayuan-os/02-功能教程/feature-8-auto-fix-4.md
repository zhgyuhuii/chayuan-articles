# 智能体运维攻略：故障一键转智能体修复的关键点拆解

智能体运维是察元AI OS里使用频率很高的一项能力。它的「故障一键转智能体修复」这样工作：系统故障时自动组装诊断上下文+排障知识库并派单给智能体处理，是「AI 服务的现场」的代表性能力。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

系统故障时自动组装诊断上下文+排障知识库并派单给智能体处理，是「AI 服务的现场」的代表性能力。

从任务视角看，它对应的关键词是「智能体运维」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 遇到故障在诊断入口发起
2. 系统打包诊断上下文
3. 智能体给出修复方案或直接处理

## 适用场景

- 桌面异常自愈
- 模型服务排障

## 进阶技巧

- 诊断上下文可导出给人工支持

## 注意事项与边界

- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- Docker/云通道等进阶形态需要一定动手能力

## 常见问题
### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 什么是系统级 MCP？

系统提供 chatop MCP server（80+ 工具），智能体能开窗、嵌网页、跑终端、读写便签日历、换壁纸截屏等；配置自动同步到六家智能体。
