# arm64安装包选择装机指南

先说这篇能帮你干什么：arm64安装包选择是飞腾、鲲鹏这类机型动手装机前的第一道选择题，读完你能在察元AI OS上把包选对、装好、验完。文中步骤点到的按钮都按界面原文抄录。全文按装前确认、动手安装、装后验证的顺序展开，边界与限制也单独收了一节。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：国产 CPU 架构对应关系。

安装包从官方分发渠道获取；第三方镜像站的包来路说不清，别在那儿贪快。

## 选包前的架构自查

包选错架构，后面每一步都白费。开机先跑一遍 uname -m，记下终端打印的架构名，再对照安装包文件名里的架构字段——ChaAIOS-版本-架构.deb 这种命名把版本与架构都写进了文件名，两处对得上再动手下载。

一个容易踩的误区是只看操作系统名字：银河麒麟 V10 名下既有 x64 机型也有 arm64 机型，只凭系统名猜架构会猜错，判断依据永远是 CPU 本身，兆芯、海光归 x64 一边，飞腾、鲲鹏归 arm64 一边。

## 实操全过程

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

四步里最容易想当然的是第一步。手头机器不止一台时，别凭记忆分派架构，逐台跑 uname -m 更稳。第三步的首次启动初始化交给系统自己完成，期间不要中途断电打断它。第四步是国产环境的习惯做法，不依赖外部网络也能把对话跑起来。

## 装错了怎么补救

万一 dpkg 安装时报了架构相关的错误，按三步排查：先核对包文件名末尾的架构段与 uname -m 的输出是否一致；再确认拿到的是 deb 形态而不是其他平台的安装器；最后把银河麒麟 V10、统信 UOS 20 的版本要求重新对一遍。多数架构问题在这三步之内就能定位。排查时顺手把 uname -m 的输出和包文件名留个记录，后续要向管理员描述问题时能省不少来回。

## 其他平台装法速览

arm64 之外的平台装法一并附上，方便手里有多类设备时对照：

Docker 服务器：获取 docker-compose.yml；docker compose up -d 启动；浏览器访问默认 52584 端口得到多用户网页桌面。

Windows：取对应架构的 exe 安装器，双击安装，零额外依赖；首次启动创建本机账户，进入桌面。

## 国产平台要点

银河麒麟 V10 的 x64 机型（兆芯、海光）选 x64 包，arm64 机型（飞腾、鲲鹏）选 arm64 包；统信 UOS 20 用 deb 形态，arm64 真机已实测，这条路径走得通。龙芯暂不在支持范围内，选包前用 uname -m 把架构确认清楚。

## 装完后的第一件事

进桌面先做两个小测试：让对话应用用本地模型应一句话，再去应用商店刷新插件列表，两处都通就说明模型服务和网络链路都正常。挑这两个点是有讲究的：对话应用走模型服务，插件列表走网络链路，各测一条通路，哪个打不开就能把问题定位到对应环节，比盲目重装有效得多。

## 怎么确认做成了

- 进入桌面后先让对话应用用本地模型答一句话，答得上就算数
- 第一次启动的初始化要等 5 到 30 秒，这段时间放着别动它

判断标准就这两条：本地模型能回话、插件列表能刷出来，都满足就算装成了，不必再反复卸载重装求稳。

## 装机路上会碰到的几个限制

这几条是 arm64 机器装机后常被问起的限制，都属系统既有口径，不是装错了：

- 云端厂商的模型不随系统附带，调用的 API Key 要用自己的账号去申请
- Docker 云桌面与跨终端互联属于进阶玩法，对动手能力有要求，刚装完先别急着碰
- 8GB 内存的机器，对话模型一次挂一个就好，同时压多个复杂任务会吃紧
- 视频生成在本机没有对应能力，需要时走云端路由完成

## 全量包、轻量包与离线迁移

下载前想清楚要哪种包：全量安装包把模型权重一并打包，体积约 4.7GB；轻量包只有约 1GB，完整离线能力需要额外下载权重。怎么选可以看网络条件——机器在隔离内网、装完没机会联网补权重，直接上全量包一步到位；能联网的机器先装轻量包，用到再补权重也不迟。装好之后，插件支持启停卸载与离线安装，也支持 tar 包离线迁移。本地服务数量不少，全靠人盯不现实，自愈机制会让小故障无感恢复。

## 本机服务的统一出口

这套系统的本机服务有统一的出口口径：模型库按本机内存预算分层推荐，能跑、勉强、跑不动三档标记一眼可辨；OpenAI 兼容出口统一挂在 127.0.0.1:52581，智能体只配一个地址，代理只监听本机回环，跨机访问需要另行打通。进阶面板里还能对被代理模型做树形多选、把厂商路由加入或移出、签发吊销虚拟 Key、查调用审计。对装机场景而言，这一层不需要专门配置，装完即生效；知道出口位置的意义在于日后排障时，能分清问题出在本机代理还是远端服务。
