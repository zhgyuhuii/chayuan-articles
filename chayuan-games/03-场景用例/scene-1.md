# 大模型对比评测自己做：三局两胜定胜负

模型群里隔三差五就要吵一次：A 家的新模型和 B 家的老旗舰，到底谁强？榜单各说各话，跑分互有胜负，评论区盖两百楼也吵不出结果。其实这件事可以自己动手——大模型对比评测自己做，找一张棋牌桌，让两个模型面对面打几局，输赢摆在棋盘上，比搬谁的榜单都有说服力。察元竞技场干的就是这个活：把两个模型拉上同一张桌，你当观众兼裁判。

## 这件事原来的难处

想自己比两个模型，传统路子每一步都是坎。

先说要写脚本。你得自己接两家 API，处理两套鉴权、两种限流策略，再写调度让它们轮流出招，还要判断对局什么时候结束。光是输出格式对齐就能耗掉一个晚上，做完也还算不上评测，只能算跑通。

再说比什么。拿题库考模型，考的是记忆与问答，两家可能都考九十多分，差距看不出来；而真实决策能力——算子力、布防、收官、关键时刻敢不敢押——题库里压根没这道题。

还有判分问题。模型自己宣布「我赢了」不算数，你需要一个铁面裁判，每个回合按规则核对，谁都不许赖账，谁出招违规也不许混过去。

榜单本身也有黑箱。同一份评测，换个题目池、换个打分口径，名次就能颠倒过来；你不知道模型有没有见过题，也不知道采样了多少任务。透明度缺失，是这类争论永远没有结果的根本原因。

## 用察元竞技场怎么做

第一步，配两个选手。装好察元竞技场（官网 aidooo.com 或开源仓库 github.com/zhgyuhuii/chayuan-games 下载，Windows、macOS、Linux 都有安装包），进设置 ＞ 模型配置。内置 85 家厂商目录，点选你要比的厂商，填上各自的 API Key，点「测试连接」确认 Key 可用；想省事就点「获取模型」，它用你当前填写的地址与 Key 实际请求一次，把这家账号下可用的模型全列表拉回来，勾选入库就行。

第二步，定赛制。这里说的三局两胜不是应用内置规则，而是你自己定的赛制约定：先约好打三局，谁先拿下两局算这轮占优。玩法建议从五子棋起步，规则简单、单局短、胜负干脆；想看深度推演换中国象棋，想看心理博弈换德州扑克。开机机观战模式，在批量选模型里点选两个选手，开打。

第三步，当好看的裁判。对局室默认匿名观战，座位只显示玩家A、玩家B，谁是谁要到终局才由对局引擎揭晓，省得你先入为主。每一手的思维链气泡实时滚动，两个模型各自的盘算全程可见；每手的延迟与 token 用量摆在名牌旁，谁在长考、谁秒出，一眼分明。

第四步，看数据别只看输赢。每局自动生成形势曲线，谁压着谁打、哪一手陡然翻盘，一条线看清；打完进复盘，逐手的妙手与失误标注都在，为什么赢、为什么输，翻一遍就明白。成绩会进 TrueSkill 天梯，打得越多，积分越有参考价值。

第五步，扩大样本再下结论。三局两胜只能定方向：这一轮谁占上风。要下「谁更强」的结论，请把局数往上加——十几局能看出风格差异，几十局起步才谈稳定性。换个玩法再跑一轮，完全信息与不完全信息各来一遍，结论才立得住。中间遇到模型 API 限流，应用会自动退避重试，偶尔出废招也有代走兜底，不会卡死你的评测现场。如果两个模型实力确实接近，别硬分高下——打成平手本身就是有价值的结论，说明在你的用法里两者可以互换。

## 小样本对局怎么读才不翻车

打完了别急着发结论，几条读法能让你少踩坑。

分清「这一局」与「这个模型」。单局的胜负归单局，模型的能力归一串对局。看结果先看风格：谁爱攻谁爱守、谁优势时稳得住、谁一落后就乱走，这些比一个比分更有迁移价值。

把先后手因素摆平。五子棋、象棋里先手都占便宜，三局可以互换先后再打，别让座次背锅。

留意学习曲线。竞技场有开局记忆，模型会避免在同型局面里重复犯错，连打多局时谁的纠错更快、谁的进步曲线更陡，这也是对比的一部分。

结论写清楚条件。你要发的不是「A 比 B 强」，而是「在某种玩法、某几局样本、某个时间段下，A 对 B 占优」——条件写全，读者才知道这份对比的边界在哪。

## 适合谁、不适合谁

适合的人：在模型群里吵谁强、想自己拿证据的人；给自己挑主力模型、看腻了营销通稿的使用者；要给团队选型、需要拿一手对局材料去说服领导的工程师。

不适合的人：想把三五局结果当论文数据的研究者——小样本说明不了学术意义上的优劣；以及只想看现成排名、不愿意动手的人，这里没有官方榜单，一切结论靠你自己拉上桌打出来。

顺带一提，这套方法还能反过来用：在群里发起一场公开擂台，规则你定、模型你选、结果大家围观，讨论度比转发一百次榜单截图都高。

## 常见疑问

### 三局两胜是应用内置的规则吗

不是。竞技场提供的是对局环境与代码裁判，三局两胜是你自己定的赛制约定。打几局、怎么算赢、按什么玩法算，主动权全在你手里。

### 要不要告诉模型对手是谁

不用操心。默认匿名观战之下，两个模型各下各的棋，座位上只有玩家A、玩家B这样的代号，你不看终局揭晓，自己也未必猜得出谁是谁。

### 打多少局才够下结论

三五局只能看方向，十几局能看出风格差异，几十局起步再谈谁更稳。样本量不足的时候，任何「谁碾压谁」的断言都别当真，包括你自己打出来的。

### 费用怎么算

软件本身 MIT 协议开源免费；两个模型对打消耗的是你向厂商购买的 API 额度，局数越多、模型越大，花得越多。挂 Ollama 本地模型对打则零成本，断网也能玩。

### 我自己能下场当第三方吗

能。人机局里你亲自执子，中途还可以在 AI 接手与人工接管之间随时切换，下一手生效；人类挑战者的天梯战绩单独统计，不与模型混在一张榜里。

榜单是别人跑出来的分数，棋盘是你自己看出来的判断。与其在评论区替厂商站队，不如花一个晚上，让两个模型当着你的面给答案。三局两胜定不了真理，但足够帮你定下来：下一年你的主力模型该填哪家 Key。
