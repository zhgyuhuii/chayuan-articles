# 手机访问：顶栏手机图标打开共享面板

手机访问的麻烦不在功能本身，在于信息散。远程指导、会议室投屏、手机救急，一套机制全覆盖。这篇把它收拢成一条能照着走的路径。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：手机浏览器连回桌面。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 做完后的验证

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 它的局限也要说清楚

功能归功能，这几个边界先摆清楚：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

## 接着回答几个常见问题

### 二维码/链接位置一直转圈，或显示「网络异常」？

出码前产品会确认云端（aidooo.com）可达，探测波动会自动重试。先检查本机外网；持续「网络异常」可点「停止分享」稍后重开。

### 访客输对口令也被拒「访问口令不正确」？

口令随房间重置而更换——分享者若重置过链接，旧口令全部作废，索要新链接+新口令。连续输错会触发「尝试次数过多，请一分钟后再试」，等一分钟再输。

### 分享链接安全吗？

「分享 Harness 页」的链接即钥匙：打开的人可以完整操作本机 Harness（会话、文件、终端与智能体指挥权），只发给信任的人；不用时点「停止分享」立即失效。整桌共享房间另有 9 位口令门，访客必须凭口令入房。

## 更多操作细节

第 1 步 · 打开共享面板（顶栏手机图标）

1. 顶栏右侧手机图标（悬停提示「分享 Harness 页」），点开桌面同源面板；分享相关状态时图标右上出现状态点（绿=分享中且有访客在线，橙=分享中暂无在线访客）。点面板外任意处关闭。
2. 2026-10-14 产品改版后，面板只呈现「分享 Harness 页」一个板块（整桌镜像「远程分享/远程控制」入口已隐藏，能力保留；详见常见问题 Q5）。

## 更多操作细节

第 2 步 · 分享 Harness 页（把本机对话页给外网设备看/操作）

1. 面板打开时该板块默认展开，且未开启会自动开启（首次稍等，出码前显示加载圈）；
2. 看到什么：板块标题「分享 Harness 页」，右侧绿色「分享中」徽章与「收起/「展开」按钮；中间是二维码（微信/浏览器扫码均可）与链接框（形如 https://aidooo.com/h/〈房间号〉）；底部红色「停止分享」按钮；
3. 对方扫码或打开链接：看到的是本机 DeepSeek Harness 的真页面（非投屏），可直接对话与操作；链接有效期内可多人同时打开、实时同步（一边发消息其他端同步刷新）；你点「停止分享」后链接立即失效；
4. 链接框点击即复制，旁边「链接」按钮等效（复制后短暂显示「已复制」）；
5. 云端不可达时显示红色「网络异常」（后台自动重探，恢复后码/链接自动回来）；此时只能先「停止分享」稍后再试。

## 更多操作细节

第 3 步 · 设置 ＞ 远程访问（看房间与连接终端）

1. 打开 设置 ＞ 远程访问，页面标题「远程连接」，说明行「当前共享房间与连接中的终端（5 秒自动刷新）。管理操作（授权/踢出）在分享面板进行。」；
2. 看到什么：状态卡顶部一个圆点 + 「共享中」或「未共享」（共享中时旁边显示房间号前 8 位）；下方逐行列出除你（分享者）以外的房间成员——每行：绿/灰在线圆点、成员昵称、角色标签（绿色「控制中」=可操作，灰色「只读」）、「在线/离线」；
3. 没有成员时显示「暂无终端连接」；页面打不开时显示「share 服务不可达」。
4. 注意：这张卡显示的是整桌共享房间的状态；只开「分享 Harness 页」时它显示「未共享」属正常。

## 更多操作细节

第 4 步 · 认识三种角色（整桌共享房间）

分享者的管理动作（共享进行时）在桌面右侧常驻的「远程用户」清单完成：

1. 每个成员行：昵称 + 角色徽章（「控制中」/「只读」）+「授予操作权」（对只读成员，变「降为只读」）+「踢出」（红色，点击弹确认「把 〈昵称〉 移出房间？其身份将被拉黑，重置链接前无法再进入。」）；
2. 访客点「申请操作权」时，对应成员行高亮并出现「同意控制」/「拒绝」按钮（30 秒未决自动消隐）；
3. 清单可折叠成右缘一个小圆点（角标=在线人数，有申请时橙色呼吸提醒）；访客发来的聊天消息也在清单里行内显示、可直接回复；
4. 整桌共享停止或你不是分享者时，这个清单不显示。

| 角色 | 谁是 | 能做什么 |
|---|---|---|
| 分享者（host） | 发起共享的这台机器 | 看到一切；逐个授予/撤销操作权、踢出成员、停止共享 |
| 可操作（editor，桌面清单里标「控制中」） | 被分享者授权的访客 | 查看并操作分享者的桌面 |
| 只读（viewer，新成员默认） | 普通访客 | 只能看，不能操作；可申请操作权 |

## 更多操作细节

第 5 步 · 访客侧：加入共享桌面（拿到链接的人这样操作）

1. 浏览器打开分享者给的 /s/〈房间号〉 链接，出现「加入共享桌面」门：填「昵称（可选）」与「访问口令（9 位数字）」，点「加入」（连接中显示「连接中…」）；
2. 进入后看到「已加入共享桌面」横幅与自己的角色徽章：只读时提示「你处于只读模式：可以看到一切操作，但无法操作。」，可操作时提示「分享者已授予你操作权。」；
3. 只读访客可点「申请操作权」（已申请显示「已申请，等待分享者授权…」），等分享者在右侧清单里「同意控制」；
4. 左侧「在线成员」列表可看房间内所有人及角色；随时点「退出共享房间」离开。

如果只记一件事：三级权限角色。剩下的细节，照步骤节走就行。
