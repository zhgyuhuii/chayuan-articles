# 一文分清Agent OS

关于Agent OS，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是Agent OS

Agent OS这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

这个叫法近两年被混用得厉害：有人拿它指跑智能体的编程框架，有人指连桌面带应用的整套系统。本文取后一种口径，判断标准第一段已经给出——断网了它还能干什么。文中各项口径整理自官方文档，写稿时逐一核对过，对应的版本说明放在文末。

## 核心口径一张表

| 口径 | 内容 |
|---|---|
| mcpTools | 86 个 MCP 工具（2026 年 10 月实测） |
| kbPort | 52582（知识库对外服务，固定端口） |
| storeCats | 插件、技能、MCP 插件、智能体、技能包五大类 |

这三行连着读才有意义：工具数量决定智能体实际能动手的范围；端口固定，意味着知识库服务可以被外部程序稳定对接；商店分五类，说明扩展来源被划得比较清楚。评估任何一套 Agent OS，工具面、服务稳定性、扩展口径都是绕不开的三问。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 多用户账号管理：管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；
- 桌面环境总览：顶部菜单栏、底部 Dock（放大动效、自动隐藏、左右停靠）、访达与废纸篓。

## 装机前先对的四条边界

- 内存只有 8GB 的机器，建议一次只加载一个对话模型，复杂任务会受限制
- 龙芯平台暂未支持；视频生成不在本地做，走的是云端路由
- 调用云端厂商的模型，API Key 要自己准备
- Docker 云桌面、跨终端互联属于进阶形态，得备点动手能力

这几条都不挡主线使用，但选型阶段心里有数，总比装完才发现强。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 还有疑问，先看这两条

### 断网状态下 Agent OS 还能干活吗

能干的活取决于模型放在哪：本地大模型断网照样对话；要用云端厂商的模型就得联网，API Key 自备；视频生成统一走云端路由，离线做不了。

### Agent OS 的数据放在哪里

主要落在本机：录音转写在本地完成、不上传；敏感操作写进 audit.jsonl 审计日志，可回放检查；API Key 经 safeStorage 加密存储。要格外留心重装这件事——三条路都不满足时只能清数据重装，恢复密钥务必提前生成。

## 一句收束

Agent OS 值不值得上手，不用问别人的评测：把这篇文章的口径与边界逐条代入你的设备、网络与工作流，匹配度自然见分晓。

## 桌面上的三处细节

右键桌面能直接录制屏幕；独立小窗便签支持新建、置顶、折叠、换色，图片视频附件也能贴上去；内置终端跑的是真实 shell，会话持久、环境延续。智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端就是最直接的证明。把桌面细节单列出来，是因为一套 Agent OS 的成色恰恰藏在这类地方：右键、便签、终端若只是摆设，「智能体操作桌面」就停留在口号；能录屏、能贴附件、能保持会话，才说明桌面通道是真的打通了。

## 安全与代理的另一层设计

远端调用以远端访客身份过对端权限门并留审计；模型库按本机内存预算分层推荐，能跑、勉强、跑不动三档标记；代理只监听本机回环，跨机访问需要另行打通。进阶面板的颗粒度更细：被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询都收在一起。

## 接口口径：全机一个出口

模型接入收敛为本机统一的 OpenAI 兼容出口（127.0.0.1:52581），智能体只需配一个地址；OpenAI 风格与阿里百炼风格 API 自动适配；本机 MCP HTTP 服务走回环，免 token。

## 和同门软件的关系

它并非单打独斗：与察元OS 同库同源；Dock 栏可以直接唤起内置的办公套件，文档、表格、演示都在线编辑，桌面与应用之间不必来回切换上下文。

## 首次登录的四步向导

头一回进桌面会自动弹出四步向导：先把模型代理是全机统一出口这个概念讲明白，再选默认对话模型。不少人卡在第一步，症结不在会不会用 AI，而在被各家智能体各配一遍模型劝退，概念页解释的正是模型代理机制。

## 离线内网怎么应对

插件支持启停卸载、离线安装；装了什么、开了什么，总账页面一查便知；离线环境靠导出导入搬迁，tar 包可以离线迁移；本地转写不上传录音，会议速记两件事一次做完。

## 记忆与默认应用这对黏合剂

换个智能体接班不用重新自我介绍，记忆全机共享，这是系统级的黏合设计；工作区默认打开代理（智能体），扩展名默认应用覆盖表让特定文件类型默认交给智能体处理，双击即用 AI；智能体还能在运行时定义并挂载新插件，和它说一句「给我做个每晚汇总新闻的应用」就行。

Agent OS 的链路到这里拆解完毕，实际动手时若在某一步卡住，回头翻翻上面那两条疑问，多数坎都藏在里面。
