# 为什么说察元OSDock 设置被低估了？

关于察元OSDock 设置，这篇的答案会得罪人：这不是噱头，但也不是人人必需。

先把背景交代清楚。这个问题的来源很实际。贴边的判定位置跟着 Dock 位置走：Dock 在底部就贴屏幕底边、在右侧就贴右缘。「自动隐藏（鼠标贴边呼出）」勾选框：勾上后 Dock 平时收起、鼠标贴到所在屏幕边缘时浮出。设置页这个勾选是「隐藏/常驻」两态；更细的三态在 Dock 空白处右键 「显示与隐藏」：「图标放大效果（悬停放大）」勾选框（默认开）：鼠标扫过 Dock 时图标放大的鱼眼效果，关掉则无放大。这不是玄学，是写进文档里的行为。

说到底，工具是拿来用的，不是拿来评测的。

回到察元OSDock 设置的实际使用，我的建议是分两步走。第一步只跑主链路，把最核心的那件事从头到尾做通，不做任何定制；第二步才是按自己的习惯调配置。顺序反过来的人，大多数卡在半路就放弃了，然后得出一个「不好用」的结论，其实是学习路径错了。

### 先看它的定位

跨设备协作默认全部关闭，想开哪类授权自己开，开了也都留痕。点 Dock 上的「设置」图标打开设置窗口。

Dock 空白处右键 「恢复已隐藏的图标」；或在「应用管理」 应用 页里重新显示/发送快捷方式到桌面。设置 桌面与 Dock 分区管四件事：Dock 停靠位置（底/左/右）、自动隐藏、图标放大效果与图标大小，以及「开机自动打开 Harness」。

说到底，工具是拿来用的，不是拿来评测的。

这个问题后台问得不少：「窄视口自动隐藏」和「始终隐藏」有什么区别？ 桌面主程序形态会等对话服务就绪后再开窗（避免开出空壳窗口）。

### 它做对的那件事

如果开了「始终隐藏」后忘了位置，到 设置 桌面与 Dock 取消「自动隐藏（鼠标贴边呼出）」即可强制常驻。「始终显示」（默认）：Dock 常驻占位。Dock 自身的右键菜单还有显示隐藏三态和图标管理。顺手提一句，别跳过。

它与「图标大小」是两回事——前者管悬停时的动态放大，后者管 Dock 的基础图标尺寸。屏幕窄（如竖屏、小窗口）想让 Dock 靠边或藏起来腾空间。觉得 Dock 图标太小/太大，或不喜欢悬停放大效果。有人觉得这步多余，我持相反意见。

「Dock 可以放到屏幕左边/右边吗？怎么自动隐藏？」「任务栏图标能调大一点吗？那个悬停放大怎么关？」第 4 步 · Dock 图标管理（顺带总览）。这一点挺难得，很多同类产品只在宣传页里讲。

一个绕不开的问题：共享桌面会话里改 Dock 设置，对方会跟着变吗？ 「开机自动打开 Harness」勾选框（默认关）：勾上后，登录进桌面时自动打开 DeepSeek Harness 会话窗口（桌面主对话窗）。

### 代价与边界

不勾则开机不弹，需要时自己点 Dock 里的 Harness 图标。前者只在窗口/视口较窄时收起（宽屏正常常驻），后者无条件一直隐藏。都在 Dock 空白处右键 「显示与隐藏」里选。「怎么让 Harness 开机自动打开？」

还有一个判断角度常被忽略：看察元OSDock 设置失败的时候是什么样子。顺的时候大家都差不多，差别全在出问题的那一刻，报错信息是否说人话、能不能原地重试、数据会不会丢。这些细节官方文档很少写，但恰恰是它们决定你用一个月之后还愿不愿意继续用。

空白处右键：「停靠位置」「显示与隐藏」三态、「恢复已隐藏的图标」（把此前隐藏/移除的图标找回来，后缀数字为可恢复数量）、「应用管理」。桌面形态（察元AI OS）、非锁屏状态（锁屏下设置不可达）。无其他依赖；所有设置即时生效并持久化。这个细节不影响功能，但决定你愿不愿意一直开着。

评论区肯定有人想问：误隐藏了 Dock 图标怎么找回？ 左栏分区列表点「桌面与 Dock」，右侧两张卡：「Dock 位置」与「Dock 行为」。

把反方观点也说全，才算讲道理：等价快捷入口：在 Dock 空白处右键 「停靠位置」 「左侧停放」「右侧停放」「底部停放」（当前项带 ）。「窄视口自动隐藏」：窗口窄时才自动隐藏。Dock 最右端是废纸篓：左键打开废纸篓应用，右键「打开废纸篓」「清倒废纸篓」，拖文件上去即删除进回收站。这个数字记得住，用的时候就不慌。
