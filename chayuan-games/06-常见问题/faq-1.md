# 察元竞技场收费吗：软件免费与模型费用全说清

聊大模型应用，很多人开口先问钱。察元竞技场收费吗？这个问题要拆成三笔账：软件本体一笔、模型调用一笔、本地推理一笔。三笔账性质完全不同，混在一起谈，就容易误会成「要么全免、要么全收」。三笔账算清楚，你花没花、花给谁、花在哪一层，就都有了答案。先把结论放上桌：软件本体 MIT 协议开源免费，云端模型的调用费用由你自己向厂商支付，Ollama 这类本地推理零成本。下面按这三笔账，把 11 款玩法（2026 年 11 月，版本 0.1.0）背后的费用逻辑一次说清，顺带回答几个高频追问：钱付给谁、用量在哪看、预算怎么控。

### 察元竞技场收费吗？软件本体要不要掏钱

不掏钱，软件本体按 MIT 协议开源免费。安装包从官网 aidooo.com 或开源仓库 github.com/zhgyuhuii/chayuan-games 拿，装上就能用，棋类五款、扑克三款、麻将三款，一共 11 款玩法分组摆在大厅里，全部直接可玩，没有玩法解锁，没有会员等级，也没有内购。从下载到开局，这条链路上你不需要输入任何付款信息。MIT 协议给的不止免费：代码公开，你可以自己编译、自己改，拿去搭自己的对局环境都在协议允许范围内；开源也不等于做做样子，源码、协议、构建方式都摆在仓库里，谁都可以查。另外别把「开源免费」误会成「没人管」，它和察元AI OS 内置的竞技场引擎层逐字节同构，是正经在维护的产品线。

### 模型调用的钱付给谁，竞技场赚差价吗

钱付给你所选模型的厂商，竞技场不经手也不加价。它内置 85 家厂商目录，DeepSeek、智谱 GLM、通义千问 Qwen、Moonshot Kimi、百度文心、讯飞星火、OpenAI、Anthropic Claude、Google Gemini 都在名单里，你填的是各家自己的 API Key，调用产生的费用按各厂商计费规则从你的账户里扣。竞技场在这里只负责把请求送到厂商接口，不转售、不代收，自然谈不上赚差价。你还可以手填任何 OpenAI 兼容端点，OneAPI、NewAPI 这类中转也能接，走中转就按中转商的规则结算，竞技场照样只当传话人。顺带说一句，配置模型本身不产生费用，「测试连接」和「获取模型」只是一两个轻量请求，校验 Key、拉模型列表，开销可以忽略。

### 用 Ollama 本地模型真的零成本吗

真的零成本，这条写在产品的费用口径里。Ollama、LM Studio、Xinference 这类本地推理引擎接入时免 Key，模型跑在你自己的电脑上，没有 API 账单，断网照样对弈，模型权重的下载也不另收费，Ollama 的模型库按官方页面标注的体积拉取即可。代价不在钱上，在机器上：模型文件吃内存吃算力，大参数模型对硬件要求不低；而家用机器跑得动的本地模型参数量普遍偏小，出招质量与云端强模型有可见差距。省下账单的同时，你得接受棋力和流畅度上的折扣，这笔交换划不划算，取决于你玩对局是为了练手还是较真。

### 挂机跑一晚锦标赛，钱花在哪儿

花在你所选云端模型的 token 上。锦标赛是多模型循环赛，排程自动生成，模型越多、轮次越多，消耗越大；开深度思考档还会进一步放大用量。竞技场不会替你扣一分钱，但厂商按实际用量计费，一晚上烧掉多少额度，取决于你选了几个模型、什么玩法、思考档开到哪一档。顺便澄清一个误会：竞技场不收抽成，也不搞充值返利那一套，账单和它无关，和厂商有关。想挂机的人建议先小规模试一轮，看看对局室里的用量表现再放量，别头一晚就拉满阵容。

### 每一手花了多少 token，在哪里看

对局室里直接看。每手的延迟和 token 用量都摆在对局过程中，你看模型落子的同时就能知道这一手花了多少，整局累计下来心里有数。这个数字只展示、不换算成金额，因为各家厂商定价不同还经常调整，竞技场不做换算，免得给出误导性的估价。有人问为什么不直接显示金额，道理就在这里：估价这件事，做一次错一次，不如不做。想知道实际花了多少钱，拿用量对照你所用厂商的价目表，或者直接去厂商控制台翻账单，两边一对就是答案。顺带一提，复盘里的逐手标注和形势曲线跟费用无关，但能帮你判断哪些对局值得花这个钱。

### 有没有隐藏收费或者玩法解锁

没有。MIT 开源、API 费用自付、本地推理零成本，这三条是对外一致的费用口径，不存在「免费版阉割玩法、付费版解锁全部」的设计。日麻立直在大厅里是隐藏入口，但那是入口藏得深，不是收费墙，引擎完整可用，找进去就能玩。也别把察元AI 家族其他产品线的定价安到竞技场头上，那是另一套产品的事，竞技场自己的账很简单：软件不要钱。真想确认，打开设置把每个页面翻一遍，你找不到任何充值入口或订单页面，这比任何承诺都有说服力；代码也在开源仓库里摆着，随时可以自己验证。

### 想把模型费用控住，有什么务实做法

三条路子。其一，能用本地模型的场景就用 Ollama，练手局、调试局、随手玩的局全零成本，试错不心疼；其二，云端强模型留给关键对局，比如你真想比较两家模型的水平、想看高质量思维链的时候再请上来；其三，善用 token 用量展示，跑锦标赛之前先单开一局感受单局用量，再决定循环赛的规模和挂机时长。费用这东西，看得见才谈得上控制，这正是竞技场把用量直接摆在对局室里的用意。

收费问题聊到最后，其实是两类成本的问题：软件成本归零，模型成本透明。前者由开源协议保证，后者由用量展示和厂商账单兜底，谁都不糊涂。至于值不值，取决于你想不想亲眼看大模型上桌对弈。想，装一个晚上就回本；不想，一分钱也不用花，这个买卖的风险算是被设计兜住了。免费的另一个好处是卸载无负担，不合口味删掉就走，没有沉没成本；先本地后云端，也是不少人的上手顺序，免费跑通流程，再决定要不要充值。
