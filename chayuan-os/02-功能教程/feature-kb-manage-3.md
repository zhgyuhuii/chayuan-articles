# 批量加载落地记：季度清理过时文档

「知识库里怎么批量删除文档」——这个问题最近被问了好几次。答案不复杂：批量加载在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 为什么值得了解

要一次加载、下载或清掉一批文档，季度清理过时文档；批量补载新资料，想删掉过时资料，并确认索引里不会再命中它。

## 具体怎么操作

状态徽标的颜色含义（两种视图一致）：绿色「就绪」、红色「失败」、黄色「未加载」，进行中的「解析中/向量化中」为主题色并跟百分比数字。视图只影响显示方式，不影响任何数据。

1. 顶部工具行：中栏最上方一行是「上传文件」「上传文件夹」两个按钮＋右侧一个双图标视图切换（列表图标 / 卡片图标，只显示图标不带文字，点谁切哪边）；下一行是搜索框「搜索文档…」＋排序下拉（「最新」「名称」「大小」三档）＋行尾「全选」勾选框（悬停可见提示）。
2. 切换视图：
    1. 列表视图（默认）：每行＝勾选框（悬停显示）＋文件图标＋文件名＋第二行「来源路径 · 大小 · 日期」＋右侧状态徽标＋行尾悬停操作图标簇；加载中的行下方带进度条，失败的行下方带红色错误原因；
    2. 卡片视图：网格卡片（每张）＝左上角勾选框＋大图标＋两行文件名＋来源路径或大小＋状态徽标（＋进度条/错误），点卡片即勾选，操作图标簇在卡片右上角。
    3. 搜索过滤：在「搜索文档…」框输入文字，按文件名或来源路径即时过滤（不区分大小写），不用回车。库非空而过滤结果为空时，列表显示「没有命中——换个说法或检查嵌入模式是否开启。」。注意：「全选」与批量操作都只作用于当前过滤后可见的文档——先过滤再全选，是「只处理某类文件」的实用做法。
    4. 排序：下拉三档——「最新」（默认，按更新时间降序，刚动过的排前面）、「名称」（名字字母序）、「大小」（从大到小）。过滤与排序可同时生效（先过滤出可见集合，再按所选方式排）。
    5. 文件夹分组：用「上传文件夹」导入的文档按来源路径自动分组——组头＝折叠箭头＋文件夹图标与路径＋组内数量＋组级勾选框（整组全选/半选/全不选三态）；散文件归入「独立文件」组排在最后；只有一组且全是散文件时不显示组头。点组头箭头折叠/展开该组，折叠组的文档仍在数据里、只是不显示。
3. 选择文档：悬停文档行/卡片出现勾选框，点行（卡片）即选中/取消；组级勾选整组；「全选」勾选当前可见全部；已有选中时所有勾选框保持常显。选中后列表上方出现批量操作栏，按状态分三段：
    1. 有选中：「已选 {n} 项」＋「加载」（对选中项触发解析向量化，只有其中「未加载/失败」的会被入队）＋「下载」（逐个触发浏览器下载原文件）＋「删除」（弹确认）＋「取消选择」；
    2. 无选中、库里有待加载文档：「{n} 个文档待加载」＋「全部加载」；
    3. 库里有加载中的文档：「加载中 {n} 项」＋「全部取消」。
4. 单文档操作（悬停行尾/卡片右上角的图标簇，从左到右）：
    1. 加载（悬停提示「加载（解析并向量化）」）——仅「未加载/失败」状态显示；
    2. ■ 取消加载（悬停提示「取消加载」）——仅「解析中/向量化中」显示；
    3. 下载（悬停提示「下载原文件」）——任意状态可用，走浏览器下载、保留原文件名（中文名不乱码）；
    4. 删除（悬停提示「删除文档」）——任意状态可用。
5. 删除与确认：
    1. 单删：点 后行内（卡片视图下确认条覆盖整张卡片）出现红色确认条「删除该文档及其全部向量？」，右侧「删除」「取消」两个按钮，点「删除」才执行；
    2. 批量删：批量栏点「删除」后确认条显示「删除选中的 {n} 个文档及其全部向量与原文？」；
    3. 执行内容：正在加载的文档先中止任务，然后依次清掉每个文档的向量、全文索引、分块、库内记录，以及磁盘上的原文件——删除后检索立即不再命中，原文件也无法再从应用内下载。

上手按顺序做：（第 3 个切入角度）

1. 双视图切换
2. 批量操作
3. 删除彻底不留残骸
4. 场景验证：季度清理过时文档
5. 场景验证：批量补载新资料
6. 串联场景：官网下载全量离线包（含五件套权重，约 4.7GB）

## 关键能力点

- 双视图切换
- 批量操作
- 删除彻底不留残骸

## 它的局限也要说清楚

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 你可能会问

### 删除能撤销吗？

不能。删除会连磁盘原文一起清掉，没有回收站。删前可用「下载」（单篇 或批量「下载」）把原文备份到本机再删。

### 批量「加载」是一次全跑吗？

每个库一条串行队列，选中的文档逐个依次处理；界面按行各自显示进度，等不及可以点 ■ 或「全部取消」。

### 为什么有的行没有 加载图标？

 只对「未加载/失败」状态的文档显示；已「就绪」的文档无需再加载，正在加载的显示 ■（取消）。

## 更多操作细节

验证

1. 删除一个文档后：列表少一行，左栏该库的文档计数同步减 1；
2. 删除前先点 「下载原文件」，对比下载文件与原文件大小一致——备份到位；
3. 删除后到右栏「检索」输入该文档特有的关键词：不再命中（向量与全文索引已一并清理）。
