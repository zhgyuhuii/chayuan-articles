# 本地LLM部署操作详解：真实界面步骤与常见坑

被本地LLM部署折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI OS为准。

## 它是什么，为谁服务

从内置「模型库」把本地大模型权重下载到本机：每行按本机内存预算给出 /△/关闭 分层推荐；下载走多源自动换源（ModelScope 主源 ＞ hf-mirror / AI快站 镜像 ＞ HuggingFace 官方垫底）、支持断点续传；下载完进「我的模型」，点「启动」加载进内存即可被对话 / 知识库 / 智能体使用，数据不出本机、断网可用。

断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。

入口、步骤、验证三段看清，这事就顺了。

## 操作前的准备工作

- 联网。下载走多源自动轮换：ModelScope（主源，含其 API 通道）＞ hf-mirror.com / hf-mirror.net / aifasthub.com（AI快站）镜像 ＞ HuggingFace 官方垫底，国内网络可直接下载。
- 磁盘空间：下载前自动预检，需要约「模型体积 × 1.05 + 200MB」余量；不足直接报「磁盘不足：还需约 XGB，当前可用 YGB」。
- 权重全机一份：页面上有固定提示「模型全机只保留一份：下载/删除影响本机所有用户」。
- 不想下载？ 完整安装包随机播种的「装机即用」五件套开箱即可加载：Qwen3.5-4B Q4_K_M（对话）、BGE-M3（嵌入）、BGE Reranker v2 M3（重排）、Piper huayan 中文语音（语音合成）、Whisper Small（语音识别）；未带模型包的安装形态，模型库中有同量化的 Qwen3.5-4B 在线档可补装。
- 完全离线的机器不走本教程，用「＋ 添加模型」按路径导入本地权重（导入不复制文件），离线放置与直链下载另见后续教程 M4（离线导入本地模型权重）。

## 操作步骤详解

1. 进入本地模型页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）列出十一类导航：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 视频解析 / 生图 / 视频生成 / 语音识别 / 语音合成。进页默认选中「对话」。右栏页面自上而下：状态条 ＞ 服务地址条 ＞ 「模型全机只保留一份」提示 ＞ 「我的模型」（已安装）＞ 「模型库」（未下载）。同一模型只会出现在其中一个分类页。

2. 认识状态条（顶部）

1. 健康灯 + 文字：「正常」（绿）/「引擎异常」（黄）/「不可达」（红）/「已停用」（灰）/「引擎缺失」（黄）；
2. 实例计数：「N 个模型运行中」或「无运行中的模型」；
3. 「空闲自动卸载策略」下拉（悬停提示「空闲自动卸载策略」）：「自动卸载：关 / 5 / 15 / 30 / 60 分钟自动卸载」，默认 15 分钟；
4. 「重启全部」「全部关闭」：点击后行内出现红色二次确认条——「重启全部运行中的模型？」/「关闭本地模型服务？全部实例将卸载（厂商模型不受影响）」，点「好」执行、「取消」收回；
5. 服务被停用时，此处只剩「启动」按钮。

3. 服务地址条（第二行）

显示本分类的对外端点，如对话类为 http://127.0.0.1:52581/v1/chat/completions；「复制」（点击后变「已复制」）、「配置帮助」展开 curl 示例。各分类端点：对话/代码补全/图像理解 /v1/chat/completions、嵌入 /v1/embeddings、重排 /v1/rerank、决策 /v1/systemone、语音识别 /inference（生图/视频生成/语音合成走系统内置调用，不显示此条）。底部注：「免 key 直连：本机任意智能体不带 key 即可用（审计归因 anonymous）…」。

4. 按 /△/关闭 挑模型（模型库区）

「模型库」标题旁有图例：「本机推荐 · △ 可跑，内存吃紧 · 关闭 超出本机内存（仍可下载，加载时会被守卫拦截）」。每行结构：

1. 行首彩色徽标： 绿 / △ 黄 / 关闭 红（判定规则：模型内存 + 2GB 余量 ≤ 当前可用内存 = ；不超过物理内存 − 2GB 系统保留 = △；超出 = 关闭）；
2. 模型名（beta 模型带黄色 beta 标）；
3. 第二行参数：「参数量 · 上下文 · 下载体积 · 运行内存」，如 4B · 32K · 2.6GB · 3.3GB RAM；
4. 行尾动作按钮（见下一步）。

5. 开始下载

点行尾「下载 <体积>」（如「下载 1.6GB」）：

1. 进行中：按钮变「取消下载」，行下出现进度条，右侧显示「排队中…」或「<源站名> 百分比」（如 ModelScope 37%）；下载中页面约 1.5 秒自动刷新一次进度；
2. 点「取消下载」：断点保留，之后可续传。

6. 失败自动换源、断点续传

1. 单个源 404 / 超时 / 中断：自动切换下一源重试，顺序 = ModelScope（含 API 通道）＞ hf-mirror.com ＞ hf-mirror.net ＞ aifasthub.com ＞ HuggingFace 官方（整体垫底）；
2. 连接中断：报「连接提前中断（断点已保留，可续传）」，按钮变「继续下载」；手动暂停同理；
3. 所有源都失败：报「所有 N 个源均失败（断点已保留，可重新下载续传）」，按钮变「重试下载」，行内显示具体错误；
4. 断点保留意味着任何中断都不用从头重下。

7. 下载完成 ＞ 启动加载

1. 下载完成后模型自动从「模型库」进入上方「我的模型」列表；
2. 点该行「启动」：提示「已发起启动（后台预热）」——系统先做内存预算预检，再拉起引擎进程、健康检查，大模型首次加载可能需要十几秒；
3. 预检不过会明确报错：「内存预算不足：加载需要约 XGB，当前预算 YGB 已被运行中的模型占用。请先在模型管理中卸载：<名单>」，或「此机器内存不足以加载该模型…请选择更小的模型」；
4. 加载成功：行首亮绿点（运行中）；黄点 = 「运行中·探针验证中」（探针尚未确认）。顶部计数 +1；
5. 点「测试」验证链路：通过显示「测试通过 · <耗时>ms」（嵌入模型附维度、对话模型附样例回复），失败显示「关闭 测试失败 · <原因>」。

8. （可选）我的模型行内其他操作

每行按钮（悬停有说明）：「停用」（卸载运行中的模型，立即释放内存）/「钉住」（悬停「钉住：空闲自动卸载豁免」，钉住后行内显示 ；「取消钉住」恢复参与自动卸载）/「设置」（启动参数：省内存·均衡·性能三档与高级覆盖，见后续教程 M5）/「删除」——行内二次确认「删除 <名称> 的已下载权重（<体积>）？删除后可重新下载。」点「好」执行、「取消」收回。手工放置过、与内置目录疑似同款的权重行会出现「认领」/「已认领（撤销）」。

9. 「＋ 添加模型」（离线导入入口）

「我的模型」标题行右侧「＋ 添加模型」打开导入对话框：填「模型文件路径」（桌面形态有「…」文件选择按钮）＞ 选模型类型（对话/嵌入/重排序/决策/代码补全/图像理解/语音识别）＞ 填「显示名称」与「上下文 (K)」＞ 点「导入并运行」。导入不复制文件，直接引用原路径。详细离线流程见后续教程 M4。

## 怎么确认做成了

验证

1. 「我的模型」列表出现目标模型（模型库对应行消失）。
2. 点「启动」后行首亮绿点，状态条计数 +1（如「1 个模型运行中」）；点「测试」显示「测试通过」。
3. 浏览器或终端访问 http://127.0.0.1:52581/v1/models（免 key）：清单出现 local/<模型id> 条目。
4. 在向导（M1 第 2 步）或灵宠选模型树里，该模型出现在「本地与自建 · local/」组下；运行中带绿色「运行中」标记。

## 什么情况下用得上

按内存挑合适的模型档位，想用本地模型对话 / 跑知识库，机器上还没有对应能力的模型；内网机器补齐模型能力；下载到一半断网 / 失败，想知道会不会白下、怎么续传。

用户常搜的问法：本地模型去哪里下载？模型库在哪里；我的电脑 8G 内存能跑哪个模型？ △ 关闭 是什么意思。

## 这些坑和边界要知道

如实说明，它不是万能的：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 下载几个 GB 的权重需要时间与磁盘空间
- 8GB 内存建议一次只加载一个对话模型
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 接着回答几个常见问题

### 关闭 徽标的模型能下载吗？

能——徽标含义明示「仍可下载，加载时会被守卫拦截」。点「启动」时会被内存预算预检拦下，并提示需要多少内存、建议先卸载谁。内存不够就换小参数量模型（参考 档），或先「停用」部分运行中的模型。

### 模型跑一会儿自己停了？

默认「15 分钟无人使用自动卸载」在释放内存，不是故障。常用对话/嵌入模型点行内「钉住」豁免自动卸载；时限在状态条下拉可调（自动卸载：关 / 5 / 15 / 30 / 60 分钟）。

### 完全断网 / 所有源都下载失败怎么办？

断点已保留，联网后点「继续下载」从断点续传。彻底离线的机器：在任意联网电脑按帮助中心「离线下载与导入」的直链下载权重文件（U 盘/内网搬运）放到本机，再用「我的模型 ＞ ＋ 添加模型」按路径导入（不复制文件、原路径引用）。

### 启动报「二进制缺失 / 引擎缺失」？

推理引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；恢复方法详见帮助中心「引擎二进制」。
