# 通知中心：察元AI OS 桌面基础操作速查，别再瞎试

通知中心的麻烦不在功能本身，在于信息散。新桌面系统的肌肉记忆速查，五分钟上手。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

排通知中心的错，顺序比速度重要：环境与模型先就位，然后对操作路径，最后核边界。三层各有一些典型症状，对号入座能省很多时间。

## 高频故障与对策

### 勿扰时段内通知会不会丢？

不会丢。勿扰只是「不弹横幅、不语音播报」，通知照常进历史与未读计数，事后打开铃铛面板都能看到。

## 正确的操作路径

第 3 步 · 控制中心与专注模式（现状口径）

1. 当前版本桌面形态没有挂载独立「控制中心」面板（Wi-Fi/专注模式/声音的控制中心组件尚未接入菜单栏），勿按其他系统的习惯寻找。
2. 免打扰需求用勿扰时段实现（见第 5 步，即通知场景下的专注模式）；亮度/声音等硬件设置走操作系统自身。

第 5 步 · 通知设置（设置 ＞ 通知）

1. 在哪里：设置左侧栏选「通知」分区，卡片标题「通知与勿扰」，说明「通知本地保留（上限 200 条）；勿扰时段内不弹横幅、不播报，只入历史与未读。」
2. 「接收运营消息」（默认开）：关闭后不再拉取官网推送，卡片下方补一句「关闭后不再拉取官网推送；重新打开从当下开始（不补发关闭期间的）」。
3. 「启用勿扰时段」：勾选后出现「开始」「结束」两个时间框（默认 22:00 ＞ 08:00，支持跨午夜，如 22:00–08:00 即晚十点到次日早八点）。
4. 「发一条测试通知」：点一下立即产生一条系统通知（用于验证链路）。
5. 每项改动后显示「已保存」提示。

## 怎么确认做成了

验证

1. 点察元菜单「锁定察元」（或 Ctrl+L）应立即落锁，输对密码回桌面。
2. 打开两个应用窗口后点菜单栏「窗口」——两个条目都在列，点非焦点条目该窗口应前置。
3. 设置 ＞ 通知点「发一条测试通知」：右上角弹出横幅、铃铛角标 +1，打开面板能在「系统」组看到这条。
4. 勿扰开始时间设为当前时间前一小时、结束设为一小时后，再发一条测试通知——不弹横幅，但面板历史里有一条未读。

## 常见问题

### 找不到控制中心（Wi-Fi/专注模式面板）？

当前版本桌面形态未挂载控制中心面板；通知层面的专注/免打扰用 设置 ＞ 通知 ＞ 「启用勿扰时段」，其余硬件开关在操作系统自己的设置里。

### 通知历史最多留多少？会占很多空间吗？

本地保留、上限 200 条（超出按先进先出淘汰），面板底部标注「历史上限 200 条」。

### 「切换用户」和「退出登录」有什么区别？

「切换用户…」是输入目标用户名密码直接进入对方会话（你的会话窗口被隐藏、回到锁定页，可随时再切回）；「退出登录」结束当前会话。两者凭据与开机登录门、锁屏是同一套账号密码。

## 更多操作细节

第 1 步 · 锁屏与解锁

1. 锁屏入口（桌面形态）：
    1. 菜单栏左端察元菜单 ＞「锁定察元」（菜单项标注 ⌃⌘Q 字样）；
    2. 键盘 Ctrl+L 直接落锁；
    3. 菜单栏右侧用户菜单 ＞「锁定察元」（多用户时显示）；
    4. 闲置自动锁屏：设置 ＞ 通用 ＞ 「自动锁屏」选时长后生效。
    5. 解锁：锁屏画面点一下出现密码框，输入账号密码回车；连错 5 次起递增退避（5 秒起步、翻倍、重启不清零）。
    6. 手机形态另有 设置 ＞ 系统 ＞「锁定屏幕」按钮。

## 更多操作细节

第 6 步 · 切换用户与退出登录

1. 用户菜单（菜单栏右侧头像按钮，仅多用户体系显示）：显示当前用户昵称·用户名，内含「锁定察元」「切换用户…」「退出登录」。
2. 「切换用户…」弹出「切换用户」小窗：填「用户名」「密码」提交——校验走与开机登录门同一套账户（数据按用户隔离，互相看不到文件）；切回自己=直接回桌面，切到他人=主进程把对方会话窗口推到前台、本窗口隐藏并回到锁定页。凭据错误显示「用户名或密码错误」；尝试频繁显示「尝试过于频繁，{n} 秒后再试」；无桥形态显示「当前形态不支持切换用户」。
3. 「退出登录」结束当前用户会话。
4. 察元菜单 ＞「切换用户…」（标注 ⌘Q）：进入锁屏登录门，在用户卡片墙上选用户登录。锁屏页也有「切换用户…」入口（同一弹层）。

## 放回产品盘面看

把通知中心放回察元AI OS的整体盘面：首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入，保存后随系统技能分发到智能体，图片搜索与图库平台支持。

## 安全与数据边界

安全口径单独立一层：一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全；隐私敏感环境先关遥测再干活，处置设备前清数据；（本机 MCP HTTP 服务，回环免 token），敏感操作全部写审计日志 audit.jsonl，可回放检查；远端调用以远端访客身份过对端权限门并留审计。
