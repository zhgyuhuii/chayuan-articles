# 题库评测与对局评测：两种考察方式怎么互补

模型考试分数很高，上了牌桌却乱跟注乱拆牌——这种反差不是段子，而是题库评测与对局评测天生考的东西就不一样。前者像笔试，题目固定、答案标准；后者像打球，对手实时应变、局面不断刷新。这篇把两种考察方式拆开讲，写给正在为模型选考察方式的人，也写给看着榜单分数想不明白为什么和体验对不上的人。

两种方式同框对照，先看这张表。

| 维度 | 题库评测 | 对局评测 |
|---|---|---|
| 考察内容 | 静态知识与问答推理 | 动态博弈中的连续决策 |
| 出题方式 | 固定题集，题目事先确定 | 对手实时反应，局面不断生成 |
| 过程变量 | 单轮作答，一次定分 | 多轮交互，状态逐手累积 |
| 可测出的行为 | 记忆、知识面、解题套路 | 算子力、诈唬、防守、收官 |
| 结果呈现 | 分数与正确率 | 胜负、形势曲线、？！标注 |
| 在察元竞技场的角色 | 不是它的方向 | 它的全部 |

## 静态知识考记忆，动态博弈考决策

题库评测的本质是静态知识抽查：题目提前写好，模型在限定作答里给出答案，答对得分。它适合量出知识面的宽窄和解题的稳定性，跑分成本也低，挂个脚本一晚上能扫完一套题。

对局评测是另一回事。察元竞技场里的每一局都是动态的：对手每手都在变，棋盘和牌面随之刷新，模型要在多轮交互里持续做决策。五子棋要算杀，德州扑克要算底池与牌力，麻将要防守点炮——这些行为没有一道固定题目能考出来，只有在真实对手面前才被逼出来。

## 各自测不出什么

题库测不出博弈行为。诈唬、诱敌、弃子防守、收官取舍，这些能力在「一问一答」里没有舞台；一个题库高分模型，完全可能在牌桌上被低分模型诈得团团转，因为决策节奏和答题节奏是两种东西。

对局也测不出百科知识。模型知道不知道某年某地的历史事件，一场斗地主照不出来。所以两种方式互有盲区：想知道模型「知道什么」，做题；想知道模型「面对对手会怎么打」，对局。谁也替代不了谁。

落到察元竞技场上还有个附加观察维度：思维链。模型怎么解释自己的出招、推演线写得多扎实，这些文字材料本身就是行为样本，题库里可比不了。

## 对局评测在竞技场里怎么落地

察元竞技场把对局评测做成了一套完整设施。裁判归纯逻辑代码，胜负判定不受模型影响，只认规则真值；TrueSkill 天梯按胜平负自动更新段位，人类挑战者战绩独立成榜；锦标赛支持多模型循环赛自动排程，积分榜实时刷新，打完出冠军。

复盘环节的观察维度也是题库给不了的：形势曲线画出局势走向，逐手？！标注点出妙手与失误，AI 赛后解说把整局串讲一遍，棋谱可导出 JSON，协议画像统计每个模型的出招习惯。对局过程本身也透明：思维链气泡实时滚动，每手延迟与 token 用量摆在对局室里，模型是稳扎稳打还是急躁冒进，看得一清二楚。

## 怎么搭配着用

常规做法是两条腿走路：选型筛库时先跑题库，快速排除明显不合格的候选；进入候选名单后拉上竞技场打对局，看真实博弈里的表现。题库负责「会不会」，对局负责「打起来怎么样」，顺序通常从便宜到贵——对局要消耗真实 API 额度，题库跑分相对省。

还有一条经验式的：题库分数和对局表现对不上号是常事，别用前者直接推断后者。解题的正确率和牌桌上的稳定性，是两种稳定性，两份成绩单要分开看。

## 一次选型的完整动线

把两种方式串起来看一条完整的选型动线。起点是题库：公开基准跑一遍，淘汰明显不合格的候选，这一步花销小、速度快。第二步进竞技场配模型，85 家厂商目录点选填 Key，「获取模型」一次拉全候选清单。第三步小规模对局：挑两三款差异大的玩法，机机观战各打几局，看思维链气泡里的推演质量，顺手记下协议画像里的格式遵守率与平均耗时。第四步才是锦标赛：入围模型开循环赛，积分榜实时刷新，天梯段位随胜平负更新。

这条动线的每一步都可回头：对局数据全在本机，棋谱导出 JSON，回放器按协议字段筛关键手，哪一步有疑问就重放哪一步。评测从「一次性考试」变成「可重放的实验」，这是两种方式组合之后才有的效果。

模式选择上也有讲究：人机局适合辅导式观察，你亲自下场试探某款模型的应变；机机观战适合横向对比，批量勾选模型两两开打；天梯挑战适合长期追踪，按段位约战，赢者升段。

## 条件式推荐

要快速筛选模型、比较知识面与解题能力，题库评测效率高，公开基准刷一遍就有数，成本低。

要观察模型在博弈里的决策行为、稳定性和抗干扰能力，或者想给自己的模型找考场，用察元竞技场这类对局评测，11 款玩法任选，85 家厂商目录里谁都能上桌。

预算有限的话，先题库后对局，把对局额度留给入围选手，别一上来就全量打锦标赛；用 Ollama 本地模型做对局评测则零成本，代价是小模型表现通常有限。

## 实话实说：三条边界

对局评测单局随机性大，一两局的输赢说明不了问题，要多打几局再下结论；对局消耗真实 API 额度，挂机跑锦标赛的钱是你自己付的；题库这头也别神化，公开题集可能被模型「背过」，分数要带着保留看。

## 你可能会问

### 对局评测能替代题库评测吗

不能，两者考察面不同。题库测静态知识，对局测动态决策，互有盲区，搭配使用才是完整画像。

### 打多少局才能看出模型高下

没有统一数字。局数越多结论越稳，锦标赛循环赛多打几轮，天梯段位的区分度会随对局量上升。

### 察元竞技场自带题库吗

不带。它聚焦完整对局，不做题库打分，这正是它与常规评测工具的分野。

### 对局评测要花多少钱

软件 MIT 免费；用云端模型时 API 费用由你向厂商支付，用 Ollama 本地模型零成本。

### 题库分数高对局就一定强吗

不一定。两者考察面不同，分数对不上表现是常事，所以选型动线里对局验证这一步不可省。

会做题和会打牌之间，隔着一整个博弈世界。两种考察方式不是敌人，是互补的两只眼睛：一只看知识存量，一只看决策质量。把两只都用上，你对一个模型的判断才立得住。
