# 职业教育行业怎么用察元OS：从痛点到落地

职业教育行业的文档与信息工作有其固有节奏：多岗位协作时版本混乱、批注流转低效。察元AI OS在职业教育场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出职业教育行业的完整应用路径。

## 职业教育行业的典型痛点

- 多岗位协作时版本混乱、批注流转低效
- 跨部门数据与引用需要反复核对出处
- 历史文档数字化程度低，检索与复用困难

## 对应的能力组合

- **九语言界面**（系统语言）：中文、English、日本語、한국어、繁體中文、Русский、Español、Français、Deutsch 九种界面语言。
- **插件页签（三源）**（插件市场）：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。
- **技能页签与技能商店**（技能商店）：技能管理页签：启停（改写 SKILL.md 元数据）、打开目录、删除（入废纸篓）、tar.gz 离线导出导入；技能商店可搜索 GitHub 技能仓库一键安装（内置 anthropics/skills 等精选）。
- **Dock 与窗口管理**（Dock栏）：Dock 支持位置/自动隐藏/放大效果/图标三挡大小、分组（徽章+溢出计数）、Windows 式最小化磁贴；多窗口可拖拽、多屏切换。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按开发者场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程

## 常见问题
### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 其他软件能用本机模型吗？

能。统一模型代理提供 OpenAI 兼容与 Anthropic 协议接口（对话/嵌入/重排/语音），任何支持的客户端指向本地代理即可。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
