# 技能包商城 vs 单个技能自己找（深度对比）

技能包商城 vs 单个技能自己找，是很多用户在选型阶段绕不开的问题。这篇深度对比不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 维度对照表

| 维度 | 本方案（能力广场） | 对照方案 | 说明 |
|---|---|---|---|
| 效率 | 一包配齐行业常用技能 | 一个个找耗时 | 买断省时间 |
| 成本 | 付费买断（约一成免费） | 自己找多为免费 | 看预算 |
| 质量 | 包详情含 solves/audience 筛选过的技能 | 质量自辨 | 策展价值 |

## 逐项解读

**效率**：买断省时间。能力广场侧的做法是「一包配齐行业常用技能」，对照方案为「一个个找耗时」——差异的本质在于设计取向不同，而非优劣。

**成本**：看预算。能力广场侧的做法是「付费买断（约一成免费）」，对照方案为「自己找多为免费」——差异的本质在于设计取向不同，而非优劣。

**质量**：策展价值。能力广场侧的做法是「包详情含 solves/audience 筛选过的技能」，对照方案为「质量自辨」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

个人玩票自己找；行业落地追求效率选技能包。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 政企可私有化部署（Docker），数据自主可控

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 复制安装命令安全吗？

网站不存二进制，安装命令指向原始仓库/官网；执行前建议确认条目 health 状态为 active，MCP 类条目注意查看 scopes 风险分级。
