# 信创办公软件是什么：个人替换订阅制办公软件

搜信创办公软件的需求分两拨：政企单位要国产系统上能批量部署的一套，个人用户想在订阅到期前找到替代。这篇把定义、口径、边界摊开，两拨人各自对号。

## 什么是信创办公软件

信创办公软件指的是能在国产化环境里稳定落地的办公套件：入口、步骤、边界俱全，六个编辑器合在一个开源应用里，AI 能力嵌在各个环节。它比普通办公软件多一层要求——不止国产系统上能装，还得在无外网的政企环境里站得住。

数字与界面口径参照官方文档，核对的版本与截止时间见尾注。

## 信创语境下的落点

落点是下载安装与首次启动：Windows 用 NSIS 安装器、macOS 用 dmg、Linux 有 deb、rpm 与 AppImage（glibc 2.34 以上）。装机包认准官方渠道，镜像站的包看不出被谁动过。

单独说它的原因：开源办公套件能离线装、信创环境能跑，替换传统办公链路可以从这一步迈出去。

## 最短上手路径

最短路径走一遍：

1. 按平台选安装包，Windows、macOS、Linux 三平台共五形态
2. 免 root 即可安装，不需要动管理员权限
3. 麒麟与 UOS 环境用 AppImage 加 deb 两种包
4. 场景验证：政企内网批量装机
5. 场景验证：个人替换订阅制办公软件
6. 串联场景：Docs 写正文，察元AI 页签全文校对出批注

第四到第六步是验证项。批量装机那条线看的是部署效率：终端数量、内网条件、运维人力摆在一起，桌面端与服务器端哪个省事就上哪个。个人替换那条线看的是习惯迁移：高频文档先过一遍打开与保存，确认往返无异常，再谈彻底切换。串联场景则用来检验 AI 校对的批注锚定是否真的落在原文上——Docs 写完正文，察元AI 页签跑全文校对，批注逐条对应。

## 落点的能力面

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb

这三条决定了适配广度：平台与形态越全，存量设备越不用换；免 root 降低了政企终端的安装门槛；麒麟与 UOS 的专用包则对着信创环境里最常见的两类系统。

## 套件其他板块

- 扫描件 OCR：无需按钮、自动触发——页面有效文字不足 8 字符即判为扫描页，交给系统引擎处理
- Markdown 编辑：双栏实时预览，front matter、双链、反向链接、斜杠菜单、标签、关系图谱齐备；图床可接 S3、SM.MS、GitHub；成品能导出为 Word、PDF、图片。
- HTML 可视化编辑：预览与源码可切换，点选元素就地编辑，配样式面板、面包屑、Ask AI、插入骨架与图片去背景。
- CLI 命令行：chaoffice 的命令行入口共 17 个子命令。

## 信创选型常见疑问

### 断网状态下它还能干什么？

套件本地优先、离线可用；AI 这部分看模型配置（BYOK 或本地端点），连本机 Ollama 这类端点即可离线跑，不配模型时只剩传统办公功能。

### 打开文档时哪些格式不在支持范围？

打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等；碰到老格式会给出明确提示，按提示转成新格式再打开。

### 麒麟或 UOS 上的安装包有什么不同？

就形态而言：麒麟与 UOS 走 AppImage 加 deb，通用 Linux 发行版另有 rpm 等形态可选。

## 个人替换订阅制的账

替换的核心顾虑通常是存量文档能不能顺利打开。打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等常见格式，老格式给出明确提示，转存新格式即可继续。个人的替换节奏建议软着陆：新旧并行一段时间，高频文档先迁，低频的按需搬，订阅到期与否就不构成压力；迁移期间产生的双份文档，用完一版删一版，避免越积越多。

## 政企批量装机的做法

批量装机有两条路：桌面端逐台装——三平台五形态安装包、免 root 即可装，麒麟与 UOS 走 AppImage 加 deb；或服务器部署后全员浏览器访问，把安装量收敛到一台服务器，终端只管开浏览器。两条路的取舍标准就一条：内网终端允许跑什么形态。

## 盘面里的其他能力

装进整个套件看，落点之外还有这些：Docs 端批量通知与论文写作两个长尾场景由现成助手承接；表格端透视表与公式引擎是硬指标，自研边车保证 xlsx 往返不失真；演示端录课与路演的旁白在放映态内直接录，不必开第二个软件。这些板块与安装落点同属一个应用，装机一次全部到位，不需要按模块分头折腾。

## 安全与数据口径

API Key 存本机 ai-settings.json，不上传，且支持环境变量引用——部署脚本因此不必把 Key 明文写进配置文件；模型层的 BYOK 目录覆盖 94 家供应商，本机 Ollama 这类本地端点同样可接。政企内网关心的部署形态也在这里：服务器部署后，全员经浏览器可用。

## 无网环境的运行条件

本地优先、离线可用是它的基本盘。内网环境的注意力放在模型端点上：端点可达，AI 功能就在；端点不通或未配置，剩下的传统办公功能照常工作。内网里配本地端点还有个附带好处：推理不出内网边界，文档内容不经过公网，BYOK 的 Key 也只配在自己掌握的端点上。

## 一句收束

信创办公软件的判断标准不玄：装机形态对得上自己的系统、离线条件对得上自己的网络，就可以进入试装；两条都对不上，先解决环境再谈工具。
