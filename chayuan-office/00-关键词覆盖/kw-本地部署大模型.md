# 本地部署大模型是什么：按能力分设默认模型

模型在自己机器或自己机房里跑，文档也在自己手里，这条链路通不通，决定涉密环境能不能用上 AI 办公。这篇按「本地部署大模型」这个关键词，把部署口径、接入方式与降级兜底一次说清，产品侧以察元AI Office 为例。

## 什么是本地部署大模型

本地部署大模型指的是把推理服务放在自己掌控的硬件上——工作站、部门服务器或内网机——办公软件连这个端点取能力，而不是把内容发往公网服务。落到这套开源 AI 办公套件上，接法走模型供应商 BYOK：目录里 94 家供应商分成四组（国内 29、国际 34、本地 9、聚合 22），底下配 28 个适配器；协议内部支持 5 种，用户可在 Anthropic Messages、OpenAI Chat、OpenAI Responses、Gemini Native 四种里选；模型列表实时拉取、不预置。文中口径以官方文档为底，版本对应关系见文末。

单独拎出来讲的理由：Key 在自己手里，不被任何一家厂商绑定，云端与本地端点想切就切。

## 部署前先想清楚的三件事

先想用途：校对、摘要、改写这类轻任务，对端点的要求远低于长文生成，别一上来就按最重的算力规划。再想位置：个人机、部门服务器、内网机房，三者的运维责任完全不同，放哪台机器就要有人管那台机器。最后想退出：端点地址是可改的配置而不是写死的绑定，今天选的方案不合用，换一个端点重配一遍即可，历史文档不受任何影响。这三件想清楚，部署就不容易返工。

## 信创与内网环境的适配

开源办公套件能离线装、信创环境能跑，本地部署大模型与它是同一条思路的两端：系统环境自主、模型服务自主。装好之后手册离线可读，快捷键表齐全，新手到熟手的过程被压缩，不依赖外部文档站点。若这台机器上桌面环境已激活，办公套件跟着免激活，内网批量装机时省一道手续。

## 接入的几步

1. 定部署形态：个人用本机推理服务，公司走统一采购的 API 接入，两条路在配置上没有区别。
2. 在设置的模型分区里填地址与密钥：Key 存本机 ai-settings.json，不上传，也可改成环境变量引用。
3. 拉取模型列表并勾选启用，产品不预置名单，接口给什么列什么。
4. 按对话、生图、媒体、搜索四类能力分别设默认模型，写作与画图可以各用各的。
5. 两条边界先记下：AI 功能依赖已配置模型，没配模型时只有传统办公功能可用；内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型。

## 降级与兜底

本地端点也有不稳的时候，这套软件的兜底设计是：AI 挂了自动降 9 类本地正则兜底，基础处理不中断。报价、身份证号这类片段不想给模型看，隐藏后其他部分照常 AI 处理；涉密文档不能出网时，本地模型让 AI 校对、AI 改写在隔离环境照常工作。这几条叠起来，才算把「本地」二字落到实处，而不是把模型挪个地方继续裸奔——部署只是手段，可控才是目的。

## 隐私与遥测的账

API Key 存本机 ai-settings.json 不上传，支持环境变量引用；自建部署可做到零遥测，数据出不出门完全自己说了算。公司统一采购的 API 接入场景，密钥集中管理、请求走内网网关，审计口径也干净。

## MCP 把能力面撑开

搜索、数据库、浏览器这些 MCP 能力接进来，AI 面板就不止会改文档；外部智能体也可接入，写材料引用内部资料且带出处，写作与知识库一条链打通。模型部署在本机，这些扩展同样跟着不出网。对写材料的人来说，这意味着检索内部资料、引用出处、改写文档可以在同一块面板里连续完成，中间不需要把内容粘贴到任何外部服务；对管内网的人来说，这意味着边界清晰：模型在哪、数据就在哪，出了机房这道门什么都不外流。让编程智能体天生会用办公套件，写代码调文档 API 不用翻文档，自动化脚本同样只面向本机端点。

## 常见疑问

### 模型部署在本机后，办公软件还需要连外网吗

不需要。AI 功能依赖已配置模型，端点指向本机服务时，编辑与 AI 两条线都在本地闭环；本地优先、离线可用是整套软件的底色，外网断了不影响主线。

### 本地跑模型，文档格式支持会不会打折扣

不会。打开格式路由表覆盖 docx、odt、xlsx、csv、pptx、pdf、md、html 等，这是编辑器层的能力，与模型部署在哪无关；模型只影响 AI 生成与校对那一段。

### 涉密材料想借用 AI 校对，这条路走得通吗

走得通，前提是模型在本机。涉密文档不能出网，本地模型让 AI 校对、AI 改写在隔离环境照常工作；更谨慎一点，报价、身份证号这类片段先隐藏，剩余部分照常处理，两道闸一起上。

## 一句收束

本地部署大模型值不值得深入，判断标准很简单：把上面的口径与边界代入你的实际需求，对得上就装来试，对不上不必跟风。端点配不通时，先查地址与协议是否匹配，再回看本篇疑问一节。
