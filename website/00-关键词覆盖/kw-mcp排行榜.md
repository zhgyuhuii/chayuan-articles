## 你可能会问

### MCP 板块的资源从哪来？

数据来自 11 个源的持续采集与去重：awesome-mcp-servers、Smithery、GitHub topics、mcp.so、MCP 官方 registry、servers.org、docker registry、官方参考服务器等。

### 怎么判断一个 MCP 服务还活着？

榜单机制会自动剔除标记为 dead 或 archived 的失效资源；点进详情页看最近更新时间与 star 走势也能判断。

### 安装配置在哪看？

每个资源详情页有安装与配置说明，复制到你的 MCP 客户端（Claude Code、Codex、Cursor 等）即可。

### 下载安装包需要登录吗？

需要。完成站内账号或微信扫码登录后即可下载，登录后还能收藏资源与管理下载记录。

### 怎么确认下载的是官方安装包？

官网 aidooo.com 是仅有的官方分发入口，下载页直链由管理后台自动同步生成；不要使用第三方站点的镜像包。
