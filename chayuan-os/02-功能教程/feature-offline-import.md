# 一篇讲透GGUF导入：准备、步骤、验证与边界

被GGUF导入折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI OS为准。

## 概念先掰开

不联网也能给察元补模型：要么在 设置 ＞ 模型 里用「＋ 添加模型」按路径导入本机已有的 GGUF / whisper .bin 权重（零拷贝——不复制不移动，直接引用原路径），要么在联网电脑按直链下载权重、拷到本机模型目录放置后让系统重新扫描识别。

完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入。

入口、步骤、验证三段看清，这事就顺了。

## 动手前的准备

- 权重格式：仅支持 .gguf（对话/嵌入/重排/决策/代码补全/图像理解，走 llama-server）与 whisper ggml 的 .bin（语音识别）；.safetensors / 原始 .bin 权重不能直接用，需先用 llama.cpp 工具链转量化。
- 磁盘空间：放置法文件多大占多大（无解压放大）；路径导入法不占额外空间（零拷贝引用）。
- 放置法要知道模型目录位置：桌面多用户形态的权重根 = <数据根>/shared/models/chatop-models/models/，数据根默认在「文档」目录下的 chatop-data（如 macOS ~/Documents/chatop-data，首次开机也可自选/导入别的位置）；本机实时真实路径以 GET http://127.0.0.1:52584/api/chatop-models/status 返回的 paths.modelsRoot 为准。
- 在线下载、断点续传等常规路径见对应教程；本篇只讲离线两条路。

## 从打开到做完的每一步

1. 进入本地模型页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）选一个能力分类（对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 语音识别 / …），右栏即该分类的本地模型页。

2. 打开导入对话框

「我的模型」标题行右侧点「＋ 添加模型」，弹出对话框，标题「导入本地模型文件」。

3. 填「模型文件路径」

1. 输入框占位提示 /Users/you/Downloads/model-Q4_K_M.gguf；
2. 桌面形态输入框旁有「…」按钮（系统文件选择器）；web/docker 形态没有该按钮，需手动填服务侧完全路径；
3. 填入路径后系统自动做两件事：按文件名猜「模型类型」并自动填「显示名称」（默认取文件名去掉扩展名）。

4. 选「模型类型」（可选，自动识别可改）

七个类型 chips：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 语音识别。文件名自动识别规则：.bin ＞ 语音识别；含 decision/startlux ＞ 决策；含 embed/bge ＞ 嵌入；含 rerank ＞ 重排序；含 coder/code ＞ 代码补全；含 vl/vision/minicpm ＞ 图像理解；其余 .gguf ＞ 对话。选「决策」时下方提示：决策标签仅适用于 StartLux 系（Qwen 词表）决策模型，其他基座会产出无效概率。

5. 填「显示名称」与「上下文 (K)」

1. 「显示名称」默认取文件名，可改；
2. 「上下文 (K)」默认 8（即 8192 token，有效范围 512–1048576 token）；语音识别类型不需要。

6. 点「导入并运行」

1. 成功：对话框关闭，模型立即出现在「我的模型」列表，行首带「本地」小标、第二行显示原路径；此时只是登记引用，模型还没加载进内存——点行内蓝色「启动」按钮完成加载；
2. 失败（红色提示，对应校验顺序）：「请填写模型文件路径」＞「仅支持 .gguf 与 whisper .bin 模型文件」＞「文件不存在或不可读：<路径>」＞「导入失败」。

7. 认领（可选）

导入的文件若与内置目录里的模型疑似同款：强匹配自动认领（直接继承该目录模型的引擎参数与上下文；视觉目录模型例外——单文件导入没有多模态投影器，认领后收窄为纯文本链路）；弱匹配在行内显示「认领」按钮，点了才联动，已认领显示「已认领（撤销）」。

8. 在联网电脑下载权重

帮助中心 ＞ 模型服务 ＞ 「离线下载与导入」有模型库全部模型的直链表（主源 ModelScope、备源 hf-mirror），任选其一，文件名保持原样。例如：

权威直链与期望落位以管理面 GET /api/chatop-models/status 返回的每个模型 sources[]（直链）与 targetDir（放到哪）为准。大文件（>4GB）拷 FAT32 U 盘会失败，用 exFAT/NTFS。

| 模型（目录 id） | 期望主权重文件名 |
|---|---|
| qwen3.5-4b-q4km（装机对话档）/ qwen3.5-4b（在线档） | Qwen3.5-4B-Q4_K_M.gguf |
| bge-reranker-v2-m3（重排） | bge-reranker-v2-m3-Q8_0.gguf |
| whisper-small-int8（语音识别） | ggml-small-q8_0.bin |

9. 放置到模型目录

1. 补装模型库里的模型：放到 <modelsRoot>/<模型id>/<期望文件名>（如 <modelsRoot>/qwen3.5-4b/Qwen3.5-4B-Q4_K_M.gguf），放置后该模型在「我的模型」点亮为已安装；
2. 放任意 GGUF：在 <modelsRoot>/ 下新建子目录放入权重（目录名即模型 id，别与内置模型 id 重名，避免中文/空格）；同目录多个权重默认取体积最小的一个；
3. 可选在同一子目录放 model.json 侧车覆盖识别：{"name":"显示名","caps":["chat"],"file":"主权重.gguf","dims":1024,"contextWindow":32768,"ramMB":3200,"engineArgs":[...]}。不放侧车时按文件名/目录名猜能力：whisper/ggml-*＞语音识别、decision|startlux＞决策、rerank＞重排、embed|bge|e5-|gte-＞嵌入、vl|vision|llava|minicpm-v＞对话+图像理解、其余＞对话。

10. 让系统识别放置的文件

放置的文件在应用启动时自动扫描；桌面正在运行时放置的，重启察元后生效。也可以不重启：让任一智能体（或终端）对本机管理面发一次再扫描——

bash

curl -X POST http://127.0.0.1:52584/api/chatop-models/scan

返回 {"ok":true,"models":N,"local":M}（local 为本地放置识别出的条目数）。注意：当前版本设置界面里没有「扫描」按钮（帮助中心旧文提到的模型服务页扫描按钮已随该应用并入设置而移除），再扫描走上面的 API 或重启。

11. 加载并使用

回到 设置 ＞ 模型 对应分类的「我的模型」，点「启动」加载（加载前有内存预算预检）；之后与在线下载的模型完全同权：对话/知识库/智能体可用，代理 local/<模型id> 可调。

## 如何确认操作生效

验证

1. 「我的模型」出现该模型：路径导入的带「本地」小标、第二行显示原路径；放置法的显示名 = 目录名（或侧车 name）。
2. 点「启动」后行首亮绿点，顶部计数 +1；点「测试」显示「测试通过 · <耗时>ms」（嵌入模型附维度）。
3. 浏览器打开 http://127.0.0.1:52581/v1/models（免 key）：清单出现 local/<模型id> 条目。
4. 放置法识别后，DeepSeek Harness 对话窗的模型下拉出现该模型（对话/图像理解类）。

## 谁需要这个功能

下载总失败或速度太慢，想在别的电脑下好再 U 盘搬运；保密机房用 U 盘搬模型；机器完全断网 / 内网隔离（涉密单位、离线工位），在线模型库下不动，手里已经有 GGUF 权重（自己量化/公司内网分发），不想再下一遍。

用户常搜的问法：断网的电脑怎么装本地模型；我自己有一个 GGUF 文件，怎么导入察元。

## 它的局限也要说清楚

如实说明，它不是万能的：

- 文件放错目录扫描不到，需按指引路径放置
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 接着回答几个常见问题

### help 里说「放好后点扫描按钮」，按钮在哪里？

当前版本的设置 ＞ 模型 页没有扫描按钮（旧「模型服务」应用已并入设置，该按钮未随迁）。放置后重启应用自动扫描，或用第 10 步的 curl 再扫描。

### 离线机器上引擎报「二进制缺失」？

引擎（llama-server / whisper-server）随安装包分发，最常见是被杀毒软件隔离。从安装目录 resources/chatop-models/vendor/ 找回或加白名单后重装；也可用环境变量 CHATOP_LLAMA_SERVER_BIN / CHATOP_WHISPER_SERVER_BIN 指向自备二进制的完全路径。详见帮助中心「引擎二进制」。

### 导入后把原文件移动/删除了会怎样？

导入是引用不是拷贝：原文件不在了，该条目自动从「我的模型」消失（登记仍保留）；把文件放回原路径即自动恢复。行内「删除」对导入模型只弹「移除「<名称>」的本地导入登记？原文件不会被删除。」——也绝不删你的原文件。

### .safetensors / HuggingFace 原始权重能导吗？

不能。导入校验只放行 .gguf 与 whisper ggml 的 .bin（.bin 恒按语音识别处理），其他扩展名直接报「仅支持 .gguf 与 whisper .bin 模型文件」。先用 llama.cpp 的转换/量化工具产出 GGUF 再导入。

GGUF导入的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
