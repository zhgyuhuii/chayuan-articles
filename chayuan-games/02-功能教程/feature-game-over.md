# 终局卡与再来一局：认输收尾交互详解

一局棋怎么开始，教程很多；怎么结束，反而少有人讲。其实收尾环节藏着不少讲究：认输之后棋局还在不在，机机观战里匿名座位的底牌什么时候翻开，想接着打是不是要回大厅重走一遍流程。这篇把察元竞技场的终局卡与再来一局讲透，顺带说清认输这个动作的前因后果。

## 先弄清楚它是什么

终局卡是一局对局结束时弹出的收尾卡片，相当于一局棋的「落幕页」。它承担三件事：亮出胜负结果；完成终局揭晓——机机观战里座位一直显示玩家A、玩家B、玩家C、玩家D，谁是谁的真身，到这里才翻开底牌；给出两个去向入口，关闭与再来一局。

再来一局是延续动作：按当前这局的配置续开一场，不用回大厅重新选玩法、选模型。牌桌上打完一局喊一声「再来」，这个入口就是把这声「再来」做成了交互。

认输是中途收尾动作。局面崩了、临时有事、不想耗了，用认输把这一局体面地结束掉。关键口径一句话：认输不清盘。认输的对局照常留档，记录页里找得到，回放复盘一样能进——你认掉的那局棋，一手都不会少。

还有一条底层原则撑着收尾体验：胜负判定百分之百归代码。11 款玩法各有一套纯逻辑裁判引擎，只认规则真值，模型只出招、不判罚。你在终局卡上看到的结果，是裁判引擎盖章的结论，不是谁自封的——收尾卡片上的每一行字都站得住。

## 动手前要备好什么

没有前置门槛。打一局人机局或者机机观战，走到终局或者中途想走，自然就会用到这套交互。一个小提醒：收尾交互和终局判定是两回事，胜负归代码裁判判，终局卡只负责把这枚结果体面地端给你。

为什么要把收尾单独写一篇？因为收尾是复用率高的交互。开局配置一次管一局，收尾入口一晚要用几十次：每局打完都要跟终局卡打交道，认输、再来一局、关闭这三个动作顺不顺，直接决定一晚上的观战质感。

## 五种收尾场景的实际走法

场景一，打到终局。胜负落定，终局卡出现：先看结果；机机观战的话重点看终局揭晓，前面一直猜的玩家A、玩家B到底是谁家模型，此刻见分晓。

揭晓这一下别小看：观战时你对着玩家A、玩家B猜了一整局「这手诈唬像谁的风格」，终局卡翻开的一刻，所有伏笔一起兑现，这是匿名观战设计里最有仪式感的瞬间。

场景二，想接着打。在终局卡上选再来一局，新的一局按当前配置续开，玩法不变、对手不变，省掉回大厅重配的往返。连着打一个晚上，这个入口会用得非常勤。

它省下的不只是几步操作。连打的时候，节奏感很值钱：一局接一局不断线，思路和情绪都是连续的；每局都弹回大厅重配，玩兴散得快。小入口，大连贯。

场景三，想收工。选关闭，终局卡收起，对局已经留档，回大厅或者去记录页都行。这局棋没有消失，记录页里随时能翻出来回放。换句话说，关闭不是终点站，只是把这一局从进行时挪进档案库；档案库的门随时为你开。

场景四，中途认输。局面看不下去或者临时有事，用认输结束这一局。认输后同样走终局流程留档——认输的局照样有终局卡、照样进记录、照样能回放复盘。它是一局棋的正规收尾方式，不是把数据抹掉。看不开的棋友记住这句就行：认输留给下一局翻盘的机会。

扩展场景，挂机长跑。锦标赛的排程自动推进，跑完的每一局各自留档；你睡前开赛，早上从记录页看战报，收尾的事一概不用管。

## 做完后的验证

两个动作验证一遍就放心了。其一，认输一局，去记录页找它——找得到、进得去回放，说明认输不清盘落到了实处。其二，再来一局之后看新局配置——玩法与对手沿用当前对局，你不需要重新走一遍配置流程。

验证时顺手留意一件事：认输的局在回放里应该能看到完整的逐手过程，包括认输前最后一手的局势。如果回放断在半路或者记录缺条目，那才是异常；正常情况下，认输与打满全程在留档上没有区别。

## 这些边界要心里有数

再来一局沿用配置，也意味着费用延续。云端模型每打一局都消耗你的 API 额度，连打一晚上的开销要有数；想零成本连打，换 Ollama 本地模型上桌。

认输是终局动作，不能反悔续下。落子无悔的另一面是认输不回头，真想继续练，再来一局重新开。认输前想清楚，认输后不纠结——这是牌桌礼仪，也是好习惯。

终局揭晓的时机在终局。观战中途别急着追问座位身份，匿名观战的设计意图就是把悬念留到最后，提前剧透反而没了味道。

终局卡是结果的展示窗口，不是数据本体。就算手快直接关了应用，对局数据也已落在本机，记录页里照找得到——留档在先，展示在后。

界面细节以 0.1.0 版本的实际呈现为准，收尾交互后续版本可能微调。

## 高频疑问

### 认输之后这局棋还在吗

在。认输不清盘，对局照常留档，记录页里找得到，回放复盘不受影响。

### 再来一局会重新弹配置吗

不会。它按当前对局的配置续开，玩法与选手延续；要换对手，回大厅或设置里调整。

### 机机观战的匿名身份什么时候揭晓

终局揭晓。座位在局中只显示玩家A、玩家B、玩家C、玩家D，真身留到终局卡翻开。

### 关闭终局卡对局会丢吗

不会。关闭只是收起卡片，对局已留档在本机，记录页随时能翻出来回放。

### 中途关掉应用算认输吗

对局以引擎判定的终局为准，异常退出后留没留下终局，以记录页里实际留存的对局状态为准；建议用认输把要收的局正规收尾。

### 认输之后天梯分怎么算

认输即认负，结果按对局引擎的终局判定进入天梯结算，人类挑战者的战绩独立统计，不与模型混榜。

收尾交互是被低估的体验细节。终局卡把「结果、悬念、去路」收进一屏，认输不清盘保住了每一局的数据，再来一局把牌桌本能做成了按钮——这些地方做得顺，你才愿意一局接一局地打下去。棋局的落幕方式，决定了你下次还愿不愿意开场。
