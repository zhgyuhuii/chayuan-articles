# 模型代理入门指南：模型配置可一键写入五家

模型代理解决的是一个很具体的痛点：每家 AI 软件都要单独配模型地址和密钥，改一次配置就得挨家跑一遍。这篇把这套设计讲透。

## 什么是模型代理

模型代理，是架在本机的一个统一模型出口：所有 AI 软件连它一个地址，它在本地模型与云端厂商之间路由。搭载这一设计的察元AI OS（Chayuan AI OS）是一款 AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

数字对应版本与截止时间，文末尾注一并给出。

## 在察元AI OS里落在哪

模型代理在察元AI OS里的落点是设置 ＞ 模型 里的代理设置页：本机统一 OpenAI 兼容出口（127.0.0.1:52581），智能体只配一个地址；local 星号开头的本地模型未运行自动加载，厂商斜杠开头的请求转发云端，免 Key 直连。

为什么值得单独说：全机 AI 软件共用一套模型配置——地址只有一个，模型随便换，客户端无感。

## 最短上手路径

先搞懂概念再动手：

理解代理模型（概念）

```
本地模型（llama-server 实例）──┐
├─→ 模型代理 127.0.0.1:52581 ─→ 对话 · 知识库 · 智能体
云端厂商（厂商路由转发）───────┘
```

1. 统一命名空间：本地模型叫 local/<模型id>，云端厂商模型叫 <厂商id>/<模型名>（如 local/qwen3.5-4b-q4km、deepseek/deepseek-chat）。调谁都走同一个地址、同一套 OpenAI 兼容协议。
2. 免 key 直连：代理对鉴权层一律放行——不带 key、带任意值都能调用；Authorization 头仅用于审计归因（恰好匹配在册虚拟 key 记智能体名，其余记 anonymous）。真实厂商 key 只在代理服务端解析，永不出本机凭证库。
3. 本地自动拉起：调 local/<id> 时模型已安装但未运行，代理会自动加载它（并发去重，等待窗口较长；内存守卫照常拦截超预算加载）。未安装返回 404「未下载：可到「设置 ＞ 模型设置」的模型库下载」。
4. 好处：以后换模型、换厂商，智能体配置里的地址都不用动——只改模型名即可。

## 落点的能力面

- OpenAI chat/responses 与 Anthropic messages 协议互转
- 对话、嵌入、重排、语音端点齐备
- 本地模型按需自动加载

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，
- 跨端知识库共享：设置跨终端互联（DDS）后，对配对终端开模型加知识库授权，kb_list 自动合并远端库、kb_search 可跨机检索。
- WPS 引用知识库：察元AI文档助手（WPS 加载项）自动发现本机知识库对外服务（52582 端口，
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 默认应用与打开方式：工作区默认打开代理（智能体）加扩展名默认应用覆盖表；文件右键设为默认。
- 插件源与网络设置：内置插件源开关、自定义社区源与技能源、npm registry 与代理设置。

## 配置前要认下的几条

- 设备内存 8GB 时只加载一个对话模型，复杂任务受限
- 龙芯平台这版没排上；视频生成本地不提供，走云端路由
- 云端厂商模型调用，API Key 由自己准备
- Docker 云桌面、跨终端互联这类进阶形态，考验动手能力

边界都在明面上，不影响主流程。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 代理用起来的疑问

### 智能体报 Connection error / 打不通 52581？

按序排查：① 浏览器打 /health（见验证 1）——通则代理正常，问题在智能体配置的地址或模型名；② 不通则到 设置 ＞ 模型 看顶部健康灯，本地模型服务停了代理随之不在，恢复服务即可；③ 服务正常但代理页显示「代理未运行」，点「一键重应用」。注意端口固定 52581 不会漂移，不存在被占用后换到别的端口的情况。

### 调用报「未知模型命名空间「xxx」：应为 local/<id> 或 <厂商id>/<模型>」？

模型名写错了，或该厂商还没加入代理路由。错误响应会附带当前路由表里的可用命名空间（(deepseek, agnes, …)）供对照；厂商加入方法见对应教程 第 8 步。

### 调 local/ 模型返回 404「未下载：可到「设置 ＞ 模型设置」的模型库下载」？

这个 id 的模型本机没装。到 设置 ＞ 模型 ＞ 本地模型 组对应分类的「模型库」下载，或在「我的模型」核对真实模型 id（引用串要和清单里的 local/<id> 完全一致）。

### 卸载会删掉我的数据吗？

卸载只移除程序本体，数据目录留在原地，卸前记得自行备份；要彻底清理，手动删数据根目录即可。

### 模型代理离线时还能用吗

本地模型这条路不依赖外网：调 local/ 开头的命名空间走本机；厂商斜杠开头的请求要转发云端，断网就不通。进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询；写入智能体配置的是代理地址，代理停了它们就连不上模型。

## 一句收束

模型代理的价值要换过一次模型才体会得到：地址没动、密钥没动，只改一个模型名，全机就切过去了。

## 代理设置页长什么样

打开代理设置页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）里点「模型代理设置」。页面自上而下分区：运行状态 ＞ 服务地址 ＞ 虚拟 key ＞ 被代理模型 ＞ 厂商路由 ＞ 调用审计。

用好代理还有个前提：它只监听本机回环，跨机访问得另行打通。
