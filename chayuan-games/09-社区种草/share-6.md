# 睡前挂一场AI锦标赛

首图建议：锦标赛积分榜截图配大字「睡前挂一场AI锦标赛」

睡前最后一件事，从刷手机换成排一场 AI锦标赛 试试。
挑一批模型，设成循环赛，剩下的交给对局引擎自动排程——你关灯睡觉，它们替你打到天亮。
早上睁眼后的头一件事不再是摸闹钟，是点开积分榜看谁是冠军。
这种挂机玩法，把看 AI 打架变成了一种睡前仪式。
对了，比赛不会因为你睡着而暂停，它们不需要观众也能打完全场。
心理上也有妙处：与其睡前刷短视频越刷越清醒，不如想着客厅里那台机器正在替你办比赛，睡得反而踏实。
睡前排赛这个动作本身就很解压，像给明天的自己留了一份礼物。

## 排赛前的三分钟

参赛名单从 85 家厂商目录里挑，DeepSeek、通义千问、Kimi、豆包、OpenAI、Claude、Gemini 都在名册上，接口清一色 OpenAI 兼容。
每配一家，先「测试连接」验 Key，再「获取模型」把账号里能用的型号实拉出来勾选，队伍就齐了。
每家的 Key 独立保存，比赛跑起来互不干扰，一家限流不至于全队熄火。
Key 明文只存本机配置文件，不会随比赛上传到任何地方。
名单可以混搭：云端强模型坐镇，Ollama 本地模型凑热闹，本地推理免 Key 零成本，混着看层次更多。
名单长短自己定：两个模型的单挑局一晚能打好几轮，八模型的循环赛就是通宵大戏，按预算点菜。

## 挂机怎么挂

锦标赛模式支持多模型循环赛，自动排程不用人盯，积分榜实时刷新。
半夜偶然醒来瞄一眼，还能看到战况在推进，有种彩票开奖的错觉。
谁跟谁打、打几轮，引擎全安排好了，你醒来之前赛程已经跑了大半。
排好队伍就可以去洗漱了，中途限流有自动退避兜着，一家接口出状况不拖累全场，代走次数超限的直接判负，整晚不会白挂。
棋类、扑克、麻将都在大厅里，想给哪个项目办赛你自己挑，五子棋快，血战麻将慢，混着排节奏刚好。
棋局的兜底逻辑也在：模型出招失败走启发式代走，能挡杀就挡、能吃就吃；代走超限判负这条线，保证比赛总能出结果。
第二天早上收获的是一整面战报：积分榜、冠军归属，还有一堆可以回放的棋局。

## 早上战报怎么看

先看积分榜，谁领跑、谁垫底，一屏扫完。
再挑几盘关键局进回放，形势曲线摆在那里，哪一手开始崩顺着曲线找。
积分榜截图配一句昨晚战况，发群里比早安帖好使。
复盘里的逐手问叹号标注也值得翻，妙手和失误都被圈了出来。
多翻一步还有协议画像：出招格式遵守率、平均耗时，昨晚每位选手的发挥风格全画在像上。
榜首常客和爆冷黑马同框，是循环赛最有看头的部分。
想留档或者拿去别的工具接着研究，棋谱支持 JSON 导出。

## 顺手记的细节

想深挖就进记录页翻历史局，回放器按协议字段筛关键手；界面中英双语，暗色主题夜里看不刺眼。
战报看累了，把关键局的棋谱 JSON 存下来，攒成自己的模型观察笔记。

## 三个点，两好一坑

1. 省心是真好。排好就睡，全程不用盯，自动排程加兜底机制，挂机体验比想象中稳。
2. 战报够厚。积分榜加回放加标注复盘加协议画像，早上一杯咖啡的时间根本看不完，信息量管够。
3. 坑在账单。云端模型按厂商计费，一晚跑下来 token 量不小，睡前那一眼余额很重要。费用这块没有惊喜，只有惊吓的可能，务必睡前查。
顺手提一句：冠军揭晓那一屏，值得截图发群。

## 也要说实话

- 费用提醒放在前面说：软件本身 MIT 免费，模型调用是真金白银，心疼钱包就把参赛队伍砍短，或者让 Ollama 本地模型顶几个席位，本地推理零成本。
- 不是每晚都能跑完。模型越多、局数越多越慢，规模大了当天看不完很正常，接着挂就行。
- 单场冠军不代表实力定论。结果受当晚接口状态影响，限流、退避都会搅局，别把一次成绩当成铁榜单。
- 挂机也有翻车戏。本地小模型上场基本是送分，纯图热闹可以，较真排名就把它们撤了。
- 挂机请给机器留个凉快环境，长跑一晚，该散热散热。

适合谁：手里模型多、想批量摸底的人，和单纯想睡前挂点乐子的围观党。
不适合谁：对 API 账单敏感到一分钱掰两半花的朋友，挂机的自由是有成本的。

## 评论区高频问题

### 一晚上真跑得完吗？

小规模没问题，模型多、局数多就慢；循环赛是自动排程的，跑不完就接着挂，中断不了大局。

### 费用大概什么量级？

软件不收钱，API 按厂商牌价走；量级取决于模型数量、局数和模型话痨程度，睡前看一眼余额比事后对账单舒服。本地模型多的队伍基本不花钱，就是名次别抱期待。

### 锦标赛和天梯什么区别？

锦标赛是一晚定胜负的循环赛，打完出冠军；TrueSkill 天梯是长线段位爬升，赢者升段，一个管单场，一个管生涯。

### 用本地模型挂机行不行？

行，Ollama 这类本地推理免 Key 又零成本，代价是本地小模型棋力有限，比赛观赏性打折，图个热闹够了。

### 能只看几个模型的对比吗？

可以，参赛名单自己定，两个也行一排也行；人少速度快，人多戏份足，看你想吃快餐还是看连续剧。
