# 自托管模型评测：开源竞技场与商业评测平台

评测跑完，数据躺在别人的服务器上，想复盘还得导出截图——有些团队接受不了这种被动。自托管模型评测把考场搬回自己机器上：数据自己管、过程自己看、费用自己算。察元竞技场是自托管路线里的一个形态，这篇把它和商业评测平台摆在一起，从数据主权、可复现性、费用结构三个维度讲清楚差别，写给正在两条路线之间做选型的人。

三条主线维度，先看一张对照表。

| 维度 | 商业评测平台 | 自托管开源竞技场 |
|---|---|---|
| 数据归属 | 平台服务端，政策以其官方页面为准 | 全部落在本机 |
| 可复现性 | 取决于平台开放程度 | 棋谱 JSON 导出，本机可重放对比 |
| 考察方式 | 多为题库、基准与打分 | 完整棋牌对局，代码裁判 |
| 费用结构 | 以其官方页面为准 | 软件侧零费用（MIT），模型 API 费用由使用者向厂商支付 |
| 定制空间 | 平台限定 | 开源可改，引擎层纯逻辑零 IO |
| 结果公开性 | 平台榜单 | 本机 TrueSkill 天梯，无官方榜单 |

## 数据主权：考场设在家里

商业评测平台把评测做成服务：你提交任务，它在云端跑，结果在它的界面里看，数据政策以其官方页面为准。好处是省事，不用自己搭环境。自托管这边则是装好即用，不用注册不用登录；对局数据在本机怎么备份、怎么清理，都按你自己的习惯来。

自托管把考场设在家里。察元竞技场是 Electron 桌面应用，装在本机，11 款玩法对局全程本地裁决：纯逻辑裁判只认规则真值，模型只出招没有判罚权。Key 以明文保存在本机的应用数据目录里，对局记录、天梯积分、复盘数据一概不出你的电脑；模型流量走本机网关统一出口，随机端口加路径令牌鉴权。接 Ollama 本地推理，整条链路可以完全离线。对内部模型评估、不想外送数据的场景，数据不出本机是硬前提，这一点只有自托管路线能给。省事与主权各有代价，后面边界一节会摊开讲。

## 可复现性：让结果经得起重跑

评测结果能不能复现，取决于过程数据留得全不全。竞技场的对局有完整棋谱，可导出 JSON 文件，回放器支持按协议字段筛选关键手；复盘有逐手？！标注与形势曲线，哪一手翻盘的看得清；协议画像统计每个模型的出招习惯，JSON 格式遵守率、平均耗时都有记录；开局记忆让模型避免在同型局面重复犯错。同一次评测想重放、想换模型对照，本机数据都支撑得住。

商业平台的过程数据开放程度各异，以其官方页面为准，这里不代下结论。

定制空间也值得一说：竞技场开源可改，引擎层纯逻辑零 IO，想把某款玩法的裁判抽出来嵌进自己的流程，或者改计分口径做内部实验，代码都在仓库里；协议固定、记录结构化，二次开发不用对着黑盒猜。商业平台的定制范围由平台方圈定，以其官方页面为准。

## 考察方式的主权也是主权

数据主权之外还有一层容易被忽略：考什么的决定权。商业平台的考察维度由平台定义，你能选的多是跑哪个基准；自托管路线里，考察设计权在你手里。

察元竞技场的做法是把「考博弈」做成完整体系：11 款玩法覆盖完全信息与不完全信息两类博弈；四种对战模式——人机局、机机观战、锦标赛、天梯挑战，人机局里还能随时在 AI 接手与人工接管之间切换；胜负判定 100% 归本机纯逻辑裁判，模型无判罚权；思维链气泡、延迟、token 用量全程可观测。哪些玩法算分、让谁和谁打、跑多少局，全是本机配置的事，调整即时生效，不用走任何申请流程。考察口径自己定，结论才真正对得上你要回答的问题。

## 费用结构：谁的账单谁清楚

商业平台的费用以其官方页面为准，订阅、按量、企业报价都有可能，选型时把这笔账算进总成本。

自托管路线的账很好算：软件 MIT 开源免费，没有平台使用费；花钱的地方只有模型 API，流量去向由你自己填的授权决定，费用由你向厂商支付；Ollama 本地零成本。费用和用量都在自己眼皮底下，锦标赛要烧多少额度，挂之前心里能估量——各家按 token 计费的口径不同，具体以其官方页面为准。

还有个费用视角的差异：商业平台费用随平台报价波动，自托管路线里软件侧永远是零，可控的只有模型 API 一项，预算规划简单得多。开源协议在这条路线上也是主权的一部分：MIT 意味着使用、修改、内部分发都宽松，不受服务条款变更的影响。

## 条件式推荐

要标准化题库分数、要平台背书的榜单结论，商业评测平台合适，选哪家看它覆盖的基准与你的预算。

要数据完全自持、要过程可复现、要考察模型的博弈行为而非答题分数，用察元竞技场这类自托管开源竞技场，装在本机自己跑。

两者结合也常见：题库筛人，对局验货，公开榜单看大盘，本机天梯管自家模型的日常体检，各司其职。

## 实话实说：三条边界

自托管意味着没有大众榜单，你的天梯只反映本机对局，横向对照全平台水平做不到；模型 API 费用自付，大范围锦标赛要掂量额度；察元竞技场聚焦棋牌考察，写代码写文章的能力它不测，版本 0.1.0 功能还会演进。

## 你可能会问

### 自托管评测需要服务器吗

不需要。察元竞技场是 Electron 桌面应用，Windows、macOS、Linux 台式机笔记本都能装，对局与数据全在本机。

### 评测数据可以导出吗

可以。棋谱支持 JSON 导出，回放器按协议字段筛选，复盘标注与形势曲线都在本机可查。

### 商业平台和开源竞技场选哪个

看考察目的。要题库分数与平台榜单选商业平台，以其官方页面为准；要对局行为与数据主权，选开源竞技场，两者不冲突。

### 用自己的 Key 安全吗

Key 明文只存本机应用目录，不上传；模型流量走本机网关统一出口，随机端口加路径令牌鉴权，外部进程够不到。

### 团队内部评测适合用竞技场吗

适合。对局数据不出本机、过程可复现，内部模型的博弈能力评估可以直接跑，天梯战绩独立统计；多人协作类需求按你团队的实际情况另行评估。

数据主权不是口号，是可复现性的地基。考场设在自己机器上，每一手棋谱、每一次退避、每一个画像数据都归你，评测结论才真正经得起重跑。想让模型评测这件事从「看别人放榜」变成「自己出题」，自托管开源竞技场是一条值得走的路。
