# 技能市场指南排查路径：团队技能基线收集

技能市场指南的麻烦不在功能本身，在于信息散。技能是智能体的操作手册，装了技能的智能体才会按你的流程干活。这篇把它收拢成一条能照着走的路径。

## 先定位问题在哪一层

按这个顺序排查技能市场指南通常最快：先确认前置条件（环境与模型就绪），再核对操作路径，最后看边界限制。

## 正确的操作路径

怎么确认技能生效了

1. 安装后重启对应智能体会话
2. 让智能体列出已装载的技能，或直接按技能名调用
3. 技能按 SKILL.md 里的触发条件自动激活
4. 不生效先检查技能目录路径是否放对

上手按顺序做：（第 4 个切入角度）

1. 社区技能聚合
2. 技能包批量形态
3. 搜索与分类
4. 场景验证：给 Claude Code 装发版测试技能
5. 场景验证：团队技能基线收集
6. 串联场景：能力广场 MCP 板块检索
