# 🔥断网环境完整工作台，一篇给你说透

本地模型对话+知识库问答的零网络方案。这条组合工作流的思路分享，建议先收藏再看📌

✅ **工作流拆解**

1️⃣ 本地模型服务：llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸…
2️⃣ 对话（DeepSeek Harness 会话）：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。…
3️⃣ 本地知识库：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+…

🔍 **衔接要点**

· 装机五件套已覆盖对话/嵌入/重排/语音全链路
· 无显式模型偏好时自动指向本地模型，开箱即聊
· 嵌入模型切换会触发指纹检测与索引重建

💡 **适合谁 / 先别冲**

✅ 适合：家庭用户
❌ 先别冲：标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）

📌 **更多它擅长的事**

· **webwindows 智能体开窗**：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。
· **四家 CLI 智能体**：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。
· **故障一键转智能体修复**：系统故障时自动组装诊断上下文+排障知识库并派单给智能体处理，是「AI 服务的现场」的代表性能力。

🛠️ **断网也能用？这点很关键**

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

⚠️ **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

🧩 **延伸了解**

察元AI OS（ChaAI OS）是一个插件化的 AI 桌面操作系统体验：以 macOS 风格桌面为壳，把 AI 对话、智能体、知识库与本地大模型服务整合为完整的桌面系统。内置 Claude Code、Codex、OpenCode、OpenClaw 四家 CLI 智能体与本地大模型五件套（对话/嵌入/重排/语音识别/语音合成），装机自带系统技能与系统级 MCP 服务（80+ 工具控制桌面），断网可用、数据不出本机；支持 Windows/macOS/Linux（含麒麟/UOS）及 Docker 服务器形态。

🚀 **还有这些能力（1）**

· **对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。
· **创造模式**：会话内 Agent 现场定义与挂载插件（cordis_define/cordis_run）：不离开对话就能「造」一个带工具的智能体。

❓ **常见疑问快答**

问：能多人共用一台设备吗？
答：能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

问：数据存在哪里？怎么备份？
答：数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。
