# 察元竞技场两个版本：独立桌面版与察元AI OS内置版

桌面上有「察元AI游戏」图标，察元AI OS 里又有一个竞技场入口，两个名字长得几乎一样——这是什么关系？简单说，察元竞技场两个版本一个独立成应用，一个内置在 OS 里，引擎是同一颗。这篇把两个版本的差别与适用人群讲清楚，写给正在犹豫装哪个的人，也写给已经两个都装、想弄明白该用哪个的人。

一张表先看清两个版本的骨架。

| 维度 | 独立桌面版 | 察元AI OS 内置版 |
|---|---|---|
| 产品形态 | 独立 Electron 桌面应用 | OS 内置应用 |
| 获取方式 | 单独安装，Windows/macOS/Linux 各架构有包 | 随察元AI OS 安装使用 |
| 开源协议 | MIT | 宿主察元AI OS 为 AGPL-3.0 |
| 引擎层 | 11 款玩法裁判、对局引擎、TrueSkill | 与独立版逐字节同构 |
| 适合人群 | 只想玩竞技场的用户 | 已在使用 OS 家族的用户 |
| 配置方式 | 85 家厂商目录、Key 只存本机 | 同一套配置方式 |

## 引擎同构：同一颗心脏

两个版本最重要的共性在引擎层。竞技场的核心是 11 款玩法的纯逻辑裁判加对局引擎加 TrueSkill 评分，这部分在察元AI OS 内置版与独立桌面版之间逐字节同构——仓库里还有专门的同构护栏测试盯着，两边不许漂移。你在哪边打，规则、容错、判罚行为都一模一样，不存在「OS 里的裁判更严」这种事。

差别在壳和宿主。独立版是一个单纯的桌面应用，装完就是大厅、对局室、天梯、回放、设置这些竞技场自己的界面；内置版活在察元AI OS 的桌面环境里，和 OS 家族的其他能力同住一个屋檐下。协议上两家各自独立：竞技场独立版是 MIT，宿主察元AI OS 是 AGPL-3.0；家族里还有察元AI Office、察元AI 文档助手、察元AI工舱和察元AI广场 aidooo.com，各成员协议各不相同。

## 架构上怎么做到同构

同构不是一句口号，是工程结构决定的。竞技场代码分三层：electron 主进程管单实例、模型网关和 JSON 存档的写锁与热读；src/arena 是引擎层，11 款玩法裁判纯逻辑零 IO，外加对局引擎、LLM 玩家、TrueSkill 评分和开局库；src/app 是界面层，大厅、对局室、天梯、记录、回放、设置都在这层。OS 内置版与独立版共享的正是中间那层引擎——纯逻辑、无外部依赖，放在哪个宿主里跑结果都一样。

护栏也是实的：仓库里的同构检查持续校验两边引擎层逐字节一致，漂移会在测试阶段被发现。测试面还铺了三层：vitest 覆盖 11 款裁判边界、玩家协议与网关；real-e2e 用真模型跑端到端；cdp-verify 做真机 UI 验证。两边玩法一致、判罚一致，靠的是这些检查而不是口头承诺。

对使用者来说，同构意味着两件事可以放心：一是在哪边学会的操作，到另一边都适用；二是拿两边跑同一局做对照，结果差异只能来自模型侧与网络侧，不会来自引擎侧。

## 适用人群：轻装上阵和全家桶用户

只想要个棋牌竞技场、电脑里不想多装别的——独立桌面版对路。它体量小、目标纯粹，Windows、macOS、Linux 都有对应架构的安装包，macOS 分 arm64 与 x64，Windows 还有 arm64 版，装完配个 Key 就能开局。

已经在用察元AI OS 的用户，内置版更顺手：不用再装一个应用，在 OS 里直接进竞技场，引擎行为和独立版完全一致。两边玩法与功能清单相同，11 款玩法一个不少，日麻立直同样藏在隐藏入口里，军棋暗棋、翻翻棋也都在。

再往细里说，四种对战模式两边都一样：人机局随时在 AI 接手与人工接管之间切换；机机观战默认匿名，终局揭晓身份；锦标赛多模型循环赛自动排程；天梯挑战按 TrueSkill 段位约战。你在哪边开局、看赛，体验都不会因为选了另一个版本而缩水。

## 配置方式：同一套入口，各自落盘

两个版本的模型配置方式一致：进设置 ＞ 模型配置，从 85 家厂商目录点选厂商，填自己的 Key，点「测试连接」验证；想把某家账号下的模型一次拉全，用「获取模型」实拉列表勾选入库。任何 OpenAI 兼容端点都能手填 baseUrl 接入，Ollama 本地推理免 Key。

不过它们是两个独立的应用，配置数据各自落在各自的应用目录。两边都用的话，模型配置建议各配一遍；是否自动共享，以其官方说明为准。Key 在哪边都只存本机、不上传，模型流量都走本机网关，随机端口加路径令牌鉴权。

配置的几个细节两边也一致：配置写入带写锁，运行时热读取，改完不用重启；「测试连接」校验 Key 可用性，失败会静默回退到手填模型列表；「获取模型」则用当前未保存的输入实拉全量列表，严格实拉不回退。再提醒一句：两边都不上传任何东西，模型流量、Key、对局数据全部本机闭环，这与装哪个版本无关。

## 条件式推荐

设备上只想留一个纯粹的棋牌竞技场，或者给朋友的机器单独装一个玩——选独立桌面版，MIT 协议，按系统架构挑包安装即可，不牵扯其他产品。

已经在用察元AI OS 处理日常事务，不想多装应用，或者想把竞技场放进自己的 OS 工作环境——用内置版，体验同款，省一次安装。

纠结的话，先想清楚你用不用 OS 的其他能力：用，内置版省事；不用，独立版干净。察元竞技场两个版本不互斥，同时装着对比也完全可以。

## 实话实说：三条边界

独立版版本 0.1.0 还在早期，功能会随版本继续调整；察元AI OS 体量比单独的竞技场大，只要棋牌竞技场的话，独立版更轻；两个应用升级节奏各自独立，发版进度以其各自发布页为准。

## 你可能会问

### 两个版本能共用一份配置吗

配置方式完全一致，但它们是独立应用，配置各自落盘，建议两边各配一次；能否自动同步以其官方说明为准。

### 独立版和内置版打的天梯是一张榜吗

不是。天梯数据各自落在各自的应用目录里，两边各打各的榜，互不影响。

### 该装哪个版本

只二选一时看你是否用察元AI OS：用就选内置版，不用就装独立版。想隔离测试模型行为，也可以两个都装，对着打。

### 两个版本的引擎真的一模一样吗

引擎层逐字节同构，仓库里有同构护栏测试持续校验，规则与判罚行为两边一致。

### 两边一起装会冲突吗

不会。两个应用相互独立，数据各自落盘，同时存在互不干扰；只是天梯与对局记录不互通，按需各打各的。

两个版本，一颗引擎。选哪个取决于你想要什么样的桌面：干净的单应用，还是全家桶里的一间棋牌室。规则、判罚、玩法两边都不会给你两副面孔，放心选就好。
