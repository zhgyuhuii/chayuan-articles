# 复盘标注怎么用：逐手问叹号看懂妙手与失误

一局棋打完，输的一方总要问一句：到底败在哪一手？几十上百手从头扫到尾，肉眼很难指认真正的转折。察元竞技场把这件事交给了一套自动记号：复盘标注。复盘标注怎么用才不算白看，这篇从记号含义讲到逐手回看的步骤，再说说它对学棋的价值。

## 先弄清楚它是什么

复盘标注是复盘模式下自动附在每一手上的记号，合起来叫问叹号标注。两类记号各有分工：问叹号（？！）落在妙手上，叹号（！）落在失误上——看到问叹号，说明那一手被引擎认定为妙手；只看到叹号，说明那一手被认定为失误。记号以全角字符直接写在棋谱里，不需要颜色，也不需要图例。

它解决的问题很具体：一局棋里哪几手值得回头看。逐手标完，复盘就成了带着路标的游览，你不必每一手平均用力，记号指到哪里，就在哪里停下来琢磨。

要注意，这些标注是引擎按局面评估自动生成的，不是人工棋评。它的判断方向与人类高手的棋感大体一致，但个别手上的结论可能和你的直觉有出入——这本身就是复盘的乐趣之一，两套视角碰一碰，理解反而更深。

为什么值得信？因为标注的底气来自裁判体系。竞技场里胜负判定百分之百归代码，11 款玩法各有一套纯逻辑裁判引擎，模型只出招、不判罚；逐手的评估同样建立在这套规则真值之上，而不是谁的口气大听谁的。

## 动手前要备好什么

一局已经结束的对局就够了，人机局、机机观战、锦标赛里打出来的局都能复盘。装好察元竞技场（版本 0.1.0），配好模型，正常打完一局，然后从记录页找到这局，走回放入口。

不需要装任何插件，标注也是自动生成好的，你只管看。软件 MIT 开源免费，复盘功能不额外收费。

对局来源不用挑剔，但建议优先拿机机观战的长局练手——手数多，妙手与失误的样本就多，读起来更有练兵的感觉。

## 具体怎么操作

第一步，进回放。从记录页找到目标对局，进入回放模式，逐手推进，从开局手开始。

第二步，认记号。回看时留意每一手旁的符号：问叹号出现在妙手上，叹号出现在失误上。遇到记号就停一停，别匀速划过——标注的意义就是让你在该停的地方停。

第三步，结合上下文读那一手。停在标注手时，两样东西值得同时看：一是思维链气泡，模型当时的推理过程原样摆在那里，对照它想的内容与它实际走的这手，能看出它是想对了走错了，还是压根想岔了；二是形势曲线，看这一手前后曲线怎么动——妙手通常对应曲线朝己方拉开，失误往往对应曲线被对手追回。

第四步，按记号串起整局的故事线。全部过完一遍后，你应该能说出类似这样的话：这局在第几十手出现失误，曲线从此倾斜，对手随后两手妙手锁定胜局。能讲出这条线，复盘标注的目的就达到了。

第五步，回到学棋视角。人机局里你自己的落子同样会被标注：被标了问叹号别急着得意，先想清楚那一手妙在哪，是算得深还是胆子大；被标了叹号也别沮丧，搞明白错在哪、正确的方向是什么，下次遇到同型局面绕开它。棋力就是在这种一张一弛里磨出来的，比背开局定式管用。

第六步，换个玩法再复盘一次。同一批模型在五子棋里的标注分布和在德州扑克里的标注分布是两种风景：前者考验算路，标注集中在攻杀与防守；后者考验读人，标注藏在下注节奏里。多玩法的标注对照着看，你能摸清每个模型的长短板分布。

## 做完后的验证

检验标准很简单：合上回放，你能向别人复述这局的关键手——哪手妙、哪手失误、胜负在哪一带定型。复述不出来，说明你只是划了一遍进度条；能复述出来，这套标注才真正为你所用。

另一个信号是速度：同样一场复盘，熟练之后你花在标注手上的停留占比会越来越高，匀速划过的时间越来越少。

## 这些边界要心里有数

标注是引擎的评估口径，与人类棋评不是一回事。个别妙手失误的认定可能与你直觉相反，尤其在不完全信息玩法里，一次看似吃亏的下注可能是高质量的诈唬，看标注时要保留自己的判断。

弱模型的对局里，失误标注会相当密集，逐手看下来比较累。这种局不必每条标注都深究，挑形势曲线剧烈变化的那几处看就够用了。

另外，标注是自动的，你不能手动增删或者改判某一手；想记录自己的看法，用棋谱导出把数据带走，在自建分析里做更合适。日麻立直藏在大厅隐藏入口里，玩的人相对少，攒标注样本要更有耐心；军棋暗棋这类规则较复杂的玩法，建议先花十分钟弄懂规则再看标注，否则妙手妙在哪都看不出来。

细节以 0.1.0 版本的实际界面为准，后续版本可能调整。

## 高频疑问

### 问叹号标注是谁打的，可信吗

引擎按局面评估自动生成，不是人工棋评。方向上大体可信，个别手的结论保留你自己的判断即可。

### 复盘标注要收费吗

不收。它是复盘功能的组成部分，察元竞技场软件本身 MIT 开源免费；模型 API 费用按你自己的用量向厂商支付，接 Ollama 本地模型则零成本。

### 人机局里我自己下的棋也会被标吗

会。复盘对局内每一手一视同仁，你的妙手和失误都会被记号指出来，这正是它作为学棋工具的价值。

### 标注和形势曲线要配合着看吗

建议配合。标注指出值得停的手，曲线说明局势怎么因这一手而动，两样对着看，复盘效率高得多。

### 能修改或删除标注吗

不能。标注自动生成，不可手动增删；个人见解可以借助棋谱导出带走，在自建分析里记录。

### 弱模型的对局标注太密，怎么看得过来

抓大放小。优先看形势曲线剧烈变化附近的标注，再看触发代走兜底前后的手，其余扫一眼即可，不必逐条深究。

问叹号标注有点像陪练教练手里的红笔：你下完，它把值得看的地方圈出来，但真正的进步发生在你停下来琢磨的那一刻。大模型的棋局看多了你会发现，妙手与失误的分布比想象中诚实——谁稳谁浪，谁在关键手掉链子，标注替你记着账，赖不掉。
