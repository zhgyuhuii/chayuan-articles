# 配置要求：模型配置可一键写入五家

先说这篇能帮你干什么：读完能在察元AI OS里独立完成配置要求，路径是配置要求。步骤里的每个「」按钮都是界面原文。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：内存架构系统版本一张表。

安装包从官网 aidooo.com 获取。

## 完整操作步骤

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 其他平台装法速览

Linux（deb）：按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64；sudo dpkg -i 安装 deb 包；应用菜单启动，首次启动自动初始化数据目录。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 这些坑和边界要知道

用之前要认的账：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 放回产品盘面看

把配置要求放回察元AI OS的整体盘面：换个智能体接班不用重新自我介绍，记忆全机共享是系统级的黏合剂，设置里指向远程 dsh web 地址并测试连接，桌面客户端接远端算力，本机轻薄、远端肥厚时，桌面只当壳，遥测开关、清除桌面数据（破坏性操作有警示）。

## 安全与数据边界

安全口径单独立一层：周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；本机轻薄、远端肥厚时，桌面只当壳；遥测开关、清除桌面数据（破坏性操作有警示），升级不丢数据是底线，检查更新静默失败不影响使用。

## 平台与形态

平台与形态的账：模型配置改乱了、服务起不来，回到出厂态是最干净的自救手段，一键回到出厂模型配置；右键编辑改配置，删除有两步确认，桌面上的野宠可以收编为正式灵宠建档；命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一。
