# 出差/远程办公者的远程办公方案（效率视角）

如果你是出差/远程办公者，下面这些场景大概率不陌生：外面连不回公司机器。手机连回你的 AI 工作站。这篇效率视角以察元OS为工具，把这个岗位的远程办公工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 外面连不回公司机器
- 手机上没桌面环境
- 临时要处理文件

## 用察元OS怎么解：工作流拆解

1. 云通道连接设备
2. 手机浏览器 /m/ 入口
3. 远程查看与操作

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「云通道连接设备」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。手机连回你的 AI 工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 需提前配置云通道
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 如实说说它的不足

- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 能多人共用一台设备吗？

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。
