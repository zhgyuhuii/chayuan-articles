# 大模型板块避坑指南：从入口到完成的完整流程

大模型目录是察元AI 能力广场里使用频率很高的一项能力。它的「大模型板块」这样工作：主流大模型信息目录：能力、入口、定价参考，配合智力榜/免费榜/对比页使用。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

主流大模型信息目录：能力、入口、定价参考，配合智力榜/免费榜/对比页使用。

从任务视角看，它对应的关键词是「大模型目录」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 进入 model 板块（模型中心）
2. 按厂商/能力筛选
3. 查看定价与入口
4. 跳转对比页横向比较

## 适用场景

- 模型选型调研
- API 入口查找

## 进阶技巧

- 模型详情关联实测分数

## 注意事项与边界

- 价格以厂商官方为准
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 网站本身需要网络访问（内网场景走私有化部署方案）
- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性

察元AI 能力广场属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI OS（插件化的 AI 桌面操作系统，本地大模型与智能体工作站）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 能投稿自己的项目吗？

可以。投稿页提交资源信息（简介、安装命令、官网地址），进入人工审核队列；重复、信息不全或活跃度低的项目可能被拒，状态在「我的」页查看。

### 模型价格信息准吗？

价格页为人工整理的参考价目（40 厂商 201 条目），模型定价随厂商政策变动，下单前请以厂商官方页面为准。

### 政企可以私有化部署吗？

可以，整套门户支持 Docker+nginx 私有化部署，数据与升级自主可控。
