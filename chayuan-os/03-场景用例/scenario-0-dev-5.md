# 开发者的开发者工具方案（清单式指南）

如果你是开发者，下面这些场景大概率不陌生：AI 编程工具装一堆、配置各一套。把工具链收进一个桌面。这篇清单式指南以察元OS为工具，把这个岗位的开发者工具工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- AI 编程工具装一堆、配置各一套
- 本地模型与云端模型来回切
- 系统操作与编码上下文割裂

## 用察元OS怎么解：工作流拆解

1. 安装后四家 CLI 开箱即用
2. 智能体管理统一供应商档案
3. 系统技能让智能体能操作系统
4. MCP 一次配置六家同步

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「安装后四家 CLI 开箱即用」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。把工具链收进一个桌面。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 四家 CLI 约 1.3GB，注意磁盘
- Docker/云通道等进阶形态需要一定动手能力
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- Docker/云通道等进阶形态需要一定动手能力
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 产品家族与生态位

察元AI OS属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI 能力广场（aidooo.com）（人工智能资源门户：插件/技能/MCP/提示词/模型一站检索）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
