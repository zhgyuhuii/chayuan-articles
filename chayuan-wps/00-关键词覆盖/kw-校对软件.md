# 校对软件是什么：定义、场景与上手路径

关于校对软件，网上说法很多，有说简单的有说复杂的。实际用下来，察元AI文档助手的拼写与语法检查路径是清晰的，只是有些细节不说不知道。这篇按真实操作走一遍，顺带把容易误解的点标出来。

## 什么是校对软件

顶部工具栏「拼写与语法检查」按钮对全文或选中内容做错别字、语法、标点、搭配检查：有选中只查选中，无选中确认后查全文；检查在独立进度窗里分块并发执行，关掉进度窗任务照跑，结果以批注形式精确钉到原文问题处。

放到察元AI文档助手的语境里：WPS 三端智能加载项，校对、编审、核对、脱密，一个文档智能体，拼写与语法检查是其中承上启下的一环。

## 先看看痛点对不对得上

分块并发让长文档校对不再超时，批注式结果方便逐条确认。

典型使用场景：重点段落精查，发文前全文校对。

## 在察元AI文档助手里怎么用

入口与核心步骤：

1. 发起检查

1. 在哪：顶部工具栏「AI 助手」分组的大按钮「拼写与语法检查」。
2. 看到什么（按选区分流）：
    1. 有选中（不少于 2 个字符）：直接以「选中」模式启动，只检查选中内容；
    2. 无选中：弹确认框「当前未选中文档内容，将对全文执行“拼写与语法检查”。 点击“确定”后开始处理全文。」——全文超过 12000 字时附加「当前内容较长，处理可能需要更久，请耐心等待。」，超过 30000 字时附加「当前内容很长，处理时间可能较久，并可能触发分段或较长响应，请确认后继续。」；点「确定」开始，「取消」不执行；
    3. 文档没有正文：提示「当前文档没有可检查的正文内容」。

2. 读进度窗

1. 看到什么：独立提示窗，标题「拼写与语法检查」（选区模式为「拼写与语法检查（选中）」），标题旁状态徽章：准备中 / 进行中 / 已完成 / 失败 / 异常结束 / 已停止。
2. 副标题固定一行：「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」
3. 进度区：「正在检查：第 x / y 段」+ 百分比进度条 +「当前检查内容」卡显示正在检查的原文片段。
4. 右上按钮：「停止任务」（仅任务运行中显示）和「关闭」。
5. 完成时显示「已完成，共添加 N 处批注」，随后提示「即将自动关闭」并自动关窗；停止后显示「任务已停止」。
6. 底部提示：「可在「任务清单」中查看详细进度；关闭此提示窗不会停止任务。」

3. 看结果：批注钉在原文上

1. 看到什么：每处问题在原文对应位置加一条批注。模型按结构化 JSON 返回每个问题的问题片段、建议改法、原因、所在整句和前后各最多 12 个字的锚定上下文；程序按「原文查找 ＞ 范围复核」把批注精确钉到问题文字上（表格里的坐标漂移会自动重定位，钉不上就不硬挂）。
2. 批注内容格式：「<原因>: 建议改为「<建议>」」（无建议时只写原因），例如「错别字: 建议改为「作业」」。

## 怎么判断适不适合你

适合你的情况：日常就是发文前全文校对，希望流程固定、结果可验证。

不必勉强的情况：需求不在这条线上的人。察元AI文档助手的思路是把边界写明白，条件式地推荐。

## 常见问题

### 报「请先在设置中配置拼写与语法检查模型」？

说明默认对话模型也没配好。到设置里配好对话模型，或在设置里专门指定「拼写与语法检查模型」后重试。

### 长文档检查很慢，能提速吗？

检查按块分片进行，默认块长约 6000 字。从工具栏发起的检查要边查边写批注，逐块串行执行；通过文档智能体发起的校对（先出预览、你确认后再落笔）按并发设置执行（默认并发 3，可调 1–8，当前版本这两个参数暂无设置界面）。最有效的提速是给检查指定一个更快的「拼写与语法检查模型」。

### 检查会直接改动我的正文吗？

不会。检查结果只加批注；要把建议落到正文，用对话链路「校对结果」卡上的「直接改正正文」按钮（按定位逐处安全替换，定位不稳的自动降级为批注），或按批注手动修改。

### 关闭进度窗后任务还在跑吗？

在跑。副标题写明「任务可关闭提示窗继续执行，只有点击停止才会中止任务。」关窗不影响检查；只有点「停止任务」（或任务清单里的停止）才会中止。

## 补充答疑

### 为什么有些“病句”没被报出来？

检查提示词只报「明确可证实的错别字、语法错误、标点误用、固定词误写、搭配错误」，明确排除风格偏好、口语化、语气优化等主观润色项，避免误报。需要文风润色请用「文本分析 ▾」里的相关功能。

## 更多操作细节

4. 中途停止

1. 在哪：进度窗「停止任务」按钮（或任务清单里对应任务的停止入口）。
2. 看到什么：任务状态变「已停止」。停止信号跨窗口生效——即使你关掉了进度窗，也能从任务清单里停掉它。

5. 对话里也可以校对（MCP 链路）

1. 在哪：AI 助手窗格开启文档智能体后，直接对 AI 说「校对一下这篇文档」。
2. 看到什么：模型跑校对任务后，消息里出现「校对结果」卡（汇总发现 N 处问题），下方两个按钮：「写成批注」和「直接改正正文」——选哪个由你决定，不会不打招呼就改正文；本轮修改前已创建快照时还有「一键撤销」卡。

## 安装与运行答疑

### macOS 装完还是旧版？

安装器无完全磁盘访问权限时容器写入会假成功，运行官方修复脚本 repair-mac-jsaddons-container.sh（支持 status、修复、rollback 三种模式）后重装。

### Win7 或 Win8 能用吗？

加载项可装，但 MCP 预编译二进制跑不了，需要装 Node.js 16.x，由启动脚本自动回落到 node 运行。
