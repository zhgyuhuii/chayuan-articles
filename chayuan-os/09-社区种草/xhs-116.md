# 🎯本地模型服务隐藏用法｜本地大模型一次讲清

用过察元OS的宝子看过来，本地模型服务这个功能很多人没用到极致👇

✅ **它能干嘛**

llama.cpp（对话）+ whisper.cpp（语音识别）+ sherpa-onnx/piper（语音合成）引擎随软件分发；一个模型一个进程，显式加载/卸载，内存预算=总内存 45% 硬底线，崩溃自清理。

🔍 **三步用起来**

1️⃣ 模型服务应用里浏览模型库
2️⃣ 显式加载需要的模型
3️⃣ 用完卸载释放内存

💡 **什么场景最香**

· 按任务灵活挂载模型

📌 **避坑提醒**

⚠️ 8GB 内存建议一次一个对话模型

🛠️ **更多它擅长的事**

· **Dock 与窗口管理**：Dock 支持位置/自动隐藏/放大效果/图标三挡大小、分组（徽章+溢出计数）、Windows 式最小化磁贴；多窗口可拖拽、多屏切换。
· **四家 CLI 智能体**：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。
· **察元智能广场**：内嵌 aidooo.com 能力广场的桌面应用：离线时回落本地页；与网页版同源，检索 2.5 万+ 插件/技能/MCP/提示词/模型资源。

⚠️ **断网也能用？这点很关键**

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

🎯 **数据安全要知道的**

· 全部本地服务只监听 127.0.0.1，数据不出本机
· 本地模型五件套随软件分发，断网即用
· 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

🧩 **说点大实话（缺点）**

· 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大
· 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
· 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
