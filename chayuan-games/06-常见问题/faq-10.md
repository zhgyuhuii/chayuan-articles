# 对局数据会泄露吗：记录、天梯与隐私边界

下棋打牌的记录算隐私吗？有人觉得不过是一盘棋，有人连棋谱都不想让外人看见，尤其是机机观战里模型聊了什么、你的模型阵容怎么搭配的。对局数据会泄露吗？察元竞技场的处理思路一句话能概括：全部落在本机，没有任何上报动作，想带走自己导出。演示和真博弈的区别之一，就是数据愿不愿意留在你手里。这篇结论先行、边界后置，把记录存在哪、天梯积分怎么管、云端模型看到什么、导出后的责任边界挨个划清，这条边界同样适用于你把棋谱发到网上之前要想清楚的事。

### 对局数据会泄露吗？先把结论放在前面

竞技场这边没有泄露通道：对局记录、天梯积分、棋谱全部落在本机 JSON 存档，没有任何上报行为，软件也不依赖什么账号体系，没有云端档案，你的战绩只活在你的硬盘里；11 款玩法的裁判都在本地跑，判定过程不依赖任何在线服务，你打过的每一局都只待在自己的电脑里。要说完全没有风险也不诚实，风险来自两头——你主动用云端模型时发给厂商的内容，和你本机文件本身的安全，这两头后面分开讲，一个一个拆。

### 对局记录存在哪里，是什么格式

在本机应用数据目录里，JSON 格式的存档文件。每局的记录带着完整过程：谁坐哪个座位、每一手的出招与 comment、胜负结果，都写进存档。文件的读写带写锁，运行时热读取，多开对局时记录不会互相踩，也不会把文件写坏；存档目录跟着应用走，卸载应用不等于删除存档，想清理要动手删文件。JSON 存档的可读性是刻意为之，你想审计自己被记了什么，用文本编辑器打开就知道，结构对程序分析也友好，自己写脚本做统计没有门槛。

### 天梯积分也存在本机吗

是，TrueSkill 天梯的积分和段位同样落在本机存档。模型们的排位、你作为人类挑战者的独立战绩，都记在本地文件里，不经过任何服务器；积分数据的更新发生在每局结算后，写锁保证并发对局不打架。换句话说，这个天梯是你自己电脑上的排位现场，删掉存档等于重开一档，备份存档等于留住整个赛季，想给朋友展示战绩，截图或者导出棋谱都行，发什么、发多少由你决定。天梯数据没有云端备份，重装系统前记得先备份存档目录，这比什么承诺都实在。

### 打牌下棋的过程会被上传吗

不会。对局室里的思维链气泡、每手的延迟和 token 用量，这些展示内容都来自你本机与厂商接口之间的请求，思维链气泡里的内容来自模型本来的回复，展示在本机界面里，不上传别处；竞技场不做二次上报，也没有遥测这一说，11 款玩法的裁判判定全在本地代码里完成，模型出的招先过本机容错链，才进棋盘。整个软件里找不到一个「把对局发出去」的动作，竞技场自己不产生对外流量，对外的流量只有你配的模型请求，你不必翻抓包工具去验证一句承诺。

### 用云端模型时，厂商能看到我的对局吗

能看到发过去的部分，这是云端模型的固有属性：模型要出招，就必须看到局面、历史和合法动作清单，这些内容随请求发给你所选厂商的接口。用哪家，哪家就收到，这是你自己填 Key 授权的；想知道发了什么，看导出棋谱里的对局上下文，和请求内容基本同源。这一点不是竞技场的锅，任何调用云端模型的产品都一样，区别只是有没有跟你说清楚。想缩小暴露面，就少用云端模型玩你不想让厂商看到的局，或者干脆上本地模型，整条链路不出你的电脑；用云端时，就当在对局室门口挂了块「厂商可见」的牌子，知情权在你，选择权也在你。

### 棋谱导出之后归谁管

归你管。棋谱可以导出成 JSON 文件，放到哪个网盘、发给哪个朋友、喂给哪个分析程序，都是你的自由，把棋谱喂给自己的程序做分析，正是开源协议欢迎的玩法；竞技场只负责把文件生成出来，导出后的流转它既不知道也不参与。这份自由也附带责任：导出文件里带着完整的对局过程和你用的模型信息，往哪里放、给谁看，风险自己掂量，别把自家的排位家底随手丢进公开网盘；导出文件不做脱敏，里面有什么你导出前就能看，心里有数再出手，定期导一次还能兼作赛季备份。

### 机机观战的匿名设计跟隐私有关吗

有关系，但保护的是观战体验而不是数据。机机观战默认匿名，座位上只显示玩家A、玩家B、玩家C、玩家D，哪把座位坐着哪个模型、谁手里捏着什么牌，要等终局才揭晓，这样你看牌局不会被「我知道某模型拿了好牌」的预设立场带偏，解说和复盘也更客观；观战里模型之间的「对话」其实是各自的出招 comment，看它们嘴上互相较劲也是乐趣。匿名是体验设计，终局揭晓属于玩法的一部分，和隐私保护不是一回事，别混淆；匿名期间的信息都在你本机，谈不上泄露，是设计好的悬念。

数据边界捋下来是一条清晰的线：本机之内，记录、积分、棋谱全归你；本机之外，只有你亲手授权的云端模型请求。竞技场不上传、不遥测、不建账号，把隐私的主动权整个交回用户手里。剩下的部分——电脑的锁、网盘的选择、Key 的轮换——是每个本机应用用户共同的家庭作业，谁也替不了你，把这些做完，这条边界才真正完整。数据留在哪里，是产品的态度；数据怎么用，是用户的修养；这条边界想稳，两端都不能省。
