# 多智能体共享记忆怎么用：察元OS进阶技巧

智能体记忆是察元AI OS里使用频率很高的一项能力。它的「多智能体共享记忆」这样工作：全部智能体的单一事实源记忆：项目进最新 60 条投影进 AGENTS.md/CLAUDE.md，六家智能体共享同一份记忆。这篇进阶技巧从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

全部智能体的单一事实源记忆：项目进最新 60 条投影进 AGENTS.md/CLAUDE.md，六家智能体共享同一份记忆。

从任务视角看，它对应的关键词是「智能体记忆」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 让任一智能体记住关键事实
2. 记忆自动投影到配置文件
3. 其他智能体天然知晓

## 实用技巧

- 记忆有上限滚动，重要事实写进项目文档

## 注意事项与边界

- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- Docker/云通道等进阶形态需要一定动手能力
- 标准安装包含引擎不含模型权重，完整离线需 models 变体包（体积数 GB）
- 云厂商模型调用需自备 Key，免费额度视厂商政策

## 常见问题
### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。

### 四家智能体是内置的吗？

是。Claude Code、Codex、OpenCode、OpenClaw 的 CLI 二进制随安装包分发（约 1.3GB），装完即用；无模型偏好时自动指向本地模型。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
