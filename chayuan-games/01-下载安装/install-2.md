# 察元竞技场Windows安装：exe双架构安装步骤

先给结论：察元竞技场Windows安装的难度集中在选包这一步，选对了 exe，后面的安装就是一路确认。这篇按选包、安装、首启验证的顺序走一遍，每步写清你会看到什么，Windows 用户照着做就能跑通。

## 装之前先认识它

察元竞技场是察元AI 家族的开源棋牌竞技场，MIT 协议，让各家大模型在 11 款棋牌玩法里对弈，从五子棋、象棋、围棋到斗地主、德州扑克、麻将都有。它在 Windows 上以 exe 安装包形态分发，装好后是一个独立的桌面应用。

有个名字上的细节：它的 Electron 产品名叫「察元AI游戏」，安装包文件名和装好后的应用名里都是这几个字。你在开始菜单里搜不到「察元竞技场」四个字时别慌，搜「察元AI游戏」或者「察元」就能找到。写稿依据的版本为 0.1.0，口径时间 2026 年 11 月。

## 选包：x64 还是 arm64

Windows 提供双架构 exe，选错架构是装不上的，所以把这一步单独拎出来。

绝大多数人的答案是 x64。打开系统设置，进到系统信息或「关于」相关的页面，看系统类型：写「基于 x64 的处理器」就选 x64 包。台式机、普通的英特尔与 AMD 笔记本全在这一类。

arm64 包是给骁龙平台的 Windows 笔记本准备的。如果你的设备型号本身是 ARM 架构（近年一些主打续航的轻薄本），系统类型一栏会写基于 ARM 的处理器，这时才选 arm64 包。

一句话：拿不准就开系统设置查一眼系统类型，十秒钟的事，比装完失败再排查省时间。安装包认准官方渠道去拿，来路不明的第三方下载站别碰。

## 安装步骤：每步看到什么

选好包之后，过程很短。

先双击下载好的 exe。如果弹出系统的安全提示，询问是否运行不认识的应用，先确认这个包确实来自上面两个官方渠道，确认无误再选择继续运行。提示本身不代表包有问题，只是系统对没有广泛分发记录的安装包的常规提醒，处理思路在本系列排错篇里还有展开。

接着进入安装向导。向导会请你确认安装位置，默认给出一个系统盘下的程序目录，没有特殊需求就用默认值；想把软件放到别的盘，在这里改路径即可。之后就是等向导跑完，进度条走完会给出安装完成的提示。

装完后从开始菜单启动。应用名显示为「察元AI游戏」，如果你在安装时允许创建桌面快捷方式，桌面上也会有一个对应图标，双击就能打开。

## 首启验证：看到什么才算装成了

打开应用后，你应该看到一个暗色底的整体界面，这是它的竞技场风格，中英双语支持。首屏功能区就是大厅：11 款玩法按棋类、扑克、麻将三组排开，五子棋、中国象棋、围棋、军棋、斗地主、德州扑克、掼蛋、三款麻将都在列。

看到大厅只算界面正常，还要验证引擎和网关活着。最简单的办法是进设置 ＞ 模型配置，看厂商目录能不能正常展示——内置 85 家厂商，列表能刷出来，说明应用本体的资源加载没问题。再配一家你手上有 Key 的厂商，点「测试连接」，有反馈就说明模型网关也在正常工作。到这里，安装与首启验证就闭环了。

回大厅开一局人机局，让模型走两手，看对局室里的思维链气泡能流出来，整条链路就都通了。

顺带说两个首启时会遇到的小现象。一是重复双击图标不会开出第二个窗口，主进程做了单实例处理，再次启动会把已运行的窗口带到前台，这是设计行为不是故障。二是界面目前是暗色主题，喜欢浅色的用户先适应一下，配色属于设计取向，与显示设置无关。

## 程序目录与应用数据目录是两回事

装完之后，你的电脑上有两个地方和它相关，分清了能少很多困惑。

一个是你选的安装目录，放的是程序本体，卸载软件动的是这里。另一个是应用数据目录，API Key 配置、对局记录、天梯积分都存在这里，位置跟着系统用户走，不在安装目录里。

这个区分有两个实际用处：重装软件时你的配置与数据不受影响；想彻底清理时，光卸载程序不够，还要去应用数据目录把残留一并删掉。这份配置文件的具体机制，本系列讲 Key 管理的那篇有完整展开。

## 边界与实话

三条要说。架构别选错，arm64 的包装到 x64 机器上会直接失败，反过来一样，重下对应架构即可。部分安全软件可能对不太出名的安装包弹提醒，从官方渠道下载的包可以核对来源后放行，但判断权在你，拿不准就先去开源仓库核对发版说明。版本 0.1.0 还在早期，安装器形态与目录结构都可能随版本调整，遇到细节对不上以软件实际为准。

另外一句安装路径的建议：向导里的默认路径直接用没有任何问题，想改路径时避开层级很深或名字怪异的目录，这是 Windows 装软件的通用稳妥习惯，与这款应用无关。

另外提醒一句费用口径：软件本身 MIT 开源免费，但云端模型的 API 费用由你自己向厂商支付，Windows 机器挂机跑锦标赛烧的同样是你自己的额度，介意账单就接 Ollama 本地模型。

## 装机相关的几个疑问

### 装在 C 盘还是 D 盘

安装向导里路径可以改。软件本体不大，放默认的系统盘目录没有任何问题；想集中管理就换到常用的软件盘。模型 API Key 与对局记录存在应用数据目录里，跟着用户资料走，与安装盘选择无关。

### 装完开始菜单里找不到应用

搜「察元AI游戏」，它的 Electron 产品名与「察元竞技场」不同名，搜中文名搜不到是正常的。再不行就去安装目录里找启动程序。

### 有没有免安装的绿色版

官方目前提供的是 exe 安装包形态，没有绿色免安装版。想少装东西可以考虑在 Linux 上跑，或者等后续版本看官方是否提供新形态，以官方发布页的实际产物为准。

### 想卸载怎么办

从系统设置的「应用和功能」或「已安装的应用」里找到它，按常规流程卸载即可，与其他桌面软件没有区别。

### 装完需要重启电脑吗

不需要。安装向导走完直接启动应用即可，没有需要重启系统才能生效的驱动或服务，这一点与很多软件相同。

### 能同时开好几个应用窗口吗

不能。主进程做了单实例处理，重复启动只会把已开的窗口带到前台。想让多场对局并行，在应用内同时开多局即可，不需要多开应用。

Windows 这边从选包到验证就这么多内容，真正容易卡人的只有架构判断这一处。装好之后别停，去设置里把模型配上，看大模型在你的屏幕上走出一步棋，比看任何介绍都直观。
