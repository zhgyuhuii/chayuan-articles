# 协议画像怎么读：摸清每个模型的出招习惯

模型和人一样有性格。有的出招干脆利落，有的动不动进入长考；有的规矩得像交作业，每次都把格式写得整整齐齐，有的十次里总有三四次格式跑偏。这些差异在对局室里零散地飘过，很难形成整体印象。察元竞技场把它们攒成了一份档案：协议画像。协议画像怎么读，每个指标什么含义，这篇说清楚。

## 先弄清楚它是什么

协议画像是一个统计功能：统计每个模型的出招协议习惯，把 JSON 格式遵守率、平均耗时这些指标汇总起来，形成一份「模型性格画像」。

先解释两个核心指标。

JSON 格式遵守率：竞技场要求模型按统一协议出招，规范的输出是带 JSON 的着法。遵守率高，说明这个模型大多时候规规矩矩按格式出牌，解析容错链很少介入；遵守率低，说明它经常输出跑偏，系统要靠剥思维链、抽大括号这些容错手段帮它把招捡出来，极端时还会触发代走兜底。

平均耗时：模型走一手平均花多长时间。这个数字受多重因素影响——网络状况、厂商限流、模型本身的思考档位。思考型模型在长对局里通常更稳，但一手的等待时间也长，这是性格不是毛病。

为什么要在意遵守率？因为它直接牵动两样东西：对局流畅度与你的耐心。遵守率低的模型，解析容错链频繁介入，出招延迟叠加，观战节奏一卡一卡；遵守率高的模型，出招一步到位，看着舒服。画像里的数字，背后全是真实对局里的体验差异。

这两个指标之外，对局室里每手的延迟与 token 用量是实时散点，协议画像是把它们沉淀成汇总视角。一个管当下，一个管档案，合起来才是完整的模型观察。

## 动手前要备好什么

协议画像读的是统计，统计需要样本。先把想观察的模型拉上桌打上若干局——机机观战挂着跑就行，样本攒够了再来看画像，数字才有参考价值。另外对「协议」这个概念有个基本认识：模型出招走统一协议，格式规范与否直接影响对局流畅度，这是理解画像的前提。

样本怎么攒有讲究：与其一场超长对局，不如多来几场中等长度的——场次多比单场长更能抹平偶然性，画像里的均值才靠得住。挂机的时候费用提醒照旧：云端模型自付额度，Ollama 零成本。

## 具体怎么操作

第一步，攒样本。给你关心的模型安排若干场对局，玩法可以混着来，也可以盯住单一玩法看更纯粹的表现。

第二步，打开协议画像，找到对应模型的条目，逐项看指标：JSON 格式遵守率在什么档位，平均耗时是快是慢。

第三步，横向对比。把几个模型的画像摆在一起看，差异立刻显形：谁守规矩谁爱跑偏、谁出招快谁爱长考，一张表上分明。

第四步，结合对局表现解读性格。指标是骨头，性格是肉：遵守率高、耗时短、战绩也不差的，是「规范快枪手」；遵守率平平但棋风凶悍的，是「散装猛将」；耗时长的要分清是网络慢还是真的在深思，对照对局室里思维链气泡的长度能看出端倪。给每个模型写一句性格小结，画像才算读透了。

再往深处走一步，可以把性格与玩法绑着看：同一个模型在象棋里守规矩、在德州扑克里跑偏，未必是它变了，可能是牌类协议对它更难。分玩法攒画像，结论比混在一起算更扎实。

第五步，让画像反哺配置。知道哪个模型格式稳，锦标赛、批量选模型拉选手时心里就有谱；知道哪个模型动辄触发容错，安排对局时对它的等待时间就有预期，不会误以为是应用卡了。

## 做完后的验证

拿你的模型名单做个快问快答：随便点一个，说出它的 JSON 遵守率大概什么档位、出招快还是慢、容易不容易跑偏。答得上来，说明画像读进去了；答不上来，回去再对着指标过一遍。

顺便练练横向眼光：把两个模型的画像交换着看，问自己「如果让它们同桌打一场，谁的节奏会乱」。能用画像预判对局气质，说明指标已经内化成直觉。

## 这些边界要心里有数

画像统计的是协议习惯，不是棋力。遵守率高不代表下得好——一个格式漂亮但招法平庸的模型完全可能画像好看、战绩难看，反过来也成立。棋力看天梯，习惯看画像，两码事。

样本量小的时候，数字波动很大。三五局攒出来的遵守率说明不了太多，别急着下硬结论；多打一些场次，画像会自己变清晰。

平均耗时的对比要留心公平性。跨厂商对比时，网络与限流的影响混在里面，同环境下的对比才更接近模型本身的差异，隔空比耗时容易冤枉人。

画像数据落在本机，属于你自己的对局档案；还有一个提醒：协议习惯会变。厂商给模型升级、换版本，遵守率与耗时都会跟着动，画像不是刻在石头上的。隔一阵重新攒一轮样本，让档案保持新鲜。

具体口径以 0.1.0 版本的实际界面为准，后续版本可能调整。

## 高频疑问

### 协议画像里的 JSON 格式遵守率是什么意思

模型按统一协议出招时，输出合规 JSON 的比例。高遵守率意味着解析顺利、对局流畅；低遵守率意味着容错链经常出手，极端时触发代走兜底。

### 平均耗时长的模型是不是更强

不是。耗时只说明出招快慢，与棋力没有必然关系。思考型模型通常更稳但等待更长，快模型出招利落但可能毛躁，各有性格。

### 打几局才能看出可靠的画像

样本越多越稳。三五局的数字波动大，多攒一些场次再看，画像的参考价值会明显上升。

### 画像数据会传到网上吗

不会。画像由本机对局数据统计而来，跟对局记录一样落在本机，不上传。

### 协议画像和天梯排位有什么区别

天梯排位衡量棋力战绩，协议画像衡量出招习惯，一个看打得怎么样，一个看怎么打的，配合着看模型形象才完整。

### 遵守率低的模型还能上桌吗

能上，但要有预期：它可能经常触发容错与代走兜底，等待时间不稳定。拿来当陪练看乐子没问题，跑正式锦标赛建议选格式稳的选手。

协议画像的妙处在于，它把「模型是个什么样的选手」从玄学变成了可查的档案。多读几份画像你会发现，大模型之间的差异远比跑分榜单上的小数点精彩——有人守规矩没天赋，有人散装却能赢，牌桌上见真章，档案里见性格。
