# 察元OS.cop.tgz 离线插件包使用指南（离线插件包）（细节版）

离线插件包是察元AI OS里使用频率很高的一项能力。它的「.cop.tgz 离线插件包」这样工作：插件依赖闭包打包导出为 .cop.tgz，离线直拷导入（校验路径穿越、零网络），支持多选批量安装。这篇避坑指南从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

插件依赖闭包打包导出为 .cop.tgz，离线直拷导入（校验路径穿越、零网络），支持多选批量安装。

从任务视角看，它对应的关键词是「离线插件包」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 在插件页签导出 .cop.tgz
2. 拷贝到目标机器
3. 导入并批量安装

## 适用场景

- 内网机器装插件
- 团队统一插件集

## 进阶技巧

- 导出即依赖闭包，不怕漏依赖

## 注意事项与边界

- Docker/云通道等进阶形态需要一定动手能力
- 模型相关能力建议先在非关键文稿上试跑一次，确认输出风格符合预期

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同

## 常见问题
### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 内置了哪些模型？

装机五件套：Qwen3-4B-instruct（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文（语音合成）；标准包含引擎不含权重时可通过 models 完整离线包或在线下载补齐。

### 免费吗？怎么收费？

免费下载使用，购买前后功能完全一致（永不门控）；首运行 90 天静默期后每日首次启动弹一次购买页（可关闭）。四档价格 ¥149/359/599/1049，离线短码激活。
