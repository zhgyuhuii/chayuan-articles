# ✨文档脱密隐藏用法｜文档脱敏一次讲清

用过察元文档助手的宝子看过来，文档脱密这个功能很多人没用到极致👇

✅ **它能干嘛**

把确认的敏感词替换为占位符并建立密码保护的映射关系，实现可逆脱敏：对外发送脱敏版，内部留存映射可一键复原（付费功能）。

🔍 **三步用起来**

1️⃣ 先运行涉密关键词提取并确认词表
2️⃣ 发起「文档脱密」，设置复原密码
3️⃣ 得到脱敏稿外发，映射加密留存

💡 **什么场景最香**

· 标书外发前去除内部报价与人员信息
· 论文送审去除单位与项目编号

📌 **避坑提醒**

⚠️ 付费功能；脱敏稿仍建议人工抽检

🛠️ **更多它擅长的事**

· **文档脱密**：把确认的敏感词替换为占位符并建立密码保护的映射关系，实现可逆脱敏：对外发送脱敏版，内部留存映射可一键复原（付费功能）。
· **文档审计助手**：围绕书签规则与字段实例逐书签审计，识别规则内与规则外的风险，支持批注归因与审计报告输出。
· **保密检查**：对密级标识、涉军涉装、单位身份、联系方式、项目编号、商业秘密等做分级风险提示，用于发文外发前自检（付费功能）。定位是辅助参考，不替代人工定密。

⚠️ **断网也能用？这点很关键**

离线与内网是这款加载项的一等公民设计：通过 Ollama 或任意 OpenAI 兼容网关（LM Studio、Xinference、One API、New API、FastChat、Custom OpenAI）即可在无公网密钥的情况下完整使用全部功能；产品内置本地引擎一键安装引导，自动检测环境并在官网与 ModelScope 镜像之间择优下载，适配国内网络。需要注意的是，加载项本身不内置模型权重，本地推理需要先装好 Ollama 等引擎（引导流程会带你完成）。

🎯 **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容

📝 **免费还是要花钱**

开源（Apache-2.0）免费使用 + 付费高级功能不限量授权。免费部分：免费版对话每日 30 次；执行助手、文档脱密、脱密复原、涉密检查、涉密关键词提取每日 2 次（共用池）。

🧩 **说点大实话（缺点）**

· 免费版每日对话 30 次，重度使用需要付费或自建模型端点
· 脱密/复原/涉密检查/涉密关键词提取是付费功能（每日免费 2 次共用池）
· 校对质量依赖所配置的模型：本地小模型对复杂逻辑错误的把握弱于云端旗舰模型

🚀 **延伸了解**

察元AI文档助手是一款 WPS 文字智能加载项（jsaddons 形态），在编辑器内提供「察元 AI 助理」与「察元 AI 编审」两个功能页签，用大模型完成文档对话、校对审查、表单填报与正文写回；同时内置本机 MCP 文档智能体服务（127.0.0.1:62588），可被 Claude Code、Codex、Cursor 等外部智能体直接调用读写本机 WPS 文档，支持离线/内网模型，文档与密钥不出本机。

❓ **常见疑问快答**

问：支持哪些操作系统？
答：Windows（x64/arm64）、macOS（arm64/x64）、Linux（x64/arm64，含麒麟、UOS；飞腾/鲲鹏选 arm64）。

问：校对结果可靠吗？
答：校对由大模型推理完成，输出「原文引用+建议+理由」的结构化清单并默认以批注写回，每条都由人工裁决；它擅长语境类错误（搭配、语法、逻辑），最终采用权在用户。
