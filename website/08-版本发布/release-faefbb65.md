# 升级到 v内容护城河建设 前必读的几件事

v内容护城河建设（2026 年中）带来了 3 项主要更新。这篇解读把每项更新「翻译」成使用层面的变化，并给出升级建议。

## 本版主要更新

- 教程库采集 2.1 万+ 条（arxiv/github/B 站等）
- 技能包商城 311 包 13 行业
- 20 行业 200 场景库与 4526 助手目录

以「教程库采集 2.1 万+ 条（arxiv/github/B 站等）」为例：它解决的是此前用户反馈集中的场景。升级后建议第一时间验证这个场景——如果它正是你的痛点，这一版就值得升；如果你的工作流不涉及，也可以观望一个补丁版本再升。

1. 升级前备份用户数据目录（各产品数据目录见官方文档）
2. 从官网 https://aidooo.com 或对应发布渠道获取新版安装包
3. 覆盖安装，完成后验证常用链路
4. 如有问题，用备份目录回滚到旧版

## 离线运行与部署形态

能力广场是网站形态，本身需要网络访问；它的价值在于「信息与安装命令」，不存任何二进制文件——真实安装一律跳转原始地址（GitHub、官网、npm 等），因此不会形成单点供应链风险。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 政企可私有化部署（Docker），数据自主可控
- 网站不存任何二进制文件，安装一律跳转原始地址

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 如实说说它的不足

- 价格与免费额度信息为参考整理，最终以厂商官方页面为准
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 产品家族与生态位

察元AI 能力广场属于察元AI 产品家族，家族成员包括：察元AI文档助手（WPS 文字智能加载项：校对、编审、脱密与本机 MCP 服务）；察元AI Office（开源 AI 办公套件：文档/表格/演示/PDF 六编辑器）；察元AI OS（插件化的 AI 桌面操作系统，本地大模型与智能体工作站）。同一账号体系与官网 https://aidooo.com 承载全部产品的下载、激活与更新。

## 常见问题
### 资源失效了怎么办？

条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注；发现问题可通过反馈渠道或机器人客服上报。

### 手机能用吗？

能，网站适配移动浏览器；在察元AI OS 里还有内嵌的察元智能广场应用。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。
