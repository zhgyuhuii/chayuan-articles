# 插件导航排查路径：教程库只做元数据导航

插件导航这件事，值不值得专门学一篇，看一个细节就够：官方分类对齐。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI 能力广场。

## 先定位问题在哪一层

按这个顺序排查插件导航通常最快：先确认前置条件（环境与模型就绪），再核对操作路径，最后看边界限制。

## 正确的操作路径

挑一个插件

1. 进插件板块按分类筛选
2. 对比下载量与榜单位置
3. 在 OS 应用商店搜索同名插件一键安装
4. 或按详情页说明手动安装

插件装到哪

1. 察元AI OS 用户走应用商店在线安装，与广场同源
2. 内网机器用 .cop.tgz 离线包导入，断网也能装
3. 装完在 OS 桌面或对应宿主里启用
4. 不想要了在商店里停用或卸载

## 进阶用法与边界

- 官方分类对齐
- OS 商店同源直装
- 下载量与 star 参照
