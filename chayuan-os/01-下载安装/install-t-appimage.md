# AppImage打不开排查安装

AppImage打不开排查这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决AppImage打不开排查。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：FUSE 缺失标准处理。

安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 注意事项与真实边界

如实说明，它不是万能的：

- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 放回产品盘面看

把AppImage打不开排查放回察元AI OS的整体盘面：Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力，首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念；完全隔离的内网没法在线下载，U 盘搬运权重文件是最现实的路径，系统为此做了零拷贝导入；保存后随系统技能分发到智能体。

## 安全与数据边界

安全口径单独立一层：管理员建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；全新安装选数据目录或导入拷贝根，创建管理员；数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录，智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力。

## 平台与形态

平台与形态的账：内置浏览器窗，配合 webwindows 可被智能体驱动；整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处；公文写作的场景里 WPS 是主战场，资料引用不开 WPS 就没意义。
