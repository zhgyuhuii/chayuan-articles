# 对局记录管理：历史棋局都存在哪

棋局跟照片一样，打完不该就地蒸发。昨天那场精彩的机机观战、上周那局你翻盘的人机局，隔一阵想回味，去哪里找？察元竞技场给每局棋都留了档：对局记录管理。这篇讲清记录页的结构、存档落在哪、怎么从记录走到回放，以及备份这件容易被忽略的事。

## 先弄清楚它是什么

对局记录管理，是竞技场对历史棋局的集中存放与检索能力，界面载体是记录页。你在 11 款玩法里打的每一局——人机局、机机观战、锦标赛产生的对局——都会自动留档，不需要你手动保存。

记录页的结构围绕「一局一条」展开：每条记录对应一场对局，带玩法、参与者、结果这些基本信息，记录按时间排列，翻找历史棋局就在这里进行。

记录的来源覆盖所有对局模式：人机局里你和模型的每一次交手、机机观战里你围观过的每一场混战、锦标赛跑出的每一轮结果，都在归档范围。换句话说，只要在桌上打过，就有据可查。

存档机制要单独说：对局记录落在本机。竞技场的存档走 JSON 存储，写入带写锁、运行时热读取，这是工程侧的严谨，落到你这边就是一句实在话——棋局数据在你自己的电脑里，不依赖任何云端账号。

写锁加热读取值得翻译成人话：写锁保证多局同时落盘时不互相踩坏数据，热读取保证运行中随时翻档案不卡顿。你感知不到它们，只会感觉「记录一直都在，随时打开都有」。

记录与回放是上下游关系：记录页是入口，回放是内容。从一条记录进去，就能逐手回看、看形势曲线、看问叹号标注，对局记录管理是整条复盘链路的大门。

门后的风景取决于你用得勤不勤：只打不复盘，记录就是流水账；打完顺手复盘，记录就变成进步的台阶。同一个记录页，两种用法，两种收获。

## 动手前要备好什么

不需要任何准备，打了就有记录。要说准备，只有一件事值得提前想：既然记录只在本机，你的备份习惯就决定了历史棋局的安全边际——这一点边界部分细说。

顺带说一句，记录是自动的，与是否付费无关——软件 MIT 开源免费，模型 API 费用自付，本地 Ollama 零成本，而记录功能对三种付费口径的用户一视同仁。

## 具体怎么操作

第一步，打完对局自然留档，这一步什么都不用做。

第二步，打开记录页。从应用内进入记录，你的历史棋局都在这里。刚打完的局会出现在列表靠前的位置，越往后翻日期越早。

第三步，按玩法与时间定位目标对局。想回味哪局，顺着列表找它——比如昨天那场四模型斗地主，或者上周翻盘的那局象棋。

找特定模型参与的对局也有线索：记下那个模型的名字，翻记录时留意参与者信息，交集一对就能锁定。

第四步，进回放。从记录进入对局的回放，逐手回看：配合形势曲线看攻守走向，配合问叹号标注看妙手与失误，配合思维链气泡看模型当时的盘算。记录页的每一条，都是通往整局复盘的入口。

第五步，需要带走的用棋谱导出。想在竞技场之外分析这局棋，用棋谱导出把整局存成 JSON 文件，数据就跟你走了。

再养成一个小仪式：每攒够一周的对局，挑一两局值得留的导出归档。这个动作三十秒，坚持下来，你的棋局库就从「本机缓存」升级成「私人博物馆」。

## 做完后的验证

随手挑一局几天前打的对局：记录页里能找到、点进去能回放、逐手数据完整，说明记录与存档都在正常工作。再检查一局认输的对局——看它在不在记录里，验证「认输不清盘」的口径。

验证再加一环：挑一局锦标赛对局，确认它能进回放且逐手完整——锦标赛场次多，是记录系统不错的压力测试样本，它过关，日常对局更不用担心。两轮验证跑完，对记录页的信任就有了底。

## 这些边界要心里有数

记录只在本机，不云同步。这是隐私上的优点，也是运维上的责任：换电脑、重装系统、卸载应用，都可能带走你的历史棋局。在意存档的话，定期备份应用数据目录，或者把重要对局用棋谱导出留一份 JSON 在网盘与移动硬盘里。

记录会随对局数量增长，占用磁盘空间。挂锦标赛跑长线的玩家尤其明显，几百场对局攒下来体积不小，磁盘紧张时优先导出想留的棋谱，再考虑清理空间。

记录的管理动作以应用内提供的为准。版本 0.1.0 阶段，检索能力的丰富程度以实际界面为准，记录多了翻找会费点时间——这也是建议定期导出归档的原因之一。

记录的安全模型值得想清楚：本机存档防的是平台侧的风险，不防本机侧的意外。硬盘损坏、误删目录、系统重装，都发生在「你的电脑」这一侧——备份的价值，正在于把这一侧的风险也兜住。

## 高频疑问

### 对局记录存在哪里

存在本机，应用数据目录下，与模型配置等数据同在本机管理，不上传云端。具体子目录以版本为准。

### 换电脑能把记录带走吗

能，但要自己动手：备份应用数据目录迁移过去，或者逐局用棋谱导出带走 JSON。没有云同步，数据迁移靠自觉。

### 记录会占用多少空间

随对局数量增长，短对局体积很小，长锦标赛累积可观。定期导出重要棋谱、留意磁盘余量即可。

### 记录能删除吗

管理动作以应用内实际提供的为准；数据都在本机，动手清理前建议先把想留的对局导出留档。

### 回放和记录是什么关系

记录是入口，回放是内容：从记录页进入某局，才能逐手回看、看形势曲线与问叹号标注。

### 能按玩法筛选记录吗

检索能力的丰富程度以 0.1.0 实际界面为准；记录条目本身带玩法信息，列表翻找加导出归档的组合，已经能覆盖大部分找回需求。很久之前的一局也能找回：记录按时间排列且全部落在本机，只要应用数据目录没被清理，历史对局一直在。

历史棋局的归宿，考验一个产品的良心。察元竞技场把记录全部落在本机，把出口开成棋谱导出——进可回放复盘，退可带走归档，棋局的每一手都握在你自己手里。养成定期备份的习惯，多年后翻开这些棋局，每一局都还带着当天的硝烟味。
