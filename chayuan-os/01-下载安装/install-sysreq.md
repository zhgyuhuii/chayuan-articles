# 配置要求：模型配置可一键写入五家

这篇把察元AI OS的配置要求收拢成内存、架构、系统版本一张表，装之前照着核对，省得装到一半才发现机器不匹配。

## 安装前确认

| 项目 | 口径 |
|---|---|
| 操作系统 | Windows 10/11（Linux 装法见下文速览） |
| CPU 架构 | x64 或 arm64 |
| 安装包 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| 说明 | 内存架构系统版本一张表 |

安装器认准官方发布渠道，别从陌生站点取包。

## 完整操作步骤

1. 按机器架构从官方渠道取对应的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 其他平台装法速览

Linux（deb）：按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64；sudo dpkg -i 安装 deb 包；应用菜单启动，首次启动自动初始化数据目录。这条路径同样吃架构匹配，选包前用命令确认一遍最稳。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

装完回头把这张表再过一遍，机器实际情况与口径逐项对上，后面排查问题就有了基准：出状况时先分清是配置不达标还是环境变动，方向不容易跑偏。

## 动手前认下这几条边界

- 龙芯暂无可用版本；视频生成不在本地完成，而是经云端路由输出
- 设备内存 8GB 时，建议同一时间只装载一个对话模型，跑复杂任务会受限
- Docker 云桌面、跨终端互联这些进阶形态，上手门槛不算低
- 云端厂商的模型调用，API Key 需自行准备

## 内存怎么估

本地模型对内存是硬约束，差一点就是跑不动，不像传统软件还能凑合着用。装机前先看两处：这台机器准备跑哪些模型，以及模型库给出的分层标记——它会按本机内存预算把模型分成能跑、勉强、跑不动三档，装完在设置里扫一眼就知道余量。打算以本地模型为主的机器，内存预算宁可留足，交互上才不至处处受限。内存估法的另一半在云端：主要调用云端模型的机器，本地内存压力小得多，表里的口径对它们宽松；本地、云端混用的机器按本地模型的高峰占用预留即可，断网时云端模型不可用，可设自动回落到本地。

## 架构和系统版本怎么查

Windows 下进设置＞系统＞关于，能看到处理器架构与系统版本；拿不准架构时，命令行执行 `echo %PROCESSOR_ARCHITECTURE%`，输出 AMD64 对应 x64 包，ARM64 对应 arm64 包。Linux 侧用 `uname -m` 查询，x86_64 取 x64 包，aarch64 取 arm64 包，飞腾/鲲鹏多为 aarch64，兆芯/海光多为 x86_64。

## 远程与桌面的分工

记忆全机共享，换一个智能体接班时不必重新交代背景，这是系统层面做好的黏合；远程这块，在设置里填入远程 dsh web 地址并测试连接，桌面客户端即可借远端算力干活，本机配置单薄而服务器宽裕时，桌面端只负责呈现外壳；遥测开关与清除桌面数据属于不可逆操作，触发时有警示提示。

## 升级与数据的底线

定时巡检、清晨早报、盯梢数据变化这类例行任务都能派给它，睡醒收结果就行；升级环节另有一条底线：数据不会因升级丢失，检查更新即便静默失败，也不妨碍现有功能使用。

## 配置改乱了怎么自救

模型配置被改乱、服务起不来时，回出厂态是最省事的自救路径，一键即可恢复出厂模型配置；配置文件支持右键编辑，删除动作有两步确认挡着，桌面上来路不明的野宠也能收编为正式灵宠并建档。

## 与各家智能体的配合

命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；MCP 是智能体的手，一处配置全家生效，改之前能验证连接省得排错，配置自动投影进配置文件。

## 首登向导先讲什么

首次登录桌面会自动弹出四步向导：先讲清楚模型代理是全机统一出口这个概念，再选默认对话模型，概念页解释模型代理机制。很多人卡在第一步不是不会用 AI，是被各家智能体各配一遍模型劝退的；在这里配好后一键应用到各家智能体，保存后随系统技能分发下去。

## 两类常被问到的情况

虚拟机里能不能装？虚拟机本质上也是一台 Windows 机器，满足表里系统与架构两项口径就能按同一套步骤走，内存按本地模型的预算单独估。老电脑要不要先升系统？系统版本低于 Windows 10 的机器，先把系统补到位再考虑安装；架构过老同理，这属于硬件层面的硬约束，软件绕不过去。多台机器批量安装时，配置要求里需要逐台核对的是架构这一项，其余条目在同型号机器上是一致的。

## 不联网的环境里还剩哪些能力

tar 包支持离线迁移；本地转写不上传录音，会议速记两件事一次做完；本地音乐（用户音乐目录）与音视频播放，与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）。

到这里，配置要求从核对到装完验证就串起来了，卡壳的地方回到对应小节再对一遍条目，表里每一项都对上再继续往下走。
