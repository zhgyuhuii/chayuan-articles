# AI操作系统下载怎么做？Windows 安装指南一次讲清

NSIS 零依赖安装与首启初始化。本文以「Windows 安装指南」为主题，给出察元AI OS的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：官网 aidooo.com https://aidooo.com；GitHub Releases https://github.com/zhgyuhuii/chayuan-harness。系统要求总览：Windows——Windows 10/11（x64）与 Windows on ARM（arm64）；macOS——Apple Silicon / Intel；Linux（deb 系）——x64/arm64；UOS 20 推荐 deb；银河麒麟 V10（飞腾/鲲鹏/兆芯/海光）有专门适配章节；Linux（通用）——x64/arm64，FUSE 2；服务器/Docker——任意可跑 Docker 的服务器。

## Windows 安装步骤（NSIS 安装器 exe（ChaAIOS-<版本>-<arch>.exe））

系统要求：Windows 10/11（x64）与 Windows on ARM（arm64）。安装后无需联网即可启动使用本地模型对话

1. 从官网或 GitHub Releases 下载 ChaAIOS-<版本>-x64.exe
2. 双击 NSIS 安装器完成安装（零额外依赖）
3. 启动后数秒进入桌面（初始化数据目录约 5-30 秒）
4. 对话应用里选择本地模型即可开聊（无需联网）

## 安装后怎么验证

1. 重启宿主程序，确认功能入口已出现（Windows 环境）
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：升级采用覆盖安装方式，用户数据目录不受影响

## 相关报错速查

- 锁屏密码忘了？——多用户体系提供管理员密码找回流程：以管理员身份登录后在用户管理中重置目标账户密码。
- 语音输入没反应？——检查系统麦克风权限与默认输入设备；确认 whisper 语音识别模型已加载；嘈杂环境建议使用外接麦克风。
- 智能体（CLI）无法启动？——在应用管理→智能体页检查安装状态并重装；四家 CLI 二进制随安装包分发（约 1.3GB），磁盘空间不足会导致启动失败。

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 常见问题
### 智能体（CLI）无法启动？

在应用管理→智能体页检查安装状态并重装；四家 CLI 二进制随安装包分发（约 1.3GB），磁盘空间不足会导致启动失败。

### 检查更新失败？

更新需要联网访问官网 API；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

### 首次启动感觉「卡住」了？

首启要初始化数据目录并加载模型服务，5-30 秒属正常范围；期间无需干预，完成后自动进入桌面。
