# 首次启动流程安装指南：全平台步骤与验证

内网机器要把数据放 D 盘防重装丢失，过去要折腾好几个工具拼起来。现在察元AI OS把这件事做成了一个功能：开机登录门与数据目录。下面按我实际操作的顺序走一遍，包括容易踩的坑。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：登录门、数据目录与首配。

Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 官网 aidooo.com 下载对应架构的 exe 安装器
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10/11，x64 或 arm64 | NSIS 安装器（ChaAIOS-版本-架构.exe） |
| macOS | Apple Silicon 或 Intel | dmg（ChaAIOS-版本-arm64.dmg / x64.dmg） |
| Linux（deb） | x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb | deb（ChaAIOS-版本-架构.deb） |
| Linux（AppImage） | x64/arm64，需要 FUSE 2 | AppImage（ChaAIOS-版本-架构.AppImage） |
| Docker 服务器 | 任意可跑 Docker 的服务器 | docker compose（察元AI工舱形态） |

## 装完后的第一件事

首次登录桌面会自动弹出模型设置向导，四步配好默认模型并应用到智能体；随后到设置账号与找回里生成恢复密钥，这两件事做完，这台机器就算真正就绪。

## 架构对照速查

| 设备 | 架构 | 选包 |
|---|---|---|
| 飞腾、鲲鹏 | arm64 | arm64 的 deb 或 AppImage |
| 兆芯、海光 | x64 | x64 包 |
| 常见 Intel、AMD | x64 | x64 包 |
| Apple Silicon | arm64 | arm64 的 dmg |

拿不准就终端执行 uname -m：输出 aarch64 选 arm64，输出 x86_64 选 x64。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 这些坑和边界要知道

如实说明，它不是万能的：

- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 高频疑问

### 开机每次都要输密码，能省掉吗？

密码本身不能置空（最短 3 位的硬校验）。默认的「开机登录」已经是最省路径：开机直接落上一位用户的锁屏，只输一次密码即进；在 设置 ＞ 用户 关闭该开关则会落在选人卡片墙。忘了密码看 A2。

### 重装后弹「检测到重新安装」，选哪个？

想继续用原来的账号和数据选「继续使用现有数据」；想把机器转手/从头再来选「全新开始」——旧数据被整体封存为带时间戳的备份目录（不删除），反悔了还能通过「导入」找回。

### 装好之后还能改数据目录吗？

界面层面不能——数据目录只在首装向导里可选，向导不会再出现。已初始化后的迁移办法：把整个 chatop-data 拷到目标位置/机器，在新机首启时走「从另一台电脑导入」（同平台直接原地接管）；或重装后选「全新开始」再导入旧根。

## 补充答疑

### 导入时提示「该文件夹不是有效的察元数据目录（缺 registry.json）」？

选中的不是完整数据根。要拷的是整个 chatop-data 文件夹（里面有 registry.json、users/ 等），不是其中的某个子目录或安装目录。

### 数据目录能放进 iCloud/坚果云这类同步盘吗？

能选，但会立刻出现黄色警告：聊天记录与密钥会被同步软件带走，多台设备同时使用可能损坏数据，建议另选本地目录。要跨设备迁移，用「拷贝整个文件夹 ＞ 新机导入」的方式（分支三）更安全。

### 恢复密钥当时没抄/跳过了怎么办？

向导生成的密钥不因跳过而删除，但明文不会再显示。到 设置 ＞ 账号与找回 输当前密码「重新生成」一把新密钥重新抄写（旧密钥立即作废），详见对应教程。

## 更多操作细节

分支二 · 日常开机（登录门）

1. 每次开机都完整走欢迎页 ＞ 开机动画两屏，动画结束后由 设置 ＞ 用户 的「开机登录」开关决定落点：
    1. 开（默认）：直接落上一位用户的锁屏，输该用户密码解锁进桌面；
    2. 关：出现登录窗「选择一个用户」——用户卡片墙（头像+昵称+用户名；被停用的用户不显示）。点选一个设了密码的用户卡片，下方出现「输入密码」框与「解锁」「退出」按钮（「退出」= 退出整个应用）。输对密码直接进入桌面（门里认证过，不再二次要密码）。
    3. 密码错误分支：「密码不正确」；连错触发退避 ＞ 「尝试过于频繁，{n} 秒后再试」；账号被停用 ＞ 「该账号已停用」。
    4. 忘记密码：点选用户卡后下方的「忘记密码？」进入找回面板。
    5. 少见分支「补设密码」：账号表里存在还没设过密码的用户时，开机先强制「你好，{用户名}」屏：按引导「为这台设备的管理员账号设置一个密码（3 位 PIN 起即可）」，填两遍新密码点「保存并进入」。

分支三 · 导入拷贝根（从另一台电脑迁移）

1. 入口在向导「数据目录」屏的「从另一台电脑导入」区，说明原文：「已有拷贝过来的 chatop-data 数据文件夹？选择它即可同步全部用户、应用、插件与智能体。」点「选择数据文件夹…」选中旧机拷来的整个数据根文件夹。
2. 校验失败分支：文件夹里没有 registry.json ＞ 「该文件夹不是有效的察元数据目录（缺 registry.json）」；里面没有任何用户 ＞ 「该数据目录里没有任何用户」。
3. 同平台（如 mac＞mac）：不复制数据，整个文件夹原地接管——系统记录重定向并自动重启，直接用它当数据根。
4. 跨平台（如 win＞mac）：把数据复制进本机默认根，复制期间显示「正在导入数据…」，完成后自动重启；平台相关组件下次会话自动重建。若文件夹带共享模型权重（shared/models/chatop-models），先弹「并入模型权重」对话框：「该数据文件夹带有共享模型权重（约数 GB）。」「模型全机只保留一份，并入后本机所有用户共用；不并入则导入后可重新下载。」勾选框「并入模型权重（约 4G，耗时较久）」（默认勾选），按钮「开始导入」/「先不导入了」。
5. 重启后登录门列出导入的全部用户，用原密码照常登录；每个用户的会话数据、应用、插件全部就位。

另：重装检测选择框

在已有用户的机器上重新安装/覆盖安装后首启，会弹「检测到重新安装」，说明原文为：本机已有 {n} 位用户的账号数据（含模型/聊天/设置）。「继续使用现有数据」直接进入原有账号；「全新开始」将重新走安装向导（旧数据整体封存，不删除，可找回）。按钮「继续使用现有数据」（直接进原有账号流程）或「全新开始」（旧数据根整体封存为 chatop-data.backup-<时间戳>，不删除，重走完整向导，之后仍可用「导入」找回）。

安装这步别跳验证：装完先确认核心功能可用，再往下配。
