# 给智能体找数据库 MCP：MCP市场概念与上手

MCP市场这个词常被当成商城来搜，进来的人想问的其实是：东西全不全、能不能信。本篇就按这两问，定义、口径、边界逐段给。

## 什么是MCP市场

MCP市场说的是察元AI 能力广场里集中上架 MCP 服务的那块货架：智能体门户下，插件、技能、MCP、提示词、大模型资源集中检索与下载。

数字与版本口径源自官方文档，尾注标了截止时间。

## 支持哪些端

入口有两条：网页端开箱即用，桌面产品（Windows/macOS/Linux，含麒麟/UOS）安装包从站内下载。两条入口的分工也简单：临时查用网页端，长期用装桌面端，按使用频率选就行。

## 市场、导航、商城，差别在哪

顺带辨析词义：导航只管指路，市场负责陈列与检索，商城还带交易。这里的 MCP 市场偏前两者之间——资源集中上架、持续补货、可检索可投稿，但服务的本体仍在各自源站。理解这个定位，就不会拿电商平台的预期来要求它，也不会因为「不是商城」而低估它的检索价值。

## MCP 货架的构成

MCP市场的落点是 MCP 板块，货架上的货是 MCP 服务器资源；进货渠道共 11 路，awesome-mcp-servers、Smithery、mcp.so、官方 registry 等都在列；上架前统一去重，检索支持分类与关键词两条路，安装方法看各条目详情页。

单说它的必要性：MCP 生态长速惊人，个人收藏夹迟早过期，持续同步的货架才能保鲜。顺带说说「货架」和「仓库」的区别：这里不囤正文，条目背后都指着源站的仓库地址，更新、issues、发布记录都在原处，货架只保证你找得到、不过期。

## 最短上手路径

四步流程：

找一个 MCP 服务

1. 进智能广场，打开 MCP 板块
2. 敲入领域关键词，比如 github、搜索、数据库
3. 在详情页读安装与配置说明
4. 把配置复制进你使用的 MCP 客户端

## 丑话在前

- 榜单数据是 GitHub star 快照，标了 dead/archived 的失效条目会被清走
- 教程类条目只做目录，正文回源站
- 不登录拿不到安装包，账号或微信扫码均可

丑话说完，该逛逛还是可以逛。再补一句给安全敏感的人：装 MCP 意味着把一部分数据访问权交出去，企业内网环境动手前先过内部审批，这步别省。

## 账号与上架

- 登录分站内账号与微信扫码两条路，收藏上限 200 条
- 投稿与需求墙先审后上
- 安装包清单由管理后台同步生成，分发只认官方渠道

## 逛市场的常见问答

### MCP 板块的资源从哪来？

数据来自 11 个源的持续采集与去重：awesome-mcp-servers、Smithery、GitHub topics、mcp.so、MCP 官方 registry、servers.org、docker registry、官方参考服务器等。

### 怎么判断一个 MCP 服务还活着？

榜单机制会自动剔除标记为 dead 或 archived 的失效资源；点进详情页看最近更新时间与 star 走势也能判断。

### 安装配置在哪看？

每个资源详情页有安装与配置说明，复制到你的 MCP 客户端（Claude Code、Codex、Cursor 等）即可。

### 拿安装包要过登录这一关吗？

要登录。站内账号或微信扫码任选其一，登录后收藏与下载记录都能管理。

### 怎么认出官方出品的安装包？

直链由管理后台自动同步生成，这是辨认官方包的主要依据；镜像站来路不明，别拿系统安全冒险。

## 一句收束

把这个市场当超市逛：清单先列好，直奔目标货架，比漫无目的闲逛提货效率高得多。顺带一句：收藏夹和市场不冲突，确认好用的固定下来，待验证的留在市场里观察。

## 判断一个 MCP 还活着的方法

1. 看条目的仓库地址与最近更新时间
2. 无 GitHub 数据的条目看本站下载量参照
3. 失效（dead 或 archived）资源会被自动剔出榜单，榜单里能搜到的都是活跃条目
4. 拿不准就点仓库地址去源站确认

这套判断方法在其他资源站也通用：活跃度看更新时间，可信度看数据来源，存疑就回源站核实。把三个动作养成习惯，逛任何市场都不容易踩空。

## 市场在整个门户里的位置

提交作品页受理插件、技能、MCP 等资源的上架投稿，字段包括名称、主页地址、图标外链与分类说明；工具生态本身散布在 GitHub、npm、各家市场里，这里做的是收拢与排序。

授权分服务版与至臻版等形态；智力榜与免费模型榜两榜并存，前者看能力上限、后者看成本下限。顺带一句：这两榜看模型，MCP 板块看工具，选型时两边对照着来，模型与工具的搭配才算完整。
