# 企业在线部署安装：三平台安装包

企业在线部署这件事，值不值得专门学一篇，看一个细节就够：三平台安装包。围绕这个细节有一整套入口和验证链路值得拆开讲，本文以察元AI文档助手为例。集中分发的好处是口径统一：内网里所有机器拿到同一份安装产物，版本不一致引发的排障成本从源头就被压掉；代价则是多出服务器侧的一层准备工作，本篇把这层准备和装完的验证串起来讲。

## 内网机器装机前的盘点

- 系统要求：WPS Office 已安装
- 安装包：chayuan-6.1.2-windows-x64.exe（自解压）
- 说明：静态服务器集中分发。

安装包出自官方渠道，企业环境里更应管住来源，来路不明的包不要往内网机器上放。装机前的盘点在企业里也比个人机器要紧：WPS 版本、系统架构、是否涉密，直接决定后面走哪条分支，清单先过一遍，比装到一半再回头排查划算。

## 单机安装仍是四步

1. 从官方渠道取 exe 安装包
2. 双击安装：加载项被放进 WPS jsaddons 目录，本机服务自注册并带看门狗
3. 彻底退出后重启 WPS
4. 文字端两个选项卡现身，安装即成

四步里最容易被跳过的是第 3 步的完全退出：运行中安装会被旧注册覆写，表现就是装完没反应，白白多一轮排查。第 4 步的选项卡是最终判据，前面任何一步没走稳，都会在这里显形。

## Linux 机器的一行命令装法

Linux：用 sudo dpkg -i 装 deb，加载项会进入 ~/.local/share/Kingsoft/wps/jsaddons；选项卡没出来就执行 quickstartoffice restart。

## 装完先通一次模型对话

第一件事是配模型：设置里选一家已购通道或本机 Ollama，点测试连接通过后，随便开一篇文档跑一次 AI 助手对话，通了再干正事。

## 各端选项卡到齐即算落地

- 文字端两个选项卡齐了、表格与演示端各自的选项卡也在，这轮部署就算落地
- 哪一端没出现，就把宿主软件彻底退出再启动一次

## 铺开之前要知道的边界

- macOS 安装器缺完全磁盘访问权限时会假成功
- Win7 与 Win8 的机器跑不了 MCP 预编译二进制，服务要靠 Node 16 回落
- 脱密的占位替换允许还原，可它没配套免密找回：密码遗失，谁也帮不了你解锁

这三条里，macOS 那条最容易被误判成安装包损坏，Win7/8 那条则要提前安排 Node 环境。批量铺开之前把目标机器的构成摸清楚，两类问题都能提前绕开。

## 部署前的最后核对

- 本机已安装 WPS Office（文字 / 表格 / 演示任意端均可）。
- 本篇口径落在 v6.1.2 的发布产物上；升级场景拿新版包直接覆盖即可。

这两条核对完，稳妥的做法是先挑一台非关键机器走通全流程，单机验证过了再批量铺开，问题就暴露在最小范围内。

## 集中更新怎么走

覆盖式升级的口径放在企业环境里很省事：静态服务器上的产物换成新版，各机器重新拉取安装，一轮集中更新就完成了。三端使用同一套前端构建产物，差异只在安装路径与部署方式，因此一次更新能同时照顾文字、表格、演示三个端口。

## 这套方案落到企业手里的三样

- 三平台安装包统一从一个静态源分发
- macOS 容器写入失败交给修复脚本处理
- HTTPS 静态部署承担集中更新

## 铺开后，每台机器上跑着什么

在线分发铺开之后，每台装好加载项的机器都会在本机 62588 端口开放 MCP 文档智能体服务（地址 http://127.0.0.1:62588/mcp），它自动发现本机察元AI OS 知识库（固定端口 52582），回答带编号引用与文件来源。企业侧还有两条值得留意：远程知识库走 chayuan-server 三鉴权（JWT、HMAC、none）；每次确认写操作都会记入 audit.jsonl 审计日志，事后有据可查。

做网络策略时，两个端口号建议提前记进资产清单：62588 承载文档智能体服务，52582 是知识库的固定端口。三鉴权管的是远程访问的凭证，审计日志补的是动作留痕，两张牌一起打，内网里的每一次写操作才说得清来龙去脉。

## 助手规模与设置面板

文字端自带 4526 个领域助手、覆盖 228 个行业领域；助手目录支持搜索、收藏常用、按领域浏览，员工可以各自攒出顺手的助手工作台。设置面板把模型清单管理、助手设置（默认写回动作可改）、网络与升级等收在一处，逐项调整都有明确入口。

## 涉密与内网环境

内网场景支持 Ollama 等离线模型；同时要记住，交给模型处理的是整份文档，涉密稿件应先切到本机离线模型再跑。这两句合在一起，才是涉密环境下完整的取舍口径。离线路线的价值在内网里会被放大：模型不出网，文档也就跟着不出网。涉密机器的部署方案里，模型配置应当作为标准环节统一执行，而不是留给每台机器的使用者各自摸索。

知识库绑定走输入区书本按钮（topK 默认 5、RRF 融合、混合检索默认开、重排默认关），生成结果按助手定义的写回方式落进文档。这些默认参数对新装的机器同样即开即用，不额外增加部署工作量。

企业在线部署的链路到这里拆完：入口、验证、边界各归各位。真卡住时，按平台和环节回上文对号入座，比盲目重装或反复重试省事得多。
