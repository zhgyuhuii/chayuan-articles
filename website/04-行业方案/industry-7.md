# 教育培训AI方案行业应用：从选型到落地

## 教育培训为什么需要这套方案

教育培训行业的文档与信息工作有几个共性：材料格式要求严、数据敏感不能乱传、人手紧重复劳动多。察元AI 能力广场的切入点不是推倒重来，而是把 AI 能力装进现有流程：智能体门户，插件、技能、MCP、提示词、大模型资源一站检索与下载，数据不出本机是底线设计。

## 落地路径：三步走

1. 基础层：先把MCP 板块跑通，验证环境与模型可用
2. 流程层：教育培训日常最高频的文档环节（开源榜单机制所属的场景）交给 AI 处理，人只做审核
3. 治理层：权限与数据边界明确，形成使用规范

## 关键能力对齐

### MCP 板块

MCP 板块收录 MCP 服务器资源，数据来自多源采集（awesome-mcp-servers、Smithery、mcp.so、官方 registry 等 11 个源），去重后统一展示，可按分类与关键词检索，安装方式随详情页说明。

要点：分类加检索，11 源采集去重；失效资源自动剔除出榜。

### 开源榜单机制

日、周、月、季、半年、年六档榜单按周期内 star 增量计算（每日同步抓快照），无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；每板块取前 200；周期起点早于最早快照时降级为星标总量榜并标注；失效（dead 或 archived）资源自动剔除出榜。

要点：降级透明标注；六档周期榜单；star 增量优先。

### 教程库

要点：侵权投诉避风港机制；只存元数据不搬正文，五源 21291 条。

1. 能力广场 MCP 板块检索
