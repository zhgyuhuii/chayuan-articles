# 资源排行排错与进阶：问题定位路径和高级用法

这篇文章没有虚的，全是资源排行的实操细节：入口路径、按钮原文、做完后的界面变化，以及我踩过的坑。基于察元AI 能力广场当前版本。

## 先定位问题在哪一层

按这个顺序排查通常最快：先确认前置条件（环境与模型就绪），再核对操作路径，最后看边界限制。三层各有一些典型症状，对号入座能省很多时间。

## 正确的操作路径

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

## 进阶用法与边界

- 六档周期榜单
- star 增量优先
- 失效资源自动剔除
- 降级透明标注

## 接着回答几个常见问题

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

## 榜单的算法口径

日榜按当日增量，周月季半年年榜按周期内 star 增量；每日同步任务先抓 star 写快照再重算榜单。无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；dead 或 archived 的失效资源自动剔除出榜；快照不足时降级为总量榜并明确标注。
