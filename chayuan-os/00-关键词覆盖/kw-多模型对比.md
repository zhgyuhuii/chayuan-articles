# 模型配置可一键写入五家：多模型对比概念与上手

多模型对比这个词被搜得越来越多，但它到底指什么、和普通工具软件差在哪，说法很杂。这篇按官方口径给定义、给数字、给边界，产品以察元AI OS为例。

## 什么是多模型对比

把多模型对比拆开看，它指的是这样一类东西：察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

## 在察元AI OS里落在哪

多模型对比在察元AI OS里的落点是宠物群聊（多模型讨论）：建群：群名加勾选至少两只成员，选协同方式，可选群分区（桌面出图标双击进群），发一条命题，多个大模型开始围绕它讨论。

为什么值得单独说：单个模型有偏好也有盲区，让几个模型围绕同一命题各自作答或接力深化，做方案对比、头脑风暴、交叉验证都直观。

## 最短上手路径

试一遍就明白：

第 3 步 · 选分区（可选，决定桌面图标）

1. 保持「自动（推荐）」：引擎把群分区收进隐藏目录（Workspaces/.pet/groups/<群名>-<短码>，附件也落这里），桌面不出现分区图标；
2. 从下拉选一个已有分区，或点「+ 选择文件夹…」在系统对话框里选/新建文件夹：
    1. 该分区成为群的可见工作区，桌面出现这个分区的图标；
    2. 双击桌面上的分区图标 = 直接打开宠物群聊并定位到这个群；
    3. 事后在群管理面板也能换分区。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

## 你可能会问

### 「创建」按钮点不动？

两个原因：勾选成员少于 2 只（表单字段名写明「选择成员（≥2）」），或一只灵宠都没有（先点左栏「建宠物」）。

### 勾了七八只成员，为什么群里只有 6 只？

引擎建群时成员最多取前 6 只（按勾选顺序）。想让特定灵宠进群，先勾它；建群后在 群管理 ＞ 「+ 添加成员」 里补加不受这个 6 只上限约束。

### 桌面上没看到分区图标？

分区选「自动（推荐）」时不产生桌面图标（目录收在隐藏根里，附件照常落盘）。想桌面可见：打开群管理面板，把「群分区」从「自动（推荐）」换成具体文件夹。

### 8GB 内存能装吗？

能。装轻量包，一次只加载一个对话模型；重活交给云端模型（需自备 Key），日常对话与知识库检索本地跑得动。

### 能和原有系统共存吗？

能。察元OS 是独立桌面应用，不动原有系统；不需要重装系统或分区，装完即用，不想用直接卸载。

## 更多操作细节

第 1 步 · 打开应用

点 Dock 上的「宠物群聊」图标：

1. 左栏：顶部两个按钮——蓝色「建宠物」和「建群」；其下是群列表（一个群都没有时显示「还没有群，点上方「建群」」）；栏底显示「宠物 {n} 只」计数；
2. 主区（未选群时）：中央提示「建两只宠物、建一个群，发一个命题，看它们讨论」。

## 更多操作细节

第 2 步 · 打开建群表单

点「建群」，弹出标题为「建群」的表单弹窗。自上而下五个字段：

| 字段 | 说明 | 默认值 |
|---|---|---|
| 「群名」 | 群聊显示名；留空创建时自动用「宠物群」，超长按 24 字截断 | 空 ＞ 「宠物群」 |
| 「协同方式」 | 两个按钮：「并行」「串行」——选中者蓝底白字。选「串行」时下方出现说明「按顺序逐个接力发言（后手看得到前手输出）；一轮完成自动开下一轮，无休止讨论直到「结束讨论」或关闭接力」 | 「并行」 |
| 「群分区」 | 下拉：第一项「自动（推荐）」+ 已有分区列表；旁边「+ 选择文件夹…」按钮（桌面形态支持时显示）可现场挑/建文件夹。选定后表单出现提示「已选定分区：桌面将出现该分区图标，双击可打开群聊」 | 「自动（推荐）」 |
| 「群默认知识库」 | 下拉：「不绑定」+ 本机知识库列表；下方提示「成员发言时自动检索；群库优先级最高（挂了群库全员都用群库），未挂时用各宠物绑定库」 | 「不绑定」 |
| 「选择成员」（≥2） | 灵宠复选卡组（头像+名字），勾中的卡片蓝框高亮 | 无勾选 |

这篇把宠物群聊（多模型讨论）的链路拆完了。卡住就回看常见问题那一节，多数坎都在那里。
