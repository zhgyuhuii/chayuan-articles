# 察元竞技场界面导览：装完先认识六个功能区

进一个陌生的小区，先看导览图能省一半时间；装一个新软件，先把功能区认一遍也是同样的道理。察元竞技场的界面结构不复杂，六个功能区各管一摊，这篇逐区讲清察元竞技场界面里每块是干什么的，你装完软件花五分钟读完，上手就不会迷路。

## 界面整体长什么样

打开应用，看到一个暗色底的整体界面，这是它的竞技场风格，支持中英双语。版本 0.1.0（2026 年 11 月口径）目前就是这个暗色主题，界面信息密度不低，但分区逻辑清晰：选玩法、看对局、查排位、翻记录、做复盘、改配置，六件事对应六个区。

技术形态顺带一提：界面层基于 React 19 加 Vite 7 构建，属于当代桌面应用的主流方案，但今天不聊技术，只讲你眼睛能看到的东西。

## 大厅：一切的起点

大厅是你每次打开应用先落到的地方，作用一句话：选玩法、开对局。11 款棋牌玩法在这里按棋类、扑克、麻将三组排开——棋类是五子棋、中国象棋、围棋、军棋暗棋、军棋翻翻棋；扑克是斗地主、德州扑克、掼蛋；麻将则是四川血战、广东推倒胡、日麻立直。

每款玩法点进去就能选对战模式：人机局是你亲自下场对模型，机机观战是看模型互相打，锦标赛是让一批模型循环赛跑个联赛。要注意的是，日麻立直在大厅里是隐藏入口，引擎完整可用但入口藏得深，算给懂行的人留的彩蛋，找不到入口不是坏了。

三种开局方式对应三种玩姿态。人机局里中途还能在 AI 接手与人工接管之间随时切换，下一手生效，打累了让它替你续几手；机机观战支持批量选模型，多台机器同台，座位默认匿名；锦标赛的排程自动生成，挂一晚跑一轮，早上看战报。选哪个不取决于界面，取决于你想出力还是想看戏。

## 对局室：好戏在这里上演

对局室是对局进行中的现场，作用一句话：看模型怎么想、怎么走。这里有两个别的产品给不了的东西：一是思维链气泡，模型每走一手，它的推理过程实时流式滚出来，你能看到它在盘算进攻还是防守、要不要拆牌诈唬；二是每手的延迟与 token 用量展示，哪个模型反应快、哪个模型想得久，一目了然。

多人对局里各座位的出招与思考都在这里滚动，观战模式下座位默认匿名显示玩家A、玩家B，谁是谁要到终局才揭晓，免得你先入为主。

## 天梯：胜负换成分数的地方

天梯是排位区，作用一句话：看谁强谁弱。它用微软 TrueSkill 算法给每个模型算分，段位分层，对局结果自动更新积分，谁压得住谁一张榜看清。人机局里你作为人类挑战者的战绩单独统计，不和模型混在一个榜里，想约战也可以按段位匹配着打。

挂机跑完一轮锦标赛，积分榜实时刷新，打完出冠军——早上起来看战报，这种玩法天梯就是结算面板。

## 记录：你的对局台账

记录区存放历史对局，作用一句话：翻旧账。每局谁打的什么玩法、结果如何，都落在这里，点开就能进回放。它和天梯的分工是：天梯给结论（分数与段位），记录给过程（每一局的原始档案），数据都只存本机。

## 回放：复盘与看戏两用

回放器负责把一局棋摊开细看，作用一句话：看清胜负是怎么来的。每局自动生成形势曲线，局势走向哪里倾斜一目了然；复盘模式下逐手有问叹号标注（妙手）与叹号标注（失误），配上赛后解说，一局为什么输翻一遍就明白。棋谱还能导出成 JSON 文件，想自己做分析、喂给自己的程序都可以。

## 设置：配模型的地方

设置区是对局之外你打交道最多的地方，核心是模型配置：从内置的 85 家厂商目录里点选厂商，填 API Key，用「测试连接」「获取模型」两个按钮验证与拉取模型列表，Ollama 这类本地推理还能免 Key 接入。这篇导览不展开配置细节，本系列后面有专门几篇讲。

## 一条动线串起六个区

给一个新手动线：大厅选五子棋开人机局，进对局室看模型边想边走；打完去天梯看积分变化，再到记录里找到这一局，进回放看形势曲线和逐手标注；觉得模型不顺手，进设置 ＞ 模型配置再添一家厂商。走完这一圈，六个区的用途就长在你脑子里了。

## 六个区之外：数据都在本机

逛完六个区，还有一个事实值得单独说：这些区里产生的数据全在本机。对局记录、天梯积分、协议画像统计出的出招习惯，都落在你自己的电脑里，不上传任何服务器。想清理就删，想带走就拷，牌桌历史完全归你。

这也是它能放心挂机跑锦标赛的前提之一：赛程、积分、棋谱都在本地流转，不依赖外部服务，配着本地模型时断网照样能玩完整的一局。数据归属这件事，用得越久越能体会到分量。

## 边界与实话

三条说在前面。日麻立直是隐藏入口，大厅里找不到不算故障。界面目前是暗色主题，喜欢浅色界面的人暂时要适应。版本 0.1.0 还在早期，分区名称与布局都可能随版本调整，遇到与本文描述不一致的地方，以软件实际界面为准。另外，对局室里每手都要等模型响应，弱模型或限流时等待会变长，系统有代走兜底不会卡死整局，但体验会打折。

## 你可能会问

### 界面能切换语言吗

支持中英双语，具体切换方式以设置区的实际选项为准。中文用户默认环境下即可正常使用，不需要额外配置。

### 为什么有的玩法我在大厅找不到

先想到日麻立直这个隐藏入口。其余 11 款玩法都正常陈列在棋类、扑克、麻将三组里，如果整体缺失，检查一下应用版本是否完整安装。

### 不配模型能在界面里逛吗

大厅、天梯的榜面这些不依赖模型的部分可以看，但对局没有模型就走不起来。建议先按本系列配置教程接一家厂商或 Ollama 本地模型，再开始逛。

### 六个区有推荐的使用顺序吗

上文那条动线就是推荐顺序：大厅开局、对局室观战、天梯结算、记录存档、回放复盘、设置调整。转熟之后你想从哪个区开始都行。

### 界面卡顿是软件问题吗

多数不是。界面本身很轻，等待几乎都来自模型响应，对局室里每手的延迟都标着，慢的时候能看到思维链还在滚动输出。本机卡顿与模型等待，看延迟标注就能分清。

界面导览的意义在于建立全局感：知道每个区管什么，后面遇到任何教程里的路径都不会陌生。接下来就该解决「模型从哪来」的问题了，本系列下一篇就从配置模型讲起。
