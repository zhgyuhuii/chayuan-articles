# 环境保护行业怎么用察元OS：从痛点到落地

环境保护行业的文档与信息工作有其固有节奏：对外材料有保密与合规要求，外发前自检环节薄弱。察元AI OS在环境保护场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出环境保护行业的完整应用路径。

## 环境保护行业的典型痛点

- 对外材料有保密与合规要求，外发前自检环节薄弱
- 临时性、突击性材料多，加班赶稿是常态
- 文档量大、格式要求严，人工处理占用大量时间

## 对应的能力组合

- **多智能体共享记忆**（智能体记忆）：全部智能体的单一事实源记忆：项目进最新 60 条投影进 AGENTS.md/CLAUDE.md，六家智能体共享同一份记忆。
- **Spotlight 全局搜索**（全局搜索）：Ctrl/⌘+K 唤起的全局搜索：搜应用、文件、知识库，还能直接「问 AI」出直答卡。
- **便签/日历/提醒/联系人**（桌面效率）：系统级个人信息管理四件套：便签贴桌面、日历日程、提醒事项、联系人，全部可被智能体通过控制面读写。
- **四家 CLI 智能体**（CLI智能体）：Claude Code、Codex、OpenCode、OpenClaw 四家命令行智能体以「应用」形态运行：真实 pty 终端、绑定工作区目录、多标签；二进制随安装包分发（约 1.3GB），开箱即用。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按学生场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- API Key safeStorage 加密存储，仅注入子进程
- 权限门三级管控（T0 直放/T1 每次询问可记忆/T2 每次必问），超时视为拒绝（fail closed）
- 全部本地服务只监听 127.0.0.1，数据不出本机

## 常见问题
### 哪里下载、遇到问题去哪反馈？

官网 aidooo.com 或 GitHub Releases（zhgyuhuii/chayuan-harness）；应用内置帮助中心（26 篇离线文档）与诊断入口。

### 能多人共用一台设备吗？

能。管理员多用户体系：各账户独立空间、锁屏快速切换、密码可由管理员重置。

### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。
