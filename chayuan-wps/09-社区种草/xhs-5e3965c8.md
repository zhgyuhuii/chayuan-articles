# 🚀机关文秘自救指南：公文写作助手这么干

刷到这篇的机关文秘先别划走👀 如果你也有「红头文件退文率高，错别字与格式硬伤是重灾区」的困扰，这篇直接抄作业。

✅ **痛点自查**

· 红头文件退文率高，错别字与格式硬伤是重灾区
· 发文前人工逐字核对话的时间成本太高
· 密级标识、落款日期等要素容易漏

🔍 **解法工作流**

1️⃣ 用「拼写与语法检查」批注模式先过一遍错别字与标点
2️⃣ 「检查段落序号格式」确保一、（一）、1. 体例一致
3️⃣ 「保密检查」做密级标识与敏感信息分级提示
4️⃣ 「政策公文风格改写」统一语体后出稿

💡 **为什么值得试**

装进 WPS 文字的 AI 文档智能体：对话、审查、校对、脱密，改完直接写回正文。而且从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法…

📌 **适合谁 / 先别冲**

✅ 适合：机关文秘、法务/律师助理
❌ 先别冲：仅支持 WPS 桌面端（12.x/365），不支持网页版 WPS 与其他办公软件

🛠️ **更多它擅长的事**

· **批注解释/超链接解释**：对文档中的批注内容做解释（老文件批注看不懂时）、对超链接目标做摘要说明，降低上下文切换成本。
· **多文档错别字校对（MCP）**：通过本机 MCP 服务的 proofread_run 工具对多个文档执行错别字校对：先 dryRun 预览问题清单，确认后用 proofread_apply_comments 把批注钉到具体错字（含表格单元格），支持异步任务轮询。外部智能体（Claude Code、Codex、Cursor）可直接调用。
· **AI 痕迹检查**：从套话密度、结构模式、元话语等维度对文本做保守的疑似度评估，可定位原文片段辅助人工复核；明示不构成定论，用于起草后自检「AI 味」。

⚠️ **断网也能用？这点很关键**

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

🎯 **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容
