# 模型直跑单聊进阶理解：从会用到懂原理

用察元AI OS有段时间了，灵宠对话窗是我用得比较多的一个功能。这篇把我积累的操作顺序和几个关键细节写出来，新手可以照着走，老手可以查漏。

## 是什么与为什么

「灵宠对话」是一个不经智能体、直接与模型对话的聊天窗口：支持多会话 Tab、流式回复、附件上传，输入框旁可绑定知识库和选择模型（含「智能路由 · 自动选择模型」），模型直跑的灵宠双击即开自己的对话窗。

不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处。

下面直接进入正题。

## 机制拆解

不开群也能跟单只宠深聊，会话级的知识库绑定让回答带出处。

能力面拆开看：知识库绑定；多会话 Tab 并行；模型随会话切换。

一个常被问到的问题：灵宠对话和 DeepSeek Harness 主对话窗有什么区别。灵宠对话是「模型直跑」：不经过智能体，没有工具调用、不读写文件，换来的是启动快、行为可预期；需要让 AI 操作本机（跑命令、改文件、查库调用工具）时用 DeepSeek Harness。

从提问口径看，用户最关心的是灵宠对话窗口在哪里打开？和 DeepSeek Harness 有什么区别？

## 实操全过程

按最短路径验证一遍：

第 1 步 · 打开窗口（三个入口任选）

注意：挂了智能体的灵宠双击打开的是该智能体的工作台，不是本窗口。

1. Dock：点 Dock 上的「灵宠对话」图标，打开一个不绑定具体灵宠的通用窗，标题为「灵宠对话」；
2. 双击模型直跑灵宠：在桌面双击一只未挂智能体的灵宠，打开属于它的对话窗：
    1. 窗口标题 = 灵宠名字，开窗位置自动避开灵宠本体（不挡住它）；
    2. 该灵宠已有窗口时，双击是聚焦复原已有窗，不会重复开；
    3. 开窗时从灵宠档案现读模型与知识库初值注入本窗；
    4. 右键菜单：右键模型直跑灵宠 ＞ 「打开页面」，效果同双击。

第 2 步 · 认识界面

1. 顶栏：红黄绿交通灯 + 居中标题（应用图标 + 灵宠名，通用窗显示「灵宠对话」）+ 右侧「」按钮（悬停提示「新会话」）；
2. 会话 Tab 条（顶栏下方）：
    1. 每个 Tab 默认标题「会话 1」「会话 2」…；
    2. 绑了知识库的 Tab 标题旁亮蓝色「KB」小标；
    3. 悬停 Tab 出现「关闭」（提示「关闭会话」）；
    4. 关掉最后一个 Tab 会自动换一个新的空 Tab，窗口不会因此关掉；
    5. 空态欢迎页：灵宠立绘（无灵宠时用应用图标）+ 大字「你好，我是{灵宠名}」（通用窗为「你好，我是灵宠对话」）+ 一行说明「模型直跑模式：不经过智能体，直接与模型对话。输入问题开始。」；
    6. 底部输入区（一个圆角框，从左到右）： 知识库按钮 ＞ 附件按钮 ＞ 模型按钮 ＞ 输入框 ＞ 发送按钮。

第 3 步 · 发消息、看流式回复

1. 在输入框打字（占位符「给模型发消息…（Enter 发送 / Shift+Enter 换行）」）：
    1. Enter 发送、Shift+Enter 换行；
    2. 中文输入法正在组词时的 Enter 不会误发；
    3. 输入框为空且没有待发附件时发送按钮置灰；
2. 发送后：
    1. 右侧出现你的气泡（纯文本），左侧出现助手气泡逐字流式输出，尾部带闪烁光标；
    2. 助手气泡按 Markdown 渲染：表格、代码块、SQL、标题等自动排版（2026-10-29 起，此前特殊字符报障已修）；
    3. 输出期间发送按钮变成灰色「■」（悬停提示「停止」，点击中止本次生成）；
    4. 出错时消息流顶部出现红色错误条（如 HTTP 错误详情），空的助手气泡会被移除；
    5. 每次发送携带最近对话历史（约 6000 字符预算，从新到旧回装，超预算的更早消息被裁掉），单次回复长度上限 2048 token。

## 注意事项与真实边界

边界都在这：

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重

## 高频疑问

### 没选模型直接发消息报错了？

未选模型时按 smart/auto（智能路由）发送。智能路由需要先在模型代理侧配置强/轻模型，未配置时代理会拒绝并提示；给本窗选一个具体模型（第 7 步）即可绕开。

### 回复到一半卡住或报错？

本地引擎被其他智能体占满时，代理会返回 busy，本窗会自动等待重试（3 次、每次 3.5 秒）后仍忙才报错；稍等片刻重发即可。点「■」可随时中止当前生成。

### 模型菜单显示「暂无可用模型（代理 /v1/models 空）」？

本地与厂商都没有可用对话模型。按 M3 装一个本地对话模型，或按对应教程配置并启用一家厂商。

### 灵宠对话和 DeepSeek Harness 主对话窗有什么区别？

灵宠对话是「模型直跑」：不经过智能体，没有工具调用、不读写文件，换来的是启动快、行为可预期；需要让 AI 操作本机（跑命令、改文件、查库调用工具）时用 DeepSeek Harness。

## 补充答疑

### 附件发了但模型好像没读？

对照第 6 步的读取规则：图片类不注入正文（只带文件名）；文档类只注入前 8000 字符；极长文档等于只给模型看头部。

### 关掉窗口会话还在吗？

不在。灵宠双击打开的对话窗关闭即真关，再双击是全新会话（模型/知识库初值从灵宠档案重新读取）；会话 Tab 只在窗口存活期间存在。

### 窗口提示「模型代理未就绪——请稍候或到 设置 ＞ 模型 检查」？

代理随模型服务自启，这条说明启动探测失败。到 设置 ＞ 模型 查看服务健康状态，恢复后重开本窗口即可（窗口只在启动时探测一次）。

## 更多操作细节

第 4 步 · 多会话 Tab

1. 点顶栏「」新增 Tab：新 Tab 继承当前 Tab 选好的模型和知识库；
2. 各 Tab 消息流、模型、知识库完全独立，互不影响；
3. 点 Tab 切换（切换会清掉尚未发送的附件暂存）；点「关闭」只关本 Tab。

第 5 步 · 绑定知识库（按钮）

1. 按钮悬停提示「选择知识库」，点击弹出菜单：
    1. 「不绑定知识库」+ 本机全部知识库列表；
    2. 列表为空时显示「暂无知识库（桌面建库后可选）」；
    3. 菜单外的任意处点击或按 Esc 收起（模型菜单同理）；
2. 选中一个库后：
    1. 按钮点亮蓝色并带小圆点，所在 Tab 标题旁出现「KB」标；
3. 每次发言自动检索该库（整句无命中时按关键词回退重试）：
    1. 命中 ＞ 以「【知识库参考】」注入模型，片段带编号出处；
    2. 助手回复下方出现蓝色脚标「[1] 文档名」，点击弹出浮层显示该片段全文（含章节路径）；
    3. 挂了库但本轮没检到 ＞ 向模型显式声明「本轮检索无结果」，模型被要求如实说没查到、不许编「库里正好有」。

第 6 步 · 上传附件（按钮）

1. 悬停提示「上传附件」，点击打开文件选择器，可多选；
2. 选中后输入框上方出现「文件名」小条，每条带「关闭」可单独移除；
3. 附件正文的读取规则（发送前自动完成）：
    1. txt / md / markdown / csv / tsv / log / json / js / ts / py / sh：直接读文本，截前 8000 字符；
    2. doc / docx / pdf / xlsx / xls / pptx / html / htm：走文档抽取服务转正文，截前 8000 字符；
    3. 其他类型（如图片）：只附文件名，不注入正文；
    4. 发送后附件以「【附件：文件名】+ 正文」块拼进这条消息；只发附件不写字也行，发出的消息显示为「（文件名, …）」。

模型直跑单聊的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
