# 离线插件包入门指南：应用商店对接察元AI 能力广场

## 什么是离线插件包

离线插件包这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。北京智灵鸟科技中心出品。

## 在察元AI OS里落在哪

离线插件包在察元AI OS里的落点是应用商店与智能广场：应用商店对接察元AI 能力广场（aidooo.com）：插件、技能、技能包、MCP 插件、智能体五类内容在线下载与云端推送更新，聚合全球生态资源并配排行榜；内网环境走离线包导入。

为什么值得单独说：能力不是写死在系统里的，是从商店长出来的，越用越全。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图，

- 跨终端聊天与远程执行：与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）。

## 实话实说：哪些人不必急着装

- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 云端厂商模型调用需自备 API Key
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力

这些边界不影响主线使用，但选型前知道比不知道强。

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 你可能会问

### 离线插件包要联网吗

与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）；离线消息暂存后送达；设置常驻任务新建：写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关。以官网 aidooo.com 当前页面为准。

### 离线插件包数据存在哪

周期巡检、每天早报、定时盯数据这类活交给它，早上来收报告即可；内置插件源开关、自定义社区源与技能源、npm registry 与代理设置；内网或特殊网络环境装插件的必经配置。以官网 aidooo.com 当前页面为准。

## 安全与数据边界

安全口径单独立一层：数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录；智能体不知道它会哪些本机工具就等于没有，技能手册镜像让它们天生会用系统能力，MCP 服务清单增删改（stdio、HTTP、SSE、本机 52583）；让 AI 操作电脑的前提是管得住它：分级确认加超时拒绝加审计，三道锁缺一不可；审计日志全量记录。

## 平台与形态
