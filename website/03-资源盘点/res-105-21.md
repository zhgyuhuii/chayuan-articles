# 聚合平台（OpenRouter 类）用法：资源怎么找怎么选

聚合平台（OpenRouter 类）用法。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：模型厂商板块（模型厂商）、API 价格页（API价格）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**模型厂商板块**：全球厂商与聚合平台目录，按「一线厂商→国产→聚合平台→本地部署→更多」分层，标注免费/免Key/本地标记与价格参考。

1. 进入 vendor 板块
2. 按分层浏览或搜索
3. 进厂商详情看模型列表

**API 价格页**：40 家厂商 201 个模型条目的静态价目表：人工整理、结构化展示。

1. 进入 /pricing
2. 按厂商/价格排序
3. 跳转厂商官网核实

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 网站本身需要网络访问（内网场景走私有化部署方案）

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 教程库内容是网站自己写的吗？

不是。教程库是公开网络学习资源的采集导航（arxiv 论文、github 仓库、B 站视频、课程、电子书、文档等），按主题与类型结构化组织，学习时跳转原始出处。

### 客服机器人能干什么？

右下角悬浮窗：基于 RAG 回答产品与资源问题、推荐相关内容、收集需求反馈。

### 资源数量有多少？
