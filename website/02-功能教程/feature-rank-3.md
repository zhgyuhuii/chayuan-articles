# 三个场景吃透AI工具排行的用法

被AI工具排行折腾过的人应该都有体会：明明是个高频操作，每次做都要重新想一遍流程。干脆整理成一篇，从打开哪个应用到看到什么结果，一步不落。以下内容以察元AI 能力广场为准。

## 先看看痛点对不对得上

找近期上升最快的 MCP，季度回顾生态趋势。

## 从打开到做完的每一步

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

## 关键能力点

- 六档周期榜单
- star 增量优先
- 失效资源自动剔除
- 降级透明标注

## 别在这几处栽跟头

功能归功能，这几个边界先摆清楚：

- 教程库只做元数据导航，正文仍在源站
- 榜单依赖 GitHub star 快照，资源失效（dead/archived）会自动剔除出榜

## 接着回答几个常见问题

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。

### 下载安装包需要登录吗？

### 怎么确认下载的是官方安装包？

官网 aidooo.com 是仅有的官方分发入口，下载页直链由管理后台自动同步生成；不要使用第三方站点的镜像包。

## 下载中心的机制

首页产品家族四卡对应察元AI OS、察元AI Office、察元AI文档助手与察元AI工舱，下载清单由管理后台的发布流程自动同步生成（产品、渠道、平台、架构逐级展开），手工编辑会被下次发布覆盖，保证直链始终指向最新版本；带提取码的网盘链接会自动复制提取码。

## 投稿与需求墙

把自己的插件、技能、MCP 服务投给广场：填名称、地址、分类与说明，审核通过后上架展示；需求墙是公开的，官方与社区按热度排期，客服机器人也会把对话里收集的需求汇入同一个池子。

## 榜单的算法口径

日榜按当日增量，周月季半年年榜按周期内 star 增量；每日同步任务先抓 star 写快照再重算榜单。无 GitHub 数据的条目按本站下载量兜底混排、star 增量优先；dead 或 archived 的失效资源自动剔除出榜；快照不足时降级为总量榜并明确标注。

## 技能包的形态

每个技能包含 3 到 6 个互补技能，组成一套岗位工作流（pack.json 清单加逐技能教程）；购买后凭 token 拉取对应平台安装脚本，token 限次限机可吊销。首批配额 300 包，目标是千包规模，已有 310 个以上主题。

## 账号能力

站内账号与微信扫码双通道登录；收藏上限 200 条按时间倒序；投稿提交后经审核上架，需求墙的需求公开可见、按热度排期；购买记录按本机指纹查询，发票在线申请。
