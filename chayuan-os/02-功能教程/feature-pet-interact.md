# 灵宠互动：点了一下灵宠它跳了一下，一次走通

很多人搜「点了一下灵宠它跳了一下，是打开什么了吗」，搜到的多是概念解释，落不到操作。这篇以察元AI OS为准，把灵宠互动从打开哪个应用讲到看到什么结果。

## 这个功能到底解决什么问题

灵宠互动在察元AI OS里的形态一句话说清：点击与右键是两套操作：名牌显示干活中、待命、休眠、思考中、输出中等状态；右键菜单有单聊、编辑、任务、装扮、钉住等；可拖拽、可开关漫游、双击直开工作台。

按真实界面写，按钮文案原样引用。

## 先确认这些再开始

- 桌面形态（察元AI OS），且至少有一只灵宠在桌面上。
- 在场规则（哪些灵宠会出现在桌面）：钉住的；绑定常驻任务正在执行的（含完成后 10 秒停留）；被双击启动且工作台窗还开着的。其余灵宠收在名册里。另外：某智能体的终端窗开着但没给它建过档时，桌面会出现该智能体的「野宠」。

## 完整操作步骤

1. 单击：逗它一下（不开菜单）

左键单击灵宠本体，随机播放一个彩蛋动作——「跳一下」或「左右晃」（每个动作有冷却时间，连点不会连环播放）。单击不会移动位置、不会打开任何菜单；菜单只能右键打开。桌面上的群实体（圆桌）单击则是整体晃动一下的动画，同样不开菜单。

2. 双击：直开工作台 / 直聊窗

双击灵宠：

双击后这只灵宠登记为「启动在场」，工作台窗关掉后它离场回名册（钉住的除外）。

1. 挂智能体的：打开该智能体的工作台窗口，直接落到这只灵宠的分区（不弹工作区选择器）。窗口会摆到灵宠不在的那半边屏幕，不会把灵宠盖住；
2. 模型直跑的：打开这只灵宠自己的「灵宠对话」直聊窗（窗口标题=灵宠名）；再次双击复用已开的同一只窗，不会越开越多。

3. 右键：浮卡菜单（逐项）

右键灵宠弹出磨砂圆角菜单卡（宽度跟随文字，最长 240px 封顶，超长行省略号截断）。正式灵宠的菜单从上到下：

野宠（临时）的菜单短一些：头部是智能体名＋「开工 <时间> · <目录名>」；「打开页面」（打开该智能体终端窗）、「分区目录」、「收编建档」、「删除灵宠」、「出战装扮」（灰）。

点菜单外的任意位置关闭菜单。

桌面群实体右键（圆桌造型，头顶「群名 · 人数」小牌）：菜单含群名/成员/分区信息行、「打开群聊」、「固定群到桌面（钉住常驻）」/「取消固定」、「编辑群聊」；有最近命题时还列「最近会话」若干条。双击群实体打开宠物群聊并定位该群。

1. 头部两行：灵宠名；状态行「待命 · <状态>」；
2. 「打开页面」：与双击等效——挂智能体的开工作台，模型直跑的开直聊窗；
3. 「分区目录」：在文件管理器（我的电脑）中打开这只灵宠的分区目录；
4. 「编辑灵宠」：打开编辑弹窗；
5. 「固定到桌面（钉住常驻）」/「取消固定」：切换钉住态（当前已钉住时显示后者）；
6. 「当前任务 · <状态>」信息行：当前状态回显（其上方预留给「最近会话」最近 3 条会话的区域，仅在有已读取的会话记录时出现——当前版本右键不会触发会话记录读取，该区域实际不显示）；
7. 「历史任务」：进入历史视图（列表 + 底部「＜ 当前任务」返回主视图）；当前版本会话记录的加载链未接通，历史视图显示「还没有历史任务」空态；
8. 「删除灵宠」：第一次点击变为红色「确认删除？再点一次」，3 秒内再点才真删；
9. 「出战装扮」：当前灰显不可点（装扮能力未上线）。

## 如何确认操作生效

验证

1. 单击桌面灵宠：它播放「跳一下」或「左右晃」之一，位置不变、无菜单弹出。
2. 双击挂智能体的灵宠：工作台窗在另一半屏打开，目录是它的分区；右键该灵宠可见「打开页面」「分区目录」「编辑灵宠」「固定到桌面（钉住常驻）」「历史任务」「删除灵宠」等项。
3. 双击模型直跑灵宠：弹出「灵宠对话」直聊窗；再双击一次是聚焦同一窗而非新开。
4. 点底栏「动态」按钮：变为「静态」，场景背景从视频切换为静态海报；再点切回。

## 什么情况下用得上

想看某只灵宠的状态（干活/思考/输出）与最近会话、历史任务，想直接跳进某只灵宠的智能体工作台或分区目录，双击进工作台继续对话，低配机器想让桌面场景动画更省资源。

用户常搜的问法：点了一下灵宠它跳了一下，是打开什么了吗；灵宠右键菜单里都有什么？『出战装扮』怎么是灰的。

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 接着回答几个常见问题

### 单击灵宠怎么没反应？

单击只触发彩蛋动作且每个动作有冷却（如「跳一下」冷却 2.5 秒），刚播放过再点会静默跳过。想开菜单请用右键，想开工作台用双击。

### 右键菜单里「历史任务」怎么总是「还没有历史任务」？

当前版本会话记录的加载链未接通，历史视图暂为空态占位。任务灵宠的执行状态看头顶气泡；常驻任务的历史运行记录在 设置 ＞ 常驻任务 的历史里。

### 「出战装扮」为什么点不了？

装扮能力尚未上线，菜单里该项当前固定灰显，属预留入口。

### 灵宠挡住了窗口/图标怎么办？

直接把它拖走（拖拽落点会记住）；或双击开它的工作台——窗口自动摆到灵宠不在的半屏，不会压住它。

### 重启后灵宠位置变了？

每次开机灵宠重新自动网格分布（防历史位姿重叠），拖拽摆位只在当次会话内有效，这是设计行为不是丢数据。
