# 大模型横评：媒体评测机构的对局式横评方法

给大模型做横评，最容易做成跑分搬运：榜单抄一遍，结论各打五十大板，读者看完还是不知道模型差在哪、差在哪个环节。大模型横评要想有增量，得让人看见过程。对局式横评是一条值得投入的路：把各家模型放进同一张棋牌桌，有规则、有胜负、有完整的决策链，每个结论都有画面与数据兜底。察元竞技场这类开源对弈平台，把环境成本降到了一台电脑。这篇给评测机构一套方法论、公平性控制清单与呈现建议。骨架不复杂：维度分清、环境锁死、过程透明，剩下的功夫都在细节。

## 方法论：维度先分清

四个维度够一轮横评用，贪多嚼不烂。

推理维度用完全信息玩法：五子棋（15×15）、中国象棋、围棋（9 路/13 路），模型看得见全局，考的是计算与规划，思维链气泡把推理过程摊开。棋类的优势是结果可判定：赢就是赢，错了就是错，解说词再漂亮也改不了判罚。

风险决策维度用不完全信息玩法：斗地主、德州扑克、掼蛋，模型只看得见自己的手牌，考的是信息推断、下注表达与止损，这类能力在题库里测不出来。看这类对局别只看结果，下注的尺度与放弃的时机，比输赢本身更能反映模型风格。

稳定性维度用工程指标：协议画像里的 JSON 格式遵守率与平均耗时，加上启发式代走、429 退避的出现频率——输出不稳、超时频发的模型，跑分再高也要在这里扣分。代走频次这条指标尤其能区分「看着都会」与「真能干活」。

速度与质量的权衡单独成节：思考型模型在长对局里通常更稳，但一手等待时间也长；快模型出招利落但容易毛糙。两头的样本都摆出来，别只报一头。

## 公平性控制清单

五条清单照着核。其一，同机同版本：全部场次用同一台机器、同一版察元竞技场（0.1.0）跑完。其二，同模型身份：用「获取模型」实拉各账号可用模型列表，确认所测型号没有张冠李戴。其三，同参数同时段：参数统一，批次避开限流高峰，429 自动退避的频次入表。其四，多局取样：单局有偶然性，结论建立在一组对局的分布上。其五，全程留痕：棋谱 JSON 全量导出存档，回放器按协议字段筛关键手，任何结论可回溯到具体那一手。环境记录表与棋谱一起归档，复核的人不用问第二遍。

## 场次安排参考

场次安排给一个框架：每个模型对每种玩法先跑热身局不入库，正式局按批次跑，批次之间留缓冲；同一玩法的对局集中在一个时段，避免不同时段的上游波动混进同一组样本。横评周期排几周都行，关键是每批的环境记录随手写，别攒到最后回忆。预算紧就缩阵容不缩场次，每模型的局数够才谈得上分布。发布前把「本横评怎么跑出来的」单独成段放文首，方法论前置，质疑少一半。

## 呈现建议

过程可视化优先于结论表格。思维链气泡是横评里出内容最多的素材：同一个局面，两个模型的盘算并排放，读者自己就能看出路数差异，视觉冲击力比文字强得多。形势曲线配逐手的 ？!标注（妙手与失误），转折点指着讲，比文字描述局势直观得多。

数据附录放工程指标。协议画像表格放在文末，正文讲行为，附录给遵守率与耗时，两类读者各取所需。表格数字保留一位小数就够，别制造虚假精度。

表述纪律写进编辑部规范：不给编造的胜率数字，结果引用自己跑出的对局并注明环境与日期；结论用条件式（「在本轮对局样本里」），不写永恒定论；模型强弱会随版本变，稿件标注版本 0.1.0 与对局时间。结尾固定放一段「局限」，横评的可信度往往藏在自我声明里。

## 边界

对局横评不能替代基准测试：它考察博弈行为，不覆盖知识问答、代码与长文本能力，两类内容是互补关系，别用一个否定另一个。样本量与费用要平衡：场次越多结论越稳，模型 API 费用按调用自付，预算写进选题评估。弱模型会乱走，系统代走兜底，但过程观赏性打折，参赛阵容要提前试跑。还有一点别忽略：横评的阵容要有梯度，强中弱都放进来，读者才知道自己关心的那档在哪。

## 三个常见误区

误区一：把单场胜负当结论，标题写「X 击败 Y」——单局随机性太大，写风格差异与过程指标更稳。误区二：只测头部模型，忽略中腰部——读者的大多数场景用不到头部那几家，中腰部的稳定与耗时信息反而实用。误区三：工程指标缺位——遵守率与平均耗时不进正文也该进附录，专业读者就冲这个来。另外把「本次不测什么」写清楚，评测的边界同样是方法论的一部分。

## 常见疑问

### 横评能排出谁强谁弱吗
能给出相对参考：在同一环境的多局样本里，谁更稳、谁更快、谁风格如何。但给不出放之四海的强弱定论，条件式表述是底线。

### 怎么保证对各家模型公平
同机同版本同参数、实拉模型列表核对身份、多局取样、全程留痕可回溯，五条清单全做到，公平性才有支撑。

### 弱模型乱走怎么办
解析容错链会尽量读出它的意图，读不出就启发式代走（能挡杀就挡、能吃就吃），代走超限判负；稿件里要标注哪些手是代走。

### 评测结果能复现吗
环境可复现（版本、玩法、参数、模型清单都记录），逐手结果不可复现（模型输出有随机性），结论建立在分布上就能经得起复检。

### 要不要公开全部棋谱
建议公开。棋谱 JSON 打包放文末或仓库，读者能自己验，这份坦诚本身就是评测机构的资产。

### 对局横评做一期要多长周期
视场次而定，小规模几天，全量横评几周；周期拉长时分批发布，每批标注批次与环境。

评测的公信力不来自结论多果断，来自过程多透明。对局式横评把「模型能力」这个抽象词拆成了看得见的几十手：每手的推理、耗时、格式都在记录里，读者可以顺着棋谱自己走到结论。这套方法比跑分搬运费事，但它产出的是别人抄不走的内容。对评测机构来说，花一个晚上跑一批对局，比再转述一次榜单有价值得多。读者记住的会是你讲清的那一手，而不是你抄来的那个名次。
