# 多用户怎么做：察元OS 怎么再建一个用户

多用户这件事，值不值得专门学一篇，看一个细节就够：用户增停删管。这个细节背后是一整套入口和验证链路，下面完整拆开，基于察元AI OS。

## 先弄清楚它是什么

多用户能做的事拆开就这几件：强制下线；重置普通用户密码，独立数据空间；用户增停删管。对应的界面入口是多用户账号管理

概念一分钟，操作十分钟，这篇都覆盖。

## 动手前的准备

- 桌面形态（察元AI OS）多用户根模式：账号存放在数据根的注册表（registry.json）里，由桌面主进程管理。web/docker 部署形态的 设置 ＞ 用户 是另一套「用户与访问链接」管理面，见对应教程。
- 管理卡仅管理员可见：任何用户都能看到顶部的「我的账号」改密卡；「开机登录」「用户列表」「全员共享模型 Key」「全员安装插件」「管理员操作审计」五张卡只在管理员登录时出现。管理员账号本身在首次安装向导里创建。
- 账号规则（主进程硬校验）：用户名 1-32 字符且不能与现有用户重名（不区分大小写）；密码最短 3 位；昵称为必填。

## 具体怎么操作

第 1 步 · 打开用户管理面

Dock ＞ 「设置」＞ 左栏「用户」分区。顶部第一张卡「我的账号」；管理员继续往下是「开机登录」「用户列表」「全员共享模型 Key」「全员安装插件」「管理员操作审计」。

第 2 步 · 添加用户（用户列表卡）

1. 「用户列表」卡底部点「添加用户…」，弹出「添加用户」窗口。
2. 逐项填写：
    1. 头像：默认按用户名确定性预选一枚内置头像（20 枚 AI 人物形象，同名恒同图）；可点「上传头像」传本地图片（上限约 2MB），或在预设网格里改选/点已选中的取消（回退首字母圆）。卡内说明「不传则显示首字母；锁屏与登录门将显示该头像」。
    2. 「用户名（登录用）」（≤32 字符）：登录门/锁屏选人用的名字。
    3. 昵称输入框（占位符显示「昵称（锁屏显示，可选）」，实际提交时必填——留空点创建会报「昵称为必填（跨终端互联时其他终端将以此称呼你）」）。
    4. 「密码（至少 3 位）」与「再输一次密码」。
    5. 点「创建用户」。成功后弹窗关闭，页面出现「用户已创建」，用户列表新增一行。
    6. 失败分支：用户名重复 ＞ 「用户名已存在」；密码不足 3 位 ＞ 「密码（至少 3 位）」；头像超限 ＞ 「头像过大（上限约 2MB）」。
    7. 建好的用户名+密码就是该用户的同一套凭据：锁屏解锁、开机登录门、远程访问（外网 /a/ 访问链接）三处通用，创建/重置即时生效。

第 3 步 · 为用户重置密码

1. 在用户列表找到目标行，点「重置密码」（每一行都有，含管理员自己）。
2. 弹窗标题「为「{用户名}」设置新密码」，在「新密码（至少 3 位）」框输入，点「重置密码」。
3. 成功提示「密码已更新」，新密码即时生效：该用户随即用新密码在锁屏/登录门/远程访问登录；其已登录的网页远程会话全部作废，需重新登录。
4. 注意：管理员重置不会清除该用户「智能体面试」找回通道的失败计数——若其面试通道正在冷却/锁死，重置密码后依旧要等冷却结束。

## 做完后的验证

验证

1. 新建：创建一个用户后按 Ctrl+L 落锁，锁屏「切换用户…」进登录门，应看到新用户的卡片（头像/昵称），用其密码可登录。
2. 重置：重置某用户密码后，让其用新密码登录成功、旧密码报「密码不正确」。
3. 停用：停用后重启应用，登录门卡片墙不再列出该用户；「启用」后重新出现。
4. 删除：删除后在「管理员操作审计」卡看到 delete-user 记录；数据根 chatop-data/users/ 下该用户的目录已不存在。

## 什么情况下用得上

人员离开/账号临时不用，想停用账号或把还挂在线的会话踢下线，一台电脑多人用（家人/同事共用），想给每人建一个独立账号，各人的桌面数据互不可见；家庭共用一台电脑；普通用户忘了密码，找管理员在设置里直接重置。

用户常搜的问法：察元OS 怎么再建一个用户；管理员怎么帮别人改密码。

## 它的局限也要说清楚

如实说明，它不是万能的：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- 云端厂商模型调用需自备 API Key

## 常见问题

### 删除用户后反悔了，数据还能找回吗？

不能。确认框里「不可恢复」是实义：该用户的 profile、home、找回画像被整目录删除，无回收站。建议删除前先「停用」观察；确要保留备份，先把整个 chatop-data 目录拷贝一份。

### 管理员能被停用或删除吗？能增加第二个管理员吗？

都不能。主进程对管理员角色有硬保护（停用/删除直接拒绝），界面也不提供这两个按钮；新建用户一律是普通用户角色，目前没有提权/移交管理员的入口。

### 普通用户自己能改密码吗？

能，不用找管理员：设置 ＞ 用户 ＞ 「我的账号」卡，输当前密码+新密码点「修改密码」。管理员重置是给「用户自己也进不去」时用的兜底。

### 重置密码后，那个用户手机/浏览器上开着的远程桌面会怎样？

会立即失效：改密会话版本号 +1，其所有已签发的远程会话（wa_sess）全部作废，需用新密码重新登录。

### 踢下线和停用有什么区别？

踢下线只结束当前会话（窗口关闭、需重新登录），账号一切照旧；停用是封住账号（登录门不再显示、密码登录被拒），但保留其会话之外的全部数据，可随时启用恢复。
