# 麒麟装办公套件：个人替换订阅制办公软件

麒麟装办公套件，难点从来不在安装动作本身，而在包型选择与批量分发的口径。本文以政企内网批量装机为主线，界面文案原样照录。

## 安装前确认

- 系统要求：Windows 10 及以上，x64/arm64
- 安装包：NSIS 安装器 exe
- 说明：信创环境免 root 安装。

安装包认准官方分发入口；其余站点的包不保证没被动过手脚，政企环境装机尤其别用。

## 一步步来

1. exe 安装包从官方入口取得，进内网前先核对来源
2. 双击安装
3. 启动后在设置里配置模型供应商（BYOK）或指向本机 Ollama
4. 开始页新建或打开文档

上面四步是 Windows 机器的走法，也是默认叙述线；麒麟机器照着「其他平台装法速览」那一节换包型即可，顺序完全一致。

## 其他平台装法速览

Linux：官方渠道下载对应包；deb 用 dpkg -i，AppImage 加执行权限直接运行；麒麟/UOS 走 AppImage 加 deb，免 root。

两种包型的取舍并不复杂：机器归信息科统一管、习惯走软件源或脚本装包的，用 deb 一条命令入库；机器分散、或者压根不打算给办公软件动系统目录的，AppImage 更省事——文件放在哪个用户目录下都能跑，卸载等于删文件，不留配置残留之外的任何痕迹。信创环境常见的情况是两者混用，按科室现状分派即可。

## 全平台安装速览

| 平台 | 环境要求 | 安装包 |
|---|---|---|
| Windows | Windows 10 及以上，x64/arm64 | NSIS 安装器 exe |
| macOS | macOS 11 及以上，Apple Silicon/Intel | dmg 与 zip |

## 装完后的第一件事

验收动作就三样：设置里把厂商 API 或本机 Ollama 接上，开始页新建 docx，请 AI 写一段测试文本；三样都过，这台机器就算可以交付。

内网机器走这个验收流程时，第三步可以换成隔离环境里可用的本地模型：能出一段文字，说明模型链路在断网状态下也成立。政企批量装机建议把这三步写进交接单，比口头交代靠谱。

## 收尾检查

- 开始页能新建六种格式文档，设置里模型可配置
- 若没有生效，先完全退出宿主软件再重启一次

重启这条经常被跳过。装完立刻点开功能、发现异常又立刻报障，其实多数只是宿主进程没刷新完；把「先重启再看」放在报障之前，能省掉一轮不必要的沟通。

## 注意事项与真实边界

有几点短处得先讲明白：

- web/dsh 形态内只有五个编辑器、不含 HTML，也见不到购买与激活的界面

## 装机相关的常见疑问

### 欢迎引导被我关掉了，想再看一遍怎么办？

引导只出现一次，界面不提供「重看引导」入口。想系统了解产品，按 F1 打开内置图文手册（18 主题，可搜索），见产品内的对应手册。

## 装到麒麟上能得到什么

- 三平台五形态安装包
- 免 root 可装
- 麒麟与 UOS 走 AppImage 加 deb
- 覆盖 Windows/macOS/Linux（含麒麟/UOS），同一套界面与文档格式跨平台通用

对政企内网批量装机来说，免 root 意味着不需要逐台机器开管理员权限；AppImage 与 deb 双包型并行，按发行版策略各取所需，一条分发脚本就能覆盖不同批次的工作站。

从「替换订阅制办公软件」这个角度看，装机形态本身就是差异所在：软件装在自己机器上、文档存在本地目录里，授权关系不挂在某个在线账号上；能不能用 AI、用哪家的 AI，由配置文件里的模型档案说了算。订阅制方案里那些「登录才能编辑」「到期停用」的依赖，在这条装机路径上不存在。当然代价也在上文写清楚了——没配模型时 AI 部分不工作，传统编辑功能不受影响。

## 数字口径备忘

壳内 MCP 服务端口 52588；知识库五级自动发现，注册表端口 52584，检索上下文预算默认 12000 字；支持 BYOK 接入 94 家模型供应商与本机 Ollama 等本地端点；十分区设置地图：通用、语言（22 种）、主题、模型、知识库、隐私等，通用区逐项可调。

## 内网与离线的实际口径

手册离线可读，快捷键表齐全；自带 Key 意味着不被单一厂商锁定，国内国际本地端点随切随用；内置账号登录当前版本未开放，现阶段须 BYOK 或本地模型；涉密文档不能出网的场合，本地模型让 AI 校对、AI 改写在隔离环境照常工作。还有一条常被忽略：AI 功能依赖已配置的模型，未配模型时只有传统办公功能可用，验收机器时别把它当成故障。

## 装机批量分发的小经验

给整个科室推这套软件时，建议先挑一台「最不好装」的机器试水：老旧内核的、桌面环境定制的、安全策略最严的都算。试水机走通全流程后，再把包型选择和验收步骤固化成内部说明，后面几十台机器就是重复劳动，出问题的概率反而低。反过来先在全新机器上装、再推广到老机器，中间踩的坑会多出不少。

这套流程里最容易翻车的环节不是安装本身，而是模型配置：每台机器都要走一遍设置弹窗，Key 从哪来、填到哪一格，提前写成一句话说明发下去，比事后逐个答疑省时间。

这篇把下载安装与首次启动的链路拆完了。哪一步卡住，回头翻上面的疑问小节，多半能对上号。
