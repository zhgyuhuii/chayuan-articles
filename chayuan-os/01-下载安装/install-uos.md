# 统信UOS安装是什么：家外部 CLI 智能体

统信UOS安装这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI OS的真实界面顺序走一遍，先解决统信UOS安装。

## 安装前确认

- 系统要求：x64/arm64；银河麒麟 V10、统信 UOS 20 推荐 deb
- 安装包：deb（ChaAIOS-版本-架构.deb）
- 说明：UOS 20 用 deb 的原因与步骤。

安装包从官网 aidooo.com 获取。

## 具体怎么操作

1. 按 CPU 架构选包：飞腾/鲲鹏选 arm64，兆芯/海光选 x64
2. sudo dpkg -i 安装 deb 包
3. 应用菜单启动，首次启动自动初始化数据目录
4. 麒麟/UOS 环境优先本地模型，离线即用

## 其他平台装法速览

Windows：官网 aidooo.com 下载对应架构的 exe 安装器；双击安装，零额外依赖；首次启动创建本机账户，进入桌面。

macOS：官网下载 dmg 并打开；把察元AI OS 拖入应用程序文件夹；启动后创建账户进入桌面。

## 国产平台要点

银河麒麟 V10 的 x64 机型（兆芯、海光）选 x64 包，arm64 机型（飞腾、鲲鹏）选 arm64 包；统信 UOS 20 用 deb 形态，arm64 真机已实测。暂不支持龙芯，选包前用 uname -m 确认架构。

## 装完后的第一件事

装完先干两件事：一是让模型设置向导跑完，把默认模型应用到各家智能体；二是试一次断网对话，确认本地模型链路通了。恢复密钥也顺手生成，忘了密码时它是仅有自助路径。

## 怎么确认做成了

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 边界先摆桌面上

功能归功能，这几个边界先摆清楚：

- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key

## 放回产品盘面看

把统信UOS安装放回察元AI OS的整体盘面：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注，共用办公环境下没密码的桌面等于裸奔，锁屏是最基础的一道闸；本地优先系统没有厂商服务器帮你重置密码，三路找回就是你的救命通道；数据目录自选意味着整个系统可以装在非系统盘，换机迁移就是拷目录。

## 安全与数据边界

安全口径单独立一层：全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重，与察元OS 同库同源；各家能力矩阵标明能否一键安装、写入模型、收系统技能、收 MCP、记忆采集；装智能体最常见的坑是 Node 版本与镜像源，一键安装把这些全抹平。

## 平台与形态

平台与形态的账：整套系统无头跑在 Docker 里作为多用户云桌面（察元AI工舱形态）：员工浏览器打开即用；Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌；设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness。

## 价格与授权

价格口径一并交代：免费下载使用，购买只停提醒、不锁功能；四档价格：149/359/599/1049 元，离线短码激活（HMAC 签发、绑定 16 位机器指纹、本地验签），跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定。

## 产品家族与搭配

察元AI OS不是单打独斗：设置关于里检查更新、下载并重启安装，一台服务器全组使用，运维只管一处，终端零安装，购买 OS 授权后，同机察元AI Office 自动免激活，Dock 直开内置的察元AI Office：文档、表格、演示在线编辑。

## 几条硬数字

能落到数字上的几条：换嵌入模型必须重建索引，大库上 Milvus，这些运维动作都收在设置页；就触发 kb_search、kb_list、kb_read_doc 工具链，三个 KB 工具自然语言触发，对配对终端开模型加知识库授权。

## 离线与内网

离线内网这条线的口径：本地引擎档同时最多 4 路并发，厂商云端档 16 路，超出排队，本地模型多宠同发会排队（本地档 4 路并发上限）；设置默认模型里给文生图与图生图各选自动或指定模型（本地已装生图模型或已启用厂商），首次下载约 2GB 权重。
