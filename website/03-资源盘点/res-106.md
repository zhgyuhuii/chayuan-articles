# 能力广场专题｜国产厂商目录导航

国产厂商目录导航。察元AI 能力广场（https://aidooo.com）把这类资源做了结构化收录：条目统一字段、带安装命令或配置片段、标注可用性状态。这篇专题按「怎么找→怎么选→怎么用→怎么避坑」四步给出完整路径。

## 这个专题解决什么

找资源难的不是「没有」，而是散落各处、质量不均、无法比较。能力广场用统一结构收敛这类问题：模型厂商板块（模型厂商）、大模型板块（大模型目录）等板块按统一字段维护，搜索与筛选组合使用。

## 相关板块怎么用

**模型厂商板块**：全球厂商与聚合平台目录，按「一线厂商→国产→聚合平台→本地部署→更多」分层，标注免费/免Key/本地标记与价格参考。

1. 进入 vendor 板块
2. 按分层浏览或搜索
3. 进厂商详情看模型列表

**大模型板块**：主流大模型信息目录：能力、入口、定价参考，配合智力榜/免费榜/对比页使用。

1. 进入 model 板块（模型中心）
2. 按厂商/能力筛选
3. 查看定价与入口

## 选择清单

1. 先看 health 状态，优先 active 条目
2. MCP 类看 scopes 风险分级，权限最小化原则
3. 排序数据可参考，但不迷信单一指标
4. 复制安装命令执行后做一次冒烟验证
5. 好用的资源收藏沉淀，失效的反馈上报

## 避坑提示

- 教程库内容来自公开网络采集导航，质量与时效需自行甄别
- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权

## 离线运行与部署形态

对断网环境，广场的配合方式是：先在联网机器上完成检索与命令复制，再转入内网执行；政企可私有化部署整套门户（Docker + nginx，含 SQLite 数据与 SSR 快照层）。

## 数据安全与隐私边界

- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 政企可私有化部署（Docker），数据自主可控
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）

## 费用与授权的边界（如实说明）

浏览免费；技能包买断制；部分教程条目付费。免费部分：全部板块浏览、搜索、榜单、对比、价格页、教程库均免费。付费部分：技能包商城：311 个技能包（13 大行业分类，免费占比约 10%），买断制、token 授权限 3 台设备、离线包含订单水印；支持微信/支付宝；购买后在察元AI OS / 八款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）中激活使用

## 常见问题
### 资源失效了怎么办？

条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注；发现问题可通过反馈渠道或机器人客服上报。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 下载产品从哪个入口？

产品页（/products）集中提供察元AI OS、察元AI Office、察元AI文档助手等的版本说明与各平台安装包入口。
