# 科研教育行业怎么用察元OS：从痛点到落地

科研教育行业的文档与信息工作有其固有节奏：多岗位协作时版本混乱、批注流转低效。察元AI OS在科研教育场景下的定位，是把可标准化的环节交给工具、把判断留给从业者的「人机协同」。本文按痛点→能力→落地步骤→边界的顺序，给出科研教育行业的完整应用路径。

## 科研教育行业的典型痛点

- 多岗位协作时版本混乱、批注流转低效
- 跨部门数据与引用需要反复核对出处
- 历史文档数字化程度低，检索与复用困难

## 对应的能力组合

- **故障一键转智能体修复**（智能体运维）：系统故障时自动组装诊断上下文+排障知识库并派单给智能体处理，是「AI 服务的现场」的代表性能力。
- **插件页签（三源）**（插件市场）：npm 官方/npmmirror/社区精选三源可切换的插件市场：七类分类过滤（工具/界面/知识/集成/实用/安全/智能体）、分页浏览、拖拽排序、分组、已装标记。
- **应用商店**（AI应用商店）：插件/技能双类型商店（规划五类商品：插件/技能/MCP/提示词/智能体+技能包），aidooo.com 为默认首选源；免费直下，付费走内嵌收银台 webview，支持断点续传、sha256 校验、原子换入。
- **统一模型代理**（模型网关）：统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。

## 落地四步

1. 盘点本岗位高频文书/信息任务，挑最耗时的两个作为切入口
2. 按内网/涉密单位用户场景的工作流试跑一周，记录节省的环节
3. 把常用任务固化为助手或规则模板，团队复用
4. 建立人工复核节点：工具产出 → 从业者裁决 → 定稿

## 合规与边界

- 涉密与敏感材料遵循本单位管理规定，必要时使用离线部署形态
- Docker/云通道等进阶形态需要一定动手能力
- 行业判断责任始终在人，工具输出作为参考

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- API Key safeStorage 加密存储，仅注入子进程

## 常见问题
### 技能和插件有什么区别？

技能（SKILL.md 目录）教智能体「怎么做某类事」；插件（dsh 插件）给桌面增加「新应用或面板」；两者都可离线导出导入。

### 手机能用吗？
