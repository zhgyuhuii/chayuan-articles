# AI智能体是什么：按项目选趁手的智能体

搜AI智能体的人通常带着两个问题：是不是噱头、值不值得装。这篇不站队，定义、口径、边界三段摆开，你自己对号。

## 什么是AI智能体

AI智能体这个说法对应的产品是察元AI OS（Chayuan AI OS）：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面。

数字都能在官方文档里核到，文末尾注标了时间点。

## 最短上手路径

从这几步开始：

1. 17 家外部 CLI 加内置 Harness
2. 能力矩阵一目了然
3. 新装约 5 秒自动感知
4. 官方品牌图标自动拉取
5. 场景验证：对比不同智能体的代码质量
6. 场景验证：按项目选趁手的智能体

两个场景验证各有侧重：前者拿同一段代码任务丢给不同智能体，比对产出质量；后者把候选智能体放回你的项目类型里试——写脚本、改遗留代码、跑长任务，各家的脾气差别不小，试过才有发言权。

## 落点的能力面

落点的能力面覆盖四件事：17 家外部 CLI 加内置 Harness 的统一管理、能力矩阵的直观呈现、新装约 5 秒的自动感知、官方品牌图标的自动拉取。后两件看似边角，实际决定体验的顺滑度：新工具装完即出现在矩阵里，不必手动登记，也不会留一堆占位图标。

## 察元AI OS的能力地图

- 知识图谱：知识库应用里有个同名页签，自动生成文档与实体的二部图。
- 画图应用：内置 jspaint 画板（仅桌面形态），涂鸦、批注、简单标注都行。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 系统技能应用到智能体：将系统能力手册连同动态生成的模型清单，镜像进六家智能体的技能目录。
- 桌面右键菜单：桌面空白处右键：新建、上传、更改墙纸、小组件、便签、图标大小与排序、添加快捷方式。
- Spotlight 聚焦搜索：Ctrl 或 Cmd 加 K 唤起：搜应用、文件、内容，加问 AI 知识库直答，支持语音输入。

## 先看四条限制

- 8GB 内存的设备同时加载一个对话模型为宜，复杂任务受限
- 龙芯平台暂不在适配范围；本地没有视频生成，该能力走云端路由
- 要调云端厂商模型，请自备 API Key
- Docker 云桌面、跨终端互联一类进阶形态，需要些动手功夫

限制就这四条，提前知情总比临场抓瞎好。

## 数据与安全设计

- 敏感操作记录在 audit.jsonl 里，可以回放核对
- API Key 存在 safeStorage 加密层里，遥测可整体停用

## 两个常见疑问

### 联网与否对 AI智能体影响大吗

影响主要在模型侧：本地大模型不联网也能对话；云端厂商模型要联网并自备 API Key。涉及网页的操作，则由内置浏览器窗配合 webwindows 交由智能体驱动。

### AI智能体的数据放在何处

分形态：单机桌面形态把本地大模型、知识库、智能体、宠物群聊装进一个桌面；工舱形态则无头跑在 Docker 里作为多用户云桌面，员工浏览器打开即用，账户隔离、数据在服务器侧统一管理。

## 一句收束

AI智能体怎么选，上文给了六个步骤和一张能力矩阵，照着走一遍，趁不趁手自有答案。顺带一句：智能体是耗材不是信仰，按项目轮换着用才是常态。

## 日历与办公：桌面里的常驻件

四本日历把生活与工作分开记，AI 能读会写；Dock 直开内置的办公套件，文档、表格、演示在线编辑；整套系统以完整桌面环境为壳——它不是塞给你的又一个软件窗口，而是桌面本身的延伸。

## 智能体操作桌面的真实通道

文件可浏览上传、右键用智能体打开、可设为默认打开方式；智能体能对一个桌面做的事，基本就是一个熟练用户能做的，终端是证明；内置浏览器窗配合 webwindows 可被智能体驱动，不装第三方浏览器也能完成网页操作；与配对终端可发消息附件、让对方智能体执行任务、离线暂存送达，武力值徽标（信号格加等效算力）显示连接状态。

## 平台与形态

平台与形态的账：web 与 docker 形态提供 9 位字母外网后缀访问链接、wa 会话管理、踢线操作，Dock 文生图应用：提示词加负面提示词，生成后可设为壁纸或开 30 分钟自动换壁纸；应用页签：dock 应用隐藏、新建分组、自定义网页、本地程序、HTML、文件四类应用封装上桌，设置桌面与 Dock：位置、自动隐藏、图标放大与大小、开机自动打开 Harness。

## 提醒事项与可定义的桌面

提醒事项支持智能筛选（今天、已计划、旗标、已完成）与多列表管理；桌面本身能被 AI 定义，能力边界从预装走向按需生成。

## 配置怎么分发到各家智能体

配置完成后一键应用到各家智能体，统一生效；保存后随系统技能分发到智能体，设置结果同步到智能体侧。这套分发逻辑的意义在于改一处、全生效：模型代理地址或技能清单更新后，不必挨家挨户重配，各家智能体拿到的是同一份口径。

## 容量与依赖的账

全量安装包含模型权重约 4.7GB，轻量包约 1GB，完整离线能力需要额外下载权重；云端厂商模型那边得自己备好 Key。

真要浓缩成一句话：一台机器同时管 17 家外部 CLI 加内置 Harness，配置互不打架。
