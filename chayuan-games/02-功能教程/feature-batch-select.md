# 批量选模型：机机观战一次配齐参赛选手

办一场像样的模型对局，参赛选手动辄七八个：今天想看四个模型打斗地主，明天想让一排模型跑锦标赛积分榜。要是每开一局都得把模型一个个点选一遍，光是选人就把兴致磨没了。察元竞技场给这件事配了顺手的解法：批量选模型。这篇讲清批量勾选怎么操作，以及它和锦标赛怎么复用。

## 先弄清楚它是什么

批量选模型是竞技场里给参赛选手「配齐人马」的能力：在选模型的环节一次勾选多个模型，不用逐个添加。它的适用面覆盖两大场景——机机观战与锦标赛共用这套选人流程。今天勾一批模型开桌观战，明天同一批人马拉去跑循环赛，选人动作是同一套。名单是竞技场里的常用资产，攒熟了之后，开一局的时间成本会越来越低。

把场景摆出来更直观：机机观战选两个或多个模型开打，你在旁边旁观；锦标赛选一批模型打循环赛，排程自动生成，积分榜实时刷新，跑完出冠军。两者的起点都是「把选手配齐」，批量选模型就是配齐选手的那一步。

配合匿名观战的机制看更有意思：批量勾选进来的一群模型，在座位上统统隐去真名，显示玩家A、玩家B、玩家C、玩家D，你只能靠行棋风格猜谁是谁。选手越多，猜谜越热闹，终局揭晓时翻牌的快乐也越足。

它省的不只是点击次数。选手名单整齐，观战时的座位博弈才丰富，锦标赛的轮次才成规模——选人这一步的质量，直接决定后面一整晚的内容质量。尤其在锦标赛场景里，选手名单就是赛事本身：名单定了，轮次定了，积分榜的故事线就定了。

## 动手前要备好什么

批量勾选的前提是「有得可选」。先去设置 ＞ 模型配置把选手们的入场手续办好：从 85 家厂商目录里挑厂商点进去，填上你自己的 Key，用「测试连接」验一验；「获取模型」能把该账号可用的模型全列表实拉下来勾选入库；本地模型走 Ollama 免 Key 接入。

一个原则记牢：没配置好的模型，批量勾选时勾了也上不了桌。选人环节只认你已经接入的模型，配置是选人的前置。

名单怎么搭有讲究。看棋好玩，讲究阵容反差：思考型与响应型混搭，保守派与激进派同桌，火药味才足。跑锦标赛求稳定，讲究选手齐整：格式稳、不轻易触发容错的模型优先，弱选手可以进，但别让短板拖垮整场节奏。

## 具体怎么操作

第一步，回大厅选模式。想看对打就开机机观战，想办联赛就开锦标赛，两条路都会走到选模型这一步。

第二步，批量勾选参赛模型。在选人环节一次勾选你要的多个模型——想看混战就多勾几个，想看单挑就勾两个。勾选范围随你：同厂不同款可以同桌，跨厂混编也行，本地模型与云端模型还能同台竞技。

勾选的颗粒度是模型，不是厂商：同一家厂商目录下拉了几个模型，就按模型逐个勾。想让两家厂牌对垒，就一边勾 A 家一边勾 B 家；想办大混战，就雨露均沾地全勾上。

第三步，确认开桌或开赛。机机观战勾完直接开打，座位按匿名观战显示玩家A、玩家B、玩家C、玩家D，终局才揭晓真身；锦标赛勾完自动生成循环赛排程，积分榜实时刷新，挂着跑就行。

开打之后就不用管选人了：座位落定、排程生成，剩下的交给对局引擎。你此刻只需要准备点喝的，以及一副看好戏的闲适心情。

第四步，复用你的选手名单。这批人马明天还想用？重新走到选人环节按同样的思路勾选即可。观战与锦标赛共用选人流程，意味着你练熟的勾选手法两个场景通吃，不用学两遍。

第五步，按需增减。选手名单不是一次定终身：想加新模型，先去设置里配置好，再回选人环节勾上；想撤掉谁，勾掉就行。增减的灵活度让名单始终贴合当晚的心情与额度。

## 做完后的验证

开桌或开赛前扫一眼座位与赛程：你勾的模型是不是都在名单里。机机观战看座位数对不对，锦标赛看参赛名单与轮次排程对不对。都在，就等着看戏；缺了谁，回配置环节补手续。

锦标赛多看一眼排程合理性：循环赛意味着每位选手都会碰上其他选手，轮次排满才算配齐；少了谁，积分榜就失真，宁可开赛前多花十秒核对。

## 这些边界要心里有数

勾得越多，跑得越久、花得越多。云端模型每手都消耗你的 API 额度，锦标赛循环赛场数随参赛人数增长，八个人打一轮比四个人打一轮贵得多也慢得多。挂机跑大赛之前先掂量额度；Ollama 本地模型零成本，大规模混战用它压阵更安心。

没配好的模型进不了名单，这是前提不是缺陷。批量选模型加速的是「选」，不替你完成「配」。

弱模型进混战要降低预期。废招多、触发代走兜底频繁的选手会拉低整场观感，选手质量参差时，观赏性向短板看齐——这是费用与筛选的权衡，不是功能问题。

批量选模型管选人，不管盘口。谁强谁弱，天梯与实战说了算；别因为某家名气大就重仓勾选，桌上见真章。

## 高频疑问

### 批量选模型在哪些场景下用

机机观战与锦标赛的选模型环节都支持，两处共用同一套选人流程，勾选逻辑一致。

### 一次最多能勾多少个模型

上限以应用内实际界面为准。建议按费用与时长掂量：选手越多，对局与轮次越多，云端模型的额度消耗也越大。

### 本地模型能进批量名单吗

能。Ollama、LM Studio、Xinference 这类本地推理免 Key 接入，配置好之后与云端模型一样参与勾选，跑起来零 API 成本。

### 勾选错了怎么调整

开局前在选人环节取消勾选重新勾即可；配置层面的问题回设置 ＞ 模型配置处理。

### 机机观战和锦标赛用的是同一批模型配置吗

模型来源是同一份配置，选人流程也是同一套，区别只在开打方式：一个开桌观战，一个自动排程循环赛。

### 观战中途能换选手吗

以应用内实际能力为准；稳妥的做法是开局前用批量勾选一次配齐，中途换选手容易打断对局节奏。

批量选模型解决的是个「人越多越麻烦」的老问题，解法朴素：让选人回到勾选清单本来的样子。真正的乐趣在勾完之后——四个模型抢地主、八个模型跑积分榜，选手配齐的那一刻，竞技场才算真正开张。你的模型名单攒得越厚，这张桌子越好玩。
