# ✨发文前五步自检流水线，一篇给你说透

错别字→序号→保密→脱密的机关发文标准动作串联。这条组合工作流的思路分享，建议先收藏再看📌

✅ **工作流拆解**

1️⃣ 拼写与语法检查：面向错别字、语法、标点、固定搭配等「可证实」问题的结构化校对：输出可解析的 JSON 问题清单（原文引用+修改建议+理由），默认以批注写回钉到具体位置，适合长文…
2️⃣ 检查段落序号格式：针对公文、标书、制度文件的编号体系（一、（一）、1.、（1））做一致性检查，输出分级结论与修改建议，默认不改写正文。…
3️⃣ 保密检查：对密级标识、涉军涉装、单位身份、联系方式、项目编号、商业秘密等做分级风险提示，用于发文外发前自检（付费功能）。定位是辅助参考，不替代人工定密。…
4️⃣ 文档脱密：把确认的敏感词替换为占位符并建立密码保护的映射关系，实现可逆脱敏：对外发送脱敏版，内部留存映射可一键复原（付费功能）。…

🔍 **衔接要点**

· 同音字（的/地/得、象/像、做/作）与形近字（己/已/巳、戊/戌/戍）是中文高频错误，校对清单会显式覆盖
· 公文编号错误是退文高发原因，发文前必查
· 与「涉密关键词提取」「文档脱密」串联成外发前流水线
· 复原密码务必留存，丢失后无法还原

🛠️ **断网也能用？这点很关键**

从 4.0 版本起，安装包内嵌 sidecar 单文件二进制并注册开机自启，适配离线、内网与县级环境部署；推理指向本地或内网端点后，文档内容不出本机。MCP 服务只监听 127.0.0.1:62588 回环地址，本机即信任边界，远程机器无法直连——这是「涉密不出域」的安全设计，可用环境变量 CHAYUAN_MCP_PORT 调整端口。

⚠️ **数据安全要知道的**

· MCP 服务仅监听 127.0.0.1:62588，无需 Token 与命令行，sidecar 与 WPS 同机运行，文档与密钥不出域
· 知识库凭据采用 AES-GCM + HKDF 端侧加密落盘，密钥派生自设备绑定 OPFS 盐，明文永不落盘、不参与同步
· 匿名指标上报默认关闭（opt-in），不采集文档内容

答：在支持 MCP 的客户端里添加服务地址 http://127.0.0.1:62588/mcp 即可；安装器会自动把使用技能投放到 Claude Code/Cursor/Codex 的技能目录。
