# 安装包校验：逐文件校验的习惯

安装包校验要落到手上，无非三道坎：校验工具用什么、摘要从哪取、对不上时怎么处置。这篇沿察元AI OS 的装机动线把安装包校验讲透，从下载那一刻一路管到首次启动。

## 安装前确认

- 系统要求：Windows 10/11，x64 或 arm64
- 安装包：NSIS 安装器（ChaAIOS-版本-架构.exe）
- 说明：逐文件校验的习惯。

安装包只走官方发布渠道这一条路，第三方站点流出的文件难保没被二次打包过。

## 一步步来

1. 从官方发布页取对应架构的 exe 安装器，文件名里的架构字段先看清
2. 双击安装，零额外依赖
3. 首次启动创建本机账户，进入桌面
4. 对话应用里选本地模型即可开聊，全程无需联网

## 如何确认操作生效

- 启动进入桌面，对话应用选本地模型能正常回复
- 首启初始化需要 5 到 30 秒，属正常现象，期间不用干预

## 为什么建议一个文件一个文件过

传输环节的变数比想象中多：网络抖动会让文件截断，某些下载工具断点续传时拼接错位，来路不明的镜像还可能整包替换。这些问题多数要到双击安装那一步才暴露，而安装器给出的报错往往定位不到根因，白白折腾一轮。拿到安装包先过一遍校验再动手装，排查故障时就能把「文件本身有问题」这个变量先行排除。逐文件校验省力的地方还在于积累信任：头一回安装验证通过的那个包，把校验值记下来，下次给别的机器安装时先比对再运行，就不必重新趟一遍坑；团队里多人各自下载容易出现版本参差，统一以同一份校验值为准，出了状况也好对齐排查口径，省下的都是反复重装的时间。

## 校验值怎么比对

发布页若附了 sha256 校验值，Windows 下可以在命令行执行 `certutil -hashfile 文件名 SHA256`，把生成的摘要与发布页逐字符对照，对不上就删掉重下，不要抱着侥幸心理继续安装。没有校验值可查时，至少核对文件名里的版本与架构字段，和上面安装前确认列出的命名规则吻合后再运行。

## 校验没过时通常是什么表现

摘要对不上，多半说明文件在传输中出了状况：体积与发布页标称的不一致、安装器一启动就退出。这些表现都指向同一个处理方式——重新获取安装包，而不是反复双击硬试。另一种情况是架构拿错：x64 的机器取了 arm64 的包，校验值本身没问题，但文件名与机器对不上，这种情况回到下载页重选架构再取一次就好。

## 装之前先把限制摸清楚

- Docker 云桌面与跨终端互联属于进阶玩法，配置过程要花些功夫
- 龙芯平台目前没有对应版本；视频生成本机不做，交给云端路由
- 想调用云端厂商的模型，API Key 得自己准备
- 内存只有 8GB 的机器，一次挂载一个对话模型更稳妥，复杂任务会吃力

## 装好后桌面是什么样

桌面与 Dock 可调的项目包括摆放位置、自动隐藏、图标随鼠标放大与整体大小，也能设定开机自动拉起 Harness，桌面空白处右键还能录屏；小窗便签独立于普通窗口之外，支持新建、置顶、折叠、换底色，图片和视频都能作为附件贴进去；内置终端不是摆设，跑的是真实 shell，会话可持久，上次的环境下次还在。

## 数据安全上几个值得核对的点

填进系统的 API Key 走 safeStorage 加密落盘，遥测开关可以整体关掉；模型库会按本机内存预算给出分层建议，每档标明能跑、勉强还是跑不动；本机模型请求统一走 OpenAI 兼容出口（127.0.0.1:52581），智能体只需配这一个地址，代理只绑本机回环，要让别的机器访问得另行打通链路。

## 应用和 Dock 怎么组织

应用页签里可以把 dock 上的应用隐藏或归入新建分组，网页、本地程序、HTML 页面、文件四类东西都能封装成桌面上点得开的应用；Dock 天天要碰，摆在哪、多大，直接决定手感；从 Dock 能直接打开内置的察元AI Office，文档、表格、演示都可以在线编辑。

## 和其它组件的搭配

它并非孤立运行：插件可以启停、卸载，也支持离线安装；灵宠商店的主题页签把场景背景、36 个图标皮肤和灵宠皮打成一个组合包整套装上；系统更新入口在设置的关于页，检查更新后下载重启即可完成，部署侧一台服务器供全组共用，运维只维护一处，各终端不用装东西。

## 模型相关入口记两条

设置＞模型＞设置向导就是重跑入口；以后想换默认模型，进设置重跑一遍向导就行，无需重装。本地模型管的是从无到有，真正吃力的任务仍要靠云端旗舰模型顶着，而云端在断网时用不了，好在可以设定自动回落到本地。

## 断网时还能用什么，内网要补哪一步

本地音乐（用户音乐目录）与音视频播放，与配对终端发消息附件、让对方智能体执行任务、离线消息暂存送达、武力值徽标（信号格加等效算力）；内网或特殊网络环境是装插件的必经配置。

## 文件交给智能体的路径

文件可以浏览上传、右键交给智能体打开，也能设成默认打开方式；从文件管理器右键直接派活给智能体，是日常最顺的一条 AI 入口。智能体在一台桌面上能做的事，大致就是一个熟练用户能做的事，内置终端是最直接的证据，浏览器窗也一样，配合 webwindows 机制可被智能体接管操作。
