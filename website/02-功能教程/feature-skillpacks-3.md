# 从需求到交付：技能包商城

技能包商城这件事，卡住人的通常是三步：入口在哪、要点哪些按钮、做完怎么确认。这篇按察元AI 能力广场的真实界面顺序走一遍，先解决给运维岗位买整套技能包。

## 为什么值得了解

给财务团队配报表技能包；给运维岗位买整套技能包。

## 一步步来

买一个技能包

1. 进技能包商城按一级行业、二级场景或关键词筛选
2. 点目录卡片看包内技能清单与教程（付费前只显示介绍与价格）
3. 下单购买获得 token
4. 已购后点卡片弹出安装工作台，凭 token 拉取对应平台安装脚本

装完怎么管

1. 安装工作台里可以查看 token 使用次数与绑定设备
2. 换机器按 token 规则迁移，次数用完可续
3. 对包质量有评价权：详情弹窗里有赞踩
4. 内容有 AI 辅助生成的部分会在页面标注

## 关键能力点

- 每包 3 至 6 技能成套
- 一次购买装进八款智能体
- 断网离线安装
- 一级行业加二级场景筛选

## 几个容易忽略的细节

用之前要认的账：

- 教程库只做元数据导航，正文仍在源站
- 下载前需要完成登录（账号或微信扫码）

## 你可能会问

### 技能包里都有什么？

每包含 3 到 6 个互补技能，组成一套岗位工作流（如后端开发、教案制作、田间试验），配 pack.json 清单与教程。

### 买了以后怎么装？

购买获得 token，凭 token 拉取对应平台（Windows、macOS、Linux）的安装脚本执行；token 限次限机，可吊销。

### 技能包会过期吗？

按购买时的授权形态执行（时间授权或次数授权），过期后可续费，包内容本身持续更新。
