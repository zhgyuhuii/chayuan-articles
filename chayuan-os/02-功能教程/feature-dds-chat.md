# 从入口到验证：远程执行

先说这篇能帮你干什么：读完能在察元AI OS里独立完成远程执行，路径是让显卡机跑生图任务。步骤里的每个「」按钮都是界面原文。

## 是什么与为什么

远程执行能做的事拆开就这几件：消息附件互发；离线消息暂存后送达；远程派活给对端智能体。对应的界面入口是跨终端聊天与远程执行

按真实界面写，按钮文案原样引用。

## 先确认这些再开始

- 两台桌面形态终端在同一局域网，互联默认开启、双方「被发现」开着。
- 聊天零门槛：双击对方即可开聊；但消息文本用配对密钥加密——密钥在双方首次发生直连动作（如「派任务」）时自动协商建立，未建立前发出的消息会先显示「· 待送达」暂存，建立后自动补投（见常见问题 Q1）。
- 派任务需要对方授权：对方要在它的 设置 ＞ 跨终端互联 ＞ 通讯录 里给你这台开「智能体执行」；没开则任务被直接拒绝。
- 派任务在对方终端由其本机可用模型执行（经对方模型代理，免 key），执行前后对方会收到通知并可审计。

## 具体怎么操作

第 1 步 · 打开聊天窗（三个入口任选）

打开后是标题为「跨终端聊天」的窗口：左栏「终端」会话列表（头像+武力值徽章+昵称+最后一条消息摘要+未读红点，按在线优先/武力值排序）；右栏聊天区，未选会话时提示「选择左侧终端开始聊天」。

1. 顶栏双人图标 ＞ 互联弹层 ＞ 双击终端行（悬停提示「双击开始聊天」）；
2. 设置 ＞ 跨终端互联 ＞ 通讯录表该行操作列点「聊天」（对方离线时按钮灰、悬停「对方离线」）；名称列双击同样可开；
3. 通知中心里「跨终端消息 · 〈昵称〉」条目双击直达对应会话（悬停提示「双击打开聊天窗口」）。

第 2 步 · 发文字消息

1. 底部输入框（占位符「输入消息，Enter 发送」）输入文字，Enter 或点蓝色「发送」按钮；
2. 看到什么：自己的消息立即以蓝色气泡上屏，时间戳为「HH:MM」（非当天显示「M/DD HH:MM」）；发送中/未送达的消息尾部带灰色「· 待送达」标记，送达后消失；
3. 对方回的消息在左侧带其头像；会话有新消息时你会在通知中心收到「跨终端消息 · 〈昵称〉」通知（正文为消息前 80 字）。
4. 每个会话最多保留最近 500 条消息，超出自动从头滚动清理。

第 3 步 · 发图片/附件

1. 点输入框左侧「」按钮（悬停提示「发送图片/附件」）；
2. 弹出系统文件选择窗（标题「选择要发送的文件」），选中一个文件；
3. 看到什么：图片（png/jpg/gif/webp/bmp）在气泡里直接显示缩略图，点击放大打开；其他文件显示文件卡片（图标 + 文件名 + 大小）。对方收到的文件同样以卡片/缩略图呈现。

## 收尾检查

验证

1. 双机互发一条文字消息：双方气泡即时上屏、无「待送达」尾巴（若首条一直待送达，按常见问题 Q1 处理）。
2. 发一张 png 图片：对方会话里出现可点击的缩略图。
3. 对方关掉「智能体执行」授权后派任务：收到 unauthorized: agent_call not granted；重新开授权再派：聊天里出现「任务」+「任务结果」两条气泡，对方通知中心有「智能体任务开始/完成」两条记录。

## 什么情况下用得上

台式机上装了大模型，想用笔记本「蹭」台式机的算力，或让算力强的那台替自己干活，消息发出去一直显示「· 待送达」，不知道卡在哪；两台察元OS 之间要快速传一段话、一张截图、一个文件，不想走微信/网盘；给同事机器派活。

用户常搜的问法：两台察元OS 之间怎么发消息、传文件；能让另一台电脑上的 AI 帮我执行任务吗。

## 注意事项与真实边界

功能归功能，这几个边界先摆清楚：

- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 云端厂商模型调用需自备 API Key
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限

## 接着回答几个常见问题

### 第一条消息一直显示「· 待送达」？

两台机器还没建立过配对密钥（文本消息用它加密）。任一方先在聊天窗点「派任务」发一个任务、或等对方先向你发起任何直连动作，握手完成后暂存消息会在下一轮（约 30 秒内）自动补投。持续不通再按 R1 Q1 排查网络与「被发现」状态。

### 派任务返回 unauthorized？

对方没在它的 设置 ＞ 跨终端互联 ＞ 通讯录 里给你开「智能体执行」。授权是数据拥有方在自己机器上开的，方向别搞反。

### 消息能撤回吗？发错了怎么办？

不能撤回。聊天记录只存在双方本机（每会话滚动保留最近 500 条），删不掉对方的副本；敏感内容别发，或事后请对方拉黑/解除关系。

### 附件有大小限制吗？

文件经分块传输并带哈希校验与断点续传，界面上没有声明的单文件上限。注意暂存消息（含附件）超过 7 天未送达即过期不再投递——长期离线的对端收不到。

### 对方收不到我的文件/消息，但我这边没报错？

三种可能：对方把你拉黑了（对拉黑终端一切消息静默丢弃，发送方只见「待送达」不报错）；对方离线超过 7 天（暂存过期）；网络多播受限。先让对方检查通讯录里你的行是否被置灰。
