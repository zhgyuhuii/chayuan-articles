# 聚合门户 vs 厂商官网直取（场景化推荐）

聚合门户 vs 厂商官网直取，是很多用户在选型阶段绕不开的问题。这篇场景化推荐不给「闭眼选谁」的答案，只给统一维度的对照表和条件式建议——你的场景条件不同，结论就不同。

## 逐项解读

**比价**：选型效率。能力广场侧的做法是「201 模型价目+智力榜并排」，对照方案为「一家一页自己拼」——差异的本质在于设计取向不同，而非优劣。

**准确**：下单前回官网核实。能力广场侧的做法是「参考数据，标注以官方为准」，对照方案为「官方一手信息」——差异的本质在于设计取向不同，而非优劣。

**发现**：信息差价值。能力广场侧的做法是「免费额度/活动聚合提醒」，对照方案为「不逛不知道」——差异的本质在于设计取向不同，而非优劣。

## 条件式建议

调研比价用聚合门户，最终下单回官网。再补三条判断线索：

- 先明确你的硬约束（保密/预算/平台），硬约束直接淘汰不满足者
- 拿真实任务各试三天，比看十篇评测有用
- 考虑迁移成本：现有流程改动越小越好，渐进替换最稳

## 什么情况下不选它

- 投稿有人工审核门槛，重复或低活跃项目会被拒
- 技能包买断制且 token 限 3 台设备，多设备团队需规划授权
- 教程库内容来自公开网络采集导航，质量与时效需自行甄别

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 政企可私有化部署（Docker），数据自主可控
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注
- 注册仅需基础信息，支持图形验证码；会话走 JWT Cookie
- 网站不存任何二进制文件，安装一律跳转原始地址

## 常见问题
### 和察元产品家族什么关系？

aidooo.com 是家族官网与资源门户：产品下载、激活购买、应用商店目录都在这里；OS 客户端内嵌同源广场。

### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。
