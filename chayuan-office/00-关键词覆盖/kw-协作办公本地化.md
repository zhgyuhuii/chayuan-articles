# 一文分清协作办公本地化：家供应商目录

协作办公本地化要过的关只有一道：数据与密钥能不能都留在自己手里。这篇以察元AI Office 为例，把模型接入、密钥存放与边界讲透。

## 什么是协作办公本地化

这套样本是察元AI Office（Chayuan AI Office）——开源的 AI 办公套件，六编辑器一体、AI 嵌进每个编辑器；「本地化」在它身上的落点是模型与密钥的属地。

口径来源官方文档，版本信息在尾注统一交代。

## 本地化落在哪里

落点是模型供应商 BYOK：94 家供应商目录（国内 29、国际 34、本地 9、聚合 22）配 28 个适配器，支持 5 种协议（用户可选 4 种：Anthropic Messages、OpenAI Chat、OpenAI Responses、Gemini Native）；模型列表实时拉取不预置，Key 存本机 ai-settings.json 不上传，支持环境变量引用；按对话、生图、媒体、搜索四类能力分别设默认。

单说的理由：Key 在自己手里，就不必被单一厂商拿捏，国内、国际与本地端点想切就切。

## 最短上手路径

照着下面配一家厂商：

第 3 步 · 配置一家供应商（以 DeepSeek 为例）

1. 左栏「国内平台」组点「深度求索 DeepSeek」，右栏出现配置表单，头部有状态（「已启用，模型出现在选择器中」/「未启用」）和启用开关。
2. API 地址：已预填厂商默认值（DeepSeek 对应其官方接口地址）；自建或反代地址直接改写。
3. 协议：下拉四选——「Anthropic Messages（直连，不转换格式）」「Chat（OpenAI Chat Completions）」「Responses（OpenAI Responses API）」「Gemini Native（generateContent）」，页脚注明「四种协议均为原生直连，无需格式转换」。目录厂商已按其原生协议预选，一般不用改（内部适配共 5 种协议，第 5 种 codex-app-server 由 Codex CLI 适配器内部使用，不出现在下拉里）。
4. API 密钥：粘贴密钥（输入框旁「显示密钥 / 隐藏密钥」切换明文）；已保存过时标注「已配置（留空保持不变）」——留空重新保存不会清掉旧 Key。可灵（Kling）这类 AK/SK 双字段厂商会各给一个输入框，保存时按声明折叠成一个密钥。表单旁「获取密钥」直达该厂商控制台。
5. 点「获取模型列表」：从该厂商 /models 类接口实时拉取（本地服务型厂商先走 Ollama 风格 /api/tags，失败自动回退 OpenAI 风格清单）；成功提示「获取到 N 个模型」，失败提示「获取失败：<原因>」——产品不预置名单，接口给什么列什么。
6. 在模型清单里勾选要启用的模型（按「对话 / 视觉 / 向量 / 生图 / 视频生成 / 语音合成 / 语音识别 / 音频理解 / 视频理解」类型分组，组头可整组「全选 / 全不选」、可折叠）；至少勾一个。
7. 点「保存并启用」（已启用厂商为「保存更改」）。保存前会自动用当前协议再验证一次模型列表接口，失败则提示「协议验证失败，未保存：<原因>」，错误协议不会落盘。

## 落点的能力面

- 94 家目录
- 按能力分设默认模型
- Key 不出本机

三条合起来是本地化的骨架：目录广决定可选面，分设默认决定用法灵活度，Key 属地决定信任基础。

## 配置中的常见疑问

### 获取模型列表成功，保存却报「协议验证失败」？

保存动作会用你当前选的协议再探一次接口，两者不一致（比如把 Gemini 原生厂商选成 Chat 协议）就会拦下。按厂商原生协议改回下拉预选项再保存；自定义网关按它实际支持的协议选。

### 模型列表是空的或「未解析到任何模型」？

产品不内置名单，接口给什么显示什么。先确认服务在线、地址端口正确，再点「获取模型列表」重试。

### 我的 Key 会被上传吗？

不会。Key 只存本机 ai-settings.json，请求直发你填的 API 地址；匿名统计只收应用事件，不含文档内容与密钥。介意明文落盘就用第 6 步的 apiKeyEnv 环境变量间接引用。

### 隔离环境里 AI 还能干活吗？

能。内置账号登录当前版本未开放，现阶段走 BYOK 或本地模型；涉密文档不能出网的场合，本地模型让 AI 校对、AI 改写在隔离环境照常工作。

### 协作流程里哪些文档进不了 AI 处理？

加密只读文档仅支持查看；AI 挂了自动降 9 类本地正则兜底，规则处理这条路始终在。

## 一句收束

协作办公本地化的判断就一句话：模型可选、密钥自持、处理留在本地，三条都过线，本地化才算落地；哪条过不了线，先补环境再谈工具。

94 家目录是入口地图，真正影响日常体验的是按能力分设默认模型这一步，配完再谈协作流程。

## 进入模型设置的路径

第 1 步 · 打开「模型设置」

1. 主页左下角账号行上有一个齿轮按钮（悬停提示「设置」），点击打开设置弹窗；左栏共十个分区：模型设置 / 默认模型 / 生图、媒体与搜索 / 本机文件搜索 / 远程存储 / 通用 / 集成 / MCP 管理 / 技能 / 关于，本篇用前三区（AI 按能力各选各的模型，三区各管一段）。
2. 右栏初次进入是说明页：上半「国内常用模型」卡片墙（DeepSeek、智谱、阿里百炼、月之暗面 Kimi 等 11 家）、下半「国外常用模型」（OpenAI、Anthropic、Gemini 等 10 家），已启用的卡片带「已启用」角标；页尾提示更多服务走左侧完整目录。初次进入的这页相当于目录页，常用厂商一眼扫完，冷门的去左侧完整目录里找。
