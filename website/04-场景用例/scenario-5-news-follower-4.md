# AI 资讯跟踪者提效实录路线：AI资讯这样落地

如果你是AI 资讯跟踪者，下面这些场景大概率不陌生：信息源太分散。一个站跟住生态动态。这篇深度复盘以能力广场为工具，把这个岗位的AI资讯工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 信息源太分散
- 重要发布总错过
- 促销活动不知道

## 用能力广场怎么解：工作流拆解

1. 资讯板块每日浏览
2. RSS 订阅活动
3. 榜单追新项目

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「资讯板块每日浏览」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。一个站跟住生态动态。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 资源信息为元数据收录，安装执行依赖原始仓库/官网的可用性
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

与客户端联动：察元AI OS 内置「察元智能广场」应用（离线回落本地页），客户端启动拉取资源清单缓存，搜索与安装走同一 API 并计入下载量。

## 数据安全与隐私边界

- 备案主体：豫ICP备2025150518号-1（北京智灵鸟科技中心）
- MCP 类条目展示 scopes 风险分级（0-3 级），帮助用户识别权限风险
- 网站不存任何二进制文件，安装一律跳转原始地址
- 条目有 health 状态机（active/degraded/dead/archived），失效资源透明标注

## 常见问题
### 免费的模型 API 去哪找？

免费榜（/rank/free）聚合零成本与极低价模型，厂商目录标注免费/免Key额度，配合活动板块蹲促销。

### MCP 配置片段怎么用？

复制条目提供的 MCP JSON 配置，粘贴进你的 MCP 客户端（Claude Code、Cursor、察元AI OS 等）配置文件或设置界面即可接入。

### 支持英文吗？
