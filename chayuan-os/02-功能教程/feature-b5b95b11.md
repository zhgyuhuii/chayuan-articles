# 一文打通知识库驱动的问答台｜知识库问答

导入资料、引用问答、代理共享。这套组合工作流把本地知识库→对话（DeepSeek Harness 会话）→统一模型代理串成一条线，在察元AI OS里一气呵成完成。本文按步骤拆解每个环节的做法与衔接点，并给出适用与不适用边界。

## 这套工作流解决什么

导入资料、引用问答、代理共享。单点工具人人会用，难的是把多个能力串成不返工的流水线：前一步的产出正好是后一步的输入，中间不换软件、不倒格式。察元AI OS的优势正是所有环节都在同一个体系内完成。

## 分步拆解

**第 1 步·本地知识库**：导入 PDF/Word/Excel/HTML/Markdown/TXT/图片 OCR（≤48MB 异步摄取），向量（sqlite-vec）+ 全文（FTS5）+ RRF 融合 + 可选重排 + 邻块扩窗检索；引用式问答带 [1][2] 引用、片段展开与源文件下载。

1. 知识库应用新建库并导入文件
2. 等待异步摄取完成
3. 提问并查看带引用的回答

**第 2 步·对话（DeepSeek Harness 会话）**：「对话」应用是内嵌 dsh 会话运行时的 AI 会话窗口：多会话多开、流式输出、工具调用、本地/云端模型一键切换；⌥Space 全局唤起。

1. 打开对话应用或按 ⌥Space
2. 选择本地或云端模型
3. 发起会话，多窗口并行不同任务

**第 3 步·统一模型代理**：统一代理端口提供 OpenAI 兼容与多协议接口：/v1/chat/completions（流式）、/v1/responses、/v1/messages（Anthropic 协议双向换算）、/v1/embeddings、/v1/rerank、语音识别与 TTS；可签发虚拟 Key。

1. 任意 OpenAI 兼容客户端指向本地代理
2. 按需使用对话/嵌入/重排/语音端点
3. 给外部工具签发虚拟 Key

## 衔接点与易错处

- 嵌入模型切换会触发指纹检测与索引重建
- 可选 Milvus 作为向量库
- 无显式模型偏好时自动指向本地模型，开箱即聊
- Anthropic 协议双向换算意味着 Claude 客户端也能用本地模型

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 常见问题
### 断网能用吗？

能。本地模型对话、知识库、桌面与应用、智能体终端均可离线；仅模型下载、云端模型、应用更新需要网络。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。

### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。
