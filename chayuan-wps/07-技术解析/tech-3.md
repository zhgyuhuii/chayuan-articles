# 三级生图降级链深度解析：机制、设计与取舍

关于三级生图降级链，网上说法很多，有说简单的有说复杂的。实际用下来，察元AI文档助手的三级生图与网络搜图路径是清晰的，只是有些细节不说不知道。这篇按真实操作走一遍，顺带把容易误解的点标出来。

## 是什么与为什么

智能体给文档/PPT 配图时按「三级图源」自动降级：Tier 1 用你在设置里启用的图像生成模型生图（最多逐个尝试 3 个）＞ 不通则 Tier 2 按你配置的「网络资源搜索」清单搜图下载 ＞ 再不通由 Tier 3 对话模型直接绘制 SVG 矢量图形兜底。每一级只做自己份内的事，失败如实上报，绝不静默换一个可能计费的来源。

配图这事儿要稳定：模型挂了搜图顶上，搜图不行矢量兜底，成本不会偷偷变。

按真实界面写，按钮文案原样引用。

## 原理与设计取舍

不静默换花钱来源的降级铁律怎么落地。

配图这事儿要稳定：模型挂了搜图顶上，搜图不行矢量兜底，成本不会偷偷变。

能力面拆开看：铁律不静默换源；免 Key 图源；三级降级。

一个常被问到的问题：为什么我启用了搜图资源，配图时却没用到。常见两个原因：① 修改后没同步——本机服务离线时启用清单没落盘，点「同步本机服务」补同步；② 凭据不齐——启用了需 Key 的资源但没填 Key，链路会跳过它继续下一个，最终落到免 Key 兜底。

从提问口径看，用户最关心的是配图的三级降级是什么？必须都配吗？

## 一步步来：从入口到完成

按最短路径验证一遍：

一、配置 Tier 1：图像生成模型

1. 在哪：设置 ＞ 默认设置，左侧设置项列表选「图像生成模型」（与「对话模型」「视频生成模型」「语音转换模型」并列）。
2. 做什么：添加/启用支持生图的厂商模型（填 API Key、启用开关），可启用多个。
3. 看到什么：运行时链路逐个尝试已启用的生图模型，最多尝试 3 个；某个模型失败会换下一个，全部失败才降级。产物图片经本机服务落盘到 WPS 容器可读的本地路径，插入工具直接可用。
4. 一个模型都没启用时：链路报「未配置图像生成模型（设置 ＞ 默认设置 ＞ 图像生成）」并进入降级。
5. 手动生图入口（点按钮生成文件、不自动插正文）见对应教程；本篇的三级链用于对话配图/生成PPT等自动插图场景。

二、配置 Tier 2：网络资源搜索

1. 在哪：设置 ＞ 默认设置，左侧设置项列表选「网络资源搜索」。页首说明原文：「三级生图的中坚：生图模型不可用时按此清单网络搜图，搜图不通再由大模型绘制 SVG。Key 只保存在本机，搜索经本机服务执行。」
2. 清单分三组共 10 个内置资源，卡片上有「搜图」「需 Key/免 Key」标签：
    1. 网页搜索：Serper（免费额度 2500 次/月）、Tavily、Linkup（仅网页结果，不参与搜图）、SearXNG（自建元搜索，「API Key」输入框位置填的是实例地址，无需 Key）；
    2. 图片图库：Pexels、Pixabay、Unsplash（免费档 50 次/小时）；
    3. 免 Key 兜底：必应图片（国内可达，三级生图默认兜底）、Openverse（CC 授权图库，海外网络）、DuckDuckGo（免 Key 网页搜索）。
    4. 做什么（逐卡操作）：点开关「启用」＞ 展开的凭据框里粘贴 API Key（可点眼睛图标显示/隐藏）＞ 点「申请 Key」可跳转官方申请页 ＞ 点「测试」发一次最小真实请求验证连通。SearXNG 卡片的输入框标签是「实例地址」。
    5. 看到什么：测试通过显示「<延迟>ms」，失败显示「关闭 <原因>」；页首状态条实时显示「已启用 N / 已配 Key N / 免 Key 恒可用 N」与同步状态。
    6. 关键一步——「同步本机服务」：启用清单变更后会自动同步到本机服务（落盘 dataDir/web-resources.json，供 image_search 搜图工具消费）；本机服务离线时状态条显示「本机服务未同步」（设置仍保存在本地），服务恢复后点该按钮手动补同步。
    7. 页首「全部测活」：对已启用与全部免 Key 资源逐个测试，弹toast「测活完成：N/M 连通」。

三、链路怎么跑（无需操作，理解用）

dataDir 位置：Windows 为 %LOCALAPPDATA%\chayuan-wps\mcp，macOS/Linux 为 ~/.config/chayuan-wps/mcp；下载与生图产物在其下 tmp-images/（macOS 优先落 WPS 沙盒容器内对应目录，保证容器内可读）。

1. 对话里提出配图需求（或用 W32 的生成PPT/配图组配方），模型调用生图工具。
2. Tier 1 模型生图：按「图像生成模型」启用的模型逐个试（≤3 个）；未走通时任务进度提示「模型生图未走通，尝试本机生图服务」，回落到本机服务的原生生图通道（配置文件 dataDir/image-gen.json，未配置时报「未配置生图模型（dataDir/image-gen.json），请改用 svg_add 矢量图形兜底」）。
3. Tier 2 网络搜图：生图两级都不通，模型改调搜图工具——你在「网络资源搜索」启用的资源按清单顺序先试（要求已配好凭据），全不行再落内置免 Key 兜底（必应图片 ＞ Openverse，无需启用恒可用）；搜到候选后逐张尝试下载（校验图片内容防止死链），成功返回本地路径交给插入工具。
4. Tier 3 SVG 兜底：搜图也不通时，对话模型直接生成 SVG 矢量图形源码，用演示/文档工具的 svg_add 画到页面（纯本地生成，不依赖图片模型与图库网络）。
5. 铁律「绝不静默替位」：每一级失败都返回明确的 ok:false 与原因，由调用方决定降级，不会静默换一个可能计费的来源；每级用了哪个来源会在结果里注明（source/origin）。

## 别在这几处栽跟头

用之前要认的账：

- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道
- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度

## 你可能会问

### 必须三级都配置吗？

不是。三级是「能配则配、按序降级」：只配 Tier 1 也能生图（生图全挂才需要 Tier 2）；完全什么都不配时，免 Key 搜图兜底（必应/Openverse）和 Tier 3 SVG 仍然可用——只是效果上限低一些。

### 为什么我启用了搜图资源，配图时却没用到？

常见两个原因：① 修改后没同步——本机服务离线时启用清单没落盘，点「同步本机服务」补同步；② 凭据不齐——启用了需 Key 的资源但没填 Key，链路会跳过它继续下一个，最终落到免 Key 兜底。

### API Key 会泄露吗？

Key 只保存在本机（加载项本地设置），搜图请求由本机 MCP 服务直接发往各资源官方接口，不经第三方服务器转发；同步到本机服务的配置文件也只落在本机 dataDir。

### Serper 免费额度用完会怎样？

该资源请求失败并记录原因，链路按清单顺序换下一个启用资源，或落到免 Key 兜底——不会卡死也不会静默产生费用（每来源只做自己份内的事，失败如实上报）。额度以 Serper 官方口径为准（清单标注免费额度 2500 次/月）。

三级生图降级链的能力边界也写清楚了：能做什么、不擅长什么。工具好不好用，很大程度上取决于你知不知道它的边界。
