## 先弄清楚它是什么

开源榜单实操能做的事拆开就这几件：降级透明标注，热门/新品/趋势三维度；star 增量优先；六档周期榜单。对应的界面入口是开源榜单机制

先把定位立住，再看步骤。

## 开源榜单机制：从入口到完成

用榜单找资源

1. 进榜单页选周期（日/周/月）
2. 按板块切到 MCP 或插件等类目
3. 点开感兴趣的资源看详情
4. 结合下载量判断活跃度

三个维度怎么选

1. 找经过验证的稳定项目看「热门」
2. 找新出的潜力项目看「新品」
3. 找近期涨势猛的看「趋势」
4. 增量数据积累中的板块会标注按星标总量排序，看到标注就换长周期档

## 接着回答几个常见问题

### 榜单多久更新一次？

每日同步任务先抓取各条目的 star 数写入快照，再重算日、周、月、季、半年、年六档榜单。

### 为什么有的资源榜上找不到？

两种情况：资源被标记为 dead 或 archived，会被自动剔除出榜；或者周期起点早于最早快照日，该周期降级为星标总量榜并明确标注。

### 榜单排名能花钱买吗？

不能。榜单按 star 增量与本站下载量计算，无付费干预位。
