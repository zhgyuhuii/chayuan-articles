# 表格AI助手实操上手指南：照着做十分钟跑通

用察元AI文档助手有段时间了，表格助手是我用得比较多的一个功能。这篇把我积累的操作顺序和几个关键细节写出来，新手可以照着走，老手可以查漏。

## 这个功能到底解决什么问题

WPS 表格端的「察元AI助理」选项卡把高频表格配方做成 Ribbon 一键钮：点一下自动打开 AI 助手面板并把配方提示词填进输入框（一键型配方还会自动发送），智能体按配方用表格工具读写当前工作簿；全部 66 个表格配方（通用高频 + 行业包）在助手面板侧栏可查可搜。

不会写公式就按公式助手，不会分析就按数据洞察，表格工作的台阶被垫平。

按真实界面写，按钮文案原样引用。

## 前置条件

- 已在 WPS 表格中启用加载项，Ribbon 出现「察元AI助理」选项卡；
- 已配置可用对话模型：配方由对话模型编排表格工具执行，未配置模型无法执行；
- 「AI表格助手」面板按上次形态打开（浮窗或停靠），面板打不开时的提示与排查见常见问题 Q1。

## 实操全过程

入口都在表格端 Ribbon「察元AI助理」选项卡 ＞「AI助手」组（组内布局为：大按钮一排 ＞「文档安全」▾ ＞「更多表格助手」▾ ＞「设置」）。

1. 「AI表格助手」：单开对话面板

1. 点「AI表格助手」：打开 AI 助手对话面板。面板只有一个实例——已开着时再点只会把它聚焦到前台，不会重复开窗；按上次记忆的形态打开（浮窗或左/右/底停靠）。已开但失焦的窗口不会被销毁，里面执行中的任务不丢。

2. 一键直达钮：公式助手 / 数据洞察 / 一键图表 / 数据清洗 / 报表结论 / 一键美化

1. 每个按钮对应一条固定配方，点击后面板自动打开（或聚焦）并拾取配方提示词：
    1. 立即执行型（点完即自动发送，无需补充）：「数据洞察」（只读分析概况/趋势/异常/TOP5）、「数据清洗」（先出问题清单，等你回复"确认清理"才动手）、「报表结论」（300 字内结论报告，不改表）、「一键美化」（表头深底白字/边框/对齐，不动数值）；
    2. 预填补充型（提示词进输入框，光标停在末尾等你补充）：「公式助手」（末尾填你的需求，配方要求优先用 SUM/SUMIF/VLOOKUP 等标准函数，数字由表格自己算、可复核）、「一键图表」（末尾填补充要求，模型自动推荐图型）。
    3. 提示词拾取机制：点击按钮 ＞ 配方写入加载项存储（ai_chat_prefill_prompt）＞ 面板轮询在约 1.5 秒内拾取；面板已开也一样生效。若面板正在执行回合，本次点击不会打断任务，等回合结束后再点一次即可。

3. 「文档安全」▾：保密检查 / 加密工作簿 / 解密工作簿

1. 「保密检查」：立即执行型，自动发送只读扫描指令——识别手机号/身份证号/银行卡号/邮箱/工资薪酬列等敏感数据，输出「位置+类型+样例脱敏展示（如 1381234）」的问题清单，不改任何单元格；保密检查能力全貌见对应教程。
2. 「加密工作簿」：预填型。发送后智能体会先在对话里向你询问密码，拿到密码才调用表格工具 security_encrypt_save 完成加密并报告保存路径（可选另存副本）。密码遗忘无法找回。
3. 「解密工作簿」：预填型。智能体先提醒你备份，确认后用 security_decrypt_save 移除打开密码并报告保存路径。

4. 「更多表格助手」▾：高频带参配方

1. 菜单项：排序汇总 / 多表合并汇总 / 两表对比差异 / 表格翻译 / 敏感信息脱敏 / 智能分列 / 按列拆表 / 文档抽取成表 / 数据战报页，均为预填型——点击后面板打开，提示词已带好操作套路（如多表合并会自动先列工作表、合并后加「来源表」列），你只需在末尾补充「合并范围与补充规则」「拆分依据列」等具体信息再发送；
2. 其中「文档抽取成表」从 Word 文档抽字段生成台账表、「数据战报页」把表格核心数字写成演示稿战报页，属跨宿主配方（需要对应宿主有打开的文件）；
3. 菜单最底部与组分隔线后各有一个「设置」，都打开与文字端同一个设置窗口。

5. 「模板新建」大按钮

1. 打开「从模板新建」对话框，按当前宿主列出已登记模板供新建表格。

6. 助手面板侧栏：66 个表格配方全集

1. 在哪：AI 助手面板左侧栏「助手」页签。表格宿主只显示表格配方，与 Ribbon 的关系是「Ribbon=高频直达，面板=全集」；
2. 看到什么：配方按分组折叠陈列（通用高频、财务、电商运营、HR、销售、教育、跨宿主、医疗健康、制造仓储、政务事业、门店零售、个人生活），组名右侧有数量角标；每条含图标、名称、「内置/自定义」标记、一句说明；
3. 每条右侧三个动作：收藏（星标置顶）、「执行助手」（，行为同 Ribbon：立即执行型直接发送、预填型等补充）、「使用说明」（?，弹出分步说明书——表格端未逐条编制的配方会按执行方式自动生成通用步骤，保证条条有说明）；
4. 面板另有配方之外的「表格创建」「导出转换」「公式解释」「异常标色」「数据日报生成」等，只在侧栏可见；
5. 配方的启用停用与编辑（名称/说明/提示词/触发方式）在 设置 ＞ 助手设置，见对应教程。

## 怎么确认做成了

验证

1. 点「数据洞察」：AI 助手面板弹出，配方提示词自动发送（无需手动点发送），随后对话里出现只读分析结论；
2. 点「公式助手」：面板弹出，输入框已有公式配方提示词且光标停在末尾，补一句需求再发送；
3. 点「加密工作簿」并发送：智能体先在对话里问你要密码，而不是自编密码；加密完成后报告保存路径；
4. 点「设置」：弹出设置窗口，与文字端「设置」是同一个。

## 适用场景

行业固定的重复劳动：费用归类、流水对账、多表合并、两表比差异、按列拆表、文档抽取成台账等；公式不会写问助手；想让 AI 直接帮你在表格里算数：生成公式、做数据洞察、出图表、清洗脏数据、写报表结论；表格外发前要做保密检查，或要给整个工作簿加/去打开密码。

用户常搜的问法：表格 Ribbon 上那一排 AI 按钮都是干什么的；点『数据洞察』之后发生了什么？为什么有的按钮直接就发出去了。

## 注意事项与真实边界

如实说明，它不是万能的：

- 付费四项（脱密、复原、保密检查、涉密关键词提取）没有免费额度
- 脱密占位替换是可逆设计，忘记密码没有任何免密恢复通道

## 常见问题

### 为什么有的按钮点了就自动发送，有的要我再补内容？

设计如此：结论明确、无需补充的配方（数据洞察/数据清洗/报表结论/一键美化/保密检查）点了直接发送；需要你给参数的（公式助手/一键图表/加密工作簿/「更多表格助手」全部）只预填提示词，光标停在末尾等你补充。

### AI 助手面板每次打开的位置/大小都不一样吗？

面板按上次形态记忆（浮窗或停靠及位置），想固定摆放见对应教程；任务执行中窗口位置切换会置灰。

### 点了「数据洞察」没反应？

三种常见原因：① 面板正在执行上一回合——一键指令不会打断执行中的任务，等回合结束再点；② 面板打开失败——会弹「AI 助手面板打开失败（原因）」提示，按原因排查（多为当前 WPS 宿主不支持助手窗口 API，需升级 WPS）；③ 模型未配置——先完成对应教程。

### 侧栏里的配方能不能改提示词或停用？

能。设置 ＞ 助手设置 里对每条配方编辑名称/说明/提示词/触发方式/启用停用，改动同时作用于面板展示与点击执行；停用后面板不再显示该条。

如果只记一件事：九大按钮直达。剩下的细节照步骤节走就行。
