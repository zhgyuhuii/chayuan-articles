# 搜索API配置排错：五家搜索源可配

「怎么给智能体开联网搜索？搜索 API Key 填在哪里」——这个问题最近被问了好几次。答案不复杂：搜索API配置在察元AI OS里是现成能力，这篇把入口、步骤、验证一次写全，按钮文案原样引用。

## 先定位问题在哪一层

按这个顺序排查搜索API配置通常最快：先确认前置条件（需要 Key 的平台先去对应官网注册并拿到 Key（每张平台卡上有「申请 Key」按钮直达官网）。），再核对操作路径，最后看边界限制。

## 正确的操作路径

6. 添加/删除自定义平台

1. 「自定义平台」组头右侧「+ 自定义平台」展开内联表单：「平台名称（如 必应）」（必填）、「端点/备注（可选，写入技能）」、「需要 Key」勾选框（默认勾选）＞「取消」/「添加」（名称为空时「添加」置灰）。新卡片带蓝色「自定义」小标；
2. 自定义平台同样可填 Key、可开关；卡片右上「关闭」删除（悬停提示「删除」）。

7. 配好的 Key 如何被用起来（不需要你操作，了解即可）

1. 网页检索降级链（智能体 web_search 工具与群聊 同一执行器）：默认 DeepSeek 搜索，不可用逐档降级 serper ＞ tavily ＞ linkup ＞ searxng ＞ duckduckgo，每档只在「Key 已配或免 Key」时尝试、单档 8 秒超时，直到有一档返回结果；
2. 图片搜索/图库素材：平台与 Key 随 models.md 写入智能体技能手册，智能体按手册直接调用对应平台。

## 进阶用法与边界

- 五家搜索源可配
- 图片搜索与图库平台支持
- 默认内置 web_search 工具多档兜底
- 边界：需要相应平台的 Key（部分有免费额度）
- 边界：断网时联网搜索自然不可用

## 接着回答几个常见问题

### 关掉某平台开关有什么影响？

该平台不写进 models.md；「网络检索」组的平台同时从降级链里消失（该档直接跳过）。开关只影响「允许智能体使用」，已存的 Key 仍保留在凭证库里，重新勾选即可恢复。

### 保存时报「模型代理未运行，无法接入云端厂商」？

本页保存时会顺带处理模型分类里选了云端厂商的路由。到 设置 ＞ 模型 查看本地模型服务健康灯、恢复模型代理（127.0.0.1:52581）后再回来点「保存并更新技能」。

### 能加清单之外的平台吗？

能。「+ 自定义平台」填平台名与端点备注，勾「需要 Key」的话同样有 Key 输入框；保存后与内置平台一并写入 models.md 供智能体调用。

## 动手前再核对一遍

- 需要 Key 的平台先去对应官网注册并拿到 Key（每张平台卡上有「申请 Key」按钮直达官网）。
- 不配 Key 也能搜：系统的联网检索默认走「DeepSeek 搜索」（官方目前免费），不可用时逐平台降级，最终落到完全免 Key 的 DuckDuckGo 兜底；图片搜索组（Bing Images / Baidu Images / Openverse）也全部免 Key。参见下文「常见问题 Q1」。
- Key 保存在本机 harness 凭证库（~/.dsh/.credentials.yaml，引用名 CHATOP_SEARCH_<平台>_KEY），与模型厂商密钥同库。

安全口径单独立一层：本机 Stable Diffusion 链路出图不联网，隐私与免费兼得，一台设备多人用，数据隔离是底线，管理员统一管账号比各自为战安全；隐私敏感环境先关遥测再干活，处置设备前清数据，（本机 MCP HTTP 服务，回环免 token）。

## 平台与形态

平台与形态的账：命令行 AI 编程智能体一茬茬冒，一台机器管十几家、配置互不打架，是这套系统的核心场景之一；各家配置文件面文档化；MCP 是智能体的手，一处配置全家生效，改之前能验证连接省得排错；自动投影进配置文件。

## 价格与授权

价格口径一并交代：跨终端互联（DDS）出厂零共享，开哪类授权完全由用户决定；需要相应平台的 Key（部分有免费额度），形象可从灵宠商店免费获取，也可工坊自定义；内置场景免费切换。

## 产品家族与搭配

察元AI OS不是单打独斗：单一搜索源挂了就变瞎，五档兜底保证能查到东西；默认 DeepSeek 搜索；API Key 用 safeStorage 加密存储，遥测可整体停用，云端厂商模型调用需自备 API Key。

## 几条硬数字

能落到数字上的几条：:52581（OpenAI 兼容统一模型代理），（知识库对外服务，固定端口），（web/Docker 形态网页桌面默认端口）；GB 内存设备建议一次只加载一个对话模型，复杂任务受限。

## 离线与内网

离线内网这条线的口径：本地转写不上传录音，会议速记两件事一次做完；本地音乐（用户音乐目录）与音视频播放，与配对终端发消息附件、让对方智能体执行任务、离线暂存送达、武力值徽标（信号格加等效算力）；离线消息暂存后送达。
