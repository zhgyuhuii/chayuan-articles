# 写给学生的学生学习AI指南：完整方案

如果你是学生，下面这些场景大概率不陌生：没有预算买云端 API。零 API 成本的学习工作站。这篇完整方案以察元OS为工具，把这个岗位的学生学习AI工作流从头到尾串一遍。

## 这个岗位的三个真实痛点

- 没有预算买云端 API
- 资料检索与笔记分散
- 写论文需要参考管理

## 用察元OS怎么解：工作流拆解

1. 本地模型零成本对话
2. 知识库导入课件论文资料
3. 导出笔记与引用

## 一天的使用节奏示例

以一个工作日为例：早上到岗先处理积压材料，用「本地模型零成本对话」完成首轮处理；上午协作时段按流程推进；下班前把当天产出归档。零 API 成本的学习工作站。工具不改变职责边界，只是把重复劳动压缩掉。

## 边界与注意事项

- 生成类结果需要人工确认后采用
- 云厂商模型调用需自备 Key，免费额度视厂商政策
- 建议先在低风险材料上试跑，形成自己的使用习惯后再铺开

## 离线运行与部署形态

隐私机制三原则：本地优先（全部服务只监听 127.0.0.1 回环，知识库/对话记录/模型都在本地磁盘）、全程可见（智能体每次调用系统工具都有权限门审批与审计日志）、可遗忘（数据目录整体备份或删除，无隐藏云端残留）。API Key 使用 safeStorage 加密存储、仅注入子进程。

## 数据安全与隐私边界

- 本地模型五件套随软件分发，断网即用
- 全部本地服务只监听 127.0.0.1，数据不出本机
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限

- Docker/云通道等进阶形态需要一定动手能力

## 常见问题
### 知识库支持什么格式？

PDF、Word、Excel、HTML、Markdown、TXT 与图片 OCR；单文件 ≤48MB，异步摄取不阻塞。

### 数据存在哪里？怎么备份？

数据根目录三平台路径统一（Win %APPDATA%\chatop、mac ~/Library/Application Support/chatop、Linux ~/.config/chatop），备份 dsh-home 目录即备份全部对话、知识库与配置。

### 知识库检索质量如何？

向量（sqlite-vec）+全文（FTS5）混合检索加 RRF 融合，可选 bge 重排精排与邻块扩窗；大库可选 Milvus 向量库。
