# 察元OSwebwindows 智能体开窗使用指南（智能体窗口）

智能体窗口是察元AI OS里使用频率很高的一项能力。它的「webwindows 智能体开窗」这样工作：智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

智能体可打开真实 Electron 原生窗、加载网页/HTML、执行 JS、截图、点击穿透、置顶与透明度调节——AI 的「眼睛和手」延伸到图形界面。

从任务视角看，它对应的关键词是「智能体窗口」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

1. 在智能体会话中要求打开某网页
2. 智能体截图理解页面
3. 按需执行 JS 或调整窗口属性

- 自动化网页操作

## 离线运行与部署形态

完全断网可用是察元AI OS 的基础设计：本地模型对话（llama.cpp 引擎随软件分发，无需 Python/CUDA）、知识库导入/检索/问答、桌面与文件/终端/编辑器等系统应用、四家智能体终端与管理，全部离线工作；仅模型下载、云端模型调用、应用更新需要联网。装机自带五件套模型：Qwen3-4B（对话）、bge-m3（嵌入）、bge-reranker-v2-m3（重排）、whisper-small-int8（语音识别）、piper 中文语音合成。

## 数据安全与隐私边界

- API Key safeStorage 加密存储，仅注入子进程
- 本地模型五件套随软件分发，断网即用
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）
- 全部敏感操作写审计日志 audit.jsonl，可回放检查

## 常见问题
### 察元AI OS 是什么？

一个插件化的 AI 桌面操作系统体验：macOS 风格桌面为壳，整合 AI 对话、四家 CLI 智能体、本地大模型服务、本地知识库与系统级 MCP 控制面，断网可用、数据不出本机。

### 智能体操作电脑安全吗？

有三级权限门：T0 直接放行、T1 每次运行询问（可记住）、T2 每次必问（截图/关机等）；审批超时视为拒绝，全部操作写审计日志。

### 应用商店卖什么？

插件与技能为主（规划含 MCP/提示词/智能体/技能包五类），默认源为 aidooo.com；免费直下、付费内嵌收银台，支持断点续传与 sha256 校验。
