# 会议全程记录：语音输入概念与上手

语音输入被提得多了，可它到底是输入法的一个模式，还是系统级能力，边界常被说糊。这篇以察元AI OS为例，按官方口径给定义、给数字、给边界。

## 什么是语音输入

语音输入不是孤立的一个按钮，而是有入口、有步骤、也有边界的一整面能力：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊同处一个桌面。

本文涉及的数量与版本口径皆以官方文档为准据，文末尾注写明截止时间。

## 在察元AI OS里落在哪

语音输入在察元AI OS里的落点是录屏与语音记录：右键桌面录制屏幕；语音记录集录音、转写、保存位置设置于一体，话音落下字就跟着出来。

值得专门一提的地方：转写不出机器，录音与纪要一次收齐。

## 最短上手路径

六步路径排开如下：

1. 桌面级录屏
2. VAD 切分逐段转写
3. 保存位置可设
4. 场景验证：会议全程记录
5. 场景验证：口述灵感收集
6. 串联场景：全量离线包由官方渠道获取（含五件套权重，约 4.7GB）

## 落点的能力面

- 桌面级录屏
- VAD 切分逐段转写
- 保存位置可设

这三项能力的组合逻辑是：录屏负责画面留档，转写负责把声音变成可检索的文字，保存位置决定产物去哪；对做会议纪要的人来说，等于一条流水线。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签承载自动生成的文档与实体二部图
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 配置智能体：自动那条路把代理地址加模型一次写入五家，带备份与回退
- 录屏与语音记录：右键桌面即能录制屏幕；语音记录把录音、转写、保存位置设置装进同一根贴顶长条，字随话出。

## 四类人建议先等等

- 8GB 内存的设备，同时加载一个对话模型就是上限，复杂任务会受限
- 龙芯适配还没到位；视频生成不在本地提供，路由到云端
- 调云端厂商模型的 Key 由你自己准备
- Docker 云桌面、跨终端互联考验动手能力，零基础勿入

先等等不等于不用；等需求清晰、机器升级后再来，这些边界自然就不扎眼了。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 输入相关的三个疑问

### 语音记录存哪由什么决定？

设置小窗「保存位置」：选「当前文件夹」时存到录音开始那一刻最近打开的文件夹（如我的电脑正浏览的目录），取不到回落桌面 Recordings；选「桌面 Recordings」则固定存 Recordings 目录。录屏不受此设置影响，永远存 Desktop/Recordings。

### 语音输入离线时哪些功能受影响

离线照样能跑的有：本机 Stable Diffusion 链路出图不联网，隐私与免费兼得；常驻任务的设置——写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关——都在本机完成。联网才有意义的是：内置 web_search 工具默认走 DeepSeek 搜索。

### 输入框旁边能配什么

知识库绑定与模型选择（含智能路由自动选模型）就在输入框旁；要新库也简单，知识库应用左栏输入库名即建，每库独立存储，系统缺省带一个 default 库。

## 怎么下结论

语音输入的价值要放在输入场景里衡量：打字慢、口述快的人获益最大；文本精度要求高的场景，转写稿仍需要一道人工校对——但校的是现成稿子，不是从零起草，工作量差着一个量级。

## 桌面之外的几层盘面

本机轻薄、远端肥厚时，桌面只当壳；它能把应用造出来挂上桌面——桌面本身能被 AI 定义，能力边界从预装走向按需生成；搜索这件事同样不绑死在某一家平台上。这几层加起来，才凑成「输入只是入口、桌面才是容器」的完整图景。

## 数据与隐私的开关

遥测可整体关闭，清除桌面数据属破坏性操作、有警示；升级不丢数据是底线，检查更新静默失败不影响使用；账户隔离，数据在服务器侧统一管理。

## Dock 与桌面设置

设置里可调桌面与 Dock 的位置、自动隐藏、图标放大与大小，还能设开机自动打开 Harness。Dock 是使用频率最高的区域，从这里直开内置的察元AI Office，文档、表格、演示在线编辑，每次产出的 markdown 报告落盘归档。Ctrl 或 Cmd 加 K 则唤起聚焦搜索，搜应用、文件、内容，加问 AI 知识库直答，支持语音输入。

## 引用排障一条

Office 或 WPS 引用不到知识库，九成是服务没起或端口被占，三层检查定位到具体一层。

## 模型配置的进阶玩法

local 星号开头的本地模型未运行会自动加载；让全机所有 AI 软件共用一套模型配置的关键设计是：地址只有一个，模型随便换，客户端无感。进阶面板支持被代理模型树形多选、厂商路由加入移出、虚拟 Key 签发吊销、调用审计查询——给外部工具开权限又不想交出真实厂商 Key，虚拟 Key 加审计是标准答案。

录屏与语音记录的入口都在桌面右键那一层，找到就能用；文中界面名称均按版本原文记录。
