# 位后缀链接：访问链接完整走法

先说这篇能帮你干什么：读完能在察元AI OS里独立完成访问链接，路径是给同事发临时访问链接。步骤里的每个「」按钮都是界面原文。

## 一句话说清定位

访问链接是察元AI OS（aidooo.com）里的一个能力模块：AI 桌面操作系统，本地大模型、知识库、智能体、宠物群聊装进一个桌面，web 与 docker 访问链接是其中面向这类需求的一环。

概念一分钟，操作十分钟，这篇都覆盖。

## 前置条件

- 仅 web/docker 部署形态有本篇功能。桌面形态（察元AI OS）的账号由桌面自管，其 设置 ＞ 用户 底部的「远程访问」卡给出的是令牌制 /a/ 链接，没有 9 位后缀。
- 管理面只能在本机（服务器）上操作：web 桌面从部署机本机浏览器打开（dsh web 主端口 52584，docker 镜像的发布端口同为 52584），用户与访问链接管理接口仅接受环回请求；远程侧只出登录页。
- 云端在线：9 位后缀由云端路由服务按「设备+用户」签发，需要部署机能访问默认云基址 https://aidooo.com:8443；连不上时设置页会提示「无法连接云端服务，外网链接与分享链接暂不可用」。
- 「外网连接」开关已开启（默认关闭）：不开就没有可用的外网链接。
- 首次使用需先初始化管理员（见第 1 步）。

## 实操全过程

第 1 步 · 初始化管理员（首次，仅一次）

1. 在部署机本机浏览器打开 web 桌面（http://127.0.0.1:52584），进 设置 ＞ 用户。
2. 首次使用时顶部出现橙色「初始化管理员」卡，说明原文：「首次使用请设置本终端的管理员账户与密码（仅本机操作；此后可创建普通用户并生成各自的外网访问链接）。」
3. 填「管理员用户名（字母/数字）」（1-32 位，限字母/数字/-/_）、「密码（至少 3 位）」、「再次输入密码」，点「完成初始化」。成功显示「初始化完成，请刷新或重新打开设置」。错误分支：「密码至少 3 位」「两次输入的密码不一致」「用户名已存在」「初始化失败，请重试」。已初始化后这张卡不再出现。

第 2 步 · 建用户、拿访问链接（用户与访问链接卡）

1. 卡片说明原文：「创建用户自动生成密码与 9 位字母外网后缀（需云端在线）；停用后链接立即失效，重新启用换新后缀。」
2. 在「新用户名（字母/数字）」框输入名字（同样限 1-32 位字母/数字/-/_）点「创建」。创建成功出现绿色提示条「已创建 {用户名}，初始密码：」＋一串 8 位随机密码——只显示这一次，旁边有「复制」按钮，抄给该用户。
3. 用户行内显示其 9 位小写字母后缀（/xxxxxxxxx，云端签发回填后出现；悬停提示「9 位字母外网后缀」）和「链接」按钮——点击复制完整访问链接，形如 https://aidooo.com:8443/a/<后缀>?u=<用户名>。
4. 失败分支：「用户名已存在」/「创建失败」。

第 3 步 · 用链接进入远程桌面

1. 在任意设备的浏览器打开访问链接，出现远程登录页「察元 · 远程桌面」（提示「输入本机用户名与密码进入桌面」）：填该用户的用户名和密码，点「登录 / Sign in」。
2. 登录成功即进入该用户自己的独立桌面：首次登录系统自动为其拉起一个独立的 dsh 实例（端口在多用户会话段 52601 起顺序分配，各用户的存储/房间/技能完全隔离），此后该实例常驻（异常退出自动重启）。
3. 登录态由 wa_sess 会话 cookie 保持，30 天内免重复登录；登录接口有防爆破限速（每 IP 每分钟 10 次）。链接与账户绑定：/a/ 链接的持有者不能借别人的账户进桌面（后缀/令牌归属校验）。

## 做完后的验证

验证

1. 部署机本机执行 curl http://127.0.0.1:52584/__wa/state，应返回 {"ok":true,"mode":"users","enabled":true,...}（enabled 反映「外网连接」开关）。
2. 用另一台设备/手机打开某用户的访问链接：应出现「察元 · 远程桌面」登录页；输错密码被拒，输对该用户密码进入其桌面。
3. 停用该用户后立刻刷新该链接：链接已失效（后缀吊销）；「启用」后用户行显示的是新后缀。
4. 在「在线桌面会话」区对一个在线用户点「踢下线」：其远程页面断开，几秒后该行从会话列表消失。

## 什么情况下用得上

管理员要给新同事开账号、停用离职账号、把还在线的会话踢下线；在服务器/Docker 容器里部署了察元（web 形态），多人要从各自的浏览器远程使用，每人一个独立桌面，给同事发临时访问链接；清理僵尸会话。

用户常搜的问法：docker 版怎么多人用？每人一个链接是怎么发的；我的访问链接打不开，提示连不上云端怎么办。

## 边界先摆桌面上

用之前要认的账：

- 云端厂商模型调用需自备 API Key
- 8GB 内存设备建议一次只加载一个对话模型，复杂任务受限
- Docker 云桌面、跨终端互联这类进阶形态需要一点动手能力
- 暂不支持龙芯平台；本地不提供视频生成（视频生成走云端路由）

## 接着回答几个常见问题

### 用户行没有「链接」按钮 / 我的访问链接不显示？

链接依赖两个条件：该用户的 9 位后缀已由云端签发（需部署机能连 https://aidooo.com:8443），且云端探测通过。看到橙色「无法连接云端服务，外网链接与分享链接暂不可用」就是探测未过——检查部署机出网，面板每 10 秒自动重试，恢复后链接自动回来；同时确认「外网连接」开关已开启。

### 9 位后缀是什么规则？会变吗？

9 位小写字母，由云端路由服务按「设备+用户」签发、回填到本机账户文件里保存，正常使用期间沿用同一个后缀。会换的情况：停用后再启用（停用时旧后缀已吊销、启用换发新的）；删除用户（后缀随账号作废）。

### 停用和删除有什么区别？

停用可逆：吊销链接、关停进程，数据不动，启用后换新后缀恢复。删除不可逆：账号移除、链接作废、进程关闭，但数据目录保留——彻底清理需另行删除其用户目录。

### 重置密码后，该用户已登录的浏览器会怎样？

立即失效（改密使会话版本号 +1，其所有 wa_sess 会话作废），需用一次性显示的新密码重新登录。新密码只在提示条里显示一次，关掉就再也看不到，丢了就再点一次「重置密码」。

### 密码忘了能像桌面版那样用恢复密钥/智能体面试找回吗？

不能。恢复密钥与验证画像找回体系仅桌面形态。web/docker 形态找管理员：在 设置 ＞ 用户 点该用户的「重置密码」生成新密码即可。
