# 内网机器补齐模型能力：大模型本地部署概念与上手

关于大模型本地部署，最能过滤噪音的一个问题是：断网了它还能干什么。这篇从这个标准出发，把察元AI OS的能力面与边界一次说清。

## 什么是大模型本地部署

把大模型本地部署拆开看，指的是不依赖云端服务、把模型放在自己机器上跑这件事。在这件事上，察元AI OS（Chayuan AI OS，简称察元OS）是一款 AI 桌面操作系统，以完整桌面环境为壳，内置本地大模型五件套、引用式知识库、17 家外部 CLI 智能体管理、宠物群聊多模型讨论与系统级 MCP 控制面，支持 Windows/macOS/Linux（银河麒麟、统信 UOS）及 Docker 云桌面形态，断网可用、数据不出本机。

文中数字与功能口径整理时对过官方文档，版本对应关系见文末。

## 平台与形态

能跑在哪：Windows 10/11（x64/arm64）、macOS（Apple Silicon/Intel）、Linux（deb/AppImage，银河麒麟 V10 与统信 UOS 已实测）、Docker 服务器形态。

## 在察元AI OS里落在哪

大模型本地部署在察元AI OS里的落点是下载本地模型：模型库按本机内存预算分层推荐（能跑/勉强/跑不动三档标记），支持断点续传，下载源自动在 ModelScope、hf-mirror、HuggingFace 之间换。

为什么值得单独说：断网环境、涉密内网、不想花钱调 API，这三类需求都指向同一件事：把模型放在自己机器上跑。自己跑模型，硬件预算得自己出，换到的是数据留在本机、断网也能接着用。

## 装之前先掂量这几条

- 内存 8GB 的设备，同时只加载一个对话模型更稳妥，复杂任务会受限
- 龙芯平台暂时不在支持列表里；视频生成不在本地做，走的是云端路由
- 要调云端厂商的模型，API Key 得自己准备
- Docker 云桌面、跨终端互联这些进阶形态，对动手能力有要求

边界归边界，主线功能不受影响；只是选型之前心里有数更踏实。

## 数据与安全设计

- 敏感操作全部写审计日志 audit.jsonl，可回放检查
- API Key 用 safeStorage 加密存储，遥测可整体停用

## 下载与运行的高频疑问

### 完全断网 / 所有源都下载失败怎么办？

断点已保留，联网后点「继续下载」从断点续传。彻底离线的机器：在任意联网电脑按帮助中心「离线下载与导入」的直链下载权重文件（U 盘/内网搬运）放到本机，再用「我的模型 ＞ ＋ 添加模型」按路径导入（不复制文件、原路径引用）。

### 带关闭徽标的模型还让下载吗？

能——徽标含义明示「仍可下载，加载时会被守卫拦截」。点「启动」时会被内存预算预检拦下，并提示需要多少内存、建议先卸载谁。内存不够就换小参数量模型，或先「停用」部分运行中的模型。

### 模型跑一会儿自己停了？

默认「15 分钟无人使用自动卸载」在释放内存，不是故障。常用对话/嵌入模型点行内「钉住」豁免自动卸载；时限在状态条下拉可调（自动卸载：关 / 5 / 15 / 30 / 60 分钟）。

### 模型加载失败或提示内存不足？

系统有内存预算硬底线（总内存的 45%）保护：先卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。

### 检查更新失败？

更新检查依赖联网的官方接口；断网时静默失败、不影响使用，也可以手动拿新版安装包覆盖安装，数据目录会保留。

## 本地模型页的内部结构

1. 进入本地模型页

打开 设置 ＞ 模型，左栏「本地模型」组（默认展开）列出十一类导航：对话 / 嵌入 / 重排序 / 决策 / 代码补全 / 图像理解 / 视频解析 / 生图 / 视频生成 / 语音识别 / 语音合成。进页默认选中「对话」。右栏页面自上而下：状态条 ＞ 服务地址条 ＞ 「模型全机只保留一份」提示 ＞ 「我的模型」（已安装）＞ 「模型库」（未下载）。同一模型只会出现在其中一个分类页。
