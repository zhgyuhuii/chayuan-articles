# PDF编辑实操教程：从入口到完成每一步都有反馈

如果你正在琢磨PDF编辑，大概率是被这些问题卡住的：入口在哪、要点哪些按钮、做完怎么确认。我第一次用察元AI Office的PDF 真文本编辑与涂黑时也绕了点弯路，这篇把正确顺序整理出来，照做十分钟内能跑通。

## 这个功能到底解决什么问题

「编辑」页签让 PDF 像文档一样改字：点页面上的文字直接改——改的是 PDF 里真实的文字对象（PDFium 引擎重写页面内容流），不是盖一层白底注释，改完仍可搜索、可复制；「涂黑」则把指定区域的内容从文件里物理删除并生成新副本，原文档不动，用于发出去之前抹掉敏感信息。

多数 PDF 编辑器的改字是贴白块盖图，真文本编辑改的是内容流本身，复制出来也是新文字。

入口、步骤、验证三段看清，这事就顺了。

## 开工前检查这几样

- 加密只读文档（「加密文档仅支持查看」）不可用本篇全部功能；普通文档无需任何配置，全部本机完成。
- 与「对 AI 隐藏」是两回事：PDF 编辑器没有「对 AI 隐藏」；本篇「涂黑」是把内容从文件里删掉，防的是所有拿到文件的人。

## 一步步来：从入口到完成

第 1 步 · 编辑页面上的文字（「编辑」页签 「编辑文字」）

1. 切到「编辑」页签，点「编辑文字」（提示「点击页面文字直接修改」），进入编辑模式。
2. 点击页面上的任意一段文字：原位出现编辑框，文字已预选中，直接输入替换。编辑框上方是样式条：
    1. 「字体」下拉：「原字体」（默认，沿用该段原字体）或 Arial / Times New Roman / Courier New；
    2. 字号数字框（4–200）、「B」加粗、「I」斜体、颜色块（取色器改文字颜色）、垃圾桶「删除这段文字」。
    3. 整段挪位置：鼠标按住编辑框边框拖动即可移动整段（提示「拖动边框移动整段文字」）。
    4. 提交与放弃：点击编辑框以外提交修改；按 Esc 放弃本次修改。
    5. 保存时改写才写盘（Ctrl/⌘+S）。个别页改写失败会被整页跳过并提示，不会损坏原文件——保存验证失败的提示原文：「第 {pages} 页的修改未能完整写回，已取消保存以保护原文件；请撤销该页的相关修改后重试」。

第 2 步 · 为什么叫「真文本编辑」（实现口径，用户视角）

1. 应用通过 PDFium 引擎（wasm）直接操作 PDF 的文本对象：定位选中文字对应的文本对象 ＞ 用 FPDFText_SetText 重写其文字 ＞ 删除/插入页面对象 ＞ FPDFPage_GenerateContent 重新生成页面内容流。改完后页面里就是新文字本身，能被搜索、复制、再次编辑。
2. 字体处理：先校验原字体的字符表（cmap）能否画出所有新字——能画就沿用原字体；画不全时自动从本机字体里找能画全部新字的字体，并把用到的字形子集化嵌入文件，保证在没装该字体的电脑上显示一致。
3. 极限情况：一段文字里混着没有任何字体能画的字符（如 emoji），会提示「没有字体能在 PDF 中绘制这段文字（暂不支持 emoji 等特殊符号）」。
4. 定位不到对应文字对象时提示「无法编辑这段文字：未能在文档中定位到对应的文本」；改完太长放不下时提示「编辑后的段落放不下：多出的文字会盖住下方内容。请缩短文字，或按 Esc 放弃修改」。

第 3 步 · 插入文字 / 插入图片（「编辑」页签）

1. 「插入文字」（提示「在 PDF 中插入可搜索的文字」）：弹出对话框输入内容、设字号/颜色/对齐（左对齐/居中/右对齐），确认后点击页面放置；插入的是与第 1 步同源的真文本对象，可再点选进行「编辑插入的文字」「删除插入的文字」。
2. 「插入图片」：选本地图片（png/jpeg/webp/gif/bmp）后点击页面放置；放置后可移动/缩放，并可选「置于文字上层」或「置于文字下层」。
3. 「编辑图片」（提示「点击页面上的图片：拖动移动、拖角缩放」）：点选页面上已有图片后可移动、缩放、旋转 90°、替换、删除、水平/垂直翻转、裁剪、「去除背景」（容差可调）与透明度。
4. 「水印」按钮打开「水印与页眉页脚」对话框：水印页签设文字（占位「如：机密、样本」）、角度、不透明度、字号；页眉页脚页签设左/中/右六格与「页脚居中显示页码」（可用占位符 {page} 当前页、{total} 总页数）。

第 4 步 · 涂黑（「注释」页签 「涂黑区域」＞「应用涂黑」）

1. 切到「注释」页签，点「涂黑区域」（提示「拖动以标记将永久移除的区域」），在页面上拖框，框住要抹掉的内容；可拖多个框。
2. 此时的框只是标记，还没删任何东西——保存原文档不会应用涂黑（界面提示原文：「涂黑未应用。点击“应用涂黑”可将这些标记应用到工作副本；普通保存不会应用这些标记。」）。点「清除标记」可全部撤销。
3. 点「应用涂黑」：先弹确认框「标记区域内的内容将被永久移除。继续后请在系统另存为对话框中选择新副本？」——确认后弹出系统保存对话框（标题「保存涂黑副本为」，默认文件名 原名-redacted.pdf）。
4. 选好位置后应用生成新副本并打开：副本里被标记区域的内容（文字/图片等页面对象）已从文件中物理删除，不是黑框盖住，拿不到被涂掉的原文；原文档保持原样不动。
5. 两个保护性拦截：还有其他未保存修改时提示「应用涂黑前请先保存其他待处理更改。」；有未应用的涂黑标记时改页面结构（删页/重排等）会提示「请先应用或取消待处理涂黑标记，再更改页面结构。」

## 如何确认操作生效

验证

1. 改一处文字并保存后：Ctrl/⌘+F 搜新文字能命中，搜旧文字不再命中；用鼠标能选中并复制到新字（证明是真文本而非图片）。
2. 涂黑验证：对含身份证号的区域涂黑并「应用涂黑」生成副本后，在副本上 Ctrl/⌘+F 搜该号码——无结果；把副本页面放大到最大，黑块下也没有残字。原文档打开检查，内容完好。
3. 插入文字后保存，用其他阅读器打开该 PDF，能选中复制插入的那句话。

## 什么情况下用得上

合同里写错一个日期/金额，只想改几个字，不想重做整份 PDF；对外文件涂掉敏感段，想在页面上补一句话、插一张图，或者给整份文件盖水印/页眉页脚，合同到期日改签。

用户常搜的问法：PDF 怎么改文字；PDF 涂黑之后别人还能恢复出来吗。

## 别在这几处栽跟头

功能归功能，这几个边界先摆清楚：

- 加密只读文档仅支持查看
- emoji 等特殊符号无法绘制
- .doc/.ppt 老格式明确不支持打开，需要先转成 docx/pptx
- AI 功能依赖已配置的模型（BYOK 或本地端点），未配模型时只有传统办公功能可用

## 接着回答几个常见问题

### 为什么有的文字点不开编辑框？

两种常见原因：该页是扫描图片（没有文字对象可定位，等 OCR 识别后可用问 AI/搜索，但仍不能改字）；或该段文字被做成了特殊编码/曲线，定位不到文本对象时会明确提示「无法编辑这段文字」。曲线字只能用涂黑+插入文字的方式重做。

### 保存时提示第 X 页修改未能完整写回？

这是保护机制：该页的改写没有通过写回校验，应用取消了整个保存、原文件未动。按提示撤销该页的最近修改（Ctrl/⌘+Z）后重试；仍失败可把该处内容删掉用「插入文字」重打一遍。

### 改完字以后字体变得和原来不一样？

「字体」下拉选了具体字体所致。改字时保持默认「原字体」即可沿用原字体；原字体画不全新字时应用会自动找本机替代字体并子集化嵌入。要求严格还原时，尽量只改动必要的字符。

### 涂黑的副本还能「撤销涂黑」吗？

不能。应用涂黑是物理删除，副本里已经没有那段内容，没有可恢复的原始数据。所以确认框才要求另存新副本、原文档不动——需要保留原始版本时记得别把原文件删了。
