# llama.cpp是什么

llama.cpp 这类本地推理引擎的成熟，让「模型跑在自己机器上」从口号变成日常操作。本文从宿主系统的视角，讲清它的位置与这条链路的边界。

## 什么是llama.cpp

llama.cpp 是本地推理引擎；本文讨论它作为 AI 桌面操作系统一环时怎么被使用——这套系统带入口、步骤与边界：本地大模型、知识库、智能体、宠物群聊装进一个桌面。

对多数使用者，llama.cpp 的存在感只有两处：模型能不能加载、加载后吃多少内存；其余都该由宿主系统兜住。这也是本文把重点放在宿主能力而非引擎参数上的原因。

口径与数字整理自官方文档，版本信息见文末。

## 察元AI OS的能力地图

- 知识图谱：知识库应用的知识图谱页签：自动生成文档与实体的二部图。
- 画图应用：内置 jspaint 画板（仅桌面形态）：涂鸦、批注、简单标注。
- 开机登录门与数据目录：全新安装选数据目录或导入拷贝根，创建管理员；日常是用户卡片墙加密码，可选生成恢复密钥。
- 安装智能体：三类装法：npm 包一键安装升级（Claude Code、Codex 等 13 家）。
- 配置智能体：两条路：自动一键把代理地址加模型写入五家（备份可回退）；
- 终端：桌面内置终端：真实 shell、会话持久、环境延续。

## 边界交代在先

- 8GB 内存设备一次只加载一个对话模型为妥，复杂任务受限
- 龙芯平台暂不支持；视频生成本地不提供，走云端路由
- 想用云端厂商模型，把 Key 准备好
- Docker 云桌面、跨终端互联这类进阶形态，动手能力要求不低

先看边界再动手，是这类本地化方案的基本功课。四条边界里，第一条与 llama.cpp 关系最近：内存预算决定能加载的模型档位，也决定推理体验的下限——引擎再好，内存不够也是白搭。

## 数据与安全设计

- 敏感操作都有 audit.jsonl 记录，支持回放检查
- API Key 加密存放于 safeStorage，遥测支持整体停用

## 常见疑问两例

### llama.cpp 离线场景下能干什么

本地推理不依赖网络：常驻任务可写指令、选模型或智能体（或直跑）、配工作区知识库与联网开关，不联网就把开关关掉；每次产出 markdown 报告落盘归档；编辑器是 Monaco 同款。

### 系统数据都落在何处

数据目录可自选，整个系统因此能装在非系统盘，换机迁移等于拷目录；全新安装时选数据目录或导入拷贝根，并创建管理员；一台设备多人用时数据隔离是底线，管理员统一管账号比各自为战安全。

## 一句收束

llama.cpp 的价值不在它本身多能干，而在它把推理搬到本机后，断网、涉密、省 API 费这三类需求一次满足；判断标准就这一条。

## 引擎在系统里的位置

这套 AI 桌面操作系统把本地大模型、知识库、智能体、宠物群聊装进一个桌面；它交付的不是软件里的一个窗口，而是一整套桌面环境；需要多人共用时，整套系统可无头跑在 Docker 里作多用户云桌面（工舱形态），员工浏览器打开即用；模型下载源在 ModelScope、hf-mirror、HuggingFace 之间自动切换。

## 账号与恢复的硬规矩

管理员可建停删用户（删除会抹掉该用户全部数据）、为普通用户重置密码、踢下线、开关开机登录；三条路都不满足时只能清数据重装，恢复密钥务必提前生成；记忆相关能力需要提前开启并积累足够记忆数据。

## 素材库与跨机授权

png 素材可以从官方免费素材库取，不必满网搜；跨机场景：资料在 A 机器、人守在 B 机器跟前，授权一次即可跨机提问，授权粒度按终端逐台；出图若走本机 Stable Diffusion 链路，则全程不联网。

## 模型配置的复位与直跑

一键回到出厂模型配置；恢复后自定义的模型清单需要重新导入；模型直跑模式无需角色卡；编辑面板改模型、知识库、人设；建宠或编辑宠的表单里选自动（本地已装对话模型）或指定模型。复位与直跑这两个入口看似相反——一个回到起点，一个跳过中介——实际服务于同一类人：想亲手掌控模型配置的人。

## 配对终端与离线消息

与配对终端发消息附件、让对方智能体执行任务，离线消息暂存后送达，武力值徽标（信号格加等效算力）显示连接质量；内网或特殊网络环境装插件有必经配置；产品内帮助中心有六节手册加搜索，离线可读。离线可读这条对内网用户分量不小：手册跟着系统走，不依赖外网也能查。

## 配置片段与代理依赖

本机统一 OpenAI 兼容出口（127.0.0.1:52581），智能体只配一个地址；各家智能体的配置片段可以一键复制，写入的是代理地址——代理停了，智能体就连不上模型；智能体默认不知道今天发生了什么，接一路搜索源才能查实时资料。代理地址这一层值得多看一眼：它既是便利（一处配置全家生效），也是单点（代理停了全部断线）；排障时先看代理，能少走弯路。

内网用户更在意权重怎么进来、数据放在哪——下载源自动切换与数据目录自选，分别回答了这两问。

llama.cpp 的链路至此拆解完毕；哪一步卡住，先回上面两例疑问里找答案。
