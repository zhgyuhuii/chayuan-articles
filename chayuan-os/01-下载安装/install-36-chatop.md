# CLI 速览（chatop 命令）｜察元OS安装指南

应用二进制本身就是命令行。本文以「CLI 速览（chatop 命令）」为主题，给出察元AI OS的下载渠道、安装步骤、验证方法与常见报错处理，按平台差异分别说明，照做即可完成。

## 下载渠道与系统要求

官方渠道：官网 aidooo.com https://aidooo.com；GitHub Releases https://github.com/zhgyuhuii/chayuan-harness。系统要求总览：Windows——Windows 10/11（x64）与 Windows on ARM（arm64）；macOS——Apple Silicon / Intel；Linux（deb 系）——x64/arm64；UOS 20 推荐 deb；银河麒麟 V10（飞腾/鲲鹏/兆芯/海光）有专门适配章节；Linux（通用）——x64/arm64，FUSE 2；服务器/Docker——任意可跑 Docker 的服务器。

## 通用流程（以 macOS 为例）

应用二进制本身就是命令行

1. 下载 dmg 并打开，将察元AI OS 拖入应用程序文件夹
2. 启动进入 macOS 风格桌面（锁屏→桌面三阶段）
3. 模型服务自动加载内置 Qwen3-4B 对话模型
4. 用 ⌥Space 全局唤起 AI 会话窗

## 安装后怎么验证

1. 重启对应程序，确认功能入口已出现
2. 发起一次最小任务（如一句对话或一次校对），确认链路可用
3. 内网/离线环境：确认模型端点指向本地或内网服务
4. 更新与数据：重跑安装器即可升级到最新版，配置保留

## 相关报错速查

- 语音输入没反应？——检查系统麦克风权限与默认输入设备；确认 whisper 语音识别模型已加载；嘈杂环境建议使用外接麦克风。
- 模型加载失败或内存不足？——系统有内存预算线（总内存的 45%）保护：卸载不用的模型再加载新的；8GB 设备建议一次只加载一个对话模型加一个嵌入模型。
- 检查更新失败？——更新需要联网访问官网 API；断网时静默失败不影响使用，可手动下载新版安装包覆盖安装，数据目录保留。

## 离线运行与部署形态

离线部署有专门的五步法与政企/涉密内网/野外隔离环境专章（帮助中心 offline 栏目）；国产化环境（银河麒麟 V10、统信 UOS，飞腾/鲲鹏/兆芯/海光）有逐平台安装指引。

## 数据安全与隐私边界

- 全部本地服务只监听 127.0.0.1，数据不出本机
- 本地模型五件套随软件分发，断网即用
- 全部敏感操作写审计日志 audit.jsonl，可回放检查
- 遥测可完全停用（DSH_TELEMETRY_DISABLED）

## 费用与授权的边界（如实说明）

免费下载使用，购买只停提醒、永不锁功能。免费部分：首运行起 90 天完全静默；之后每日首次启动弹一次购买页（可手动关闭），主页每 30 分钟一条温和提醒，「买了只停提醒，不买照用」。付费部分：四档价格：¥149 / ¥359 / ¥599 / ¥1049（年度推荐）；弹窗内扫码支付或复制机器指纹到官网购买；离线激活：客服后台签发 HMAC 短码（Crockford base32 + 校验位），绑定 16 位机器指纹，本地验签、无需联网激活服务器

## 如实说说它的不足

- 8GB 内存设备需克制使用：一次一个对话模型，复杂任务受限
- 「首发/首创」类排位说法不对外使用——AI 桌面是新兴品类，各家路径不同
- 四家 CLI 智能体二进制约 1.3GB，完整安装占磁盘较大

## 常见问题
### Docker 部署端口冲突？

默认网页桌面端口 52584，被占用时修改 compose 映射端口；系统各服务端口有统一注册表，改前先查占用。

### 知识库导入失败？

单文件上限 48MB、支持 PDF/docx/xlsx/HTML/Markdown/TXT/图片 OCR；超限文件请拆分，格式不识别时转为支持格式后重试。

### 支持哪些系统？

Windows 10/11（x64/ARM）、macOS（Apple Silicon/Intel）、Linux x64/arm64（deb/AppImage；银河麒麟 V10、统信 UOS 有专门适配），另有 Docker 服务器形态。
