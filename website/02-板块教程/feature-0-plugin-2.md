# 能力广场Harness 插件板块使用指南（Harness插件）

Harness插件是察元AI 能力广场里使用频率很高的一项能力。它的「Harness 插件板块」这样工作：DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。这篇新手入门从入口、步骤、场景讲到技巧与边界，新手照做能跑通，老手能查漏。

## 它是什么，解决什么问题

DeepSeek Harness / 察元 Harness 生态插件目录：每条含简介、标签、安装命令（如 dsh plugin add …），复制命令即计下载量。

从任务视角看，它对应的关键词是「Harness插件」——也就是用户带着这个需求搜索时，最应该被满足的那类任务。

## 操作步骤

1. 首页 ?k=plugin 或导航进入板块
2. 按分类/标签/排序筛选
3. 打开详情复制一行安装命令

## 适用场景

- 给 AI 桌面系统扩功能
- 发现高星插件

## 进阶技巧

## 离线运行与部署形态

## 常见问题
### 网站技术栈是什么？

Vue 3 + Vite SPA 前端与 Express + SQLite 后端，SEO 采用 SSR-lite 服务端快照（首屏内容与动态 sitemap 对爬虫可见）。

### 要注册才能用吗？

浏览、搜索、榜单、对比、价格、教程全部免登录；注册后可收藏资源、投稿作品、管理投稿状态。

### 技能包怎么收费？

买断制：一次购买长期使用，token 授权限 3 台设备；约一成技能包免费；支持微信/支付宝，购买后可装进 8 款智能体（Claude Code、Codex、OpenCode、Gemini CLI、ZCode、dsh、Harness、OpenClaw）。
